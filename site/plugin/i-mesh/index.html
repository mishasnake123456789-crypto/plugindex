What I-Mesh does

I-Mesh, short for Image Mesh, is a Blender add-on by Luwizart that creates 3D objects from a 2D picture. It generates depth information from the selected image and uses it to form the geometry, with procedural parameters to shape the outcome.

Images with alpha channels are supported, and one click produces clean UVs and a texture. As of the 3.3 update it runs offline with no internet connection and has a new, improved interface. It is handy for turning artwork, logos and photos into relief models.

Key features

  • Generates 3D objects from 2D images
  • Depth information created automatically
  • Procedural parameters for adjustment
  • Alpha channel support and one-click UVs
  • Offline operation since the 3.3 update
