What Search and Replace does

Search and Replace is a Premiere Pro panel from MoovIT for batch renaming. Enter the text to find, the text to put in its place and the range to search, and it updates every match in the names and metadata of video clips and markers.

Changes made by the replace function can be undone in one go, which makes experimenting safe. This is useful when a naming scheme changes midway through a project, or when a typo has spread through many markers. It supports Premiere Pro 7.0 and later.

Key features

  • Find text within a defined search range
  • Replace matches with new text
  • Covers clip names and metadata
  • Covers marker names and metadata
  • Undo all replacements
