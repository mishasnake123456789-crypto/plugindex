Blender add-on that chains Anim parent constraints so an object can follow one target after another without jumping.

What Objects Parenter - Constraints does

Switching what an object follows mid-animation usually makes it snap to a new place. Inlet's Objects Parenter - Constraints daisy chains Anim parent actions so an object finishes following one target and smoothly takes up the next.

It retains location through the handover, avoiding the break default constraints create, and follows bones as they are attached and re-attached with no custom pathfinding. This fits sequences like picking up and dropping a prop or passing it between characters.

Key features

  • Daisy-chained Anim parent actions
  • Location preserved when targets change
  • Follows attached and re-attached bones
  • No custom pathfinding needed
  • Suits grab and drop sequences
