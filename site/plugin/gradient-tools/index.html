Designs palettes and gradients on a 2D grid, then paints them onto meshes or vertex colors with no UVs needed.

What Gradient Tools does

Gradient Tools lets you design color ramps and paint them onto models in real time. Meshes, curve objects and vertex color layers are all valid targets, and no unwrapping is involved.

Paint with Project, Quick Snap, Freehand, Radial or Path tools, each showing a live preview on screen before you commit. A GPU preview redraws every frame, F inverts mid-drag, and a shortcut HUD appears on screen. Stylized and low-poly artists can color assets quickly.

Key features

  • Palette and gradient design on a 2D grid
  • Project, Quick Snap, Freehand, Radial and Path tools
  • Live GPU preview with shortcut HUD
  • No UV unwrapping needed
