Blender add-on that centralizes render engine, camera, HDRI and lighting setup for new projects.

What Setpro does

SetPro collects project setup into a single view in Blender so you do not repeat the same steps on every new file.

One-click configuration applies the render engine (Cycles or Eevee), HDRI, lighting and basic 3D model assets, while camera and general settings are managed from the same interface. It supports Blender 3.5 through 4.5.

Key features

  • One-click project configuration
  • Cycles and Eevee selection
  • Camera and general settings in one view
  • HDRI and lighting setup
