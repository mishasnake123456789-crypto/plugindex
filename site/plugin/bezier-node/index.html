What Bezier Node does

Plugin Everything's Bezier Node is a plugin built for After Effects aimed at drawing and animating curved lines. Curvature goes from completely straight to 1000 percent curvy, along either the X or Y axis.

A symmetry mode adds extra lines, and color and gradient fill are supported. Trim paths work with multi-line parameters, caps can be butt or round, and arc and pipe modes provide additional shapes. Start and end points have individual curvature, and an auto null layer control system makes them easy to steer. It is helpful for connectors, flowing strokes and abstract line art.

Key features

  • Curvature from straight to 1000%
  • Symmetry mode with extra lines
  • Color and gradient fill
  • Multi-line trim paths
  • Arc and pipe modes with auto null controls
