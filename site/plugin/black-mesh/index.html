What Black Mesh does

Black Mesh by Yey! offers a non-destructive voxel workflow for building complex hard-surface forms in Blender. It provides boolean voxels, smooth voxels and layers, and is aimed at sci-fi style modeling. It can also be paired with other boolean tools.

The workflow is a chain: add a Source object, then Booleans from objects or collections, then a Filter such as smoothing. Because each stage stays editable, artists can explore shapes and revise them without redoing work.

Key features

  • Boolean and smooth voxels
  • Layers
  • Non-destructive Source, Boolean and Filter chain
  • Combines with other boolean tools
