Blender mesh add-on with Relax++ and Taper++ operators offering more control than their modifiers.

What Operators++ does

Operators++ brings two modifier-like tools to the mesh itself in Blender, adding options their modifier versions lack for modeling.

Relax++ has per-axis control, a strength fade, 1 to 64 iterations and a Preserve Volume mode that reprojects onto the base mesh using several axis options, with Pin Corners and Preserve Sharp. Taper++ applies tapers to selected vertices with orientation, center and axis choices, adds a curve and minimum scale, and can limit positive and negative taper at a set distance.

Key features

  • Relax++ with volume preservation
  • Taper++ on selected vertices
  • Per-axis and strength controls
  • Limit Negative and Limit Positive clamps
