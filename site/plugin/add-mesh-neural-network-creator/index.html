What Add Mesh: Neural Network Creator does

Add Mesh: Neural Network Creator generates visualizations of neural networks in Blender, helpful for explainer videos, presentations and science communication. The networks are fully connected, and you can edit the connections afterwards.

Three creation modes exist: 2D quick, 3D quick, and a Geo mode built on Geometry Nodes. Quick mode offers spherical, cubic and disc neurons, while Geo mode accepts any mesh object. Neurons are instances, so changing one changes all, and synapses are separate objects for individual styling, with each network placed in its own collection. Educators and motion designers will find it saves manual layout.

Key features

  • Fully connected editable networks
  • 2D quick, 3D quick and Geo modes
  • Spherical, cubic, disc or custom neurons
  • Instanced neurons
  • Separate synapse objects
