What Twodphysics does

TwoDPhysics brings 2D rigid body simulation to Blender, whose built-in physics system is 3D-focused. A separate 2D engine means flat objects behave correctly without 3D workarounds.

It works alongside Grease Pencil and other 2D animation methods, and is available for Windows and Linux. Documentation is included and it is released under the GPL.

Key features

  • 2D rigid body simulation
  • Engine separate from 3D physics
  • Works with Grease Pencil
  • Windows and Linux support
