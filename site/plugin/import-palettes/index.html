What Import Palettes does

Import Palettes brings color palettes into Blender through the File, Import menu. It was one of the bundled add-ons in Blender 4.1 and is now distributed as-is.

It asks for access to the folder holding your palette files and comes with limited support. Painters and texture artists who store swatches outside Blender can load them for use in their painting palettes. The tool is a simple loader rather than a palette editor, which keeps it light for anyone maintaining shared color sets.

Key features

  • Imports color palettes
  • Available in File > Import
  • Requests access to palette folder
  • Carried over from Blender 4.1 bundle
