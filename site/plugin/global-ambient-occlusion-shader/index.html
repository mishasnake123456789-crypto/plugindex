What Global Ambient Occlusion Shader does

Global Ambient Occlusion Shader tackles the floating look that objects can get with ray-traced AO in EEVEE Next. It inserts an ambient occlusion shader into all materials in a project automatically, saving you from editing each node tree by hand.

You can apply it to every material in the scene or only those of selected objects, remove it again with one click, and optionally add a material to objects lacking slots. A debug mode helps with checking, and an N-Panel exposes strength, sample count and distance settings. Eevee artists seeking more grounded contact shading will find it a quick fix.

Key features

  • Adds AO shader to all materials automatically
  • Applies to the scene or selected objects only
  • One-click removal
  • Optional material for objects without slots
  • Strength, samples and distance controls
