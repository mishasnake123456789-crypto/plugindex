What False Colour does

False Colour, from NT Productions, assigns different colors to different brightness regions of an image. It is a luminance-driven effect in the vein of thermal or heat-map looks.

Adjustable blending controls and a randomise function help produce many variations quickly. It runs in After Effects and Premiere Pro, supports M1/ARM since version 1.1, and works with hosts back to CC 2014. It can be used for stylized grades, thermal-style looks, or simply to explore unexpected palettes quickly.

Key features

  • Luminance-based recoloring
  • Adjustable blending
  • Randomise values for varied looks
  • Works in After Effects and Premiere Pro
  • M1/ARM support from version 1.1
