What Halftone does

Halftone from Nx Color brings print-style dot patterns to DaVinci Resolve in the form of DCTL tools. It covers both black-and-white halftone treatments and full CMYK colour versions, giving colourists and editors a stylized finish without leaving the grading page.

Version 2.0 added macOS support via Metal and OpenCL, so it now runs on macOS, Windows and Linux. It is compatible with DaVinci Resolve 19 and 18, and access is immediate once you have it.

Key features

  • Monochrome halftone treatment
  • CMYK colour halftone
  • Built as DCTL tools for Resolve
  • macOS via Metal and OpenCL since 2.0
  • Windows, macOS and Linux; Resolve 19 and 18
