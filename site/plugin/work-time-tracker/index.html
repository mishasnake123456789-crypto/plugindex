Tracks work time in Blender automatically by project stage, pausing on idle and storing everything in the .blend file.

What Work Time Tracker does

Work Time Tracker detects activity in the scene, begins counting and pauses after a configurable idle timeout, so no manual start and stop is needed. All time is saved in the .blend file.

Project stages divide the total into named phases such as Modeling, Texturing and Rigging. This makes it easier to see where hours go on a project, estimate future work and report time to clients. The running breakdown helps with estimating future jobs and with reporting how long each phase actually took.

Key features

  • Automatic activity detection
  • Configurable idle timeout
  • Named project stages like Modeling and Texturing
  • Time stored inside the .blend file
  • No manual start/stop
