Blender add-on for procedural, repeatable bends of mesh geometry using an automatic geometry nodes modifier.

What Bender - Simple Bend Add-On does

Bender lets you bend meshes in Blender while keeping every bend editable. Because the process is procedural, you can return later to adjust any bend, and a single object can be bent multiple times, each bend selectable from a list.

A reference plane and a limit plane define what is bent, with an option to bend both sides and negative angles for the opposite direction. A gizmo built from mesh geometry can be hidden. Everything is controlled from the 3D View side panel, which adds a geometry nodes modifier automatically. A user manual is included.

Key features

  • Procedural bends that stay adjustable
  • Multiple bends per object
  • Reference and limit planes
  • Hideable bend gizmo
  • Side panel control, user manual included
