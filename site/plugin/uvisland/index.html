Slices atlas textures into separate planes from Blender's UV Editor using black-and-white or alpha detection.

What Uvisland does

Uvisland converts a sprite or texture atlas into individual planes. With the atlas open in the UV Editor, a click separates each element so you can keep working with it or use it right away.

Two detection modes exist: one reads a black and white atlas, the other reads an alpha channel. They work with opacity maps or the alpha of a PNG file. Artists handling foliage cards, decals or sprite sheets can quickly produce separate meshes.

Key features

  • One-click atlas slicing
  • Atlas textures turned into planes
  • Black-and-white and alpha detection
  • Works from the UV Editor
