What Bezier Curve Editor does

Bezier Curve Editor lets you shape keyframe easing right in Blender's timeline. Moving control points on its graph shapes custom curves that you assign to chosen keyframes.

Auto Apply previews changes in real time, elastic curves are supported, and frequently used curves can be saved as presets. Animators who want expressive timing without opening the Graph Editor can adjust motion quickly. Saved curves can be reused across animations so a project keeps consistent timing and feel.

Key features

  • Drag control points in the timeline
  • Auto Apply live preview
  • Elastic curve support
  • Save frequently used curves
