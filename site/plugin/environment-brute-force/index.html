What Environment Brute Force does

Environment Brute Force is a Blender add-on for finding which HDRI suits a scene without trying each one manually. It automates a tedious comparison before the final render.

Point it at a folder of environment images and it applies them one after another, rotating each a full 360 degrees across a frame range you set, with the number of frames per image adjustable. Rendering the sequence with Ctrl+F12 produces files named with the image and the rotation angle, making it easy to review the results. Documentation is included.

Key features

  • Loops through a folder of environment images
  • Full 360 degree rotation per image
  • Configurable frames per environment
  • Output files named by image and angle
