What Qol Tools: Hud-Dimensions does

QOL Tools: HUD-Dimensions shows the true size of the selected objects as a permanent overlay, so you can check measurements without opening the N panel.

HUD position and color are customizable, and a hotkey button lets you set an object's size directly regardless of scale. A warning color flags objects with an incorrect scale, which helps catch texture problems early. It is offered in the Blender 4.2 extension format and includes documentation. It suits modelers who care about real-world proportions.

Key features

  • Always-on dimension overlay
  • Customizable placement and color
  • Set size via hotkey independent of scale
  • Warning color for wrong scale
