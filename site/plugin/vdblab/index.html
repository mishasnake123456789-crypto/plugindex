What Vdblab does

VDBLab is a Blender tool from BeFX Studios dedicated to creating explosions. It gives you emitters, domain settings and a shader in one package, so you can set up a blast without assembling the pieces yourself.

Explosions can be saved as presets, and the tool covers styles such as shockwaves, aerial bursts and debris. Documentation is included, it is released under the GPL license, and it works with Blender 3.5 up to 5.1. Artists producing explosion effects will find it most useful.

Key features

  • Emitters, domain settings and shader included
  • Save explosions as presets
  • Shockwave, aerial and debris styles
  • Documentation included
  • Supports Blender 3.5 to 5.1
