Retopology toolkit for Blender with a display shader, quad strips, face fill and loop tools.

What Jretopo Tools does

Jretopo Tools helps build clean, production-ready topology over high-resolution models in Blender. A dynamic retopo shader draws the new mesh above the sculpt, with adjustable colors, transparency and line thickness.

The Create tool lays down the initial mesh, Quad Strip adds smooth, even strips with mouse clicks, and Face Fill detects open areas and fills them with tris, quads and caps, including a mode that suggests a fourth point. A Loops tool completes the set. It suits character and hard-surface artists converting sculpts or scans into usable meshes.

Key features

  • Dynamic retopo overlay shader
  • Create tool for the first mesh
  • Quad Strip drawing by clicks
  • Face Fill with tris, quads and caps
  • Loops tool
