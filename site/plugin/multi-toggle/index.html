What Multi-Toggle does

Multi-Toggle extends Blender's visibility controls so you are not forced to click each item separately. Select a group of objects or collections, then apply a toggle from either the 3D Viewport or the Outliner.

It covers Exclude from View Layer for collections, Disable Selection, Hide in Viewport, Disable in Viewport and Disable in Renders. This fills a gap in the default interface, where several of these states cannot be changed in bulk. Scene organizers and anyone with crowded outliners benefit most.

Key features

  • Bulk toggling for objects and collections
  • Works in the 3D Viewport and Outliner
  • Handles exclude, select, hide and render states
  • Fills a gap in the default interface
