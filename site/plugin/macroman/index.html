What Macroman does

MacroMan stores snippets of Python code as macros that call Blender's Python API, so repetitive tasks can be automated without leaving the app. Macros are created and edited in the default Text Editor panel, avoiding external script management.

They are reachable through a keybindable menu, or you can give individual macros their own shortcuts. Each macro is saved on disk as a .py file, which makes external editing, organization and backup simple. It suits technical artists and scripters who want a lightweight way to keep handy automation at their fingertips.

Key features

  • Create and edit macros in the Text Editor
  • Keybindable menu and per-macro shortcuts
  • Stored as plain .py files
  • Full Blender Python API access
