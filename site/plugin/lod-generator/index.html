What Lod Generator does

dreamyartworld.com's LOD Generator automates level-of-detail creation in Blender. It produces as many as eight LODs, LOD0 through LOD7, each with its own toggle, retaining UVs, volume and materials.

A real-time distance preview switches LODs by camera. Smart Export v2 supplies presets per engine and also creates metadata for Unity prefabs, Unreal blueprints and AR/VR manifests, with industry profiles for targets like mobile. Game and XR developers get consistent optimized assets without decimating each by hand.

Key features

  • Up to 8 LOD levels with toggles
  • Real-time LOD distance preview
  • Smart Export v2 engine presets
  • Unity, Unreal and WebXR metadata
  • Industry profile presets
