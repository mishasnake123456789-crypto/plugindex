What Grease Pencil QuickTools_ does

Grease Pencil QuickTools places commonly used Grease Pencil actions into a single N sidebar panel in Blender. Selecting a tool switches to the appropriate mode automatically, and brush colors are unified.

QuickTaper thins the points of selected strokes toward their ends, with Shift for taper in only and Ctrl for taper out only. Other quick tools sit alongside it. 2D animators and illustrators drawing in Blender can work with fewer menu trips. Keeping the commonly used tools in one place reduces repeated mode changes while drawing, which helps during fast sketching and animation passes.

Key features

  • Tools grouped in the N sidebar
  • Automatic mode switching
  • Unified brush colors
  • QuickTaper for stroke thickness
