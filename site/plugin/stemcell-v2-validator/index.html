What Stemcell V2 Validator does

Stemcell V2 Validator is a Blender add-on for artists who sell or submit models to TurboSquid and need them to meet the StemCell v2 Specification. It inspects the model and reports where it falls short.

Findings are grouped into clear categories with detailed feedback, and many requirements can be corrected automatically with the add-on's auto-fix. It supports Blender 4.0 through 4.5, ships with documentation and is released under the GPL license. Running it before submission can save time otherwise spent on rejected uploads and manual cleanup.

Key features

  • Checks models against StemCell v2 rules
  • Auto-fixes issues that can be corrected automatically
  • Categorized, detailed issue reports
  • Works with Blender 4.0 to 4.5
  • Documentation included
