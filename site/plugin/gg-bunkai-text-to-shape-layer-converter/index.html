What GG Bunkai - Text to Shape Layer Converter does

GG Bunkai changes text layers into shape layers in After Effects, so letterforms can be animated with shape tools such as path operations. It can keep the text as one shape layer or break it apart.

Splitting choices include by line, by word at spaces and line breaks, by character, and by each structural separation within a character. Every resulting shape layer gets a centred anchor point, which makes animating pieces easier. An option disassembles each connected path for even finer control.

Key features

  • Converts a text layer to one shape layer
  • Splits by line, word or character
  • Splits at structural separations of glyphs
  • Centred anchor point on every piece
  • Option to disassemble connected paths
