What Path Distribute does

Path Distribute is a MAXScript utility by Martin Breidt for arranging selected objects along a curve in 3ds Max. The objects are spread out evenly, saving you from placing and measuring each one by hand.

The distribution stays live: when the curve is later modified, the objects retain their relative positions along it, so a layout can be revised freely. It is a simple tool suited to fences, lamp posts, beads, chain links and similar repeated items. It is documented for 3ds Max 5 and 6, so it comes from an earlier era of the software.

Key features

  • Distributes selected objects evenly along a curve
  • Objects keep relative positions when the curve changes
  • Provided as a MAXScript utility
  • Works with 3ds Max 5 and 6
