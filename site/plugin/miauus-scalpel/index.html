What miauu's Scalpel does

Scalpel is a 3ds Max script by miauu that subdivides geometry interactively by drawing cut lines. Each cut starts at a vertex or edge, and snapping options keep the result precise: nearest vertex, edge midpoint, set angles, or an exact position along an edge.

Positions can be set by percentage, down to 0.5 percent, or by system units, down to 0.01. Perpendicular cuts are possible relative to the snapped edge or the edges the cut begins from, and a default QuickSlice mode snaps to preset angles. An on-screen readout gives the cut position in percent, the distance to each end of the edge and the full edge length, and Snap Step and Snap Angle can be changed during the cut. It works on Editable Poly and Edit Poly.

Key features

  • Snap to nearest vertex or edge midpoint in Auto or Manual mode
  • Precise cuts by percentage or system units
  • Angle snapping and perpendicular cuts
  • Heads-up display with cut position and edge lengths
  • Works on Editable Poly and the Edit Poly modifier
