What ToothPaste (Paste SVGs) does

ToothPaste lets you copy vector art in a design app and paste it into Blender directly, with no saving or import dialogs. It works with Grease Pencil, Curves, Text and images.

Pasting as Grease Pencil keeps top-level groups as layers with names, and rebuilds masks and clipping using layer masks and holdout. SVG paths can become native curves, text elements become real font objects, and bitmaps become a mesh plane or reference. Fill and stroke map to materials with partial gradient support. It was tested with Affinity Designer, Illustrator, Figma and Inkscape.

Key features

  • Paste SVG straight from the clipboard
  • Grease Pencil with layers and masks
  • Native curves and font objects
  • Bitmaps as mesh planes or references
  • Tested with Affinity, Illustrator, Figma and Inkscape
