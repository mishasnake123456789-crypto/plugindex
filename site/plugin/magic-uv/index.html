What Magic UV does

Magic UV is a collection of UV editing tools for Blender developed by nutti. It was once bundled with Blender 4.1 and is now an extension supplied with limited support.

Version 6.7.1 fixed the conversion from add-on to extension. Settings are found in the Add-ons Preferences, and it can be installed by dragging it into Blender or from disk. No special permissions are needed and it is released under GPL v2 or later. Texture and game artists working with UV maps can use its extra operations beyond the defaults.

Key features

  • UV toolset for Blender
  • Version 6.7.1 fixes extension conversion
  • For Blender 4.2 LTS and newer
  • Configured in Add-ons Preferences
