What Autokey Highlight does

Autokey Highlight is a Blender add-on by Lauloque that gives a clear visual warning when automatic keyframing is active. While Autokey is enabled, the viewport gets a red border, and the border follows the current Autokey state.

This prevents accidental keyframes when you move objects without realizing recording is on. The border color and width can be customized in the add-on preferences. It is released under the GNU GPL v3 or later, requires no special permissions, and supports Blender 4.2 LTS and newer.

Key features

  • Red viewport border while Autokey is on
  • Border follows the current Autokey state
  • Customizable color and width
  • Requires no special permissions
  • Supports Blender 4.2 LTS and newer
