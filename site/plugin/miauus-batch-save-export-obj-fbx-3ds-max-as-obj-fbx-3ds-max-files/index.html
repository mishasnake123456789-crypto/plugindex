What miauu's Batch Save/Export OBJ/FBX/3DS/MAX as OBJ/FBX/3DS/MAX files does

This miauu script batch-converts OBJ, FBX, 3DS and MAX files in 3ds Max, saving or exporting them to any of those formats. A list with checkboxes decides which entries are processed, including which ones are written out as MAX files, and the Max version used for saved files can be chosen.

Get Directory loads every supported file in a folder, optionally with subfolders, and Get File(s) allows picking several files. Right-clicking an entry opens its folder in Windows Explorer, and middle-clicking removes it. A Show Full Path option and a resizable interface complete it. It is handy for converting asset libraries in bulk.

Key features

  • Batch save or export between OBJ, FBX, 3DS and MAX
  • Checkbox list of files to process
  • Choose the 3ds Max version for saved MAX files
  • Load a whole folder, optionally with subfolders
  • Right-click opens folder, middle-click removes entry
