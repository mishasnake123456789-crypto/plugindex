What BtnHook does

BtnHook is a tool by Terrible Junk Show that turns the buttons in After Effects script panels into shortcuts. Many scripts offer buttons but no keyboard access, and this bridges that gap.

It operates within the After Effects interface and is compatible with versions 2020 through 2026. The release is version 1.0, and a demo video is available. People who rely on many ScriptUI panels can speed up repeated actions by assigning keys to buttons.

Key features

  • Creates shortcuts from UI script buttons
