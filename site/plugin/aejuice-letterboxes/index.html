What AEJuice Letterboxes does

AEJuice Letterboxes is a set of letterbox bars for adding a film-style frame to any project. Choose a still bar, an animated one, or a grain variant, and drop it over your footage in After Effects, Premiere Pro, DaVinci Resolve or another editor.

Every letterbox is supplied in 4K ProRes. Size and colour can be adjusted, and the AEJuice Pack Manager provides fast previews, drag-and-drop import and favourites. Editors working on music videos, commercials and similar footage can give clips a cinematic feel in seconds, with grain versions for those wanting texture in the bars.

Key features

  • Still, animated and grain letterboxes
  • 4K ProRes for every letterbox
  • Adjustable size and colour
  • Drag-and-drop application
  • Pack Manager with preview and favourites
