Blender add-on that keeps primitive parameters editable after creation in the Object tab.

What Paramix does

Paramix exposes the creation settings of mesh primitives in Blender's Properties editor, so they can be changed non-destructively afterward. It suits fast prototyping and iterative design.

It works with Torus, Sphere, Cylinder, Cone and Circle primitives added through Shift+A > Mesh, adding a panel in Properties > Object for segments, radii, depth, fill types and more.

Key features

  • Editable primitive parameters after creation
  • Torus, Sphere, Cylinder, Cone and Circle
  • Panel in Properties > Object
  • Non-destructive changes
