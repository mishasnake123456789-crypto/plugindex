What Verticality Vertex Measure does

Verticality Vertex Measure is a Blender add-on by saiwfy dedicated to one job: finding how tall an object is relative to a given plane. It concentrates on vertical distance within the scene.

The listing mentions documentation, a demo video and a GPL license, and it is marked for Blender 3.6. It is a small utility for modelers and layout artists who need a quick height check without setting up manual measurement tools.

Key features

  • Measures object height relative to a plane
  • Focused on vertical distance
