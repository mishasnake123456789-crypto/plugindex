What Beantextures does

Beantextures is a Blender add-on by daringcuteseal that generates shader node groups able to switch between images, and exposes the image index in pose mode. This gives 2D texture rigs animatable controls without wiring drivers by hand.

Four ways of indexing are offered: simple integers, bounded integers, bounded floats and enum dropdowns. The node groups use native stacked mix nodes, and the index property can be opened from a pie menu or a list popup with custom icons and a sortable order. It can also output the alpha of the active image.

Key features

  • Four image indexing types
  • Generates native image-switching node groups
  • Image index in pose mode via pie menu or list
  • Custom icons and sortable property order
  • Alpha output of the active image
