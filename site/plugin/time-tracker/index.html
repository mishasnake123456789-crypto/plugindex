Blender add-on that logs time spent in each blend file, tracks sessions and detects inactivity.

What Time Tracker does

Time Tracker records how long you work in each blend file. It creates a session every time a file is opened and extra sessions if it is reopened on the same day.

A stop-and-go function runs from a modal operator with hand-operated pause and continue, idle is detected, and a detailed sortable overview is shown. Freelancers who bill by hours and studios checking project effort can see where time goes.

Key features

  • Per-file session logging
  • Pause and continue controls
  • Inactivity detection
  • Sortable time overview
