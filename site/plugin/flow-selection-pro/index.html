A Blender selection tool putting box, lasso, circle, tweak and topology selection on one button.

What Flow Selection Pro does

Flow Selection Pro replaces Blender's selection tool switching with a gesture-driven system on a single button. Dragging from empty space chooses between Box, Lasso and Circle depending on direction, and a live preview shows what will be selected as you drag. It behaves the same on mouse, pen or trackpad.

The Circle brush resizes with a double click, while single click, double click and Tweak share the same button. In Edit Mode, topological gestures include Loop, Shortest Path, Coplanar, Checker Deselect, Loop-Span and Boundary Loop. Modelers who select constantly will cut down tool changes.

Key features

  • Box, Lasso and Circle from one drag
  • Live selection preview
  • Circle brush resized by double click
  • Edit Mode loop, shortest path and coplanar gestures
  • Consistent on mouse, pen and trackpad
