What Chromalight does

ChromaLight is a Blender add-on that studies a reference image, pulls out its dominant colors and brightness levels, and uses them to light your scene. It saves the trial-and-error of matching a mood by eye, and it adjusts the world background so the whole frame stays consistent.

Run it to generate a fresh set of lights, or point it at existing lights and update them to a new palette. After generation, light strength, hue and world exposure remain editable for fine tuning. Palettes can be stored and recalled later, which helps when you want several scenes to share the same look.

Key features

  • Extracts key colors and brightness from a reference image
  • Generates balanced lights from the palette
  • Updates existing lights to a new reference
  • Syncs the world background color
  • Saves and recalls palettes
