What AnimLayerCleaner does

AnimLayerCleaner tackles a hidden performance problem in 3ds Max. Some animation layers become bugged and can drag down scene performance without producing any error messages, which makes them hard to track down.

The script detects those layers and cleans them out of the scene. It is written entirely in MAXScript, installs through Run Script or by dragging into the viewport, and can be placed on a toolbar button through Customize User Interface. It is released under the MIT license. Animators and riggers dealing with mysteriously slow scenes may find the cause here.

Key features

  • Detects bugged animation layers
  • Cleans problem layers from the scene
  • Written in MAXScript
  • Run Script or drag-and-drop installation, with toolbar button
  • MIT license
