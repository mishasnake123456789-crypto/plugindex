What Clutter Zones does

Clutter Zones dresses shelves, tables and similar spaces in Blender by packing assets into a box you can resize. It respects real object bounds to avoid collisions.

Items can be stacked across multiple levels, with adjustable density, gaps, rotation and stacking levels. The results show no interpenetrating geometry. Placement uses instances, so it is non-destructive and light on memory with materials preserved, and Live Update shows changes while you resize. Documentation is included.

Key features

  • Packs assets inside a resizable box
  • Multi-level stacking
  • Density, gap and rotation controls
  • No interpenetrating geometry
  • Instance-based, Live Update preview
