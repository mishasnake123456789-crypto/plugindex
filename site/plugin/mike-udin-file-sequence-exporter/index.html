What Mike Udin File Sequence Exporter does

Mike Udin File Sequence Exporter turns an animated Cinema 4D scene into a numbered series of files, one per frame. The output can then be loaded as animated geometry in other graphics packages.

Two formats are offered: Cinema 4D .c4d, which works best with Element 3D, and Wavefront .obj for Stardust and Plexus. The author notes that it handles many animated scenes where other plug-ins and scripts fail. Motion designers who pass 3D animation into After Effects tools will find it a reliable bridge.

Key features

  • One .c4d or .obj file per frame
  • c4d format suited to Element 3D
  • OBJ format for Stardust and Plexus
  • Works on any animated Cinema 4D scene
