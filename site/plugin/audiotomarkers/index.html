After Effects script that turns audio intensity into layer markers, layer splits or incrementing numbered text.

What AudioToMarkers does

AudioToMarkers by Lloyd Alvarez converts the loudness of a track into useful edit points inside After Effects. It reads the keyframes produced by the Convert Audio to Keyframes assistant and acts on peaks in intensity.

Based on those peaks it can place markers on a layer, split the layer, or create a text layer with numbers that increase. A minimum-frames-before-cut setting prevents cuts from being too close together, Sound Keys is supported, and a Refresh button updates the layer list if a layer is missing. Editors can use it to cut footage to music or dialogue rhythm.

Key features

  • Markers placed from audio intensity
  • Splits layers based on intensity
  • Creates incrementing numbered text layers
  • Minimum-frames-before-cut setting
  • Sound Keys support
