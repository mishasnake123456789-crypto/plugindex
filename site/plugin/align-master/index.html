Aligns multiple selected Blender objects along the X, Y or Z axis with adjustable spacing and optional reverse order.

What Align Master does

Align Master is a simple Blender add-on for lining objects up neatly. Choose an axis and the selected objects are placed in a row, taking their position from the first object you picked.

An offset value sets the gap between them, with positive numbers spacing in one direction and negative ones the other. A reverse option starts from the last selected object instead. The controls live in the Item tab of the 3D Viewport sidebar, making it a quick tool for layout, display arrangements and tidying scenes.

Key features

  • Align along X, Y or Z
  • Custom offset for spacing
  • Negative offsets reverse direction
  • Reverse order option
  • Panel in the Item tab of the sidebar
