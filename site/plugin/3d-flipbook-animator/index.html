What 3D Flipbook Animator does

3D Flipbook Animator turns a Blender collection of meshes into a single flipbook-style animated object, driven by Geometry Nodes so only the current frame shows. It supports pure frame-by-frame work and a hybrid mode that adds morph-blended inbetweens.

Animated meshes, curves, metaballs and text can be extracted into sequential snapshots, including setups that keep armature modifiers and vertex groups. GPU onion skinning shows previous and next frames in red and green. Morph blending interpolates vertices between two frames with easing, and a vertex clipboard supports blended pasting. Range tools delete, duplicate, reverse or ping-pong frames, which also helps when editing Alembic or simulation caches.

Key features

  • Collection to flipbook conversion
  • Extraction of animated geometry into frames
  • GPU onion skinning
  • Morph blending with easing
  • Delete, duplicate, reverse and ping-pong ranges
