What Renderboost Addon does

RenderBoost Addon, from Omega VFX Ltd, shortens animated renders in Blender through frame interpolation. It creates additional frames out of an image sequence you already have, meaning fewer frames require direct rendering.

The number of interpolated frames is adjustable, letting you balance smoothness against computing cost. It can create the video automatically, and command line support arrived in version 0.1.1. It is designed for Blender 4.1 and 4.2. Useful for previews or projects where render time is the bottleneck.

Key features

  • Interpolates frames from an image sequence
  • Adjustable number of interpolated frames
  • Automatic video creation
  • Command line support since 0.1.1
  • Designed for Blender 4.1 and 4.2
