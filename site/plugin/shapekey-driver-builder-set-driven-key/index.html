What Shapekey Driver Builder - Set Driven Key does

Shapekey Driver Builder gives riggers a simple interface for creating shape key drivers without digging through Blender's driver editor. It suits facial rigs, corrective shapes and muscle flex.

Facial shape keys can be hooked to armature bones, and a position can be recorded to trigger a shape key at a given value. Driver keyframes are set across several shape keys in a few clicks, and Flip Driver mirrors a setup to the other side when names follow a convention. Finished files keep working without the add-on installed.

Key features

  • Shape key drivers without the driver editor
  • Flip Driver mirrors left and right setups
  • Records trigger positions for corrective shapes
  • Files work without the add-on installed
