What New Object From Selected Geometry does

New Object From Selected Geometry builds a new object from whatever geometry you select in Edit Mode.

It can take geometry from several objects, handy for bridging gaps between objects or tracing lines, and offers options to create from faces. Modelers making patches, bridges and splits get a quick way to create a clean separate mesh. Creating geometry separate from the source avoids altering original meshes, and it is quick for patching holes, building trim or tracing outlines.

Key features

  • New object from Edit mode selection
  • Works across different objects
  • Fill gaps or trace lines
  • Face-based creation options
