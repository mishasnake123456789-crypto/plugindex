Real-time histogram and vectorscope overlays for Blender's viewport color.

What Viewport Scopes does

Viewport Scopes provides live histogram and vectorscope readouts of what you see in the viewport. The histogram shows RGB and Luma channels with zoom, while the vectorscope shows hue and saturation in real time.

The add-on recognizes the composition node tree and can draw viewport color into an image texture so Blender's native scopes, such as the waveform, can read it. It supports exposure and grading decisions while you work.

Key features

  • RGB and Luma histogram with zoom
  • Live vectorscope
  • Composition node tree recognition
  • Feeds native scopes via image texture
