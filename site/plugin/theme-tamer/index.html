Blender add-on for searching, grouping and batch-editing theme properties, then saving the result as a theme.

What Theme Tamer does

Theme Tamer eases creating custom Blender interface themes. Properties can be searched and automatically grouped by color from your favorite themes, by their labels or into groups you define.

Each group can be edited as a batch, a color-based filter helps pick properties directly from the UI, and finished work is saved as a theme through Blender. Interface customizers no longer have to adjust hundreds of values one at a time.

Key features

  • Auto-group by color, label or custom groups
  • Batch-edit properties by group
  • Color-based property picking from the UI
  • Save as a Blender theme
