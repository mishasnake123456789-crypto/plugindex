Set of Blender time-savers: object vault, instant nodes and floor, one-click HDRI and hidden-object finding.

What Kronos does

Kronos removes small time sinks from everyday Blender work. Vault stores objects outside the blend file, which reduces clutter and scene lag, while Instant Nodes adds up to fifteen nodes to the shader editor.

Instant Floor places an adjustable floor under the selected object wherever it sits, and an HDRI tool sets up lighting in one click with adjustable rotation and brightness. Tools for finding hidden objects are included. Generalists who build quick scenes will cut a lot of repetition.

Key features

  • Vault backs up objects outside the file
  • Instant Nodes adds up to 15 shader nodes
  • Instant Floor under any object
  • One-click HDRI setup
  • Hidden object finder
