Blender add-on running a non-blocking task-queue baking pipeline over materials, bake passes and frame ranges.

What Sequenced Bake does

Sequenced Bake processes bakes in Blender as a queue of tasks while keeping the interface responsive.

Execution is modal and timer-driven, so Blender does not freeze. The queue is assembled from materials (active or all), the enabled bake types and a frame range, run by a modal task scheduler. Artists baking many passes across frames can continue working meanwhile. The queue approach is practical for long jobs, since passes and frames run one after another and the artist can keep inspecting or editing the scene while they finish.

Key features

  • Non-blocking modal execution
  • Queue from materials, bake types and frames
  • Task scheduler engine
  • Responsive interface during bakes
