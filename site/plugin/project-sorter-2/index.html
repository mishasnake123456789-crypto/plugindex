What Project Sorter 2 does

Project Sorter 2 from Leyero takes over the housekeeping of imported media, ordering items in After Effects and Premiere Pro by rules, and in After Effects it can mirror an existing folder structure.

Sorting criteria include media type, duration, use count, resolution, aspect ratio, alpha channel and audio sample rate. Actions can move items inside the project, move files on disk, or add and update metadata, and a conflict system handles clashing parameters. Items can be dropped in, a split view compares two presets, archives can be unzipped before import, and downloads into linked folders can import themselves.

Key features

  • Rule-based sorting by media type, duration, resolution and more
  • Move items in the project or on disk
  • Add or update metadata
  • Split view comparing two presets
  • Auto-unzip and auto-import from linked folders
