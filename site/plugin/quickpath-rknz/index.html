Lightweight Blender add-on that shows live motion paths for bones and objects and updates them as keyframes move.

What QuickPath RKNZ does

QuickPath RKNZ visualizes the motion of bones and objects directly in Blender. Paths recalculate in real time whenever you move a keyframe, and a toggle at the top of the panel turns the live update on or off.

Each entry can be customized individually, with its own color, line width and dot markers, so several trajectories stay readable together. Animators use motion paths to check arcs and spacing, and this tool keeps them current without manual recalculation.

Key features

  • Real-time live path updates
  • Toggle for live update
  • Tracks bones and objects
  • Per-entry color, line width and dot markers
