A Premiere Pro panel for FlowCaster.live group review sessions, with live comments, drawing and marker management.

What FlowCaster.live does

FlowCaster.live connects the editor to a group review and approval session. The panel shows the same video the group is watching, along with real-time telestration and text comments, rather than in a separate window.

New comments and drawings can optionally become timeline markers. Offline, it can load and save Premiere CSV markers, Avid XML markers and Resolve EDLs, or clear a sequence's markers. Sessions can be saved and reloaded after they end.

Key features

  • Live group review inside Premiere Pro
  • Real-time telestration and comments
  • Optional markers from feedback
  • Load and save Premiere, Avid and Resolve markers
  • Save and reload sessions
