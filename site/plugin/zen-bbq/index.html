Blender add-on for creating and previewing bevels via the Cycles Bevel Shader Node, stored non-destructively in mesh attributes.

What Zen Bbq does

Zen BBQ provides fast control over bevels in Blender by working via the Cycles Bevel Shader Node. Values are saved in mesh attributes, so the geometry itself is never modified.

Bevel values can be applied to a whole model or to single edges and vertices, in the full range of units from millimetres to kilometres, inches and feet. Custom preset groups help reuse settings. Hard-surface artists can get soft, light-catching edges in renders without actual bevel geometry.

Key features

  • Full control of the Bevel Shader Node
  • Per-edge and per-vertex values
  • Wide range of measurement units
  • Custom preset groups
  • Non-destructive attribute storage
