Blender add-on that copies the active node into every material of the selected objects to prepare multi-material baking.

What Bake Node Sync does

Bake Node Sync tackles a chore that comes up whenever several materials share one bake. It takes the active node and syncs it across every material on the selected objects, finding the matching node in each one or creating it where it is missing.

That keeps image targets and similar nodes consistent without opening each material by hand, which is useful for multi-material baking and texture workflows. It works with Cycles and Eevee on Blender 4.5 through 5.1, and documentation is included.

Key features

  • Syncs the active node across all materials of selected objects
  • Finds the matching node in each material
  • Creates missing nodes automatically
  • Works with Cycles and Eevee
  • Supports Blender 4.5 to 5.1
