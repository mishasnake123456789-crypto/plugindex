What Anicam does

Anicam is a Blender add-on that makes render resolution animatable, something the default Dimensions settings do not allow. It suits sequences where the frame size has to change partway through.

A panel in the 3D Viewport's N sidebar offers resolution fields synced with Blender's Dimensions. Keyframe them with the I key and the curves appear in the Graph Editor and Nonlinear Animation windows. Resolution can also be driven by timeline markers, changing as the playhead passes each one, and a Render Sequence button outputs frames at the animated sizes.

Key features

  • Animatable resolution fields in the N panel
  • Keyframes visible in the Graph Editor
  • Resolution changes driven by timeline markers
  • Render Sequence button for animated sizes
