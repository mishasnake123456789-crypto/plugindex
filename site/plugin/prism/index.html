What Prism does

Prism is a render pass manager written in native 3ds Max script, making it simple to install and set up. It simplifies how passes are created and organized, allowing an unlimited number of passes inside a single output file, each with its own range of settings.

A file naming template system makes rendered output easy to locate. Jobs can go to a network through Autodesk Backburner or Thinkbox Deadline, and nothing extra needs installing on the farm computers. Popular render engines such as V-Ray 3.0 and Corona are supported, so artists who split scenes into passes for compositing can keep everything controlled from one place.

Key features

  • Unlimited render passes in a single output file
  • Wide range of settings per pass
  • File naming template system
  • Network rendering through Backburner and Deadline
  • Supports V-Ray 3.0 and Corona
