Blender toolset that measures, matches and visualizes texel density across meshes and texture sizes.

What Texel Density Checker does

Texel Density Checker helps keep texture resolution consistent between Blender objects. It calculates density for a mesh at various texture sizes, including non-square and custom ones.

UVs can be rescaled to a target density, and density can be copied from one object to others. Faces with matching density or UV space can be selected, and a checker material with vertex color visualizes density, UVs and islands. Presets exist for small texture sizes. Game artists aiming for uniform quality will find it essential.

Key features

  • Calculates texel density per mesh
  • Rescales UVs to a target density
  • Copies density between objects
  • Checker material and vertex color visualization
