What Set Parent To Structure does

Set Parent To Structure is budum's script for After Effects aimed at rig preparation. It connects artwork layers to a character skeleton by creating parent-child links automatically, which removes a repetitive part of character setup.

A button disconnects existing links, and support for Duik17 arrived in version 0.5. The project has been open source since version 0.4 and works with After Effects from CC 2014 through 2022. Character animators using a skeleton rig can use it to attach limbs and body parts faster.

Key features

  • Automatic parent-child links to a skeleton
  • Button to disconnect links
  • Duik17 support
  • Open source since version 0.4
  • Compatible with CC 2014 to 2022
