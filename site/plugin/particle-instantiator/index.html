What Particle Instantiator does

Particle Instantiator turns a Blender particle system into actual objects, each following its particle's exact motion via keyframes. Animations, constraints, modifiers, drivers and custom properties are copied over from the dupli objects.

Animation can be remapped to each particle's own lifetime, drivers can reference individual particles, and particles can become rigid bodies. Interpolation modes, parenting, naming and layer options are included. It is most suited to small particle systems needing complex per-object animation, and can be combined with the Cycles Object Color and Level Of Detail Manager add-ons.

Key features

  • Particles become real keyframed objects
  • Copies animations, modifiers and constraints
  • Drivers retargeted to each particle
  • Option to turn particles into rigid bodies
  • Interpolation, parenting and naming options
