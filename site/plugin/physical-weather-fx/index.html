What 🔖Physical Weather Fx does

Physical Weather FX adds weather conditions to Blender scenes. Pick your objects, press a single button, and the system is set up ready for rain, snow, fog and wind.

Weather shaders apply custom shaders to objects that respond in real time to conditions. A procedural sky and lighting setup provides adjustable cloud layers, motion driven by wind and global illumination. Environment artists and visualizers can create atmospheric shots without building each effect separately.

Key features

  • Rain, snow, fog and wind
  • Weather shaders react in real time
  • Procedural sky with cloud layers
  • Wind-driven motion
  • One-button scene setup
