What Timelapse does

Timelapse is a Blender add-on from Silky-Renders that records the progress of your work by capturing screenshots at regular intervals. Choose a gap in seconds and an image format (JPG or PNG), then begin or end capturing at any moment.

Each frame is taken with Blender's own screenshot function. Images are saved to a directory you pick, or to an automatic Timelapse folder next to the blend file, and an Open Folder button takes you straight to them. It is useful for making sped-up videos of modeling or sculpting sessions.

Key features

  • Screenshots at an interval set in seconds
  • Uses Blender's built-in screenshot function
  • JPG or PNG output
  • Custom directory or automatic Timelapse folder
  • Start/Stop control and Open Folder button
