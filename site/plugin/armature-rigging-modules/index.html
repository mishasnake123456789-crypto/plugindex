What Armature Rigging Modules does

Armature Rigging Modules is a Blender plugin for rigging characters in a modular way. It works on almost any existing armature, so you can build a rig up piece by piece rather than starting from a fixed template.

Modules exist for limbs, feet, hands, the spine and the head, driven by scripted mechanics that handle soft IK and automatic switching between IK and FK. Documentation is included. It is part of the B.L.E.N.D set and ships inside Mr Mannequins Tools, making it a fit for riggers who want control over each body part.

Key features

  • Modular setup for arms, legs, feet, hands, spine and head
  • Soft IK for smoother limb extension
  • Automatic IK/FK switching
  • Works on existing armatures of varying complexity
  • Documentation included
