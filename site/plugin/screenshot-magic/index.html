What Screenshot Magic does

Screenshot Magic records your work without you having to think about it. It takes viewport screenshots at an interval you choose, so you can document progress or assemble a time-lapse afterwards.

The interval is set in seconds from the 3D View sidebar, where Start and Stop buttons control recording. Images are saved to a custom output directory. Modelers, sculptors and educators who share process videos will find it far easier than capturing frames manually.

Key features

  • Automatic viewport capture at set intervals
  • Interval in seconds from the sidebar
  • Start and Stop recording
  • Custom output directory
