Blender keymap with standard conventions such as left-click select and Ctrl-A, plus mouse-only navigation.

What Shotgun does

Shotgun is an alternative keymap that makes Blender feel closer to other programs. It is built around left-click selection and standardizes familiar shortcuts such as Ctrl-A for select all.

Navigation can be done with the mouse only: orbit, pan and zoom without touching the keyboard. It builds on Blender's default keymap, so many existing hotkeys are untouched, and it installs and updates through the usual mechanisms. Newcomers from other 3D software will adapt faster.

Key features

  • Left-click selection keymap
  • Mouse-only orbit, pan and zoom
  • Standard hotkeys like Ctrl-A
  • Built on the default keymap
