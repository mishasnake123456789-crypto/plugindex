What Isometric Scene Setup does

Isometric Scene Setup configures Blender for isometric views and for rendering normal maps in 2D. It handles the camera and scene settings that would otherwise need to be dialed in by hand.

Pixel artists and game developers building isometric assets can use it to produce consistent renders, plus normal maps for lighting 2D sprites. It speeds up the first steps of an isometric asset pipeline.

Key features

  • Isometric camera setup
  • 2D normal map rendering
  • Consistent scene settings
