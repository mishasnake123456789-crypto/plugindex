Blender viewer for Gaussian Splatting that imports PLY and SPZ files and can cast splat light onto scene objects.

What Fast Splatting does

Fast Splatting displays 3D Gaussian Splatting data inside Blender, so scanned or captured scenes can sit beside conventional models. It imports PLY files and includes an importer for the SPZ format.

A custom incremental transparent sorting method keeps the viewport smooth, and light generated by the splats can fall on other Blender objects. It runs with the Eevee render engine and supports Blender 4.2 through 5.1, with documentation available. Useful for artists who want to combine photographic captures with ordinary 3D assets in one scene.

Key features

  • Imports PLY and SPZ files
  • Incremental transparent sorting
  • Casts splat light onto objects
  • Blender 4.2 to 5.1
  • Runs with Eevee
