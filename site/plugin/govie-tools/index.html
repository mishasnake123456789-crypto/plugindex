What Govie Tools does

Govie Tools is a Blender add-on from 3D-Interaction-Technologies that optimizes models and exports them as GLB files targeted at the Govie Editor. It takes care of several details specific to that workflow so exported content behaves correctly.

You can add and remove custom properties, such as visibility, that the Govie Editor reads. NLA tracks are renamed so animations can play at the same time, particle systems become keyframed objects, and UV animations are created and exported through helper objects. Export settings are simpler to reach, and a local preview of the GLB speeds up iteration.

Key features

  • Custom properties like visibility for the Govie Editor
  • NLA track renaming for simultaneous playback
  • Converts particle systems to keyframed objects
  • UV animation export via helper objects
  • Local preview of exported GLB files
