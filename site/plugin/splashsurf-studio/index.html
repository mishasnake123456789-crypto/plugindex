Blender add-on that reconstructs surface meshes from particle-based fluid data on the fly using pySplashsurf.

What Splashsurf Studio does

Splashsurf Studio turns fluid particles into a mesh inside Blender. It treats the vertices of an object as particle positions and constructs a surface from them using the pySplashsurf library, based on the splashsurf tool.

The reconstruction refreshes automatically when input data changes each frame, for example when loaded through the Sequence Loader add-on, and the resulting surface can feed Geometry Nodes. Controls are in the N panel in Object Mode. Packages exist for Windows x64 and Arm, macOS Intel and Apple Silicon, and Linux.

Key features

  • Surface reconstruction from particle positions
  • Based on the pySplashsurf library
  • Auto-refresh with per-frame data
  • Output usable in Geometry Nodes
  • Windows, macOS and Linux packages
