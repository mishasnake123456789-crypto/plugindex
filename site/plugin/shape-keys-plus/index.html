What Shape Keys Plus does

Shape Keys Plus gives Blender two operations that facial and character artists often miss: duplicating a shape key and mirroring it. These are the equivalent of working with blendshapes in Maya, helping those used to that workflow feel at home.

The buttons are added to the Shape Key Specials menu in the Shape Keys properties, so they appear where you already manage keys. Documentation is included, it supports Blender 2.92 through 4.3 and it is released under the GPL. Artists building symmetrical facial expressions will save repetitive sculpting by mirroring one side into the other.

Key features

  • Duplicates shape keys
  • Mirrors shape keys, like Maya blendshapes
  • Buttons in Shape Key Specials
  • Supports Blender 2.92 to 4.3
  • GPL licensed
