Connects Premiere Pro to Celtx Studio so screenplays can drive bins and organization.

What Celtx does

Celtx links Premiere Pro to the online Celtx Studio, letting editors see screenplays in the editing environment. Scripts can be imported from PDF, FDX, TXT, DOC/DOCX and RTF files and shown without reformatting.

Bin structures with one bin per scene are generated automatically, and media markup ties assets to script content for fast navigation and sequence building. Imported scripts can be synced to include or ignore edits from Studio without harming editorial work, and version 1.1.0 added an Accept all option.

Key features

  • Screenplay import from PDF, FDX, TXT, DOC and RTF
  • Automatic scene-based bin structure
  • Media markup tags assets to script content
  • Sync with Celtx Studio changes
  • Accept all option from 1.1.0
