What Spread Objects does

Spread Objects is a free Blender add-on that lays selected objects out on a grid with even spacing. It works out the number of columns and rows on its own, and calculates the gap between each object, so no manual math or dragging is needed.

A keyframed mode records start and end positions, so objects animate from where they were to their grid spots. The command is reached from the Object menu, and documentation is included. It is handy for presenting asset libraries, organizing parts and quickly producing tidy arrangements for renders.

Key features

  • Arranges selected objects on an even grid
  • Auto-calculated columns, rows and spacing
  • Keyframed mode with start and end positions
  • Available from the Object menu
  • Documentation included
