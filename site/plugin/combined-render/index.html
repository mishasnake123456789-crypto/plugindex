What Combined Render does

Combined Render automates multi-view output in Blender. It can place a camera in each of several scenes, or ring a selected object with four cameras covering front, top, left and right, then render everything in one go.

Each run yields five pictures: one per camera and a single image combining all four. Cameras keep facing their target as it moves, and can be re-aimed at another object or recentered. Panels switch between scenes to adjust per-view settings. Name, output path and resolution are configurable, with a toggle for an Instagram-sized default, and the output folder opens afterward. Documentation is included.

Key features

  • Four-camera rig around an object
  • Camera per scene option
  • Separate shots plus one combined image
  • Cameras follow moving targets
  • Configurable name, path and resolution
