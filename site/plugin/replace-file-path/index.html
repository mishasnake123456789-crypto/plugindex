A Blender add-on that searches loaded image paths for a string and rewrites matches with a replacement.

What Replace File Path does

Replace File Path fixes broken or moved texture locations in Blender. It lists every loaded image in the file and lets you find a string in their paths, then rewrite each match with a replacement you specify.

Individual paths can be edited straight from the list. A select option limits the replacement to checked items, or applies to all when none are checked, and a condition setting limits it to paths containing a given string. Artists relocating project folders, moving between drives or handing scenes to others will save time over relinking images one at a time.

Key features

  • Lists all loaded image paths
  • Search and replace across paths
  • Edit individual paths from the list
  • Apply to checked items only
  • Condition setting limits matches
