What Depth Ai: Advanced Ai Depth Estimation Solution does

Depth AI, from Lianheng Tech, produces depth information from a flat image inside Blender.

It can generate image planes with depth maps, create a depth map using Edge AI, and convert recognized image objects into meshes with depth and materials. Main Object Mode and Full Image Mode offer two workflows. The Depth AI Manual provides documentation.

Key features

  • AI depth map generation
  • Image objects converted to meshes
  • Main Object and Full Image modes
  • Image planes with depth
