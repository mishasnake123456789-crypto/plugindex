What Trim N Collect does

Trim N Collect prepares an After Effects project for archiving or exchange by shrinking its media footprint. It trims the footage that is actually used, with optional handles, merges overlapping media and gaps, and transcodes using templates for image sequences and OpenEXR sequences.

It builds folders and export scripts automatically, copies whole sequences intact when needed, and collects Cinema 4D files without dependencies. Facilities and freelancers sending projects to colleagues or storage will find it reduces disk usage.

Key features

  • Trims used footage with optional handles
  • Consolidates overlapping media and gaps
  • Transcode templates for image and EXR sequences
  • Automatic folder creation and export scripts
  • Collects Cinema 4D files without dependencies
