What M-Suzanne_Addon does

M-Suzanne_Addon is a multi-purpose Blender collection from Animation Store, updated for Blender 4. It groups tools for rigging, scattering, snapping and the timeline into a single package, so common animation chores live in one place.

A fake liquid rig creates the look of someone drinking using simple geometry and a full rig, without geometry nodes, complicated materials or simulation. It works with various cups and any drink material. A Sharp_curve feature makes angular curve shapes in one click. Documentation is included for getting started.

Key features

  • Rig, scatter, snap and timeline tools
  • Fake liquid drinking rig
  • Works with various cups and materials
  • One-click sharp curves
  • Updated for Blender 4
