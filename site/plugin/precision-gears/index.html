What Precision Gears does

Precision Gears is a Blender addon by Keep Making that offers mathematically accurate involute gears in a faux parametric system. You can change gears on the fly and set up animated parametric gear chains.

Gear types include spur, helical, herringbone, rack, internal variants, bevel, spiral bevel, worm, GT2 and crown. Global scaling is supported, and bores come as center extrusions, set screws, cross bores, polygon bores, or round bores that subtract or add material, each with a preview. It serves mechanical designers and 3D printing makers.

Key features

  • Spur, helical, herringbone, rack, bevel, worm and more
  • Faux parametric changes with global scaling
  • Bore options with previews
  • Animated parametric gear chains
  • Accurate involute tooth profiles
