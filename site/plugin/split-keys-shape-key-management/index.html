What Split Keys: Shape Key Management does

Split Keys: Shape Key Management reduces clutter in long shape key lists in Blender. Related keys are combined into a group that you can control from one place.

Up to three keys can be joined, with three separate sliders for the grouped keys and every value shown together. It is handy for left and right pairs such as eyebrows, but works with any mesh and any grouping. Documentation is included.

Key features

  • Combine up to three shape keys
  • Values displayed in one place
  • Three sliders per group
  • Suited to left and right mesh sides
