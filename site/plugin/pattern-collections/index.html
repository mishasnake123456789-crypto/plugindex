Blender add-on that sorts objects into collections using RegEx and JSON rules based on names, types, materials and modifiers.

What Pattern Collections does

Pattern Collections organizes Blender scenes by sorting objects into collections according to properties and metadata.

Rules can match included or excluded names, hierarchies, types, materials, collections, UV layers, modifiers and attributes, and are configured with RegEx and JSON and layered together. Each rule has its own controls. Artists with large imported scenes get structure automatically. Rules can be layered and individually enabled, so a single configuration can organize a cluttered file by several criteria in one pass.

Key features

  • Sort by names, types, materials and modifiers
  • RegEx and JSON rule configuration
  • Layered sorting rules
  • Per-rule controls
