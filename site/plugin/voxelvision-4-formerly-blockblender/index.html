What Voxelvision 4 (Formerly Blockblender) does

Voxelvision 4, formerly Blockblender, converts models, images and text into blocks resembling Minecraft's in real time using geometry nodes. It also generates gradients.

Four voxelization methods are available: Best Performance, Volume Based, Precision, and Better Hole Resistance, the last meant for models with holes. Custom block palettes are supported. Content creators can quickly produce block-style art. Because everything is computed with geometry nodes, results update live as the source changes, which makes it convenient for animation as well as static builds.

Key features

  • Models, images and text to blocks
  • Four voxelization methods
  • Custom block palettes
  • Real-time geometry nodes
