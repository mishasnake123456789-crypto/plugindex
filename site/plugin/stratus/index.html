What Stratus does

Stratus is a sky creation tool for Blender that produces HDRI skies in minutes. A viewport editor gives real-time feedback while you create and edit the atmosphere, and a range of realistic sky environments can be generated.

Cloudscapes can be animated, and rendering uses techniques similar to those in modern video games, which keeps render times short. It suits architectural visualization, product rendering and animation work that needs believable backgrounds and lighting.

Key features

  • Viewport editor with real-time feedback
  • Variety of realistic sky environments
  • Animated cloudscapes
  • Fast game-style rendering techniques
