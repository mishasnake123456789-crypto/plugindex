Modal Blender tool suite from Pitiwazou for adding and managing modifiers such as cuts, arrays, booleans and bevels.

What Speedflow does

Speedflow brings modal tools for adding and controlling modifiers straight into Blender's 3D view, handling cuts, arrays, booleans, bevels, mirrors and further operations.

The Cutter modal cuts, unions and creates rebools and lines. The Array modal manages multiple arrays, circular arrays, direction changes and arrays along curves or cables using start and end caps. The Boolean modal adds multiple booleans with intersection, difference and union, and updates automatically with a bevel. Hard surface modelers cut the clicks needed in the properties panel.

Key features

  • Cutter modal for cuts, unions and rebools
  • Array modal with circular and curve arrays
  • Boolean modal with auto-update
  • Bevel and mirror modals
