What Automatic Wood & Brick | Smart Placement System does

This Blender add-on, from Blender Procedural, uses Geometry Nodes to cover chosen meshes with stylized brick, stone, wood and plank pieces. It is meant for building walls, floors and structures quickly from simple base shapes.

Custom meshes can be plugged in for the bricks or planks. Scale is adjustable on each axis with random variation, rotation can be randomized for a natural look, and an optional automatic UV unwrap offers subdivide and scale settings. Append mode layers details on without destroying the base. Smart Brick and Smart Wood systems, a UI panel and a test scene are included, useful for castles, villages, ruins and game environments.

Key features

  • Geometry Nodes brick and wood placement
  • Custom brick, stone or plank meshes
  • Per-axis scale and random variation
  • Optional auto UV unwrap
  • Non-destructive append mode
