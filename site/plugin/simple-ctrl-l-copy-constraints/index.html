What Simple "Ctrl + L" Copy Constraints does

This Blender extension from Mantaframe places constraint copying in the familiar Ctrl+L Link/Transfer Data menu. Select several objects, make one active, and copy its constraints to all the others.

There are no extra panels or settings to learn, since it simply slots into an existing menu. Documentation is available. Riggers and animators who set up repeated constraint arrangements across many objects will appreciate the reduction in clicks. It spares you from adding the same constraint again and again.

Key features

  • Adds Copy Constraints to the Ctrl+L menu
  • Transfers to many selected objects at once
  • No extra panels or settings
  • Integrates into an existing menu
