What Quick Export does

Quick Export is a Blender addon from Maro3D that adds an Export button to the Outliner. One click exports the collection that contains the active object, so you no longer open Collection properties every time.

The add-on searches upward from the active object's collection for the first one with exporters configured, then runs the appropriate exporter. If a collection has several exporters, all of them are used. The button can also be added to Quick Favorites for even faster access, which helps when you iterate on game assets or avatars.

Key features

  • One-click export from the Outliner
  • Finds the first collection with exporters
  • Runs every configured exporter
  • No need to open Collection properties
  • Can be pinned to Quick Favorites
