What Magic Coordinate Addon - Dynamic Mapping does

Magic Coordinate Addon keeps procedural textures uniform across objects of varying shape while sharing a single material. It normalizes stretching and scaling automatically, with no need to apply scale in Object Mode.

The Set wizard configures the modifier for several objects in one click, and the Get wizard makes existing procedural materials compatible in one or two clicks by replacing or connecting the node group as the coordinate input. It is useful for architectural and set dressing work.

Key features

  • Even procedural mapping across proportions
  • No need to apply scale
  • One-click setup wizard for multiple objects
  • Makes existing materials compatible
