What Massfx- Dynamic Physics Painter does

MassFx Dynamic Physics Painter populates Blender scenes by letting assets fall and settle using the rigid body system. Press, drag and let go to heap objects on any surface, with a particle-based brush doing the placement.

Clusters of objects are assigned to a collection, and the panel gives both particle and physics options in a simple layout that suits beginners and professionals. A passive rigid body is added automatically when none is found, and a Collection Manager is included. It fits scene dressing for game cinematics and commercials.

Key features

  • Drop or paint assets with rigid body physics
  • Particle-based brush
  • Clusters assigned to a collection
  • Automatic passive rigid body
  • Includes a Collection Manager
