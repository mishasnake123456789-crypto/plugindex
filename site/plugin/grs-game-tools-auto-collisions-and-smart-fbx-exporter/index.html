What Grs Game Tools: Auto-Collisions & Smart Fbx Exporter does

GRS Game Tools combines a collision generator and a smart FBX exporter in the Blender N-panel, aimed at preparing assets for Unreal Engine. It is meant to shorten the repetitive part of getting props into a game.

A Top-Down Slicer builds optimized, merge-ready UBX pillars for stairs, walls and caves without relying on costly convex hulls. Auto-Primitive Detection analyzes a prop's volume and assigns UBX, USP, UCP or UCX types using fill-ratio tolerances. A smart batch export handles the FBX output. Environment and prop artists gain a consistent handoff.

Key features

  • Top-Down Slicer for UBX pillars
  • Auto-Primitive Detection by fill ratio
  • UBX, USP, UCP and UCX assignment
  • Smart batch FBX export
