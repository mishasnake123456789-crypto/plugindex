What Textura - Smart Pbr Automation does

Textura automates PBR material setup in Blender. It identifies texture files and connects them to the Principled Shader on its own, saving manual node wiring.

It detects and manages UDIM tiles for production pipelines and processes Occlusion-Roughness-Metallic maps with customization options. Two workflows are offered: Smart Setup for full control and Fast Setup for standardized folders. It suits artists handling large texture libraries. Notable points: automatic texture identification, UDIM tile detection and ORM processing.

Key features

  • Automatic texture identification
  • UDIM tile detection
  • ORM processing
  • Smart Setup and Fast Setup workflows
