What keyboardFX does

keyboardFX is a tool from Real Creations for making keyboard graphics in After Effects. It generates fully customizable keyboards and typing animations that you define, which is useful for tutorials, app promos and tech explainers.

Intelligent case detection inserts {{SHIFT}} codes when text changes between lower and upper case and updates the mobile keyboard layout. A Virtual Keyboard panel enters special codes for each keyboard type, and the mobile and tablet keyboard covers numbers 0 to 9 and both letter cases. It supports After Effects from CS6 through 2025.

Key features

  • Fully customizable keyboards
  • User-defined typing animations
  • Case detection with {{SHIFT}} codes
  • Virtual Keyboard panel for special codes
  • Mobile and tablet keyboard layouts
