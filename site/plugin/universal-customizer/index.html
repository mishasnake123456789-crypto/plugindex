3ds Max script that deforms repeated meshes through up to 16 parameter spinners without changing vertex count.

What Universal Customizer does

Universal Customizer lets you vary a mesh in 3ds Max through parameters, which is useful when a scene contains many similar objects that need individual tweaks. It moves existing vertices without changing the vertex count.

Up to 16 spinners are linked to chosen vertex groups and set to a Move, Scale or Rotate action. One control may drive several groups, and a vertex can belong to more than one. Configurations live in an editable external .ucf file, with object types identified by name and vertex count. It works with editable_Mesh and editable_Poly, includes example models and a PDF guide, and was tested on 3ds Max 2016 to 2022.

Key features

  • Up to 16 spinner controls tied to vertex groups
  • Move, Scale or Rotate actions
  • One control can drive multiple groups
  • Settings stored in an editable .ucf file
  • Works with editable_Mesh and editable_Poly
