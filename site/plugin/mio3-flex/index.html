Blender add-on that smooths edge loops into freeform curves using an adjustable path deform.

What Mio3 Flex does

Mio3 Flex reshapes edge loops into smooth curves in Blender. Select a loop, apply Path Deform and move the spline's control points to even out the mesh.

X-axis mirroring covers control points and mesh, axis constraints lock movement, control-point density adapts to vertex count and the original edges are displayed as reference. Modelers refining silhouettes, rims and organic outlines can sculpt with precision. Because it uses a path to shape the loop, adjustments can be made gradually instead of nudging each vertex.

Key features

  • Smooths vertices along a curve
  • X-axis mirroring
  • Axis constraints for X, Y or Z
  • Auto control-point density
  • Original edges shown as reference
