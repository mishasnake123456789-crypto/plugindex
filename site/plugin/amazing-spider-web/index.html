What Amazing Spider Web does

NENGHUO Studio's Amazing Spider Web generates webs with Geometry Nodes, built in Blender 4.1. The web's form is adjustable, and suspension strength sets how taut it hangs.

Water droplets and wind add atmosphere, and a physical simulation lets the web react. It works in both Cycles and Eevee, and documentation is included. Horror, nature and macro scene artists can create convincing webs without modeling every strand. The settings are adjustable, so one setup can produce delicate morning webs or storm-battered ones.

Key features

  • Geometry Nodes web generator
  • Adjustable web shape
  • Suspension strength control
  • Water droplets and wind
  • Physical simulation
