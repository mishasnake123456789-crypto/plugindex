What B SubEditor does

B SubEditor is a Blender add-on by Dinesh007 for subtitle handling inside the Text Editor and the Video Sequence Editor. It reads and writes subtitles as SRT, VTT, SBV or plain TXT.

The Text Editor footer reports line count, cursor position, how many characters are selected, and the indentation of the current line, with a checkbox to include or exclude spaces. From an imported subtitle text block it can create VSE text strips on a target channel, and a Connect Strips option joins the created strips. Video editors can handle captions without leaving Blender.

Key features

  • Imports and exports SRT, VTT, SBV and TXT
  • Text Editor footer with counts and cursor info
  • Creates VSE text strips from subtitles
  • Choice of target channel
  • Connect Strips option
