What Easy Custom Normals - Simplify Stylized Shading Workflows does

Easy Custom Normals is a toolset for writing custom normals in Blender through Geometry Nodes modifiers. It aims at stylized shading, where messy or triangulated topology normally produces ugly shading on toon and anime characters.

A Laplacian smoothing plus weighted normals modifier cleans up imperfect meshes. The Pro tier adds an anime face proxy system, where rigged curves drive smooth face normals, and bones can also steer normals, with preview, adjustment and masking options. The setup can stay live in the modifier stack or be exported for game engines.

Key features

  • Laplacian smooth plus weighted normals modifier
  • Anime face proxy system in the Pro tier
  • Set normals using bones with masking
  • Keep live or export for game engines
