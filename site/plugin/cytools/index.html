What Cytools does

CJK's Cytools is a collection of varied Blender add-ons. CYGPT: Operator writes Python from text instructions using gpt-3.5-turbo, gpt-4 or a local Llama3-8b via Ollama, and remembers earlier scripts. CYGPT: Blendalle generates textures in the Image Editor from prompts through DALL-E.

The rest of the set holds a growth simulation, fog and light generators, camera shake, color randomizing and a multi-camera renderer. Technical artists wanting experimental helpers have plenty to explore.

Key features

  • AI Python script generation
  • Text-to-texture via DALL-E
  • Growth simulation
  • Fog and lamp generators
  • Camera shake and multi-camera renders
