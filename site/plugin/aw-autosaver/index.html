What aw-Autosaver does

aw-Autosaver, developed by MotionLand, is a replacement for the built-in After Effects auto save. It writes .aep backups automatically or on demand to any folder you choose, giving much more control than the default behavior.

The interval and number of kept versions are adjustable, and the project copy can be saved alone if wanted. Alt-click lets you attach a comment to a version, and the panel tracks the version count. Buttons jump straight to the project folder or the versions folder, each project copy lives in its own folder, and the versions folder is backed up as well. The interface is customizable.

Key features

  • Automatic or manual backups to any location
  • Adjustable interval and version count
  • Alt-click comments on versions
  • One-click buttons to open project and version folders
  • Customizable UI
