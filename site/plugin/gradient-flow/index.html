What Gradient Flow does

Gradient Flow, by Muhammad Adnan, moves gradients between layers in After Effects. Copy a gradient from a shape layer or solid and paste it onto others, which keeps branding consistent and speeds up style testing during revisions.

The paste can reach multiple selected layers at once and target Fill, Stroke or both. A Preserve Layout Mode maintains the gradient structure, and a Full Mode paste option is available. The interface is clean and minimal. Motion designers handling client updates will find it handy.

Key features

  • Copy and paste gradients between layers
  • Paste to many layers at once
  • Target Fill, Stroke or Both
  • Preserve Layout Mode
  • Full Mode paste option
