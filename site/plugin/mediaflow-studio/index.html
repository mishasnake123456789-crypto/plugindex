Compresses, converts and batch processes video inside Blender using FFmpeg, including frame extraction.

What Mediaflow Studio does

Mediaflow Studio brings media handling into Blender by running FFmpeg directly. There is no need to leave the application to shrink a render or convert a format.

Three modes cover converting and compressing, extracting frames, and creating video from image sequences. H.264 and H.265 are supported with CRF quality from 0 to 51, custom bitrates and six levels of compression, and a batch queue manages multiple jobs. Animators delivering previews and clients' formats will save trips to other software.

Key features

  • Convert & Compress, Extract Frames, Create Video modes
  • H.264 and H.265 with CRF control
  • Custom bitrates and six compression levels
  • Batch queue management
