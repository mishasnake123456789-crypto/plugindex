What Auto Backup does

Built by HanaYuki, Auto Backup is a script running inside After Effects that creates a backup each time you save. It gives you earlier versions to return to when something goes wrong, which the regular AutoSave often cannot offer.

If a project file becomes corrupted and only an outdated AutoSave remains, the stored backups let you recover. They also help when an applied effect plug-in turns unstable and you need to revert. It is compatible with After Effects 2022 through 2026, and version 1.1 added bug fixes and optimizations.

Key features

  • Backup created on every save
  • Recover from corrupted project files
  • Revert after an unstable plug-in
  • Compatible with After Effects 2022 to 2026
