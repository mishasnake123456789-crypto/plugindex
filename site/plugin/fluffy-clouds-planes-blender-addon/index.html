What Fluffy Clouds Planes - Blender Addon does

Fluffy Clouds Planes is a plugin by Besa_Art for creating cloudscapes with flat cloud planes. A categorised library gives an overview of the cloud in use, and shader and animation sections sit in the same panel.

Proxy clouds stop the camera view from being crowded with planes, and shadow clouds are supported. It is a lightweight way to produce skies above or below the viewer. Using flat planes keeps scenes light, so it works well for airplane shots, fantasy vistas and stylized skies in animation.

Key features

  • Categorised cloud library
  • Shader and animation controls in one panel
  • Proxy clouds to limit plane count
  • Shadow clouds
