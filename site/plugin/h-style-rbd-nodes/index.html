What H-Style RBD Nodes does

H-Style RBD Nodes, by Excifroge, covers a destruction workflow in Blender: fracture an object, bake the rigid body simulation and export it for game effects. It uses Geometry Nodes and is tagged under Physics, Geometry Nodes and Game Engine.

The add-on is open source under GPL-3.0-or-later and requires Blender 5.2.0 or newer.
