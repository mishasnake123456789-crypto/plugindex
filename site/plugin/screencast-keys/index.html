Blender add-on that shows keyboard and mouse input and the last operator on screen for tutorials.

What Screencast Keys does

Screencast Keys displays what you press on the keyboard and mouse, along with the last operator you ran, directly in the Blender interface. It was made to help produce tutorials and demonstrations.

The overlay can be styled with text color, shadow, background planes and corner radius, and sized by font, margin, line thickness and mouse figure. Positions can be set relative to the region, area, window or cursor. A repeat count merges repeated presses into one entry. Educators, streamers and people recording workflows get a clear record of each action.

Key features

  • Keyboard, mouse and operator display
  • Customizable colors, shadow and backgrounds
  • Flexible positioning options
  • Repeat count for repeated keys
