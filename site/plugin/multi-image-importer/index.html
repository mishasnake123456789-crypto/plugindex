What Multi-Image Importer does

Multi-Image Importer brings batches of images into Blender using paths copied to the clipboard as text, with Ctrl+Shift+C on Windows or Cmd+Option+C on Mac.

It can create image empties as placeholders or fully textured planes with alpha, and offers alignment in a single row, a grid or other layouts, plus spacing, scale and rotation controls. Artists assembling reference boards, mood walls or image-based sets can place dozens of pictures in seconds.

Key features

  • Clipboard-based path import
  • Image empties or textured planes with alpha
  • Row and grid alignment
  • Spacing, scale and rotation control
