What OrganizerPro does

OrganizerPro is a script by JB Noel that tidies the project panel in After Effects. Studios and freelancers alike end up with messy bins, and this sorts everything according to your selection and settings with a click.

Selected comps go into a root RENDER folder, with the rest placed in RESOURCES. Folder structures can be customized, files are identified by source, type and extension, and presets can be shared with colleagues through a file. Comp timing can be zero-based so each begins at 0, and redundant files and empty folders can be removed.

Key features

  • One-click project panel sorting
  • RENDER and RESOURCES folder structure
  • Customizable folders and file type detection
  • Shareable presets
  • Removes redundant files and empty folders
