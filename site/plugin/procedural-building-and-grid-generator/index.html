What Procedural Building And Grid Generator does

The Procedural Building and Grid Generator creates architectural scenes without modeling each structure. A building generator takes length, width and height, while a grid generator arranges many buildings into city layouts.

Roof greebles can be removed with a button, an optional floor can extend past the building's perimeter, and lamps with a built-in emission shader are added in one click. A building shader colors walls, windows, frames and trims per floor. Environment artists building cityscapes can fill space quickly.

Key features

  • Building generator with length, width and height
  • Grid generator for street layouts
  • Removable greeble roof assets
  • One-click lamps with emission shader
  • Per-floor shader for walls, windows and trims
