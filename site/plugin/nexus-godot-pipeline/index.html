What Nexus Godot Pipeline does

Michael Kulzer's Nexus Godot Pipeline joins Blender and Godot so gameplay setup happens during modeling. Define physics, materials and level layout in Blender, export one time, and bring it into Godot in a usable state.

Physics bodies can be Static, Rigid, Character or Animatable, configured in the viewport. A collision generator produces Box, Sphere, Capsule or Convex shapes, and NavMeshes plus Area3D triggers import ready. Principled BSDF and procedural shaders are converted. Game developers using both programs skip engine-side setup.

Key features

  • Physics bodies set in the viewport
  • Box, Sphere, Capsule and Convex collisions
  • NavMeshes and Area3D triggers
  • Principled BSDF shader conversion
  • Level assembly on import
