Manages feedback and versions in Premiere Pro with one-click new versions and jump-to-time markers.

What Feedback Pro does

Feedback Pro helps editors keep track of revision notes. One click creates a new sequence version, naming it with V+1 at the end and the date at the start, both customizable.

Feedback can be pasted from any text source, saved in any order, and turned into timeline markers with times detected automatically so you can jump to each point. The panel can switch sequences or projects automatically and export the current sequence consolidated as a project.

Key features

  • One-click versioning with V+1 and date naming
  • Paste feedback from any text source
  • Markers with auto-detected times
  • Automatic sequence and project switching
  • Export consolidated sequence as a project
