What Organizer does

imagimation's Organizer helps keep large Blender scenes tidy. It finds objects lacking materials or UV maps, renames in bulk, replaces materials and picks objects according to modifiers, attributes or transform state.

Naming utilities include name selection, prefixes and suffixes, and matching mesh data names to object names. Material checks find objects with none, unused materials and empty slots, then delete or replace them in batches. Modifier management rounds it out, making it a good audit pass before delivery.

Key features

  • Find objects missing materials or UVs
  • Batch rename with prefix and suffix
  • Match mesh data names to object names
  • Remove or replace materials in bulk
  • Select by modifier or transform state
