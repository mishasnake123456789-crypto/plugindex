What Architect Core Toolkit does

Architect Core Toolkit bundles tools for each stage of an architectural visualization project. Cleaner prepares geometry, MAD supplies materials tuned for Cycles, and CID creates Color ID passes for post-production.

Cleaner removes doubles, fixes normals and clears unused materials in one click, and works on assets from SketchUp, Revit, online libraries, scans and CAD imports. The MAD library is calibrated for Cycles. Archviz artists who import messy models can get them render-ready and ready for compositing masks.

Key features

  • Cleaner: remove doubles, fix normals, drop unused materials
  • Handles SketchUp, Revit, scan and CAD imports
  • MAD materials calibrated for Cycles
  • CID Color ID passes for post-production
