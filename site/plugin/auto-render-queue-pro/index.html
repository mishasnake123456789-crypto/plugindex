What Auto Render Queue Pro does

Mamba CG's Auto Render Queue Pro manages renders across many .blend files. Add files to a project queue, choose scenes for each, and give every project its own output folder.

It writes scripts suited to each system, .bat for Windows and .sh for macOS and Linux, so rendering starts with one click. You can preview, reorder and manage the stack. Artists who render overnight or batch many scenes avoid opening each file.

Key features

  • Queue multiple .blend files
  • Pick scenes per file
  • Custom output folders
  • Generates .bat and .sh scripts
  • Preview and reorder the stack
