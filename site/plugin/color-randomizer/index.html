What Color Randomizer does

Color Randomizer is a Blender add-on by ilumetric that gives objects random colors. It is aimed at cases where neighboring objects share the same or similar colors and become hard to tell apart.

One button applies a random color, and pressing it again lets you cycle until you like the result. Since version 1.3.0 it works on multiple objects at once. A prefix added to object names keeps each color unique, and that prefix can be removed when your work is finished. No special permissions are required, and it supports Blender 4.2 LTS and newer.

Key features

  • One-button color randomization
  • Repeat presses to pick a preferred color
  • Multi-object support since 1.3.0
  • Name prefix keeps colors unique
  • Prefix removal when finished
