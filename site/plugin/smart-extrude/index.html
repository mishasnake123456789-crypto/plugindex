Replaces Blender's extrude with a mesh-agnostic version that skips connecting and deleting extra geometry.

What Smart Extrude does

Smart Extrude reworks extrusion in Blender so the tool ignores existing mesh structure. You extrude without the usual follow-up steps of joining and deleting geometry, and it can also be used to repair models.

Modes exist for faces, edges and vertices. An intelligent mode picks between Along Normal and Group Normal automatically, with overlap handling and individual extrusion available, and Along Axis extrusion is also provided. It shortens common hard surface modeling steps.

Key features

  • Face, edge and vertex extrude modes
  • Intelligent normal detection
  • Along Normal, Group Normal and Along Axis
  • Useful for model repair
