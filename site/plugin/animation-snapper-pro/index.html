What Animation Snapper Pro does

Animation Snapper Pro is a Blender plugin for attaching one object to a point on another during animation. Rather than adding constraints or parent chains, it records the result as keyframes, which keeps scenes light and tidy.

Any vertex, edge or face on nearly any mesh can act as the anchor. Snap Now places the moving item on its source, with or without an offset, while batch snapping forwards or backwards makes an object follow another across a frame range in a single click. It is useful for props, hands and anything that must stay glued to a moving surface.

Key features

  • Snap to any vertex, edge or face
  • No extra constraints or parenting
  • Snap Now with optional offset
  • Batch snapping across a frame range
