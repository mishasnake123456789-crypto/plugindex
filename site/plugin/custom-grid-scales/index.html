What Custom Grid Scales does

Custom Grid Scales is a Blender add-on by Jacob-Beatty that lets you keep a personal list of viewport grid scales. You create the list in the Viewport Overlays panel and step through it while working.

The left and right bracket keys move down and up the list, and the shortcuts can be reassigned in the keymap preferences. Increments can be set to match other software, for example Unreal Engine, which suits level and game asset work. It supports Blender 4.2.1 LTS and newer and is licensed under the GNU GPL v3 or later.

Key features

  • Custom list of grid scales in Viewport Overlays
  • Cycle with the [ and ] keys
  • Reassignable shortcuts
  • Increments matching other tools like Unreal Engine
  • Supports Blender 4.2.1 LTS and newer
