Exports Blender Asset Browser library definitions to JSON and imports them into another Blender version.

What Assetlib-Exp-Imp does

AssetLib-EXP-IMP moves your asset library setup between Blender versions. Exporting writes every library's name, folder and import method to a JSON file placed on the Desktop.

Import loads the JSON in a new version to restore or update the libraries. Saves re-adding each library by hand after upgrading. This makes upgrading to a new Blender build smoother for people with many linked asset folders. Libraries are restored together with their import settings, so assets appear exactly as they did before.

Key features

  • Export library name, path and import method
  • JSON file written to the Desktop
  • Import restores or updates libraries
  • Moves setups between Blender versions
