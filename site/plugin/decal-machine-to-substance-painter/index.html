What Decal Machine To Substance Painter does

This Blender add-on prepares decals for use in industry-standard texturing software. It converts single decals or whole libraries.

Ambient occlusion, curvature and height maps are separated automatically, components are squarified in a couple of clicks, and each component gets a unique name identifier. It replaces tedious manual steps when moving decal sets into Substance Painter. Among its capabilities are convert decals or libraries, separate AO, curvature and height maps and squarify components.

Key features

  • Convert decals or libraries
  • Separate AO, curvature and height maps
  • Squarify components
  • Unique name identifiers
