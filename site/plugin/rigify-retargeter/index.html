What Rigify Retargeter does

Stellart's Rigify Retargeter moves animation from other skeletons onto a Rigify rig in Blender. Mixamo, BlenQuick Auto-Rigger, custom and add-on-made rigs are all handled within seconds.

A Stay put option stops characters sliding during walks or runs. It works on Linux and Windows, updates are free and documentation is included. Animators reusing mocap libraries on Rigify characters can skip manual constraint setups. Because the process is quick, trying several animation sources on one character becomes realistic.

Key features

  • Retargets any rig to Rigify
  • Mixamo and BlenQuick support
  • Stay put option for walks and runs
  • Linux and Windows
  • Free updates
