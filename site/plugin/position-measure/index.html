What Position measure does

Position measure is a minimal measuring script for 3ds Max by Chuggnut. Select two objects and it reports the distance between them. When a single object is selected, it instead measures the distance between two vertices.

Results are printed in the prompt line, so no extra windows or objects are added to the scene. It does one thing and is intended for quick checks while modeling or arranging. Users who need only a number, without placing tape helpers or dimension objects, will find it convenient. The script is at version 2.3.5.

Key features

  • Distance between two selected objects
  • Vertex-to-vertex distance on a single object
  • Result printed in the prompt line
  • Single-purpose distance script
  • Version 2.3.5
