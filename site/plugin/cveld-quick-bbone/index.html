What Cveld Quick Bbone does

Cveld Quick Bbone is a rigging support tool for building bendy-bone rigs without setting up each bone by hand. It generates BBone rigs rapidly and is documented so newcomers can get started easily.

Version 2.0 officially supports Blender 2.93 and 3.6, with separate builds provided for Blender 4.5 and 5.0. The add-on is released under the GPL license, and the developer offers support through Twitter. It suits riggers who regularly build flexible limbs, tails, tentacles or similar bending structures.

Key features

  • Fast BBone rig generation
  • Official support for Blender 2.93 and 3.6
  • Separate builds for Blender 4.5 and 5.0
  • Documentation included
