What NodeExporter does

NodeExporter is a Blender plugin that extracts node networks and presents them in a viewer you can open in any browser. It reads Geometry Nodes trees and Shader Materials and compiles them into one standalone HTML file built with HTML5, CSS3 and JavaScript.

The file needs no local server or outside dependencies, which makes it easy to send to clients or colleagues. It serves documentation, tutorials and visual reference, letting people pan around a node graph without owning Blender. High-resolution graphical export is included as well.

Key features

  • Standalone HTML viewer with no server required
  • Exports Geometry Nodes and Shader Materials
  • Interactive browsing of node graphs
  • High-resolution graphical export
