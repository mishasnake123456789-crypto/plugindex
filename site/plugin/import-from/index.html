What Import From does

Import From is a narrow After Effects panel by rhymage that skips the folder navigation normally needed when importing. A click opens the native Import window directly at the project's own directory or at saved favorite locations.

The project folder, its parent and its grandparent each have a button, and Alt-click reveals the folder in Explorer or Finder. Custom folders become numbered favorites that can be reordered or deleted from a gear dialog, and they are stored in After Effects preferences. Relative Path Mapping follows the project if it moves, importing from the current .aep location. The panel is only 30 pixels tall.

Key features

  • One-click import from project, parent and grandparent folders
  • Alt-click opens folders in Explorer or Finder
  • Numbered custom favorites
  • Relative Path Mapping for moved projects
  • Ultra-slim 30px docked panel
