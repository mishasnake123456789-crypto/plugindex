What Maze Generator does

Maze Generator builds maze geometry in Blender. You set rows, columns, cell size and wall height, and can add floors, ceilings and boundary walls with entrances and exits cut in.

Optional solidify and bevel modifiers set wall thickness and soften edges. A random seed gives reproducible mazes, isolated islands can be deleted, and iterations adjust complexity. Parameters update in real time. Game designers, educators and motion artists can generate puzzle layouts quickly.

Key features

  • Adjustable rows, columns, cell size and height
  • Floors, ceilings and boundary walls
  • Solidify and bevel options
  • Seed input and complexity control
