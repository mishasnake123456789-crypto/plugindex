What Clothmaster(Cloth Simulation With 1 Click) does

Clothmaster, from NIXO, shortens the setup of cloth simulations in Blender. A single Clothify action converts the selected object, subdividing it heavily, adding a Subdivision Surface modifier, applying smooth shading and enabling self-collisions, so you do not step through each setting yourself.

Extra buttons subdivide further for more detail, create pillows, add collision to other objects and pin vertices by building a vertex group and assigning it to the cloth modifier's pin group. This suits dynamic setups like drapes, flags and bedding for artists who want quick results without learning every cloth parameter.

Key features

  • One-click Clothify setup
  • Subdivide More for added detail
  • Pillow creation
  • Collision setup for other objects
  • Pin Vertices through a vertex group
