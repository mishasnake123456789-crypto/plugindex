What Select Similar Objects (Blender does

Select Similar Objects helps when a scene is full of items with unhelpful names. It finds and highlights objects that are about the same size, that are instance copies, or that share a material.

That makes it possible to sort or tidy hundreds of objects by what they are rather than what they are called. Documentation is included. It works with Blender 3.6, and support for 4.2 is planned. Useful for cleaning up imported CAD or scanned scenes.

Key features

  • Finds objects of similar size
  • Selects instance copies
  • Selects by shared material
  • Works with Blender 3.6
