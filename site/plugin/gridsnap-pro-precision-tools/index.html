What Gridsnap Pro - Precision Tools does

Gridsnap Pro collects precision tools for hard-surface, product and 3D-printing work in Blender. Snap and Place drops objects onto surfaces with optional normal alignment and snaps origins or vertices to custom grid steps on any axis.

A measurement set handles distances, angles, radii, arcs and polylines as overlays, with saved dimensions that can be re-measured live and exported as CSV, JSON or an SVG blueprint. A shape quality check compares geometry against circles, rectangles, hexagons and other regular forms, flags bad vertices, and correction tools clean arcs and corners. Parametric resize scales to an exact typed length, and four technical overlay styles are included.

Key features

  • Surface snapping with align-to-normal and grid snapping
  • Distance, angle, radius and arc measurement overlays
  • Saved dimensions exportable to CSV, JSON or SVG
  • Shape quality check with problem vertex selection
  • Arc, corner and outline correction tools
