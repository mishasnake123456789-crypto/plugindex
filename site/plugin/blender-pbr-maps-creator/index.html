What Blender Pbr Maps Creator does

Blender PBR Maps Creator produces texture-driven maps from existing images. Outputs include ambient occlusion, height, roughness, metallic and normal maps.

The generated results are wired into Blender materials, taking you quickly from files to a usable material. Handy when you have only a color texture and need a full PBR set. It is useful for building complete material setups from a single starting texture. Wiring is done for you, which removes the repetitive node linking that follows generating each map.

Key features

  • Generates AO, height, roughness, metallic, normal
  • Texture-driven map creation
  • Maps wired into Blender materials
