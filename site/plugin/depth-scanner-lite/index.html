What Depth Scanner Lite does

Depth Scanner Lite is Blace Plugins's plugin for After Effects that estimates how far away things are in a video frame and outputs a depth map. It is built on blace.ai and now uses the Depth Anything v2 model for its estimates.

The resulting maps can drive effects such as fog, depth-based color grading or transitions without any 3D scene data. A Stop Processing button cancels long computations immediately, and a CUDA memory sharing option speeds up rendering at resolutions above 4K. Artists who outgrow this edition can move up to Depth Scanner 2 whenever they like.

Key features

  • Automatic AI depth estimation from video
  • Runs on Depth Anything v2
  • Stop Processing button cancels long jobs
  • CUDA memory sharing for resolutions above 4K
