What Autorigpro-To-Rigify does

Autorigpro-To-Rigify bridges two popular rigging systems. Place markers quickly in Auto-Rig Pro, then let this add-on align a Rigify metarig to those reference bones.

It converts the body bones only, with face bones not included, and fits into a workflow of ARP marker placement followed by Rigify generation. It runs before Auto-Rig Pro's skinning and binding process, and documentation is included. Riggers who prefer Rigify output but like ARP's marker placement will save manual alignment time.

Key features

  • Aligns Rigify metarig to ARP reference bones
  • Converts body bones, face bones excluded
  • Supports ARP markers then Rigify generation flow
  • Runs before ARP skinning and binding
  • Documentation included
