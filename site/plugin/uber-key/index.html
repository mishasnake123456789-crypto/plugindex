What Uber Key does

Uber Key tackles a classic After Effects annoyance: changing an animated mask or shape path normally means fixing every keyframe separately. With this tool, you switch it on, edit the path once, and the change carries through the rest of the animation.

It handles both points and curves, and works on mask paths as well as shape paths. If you only want certain keyframes to change, select them beforehand. Compatible with After Effects CC 2015 through 2025, it suits anyone doing rotoscoping or path-based character and logo animation.

Key features

  • Propagates a single path edit to later keyframes
  • Supports mask paths and shape paths
  • Simple on/off toggle for edits
  • Optionally limit changes to selected keyframes
  • Works with After Effects CC 2015 to 2025
