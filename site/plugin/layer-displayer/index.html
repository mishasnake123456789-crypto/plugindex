What Layer Displayer does

Layer Displayer is a script by Duhazzz for taming crowded timelines in After Effects. Short typed commands show only the layers you want, such as hiding masks, nulls, locked or enabled layers, or revealing those within the work area.

Layers can also be shown by matching the labels of selected layers or sharing a selected layer's parent, the Shy setting can be flipped across all layers, and guide layers can be shown. Keyframes under the time slider or within the work area can be selected. Custom groups can be created without binding to labels, displayed by name or removed.

Key features

  • Typed commands to filter layer visibility
  • Filter by work area, label, parent or lock state
  • Invert Shy and show guide layers
  • Select keyframes at time or in work area
  • Custom layer groups
