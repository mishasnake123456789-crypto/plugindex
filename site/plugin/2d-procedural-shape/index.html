Single-node generator for basic 2D vector shapes in Blender with corner rounding and degree-based rotation.

What 2D Procedural Shape does

2D Procedural Shape produces simple vector shapes in Blender from one node. Rather than building shapes from meshes or curves, you adjust values on the node and get a clean result that works in both Eevee and Cycles.

A Shapeness control shifts the form, each corner can be rounded individually, and rotation is set in degrees. The node is lightweight and documentation is included. It suits motion designers and shader artists who need quick graphic shapes for backgrounds, masks and flat design layouts.

Key features

  • Generates 2D shapes from a single node
  • Shapeness control
  • Individual corner rounding
  • Rotation in degrees
  • Ready for Eevee and Cycles
