Fills the inside of any sealed Blender mesh with stars, with clustering and color controls from one panel.

What Starfield Generator does

Starfield Generator populates a volume with stars using a target shape you choose. Any manifold mesh works, such as a torus or Suzanne, and parameters are set from one clean panel instead of tangled nodes.

Clustering ranges from uniform distribution to galaxy-like clumps, and star colors match deep-space imagery by default, with an optional red or blue bias. Artists creating space scenes, nebula backdrops or galaxies get convincing results quickly.

Key features

  • Stars generated inside any sealed mesh
  • Single parameter panel
  • Uniform to galaxy-like clustering
  • Deep-space star coloring with bias option
