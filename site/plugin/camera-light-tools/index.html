Adds lights from camera view through a pie menu, aligned to a chosen object in Blender.

What Camera Light Tools does

Camera Light Tools speeds up lighting a subject from the camera's perspective. While looking through the camera, select an object and pick a light from a pie menu; the new light lines up with that object by itself.

A Link Light feature keeps the light adjustable as it rotates around the subject, and the hotkey is customizable. Version 1.3 has a new design, with earlier releases also included. Product and character artists setting up key and fill lights will find it a quicker alternative to manual positioning.

Key features

  • Add lights from the camera view
  • Automatic alignment to the selected object
  • Link Light for orbiting adjustments
  • Customizable hotkey
