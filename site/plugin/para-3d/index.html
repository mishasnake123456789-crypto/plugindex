What Para 3d does

Para 3d, from Parametric Zoo, is a group of Level 2 scripted plug-ins for 3ds Max and 3ds Max Design. It opens up MaxScript functions so that users can build rule-based design and animation without writing everything by hand.

Para Nodes behave like Helper objects that store information about Max objects and are made and edited only through Para 3d. They fall into Helper Objects, which act on objects, and Controllers, which drive the Helpers. Included are an Edit Poly node with subdivision and smoothing, a Link controller, plane construction and a Text controller. It suits computational designers.

Key features

  • Para Nodes that store data about Max objects
  • Para Helper Objects and Para Controllers
  • Edit Poly node with subdivision and smoothing
  • Link controller for the edited poly object
  • Plane construction and text conversion
