What UbiSoft Pod formats does

UbiSoft Pod formats, by Syroot, opens the file formats of Ubisoft's 1997 racing game Pod, also known as Planet of Death, inside Blender. Tracks, cars, ghosts, images and sounds can be imported, modified and exported.

Track handling includes textures, animations, obstacles, lighting, checkpoints, starting gates, speakers, repair pits, scripting and opponent paths. Cars bring damaged sections, LoD meshes and stats, ghosts can generate opponent paths, and images and sounds are read from containers. CDPatcher-compatible installation files can be exported, and all format versions are supported.

Key features

  • Import and export Pod tracks and cars
  • Track logic, checkpoints and opponent paths
  • Ghost files and sounds from containers
  • Image conversion
  • CDPatcher-compatible export
