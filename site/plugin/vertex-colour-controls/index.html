What Vertex Colour Controls does

Vertex Colour Controls, or VCC, is a Blender plugin for painting precise values into vertex colour data. It targets cases where exact numbers matter more than freehand brushing, such as masks and data stored for game engines.

You choose which of the red, green, blue and alpha channels receive a value, and can use simple 0 to 1 strengths or full colours across several meshes at once. A custom shader, controlled from the VCC panel, displays each channel on its own or the normal RGB view. Strength and colour values can be saved for reuse.

Key features

  • Apply values to several meshes at once
  • Choose which RGBA channels to write
  • Custom shader to view single channels
  • Save strength and colour values for reuse
