Converts Cinema 4D's Volume Builder into voxel shells, cubes, planes or point clouds from meshes, splines, VDBs or Pyro.

What Rocket Lasso Voxel Mesher does

Rocket Lasso Voxel Mesher takes the Volume Builder and outputs it as one of four voxelized forms: Outer Shell, Cubes, Planes or Point Clouds. Inputs can be meshes, splines, VDB files or Pyro simulations.

One click converts the result into a point cloud and Cloner with the same look, scale and color. Colors can be sampled from any image or Cinema 4D shader using the mesh's original UVs, and per-voxel color moves to Color Vertex Maps, Redshift, other renderers or a Cloner. Non-uniform grids and layered meshers at different resolutions are supported. Great for blocky and pixel-style motion graphics.

Key features

  • Outer Shell, Cubes, Planes and Point Cloud outputs
  • Works with meshes, splines, VDBs and Pyro
  • One-click point cloud and Cloner conversion
  • Color sampling from images or shaders
  • Layer meshers at different resolutions
