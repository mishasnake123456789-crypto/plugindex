What Distribute does

Distribute is a small Blender tool by Blenderbob that evens out the spacing of selected objects. It lays them out starting at the first and ending at the last along X, Y or Z.

Diagonal distribution was added in version 1.1.0. The command is in the viewport's Edit tab and requires no special permissions. Layout artists arranging rows of props, columns or repeated elements can avoid manual nudging. It is a modest utility, but it replaces the tedious job of typing coordinates for each object when arranging evenly spaced items.

Key features

  • Even spacing along X, Y or Z
  • Diagonal distribution
  • Located in the viewport Edit tab
  • No special permissions
