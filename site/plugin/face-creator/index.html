What Face Creator does

Face Creator is a Blender plugin from studioromanrec that builds a 3D face from a photograph. With one click it produces a model that already has a material applied.

It is available on Windows, Apple Silicon Macs and Linux, and renders with Cycles and Eevee, and supports Blender 3.3 through 5.0. It is listed as extension compatible and includes documentation. A quick starting point for portraits and likenesses. The generated model can then be refined, rigged or rendered, making it a handy starting point for avatars and stylized portraits.

Key features

  • One-click photo to 3D face
  • Material applied automatically
  • Windows, macOS Apple Silicon and Linux
  • Blender 3.3 through 5.0
