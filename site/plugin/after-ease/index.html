What After Ease does

After Ease is a panel from KraftyFX for crafting bouncy and elastic movement in After Effects. Getting overshoot and spring behavior from standard keyframes is tedious, so this tool lets you shape the curve visually and see it live before committing.

Once the curve feels right, it can be applied as an expression or baked straight into keyframes so you can keep adjusting by hand. It works on selected numeric properties and also on mask and shape paths. The baking step turns the expression result into regular keys, which helps when a project has to be handed on or edited further. Manual installation steps are provided for both macOS and Windows.

Key features

  • Live preview while tuning bounce and elastic curves
  • Apply as an expression or bake to keyframes
  • Works on numeric properties, masks and shape paths
  • Detailed parameters for shaping the motion
