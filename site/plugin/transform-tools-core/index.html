Transform Tools Core

Developer: yasser-idris

FreeBlender

Blender add-on that transforms selections between two gizmo states, moving, rotating and scaling from Previous to Active.

What Transform Tools Core does

Transform Tools Core uses a pair of gizmos to define a start and an end state, then applies the difference between the two matrices to selected elements. Position the Previous gizmo, position the Active gizmo, and the selection moves accordingly.

Translation, rotation and scale are all handled, and the add-on can also set Blender's own transform orientation and pivot point to match the Active gizmo. This is useful for precise placement, alignment of parts and repeating a relationship between two reference frames.

Key features

  • Dual-gizmo state-to-state transformation
  • Translate, rotate and scale in one step
  • Matrix-based transform between states
  • Aligns native orientation and pivot to the Active gizmo
