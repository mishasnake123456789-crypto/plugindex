What iZotope RX Standard does

iZotope RX Standard supplies Premiere Pro editors with tools for fixing clicks, breaths and cross-signal bleed, along with dialogue and music processing. Version 9.3.0 rebuilt De-bleed and Breath Control with machine learning.

De-bleed finds leakage such as headphone bleed without a reference track and includes a real-time plugin. De-click uses a low-latency algorithm, and Dialogue Isolate and Music Rebalance were improved. Other additions include Streaming Preview, Mid/Side mode, Loudness Optimize, and ARA support in the Spectral Editor. Plugin formats are 64-bit only.

Key features

  • Machine-learning De-bleed
  • Neural-net Breath Control
  • Low-latency De-click
  • Improved Dialogue Isolate and Music Rebalance
  • Streaming Preview, Mid/Side and Loudness Optimize
