What Sculpt Layers for Multires does

Sculpt Layers for Multires, by beni, adds layers to Multires sculpting so you can build detail in stages and adjust how strongly each layer shows. Each mesh keeps its own set. It is listed under Sculpt.

It is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.

Key features

  • Per-mesh sculpt layers
  • Strength control for each layer
  • Open source, GPL-3.0-or-later
  • Requires Blender 4.2.0 or newer
