What The Shipwright does

The Shipwright automatically builds sci-fi forms and components in Blender, based on the Big Medium Small principle. Mark Kingsnorth designed it for modelers, game developers and concept artists who want starting points for further modeling or sculpting.

Changing parameters updates the objects live, a levels interface scatters layers of parts, and an iterator can create many variations overnight. An editable lattice cage is attached for shape changes, and you can add your own objects. Spaceship and vehicle designers explore concepts rapidly.

Key features

  • Live-updating parameters
  • Levels interface for scattering layers
  • Iterator for many variations
  • Lattice deformation cage
  • Support for custom objects
