What Extrude Along Path does

Extrude Along Path is a Blender add-on by RobbieK that sweeps profile geometry along a path, either by extruding or by raking. This is a revival of a tool from the 1D_scripts set that dates back to Blender 2.x, republished via the extensions library.

It supports Blender 4.2 LTS and newer, is released under the GNU GPL v3 or later, needs no special permissions and is a download of only about 15 KB. It serves modelers who want to build pipes, rails and trims from a profile and a path.

Key features

  • Extrudes or rakes profiles along a path
  • Revived from the 1D_scripts collection
  • Supports Blender 4.2 LTS and newer
