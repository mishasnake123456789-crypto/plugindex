What Blender Batch Renamer & Sorter does

Blender Batch Renamer & Sorter is an organization add-on for tidying scene contents. It previews all name changes before they are applied, so mistakes can be caught first.

A sorting engine arranges objects by several criteria in one click, and intelligent naming detects object types to add prefixes such as MSH_ and CAM_. Collection order is managed, with prefix and suffix options. It is a good fit for artists preparing scenes for handoff.

Key features

  • Visual preview of name changes
  • One-click sorting by multiple criteria
  • Type detection with prefixes like MSH_ and CAM_
  • Collection order management
