Places a four-sided image plane and a height box in the 3ds Max viewport, with hide and opacity controls for both and freeze for the plane.

What Drop4Side does

Drop4Side places a four-sided image plane in the 3ds Max viewport, typically used as a modeling reference. Controls let you select, hide or freeze the plane and change its opacity, so it can stay out of the way when not needed.

A height box is available too, with separate height, hide and opacity settings, giving a quick volume reference for scale. Installation is a drag and drop of the .ms file into the viewport, and the tools then appear under DW tools in Customize User Interface. It helps modelers working from blueprints or reference views set up reference geometry quickly.

Key features

  • Creates a four-sided image plane
  • Select, hide, freeze and opacity controls
  • Height box with height, hide and opacity settings
  • Drag-and-drop .ms installation
  • Tools listed under DW tools
