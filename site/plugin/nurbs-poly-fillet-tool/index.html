Blender add-on that fillets curve corner points from a curve edit mode context menu and can reverse the fillet.

What NURBS/Poly Fillet Tool does

NURBS/Poly Fillet Tool adds a Filet Helper entry to the context menu in Blender's curve edit mode. Pick a corner control point, open the context menu and choose Fillet Curve Points to round it off.

A matching Merge Points at Segment Intersection command reverses the operation, collapsing the created points back to one corner. This is helpful when drawing technical outlines, logos or paths where rounded corners need to be added or removed without redrawing.

Key features

  • Context menu in curve edit mode
  • Fillet Curve Points command
  • Merge Points at Segment Intersection to reverse
  • Works on corner control points
