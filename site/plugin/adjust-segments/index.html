A Blender add-on that resamples the segment count of polylines and quad surfaces from the right-click menu.

What Adjust Segments does

Adjust Segments changes how many segments make up a line or a quad surface in Blender. After selecting a polyline or surface, right-click and choose the operator to resample it, with the add-on detecting the context itself through one operator.

A Segments parameter sets the new count, a Uniform option controls whether vertices are spaced evenly, and Use Increment makes the number an addition rather than a direct total. Documentation is included. Modelers adjusting edge density on curves, rails or panels without rebuilding topology will find it simple and direct.

Key features

  • Resamples polylines and quad surfaces
  • Right-click menu access
  • Segments count parameter
  • Uniform spacing option
  • Increment mode
