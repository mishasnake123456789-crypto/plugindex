An Adobe panel for editing, transferring and exporting Premiere Pro project item metadata and clip markers.

What Metadata Handler does

Metadata Handler manages the columns of project item metadata. Column to Column Changer copies or swaps values between fields, and Column Data Changer adds prefixes or suffixes, applies sequential numbering like 01_ or 02_, or overwrites entries.

Delete Column Data clears columns in bulk. Metadata Exporter writes CSV or TSV with SMPTE, Frames or Feet+Frames time formats, and Clip Marker Exporter sends clip markers out as well, with multicam supported.

Key features

  • Copy or swap metadata between columns
  • Prefix, suffix and sequential numbering
  • Bulk clear of column data
  • CSV/TSV export with SMPTE, Frames or Feet+Frames
  • Clip marker export with multicam support
