What Procedural Clock does

Procedural Clock builds animated digital clocks in Blender with Geometry Nodes. You set the time and speed, and the animation runs on its own without keyframes.

A hologram effect turns flat text into layered 3D visuals with adjustable layer depth, and a glitch system adds distortion. It supports 12-hour and 24-hour timers with customizable color, spacing and layout. Useful for sci-fi interfaces, countdowns and title sequences. In practice that means runs without keyframes and hologram effect with layer depth control.

Key features

  • Runs without keyframes
  • Hologram effect with layer depth control
  • Built-in glitch system
  • 12h and 24h timers
