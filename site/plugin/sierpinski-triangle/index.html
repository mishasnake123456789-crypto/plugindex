What Sierpinski Triangle does

Sierpinski Triangle, by Jonny-B, produces the well-known fractal in Blender. It creates flat Sierpinski triangles and three-dimensional Sierpinski pyramids, and any mesh can serve as the building block of a pyramid.

The generator is found in the 3D Viewport under Add > Mesh > Sierpinski. It is a fun tool for generative art, math demonstrations and decorative geometry, giving fractal forms without scripting.

Key features

  • 2D Sierpinski triangle generation
  • 3D Sierpinski pyramid generation
  • Stack any mesh into a pyramid
  • Located in Add > Mesh > Sierpinski
