After Effects plugin that adds chamfers and bevels to text and shapes using luma, alpha or height map sources.

What Bevelizer does

Bevelizer by Dragoy styles text, logos and other shapes with chamfered or beveled edges in After Effects. It offers three source modes: Luma reads edges from brightness for footage, Alpha uses transparency for clean text and vector work, and Height Map treats luminance as depth data.

Matcap creation tools are included, and a free browser-based web tool can be reached from the Matcap Gallery via the Create Matcap button. Smart Jitter introduces small variations, while Full Shuffle picks random curve presets and matcaps to spark ideas quickly. Motion designers can get dimensional surfaces without a full 3D app.

Key features

  • Luma, Alpha and Height Map modes
  • Matcap creation tools
  • Free browser-based web tool
  • Smart Jitter for subtle variations
  • Full Shuffle of curve presets and matcaps
