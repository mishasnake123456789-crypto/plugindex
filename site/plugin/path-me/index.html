Copies and imports asset file paths in After Effects with a single click.

What Path Me does

Path Me deals with the file paths of your assets. One click copies paths from the Project panel, timeline or render queue to the clipboard or a file, for single or multiple selections.

With nothing selected it scans the whole active panel, and selecting comps scans their contents, with an option to include sub-comps. It also imports files from paths on the clipboard and understands both Mac and PC paths. Useful for documentation, handoffs and relinking.

Key features

  • Copy paths to clipboard or file
  • Works from project panel, timeline or render queue
  • Scans comps and optionally sub-comps
  • Imports files from copied paths
  • Mac and PC path support
