What Smart Transform does

Smart Transform, by Claz_Arts, is a tiny Blender utility for working with many objects. It filters and selects objects according to size, position or transforms, so you do not need to pick through the Outliner.

One-click buttons invert the current selection and apply transforms. The download is only 2.6 KB, it needs no special permissions, works on Blender 4.2 LTS and newer, and is released under GPL v3.0 or later.

Key features

  • Select objects by size or position
  • Filter by transforms
  • One-click invert selection
  • One-click apply transforms
  • Only 2.6 KB
