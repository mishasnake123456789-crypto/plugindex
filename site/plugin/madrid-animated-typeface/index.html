What Madrid - Animated Typeface does

Madrid is a monoline geometric typeface from Animography, drawn with even strokes and given spirited animation for each character. It works inside After Effects compositions to build kinetic titles quickly.

Version 1.5 improved layer setup and controllers, and it works with the Animography Controller, Font Manager and the JSX format. It supports After Effects 2020 through 2024, and suits clean, modern branding. With the controller and layer setup ready to go, titles can be styled and timed with little manual keyframing.

Key features

  • Geometric monoline letterforms
  • Lively character animations
  • Works with Animography Controller
  • Optimized layers and controllers in 1.5
  • Font Manager and JSX support
