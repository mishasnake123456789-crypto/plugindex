What Polylink - Blender To Unreal Engine Exporter does

Polylink is a Blender addon from Poly Playground that connects Blender to Unreal Engine. It exports selected objects with one click, can create and manage folders to keep content organized, and lets you customize export paths.

Unreal import is triggered automatically, and Live Link support updates assets in real time between the two programs. Skeletal meshes can be exported in combined or uncombined forms, with combine options for meshes. It reduces the manual FBX handling that usually slows down the Blender to Unreal pipeline.

Key features

  • One-click export of selected objects
  • Folder creation and custom export paths
  • Automatic Unreal Engine import triggers
  • Live Link for real-time updates
  • Skeletal mesh export, combined or separate
