What Text At Marker does

Text At Marker, from Motion Embassy, ties text animation to markers in After Effects. You choose how many and which words, characters or lines animate at each marker, which makes syncing type to music or narration straightforward.

Animation can start at each unit using a delay or markers, and groups are formed by adding a number to a marker. Six directions are offered: Default, Reversed, Outwards, Inwards, Random and User Defined, where order comes from the layer name. Multiple effects can be stacked with keyframes and easing tweaked for each. Select layers to use layer markers, or select nothing for composition markers.

Key features

  • Marker-triggered text animation
  • Word, character or line granularity
  • Six direction modes including User Defined
  • Stackable effects with adjustable easing
  • Layer or composition markers
