A Blender add-on that sets vertex colors on selected objects or vertices, or assigns random colors per object.

What Selectedtovertexcolor does

Selectedtovertexcolor is a handy tool for painting vertex colors in Blender without brush work. In Object Mode it applies one chosen color to every selected object, or gives each selected object its own random color. In Edit Mode it colors the selected vertices.

You can colorize sharp regions or create smooth transitions, and trigger the action with a click or a customizable keyboard shortcut. Documentation is included. It is useful for creating ID-style colors, masks and quick shader inputs for game assets, and for anyone who needs to tag many objects with distinct colors.

Key features

  • Apply a chosen color to selected objects
  • Random color per object
  • Vertex coloring in Edit Mode
  • Sharp or smooth color transitions
  • Shortcut or one-click trigger
