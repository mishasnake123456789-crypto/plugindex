What View Layers Toolbox does

View Layers Toolbox helps manage view layers in Blender, particularly for rendering. It is meant for scenes with large numbers of layers.

Update passes copies the passes and AOVs of a reference layer onto another view layer, and Update file outputs builds a compositing tree that renders your layers according to their passes and scene outputs. Documentation is included and it is GPL licensed.

Key features

  • Match passes and AOVs to a reference layer
  • Auto-built compositing tree for outputs
  • Designed for many view layers
  • Documentation included
