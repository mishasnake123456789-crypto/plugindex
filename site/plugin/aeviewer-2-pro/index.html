What AEVIEWER 2 Pro does

AEVIEWER 2 Pro extends MotionLand's media browser for After Effects and Premiere Pro. Projects, presets and media files can be previewed, applied and imported in one click, with more formats and import options than the basic edition.

Template authors get specific tools, including support for trial and encrypted packs. It handles responsive MOGRTs, FFX presets with animated previews and preset-type detection that creates the right layer, and imports EXR sequences, SVG files and drag-and-dropped files.

Key features

  • One-click preview, apply and import
  • Authoring tools for template creators
  • Trial and encrypted pack support
  • Responsive MOGRTs and FFX presets
  • EXR sequence and SVG import
