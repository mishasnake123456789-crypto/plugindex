What Baga Batch does

Baga Batch automates building an asset library in Blender. It renders previews with Cycles or Eevee, at roughly half a second to one second per asset depending on the setup, and exports each item to its own .blend file in the library folder you choose.

It handles collections and objects, including meshes and curves, along with materials. Asset creators who need to process dozens of items can save a great deal of manual marking and rendering.

Key features

  • Asset preview rendering with Cycles or Eevee
  • About half a second to a second per asset
  • Exports collections, objects and materials
  • One .blend file per asset in your library
