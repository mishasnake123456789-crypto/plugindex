What Levitation Pro does

Levitation Pro builds looping animation using a Sine-Wave Engine tied to the project timeline. A Cycles parameter runs a set integer number of full oscillations across the scene length, so loops are exact.

Animation ends precisely where it began with no jumps or stutter. Floating logos, hovering products and idle motion loops become easy for motion designers. In practice that means sine-Wave Engine tied to the timeline and integer cycles over the scene length.

Key features

  • Sine-Wave Engine tied to the timeline
  • Integer cycles over the scene length
  • Zero jitter, perfect loop sync
  • One-click setup
