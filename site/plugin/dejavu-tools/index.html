Blender add-on that highlights tris, n-gons and quads, auto-orients meshes and opens the current .blend folder.

What Dejavu Tools does

Dejavu Tools helps modelers find topology problems faster. It colours faces by vertex count, so triangles and n-gons stand out, and a quick selection option isolates tris, n-gons or quads for cleanup. An optional face-number overlay allows closer inspection.

It can also orient a mesh automatically from selected faces or edges in both Object and Edit Mode, which helps with imported geometry. A separate command opens the folder of the active .blend file straight from Blender. It supports Blender 4.5 to 5.1 on Windows, macOS and Linux.

Key features

  • Highlights faces by vertex count
  • Quick selection of tris, n-gons and quads
  • Optional face-number overlay
  • Auto-orients meshes from selected faces or edges
  • Opens the active .blend folder
