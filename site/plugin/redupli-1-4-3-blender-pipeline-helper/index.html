What Redupli 1.4.3 - Blender Pipeline Helper does

Redupli automates repetitive game-development pipeline steps in Blender. A one-click ReEx action chains collection processing, export and file copying.

The Collections Processor applies modifiers and flattens meshes, a multi-preset exporter writes FBX, OBJ and glTF together, and a file watcher syncs to Unity or Unreal folders when timestamps change. The Material Manager relinks duplicate slots and removes orphaned datablocks, and UDIM tools generate and rename tiles. It helps artists baking in Marmoset or Substance.

Key features

  • One-click collection, export and copy pipeline
  • Simultaneous FBX, OBJ and glTF export
  • Auto-sync to Unity or Unreal directories
  • Material cleanup and UDIM tools
