What Hudinator: Sci-Fi Ui Visualizer does

Hudinator is a Blender plugin for building sci-fi HUD panels. It comes with 140+ elements you can import: 60 made with Geometry Nodes for editing and 83 basic decals. It works in EEVEE and Cycles.

Each element has a settings window split into Settings, Material and Transform sections. Motion designers can assemble futuristic interfaces quickly. With ready elements and editable settings, users can compose convincing futuristic displays for films, games and motion pieces quickly.

Key features
