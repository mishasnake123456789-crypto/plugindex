What Arraytool does

Arraytool is a Blender plugin for making repeated copies. It arrays a single object or a whole collection in one of three ways: straight, circular or along a curve.

Meshes, lights, text objects and curves are all supported, with count, rotation, scale and spacing adjustable. Circular arrays can be centered on the 3D cursor or on the object itself. Useful for fences, columns and decorative patterns. Multiple methods in one add-on replace several modifiers and manual steps, which makes repetitive layouts faster to build and revise.

Key features

  • Straight, circular and curve arrays
  • Single objects or collections
  • Count, rotation, scale and spacing controls
  • Meshes, lights, texts and curves
