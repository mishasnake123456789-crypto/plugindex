What Blocksurfaces-References-Tool does

Blocksurfaces-References-Tool prepares reference material inside Blender before you start modeling a character or object. Rather than juggling external image viewers, you keep references in the 3D view.

Images can be dragged into the scene and set as front and side references in one click, or you can draw references with Grease Pencil, optionally mirrored for symmetry with an Apply Mirror and Join action. A distance setting spaces them from the model center, separate opacity sliders can be linked, references can be hidden by type or locked, and keyboard shortcuts toggle visibility.

Key features

  • Drag-and-drop front and side references
  • Grease Pencil references with mirror support
  • Separate opacity controls, optionally linked
  • Hide, show or lock references by type
