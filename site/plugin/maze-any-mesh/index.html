Blender add-on that builds a maze over any selected mesh area or vertex-edge network using a recursive backtracker.

What Maze any Mesh does

Maze any Mesh creates mazes in Blender by running a recursive backtracker algorithm over the selected part of a mesh. It is also able to make 3D mazes from networks of vertices and edges.

A random seed produces a different maze from the same selection, and a braiding slider controls dead ends, with higher values giving fewer dead ends and more loops. Game designers and generative artists can obtain unusual labyrinth geometry.

Key features

  • Recursive backtracker algorithm
  • Random seed for variations
  • Braiding slider controls dead ends
  • 3D mazes from vertex-edge networks
