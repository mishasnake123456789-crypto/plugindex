What Smoke-Wish does

Smoke-Wish, by Holapro, offers pre-rendered atmospheric elements for Blender, including smoke, steam, clouds and fire. Because the simulations are already baked into the presets, you do not need to run or wait for fluid simulations.

Presets are applied by drag and drop, come at 2K resolution and 300 frames long, and use little RAM while rendering quickly. Documentation is included. It is a practical shortcut for artists who need convincing effects on a deadline.

Key features

  • Baked smoke, steam, cloud and fire presets
  • Drag-and-drop application
  • 2K resolution and 300 frames each
  • Low RAM usage and fast renders
  • Documentation included
