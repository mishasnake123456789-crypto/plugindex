What Nodepastr - Copy And Paste Node Groups Between Files does

May3D's NodePastr transfers node groups between separate Blender files without appending or linking. Choose a group and copy with Ctrl+Shift+C, open the other file, and paste with Ctrl+Shift+V.

Both shader and geometry node groups are handled. Documentation is included and the add-on is GPL licensed. It helps artists carry tools across projects or exchange node setups with collaborators. Compared with appending or linking blend files, it skips the dialogs and keeps the destination file clean.

Key features

  • Copy node group with Ctrl+Shift+C
  • Paste into another file with Ctrl+Shift+V
  • Shader node groups
  • Geometry node groups
  • Documentation included
