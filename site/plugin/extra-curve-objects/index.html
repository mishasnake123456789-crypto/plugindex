What Extra Curve Objects does

Extra Curve Objects, a community add-on, supplies Blender with additional ready-made curve shapes. It was bundled with Blender 4.1 and is found in the 3D viewport under Add > Curve > Extra Objects.

In version 0.2.0 the Add menu was grouped into subcategories, and add-on preferences let you choose which entries show up. The redo panels of all operators received a new interface, and some names and icons were changed for clarity. No special permissions are needed. Anyone modeling with curves, such as for profiles, wires or lettering paths, gets a faster start.

Key features

  • Extra curve types in the Add menu
  • Subcategories added in 0.2.0
  • Preferences to choose menu entries
  • Redesigned redo panels
