Blender add-on that resizes textures dynamically to cut memory use and render time on low-end hardware.

What Optimem does

OptiMem lowers texture memory demands in Blender while trying to keep render quality intact. It is aimed at artists working on modest hardware who run into storage or VRAM limits.

Texture resolutions are adjusted automatically to balance quality and performance, and VRAM load is reduced to help avoid out-of-memory failures. Frame-by-frame optimization suits animation and complex scenes, and scaling can be filtered by texture type. Render and load times drop as a side effect.

Key features

  • Dynamic texture resizing
  • Lower VRAM use to avoid memory errors
  • Frame-specific optimization
  • Filter scaling by texture type
  • Shorter render and load times
