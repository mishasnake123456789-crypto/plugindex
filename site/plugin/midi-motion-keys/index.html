Imports MIDI files into Blender and animates cube keyboards, one per track, in time with the music.

What Midi Motion Keys does

Midi Motion Keys visualizes music as playing keyboards. After importing a MIDI file, it generates a 3D keyboard for each track, built entirely from cubes.

While the music plays, every cube sinks along the z-axis to imitate a key press. Everything is set up with a single import button. It is compatible with Blender 4.0 through 4.3. Motion designers and music video makers can create piano-roll style animations without keyframing notes by hand.

Key features

  • MIDI file import
  • One cube keyboard per track
  • Cubes press down on the z-axis in sync
  • Blender 4.0 through 4.3
