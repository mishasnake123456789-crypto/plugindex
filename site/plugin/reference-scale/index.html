What Reference Scale does

Reference Scale, by Micah-Ganske, lets you drop flat scale references into a Blender scene with a few clicks, giving you something to judge proportions against while modeling. It falls under Workflow.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.

Key features
