What Change Frame Rate does

Change Frame Rate is a Blender add-on that handles FPS conversion from the Output Properties panel. Changing frame rate normally throws off timing; this does the stretching and frame range changes for you.

A 10-second animation stays 10 seconds long regardless of the new FPS, and smart undo reverts the settings quickly. It is useful for artists delivering the same animation at 24, 30 or 60 fps. Among its tools are one-click FPS conversion and automatic time stretching and frame range.

Key features

  • One-click FPS conversion
  • Automatic time stretching and frame range
  • Timing preserved at any FPS
  • Smart undo
