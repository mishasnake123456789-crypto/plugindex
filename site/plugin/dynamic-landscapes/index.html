What Dynamic Landscapes does

EBTRR's Dynamic Landscapes lets you shape terrain and watch it change live in the Blender viewport. A landscape is made from a material plus base-height and sub-height textures through Create Function Mesh.

Control comes from a Landscape Mover Empty and a 3D View panel, both animatable, so terrain can drift or travel. A Ramp option gives a stepped, stylized look, and two Clean Up options plus smoothing refine it. Many parameters can be animated. Good for fly-overs and stylized worlds.

Key features

  • Live viewport updates
  • Landscape from material and height textures
  • Animatable Landscape Mover Empty
  • Ramp option for stylized steps
  • Clean Up options and smoothing
