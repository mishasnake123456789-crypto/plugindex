What Little Helper: The Essential Blender Productivity Addon does

Little Helper is a grab bag of everyday Blender shortcuts from ahnickart. Rather than one big feature, it trims friction from many small tasks in animation, character work and simulation scenes.

Object tools handle batch renaming, vertex colors and random rotation or scale. Auto Rig Pro owners get weight copying to outfits and constraint setup. Export presets cover FBX, OBJ and an Unreal Engine 5 variant, and physics buttons add cloth, collision, fluid or rigid body. Render helpers set preview or final resolution, convert metric lengths to pixels, estimate how long an animation will take, and store keyframe ranges.

Key features

  • Batch rename and vertex color tools
  • Auto Rig Pro helpers
  • FBX, OBJ and UE5 export options
  • One-click physics setup
  • Preview and final render setup
