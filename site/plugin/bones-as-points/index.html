Blender add-on that shows armature bones as simple points, toggled non-destructively without changing bone data.

What Bones As Points does

Bones As Points changes how armature bones are drawn in Blender, replacing the usual head-and-tail shape with points. The display is only visual, so you can switch it off at any time.

Armature data is not modified, so exported rigs and animations remain compatible with the original application. Hierarchy lines are drawn between points, working partly in edit mode. It helps when cleaning up imported armatures whose bone orientations are wrong or whose hierarchy is messy. Documentation is included.

Key features

  • Displays bones as points
  • Non-destructive toggle
  • Leaves armature data untouched
  • Draws bone hierarchy lines
  • Useful for tidying imported rigs
