What Mirrorpro does

MirrorPro, from Orcavia, speeds up symmetry in Blender. You add a mirrored or symmetrized copy of an object with one click, on any axis direction, choosing that direction through an interactive gizmo instead of fiddling with modifier settings.

It supports Blender versions 3.0 through 5.0, is released under the GPL and includes documentation and a demo video. Modelers working on characters, vehicles or props who regularly need a quick mirror on a chosen axis will find it cuts down on the manual setup normally needed.

Key features

  • One-click mirror or symmetrize
  • Interactive gizmo picks the direction
  • Any axis direction
  • Supports Blender 3.0 to 5.0
  • Documentation and demo video
