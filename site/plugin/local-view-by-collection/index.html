What Local View by collection does

Local View by collection, from D3W3, sends the objects belonging to a chosen collection into Blender's local view, so you can focus on one group without selecting each object. It is listed under 3D View, Object and User Interface.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.
