What Super3D Import & Export .Hiplc does

Super3D Import & Export .Hiplc adds Houdini Indie scene support to Blender. It provides File menu entries for import and export and relies on the Super3D cloud service for conversion.

Importing uploads the .hiplc file and merges the downloaded result into the current scene, preserving cooked geometry. This lets artists move Houdini Indie work into Blender for lighting, rendering or further modeling without opening Houdini. In practice that means file menu entries for .hiplc and cloud-backed conversion.

Key features

  • File menu entries for .hiplc
  • Cloud-backed conversion
  • Import merges into the active scene
  • Preserves cooked geometry
