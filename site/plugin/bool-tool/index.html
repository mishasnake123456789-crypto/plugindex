Blender add-on for fast boolean cutting with brush booleans, auto cuts and carver tools for hard-surface modeling.

What Bool Tool does

Bool Tool speeds up boolean work in Blender, which is common in hard-surface modeling. It wraps modifier-based cutting and joining into quick operators so that shapes can be subtracted from others in a couple of clicks.

Brush booleans add modifiers on the fly, auto boolean performs destructive cuts, and workspace tools let you carve objects with custom shapes in both object and edit modes. The carver tools are ported from the Carver add-on, and cutters can be drawn directly on a mesh surface through surface alignment. Utilities help manage, remove and apply boolean modifiers. Product designers and environment artists use it constantly.

Key features

  • Brush booleans using modifiers
  • Destructive auto boolean cuts
  • Carver tools in object and edit modes
  • Surface alignment for drawing cutters
  • Utilities to manage and apply modifiers
