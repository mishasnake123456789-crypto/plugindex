What TerrainAxe does

TerrainAxe groups tools for building accurate terrain landscapes in 3ds Max. Its eight categories cover selection, creation, construction, cutting and scene tools, plus common utilities, aimed at roads, flyovers, bridges, stairs, pavements, clearings and handrails.

Selection tools pick vertices, edges and faces, such as part of a border between two vertices. Creation tools make curbs, runlines, stairs, handrails and pavement. Construct tools smooth roads, round vertices, weld vertices to edges and stitch polygons, while cutting tools lay out topology lines and grid-cut polygons. Scene tools use AdvArray to place handrails, piers, trees and street lamps. One-key DWG import and UVW tools are included.

Key features

  • Selection tools for vertices, edges and faces
  • Curb, runline, stair, handrail and pavement creation
  • Road smoothing, welding and poly stitching
  • Topology line layout and grid cutting
  • AdvArray placement of lamps, trees and piers
