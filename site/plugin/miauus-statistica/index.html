What miauu's Statistica does

Statistica by miauu expands the statistics shown in 3ds Max for the current selection and the whole scene. Four customizable sections report on the selection, the scene contents, sub-object counts and transforms.

For a selection it lists layer, material name and class, number of textures and missing textures, modifiers, Object ID and size. Scene totals cover geometry, shapes, lights, cameras, helpers, xRef scenes and the render name. Sub-object totals cover vertices, edges, faces, elements, segments and splines for editable objects and Edit modifiers. Selected cameras show FOV and focal length, and PRS info appears while transforming. Colors, an optional opaque box, and three fonts allow styling.

Key features

  • Selected object details including material, textures and modifiers
  • Scene totals for geometry, lights, cameras and xRefs
  • Sub-object counts for polys, meshes and shapes
  • FOV, focal length and live position, rotation and scale info
  • Four toggleable sections with colors, box and font options
