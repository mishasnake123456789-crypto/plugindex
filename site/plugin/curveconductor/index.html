What CurveConductor does

CurveConductor by David Beal brings curve-driven timing to After Effects. Instead of tuning bezier handles on every property separately, you create a control curve once and let several properties reference it.

Each curve is a single editable element, and any property pointing at it updates live as you reshape it. That makes custom easing consistent across a project and removes the effort of matching eases by hand. It works with After Effects 2022 through 2026, and animators who build coordinated moves benefit most.

Key features

  • One control curve drives many properties
  • Each curve is a single editable element
  • Live updates as you refine the curve
  • Custom curves without matching eases per property
  • Works with After Effects 2022 through 2026
