Shows and edits node parameters in the Blender sidebar, from node editors or the 3D Viewport, without changing workspace.

What Peek A Node does

Peek a Node shows the settings of your nodes in the Sidebar, so you can adjust values without hunting through a large graph. It is available in both the node editors and the 3D Viewport.

Nodes are arranged in node collections, much as objects are in Blender, and the add-on reproduces almost every native node interface. Shader artists and procedural modelers can tweak a material while looking at the model in the viewport instead of switching screens.

Key features

  • Sidebar view of node parameters
  • Works in Node Editors and 3D Viewport
  • Node collections for organization
  • Mirrors native node interfaces
