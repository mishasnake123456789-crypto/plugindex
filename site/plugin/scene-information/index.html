What Scene Information does

Scene Information is a simple utility that displays information about the open .blend file in Blender. It gives you a quick overview without digging through menus or the outliner.

It is helpful when checking what a file contains, particularly when inspecting files from other people or reviewing project contents.

Key features

  • Panel with file details
  • Quick scene overview
  • Lightweight utility
