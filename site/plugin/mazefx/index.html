What mazeFX does

mazeFX, made by Real Creations, is a plugin for After Effects that draws random vector mazes, or labyrinths. A maze can include a unique solution path, and masks define the shape each maze takes.

Effect controls give full command over its appearance. Output can be placed in a single shape layer or in separate layers for each part. A seed field and a random seed checkbox regenerate the same maze exactly, and a faster algorithm yields cleaner paths. It suits puzzle graphics, game backgrounds and decorative patterns.

Key features

  • Random vector mazes and labyrinths
  • Optional unique solution
  • Mask-controlled maze shapes
  • Single or separate shape layers
  • Seed control for repeatable mazes
