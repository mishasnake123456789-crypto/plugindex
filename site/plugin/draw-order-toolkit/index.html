3ds Max tools for troubleshooting draw call and render order of objects, with a face index viewer.

What Draw Order Toolkit does

Draw Order Toolkit helps diagnose order-dependent display problems in 3ds Max, notably for game exports where transparency means objects must render in a certain sequence. Refresh List shows the current draw order of objects in the scene.

Tick Geometry Only to limit the list to poly and mesh objects, and use the top-row buttons to reorder one or several selected objects. Show Index toggles a display of face indexes for the selected polygons. It works with all versions of 3ds Max, and is of most use to game artists tracking down sorting issues.

Key features

  • Refresh List shows object draw order
  • Geometry Only filter
  • Buttons to change draw order of selected objects
  • Face index display for polygon selections
  • Works with all 3ds Max versions
