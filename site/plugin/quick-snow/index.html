What Quick Snow does

Quick Snow is a Blender add-on by Anindya Jana that adds snow to any object or an entire scene by controlling the shader. It draws on geometry nodes, physically based snow materials, masks and a set of Geotools to build wintry environments.

The add-on automatically creates a dynamic snow material, wiring your existing principled BSDF, normal map and albedo map into a snow blend node, and it also copes with foliage shaders. Geotools include a snow mesh, real-time icicles and snow footprints. Blending controls handle normal blend, pixel blend and softness, and snow masks can be gradient, texture, vertex paint or edge-based.

Key features

  • Automatic dynamic snow material creation
  • GeoSnow Mesh, GeoIcicles and GeoSnow Footprint tools
  • Normal blend, pixel blend and softness controls
  • Gradient, texture, vertex paint and edge masks
  • Foliage shader support
