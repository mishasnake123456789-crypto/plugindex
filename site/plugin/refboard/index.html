What RefBoard does

RefBoard is a Blender plugin that gives you a reference board without leaving the program. It adds a dedicated node editor where images live, so inspiration and model sheets stay beside your work instead of in a separate app.

You can drag in images and PDFs, paste screenshots with Ctrl+V, or add files from the sidebar. Selected images can be laid out as rows, columns or an automatic grid, aligned to the active image, matched in width or height, and rotated or mirrored. Boards can be created and switched as needed.

Key features

  • Drag and drop images and PDFs, or paste from clipboard
  • Arrange as row, column or automatic grid
  • Align and match size to the active image
  • Rotate or mirror individual references
