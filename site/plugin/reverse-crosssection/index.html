What Reverse crosssection does

Reverse crosssection is a script from Chuggnut for 3ds Max 4.x that works on a skinned model. It flips the order of the model's crosssections, which can correct a surface whose sections run in the wrong direction.

The tool is at version 2.3.5, is free, and is available from the developer. It is a narrow utility, so it mainly serves artists still on that old release who build skinned surfaces from crosssection shapes and need to change their order without rebuilding the object by hand.
