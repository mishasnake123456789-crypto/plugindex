Blender bundle for batch texture assignment, node cleanup, baking and quick object edits.

What Quick Tools does

Quick Tools folds five Blender utilities into one add-on, with Shake Cut, Quick Modify, Node Tools, AutoTex and Quick Bake as the parts. It leans toward people who handle many downloaded assets, scans or game-ready models and want materials set up without manual node work.

AutoTex imports a batch of model files and recognizes texture types from keywords, then builds a tidy Principled BSDF with correct color spaces. Node Tools adds a masonry-style layout, a live node counter and flexible muting. Quick Bake writes shader outputs to versioned PNGs, and Shake Cut breaks node links with a shake gesture. A material manager can detect UDIM sets.

Key features

  • Batch model import with texture auto-assignment
  • Keyword-based texture type recognition
  • Node layout, counter and muting tools
  • Quick Bake to versioned PNG files
  • Shake gesture to disconnect nodes
