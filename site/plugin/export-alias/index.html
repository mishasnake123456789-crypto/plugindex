Exports Blender meshes, materials and collections to Autodesk Alias as SubD or Mesh, shaders and layers.

What Export Alias does

Export Alias connects Blender to Autodesk Alias for design workflows. Meshes go across as SubD or Mesh objects, materials become shaders and collections become layers.

Options include Selected Only, Batch mode, Up and Forward axis selection and Apply Modifiers. A Disable Booleans option exports tool objects separately so they can be used for trimming in Alias, and non-manifold geometry can be handled separately. Industrial and automotive designers moving concepts into Alias will find it streamlines the handoff.

Key features

  • SubD or Mesh object export
  • Materials as shaders, collections as layers
  • Selected Only, Batch and axis options
  • Disable Booleans for trimming in Alias
