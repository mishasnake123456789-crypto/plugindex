Blender network render farm system that spins up cloud machines on GCP or AWS or drives an existing local farm.

What Blendnet does

Rendering heavy animation on one workstation can take days. State Of The Art LLC's Blendnet builds a render farm for Blender that either provisions the needed resources from a cloud provider or automates a farm you already run. GCP, AWS and local providers are supported.

A live preview refreshes by default every five seconds, and it can be closed and reopened without disturbing the job. Workers shut down when the queue is empty, avoiding wasted cost. Studios and freelancers can scale beyond their own hardware.

Key features

  • Supports GCP, AWS and local providers
  • Dynamic preview updated every five seconds
  • Preview can be reopened without interrupting
  • Workers terminate when tasks finish
  • Automates private farm infrastructure
