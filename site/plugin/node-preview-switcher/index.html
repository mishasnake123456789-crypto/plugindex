What Node Preview Switcher does

Node Preview Switcher speeds up checking shader work in Blender. As you edit, it connects the active or modified node to the material output so you see the result straight away, then reconnects the nodes to their original state after a delay you set.

Preview can target the node being changed or the currently active one, your changes are preserved when links are restored, and header controls in the Shader Editor manage it. Shader artists who normally connect and disconnect nodes by hand to inspect masks and textures will save many repetitive steps.

Key features

  • Auto-connects active or modified node to output
  • Choose changed node or active node preview
  • Restores original links after a set delay
  • Preserves your changes
  • Header controls in the Shader Editor
