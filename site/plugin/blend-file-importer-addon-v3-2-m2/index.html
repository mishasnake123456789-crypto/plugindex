What Blend File Importer Addon V3.2(M2) does

This Blender add-on pulls 3D models out of a .blend file without having to open it. Install it, pick the file path and click Import.

It also imports obj, stl, x3d, fbx and glb/gltf files. Checkboxes decide whether cameras and lights come along from a blend file, and a Merge & Import option brings objects in joined together. It speeds up reusing assets from older projects and libraries. Highlights include import from blend files without opening, OBJ, STL, X3D, FBX, glTF support and camera and light import toggles.

Key features

  • Import from blend files without opening
  • OBJ, STL, X3D, FBX, glTF support
  • Camera and light import toggles
  • Merge & Import option
