Blender add-on that turns geometry-nodes raycasting into scanner and hologram effects.

What Raycast Scanner (Addon) does

Raycast Scanner wraps Blender's geometry nodes raycast function in a simple workflow. Select objects, click Apply scanning, and one object sweeps the others within a distance range, revealing them as if scanned.

The modifier exposes minimum and maximum distance and normal angle, rim blur, rotation, visual helpers and sparkles. A Material Mixer node group brings the output attributes, such as inside, outside and rim, into the Shader Editor. Sample setups include a sphere scan, a monkey hologram, a wobbling sphere and a hot metal ball. Documentation is bundled. It suits artists after holographic or x-ray style looks.

Key features

  • One-click scanner modifier setup
  • Distance, angle and rim controls
  • Material Mixer shader node group
  • Sample scenes and materials
  • Attributes usable in shaders and geometry nodes
