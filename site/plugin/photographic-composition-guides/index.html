What Photographic Composition guides does

Photographic Composition guides, from Atelier Bump, overlays compositional helpers in the 3ds Max viewport. It can draw quadrants, rule of thirds, custom n by N grids, golden proportions, and golden ratio rectangles or spirals.

Guides are positioned with the mouse and can be vertical, horizontal, a cross or radiating from a point. Several two-point aligned lines can be placed from a common base point, useful for perspective lines from a vanishing point, and guide color is selectable. Artists framing renders and camera shots get reference lines without leaving 3ds Max.

Key features

  • Quadrants, rule of thirds and custom grids
  • Golden proportions, rectangles and spiral
  • Vertical, horizontal, cross and point placements
  • Perspective lines from a base point
  • Selectable guide color
