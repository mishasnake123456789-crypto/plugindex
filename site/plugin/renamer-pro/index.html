What Renamer PRO does

Renamer PRO is a renaming plugin for Premiere Pro that changes many names at once. It has three modes: pattern-based naming using tokens, sequential numbering with custom formatting, and find-and-replace with regular expression support.

Tokens such as clip name without extension, index, sequence, date and track can be combined. A live preview displays validation warnings, spots duplicates and helps resolve conflicts before anything is applied. The scope can be set to selections in the project or timeline, so one tool tidies clips, bins and markers. It is aimed at editors organizing large projects.

Key features

  • Pattern, sequential and regex rename modes
  • Tokens for clip name, index, sequence, date, track
  • Live preview with duplicate detection
  • Renames clips, bins and markers
  • Project and timeline selection scope
