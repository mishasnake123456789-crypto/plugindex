What vAEriable does

vAEriable is a calculator-style script for After Effects. Instead of copying numbers by hand, you can load them straight from your project and solve the sums you need, including arithmetic, algebra and cross-multiplication for proportional scaling.

It can read the bounding-box size of a selected mask or the size of a layer, and pull the dimensions of a comp or footage item in the Project panel. Array values are handled, and the true or absolute value of an answer can be copied. A one-click compare checks two keyframes or matching properties across layers. A separate Calc-vAEr.jsxbin script can perform the compare with no panel open, from a hotkey or KBar.

Key features

  • Arithmetic, algebra and cross-multiplication
  • Loads sizes from masks, layers, comps and footage
  • Handles array values
  • One-click compare of keyframes or properties
  • Standalone compare script for hotkey or KBar
