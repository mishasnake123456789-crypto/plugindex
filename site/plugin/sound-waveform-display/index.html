Blender add-on that draws audio waveforms in animation editors to help sync actions and lip-sync.

What Sound Waveform Display does

Sound Waveform Display puts waveforms straight into Blender's animation editors, so syncing movement to audio does not need a separate sequencer setup. Sound can come from the sequencer by default or from a speaker.

On, off and refresh controls and a height offset adjust the display. Strips from the sequencer can be filtered to the selected ones, those in the sound list, audible ones or the scene range, color is customizable, and detail ranges from blocky to high. An option downloads and installs FFmpeg from preferences. It is best for short shots up to about a minute.

Key features

  • Waveforms inside animation editors
  • Source from sequencer or speaker
  • Strip filtering options
  • Adjustable color and detail
  • Automatic FFmpeg install option
