What Quick Groups (Instances) does

Quick Groups by MultLabs changes Ctrl+G in Blender so it creates a group from selected objects using regular instances. The originals are kept in a dedicated Library scene for editing.

F9 sets the group's center and name, Tab enters the group in the Library scene and returns to the main scene when nothing is selected, and Ctrl+Alt+G ungroups. Ctrl+Shift+G opens advanced options such as make single user and change instance, for example swapping one chair for another. Layout artists get an efficient instancing workflow.

Key features

  • Ctrl+G group instances
  • Edit groups in a Library scene with Tab
  • Ungroup with Ctrl+Alt+G
  • Make single user and change instance
