What Synctools Dcc Integration Suite does

SyncTools DCC Integration Suite is the Blender member of a cross-software pipeline series. It moves scene data between 3D applications with a simple copy and paste, built on a unified exchange protocol.

Axis conversion between programs is handled intelligently, and shortcuts can run in Standard or Mouse Drag mode. The suite carries meshes, NURBS geometry, transform hierarchies, PBR materials, lights, cameras, animations and armatures. It is meant for artists who bounce between applications and want to avoid manual export steps.

Key features

  • Copy-paste scene transfer between applications
  • Unified data exchange protocol
  • Automatic axis conversion
  • Standard or Mouse Drag shortcut modes
  • Meshes, materials, lights, cameras and animation
