What Match does

Match is PENCIL Park's extension for After Effects that supports people who write expressions and scripts. It deals with the tedious parts of the job, such as working out the exact path to a property and tidying code.

It can fetch and copy a universal property path in one click, apply built-in easing functions for in, out and in-and-out behavior, gather expressions from a layer and format them for scripts or scriptlets, and bake expressions into keyframes. It works with every After Effects property type using match names, and has an animated, responsive interface.

Key features

  • Copy the universal path of any property
  • Built-in easing functions
  • Fetch and format expressions from a layer
  • Bake expressions into keyframes
  • Supports all property types
