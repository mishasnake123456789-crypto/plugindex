What AEJuice Add Dynamic Text Box does

AEJuice Add Dynamic Text Box wraps a selected layer in a text box that resizes with the content. It is a script for After Effects that sets everything up with one click, so you avoid building the rig manually.

Border color, borders, stroke and other parameters can be adjusted afterwards. It works with all languages, including Arabic, and is integrated with kBar. The expressions run on After Effects versions from CC 2015 onward, which makes it handy for captions, labels and lower thirds that need a flexible background.

Key features

  • Adds a resizable text box in one click
  • Border, stroke and color controls
  • Works with all languages, including Arabic
  • Integrated with kBar
  • Supports After Effects CC 2015 and newer
