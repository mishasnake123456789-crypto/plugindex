What Curve Work does

Curve Work extends Blender's curve toolset for people who spend a lot of time with splines. It offers Boolean operations with Union, Difference and Intersection, along with mirroring and both linear and circular arrays.

Curves can be offset, including array offset, beveled with an inverse alignment function, and cleaned of single-point splines, bad extrusion and overlapping points. Segment type can be switched between automatic, vector, aligned and free, and a subdivided slide adds points along a segment with spacing control. It pairs well with other Vovrzull curve tools.

Key features

  • Union, Difference and Intersection on curves
  • Mirror, array and circular array
  • Offset and bevel for curves
  • Clean curves of stray points and splines
  • Segment type control and subdivided slide
