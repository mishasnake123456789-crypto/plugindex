Blender Text Editor shortcut that removes the current line and puts it on the clipboard, as VS Code does.

What Delete Line Shortcut does

Delete Line Shortcut gives Blender's text editor a key combination that removes the line the cursor is on. It also cuts the line's content to the clipboard so you can paste it elsewhere, mirroring how VS Code behaves.

The default key combination is Ctrl+Shift+Backspace, and it works from any line without selecting text first. You can remap it in Preferences, Keymap, inside the Text group (Text global, then Delete line). It is a small convenience for people who write Python scripts or notes inside Blender.

Key features

  • Deletes the current line in the Text Editor
  • Cuts the line to the clipboard
  • Default Ctrl+Shift+Backspace shortcut
  • Works without selecting text
  • Remappable in the keymap preferences
