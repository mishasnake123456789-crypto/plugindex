What Cloth To Shape Keys - Fix Cloth Animation does

Cloth To Shape Keys, from Recta3D, turns Cloth, Softbody and MeshSequenceCache modifier results into shape keys. Once converted, the result can be edited in sculpt mode or edit mode, which lets you correct problems in a simulation.

The original object is duplicated during conversion, and from version 1.2.0 you can keep or remove it. Previous and next shape key hotkeys are configurable, defaulting to mouse buttons 4 and 5, and frame stepping through the output properties is supported.

Key features

  • Converts Cloth, Softbody and MeshSequenceCache to shape keys
  • Edit results in sculpt or edit mode
  • Keep or remove the original duplicate
  • Customizable previous and next shape key hotkeys
  • Frame stepping through output properties
