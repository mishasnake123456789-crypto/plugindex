What Quick Project Cleaner - Blender Add-On does

Quick Project Cleaner is a Blender add-on for slimming down files. With one click it deletes unused materials, images, meshes, textures, actions, node groups and collections, reducing file size and load time.

A Dry Run safe mode previews what would be removed before anything is deleted, and a live data counter shows total and unused datablock counts in the panel. A Purge All option runs Blender's built-in purge as well. Artists who accumulate leftovers over long projects can keep their files lean before archiving or sharing.

Key features

  • One-click removal of unused datablocks
  • Dry Run safe preview
  • Live total and unused datablock counter
  • Purge All option
