What Align Pivot - set of scripts to managing pivots does

Kstudio's Align Pivot bundles several scripts for managing pivots in 3ds Max. Standard mode sets the pivot from an object's bounding box, while Smart Mode follows the actual surface rather than just overall dimensions.

Pivots can be placed by clicking a face, using the click point, the face center or the surface center, or by snapping to a vertex, bounding box or face center. Offset to Center accepts percentages or system units with positive or negative values for all selected objects. Reset Pivot, Align to Center and Align to Bottom commands are included, along with one-click variants that reuse earlier values without opening the interface. Local or world coordinates can be selected.

Key features

  • Standard bounding box and Smart surface-based modes
  • Align pivot by face click or vertex, box and face snapping
  • Offset to Center in percent or system units
  • Reset, Center and Bottom commands
  • One-click variants that reuse previous values
