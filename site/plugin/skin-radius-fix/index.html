What Skin Radius Fix does

Skin Radius Fix is a single-purpose script for 3ds Max skinning. A Skin envelope's inner and outer radius are set to a fixed size in one go, which spares you from adjusting each envelope by hand.

The saving becomes obvious on rigs with many bones, where resizing envelopes one at a time quickly turns tedious. It is aimed at riggers and character artists who prefer a quick way to get all envelopes to a consistent starting size before refining weights. The tool is by Chuggnut and does one thing only, which keeps it simple to use.

Key features

  • Sets inner and outer envelope radius to a fixed size
  • Saves time on rigs with many bones
  • Faster than manual envelope adjustment
  • Single-purpose skinning script
