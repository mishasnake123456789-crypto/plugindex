What AEJuice Flat Icons does

AEJuice Flat Icons contains 100 animated icons in a flat style, usable in After Effects and Premiere Pro. Each is built entirely from After Effects layers, so colors can be edited easily.

Every icon has IN, LOOP and OUT animations spread across a one-minute animation, at 596x596 pixels and scalable to any size. Fast Render is included, and the Pack Manager supplies quick preview, drag-and-drop import and favorites. Editors and motion designers can drop in explainer or UI icons without drawing them.

Key features

  • 100 animated flat icons
  • Editable colors on every icon
  • Built entirely from After Effects layers
  • IN, LOOP and OUT animations
  • 596x596 px, scalable to any size
