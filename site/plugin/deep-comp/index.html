What Deep Comp does

Built by Marco Sanasi, Deep Comp is a script running inside After Effects aimed at working with nested compositions. It lets you open any precomp inside the main comp and edit its layers live with instant feedback while browsing the tree of comps.

Precomps can be opened at any level, soloed or unsoloed, enabled or disabled, and a temporary alpha channel checker layer can be generated for them. In an unfolded precomp you can add or remove layers and effects, and the unfolded version can be duplicated at project level. It removes the constant switching between tabs when adjusting deep hierarchies.

Key features

  • Open precomps at any tree level on the fly
  • Solo and toggle precomps and layers
  • Temporary alpha checker layer
  • Edit unfolded precomp layers and effects live
  • Duplicate the unfolded precomp
