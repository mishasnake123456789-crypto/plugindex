What Polka Dots Maker does

Polka Dots Maker is a grape design panel for After Effects that builds dot patterns automatically. It sets up a Dot Comp and a Control Layer for you, so a repeating pattern is ready without manual cloning.

Dots can be circles or squares, and the contents of the Dot Comp can be edited freely. Scroll Speed changes how fast one row of dots moves, and Cross Scroll creates a crossing motion between rows. The panel is simple to use, making it good for backgrounds, transitions and retro graphic designs.

Key features

  • Dot Comp and Control Layer created automatically
  • Circle or square dots
  • Scroll Speed control
  • Cross Scroll animation option
  • Editable Dot Comp contents
