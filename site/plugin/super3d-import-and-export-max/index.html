What Super3D Import & Export .Max does

Super3D Import & Export .Max opens 3ds Max scenes in Blender with dedicated File menu entries. Conversion is done by the Super3D cloud service, so no local 3ds Max installation is needed.

One-click import and export keep the process off your machine. It helps studios receiving .max deliverables from clients or colleagues and wanting to continue the work in Blender. Highlights cover file menu entries for .max import and export and cloud conversion, no 3ds Max install.

Key features

  • File menu entries for .max import and export
  • Cloud conversion, no 3ds Max install
  • One-click workflow
