What Music Cue Sheet Uploader does

Music Cue Sheet Uploader helps film editors prepare cue sheets without exchanging XMLs or EDLs. It lists active tracks or filters the music with various options, and you can check and adjust the list before sending.

One click uploads it to an EditingTools.io account via an API key. There, the Cue Sheet Manager adds metadata automatically from production music libraries, and the finished sheet exports in several file formats. This cuts out the file exchange step and keeps cue sheet preparation connected to the edit.

Key features

  • List of active tracks or filtered music
  • Preview and adjust before upload
  • One-click upload using an API key
  • Metadata added from production music libraries
  • Export in various formats
