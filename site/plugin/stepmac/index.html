What Stepmac does

Stepmac is a macOS-only Blender add-on for CAD import. It reads .STEP and .STP files and builds a mesh by triangulating the underlying surfaces.

The object's components are kept during import, and builds exist for both Intel and Apple Silicon Macs including M1, M2 and M3. Useful for bringing engineering models into Blender for rendering. It addresses a gap for Mac users who need to open CAD data from engineering software without conversion tools.

Key features

  • Imports STEP and STP files
  • Triangulated surface meshes
  • Keeps object components
  • Intel and Apple Silicon builds
