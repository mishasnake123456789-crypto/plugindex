What Fontë does

Fontë is a 3D text creation add-on for Blender, bringing together typography, text animation and text modelling. It applies to text objects as well as any other 3D object, and all controls are gathered in a single compact panel.

One-click animations get titles moving quickly, and results render in both Cycles and Eevee. Documentation is included, along with a support period and product updates from Egret Studios. It targets professional titles, motion graphics and design work where polished lettering is needed.

Key features

  • 3D typography and text modelling
  • One-click text animations
  • Works on text or any 3D object
  • Single compact panel
  • Cycles and Eevee support
