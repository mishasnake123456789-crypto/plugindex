What Styriam Shaped Curves Merger does

Styriam Shaped Curves Merger solves a limitation of Blender's join command: merging curves with shape keys normally loses the shape key animation. This add-on copies shape keys along with their f-curves and modifiers.

Use it from the Object menu or the right-click context menu as Join Curves. The active object becomes the base and keeps its own modifiers and constraints. A preference can take over the Join shortcut (Ctrl+J by default) for curves with shape keys. It also supports splitting curve-driven motion across the merged result.

Key features

  • Merges curves with shape keys
  • Copies f-curves and modifiers
  • Object menu and right-click access
  • Active object is the base
  • Option to take over Ctrl+J
