Procedural 3ds Max texture map that paints gradients along an object's visible edges, with ramp and noise controls.

What Color Edge does

Color Edge generates colour gradients along the visible edges of a mesh. You decide which edges count as visible using the built-in Edit Mesh tools, then set near-edge and far-edge colours to form the gradient.

A Color Ramp section offers offset, width and ramp up and down controls, while noise comes from Regular, Fractal and Turbulence generators with strength, level and threshold settings for smoother transitions. Caches and buffers speed up calculation. A common use is blending maps and materials, for example creating a soft transition between a road mesh and terrain.

Key features

  • Gradients along visible edges
  • Edge visibility via Edit Mesh tools
  • Near and Far edge colour settings
  • Color Ramp with offset, width, ramp up/down
  • Regular, Fractal and Turbulence noise
