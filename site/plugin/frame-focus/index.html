Blender add-on that lists every Frame node in a node tree and lets you jump to, sort and recolor them.

What Frame Focus does

Frame Focus is a Blender add-on for node editors that become cluttered with Frame nodes. It lists them all in a panel, and a click centers the view on the one you want.

You can move entries up, down, to the top or to the bottom, sort by label or by color hue, and recolor nodes together, with other node types included as an option. Three display modes control how many extra controls appear next to the Select, Color and Focus buttons. It supports Blender 4.2 LTS and newer.

Key features

  • Clickable list of all Frame nodes
  • Reorder with up, down, top and bottom buttons
  • Sort by label or color hue
  • Bulk recolor of nodes
  • Three display modes
