What Gp Animator Desk does

GP Animator Desk is a Blender add-on from Calm Dude, co-created with Kevin C. Burke, that gathers panels and buttons for traditional drawn animation in Grease Pencil. Areas covered are onion skins, reference images, frame handling and tool switching.

A Draw with Hints display mode keeps the order and direction of strokes visible and prepares keyframes for automatic inbetweens. Reference drawings and imported images can be transformed and organized from a panel while you stay in Drawing Mode, a good match for Shift'n'Trace. A traditional onion skin switcher and four color presets make setting up skins quick.

Key features

  • Draw with Hints mode for stroke order and inbetweens
  • Reference panel inside Drawing Mode
  • Traditional onion skin switcher
  • Four onion skin color presets
  • Frame management and tool switching buttons
