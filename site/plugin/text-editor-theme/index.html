Blender add-on for custom text editor color themes, with 52 included and navigation extras.

What Text Editor Theme does

Text Editor Theme customizes how Blender's text editor looks. You can create, save, delete and switch themes live, and 52 ready-made themes come in the package.

Themes are stored as JSON files that are easy to tweak, share and version control, and can be imported and exported. A live HTML editor samples colors from images to generate palettes. Two bonus add-ons help with scripting: a Text Minimap with clickable navigation and a Code Navigator with one-click jumps to imports, classes and functions.

Key features

  • Live theme creation and switching
  • 52 ready-made themes
  • JSON import and export
  • Bonus minimap and code navigator
