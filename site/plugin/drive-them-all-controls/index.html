What Drive Them All - Controls does

Drive Them All - Controls is a driver management add-on that reduces the clicking needed to build control systems. Properties are captured and driven in two steps, then organized into Teams so you do not have to dig through panels.

Control Vector drives Vector3 values together, Control Boolean handles any True/False property, and right-clicking a property catches it as a control. Riggers and technical animators gain a tidy interface for custom controls.

Key features

  • Controls grouped into Teams
  • Control Vector drives X, Y and Z together
  • Control Boolean for True/False properties
  • Capture a property by right-click
  • Two-click driver setup
