What 2D Lip Sync Pro does

2D Lip Sync Pro automates mouth animation for Grease Pencil characters in Blender. It reads WAV or MP3 audio, detects phonemes and generates keyframes on mouth layers, saving the tedious frame-by-frame matching of speech.

Recognition runs offline using Vosk, the CMU Pronouncing Dictionary and Sphinx, so no cloud service or API key is needed. English is ready out of the box, while German, French, Spanish and Dutch models download in one click, with a G2P fallback. Each character can keep its own dialogue. 2D animators and motion designers will save a lot of time.

Key features

  • Keyframes on Grease Pencil mouth layers from audio
  • Offline recognition with Vosk and CMU dictionary
  • English plus German, French, Spanish and Dutch
  • Per-character dialogue
