What Blender Edge Groups Addon does

The Edge Groups add-on brings set-based management of edge data to Blender. You can create as many edge groups as you like across any number of objects, then control bevel weights, crease values, sharp marks and seams for the whole group at once.

Weights are stored inside the groups, which keeps the workflow non-destructive, and edges can be added to or removed from groups. It handles Blender 3.6 as well as newer releases past 4.0.2, where bevel weights and creases are stored as attribute data. Documentation is included. Hard-surface and subdivision modelers will find it easier than re-selecting edges repeatedly.

Key features

  • Any number of edge groups across objects
  • Bevel weight, crease, sharp and seam control
  • Weights stored in groups, non-destructive
  • Add and remove edges from groups
  • Supports attribute-based Blender versions
