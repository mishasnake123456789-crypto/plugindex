Blender add-on that overlays a clickable minimap of the node tree in every node editor, colored by node type.

What Node Minimap does

Node Minimap shows a small overview of the whole node graph so you can jump around large trees in Blender. It works with all node trees, and you navigate it with the middle mouse button.

Nodes are colored by type, reflecting any custom node colors you have set, and the active and selected nodes are highlighted. Nested levels are displayed too. Artists with big shader, geometry or compositing networks can keep their bearings.

Key features

  • Interactive minimap in all node editors
  • Middle mouse navigation
  • Colors by type and custom node colors
  • Highlights active and selected nodes
  • Compatible with all node trees
