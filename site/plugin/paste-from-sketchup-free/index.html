What Paste from SketchUp (free) does

Paste from SketchUp is a free tool that speeds up moving models from SketchUp to 3ds Max. Copy objects in SketchUp, paste in 3ds Max, and they arrive with their origin and texture preserved, skipping the usual export and import steps.

It must be installed on both sides, in either order. On the SketchUp side, an RBZ file installed through Extension Manager adds a Copy to 3dsMax command under Extensions. In 3ds Max it installs through a drag-and-drop MZP file under the D95 DESIGN category. Shortcuts can be given to both commands, so repeated transfers are quick.

Key features

  • Copy in SketchUp, paste directly into 3ds Max
  • Keeps origin and textures
  • RBZ install for SketchUp via Extension Manager
  • MZP drag-and-drop install for 3ds Max
  • Commands assignable to keyboard shortcuts
