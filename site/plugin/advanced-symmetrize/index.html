What Advanced Symmetrize does

Advanced Symmetrize extends the mesh symmetry tool that Blender ships with. Francisco Meneses built it for modelers who need to mirror geometry around something other than the object's origin without moving that origin.

The reference can be the 3D cursor, the center of the selection, or the active vertex, edge or face. Orientation can follow local or global axes, and a threshold setting defines which vertices count as symmetrical. Duplicate faces left on the symmetry plane are removed automatically. The command lives in the mesh edit menu.

Key features

  • Reference from cursor, selection center or active element
  • Local or global orientation options
  • Adjustable symmetry threshold
  • Automatic duplicate face cleanup
