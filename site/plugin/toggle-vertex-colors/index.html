What Toggle Vertex Colors does

Toggle Vertex Colors is a macro that makes a menu or toolbar button for switching vertex color rendering on and off in 3ds Max. It changes materials only at render time, so the scene itself is never permanently modified.

All native Max materials are supported, as are most plugin materials, including RenderWare, and the script can be extended for other plugin material types. Game developers who rely on vertex colors in production assets can use it to show those colors in marketing renders without maintaining a separate set of materials.

Key features

  • Toggle button for a menu or toolbar
  • Switches vertex color rendering on and off
  • Changes materials only at render time
  • Supports all native Max materials and most plugin materials
  • Extendable to other plugin material types
