3ds Max tool that shows the distance between two points with a stretching tape and number driven by a float script controller.

What Measurement tape does

Measurement tape is a small helper for 3ds Max aimed at architectural visualization, where quick on-screen dimension checks are common. It displays the distance between two points as a tape with a numeric label that stretches to match.

Dummy handles at the left and right mark the two measured points, while a center controller rotates and resizes the number and arrows so they stay readable. The tape reacts through a float script controller, and values are reported in system units. The setup merges straight into an existing scene, so a dimension marker can be dropped in wherever a distance needs to be shown or checked.

Key features

  • Visualizes distance between two points
  • Text and tape stretch via a float script controller
  • Dummy handles define the measured points
  • Middle controller rotates and scales number and arrows
  • Reports in system units and merges into the scene
