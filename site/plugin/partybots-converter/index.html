What Partybots converter does

Partybots converter is a Blender add-on by vuyghu2020 for creating maps for Partybots, a Steam game that lets you play games you build. Development stopped once the game received a level editor of its own.

It adds a dedicated tab with an add platform command and a parameter dialog that starts at an expected size. Compile marked writes triggers for the game mode file to the clipboard, which needs Clipboard permission. As of 1.0.4, platforms are added as layouts and the add-on inserts the [platforms] header automatically. It supports Blender 4.2 LTS and newer.

Key features

  • Add platform command in a dedicated tab
  • Parameter dialog with default sizing
  • Compile marked copies triggers to the clipboard
  • Platforms as layouts (version 1.0.4)
  • Supports Blender 4.2 LTS and newer
