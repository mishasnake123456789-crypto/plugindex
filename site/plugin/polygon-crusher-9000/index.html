What Polygon Crusher 9000 does

Polygon Crusher 9000 decimates heavy meshes in Blender 4.2 and later while keeping normals, UVs and materials intact. It is aimed at photoscans, dense sculpts and CAD imports with millions of polygons.

A native, multi-threaded C++ implementation of Fast-Quadric Mesh Simplification runs behind a side panel. It decimates what is visible in the viewport, including Boolean, Subdivision, Mirror, Remesh and Geometry Nodes results. Batch mode processes selected objects in parallel into a Crushed collection, six presets run from 25 to 95 percent, and a progress bar shows triangle counts.

Key features

  • Native multi-threaded C++ decimation
  • Modifier-aware, preserves UVs, normals and materials
  • Parallel batch mode for many objects
  • Six presets plus custom saved presets
