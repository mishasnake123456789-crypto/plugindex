What Addon Dev Tools does

Addon Dev Tools, from MarkSeam, saves time for people who write Blender add-ons. It removes the manual steps of reloading code and building archives.

Auto Reload watches a development directory and reloads the add-on inside Blender when files change, for single-file and package add-ons, toggled with a click. The packaging tool builds a ZIP without temporary files like __pycache__ and .pyc into a release directory suited to distribution or Blender Market submission. Controls sit in a 3D Viewport sidebar tab.

Key features

  • Auto reload on file changes
  • Single-file and package add-on support
  • ZIP packaging excluding temp files
  • Sidebar tab in the 3D Viewport
