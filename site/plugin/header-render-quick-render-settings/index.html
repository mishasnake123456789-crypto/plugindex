What Header Render - Quick Render Settings does

Header Render puts common rendering controls in the 3D Viewport header, where they are always within reach. A selector lets you switch between render engines without opening the Properties editor.

Separate buttons render the current frame or start a full animation. Version 1.1 introduced a camera check, which warns you in a dialog when the scene has a camera problem. Useful for quick test renders while lighting or modeling. Since the buttons sit in the viewport itself, switching to a different editor layout is never required.

Key features

  • Render engine selector in the header
  • One-click current frame render
  • Animation render button
  • Camera check dialog
