What Multi-View Reference Manager (Blender Addon) does

Multi-View Reference Manager automates reference setup. Select a folder and 1-Click Auto Detect reads filenames to drop each image into the correct orthographic view slot.

Global box offsets push references outward from the center so they form a non-intersecting box, and importing, rotating and scaling are handled automatically. Modelers working from front, back, side, top and bottom drawings save time. Under the hood you get auto Detect from filenames and six orthographic views.

Key features

  • Auto Detect from filenames
  • Six orthographic views
  • Global Box Offsets avoid intersection
  • Automatic rotate and scale
