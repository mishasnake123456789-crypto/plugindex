Blender add-on for recoloring themes by sampling a color and editing all matching theme entries in one filtered list.

What theme dictionary does

Theme Dictionary shortcuts the process of editing interface themes. Instead of searching nested preference trees, you pick a color with an eyedropper and the add-on locates theme entries that match or resemble it.

A tolerance value controls how strict the search is, and relevant entries appear in a filtered list for editing. Interface customizers can recolor an entire look from the colors they already see on screen.

Key features

  • Eyedropper color lookup
  • Tolerance control
  • Filtered list of matching theme entries
  • Edit entries from the results
