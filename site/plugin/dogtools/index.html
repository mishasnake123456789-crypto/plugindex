A Blender add-on for snapping objects to faces or centers, random distribution, alignment and mouse-driven placement.

What Dogtools does

DogTools speeds up object placement in Blender. Its face-to-face snap places objects against surfaces, while random distribution with a shuffle option scatters items and alignment handles even spacing.

Rotation can be done in discrete steps with the mouse wheel using a preset. Mouse-driven teleport, duplicate and linked duplicate snap to the face under the cursor, and an object's origin can also be set with the mouse. A DogPie pie menu toggles built-in options. Layout artists, set dressers and modelers assembling many parts will move quicker than with manual grabbing.

Key features

  • Face-to-face snapping
  • Random distribution with shuffle
  • Alignment with spacing
  • Discrete mouse-wheel rotation
  • Mouse-based teleport, duplicate and origin setting
