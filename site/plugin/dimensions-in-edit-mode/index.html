Blender add-on that displays and edits the dimensions of selected geometry in Edit Mode, like in Object Mode.

What Dimensions in Edit Mode does

Dimensions in Edit Mode, by Matikos, fills a gap in Blender: Object Mode shows dimensions for an object, but Edit Mode does not. This add-on displays the size of the selected geometry live and lets you edit it.

It mirrors the behavior of Object Mode and is designed to look and feel like a native interface element. It needs no special permissions, supports Blender 4.2 LTS and newer, and is released under GPL v3.0 or later.

Key features

  • Live dimensions of selected geometry
  • Editable values in Edit Mode
  • Native-looking interface
  • Blender 4.2 LTS and newer
  • GPL v3.0 or later
