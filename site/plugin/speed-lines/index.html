Attaches animated speed line strokes to moving objects in After Effects, including parented and expression-driven ones.

What Speed Lines does

Modio's Speed Lines is a script built for After Effects that adds trailing strokes behind a moving object. It works alongside other scripts and expressions, analyzing each frame so parented objects and expression-driven motion are handled.

Style controls set the number of lines, separation, thickness and offset angle, while length and offset determine how far the strokes extend from the starting point. Enable End locks the end point, with a control to move it manually. Create Speed Lines builds the setup on a shape layer, and Update Speed Lines reapplies changes afterward.

Key features

  • Strokes attached to animated objects
  • Controls for line count, separation, thickness and angle
  • Length and offset settings
  • Enable End locks the end point
  • Update button reapplies changes
