Render Notify

Developer: Nate

FreeBlender
Download Free

A Blender add-on that alerts you when a render finishes, via desktop, Discord or Pushbullet.

What Render Notify does

Render Notify removes the need to watch Blender while a long render runs. When the job completes, it sends an alert so you can leave the machine, which is handy for overnight sequences or renders running on another computer.

The Lite edition produces desktop notifications. The Full edition adds Discord messages, using your Discord ID and a webhook URL, and Pushbullet messages through an access token, plus a fun mode. It installs as a zip through Blender's Preferences and comes with documentation. Animators and archviz artists who batch render will benefit from the remote ping.

Key features

  • Desktop notification on render completion
  • Discord alerts via webhook (Full edition)
  • Pushbullet alerts via access token (Full edition)
  • Lite and Full editions
  • Installs as a zip through Preferences
