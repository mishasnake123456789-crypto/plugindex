What Motion Path Ultimate does

Motion Path Ultimate gives hands-on control over motion in Blender. Object and armature trajectories update in real time in the viewport, and they can be edited directly through handles and gizmos.

Proportional editing plus smoothing, spacing and reduction tools clean up keys, and extra functions let you adjust several motion paths at once. Animators who think in arcs can reshape movement visually instead of working only in the graph editor.

Key features

  • Real-time viewport motion paths
  • Handle and gizmo editing
  • Proportional editing, smooth, space and reduce tools
  • Adjust multiple motion paths together
