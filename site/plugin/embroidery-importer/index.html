Blender add-on that imports embroidery machine files as curves, detecting thread colors and adding thickness.

What Embroidery Importer does

Embroidery Importer reads embroidery machine files into Blender, turning them into curves.

Thickness is optional, either through a geometry nodes setup (Curve to Mesh with a circular profile) or the bevel setting of the curve. Thread colors are detected and applied through a generated material. Makers and product visualizers can render embroidered designs. This is a convenient route for making realistic stitched logos, patches and decorations, since the original machine path is preserved as editable curve data.

Key features

  • Embroidery files to curves
  • Thickness via geometry nodes or bevel
  • Thread color detection
  • Generated material
