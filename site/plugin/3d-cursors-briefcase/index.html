Blender add-on for saving, loading, undoing and managing multiple 3D cursor positions from the 3D View.

What 3D Cursors Briefcase does

3D Cursors Briefcase stores several 3D cursor states in Blender so you can return to important locations later. It works from the 3D View and requires no special permissions.

Saved cursors can be loaded back into the scene, changes can be undone and the collection can be managed. Modelers and layout artists who jump between pivots and placement points will save time re-positioning. The cursor underpins placement, snapping and pivots in Blender, so being able to recall exact positions removes a lot of repeated precision work.

Key features

  • Save multiple cursor positions
  • Load stored cursors
  • Undo cursor changes
  • Manage a collection of cursors
