What Geometry Nodes Attribute Viewer does

Geometry Nodes Attribute Viewer is a plugin and node set from Griperis that makes attribute values visible. Four node groups accept geometry and an attribute, returning the same geometry along with text for the values.

Edge, face, face corner and spline domains are supported, and the text is customizable. It helps debug node setups by revealing the numbers they produce. Seeing real values in the viewport removes guesswork and makes learning, troubleshooting and documenting node trees much easier.

Key features

  • Four node groups for viewing attributes
  • Edge, face, face corner and spline domains
  • Customizable text
  • Numbers placed at domain positions
