What Curvemesher does

Curvemesher is a curve-based modeling system for Blender. You place control points by raycasting in the viewport and the add-on generates meshes from single, dual or multiple curves.

Move a point, release the mouse and a new mesh is produced in Quads or Tris mode with adjustable interpolation along and between curves. Previews can be wireframe or textured, flat or smooth. Extras include one-click material colors, matching handles between curves, Snap To Grid, Texel Density settings, Quick Pixel UV automation and Vert Hooker constraints, which suit pixel-grid retro workflows.

Key features

  • Raycast control point placement
  • Quads or Tris mesh generation from curves
  • Live preview mesh options
  • Pixel UV, texel density and snapping tools
