What Imagegis2Camera does

Imagegis2Camera turns location data into camera setups. In Images Only mode it reads GPS coordinates from photo EXIF, and in vector mode it uses SHP or GPKG point layers.

Cameras are named from image filenames or attributes, given photo backgrounds, assigned to timeline frames and keep their own render resolution. Useful for survey documentation, site photo matching and architectural visualization. This links real locations with Blender cameras, which keeps survey photos organized by position and frame.

Key features

  • EXIF GPS import from photos
  • SHP and GPKG point layer import
  • Camera naming from filenames or attributes
  • Photo backgrounds and timeline frames
  • Per-camera render resolution
