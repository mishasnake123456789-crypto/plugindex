Edit Linked Library

Developer: JasonvanGumster

FreeBlender
Download Free

Blender add-on for editing objects, collections and node groups linked from external libraries.

What Edit Linked Library does

Edit Linked Library lets you change linked data in Blender without tracking down the source file, for objects, collections and node groups coming from other libraries.

Its commands appear under File > External Data, on the 3D View sidebar's Item tab and on the Node Editor sidebar's Node tab. Once bundled with Blender 4.1, it is now offered as it is for Blender 4.2 LTS and newer with no special permissions. Pipeline artists working with shared asset libraries gain a faster path to changes.

Key features

  • Edit linked objects, collections and node groups
  • Access from File, 3D View and Node Editor
  • For Blender 4.2 LTS and newer
  • No special permissions
