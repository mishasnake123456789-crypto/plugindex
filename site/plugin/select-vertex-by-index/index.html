What Select Vertex By Index does

Select Vertex By Index lets you pick vertices in Blender using their index number. Typing a number in the panel selects that vertex, which is useful for debugging meshes, scripting workflows and checking imports where indexes matter.

A Select Range option picks multiple vertices across a set range in one step. The add-on works with Blender 2.8 through 3.0 and includes documentation. Technical artists, developers and modelers who need precise vertex access without clicking around the viewport will find it a simple and direct utility.

Key features

  • Select or deselect by vertex index
  • Type a single number in the panel
  • Range selection for multiple vertices
  • Works with Blender 2.8 to 3.0
