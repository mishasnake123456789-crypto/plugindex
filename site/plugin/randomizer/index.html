After Effects script that gives selected layers random transform values within a range, with separate dimensions support.

What Randomizer does

Randomizer, by nab, assigns random values inside a chosen range to the transform properties of the layers you select in After Effects. It is a fast way to break up the uniformity of duplicated layers, such as scattered shapes or scaled and rotated stacks.

Version 3.3 added support for Separate Dimensions on position, and version 3.2 fixed the random number generator on Mac for CC 2015 and later. It works with After Effects releases from CS6 through 2025, and a demo video is available. Motion designers building organic layouts and particle-like arrangements will find it handy.

Key features

  • Random values for layer transform properties
  • Applies to selected layers
  • Separate Dimensions on position supported
  • Works from CS6 through 2025
  • Demo video available
