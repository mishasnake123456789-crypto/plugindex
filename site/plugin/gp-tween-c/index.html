What GP Tween (c) does

GP Tween creates in-between frames from one Grease Pencil keyframe to the next in Blender using Geometry Nodes, working on a per-layer basis.

Strokes can be interpolated to or from any spline type, and a separate stroke is created for the inbetweening process. 2D animators drawing keys can let the tool fill the frames between them. Automatic inbetweens can help speed up traditional-style animation in Grease Pencil, leaving the artist free to concentrate on key poses and cleanup.

Key features

  • Interpolates between Grease Pencil keyframes
  • Per-layer operation
  • Any spline type supported
  • Separate inbetween stroke
