Blender add-on that builds 3D scenes from Stable Diffusion depth images using displacement mapping.

What Dispmapping does

Dispmapping turns AI depth images into 3D scenes in Blender with one click. It works with Stable Diffusion WebUI depth output and Blender's displacement mapping.

It also provides a shading material function that supports AI-generated images, reads grayscale PNG, JPG or BMP files, and organizes them in a category directory structure. A floating panel on the Y key changes category names, and version 1.5.4 added a real-time image overview. It is intended for Windows users.

Key features

  • One-click scenes from depth images
  • Reads PNG, JPG and BMP grayscale
  • Category-based directory structure
  • Material function for AI-generated images
