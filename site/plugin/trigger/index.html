What Trigger does

Trigger is a script by Casey Baker that turns timing in After Effects into an event-based system. Animations inside a precomp are called up by layer markers rather than fixed positions, so retiming becomes simple and non-destructive.

One click creates multiple animation events and generates event triggers on global comp layers. Pressing Retime places a null called Trigger inside the selected precomp, and Add Trigger marks each event. You can test several versions of an animation and sequence events from the global composition, which suits complex motion graphics packages.

Key features

  • Call animations in a comp using layer markers
  • Create multiple events with one click
  • Non-destructive retiming
  • Test multiple versions of an animation
  • Sequence events from the global composition
