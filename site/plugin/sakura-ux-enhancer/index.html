What Sakura Ux Enhancer does

Sakura Ux Enhancer, by Kafuji, adds shortcuts that smooth out everyday Blender use. Top-bar buttons switch modifiers on and off, either all together or individually.

Other controls reach armature settings, layers or collections and lights, and quickly change render engines and color spaces. Viewport settings can switch automatically when entering specific modes. The Image Editor shows the active image on selection or when an image node is double-clicked, an Image Finder lists related images, and a warning appears when you edit shape keys unintentionally.

Key features

  • Top-bar modifier and scene toggles
  • Quick render engine and color space switching
  • Viewport and Image Editor automation
  • Image Finder and shape key warning
