What Sprite Maker does

Sprite Maker is a Blender add-on for producing isometric sprites for games and other 2D work. Instead of arranging cameras and rendering each angle by hand, you pick a configuration and let it render.

Choose 8 sides, 4 sides or an alternative 4-sided setup, render animations at adjustable step intervals, and set light type, size and intensity. A camera can be added so the setup is visible before export. Everything is reached through Blender's N-panel.

Key features

  • Isometric rendering in 8-side and 4-side layouts
  • Animation rendering with step intervals
  • Light type, size and intensity settings
  • Camera preview of the setup
