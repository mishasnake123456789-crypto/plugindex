What Customize Menu Editor does

Customize Menu Editor is a Blender plugin from Bookyakuno for assembling menus that fit how you work. Rather than hunting through the interface, you gather the commands you use into a menu of your own.

It can register the most recently executed operation, group items into tabs and fine-tune the layout. Menus can be exported to a text file and imported elsewhere, or exported as a standalone add-on to share with others. Documentation is included for getting started.

Key features

  • Register the last executed operation in a menu
  • Organize menus into tabs
  • Layout fine-tuning options
  • Export and import menus as text
  • Export a menu as an add-on
