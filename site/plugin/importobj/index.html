ImportObj

Developer: SimonBourgeois

Free3ds Max
Download Free

3ds Max script that imports one or many OBJ files with vertex colors, PBR textures and part-based naming handled automatically.

What ImportObj does

ImportObj brings OBJ files into 3ds Max, either one at a time or many together, and picks up vertex colors when the meshes contain them. A Normalize option scales each object to fit a size box of your choice, and imported objects can be spaced evenly.

PBR textures works with V-Ray and Corona are handled once the render engine is set before importing. Files named with part suffixes such as _part_01 and _part_02 are imported with their texture sets, materials are created, and matching parts are attached into one object. For multi-material OBJs, materials are built from the .mat file info using the diffuse map only.

Key features

  • Imports single or multiple OBJ files
  • Picks up vertex colors when present
  • Normalize scale and even spacing options
  • PBR textures for V-Ray and Corona
  • Part-based naming attached into one object
