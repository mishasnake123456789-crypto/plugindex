Parallax Node

Developer: MultLabs

FreeBlender
Download Free

Blender add-on providing a single shader node for parallax mapping with steps, strength and bias controls.

What Parallax Node does

Parallax Node adds a custom shader node to Blender that fakes depth from a height map. The height texture sits inside one node, avoiding a complicated node group.

Steps (1 to 64) trade quality against performance, Strength (0 to 100) scales the effect, and Bias (0 to 2) fine-tunes the mapping. A UV map selector supports custom UV layouts. Material artists can add convincing surface relief to bricks, tiles and cobblestones without extra geometry.

Key features

  • Single parallax shader node
  • Steps from 1 to 64
  • Strength and Bias controls
  • UV map selector
