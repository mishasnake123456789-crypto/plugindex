A notes and task panel for Premiere Pro with timecode links, per-sequence lists and focus timers.

What Notecraft does

Notecraft keeps feedback, to-dos and revision notes inside the project. Press @ to insert the playhead timecode into a note, and click any timecode later to jump to that frame.

Tasks can be typed in, or pasted as multi-line text to create many at once, and global tasks appear across all sequences. Focus and Break modes run 25 and 5 minute cycles with logging and alerts. Version 1.5.0 added priorities, inline comments and sorting and grouping. Everything auto-saves to a JSON file beside the project.

Key features

  • Insert playhead timecode with @
  • Click timecodes to jump the timeline
  • Bulk task creation from pasted text
  • Global tasks across sequences
  • Focus and Break timer modes
