Adds tag-based asset filtering and catalogue backup for Blender asset libraries.

What Asset Library Tools does

Asset Library Tools improves how you manage Blender asset libraries. It lets you filter assets by tags, which helps when a library grows large, and it can back up catalogue files.

The backups protect against accidental loss of the organizing structure you have built. Studios and individual artists maintaining shared libraries will find it handy for keeping assets easy to find and safe.

Key features

  • Tag-based asset filtering
  • Catalogue backups
  • Helps manage large libraries
