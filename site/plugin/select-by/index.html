What Select By does

Select By is a Blender plugin from Online Render that widens what selection can do. You can store a set of objects and restore it later, or pick everything in the scene that shares a name with a chosen object.

Mesh objects can be selected by polygon, vertex or edge counts, and objects filtered by scale, location, materials and more. It's particularly handy for cleaning up heavy scenes and finding oddities among many objects.

Key features

  • Store and restore selections
  • Find Copy selects same-named items
  • Select by polygon, vertex or edge count
  • Filter by scale, location and materials
