What RenderQ does

RenderQ by Gary Reisman is a script for After Effects that streamlines sending comps to the render queue. Four configurable buttons each handle a single or dual output module plus an optional still frame, so repeated delivery setups take one press.

Prefixes and suffixes, including the output module name, can be temporary or custom. Stills can come from a fixed point or the current time indicator in four formats. Render+ also cleans extra suffix numbers and brings the finished folder forward, while another button reopens recent locations. Unlimited folder destinations can be saved, including the project folder.

Key features

  • Four customizable one-press render buttons
  • Single or dual output module plus still frame
  • Custom prefixes and suffixes
  • Render+ cleans suffix numbers and opens the folder
  • Unlimited saved render locations
