A Blender add-on that places cameras, renders and composes multi-view images of an object in one click.

What Q Three Views does

Q Three Views produces orthographic-style sheets in Blender with one action. Select an object, click Render, and the add-on places the cameras, renders every needed image, then composes and shows a combined view, which suits model sheets and technical presentations.

It can render a single object, the current selection or the whole scene, keeping the frame centered on a target object or the scene center. Optional automatic hiding renders only the selected object or group. Product designers and character artists presenting turnarounds will save time on camera setup.

Key features

  • One-click camera placement, render and composition
  • Single object, selection or whole scene
  • Frame centered on target or scene center
  • Optional hiding of unselected objects
