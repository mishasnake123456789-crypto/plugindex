What Animation Preview does

Animation Preview renders fast previews of the active viewport over the scene's frame range while leaving output path, file format and other output settings untouched.

You can include audio, hide overlays such as gizmos and outlines, and disable the Simplify setting for the preview. This provides a quick way to review animation timing and share work-in-progress clips without a full render. Highlights include viewport previews over the frame range, output settings stay unchanged and optional audio.

Key features

  • Viewport previews over the frame range
  • Output settings stay unchanged
  • Optional audio
  • Hide overlays and disable Simplify
