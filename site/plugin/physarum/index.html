What Physarum does

Physarum is a native plugin by Zaebects that simulates organic growth inside After Effects. It uses an organic algorithm that spreads and branches like living matter, and it can interact with layers in the composition.

Because the behavior depends on input and settings, an endless variety of patterns is possible, making it suitable for abstract backgrounds, title treatments and generative visuals. It supports After Effects from CC 2017 through 2026, added Apple M1 support in version 1.2, and ships with sample projects matched to the plugin version.

Key features

  • Organic growth simulation
  • Interacts with composition layers
  • Near-endless pattern variety
  • Apple M1 support since version 1.2
  • Includes sample projects
