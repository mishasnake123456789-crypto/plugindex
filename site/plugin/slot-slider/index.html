What Slot Slider does

Slot Slider provides an A/B comparison for render results. A draggable divider in the Image Editor shows two render slots side by side so you can see what changed between versions.

It works with color, depth, normals or any custom render pass, supports multiple view layers, and can compare composite and raw passes. Handy for lighting, denoising and look-development decisions. Key capabilities include draggable A/B slider in the Image Editor and compares color, depth, normals and custom passes.

Key features

  • Draggable A/B slider in the Image Editor
  • Compares color, depth, normals and custom passes
  • Multi-View-Layer support
  • Composite and raw pass comparison
