Script that runs built-in or custom arrows along a path in After Effects, with adjustable stroke and styling.

What Easy Arrows does

Built by Modio, Easy Arrows is a script running inside After Effects that orients a graphic along a path automatically. You can use the supplied arrows or bring in your own graphics and compositions, which makes it useful for callouts, maps and infographic lines.

Effect controls handle how far along the path the arrow has traveled, the length of stroke trailing behind the head, and line offset. The end point can be locked and moved, direction can be reversed, and stroke width, arrow size and colors adjust together. If the path is edited later, the Update Arrow button rebuilds the setup, and the layers can be precomped for easy duplication.

Key features

  • Built-in or custom arrow graphics on a path
  • Controls for completion, trailing stroke and offset
  • Reverse direction and lock the end point
  • Update Arrow button after path edits
  • Precomp layers for easy duplication
