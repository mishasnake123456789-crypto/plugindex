What L3tt3rM4pp3r2 does

L3tt3rM4pp3r2 from BGRA Entertainment maps video onto letters to produce textmode and ASCII art looks in After Effects. The second release has a reworked interface and textmode presets, updated in version 2.8.

A letter interpolation mode called Cl34rTyp3 arrived in 2.7. Supersampling, a texture interpolation mode and extra color and scale parameters refine the result, and the color of a custom texture affects the output. Multi-frame rendering is supported. Tutorials cover making custom textures and converting fonts, so artists can use their own character sets.

Key features

  • Textmode and ASCII art video mapping
  • Textmode presets
  • Cl34rTyp3 letter interpolation mode
  • Supersampling and texture interpolation
  • MFR support and custom texture tutorials
