What Migration Manager does

Migration Manager packages your Blender setup so you can restore it after updating or move it to another machine. Instead of reconfiguring, you export once and import where needed.

It migrates user preferences, custom themes and keymaps, transfers scripts and add-ons without reinstalling each one, and carries datafiles such as matcaps and brushes. Anyone who works across several Blender versions or computers can keep their environment consistent. The feature set spans export and import the full workspace and preferences, themes and keymaps.

Key features

  • Export and import the full workspace
  • Preferences, themes and keymaps
  • Scripts and add-ons transferred together
  • Datafiles like matcaps and brushes
