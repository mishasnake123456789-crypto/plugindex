What Magic To-Do List does

Magic To-Do List keeps tasks inside Blender. Type a task into the Sidebar, tick it off, and completed ones move to a separate list with timestamps.

It runs inside Blender with no external apps, supports versions 4.0 through 4.3, and uses the GPL license. Handy for tracking steps within a project. It is intended to be a minimal, always-available reminder list for the project you are working on. Finished work stays visible with its time, giving a lightweight log of what was done and when.

Key features

  • Add tasks in the Sidebar
  • Checkbox completion
  • Completed list with timestamps
  • No external app needed
