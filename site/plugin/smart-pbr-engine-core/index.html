What Smart Pbr Engine Core does

Smart PBR Engine Core manages PBR materials and automates their creation. On import it recognizes texture suffixes and builds the shader nodes, so materials are essentially finished as soon as textures arrive.

An auto-matching system scans a parent directory and batch-matches textures to materials, and the Smart Shader Builder takes care of node setup. Artists with large texture libraries avoid wiring each map by hand. Under the hood you get automatic texture suffix recognition and smart Shader Builder node setup.

Key features

  • Automatic texture suffix recognition
  • Smart Shader Builder node setup
  • Batch matching from a parent directory
