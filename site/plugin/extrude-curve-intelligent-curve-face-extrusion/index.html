What Extrude Curve - Intelligent Curve Face Extrusion does

Extrude Curve lets a curve define how faces are extruded. Press Ctrl+E and a control curve appears immediately to shape the mesh.

You can adjust segments for smooth shapes, add or remove points, tweak tangents, depth and smoothing, and inspect the mesh from different angles. It suits modelers creating organic or flowing extrusions that would be tedious with repeated manual extrudes. Highlights cover ctrl+E starts curve-based extrusion and segments, points and tangents.

Key features

  • Ctrl+E starts curve-based extrusion
  • Segments, points and tangents
  • Depth and smoothing controls
  • View control while editing
