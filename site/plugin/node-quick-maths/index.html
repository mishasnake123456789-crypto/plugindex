Blender add-on that turns a typed math expression into linked math nodes in Shader, Geometry, Texture and Compositor editors.

What Node Quick Maths does

Node Quick Maths builds a series of Math nodes from an expression you type. It works in Shader, Geometry, Texture and Compositor node editors.

Ctrl+M opens the expression dialog by default. Standard operators such as plus, minus, multiply, divide, power, comparisons and modulo are supported, along with other math functions. Technical artists who think in formulas can avoid wiring each node by hand. Writing a formula once is faster than adding, linking and setting a dozen separate Math nodes, and the result stays editable as ordinary nodes.

Key features

  • Expression to node chain
  • Ctrl+M opens the input dialog
  • Supports + - * / ** < > and %
  • Works in four node editors
