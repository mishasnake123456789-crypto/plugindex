What 3D Maker - The Complete 3D Printing Workflow Suite does

3D Maker brings the steps of preparing a print into Blender so models need not bounce between several programs. It handles coloring, supports and handoff to the slicer you use.

A send-to-slicer command exports to Bambu Studio, Orca Slicer, PrusaSlicer, Cura, ChiTuBox, Creality Print or Lychee Slicer and detects which are installed. In Sculpt Mode you can paint vertex colors with lasso, box, polyline or circle selection, opacity blending and occlusion-aware filtering, and keep reusable palettes. The support generator builds cylindrical or rectangular supports from an overhang angle.

Key features

  • One-click export to seven common slicers
  • Vertex color painting in Sculpt Mode
  • Lasso, box, polyline and circle selection
  • Palette manager for color sets
  • Support generator based on overhang angle
