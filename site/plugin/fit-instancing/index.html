Blender add-on that instances an object onto selected quads, scaling and deforming it to fit.

What Fit Instancing does

Fit Instancing places copies of an object over selected quads, or rectangles built from groups of quads, in Blender. Each copy scales and deforms automatically to match its target area, which suits architectural surfaces and other panel-like layouts.

A lattice is generated to carry out the deformation, and objects can also be created according to the active material index. The duplicates are true instances, so editing the source object updates all of them. Documentation is included.

Key features

  • Instances fitted to selected quads
  • Automatic scaling and deformation via lattice
  • Can use the active material index
  • Edits to the source update every instance
