What Vertex Skin Weights does

Vertex Skin Weights complements weight painting in Blender with direct numbers. A live list shows which bones influence the selected vertices and by how much, including averages across several vertices.

You can select multiple bones and adjust them at once, set exact values by button or input, and nudge weights up or down with automatic redistribution to maintain balance. Smart Copy/Paste transfers weights from one vertex to many, and Hammer Weights smooths and normalizes using neighbors. It suits riggers, character artists and game developers.

Key features

  • Real-time list of influencing bones
  • Multi-bone weight editing
  • Exact numeric weight entry
  • Weight nudging with auto redistribution
  • Smart copy and paste, Hammer Weights
