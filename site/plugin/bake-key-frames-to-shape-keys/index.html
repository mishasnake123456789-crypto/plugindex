What Bake Key Frames To Shape Keys does

Bake Key Frames To Shape Keys is a Blender plugin that turns bone animation into a series of shape keys, one per frame. The animation then lives in the mesh data rather than in a skeleton.

This frees exports to programs such as Unreal Engine from the bone hierarchy. Start it from the shape keys menu or by searching with F3. Useful for cloth-like or complex animation that exports poorly as bones.

Key features

  • Bakes bone animation to shape keys
  • One shape key per frame
  • Export without bone hierarchy
  • Runs from menu or F3 search
