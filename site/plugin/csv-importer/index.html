Blender add-on that imports CSV files by drag-and-drop or File, Import, with data available in the Spreadsheet and Geometry Nodes.

What CSV Importer does

CSV Importer loads CSV data into Blender by dragging files in or using File, Import, CSV menu. Dropping works in windows other than the viewport as well.

Imported data appears in the Spreadsheet Editor and are read in Geometry Nodes via Named Attribute. Data visualization artists and technical users can drive procedural geometry from tabular information. Treating spreadsheet values as attributes lets charts, scientific datasets and other numeric records control position, scale or color of procedural geometry.

Key features

  • Drag-and-drop or File > Import
  • Data shown in the Spreadsheet Editor
  • Named Attribute access in Geometry Nodes
  • Drop support in non-viewport windows
