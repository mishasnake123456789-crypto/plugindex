What Vertex Overlap does

Vertex Overlap helps you catch duplicate vertices while modeling in Blender. Located in the Edit N-panel, it can alert you in real time when new overlapping vertices appear.

Real-time alerts are off unless you tick a checkbox. A Show Overlaps button highlights overlapping points in Vertex Selection Mode letting you see what would be merged, and a single click merges them by a threshold. Useful for clean meshes ahead of export or subdivision.

Key features

  • Real-time overlap alerts
  • Show Overlaps preview highlighting
  • Merge by threshold in one click
  • Located in the Edit N-panel
