Blender add-on for animated 3D text built on Geometry Nodes, with 20 presets and an animation node.

What Text Improver does

Text Improver is a geometry nodes based add-on for making 3D text in Blender. Twenty presets come in the download, along with a simple animation node that covers most needs.

Own materials and modifiers can be applied freely. Effects include text squeezing, edge shaping, an animated stroke and a cracking effect with animation, and a resample option adds detail. It renders in EEVEE and Cycles and suits openers, logo reveals and motion graphics.

Key features

  • 20 included text presets
  • Simple animation node
  • Squeeze, edge shaping and animated stroke
  • Crack effect with animation
  • Works with EEVEE, Cycles and modifiers
