Texfind

Developer: Lucas Vera

FreeBlender

Fixes missing magenta textures in Blender by matching and replacing paths from folders you specify.

What Texfind does

TexFind sorts out broken texture paths that leave surfaces bright magenta. You list the folders where your textures live and the add-on matches missing images against them and replaces the paths.

Up to five directory slots can be searched at once, and a sorting algorithm accounts for certain naming conventions. The interface is intentionally simple. It targets Blender 3.6 and is released under the GPL license. Anyone opening files moved between computers or received from collaborators will recover textures quickly.

Key features

  • Bulk replace across five directory slots
  • Matches textures by name
  • Naming-convention-aware sorting
  • Simple interface
