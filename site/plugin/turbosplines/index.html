3ds Max script that creates and animates multiple spline-wrapped meshes through automatically assigned Path Deform modifiers.

What TurboSplines does

TurboSplines automates path deform animation along many splines at once in 3ds Max. Path Deform modifiers are attached automatically to preset or custom meshes, with every control in one interface instead of a pile of manual setup.

Presets include cylinder, capsule, box and ribbon, or you can use your own profile shapes. Animatable settings include radius, scale, height, segmentation, rotation, twist, stretch and path percent, and values can be copied between meshes. Taper, tip and slice options refine the look, and three modes, move, grow and reveal, add variation and offset. Renderable splines convert in one click, and a helper turns splines into helical paths, useful for cables, ropes, tentacles and springs.

Key features

  • Automatic Path Deform setup on multiple spline meshes
  • Cylinder, capsule, box and ribbon presets or custom profiles
  • Animatable radius, scale, twist, stretch and path percent
  • Move, grow and reveal modes with variation and offset
  • One-click conversion of renderable splines
