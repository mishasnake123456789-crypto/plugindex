What Right Mouse Navigation does

Right Mouse Navigation lets you fly through a Blender scene like in a game engine. Hold the right mouse button and use W, A, S, D, Q and E to move; a quick click opens the normal context menu.

A time threshold in preferences separates a hold from a click, and an optional Node Editor mode pans on hold and opens the node context or search menu on click. Artists navigating large environments and architecture appreciate the familiar movement.

Key features

  • Hold right mouse for walk navigation
  • Click for standard context menus
  • Adjustable hold threshold
  • Optional Node Editor mode
