What Nte Res Tools - Essential Camera Addon does

NTE RES Tools puts the common steps of preparing a render in a single place. Set custom Resolution X and Y or switch cameras instantly to standard portrait or landscape ratios.

You can add a new camera, set the active camera, enable focus, track objects, choose the output format and engine, then render. It suits quick shot setup for artists who dislike moving across multiple properties tabs. Keeping resolution, camera and output choices together makes quick shot setup easier than switching between properties tabs.

Key features

  • Custom resolution or portrait/landscape ratios
  • Add and activate cameras
  • Focus and object tracking
  • Output format and engine selection
  • Render from the same menu
