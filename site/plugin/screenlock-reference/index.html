ScreenLock Reference

Developer: rode3d

Free3ds Max
Download Free

3ds Max script that locks a transparent reference image to the camera view to guide modeling and projection work.

What ScreenLock Reference does

ScreenLock Reference attaches a reference image to a camera in 3ds Max, placing it as a transparent overlay between the camera and the scene. A modifier is added to the selected camera, carrying the controls to load and manage the image.

Images can be loaded in any format 3ds Max supports, with transparency taken from the alpha channel. The image can be tied to the reference plane (object-space mapping) or cast from the camera in world space. Scale, position and overall transparency can be tweaked, and visibility toggles easily. It suits modeling from photos, aligning scenes for video mapping and architectural layouts.

Key features

  • Camera modifier for loading and managing a reference image
  • Supports any 3ds Max image format with alpha transparency
  • Object-space or world-space projection mapping
  • Adjustable scale, position and transparency
  • Easy visibility toggle
