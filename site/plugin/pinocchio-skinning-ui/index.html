What Pinocchio Skinning UI does

Pinocchio Skinning UI offers a simple front end to Pinocchio skinning within 3ds Max. Pinocchio is an automatic rigging and skinning approach, and this script spares you from running it through command-line steps.

The Pinocchio binary is required and must be downloaded separately from the developer's page. The script is delivered as an .mcr file, was tested with 3ds Max 2012, and is a version 1 release. It is of interest to riggers and character artists who want to try automated skinning as a quick starting point for their characters.

Key features

  • Simple interface for Pinocchio skinning
