What Atlas Pro does

Atlas Pro is a texture atlas system for game artists using Blender. It merges materials across multi-material objects, deduplicates shared ones and repacks UVs in a single operation.

The PBR builder reads Base Color, Normal, Roughness, Metallic, AO and Emission and writes atlases at 512 to 4K, with an optional ORM map. It also builds trim sheets, N-by-1 palette textures, LOD-aware layouts and has a standalone channel packer with ORM, Unity, Unreal and Mobile presets. Output names use templates and save as PNG.

Key features

  • One-click PBR atlas builder with ORM option
  • Material deduplication across multi-material objects
  • Trim sheets and palette textures
  • Channel packer with engine presets
