What Stratify does

Stratify is a layer-timing tool for After Effects that handles the repetitive work of staggering and sequencing. Rather than nudging each layer by hand, you can offset them in classic fashion or let comp position drive the stagger pattern.

A random offset engine can affect the whole layer, only the in-point or only the out-point, while Force Range gives every layer its own value. A separate Sortify mode reorders layers in a compact interface, including proximity sorting. Copy and paste with ALT inverts staggering data, helpful for motion designers building rhythmic sequences.

Key features

  • Pattern-based stagger driven by comp position
  • Random offset for whole layer, in-point or out-point
  • Force Range gives each layer a unique offset
  • Sortify mode with proximity sorting
  • Sequencing from the last layer with Shift
