What Blendtopo - Topology Optimization does

Blendtopo is a free, open source (GPL-3.0) Blender add-on that brings topology optimization to the program. Given a build space, bearings and loads, it grows load-bearing structures that use as little material as needed.

You set up the build volume, anchor points with locked axes, and force vectors, which determine where material ends up. The optimization runs live from coarse to fine, with the shape forming and refining as it goes, and pressing ESC keeps the latest result. It appeals to designers working on lightweight parts and organic engineering forms.

Key features

  • Build space, bearing and load setup
  • Live coarse-to-fine optimization
  • ESC keeps the latest result
  • Open source, GPL-3.0 licensed
