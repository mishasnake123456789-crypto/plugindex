Blender add-on that copies a project's external textures, sequences, footage, sounds and caches into a local folder and relinks them.

What Gather Resources does

Gather Resources collects the outside media that a .blend file depends on and keeps it next to the project. It handles image textures, image sequences, video footage and sound in the sequencer, and caches like Mesh Sequence Cache.

Every file is duplicated into a textures folder next to the .blend and relinked, so the project stays complete when moved to another machine or shared with a collaborator. It saves hunting down missing paths at handoff time.

Key features

  • Collects textures, sequences, VSE footage and sound
  • Handles cache files like Mesh Sequence Cache
  • Copies into a local textures folder
  • Relinks files automatically
