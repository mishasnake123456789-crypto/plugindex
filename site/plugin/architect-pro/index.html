What Architect Pro does

Architect Pro, from Leyero, handles timeline rearranging. Selected clips can move up or down to the next free track, or swap tracks. Items picked in the Project panel can be inserted; choosing a folder drops in a random item from it.

Multiple items go stacked or in a row, and timeline clips can be copied with the right video and audio tracks set so pasting is safe. A minimum insertion track can be set, and Spell Book is integrated.

Key features

  • Move selected clips to next free track
  • Swap tracks of selected clips
  • Insert project items stacked or in a row
  • Random item from a chosen folder
  • Safe copy and paste targeting
