Blender add-on that upgrades SVG import with faithful colors, stroke thickness conversion and an optional emission shader.

What Enhanced SVG does

Enhanced SVG upgrades how Blender brings in SVG files. Colors are interpreted correctly and stroke thickness is converted so the original look is kept.

An optional emission shader makes elements self-illuminating, opacity is controlled through a property in the side panel, and drag-and-drop works for importing. Motion designers and logo animators can bring vector artwork into 3D with fewer fixes. Vector artwork from design tools often arrives with wrong colors or thin strokes in Blender, and this add-on corrects those issues.

Key features

  • Correct color interpretation
  • Stroke thickness conversion
  • Optional emission shader
  • Opacity control in side panel
  • Drag-and-drop import
