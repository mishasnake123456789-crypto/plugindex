What MonkeySauce does

Built by Orrin Zucker, MonkeySauce is a script running inside After Effects aimed at placing sound effects quickly. It places selected SFX in precomps using Single, Sequence and Expanded modes, and offers tools to sync them to markers.

Squeeze speeds audio up to fit before the next marker, and Mix Order randomizes the selected files or follows project panel order. Marker placement can be manual, repeated and random, or based on a layer's start, middle or end. Marker Sync aligns to existing markers, with a Random Sync variant, and utilities include Offset, Clean and Keyframes to Markers.

Key features

  • Single, Sequence and Expanded placement modes
  • Squeeze fits audio before the next marker
  • Mix Order randomizes or follows project order
  • Marker Sync with Random Sync variant
  • Offset, Clean and Keyframes to Markers utilities
