Free Blender add-on for snapping objects, vertices and points to others by picking a source and a target.

What QuickSnap does

QuickSnap brings Maya- and 3ds Max-style point snapping to Blender. You pick a source point and then a destination, and the object moves so the two coincide.

Points can be the cursor, object origins, vertices, curve points, edge midpoints and face centers, with a pie menu to change the point type. Movement can be restricted to an axis or plane with X, Y and Z hotkeys, and wireframe display switches on automatically for the involved meshes. Modelers assembling parts precisely will save time.

Key features

  • Snap between vertices, origins and midpoints
  • Pie menu to change point types
  • Axis and plane constraints
  • Automatic wireframe display
