Blender UV Editor add-on that reshapes selected UV faces into a grid of squares and aligns vertices.

What Uv Squares does

UV Squares tidies distorted UV layouts in Blender. Select quads in the UV Editor and they are straightened into an even grid of squares that honors the horizontal and vertical proportions of the faces.

Other helpers align sequences of vertices on an axis with equal spacing, rip faces and single vertices, and join selected vertices to the nearest unselected ones. Documentation is included. Texture artists cleaning up messy unwraps, especially on tiled or rectangular surfaces, get straight, predictable UVs quickly.

Key features

  • Straightens quads into an even square grid
  • Aligns and evenly spaces vertices
  • Rips faces and single vertices
  • Joins vertices to nearest unselected ones
