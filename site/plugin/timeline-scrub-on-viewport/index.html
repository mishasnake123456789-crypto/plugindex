What Timeline Scrub On Viewport does

Timeline Scrub On Viewport displays keyframes as a HUD bar in the viewport during scrubbing, so no separate timeline editor is needed.

Filtering is context-aware: selected objects only, selected bones in Pose Mode, active animation layer, or an optional global mode that includes NLA. The HUD is non-intrusive with adjustable opacity. It keeps animators focused on the character. You get viewport keyframe HUD, filtering by object, bone or layer and optional global mode with NLA, along with the rest of the feature set.

Key features

  • Viewport keyframe HUD
  • Filtering by object, bone or layer
  • Optional global mode with NLA
  • Adjustable opacity
