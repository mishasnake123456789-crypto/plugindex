What Maya Project Workflow does

Artists who come from Maya often miss its Project Window. Valentin's Maya Project Workflow offers two File menu commands to recreate that habit in Blender: Project Window and Set Project.

Project Window makes a folder, complete with subfolders, wherever you choose. Set Project then tells Blender to use that structure, so saving, rendering and file searching land in the matching directories. It keeps productions tidy and is listed for Blender 4.0 and 4.3 with documentation under the GPL.

Key features

  • Project Window button in the File menu
  • Creates folder with subfolders
  • Set Project links the folder to Blender
  • Auto-save, render and lookup in matching folders
  • Blender 4.0 and 4.3
