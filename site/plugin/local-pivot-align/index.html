Places an object's local pivot at the minimum, middle or maximum of its bounding box on each axis in 3ds Max.

What Local Pivot Align does

Local Pivot Align repositions an object's local pivot in 3ds Max using the extremes of its bounding box. Alignment methods are Min, Center and Max, and they can be applied on each axis separately through the axis buttons.

A dedicated Center button puts the pivot in the middle of the object. Installation is straightforward: drag and drop the MZP file, or use Run Script from the Scripting menu. It is helpful for artists who need predictable pivots, for instance at the base or corner of props, before placing, rotating or exporting objects.

Key features

  • Aligns local pivot using bounding box extremes
  • Min, Center and Max methods per axis
  • Axis buttons for chosen axis alignment
  • Dedicated Center button
  • MZP drag-and-drop or Run Script installation
