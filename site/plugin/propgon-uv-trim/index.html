What PropGon UV Trim does

PropGon UV Trim helps game and environment artists work with trimsheets in Blender. Trim Layout defines divisions and automatically fits UV islands into the slots, while Scan to Trim reads existing UVs and generates the divisions and layout for you.

Trim lists and atlas presets store named regions for reuse, texel density can be managed, ID maps can be baked, and a live overlay inside the UV Editor displays the trim layout. The toolset speeds up building reusable texture atlases for modular assets.

Key features

  • Trim Layout fits UV islands into slots automatically
  • Scan to Trim builds layouts from existing UVs
  • Trim List and Atlas Presets
  • Texel density tools and ID map baking
  • Real-time UV Editor overlay
