What Erosion Add-On does

The Erosion Add-On by NM-8 erodes custom meshes in Blender with a flow-based algorithm that goes beyond typical 2D heightmap workflows. Erosion can be applied once or iteratively while modeling.

Rivers and lakes run down the surface, and vertex groups record water and flow age, plus color attributes and a flow map for shading. Curves control and animate the erosion, and a particle system automatically distributes trees and plants. A Lite version covers erosion calculation, while the full one adds the 2D flowmap, rivers, lakes and more profile curves.

Key features

  • Flow-based erosion on any mesh
  • Rivers and lakes with vertex groups
  • Flow map and color attributes for shading
  • Curve control and animation
  • Automatic particle distribution of vegetation
