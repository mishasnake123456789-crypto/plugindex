What Lightpilot Pro does

LightPilot Pro keeps lighting work inside the 3D View. Select a light and a heads-up display lets you edit the values that matter without jumping between properties panels.

Power, size, spread, angle, blend, color and temperature can be dragged quickly or typed precisely. A Scene Light Table lists lights so you can select, sort, filter by type or state, rename and toggle visibility, while Isolate mode focuses on a single light's contribution. Artists balancing many lights in a scene will find it speeds up iteration.

Key features

  • Viewport HUD for the active light
  • Edit power, size, angle, color and temperature
  • Scene Light Table with sorting and filtering
  • Rename and toggle lights from the table
  • Isolate mode for one light's contribution
