What CandleCharts AE does

CandleCharts AE, by Kyler Alford, generates financial charts inside After Effects from data you provide in a .csv file. It makes filled candlestick charts, line charts drawn from closing prices, and volume charts.

A handle-based system resizes and animates the charts, and default animations are included for each type. Horizontal price labels, vertical date labels, outlines and scaling grids are provided, and a comment-driven tagging system helps select elements quickly. A trial mode builds charts with up to five intervals. It is aimed at finance explainers and market news graphics.

Key features

  • Candlestick, line and volume charts from CSV
  • Handle-based resizing and animation
  • Price labels, date labels and grids
  • Comment-driven element tagging
  • Trial mode limited to five intervals
