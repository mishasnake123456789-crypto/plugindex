What BOOM Library Cinematic Horror does

BOOM Library Cinematic Horror is a haunting sound collection co-produced with sound designer Richard Adrian. It works with After Effects, Premiere Pro and other WAV-compatible video and audio software.

The Construction Kit holds over 12 GB of sources: ambients, organic and synthetic drones, human sounds, impacts, metal squeaks and scrapes, rises, instruments and vocal choirs. The Designed collection delivers finished effects with four variations per file, and a bundle combines both. Every file has embedded metadata. Editors and sound designers can build dread and tension quickly.

Key features

  • 12GB+ of horror source recordings
  • Ambients, drones, impacts, scrapes and choirs
  • Designed effects with four variations per file
  • Co-produced by Richard Adrian
  • Embedded metadata in every file
