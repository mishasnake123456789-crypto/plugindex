What FAST FENCING does

Fast Fencing is a 3ds Max script that generates fences through a procedural FA_Fence object, with results updating in real time as parameters change. The structure follows any 3D spline and can adapt to terrain in base, smooth or stepped ways.

Main poles sit at every spline knot and intermediate poles at each subdivision. Fence types include a textured plane, poles and a palisade, and the geometry rebuilds automatically when the spline moves. Each part has its own material ID with UV mapping on some. Distances can be scaled together, parameters copied, and fence templates saved and loaded. The Oblong and Oblong Void primitives are included.

Key features

  • Spline-driven fence structure
  • Base, smooth or stepped terrain adaptation
  • Textured plane, poles and palisade types
  • Updates when the spline changes
  • Save and load fence templates
