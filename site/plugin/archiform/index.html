Architectural modeling add-on for Blender that creates parametric floors, siding, roofs and windows in one click.

What Archiform does

Archiform speeds up architectural modeling. From a dedicated ArchiForm tab in the N-Panel you can generate floors, siding or wall covers, roofs and windows with one click.

Dimensions and properties stay parametric and adjustable in real time, and the workflow is non-destructive, so components can be added, removed or edited without breaking the model. It works with Cycles and Eevee. It helps quickly blocking out houses and buildings. Highlights include one-click floors, siding, roofs, windows, parametric real-time controls and non-destructive component editing.

Key features

  • One-click floors, siding, roofs, windows
  • Parametric real-time controls
  • Non-destructive component editing
  • Cycles and Eevee support
