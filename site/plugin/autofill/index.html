What AutoFill does

AutoFill is an After Effects plugin from Plugin Everything that animates a fill across the edges of a layer. It spares you from hand-drawn masks and long keyframe chains when you need a shape to flood or reveal itself.

Under the hood it is multi-frame rendering native, uses the GPU first and drops back to the CPU when needed, and runs natively on Apple Silicon. A cache keeps previews smooth without re-simulating. Styling comes from RGBA gradients with their own editor and Style Builder, a built-in multitrack compositing system, and quality settings add supersampling, adaptive resolution and smart anti-aliasing. Motion designers handling busy layouts will appreciate the speed.

Key features

  • Fills layer bounds without manual masking
  • Native multi-frame rendering and Apple Silicon support
  • GPU pipeline with CPU fallback
  • Cached previews that avoid re-simulating
  • Style Builder and RGBA gradient editor
