MaxScript that builds Batch Render views from selected cameras by reading width, height and frame values from their names.

What ECamera2Batch does

ECamera2Batch creates entries for the 3ds Max Batch Render Manager from the cameras you select. Each camera name is scanned for width (w), height (h) and frame (f) values, and those are pushed into the render settings.

Multiple cameras are processed together and sorted alphabetically, each batch view gets a unique output filename, and duplicate detection stops repeated views. Custom parameters override preset settings, while existing configurations stay when none are specified. Output can be JPG, PNG or TGA, with a configurable directory and naming. The batch dialog toggles automatically and a report of successes and failures is given. Handy for visualization and product rendering with many angles.

Key features

  • Parses camera names for width, height and frame
  • Processes multiple cameras sorted alphabetically
  • Unique output filenames with duplicate detection
  • JPG, PNG and TGA output options
  • Integrates with the Batch Render Manager with statistics
