Blender add-on that swaps custom tags in output paths while rendering using Python expressions, fixed paths or scripts.

What Path Maker does

Path Maker substitutes custom tags in render output paths in Blender.

Each tag becomes a string taken from a one-line Python expression, a fixed path or a Python script. It works in the Output Path field, the Base Path of File Output compositor nodes and collection exporter file paths. Pipeline-minded artists can automate file naming and folder organization. Dynamic paths help keep render output organized by date, scene or shot name, without editing the output field each time something changes.

Key features

  • Tag replacement at render time
  • Works with Output Path and File Output nodes
  • Collection exporter support
  • Python expression, path or script tag types
