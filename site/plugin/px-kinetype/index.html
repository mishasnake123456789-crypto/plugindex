What PX-Kinetype does

PX-Kinetype is a free Pixflow plugin that helps After Effects users animate type quickly. Rather than keyframing every character, you choose from a set of ready animations covering kinetic typography, text-based scenes and titles.

Animations apply with one click, and settings like speed and effect intensity let you adapt each one. A live preview covers all templates, so you can see what a style does before using it. The interface is straightforward and aimed at being easy for newcomers.

Key features

  • Free text animator for After Effects
  • Kinetic typography, text scenes and titles
  • One-click application
  • Adjustable speed and intensity
  • Live preview of every template
