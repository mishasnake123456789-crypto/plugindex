A Geometry Nodes add-on for Blender that blends normals between two objects in one click to hide shading seams.

What Easy Blend Normals does

Easy Blend Normals smooths the shading transition where two objects meet in Blender. Select the two objects, run it, and the add-on detects which is active and which is the target, then blends their normals so seams and shading breaks disappear.

It is built on Geometry Nodes, so it stays non-destructive and editable. It is lightweight with no dependencies and ready for Blender 4.5. It is useful for fixing shading after boolean operations and for unifying separate kitbash parts. Hard-surface modelers and game artists who want seamless surfaces will find it quick.

Key features

  • One-click normal blending between two objects
  • Hides seams and shading breaks
  • Non-destructive Geometry Nodes setup
  • Automatic active and target detection
  • Fixes shading after booleans
