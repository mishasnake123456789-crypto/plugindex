Blender add-on for transferring mesh data and attributes from one object to another.

What MeshDataTransfer does

MeshDataTransfer, by maumemoli, copies mesh data and attributes between objects, which helps when you rebuild or retopologize a model and want to keep what it carried. It is tagged under Mesh, Modeling and UV.

Open source under GPL-3.0-or-later, it requires Blender 4.2.0 or newer.

Key features

  • Transfers mesh data between objects
  • Transfers attributes
