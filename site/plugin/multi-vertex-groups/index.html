Blender add-on for bulk selecting, filtering, locking, copying, deleting and renaming vertex groups.

What Multi-Vertex Groups does

Multi-Vertex Groups removes the one-at-a-time limit of Blender's vertex group list. You can handle many groups together from Properties > Object Data on the active mesh.

Filter groups by name with the standard list search, then select all, deselect all or invert the filtered set. Selected groups can be locked, unlocked or deleted, and copy and rename work in bulk as well. Operations affect only the groups currently visible after filtering, which keeps large rigs manageable.

Key features

  • Name filtering with the list search field
  • Select all, deselect all and invert
  • Lock and unlock selected groups
  • Bulk delete, copy and rename
  • Acts only on visible filtered groups
