What Digit Fiddler does

Digit Fiddler from Plugin Everything counts anything in After Effects using a single slider. It is a native plugin with expressions you can read and edit, rather than a hidden black box.

Monospacing is built in, including a mode for vertical text and a buffer expansion that accommodates text strokes. A time countdown option handles clocks and timers. It supports Apple Silicon natively and Multi-Frame Rendering. Designers animating statistics, prices, scoreboards or timers will find it simpler than building an expression setup.

Key features

  • Counting driven by a single slider
  • Monospacing including vertical text
  • Time countdown option
  • Buffer expansion for text strokes
  • Native Apple Silicon and MFR support
