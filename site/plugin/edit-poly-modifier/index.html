What Edit Poly Modifier [编辑多边形修改器] does

Edit Poly Modifier by RARA lets you edit a mesh through a separate cache object, with changes reflected in real time, in the spirit of an editable-poly workflow. It is listed under Object.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.
