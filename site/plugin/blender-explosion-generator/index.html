What Blender Explosion Generator does

Blender Explosion Generator creates explosions in real time from a single Geometry Nodes setup. It renders in Eevee and Cycles and is easy to adapt.

Options simplify the system for older PCs and laptops. Documentation and a demo video are included. It is a handy base for animated explosion effects. Highlights include real-time explosions, single Geometry Nodes setup and eevee and Cycles. It also brings lighter options for older hardware.
