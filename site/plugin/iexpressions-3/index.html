What iExpressions 3 does

iExpressions 3, by mamoworld tools, gives After Effects users ready-made expressions without requiring them to write JavaScript. More than a hundred are available, each controlled through an easy interface.

It helps in building expression-driven templates, character rigs and shape animations. You can import your own expressions, and projects keep working on computers without iExpressions installed, including in Premiere Pro Motion Graphics Templates. All expressions work with the new JavaScript expressions engine.

Key features

  • 100+ expressions with easy interfaces
  • Import your own expressions
  • Projects work without the plugin installed
  • Usable in Premiere Pro Motion Graphics Templates
  • Updated for the JavaScript expressions engine
