What Extrude does

Extrude by Plugin Everything adds an extrusion effect to DaVinci Resolve, turning flat images and text into blocks with visible depth. It is built as a DCTL plugin, so it runs inside the page without a separate application.

The tool works on macOS, Windows and Linux and supports DaVinci Resolve 20 and 19. A demo video is available for anyone who wants to see the effect before deciding to use it.

Key features
