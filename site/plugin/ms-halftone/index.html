After Effects effect that applies a halftone pattern directly to a layer, with dot shape and angle controls.

What m's Halftone does

m's Halftone converts a layer into a dot pattern in the style of print. Unlike some alternatives, it applies directly to the layer with no extra map layers to prepare, so the effect is quick to set up.

The shape can be a circle, square or line. DotSize sets the largest halftone element and the spacing interval, Rotation changes the pattern angle, Offset moves its start position, and Alpha controls the transparent white area. A Sampling setting selects how halftone size is calculated.

Key features

  • Circle, square and line shapes
  • DotSize for maximum size and interval
  • Rotation and Offset controls
  • Alpha for transparent whites
  • Sampling method selection; no layer maps needed
