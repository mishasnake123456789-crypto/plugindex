What Easy Envelope - A Controllable Tool To Weighting/Skinning does

Easy Envelope is a Blender add-on by oimoyu for weighting and skinning, extending Blender's envelope weight algorithm. Instead of accepting default results, you can adjust each bone's envelope range and see which vertices it affects.

Envelope shapes can be edited and saved to or loaded from files. A live preview displays weights without switching to weight paint mode: red means 1, blue means 0, white marks untouched vertices. An adjustable gradient curve controls transitions between bones, and results can be blended into existing weights safely, provided they share an armature.

Key features

  • View each envelope and its affected vertices
  • Save and load envelope shapes
  • Weight preview without weight paint mode
  • Adjustable gradient curve between bones
  • Mix with existing weights safely
