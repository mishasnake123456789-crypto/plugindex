Procedural walking animation for biped and multi-legged rigid body characters, driven by a Geometry Nodes group.

What Ik Dynamic does

IK Dynamic creates procedural animation in Blender for characters built from rigid parts, including multi-legged creatures and bipeds. It is powered by the IK Dynamic Geometry Nodes group, and all that is required to start is an IK rig.

A Create Armature Link workflow sets up the connection, and empty objects act as controllers. Feet are placed on a ground object you specify, so steps adapt to the terrain. Game and animation artists can get believable locomotion without keyframing each step.

Key features

  • Procedural stepping for bipeds and multi-legged rigs
  • Geometry Nodes node group
  • Create Armature Link workflow
  • Feet placed on a chosen ground object
