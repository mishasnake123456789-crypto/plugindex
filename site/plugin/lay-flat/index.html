Blender add-on that rests an object on the ground plane by aligning a selected face to Z=0.

What Lay Flat does

Lay Flat orients a 3D object so a chosen face lies flat on the floor in Blender. The rotation is mathematically exact and the object ends up at exactly Z=0, which helps with 3D print preparation and architectural visualization.

An optional Move to Origin centers the face at the world origin. Non-uniform object scaling is handled, one Ctrl+Z reverses everything, and it is available in the N panel or through F3 search.

Key features

  • Aligns a selected face to the ground
  • Places the object at exactly Z=0
  • Optional Move to Origin
  • Handles non-uniform scaling
  • Single-step undo
