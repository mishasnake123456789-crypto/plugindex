What 3-Points Aligner does

KVD's 3-Points Aligner positions mesh objects by correspondence of points. Make the source active, then click source and target points; each target point jumps to the closest corner as you pick.

With Matched enabled, the source is scaled to fit the target, otherwise it is only aligned. Auto opposite adds the opposite point across a diameter for cylindrical objects, and Apply Transforms resets scale to 1 afterward. It suits assembling parts precisely, in CAD-like modeling or kitbashing.

Key features

  • Three-point alignment with corner snapping
  • Matched option scales the source
  • Auto opposite for cylindrical objects
  • Apply Transforms resets scale to 1
  • Simple pick workflow
