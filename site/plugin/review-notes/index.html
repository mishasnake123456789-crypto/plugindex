Pins review feedback onto 3D models, shader nodes and material slots inside the Blender file.

What Review Notes does

Review Notes places comments exactly where they matter. Notes can be pinned to object surfaces and follow the mesh, or attached to shader nodes and individual sockets.

Comments can target specific slots on materials, modifiers, bones and UV maps, and it functions in the 3D View, Node Editor, Shader Editor and more. Everything stays inside the .blend file, so the feedback travels with the project. Teams and instructors reviewing scenes benefit.

Key features

  • Surface notes that follow the mesh
  • Notes on shader nodes and sockets
  • Comments on materials, modifiers, bones, UV maps
  • Works across several editors
  • Stored inside the Blender file
