Blender add-on that makes color palettes from a base color and applies them to materials.

What Color Palette Generator does

Color Palette Generator helps designers and 3D artists build harmonious colors without leaving Blender. Choose a base color with the picker and generate a palette.

Schemes include Complementary, Analogous, Triadic, Split-Complementary and Tetradic. The generated colors can be applied to materials in your scene with a single click. It integrates into Blender's interface and the developer provides documentation.

Key features

  • Base color picker
  • Five color harmony schemes
  • One-click application to materials
  • Integrated into Blender's UI
