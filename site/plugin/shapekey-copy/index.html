What ShapeKey Copy does

ShapeKey Copy is a Blender add-on from Blenderbob for moving shape keys between meshes. It can copy the keys with or without their animation, and it can also copy the animation by itself.

A button sets every shape key value to zero, and a separate section copies armature animation when the two armatures are identical. After installation the panel appears in the viewport's tool tab, and no special permissions are required. It helps artists who need to share facial or corrective shapes across related characters.

Key features

  • Copies shape keys between meshes
  • Copies animation with or without keys
  • Button to zero all shape key values
  • Armature animation copy for identical rigs
  • Panel in the viewport tool tab
