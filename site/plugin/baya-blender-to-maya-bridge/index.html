What Baya - Blender To Maya Bridge does

Baya is a Blender tool by Peter Gubin that generates Maya .ma source files from inside Blender. It gives a quick route for sharing data with Maya users and for working with Maya-centric game engine exporters.

You can choose Y or Z as the up axis, with Y as the default, and base color textures carry over to the Maya materials. Documentation is included. It suits Blender users who must hand scenes to a Maya pipeline without roundtripping through other formats.

Key features

  • Generates Maya .ma files in Blender
  • Y or Z up axis choice
  • Base color textures carry over to Maya materials
  • Fits Maya-oriented game exporters
  • Documentation included
