What Text Replacer does

Text Replacer, from The Machine Must Work, helps swap the wording in After Effects-built Mogrt templates inside Premiere Pro. Text can be exported from Mogrts into a spreadsheet, optionally only for selected ones, edited, and brought back.

It also creates Mogrts straight from an SRT file and can export Mogrt text to SRT. It works with Premiere Pro 2021 through 2025, useful for localization and bulk title changes. This is helpful when a template needs many text changes or when subtitles should drive animated lower thirds.

Key features

  • Import and export Mogrt text
  • Spreadsheet export, optionally for selected Mogrts
  • Create Mogrts from an SRT file
  • Export Mogrt text to SRT
  • Premiere Pro 2021 to 2025
