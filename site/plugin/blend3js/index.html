Blender add-on for viewing a scene live in three.js and saving it out as an HTML page.

What Blend3Js does

Blend3Js connects Blender with three.js for web delivery. It starts a local HTTP server pointing at an automatically created folder beside the .blend file, which stores the glTF, images and web files.

An Electron window then displays the scene, including its cameras, animations, lights and materials, and a GUI lets you adjust those elements. The finished three.js scene exports as an ordinary HTML page. A help panel inside the add-on shows documentation as you work. It runs on Windows and on macOS with Arm chips, and supports Cycles and Eevee scenes.

Key features

  • Local server preview of the scene
  • Electron viewer for glTF content
  • GUI for cameras, lights, animation and materials
  • Export to a standard HTML page
  • Windows and Arm-based macOS
