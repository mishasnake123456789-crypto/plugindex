What Quick Tool Assistant does

Quick Tool Assistant surfaces your Quick Favorites in a clean sidebar panel, so frequently used tools are always visible. Favorites are still managed through Blender's own system, and you can add or remove them whenever you like.

The display is context-aware, showing different favorites in different editors and modes, and a shortcut finder helps locate common commands. It suits users who want a persistent toolbox without custom scripting. Under the hood you get quick Favorites in a sidebar panel and add and remove through Blender's system.

Key features

  • Quick Favorites in a sidebar panel
  • Add and remove through Blender's system
  • Context-aware tool sets per editor
  • Shortcut finder for common commands
