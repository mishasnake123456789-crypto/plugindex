What Blender Enhance Kit does

Blender Enhance Kit, by Jishnu Jithu, gathers several small add-ons that smooth out routine work. It covers render setup, outliner cleanup, fonts and colors, project folders, importing and material handling.

Render Palette puts key render settings in one panel, Groupify groups objects and batch renames, Font Mate and Color Palette manage fonts and swatches, and Import Any brings in many formats and clipboard content. Mat Switcher and Mat Cleaner handle materials, Favorite and Last Used Modifiers speed up modifier access, and Set Project and Sync Blender manage folders and settings across versions.

Key features

  • Render Palette and Groupify
  • Font Mate, Color Palette and Import Any
  • Material switching and cleaning
  • Modifier shortcuts, project setup and settings sync
