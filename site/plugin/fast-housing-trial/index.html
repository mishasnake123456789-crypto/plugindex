Trial of a procedural 3ds Max house generator with real-time parameters, optimization and autobackup.

What FAST HOUSING Trial does

FAST HOUSING Trial generates a house structure through a custom procedural mesh object named FAHouse. As with other native 3ds Max objects, it can be rendered, takes any deformer and converts to mesh.

Parameters update live while you build, supporting varied architectural styles at a simple level. An Optimize geometry option reduces polygon and vertex counts, and Autobackup writes all parameters to an external file that can be loaded later. Each part of the house has its own material ID, some with custom mapping. Artists can evaluate the tool before buying.

Key features

  • Procedural FAHouse object
  • Real-time parameter updates
  • Optimize geometry option
  • Autobackup to a loadable file
  • Material ID for every part
