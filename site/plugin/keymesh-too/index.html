What Keymesh Too does

Keymesh Too is a Blender plugin for frame-by-frame mesh animation. It rebuilds Pablo Dobarro's Keymesh from scratch and works with almost all object types apart from empties and armatures.

A frame picker interface registers each version of an object you create, adds keyframes without duplicating them in the Dope Sheet, allows naming and deleting frames, and tracks how often each version is used. You can sculpt or model each pose in turn, producing a hand-made, stop-motion look.

Key features

  • Frame-by-frame sculpting or modeling
  • Frame Picker for every object version
  • Keyframes without Dope Sheet duplicates
  • Name and remove frames
