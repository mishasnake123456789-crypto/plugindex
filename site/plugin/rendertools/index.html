What Rendertools does

Rendertools gathers several helpers that improve productivity around render output. One of them exports video to GIF using FFMPEG, added in version 1.0.6.

Individual tools are switched on in the add-on preferences by clicking diamond icons. It works with Cycles and Eevee. It suits artists who regularly turn renders into shareable clips. You get several render productivity tools, video to GIF via FFMPEG and tools enabled individually in preferences, along with the rest of the feature set.

Key features

  • Several render productivity tools
  • Video to GIF via FFMPEG
  • Tools enabled individually in preferences
  • Cycles and Eevee support
