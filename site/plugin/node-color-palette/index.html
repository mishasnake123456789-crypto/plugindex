What Node Color Palette does

Node Color Palette makes it easy to color-code nodes in Blender graphs. Select nodes, click a color and the change applies.

It works in shading, compositing and geometry nodes editors and also supports visual scripting editors such as Sverchok and Serpens. It is distributed as a Blender extension under the GPL, with documentation.

Key features

  • Click a color to recolor selected nodes
  • Shading, compositing and geometry nodes
  • Sverchok and Serpens support
  • Blender extension
