What Duwamf+ does

DuWamf+ gives quick access to folders Blender users often need but rarely find. Instead of browsing the file system, you open them from within Blender.

It reaches the current file, installation, render, scripts, user resource and temp folders. Bookmarks can be global, stored with the add-on, or project-based, stored beside the .blend file and created automatically if missing. Both sets are editable, and letter shortcuts call folders quickly from the floating menu.

Key features

  • Opens current file, install, render and scripts folders
  • Global and project-based bookmarks
  • Auto-created project bookmarks file
  • Letter shortcuts in floating menu
