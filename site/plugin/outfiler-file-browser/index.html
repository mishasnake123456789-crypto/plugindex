What OutFiler file browser does

OutFiler swaps the usual file dialogs in 3ds Max for a folder tree, covering save, load, save selected, merge, import and export. It saves and loads scenes and objects and works with formats such as OBJ.

Objects can be merged by layer, paths can be copied, pasted and saved as favorites, and a list of recent paths and files is kept. Back and next buttons walk through navigation history, and operations can be assigned to hotkeys, including copying and pasting objects to another scene or window. Work happens in the background without waiting for the interface to update, speeding up file management.

Key features

  • Folder tree replacing standard file dialogs
  • Save and load scenes and objects
  • Merge objects by layer
  • Favorite and recent paths, history navigation
  • Hotkeys and background operations
