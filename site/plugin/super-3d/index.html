What Super 3D does

Super 3D from Motion Design School is an After Effects extension that makes 3D objects easier to handle inside compositions. It adds GLB and GLTF models with one click, so you do not need to leave for another application.

Models or textures can be replaced on existing layers, even animated ones, and 3D layers can be converted to solids so effects can be applied. Custom materials are built with adjustable PBR values such as metallic, roughness, normal intensity and base color. Text and complex shapes can also be turned into extruded 3D. The interface is responsive.

Key features

  • Import GLB and GLTF models in one click
  • Replace models or textures on existing layers
  • Convert 3D layers to solids
  • PBR material parameters
  • Convert text and shapes to extruded 3D
