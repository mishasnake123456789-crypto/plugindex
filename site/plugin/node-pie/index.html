Blender add-on that turns the Add Node menu into a pie menu opened by Ctrl-click, socket drag or link drag.

What Node Pie does

Node Pie replaces the usual Add menu in Blender's node editors with a pie menu. Choosing nodes becomes a gesture, helping you build muscle memory.

Ctrl-click opens the pie anywhere, Ctrl-dragging from a socket opens it and connects the node you choose, and Ctrl+Alt-dragging across a link inserts the node there. Nodes with incompatible sockets are dimmed during link dragging, and button sizing can optionally follow how often nodes are used. Shader, compositing and geometry node users build graphs faster.

Key features

  • Pie menu for adding nodes
  • Auto-connect when dragging from a socket
  • Insert nodes into links
  • Incompatible nodes dimmed
  • Frequency-based button sizing
