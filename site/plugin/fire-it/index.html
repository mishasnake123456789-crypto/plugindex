Fire It

Developer: Blender Bits

FreeBlender

Blender add-on that makes adjustable fire effects on any surface from 3D planes instead of volumes.

What Fire It does

Fire It creates flames in Blender and attaches them to any surface. It uses 3D planes rather than volumetrics, which keeps scenes lighter, and it renders in both Eevee and Cycles.

The fire can be a roaring blaze or something small and controlled. Scale, flicker speed, color and other settings are adjustable, so a single setup can cover a candle, a campfire or a burning object. Documentation is provided by Blender Bits.

Key features

  • Flames applied to any surface
  • Built from planes, not volumetrics
  • Adjustable scale, flicker speed and color
  • Works in Eevee and Cycles
  • Documentation included
