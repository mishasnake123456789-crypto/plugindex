What timeinpixels False Color does

False Color from timeinpixels maps image brightness to colours so you can judge exposure at a glance, and it can be used in After Effects, DaVinci Resolve and Premiere Pro. Ranges are customizable and can be exported as a 3D LUT.

Thirteen presets match common monitors, including SmallHD and Zacuto. The OpenFX build, for Resolve and SCRATCH, is GPU accelerated in real time, and Resolve users can put the scale on a separate movable overlay layer. Up to 15 colour ranges, grayscale options and sharp, smooth or gradient transitions are possible. A Saturation preset helps match saturation between shots.

Key features

  • Customizable ranges exported as 3D LUT
  • 13 presets including SmallHD and Zacuto
  • Real-time GPU OpenFX version
  • Movable scale overlay in Resolve
  • Saturation mode for matching shots
