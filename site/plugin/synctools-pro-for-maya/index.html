What Synctools Pro For Maya does

SyncTools Pro links Maya and Blender with a copy-and-paste workflow. One shortcut in each application moves content in either direction, with no separate import and export steps.

You can choose what is transferred: meshes, materials, lights, cameras, armatures and baked animations. Smart scaling matches units automatically so dimensions stay consistent. It speeds up pipelines that mix both packages. Notable points: two-way sync with one shortcut, selective transfer of scene elements and baked animation transfer.

Key features

  • Two-way sync with one shortcut
  • Selective transfer of scene elements
  • Baked animation transfer
  • Automatic unit matching
