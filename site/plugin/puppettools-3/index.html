What PuppetTools 3 does

PuppetTools 3, by Greg Gunn, speeds up character and object rigging in After Effects. It sets up inverse kinematics with a single click and generates controllers for almost any piece of artwork.

Controllers can be customized in look, size, name and behavior, and shape layer and mask path vertices can also be controlled, which requires CC 2018. A free practice rig is included so newcomers can learn the workflow before rigging their own characters. Animators who want arms, legs or mechanical parts to move naturally without building rigs from scratch will find it practical.

Key features

  • One-click inverse kinematics
  • Controllers for nearly any artwork
  • Shape layer and mask path vertex control
  • Customizable controller look and behavior
  • Free practice rig included
