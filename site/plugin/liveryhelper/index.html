What LiveryHelper does

LiveryHelper is a Blender add-on by Mast26 for building and tweaking car liveries. Pick a source image, add optional metallic and roughness maps plus a base color tint, and apply the livery to the chosen mesh.

Liveries can be moved, rotated and scaled, and automatically mirrored onto the car's opposite side. Projection is either planar, like a sticker, or box and triplanar for large tiling textures. The tint offers add, multiply and mix blend modes, and the result is built as a node group together with an Empty using built-in Blender features.

Key features

  • Source image with optional metallic and roughness maps
  • Base color tint with add, multiply and mix modes
  • Move, rotate, scale and auto-mirror liveries
  • Planar or box/triplanar projection
  • Built from a node group and an Empty
