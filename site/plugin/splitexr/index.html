Blender add-on that divides multichannel EXR images, drops unused channels and wires up Cryptomatte nodes.

What Splitexr does

Multichannel EXR files hold many passes, and sorting them out in the Compositor is repetitive. VFX Grace's Splitexr splits them into separate outputs and discards channels you will not use.

It also creates and connects Cryptomatte nodes in material, object or asset mode. If the file output node isn't using the OpenEXR MultiLayer format, folder hierarchy paths get added automatically during splitting. Documentation is included. Compositors passing passes to other programs avoid node wiring.

Key features

  • Splits multichannel EXR images
  • Removes unused channels
  • Cryptomatte in material, object and asset modes
  • Automatic folder hierarchy paths
  • Documentation included
