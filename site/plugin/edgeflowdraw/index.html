Lets you sweep out a strip of quads by hand in Blender, setting edge flow and silhouette from the very beginning.

What EdgeFlowDraw does

EdgeFlowDraw lets modelers lay down topology by drawing in Blender. Instead of beginning with a block-out or point-by-point modeling, you sweep the mouse to create a path of quads that defines edge flow and silhouette from the outset.

Quad size is adjusted with the scrollwheel, even before starting a path, the last quad can be undone with the right mouse button, and holding the middle mouse button lets you orbit while drawing. It suits character and hard-surface artists who care about clean flow.

Key features

  • Draw a path of quads freehand
  • Resize quads with the scrollwheel
  • Undo the last quad with RMB
  • Orbit with MMB while drawing
