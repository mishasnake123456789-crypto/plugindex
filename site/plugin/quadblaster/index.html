Extends Blender playblast with burnt-in metadata notes and four-view collage export for animation review.

What Quadblaster does

Quadblaster improves Viewport Rendering for animation review. It exports from the current view with metadata burned into the frames, so reviewers know which file and action they are watching.

One button makes a four-view collage that shows perspective, front, side and top together. Metadata options include animator name, file name, action name, fps and frame information. Animation teams sending playblasts for feedback will find the context helpful. Presenting the data with the render removes any guessing during review sessions.

Key features

  • Viewport render export with burnt-in notes
  • Four-view playblast collage
  • Animator, file, action and fps metadata
  • One-button export
