Extends Blender's Text Editor with group load and save, multi-file search and replace and a named clipboard.

What Text Ops does

Text Ops adds file and editing tools to Blender's Text Editor. Group Load/Save opens several files in one action and writes changes to all of them together.

Conflict resolution deals with differences between external files and Blender text blocks, .txt or .py extensions are added automatically, and every text block can be exported in a click. A multi-file search and replace and an external named clipboard for storing text round it out. Scripters managing many files get more power.

Key features

  • Group Load and Save
  • Conflict resolution with external files
  • Multi-file search and replace
  • External named clipboard
