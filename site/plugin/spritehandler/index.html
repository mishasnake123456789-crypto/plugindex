Blender toolset for creating, animating and generating sprite sheets with a UV-driven node group.

What Spritehandler does

Spritehandler, from Missing Field, brings sprite sheet handling into Blender. A node group manipulates UV coordinates to step through sheets loaded in image texture nodes.

Presets create sprite planes of Animated, Static, Particle Animated and Particle Static types. Controls cover start delay, speed, index offset and loop limits. Sheets can be generated from images or animation renders, atlases can be converted into meshes with alpha-based topology, and particle systems can drive indexing. A billboard toggle is included, and it works with render farms.

Key features

  • Preset sprite plane types including particle versions
  • Playback controls for delay, speed and loops
  • Generate sprite sheets from images or renders
  • Convert atlases to meshes
  • Render farm compatible
