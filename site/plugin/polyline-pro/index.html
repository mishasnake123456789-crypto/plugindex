What Polyline Pro does

Polyline Pro by miauu creates splines in 3ds Max using exact measurements and angles, much as AutoCAD does. Four drawing modes are available: Orthographic, Polar, Arc and Freehand.

Points can be set with absolute or relative coordinates, or by pointing in a direction and typing a length or angle. Object Snaps mark points or lines so drawing continues from their projection or intersection, and splines can use the World or a User Coordinate System. Splines remain editable after drawing, and guides, tooltips and short commands give quick access. Useful for floor plans and technical outlines.

Key features

  • Orthographic, Polar, Arc and Freehand modes
  • Absolute and relative coordinate entry
  • Direct distance and angle input
  • Object Snaps for projection and intersection
  • World and User Coordinate Systems
