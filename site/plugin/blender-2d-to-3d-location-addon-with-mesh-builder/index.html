What Blender 2D To 3D Location Addon - With Mesh Builder does

This add-on computes exact 3D positions from 2D camera tracking data in Blender. The trackings can come from Blender itself or from outside programs such as After Effects or Colmap.

You can create single or grouped locations from markers and judge their quality with an RMS error value. A Mesh Builder panel adjusts empty sizes and builds faces or meshes for modeling, simulations or shadow references. Right-click menu integration speeds up selecting and moving the points. Match-move artists gain a quick path from tracks to geometry.

Key features

  • Creates single or grouped 3D locations from 2D markers
  • Works with trackings from external software
  • RMS quality evaluation
  • Mesh Builder for faces and meshes
  • Right-click menu integration
