What Dynamic Context Menu does

Dynamic Context Menu offers a spacebar menu that changes with what you are doing in Blender's Object Mode. It sits in the 3D Viewport under View3D, Spacebar, and began as an add-on bundled with Blender 4.1.

It works with Blender 4.2 LTS and newer, needs no special permissions and is released under the GNU GPL. Users who like quick, context-relevant command access instead of deep menus can reach frequent actions with a single key.

Key features

  • Context-sensitive spacebar menu
  • Object Mode focus
  • Supports Blender 4.2 LTS and newer
  • No special permissions
