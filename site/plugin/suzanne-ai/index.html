Chatbot assistant in Blender's N panel that uses ChatGPT's language model to attempt tasks you describe.

What Suzanne Ai does

Suzanne AI is a conversational helper that lives in the N panel. It runs on the same language model as ChatGPT: describe a task, and she tries to carry it out inside Blender.

If the generated code errors, a Try Again button returns the error to her for a second attempt. Chat history is written to a text file whose location you set in the add-on preferences. The add-on connects to OpenAI with your own secret API key, which requires a paid OpenAI account. Documentation and a public roadmap of planned features are provided.

Key features

  • Chat assistant inside the N panel
  • Try Again feeds code errors back
  • History saved to a chosen text file
  • Requires your own OpenAI API key
