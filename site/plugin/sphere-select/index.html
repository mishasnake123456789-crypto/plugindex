Blender add-on for selecting objects, mesh elements and points with a 3D sphere.

What Sphere Select does

Sphere Select, by K_Naoki, selects things inside a sphere you place in 3D space rather than with a flat screen-space brush. That covers objects, mesh elements and points. It is listed under 3D View.

Open source under GPL-3.0-or-later, it requires Blender 4.2.0 or newer.

Key features

  • Select with a 3D sphere
