What Instant Calamari - Faster Playback For Animation does

Instant Calamari, from CBaileyFilm, aims to speed up viewport playback of heavy rigs. From the armature's data tab, one click builds a lighter version of the character.

Child meshes are split into slices based on vertex group weights and parented to the driving bones. The original deform meshes and the new calamari meshes live in separate collections, so you can swap between them quickly. Animators who struggle with sluggish playback can work at closer to real-time speeds.

Key features

  • One-click generation from the armature data tab
  • Splits meshes into bone-parented slices by weights
  • Original and calamari meshes in separate collections
  • Quick toggling between versions
  • Leaves vertex weights intact
