What Rectangle Tools does

Rectangle Tools is a Blender add-on by shinmera for quickly drawing rectangular geometry. Select a mesh, activate the tool, and drag to extrude a rectangle from the highlighted edge, which always stays aligned with its source.

The tool works in both Object and Edit modes, shows the edge it will extrude from, and snaps to a grid whose default step of 0.1 is adjustable. Releasing the mouse commits the shape and right-click cancels. Holding Ctrl switches to a midpoint mode that pushes both sides outward, and a plain click extrudes the whole edge.

Key features

  • Works in Object and Edit modes
  • Highlights the source edge before extruding
  • Adjustable grid snapping
  • Ctrl toggles midpoint extrusion
  • Click without dragging extrudes the full edge
