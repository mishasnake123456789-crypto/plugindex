What Pickup Tool does

Pickup Tool is a Blender add-on by Mohd Khurram for animating interaction between characters and props. It attaches an object to a target, carries it, releases it, and converts the result to keyframes with little setup.

A Set Target button picks the interaction object and shows its details in the panel. One-click Pick Up attaches without manual constraints, and One-click Drop releases for throws and drops. Animators can handle hand-offs and carried items quickly.

Key features

  • Set Target with details in the panel
  • One-click Pick Up without manual constraints
  • One-click Drop for release or throw
  • Motion baked into keyframes
