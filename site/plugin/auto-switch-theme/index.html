What Auto Switch Theme does

Auto Switch Theme is a small Blender add-on by pablovazquez that keeps Blender's interface in step with your computer's light or dark mode. It checks the system appearance when Blender starts, so the editor opens in the theme that fits.

You choose which installed themes to use for each mode, and the add-on reads available themes from disk using the Files permission. A refresh icon in Preferences lets you trigger the check manually without restarting. It installs by drag and drop or from disk and supports Blender 4.2 LTS and newer.

Key features

  • Matches Blender's theme to the system light or dark mode
  • Checks appearance automatically at startup
  • Manual refresh button in Preferences
  • Choose your own theme for each mode
  • Reads existing themes from disk
