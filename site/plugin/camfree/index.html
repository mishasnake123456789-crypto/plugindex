CamFree

Developer: JR3DFUL

FreeBlender

Blender add-on that lets Fly and Walk navigation work on scene cameras carrying object constraints.

What CamFree does

CamFree solves a navigation problem in Blender: constraints on a camera normally block Fly and Walk modes. When you navigate in Camera View with a constrained camera, it duplicates the camera, strips the constraints from the copy, makes it the active camera and starts the standard navigation.

Left-click or Enter commits the final transform back to the original camera, while right-click restores the original state. It piggybacks on your existing navigation shortcuts, with manual commands in the View, Navigation menu.

Key features

  • Fly and Walk navigation with constrained cameras
  • Automatic constraint detection
  • Commit transform on accept
  • Right-click restores the original camera
  • Uses existing navigation shortcuts
