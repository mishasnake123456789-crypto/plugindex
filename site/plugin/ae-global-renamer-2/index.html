What AE Global Renamer 2 does

AE Global Renamer 2 by Lloyd Alvarez renames lots of things at once in After Effects from a very small, dockable panel. It covers project items, layers, effects, text, markers, expressions, property names and render queue footage paths.

You can use unlimited search and replace pairs, add prefixes or suffixes, apply incremental numbering with padding, or rename only duplicates. A regular expression mode is included, and name tokens like [layername], [layerindex], [compname] and [projectname] insert values automatically. Renaming setups save as presets for repeated use.

Key features

  • Unlimited search and replace pairs
  • Prefix, suffix and incremental numbering
  • Regular expression mode
  • Name tokens like [layername] and [compname]
  • Saved renaming presets
