What Super3D Import & Export .Dwg does

Super3D Import & Export .Dwg opens Autodesk DWG CAD drawings inside Blender and exports scene geometry back out. It adds File > Import and File > Export entries for the format.

Conversion runs on the Super3D cloud service, so Blender stays lightweight and no AutoCAD seat is required. Architects and engineers can use CAD plans in Blender as a basis for modeling and visualization. Highlights cover file menu import and export for .dwg and cloud conversion via Super3D.

Key features

  • File menu import and export for .dwg
  • Cloud conversion via Super3D
  • No AutoCAD seat needed
  • Brings in 2D drawing geometry
