What Decal Flow does

Decal Flow is a Blender plugin for adding surface detail with real geometry. Instead of textures, it wraps decal designs made of mesh onto other mesh surfaces.

Decals are drawn with ordinary edit mode tools on a grid of faces, and meshes can also be generated from images, so no external software is needed. A sample blend file accompanies a video tutorial. A good option for hard surface panels, logos and wear.

Key features

  • Projects mesh decals onto surfaces
  • Generates meshes from images
  • Grid-based face-driven design
  • Sample file included
