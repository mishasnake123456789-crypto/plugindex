What Unwrap does

Unwrap by Chuggnut builds on the unwrap script that came with 3ds Max 3.0. It keeps the same idea but adds a selection of preset sizes and more error checking than the original, making the process a bit more forgiving.

Multiple objects can be unwrapped at once, either onto one shared bitmap or onto separate bitmaps for each. It is maintained at version 2.3.5. It is a plain utility for anyone wanting a substitute for the built-in script, especially when several meshes should share one texture layout.

Key features

  • Based on the 3ds Max 3.0 unwrap script
  • Preset output sizes
  • Additional error checking
  • Unwraps multiple objects to one or separate bitmaps
  • Version 2.3.5
