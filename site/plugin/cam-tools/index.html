Blender add-on for adding, organizing and managing cameras with per-camera resolution and saved view slots.

What Cam Tools does

Cam Tools speeds up camera work in Blender. Add Camera From View reproduces the current viewport framing and files new cameras into a Cameras collection with tidy sequential names. A sorted list lets you select, activate, duplicate and delete cameras, and group them into sub-collections for shot filtering.

Per-camera resolution overrides leave global render settings alone, view slots save and recall viewport angles, and auto-level verticals use lens shift. Composition guides, passepartout and a depth of field panel with distance readout help framing.

Key features

  • Add camera from viewport view
  • Sorted camera list with grouping
  • Per-camera resolution overrides
  • Named view slots
  • Auto-level verticals with lens shift
