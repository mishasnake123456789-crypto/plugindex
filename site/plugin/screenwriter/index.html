Blender add-on for writing screenplays in the Text Editor, with auto-formatting, Fountain import/export and scene syncing.

What Screenwriter does

Screenwriter makes Blender's Text Editor usable for proper script writing. A sidebar panel has buttons that format lines as headings for scenes, action text, character names, dialogue, parentheticals and transitions; INT./EXT. headings are uppercased automatically.

Fountain files can be imported and exported, and scripts can be synchronized to Blender Scenes. Filmmakers and animators who want to write their story, then plan shots in the same file as their project, can keep everything together.

Key features

  • Screenplay formatting buttons in the Text Editor
  • Auto-uppercase INT./EXT. scene headers
  • Fountain file import and export
  • Sync scripts to Blender Scenes
