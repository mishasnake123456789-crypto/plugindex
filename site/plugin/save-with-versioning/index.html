What Save with Versioning does

Save with Versioning is a Blender add-on by DShot92 that bumps the number embedded in the file name at every save. Each save creates the next version, so older states remain available.

A publish function keeps a published file as the newest version, letting other files link assets to it while you continue working on incremental versions. Anything linked to the published file refreshes on publish. Version and publish suffixes can be customized in the preferences, and a sidebar file list shows all versions of the current project.

Key features

  • Automatic version increment on every save
  • Publish function for a stable linkable file
  • Linked files update when you publish
  • Customizable version and publish suffixes
  • Sidebar list of all file versions
