Free Blender add-on that pastes a Hex or RGB color from the clipboard onto a color property with gamma correction.

What Color Paster does

Color Paster takes a color you copied from a picker or a website and applies it to a Blender color property, correcting for gamma so the result matches what you saw.

It accepts Hex values with or without the leading hash, and RGB or RGBA numbers including rgb() and rgba() notation, with flexible spacing after commas. Run it from F3 search, or bind it to a shortcut or quick favorite. Documentation is included. It saves manual conversion when matching brand colors or reference palettes.

Key features

  • Pastes clipboard colors with gamma correction
  • Hex input, '#' optional
  • RGB and RGBA including rgb() notation
  • Run via F3 search or shortcut
  • Free add-on
