Blender add-on that imports meshes, materials and UVs from Autodesk 3ds Max .max files.

What Import Autodesk MAX (.max) does

Import Autodesk MAX lets Blender open geometry from native 3ds Max .max files without a trip through 3ds Max itself. It appears in File > Import and reads meshes, materials and texture coordinates.

A wide range of material types is recognized, including Standard, Physical, Multi-Sub, Raytrace, Shellac, V-Ray, Arch & Design and Corona, with their base color, roughness and metalness values. NRGSille is the author. Artists inheriting old scene files, or those collaborating with Max users, can recover assets for use in Blender.

Key features

  • Imports meshes, materials and UVs
  • Found in File > Import
  • Supports many material types including V-Ray and Corona
  • Reads base color, roughness and metalness
