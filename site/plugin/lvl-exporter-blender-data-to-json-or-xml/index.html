Blender add-on that exports scene layout data to JSON or XML for rebuilding scenes in ThreeJs, Panda3D and similar.

What Lvl Exporter - Blender Data To Json Or Xml does

Lvl Exporter writes the layout of a Blender scene into XML or JSON so another program can recreate it. It suits frameworks without a level editor, such as ThreeJs or Panda3D, where you parse the file and place objects in code.

Elements are sorted into meshes, colliders, lights, spawns and cameras. Meshes, lights and cameras are exported and categorized automatically, and you can mark an element as a spawn or a collider. Locations, rotations and scales are written out, along with type, dimension and radius for certain items. Documentation is included.

Key features

  • Exports to XML or JSON
  • Sorts into meshes, colliders, lights, spawns and cameras
  • Exports location, rotation and scale
  • Mark elements as spawns or colliders
  • Type, dimension and radius data for some items
