What Folded Paper Engine does

Folded Paper Engine, from Papercraft-Games, lets you set up gameplay directly in Blender and then produce a playable level in Godot with little manual work on the engine side. Custom property panels are used to describe characters, players and triggers.

Behaviors such as speakers, physics and holdable items can be assigned, and scene and animation metadata is passed along too. It is meant for developers who prefer to design interactive scenes in Blender and generate the Godot project automatically.

Key features

  • Custom Blender property panels for gameplay logic
  • Character, player and trigger object types
  • Speaker, physics and holdable item behaviors
  • Scene and animation metadata
  • Generates a playable Godot level
