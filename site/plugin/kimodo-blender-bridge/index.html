What Kimodo Blender Bridge does

Lewdineer's Kimodo Blender Bridge lets animators describe a movement in words and receive it on a rig, avoiding terminal work and manual BVH imports. It wraps NVIDIA's Kimodo text-to-motion AI.

One-click Install Kimodo (Auto) prepares its own Python environment, then fetches PyTorch, the model weights and the text encoder while showing progress. Motion lands on a Kimodo_Source armature or any armature chosen by eyedropper, and a Motion Segments panel chains several prompts across frame ranges with transition frames.

Key features

  • Prompt-driven motion generation
  • One-click automatic installation
  • Works on any armature via eyedropper
  • Chain prompts with frame ranges
  • Transition frames between segments
