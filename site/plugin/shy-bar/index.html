What Shy Bar does

Shy Bar, by MonkyyJM, helps manage busy compositions in After Effects by filtering layers. Dedicated windows group shapes, precomps, adjustment, audio, video, Photoshop, Illustrator and missing-asset layers, and a Seeker Sleuth search window supports case-sensitive search and multi-label color selection.

Modifier keys add layers, solo, enable or select. Filters cover solo, locked, guide, 3D and enabled layers, plus layers with masks, comments, markers, effects, motion blur or expressions. Layers matching the current time, work area or composition start and end can be selected. After Effects 2025 themes and custom buttons are supported, and a Label Colors panel is optional.

Key features

  • Windows for layer types including missing assets
  • Seeker Sleuth search with label color selection
  • Modifier-key controls for add, solo and enable
  • Filters by masks, effects, markers and expressions
  • Time-based layer selection
