What Middle Measure does

Middle Measure is a Gary Reisman tool for finding the center between things in After Effects. It uses nulls, objects, layers and layer edges as references, which is helpful for exact alignment.

It works in both 2D and 3D, can create dynamic expressions that keep layers centered automatically, and can generate lines between layers. Help tips are built into the interface, and Universal Language support lets it run in non-English installations. Designers who need precise spacing and centering will find it useful.

Key features

  • Finds the middle using nulls, layers and edges
  • Works in 2D and 3D
  • Dynamic expressions to auto center layers
  • Generates lines between layers
  • Universal Language support
