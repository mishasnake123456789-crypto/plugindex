Yatima's Blender utility for tidying the add-on list with presets, search, hiding and live code reload.

What Addons Manager does

A long list of installed Blender add-ons is hard to manage. Yatima's Addons Manager lets you switch add-ons on or off, hide some, and flip between a filtered list and the full one, with live search for finding them.

Workflow presets can be created, named, loaded, renamed and deleted, and they last across sessions. Preferences are saved and restored automatically when you turn an add-on off and on again. Developers get hot reload for their own code. Users with dozens of add-ons start up faster and cleaner.

Key features

  • Enable, disable and hide add-ons
  • Persistent workflow presets
  • Preserves preferences when toggling
  • Live search
  • Hot reload for developers
