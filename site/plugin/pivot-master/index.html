A Blender add-on that moves a mesh's origin to any selected face, edge or vertex in one click.

What Pivot Master does

Pivot Master reassigns a mesh's local origin to a chosen component with one click. Whether you select a single face, several faces, vertices or edges, the origin moves to that location, which is helpful for hinges, doors, rotations and game engine export.

It is available from the Mesh menu in Edit Mode, with custom hotkey support and Alt+1 as the default. It is compatible with Blender 3.6 and 4.0, comes with documentation and is distributed under the GPL. Modelers who reposition pivots frequently will find it avoids setting the 3D cursor first.

Key features

  • One-click origin reassignment
  • Works from faces, vertices or edges
  • Mesh menu in Edit Mode
  • Alt+1 default hotkey
  • Blender 3.6 and 4.0
