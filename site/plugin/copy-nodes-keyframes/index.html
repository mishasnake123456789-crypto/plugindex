Blender add-on that duplicates or copies nodes while keeping their animation data, drivers and links intact.

What Copy Nodes Keyframes does

Duplicating a node in Blender normally drops its keyframes and drivers. Olivier Crespo Barrio's Copy Nodes Keyframes keeps them: nodes are duplicated together with their keys, drivers and links.

Drivers inside node groups are repaired automatically when required, across several selected nodes at once, including groups whose inner nodes have drivers. You may also copy nodes and paste them into a different node tree, but not the same tree or one nested within it. Dedicated keyboard shortcuts cover both actions.

Key features

  • Duplicates nodes with keyframes, drivers and links
  • Automatic driver repair inside groups
  • Works on multiple selected nodes
  • Copy and paste into another node tree
  • Keyboard shortcuts for duplicate and paste
