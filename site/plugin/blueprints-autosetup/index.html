What Blueprints Autosetup does

Blueprints Autosetup prepares reference images for car or vehicle modeling in Blender. It imports the different blueprint views and places them correctly before you start building the model.

This addresses the scale issues and misalignment common with reference images. Documentation is included. Hard-surface and vehicle modelers can skip the tedious manual alignment of front, side and top views.

Key features

  • Imports all blueprint views
  • Positions views correctly
  • Addresses scale and misalignment
  • Documentation included
