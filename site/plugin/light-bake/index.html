Blender lightmap and probe baking tool that exports data for real-time engines.

What Light Bake does

Light Bake prepares baked lighting in Blender for game engines and other real-time targets. It pairs a lightmap baking system with an Eevee-driven probe workflow and manages the export end to end.

Presets define the lightmaps, attach objects, and run bakes in batches, with each object packed individually. Diffuse, Combined and AO bake types are offered, along with resolution and quality controls. An extra compositing step works around the denoising legacy problem. Probe baking produces radiance and irradiance packs with a global fallback probe. Results are written either as a standalone JSON file or embedded in glTF, using OpenEXR or PNG images.

Key features

  • Preset-driven lightmap baking in packs
  • Diffuse, Combined and AO bake types
  • Eevee-based radiance and irradiance probes
  • Compositing workaround for denoise issue
  • Export as JSON or glTF, EXR or PNG
