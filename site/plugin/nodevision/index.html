Blender add-on that lights up a node and its links under the cursor to make busy node graphs easier to read.

What Nodevision does

Following wires across a sprawling node tree is a chore. NodeVision by AlbertoFX highlights whichever node you hover over along with the connections attached to it, so relationships stand out immediately.

Highlight thickness can be set from thin to bold, and a toggle in the settings popover optionally selects nodes as you hover. A header button with a state icon switches the feature, and pressing ESC turns it off. Anyone building large shader or geometry graphs gains clarity.

Key features

  • Hover highlighting of nodes and links
  • Adjustable highlight line width
  • Auto-select on hover toggle
  • Header toggle with state icon
  • ESC key deactivates highlighting
