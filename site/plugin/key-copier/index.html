What Key copier does

Key copier adds familiar keyboard shortcuts to the Track View in 3ds Max. Ctrl+C copies keys and Ctrl+V pastes them, making the animation editing feel more like other software.

The script relies on Chugg_globals, which is explained in the help text that comes with it, and it is built for 3ds Max 4.x. It is a small utility from Chuggnut and mainly relevant to users of that older version who find the default copy and paste workflow for keys cumbersome.

Key features

  • Ctrl+C copies keys in the Track View
  • Ctrl+V pastes keys in the Track View
  • Uses Chugg_globals, described in the included help
  • Built for 3ds Max 4.x
