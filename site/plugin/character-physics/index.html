What Character Physics does

Character Physics adds physics effects directly to armatures in Blender, aimed at animators who want mocap-like motion without equipment.

It is a complete physics engine written in Python, with interactive simulation for ropes, wires, hair, clothing and vehicles, and support for fantasy characters. The developer publishes monthly updates with features, improvements and assets, and documentation is included.

Key features

  • Physics effects on armatures
  • Ropes, wires, hair, clothing and vehicles
  • Written entirely in Python
  • Monthly updates
