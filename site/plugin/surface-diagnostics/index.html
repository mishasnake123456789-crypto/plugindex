What Surface Diagnostics does

Surface Diagnostics is a Blender addon by JLBöhm for technical surfacing. It places a curvature graph and analytic shaders one click away, for demanding curved surfaces in car design, product design and game assets.

The toolset spans Curvature, Radius, Draft, Proximity, Slice, Sections, Isoangle and Zebra views, along with Curvature and Angle graphs. A custom geometry nodes modifier turns curvature graphs into new mesh objects. Every tool is an ordinary Blender node tree, so it functions independently in an unmodified Blender, and the shaders are applied via geometry node modifiers.

Key features

  • Zebra, Isoangle, Draft, Radius and Curvature views
  • Curvature and Angle graphs as mesh objects
  • Built as standard node trees
  • Diagnostic shaders applied via geometry nodes
  • For automotive, product and game surfaces
