What Posingatwill does

Posingatwill speeds up character posing by letting you rotate bones directly with the mouse. It works on any FK rig without preparation.

Target Set rings define the rotation direction with an outer ring and apply it with an inner one, while Roll Set rings fixed at the bone head adjust bone roll. Animators who find the standard rotate tool slow can pose more intuitively. By cutting out rig preparation, it keeps focus on the pose itself rather than controls and constraints.

Key features

  • Mouse-driven bone rotation
  • Bone roll adjustment
  • Works with any FK rig
  • Target Set and Roll Set rings
