Collects everyday Blender utilities: bulk material assignment, all-camera rendering, vertex group separation and modifier application.

What Quickaction Toolbox does

QuickAction Toolbox groups several routine jobs into short tools. Apply Material to Selected gives many objects the same material in one pass, and Render All Cameras to Folder produces an image from each scene camera and files them in a location you pick.

Other tools separate meshes by vertex group, apply modifiers, and sync viewport visibility to render visibility. It is meant for artists who want fewer clicks on common housekeeping tasks.

Key features

  • Apply a material to many selected objects
  • Render from all cameras into a folder
  • Separate meshes by vertex group
  • Apply modifiers
  • Sync viewport and render visibility
