What Hook Curve does

Hook Curve, from Animation Store, quickly sets up control over curves in Blender. Instead of hooking each point separately, one click hooks a curve with an empty, and another rigs it with a bone.

It also includes the Hook Nurbspath feature, and documentation is provided.

Key features

  • Hook a curve with an empty in one click
  • Rig a curve with a bone in one click
  • No separate point hooking
  • Includes Hook Nurbspath
