What B3D UI Language Loop does

B3D UI Language Loop is a tiny Blender add-on for people who read Blender in more than one language. Press Ctrl + Alt + Shift + T and the interface switches to the next available language, repeating through the list.

It was created for non-English speakers who follow tutorials recorded in different languages and need to see matching menu names. The whole add-on is a single Python file, b3d-ui-langloop.py, which makes it easy to download and install.

Key features

  • Cycles through Blender's interface languages
  • Ctrl + Alt + Shift + T shortcut
  • Installs from one Python file
  • Built for multilingual tutorial following
