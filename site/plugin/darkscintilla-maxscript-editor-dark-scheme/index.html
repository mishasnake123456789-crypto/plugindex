Dark color and font scheme for the 3ds Max MAXScript editor, based on schemes from popular IDEs.

What DarkScintilla: Maxscript Editor dark scheme does

DarkScintilla gives the MAXScript Editor in 3ds Max a darker look. It reworks the colors and fonts of the Scintilla-based editor using ideas from dark themes the developer uses in IDEs such as MonoDevelop, FlashDevelop, Eclipse and Visual Studio.

Almost all color settings were moved into MXS_EditorUser.properties using symbolic color names, so adjusting a color means changing one value there. The scheme uses Microsoft's Consolas font, which is a free download, and an installer script is included. Script writers who spend long hours in the editor can reduce glare.

Key features

  • Dark color scheme for the MAXScript Editor
  • Settings from MonoDevelop, Eclipse and Visual Studio
  • Symbolic colors in MXS_EditorUser.properties
  • Uses the Consolas font
  • Installer script included
