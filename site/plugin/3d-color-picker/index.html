What 3D Color Picker does

3D Color Picker puts a color-picking interface right in the Blender 3D viewport. Its cube-shaped palette lays out hue, saturation and lightness along the X, Y and Z axes, so you can pick shades spatially instead of with flat sliders.

Choices feed the Base Color of Principled BSDF materials, and light colors can be adjusted too, with several materials editable at once. A Shaker function generates random color combinations, letting you set HSV ranges per channel and favor light, dark or bright results. It is a quick way to explore palettes for a scene.

Key features

  • Cube palette mapping HSL to X, Y and Z
  • Edits Principled BSDF Base Color and lights
  • Several materials adjustable together
  • Shaker for random palettes with HSV ranges
