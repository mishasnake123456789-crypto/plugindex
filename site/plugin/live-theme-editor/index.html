What Live Theme Editor does

Live Theme Editor lets Blender users experiment with interface colors without fear. When editing starts, it stores the current theme as an XML snapshot, and anything you change shows up immediately in the interface.

Abort and Revert restores the original, whereas Reset to Start of Editing wipes the latest changes but keeps the session open. Each color and property has its own reset button. A target area selector chooses between the 3D Viewport, Graph Editor or Outliner, or tracks whichever area the cursor is over. Frequently used properties can be pinned to a top list, and sub-categories like widget colors, gradients and bone color sets are one click away.

Key features

  • Snapshot of the current theme
  • Abort and Revert, or reset to start
  • Per-property reset buttons
  • Area selector for viewport, graph and outliner
  • Pinned properties and sub-category jumps
