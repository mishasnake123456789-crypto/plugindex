What Botton_Remove does

Botton_Remove is a cleanup add-on that deletes unneeded scene elements and lets you bring them back. Items are sorted into categories for Materials, Geometry, Node Groups and Collections, using interactive dialogs and smart filters.

Quick Mode sweeps away unused materials, orphan data, empty slots and duplicates in a click. A deletion history records removals so you can recover items when needed. It keeps files lean and organized without the fear of losing something permanently.

Key features

  • Category sorting with smart filters
  • Quick Mode removes unused materials and orphaned data
  • Clears empty slots and duplicates
  • Deletion history for recovery
  • Handles node groups and collections
