What Strip Array does

Strip Array is a Blender add-on for the Video Sequence Editor. It takes chosen strips of any kind (video, image, sound or effect) and repeats them into an array, which is useful for building repetitive edits without copying by hand.

You set the number of duplicates and the offset between them, measured in frames or in time, and channel placement can be adjusted so copies do not overlap. Each duplicate can receive a random frame offset and a random color tag to help tell them apart. A counter displays how many strips exist and how many are selected.

Key features

  • Duplicates strips into arrays of a chosen count
  • Frame-based or time-based incremental offsets
  • Channel adjustment to avoid overlap
  • Random frame offsets per duplicate
  • Random color tags and a strip counter
