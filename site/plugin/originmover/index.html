Blender add-on to view and edit an object's origin position numerically in real time.

What Originmover does

Origin Mover lets Blender users place an object's origin precisely by typing coordinates. It is helpful in architectural visualization, character modeling and product design.

X, Y and Z values appear in the 3D View's Item tab and update instantly as you change them. Geometry and scale stay unaffected while only the origin moves. Documentation is available and the add-on is GPL licensed.

Key features

  • Edit origin X, Y and Z directly
  • Real-time updates
  • Geometry and scale unaffected
  • Lives in the 3D View Item tab
