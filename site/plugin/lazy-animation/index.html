Blender add-on that generates movement keyframes for selected objects along a curve to the 3D cursor, with sync and reverse.

What Lazy Animation does

Lazy Animation creates movement keyframes in Blender with a single click. Select objects, place the cursor where they should end up, set a number of frames, and they travel there along a custom curve path.

Two modes are available: frame by frame, which sequences the keyframes one object after another, and sync, which moves several objects at once for group actions. A reverse option flips the direction for back-and-forth or rewind effects. It is meant to speed up camera moves, path animations, object sequences and product positioning. Documentation is included.

Key features

  • One-click movement keyframes for selected objects
  • Travels along a custom curve to the cursor position
  • Frame-by-frame and sync modes
  • Multi-object synchronized movement
  • Reverse mode for rewind effects
