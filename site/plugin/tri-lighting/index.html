Blender add-on that adds a three-point light setup around the selected or active object.

What Tri-lighting does

Tri-lighting places key, fill and back lights around an object in Blender with a single operator. It lives in the 3D Viewport under Add > Lights and previously came with Blender 4.1.

Version 0.2.1 sets better defaults, and the operator now aborts rather than creating a camera if the scene has none. It needs no special permissions and works with Blender 4.2 LTS and newer. Beginners and product visualizers can get a balanced studio lighting rig immediately and refine it afterward.

Key features

  • Three-point light setup on an object
  • Found in Add > Lights
  • Improved defaults in 0.2.1
  • For Blender 4.2 LTS and newer
