What PageProof. Making feedback welcome does

PageProof is an online review system, and this extension connects it to After Effects and Premiere Pro. Creatives can start proofs without leaving their editing app, then see client or colleague comments and markup laid over the file.

From the panel you can create a new proof or a new version of one, mark comments as done after addressing them, and open a dashboard showing the state of your proofs. It's intended for teams that need structured review and sign-off for video and other content.

Key features

  • Create proofs from the host app
  • View comments and markup over the file
  • Mark comments as done
  • Create new proof versions
  • Dashboard of your proofs
