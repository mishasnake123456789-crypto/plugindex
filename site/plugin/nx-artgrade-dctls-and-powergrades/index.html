What Nx ArtGrade - DCTLs and PowerGrades does

Nx ArtGrade bundles several DCTL tools with ready-made PowerGrades, giving DaVinci Resolve users a set of artistic effects that can transform both video and still images. It comes from Nx Color and is built for Resolve 19.

Version 2.0 added support for macOS in addition to Windows, and the tools work with both Metal and CUDA graphics acceleration. Because PowerGrades can be dropped straight into a node tree, colorists can start from a finished stylization and then adjust it, while the DCTLs offer finer control. It suits anyone who wants creative, non-photographic treatments inside the grading workflow.

Key features

  • Several DCTL tools for artistic effects
  • Bundled PowerGrades ready to drop into a node tree
  • Works on video and images
  • Supports macOS and Windows with Metal and CUDA
