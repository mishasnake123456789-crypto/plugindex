A Blender add-on for scattering object instances by clicking, drawing curves or lines, with random rotation and scale.

What Quick Object Scatter does

Quick Object Scatter lets you place objects in a Blender scene by clicking. Add objects to the tool, then scatter them at the cursor, or draw along a curve path or a line to distribute instances along it.

Randomization is available for X, Y and Z rotation and scale. Instances can be collected into a collection you choose, and because scattered objects are duplicated as instances, they don't add much to scene weight. Environment artists, set dressers and landscape builders needing hand-directed placement of rocks, plants or props will find it direct and flexible.

Key features

  • Scatter instances anywhere you click
  • Draw along curves and lines
  • Randomize rotation and scale on each axis
  • Organize into a chosen collection
  • Instances keep scene weight low
