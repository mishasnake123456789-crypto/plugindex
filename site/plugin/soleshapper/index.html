Shoe-design add-on that deforms sole meshes procedurally using noise and zone masks, then exports them from Blender.

What SoleShapper does

SoleShapper shapes shoe soles with procedural methods rather than hand sculpting. A default sole mesh is built in, so you can begin without external files, and custom OBJ meshes can be loaded for any sole design.

Noise deformation works through vertex normals with adjustable controls, zone masking limits where the effect applies, and finished soles can be exported. Footwear designers can quickly explore tread and surface variations.

Key features

  • Built-in default sole mesh
  • Load custom OBJ meshes
  • Noise deformation via vertex normals
  • Zone masking
  • Export finished soles
