What All Objects into Assets does

All Objects into Assets removes the tedium of marking things as assets one at a time. It creates collection assets and sets up the matching catalogs automatically.

If you are converting an existing scene or a pile of models into a browsable library, this speeds up the process considerably. Artists building personal asset libraries benefit most.

Key features

  • Automatic collection assets
  • Catalog creation
  • Bulk conversion of scene content
