What Sync Blender does

Sync Blender is a plugin by Jishnu Jithu for keeping your setup consistent. It stores preferences, add-ons, extensions, bookmarks, presets and similar items in a single location on your computer.

You can restore saved settings with one click, or sync the current Blender version to match another installed version. This is useful after upgrading, when testing a beta, or when you maintain several Blender versions side by side and dislike reconfiguring each one.

Key features

  • Backs up add-ons, extensions, presets and preferences
  • One-click restore
  • Sync settings across Blender versions
  • Bookmarks and recent searches included
