Blender tools for arrays along a curve that keep objects separate and undistorted, plus curves with correct tilt to surface.

What Curvearray + Magiccurve does

Curvearray + Magiccurve contains two tools. Curve Array places objects along a curve without distorting the mesh, because it is not a modifier. Magic Curve creates curves that tilt correctly to the surface.

Curves with more than one spline are supported, with control over normal smoothness and cyclicity, and an Object Editor offers random grouping. Modelers building chains, rails, cables and repeated details can keep each object independent. Because the array is not a modifier, objects can be edited individually afterward, which is helpful for varied details such as links, posts or decorative repeats.

Key features

  • Arrays along a curve without distortion
  • Each object stays separate
  • Multi-spline curves
  • Magic Curve with tilt to surface
