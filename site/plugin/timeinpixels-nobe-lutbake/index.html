What timeinpixels Nobe LutBake does

Nobe LutBake saves the color work on the current clip in DaVinci Resolve Studio as a portable .cube 3D LUT. A global keyboard shortcut does the capture, so there is no need to dig through export menus, and it works from any app.

Cube sizes range from 17 to 100 points, including sizes matching HALD images, with decimal precision up to 16 digits. Filenames can be generated from templates using show, IDT, ODT and note placeholders and increase automatically, and a custom output folder is supported. A DRX still can optionally be saved alongside. The tool also detects spatial effects such as blur, grain and Power Windows, which a LUT cannot capture. It is made for colorists on macOS.

Key features

  • Global shortcut captures LUTs from any app
  • Cube sizes from 17 to 100 with up to 16 decimals
  • Auto-incrementing filename templates
  • Optional DRX still export
  • Detects spatial effects a LUT cannot hold
