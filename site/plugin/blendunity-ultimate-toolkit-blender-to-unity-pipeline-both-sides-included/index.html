What Blendunity Ultimate Toolkit - Blender To Unity Pipeline (Both Sides Included) does

Blendunity is two halves of one pipeline, an add-on on the Blender side and an editor package on the Unity side, so imported assets need little tidying. The goal is for materials, colliders, animation and prefabs to be configured without manual rebuilding.

The SmartPackage export wraps the FBX together with manifests for materials and the scene, plus animation clips and root motion curve data. A material translator reads the Principled BSDF node graph to build Unity materials or generate textures. Game developers who regularly move content between the two applications are its natural users.

Key features

  • Blender add-on plus Unity editor package
  • SmartPackage export with manifests and animation data
  • Translates Principled BSDF graphs into Unity materials
  • Automatic prefab construction in Unity
