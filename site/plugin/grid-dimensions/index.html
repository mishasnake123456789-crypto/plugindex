What Grid Dimensions/网格标注 does

Grid Dimensions adds scale labels to Blender's ground grid, giving an at-a-glance sense of the size of the current scene. It was developed by Shuimeng and needs no special permissions.

Its annotation display algorithm reduces overlap for distant labels while keeping nearby ones readable, and labeling is optimized in camera view. It is useful for modelers and layout artists who need to check proportions and real-world scale without placing reference measurements manually.

Key features

  • Scale markings on the ground grid
  • Reduced occlusion for distant labels
  • Optimized annotations in camera view
  • No special permissions needed
