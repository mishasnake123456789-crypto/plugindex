What Circuit Line Generator does

Circuit Line Generator creates PCB-like line patterns in Blender. It simulates electrons wandering across a grid and refusing to cross their own or each other's routes, which yields tidy, self-avoiding 3D curve paths in the manner of board routing.

You can adjust grid resolution, birth rate, initial straightness and the odds of 90 or 45 degree turns. A Geometry Nodes module builds wire geometry with varying thickness, and pulse animations called Data Packet Flow travel along the lines. All curves merge into one active object, which makes adding modifiers or assigning materials in bulk simple.

Key features

  • Self-avoiding paths that follow PCB routing logic
  • Adjustable grid, birth rate, straightness and turn odds
  • Geometry Nodes wire generation with varying thickness
  • Animated data packet pulses
  • Curves merged into a single active object
