A Blender add-on for creating and organizing custom N-panels to keep tools and add-ons tidy.

What N-Panel Manager does

N-Panel Manager helps tame a crowded Blender sidebar. You can create custom N-panels and organize add-ons, tools and settings inside them, producing a streamlined workspace that follows your own workflow.

A Pro version offers enhanced tools, premium support and more flexibility for power users. Documentation is included, it is compatible with Blender 3.6 and 4.0 through 4.3, and it is released under the GPL. Users with many add-ons who want their favorite controls in a clean arrangement will find it makes the interface easier to navigate.

Key features

  • Create custom N-panels
  • Organize add-ons, tools and settings
  • Streamlined layout
  • Pro version with extra tools
  • Blender 3.6 and 4.0 to 4.3
