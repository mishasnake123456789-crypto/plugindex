What Modeling Flow does

Modeling Flow gathers frequently used modeling controls into a single panel. It has six modifier buttons for one-click adding, four smooth and flat controls and a navigator for stepping through the modifier layers.

Eighteen edit tool combos automate chains of commands, and selection tools and object data sit alongside. It speeds up routine modeling steps. Consolidating these controls lowers the number of clicks needed for repeated operations and keeps a consistent modeling routine.

Key features

  • Six one-click modifier buttons
  • Smooth and flat controls
  • Modifier stack navigator
  • Eighteen edit tool combos
