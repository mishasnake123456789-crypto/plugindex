What Digital Rebellion Pro Media Tools does

Digital Rebellion Pro Media Tools collects several post-production utilities in one package for macOS, alongside Premiere Pro. Its main job is ingest: Auto Transfer copies camera cards to disk and verifies each file with MD5 or SHA1, letting you recopy any that fail.

Auto Mode begins a transfer as soon as a recognized card is inserted, covering P2, RED, ARRI Alexa, Canon EOS, XDCAM, XDCAM EX and AVCHD media. Other tools include a Batch Renamer that finds frame gaps in image sequences, edit and gamma shift detection, folder templating and an overview of project media.

Key features

  • Camera card copy with MD5 or SHA1 verification
  • Auto Mode for recognized drives
  • Batch renamer that detects frame gaps
  • Edit detection and gamma shift detection
  • Folder templates and project media overview
