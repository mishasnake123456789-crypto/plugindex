Blender add-on that adds annotation frames with text blocks to node graphs and helps replace node group usages.

What Node Annotator does

Node Annotator helps document and maintain node graphs in Blender. A Node annotator section appears in the Node tab of the side panel in any graph editor, offering creating and editing annotation frames with a single click.

Create annotation places a yellow box in the view, generates a linked text block and opens it for editing. Tools also locate and replace usages of custom node groups. Shader and geometry nodes artists who share or revisit complex setups will find notes easier to keep alongside the nodes.

Key features

  • Annotation frames with linked text blocks
  • Section in the Node tab of any graph editor
  • Yellow annotation box creation
  • Find and replace custom node group usage
