What Ani Offset does

Ani Offset makes it easy to change a pose across many keyframes in Blender. In Pose Mode, capture the pose, adjust it in the viewport, and the offset is propagated over a frame range you define by start and end frames.

An action and slot dropdown picks the animation to affect, and animation curves are maintained after the changes are applied. It is suited to animators tweaking bone poses over long stretches of keyed motion.

Key features

  • Capture and propagate pose workflow
  • Adjusts many keyframes from the viewport
  • Action and slot dropdown
  • Frame range by start and end
  • Keeps animation curves after changes
