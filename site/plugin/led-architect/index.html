What LED Architect does

LED Architect from GMScripts takes the guesswork out of planning LED walls in After Effects. Using real supplier presets, it works out resolution, panel layout, tile count, power draw and weight, then generates a ready composition with one click.

The comp comes with guides and test overlays, so wall dimensions can be estimated before animation begins and mockups shared with clients and production teams. Reducing technical setup errors makes it valuable for event screens, exhibition booth displays and multi-screen stage layouts.

Key features

  • Calculates resolution, tiles, power and weight
  • Built-in real supplier presets
  • One-click composition with guides and test overlays
  • Early wall size estimation
  • Client-ready internal mockups
