Opens any Blender editor in a separate floating window that can be docked back, with hotkey access.

What Freeflow Ui does

Freeflow UI pops any Blender editor out into its own floating window. 3D Viewport, Image Editor, Node Editor, Text Editor, Graph Editor and others are supported.

Windows dock back by dragging them into the main interface, and editors can be opened instantly with a hotkey you define. The panel sits in the 3D Viewport Sidebar under the UI tab. It is especially useful for multi-monitor setups. Among its capabilities are floating windows for any editor, drag to dock and undock and user-defined hotkey.

Key features

  • Floating windows for any editor
  • Drag to dock and undock
  • User-defined hotkey
  • Panel under the UI tab
