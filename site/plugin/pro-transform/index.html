Pro Transform

Developer: obaida

3ds Max script for click-and-drag transforms of an object or group, with pivot setting and hold-key scaling.

What Pro Transform does

Pro Transform gives a different way of transforming a selected object or group in 3ds Max. Left-click to set the pivot, then click and drag to define the second and third points that drive the transform; if the pivot is already right, begin with the drag.

Holding Control while dragging scales on one axis and holding Shift scales fully, with the scale canceling when the key is released. Press the right mouse button before letting go of the left one to abort the transform. It handles one object or one group, as long as the object isn't a member of a group. A dedicated undo reverts the last operation, and version 1.1 added bounding-box midpoint snapping.

Key features

  • Interactive transform from click and drag points
  • Pivot set by left click
  • Control and Shift modifiers for axis and full scaling
  • Right-click cancel and dedicated undo
  • Bounding box mid-point snap in 1.1
