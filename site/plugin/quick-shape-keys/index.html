Developer: Zemalate

FreeBlender

Shape key manager for Blender: mirror, split, transfer, merge and organize keys in an outliner-style tree.

What Quick Shape Keys does

Quick Shape Keys makes shape key work faster. It can mirror or symmetrize keys by several methods and split them by selected vertices, axis or shape, including a linked split that divides one key into two that follow changes in the original.

Basic operations such as add, subtract, multiply, replace and invert are provided, and selected keys can be merged or the key tree synchronized between objects. Keys are arranged in an outliner-like collection structure with custom icons or colors. It benefits character artists building facial expressions.

Key features

  • Mirror and symmetrize shape keys
  • Split by vertices, axis or shape, with linked split
  • Add, subtract, multiply, replace, invert
  • Merge and sync across objects
  • Collections with icons and colors
