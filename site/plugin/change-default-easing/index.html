What Change Default Easing does

Change Default Easing is a small tool from Cody Sorgenfrey for After Effects. It lets you alter the default value that the easy ease, ease in and ease out keyboard shortcuts apply, so your preferred feel is a keypress away.

Version 1.1 supports After Effects from CS6 through 2026. A demo video is available and the tool is listed as free. Animators who always tweak the default 33% influence will save time on every keyframe.

Key features

  • Changes easy ease default value
  • Changes ease in default value
  • Changes ease out default value
  • Works from CS6 through 2026
  • Free with demo video
