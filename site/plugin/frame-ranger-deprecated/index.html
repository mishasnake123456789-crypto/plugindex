What Frame Ranger (Deprecated) does

Frame Ranger, by TinkerBoi, collects utilities for handling frame ranges, keyframes, markers and actions in Blender. It has since been retired in favor of Action Commander, so new users may prefer the successor.

The add-on remains available with documentation, and the source code can be downloaded for free from GitHub. It is released under the GPL license, so animators who still depend on it can keep using or adapt it.
