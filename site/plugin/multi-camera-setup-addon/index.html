What Multi Camera Setup Addon does

Multi Camera Setup (MCS) simplifies scenes that contain lots of cameras, such as photogrammetry projects where configuring each camera takes ages. It builds a list of the cameras in the scene to work from.

You can set or replace the background image on every camera within seconds, jump between cameras or pick only the ones you need. It also fixes an FBX import issue that gives cameras the wrong direction, and supports additional file extensions. The add-on requires Blender 4.1 or later.

Key features

  • List of all scene cameras
  • Bulk background image setup
  • Quick camera switching and selection
  • Fix for wrong camera direction on FBX import
