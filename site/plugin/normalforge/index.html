Blender add-on that automates bevel-to-custom-normals setup for game meshes, aimed at Nanite pipelines.

What Normalforge does

NormalForge speeds up the bevel-to-custom-normals approach to hard-edge shading in Blender. It is designed mainly for Unreal Engine Nanite workflows where clean normals matter.

Four workflows cover detection by angle, bevel weights, an existing bevel modifier or existing geometry. Setup happens in a click, every run makes an automatic mesh backup, and a Restore button returns to the original. You can also clear custom normals without restoring geometry. Game artists save the steps of setting this up by hand.

Key features

  • Four workflows including auto-detect by angle
  • One-click custom normal setup
  • Automatic mesh backup and Restore button
  • Clear Custom Normals option
  • Targeted at Nanite pipelines
