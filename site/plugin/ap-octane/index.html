What Ap Octane does

AP Octane supports artists who render with Octane inside Blender. It collects shortcuts to commonly used render settings and passes, so you do not need to hunt through nested panels for them.

Other helpers include Vectron objects, a Scatter on Surface object with a demo, a Set Up Light Linking option, an experimental Restart Octane Server command, displacement examples and links to documentation and videos. It comes from Light Sail VR. Octane users in Blender who want quicker setup and a few handy extras will find it speeds up routine tasks.

Key features

  • Shortcuts for common Octane settings and passes
  • Vectron objects
  • Scatter on Surface object with demo
  • Light linking setup
  • Experimental Octane server restart
