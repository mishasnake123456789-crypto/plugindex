What Apv Selection Tool "Advanced Proximity Viewer" does

The Advanced Proximity Viewer selects objects that touch or lie close to the active one. An interactive display and a threshold slider define how near is near enough.

A Check Intersections action examines the active object, it works with empties and meshes, and it can select intersecting edges. The display updates live as you drag. Useful for finding collisions, clashing geometry or neighbors of a part in dense scenes. Results can then be moved, hidden or grouped together as needed.

Key features

  • Selects intersecting or nearby objects
  • Check Intersections action
  • Interactive threshold slider
  • Works with empties and meshes
