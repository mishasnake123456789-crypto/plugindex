Automates lip sync from audio in Blender using Rhubarb, for Grease Pencil and 3D shape keys.

What Lipkit does

Lipkit generates lip sync from audio using the Rhubarb phoneme engine. It works with both Grease Pencil layers for 2D and shape keys for 3D characters.

Audio can come from the Video Editor or external sound files, multiple characters and voice lines are supported, and built-in controller objects let you tweak mouth poses. Animators save hours on dialogue. In practice that means rhubarb phoneme-based lip sync and grease Pencil and shape key support.

Key features

  • Rhubarb phoneme-based lip sync
  • Grease Pencil and shape key support
  • Multiple characters and voice lines
  • Controller objects for mouth poses
