Humorous Blender add-on offering fifty creative ways, called Confabs, to dispose of or transform the startup cube.

What Cube Confabulator does

Ethan Beddard's Cube Confabulator turns the first thing you do in Blender, getting rid of the default cube, into entertainment. Fifty different routines, named Confabs, delete, alter or otherwise play with it.

Some include fluid simulation caches that are already baked. The base download weighs 314MB, while a 50MB option leaves the caches out so you can bake them after installing. Make and save Confabs of your own; ones posted on the Reddit page might be added later. Documentation comes along.

Key features

  • 50 Confabs for the default cube
  • Pre-baked fluid simulation caches
  • Smaller download without caches
  • Save your own custom Confabs
  • Documentation included
