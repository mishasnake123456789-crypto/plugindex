What Unwrap Me - Auto Uv Seams does

Unwrap Me automates seam placement for UV unwrapping in Blender. You can seam an entire mesh in one go or grow islands outward from faces you select, with a Developability setting that limits stretch error and reduces texture distortion.

The Auto Seam operator uses a fast algorithm that copes with meshes of millions of faces, and an Edge Walk operator creates seams along edge loops. Texture artists and game asset creators can skip tedious manual seam marking on complex models.

Key features

  • Auto Seam operator for very dense meshes
  • Edge Walk seams along edge loops
  • Grow UV islands from selected faces
  • Developability setting limits stretch
