Non-destructive lattice auto-rigging in Blender: generates a poseable grid around any object.

What Grid Rigger does

Grid Rigger creates a grid that fits an object's bounding box and uses it for lattice deformation. Resolution on each axis sets how many control points appear.

The rig can be resized, rotated and transformed in Object Mode, and deformation points are animated in pose mode using bones alongside the lattice modifier. It is a quick route to squash, stretch and cartoon-style deformation. Highlights include grid fitted to bounding box, per-axis resolution and non-destructive transforms.

Key features

  • Grid fitted to bounding box
  • Per-axis resolution
  • Non-destructive transforms
  • Bone-driven lattice points
