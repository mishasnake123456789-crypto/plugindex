After Effects panel that turns text prompts into editable, keyframed shape layer animations.

What Kineto does

Kineto by S1lencio generates animation from a plain-language prompt, but instead of producing a flat video clip, it creates real shape layers with keyframes. You can preview the result in the panel and then import it into your composition.

The imported animation arrives as anchored shape groups with genuine Position, Scale, Rotation and Opacity keyframes, so everything stays editable. AI-assisted prompt improvement helps phrase requests, and a library saves generations to review and edit later. Interface settings and animation options are configurable.

Key features

  • Prompts become keyframed shape layer animations
  • Preview in the panel before importing
  • Anchored shape groups with real keyframes
  • AI-assisted prompt improvement
  • Library of saved generations
