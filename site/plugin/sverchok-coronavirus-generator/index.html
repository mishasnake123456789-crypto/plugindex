What Sverchok Coronavirus Generator does

This asset is a node group for the Sverchok add-on in Blender that builds a stylized coronavirus. Instead of modeling the particle by hand, you adjust inputs and the shape updates.

Body inputs set the number, size and length, while spike inputs handle random placement, starting size, extrusion and ending size. The result is delivered as vertex, edge and polygon data, and an accompanying file is bundled in. Useful for science visualization and educational animation projects.

Key features

  • Sverchok node group asset
  • Body number, size and length inputs
  • Spike position, start, extrude and end controls
  • Outputs vertices, edges and polygons
