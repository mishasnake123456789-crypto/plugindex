What Cad Tools does

Cad Tools addresses the clutter that comes with CAD models imported into Blender. A panel in the 3D View sidebar collects the cleanup jobs, and it also works on ordinary files.

It finds objects hidden in the viewport but enabled for render, detects objects of similar size with an adjustable tolerance and gives them a metallic material for easy visualization, and removes unused material slots in one click. Product designers and engineers preparing CAD data for rendering will save time.

Key features

  • Reveals objects hidden in viewport but set to render
  • Similar-size detection with tolerance slider
  • Removes unused material slots
  • Sidebar panel in the 3D View
