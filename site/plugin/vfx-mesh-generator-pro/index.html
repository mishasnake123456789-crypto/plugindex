What Vfx Mesh Generator Pro does

VFX Mesh Generator Pro builds the geometry that stylized game effects rely on. One click creates slash arcs, shockwave rings, beams, trails, dome shields, disks and helixes.

It is geared toward Unity and Unreal Engine, producing export-friendly structures with sensible scale handling. UV direction, flow and width are adjustable, along with segment counts. Technical artists and VFX designers get effect meshes quickly instead of modeling and unwrapping each one. Having the shapes ready saves time when building slashes and impact effects for games.

Key features

  • One-click slash, shockwave, beam, trail, dome and helix meshes
  • Unity and Unreal friendly structures
  • UV direction and flow control
  • Segment and width settings
