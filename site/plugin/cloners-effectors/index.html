What Cloners + Effectors does

Cloners + Effectors from Crunchy is a procedural animation system for After Effects, particularly helpful when many layers must animate together. Effectors drive the motion, so you avoid keyframing every layer separately.

It includes Path cloner, Path Point cloner, Path effector and Path Ends effector for After Effects 2018 and above, plus an audio setup for animating to the spectrum of a track. Cloner systems or effectors can be duplicated, cloner layers can be parented, and baking is available without unbake. It works on Windows and HiDPI panels.

Key features

  • Animate many layers with effectors
  • Path cloner, Path Point cloner and path effectors
  • Audio spectrum animation setup
  • Duplicate cloner systems or effectors
  • Bake and parent cloner layers
