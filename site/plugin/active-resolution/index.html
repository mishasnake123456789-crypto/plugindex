Blender add-on that assigns a different render resolution to each camera.

What Active Resolution does

Active Resolution, by Omega VFX, lets every camera in a Blender scene have its own render resolution. This allows several resolution outputs from one project.

The resolution switches automatically based on the active camera. Controls are in a dedicated panel under Output Properties. Documentation is included and the add-on is released under the GPL.

Key features

  • Per-camera render resolution
  • Automatic switching with the active camera
  • Multiple resolutions in one project
  • Panel in Output Properties
