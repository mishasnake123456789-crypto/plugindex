Blender add-on that shows individual and total edge lengths in Object Mode, including modifier-deformed geometry.

What Edge Length Measure does

Edge Length Measure reports how long mesh edges are while you are in Object Mode in Blender. Register several selected mesh objects, and see each edge length in the 3D Viewport plus totals per object and a grand total in the sidebar.

It reads the evaluated mesh from the dependency graph, so results reflect armature or subdivision deformation without applying modifiers, and updates in real time. Units follow scene settings in mm, cm, m or km, and each object has its own visibility toggle.

Key features

  • Edge lengths displayed in Object Mode
  • Per-object and grand totals
  • Measures modifier-deformed geometry
  • Real-time updates
  • Unit-aware formatting
