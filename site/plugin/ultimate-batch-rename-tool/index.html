What Ultimate Batch Rename Tool does

Ultimate Batch Rename Tool brings renaming of objects, materials, textures (image nodes) and vertex groups into a single interface. Targets can be filtered by selection or object type.

A live side-by-side preview shows the Before and After names with status icons flagging problems, and eight renaming operations can be combined. Pipeline artists applying naming standards to large scenes can verify the result before applying it. Because renaming is previewed first, mistakes are caught before they reach the scene, which matters for large projects with many assets.

Key features

  • Objects, materials, textures and vertex groups
  • Filter by selection or object type
  • Live Before and After preview
  • Eight combinable operations
