What Screencast Ultimate: Visual Keys & Mouse Ripples does

Screencast Ultimate displays what you are doing in Blender while you do it. It targets educators, tutorial creators and streamers who want viewers to follow each action.

Click ripples spawn a cyan ring where you click. Smart Context Detection reads the current mode, so pressing G shows Move in Object Mode and Grab Brush in Sculpt Mode. Follow Mouse Mode keeps the text near the cursor so viewers keep their eyes on the model, and a history of recent actions is also shown.

Key features

  • Cyan click ripples at the cursor
  • Context-aware tool names by mode
  • Follow Mouse text display
  • Action history
  • Made for tutorials and streams
