What Mpalette Pro does

MPalette Pro, from CGoutset, speeds up shading in Blender by keeping your favorite materials at hand. A Material Palette collects the most-used materials for a specific file and assigns them to any object in one click.

A Fast Material Library lets you save materials with a click and reuse them across any blend file. It stores them in a chosen folder, generates icons automatically and packs textures so the library works on any computer. A fast assign feature applies materials quickly. Look development artists and scene builders will save time versus hunting through the material browser.

Key features

  • Per-file Material Palette
  • Reusable Fast Material Library
  • Automatic icons and packed textures
  • One-click assignment to objects
