What Poly Copy Paste does

Poly Copy Paste gives Blender's Edit Mode a clipboard-style workflow for polygons. Copy, cut and paste faces using the familiar Ctrl+C, Ctrl+X and Ctrl+V keys.

UV data, edge crease and edge sharp markings can travel with the faces, each with its own toggle. Tools are found in the N panel under Edit, with preferences covering copy options plus a shortcut cheat sheet. Blender's native shortcuts stay reachable through Ctrl+Shift variants.

Key features

  • Copy, cut and paste faces
  • UV transfer
  • Edge crease and sharp preservation
  • Toggles for each data type
  • N panel tools and preferences
