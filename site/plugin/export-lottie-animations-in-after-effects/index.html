What Export Lottie Animations in After Effects does

This LottieFiles extension handles the full Lottie round trip in After Effects. It exports animations as Lottie JSON or the smaller dotLottie format, and can bring SVG or Lottie JSON files in as compositions through copy-paste or insert.

A Feature Checker tells you whether an animation will behave on web, Android and iOS, and the preview uses ThorVG or Lottie Web renderers as you edit. Many animations can be rendered and uploaded at once. Motion System stores easing curves, presets, colours and brand assets for reuse, and a shared workspace keeps AEP projects next to exported results.

Key features

  • Output Lottie JSON or a leaner dotLottie
  • Import SVG and Lottie JSON as compositions
  • Feature Checker for web, Android and iOS
  • Preview with ThorVG or Lottie Web
  • Bulk render and upload; Motion System for brand assets
