What Turntable Viewport does

Turntable Viewport keeps a rotating view of your model in one viewport while you work normally elsewhere. Only the marked preview viewport orbits.

The object, camera and scene do not move. Orbit speed and direction are adjustable, with pause and resume controls and view reset. Modelers can check shape from all sides continuously. Key capabilities include independent live orbit, only the preview viewport rotates, speed and direction controls and pause, resume and reset.

Key features

  • Independent live orbit
  • Only the preview viewport rotates
  • Speed and direction controls
  • Pause, resume and reset
