What Corona Render Elements Manager does

Corona Render Elements Manager automates setting up render elements for Corona Renderer in 3ds Max. It checks that Corona is present, switches to the right renderer, and offers a default selection that covers basic composition needs.

A spinner adjusts ZDepth and AO max distance values from the interface. A LightMix element generates Light_ENV, a LightSelect that includes the environment light, and Light_SUN, built from the scene's Sun if there is one. Buttons select or deselect all, reset to default, filter on or off, and delete existing elements. It also adds WireColor, Cryptomatte, monochrome and RGB masks and LightSelect, with Caustics available from Corona 4.

Key features

  • Checks for Corona and switches renderer automatically
  • ZDepth and AO distance values adjustable in the interface
  • LightMix creates Light_ENV and Light_SUN selects
  • Select all, reset, filter and delete existing elements
  • Adds WireColor, Cryptomatte, masks and LightSelect
