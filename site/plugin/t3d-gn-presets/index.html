What T3D GN Presets does

T3D GN Presets, from Tams_3d, is a varied set of node groups for Geometry Nodes that you can drop into a project rather than building each from scratch. It is listed under Geometry Nodes.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.3.0 or newer.

Key features

  • Versatile collection of node groups
