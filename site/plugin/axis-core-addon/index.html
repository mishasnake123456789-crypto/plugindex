What Axis Core Addon does

Axis Core is an animation and retargeting add-on for characters built with AXIS OMNIA and VERSA rigs. It connects them to external sources from one panel.

Animation from Mixamo, ActorCore, Unreal Engine, HumanIK and DAZ Studio is retargeted with automatic bone mapping, then baked in one step. Smooth Keyframes reduces mocap jitter, Decimate Keyframes removes unneeded keys, and Push to NLA creates a strip. ARKit CSV data from Live Link Face can be applied to facial rigs, and body and face animation are handled independently.

Key features

  • Retargeting from Mixamo, ActorCore, Unreal and more
  • One-step baking, smoothing and key decimation
  • Push to NLA
  • ARKit facial data import
