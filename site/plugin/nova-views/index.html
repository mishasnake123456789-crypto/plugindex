Tracks Blender viewport history and lets you save, name and recall views through quick-access slots.

What Nova Views does

Nova Views is a Blender add-on for managing viewport angles. In the background it records each viewport's view history, so you can step backward and forward through earlier angles much like undo and redo.

Views worth keeping can be saved to a list where they are named, reordered, updated or deleted. Quick-access slots let you assign a saved view and bring it back with a shortcut, or store the current angle straight into a slot. Modelers and layout artists who keep returning to the same reference angles will find it removes a lot of manual orbiting.

Key features

  • Automatic per-viewport view history
  • Named, reorderable saved views list
  • Quick-access slots with shortcuts
  • Save the current view to a slot instantly
