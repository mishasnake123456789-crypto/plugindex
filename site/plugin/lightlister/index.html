What Lightlister does

Lightlister is a 3ds Max script built on the Lightlister shipped with V-Ray, which itself comes from the original tool in Max. It presents lights in a list so their parameters can be reviewed and adjusted together rather than one at a time.

This edition understands Corona lights and materials, including the light material, and adds IES file editing for Corona, photometric and V-Ray lights. Tooltips explain some parameters and the light name, the interface is wider, and a material button selects or edits the material. Lighting artists on interior and architectural scenes using V-Ray or Corona will find it helpful.

Key features

  • Corona lights, material and light material support
  • IES files editable on Corona, photometric and V-Ray lights
  • Tooltips on selected parameters and light names
  • Wider interface
  • Material button to select or edit the material
