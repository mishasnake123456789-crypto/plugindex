What Blaster does

Blaster is a Blender plugin for effects like laser bolts and magic rays. Add a curve, shape it, and press Blast Along Curve to generate the beam along that path.

Beams can be static or use a default animation with chosen start and end frames. Basic ray parameters are adjustable in the panel, and a Recreate Last option repeats the previous setup. Good for quick sci-fi or fantasy shots. Since the beam follows whatever curve you provide, you can reshape its path later and quickly generate variations for different shots or projectiles.

Key features

  • Beam generated along any curve
  • Optional default animation with frame range
  • Adjustable ray parameters
  • Recreate Last option
