Blender add-on that perturbs mesh edges with configurable linear or non-linear noise to build complex shapes.

What Add Noise To Mesh does

Add Noise To Mesh from Noisetik roughens or distorts mesh edges by adding noise, which speeds up the creation of intricate forms such as rocks or organic outlines.

Noise can be linear or non-linear, and its magnitude ranges from 0 up to 1 times the mesh's maximum edge length. Subdivision is configurable, noise applies on the XY plane only, and a Max Edges Limit setting keeps the edge count in check. Documentation and an example are included.

Key features

  • Linear and non-linear noise
  • Magnitude relative to maximum edge length
  • Configurable subdivision
  • XY-plane noise
  • Max Edges Limit setting
