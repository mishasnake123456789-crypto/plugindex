What Real-Time Toyrig does

Real-Time Toyrig lets you pose a model without setting up a traditional rig. Grab and move the model directly in real time.

Four modes, FK, IK, Fix and Lock, determine how controllers are selected and moved. Version 1.1.0 added Bake Keyframe, which generates keyframes for all deform bones between two controller keyframes. It is great for toy-like and quick character posing. Highlights include direct real-time posing, FK, IK, Fix and Lock modes and bake Keyframe for deform bones.

Key features

  • Direct real-time posing
  • FK, IK, Fix and Lock modes
  • Bake Keyframe for deform bones
  • No traditional rig setup
