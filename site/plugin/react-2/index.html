What React 2 does

React 2 from mograph.tools is a toolbar for building repeater and effector setups in After Effects, similar to the cloner approach in Cinema 4D. Version 2 applies effectors to almost any property, including color.

The rebuilt effector handles several effectors across several properties, with a Refresh button for updates. Layers can be arranged by Iterate, Cluster, Random, Row or Column sorting, and the Tracer feature draws lines and grids between layers. Random Evolution transitions smoothly between random values. It runs on the Legacy ExtendScript engine, while text repeaters and custom easing need the JavaScript engine.

Key features

  • Effectors on almost any property, including color
  • Multiple effectors across multiple properties
  • Iterate, Cluster, Random, Row and Column sorting
  • Tracer lines and grids between layers
  • Random Evolution for smooth random transitions
