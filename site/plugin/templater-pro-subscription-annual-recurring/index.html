What Templater Pro Subscription Annual Recurring does

Templater Pro builds on Templater Rig to automate After Effects from the desktop. Starting from a data source, it renders or duplicates batches of versioned compositions, which suits teams that must deliver a large number of variants of one master. This is the annual recurring subscription, and monthly licensing also exists.

Version 3.8.0 added per-target output settings within multi-target jobs. Footage sources can be validated before a batch runs, manual batches can be tracked in Google Sheets, and a preference stops batches if a project file is missing.

Key features

  • Renders or replicates versioned comps from data
  • Extends the Templater Rig workflow
  • Per-target output configurations (3.8.0)
  • Footage validation before batch runs
  • Google Sheets status tracking for manual batches
