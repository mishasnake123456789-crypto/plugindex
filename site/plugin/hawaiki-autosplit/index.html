What Hawaiki AutoSplit does

Hawaiki AutoSplit creates split-screen compositions for After Effects, DaVinci Resolve and Premiere Pro, plus Final Cut Pro X and Motion. Menu-driven animation pairs with fully customisable grid parameters and a preset library.

The Classic module makes rectangular grids in the traditional layout, while the Extended module uses triangle-based shapes combined into varied arrangements. Scale, crop and hold position of every box can be set to any value, borders can be styled, and version 1.5 added a Metal GPU pipeline for both modules. Editors producing multi-camera views, social posts and comparison layouts can assemble them rapidly.

Key features

  • Classic rectangular grid module
  • Extended triangle-based module
  • Adjustable scale, crop and hold position per box
  • Built-in presets and border styling
  • Metal GPU acceleration in version 1.5
