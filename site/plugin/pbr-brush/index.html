What Pbr Brush does

PBR Brush lets you paint across several PBR texture channels at once. One stroke updates base color, normal, roughness, height, ambient occlusion and emission maps together, instead of switching between them.

It paints several images in sync rather than relying on a node-based shader setup. You assign textures to slots and then paint with a button. Loading different texture sets allows model variants to be painted at the same time. Documentation is included. It is handy for hand-painted materials and quick texture detail.

Key features

  • Multi-channel PBR painting in one stroke
  • Base, normal, roughness, height, AO, emission
  • Texture slot assignment
  • Paint model variants at once
