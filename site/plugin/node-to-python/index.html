Node To Python

Developer: Brendan-Parmer

FreeBlender
Download Free

Blender add-on that converts Geometry Nodes, material and compositing node groups into readable Python code.

What Node To Python does

Node To Python writes readable Python from Blender node trees, covering Geometry Nodes, materials and compositing, and preserving positions, defaults, subgroups, names and colors.

Version 4.2.0 supports Blender 5.2 LTS and its added nodes and settings, copes with sound sockets and newer setting types such as generic vectors, and allows panel open or closed states to be set. Developers and technical artists can share node setups as code or build add-ons that recreate them.

Key features

  • Converts node groups to Python
  • Handles layout, defaults, subgroups and colors
  • Geometry, material and compositing nodes
  • Blender 5.2 LTS support in 4.2.0
