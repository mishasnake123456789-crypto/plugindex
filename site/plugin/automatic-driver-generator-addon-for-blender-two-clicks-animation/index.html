What Automatic Driver Generator Addon For Blender: Two Clicks Animation does

This add-on creates drivers without writing expressions by hand. Enter the values and a loop duration, then copy the generated driver onto the property you want to animate.

It suits oscillating motion between two values and handles shape keys, lattices and shaders. An existing driver can be replaced with one click, hashtags are added to expressions automatically, and a degree mode gives precise rotational animation. It makes looping animation quick for motion designers.

Key features

  • Driver generation from entered values
  • One-click driver replacement
  • Loop duration for oscillation
  • Degree mode for rotations
