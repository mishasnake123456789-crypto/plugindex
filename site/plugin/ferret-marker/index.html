What Ferret Marker does

Ferret Marker is a timeline utility from Nicolas Dupouy-Manescau that searches animation for a specific value. Enter the target in the edit box, and markers are added wherever the property hits it.

Two analysis methods are selectable from a dropdown. Linear Interpolation is generic and stable, while Cubic Spline Interpolation is more accurate for smooth animation created with expressions and Easy Ease keyframes. It works with After Effects from CS3 through 2026, and is handy for syncing events to the moment a value is reached.

Key features

  • Finds all occurrences of a target value
  • Target value edit box
  • Linear Interpolation analysis
  • Cubic Spline Interpolation for smooth animation
  • Compatible with CS3 through 2026
