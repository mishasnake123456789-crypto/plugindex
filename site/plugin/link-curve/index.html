Geometry nodes tool for laying repeated segments along a curve in Blender, from rigid chain links to bending tires and corrugations.

What Link Curve does

Built on geometry nodes, Link Curve attaches repeated objects to a curve, either with no deformation or with controlled bending. Uses include chains, tank treads, corrugated hoses, flexible shapes, tires and intricate cylindrical parts.

You can control the quantity, alternation and position of linked objects, set global scale and rotation, and choose between instance and non-instance placement. It's useful for mechanical and hard-surface modelers who would otherwise align each link manually.

Key features

  • Connects objects along a curve
  • Quantity, alternation and position controls
  • Global scale and rotation
  • Instance or non-instance placement
  • Optional controlled deformation
