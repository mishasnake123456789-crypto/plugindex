What Smart PSD to PNG does

Smart PSD to PNG, made by Kirill Starostin, is a script for After Effects that lightens projects built from Photoshop files. Large PSD layers can slow rendering and timeline playback, so it replaces them with optimized PNG images.

The change is reversible: one click returns to the original PSD source, and Shift-click on a PSD reverts all converted PNGs project-wide. A Fast Mode in the gear menu skips the BridgeTalk Photoshop export for quicker processing. You can convert a single PSD with all its layers or batch convert everything at once.

Key features

  • Replaces PSD layers with optimized PNGs
  • One-click revert to the original PSD
  • Global revert with Shift-click
  • Fast Mode skips BridgeTalk export
  • Batch or single file conversion
