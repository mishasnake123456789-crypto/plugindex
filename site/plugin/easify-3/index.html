What Easify 3 does

Easify 3 from Leyero gives animators finer control over motion curves. In After Effects it applies Bezier easing directly onto selected keyframes, and in Premiere Pro it supplies an animation graph editor that the host lacks.

The graph editor works with both Bezier and mathematical curves, with special curve customization. Presets can be created, imported and exported in unlimited libraries, and copied easing can be saved as a preset. Handy utilities include mirroring a curve, reversing keyframes in time, roving across time and moving keyframes to the playhead. Spell Book integration adds keyboard shortcuts.

Key features

  • Graph editor with Bezier and mathematical curves
  • Unlimited preset libraries
  • Copy and paste easing on keyframes
  • Mirror, time-reverse and rove tools
  • Spell Book keyboard shortcuts
