What Dynamic Lod Generator does

Dynamic LOD Generator is a Blender add-on for keeping heavy scenes responsive. It watches how far each chosen object sits from the camera and changes its Decimate modifier accordingly, so distant geometry carries fewer polygons.

You set the decimation intensity and distance thresholds from the interface and can apply the settings to many objects in one go. Updates happen in real time as you move around the scene, which lowers the computational load in complex scenes and animations while keeping near objects detailed. It is useful for artists building large environments who want level-of-detail behavior without managing it manually.

Key features

  • Distance-based Decimate adjustment
  • Configurable intensity and distance thresholds
  • Batch application to many objects
  • Real-time updates while navigating
  • Lowers polygon load in large scenes
