What Renderiq - Render Smarter And Faster does

RenderIQ is a separate program that manages Blender renders on Windows and Mac. It combines scene analysis, upscaling, frame interpolation and support for Turbo Tools and SceneBoost into one automated process.

It reads settings directly from selected files, handles queuing and automatic rendering, and can pause and continue without losing progress. Different files can use different Blender versions or custom preferences with only certain add-ons enabled, and multiple view layers are supported. Intelligent scene analysis adjusts settings automatically. Artists running long render queues will find it reduces babysitting.

Key features

  • Render queue that reads settings from files
  • Pause and continue without losing progress
  • Different Blender versions per file
  • Scene analysis, upscaling and frame interpolation
  • Turbo Tools and SceneBoost support
