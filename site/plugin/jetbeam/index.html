What Jetbeam does

Jetbeam helps Blender users create spotlight and searchlight compositions. It is suited to lighting streets, tall buildings, performance halls and show broadcasts.

It works with both EEVEE and Cycles, and you assemble your own beam arrangements and animations. A demo file cleared for commercial use is included along with a melody. It supports Blender 3.6 through 4.3, comes with documentation and uses the GPL.

Key features

  • Custom spotlight compositions
  • Works in EEVEE and Cycles
  • Commercial-use demo file included
  • Supports Blender 3.6 to 4.3
