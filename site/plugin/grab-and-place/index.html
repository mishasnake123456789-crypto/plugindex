Blender tool for dragging a mesh across the viewport and releasing it onto another surface with automatic height offset.

What Grab And Place does

Placing objects on surfaces by eye or by tweaking location values is fiddly. Grab And Place lets you click a mesh, drag it interactively around the 3D View and let go, and it settles onto whatever surface lies beneath.

The height offset is computed from the object's lowest vertex so it rests correctly, with an additional Placement Offset for extra clearance. Use it as a Workspace Tool via the T key toolbar or through the Grab and Place tab in the N-Panel, which also shows the offsets. Great for set dressing.

Key features

  • Click, drag and release placement
  • Auto-offset from the lowest vertex
  • Adjustable Placement Offset
  • Workspace Tool in the Toolbar
  • N-Panel tab with calculated offset
