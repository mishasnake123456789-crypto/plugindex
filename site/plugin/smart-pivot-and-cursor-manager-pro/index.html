What Smart Pivot & Cursor Manager Pro does

Baris Arslan's Smart Pivot & Cursor Manager Pro looks after pivots, origins and the 3D Cursor in one Blender panel, storing and recalling positions, aligning objects and sliding selections along axes.

X, Y and Z operators move objects, mesh elements or armature bones onto the cursor's coordinates on one axis or all together, in Object Mode, Edit Mesh and Edit Armature. Saved cursors and origins get color-coded markers, orange when active and gray when idle, with independent visibility switches. Precise modelers benefit.

Key features

  • Save and recall cursor and origin positions
  • Move to cursor on one axis or all
  • Works in Object, Edit Mesh and Edit Armature
  • Color-coded markers
  • Single N-panel
