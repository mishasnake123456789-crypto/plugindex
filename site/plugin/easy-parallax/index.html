What Easy Parallax does

Easy Parallax adds depth to flat surfaces in Blender without extra geometry. One click turns an existing material into a Parallax Occlusion Mapping shader, from your Normal, Albedo, Displacement and Roughness textures to create real-time displacement on a single face.

A Parallax Strength slider controls intensity, with a default of 0.5, and Repeat or Clip handles texture boundaries. A scan function detects texture maps, and a height map can be applied manually. It is lightweight, which suits games, real-time use, low-poly scenes and large projects.

Key features

  • One-click Parallax Occlusion Mapping
  • Uses normal, albedo, displacement and roughness maps
  • Parallax Strength slider
  • Repeat or Clip extension types
  • Lightweight for large scenes
