What Selection Toolbox does

Selection Toolbox by JokerMartini offers many ways to pick objects in 3ds Max. Quick Select shortcuts pick what is visible in the viewport, what is not, objects with or without materials, and instances of what you have selected.

Dialogs list the unique object classes, super classes, modifier classes and names, and material classes and names in the scene, so you can select matching objects. Wirecolor Select matches within a tolerance from 0 to 100 percent. Find and Select runs a string search across names and classes, and a Regex or Wildcard toggle reads input as a regular expression or simple wildcard. Selection Toggle limits the search to the current selection.

Key features

  • Quick Select by view, material state and instances
  • Lists scene classes, modifiers and materials for selection
  • Wirecolor Select with tolerance
  • String search across names and class names
  • Regex or wildcard toggle and selection-limited search
