Generates standard nominal-size lumber meshes in Blender with real dimensions, angle cuts and a CSV cut list.

What Ez Lumber does

Ez Lumber creates lumber objects using nominal sizes with their true actual dimensions, covering 1x2 through 1x12, 2x2 through 2x12, 4x4, 4x6 and 6x6 posts, and 5/4 decking boards.

Length is set in feet from 0.1 to 20 and converted to Blender's metric system. Angle cuts, including 45 degrees, can be applied in a single click, and a material list exports as CSV. It suits woodworking, framing and deck designs that need accurate parts and quantities.

Key features

  • Standard nominal lumber sizes
  • Length control in feet
  • 45-degree and other angle cuts
  • CSV material list export
