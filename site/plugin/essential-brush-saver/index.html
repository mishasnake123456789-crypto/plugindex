What Essential Brush Saver does

Essential Brush Saver is a Blender add-on by emptybraces that remembers key brush settings like strength, size and blend mode that normally revert on restart. It saves and restores them automatically.

Brushes are handled in Texture Paint, Sculpt, Vertex Paint and also Weight Paint, running both at startup and when a file is saved. The configuration is kept in a JSON file on disk. It supports Blender 4.3 and newer, and saves sculptors and painters from re-entering favorite values.

Key features

  • Saves and restores strength, size and blend mode
  • Texture Paint, Sculpt, Vertex and Weight Paint modes
  • Runs at startup and on file save
  • Settings stored in a JSON file
  • Supports Blender 4.3 and newer
