What Content Cloud Plugin for Google does

Content Cloud Plugin for Google is a panel from RIE Technology Corp. that connects After Effects and Premiere Pro to content cloud services directly. Assets can be downloaded, uploaded, previewed and linked from inside the host application.

Multiple accounts can be added and switched quickly, drag and drop is supported, and formats like PSD, audio and video preview in the panel. The developer states there is no analytics or tracking code, and that usage data is neither collected nor stored, in line with the EU GDPR. It benefits teams that manage media through cloud storage.

Key features

  • Direct connection with no analytics or tracking code
  • Multi-account switching
  • Download and upload from the panel
  • Preview PSD, audio, video and more
  • Asset linking and drag-and-drop
