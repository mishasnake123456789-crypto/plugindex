Blender add-on for organizing vertices, edges and faces into reusable groups, including crease and bevel weight sets.

What Smart Groups does

Techqon core's Smart Groups helps manage mesh selections in Blender as named, reusable sets covering vertices, edges and faces. It can build groups for creases and bevel weights, with creases that vary dynamically.

Colors assigned to groups stay visible even in Object Mode, Auto Grouping creates groups on its own, and Object Mode Editing applies bevels and creases without a mode switch. Saved selections can be recalled whenever needed. Hard-surface artists relying on creases and bevels gain a more systematic workflow.

Key features

  • Vertex, edge and face groups
  • Crease and bevel-weight groups
  • Color overlay visible in Object Mode
  • Auto Grouping
  • Bevels and creases without leaving Object Mode
