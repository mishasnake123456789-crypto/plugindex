What Directory Batch Exporter does

Directory Batch Exporter automates converting many Blender files at once. Choose a root directory and the add-on recursively finds every .blend file in it and its subfolders, then exports them to the format you choose.

Output can be FBX, OBJ, GLB, glTF, USD, Alembic, STL or PLY. Filtering settings define which files or folders to ignore or include, and output settings control where results are written, such as each file's source directory. It is a time saver for asset libraries and engine pipelines.

Key features

  • Recursive search for .blend files
  • Exports to FBX, OBJ, GLB, glTF, USD, ABC, STL, PLY
  • Filters to include or ignore files and folders
  • Output to each source directory or elsewhere
  • Processes whole asset libraries in one run
