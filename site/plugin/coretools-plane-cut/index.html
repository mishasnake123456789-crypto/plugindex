What Coretools - Plane Cut does

WalkingAloneStudio's Coretools - Plane Cut bisects a mesh with a plane, snapping precisely. Orientation modes (World, Local, Edge, 3D Cursor and Camera) make topology cleanup quicker.

Selected only mode confines the cut to chosen geometry, and an overlay shows faces and ngons beneath the cursor, in a solid color or a dithered pattern whose settings are separate. Hard-surface modelers and cleanup artists get quick, exact cuts. The highlighted overlay shows exactly which faces will be affected before you commit, which avoids undo cycles.

Key features

  • Plane bisect with built-in snapping
  • World, Local, Edge, 3D Cursor and Camera modes
  • Selected only mode
  • Overlay for faces and ngons
  • Solid or dithered highlight styles
