What Theme Property Finder does

Theme Property Finder is a Blender add-on by Nanomanpro for people who customize the interface theme. Blender stores colors, sizes and toggles separately for each editor, which makes consistent styling tedious; this tool lets you search for any property by keyword instead.

Matches are sorted per editor, for example the 3D View or the Node Editor, and names can be chosen from a generated list. Change a value in one editor, choose which matches to include, and push it to the rest with a single click. It requires Blender 4.2 LTS or newer.

Key features

  • Keyword search of every theme property
  • Generated list for choosing property names
  • One-click synchronization across editors
  • Results grouped by editor type
  • Select or deselect matches before applying
