What KitBash3D Library does

KitBash3D Library connects Cinema 4D to KitBash3D's collection via the Cargo platform, under an individual commercial license. It offers more than 20,000 textured models covering architecture, vehicles and props.

The set includes over 2,000 game-ready assets, 300 hero props and vehicles, and 200 Substance source materials, and each new KitBash3D release is part of the subscription. A one-click import arranges geometry into clean hierarchies and instances and converts materials into the native format of your render engine. Artists building environments and scenes quickly can lean on it for detailed kit pieces.

Key features

  • 20,000+ textured models
  • 2,000+ game-ready assets and 300+ hero props
  • 200+ Substance source materials
  • Every new release included
  • One-click import with render-engine material conversion
