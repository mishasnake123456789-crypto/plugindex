What Auto Pivot Baker does

Auto Pivot Baker, by NRexha, bakes object pivots into the exported model, so that objects rotate and scale around the right point once they reach a game engine. It is listed under Import-Export and Game Engine.

Open source under GPL-3.0-or-later, it requires Blender 5.0.0 or newer.
