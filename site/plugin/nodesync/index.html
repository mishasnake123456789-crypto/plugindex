Blender add-on that adds Git-style version control for Geometry and Shader node trees, with branching and remote push.

What NodeSync does

NodeSync applies version control to node setups from inside Blender. Snapshot your Geometry and Shader node trees, restore earlier versions and branch off to try ideas without risking the main setup.

History can be pushed to and pulled from a Git remote such as GitHub or GitLab, all from a panel. Technical artists building complex procedural networks gain a safety net and an easy way to share progress with collaborators.

Key features

  • Commit and restore node tree versions
  • Branching for experiments
  • Push and pull to Git remotes
  • Geometry and Shader node support
