What Atomic Blender Cluster does

Atomic Blender Cluster from Blendphys creates simple atomic nanoparticles and clusters by trimming atomic lattices like fcc or hcp. Find it under Add, Mesh, Atom cluster.

It uses Blender's instancing vertices method so structures load and handle quickly in the 3D View, and supports large atom counts. Scientists, educators and science visualizers can create nanoparticle models for illustrations and animations. Instancing keeps clusters with thousands of atoms light enough to rotate and edit comfortably.

Key features

  • Cuts fcc or hcp lattices
  • Instancing vertices for fast handling
  • Add > Mesh > Atom cluster entry
  • Nanoparticle and cluster structures
