What Bake Instance Animation (烘焙几何节点实例动画) does

Bake Instance Animation is a Blender add-on by ChyiZ_ that turns animated Geometry Nodes instances into ordinary keyframes. Instances become independent mesh objects whose position, rotation and scale are preserved across the animation, ready for export or further editing.

Results are placed into a collection that the add-on creates and manages, with a customizable name (bake_animation by default) and frame range. The controls sit under a BIA tab of the 3D viewport sidebar. This helps when procedural animation needs to leave Blender for a game engine or other software.

Key features

  • Bakes instances into independent mesh objects
  • Preserves position, rotation and scale
  • Automatic collection for baked results
  • Custom collection name and frame range
  • BIA tab in the viewport sidebar
