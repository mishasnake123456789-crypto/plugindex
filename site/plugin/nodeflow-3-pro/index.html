What Nodeflow 3 Pro does

孙堪伟's NodeFlow 3 Pro, made for Blender 5.0 and compatible back to 4.5, improves the Node Editor. A Smart Connection System routes links at right angles in a circuit-board layout, working both ways with ports aligned automatically.

Reroute points can be merged or removed in a click, and an alignment pie menu offers horizontal and vertical alignment, even distribution and width matching. For big graphs there is also a visual linking assistant and a live minimap for getting around. Shader and geometry node users get neater networks.

Key features

  • 90-degree connection routing
  • One-click reroute merge or delete
  • Alignment pie menu with distribute and match width
  • Visual linking assistant
  • Real-time minimap
