What Volume n' Tricks 2 does

Volume n' Tricks 2 is a PENCIL Park toolset for creating extruded, isometric-looking graphics from flat artwork in After Effects. It projects the extrusion onto several layers at once without needing true 3D.

Parented isometric shadows add depth, pivot and rotation features support keyframable isometric rotation with limitless extrusion, and Move Y and Move Z sliders place objects closer or farther. Results are visualized live in the Effects Controls panel. The interface is light on system resources, and files remain compatible with Lottie through .json export using Bodymovin.

Key features

  • Isometric extrusion across multiple layers
  • Parented isometric shadows
  • Keyframable isometric rotation
  • Move Y and Move Z sliders
  • Lottie compatibility via Bodymovin
