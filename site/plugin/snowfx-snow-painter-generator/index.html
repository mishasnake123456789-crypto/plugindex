What Snowfx - Snow Painter/Generator does

SnowFX is a Blender plugin for covering objects in snow. You can drop snow over the top of an object, or paint it where you want it with the Snow Painter.

After applying, a Snow Editor lets you alter the shape and look, and a Snow Height Editor controls depth. Layers can be added and combined as you paint. Documentation is included. It suits winter scenes and seasonal renders. Combining generation with painting offers both speed for large areas and control for details, making it a flexible option for winter environments.

Key features

  • Drop snow on top of an object
  • Snow Painter brush
  • Snow Editor and Snow Height Editor
  • Layered snow
