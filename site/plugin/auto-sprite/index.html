What Auto Sprite does

Auto Sprite assembles sprite sheets inside Blender. Bring in an image sequence from a folder or take your render output, select a layout and a resolution cap, and the sheet is produced.

A render queue sets sheet dimensions automatically and scales frames to fit, which removes manual arithmetic when preparing assets for 2D games or animations. It is useful for developers who render animation from 3D models and need packed sheets.

Key features

  • Sprite sheets from image sequences or render output
  • Choice of layout and resolution limit
  • Render queue with automatic sheet dimensions
  • Automatic scaling
