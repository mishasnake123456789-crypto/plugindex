What Blender Sverchok Grid Fill Node does

vkter's script extends Sverchok, the node-driven parametric modeling add-on for Blender. It runs within Script Node Lite and fills closed edge loops with mesh.

You feed it vertices and edges, plus an offset input that rotates the fill grid. An interp parameter chooses between populating the grid by simple interpolation or filling without it, and the node returns the grid data. Import the matching .json file through the Sverchok side panel. Parametric modelers and procedural designers get a quick way to cap loops.

Key features

  • Fills closed loop edges
  • Runs in Script Node Lite for Sverchok
  • Verts and edges as inputs
  • Offset input and interp toggle
  • Imported via JSON file
