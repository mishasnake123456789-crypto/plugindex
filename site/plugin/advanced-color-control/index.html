What Advanced Color Control does

Advanced Color Control by Hassaan Ahmad takes the values from After Effects' Color Picker and places them in the Effects & Controls panel, where they can be keyframed or driven by expressions. It supports HSB, HSL and RGB color models.

Each model has two modes: values can control the color, or the color can control the values. Controls are created automatically and can be customized, and the interface is a compact one-liner with labeled elements. It suits motion designers who want to animate hue, saturation or brightness separately.

Key features

  • HSB, HSL and RGB color models
  • Values Control Color and Color Controls Values modes
  • Color Picker properties in Effects & Controls
  • Animate or apply expressions
  • Automated control creation
