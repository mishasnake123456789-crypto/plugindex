Moves a Blender object's origin to the top, bottom or selected faces with a single hotkey.

What Origin Tools does

Origin Tools speeds up one of the most repeated chores in modeling: placing an object's origin. Press Ctrl + Shift + Alt + C and a prompt offers the available options.

You can send the origin to the top of the mesh, to the bottom, or to whichever face or faces are selected. This is handy for props that need to sit on a floor, hinge or pivot correctly, and for preparing assets for game engines. Documentation comes with the add-on.

Key features

  • Origin to top of the mesh
  • Origin to bottom of the mesh
  • Origin to selected faces
  • Single hotkey prompt
