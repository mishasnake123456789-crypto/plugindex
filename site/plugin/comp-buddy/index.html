What Comp Buddy does

Comp Buddy is a tool from Josh Johnson that makes two common compositing steps easier in After Effects: building an edge blur and a light wrap. Both help a foreground subject blend into a background plate.

It is compatible with After Effects CC 2019 through 2025. The release is version 1.0, free, and a demo video is available. Compositors working with keyed footage can use it to get a more integrated look without assembling the setups themselves.

Key features

  • Simplifies edge blur creation
  • Simplifies light wrap creation
