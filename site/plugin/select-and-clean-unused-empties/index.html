What Select And Clean Unused Empties does

Select And Clean Unused Empties is a Blender add-on for removing leftover empties. It selects only those that nothing depends on, so cleanup does not break the scene.

It skips empties with children, empties used as parents, and those referenced by constraints, modifiers or drivers, and it leaves out empties set as a camera depth-of-field focus object. The command is found in the Select menu. Artists who inherit imported or messy scenes can clear clutter with confidence.

Key features

  • Selects only childless, unreferenced empties
  • Skips parents, constraints and modifier targets
  • Ignores drivers and camera focus empties
  • Available from the Select menu
