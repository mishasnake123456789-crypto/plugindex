What Fast Language Switch does

Fast Language Switch from Kk puts a button next to Blender's top menu for changing the interface language. It works with common languages.

Version 0.0.5 turned the button into an icon to take less space. It needs no special permissions and supports Blender 4.2 LTS and newer. Bilingual users, teachers and tutorial makers who frequently swap languages save trips to Preferences. A one-click switch helps people who work in a second language or compare translated interface text.

Key features

  • Button next to the top menu
  • Switches between common languages
  • Icon button since version 0.0.5
  • Supports Blender 4.2 LTS and newer
