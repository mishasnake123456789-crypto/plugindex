What Storytools - Storyboard Tools does

Storytools is a Blender add-on by SamuelBernou for storyboarding and 2D animation. It adds a Storytools tab to the viewport sidebar that gathers grease pencil, camera and drawing setup tools in one place.

A popup creates a new drawing facing the camera, at the cursor or in front of the lens, optionally parented to the camera. Gizmo buttons along the bottom handle pan, move, rotate, scale and camera keying while respecting autokey. A top bar holds customizable tool presets with shortcuts. One Blender restart is needed after installation.

Key features

  • New Drawing popup places grease pencil facing the camera
  • Gizmo buttons for object and camera placement
  • Camera pan, dolly, lock-to-view and keying actions
  • Customizable tool presets with shortcuts
  • Default storyboard palette loads on new objects
