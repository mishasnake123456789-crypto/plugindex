What Blaze Puppeteer does

Blaze Puppeteer is a Blender plugin for generating motion on your own rig. It applies direct FK and IK on any humanoid rig without retargeting, and lets you create inbetweens via anchors.

Root motion can be steered with waypoints and dense paths, and looping and variations are supported. Local generation is included, with optional cloud features. Animators can block out walks and other movement quickly. Because it works directly on the rig you already have, animators can generate a base performance quickly and then refine it by hand.

Key features

  • FK/IK on any humanoid rig, no retargeting
  • Inbetweening with anchors
  • Root motion with waypoints and paths
  • Looping and variations
