Generates outward-facing 3D text labels on every face of a mesh and exports them with it as one GLB.

What Face Tag does

Face Tag is a Blender add-on from bhdesign that labels each face of a mesh with 3D text. Select a mesh, click Preview, and centered labels appear, each oriented along its face normal so it faces outward.

You can customize the label prefix, text size and extrusion depth. Labels are kept in their own collection, so the process is non-destructive and can be regenerated whenever you like. The object and all labels can then be exported together as a single GLB file. It works with Blender 4.3 through 5.0 and is handy for identifying faces in pipelines that need numbered or named surfaces.

Key features

  • One-click label generation per face
  • Labels oriented along face normals
  • Custom prefix, text size and extrusion
  • Stored in their own collection, regenerable
  • Single GLB export of object and labels
