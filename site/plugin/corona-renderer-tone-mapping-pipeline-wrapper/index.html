MaxScript wrapper that makes it easier to add, remove and read Corona Renderer 8 tone mapping operators.

What Corona Renderer - Tone Mapping Pipeline Wrapper does

This MaxScript wrapper eases scripting of Corona Renderer 8's tone mapping pipeline in 3ds Max, something the author finds awkward to do directly. It provides plain functions in place of low-level handling.

Operators can be added to the end of the list or at a specific position, and deleted individually, by position, or all at once. All operators, their IDs, or both can be returned as arrays, and an operator or its class can be fetched by position. It can also generate a unique random ID and check if the list is empty. It is intended for scripters building tools around Corona.

Key features

  • Add operators at the end or a specific position
  • Delete last, specific or all operators
  • Retrieve operators, IDs or both as arrays
  • Get an operator or its class by position
  • Generate unique IDs and check for an empty list
