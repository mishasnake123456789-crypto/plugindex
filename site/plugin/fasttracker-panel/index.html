What FastTracker Panel does

FastTracker Panel hooks both After Effects and Premiere Pro up with the FastTracker server, which indexes media living on Facilis shared storage. Instead of browsing folders by hand, users query the database and watch proxy previews right in the panel.

Chosen clips are brought into a Premiere Pro project with their metadata and proxy links attached. Logins keep assets protected, and catalogs can be locked down. Indexing and preview creation happen automatically across direct-attached and network volumes. Batch actions can cover everything returned by a search, and archive status is shown with a colored marker. It suits teams already working on Facilis systems.

Key features

  • Database search with proxy preview
  • Imports with metadata and proxy linking
  • Login-based asset protection
  • Batch actions across search results
  • Archive status color marker
