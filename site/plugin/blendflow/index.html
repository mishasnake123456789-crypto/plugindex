What Blendflow does

BlendFlow brings motion path and timing curve editing into the 3D Viewport, so trajectories and easing can be changed on the fly with instant visual feedback.

Motion paths become interactive 3D curves where you insert, delete, scale and rotate keyframes and click a point to jump to its frame. An HUD easing editor overlays the viewport. Animators can polish arcs and timing without switching editors. Key capabilities include live 3D motion path editing and insert, delete, scale and rotate keyframes on the path.

Key features

  • Live 3D motion path editing
  • Insert, delete, scale and rotate keyframes on the path
  • Click a path point to jump to its frame
  • Interactive HUD easing editor
