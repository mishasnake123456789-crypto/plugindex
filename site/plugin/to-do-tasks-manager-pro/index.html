What To-Do Tasks Manager Pro does

To-Do Tasks Manager Pro puts a checklist right in your Blender workspace. Add as many tasks as you like, and attach a reminder to each so nothing is forgotten during a long session.

Reminders can play a custom sound, and a custom keymap opens an overlay list of tasks. Lists can be saved to your computer and loaded again later. Documentation is included. Freelancers and hobbyists who juggle shots and fixes will like staying in one window.

Key features

  • Unlimited tasks
  • Reminder for each task
  • Custom reminder sound
  • Overlay list via custom keymap
  • Save and load task lists
