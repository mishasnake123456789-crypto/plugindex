What Deekay Tool does

Deekay Tool is an After Effects extension made by Motion Design School in collaboration with Deekay, aimed at character animators. Characters can be created and saved with a single click.

It includes a rigging system with a new approach and optimized limbs, an Assist panel for everyday shape and animation tasks, and an Animate feature for making and customizing animations with intuitive controls. It supports After Effects 2020 through 2025.

Key features

  • Create and save characters in one click
  • Rigging system with optimized limbs
  • Assist panel for shape and animation tasks
  • Animate feature with intuitive controls
  • Works with After Effects 2020-2025
