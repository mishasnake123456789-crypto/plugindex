Blender add-on that renames the current .blend file from inside the interface without using a file explorer.

What Rename: Change The Name Of Your File Inside Blender does

Rename lets you change the name of your .blend file without leaving Blender. Normally this means closing or switching to a file manager, and the add-on avoids that detour with an interface built into the application.

Install it as a standard ZIP add-on through Edit > Preferences > Add-ons. It supports Blender 4.2, 4.1, 3.6, 2.93 and 2.83. Note that it does not save the file automatically, so save your work before renaming. It is released under the GPL license.

Key features

  • Renames .blend files within Blender
  • Interface integrated into Blender's UI
  • Supports Blender 2.83 through 4.2
  • Installs as a normal ZIP add-on
  • Does not auto-save, so save first
