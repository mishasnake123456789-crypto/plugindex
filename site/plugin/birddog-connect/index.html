What BirdDog Connect does

BirdDog Connect adds a panel to Premiere Pro for running live review sessions with people in other locations. The timeline output is sent in full quality with embedded timecode and audio, so clients see exactly what the editor sees, frame-accurately.

Viewers can be shown the Program view, the Timeline view or an Edit Suite camera, and the editor can mix them or cut between sources. Sessions are encrypted end to end and can be password protected, with no screen sharing or separate conferencing software. Viewers watch from web, macOS, Windows, tvOS and other BirdDog Connect apps.

Key features

  • Start and stop live sessions from inside Premiere Pro
  • Program, Timeline and Edit Suite Cam views
  • Timecode and audio embedded for frame-accurate sync
  • End-to-end encryption with optional password
  • Viewing on web, desktop and tvOS apps
