A Blender add-on that puts axis constraint checkboxes in the 3D View header for Tweak and Move tools.

What Toggle Constraint Axis does

Toggle Constraint Axis adds simple checkboxes to the Blender 3D View header that restrict movement to chosen axes. This is useful when moving objects or vertices with tools like Tweak or Move and you do not want to press a key for each constraint.

The checkboxes correspond to the X, Y and Z values of the translate operator, so enabling only X permits X movement, and X plus Y limits motion to the XY plane. Default hotkeys of Ctrl+Alt+X, Y and Z toggle them, and it works by overriding keymap settings that call the translate operator. Modelers who move things constantly gain some speed.

Key features

  • Header checkboxes for X, Y and Z constraint
  • Works with Tweak and Move tools
  • Ctrl+Alt+X, Y, Z hotkeys
  • Plane limits such as XY
  • Based on keymap overrides
