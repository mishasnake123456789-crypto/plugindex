What Ls - Pro Auto Lod Generator does

LS - Pro Auto LOD Generator creates level-of-detail meshes for games. Eight levels from LOD0 to LOD7 can each be switched on or off, with live triangle count estimates.

Reduction can be set by percentage or by target polygon count, with different decimation styles such as Balanced. Rigging, weights and UV mapping are preserved, and export options target Unreal Engine, Unity and Godot. Keeping skin weights and UV layouts through reduction means LODs can be exported without extra repair.

Key features

  • LOD0 to LOD7 with per-level toggles
  • Ratio and Target polygon count modes
  • Preserves rigging, weights and UVs
  • Real-time triangle count estimate
  • Export for Unreal, Unity and Godot
