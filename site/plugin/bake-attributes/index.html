Bakes Geometry Nodes attribute values in Blender so they can drive rigs, lights and cameras.

What Bake Attributes does

Bake Attributes captures values from Geometry Nodes attributes and stores them so other parts of a Blender scene can use them. Baked values can drive rigs, lights, cameras and similar elements.

The add-on targets artists who use Geometry Nodes procedurally and need to connect that data to animation objects. It is distributed under the GPL license, is listed as extension compatible and supports Blender 4.0, 3.6, 3.5 and 3.4. Documentation is included.

Key features

  • Bakes Geometry Nodes attribute values
  • Drives rigs, lights and cameras
  • Supports Blender 3.4 to 4.0
  • GPL license with documentation
