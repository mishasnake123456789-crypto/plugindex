What Shape Key Mirror Plus does

Shape Key Mirror Plus, by Ciyorie, is a Blender add-on for mirroring and symmetrizing shape key deltas across symmetric axes, based on a symmetric base shape. It aims to avoid the errors that appear with Blender's default shape key mirroring, particularly on complex meshes made of multiple parts.

Symmetrize and Mirror operations are kept clearly separate, and the panel is integrated under Shape Keys. It supports recent Blender versions. Facial riggers and character artists who sculpt only one side of an expression can finish the other half more reliably.

Key features

  • Mirrors shape key deltas across axes
  • Symmetrizes from a symmetric base shape
  • Fewer errors on multi-part meshes
  • Separate Symmetrize and Mirror operations
  • Panel under Shape Keys
