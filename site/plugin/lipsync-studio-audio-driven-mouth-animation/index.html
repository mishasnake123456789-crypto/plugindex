What Lipsync Studio - Audio-Driven Mouth Animation does

LipSync Studio animates a character's mouth from audio and delivers the result as a blendable NLA strip. It offers three analysis engines: a fast built-in energy method, Rhubarb Lip Sync, and OpenAI Whisper for English.

Six rig presets, including ARKit 52, FACEIT, Preston Blair, MetaHuman and CC4, map the 17 viseme slots, with auto-detection from shape-key names. Analysis runs on worker threads so the interface stays responsive. An emotion overlay adds Happy, Sad, Angry or Surprised expressions, ease-in and ease-out can be set per keyframe, and results export to FBX, glTF or JSON.

Key features

  • Three analysis engines including Rhubarb and Whisper
  • Six viseme presets with auto-detect
  • Push to NLA, reversible
  • Emotion overlay and FBX, glTF or JSON export
