What Coretools - Loop Cut does

CoreTools Loop Cut inserts edge loops exactly where the cursor is, with clear preview highlights so results are predictable.

Even mode distributes loops classically. Pick Side dynamic mode keeps a uniform offset from nearby loops, and F flips the side mid-cut. Pick Side fixed offset accepts real-world values in any unit Blender supports, and a center mode is also available. Snapping adds further precision, making it a quicker alternative for detailed topology work.

Key features

  • Loop insertion under the cursor
  • Visual preview highlights
  • Even, Pick Side and Center modes
  • Real-world unit offsets
