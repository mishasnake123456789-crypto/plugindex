Standardizes low and high poly object names for baking and automatically pairs them in Blender.

What Bake Matcher does

Bake Matcher takes the naming chore out of baking. Set as Low/High-Poly renames selected objects to a standard format with automatic numbering and a _low or _high suffix.

Match Bake Objects then finds the counterpart of each object in 3D space using two methods: Bounds Mode compares bounding box corners from global mesh data, and Origin Mode compares origin points. Users can define their own base name. It is useful for baking normal maps and other textures from high to low poly.

Key features

  • Rename to _low and _high with numbering
  • Bounds Mode matching
  • Origin Mode matching
  • Custom base name
