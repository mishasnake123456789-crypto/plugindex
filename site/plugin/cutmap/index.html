Node-based version map for Premiere Pro sequences, tracking branches, variants and approval status on a canvas.

What CutMap does

CutMap gives Premiere Pro projects a visual version tree. It finds your sequences on its own, syncs with the project, and lays them out as nodes on a zoomable, draggable canvas so you can see how cuts descended from one another.

Each version carries a status of WIP, Sent, Feedback, Approved or Archived, and the tool recognizes common naming conventions. Branches and variants are managed on the same canvas, and every project keeps its own isolated workspace. It is designed for editors and post supervisors on commercials, episodic work or any job that generates many revisions.

Key features

  • Zoomable canvas of sequence version trees
  • Automatic sequence discovery and sync
  • Status per version from WIP to Archived
  • Naming convention recognition
  • Separate workspace for each project
