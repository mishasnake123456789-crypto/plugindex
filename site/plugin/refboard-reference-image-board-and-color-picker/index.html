What Refboard - Reference Image Board & Color Picker does

RefBoard from Ludiax Studio brings reference images and color sampling into the 3D View sidebar. You can add and manage images close to your modeling and shading work.

The panel previews images, lets you pick exact colors from them and apply those colors to selected mesh areas. This avoids switching to another app for references and keeps color decisions consistent. The feature set spans reference image board in the sidebar and image preview in the panel.

Key features

  • Reference image board in the sidebar
  • Image preview in the panel
  • Exact color picking from images
  • Apply colors to selected mesh areas
