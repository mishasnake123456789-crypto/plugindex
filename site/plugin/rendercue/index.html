Blender batch render queue that runs jobs in a background process with per-job overrides, resume and notifications.

What RenderCue does

RenderCue queues several scenes for rendering in Blender and runs them in a separate background process, so the interface stays responsive. Scenes from anywhere in the .blend file go into one reorderable list.

A health check flags missing cameras and bad paths before starting. Per job you can change the render engine, samples, file format, resolution scale, frame range, compositor use, transparency, camera and output path. Queues can pause and resume, even after closing Blender, and configurations save as JSON presets. Completion notices arrive via Windows toasts and Discord or Slack webhooks.

Key features

  • Reorderable global render queue
  • True background rendering
  • Queue health validation
  • Per-job overrides for engine, format and samples
  • Pause, resume and webhook notifications
