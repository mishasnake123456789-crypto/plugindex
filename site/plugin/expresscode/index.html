Brings a VS Code-style editor to After Effects expressions with completion, error checking and TypeScript.

What expressCode does

expressCode, by Jordan Steele, puts a VS Code editor inside After Effects for writing expressions. The default expression box offers little help, while this adds IntelliSense completion, real-time error checks and hover definitions.

Expressions can be edited from any comp without searching the timeline, linked to properties, and loaded from layers. A built-in library stores favorites for one-click reuse. Autocomplete covers local variables, functions, and names of comps, layers, markers, effects and parameters, and Insert Property Reference works like a pick whip with configurable format. TypeScript support is included.

Key features

  • IntelliSense, error checking and hover definitions
  • TypeScript support
  • Built-in library of saved expressions
  • Autocomplete for layer, effect and marker names
  • Pick whip style property references
