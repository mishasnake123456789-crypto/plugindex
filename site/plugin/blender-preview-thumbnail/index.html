A Windows thumbnail handler that shows the preview image inside .blend files in File Explorer.

What Blender Preview Thumbnail does

Blender Preview Thumbnail makes Windows Explorer display the preview image stored in each .blend file, in place of the generic Blender logo. Browsing a folder of projects becomes visual, so you can find a scene by its picture instead of guessing from file names.

Setup detects your Blender installation automatically and installs or removes in one click. It works with Blender 3.0 through 5.0 and later, has no background processes and therefore no performance cost, and supports any .blend file saved with File Preview enabled. Anyone managing many scene files on Windows will benefit.

Key features

  • Thumbnails for .blend files in Windows Explorer
  • Auto-detects the Blender installation
  • One-click install and uninstall
  • No background processes
  • Works with Blender 3.0 to 5.0+
