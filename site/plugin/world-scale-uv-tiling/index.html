What World Scale UV Tiling does

World Scale UV Tiling rescales custom unwrapped UVs in 3ds Max to an arbitrary physical size, such as one meter by one meter. The goal is for materials that use real-world tiling values, like those in Unreal material libraries, to appear at the right scale.

It is aimed at meshes with a hand-made unwrap, where applying a UVW Map is not an option. The script works with 3ds Max 2012 and later, and a demo video is available. Game artists and archviz users preparing assets for Unreal can avoid guesswork with texel density.

Key features

  • Resizes custom UVs to any physical size, e.g. 1 m by 1 m
  • Supports real-world tiling in Unreal material libraries
  • Works where UVW Map is not an option
  • Works with 3ds Max 2012 and later
  • Demo video available
