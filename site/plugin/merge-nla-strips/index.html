What Merge NLA Strips does

Merge NLA Strips is a Blender add-on by Likkez that merges the NLA strips you select into one strip while leaving the source intact. Rather than use Blender's built-in baking, it copies the keyframes from the selected strips.

It still processes every frame, as regular baking does, and is reached from the right-click menu in the NLA editor. Version 1.2.0 added an NLA Renamer operator that renames the action behind a strip. No special permissions are required, which keeps it easy to install for animators cleaning up cluttered NLA stacks.

Key features

  • Merges selected NLA strips non-destructively
  • Copies keyframes rather than using built-in baking
  • Processes every frame like standard baking
  • Available from the NLA right-click menu
  • NLA Renamer operator since version 1.2.0
