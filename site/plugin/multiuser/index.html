What Multiuser does

Multiuser is a Blender add-on by slumber that makes collaborative work possible, with several users editing the same scene over the network simultaneously. It follows a client and server architecture.

A data-oriented replication schema copies Blender data-blocks across the wire so every participant sees the same state. Network permission is requested so scene data can be synchronized with the server, and builds exist for Windows and macOS, on both Intel and Apple Silicon processors. It suits remote teams that want to build or review a scene together.

Key features

  • Real-time collaborative editing
  • Multiple users in one scene over the network
  • Client and server architecture
  • Replicates Blender data-blocks
  • Builds for Windows and macOS
