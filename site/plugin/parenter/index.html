Groups selected After Effects layers under a new null so they can be moved without disturbing their animation.

What Parenter does

Parenter creates a null and parents the selected layers to it, usually placed at the center of the selection. You can then reposition everything together, and the original animation stays intact.

A toggle moves the null without dragging the children, and clicking it again restores the link. A remove icon deletes the null and brings back the original parents, and Alt or Option-click also restores position, scale and rotation. Modifier keys control null placement, and layers can be added to or unlinked from an existing Parenter.

Key features

  • Groups layers under a new null
  • Toggle to move the parent without moving children
  • Remove icon restores original parents
  • Modifier keys for null placement
  • Copy, paste and clear parents
