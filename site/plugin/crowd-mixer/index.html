What Crowd Mixer does

Crowd Mixer 2.0 for Blender, from Nava Lab, builds crowds from ready-made presets in three types. Stadium handles row-based seating, Flow gives path-guided directional movement, and Standing creates static dense groups.

Presets act as a starting point you can adjust later. The tool adds variety in characters and outfits, and Instance Override allows individual edits: swapping a character, offsetting position, rotation and scale, toggling visibility and overriding speed on flow crowds. Preview-friendly tools keep large scenes manageable while you work.

Key features

  • Stadium, Flow and Standing crowd types
  • Ready-made crowd presets
  • Character and outfit variety
  • Instance Override for individual points
  • Preview tools for large scenes
