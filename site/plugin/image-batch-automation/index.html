What Image Batch Automation does

Image Batch Automation imports 3D objects one at a time and renders each automatically from several angles inside a preset lighting environment. It works with Eevee and Cycles and runs on Windows only.

Output is PNG images, with an optional .blend file for every imported object. Rotation counts and angles are set per axis, and the import scale is adjustable. It suits asset libraries and product catalogs that need many consistent preview renders.

Key features

  • Batch import one object at a time
  • Multi-angle automatic renders
  • Preset lighting environment
  • PNG plus optional .blend output
  • Per-axis rotation settings
