What Keyframe Pilot does

Keyframe Pilot is a collection of animation utilities for Blender from shigeru ozawa. It gathers common keyframe chores in one place so they can be applied quickly.

You can insert keys for location, rotation, scale or custom properties and apply ease-in, ease-out or custom easing. Loop, reverse and randomize operations create repeating, mirrored or varied motion, while Timeline Scale and Timeline Shift change timing proportionally. Align2Motion makes chosen objects follow the motion of another object or a path, and a cleanup command clears out unused keys.

Key features

  • Insert keys with ease-in, ease-out or custom easing
  • Loop, reverse and randomize keyframes
  • Timeline Scale and Timeline Shift
  • Align2Motion to another object or path
  • Remove unused keyframes
