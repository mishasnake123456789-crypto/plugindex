What Dynamic Head Property Manager does

Dynamic Head Property Manager, by Cloud-Guy, supports creators making facial animation for Roblox in Blender. It collects all the FACS poses from the Roblox website in a single place, so custom properties on bundles and dynamic heads are easier to handle.

A fast search finds any pose, edits are non-destructive and can be changed at any time, and the list you build can be exported and imported to avoid redoing work. It works with Blender 4.2 LTS and newer and needs no special permissions.

Key features

  • All Roblox FACS poses in one place
  • Fast pose search
  • Non-destructive editing
  • Export and import of your list
  • Blender 4.2 LTS and newer
