What Mysmooth does

Mysmooth is a Blender add-on for artists who smooth objects constantly and want to avoid trips to the mesh properties. One button, or the Ctrl+Alt+S shortcut, applies shade smooth with auto smooth at the default angle.

A header button shows an object's current shading state, and a submenu turns auto smooth on or off for the active object and sets the angle. Several selected objects can be smoothed or flattened together, with a prompt when types are mixed, and the button can behave as an instant smooth-or-flat toggle. The shortcut can be changed in preferences, and documentation is included.

Key features

  • One-click shade smooth with auto smooth
  • Configurable Ctrl+Alt+S shortcut
  • Header button shows current shading state
  • Works on multiple selected objects
