What Auto Create Output + Render Folder does

Auto Create Output + Render Folder removes the manual work of naming and filing renders. Paths are composed from tokens like blend file, scene, date, resolution and version.

Folder layouts such as Date/Scene, Scene/Date, Scene Only or custom ones are created for you, and still renders are written to disk automatically; animations are supported too. It keeps project output organized for freelancers and studios producing many versions of the same shot. Consistent folder structure also makes it easier to find earlier takes and compare iterations later.

Key features

  • Token-based output paths
  • Automatic subfolder creation
  • Date/Scene, Scene/Date and custom layouts
  • Auto-saves still images
