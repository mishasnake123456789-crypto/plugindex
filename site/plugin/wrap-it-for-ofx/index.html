OpenFX plugin for 3D camera projection, UV unwrapping and texture rewrapping from Alembic files in DaVinci Resolve.

What Wrap It for OFX does

Wrap It for OFX brings 3D projection techniques into DaVinci Resolve. Alembic geometry can be loaded, then used to project footage through a camera onto surfaces, or to unwrap the model into UV space and bake textures out of the shot.

The process also works in reverse: a texture can be wrapped back onto the model so that edits made flat appear correctly on the 3D object. Animated geometry is supported, and the work is GPU accelerated. It runs on Windows, Mac and Linux. Compositors doing texture extraction, patching or blending CG elements with plates will find it useful.

Key features

  • 3D camera projection
  • Loads Alembic files
  • Unwraps geometry to UV space
  • Rewraps textures onto models
  • Supports animated geometry
