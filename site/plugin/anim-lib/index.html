Blender add-on that turns the NLA Editor into an animation clip library with batch game export.

What Anim Lib does

Anim Lib repurposes Blender's NLA Editor as a place to store and manage game animation clips rather than to blend them. It targets creators whose projects accumulate large numbers of tracks and strips.

Tools cover grouping related strips onto one track, moving and reordering tracks, arranging strips with fixed spacing, and removing empty tracks. Validation checks for empty strips and duplicate action use and writes reports to the Text Editor. Clips can be batch exported to FBX or glTF (.glb) for Unreal, Godot and Unity, either as separate files or merged, and utilities keep strip and action names in sync.

Key features

  • Track and strip organization tools in the NLA Editor
  • Batch export to FBX or glTF 2.0
  • Validation for empty strips and duplicate actions
  • Rename and sync strips with linked actions
