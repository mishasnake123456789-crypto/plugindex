What Packed Data Manager does

Polynook's Packed Data Manager gives a unified overview of what a blend file holds. More than forty data types are covered, such as Object, Material, Collection, Modifier, Mesh, Custom Property, UV Map, Action and Bone.

Hundreds of filters, built-in or custom, show only data meeting your conditions, and hundreds of batch operations apply across types. Technical artists maintaining large scenes or libraries can audit and clean them systematically. Seeing every datablock type in one place makes it easier to spot unused or inconsistent items before delivery.

Key features

  • Over 40 data types
  • Hundreds of built-in and custom filters
  • Batch operations across data types
  • Inspect and select data
  • Works on the current blend file
