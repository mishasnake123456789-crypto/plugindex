What Animation Tools does

Animation Tools, by Animander, collects frequent animation chores into one Blender panel. Instead of switching between menus, you get keyframe utilities and pose helpers together, suited to both character and object animation.

Push Keyframes shifts selected keys along the timeline by a set interval, leaving keys before the current frame alone. Clean Keyframes removes redundant keys that share the same value, keeping the first and last, and can optionally run Blender's decimate. Set Keyframe Interval places stepped keyframes, and further tools cover pose flipping, onion skinning and bone constraints. Animators tidying curves will save effort.

Key features

  • Push Keyframes by a set interval
  • Clean redundant keyframes
  • Stepped keyframe interval placement
  • Pose flipping and onion skinning
  • Bone constraint tools
