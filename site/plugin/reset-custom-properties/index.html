What Reset Custom Properties does

Reset Custom Properties gives you a way to return an object's custom properties back to their defaults. Custom properties are commonly used on rigs and setups, and changing many of them makes it hard to get back to the starting state.

With this add-on, a reset is one action. Riggers and animators who rely on property-driven controls can clear experiments and restart cleanly.

Key features

  • Resets custom properties
  • Returns values to defaults
  • Handy for property-driven rigs
