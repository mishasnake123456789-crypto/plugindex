Script that exports PNG screenshots from video clips in After Effects, with an optional text watermark.

What Batch Shot does

Built by GiadaAnni, Batch Shot is a script running inside After Effects aimed at pulling still images out of video clips. It is suited to previews, client review material and web-ready assets.

Footage items are selected in the Project panel, and a percentage slider picks the exact frame to capture. Stills are exported in batch to a folder you choose. An optional text watermark can be set in color, opacity and position, with five fonts available: Arial, Helvetica, Verdana, Times New Roman and Courier New. File names are built from project, clip, date and time macros, and a progress bar with logging tracks batch jobs.

Key features

  • Batch PNG export to a chosen folder
  • Frame selection by percentage slider
  • Optional text watermark with five fonts
  • Automatic naming with project, clip and date macros
  • Progress bar and logging
