What animationPATTERNSpro does

animationPATTERNSpro, by Markus Bergelt, is a keyframe-based easing assistant for After Effects. It lets you edit existing easing types, create new ones, and keep them organized instead of redoing curves for each property.

Pattern layers hold your eases and can be reused throughout a project, which keeps the file tidy and easy to adapt. Curved motion paths are fully supported. Patterns can be copied and pasted to build your own library from any motion, saved quickly, and baked or unbaked to speed up rendering without losing flexibility.

Key features

  • Multiple pattern layers organize eases
  • Project-wide reuse of patterns
  • Support for curved motion paths
  • Copy and paste to build your own patterns
  • Bake and unbake for faster renders
