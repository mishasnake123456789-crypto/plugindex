What Power Droste does

Power Droste from CROSSPHERE .Koizumi is a multi-purpose After Effects plugin for twisting an image into a spiral and creating the recursive Droste look in the same tool. It is aimed at motion designers who want hypnotic, repeating visuals.

The controls include 3D rotation, an unroll option, and multi-strands that can each be controlled and given their own texture. Extra deformation settings push the shape further. Having spiral and Droste behavior in one effect avoids stacking several plugins to reach a similar result.

Key features

  • Spiral deformation and Droste effect together
  • 3D rotation
  • Unroll control
  • Individually controlled, textured multi-strands
  • Extra deformation options
