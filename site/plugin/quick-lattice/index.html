Blender add-on that automatically builds a lattice cage around an object so you can warp it non-destructively.

What Quick Lattice does

Quick Lattice by carlosmu handles the repetitive setup of lattice deformation in Blender. It creates the cage for the selected object and configures its dimensions, placement, orientation, subdivisions, interpolation and modifier, leaving you free to reshape the model.

Because the deformation lives in a lattice modifier, edits stay non-destructive. The tool is available from the right-click context menu, or with the w key for users of the right click select keymap, and there is an optional shortcut for faster access during modeling.

Key features

  • Auto-creates a lattice cage with matching modifier
  • Sets size, position, rotation, resolution and interpolation
  • Non-destructive deformation
  • Right-click context menu access
  • Optional keyboard shortcut
