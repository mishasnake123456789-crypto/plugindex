What Coco Color CoWorker does

Coco Color CoWorker is a panel by LetsMotion that gathers color tools inside After Effects. It provides a picker for choosing colors directly, along with a collection of ready-made palettes that has grown over several updates.

A smart palette generator arrived in version 1.2.0, and palette libraries can be imported and exported to share or back up. Holding Shift or Ctrl while using hotkeys applies a color to a shape's stroke or fill. It is compatible with Coco Color Wheel, and suits designers who handle many palettes.

Key features

  • Color picker inside After Effects
  • Smart palette generator
  • Built-in palette collection
  • Import and export of palette libraries
  • Hotkeys for shape stroke and fill
