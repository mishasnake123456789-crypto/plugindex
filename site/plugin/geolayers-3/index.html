What GEOlayers 3 does

GEOlayers 3 is a ground-up rebuild of the map animation tool for After Effects. It lets designers build and move maps without exporting from other software, and now supports Helium for 3D landscapes along with a Stable Diffusion-powered image generation plugin that runs on Stable Diffusion.

Maps can be pitched and rotated in 3D and interact fully with the After Effects 3D environment. Styling is done in the app, with Point, Line and Facet renderers adding shading, fog, shadows and depth of field. Labels appear automatically in several languages, OpenStreetMap features can be found by clicking the preview map, and 3D buildings can be drawn. A scripting API is included.

Key features

  • Maps pitched and rotated in the AE 3D space
  • In-app map styling
  • Point, Line and Facet renderers with fog and shadows
  • Helium AI image generation
  • OpenStreetMap features and 3D buildings
