What Skava Uv Master - Professional Uv Solution does

Skava Uv Master combines smart unwrapping with fast packing for game and archviz work in Blender.

Smart detection analyzes a mesh and chooses cube, cylindrical, angle-based or advanced smart projection. GPU-accelerated packing is claimed to be up to ten times faster than CPU methods, with a CPU fallback. Identical meshes are detected and their UVs stacked, and presets cover game and ArchViz needs. This reduces the manual unwrapping and packing that large scenes with many assets usually require.

Key features

  • Shape-based unwrap method selection
  • GPU-accelerated packing with CPU fallback
  • Automatic stacking of identical meshes
  • Presets for games and ArchViz
  • Handles many meshes quickly
