What Deep Clean does

Deep Clean is a Blender plugin for reducing file bloat. It removes orphaned data that remains in .blend files and gives you finer control than the standard purge.

A Purge by Data Type button on the Outliner header clears one chosen type and leaves the rest alone, Purge by Name under File, Clean Up finds data whose name contains a given string, and a duplicates operator clears copies. Images can be packed or unpacked in bulk. The result is lighter, tidier files.

Key features

  • Purge by data type from the Outliner
  • Purge by name string
  • Clear duplicates
  • Batch pack and unpack images
