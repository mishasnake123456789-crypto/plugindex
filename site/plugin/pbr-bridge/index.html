Blender add-on that builds complete PBR materials from a texture folder, with output tuned for Cycles, Unreal or Unity.

What Pbr Bridge does

PBR Bridge scans a folder of textures, recognises each map by its filename, and builds a finished material on the selected object in one click. Colour spaces are set correctly and the node tree is wired for you, which saves a lot of repetitive setup when working with large libraries.

A dropdown switches the result between Cycles and EEVEE, Unreal Engine 5 with ORM packing and DirectX normals, or Unity with smoothness conversion. It detects albedo, roughness, metallic, normal, AO, height, emission and opacity maps and understands Quixel, Poliigon, AmbientCG and Fab naming. It is pure Python and needs no internet connection.

Key features

  • One-click material build from a texture folder
  • Targets for Cycles/EEVEE, Unreal Engine 5 and Unity
  • Auto-detects maps by case-insensitive filename keywords
  • Handles PNG, JPG, TGA, TIFF, EXR and HDR files
  • Pure Python with no external dependencies
