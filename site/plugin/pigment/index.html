What Pigment does

Pigment from Filthy Baguette is a palette manager for After Effects. It can generate palettes and reroll them until something clicks, or build one from a harmony tool and an eyedropper.

Colours can be changed and held in place with lockboxes, and palettes can be saved, loaded, imported and exported. The Pigment Ramp effect creates linear or radial gradients with up to nine colours and nine presets. A web export menu offers RGB, HSL, HSV, HEX and CMYK, and Project Sync ties a composition's assets to a palette so they update automatically. Designers keeping a consistent look across scenes will appreciate it.

Key features

  • Palette generator with reroll
  • Colour harmony tool and eyedropper
  • Lockboxes to hold colours
  • Pigment Ramp gradients up to nine colours
  • Project Sync and multi-format export
