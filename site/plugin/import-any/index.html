What Import Any does

Import Any gathers Blender's separate import menus into a single place, so you do not have to remember which entry handles which format. Find it under Import, Import Any.

You can import several files at once, or copy a file path and press V in Blender to import it from the clipboard. It speeds up bringing in assets from multiple sources. Having everything in one place cuts down the friction of moving assets from different sources into a single scene, particularly when many files are involved.

Key features

  • Unified import menu
  • Batch importing
  • Clipboard path import with V key
  • Many formats in one place
