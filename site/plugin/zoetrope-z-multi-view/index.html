What Zoetrope Z Multi View does

Zoetrope Z Multi View is a collection of nine generators for After Effects, DaVinci Resolve and Premiere Pro that display as many as nine synchronized videos together on one track. Layouts can include borders or run edge to edge.

Border size and color are adjustable, and an image can be panned within each frame when its aspect ratio differs from the source. Drop zones help build the composition, with per-channel track selection in Premiere Pro and After Effects. It also works with multicam angles to produce frame-accurate multi views, useful for editors assembling split screens.

Key features

  • Nine multi-channel layout generators
  • Adjustable border size and color, or none
  • Animatable image panning within each frame
  • Drop zones with per-channel track selection
  • Frame-accurate multi views from multicam footage
