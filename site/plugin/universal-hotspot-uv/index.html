Blender add-on that stamps UVs and materials from a reference atlas mesh onto faces, aligning trims by longest edge.

What Universal Hotspot Uv does

Universal Hotspot UV brings trim-sheet mapping into the Blender 3D viewport. Rather than picking regions on a flat UV grid, you place a reference Atlas Mesh next to your model and choose trims from it directly in 3D.

When a trim is applied, the add-on aligns the longest edge of the face to the longest edge of the trim, so grain and streaks run the right way, and it copies the source material onto the target faces. Selected trims can also be scattered across many faces with random 90-degree rotations. It works in multi-object edit mode and supports Blender 4.0 to 5.2.

Key features

  • Pick trims from a 3D atlas mesh instead of a 2D UV grid
  • Longest-edge alignment keeps grain direction correct
  • One-click material transfer to target faces
  • Mass randomization with 90-degree rotation steps
  • Multi-object edit mode support
