A Blender add-on that loads reference images, assigns them to six views and aligns them to a model box.

What Easy Reference does

Easy Reference simplifies using blueprints and reference pictures in Blender. You import images from a chosen folder and it assigns them to the front, back, left, right, top and bottom views, each named with its view prefix so nothing gets mixed up.

Buttons in the panel switch the viewport and select the matching image, replacing the usual numpad shortcuts. A slider moves the references apart, and a Model Box built from your entered length, height and width helps align every view and scale the images correctly. Modelers working from blueprints or character sheets will set up their reference scenes much faster.

Key features

  • Imports reference images into six views
  • Panel buttons switch the viewport and select the image
  • Slider spreads reference images apart
  • Model Box from length, height and width for alignment
