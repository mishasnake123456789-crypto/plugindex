What Nomad Media Explorer does

Nomad Media Explorer is an extension panel for After Effects and Premiere Pro created for people who already use Nomad. It ties an existing account to the Nomad Platform, a content and asset management system built natively on AWS.

From within the panel you can browse and search stored video, audio and image material and import it straight into your project, so there is no need to download files first or switch to a browser. It is built for subscribers of the Nomad Platform who edit in these two applications and want their library within reach while they cut or animate.

Key features

  • Browse and search Nomad assets in the application
  • Import media directly into projects
  • Connects existing Nomad accounts
  • Handles video, audio and image content
