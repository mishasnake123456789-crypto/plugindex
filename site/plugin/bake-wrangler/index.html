Node-based Blender add-on for texture baking with reusable node trees, background batch baking and channel packing.

What Bake Wrangler does

Bake Wrangler improves texture baking in Blender by letting you describe bakes as node trees, from simple to complex.

Bake trees can be brought into any project and reused, and background batch baking lets you start a job and keep working, and image data can be packed into any channel including Alpha. Technical artists with repeating bake setups gain consistency. Treating bakes as node trees also means a good setup can be shared between projects, and the same structure can serve a whole library of assets.

Key features

  • Node-based bake setups
  • Reusable bake trees
  • Background batch baking
  • Channel packing including Alpha
