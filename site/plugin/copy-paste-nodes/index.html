What Copy/Paste Nodes does

Copy/Paste Nodes is a Blender add-on by david494 that moves nodes through the system clipboard as JSON text. It works in every node editor and has its own key pair, Ctrl+Alt+C to copy and Ctrl+Alt+V to paste (Cmd on macOS), independent of Blender's internal clipboard.

Because nodes become plain text, you can paste them into chats, notes or files and share setups easily. The JSON is kept short by leaving out default fields, so it stays nearly readable, and property names mirror the node tree, with default_value and location_absolute abbreviated to _val and _loc.

Key features

  • Copies nodes as JSON in all node editors
  • Own copy and paste keys, Ctrl+Alt+C and V
  • Uses the system clipboard
  • Compact JSON that omits default fields
  • Shortened property names for readability
