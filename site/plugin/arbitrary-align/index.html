What Arbitrary Align does

Arbitrary Align is a Blender modeling toolkit organized around snap points and reference planes. It lets you line up, match and project geometry from one vertex, edge, face or line to another.

Quick Match uses drag snapping when you hold G, R or S to match position, rotation or scale. Reference planes serve as temporary custom coordinate systems, with grid spacing and subdivisions you can change. It saves effort when fitting parts at odd angles.

Key features

  • Quick Match for position, rotation and scale
  • Snap points on vertices, edges, faces and lines
  • Reference planes as temporary coordinate systems
  • Adjustable grid spacing and subdivisions
