What Parent To Empty does

Parent to Empty is a Blender plugin that makes groups controllable through an empty. It makes an empty at a location you specify and attaches your selection to it.

You can parent all objects to one empty or create an empty per object, and either keep the objects' transforms or transfer them to the empty, created at each origin. It also helps remove parents again. Good for rigging props and organizing scenes.

Key features

  • One empty for all or one per object
  • Keep or transfer transformations
  • Create empty at a specified location
  • Remove parenting
