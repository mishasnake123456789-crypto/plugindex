What Motion Tweaks does

Motion Tweaks is a set of practical scripts for After Effects from Motion Design School, built and used by the school's own motion designers. It collects small tools that otherwise would live in separate files or be rebuilt on each project.

Scripts include Create Cube, Shape Waves, Wiggle, Sine, Trim Paths and Rotate First Vertex, which changes the starting vertex of a path or mask. The wiggle script adds a Z-axis value for Position, Anchor Point and Scale. The panel has a flexible grid, category views, tooltips and a theme that follows the After Effects background color.

Key features

  • Create Cube, Shape Waves, Wiggle, Sine and Trim Paths
  • Rotate First Vertex for paths and masks
  • Z-axis wiggle for Position, Anchor Point and Scale
  • Flexible grid with category views
  • Theme follows After Effects background
