What Fast Snow does

Fast Snow, from CITIGEN, turns a Blender scene into a winter version in one click. It suits scenes with many objects where editing each material by hand would take too long.

The add-on searches every material, inserts a snow node and rearranges the nodes around it. It also copes with geometry-node scenes that expose no obvious shader information. A Remove Snow option clears every node it added. It works in Cycles and Eevee and is MIT licensed.

Key features

  • One-click winter look for whole scenes
  • Inserts snow nodes into all materials
  • Handles geometry-node-based scenes
  • Remove Snow cleanly clears added nodes
