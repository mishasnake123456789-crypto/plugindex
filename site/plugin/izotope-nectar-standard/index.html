What iZotope Nectar Standard does

Nectar Standard is a vocal production plugin from iZotope that can be used in DaVinci Resolve. It contains over a dozen modules and uses intelligent processing, including an unmasking feature that helps a voice sit clearly against other tracks.

The Vocal Assistant offers a customizable starting point, the Voices module builds layered vocals from a preset, and Backer generates background singers in eight styles or from an imported acapella, having been trained on English-language material only. Audiolens can match the tone of a reference. Content creators, podcasters and music producers who want polished vocals without long manual chains will find it a convenient middle option.

Key features

  • Vocal Assistant with customizable starting point
  • Voices module for layered vocals
  • Backer creates background singers in eight styles
  • Audiolens tone matching
  • Vocal unmasking
