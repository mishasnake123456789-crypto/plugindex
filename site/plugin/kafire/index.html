What Kafire does

Kafire cuts down the work of creating fire in Blender. It produces explosion effects and aims to ease the usual process of configuring flame and smoke sims.

Two sample scenes can be downloaded, a documentation page explains the interface, and update 1.1 introduced new emission behavior. VFX artists who need quick, convincing flames without tuning every domain setting can start from it.

Key features

  • Generates fire explosion effects
  • Simplifies fire and smoke simulation
  • Two downloadable sample scenes
  • Interface documentation page
  • New emission behavior in update 1.1
