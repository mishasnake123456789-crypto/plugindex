Creates a curve-driven array from a selected Blender mesh and shapes its volume and density with a brush.

What Flexible Array does

Flexible Array turns a selected mesh into a curve array that you shape by hand. Use the Create button in the toolbar, then adjust volume along the x and z axes with a brush, each controlled separately.

Density along the y axis can be set for every point of the curve. Since version 1.1.0, volume can also be adjusted separately in the plus and minus directions. The array can be built smooth or keep its original shape, and the smooth brush has its own strength setting. It is useful for fences, cables, ropes and chains.

Key features

  • Curve array from selected mesh
  • Brush control for x and z volume
  • Per-point y-axis density
  • Separate plus and minus volume
  • Smooth or original shape
