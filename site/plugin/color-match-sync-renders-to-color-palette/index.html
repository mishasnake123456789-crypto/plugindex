A Blender add-on that adjusts colors in materials, lights or compositor nodes until they hit a target color.

What Color Match - Sync Renders To Color Palette does

Color Match solves the problem of rendered colors drifting from a brand or palette value once lighting and shading are applied. You define a target through a HEX code or color picker, and the add-on tunes RGB components until the result matches.

It works on color properties in materials and compositor nodes and supports both Cycles and Eevee, regardless of the image's color space. The solver uses gradient descent to reduce the error between the actual and target color, with an adjustable step size controlling each iteration. Product visualizers and designers who must hit exact brand colors will find it useful.

Key features

  • Target color via HEX code or color picker
  • Works on materials and compositor node colors
  • Cycles and Eevee support
  • Gradient descent minimizes color error
  • Adjustable step size
