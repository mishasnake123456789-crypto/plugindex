What Fake User Manager[Blender-Addon] does

Fake User Manager collects all data-blocks with Fake User enabled into a single list, opened from File > Clean Up > Fake User Manager.

You can toggle Fake User status from the list, remove entries, and clear unused data from one place. Helps keep files lean and aware of what is retained. The list is a quick way to audit which data is protected from being purged when the file is cleaned.

Key features

  • Central list of Fake User data-blocks
  • Toggle status directly
  • Remove list items
  • Clear unused data
