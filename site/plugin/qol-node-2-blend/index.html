What Qol Node 2 Blend does

Qol Node 2 Blend lets you keep your own node groups as reusable presets in Blender. Select a group, click once, and the preset stays available in later sessions.

When saving you choose the library, category and name, and these choices are remembered for repeat use. Saved presets are retrieved the same way as any prebuilt node. Shortcuts open the preset folder on disk and Blender's Asset file paths so libraries can be added or removed. It suits artists who rebuild the same setups often.

Key features

  • Save any node group as a preset in one click
  • Presets persist across sessions
  • Choose library, category and name
  • Add presets like built-in nodes
  • Quick access to the preset folder and asset paths
