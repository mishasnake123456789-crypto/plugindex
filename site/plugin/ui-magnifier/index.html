What UI Magnifier does

UI Magnifier from Motionist places a live circular magnifying lens beneath your cursor in After Effects and Premiere Pro. It enlarges tiny interface elements so panels and fine details are easier to read.

A shortcut key gives quick access to zoom controls, display scaling is supported, and the lens is meant to feel native inside Adobe panels. It is a lightweight CEP extension with fast setup. Beyond high-resolution displays and detailed editing, it is useful for recording tutorials, screen sharing, in-software demos, training videos and presentations.

Key features

  • Live circular magnifier at the cursor
  • Shortcut key for zoom controls
  • Display scaling support
  • Native feel inside Adobe panels
  • Lightweight CEP extension
