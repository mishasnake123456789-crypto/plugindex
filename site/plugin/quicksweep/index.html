What QuickSweep does

QuickSweep tidies messy projects by moving loose items into the right bins. Its detection system uses metadata, file extensions and keyword scoring to recognize sequences, video footage, graphics and stills, sound effects and music.

A Bin Mapping screen with accordion menus shows the project hierarchy, where you decide each category's destination, and a Sync button refreshes the bin list. Auto-Sweep mode repeats the scan in the background at intervals. Editors who import media constantly and want a consistent structure without manual dragging will benefit.

Key features

  • Sorts sequences, footage, graphics, SFX and music
  • Detects type by metadata, extension and keywords
  • Bin Mapping interface with accordion menus
  • Sync button refreshes available bins
  • Auto-Sweep background mode
