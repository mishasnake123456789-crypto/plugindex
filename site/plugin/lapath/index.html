What LaPath does

LaPath from rifemotion manages corner rounding on shape or mask paths in After Effects. An arc-recognition algorithm spots existing curves, so corners that were previously rounded can still have their radius changed.

A real-time slider engine gives interactive feedback while you refine, and one-click restoration returns a path to its original state using stored metadata, keeping keyframes and speed graphs intact. Controller rigs can be generated for several path properties on a single layer, refresh rate settings balance smoothness against CPU load, and the metadata backup keeps the timeline clean. Designers cleaning up logos and UI shapes will work faster.

Key features

  • Arc recognition for already rounded corners
  • Real-time slider feedback
  • One-click restore preserving keyframes
  • Controller rigs for multiple path properties
  • Refresh rate settings for performance
