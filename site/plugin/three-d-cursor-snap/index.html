What Three d Cursor Snap does

Three d Cursor Snap gives the Blender 3D cursor a drag interaction, similar to moving a gizmo. Hold Shift and right mouse button to pull it around and have it lock onto a vertex, edge or face under the pointer.

It is usable in Object Mode as well as Edit Mode, requires Blender 4.2 LTS or newer and asks for no special permissions. The script is tiny, at roughly 3.5 KB, so it adds little overhead for anyone who places the cursor often.

Key features

  • Shift + RMB drag moves the 3D cursor
  • Snaps to vertices, edges or faces
  • Works in Object and Edit Mode
  • Requires Blender 4.2 LTS or newer
  • Tiny footprint
