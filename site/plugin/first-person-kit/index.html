What First Person Kit does

First Person Kit pairs a Blender addon with a Godot 4.6+ project template so you can build a first-person game from tagged scene objects. The template already includes a first-person player controller.

Objects marked in Blender become gameplay in Godot. Tagged physics objects turn into RigidBodies that can be carried and thrown, and interactive elements include hinged doors, locked doors tied to inventory item IDs and toggleable radios. Level designers can lay out gameplay entirely within Blender.

Key features

  • Blender addon with Godot 4.6+ template
  • Built-in first-person player controller
  • Tags become interactive gameplay elements
  • Physics objects become carryable RigidBodies
  • Hinged and locked doors with inventory IDs
