Connects PBR textures to a Blender material in one click, with a single mapping node and color-coded frames.

What Pbr Connector Pro does

PBR Connector Pro quickly wires up texture sets for an object. Base Color, Roughness, Metallic, Normal, Height/Displacement and AO are hooked up automatically, in Cycles and Eevee alike.

A single Mapping node drives all the textures, which keeps the node editor tidy, and color-coded Frame nodes group each channel, for instance red for Base Color and white for AO. Artists who set up many scanned or downloaded materials can skip repetitive node plumbing.

Key features

  • One-click Base Color, Roughness, Metallic, Normal, Height, AO
  • Single Mapping node for all textures
  • Color-coded frame nodes
  • Works with Cycles and Eevee
  • Tidy node editor layout
