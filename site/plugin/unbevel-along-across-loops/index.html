What Unbevel Along Across Loops does

Unbevel Along Across Loops is a Blender script that undoes bevels on edge loops. Select edges along or across a beveled loop and run it from the Edge menu or the right-click menu.

Along mode collapses the selection along the loop, Across mode collapses it across the loop, and a Whole Beveled Loop option handles the full loop at once. A Bevel Scale control sets the scale of the resulting loop, and when it is zero, Remove Doubles welds the vertices. It helps modelers clean up geometry that was beveled too early.

Key features

  • Along and Across unbevel modes
  • Whole Beveled Loop option
  • Bevel Scale control
  • Remove Doubles welding at zero scale
  • Edge and right-click menu access
