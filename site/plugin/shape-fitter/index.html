Blender add-on that fits spheres, planes, cylinders and ellipsoids to selected mesh vertices in Edit Mode.

What Shape Fitter does

Shape Fitter finds primitive shapes that best match a set of vertices in Blender. It supports planes, spheres, cylinders and ellipsoids, plus a two-condyle cylinder variant, with either Average or Midpoint centering.

Each shape needs a minimum number of vertices: four for a sphere, three for a plane, six for a cylinder and nine for an ellipsoid. Cylinders use the full height span of the selection, the two-condyle version fits across two stored vertex sets, and shapes come with proper local axes. Its roots are in bone and biomechanics work, but it applies elsewhere.

Key features

  • Fits spheres, planes, cylinders and ellipsoids
  • Two-condyle cylinder over two vertex sets
  • Average and Midpoint centering
  • Correct local axes on created shapes
  • Sidebar panel in the 3D View
