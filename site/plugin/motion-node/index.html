Blender node system for motion graphics modeled on Cinema 4D's MoGraph, built from fields, cloners and deformers.

What Motion Node does

Taiga2's Motion Node takes its cue from the way MoGraph works in Cinema 4D: small, flexible blocks you connect rather than one big tool. Generators, selectors, fields, deformers and other pieces together produce motion graphics in Blender.

There are Linear, Spherical, Box and Curve fields, plus cloners such as a Hex Grid Cloner and a Linear Cloner with a Control Instance node, along with Time Offset and Align Object nodes. Two extras come bundled: a material list showing everything in the scene, and Quick Tabs for tucking away add-on tabs.

Key features

  • Linear, Spherical, Box and Curve fields
  • Hex Grid and Linear cloner nodes
  • Time Offset and Align Object nodes
  • Material list helper add-on
  • Quick Tabs helper add-on
