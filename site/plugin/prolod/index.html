Blender add-on that builds LOD meshes under an empty parent, with reduction presets, leaving the base asset intact.

What Prolod does

ProLOD generates levels of detail for a mesh in Blender. Select the mesh, click Make LODs, and the copies are placed under an empty parent while the original stays untouched.

It reads the polygon count and applies a preset curve: PrZ -50% halves polygons exponentially, 10 Step fades linearly to 20%, Aggressive Dive drops quickly and Smooth Glide is balanced. A custom preset lets you tweak reduction values, and the maximum LOD level can be selected. Game artists get consistent LOD chains without repetitive decimation.

Key features

  • Make LODs in one click
  • Original asset left untouched
  • Four base presets for reduction curves
  • Custom preset with editable values
  • Selectable maximum LOD level
