Exports each selected Blender object as its own FBX with auto-naming, centering and optional scene cleanup.

What Batch Saving does

Batch Saving automates the repetitive part of FBX export in Blender. Select several objects and each is written as an individual file.

Smart naming increments file names so nothing already on disk gets overwritten. A single option moves each object to the world center (0,0,0) with its origin at the model's center before export, and optional auto-cleanup removes each object from the scene afterwards. It is a practical tool for game asset kits and modular libraries.

Key features

  • Batch export of selected objects as FBX files
  • Auto-naming that avoids overwriting files
  • Move to world center with origin at model center
  • Optional cleanup after export
  • One-click operation
