What TypoKit does

TypoKit is a collection from MotionCodes that provides animated typefaces for After Effects. Rather than building letter animation yourself, you choose a designed style and use it like a normal font that arrives with motion.

The set includes more than ten clean, modern styles. It runs on a wide span of After Effects versions, from CC 2017 through 2026, and the current version is 1.1.2, released in December 2022. It is helpful to designers who need contemporary title animation with little setup.

Key features

  • 10+ clean, modern animated styles
  • Designed and animated typefaces
  • Compatible with CC 2017 to 2026
  • Version 1.1.2, December 2022
