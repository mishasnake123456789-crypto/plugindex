Procedural 3ds Max object that generates simple houses with roofs, windows, balconies and more, adjustable in real time.

What FAST HOUSING does

Fast Housing creates a FAHouse object in 3ds Max, a procedural mesh that behaves like any other object: it renders, accepts deformers and converts to mesh. Parameters change in real time so houses can be assembled at a simple level for urban backgrounds.

The base shape can be customized with facades B and D controlled by angles, and the roof offers a break point, extensions and asymmetric options. Extra parts include terraces, beams, arches, surrounds, frames, balconies, shutters, roof windows and chimneys, and windows can be added horizontally or vertically. Good for filling out streets and neighborhoods.

Key features

  • Procedural FAHouse object
  • Customizable base shape and roof
  • Terraces, balconies, shutters and chimneys
  • Windows placed horizontally or vertically
  • Real-time editing of all parts
