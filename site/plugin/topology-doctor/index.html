What Topology Doctor does

Topology Doctor is a Blender add-on by Arman-Jangmiri for checking mesh quality in a single click. It inspects the selected mesh, lists the topology problems it finds, then selects each and frames it in view for repair.

The analysis report can be copied to the clipboard as text. It supports Blender 4.2 LTS and newer. Modelers preparing meshes for animation, subdivision or export can use it as a quick audit before moving on.

Key features

  • One-click topology analysis
  • Lists the mesh's flaws
  • Selects and zooms to each flaw
  • Copies the report to the clipboard
  • Supports Blender 4.2 LTS and newer
