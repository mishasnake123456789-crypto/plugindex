What Vertex Magnet Pro does

Vertex Magnet Pro is a precision modeling tool for joining meshes accurately. In Edit Mode it moves selected vertices of one object onto the selected vertices of another, based on how close they are.

The snapping distance can be set from 0.01 m up to 100 m, and smart logic finds the closest vertex. The Activate button prepares the object in one click, and the controls sit in the sidebar under VertMag Pro with real-time helper messages. It suits hard-surface and kitbash work where parts must line up.

Key features

  • Proximity-based vertex snapping between objects
  • Distance adjustable from 0.01 m to 100 m
  • Closest-vertex logic
  • One-click Activate button
  • Sidebar panel with helper messages
