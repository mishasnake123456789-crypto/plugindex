What N-Panel Navigator does

N-Panel Navigator helps you find add-on panels in a crowded sidebar. Press F7 in any editor to open a search popup that filters your installed add-ons by name with instant results.

Clicking a result opens that add-on's N-panel and expands the correct category, and context-aware filtering shows only add-ons relevant to the current editor. If you have dozens of add-ons, it removes the need to scroll through tabs trying to remember where each tool lives.

Key features

  • F7 search popup in all editors
  • Click a result to open its N-panel
  • Expands the correct category
  • Context-aware filtering
