What Helper Manager does

Helper Manager is a support panel for 3ds Max built around point and dummy helpers. It speeds up the repetitive work of building helper hierarchies for rigging and animation, offering several ways to place helpers: at the origin, on a surface, at object pivots, at picked points or on selected sub-object components.

Once helpers exist, they can be attached to a selection through links, constraints or baked keys, and existing bindings can be swapped from one type to another. A hierarchy can be duplicated with new helpers that match the original, including skinned mesh transfer, or replaced by a Bones System with core and extra bones separated. A shared size setting keeps every helper consistent.

Key features

  • Create helpers at origin, surface, pivots, picked points or components
  • Attach helpers via links, constraints or baked keys
  • Convert hierarchy links and constraints between types
  • Duplicate helper hierarchies and transfer skinned meshes
  • Swap a helper hierarchy for an equivalent Bones System
