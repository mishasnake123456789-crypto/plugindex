Uses WhisperX to place a frame-accurate marker on every spoken word of an audio layer in After Effects.

What Cadence does

Built by Étienne Brûlé, Cadence is a tool running inside After Effects that listens to speech and marks it for you. Select an audio layer and it transcribes the track with WhisperX, placing a marker at the exact moment each word begins, which saves hours of manual syncing.

Word boundaries are found at phoneme-level precision, each marker shows its spoken word, and several audio layers can be processed together. Markers can be copied to the current timeline, parent layer or parent timeline, remain non-destructive on the audio layer, and keep sync over hour-long recordings. More than 90 languages are supported, which suits kinetic typography, lip-sync and voiceover-timed infographics.

Key features

  • Word-level forced alignment markers
  • Spoken words shown as marker labels
  • Multi-layer processing in one pass
  • One-click marker sync to timelines
  • 90+ languages supported
