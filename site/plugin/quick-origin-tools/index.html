Lightweight Blender add-on that sets object origins to bottom, top or axis sides in one click, including batches.

What Quick Origin Tools does

Quick Origin Tools places an object's origin at common spots with a click. Options include the bottom, the top, and the positive and negative X and Y sides.

A batch setter applies the change to many selected objects together. Its controls live in a clean N-Panel in the 3D Viewport, and installation uses the usual Add-ons preferences. It works with Cycles and Eevee, supports Blender 4.0 to 4.5, and is released under the MIT license. Handy for game assets that need a predictable pivot.

Key features

  • Origin to bottom, top, +X, -X, +Y or -Y
  • Batch setting across selected objects
  • N-Panel in the 3D Viewport
  • Works with Blender 4.0 to 4.5
  • MIT license
