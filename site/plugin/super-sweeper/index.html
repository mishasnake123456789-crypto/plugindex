What Super Sweeper does

Super Sweeper is a project cleanup script from Akimbo Studio. It sorts compositions and assets, cuts out needless nested folders, and gathers files into folders by type, turning a chaotic project panel into something readable.

Protection settings keep chosen items, including those in locked folders, out of the reorganization. Custom folders store their search term in the folder comment, which prevents duplicates when files are reimported, and a reduce option can ignore comps referenced by expressions. Help tips explain every button and checkbox.

Key features

  • Sorts comps and assets, reducing folder depth
  • Consolidates assets by file type
  • Protects locked folders and chosen items
  • Expression-aware reduce option
  • Re-search using existing folder searches
