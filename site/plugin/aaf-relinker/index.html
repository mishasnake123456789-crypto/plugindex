What AAF Relinker does

AAF Relinker by Alon Shemer is an After Effects script made for the clean-up that follows an AAF import. Through three buttons it reconnects footage to its sources even when the name and duration do not match exactly.

That makes it handy for replacing stock footage and for proxy workflows. Grab Names uses layer names instead of source names for better matches, Similar Names restricts relinking to accurate candidates, and image sequences are supported. There is also an option to link footage by name alone.

Key features

  • Three-button relinking
  • Matches despite slight name and duration differences
  • Grab Names and Similar Names options
  • Image sequence support
  • Link by name only option
