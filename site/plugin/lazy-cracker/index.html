What Lazy Cracker does

Lazy Cracker is a Blender add-on by Casey_Sheep for crack and destruction work. One sidebar panel lets you draw cracks yourself, generate procedural breaks, set up rigid bodies and produce fracture pieces ready to simulate.

Draw Crack Path has you paint a line in the viewport and slices the mesh along it, with settings for width, cutter depth and path detail, plus a choice on whether stray islands become their own objects. Auto Crack makes jagged procedural cracks that you tune by seed, margin, thickness, wiggle, intensity and pattern detail. A set of surface options deals with the freshly cut faces.

Key features

  • Draw Crack Path to cut along painted lines
  • Auto Crack with seed, intensity and wiggle
  • Loose islands can become separate objects
  • Fracture surface controls for new faces
  • Rigid body preparation in one panel
