Blender add-on that outputs mesh faces and curves as clean vector SVG paths through camera projection with hidden-surface handling.

What Svg Exporter does

X W Z's SVG Exporter produces resolution-independent vector artwork from Blender scenes. Geometry is projected through the camera, and hidden surfaces are handled by configurable occlusion detection.

Choose among three occlusion algorithms: an improved painter's algorithm using depth sorting, BVH ray casting, or BSP tree splitting. One or several objects can be exported, with meshes converted to curves, and the path data is optimized and styled as you wish. Illustrators can base vector graphics on 3D models.

Key features

  • Camera-based projection to SVG
  • Three occlusion algorithms
  • Export single or multiple objects
  • Optimized path data
  • Customizable styling
