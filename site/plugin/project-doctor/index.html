What Project Doctor does

Project Doctor, from Medhat Mounier Fayez, is an After Effects panel for rescuing and organizing messy projects. Large jobs accumulate missing links, repeated imports and unlabeled media, and this puts the fixes in one place.

It can relink missing footage from within the panel, clear duplicate assets, and let you browse and tag media without leaving After Effects. Organization is handled from a single focused view. It runs on After Effects 2020 through 2026, and version 1.0.1 resolves a folder browsing problem on macOS and improves folder selection there.

Key features

  • Relinks missing footage
  • Cleans duplicate assets
  • Browse and tag media in the panel
  • Works with After Effects 2020 to 2026
  • macOS folder selection fixes in 1.0.1
