3ds Max rigging utility that builds a library of custom spline control shapes and swaps them onto existing controllers.

What Custom Controls does

Custom Controls helps riggers make animator-friendly controls in 3ds Max. You create your own spline shapes, add them to a personal library, and use them to replace existing objects as animation controllers.

Size, orientation and color can be adjusted for each control. Only the base object is replaced, so modifiers and animation controllers stay as they were, which means a rig can be restyled late in production without breaking it. Licensing is either Node Locked or Float, and opening a scene that already uses the controls does not require a license. Selectable, recognizable shapes make rigs faster to animate.

Key features

  • Create custom spline shapes for controllers
  • Personal library of control shapes
  • Replace existing objects with custom shapes
  • Adjustable size, orientation and color
  • Keeps modifiers and animation controllers untouched
