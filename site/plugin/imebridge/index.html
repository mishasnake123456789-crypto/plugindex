Lets a system Input Method Editor work in Blender's Text Editor and 3D text editing, with the candidate window at the cursor.

What IMEBridge does

IMEBridge links your operating system's own IME (input method editor) with text editing in Blender. Without it, typing Chinese or other IME-based languages in the Text Editor or while editing 3D text is awkward; this add-on makes it behave as you would expect.

The candidate window follows the active text cursor, and a hotkey protection feature flips input to English once the pointer leaves a text area, restoring the previous state when it returns, so shortcuts keep working. It runs quietly in the background once enabled.

Key features

  • Candidate window follows the text cursor
  • Supports the Text Editor plus 3D text edit mode
  • Switches to English input outside text areas
  • Restores previous IME state on return
  • Runs in the background
