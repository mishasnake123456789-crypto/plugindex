What Corona Quick Convert (free) does

Corona Quick Convert is a free script for 3ds Max artists moving scenes over to Corona Renderer. Select the lights and materials you want to change and it converts them in one step, saving the effort of rebuilding each item manually. Materials currently convert to the Corona Legacy format.

Two versions are supplied. The MCR can be bound to a keyboard shortcut, while the MS version fits into Smart Merge or other tools offering a post-script function. Installation is a drag and drop, with no need to remove earlier versions, and the command appears under the D95 DESIGN category. It requires Corona Renderer 4 or higher.

Key features

  • Converts selected lights and materials to Corona
  • Materials convert to the Corona Legacy format
  • MCR version assignable to a shortcut
  • MS version for post-script use in Smart Merge
  • Drag-and-drop installation
