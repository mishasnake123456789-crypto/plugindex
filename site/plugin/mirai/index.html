What mirAI does

mirAI is a scripting assistant by nebulaf that lets After Effects users describe what they want in plain language and get working scripts and expressions back. It is powered by Google Gemini and OpenRouter, giving access to more than 300 models through one API key, with custom OpenAI-compatible and local servers also possible.

A short word can generate a point cloud, and AI AUTO builds a whole scene. Stackable motion tags add turbulence, swirl, explosion, trails and more, particles can follow a camera, layer path or mask, and text commands align layers to markers. Storyboard mode morphs cuts in order, and mirParticle and Design Variations extend it further.

Key features

  • Natural language prompts to scripts and expressions
  • 300+ models through one API key
  • Stackable motion tags for particle effects
  • Particles following cameras, layer paths and masks
  • Storyboard mode and Design Variations
