What Super Morphings does

Super Morphings is a plugin from Motion Design School for turning one object into another inside After Effects. It handles single morphs and multiple morphs across many objects at once, applied in one click.

Trails and Slicer effects can be added, customisation is straightforward, and holding Ctrl or Meta switches to linear morphing. It is helpful for icon transitions, logo changes and scene-to-scene shape transformations. Motion designers who want smooth morphs without painstakingly matching path vertices get a quick route.

Key features

  • One-click object morphing
  • Multiple morphs across many objects
  • Trails effect
  • Slicer effect
  • Linear morphing with Ctrl or Meta
