What Unity Style Walk Navigation does

Unity Style Walk Navigation is a Blender plugin that makes flying through the 3D Viewport feel like the Unity Editor. It substitutes the built-in Walk mode with right-click first-person navigation and gentle coasting after you let go of the keys.

Exponential smoothing applies to acceleration, braking and turning. The scroll wheel changes movement speed on the fly and the value is saved automatically, and trackpad users are supported as well. It is aimed at people moving between Unity and Blender who prefer one navigation habit.

Key features

  • Right-click first-person navigation
  • Smooth inertia for acceleration, braking and turning
  • Scroll wheel adjusts speed and remembers it
  • Trackpad support
