What Batch Comp Normalizer does

Batch Comp Normalizer is a collection of batch utilities from NickolasM for After Effects. It applies the same edits to selected compositions or entire folders, which saves time when a project contains dozens of similar comps.

The tools are Normalize Size, Effect Sync, Text Sync, Text Find/Replace, Color Sync, Layer Cleanup and Time Tools. Duplicates with suffixes allow safe testing before you modify originals. It scans the work area and ignores full-frame backgrounds so crops focus on the subject, skips locked layers and animated or expression-driven properties, and produces detailed reports on what changed and what was skipped.

Key features

  • Seven batch tools for comps
  • Works on selections or whole folders
  • Non-destructive duplicate mode
  • Text Find/Replace with whole-word option
  • Reports on changes and skipped items
