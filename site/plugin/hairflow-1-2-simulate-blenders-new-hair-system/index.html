What Hairflow 1.2 - Simulate Blender's New Hair System does

HairFlow animates Blender's new hair system. Built on simulation nodes, it moves single strands on any curves object and holds on to the shape of the original hair.

Wind effects have independent strength and turbulence controls, and gravity is adjustable. Character artists can add natural motion to groomed hair without reverting to legacy particle hair. Working on any curves object means grooms made with the new system can be animated directly, with hair responding naturally to gravity and wind.

Key features

  • Strand animation on curves objects
  • Respects original hair shape
  • Wind with strength and turbulence
  • Adjustable gravity
