What Modeler Pro 1.9 - Toolkit Addon does

Modeler Pro is a general-purpose toolkit for Blender modelers, centered on bevel control and modifier management. Bevel weight gradients apply curves of varying curvature, noise and size to bevel weights, run from a hotkeyable pie menu and needing a bevel modifier set to the weight limit method with an active edge.

A bevel weight pie menu sets exact values, while modifier toggle menus, collection helpers, Mirror Modifier Pro and savable bevel modifier presets round out the set. Hard-surface artists who iterate on bevels and modifier stacks will find the shortcuts save time.

Key features

  • Bevel weight gradients with curve types
  • Bevel weight pie menu
  • Modifier toggle menus and collection helpers
  • Mirror Modifier Pro
  • Savable bevel modifier presets
