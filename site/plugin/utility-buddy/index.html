What Utility Buddy does

Utility Buddy is a project-wide search and cleanup tool for After Effects. It locates fonts, expressions and effects wherever they hide and lets you change them in bulk, which saves hours when inheriting or tidying a messy file.

An Apply To setting limits actions to the whole project, the active comp or only selected layers. You can remove, disable or enable effects and styles across many layers, strip expressions, or deal with layers using a particular font. Finding an expression jumps straight to the script itself, and a color search is included.

Key features

  • Apply To scope: project, active comp or selection
  • Mass remove, disable or enable effects and styles
  • Remove layers using a given font
  • Mass remove expressions
  • Jump directly to a found expression
