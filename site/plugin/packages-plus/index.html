Installs and manages extra Python packages from PyPI inside Blender, with a choice of install location.

What Packages Plus does

Packages Plus handles Python libraries for Blender scripts and add-ons. Packages come from the PyPI repository and can be placed in the Blender directory, the user home directory or a custom external folder.

The Check button tells you whether a package is installed already and where it lives. This removes the command-line steps normally required. Technical artists and add-on developers who rely on libraries like NumPy or imaging packages will find it much easier.

Key features

  • Installs packages from PyPI
  • Blender, home or custom destination
  • Check button detects installed packages
  • Shows installation location
