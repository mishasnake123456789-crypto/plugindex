What Custom Output Path does

Custom Output Path is a Blender add-on by Shuimeng that lets you define output file paths using placeholders. It was made for compositor users who rename outputs frequently and want consistent naming across renders.

Placeholders include the active camera name, so files can be labeled automatically, and the approach helps avoid accidentally overwriting results when images are output continuously. The add-on is compact at around 22 KB, requires no special permissions, and supports Blender 4.5 LTS and newer.

Key features

  • Placeholder-based output path naming
  • Active camera name placeholder
  • Standardizes compositor output names
  • Helps prevent accidental overwrites
  • Requires no special permissions
