Blender add-on that moves object origins to selected faces, even across several objects.

What Set Origin Plus does

Set Origin Plus places an object's origin on a selected face in one step. It saves the usual detour of snapping the cursor and then setting the origin.

It works on one object or many at once, and can put origins at the bottom of the faces of selected objects. It is compatible with Blender 2.8 through 3.0, includes documentation, and is distributed under a Creative Commons license.

Key features

  • Origin set from selected faces
  • Single or multi-object operation
  • Origins at the bottom of faces
  • Blender 2.8 to 3.0
