What Level Of Detail Generator does

Level Of Detail Generator is a Blender plugin that builds LOD versions of a model in a single click. This helps prepare assets for games and real-time use.

A Reset Transform button restores the object's original transform values, and Apply Transform makes the current transform the new default. Documentation is included. Practical for developers optimizing scenes. Generating the variants automatically avoids repeating decimation manually for each distance level when preparing assets for engines.

Key features

  • One-click LOD creation
  • Reset transform button
  • Apply transform button
  • Documentation included
