A Blender studio kit that adds customizable procedural backdrops such as L, S and C curves.

What Backdroper does

Backdroper helps set up photography-style backdrops in Blender. One click adds an editable studio background to your scene, which suits product shots, character turntables and any render that needs a clean surround.

Five procedural backdrops are included: L Curve, S Curve, C Curve, Corner and Cylinder Stand. Presets offer clean styles or you can build your own, and elements remain fully editable, parented and organized for a non-destructive workflow. It is lightweight with render efficiency in mind, and works in both Cycles and Eevee. Product and portfolio renderers will get consistent studio looks quickly.

Key features

  • Five procedural backdrops
  • One-click studio setup
  • Presets or custom builds
  • Non-destructive, parented elements
  • Cycles and Eevee support
