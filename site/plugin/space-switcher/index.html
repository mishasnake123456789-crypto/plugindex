What Space Switcher does

Space Switcher is an animation add-on for Blender. It creates a proxy sharing a chosen bone's position, orientation and name, so the bone's animation can be offset with no manual keyframing.

You can enable or disable the switch to temporarily release the constraint, clear constraints, show or hide manipulation proxies and set a baking range. Useful for riggers and animators handling parenting changes. This helps with tasks such as handing props between hands or changing a control's parent without breaking the existing animation.

Key features

  • Proxy matches selected bone
  • Enable or disable space switch
  • Clear constraints
  • Bake range control
