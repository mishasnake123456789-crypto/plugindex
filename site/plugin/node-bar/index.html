Adds shader nodes in Blender from a bar of recognizable icons instead of search or menus.

What Node Bar does

Node Bar offers an icon bar for the shader editor. Each icon is a recognizable node with a tooltip, so you do not need the Search field or drop-down menus.

Click and drag from an icon to add a node, show the bar with a hotkey, resize it with the middle mouse and configure it from the Shader Editor N-Panel. A quicker way to build materials for visual thinkers. Visual recognition speeds up building materials, as you can find nodes by appearance rather than remembering names.

Key features

  • Icon-based node access with tooltips
  • Drag out nodes from icons
  • Hotkey to show the bar
  • Configured in the N-Panel
