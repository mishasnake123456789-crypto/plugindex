What Displacer Pro does

Displacer Pro is a free After Effects plugin that warps a layer using another layer as a displacement map. It is aimed at motion designers who want smoother and more flexible results than the stock displacement tools provide.

Displacement can be driven by translation, rotation and scale, and the map can be read by hue, saturation, luma or red channel. Gamma, softness and easing controls refine how the map is interpreted, while temporal motion blur with iterations keeps movement smooth. Chromatic aberration and built-in anti-aliasing are included. Processing is GPU accelerated at 32 bits per channel, with Multi-Frame Rendering and native Apple Silicon support.

Key features

  • Translate, rotate and scale displacement
  • Map modes: hue, saturation, luma and red
  • Gamma, softness and easing adjustments
  • Temporal motion blur with iterations
  • GPU accelerated, 32bpc, Apple Silicon native
