A Blender add-on that organizes bevels into named layers, each with its own settings and live edge visualization.

What Multibevel does

Multibevel brings structure to bevel work in Blender. Instead of juggling one weight map, bevels are placed in named layers, each with its own settings, and a live visual mode shows which edges belong to which layer so you can adjust them in the viewport.

Custom edge attributes are created automatically and assigned to the Bevel Modifier's weight input. Width and segments can be changed in the panel, edges with existing attributes can be selected, attributes can be removed with a click, and presets can be saved. Hard-surface modelers who need different bevel sizes across a model will find it organized.

Key features

  • Named bevel layers with separate settings
  • Live visual edge editing
  • Automatic edge attributes for the Bevel Modifier
  • Select or remove attributes in one click
  • Savable presets
