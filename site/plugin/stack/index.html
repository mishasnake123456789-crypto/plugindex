A single Shader Editor node that stacks textures, giving each layer its own blend mode, opacity and mask, as Photoshop does.

What Stack does

Stack adds one node to Blender's Shader Editor for combining textures in a layered way. Use as many layers as required and mix them with a familiar approach borrowed from image editors.

Ten blend modes are available, among them Lighten, Darken, Difference, Soft Light, Overlay, Screen, Subtract, Add, Multiply and Normal, and each layer has its own opacity and mask. Material artists can build complex surfaces without long chains of mix nodes.

Key features

  • Unlimited layers in a single node
  • Ten blend modes
  • Per-layer opacity
  • Per-layer masking
