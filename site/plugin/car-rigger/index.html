What Car Rigger does

Car Rigger by Stellart sets up vehicle rigs in Blender quickly. It supports cars, trucks, buses, trains, boats, planes and more.

Physics simulation and baking are built in, along with animation tools and a vehicle path system. Presets exist for boat, car, jeep or buggy, limousine, plane, sports car, trailer, truck or bus or train, and van. Animators who need believable vehicle motion can skip building the controls and constraints themselves.

Key features

  • Rigs many vehicle types in a few clicks
  • Physics simulation and baking
  • Presets for cars, boats, planes and trucks
  • Animation tools
  • Vehicle path system
