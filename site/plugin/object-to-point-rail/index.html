What Object To Point Rail does

Object To Point Rail places mesh objects along a path created from selected edges. The rail sets both the position and the direction of each object, and no modifiers are involved; the rail itself is not a curve.

Spacing is equal along the rail's length, and it works with three-dimensional rails. Settings cover swapping start and end, point amount or fixed distances, cross size and the maximum number of points shown. It suits fences, lamp posts, railings and similar repeated items.

Key features

  • Rail from selected edges
  • Equal spacing along 3D rails
  • No modifiers or curves
  • Point amount or fixed distance
