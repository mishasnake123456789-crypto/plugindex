What Typst Importer does

Typst Importer is a Blender add-on by Jan-Hendrik-Müller that turns math equations and code blocks into scene objects. You write content using Typst, for example at typst.app, place it in a Blender Text document, and then import the result as an object using the side panel.

It is built for Windows, macOS on Apple Silicon and Linux, supports Blender 5.2 LTS and newer, and is released under the GNU GPL v3 or later. It asks for file permission to import data files from disk. Useful for educational and technical animations that need neat typeset formulas.

Key features

  • Renders Typst equations and code blocks
  • Imports from a Blender Text document
  • Controlled from the side panel
  • Packages for Windows, Apple Silicon Macs and Linux
  • Supports Blender 5.2 LTS and newer
