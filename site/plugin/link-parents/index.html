What Link Parents does

Link Parents is a Blender add-on by Trukas for handling parenting of objects and bones. A Link Parent command in the Link/Transfer Data menu (Ctrl+L) copies over the parent of the active object along with its transformation matrix.

Object, bone and vertex parenting are supported. The Matrix Parent Inverse is exposed in the object's Relations panel, where it can be edited through transformation properties, and the matrix can be copied and pasted between objects. It also deals with bone constraint inverse matrices, easing rig repairs.

Key features

  • Link Parent entry in the Ctrl+L menu
  • Object, bone and vertex parenting
  • Parent inverse exposed under Relations
  • Copy and paste the parent inverse
  • Handles bone constraint inverse matrices
