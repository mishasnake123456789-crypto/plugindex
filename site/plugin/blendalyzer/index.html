What Blendalyzer does

Otago Computing's Blendalyzer makes a single interactive HTML file describing the contents of a blend file and opens it in your browser. It charts how objects connect with materials, images, collections, views, sounds, libraries, scenes, actions and armatures.

Click an element to isolate it and reveal its direct links, and filter collections, materials and images into a focused view. A report on data usage is included. Technical artists inheriting a large scene can understand dependencies before cleaning it.

Key features

  • Interactive HTML map of the blend file
  • Opens automatically in a browser
  • Click to isolate an element and its links
  • Filter collections, materials and images
  • Shows relationships across data types
