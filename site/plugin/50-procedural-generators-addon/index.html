What 50 Procedural Generators Addon does

The 50 Procedural Generators Addon brings over fifty Geometry Nodes setups into Blender through a sidebar panel. It registers an asset library and lists all setups so you can append one to the active object.

Install it as a ZIP in Preferences, use Add Asset Library to register the library, List Geometry Nodes to fill the dropdown and Append to Active Object to apply a setup. A broad starter kit for procedural effects.

Key features

  • 50+ Geometry Nodes effects and generators
  • One-click asset library registration
  • Dropdown list of setups
  • Append to the active object
