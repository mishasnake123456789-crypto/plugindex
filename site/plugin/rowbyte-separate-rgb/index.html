What Rowbyte Separate RGB does

Separate RGB from Rowbyte is a quick route to chromatic aberration in After Effects and Premiere Pro. It distorts the red, green and blue channels individually, which creates the colour fringing seen on cheap or vintage lenses.

The picture boundaries grow automatically so edges aren't cropped, a single channel can be blurred, and each channel can be blended with the original image. Multi-frame rendering is supported in After Effects, Apple Silicon in Premiere Pro, and both Mac and Windows are covered.

Key features

  • Per-channel lens distortion
  • Automatic boundary growth
  • Blur any single colour channel
  • Blend each channel with the original
  • Multi-frame rendering and Apple Silicon support
