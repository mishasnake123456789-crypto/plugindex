What Gear does

Gear is a script by Swordslayer that adds an involute spur gear primitive to 3ds Max. Instead of modeling teeth by hand, you create a gear object whose shape follows the involute profile, including undercut at the tooth base, which gives mechanical parts a believable form.

The resulting mesh is built entirely from quads, so it subdivides and edits cleanly. The code ships as a single small gear.ms file that is unencrypted and open, so technical artists can read it, modify it or build further tools on top. It is useful for anyone who needs procedural gears for mechanisms, machinery or product visualization inside 3ds Max.

Key features

  • Involute spur gear primitive
  • Tooth undercut on generated gears
  • All-quad topology
  • Unencrypted, editable script code
  • Single gear.ms file installation
