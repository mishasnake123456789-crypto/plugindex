What Quick Chromatic Aberration 3 does

Quick Chromatic Aberration 3 is a no-cost After Effects plugin that recreates the colour fringing that real camera lenses produce. It shifts and distorts the colour channels so flat footage picks up a more optical, slightly imperfect look.

Each channel can be translated, rotated, scaled and blurred separately, while a 360-degree hue control lets you aberrate any colour. Lens distortion and skew can run over adjustable iterations. It renders on the GPU in 32 bits per channel, supports Multi-Frame Rendering and Apple Silicon natively, and offers transparency controls, automatic buffer expansion and repeating edge pixels.

Key features

  • Per-channel translate, rotate, scale and blur
  • 360-degree hue control for any colour
  • Lens distortion and skew, with adjustable iterations
  • GPU accelerated, 32bpc, Multi-Frame Rendering
  • Auto buffer expansion and edge pixel repeat
