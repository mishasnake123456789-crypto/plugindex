What Script-Shelf does

Script-Shelf places a shelf above Blender's 3D view for keeping reusable Python scripts within reach. Scripts are grouped into categories, so a growing personal toolbox stays organized.

An Add to Shelf button in the text editor registers a script with one press. The script directory is configured in Blender's settings, and any scripts you add or remove manually in that folder appear in the shelf. Documentation is included. It is practical for technical artists and anyone who writes small utilities and wants to run them without opening the text editor each time.

Key features

  • Shelf above the 3D view for scripts
  • Categories to organize scripts
  • Add to Shelf button in the text editor
  • Configurable script directory
  • Documentation included
