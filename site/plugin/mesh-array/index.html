What Mesh Array does

Mesh Array, from Hydrocallis, improves object arraying in Blender. Its adjusted operators can be applied directly in mesh edit mode instead of requiring a separate object workflow.

A preset feature lets you return to earlier settings, which is useful when experimenting with spacing and counts. Documentation is included and the add-on is distributed under the GPL.

Key features

  • Improved array operators
  • Works directly in mesh edit mode
  • Presets to restore previous settings
  • GPL licensed with documentation
