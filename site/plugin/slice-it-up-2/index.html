What Slice it Up 2 does

Slice it Up 2 is a Rendertom tool for cutting layers into pieces without damaging the source. The slicing is procedural, so settings can be changed at any time, and the number of slices is not limited.

It works in both 2D and 3D space. Slice width or height can be randomized, distribution can be random or linear, and the axis direction of each slice can vary. A previous seed can be regenerated to recover a look, and the slice mask can be shrunk or expanded. It is useful for glitchy reveals, transitions and layered title effects.

Key features

  • Unlimited slices in 2D and 3D
  • Randomize width, height and axis direction
  • Random or linear distribution
  • Regenerate previous seeds
  • Shrink or expand the slice mask
