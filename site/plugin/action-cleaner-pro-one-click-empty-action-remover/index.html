What Action Cleaner Pro - One-Click Empty Action Remover does

Action Cleaner Pro tidies animation data in Blender by removing actions that hold nothing or are no longer used.

A scan summary reports how many actions are empty, deletable and protected, and Fake User protection shields the ones you want to keep. F5 opens the cleanup tools quickly. The interface is lightweight and beginner-friendly, and the add-on runs fully offline with no tracking. Useful for animators, game developers and riggers.

Key features
