What Cult Translator does

Cult Translator is a localization tool from Cult Extensions that translates text layers without leaving After Effects. No external apps, spreadsheets or copy-and-paste are involved, and formatting is preserved.

Translations are context aware, with an optional context field to guide the AI, and more than 100 languages are supported. Batch translation updates selected and nested layers automatically. It runs on macOS and Windows using the system CURL. Agencies, language providers, editors and marketing teams producing multi-market video can use it.

Key features

  • Context-aware AI translation
  • Preserves text formatting
  • 100+ languages supported
  • Batch translation including nested layers
  • Runs inside After Effects on macOS and Windows
