Tool Launcher

Developer: Rune Gangsø

FreeAfter Effects
Download Free

An After Effects panel that runs scripts, menu commands and expressions from searchable lists and toolbars.

What Tool Launcher does

Tool Launcher organizes the many scripts and commands an After Effects artist accumulates. Load folders of scripts into a searchable list or custom toolbars, and open script interfaces in pre-docked panels from anywhere.

Three panel types cover interfaces, lists and duplicable toolbars. Tools can be scripts, inline JavaScript, expressions, menu commands, OS commands, effects or animation presets. Buttons can have icons, and config files with modifier keys can be shared and copied between computers. Settings live in one window, and ft-toolbar configs can be imported.

Key features

  • Searchable script lists and custom toolbars
  • Pre-docked panels for script interfaces
  • Supports scripts, expressions, menu commands, effects and presets
  • Icons and shareable config files
  • Imports ft-toolbar configs
