What Orbit Script does

Orbit Script is Hugo Castetbon's tool for After Effects that makes a layer circle around a point. It sets up the motion for you instead of requiring manual expressions or null rigs, and the result is predictable.

Radius, speed and angle are adjustable, and smart look-at options control how the layer faces as it travels. Output is clean and fully keyframe-ready, so you can refine it afterwards by hand. It works with After Effects 2020 through 2026 and suits planets, satellites, badges and decorative elements.

Key features

  • Orbital animation on any layer
  • Radius, speed and angle controls
  • Smart look-at behavior
  • Keyframe-ready output
