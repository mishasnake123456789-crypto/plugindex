What Shading + does

Shading + by 1P2D consolidates viewport shading controls into a single pie menu in Blender. You can change the render engine, use Matcap and Solid Shading presets and handle HDRIs without opening several panels.

The pie menu switches between Workbench, EEVEE and Cycles, and Ctrl+click changes the engine without altering the shading mode. Alias shaders arrive as Matcaps along with Toon-like Matcap presets. It benefits modelers and look-dev artists who frequently flip viewport display modes.

Key features

  • Pie menu for Workbench, EEVEE and Cycles
  • Ctrl+click changes engine only
  • Alias shaders as Matcaps
  • Toon-like Matcap presets
  • HDRI management
