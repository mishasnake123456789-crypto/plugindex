What JustScrollit does

JustScrollit by RojusScripts creates credit rolls in After Effects without manual layout. You can start from scratch or import a raw text file through Smart Import, then configure the scroll's output settings.

A Reformat option and support for other formats help prepare the text, images can be added to the roll, and the credit list can be exported to edit outside After Effects. A reduce flicker option smooths the scrolling text. It is handy for film endings and project wrap-ups.

Key features

  • Credit rolls from scratch or text files
  • Smart Import
  • Scroll output settings
  • Image support
  • Reduce flicker option and list export
