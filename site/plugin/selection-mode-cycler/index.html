Selection Mode Cycler

FreeBlender

Blender add-on with mouse button keybinds for cycling mesh selection modes in Edit Mode.

What Selection Mode Cycler does

Selection Mode Cycler adds a quick way to rotate through vertex, edge and face selection in Blender's Edit Mode. By default, Mouse5 steps forward and Mouse4 steps backward, so a mouse with side buttons becomes a mode switcher.

Since version 1.1.0 it also supports UV editing, including UV sync selection, and the keymaps live in the Window category rather than Mesh. No special permissions are needed, and installation works by drag and drop or from disk.

Key features

  • Cycle selection modes forward and backward
  • Mouse5 and Mouse4 default bindings
  • UV editing and sync selection support
  • Keymaps stored under Window
  • Drag-and-drop installation
