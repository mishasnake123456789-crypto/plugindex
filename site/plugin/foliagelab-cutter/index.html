What Foliagelab - Cutter does

FoliageLab Cutter reduces the cost of leafy cards by fitting geometry tightly to opacity maps. Each actor gets a hull polygon drawn right in the Image Editor, and inner Steiner points steer the triangulation.

Per-hull settings include edge direction, pivot, angle and vertex count. It also traces high-poly silhouettes, builds complete LOD chains and creates billboard-style cross meshes. Real-time artists reduce overdraw and polygon counts for vegetation. The output helps keep vegetation light for real-time engines, where overdraw and polygon count are common concerns.

Key features

  • Draw hull polygons in the Image Editor
  • Steiner points guide triangulation
  • Trace high-poly silhouettes
  • Build full LOD chains
  • Billboard-style cross meshes
