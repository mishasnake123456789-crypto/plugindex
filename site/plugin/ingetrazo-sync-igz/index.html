What IngeTrazo Sync (.igz) does

IngeTrazo Sync, by 3dvic, imports IngeTrazo (.igz) documents into Blender, lets you reload them when they change, and returns UVs to the source. It is listed under Import-Export.

The add-on is open source under GPL-3.0-or-later and requires Blender 5.0.0 or newer.

Key features

  • Import IngeTrazo documents
  • Reload updated files
  • Send UVs back
