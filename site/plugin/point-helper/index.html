What Point Helper does

Point Helper by Chuggnut makes a point helper in 3ds Max lined up with two vertices you have selected. Select the vertices, press the button, and the helper appears aligned to them.

The axis setting can be changed to pick, which lets you choose the point object to work with. It is a small utility that saves manual placement and rotation, useful for riggers who need helpers sitting exactly along edges or between points on a mesh. It is free, at version 2.3.5, and available through the ScriptSpot library.

Key features

  • Creates a point helper aligned to two vertices
  • One button operation
  • Axis can be set to pick the point object
  • Version 2.3.5
