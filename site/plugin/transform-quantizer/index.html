What Transform Quantizer does

Transform Quantizer rounds or truncates position, rotation and scale values to a chosen threshold, and aligns objects, mesh vertices and curve vertices to a grid with adjustable spacing.

Each X, Y and Z axis has its own threshold. In Edit Mode, vertex positions can be quantized per axis, and large thresholds produce an effect similar to voxelizing a shape. Bezier curve vertices are supported too. It is helpful for modular design and stylized low-resolution looks.

Key features

  • Per-axis thresholds
  • Objects, mesh and curve vertex quantizing
  • Voxel-like effect at large values
  • Position, rotation and scale
