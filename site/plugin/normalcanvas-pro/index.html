GPU texture editor in Blender's Shader Editor that makes normal maps and PBR textures with a local AI depth model.

What Normalcanvas Pro does

NormalCanvas Pro turns ordinary images into PBR material inputs without leaving Blender's Shader Editor. Processing runs on the GPU, so filters and previews respond in real time.

It offers rectangle, circle and lasso selections with clone and heal, plus non-destructive blur, levels with a histogram and feathering. The normal map generator simulates bevels and exposes intensity, edge sharpening and micro-detail controls, with a one-click switch between OpenGL and DirectX output. A locally run Depth Anything V2 model estimates depth from a flat image, so no cloud service is needed.

Key features

  • Rectangle, circle and polygon lasso selection with clone and heal
  • Real-time Gaussian blur, levels and feathering
  • Normal map generator with bevel simulation
  • OpenGL and DirectX output toggle
  • Local AI depth estimation
