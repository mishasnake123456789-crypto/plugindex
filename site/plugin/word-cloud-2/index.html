What Word Cloud 2 does

Word Cloud 2 from Froggy Team builds word clouds from text, with animation in After Effects and support in Photoshop and Illustrator. It includes a color themes editor that handles multiple fonts, passes and layers.

A text and HTML parser is provided, with 44 stop-word languages and 124 Wikipedia search languages. Layout uses three filling algorithms and four filling direction algorithms. Results can be exported as SVG or as PNG up to 8K. Drag and drop, pseudo effect controls and baking or unbaking of expressions are included, and the font list shows installed fonts correctly.

Key features

  • Color Themes Editor with multi fonts and layers
  • Text and HTML parser with 44 stop-word languages
  • 3 filling and 4 direction algorithms
  • SVG and PNG export up to 8K
  • Bake and unbake expressions
