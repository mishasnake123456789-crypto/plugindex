What Mt. Mograph Wander does

Mt. Mograph Wander is an extension for After Effects and Premiere Pro that finds and imports media from a huge searchable library of over 62 million files. It covers GIFs, memes, emojis and social media content, and downloaded items can be sorted and added straight to the project.

A Giphy library section allows GIFs and stickers to be dropped onto timelines in one click. The interface is compact and customizable. It supports After Effects, Premiere Pro and Illustrator CC 2021 and later, helping editors source quick visuals without leaving the app.

Key features

  • Search across 62 million media files
  • Download, sort and add media to the project
  • Giphy GIFs and stickers in one click
  • Memes, emojis and social media content
  • Compact, customizable interface
