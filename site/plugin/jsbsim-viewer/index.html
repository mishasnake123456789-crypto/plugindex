What JSBSim Viewer does

JSBSim Viewer helps people working with JSBSim flight dynamics models. It imports the aircraft XML data into Blender and plots the defined nodes, points and reference locations in 3D space.

This lets you see how aerodynamic and structural points sit relative to each other, inspect the geometric layout of an aircraft and debug the FDM configuration visually. It is a compact 6.6 KB extension released under GPL v3.0 or later.

Key features

  • Imports JSBSim FDM aircraft XML
  • Plots nodes, points and reference locations
  • Shows aerodynamic and structural layout
  • Helps debug FDM configurations
  • Compact 6.6 KB extension
