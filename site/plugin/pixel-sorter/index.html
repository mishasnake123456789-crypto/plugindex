What Pixel Sorter does

Pixel Sorter creates streaked, glitchy sorted-pixel looks in After Effects, DaVinci Resolve and Premiere Pro. A single universal licence also covers Nuke and Photoshop.

There are multiple sorting modes, including angle sorting and a stretch mode, and a gradient output option and noise, adjustable by offset, length, randomness and feathering. Block and resolution settings produce chunkier pixels, constraint masks restrict where sorting occurs, and a cycle option with an infinite angle control helps animation. It supports 16 and 32-bit colour with a multi-threaded core, and Simple Mode hides advanced settings.

Key features

  • Multiple sort modes including angle and stretch
  • Gradient output and noise controls
  • Constraint masks
  • Cycle option for animation
  • 16/32-bit colour, multi-threaded, Simple Mode
