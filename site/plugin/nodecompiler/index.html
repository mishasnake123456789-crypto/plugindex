Blender add-on that checks whether two node trees are equal and links equivalent materials, geometry node setups and groups.

What Nodecompiler does

Nodecompiler compares two node trees in Blender and reports if they are equivalent. That lets it merge duplicated setups into one.

When trees match, it can link equivalent materials, geometry node modifiers and node groups, and it helps tidy node trees by reusing identical topology. It supports Blender 2.93 through 4.1, ships with documentation and is GPL licensed. Artists inheriting scenes full of duplicate materials benefit most. This helps reduce file clutter and keeps node-heavy projects easier to maintain.

Key features

  • Compares node trees for equality
  • Links equivalent materials and node groups
  • Links equivalent geometry node modifiers
  • Reuses identical topology
  • Supports Blender 2.93 to 4.1
