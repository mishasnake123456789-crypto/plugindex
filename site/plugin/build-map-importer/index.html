What BUILD Map Importer does

BUILD Map Importer brings level files from the BUILD engine into Blender, making old-school game maps available for viewing, reference or reworking. Author Jens.Ne offers it free under GPL v3 or later.

Installation is simple: drop the file onto Blender or choose install from disk. It needs Blender 4.2 LTS or newer. The 1.4.1 release throttles how often the progress display refreshes, which fixed crashes seen in some situations. Anyone converting classic BUILD levels into modern 3D workflows is the natural audience.
