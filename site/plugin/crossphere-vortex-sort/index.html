What CROSSPHERE Vortex Sort does

Vortex Sort by CROSSPHERE Koizumi is an After Effects plugin that reorders pixels into a spiralling vortex pattern. A Twist parameter allows both radial and rotational sorting.

Processing can be done pixel by pixel or in larger, customisable blocks, and the sorting order can be controlled by a chosen layer. It supports After Effects 16.0 and later. Artists making glitch-art swirls, abstract transitions or pixel-sorting looks get a distinctive variant beyond linear sorting.

Key features

  • Pixel sorting into a vortex pattern
  • Twist for radial and rotational sorting
  • Pixel or block-based sorting
  • Sorting order controlled by a layer
  • After Effects 16.0 and later
