What Graph Master 3 does

Graph Master 3 creates charts and graphs in After Effects that come already animated. Setups include bar, spline, pie, finance, line, radar and fully procedural types, covering most data-visualization needs for explainers and reports.

A quick data entry form speeds up input, an expandable preset library provides starting points, and several shading types change the look. Graphs align automatically and accept any number of data points. The interface is user-friendly with an open structure that allows adjustment, which helps infographic and presentation designers.

Key features

  • Bar, spline, pie, finance, line, radar and procedural graphs
  • Quick data entry form
  • Expandable preset library
  • Automatic alignment and animation
  • Any number of data points
