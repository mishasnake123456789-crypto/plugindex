What DirectX X Format (.x) does

DirectX X Format, by SaintBaron, handles the legacy .x model format in both directions in Blender. Meshes, materials, textures, armatures with skin weights and keyframe animation are all handled.

It reads text and binary files, including MS-ZIP compressed and 32 or 64-bit float variants. Import builds Principled BSDF materials, tries several image extensions, creates armatures out of the frame hierarchy, fills vertex groups using skin weights and builds F-curve actions. Rest pose can come from bind pose or frame hierarchy, the export dialog lets you edit texture paths, and verbose logging aids debugging. Useful for fragMOTION and Bugsnax models.

Key features

  • Import and export of .x geometry and materials
  • Armatures, skin weights and keyframe animation
  • Text, binary and compressed variants
  • Two rest pose modes
  • Editable texture paths on export
