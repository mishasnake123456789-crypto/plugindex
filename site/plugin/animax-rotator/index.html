What Animax Rotator does

Animax Rotator animates mechanical models directly in the viewport. Select an edge to set it as the hinge axis, then set the rotation and animate; no 3D cursor setup, bones or weight painting is needed.

A Dependency Chain handles parent-child relationships across complex mechanisms, and interactive GPU gizmos display rotation angles. It suits hatches, gears, doors and other moving parts, saving rigging time for product and mechanical animation. You get edge-based hinge axis, animation without rigging and dependency Chain for mechanisms, along with the rest of the feature set.

Key features

  • Edge-based hinge axis
  • Animation without rigging
  • Dependency Chain for mechanisms
  • GPU rotation gizmos
