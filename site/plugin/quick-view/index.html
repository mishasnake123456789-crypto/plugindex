Quick View

Developer: Eirik

FreeBlender

Blender add-on offering a pie menu and an interactive mode for changing viewport orientation without a numpad.

What Quick View does

Eirik's Quick View is meant for compact keyboards, or setups where the number keys are mapped elsewhere. It lets you set the viewport direction with no numpad at all.

A pie menu lists the standard views along with Camera or Perspective, and V opens it by default in object and edit mode. An interactive orientation mode, Shift+V by default, lets you look around an object or scene, and a setting picks the default projection. TKL keyboard users will like it.

Key features

  • Pie menu of standard views
  • Camera or Perspective option
  • Interactive orientation mode
  • Default keys V and Shift+V
  • No numpad required
