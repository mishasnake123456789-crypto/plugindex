What Historica does

Historica brings branching version control into Blender so you do not have to name files by hand. It serves freelancers handling client revisions, studios tracking team versions and artists exploring variations.

Branches are sorted by type such as Milestones, Experiments and Backups, and projects are detected automatically. You can switch versions in under a second, see the current version, creation time and relationships, and save to a branch without opening it or store only selected objects. Incremental saving, asset category, compact display and favorites are available.

Key features

  • Branching version control in Blender
  • Milestone, Experiment and Backup branch types
  • Version switching in under a second
  • Save to a branch without opening it
