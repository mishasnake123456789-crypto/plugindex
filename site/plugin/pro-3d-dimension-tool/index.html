What Pro 3D Dimension Tool does

Pro 3D Dimension Tool is a Blender extension for adding precise technical measurements to a model. Dimensions are made in three steps: click a start point, an end point, then set the offset distance.

Snapping to vertices, edges and midpoints keeps measurements accurate. The workflow suits architectural, product and engineering visualization where annotated dimensions are needed, giving a drafting feel without leaving Blender.

Key features

  • Three-step start, end and offset workflow
  • Snapping to vertices, edges and midpoints
  • Drafting-focused technical measurements
  • Delivered as a Blender extension
