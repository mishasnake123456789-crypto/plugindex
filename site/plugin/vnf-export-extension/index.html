Blender extension that exports mesh geometry as OpenSCAD VNF data for BOSL2, writing .scad files to disk.

What VNF Export Extension does

VNF Export Extension, by runerback, connects Blender with OpenSCAD. It exports mesh geometry into the VNF structure used by the BOSL2 library and writes .scad files that can be used in OpenSCAD projects.

Writing files to disk is the only permission it asks for. It needs Blender 4.2 LTS or newer, has builds for Windows and Linux, and installs by drag and drop. Makers and CAD users who sculpt shapes in Blender but build parametric models in OpenSCAD can move data across.

Key features

  • Exports mesh data to OpenSCAD VNF
  • Targets the BOSL2 library
  • Writes .scad files
  • Builds for Windows and Linux
  • Requires Blender 4.2 LTS or newer
