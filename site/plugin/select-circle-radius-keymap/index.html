Blender add-on that resizes the Select Circle tool with PageUp and PageDown.

What Select Circle Radius Keymap does

Select Circle Radius Keymap lets you change the brush size of Blender's Select Circle tool from the keyboard, without dragging or using the mouse wheel.

PageUp increases the radius and PageDown decreases it in the 3D Viewport while the tool is active. The key codes live in Blender's KeyMap, so you can reassign them to any keys. Documentation is included and the license is GPL.

Key features

  • PageUp enlarges the radius
  • PageDown reduces the radius
  • Keys reassignable in the KeyMap
  • Works in the 3D Viewport
