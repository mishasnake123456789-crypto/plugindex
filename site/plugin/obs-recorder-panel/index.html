What OBS Recorder Panel does

OBS Recorder Panel is a UXP panel that controls OBS from within Premiere Pro. Press record in the panel and OBS begins capturing; stop it, and the resulting file is imported into the current bin automatically.

The panel remembers where the playhead was when recording began and puts it back to that spot afterward, so the new clip lines up with what was on the timeline. This helps with commentary, voiceover over existing footage and screen capture sessions. It needs OBS version 28 or newer.

Key features

  • Start and stop OBS recording from Premiere Pro
  • Automatic import into the current bin
  • Records playhead position at recording start
  • Restores playhead for in-sync placement
  • Works with OBS 28 and up
