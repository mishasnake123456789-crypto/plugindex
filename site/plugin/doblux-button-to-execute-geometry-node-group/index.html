What DOBLUX Button to execute Geometry Node Group does

Dan-Oak's DOBLUX button places a play icon in the header of the Node Editor. Clicking it executes the Geometry Nodes group you have open on the active object.

No menus are involved and no Tool flag is required in the node group, so it works with ordinary setups. It is helpful for technical artists who build one-shot operators and want to trigger them quickly while testing.

Key features

  • Play icon in the Node Editor header bar
