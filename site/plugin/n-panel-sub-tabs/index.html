Blender add-on that groups sidebar (N Panel) tabs into sub tabs so the panel stays tidy with many add-ons installed.

What N Panel Sub Tabs does

N Panel Sub Tabs organizes Blender's sidebar by collecting tabs into Sub Tabs and categories. Anyone with dozens or hundreds of add-ons knows how crowded the N Panel gets, and this tool keeps it manageable.

A Title Panel lets you jump between tabs quickly, and holding Shift enables several tabs in one category at once. Separate settings can be kept for different workflows or workspaces, matched manually or automatically. It is a practical interface helper for heavy add-on users who want a cleaner working layout.

Key features

  • Collects N Panel tabs under sub tabs
  • Title panel for fast tab switching
  • Shift-hold opens multiple tabs at once
  • Per-workspace settings with automatic matching
