What Curve Revolution does

Curve Revolution bundles precision curve tools for design and modeling in Blender. At its core is a modal Bezier curve editor operated through interactive shortcuts directly in the 3D Viewport.

It supports Aligned, Free, Auto and Vector handle types and symmetrical point moving. Union, Difference and Intersection booleans work on Bezier curves, which helps with logos and 2D shapes. Curves can be converted into n-gon meshes, and SVG files can be imported and exported alongside utility tools.

Key features

  • Modal Bezier editor with handle types
  • Union, Difference and Intersection for curves
  • Curve-to-mesh conversion
  • SVG import and export
  • Symmetrical point moving
