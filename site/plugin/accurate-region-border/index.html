A Blender add-on that sets the render region border using exact coordinates, with animatable values.

What Accurate Region Border does

Accurate Region Border replaces dragging with numbers when defining Blender's render border. The position is given by the upper-left corner, and the size by either the lower-right corner coordinates or a width and height.

A separate panel controls the border for each 3D viewport area, the coordinate values can be animated, and a Render Animation button renders a frame sequence following the animated border. This helps with rendering test crops, focusing on detail areas or building moving-window effects. Artists who need pixel-exact region renders will find it more reliable.

Key features

  • Exact border position from upper-left corner
  • Size by corner coordinates or width and height
  • Separate control per 3D viewport
  • Animatable border values
  • Render Animation button for sequences
