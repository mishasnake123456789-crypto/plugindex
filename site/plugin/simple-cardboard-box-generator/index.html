What Simple Cardboard Box Generator does

Simple Cardboard Box Generator creates box props in Blender through a Geometry Nodes setup. You change size, folded state, tape and material variation without leaving the viewport.

Each flap has its own angle control. When the design is final, a bake feature converts the generated box into a usable asset with baked maps ready to export. A bundled FBX asset pack provides ready models for other 3D software or game engines. It is a quick way to dress warehouses and deliveries.

Key features

  • Procedural boxes built with Geometry Nodes
  • Size and individual flap angle control
  • Folded state, tape and material variations
  • Texture baking for export-ready assets
  • Bundled FBX asset pack
