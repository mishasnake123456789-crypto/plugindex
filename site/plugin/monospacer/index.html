What Monospacer does

Monospacer, made by Plugin Everything, is a plugin for After Effects that deals with the trouble of animating text set in variable-width fonts. Letters of different widths make per-character animation uneven, and this plugin compensates.

It is a universal binary with native Apple silicon support, and it supports Multi-frame rendering in After Effects 2022. A buffer expansion feature and compatibility with parented layers are included. The plugin runs across After Effects versions from CS6 through 2026, giving typographic animators a consistent result on any font.

Key features

  • Handles variable-width font animation
  • Native Apple silicon universal binary
  • Multi-frame rendering support
  • Buffer expansion
  • Works with parented layers
