Renders After Effects layers directly to files via FFmpeg, bypassing composition-level rendering.

What LayerRender does

LayerRender, from Prosya, outputs individual layers from inside a composition instead of the whole comp. It talks to an external FFmpeg without writing intermediate files, and uses all CPU cores.

Presets cover VP9, H.264, H.265, DNxHD, Cineform and ProRes, open source codecs like x264 are reachable, and every option can be changed in the Options window. Most codecs from 8-bit to 16-bit are handled. Useful for client previews of intermediate stages.

Key features

  • Layer-level rendering
  • Direct FFmpeg access without intermediate files
  • Presets for VP9, H.264, H.265, DNxHD, Cineform, ProRes
  • Options window for all settings
  • Multi-core, 8 to 16-bit support
