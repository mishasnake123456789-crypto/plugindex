Open-source Blender toolbox for optimizing scanned and game-ready assets through retopology, decimation and texture baking.

What Bakemyscan does

BakeMyScan by norgeotloic is an open-source set of tools for getting models ready, whether for cleaning scans, building game assets, sculpting, low-poly work, 3D printing or publishing to WebGL, VR and AR.

Four external remeshers are supported (Instant Meshes, Quadriflow, Meshlab and MMGtools), and three methods are built in: quick quads, naive decimation and iterative decimation. Also provided are PBR material setup for textures, baking between high-resolution and optimized meshes, and Python scripts for command-line batch processing.

Key features

  • Integrates Instant Meshes, Quadriflow, Meshlab, MMGtools
  • Built-in remeshing and decimation methods
  • PBR material setup
  • Texture baking between high and low models
  • Command line batch scripts
