What Grid Layout - Tools To Help Layout Your Uv Layout (Udims Supported) does

Detailed assets spread across numerous UDIM tiles are hard to keep orderly. Grid Layout by hodgson3d offers tools to arrange UVs, move them between tiles and read or set texel density.

UnStack lines up the UVs of repeated objects in vertical columns, spilling sideways when a column fills and onto the next UDIM when a tile is full, with padding settings for tiles and islands. Stack returns UVs to a shared position so global edits are easier. Shift and select tools complete the set.

Key features

  • UnStack repeating objects into columns
  • Stack UVs back together
  • Shift UVs between UDIM tiles
  • Sample and set texel density
  • Tile and island padding controls
