What Serpens 3 - Visual Scripting Addon Creator does

Serpens 3 lets you create Blender add-ons by connecting nodes instead of typing Python. The result is a genuine, installable add-on with panels, buttons and pie menus.

It can also produce interactive modal operators, work with geometry nodes, embed your own Python and show the code it generates. Preset nodes, auto-compile and new property types such as pointer, collection and group are supported. Artists and technical directors who want to automate pipeline steps without programming can make their own tools.

Key features

  • Node editor builds installable add-ons
  • Panels, buttons and pie menus
  • Modal operators and geometry node interaction
  • Shows generated Python code
