A Blender add-on that builds an animated GIF from rendered output frames with one button.

What Gif Exporter does

Gif Exporter creates a GIF from the images you render in Blender. After a render finishes, one button collects the frames from the render file path and writes the result to the output directory set in the add-on settings.

You can choose RGB or RGBA output, with RGBA keeping alpha, set the loop count from endless to a fixed number up to 9999, define the time per frame, and invert the order for reverse playback. Documentation covers installation and usage. Animators and motion designers who share short loops on social media or in docs will find it avoids a trip to external software.

Key features

  • One-button GIF export after rendering
  • RGB or RGBA output
  • Loop count from endless to 9999
  • Frame duration setting
  • Reverse playback option
