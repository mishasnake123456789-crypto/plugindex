What Stash N Recall does

Stash N Recall is a Blender add-on for anyone who juggles different add-on configurations. It stores your setup as a preset you can reload later, which is useful when moving between projects with different needs.

It records which add-ons are enabled or disabled, can toggle all user-installed add-ons at once, and backs up the complete preferences file with its custom settings. Several versions of your preferences can be kept side by side, so reloading a saved configuration applies the chosen state in one step.

Key features

  • Save and restore enabled add-on sets
  • Toggle all user-installed add-ons together
  • Back up the full preferences file
  • Keep multiple preference versions
  • Reload a saved configuration as a preset
