What Render Time Estimation Add-On does

Render Time Estimation Add-On, from Zym-Zym Studio, tells you how long renders and video sequences still have to run. It sits in the N-panel and offers frame stats, a progress bar and messages in the status bar.

Statistics give the shortest, longest and average frame render times, and the progress bar appears in both the N-panel and the status bar along with the remaining time. Frame render times can be exported to a CSV file for further analysis. Documentation and a few usage tips come with it. Handy for planning long animation renders.

Key features

  • Estimated remaining time for renders and sequences
  • Shortest, longest and average frame times
  • Progress bar in N-panel and status bar
  • Status bar message with remaining time
  • CSV export of frame render times
