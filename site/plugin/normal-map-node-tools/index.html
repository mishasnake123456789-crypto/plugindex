Shader node groups for Blender to combine, mix, invert, adjust and generate normal maps.

What Normal Map Node Tools does

Normal Map Node Tools supplies node groups for working with normal textures. Add Normal Map combines two or more maps and Mix Normal Map blends them, while Invert Normal Map flips one and Normal Map Intensity adjusts its strength.

Generation nodes create normal maps from other sources: Height to Normal Map, Vector to Normal Map and Image to Normal Map. They save assembling complex node math yourself and help with layered detail on materials.

Key features

  • Add and Mix Normal Map nodes
  • Invert and Intensity nodes
  • Height, Vector and Image to Normal nodes
