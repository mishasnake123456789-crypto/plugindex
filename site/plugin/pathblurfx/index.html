What PathBlurFX does

PathBlurFX, from grape design, blurs an image along a mask path you draw. It converts the path into a vector field, enabling effects similar to motion blur or smearing in directions you define.

Blur falloff varies with position along the path, and Dynamic Sampling keeps sample density consistent. GPU acceleration and a simple, minimal interface keep it responsive. Motion designers wanting directional blurs that curve around shapes, rather than straight-line motion blur, get fine control.

Key features

  • Vector field generated from a mask path
  • Motion blur and smear style results
  • Falloff varies by position along the path
  • Dynamic Sampling for consistent density
  • GPU acceleration
