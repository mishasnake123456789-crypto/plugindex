What Quick Tools Menu does

Quick Tools Menu upgrades the context menu into a single hub, inspired by Cinema 4D's. It collects materials, assets, modifiers, quick effects, physics simulations, constraints and object visibility.

Material management gives fast access to materials on the selected object, asset tools add or organize assets, and modifiers are added from a categorized submenu. It reduces trips between properties tabs. You get unified context menu, material and asset management and categorized modifier submenu, along with the rest of the feature set.

Key features

  • Unified context menu
  • Material and asset management
  • Categorized modifier submenu
  • Physics, constraints and visibility
