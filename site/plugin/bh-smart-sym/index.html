What BH Smart Sym does

BH Smart Sym is a lightweight mirroring tool for Blender's Edit Mode. Interactive 3D arrows keep a constant screen size and follow the view; click one to flip across the X, Y or Z plane through the object's origin, honoring its rotation.

You can symmetrize only the selected faces or select everything to mirror the whole mesh. Hotkeys cover positive and negative directions, and a seam cleanup removes redundant flat edges while keeping creases. A selection-aware gizmo can relocate the arrows, arrow size is adjustable, and the main hotkey defaults to Alt plus X.

Key features

  • Clickable 3D axis arrows
  • Symmetry relative to object origin
  • Positive and negative axis hotkeys
  • Smart seam cleanup
  • Selection-aware gizmo toggle
