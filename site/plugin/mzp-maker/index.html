What MZP Maker does

MZP Maker is for people who distribute their own 3ds Max scripts. It creates a complete self-installing .mzp package quickly, or if preferred it simply encrypts MaxScript files, with a choice to encrypt the scripts or leave them open source.

A script macro is built automatically with the name, category and icons, and all files are renamed automatically to prevent misspellings. Icons, ini files and images can ride along, and both the newer png/svg icon approach and the old bmp one are supported. Custom code can be inserted into the InstallerMacro.mcr file, helping authors keep packages consistent from version to version.

Key features

  • Fast creation of a complete .mzp package
  • Optional encryption of MaxScript files
  • Automatic macro creation with name, category and icons
  • Automatic file renaming
  • Supports png, svg and legacy bmp icons plus custom installer code
