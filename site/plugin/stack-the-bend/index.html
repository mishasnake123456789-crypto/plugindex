Stack The Bend

Developer: Gianni Lorusso

FreeCinema 4D
Download Free

Tag-based Cinema 4D tool that chains Bend, Twist, Bulge and Taper deformers so each follows the previous one.

What Stack The Bend does

Stack The Bend, by Gianni Lorusso, connects deformers into a chain without arranging the hierarchy manually. Put its tag next to a Bend deformer and that bend is concatenated to the previous deformer in the hierarchy.

Twist, Bulge and Taper deformers can be stacked as well. If the deformer you want to follow is not adjacent, drag it into the tag's user data link. The plugin works across Cinema 4D releases from R19 through 2024 and added support for macOS Catalina. Useful for curving, folding and rolling shapes with several deformers in sequence.

Key features

  • Chains Bend deformers through a tag
  • Also stacks Twist, Bulge and Taper
  • Link non-adjacent deformers via user data
  • Supports Cinema 4D R19 through 2024
