Converts Premiere Pro projects so they open cleanly on Windows or Mac, avoiding NFC/NFD relinking problems.

What ProjectNormalizer does

ProjectNormalizer addresses a hidden cause of broken media links when projects move between macOS and Windows. The two systems normalize filenames with accents differently (NFD versus NFC), so files may appear missing.

Choose a .prproj file, press the for Windows or for Mac button, and the plugin saves a converted project file to the desktop. It works with Premiere Pro 13.0 and later. It helps teams that share projects across both operating systems avoid time-consuming manual relinking.

Key features

  • Fixes NFC/NFD filename normalization issue
  • For Windows and for Mac buttons
  • Saves a new project file to the desktop
  • Premiere Pro 13.0 and later
