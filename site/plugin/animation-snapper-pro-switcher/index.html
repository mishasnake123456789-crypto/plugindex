What Animation Snapper Pro - Switcher does

Animation Snapper Pro - Switcher automates the fiddly work of switching an object between parents or world space in Blender, aligning and keyframing constraints as the switch occurs.

Follow-targets preserve the object's current world position and rotation when a constraint is turned on, so there is no visible jump. It natively supports the animation system in Blender 5.0, scanning Action Layers and ChannelBags. A central panel lists every switch point on the timeline for quick selection or deletion.

Key features

  • Space switching and dynamic parenting
  • Keeps world position and rotation on activation
  • Supports Blender 5.0 Action Layers and ChannelBags
  • Panel listing all switch points
  • Automatic keyframing of constraints
