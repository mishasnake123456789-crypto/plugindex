What Marker Conductor does

Marker Conductor generates markers in bulk for compositions that need to line up with time or music. A Time tab and a BPM tab both include a Duration field, and BPM markers put a cue point on the first measure, with an optional extra start offset.

The Setting tab lets you write a comment template using tokens for count, time, frame, BPM and beat. Beat numerator and denominator values go up to 16, and comp-time comment variants are available. It helps editors and animators syncing visuals to rhythm, and is usable on macOS Catalina.

Key features

  • Time tab and BPM tab for marker creation
  • Duration field on both tabs
  • Comment templates with count, time, frame, bpm and beat
  • Cue point on the first measure
  • Beat values up to 16
