Per-camera collections in Blender so lights and objects only appear for the camera they belong to.

What Lightcuts ! -> Per-Camera Lighting does

Lightcuts lets you tune lighting and composition one camera at a time. Enabling it spawns a collection named for each camera, and anything inside is visible only to that camera.

Adding, removing or renaming cameras updates the collections instantly. Meshes, lights, shadow planes, fog cubes and collection instances can all be placed in a camera's collection. It is useful for multi-shot scenes where each angle needs its own fill light or cheat object.

Key features

  • Auto collection per camera
  • Updates when cameras change
  • Hold lights, shadow planes, fog cubes
  • Objects visible only to their camera
