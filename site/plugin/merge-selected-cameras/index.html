Blender add-on that merges photogrammetry cameras into one animated camera for use as a tracking tool.

What Merge Selected Cameras does

Merge Selected Cameras, by K_Naoki, turns the separate cameras exported by photogrammetry apps like RealityScan into a single animated camera in Blender, so photogrammetry can double as a camera tracker.

Sequential cameras are merged, with variable focal length and sensor shift keyed only where they change. Multiple cuts or extra sequences from the same location can be processed, and background images are set from Movie Clips to match resolution, start frame, focal length and sensor size. You can merge only selected cameras, delete originals and set the camera name. Alembic and FBX camera exports can be imported.

Key features

  • Merges sequential cameras into one animated camera
  • Keys focal length and sensor shift only when changed
  • Handles multiple cuts and sequences
  • Background images set from Movie Clips
  • Alembic and FBX camera import
