What Animation Editor Pro does

VertSoftex Studio's Animation Editor Pro offers a cleaner interface for character animation, built on Blender's native NLA editor. Strips can be created, edited, combined and refined without destroying anything, with stacking, sequencing and visual track previews.

Global Transitions change several strips across multiple tracks at once, with timeline cleanup via a Relocation Frame number. One-click mirroring is another highlight, and support periods come at no extra cost. Animators combining mocap clips or reusable actions can blend them faster.

Key features

  • Non-destructive animation strips
  • Global Transitions across tracks
  • Relocation Frame cleanup
  • One-click mirroring
  • Visual track previews
