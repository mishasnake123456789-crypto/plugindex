What Sprites 2D ... But 3D - Dynamic 3D Billboarding does

Sprites 2D ... But 3D is a Blender add-on for placing 2D sprites in 3D space so that they always face the camera. It suits sprite-based, isometric or retro game visuals.

Any set of sprites can be targeted, each with its own location, and they react in real time when the camera moves. They can stay separate or be grouped, and animation states like idling, running and attacking are supported. An optional Sprite Makey Make variation adds a sprite sheet creator and turntable tool. Documentation is included.

Key features

  • Billboarding toward the camera
  • Real-time reaction to camera movement
  • Sprite groups and animation states
  • Optional sprite sheet and turntable tool
