What Body Type Generator Pro- Smart Anatomy Markers + Shape Keys does

DanilGOE's Body Type Generator Pro begins with one humanoid basemesh. Place anatomy markers, then create variants through presets, sliders and weighted zones, which come out as named Shape Keys.

Marker placement uses raycasting in a guided order and mirrors left to right, with nineteen markers in total. Seventeen weighted body zones are computed from those markers, with smart weighting and a fallback. Thirteen presets cover female and male builds. Character artists can produce varied figures quickly.

Key features

  • 19 anatomy markers with mirrored placement
  • 17 automatically weighted body zones
  • 13 female and male presets
  • Output as named Shape Keys
  • Sliders for fine control
