Light Blender add-on that makes the top view treat the X axis as forward instead of Y.

What Top 3D View X Axes Forward does

Top 3D View X Axes Forward changes the orientation of Blender's top view so that X points up on screen, rather than the default Y direction.

This suits models built along the X axis, like cars or buildings, because the top view then matches how they are laid out. Apply it from Quick Favorites or a shortcut. The add-on is small and has a single purpose, and it is released under the MIT license.

Key features

  • Top view with X axis forward
  • Helpful for cars and buildings aligned to X
  • Apply via Quick Favorites or shortcut
  • Single-purpose lightweight add-on
  • MIT license
