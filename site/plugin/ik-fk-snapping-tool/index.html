What IK-FK Snapping Tool does

IK-FK Snapping Tool matches poses when switching between IK and FK in Blender. Snap from IK to FK or FK to IK at the press of a button.

Named snapping presets can be saved and switched, and bone fields cover slots for the FK Upper, FK Lower, FK End, IK Control and IK Pole bones. It is a fork of Mystfit's IK-FK Snapping add-on, offering extra options. Animators can change limb control modes without pops. Saved presets let one tool serve arms, legs and other limbs, because each limb's bone names can be stored separately.

Key features

  • Snap IK-to-FK and FK-to-IK snapping
  • Named snapping presets
  • Fields for FK and IK bones
  • Fork of an earlier snapping add-on
