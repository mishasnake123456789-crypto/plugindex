What Flared2 - Cinematic Lens Flares In Real-Time does

Flared2 produces lens flares directly in the Blender viewport, in both Eevee and Cycles. A flare can be added in three clicks and adjusted while seeing the result live.

More than sixty default presets are included and you can create and share your own. 2D mode keeps a fixed size while 3D mode scales with distance. Separate generators create flare elements for point lights and sun beams, such as glow, streaks, ghosts, starbursts, halos, hoops and lens dirt, and obstacles are detected live. Motion designers and VFX artists add sci-fi or cinematic shine to shots.

Key features

  • Real-time viewport flares
  • 60+ presets, shareable custom ones
  • 2D and 3D size modes
  • Generators for ghosts, streaks, halos, dirt
  • Obstacle detection
