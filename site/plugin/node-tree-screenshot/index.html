What Node Tree Screenshot does

Node Tree Screenshot, by LukasTönne, solves a common annoyance in Blender: a node graph too big to see at once. Its operator takes screenshots of the separate sections of a tree and joins them into a single picture.

That makes it easier to document shaders, compositing setups or geometry node graphs, share them for feedback, or keep a reference. It requires Blender 5.1 or newer, comes in builds for Windows, macOS Apple Silicon and Linux, and installs by drag and drop or Install from Disk. No special permissions are needed.
