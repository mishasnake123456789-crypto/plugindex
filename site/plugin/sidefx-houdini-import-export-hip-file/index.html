What Sidefx Houdini Import-Export (.Hip) File does

blenderVfxMaster's add-on reads SideFX Houdini scene files directly in Blender. A new File > Import > SideFX Houdini File menu entry accepts .hip, .hipnc and .hiplc files.

Geometry, transforms and scaling survive the move, with scale and transformation tuned automatically, and a detailed log records each import. Houdini Commercial, Indie and Apprentice are supported. Pipelines that bring Houdini assets into Blender skip manual conversions. The import log makes it easier to see what arrived and to diagnose anything that did not.
