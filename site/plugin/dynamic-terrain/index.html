What Dynamic Terrain does

Dynamic Terrain is a Blender add-on for building landscapes without wiring up geometry nodes, node shaders and node groups yourself. Parameters update in real time, so you can iterate on a terrain quickly.

Procedural textures can be applied and adjusted, rocks, trees and other assets can be scattered with weight paint controlling their distribution, and lakes and rivers are customizable through edit mode or proximity to geometry. Version 1.0.6 added baking procedural textures to PBR textures. The interface suits both beginners and experienced users making game environments or animations.

Key features

  • Terrain generation without manual node setup
  • Real-time adjustable parameters
  • Asset scattering with weight paint control
  • Customizable lakes and rivers
  • Bake procedural textures to PBR maps
