Distributes up to four objects along a Blender curve with spacing, taper controls and eight animation presets.

What Curve Array Pro does

Curve Array Pro places objects along any curve and animates them from the N-panel. Up to four different objects can alternate, appear randomly or follow a weighted distribution, set by count or fixed world-space spacing.

Per-axis controls cover spacing, scale, rotation and offset, with a taper to shrink instances along the curve. Eight animation presets add motion. Useful for chains, fences, conveyor lines and abstract motion graphics. Highlights cover up to four objects along a curve and alternating, random or weighted distribution.

Key features

  • Up to four objects along a curve
  • Alternating, random or weighted distribution
  • Per-axis spacing, scale, rotation and offset
  • Taper and eight animation presets
