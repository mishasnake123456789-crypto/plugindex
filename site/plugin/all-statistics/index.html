What All Statistics does

All Statistics shows extra scene information live in 3ds Max. While you work it reports materials (applied and active), smoothing groups, material IDs and sub-object IDs, whatever the object or modifier.

This saves repeatedly opening dialogs to find which material or smoothing group a selection uses. The toggle and settings are reachable through the 3ds Max global search, and settings persist from one session to another. It is helpful for modelers and game artists who need to confirm ID assignments and shading groups while editing geometry.

Key features

  • Real-time applied and active material display
  • Smoothing group readout
  • Material ID and sub-object ID display
  • Works across all objects and modifiers
  • Toggle and settings in global search, persistent between sessions
