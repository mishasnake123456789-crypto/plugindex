What Quick Catalogs ( Asset Browser ) does

Quick Catalogs, by justOniL, creates Asset Catalogs for Blender's Asset Browser straight from selected collections, which saves setting each one up by hand. It is categorised under Pipeline.

It is open source under GPL-3.0-or-later and needs Blender 4.2.0 or newer.

Key features

  • Makes catalogs from selected collections
  • Works with the Asset Browser
  • Open source, GPL-3.0-or-later
  • Requires Blender 4.2.0 or newer
