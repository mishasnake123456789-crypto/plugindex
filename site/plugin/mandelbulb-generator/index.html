What Mandelbulb Generator does

Mandelbulb Generator is a Blender plugin for creating three-dimensional fractal forms. It evaluates a signed distance field and turns the result into real mesh geometry, so the fractal can be rendered, shaded and edited like any other object.

The power parameter is animatable, and keyframes are supported, which allows morphing fractals. A Julia set mode, offset and twist distortions for spiral structures, and surface extraction with the Surface Nets algorithm give smooth normals and iso level control. The field is calculated with NumPy across selectable grid resolutions.

Key features

  • Mandelbulb and Julia set modes
  • Animatable power parameter with keyframes
  • Offset and twist distortions
  • Surface Nets meshing with iso level control
  • NumPy-based field evaluation
