What Corona Elements to Photoshop Automator does

Corona Elements to Photoshop Automator removes the manual export step after rendering. It watches a Corona render and, when the pass or noise limit is hit, writes every render element as a 16-bit TIF with alpha and assembles a layered Photoshop document.

Settings for the Photoshop.exe path and save folder live in a GUI, with a START MONITORING button and a progress bar showing passes and noise. Photoshop is launched or focused and the TIFs are stacked headlessly, with layers grouped in a set named for the scene. It installs by drag and drop MZP, runs without admin rights, and flags Photoshop errors in red with an Open Log button.

Key features

  • Monitors Corona renders and saves elements as 16-bit TIFs
  • Stacks TIFs into a grouped Photoshop document
  • GUI for Photoshop path and save folder
  • Progress bar for passes and noise level
  • Drag-and-drop MZP install without admin rights
