What Fastscale does

Fastscale is a Blender plugin for quick, directional scaling. Standard scaling is limited to the global or local axes, whereas this tool lets you stretch a mesh along any direction parallel to your view.

Press the button, click the mesh to define the origin, with no need for the 3D cursor, drag to scale and release to finish. Documentation is included. It is convenient for adjusting shapes freely in sculpt-like modeling or blockouts.

Key features

  • Scale along any axis parallel to the view
  • Click-drag-release workflow
  • Set origin by clicking the mesh
  • No 3D cursor needed
