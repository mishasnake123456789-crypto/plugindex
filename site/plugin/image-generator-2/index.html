What Image Generator 2 does

Image Generator 2, by Paul Thien Store, links Blender's 3D Viewport sidebar to Google Gemini and OpenAI so a plain clay render can become a finished-looking visual. Users can polish product shots, explore concept variations, edit a masked region or build sets from several angles.

Edit Render takes the current render result as input, with options to protect camera, lighting, shape, materials, logos and label text. Text to Image starts from a prompt alone. A consistency mode feeds earlier output back as reference, and IMAGINE re-renders when camera, lens or resolution change. A split view shows results next to the viewport, and results from History can be upscaled.

Key features

  • Edit renders with preservation controls
  • Text-to-image generation
  • Consistency across camera angles
  • Masked region editing with Annotate
  • AI upscaling from History
