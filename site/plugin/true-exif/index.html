A free Premiere Pro tool for viewing and copying camera metadata such as shutter speed, aperture and ISO.

What True Exif does

True Exif shows acquisition data from video and photo files that Premiere's own metadata panel leaves out. Shutter speed, aperture, ISO and white balance can be viewed, and the values copied for reuse.

Version 2.0.0 added support for footage from Sony cameras, and exif values can be stored as presets. It is free and works with Premiere Pro CC 2019 through 2025, useful for matching shots during color work. Seeing exposure details at a glance helps with matching shots from different cameras and settings.

Key features

  • Shows shutter speed, aperture, ISO and white balance
  • Reads video and photo files
  • More metadata than the built-in panel
  • Sony camera support from 2.0.0
  • Exif value presets
