What Multixport Pro does

Multixport Pro brings Blender's own export presets into a single dropdown so they can be run with one click. It writes geometry to BLEND, FBX, GLB, Alembic, USD, STL and OBJ.

The Generate Multiple Files option exports several objects or collections into separate files per format, and export profiles save your full set of options for reuse. It suits pipelines delivering the same asset to several applications or engines. Because settings are saved as profiles, repeated deliveries to the same engine or tool become a single action.

Key features

  • Presets collected into one dropdown
  • Formats: BLEND, FBX, GLB, Alembic, USD, STL, OBJ
  • Separate files per object or collection
  • Saved export profiles
  • One-click execution
