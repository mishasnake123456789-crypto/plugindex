Blender add-on that finds every external file a .blend uses and copies it into an organized Assets folder next to the file.

What DepotKit does

DepotKit prepares a project for archiving, sharing or moving. It scans the .blend file for referenced assets such as images, audio, fonts, linked libraries, Alembic caches, VDB volumes, video clips, sequencer strips, compositor nodes, point caches and scripts.

Everything found is copied into a tidy Assets folder beside the file. Studios and freelancers handing off projects can avoid broken paths and missing textures.

Key features

  • Scans for images, sounds, fonts and linked libraries
  • Handles Alembic, VDB and point caches
  • Includes movie clips, VSE and compositor references
  • Copies into an organized Assets folder
