What Timeme does

TimeMe is a Blender plugin for measuring how long a project takes. It runs quietly in the background, counts the time you spend and writes the figures into the current .blend file, so the data travels with the project.

It starts automatically on new or opened files and keeps four counters: total open time, working time, active time and rendering time. Buttons output the statistics to a text block or the clipboard, and a reset button clears the counters. It suits freelancers who need to bill or estimate.

Key features

  • Background timer saved inside the .blend file
  • Counts open, work, active and render time
  • Starts automatically with each project
  • Output stats to text or clipboard
  • Reset button
