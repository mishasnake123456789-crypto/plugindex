What Uv Island Colorizer does

UV Island Colorizer is a Blender add-on that makes busy UV layouts readable by tinting every island differently. A single sidebar panel in the UV Editor lets you review, rename and select islands.

Materials can be assigned to chosen islands with one click and tracked in the same panel, and textures can be generated for selected islands using automatically built stencil masks, with a shortcut into texture paint mode. Colors update as the mesh changes. Texture artists unwrapping complex models will find it helpful.

Key features

  • Unique color per UV island
  • Panel to view, rename and select islands
  • One-click material assignment per island
  • Texture generation with stencil masks
  • Colors update as you edit the mesh
