What NewBlue Titler Pro does

Titler Pro from NewBlue lets editors design animated titles and motion graphics for DaVinci Resolve and Premiere Pro. It is based on the reworked NTX engine and can be used inside the editor or as its own application.

Rendering is fully GPU accelerated with title caching, and text can be flat or three-dimensional vectors. Animations come from a drag-and-drop library, and Quick Edit allows several titles to be changed together. An elastic timeline makes animations follow the trim points, so one design can serve various durations, and object following keeps layers positioned relative to a lead layer. Video editors producing lower thirds, openers and credits will benefit.

Key features

  • GPU-accelerated 2D and 3D vector text
  • Drag-and-drop animation library
  • Quick Edit for multiple titles
  • Elastic timeline adapts to trim points
  • Object following between layers
