Procedural texturing suite for Blender combining material generators, layer-based painting and PBR baking.

What B- Node Painter does

B- Node Painter brings material creation, painting and baking into one Blender environment. It is built on native Blender math nodes, so materials still open for people who do not have the add-on.

You can build generators and paint fine details in the same place. Fast Bake uses a 32-bit cache to turn heavy node chains into a cache in one click while keeping full color depth, and Smart Groups encapsulate parts of a setup. It suits texture artists who prefer procedural, non-destructive work.

Key features

  • Generators and layer painting in one place
  • Built on native Blender math nodes
  • Fast Bake with 32-bit cache
  • Smart Groups
  • PBR baking
