What HB ModelingBundle does

HB ModelingBundle from C4Dstuff collects more than 70 scripts aimed at 3D modeling in Cinema 4D, many of which replace sequences of around ten clicks with one. It also ships a set of shortcuts, a modeling layout and a template scene that shows tool settings in the viewport for fullscreen work.

Scripts are grouped into sets, such as eight snapping scripts, four for brush size and strength, and seven for cloning. Individual tools include HB_Delete with six delete modes and HB_Divider for parametric division. Modelers who repeat the same operations all day can speed up their routine.

Key features

  • 70+ modeling scripts
  • Custom shortcuts and modeling layout
  • Template scene showing settings in the viewport
  • 8 snapping, 4 brush and 7 clone scripts
  • HB_Delete with six delete modes
