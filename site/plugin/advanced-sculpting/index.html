What Advanced Sculpting does

Advanced Sculpting reworks how sculpt mode looks and feels in Blender. A minimalist custom interface keeps the sculpted mesh in focus rather than menus and settings.

The UI is split into a Control Panel, a Brushes Panel and a Widget, each toggled independently. The first two can be pinned in position or dragged around. Brushes are grouped into categories, and textures can be organized in folders, making large brush collections easier to manage.

Key features

  • Control Panel, Brushes Panel and Widget
  • Panels can be locked or moved
  • Brush categories
  • Texture folder organization
