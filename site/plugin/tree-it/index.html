What Tree It does

Tree It is a procedural tree generator for Blender. It uses Geometry Nodes to create trees and renders in both Cycles and Eevee.

Compatible with Blender 4.0 through 5.0, it is available as a Blender Extension under a GPL license and includes documentation. Environment artists can use it to populate landscapes without modeling each tree. Since the trees are generated rather than modeled, adjusting species-like variation or density is quick, which suits landscapes, parks and architectural settings.

Key features

  • Procedural trees from Geometry Nodes
  • Cycles and Eevee support
  • Blender 4.0 through 5.0
  • GPL licensed with documentation
