What Skp Editor - Perfect Export And Import Sketchup File(.Skp) does

Skp Editor connects Blender and SketchUp by reading and writing .skp files. Imported geometry stays editable in Blender, and scenes can be exported back to SketchUp.

Textures are supported, including node-based ones, and UV and scene data are carried through. Material values can be adjusted on import without adding a new texture, and it works with render scenes. Documentation is included.

Key features

  • Import and export .skp files
  • Editable imported geometry
  • Node-based texture support
  • UV and scene data preserved
