What Scripshon Trees does

Scripshon Trees is a panel from shock tm for After Effects and Premiere Pro that organizes your scripts into one launcher. Point it at a directory and it creates an icon for every file and subfolder, so any script can be run with a double-click.

It handles jsx, jsxinc, jsxbin and psj files, among others. A built-in editor allows quick changes, a search field finds scripts, and scripts stored on the web can be linked in addition to local ones. Folder alignment settings and extra execution buttons tailor the layout. It also works in other Adobe applications.

Key features

  • Builds icons from a script folder
  • Double-click to run scripts
  • Built-in script editor and search
  • Links web-hosted and local scripts
  • Supports jsx, jsxinc, jsxbin and psj
