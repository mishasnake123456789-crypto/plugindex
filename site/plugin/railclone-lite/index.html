What RailClone Lite does

RailClone Lite builds parametric assets from visual rules in 3ds Max, covering everything from small interiors and facades to buildings and civil engineering projects. Version 7 brings new spline tools and workflow improvements for procedural modeling, along with access to a library.

Spline Operators transform, combine, offset, create catenaries, connect and apply booleans to splines directly in the graph editor, and they remain editable. Other updates include an optimized Point-Cloud mode for viewport speed, Style Editor improvements, a Y Corner input for placing rows into 2D arrays, and transform nodes that select sections from a RailClone Slice segment.

Key features

  • Visual rule-based parametric modeling
  • New spline operators editable in the graph editor
  • Point-Cloud mode for viewport performance
  • Style Editor improvements and macros
  • Y Corner input for 2D arrays
