What Shutter - 2D Toolset does

Shutter is a set of 22 compositor nodes for image and video work in Blender, divided into Adjustments, Artistic and Utilities groups.

Adjustments include Smart Contrast, Temperature, Tint, Vibrance, Clarity, Exposure, Vignette, Sharpen and White Balance. Artistic nodes provide Halftone, Blur Vignette, Film Grain, Color Pop, Tilt Shift, Thermal Vision, Soft Glow, Bloom and Edge Detect. The utility group holds tools such as a Denoiser and Average Color. It saves building these effects from basic nodes.

Key features

  • 22 compositing nodes
  • Adjustment nodes for exposure, white balance, clarity
  • Artistic nodes such as halftone, bloom, tilt shift
  • Utility nodes including denoiser
