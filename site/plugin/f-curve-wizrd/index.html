What F-Curve Wizrd does

F-Curve Wizrd organizes animation curves in Blender's Graph Editor. Large rigs produce hundreds of curves, and this add-on gives animators and technical artists faster ways to find and manage them.

Curves can be filtered by type, such as location, rotation, scale, bones, shape keys, custom properties or key count, and soloed with one click. Visibility and mute states can be toggled or saved as named states. Noise, Envelope and Cycles modifiers, interpolation and handle types can be applied in bulk. Everything sits in a Wizard tab in the sidebar.

Key features

  • Filter curves by type, key count and more
  • One-click solo with view focus
  • Save and load visibility and mute states
  • Batch modifiers, interpolation and handle types
