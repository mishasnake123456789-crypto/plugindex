What Quick Measure does

Quick Measure is a Blender plugin from B3dHub for checking dimensions. It can gauge an object's length whatever mode you're in, so you do not need to switch contexts.

Multiple measurements are supported, with or without snapping, and you can save them for later reference. It works with Blender 3.6 through 5.1, is GPL licensed and includes documentation. Handy for product design, architecture and anything built to scale. Keeping the readout within reach of everyday modeling means you can verify sizes without leaving your current workflow or setting up dedicated measuring objects.

Key features

  • Measure in any mode
  • Multiple measurements
  • Optional snapping
  • Save measurements
  • Blender 3.6 through 5.1
