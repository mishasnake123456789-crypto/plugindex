What breakdowns does

breakdowns is a PENCIL Park plugin that documents the structure of an animation in After Effects. It labels, exports and organizes layers along with a video, making it easier to show how a piece was built.

It is designed for animators working with vertical stacks of layers and adds no extra elements to your project, so layers stay unaltered and the project remains tidy. Organization follows a Photoshop-style approach with customizable labels and layer order. It generates unique sequences and animations for versioning and is also useful for behind-the-scenes renders.

Key features

  • Labels and exports layers with a video
  • No elements added to the project
  • Photoshop-style layer organization
  • Sequences for project versioning
  • Behind-the-scenes render creation
