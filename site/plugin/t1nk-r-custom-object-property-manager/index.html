What T1Nk-R Custom Object Property Manager does

T1Nk-R Custom Object Property Manager is a Blender add-on for handling custom properties on objects. It works on a single object or in batches, applying changes across a whole selection.

You can add a property to many objects, reset its value to a chosen one, add it only to objects that lack it while leaving existing values alone, or delete it from many objects. This is useful for technical artists and pipeline developers who tag objects with metadata for exports, scripts or game engines.

Key features

  • Add a custom property to many objects
  • Reset a value across a selection
  • Add only where missing
  • Delete a property from many objects
