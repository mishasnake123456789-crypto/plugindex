What Superpose 2 does

Superpose 2 is an auto clean plate tool by Christian Schnellhammer for After Effects. Given an image sequence recorded with a static camera, it removes moving objects such as snow, rain or crowds and produces a clean plate of the background.

A clean plate is useful for object removal, set extension and compositing work. The plugin is compatible with After Effects 2025 and 2026, with macOS support limited to Apple Silicon, and a demo video is available. It spares artists from painting out each distraction frame by frame.

Key features

  • Auto clean plate from image sequences
  • Removes snow, rain, crowds and similar movers
  • Designed for static camera footage
  • macOS support limited to Apple Silicon
