What Pipeline Inspector does

Pipeline Inspector is a Blender add-on that tests assets for common problems before delivery. From the N-panel, one click runs five checks: texture presence, material assignment, applied scale, UV existence and normals.

The result is a READY or NOT READY status with a score, plus counts of blocking issues and warnings and details for each check. Studios and freelancers handing assets to a game or production pipeline can catch problems early.

Key features

  • One-click inspection from the N-panel
  • READY or NOT READY status with score
  • Blocking issue and warning counts
  • Five handoff checks
