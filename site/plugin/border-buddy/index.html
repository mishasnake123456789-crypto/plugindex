What Border Buddy does

Border Buddy is a Blender add-on by SimonThommes for remembering render borders. In a panel of the output properties you grab the render border currently set in camera view, name it, and bring it back later from a list.

Pressing plus stores a snapshot. This helps when you switch between regions of a frame repeatedly, such as when testing different parts of a shot. It needs no special permissions, supports Blender 4.2 LTS and newer, and is released under the GNU GPL v2 or later.

Key features

  • Snapshot the render border with the plus button
  • Name each stored border
  • Recall borders from a list
  • Panel in output properties
  • Supports Blender 4.2 LTS and newer
