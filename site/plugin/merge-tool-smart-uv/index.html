Blender add-on for merging mesh and UVs by dragging, with Smart Stitch and crack cleanup.

What Merge Tool Smart UV does

Merge Tool Smart UV, by Magomedkhabib-Magomedov, lets you drag vertices together so the mesh and its UVs merge as one, using Smart Stitch and clearing small cracks. It is listed under Mesh and UV.

Open source under GPL-3.0-or-later, it needs Blender 5.0.0 or newer.

Key features

  • Drag to merge mesh and UVs
  • Smart Stitch
  • Crack cleanup
