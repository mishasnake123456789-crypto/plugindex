What Fast_Frame_Scrub_Basic does

Fast_Frame_Scrub_Basic removes the need to reach for the Timeline editor. Hold the trigger, by default Spacebar or a mouse drag, and move to scrub through frames from where you are working.

Magnetic snapping jumps to nearby keyframes when a modifier key (Ctrl, Alt or others) is held. It works globally in the 3D Viewport, Node Editor and Graph Editor, helping animators review motion without changing layouts. This is useful when reviewing animation or adjusting nodes without changing screen layouts.

Key features

  • Hotkey and drag scrubbing
  • Works in 3D Viewport, Node Editor, Graph Editor
  • Magnetic keyframe snapping with modifier
  • No Timeline editor needed
