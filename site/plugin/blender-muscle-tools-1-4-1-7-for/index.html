What Blender Muscle Tools 1.4 + 1.7 For does

Blender Muscle Tools helps create muscle systems for characters that already have a rig. Any mesh can be turned into a muscle and bound to the character, adding anatomical deformation that makes animation and renders look more natural.

Jiggle options and shape changes add secondary motion, and the jiggle is visible while scrubbing or playing the timeline. A Muscle Creator speeds up making new muscles. This listing covers versions 1.4 and 1.7 of the toolset, for riggers and character artists who want more lifelike bodies.

Key features
