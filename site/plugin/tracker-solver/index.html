What Tracker Solver does

Mike Sevigny's Tracker Solver is a tool built for After Effects that converts a 2D layer's position keyframes into a true 3D position. It triangulates using the active camera's motion and settings, which helps place 3D layers where a tracked point sits in the scene.

It works with any After Effects camera, including ones imported from other applications, and can use Mocha data. At least three keyframes are needed, and extra keyframes improve accuracy. One layer is solved or unsolved at a time. Cameras with animated zoom and Point of Interest cameras are not supported.

Key features

  • Triangulates 3D position from 2D keyframes
  • Works with any After Effects camera
  • Minimum of three keyframes, more improve accuracy
  • Can use Mocha data
  • Solve or unsolve one layer at a time
