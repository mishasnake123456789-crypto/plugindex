What YY_HexTex does

From Andrew Yang comes YY_HexTex, a plugin for After Effects that draws repeating hexagon patterns. It is meant for tech-style backgrounds, overlays and mattes where you want a honeycomb grid without building it from shapes.

You can shift the grid with the anchor point, set hexagon diameter and angle, and shape the border with thickness and hardness. Color and alpha are adjustable, Invert Alpha fills the cells rather than drawing lines, and 20 blend modes combine the pattern with the layer beneath. Clip RGB uses the source layer as an alpha matte. Every parameter animates in the comp, so no nested precomps are needed.

Key features

  • Tiled hexagon texture generation
  • Anchor, size and angle controls
  • Thickness and hardness for borders
  • Invert Alpha for filled cells
  • 20 blend modes and Clip RGB matte option
