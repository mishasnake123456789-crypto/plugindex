What Haggis Tools does

Haggis Tools is a Blender plugin from Online Render that targets repetitive tasks. Helpers for selection, animation, objects and the interface show up in compact menus and top-right icons throughout the workspace.

Location, rotation and scale can be copied and pasted between objects, or stored and recalled, and selection tools include select by polycount and objects disabled in the render engine. It trims small, repeated steps from daily work. Grouping these small helpers behind quick access points means fewer trips through menus, which adds up over a long working day.

Key features

  • Copy, paste and store transforms
  • Select by polycount or render-disabled state
  • Quick menus and header icons
  • Animation and object utilities
