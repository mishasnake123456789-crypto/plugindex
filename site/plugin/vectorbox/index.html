Builds colorful 3D boxes in After Effects whose strokes stay the same size at any dimension.

What VectorBox does

VectorBox generates 3D boxes made of vector faces, with strokes that remain consistent however the dimensions change. You set the width, height and depth, and choose stroke size and color.

Each face gets its own color. Wireframe mode turns the faces off so only the strokes are seen, and Squash & Stretch interpolates between two sets of dimensions. It suits explainers, packaging graphics and stylized animation. Because strokes remain even as the box changes shape, it works well for flat, graphic and explainer-style animation.

Key features

  • Adjustable box dimensions
  • Stroke size and color control
  • Independent color for each face
  • Wireframe mode
  • Squash & Stretch between two sizes
