What LAYERQ does

LAYERQ, by TOKI Projects, manages layer visibility sets and renders them in bulk for After Effects. When one composition needs many versions, such as different languages or product colors, it avoids duplicating comps and queueing each by hand.

Sets are named and saved per composition, work across nested precomps, and preview through the native Solo property. Render All and Render Selected send variations to the queue, with an Add to Queue Only mode for multiple shots. Each set can carry its own output module, render settings and file name template. The interface is bilingual in English and Japanese.

Key features

  • Named visibility sets per composition
  • Hierarchical support for nested precomps
  • Live preview using native Solo
  • Render All, Render Selected or queue only
  • Per-set render settings and file name templates
