What Plugin Everything Effect Matte does

Effect Matte from Plugin Everything is an After Effects plugin that builds mattes from a layer's own shape. It is designed for text and video layers and works in 32 bits per channel.

You can grow or shrink the matte with positive or negative expansion, round its corners, feather the edge, and invert it. Auto Set Matte configures the matte automatically when the effect lands on a layer, trimming setup time. The plugin runs natively on Apple Silicon and supports multi-frame rendering, so it stays quick in modern projects.

Key features

  • Positive and negative expansion
  • Roundness and feathering controls
  • Invert matte option
  • Auto Set Matte on application
  • Native Apple Silicon and MFR support
