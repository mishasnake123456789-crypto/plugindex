What Motion Factory File Manager does

This Pixflow panel that keeps your template packages and media tidy without leaving After Effects or Premiere Pro. It combines browsing, a library and file management in one workspace.

You can manage folders, set up your own file categories and arrange template packages, with a fluid live preview to check an item before using it. MOGRT files, images, video and audio are all supported, so one panel can handle most of the assets a motion designer collects over time.

Key features

  • Folder management inside the host app
  • Customizable file categories
  • Organizes template packages
  • Live preview of items
  • Handles MOGRT, image, video and audio files
