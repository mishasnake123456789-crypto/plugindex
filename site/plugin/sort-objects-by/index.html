Sorts and ranks Blender scene objects by vertex count, modifiers, subsurf level, materials and textures.

What Sort Objects By does

Sort Objects By lists mesh objects in a scene according to criteria such as vertex count, number of modifiers or subsurf level, and ranks them so heavy objects stand out.

It also orders by materials and textures, showing the ones in use, and filters for physics modifiers and materials with a normal input. It is a quick optimization audit for heavy scenes. Highlights include sort by vertices, modifiers, subsurf, show materials and textures used and physics and normal input filters.

Key features

  • Sort by vertices, modifiers, subsurf
  • Show materials and textures used
  • Physics and normal input filters
  • Ranking view for heavy objects
