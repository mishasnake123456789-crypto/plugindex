What External Python Button-Bar Addon For Windows does

This tool is a separate macro bar that attaches to the right edge of the Blender window, so it does not use any space inside Blender's own interface. Each button launches a Python script you provide.

Up to nine layers of buttons are available, four already filled with ready-made actions and five left open for your own. Every button can run different code for a left click and a right click. Technical artists who rely on lots of small custom scripts can keep them one click away at all times.

Key features

  • Attaches along the right edge of Blender's window
  • Up to nine button layers, four prefilled
  • Separate scripts for left and right click
  • Runs your own Python code
