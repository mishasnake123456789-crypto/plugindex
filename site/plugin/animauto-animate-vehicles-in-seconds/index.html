What Animauto - Animate Vehicles In Seconds does

Animauto is a Blender plugin for animating cars and other vehicles without keyframes. Set it up with a few clicks, draw the route, and it takes care of the motion.

Wheels spin and steer to follow the path, so turns need no manual keyframing, and the dynamic suspension lets chassis and wheels react to the ground. A quick method for background traffic and chase scenes. Since the animation is driven by the path, changing the route or speed updates the motion automatically, avoiding repeated keyframe work.

Key features

  • Fully procedural vehicle animation
  • Smart steering along the path
  • Dynamic suspension reacting to terrain
  • Automatic wheel spin
