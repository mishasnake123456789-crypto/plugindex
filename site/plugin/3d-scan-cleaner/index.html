What 3D Scan Cleaner does

3D Scan Cleaner, by Ignacio Matey, prepares photogrammetry and other scans for real use in Blender. Raw scans are heavy and messy, and this tool reduces memory use, in some cases by over 80 percent.

A decimate ratio simplifies the mesh, a floor height control strips the ground, and X/Y cut values trim the sides. Apply runs the decimation and removes stray islands, while Reset clears the modifiers. Fix Texture opens texture painting with the clone tool to repair stretched areas, and Instance Geometry reuses a scan with optional randomization. Requires Blender 3.1 or higher.

Key features

  • Decimate ratio control
  • Floor height removal and X/Y cutting
  • Removes extra mesh islands
  • Fix Texture with clone tool
  • Instance scans with optional randomization
