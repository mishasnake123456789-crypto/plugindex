What Atmospheric: Smoke Elements Add-On does

Atmospheric: Smoke Elements Add-On provides pre-keyed, looping smoke and steam for Blender scenes. More than fifty elements are sorted into four categories: heavy plumes, low steam loops, upward steam and lingering fog.

Usage is three steps: select, preview, place. Assets run at 2K resolution, are optimized for Cycles and EEVEE, and use Blender's native material system so they stay adjustable after placement. An automated track-to-camera option is included, and the purchase comes with free future updates. Suited to street scenes, explosions and industrial set dressing.

Key features

  • 50+ looping smoke and steam elements
  • Four categories from fog to heavy plumes
  • Select, preview, place workflow
  • 2K assets for Cycles and EEVEE
  • Track-to-camera option
