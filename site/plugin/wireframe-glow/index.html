What Wireframe Glow does

Wireframe Glow, by Egret Studios, is a Blender add-on for producing colored wireframe visuals, where mesh edges are shown as vivid lines instead of solid surfaces. It works with both Cycles and Eevee, so the look can be rendered in either engine.

It is distributed as a Blender extension and supports versions 4.0 through 5.0. Documentation is included, and the add-on is released under the GPL.

Key features

  • Colored wireframe creation
  • Works with Cycles and Eevee
  • Blender 4.0 to 5.0
