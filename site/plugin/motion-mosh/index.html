What Motion Mosh does

Motion Mosh recreates the smeared, melting look of datamoshing without the usual round trip of exporting, corrupting and re-importing video. Everything happens live inside After Effects, DaVinci Resolve or Premiere Pro, so you can see the result as you work.

The effect is accelerated on the GPU and responds interactively, and a frame offset slider changes how the smearing behaves. It also renders through Media Encoder, and an OFX build covers Nuke, Resolve and similar hosts. It comes from Pixel Sorter Studio and suits anyone chasing glitch aesthetics for music videos, titles or stylized cuts.

Key features

  • Datamosh-style looks generated in real time
  • GPU accelerated processing
  • No export and re-import workflow
  • Frame offset slider
  • Renders through Media Encoder; OFX build available
