What Collapse and reset-X does

Collapse and reset-X combines two common preparation steps for exporting models from 3ds Max. It carries out a reset XForm strong enough for export, unlike the non-export-proof version of the script, and collapses the stack in the same action.

It also tries to detect flipped normals and correct them, although the author notes this does not always succeed, so the result should be checked. The tool is made by Chuggnut, is at version 2.3.5 and is listed as free in the ScriptSpot library. It suits game artists readying assets for export.

Key features

  • Export-strength reset XForm
  • Collapse bundled with the reset
  • Attempts to detect and fix normal flips
  • Version 2.3.5
