What Freestyle Wireframe & Rest On Ground does

Freestyle Wireframe & Rest on Ground supports technical rendering workflows in Blender with two small but helpful features.

For wireframes, it enables Freestyle automatically, sets the Line Set to use Edge Marks only, marks all edges of selected meshes and lets you set line thickness, with gradient colors along strokes. A second function drops selected objects to the ground at Z = 0 in one click. Controls sit in the WireFrame Render tab of the N-panel.

Key features

  • Enables Freestyle automatically
  • Edge Marks only line set
  • Adjustable line thickness and gradient color
  • Drop objects to Z = 0
  • Controls in the N-panel
