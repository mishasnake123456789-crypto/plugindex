What Transfer Vertex Order does

Transfer Vertex Order is a Blender add-on by Nick Barre for fixing mismatched vertex order, a frequent cause of trouble with blendshapes. It copies the vertex, edge and face ID order from one mesh and pastes it onto another that shares the same topology.

It is triggered from a pie menu with two clicks and is quick: roughly 20 seconds on a mesh of 3 million triangles and an instant on low-poly models. It fits morph target workflows, includes documentation, and works from Blender 2.8 up to 5.0.

Key features

  • Transfers vertex, edge and face ordering
  • Two-click pie menu operation
  • Handles 3 million triangles in about 20 seconds
  • Suits blendshape and morph target setups
  • Supports Blender 2.8 to 5.0
