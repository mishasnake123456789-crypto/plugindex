Builds lightweight proxy meshes from detailed Blender models to speed up rigid body simulations and playback.

What Proxybody does

Proxybody generates simplified stand-ins for your models so that rigid body simulations run faster. Reducing scene complexity improves playback and makes high-poly simulation results more achievable.

Placement uses array and surface tools, and built-in randomization adds variety to the arrangement. It is helpful for piles, debris and many-object collisions where full-resolution meshes would slow the viewport to a crawl. Using lightweight stand-ins in the simulation, then swapping in detailed models, is a common way to keep scenes responsive.

Key features

  • Creates optimized proxy meshes
  • Lighter simulation and smoother playback
  • Array and surface placement tools
  • Built-in randomization
  • Supports high-poly simulation results
