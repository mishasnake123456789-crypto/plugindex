What OEBS Icon Viewer does

OEBS Icon Viewer is a tool for add-on developers and scripters working in Blender. A panel in the Text Editor sidebar lets you browse and search the internal icon library, and copy an icon's code, for example icon='FILE_FOLDER', to the clipboard.

Search matches by name and by look, icons are sorted into categories such as Animation, Modeling and Scripting, and thousands load without slowing the interface. A link to ui.blender.org/icons gives the official reference. It follows Blender Extension standards.

Key features

  • Browse and search internal icons
  • One-click copy of icon code
  • Categories by context
  • Handles thousands of icons smoothly
  • Link to the official icon reference
