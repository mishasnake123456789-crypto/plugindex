What Real Time Ship Simulator does

Real Time Ship Simulator, by Ignacio Matey, simulates how ships or any floating object behave on water in Blender. A physically based solver runs in real time and works with the ocean modifier and other customizable oceans.

Parameters are few: starting frame, flotability, buoyancy, plus velocity and angle. A button shows the guide geometry used for rigid body dynamics, an option applies a premade ocean material, and Set as Initial Conditions places the start before Simulate runs. Baking to keyframes is needed before rendering and allows export.

Key features

  • Real-time floating object solver
  • Works with the ocean modifier
  • Few simple parameters
  • Guide geometry display
  • Bake to keyframes for export
