What Ephoto Dam does

Ephoto Dam is a plugin that connects After Effects, Premiere Pro and other Adobe programs to the Ephoto Dam cloud asset manager. Images can be imported straight from the DAM for editing, so there's no need to download and relocate files manually.

Within the Adobe software you can search media, look through albums and explore your thesaurus. Version 3.3.0 added automatic updating of assets in InDesign when a new version appears in Ephoto Dam. It's meant for teams that already store their media there.

Key features

  • Import images directly from Ephoto Dam
  • Media search inside Adobe apps
  • Album viewing
  • Thesaurus browsing
  • InDesign auto-update of assets (v3.3.0)
