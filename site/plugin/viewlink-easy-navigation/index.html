What Viewlink - Easy Navigation does

Viewlink links several Blender viewports so they move together. It supports undocked viewports on separate monitors, which is useful when you want multiple perspectives of a model at once.

It relies on direct Python-based linking rather than locking cameras, and the frame rate sync is adjustable. It runs on Windows, macOS and Linux, and documentation is included. Modelers and sculptors using multi-monitor setups can keep reference views synchronized. In practice that means links multiple viewport views and undocked viewports on separate monitors.

Key features

  • Links multiple viewport views
  • Undocked viewports on separate monitors
  • Adjustable frame rate sync
  • No camera locking required
