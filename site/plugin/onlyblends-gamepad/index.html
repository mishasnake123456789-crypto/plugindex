What OnlyBlends.Gamepad does

OnlyBlends.Gamepad lets you read input from game controllers inside Blender, using a node-based setup. Buttons and sticks become values that can drive other parts of your scene.

That opens the door to interactive prototypes, live puppeteering or game-style experiments directly in Blender. Developers and creative coders who want physical controls rather than the mouse can map inputs to logic with nodes.

Key features

  • Gamepad input through nodes
  • Supports other input devices
  • Drives scene logic live
