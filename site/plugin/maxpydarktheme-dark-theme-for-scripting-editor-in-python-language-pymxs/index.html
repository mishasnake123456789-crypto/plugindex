What MaxPyDarkTheme: Dark Theme for Scripting Editor in Python Language PyMXS does

A dark color scheme for the PyMXS Python editor inside 3ds Max is what MaxPyDarkTheme provides. Its Python-blue palette is deliberately different from DarkScintilla, so you can tell at a glance whether you are in a MaxScript or a Python window, MaxScript being black and Python blue.

Install it with Scripting, Run Script, using the supplied .mzp file. Because python.properties sits inside the 3ds Max root folder, 3ds Max must be run as administrator, and the installer creates python_backup.properties for recovery. Colors can be customized, with a guide on the developer's page. It suits scripters who spend long sessions in the editor.
