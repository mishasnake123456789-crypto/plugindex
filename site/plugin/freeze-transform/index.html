Freeze Transform

Developer: Nikita Akimov

FreeBlender

Saves an object's world transform in Blender so it can be moved freely and snapped back later.

What Freeze Transform does

Freeze Transform remembers where an object is. The Freeze Transform button stores the selected object's world position, rotation and scale, and To Frozen returns it to those values after you have moved, rotated or scaled it.

It works on one object or on all selected objects and sits in the 3D Viewport N panel under its own tab. Documentation is included and it is GPL-licensed. It is handy for experimenting with placement without losing the original pose.

Key features

  • Save world position, rotation and scale
  • Return with the To Frozen button
  • Single or multiple objects
  • N panel tab
