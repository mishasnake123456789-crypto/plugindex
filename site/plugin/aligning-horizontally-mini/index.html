What Aligning Horizontally Mini does

Aligning Horizontally Mini is a Blender add-on by Hydrocallis that arranges chosen objects into an adjustable grid in the 3D viewport. Each of the X, Y and Z axes has its own spacing value, and the number of objects along X and Y can be changed.

Grouping by name is possible with a split character of your choice (a period by default), and every group can be positioned in any of six directions. Another option places the active object at the start of the arrangement. It is useful for presenting asset libraries and product lineups.

Key features

  • Customizable grid layout for selected objects
  • Separate X, Y and Z spacing
  • Adjustable counts on X and Y
  • Grouping by name with a split character
  • Six group placement directions
