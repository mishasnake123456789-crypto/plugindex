What Grease Pencil Draw Transform does

Grease Pencil Draw Transform lets you adjust strokes without switching out of draw mode in Blender. Hold a letter key and click a stroke to grab, rotate, scale, pinch or slide it, with the stroke reprojecting onto the canvas afterwards.

Single-press actions handle delete, smooth and duplicate, and a thickness tweaker changes the width of pointed strokes. The pinch tool propagates along the line, and its radius is set with number keys. Duplicate can be locked to a view-space X or Y direction. Keybindings can be customized or turned off in preferences, and documentation is included.

Key features

  • Hold-key transforms: grab, rotate, scale, pinch, slide
  • Delete, smooth and duplicate shortcuts
  • Thickness tweaker for pointed strokes
  • Duplicate constrained to view axes
  • Rebindable or disableable keymap
