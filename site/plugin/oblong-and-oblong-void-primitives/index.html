What Oblong and Oblong Void Primitives does

Oblong and Oblong Void Primitives, by Christophe Blattmann, adds two rounded elongated base shapes to the 3ds Max create menu: a solid oblong and an oblong void. Parameters can be changed in real time as you build.

Both primitives provide mapping coordinates for texturing and separate material IDs for different parts. Support was added for Autodesk 3ds Max 2025. Modelers creating pill shapes, slots, handles, rails or architectural openings can start from these instead of constructing and capping splines.

Key features

  • Oblong and oblong void primitives
  • Real-time parameter changes
  • Mapping coordinates for texturing
  • Separated material IDs
  • Support for 3ds Max 2025
