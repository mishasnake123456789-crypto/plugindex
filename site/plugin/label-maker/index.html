After Effects plugin that colours layer labels automatically from the pixels of each layer.

What Label Maker does

Label Maker tidies a crowded After Effects timeline by assigning label colours for you. It looks at the pixels in each selected layer and sets the label to a matching colour, so a glance at the timeline reveals what each layer contains.

It is a universal binary with native Apple Silicon support. Version 1.0.2 fixed problems with layers outside the composition bounds and with selecting camera or light layers. The plugin works from After Effects CC 2014 through 2025.

Key features

  • Analyses pixels of selected layers
  • Sets label colours to match automatically
  • Native Apple Silicon support
  • Fixes for out-of-bounds, camera and light layers
  • CC 2014 through 2025
