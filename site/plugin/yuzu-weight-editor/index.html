What Yuzu Weight Editor does

Yuzu Weight Editor shows vertex-group weights in a table, in the spirit of Maya's SiWeightEditor. It gathers numeric editing, copy and paste, symmetry and binding helpers in one window for riggers and character artists.

Tabs separate All, Deform and Other groups. The display can show selected-only, full or viewport-linked data. Weights can be copied by cell, vertex or object, mirror-pasted through a naming dictionary, rounded, normalized and limited per vertex. Invalid weights are flagged, and unused groups can be deleted or missing bone groups added in one click.

Key features

  • Spreadsheet layout with group tabs
  • Copy, paste, mirror and symmetry tools
  • Detects invalid weights
  • Round, normalize and limit influences
