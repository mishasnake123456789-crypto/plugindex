What Physics Placer does

Physics Placer is a Blender add-on from Blender Procedural for placing objects dynamically in a scene. Rather than positioning every item by hand, you let the add-on handle the arrangement.

It runs on Blender 3.4 through 5.0, handles Cycles and Eevee alike, ships with documentation, comes with documentation and is distributed under the GPL license. Environment artists and set dressers who want natural-looking arrangements of props can use it to save time.

Key features

  • Dynamic object placement
  • Supports Blender 3.4 through 5.0
  • Works with Cycles and Eevee
  • Documentation included
