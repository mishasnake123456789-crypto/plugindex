Randomly drops objects into a cube volume with rigid body physics to create piles and stacks in Blender.

What Stable Dropper does

Stable Dropper fills a space with scattered objects that settle naturally. Any cube can serve as the drop area, and objects are released at random positions inside it without overlapping.

Rotation and count are controllable, a seed makes results repeatable, and rigid body physics are configured automatically. An optional container can catch the objects, and playback of the simulation is a click away. Perfect for coins, rocks, boxes and other loose heaps.

Key features

  • Drops objects inside any cube volume
  • Seed for repeatable randomness
  • Automatic rigid body setup
  • Optional container object
