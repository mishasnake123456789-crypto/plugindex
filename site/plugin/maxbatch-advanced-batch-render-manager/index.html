What MaxBatch - Advanced Batch Render Manager does

MaxBatch queues and manages many render jobs in 3ds Max. Several cameras and Scene States of the open file can be rendered, or a list of outside .max files can be worked through in sequence.

Each camera can have overrides for resolution, aspect ratio, scale, frame range and Scene State, and engine settings such as noise threshold, time limit, subdivs or pass limits apply per job. Output handling covers V-Ray Separate Render Channels and Corona CXR, Auto-Name paths drawn from scene, camera and date, and Max's own EXR, TIF, PNG and JPG options dialogs. Telegram integration sends status and previews, and unattended features include overwrite-warning handling. Intended for V-Ray 7 or Corona 14.

Key features

  • Queue cameras, Scene States or external .max files
  • Per-camera resolution, aspect, frame range and state overrides
  • Per-job engine limits for noise, time, subdivs or passes
  • Auto-Name output paths and native format dialogs
  • Telegram status updates and unattended operation
