What Keyless does

Keyless is YB Motion's script for After Effects that animates properties without setting keyframes. It applies Penner easings along with the right controls automatically, which is especially useful for people building MOGRT templates.

It also supports path properties, using key keyframes for the setup, and includes a linear easing type. An overshoot slider defaults to the classic value of 1.70158. It suits anyone who has outgrown the basic linear() function and wants a more expressive way to drive motion.

Key features

  • Animate any property without keyframes
  • Automatic Penner easings and controls
  • Path property support
  • Linear easing type
  • Overshoot slider with default 1.70158
