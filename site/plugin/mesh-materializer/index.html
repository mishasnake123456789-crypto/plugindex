Blender add-on that wraps one object onto another's surface using the target's UV map, like a material.

What Mesh Materializer does

Mesh Materializer lays geometry over a surface the way a material would be applied. It uses the target's UV map to wrap an object onto it, non-destructively, through its own modifier.

A right-click entry runs the operation in one step. The object's X axis maps to U and its Y axis to V, UVs and materials transfer to the new object, and you control height above the target plus position, scale and rotation on its surface. It combines with other modifiers. Modelers adding scales, tiles or decorative patterns find it useful.

Key features

  • Wraps objects using the target UV map
  • One-step right-click operation
  • Transfers UVs and materials
  • Position, scale, rotate and height controls
