Animation helpers for Blender: pick-up and drop parenting, object pinning, camera fixes for stepped animation.

What Pickup Tools does

Pickup Tools bundles several time-saving utilities for animators: PickUp, ObjectPin, CamCorrect, Quick Foot Reset and a stepped viewport render module.

PickUp and Drop animate objects or bones with a click, creating Child Of constraints with offsets and keyframes. It copes with animated targets and several pick-up and drop sequences without manual cleanup, giving clean parenting from object to object or bone to object. CamCorrect and the stepped render handle stepped-animation camera issues.

Key features

  • PickUp and Drop with Child Of constraints
  • Multiple sequences without cleanup
  • Object pinning
  • Stepped-animation camera correction
  • Quick Foot Reset
