What Auto Sync Object Data Names does

Auto Sync Object Data Names is a Blender add-on by GeeDoubleU that keeps mesh, curve, light and camera data names consistent with the object names they belong to. Renaming happens automatically, so the outliner stays easy to read.

You can set a custom prefix for new data names, choose whether shared data is renamed or left alone, with an optional warning, and turn the feature off for specific object types. A manual sync operator is available from the Object menu or right-click for selected objects or the whole file, and an Include Children option syncs recursively.

Key features

  • Object data is renamed after its parent object
  • Custom prefix for new data names
  • Multi-user data handling with optional warning
  • Per-object-type enable or disable
  • Manual sync for selected or all objects
