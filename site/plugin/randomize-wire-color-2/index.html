Free 3ds Max script that assigns soft pastel random wire colors to selected objects to tell parts apart.

What Randomize Wire Color 2 does

Randomize Wire Color 2 gives each selected object a random wire color, drawing from softer pastel tones similar to those in Blender. It is particularly handy for CAD imports, where wireframes are often all black, and for detached geometry sharing one color.

Drag it onto the 3ds Max viewport to install; a Random Wire Color command then appears under Shiva Tools and can be put in any menu. It is free and supports 3ds Max 2015 and later. Using it makes it far easier to identify separate parts in the viewport.

Key features

  • Random wire colors for selected objects
  • Soft pastel palette similar to Blender
  • Distinguishes parts in CAD imports and detached geometry
  • Drag-and-drop installation
  • Works with 3ds Max 2015 and later
