Swaps Blender scene and character colors by syncing color properties to a palette, with import from coolors.co.

What Colordock does

Colordock lets you switch between looks by driving colors from a palette. Selected color properties, such as viewport color, RGB node color or any property with an accessible data path, are synced to the palette you choose.

Palettes support unlimited colors, can be generated with a custom color ramp setup, and can be imported from coolors.co URLs or built yourself. Illustrators and stylized artists can try different colorways on one scene quickly.

Key features

  • Syncs color properties to a palette
  • Unlimited colors per palette
  • Import palettes from coolors.co URLs
  • Custom palette generation with color ramp
  • Works with viewport and node colors
