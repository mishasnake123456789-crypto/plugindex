What Raseone Font Family does

Raseone Font Family from Highground is a graffiti typeface first created in 1999, now available for After Effects and Premiere Pro. It is a layered type system of five styles: original, fill, outline, fat 3D and fade.

Each style holds 238 characters, covering two graffiti alphabets, numbers, punctuation, symbols, arrows and flourishes, with icons and dingbats added. Styles can be stacked on top of each other to make two-dimensional and three-dimensional outline and fill effects. There is some multilingual support, and a color SVG version arrived in 2.0.0.

Key features

  • Five stackable styles
  • 238 characters per style
  • Two graffiti alphabets plus arrows and flourishes
  • Stack styles for 2D and 3D outline effects
  • Color SVG version since 2.0.0
