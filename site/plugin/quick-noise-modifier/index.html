What Quick Noise Modifier does

Quick Noise Modifier is a Blender plugin from sum studio that makes adding shake and jitter fast. Right-click a property and add a Noise modifier, then adjust parameters in a pop-up that opens in the 3D View.

It covers an active object's location, rotation and scale, bone rotation and scale, and light properties. Ideal for adding organic wobble to animation. Adding the modifier directly from the property avoids opening the Graph Editor, making quick organic motion easy to apply and adjust.

Key features

  • Right-click to add Noise modifier
  • Pop-up parameter window
  • Object, bone and light properties
  • Works on the active object
