Blender add-on that aligns chosen UVs to a custom atlas grid defined by a plane mesh, from the UV Editor.

What UV Snapper does

UV Snapper aligns selected UVs to a custom atlas in a single button press, working from the UV Editor. The atlas is a plane mesh with edges standing in for grid lines, which the tool reads to find the grid.

All UV selection methods are supported, including UV Sync mode. Game artists and texture atlas builders who need islands to fit atlas cells exactly can avoid dragging UVs by hand. Texture atlases for games often require islands to sit on exact cells, and snapping removes the guesswork and the pixel bleeding that results from misalignment.

Key features

  • Snaps UVs to a custom atlas
  • Atlas defined by a plane mesh
  • Supports all UV selection methods
  • Works in UV Sync mode
