What Sliceform Popup Tools does

Sliceform Popup Tools converts a 3D mesh into intersecting flat slices that can be assembled into a sculpture or folded like a pop-up card. Materials can be paper, wood, cardboard or metal, so it suits makers, laser cutting and paper engineering.

Four modules split the job: MeshMaker combines objects and uses voxel remeshing to close holes for watertight geometry, SliceMaker sets a grid from X and Y slice counts and boundary offset and cuts pieces with booleans, SlotMaker adds slots, and TabMaker handles pop-up mechanics. Designers and fabricators will find it a complete pipeline.

Key features

  • MeshMaker, SliceMaker, SlotMaker and TabMaker modules
  • Voxel remeshing for watertight meshes
  • Grid by slice counts and boundary offset
  • Pop-up card mechanics
