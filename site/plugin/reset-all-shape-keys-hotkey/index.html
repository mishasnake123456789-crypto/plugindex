What Reset All Shape Keys Hotkey does

Reset All Shape Keys Hotkey is a Blender plugin that sets the shape keys of the chosen mesh to zero in a single step and can add keyframes for the reset values.

You can ignore keys already at zero, choose individual keys to bypass, and leave out keys depending on where they sit in the list. A hotkey can be assigned for fast access. Facial animators will find it useful. Fast resetting is handy when posing faces or testing combinations, since you can return to a neutral state instantly.

Key features

  • Reset all shape keys in one action
  • Optional keyframing of reset values
  • Skip keys already at zero
  • Choose keys to bypass
