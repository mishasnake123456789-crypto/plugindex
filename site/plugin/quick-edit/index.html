Icon shortcuts that jump from Blender Object Mode to Edit Mode with an edge or face tool pre-selected.

What Quick Edit does

Quick Edit adds colored icon buttons for faster mesh editing. Green icons are shortcuts for edge editing and pink icons for face editing.

Clicking one switches from Object Mode to Edit Mode and selects the matching tool; a double-click on the left mouse button returns to Object Mode. It is available as a panel inside Bool It and in the hIVE Bundle, and documentation is included. Among its capabilities are edge and face shortcut icons, enters Edit Mode with the tool ready and double-click back to Object Mode.

Key features

  • Edge and face shortcut icons
  • Enters Edit Mode with the tool ready
  • Double-click back to Object Mode
  • Available in Bool It and hIVE Bundle
