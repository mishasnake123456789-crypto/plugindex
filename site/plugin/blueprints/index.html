What Blueprints does

Blueprints is a Blender add-on by Blenderbob for managing reference images while modeling. It sets up background images in all views automatically, and a swap-axis option makes the X axis the front view.

All images can be adjusted at the same time, which keeps front, side and top references aligned. The add-on requires no special permissions, supports Blender 4.2 LTS and newer, and is released under the GNU GPL v3 or later. Useful for vehicle, character and prop modelers working from blueprints.

Key features

  • Automatic setup of background images in all views
  • Swap-axis option for the front view
  • Adjust all images together
  • Supports Blender 4.2 LTS and newer
  • Requires no special permissions
