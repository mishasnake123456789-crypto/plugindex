What Sound Nodes - Audio Visualization does

Sound Nodes is a Blender add-on by Miha Marinko that analyzes music files and stores the results as keyframes, which keeps previews smooth. That data feeds custom nodes inside the Geometry Nodes editor, letting audio drive animation.

It reads .mp3, .wav, .flac and .ogg files. A Sound Info node outputs loudness, average frequency and beats; spectrogram nodes display the frequency content, and a Chromagram node reveals the energy of musical notes. Motion designers can build visualizers and reactive scenes entirely with nodes.

Key features

  • Extracts audio data into keyframes
  • Custom Geometry Nodes for audio data
  • Supports mp3, wav, flac and ogg
  • Sound Info node with loudness, frequency and beats
  • Spectrogram and Chromagram nodes
