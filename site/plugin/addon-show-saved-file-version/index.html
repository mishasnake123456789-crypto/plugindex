Small Blender add-on that tells you which Blender version the open .blend file was last saved with.

What Addon_Show_Saved_File_Version does

Addon_Show_Saved_File_Version answers a simple question quickly: which release of Blender wrote the file you have loaded. It helps when moving projects between installs.

Trigger it with Shift-Ctrl-V in the viewport or from View > show saved file version. The add-on is distributed under the GPL license and includes documentation. It is a tiny utility, but one that avoids guesswork when a file behaves oddly after being opened in a different version.

Key features

  • Shows the Blender version that saved the file
  • Shift-Ctrl-V shortcut in the viewport
  • Menu entry under View
  • GPL license
  • Documentation included
