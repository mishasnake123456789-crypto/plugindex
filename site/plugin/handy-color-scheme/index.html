What Handy Color Scheme does

Handy Color Scheme brings color theory into Blender's material workflow. From one starting color it generates monochromatic, complementary, analogous or triadic harmonies and applies them to selected objects within a defined threshold.

A Proportion feature applies the 60-30-10 rule automatically, assigning a lead color, supporting colors and wild-card accents. A contrast function adjusts the look of selected objects. It helps beginners and quick concept scenes arrive at balanced palettes. Notable points: four harmony types from one color, automatic 60-30-10 proportion rule and contrast adjustment.

Key features

  • Four harmony types from one color
  • Automatic 60-30-10 proportion rule
  • Contrast adjustment
  • Applies to selected objects
