Generates non-tiling plank floors from individual boards in any closed 2D shape or flat object in 3ds Max.

What FloorGen Tools does

FloorGen Tools by NiK684 creates floors made of separate boards for architectural visualization, avoiding the repetition of a tiled texture. Boards can be generated inside any closed 2D shape or on flat objects and are ready to receive the MultiTexture map.

Board width, length and grout size are individually controllable, and boards can be randomly rotated, offset and tilted. Interactive updates give instant feedback while you adjust settings, textures can be assigned randomly with the MultiTexture Map, and a manual update mode helps with very large floors. The results hold up in close views.

Key features

  • Floors in closed 2D shapes or on flat objects
  • Control of board width, length and grout
  • Random rotation, offset and tilt
  • Interactive update with manual mode for big floors
  • Random textures via MultiTexture Map
