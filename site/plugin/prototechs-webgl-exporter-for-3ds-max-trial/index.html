What ProtoTech's WebGL Exporter For 3ds Max® - Trial does

This is the trial edition of ProtoTech's WebGL Exporter, which saves solid bodies from 3ds Max straight into HTML files. The resulting interactive 3D models open in any modern web browser and can be embedded in web pages.

Face-level and body-level materials export both colors and textures. Precision Control adjusts file size and output quality through precision values, and Tessellation Options let you tessellate at the body or face level. The trial lasts for 15 uses or seven days. It supports 3ds Max 2023 through 2026 on Windows 10 and 11, and lets teams evaluate it before buying.

Key features

  • Exports solid bodies to HTML
  • Face and body-level colors and textures
  • Precision Control for size and quality
  • Body or face tessellation options
