What AE Notepad 2 does

AE Notepad 2 from SUZA VFX is a note-taking panel for editors and animators. Ideas and tasks can be jotted down against a particular moment, then clicked later to return the timeline to that point.

Notes and to-dos carry timestamps, can be set to a priority level and filtered, and can be tagged by comp. Canvas mode supports rich text, work is autosaved every five seconds, and the whole set can be exported to PDF. It runs in After Effects and Premiere Pro, which suits anyone tracking revisions and client feedback during a project.

Key features

  • Timestamped notes and to-dos
  • Jump back to any timeline moment
  • Priority setting and filtering
  • Comp tags and rich text canvas mode
  • Autosave every five seconds and PDF export
