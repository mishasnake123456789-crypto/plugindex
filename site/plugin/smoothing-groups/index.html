Blender shading control system using reusable groups for sharp edges, seams, creases and bevels.

What Smoothing Groups does

Smoothing Groups manages sharp and smooth shading through editable groups rather than hand-marking edges after every mesh change. It suits hard-surface modeling, subdivision workflows, product visualization and game assets.

Five group types work together: Smoothing Groups, UV Seams, Crease, Bevel Weight and Selection. A master group can drive linked ones, and Smart Auto Grouping uses angle or normal detection with live preview. Groups store in mesh data, overlays show in color, a modifier manager and selection tools are built in, and a pie menu and tutorial system are included.

Key features

  • Five linked group types
  • Smart auto grouping with live preview
  • Color overlay and modifier manager
  • Non-destructive, saved in mesh data
