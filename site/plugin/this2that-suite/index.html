Offers a modular Blender add-on suite for generating curves, transferring materials and placing objects to the view or camera.

What This2That Suite does

This2That Suite is a collection of small tools run by a manager, so you enable only the modules you actually need. Panels for each tool can be shown or hidden in the 3D Viewport.

Included tools generate Bezier curves from locations, transfer materials between objects, and position objects relative to the view or camera. The modular approach keeps the interface lean. It suits artists who like focused utilities and want to avoid clutter.

Key features

  • Manager to enable only needed modules
  • Show or hide tool panels in the viewport
  • Location2Curve generates Bezier curves
  • Material transfer between objects
  • Position objects to view or camera
