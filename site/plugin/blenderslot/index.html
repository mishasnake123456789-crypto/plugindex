Blender add-on that records operations as scripts, stores custom scripts and can generate scripts with Ollama AI.

What Blenderslot does

Blenderslot lets you capture what you do in Blender as a script, then name, edit, run and save it without leaving the application.

Saved scripts are kept in the add-on with an add button for later reuse. Version 1.1 added script generation through Ollama, a local AI model runner. Documentation is included, and it supports Blender 3.6.8 LTS and 4.0.2. It suits users who want to automate repeated steps without writing everything by hand.

Key features

  • Records operations as a script
  • Name, edit, run and save scripts
  • Reusable script storage
  • AI script generation with Ollama
  • Supports Blender 3.6.8 LTS and 4.0.2
