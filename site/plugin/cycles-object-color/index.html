Gives every object its own color, separate from mesh and material, through its pass index in Cycles.

What Cycles Object Color does

Cycles Object Color lets one material produce different colors across many objects. Each object's color is driven by its pass index, independent of mesh and material.

The pass index can address 32768 distinct color, grayscale or transparency values, and eight color modes combine color, grayscale and transparency options. Useful for crowds, variations and mass color changes. This avoids duplicating materials just to change tints, keeping shader lists short and renders flexible.

Key features

  • Per-object color from pass index
  • 32768 distinct values
  • Eight color modes
  • One material for many looks
