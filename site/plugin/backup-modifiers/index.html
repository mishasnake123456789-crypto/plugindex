Blender add-on that applies modifiers while keeping a backup object so you can switch back, edit and re-apply later.

What Backup Modifiers does

Backup Modifiers, by R4V3N, removes the fear of applying modifiers. A special apply button creates a backup automatically before the modifiers are applied.

The Original button jumps to the backup copy, and the Applied button returns to the applied version without updating modifiers. You can edit the backup and re-apply at any time. Modelers who need applied geometry but want to keep their non-destructive setup have both.

Key features

  • Apply button creates an automatic backup
  • Original button switches to the backup
  • Applied button returns to the applied object
  • Edit and re-apply anytime
