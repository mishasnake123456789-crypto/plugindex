What Lead Edge Maze Ash Creator does

Lead Edge Maze Ash Creator, from dartmeadow, generates three-dimensional mazes inside Blender. Version 2.4.1 introduced scalable 3D maze cube generation, with the path solution shown either as an animation or instantly, plus an information card for the maze cube.

A solidify feature can be adjusted through the modifier panel. The add-on requires no special permissions. It is suited to puzzle designers, game prototypers and anyone wanting a procedural labyrinth as a model.

Key features

  • Generates 3D mazes in Blender
  • Scalable 3D maze cubes
  • Animated or instant path solving
  • Maze cube info card
  • Solidify adjustable in the modifier panel
