What timeinpixels Nobe Display NDI does

Nobe Display NDI lets DaVinci Resolve send its preview to a chosen place on the desktop, without extra monitoring hardware. It can also stream that image across a network through NewTek NDI, so others can watch the picture on another machine.

The package consists of the Nobe Display App and the Nobe Display Connect OpenFX plugin, and it works on both the Edit and Color pages. Monitor calibration is supported through ICC profiles and a display 3D LUT, with quick gamma, gain and RGB adjustments available. GPU acceleration keeps things real-time. Colorists and editors working with a budget setup or remote clients get a flexible reference display.

Key features

  • NDI output streaming
  • ICC profile and display 3D LUT calibration
  • Works on Edit and Color pages
  • Gamma, gain and RGB quick adjustments
  • App plus OpenFX connect plugin
