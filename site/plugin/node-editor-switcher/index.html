What Node Editor Switcher does

Node Editor Switcher makes moving between Blender's node editors faster. Geometry, Shader, World and Compositor editors are all reachable from one add-on.

A pie menu opens in the Node Editor with E by default, quick access buttons can be enabled at the top right of the header from preferences, and keyboard shortcuts are mapped too. Artists who bounce between shading, geometry nodes and compositing will have fewer menu hunts. Switching with a single click or key reduces the number of times you have to open the editor-type dropdown during a session.

Key features

  • Pie menu opened with E
  • Quick access header buttons
  • Keyboard shortcut mapping
  • Covers four node editors
