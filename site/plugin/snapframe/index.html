After Effects script that exports the current frame as an image in one click at 8, 16 or 32 bit depth.

What SnapFrame does

SnapFrame by Ahmed Abdallah exports a single frame from After Effects as an image with one click. It supports 8-bit, 16-bit and 32-bit depth without altering image colors, and remembers your chosen settings between exports.

When a file with the same name exists, a number is appended so nothing is overwritten. A Default button restores the original settings, and a UI Setting tab provides a delay for the gap between export and import. If import fails because of a slow disk, a retry window appears.

Key features

  • One-click frame export as image
  • 8, 16 and 32-bit depth support
  • Settings retained across exports
  • Auto-numbering to avoid overwrites
  • Retry window for slow disks
