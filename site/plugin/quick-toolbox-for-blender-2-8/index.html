What Quick Toolbox For Blender 2.8+ does

Quick Toolbox for Blender 2.8+ collects tools, brushes and custom preset brushes in a single panel that shows only what suits your current mode. It opens with the spacebar and covers modes from Grease Pencil, Object and Sculpt to Edit, Vertex Paint, Weight Paint, Texture, Node editor and Video editor.

Tools appear alphabetically. New brushes and tools introduced in future Blender releases are added automatically, and that auto update can be turned off in settings. It reduces trips through toolbars and menus when switching tasks.

Key features

  • Mode-specific tools across many editors
  • Opens with the spacebar
  • Custom preset brushes
  • Auto-adds new tools from Blender updates
  • Alphabetical tool list
