Blender 2.79 and 2.80 add-on for faster render resolution switching and custom resolution buttons.

What Res Switch does

Res Switch adds a panel to the Render tab and the compositor's Node Editor in Blender 2.79 and 2.80, giving a quicker way to change resolution for rendering and compositing.

It can swap X and Y, apply a resolution by percentage, keep the aspect ratio, and set the scene resolution from an active node or selected image in one click. Custom resolutions are saved as buttons inside the file, with an edit mode for reordering. Aspect ratios are displayed with an adjustable pixel tolerance.

Key features

  • Swap X/Y and percentage-based resolution
  • Set resolution from node or image
  • Custom resolution buttons saved in the file
  • Aspect ratio display with tolerance
