What Synctools Pro For Marvelous Designer does

SyncTools Pro links Marvelous Designer and Blender through a copy/paste workflow built on a unified FBX-based exchange. Garments, cloth simulation results, UV layouts and basic materials travel between the two applications.

Synchronization goes both ways from the same shortcut. Each MD garment arrives as its own Blender object with names and groups intact, its auto-generated UV layout carries over for shading, and baked cloth animations come across as keyframes. It speeds up clothing pipelines.

Key features

  • Two-way sync with Marvelous Designer
  • Garments as separate named objects
  • UV layout carried over
  • Baked cloth animation as keyframes
