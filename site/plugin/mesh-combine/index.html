What Mesh Combine does

Azerilo's Mesh Combine fuses several objects into a single mesh and combines their textures in an atlas, readying assets for Unity, Unreal Engine or web 3D viewers.

Full PBR is supported: Color, Normal, Roughness and Metallic atlases are produced in sync. A shelf-packing algorithm arranges textures efficiently, preferring square atlases up to 8K, and UVs are remapped automatically on duplicated objects. Game and web developers cut draw calls and file counts. Combining meshes and textures this way also makes asset libraries simpler to manage and upload.

Key features

  • Merges objects into one mesh
  • Synchronized Color, Normal, Roughness and Metallic atlases
  • Shelf-packing up to 8K
  • Automatic UV remapping
  • Targets Unity, Unreal and web viewers
