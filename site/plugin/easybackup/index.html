What Easybackup does

Easybackup saves a copy of your project elsewhere without touching the original. It targets artists who want tidy, reliable backups stored in a set folder.

The backup packs all textures and adds date, time and a custom suffix to the name, duplicating the file if one with that name exists. It can write to a cloud-synced folder such as OneDrive and reports when you last backed up. Default Path and Custom Path methods are available, with settings saved per blend file.

Key features

  • One-click backup to another directory
  • Packs textures, adds date, time and suffix
  • Cloud folder support
  • Last backup time reporting
