What Swap Resolution does

Swap Resolution saves you from retyping width and height whenever a project changes orientation. It is for people who move between vertical and horizontal formats regularly.

The button sits in Properties under Format and switches the render settings between portrait and landscape. It installs as an ordinary add-on from a .zip file, includes documentation, and is released under the GPL.

Key features

  • Toggles portrait and landscape
  • Located in Properties under Format
  • Installs from a .zip file
