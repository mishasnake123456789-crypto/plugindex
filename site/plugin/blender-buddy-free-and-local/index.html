What Blender Buddy (Free And Local) does

Blender Buddy is an in-app helper from CGMatter that lets you ask questions, run code and look things up online while staying inside Blender. Its answers draw on the Blender API and documentation, so it is geared toward scripting and tool questions rather than generic advice.

It installs through Blender's extension system and is released under the GPL license. The idea is simple: cut down on switching between Blender, a browser and a script editor when you are stuck.

Key features

  • Ask questions from inside Blender
  • Run code within the application
  • Search online without leaving Blender
  • Answers based on the Blender API and documentation
  • Installs through Blender's extension system
