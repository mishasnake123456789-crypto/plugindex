What DataWire does

DataWire turns general object properties in 3ds Max into parameters that can be wired. A custom modifier turns values like face count, spline length and dimensions into parameters that can be wired to other objects or a TextPlus 3D text object.

Each parameter has a pick button for easy integration with the parametric TextPlus object. Spline properties include number of vertices, total length and X, Y, Z dimensions, and geometry properties include vertex count, face count and dimensions. This makes it simple to build setups where text or objects react to live measurements, useful for infographics, architectural projects and statistics displays.

Key features

  • Custom modifier exposing object properties
  • Pick button on each parameter for TextPlus integration
  • Spline vertex count, length and dimensions
  • Geometry vertex count, face count and dimensions
  • Wires values to other objects or 3D text
