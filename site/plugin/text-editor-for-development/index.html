What Text editor for Development does

Text editor for Development improves Blender's built-in text editor for people writing add-ons. A folder-view explorer in the sidebar works like VSCode's, letting you browse project files.

The Templates menu can copy learning material or a multi-file add-on starter template into a local folder. Preferences control which sidebar category hosts the explorer and the default names for new files and folders, show hidden items, and choose whether deleted texts unlink from the blend file. It requests file and network permissions for browsing folders and cloning remote Git repositories.

Key features

  • VSCode-style folder explorer
  • Clone learning material
  • Clone a multi-file add-on template
  • Show hidden items and unlink options
  • Requests file and network permissions
