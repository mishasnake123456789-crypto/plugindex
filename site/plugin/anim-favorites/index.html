What Anim Favorites does

Anim Favorites spares you from retyping search filters while animating. Save filter text as favorites and click one to apply it immediately.

Favorites can be stored per file (local) or across all projects (global), and local ones can be promoted to global. Convenient for riggers and animators who filter the same channel names repeatedly. The saved terms make it easier to jump straight to channels such as a specific bone or property when animating.

Key features

  • Save filter text as favorites
  • One-click filter application
  • Local or global storage
  • Promote local to global
