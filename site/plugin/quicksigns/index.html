Blender add-on that builds 3D text signs from over 1,000 searchable Google Fonts with adjustable size, depth and bevel.

What QuickSigns does

QuickSigns links Blender to Google Fonts so you can build 3D lettering without leaving the program. Search and download from more than a thousand free fonts, then set size, depth and bevel and create a sign with one click.

Fonts can be browsed by style, including serif, sans serif, handwritten, display and monospace, and a live preview helps compare choices before committing. Artists making shop fronts, titles and logos in 3D can skip manual font installation.

Key features

  • Google Fonts search and download
  • Style filters like serif and handwritten
  • Live font preview
  • Adjustable size, depth and bevel
  • One-click sign creation
