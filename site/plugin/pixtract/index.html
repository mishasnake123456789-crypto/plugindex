What Pixtract does

Pixtract exports sprite sheets from Blender for use in 2D and game projects. It can draw from actions, Grease Pencil animation and shape keys, so several kinds of animated assets share one export path.

It writes accompanying JSON for engines such as Unreal and renders with Cycles or Eevee. It works with the Blender extensions system, and the developer provides documentation.

Key features

  • Sprite sheet export
  • Actions, Grease Pencil and shape keys supported
  • JSON output for Unreal and similar engines
  • Renders with Cycles or Eevee
