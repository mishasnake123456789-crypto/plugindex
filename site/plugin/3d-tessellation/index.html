What 3D Tessellation does

3D Tessellation brings Delaunay and Voronoi tools to Blender. It subdivides a closed mesh into tetrahedra, useful for FEM simulations and physical analysis, or into organic Voronoi cells with cavity handling.

Generation runs through four steps, starting with surface extraction using adaptive subdivision and internal point generation, followed by boundary clipping. Weight Paint controls point density, and a Smooth SFD asset smooths organic surfaces. Designers, engineers and researchers can use it for lattice and fracture-like structures.

Key features

  • Delaunay tetrahedra for FEM and analysis
  • Voronoi cells with cavity handling
  • Four-step generation pipeline
  • Weight Paint density control
  • Smooth SFD asset for organic surfaces
