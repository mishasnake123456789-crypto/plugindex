What Multi Objects Workflow - Sculpt, Paint & Weight Paint Multiple Meshes Non-Destructively does

Multi Objects Workflow lifts a limitation in Blender where sculpting and painting act on one object at a time. Select several meshes, begin a session, and the edits flow back to each original object on their own.

That means sculpting across seams between parts, weight painting body, clothing and accessories at once, and painting shared vertex color attributes. Texture paint is written to the images used by each object's materials, and edit-mode topology work crosses object boundaries with weights and attributes carried over. Material slots merge without index clashes. It fits characters with armor pieces and modular kits.

Key features

  • Sculpt across multiple objects
  • Joint weight painting
  • Unified vertex color painting
  • Texture paint saved to each material's images
  • Edit Mode work across object boundaries
