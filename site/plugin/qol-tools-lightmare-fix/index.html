What Qol Tools: Lightmare Fix does

QOL Tools: Lightmare Fix reduces clutter from lights in Cycles viewports. Unused custom distances leave long lines, and this tool removes them from the View menu.

It acts on all lights by default by setting custom distances to zero, and can also turn off the custom distance in Eevee. It uses the Blender 4.2 extension format, is included free in the QOL Tools full collection, and has documentation.

Key features

  • One-click light clutter removal
  • Acts on all lights by default
  • Eevee custom distance toggle
  • Blender 4.2 extension format
