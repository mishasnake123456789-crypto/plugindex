What Matrix World Data Addon does

Matrix World Data Addon reports the position and rotation of a rigid body object while a simulation plays. It gives you the exact numbers for whichever frame you inspect.

It works in Blender 2.79b and 2.8 or later, is released under a Creative Commons license, and includes documentation with a detailed tutorial. The readout helps anyone who needs accurate transform data from physics results, such as for placing objects or reproducing a simulated pose.

Key features

  • Displays rigid body location and rotation
  • Exact values at any frame
