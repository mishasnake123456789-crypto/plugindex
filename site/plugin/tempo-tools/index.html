What Tempo Tools does

Tempo Tools is a Blender plugin for making animation that follows music. You set the BPM and length, and the scene is adjusted into a loop with a grid drawn on the timeline so every move lands on the beat.

The Animator drives a selected object's location, rotation and scale and lets you set speed, and the Beat Grid decides which beats trigger motion. Noise modifiers add variation. VJs and motion designers can quickly produce loops and audio visualizers that stay in time.

Key features

  • BPM and length setup with a timeline grid
  • Animate location, rotation and scale
  • Choose which beats the motion hits
  • Noise modifiers for variation
