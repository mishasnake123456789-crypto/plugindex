Applies stylized graffiti to any Blender object from the viewport sidebar in one click, without editing nodes.

What Easy Graffiti does

Easy Graffiti puts street-art style surfaces on objects with no shader work. Choose a style and click, and graffiti is added in a non-destructive way, leaving the original materials intact.

Styles can be swapped or replaced at any time, and several textures with different masks can be layered for varied results. Everything is operated from the 3D Viewport sidebar. Environment artists dressing walls and urban props can add believable tagging quickly.

Key features

  • One-click graffiti application
  • Swap or replace styles any time
  • Layer textures with different masks
  • Non-destructive, original materials stay
  • Controlled from the 3D Viewport sidebar
