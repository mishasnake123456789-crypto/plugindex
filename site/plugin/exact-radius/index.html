What Exact Radius does

Exact Radius is a Blender plugin for modelers who need circular holes and rings at precise sizes. Select a ring of vertices, type a radius, and it becomes a true circle of that measurement.

The value works like input for Move or Scale, and math expressions are accepted, so typing 20/2 converts a diameter to a radius. It can handle one ring or several at once, such as separate holes or several rings stacked in one mesh, each is fitted and resized on its own. Editing several objects together also works.

Key features

  • Type an exact radius, with math expressions
  • Fits perfect circles to selected vertex rings
  • Handles many rings independently
  • Multi-object Edit Mode support
