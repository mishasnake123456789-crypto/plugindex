What Qol Tools: Spec Lighting Ops does

QOL Tools' Spec Lighting Ops is a compact set of utilities for specular lighting in Cycles. A pie menu, opened with the right mouse button or L, places highlights, and its main command adds a soft light.

It offers a simpler path into Blender's native light linking, with choices to light only selected objects or to leave them out. Each new light gets its own custom node network controlling shape, placement and color. Product and lookdev artists shaping reflections benefit.

Key features

  • Highlight placement from a pie menu
  • Add soft light command
  • Simpler light linking
  • Light or exclude selected objects
  • Custom node network per light
