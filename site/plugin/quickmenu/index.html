Blender add-on offering quick access to object and modifier creation, view display, camera placement and render management.

What QuickMenu does

QuickMenu gathers frequent Blender actions into fast shortcuts, covering object and modifier creation, viewport display tweaks, camera setup and render management. Context checks have been tuned so the features trigger more reliably.

Quick-Add provides eight buttons that add everyday objects and modifiers, next to a Quick-Mod tool, and new objects snap to the location and orientation of the 3D Cursor. A Quick Origin Setup shortcut works in both Object and Edit Mode, and Quick-Cam attaches the camera to the current perspective. It suits anyone who wants fewer menu trips during everyday scene building.

Key features

  • Eight-button Quick-Add and Quick-Mod
  • New objects align to the 3D Cursor
  • Origin setup in Object and Edit Mode
  • Quick-Cam snaps camera to current view
  • Render management shortcuts
