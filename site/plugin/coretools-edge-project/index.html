What Coretools - Edge Project does

Coretools - Edge Project extends selected open edges of one or more objects until they meet nearby visible geometry in Blender. Each edge is extended on its own, in its own direction in world space, which makes it helpful for closing gaps or fitting borders to a surface.

It supports editing single or multiple objects at once and considers all visible meshes, including those with temporarily hidden geometry. A filter ignores objects displayed as Bounds or Wire, and the object itself. Documentation is included. Hard-surface and architectural modelers fitting panels, trims or borders will find it faster than manual extrusion.

Key features

  • Projects open edges toward visible geometry
  • Each edge extends independently in world space
  • Single and multi-object editing
  • Filter ignores Bounds and Wire objects
