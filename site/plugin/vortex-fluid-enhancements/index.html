Blender add-on that adds procedural animated detail to fluids using simulation data, with wave, water and foam tools.

What Vortex - Fluid Enhancements does

Vortex adds detail to water and other fluids in Blender, drawing on the data from the actual fluid simulation so waves move with the flow.

Vortex Flow generates procedural, animated waves, Vortex Water is a physically based shader for reflection, diffuse scattering and transmission, and Vortex Foam makes foam maps. VFX artists can raise the realism of simulated liquids. Because the detail is driven by the simulation itself, ripples and foam line up with the actual motion of the liquid instead of looking like a separate overlay.

Key features

  • Vortex Flow wave generator
  • Physically based Vortex Water shader
  • Vortex Foam map generation
  • Uses fluid simulation data
