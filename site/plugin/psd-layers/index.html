What Psd-Layers does

Psd-Layers is a Blender add-on from Split Studios that brings a layer-based painting workflow, similar to Photoshop or Krita, into Blender. Each layer's blend mode, opacity and visibility are controlled through ordinary Blender shader nodes.

It supports PBR painting using a metalness setup, with channel maps that can be baked, plus a solo button that shows each channel on its own in the 3D View. You also get image mapping, masking, a palettes section that pastes hex values from websites, and a per-layer pack icon that goes red when an image has unsaved changes.

Key features

  • Layered texture painting with blend modes and opacity
  • PBR metalness workflow with channel map baking
  • Solo button to view single channels
  • Image mapping, masking and spreadsheet editing
  • Palette section that pastes hex colors from the web
