What Right-Angled Node Connection does

Right-Angled Node Connection, by hyee_haw, offers tools for routing links between nodes at right angles, which tends to make a node graph look tidier and easier to read. It is listed in the Node category.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.
