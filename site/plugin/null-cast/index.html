What Null Cast does

Null Cast streams live video onto objects in a Blender scene. Built with OpenCV and MSS, it enables in-camera visualization without screen replacement in post-production.

Webcam Mode takes input from USB cameras or capture devices at resolutions from 320x240 to 1920x1080, and Screen Mode mirrors your desktop, specific monitors or custom regions. Useful for virtual production, monitor displays and live demonstrations. Among its tools are webcam streaming from USB or capture devices and screen capture of desktop, monitor or region.

Key features

  • Webcam streaming from USB or capture devices
  • Screen capture of desktop, monitor or region
  • Live projection onto any mesh
  • No post-production screen replacement
