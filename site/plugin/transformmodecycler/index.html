What TransformModeCycler does

TransformModeCycler is a set of four macros by Martin Breidt designed for assignment to keyboard shortcuts in 3ds Max. They switch between selection and transform modes and cycle through the commonly used coordinate systems, so common changes need only a keypress.

Q, W, E and R are given as an example set of bindings. The listing shows compatibility with 3ds Max 4, and it is marked obsolete since R5, since later versions added similar functionality. It is mainly of historical interest or for users of old versions who want a quicker way to change modes and reference coordinate systems without using toolbars.

Key features

  • Four macros for keyboard shortcuts
  • Switch between select and transform modes
  • Cycle through common coordinate systems
  • Q, W, E, R example binding set
  • Works with 3ds Max 4, obsolete since R5
