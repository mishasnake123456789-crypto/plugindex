What PinSolver does

PinSolver, by K_Naoki, matches cameras and objects to images in Blender by linking points on the picture to points in 3D space, using OpenCV's Perspective-n-Point algorithm. It covers work from a single static frame to video matchmoving.

Layout Mode handles single-frame camera matching and prop placement, while Matchmove Mode works with Blender's 2D tracking data to bake camera or object animation. One pin snaps along the camera ray, two pins give basic orientation and translation, and three or more solve full six-degree-of-freedom position and rotation.

Key features

  • OpenCV PnP point linking
  • Layout Mode for single-frame matching
  • Matchmove Mode bakes camera or object animation
  • 1-Pin and 2-Pin modes
  • 3+ pins solve full 6DoF
