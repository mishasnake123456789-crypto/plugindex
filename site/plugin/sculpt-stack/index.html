Blender sculpt mode add-on that captures passes as blendable layers with weight sliders, masks and baking.

What Sculpt Stack does

Sculpt Stack brings a layer workflow to Blender sculpting. Each sculpt pass becomes an independent layer.

Any number of layers can be captured, each with a weight slider adjustable live before baking. A master opacity fades the whole stack for quick before and after comparisons. Per-layer masking uses Blender's native Mask brush, so you can paint, preview and bake the masked result. Adjusting layer strength late in the process lets sculptors experiment without redoing work.

Key features

  • Blendable sculpt layers
  • Per-layer weight sliders
  • Master opacity control
  • Per-layer masking with Mask brush
  • Bake when satisfied
