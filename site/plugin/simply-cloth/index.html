What Simply Cloth does

Simply Cloth Studio 2 streamlines making and simulating clothing in Blender. It was redone for Blender 5.0 with a fresh interface and better speed, putting garment setup in one toolset.

An adaptive wrinkle recognition system generates wrinkle maps from the current frame and a weight map, with controls for threshold, subdivision, modifier position and merge distance. Pinning, sewing and a collection of cloth presets are part of it. Character artists and animators who need convincing fabric behavior without building every setup manually will find it a useful time saver.

Key features

  • Adaptive wrinkle recognition system
  • Wrinkle generator with threshold and subdivision controls
  • Pinning and sewing tools
  • Cloth presets
  • Built for Blender 5.0
