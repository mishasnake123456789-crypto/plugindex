Meshinator

Loads Blender meshes from dropped images and saves scenes back to image files.

What Meshinator does

Meshinator treats images as containers for geometry. Drag an image into Blender and a mesh is generated, or save a full scene back to an image in one click.

Meshes can also be added from your file explorer via drag and drop. Extra tools separate textured materials in one click and apply location, rotation, scale and modifiers. An unconventional way to move meshes around. It is an unusual approach that may appeal to artists who like to share or archive meshes as pictures.

Key features

  • Load and save meshes as images
  • Drag-and-drop mesh generation
  • Add meshes from the file explorer
  • One-click textured material separation
  • Apply transforms and modifiers
