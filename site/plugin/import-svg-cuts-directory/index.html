FreeBlender

Blender add-on that imports all SVG files from a folder and extrudes and stacks them into one object.

What Import SVG Cuts Directory does

Import SVG Cuts Directory builds a 3D object from a folder of SVG cut profiles. It appears in File, Import, SVG Cuts Directory.

Every SVG in the chosen directory is imported, then extruded and assembled according to distance and extrusion options. Cuts are ordered alphabetically by filename. Makers working with layered laser-cut or sliced models can reconstruct them in 3D. The result is a stacked 3D form built from flat outlines, which is a common way to reconstruct objects from sliced profile drawings.

Key features

  • Imports every SVG in a directory
  • Extrude and assemble by distance
  • Alphabetical ordering by filename
  • File > Import menu entry
