What Colume does

Colume is a grape design plugin that generates color gradients in 3D space from the lights in a composition. It works with the camera, so gradients behave correctly as the view moves, and the type of light does not matter.

Color space and interpolation mode are selectable, and spatial turbulence can be blended in, with adjustable strength and map scale plus phase shift and speed for animation. An option limits the effect to lights whose names start with color. GPU acceleration keeps previews quick, and the controls are straightforward.

Key features

  • Gradients from lights in 3D space
  • Camera compatible
  • Color space and interpolation choices
  • Animatable spatial turbulence
  • Option to use only lights named color
