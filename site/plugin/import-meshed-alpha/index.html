Blender add-on that turns an image's alpha channel into mesh objects with non-destructive pre-processing.

What Import Meshed Alpha does

Import Meshed Alpha creates mesh objects from the transparency of an image in Blender. Pictures can come in through the add menu or by converting existing image reference planes, which keep their transforms.

Before conversion you can adjust the image non-destructively with RGB as alpha, black and white points, invert, predivide, dilate and erode. Outlines are fitted with spline, poly or per-pixel tracing, and the mesh can be cleaned by dissolving to n-gons, dividing, triangulating and removing small islands. Output is fully UV unwrapped, and a Finalize button locks the settings.

Key features

  • Mesh generated from the alpha channel
  • Import via add menu or reference plane conversion
  • Non-destructive levels, invert and dilate controls
  • Spline, poly or per-pixel curve tracing
  • UV-unwrapped output with optional material
