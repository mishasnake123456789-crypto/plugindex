What AEJuice Fix Legacy Expressions does

AEJuice Fix Legacy Expressions updates expressions in a project so they run under the JavaScript engine introduced in After Effects 16, which broke a number of older habits. The fixes keep expressions working in both old and new versions.

It corrects if and else on one line without brackets, expressions ending in a function declaration, the this() shorthand (replaced with thisLayer()), snake case properties and methods, and Source Text character access, which gets .value added. It saves hours when reviving older projects.

Key features

  • Updates expressions for After Effects v16+
  • Fixes if/else without brackets
  • Replaces this() with thisLayer()
  • Fixes snake case properties and methods
  • Adds .value for Source Text character access
