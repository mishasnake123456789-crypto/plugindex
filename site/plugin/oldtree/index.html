A Blender add-on that generates a complete tree with trunk, branches, roots, moss and ivy in a few clicks.

What Oldtree does

Oldtree produces a whole tree in Blender in two or three clicks, covering the trunk, branches, roots, moss, ivy and leaves. Every press of Create Tree gives a brand new result, so a forest can be filled with unique, aged-looking trees.

A Deform Tree value bends the branches and trunk, with higher numbers adding more effect and lower ones straightening the tree. Size Tree scales height and Create root adds roots. The generated tree comes prepared with vertex groups, a UV map with seam edge, and vertex colors for bark roughness and moss color. Environment artists who need characterful old trees will find it convenient.

Key features

  • Full tree with trunk, branches, roots, moss and ivy
  • New variation on each Create Tree press
  • Deform and size parameters
  • Prepared vertex groups, UV map and vertex colors
