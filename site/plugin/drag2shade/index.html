What Drag2Shade does

Drag2Shade makes material setup in Blender a drag-and-drop job. Release an image on a mesh in the viewport or in the Shader Editor, and the add-on figures out what kind of map it is and connects it to the Principled BSDF.

Detection works from filenames and recognizes ten map types, from base color and roughness to transmission, specular and displacement. When a name is ambiguous, a popup lets you pick the slot. An N-panel offers whole-folder import and a paste-URL option that downloads a texture. Each material's textures sit inside one tidy node group, and a controller panel gives per-slot pickers.

Key features

  • Drop textures onto meshes or the node editor
  • Filename-based map detection
  • Manual slot picker for unclear names
  • Folder import and URL download
  • Textures wrapped in one node group
