Blender Compositor add-on that assigns Cryptomatte ID mattes from the active collection's objects automatically.

What Compositor Mask does

Compositor Mask automates matte setup in the Blender Compositor Editor.

An Add button collects Mesh and Curve objects from the active collection, including nested children and child collection objects, and sets their names as Matte IDs. A Remove button clears those IDs and leaves other objects unchanged. All other object types are filtered out. It spares you from typing each name. This makes it quick to isolate objects in post-production for color correction or compositing.

Key features

  • Auto-assigns Cryptomatte Matte IDs
  • Collects meshes and curves with nested children
  • Remove button clears IDs
  • Filters out other object types
  • Add and Remove node setup
