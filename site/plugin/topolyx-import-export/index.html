What Topolyx Import/Export does

Topolyx Import/Export adds support for the Topolyx format to Blender. It lets you bring Topolyx meshes into a scene and write Blender meshes back out in the same format.

This is mostly useful for anyone whose workflow includes the Topolyx tool and who wants to move geometry between it and Blender without converting through other formats. The add-on keeps that exchange within Blender's own import and export menus.

Key features

  • Imports Topolyx meshes
  • Exports meshes to Topolyx
  • Adds format support to Blender
