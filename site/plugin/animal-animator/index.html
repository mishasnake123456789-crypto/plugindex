What Animal Animator does

Animal Animator is a Blender add-on offering ready-made poses and animation for animal rigs. It targets the common problem of animating quadrupeds and other creatures from scratch, where convincing movement takes a lot of time.

The animations are described as game-ready, so they suit developers and indie artists who need believable animal motion for real-time projects. Applying library content to a rig gives a quick base that can then be refined by hand.

Key features

  • Pose and animation library
  • Designed for animal rigs
  • Game-ready motion
  • Starting point for hand tweaking
