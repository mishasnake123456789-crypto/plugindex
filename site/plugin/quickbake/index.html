Automates Cycles texture baking prep and bakes multiple modes or objects at once in Blender.

What Quickbake does

QuickBake handles the preparation that Cycles baking normally demands before you press the button. It sets up what is needed and then bakes in the modes you choose.

Modes such as diffuse and roughness can run together, and several objects can bake into one texture, or into one texture per mode. New UVs can be created based on existing ones. Game artists consolidating props into a shared atlas will save a lot of setup time.

Key features

  • Automatic bake preparation in Cycles
  • Runs several bake modes together
  • Multiple objects into one texture
  • Creates new UVs from existing ones
