Blender Edit Mode add-on that grows mesh selections from a clicked element through adjacency flood fill with live preview.

What Magic Wand does

Magic Wand adds a topology-aware selection tool to Blender. Click a face, edge or vertex and the selection expands outward through connected geometry, similar to a magic wand in image editors.

A real-time preview shows what will be selected before you commit, and sidebar settings tune the behavior. Modelers isolating panels, regions or components in dense meshes can select them in a single click.

Key features

  • Flood-fill selection from face, edge or vertex
  • Real-time preview before committing
  • Sidebar settings
  • Works in Edit Mode
