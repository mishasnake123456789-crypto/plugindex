What Boolean Bevel Addon does

Boolean Bevel Addon, from Bukoros Design, offers bevel-friendly boolean operations for Blender's subdivision modeling. It is built entirely with Geometry Nodes, so each operation is stored as a modifier that stays editable or can be deleted at any moment.

Modes include Surface, Strip, Emboss, Slide and Slice. Bevels can use a custom profile and variable width, sharp corners are governed by the Break Angle parameter, and you can pick either the Manifold or Exact boolean solver. Hard surface modelers can cut details without wrecking topology.

Key features

  • Fully Geometry Nodes, non-destructive
  • Surface, Strip, Emboss, Slide and Slice modes
  • Custom bevel profile and variable width
  • Break Angle for sharp corners
  • Manifold or Exact boolean solver
