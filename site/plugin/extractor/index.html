3ds Max script that saves each selected mesh as its own Max file and captures a screenshot of each one.

What Extractor does

Extractor splits a scene into individual assets in 3ds Max. All selected meshes are saved as separate Max files, and a screenshot of each extracted mesh is captured along with it.

Groups can be handled as a single entity or their children can be extracted as separate assets. Drag Extractor.mcr into the viewport to install; 3ds Max 2023, 2024 and 2025 are supported. Artists building asset libraries from large scenes will like having a file and preview image for every piece without exporting each by hand.

Key features

  • Extracts selected meshes into separate Max files
  • Screenshot of each extracted mesh
  • Group as one entity or children as separate assets
  • Drag-and-drop Extractor.mcr install
  • Works with 3ds Max 2023 to 2025
