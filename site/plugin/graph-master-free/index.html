A free After Effects tool for building and animating procedural bar graphs.

What Graph Master Free does

Graph Master Free helps motion designers create bar charts without rigging each bar manually. The setup is fully procedural with an open structure, so you can customize it deeply.

It includes an expandable library of presets and three shading types. You can use any number of bars, which align themselves automatically, or use dual bars. Layouts switch between horizontal and vertical, or between positive and negative values, with one click. Graphs come already animated and are quick to customize.

Key features

  • Fully procedural, open structure
  • Expandable preset library
  • Three shading types
  • Any number of bars, with dual bar option
  • One-click horizontal/vertical and positive/negative switch
