Blender add-on that turns Sculpt Mode face sets to material slots, UV maps, vertex groups or integer attributes.

What Face Set Operators does

Face Set Operators lets you draw divisions with brush strokes in sculpt mode and turn them into other data. This saves selecting faces in edit mode.

Face Sets can become material slots with dummy materials, which helps with ID mapping for Substance Painter or the Quad Remesher add-on, plus UV maps, vertex groups and integer attributes. Sculptors and texture artists preparing models for painting or retopology can work more fluidly.

Key features

  • Face sets to material slots
  • Face sets to UV maps
  • Face sets to vertex groups
  • Face sets to integer attributes
