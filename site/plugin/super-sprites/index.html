What Super Sprites does

Super Sprites is a rendering setup for Blender that turns 3D models into 2D sprites in a pixel art style. Model and animate a character, then render it across a number of directions you choose.

The directional renders can produce a turntable effect or speed up character animation output. Shadows and height information can also be exported. It suits indie developers creating retro-styled games. The approach gives a consistent, repeatable way to turn one animated model into complete sets of directional frames for 2D engines.

Key features

  • 3D to 2D pixel art sprite setup
  • Render in a chosen number of directions
  • Turntable effect output
  • Exports shadows and height data
