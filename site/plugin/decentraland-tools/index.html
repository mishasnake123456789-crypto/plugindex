What Decentraland Tools does

Decentraland Tools prepares content for the Decentraland platform inside Blender. It creates parcel grids at 16 meters per parcel and checks scene limits for triangles, entities, materials, textures and height as you work.

Wearable tools import official base meshes and validate per-category limits, while the emote workflow uses the official avatar rig. Material utilities batch replace, resize and validate textures, LODs are generated by decimation, and a PBR atlas optimizer merges compatible materials. One-click GLB export applies Decentraland-friendly defaults, alongside cleanup and renaming tools.

Key features

  • Parcel grids with live scene limit checks
  • Wearable base meshes and validation
  • Emote rig workflow
  • LOD generation and PBR atlas optimizer
  • One-click GLB export with Decentraland defaults
