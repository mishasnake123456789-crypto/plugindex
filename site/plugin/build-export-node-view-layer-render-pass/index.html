What Build Export Node [View Layer Render Pass] does

Build Export Node, by Bookyakuno, builds the compositing network needed to save render passes in Blender. Click the button, render, and each pass lands as an image. Choose between every pass of the active view layer or every pass of every layer.

Depth and mist are normalized and inverted for export, Cryptomatte connects to produce a pick image like an ID map, and denoising nodes are added when denoising data is on. It can also batch-set pass indices for materials and objects, randomly color objects for coding, and separate output into folders per view layer.

Key features

  • Builds export nodes for all passes
  • Depth and mist prepared for export
  • Cryptomatte pick image support
  • Denoising node setup
  • Batch pass index and per-layer folders
