What Incremental Auto-Save does

Incremental Auto-Save by Mets strengthens Blender's native autosave. It never replaces existing autosaves and keeps a customizable number of backups.

If the chosen autosave path is invalid it uses the system temp folder as a fallback, it saves unsaved files such as Unnamed.blend, and it accepts several autosave paths and uses the first one that works. Anyone who has lost work to a crash will appreciate the safety net. Keeping several versions is valuable when a bad edit goes unnoticed for a while and you need to step back further than the latest save.

Key features

  • Never overwrites existing autosaves
  • Customizable number of backups
  • Autosaves unsaved files
  • Fallback to OS temp folder
  • Multiple autosave paths
