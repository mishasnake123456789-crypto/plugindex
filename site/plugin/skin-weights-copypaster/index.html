What Skin Weights Copypaster does

Skin Weights Copypaster is a Blender add-on by Ihor-Spasivskyi for transferring skin weights vertex to vertex. It copies the weights of the first vertex in a selection and pastes them across other vertices, in Edit and Weight Paint modes.

Pasting can clear existing vertex groups on the targets first, and weights can be normalized afterward if the copied values were not. A set-weight operator applies precise values from a preset list that can be adjusted in a viewport panel, and in Weight Paint mode an edge loop can be selected.

Key features

  • Copies weights from the first selected vertex
  • Paste with optional clearing of existing groups
  • Optional weight normalization
  • Set exact weight values from presets
  • Edge loop selection in Weight Paint mode
