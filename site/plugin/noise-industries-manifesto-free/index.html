What Noise Industries Manifesto (Free) does

Noise Industries' Manifesto creates static titles, rolls and crawls for After Effects, DaVinci Resolve and Premiere Pro. Rolls and crawls adopt the duration of the clip, so no keyframing is needed.

Simple one-line titles are edited from the parameter inspector, while a separate text window handles more elaborate styling. It can read existing RTF files from disk so layout can be done elsewhere, includes motion blur and de-flickering at any frame rate, and can mask titles with external media. Several templates are supplied. Editors producing credits and captions quickly will appreciate the minimal setup.

Key features

  • Static titles, rolls and crawls
  • Duration matches the clip, no keyframes
  • Reads RTF files from disk
  • Motion blur and de-flickering
  • Masking with external media and bundled templates
