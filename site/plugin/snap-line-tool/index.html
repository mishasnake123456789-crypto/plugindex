What Snap Line Tool does

Snap Line Tool builds on Blender's built-in snapping by adding a line tool for drawing geometry. It was originally bundled with Blender 4.1 and is found at View3D > Tools > Line Tool.

It belongs to the Mesh category, works with Blender 4.2 LTS and newer, needs no special permissions and is released under GPL v3 or later. Modelers who draw edges and faces by snapping to existing geometry can lay out precise outlines faster.

Key features

  • Line tool built on snapping
  • Found under View3D Tools
  • Mesh category tool
  • For Blender 4.2 LTS and newer
