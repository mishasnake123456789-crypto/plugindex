What Animax - Procedural Animation System does

Animax offers a simple way to animate multiple instances in Blender without writing math or building geometry node trees. It provides twelve effects and dozens of presets.

There are 34 animation presets and mesh fracturing tools with 13 fracturing presets, and custom presets can be saved and loaded. Objects inside a collection can be animated, procedural text animation is supported, and instances from any geometry node tree can be animated. Motion designers can create intricate patterns, reveals and breaking effects fast.

Key features

  • 12 animation effects and 34 presets
  • Mesh fracturing with 13 presets
  • Save and load custom presets
  • Animate collections, text and instances
