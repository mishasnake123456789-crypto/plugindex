What Rotate To Grid does

Rotate To Grid orients an object in 3ds Max so that a selected edge lines up with the closest axis, using face normals to decide. Edit Poly and Editable Poly are both handled.

When non-planar faces share a smoothing group it uses their average normal, and when they share none it uses the normal of a single face. Drag the .ms file into the viewport or use Scripting, Run Script; a Rotate to Grid entry then shows up under Custom for hotkeys or toolbars. It was tested on 3ds Max 2023 and 2024, and helps align background planes in virtual studios or restore lost orientation.

Key features

  • Orients an object along a selected edge to the nearest axis
  • Works with Edit Poly and Editable Poly
  • Average normal for non-planar faces in a smoothing group
  • Adds a Custom category entry for hotkeys or toolbars
  • Tested on 3ds Max 2023 and 2024
