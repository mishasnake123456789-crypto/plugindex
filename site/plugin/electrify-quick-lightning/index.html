What Electrify - Quick Lightning does

Electrify, from CGI Forge, creates lightning bolts in Blender with a single click. Four types exist: Simple, Branched, Random and LowPoly. Simple lightning can be shaped like a bezier curve with tips connecting to objects and ten settings including distortion strength and thickness.

Branched lightning uses nine control objects and nine parameters, Random produces a new shape on every Generate, and LowPoly uses a plane with a node-based material that faces a chosen object. It works in Eevee and Cycles from Blender 2.8 up, with a shrink wrap setup for connections, an example file and a 19-page guide.

Key features

  • Simple, Branched, Random and LowPoly bolts
  • Tips attach to objects
  • Procedural and animatable
  • Eevee and Cycles from Blender 2.8
  • Example file and 19-page PDF guide
