What Animation Gen does

Animation Gen is a Blender plugin for motion designers who want movement driven by curves. Select an object, a group or a light, and shape the motion using a simple interface.

Completed animations can be saved as presets and reused in other projects, and groups can be animated in a few clicks. Documentation with examples is included. It's a time saver for repeated motion graphics patterns. Since it relies on curves for timing and movement, results are easy to tweak, and the saved presets help keep a consistent style across a series of projects.

Key features

  • Curve-driven movement
  • Animate single objects, groups and lights
  • Save animations as presets
  • Simple interface
