What HydroChrome does

HydroChrome creates liquid, abstract motion graphics inside After Effects and Premiere Pro. It can act as a background generator that produces slowly flowing chrome shapes, or it can chromify your footage so it takes on that metallic, fluid look.

It is a GPU effect that renders live in both applications on Mac and Windows. The animation loops at every Time Offset cycle, making seamless backgrounds easy. Supported graphics cards include the GTX 1050 and 1080 and the RTX 50 series.

Key features

  • Generates abstract flowing backgrounds
  • Chromifies existing footage
  • Renders live on the GPU
  • Loops at each Time Offset cycle
  • Mac and Windows
