What Psx Effect Vertex Snapping Addons Blender By Fortunaliquida does

PSX Snap Effect imitates the unstable vertices of low-poly PlayStation era graphics. It fits horror scenes, glitch art and a grimy, VHS-damaged 3D aesthetic.

A realtime slider sets vertex snap intensity, automatic jitter animates frame by frame without keyframes, and an Empty speed control customizes the noise movement. A Clean Mesh button strips every effect in one click, and there is a reset to defaults. Retro game developers and stylized animators can add authenticity quickly.

Key features

  • Vertex Snap Intensity slider
  • Automatic jitter without keyframes
  • Noise speed control via an Empty
  • Clean Mesh button and reset
