What Uv-Outfit - Merge does

UV Outfit - Merge is a Blender plugin that tidies UV maps. When you join objects from other 3D applications, they often keep UV layers with inconsistent names, leaving a messy list.

The add-on combines those layers into a single one and copes with names like UVW, UVSet or UVTexture. It is aimed at characters assembled from several outfit pieces and prepares them for texturing and export. Cleaning up the map names early avoids export problems and confusion later when textures are applied to the combined character.

Key features

  • Merges multiple UV layers into one
  • Handles names like UVW, UVSet and UVTexture
  • Made for joined imported models
  • Cleaner UV lists
