What Pretty Nodes does

Pretty Nodes keeps complex node trees readable in Blender. It collects tools for coloring nodes, handling reroute chains, resizing frame labels and aligning nodes across the Shader Editor, Compositor and Geometry Nodes.

A custom palette with named colors applies through a context menu and persists between sessions. The Reroute Helper links selected reroutes in order and can clean an orthogonal chain, and labels can be assigned from the root node. These utilities suit artists who build large node setups and want them organized for themselves and for colleagues.

Key features

  • Persistent named node color palette
  • Reroute Helper for chaining and cleanup
  • Assign labels by root node
  • Frame label size adjustment
  • Works in Shader, Compositor and Geometry Nodes
