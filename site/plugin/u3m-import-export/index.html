What U3M Import/Export does

U3M Import/Export adds support for the U3M file format to Blender. U3M is a material format, and the add-on lets you load such files into Blender and send your own back out.

It helps artists who obtain or distribute materials in this format, such as through Vizoo's tools, and want them in their Blender projects without rebuilding them by hand. Sharing materials between applications becomes a matter of using the import and export menus.

Key features

  • Import U3M files
  • Export U3M files
  • Moves materials between applications
