3ds Max script that retopologizes many objects at once with symmetry and area-based density for consistent meshes.

What Batch Retopo does

Batch Retopo applies automatic retopology to several objects in one operation in 3ds Max. A symmetry option slices the object before retopo to create symmetric topology, and density is based on surface area so that mesh density stays consistent between objects.

A polycount option adapts polygon density to size, so small objects get smaller polygons and large ones get larger. With symmetry on, Keep Modifiers Stack adds subdivide and vertex weld modifiers to prevent gaps along the seams. The VDB option in 3ds Max 2025 is supported, with a boolean added in VDB mode on 3ds Max 2024. Pressing Esc stops the script. Good for processing scan or sculpt batches.

Key features

  • Retopologizes multiple objects in one operation
  • Symmetry option for symmetric topology
  • Surface-area-based density and adaptive polycount
  • Keep Modifiers Stack with subdivide and vertex weld
  • Supports the 3ds Max 2025 VDB option
