What Text2Spreadsheet does

Text2Spreadsheet pulls the text from an After Effects project into a spreadsheet so it can be edited elsewhere, then pushes the changes back into the right layers with a click. This suits translations, client proofing and any job where many people review wording.

There are no custom rules or complex batch logic to set up; you simply mark the layers you want included. It can also create compositions in bulk based on spreadsheet rows. The script is from mamoworld tools.

Key features

  • Export and import text via a spreadsheet
  • Reapply edits with one click
  • Batch-create comps from spreadsheet data
  • No rules or automation to configure
  • Manually mark layers to include
