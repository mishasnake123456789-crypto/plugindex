What RizomUV Virtual Spaces does

RizomUV Virtual Spaces is Rizom Lab's UV mapping software, serving Cinema 4D users who need clean texture layouts fast. It unwraps, packs and optimizes models in seconds, from indie stills through games to film.

Automated unwrapping produces optimized UV maps with little hand adjustment, and advanced packing algorithms include a rebuilt GPU packing system, Windows CUDA only, reported as three to four times faster with two to four percent better tile coverage. A strategy selector offers Efficient, Padding Perfect and Pixel Aligned modes. Texture artists and modelers who spend time on UV layout will benefit.

Key features

  • Automated unwrapping with minimal manual work
  • Rebuilt GPU packing, Windows CUDA only
  • Efficient, Padding Perfect and Pixel Aligned modes
  • Advanced packing algorithms
