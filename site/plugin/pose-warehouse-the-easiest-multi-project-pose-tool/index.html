What Pose Warehouse - The Easiest Multi-Project Pose Tool does

BOSSposes' Pose Warehouse addresses the problem of poses locked inside one file. A pose stored in one project can be loaded into any other, even years later.

Saving and loading take a click, bringing Maya-like pose handling to Blender. In a keyframe workflow you load poses, apply them with a right-click and blend among them. Lifetime updates are promised for all users, with additions planned, and documentation is included. Character animators building a personal pose library across productions will appreciate it.

Key features

  • Poses reusable across projects
  • Click save and load
  • Maya-like pose handling
  • Right-click apply and pose blending
  • Lifetime updates
