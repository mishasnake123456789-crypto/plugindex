What LottieFiles does

The LottieFiles extension links After Effects and Premiere Pro with the Lottie ecosystem. Motion designers can bring animations in, build them in After Effects and output it as Lottie JSON or dotLottie files for sites and apps.

A preview plays your work in the Lottie web player inside the panel, and a render timing graph helps you spot what is hurting file size or CPU load. Animations can be uploaded to LottieFiles as checkpoints for private sharing and demos, and thousands of free public animations can be searched, with AEP downloads when offered. Motion System applies brand colours, fonts and easings in one click.

Key features

  • Output as Lottie JSON or dotLottie
  • Live Lottie preview in the panel
  • Render timing graph to optimize size and CPU
  • Upload checkpoints for private sharing
  • Motion System applies brand styles in one click
