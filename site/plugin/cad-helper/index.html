What CAD-Helper does

CAD-Helper is a Blender extension built for tidying CAD data that arrives as a tangle of hundreds of parts and nested sub-assemblies. It adds operators for navigating and restructuring that hierarchy.

You can select parents or children recursively, filter by name, RegEx, object type, polygon count, depth or bounding box, and then clean up by removing empties while reconnecting children. Meshes can be flattened and joined with modifiers applied, and identical objects are detected by geometry measurements and linked to share one mesh data-block, which cuts scene weight.

Key features

  • Recursive parent and child hierarchy selection
  • Filter by name, RegEx, type, poly count or size
  • Delete empties and reconnect children
  • Flatten and join meshes with modifiers applied
  • Detect identical parts and link shared mesh data
