What Group input helper(节点组输入助手) does

Group input helper makes group input nodes easier to manage in Blender's geometry and shader node editors. Each action has its own hotkey.

Quick Add Group Input Node, on key 1, exposes just the target socket while hiding the rest, handy as the number of sockets grows. Split, merge and move selected group inputs with Shift+1 to keep the graph tidy. Node artists with large groups benefit from a cleaner layout.

Key features

  • Quick Add Group Input Node on hotkey 1
  • Split, merge and move group inputs
  • Works in geometry and shader nodes
  • Hotkey for each action
