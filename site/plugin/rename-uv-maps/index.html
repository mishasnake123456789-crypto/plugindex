Blender add-on that renames UV maps on all selected meshes to match the active object's UV map name.

What Rename Uv Maps does

Rename UV Maps removes inconsistency in UV channel names across objects in Blender. Mismatched names often break baking or material setups, and this tool unifies them.

It works from the UV Maps panel without adding new interface clutter. Every selected mesh gets the same UV map name as the active object, undo is supported, and the add-on is light on resources. Non-mesh objects in the selection are skipped quietly without errors. Documentation is included.

Key features

  • Matches UV map names to the active object
  • Works from the UV Maps panel
  • Undo support
  • Skips non-mesh objects safely
  • Lightweight, no extra panels
