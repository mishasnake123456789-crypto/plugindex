What MediaSilo Panel does

MediaSilo Panel ties Premiere Pro and After Effects to the MediaSilo platform for asset management and presentations. Assets can be imported directly from MediaSilo projects, so editors need not switch tools to retrieve material.

A sequence, composition or document can be exported as a private link for a selected audience or as a public link, protected with expiration dates and custom passwords. Recipient comments are pulled back and synced to the timeline, and versions update automatically while you iterate. Studio-grade security is built in.

Key features

  • Import assets from MediaSilo projects
  • Private or public sharing links
  • Expiration dates and passwords
  • Recipient comments synced to the timeline
  • Auto-updating versions
