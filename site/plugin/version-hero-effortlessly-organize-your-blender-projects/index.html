What Version Hero - Effortlessly Organize Your Blender Projects does

Version Hero handles file versioning, project setup and asset library upkeep for Blender from a single sidebar. It aims to keep project folders orderly and prevent accidental overwrites.

Smart Versioning creates numbered versions with viewport previews and metadata, and lets you browse, open or restore them safely. A status indicator reads Unsaved, Modified or Synced, with warnings and hidden risky actions while viewing a version file. A Create Version button sits in the 3D View top bar, and old versioned files can be converted safely.

Key features

  • Numbered versions with previews and metadata
  • Safe browse, open and restore
  • Unsaved, Modified or Synced status indicator
  • Create Version button in the top bar
  • Legacy conversion and folder templates
