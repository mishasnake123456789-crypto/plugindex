What Keyframe selected does

Keyframe selected is a Blender add-on by xbodya13 for fast keying. It adds or removes keyframes directly on the objects and bones you have selected, with no keying set to prepare first.

Holding Alt applies the action to all selected objects and bones, and the same insert and delete commands are available from the right-click menu. Color feedback shows what happened and can be turned off in the settings. The add-on requires no special permissions and supports Blender 4.4 and newer, which suits animators who key often.

Key features

  • Insert or delete keys without keying sets
  • Alt applies to all selected items
  • Right-click menu access
  • Optional color feedback
  • Supports Blender 4.4 and newer
