What Matte Tool 2 does

Matte Tool 2 is a toolset from MotionCodes for working with mattes and layers in After Effects. Twenty tools gather common operations in a responsive panel, saving artists from repeating them manually.

It includes a merge shape layers tool and explode tools for shape, text and Ai layers, which split a single layer into its parts. The interface adapts to panel size. The set is compatible with After Effects from CC 2015 through 2026, and suits anyone who builds cutouts and track mattes regularly.

Key features

  • 20 matte and layer tools
  • Merge shape layers
  • Explode shape, text and Ai layers
  • Responsive interface
  • Works with CC 2015 through 2026
