What Bsnow does

BSnow, from IK3D, lays snow onto existing models in Blender for winter scenes, working on landscapes, rocks, statues and foliage. The add-on creates simulation domains automatically for the selected object and can batch several domain objects into one simulation.

Domains can be edited for resolution and upsampling with linear or cubic interpolation. A collision mesh tool tests particle collision before running to expose bad geometry or non-manifold edges. Settings for particle size, amount, temperature and physics give granular control. Environment and archviz artists wanting realistic accumulation will find it capable.

Key features

  • Automatic domain creation with batching
  • Editable resolution and upsampling
  • Collision mesh test finds bad geometry
  • Particle, temperature and physics settings
