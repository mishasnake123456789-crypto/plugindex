Blender add-on that inserts vertices between pairs of selected vertices at a distance you specify.

What Vertex_Insert does

Vertex_Insert adds new vertices between existing ones in Blender's edit mode. You select an even number of vertices, enter the distance, and press one of two buttons.

Each button produces a different placement result, giving you control over where the new points land relative to the selected pair. It is compatible with Blender 4.0 and includes documentation. Modelers who need exact spacing along edges can avoid measuring and nudging points by hand.

Key features

  • Inserts vertices between selected pairs
  • Placement at a user-set distance
  • Two buttons with different results
  • Requires an even number of selected vertices
  • Compatible with Blender 4.0
