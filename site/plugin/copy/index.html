Blender plugin that copies and pastes modifiers, materials, transforms and animation across several objects.

What Copy does

Copy+ is a Blender plugin for transferring attributes from one object to many. Animation, modifiers, materials and the location, rotation, scale and dimensions of an object can all be transferred, which saves repeating identical edits object by object.

Transform values can be copied and pasted on any axis, and an All command copies rotation, scale and location together. Transform, rotation or scale can be zeroed per axis, and an object's origin can be changed quickly. It is useful for scenes with many similar assets, where consistent settings must be applied across a large selection.

Key features

  • Copy and paste modifiers and materials
  • Copy rotation, scale, location and dimensions per axis
  • All command for combined transforms
  • Copy and paste animation
  • Zero out transforms and change origin quickly
