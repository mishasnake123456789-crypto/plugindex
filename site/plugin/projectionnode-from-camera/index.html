Blender add-on that makes a node group which casts a camera's background picture onto surfaces for camera-mapped shading.

What ProjectionNode from Camera does

ProjectionNode from Camera makes a node group that projects a camera map from the image set in a camera's background, a handy trick for camera mapping in Blender.

A panel in the shader editor's node tab has camera and background pulldowns, and the Make CameraProjection Nodes button generates the group. Wire its color output into a shader and the image gets projected. VFX and matte painting artists can set up projection mapping without manual node work.

Key features

  • Projects a camera background image onto surfaces
  • Panel in the shader editor sidebar
  • Camera and background pulldowns
  • Generates a CameraProjection node group
