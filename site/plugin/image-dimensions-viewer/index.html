What Image Dimensions Viewer does

Image Dimensions Viewer prints the size of an image right where you work with it. In the Node Editor the label sits above an Image Texture node whenever the node has an image selected, and in the Image Editor it appears above or below the picture.

A checkbox named Image Dimensions in the Overlays dropdown switches the labels on. Texture and material artists who need to check resolutions quickly will no longer need to open the sidebar.

Key features

  • Dimension label in Node Editor and Image Editor
  • Appears above Image nodes with a selected image
  • Toggle through the Overlays dropdown
  • Placement above or below the image
