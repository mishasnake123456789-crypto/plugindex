Blender add-on that fixes the spacing of two selected vertices to a value you enter, along chosen axes in Edit Mode.

What Set Vertex Distance does

Set Vertex Distance gives precise spacing control in Blender's Edit Mode. Select two vertices on any mesh, type the distance you want, and it applies along X, Y, Z or all axes.

Single Vertex Mode moves just the active vertex, while Component Mode, added in version 2.0, moves an entire connected piece and keeps its internal structure. A modal dialog in the Edit tab of the sidebar offers a live distance preview, undo and redo work, and shortcuts can be customized. It helps with mechanical, parametric and architectural modeling.

Key features

  • Exact distance between two vertices
  • X, Y, Z or all-axis control
  • Component Mode moves connected geometry
  • Live preview with undo and redo
  • Customizable shortcuts
