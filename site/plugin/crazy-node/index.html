Crazy Node

Developer: CP-Design

FreeBlender

Blender add-on that turns node groups into one node showing texture, ramp, curve and mix nodes directly in its panel.

What Crazy Node does

Crazy Node converts a node group into a special node that exposes TexNode, RampNode, CurveNode and MixNode right on its face. You can edit them without opening the group.

A Crazy Node is made either by adding an empty one and pointing it at a node tree, or by converting a group from the right-click menu or with F5. The package also includes Cp Image Node, a custom node bundling frequently used texture controls. It tidies shader graphs that would otherwise need constant group entering.

Key features

  • Shows TexNode, RampNode, CurveNode and MixNode in the node UI
  • Create empty or convert existing groups
  • Convert via right-click menu or F5
  • Includes Cp Image Node
  • Edit without entering the group
