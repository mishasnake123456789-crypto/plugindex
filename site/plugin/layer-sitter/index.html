Manages parenting in After Effects through a filterable list, custom nulls and Quick Parents.

What Layer Sitter does

Layer Sitter, from GMD Motion, focuses on the parent relationships between layers. Rather than dragging pick-whips, you choose a parent from a filterable list and apply it to the selected layers.

It can also create customized null objects to serve as parents. Quick Parents let you save a favorite parent and attach layers to it later, and you can select, add or remove them. This is useful for rigging and for building hierarchies in busy compositions.

Key features

  • Parent selected layers via a filterable list
  • Create customized nulls for parenting
  • Quick Parents for frequent targets
  • Select, add and remove Quick Parents
