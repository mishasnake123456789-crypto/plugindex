Duplicates the active Blender object with all visible modifiers applied and offsets it beside the original.

What Moddiff does

ModDiff makes an applied copy of the active object in one click. All visible modifiers are baked into the duplicate, and the copy is offset next to the original based on its bounding box.

A multiplier value generates several iterations to compare side by side. It lets modelers preview or keep the result of a modifier stack without destroying the source object. Highlights cover one-click applied duplicate and automatic offset using bounding box.

Key features

  • One-click applied duplicate
  • Automatic offset using bounding box
  • Multiplier for side-by-side iterations
