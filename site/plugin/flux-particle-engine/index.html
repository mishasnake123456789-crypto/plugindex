What Flux Particle Engine does

Flux Particle Engine splits particle work into two parts: a studio that runs in any web browser with nothing to install, and a bridge that delivers the result into Blender. You design the effect visually, then send the complete configuration to your open scene in one click.

Emission, velocity, turbulence, gravity, lifetime and colour can all be tweaked in real time, which suits fire, dust, sparks, smoke and magic effects. It works with Blender 4.5 to 5.1 in Cycles and Eevee. A single-seat licence is activated with a key, and documentation is available.

Key features

  • Browser-based particle studio, no install needed
  • Live bridge sends full setup into Blender in one click
  • Real-time control of emission, velocity, turbulence and gravity
  • Lifetime and colour adjustments
  • Works with Blender 4.5 to 5.1
