Adds stylized contact shadows and edge separation to animation and generates motion vector EXR passes in Blender.

What Motionflow does

MotionFlow gives animation more depth and form by acting like a stylized contact shadow and edge separation system. It also generates motion vector EXR passes for compositing.

It supports meshes, armatures, curves and empties, stores motion data frame by frame in a clean folder structure, and sets up Compositor nodes with one click from the sidebar. Compositors can add motion blur and depth cues. Key capabilities include stylized contact shadow and edge separation and motion vector EXR passes.

Key features

  • Stylized contact shadow and edge separation
  • Motion vector EXR passes
  • Supports meshes, armatures, curves and empties
  • One-click Compositor setup
