What Grid Spacing Tool does

Grid Spacing Tool by FishMan is a trio of scripts that make grid adjustments faster in 3ds Max. Set Grid Type selects between two grid options, while Increase Grid and Decrease Grid move the grid size up or down through available presets.

The current grid size is displayed in the top right area of the viewport, so you always know the setting. Set Grid Type fits on a toolbar or quad menu, and the other two can be assigned to hotkeys. Installation is by dragging the .ms file into the viewport or through Scripting, Run Script. Helpful for modelers who change snapping scale often.

Key features

  • Set Grid Type script with two options
  • Increase Grid steps size up through presets
  • Decrease Grid steps size down through presets
  • Grid size shown in the viewport
  • Toolbar, quad menu and hotkey assignment
