Blender add-on that replaces any mesh with a light low-poly impostor for big EEVEE scenes.

What Instant Impostors does

Instant Impostors turns any mesh in Blender into a lightweight low-poly impostor so that large-scale scenes stay responsive. Rendering is shader based, with 3D parallax, self-shadowing and translucent effects, and EEVEE is the only supported engine.

Generation is a single click. Ambient occlusion is baked into every impostor to add fidelity, and options such as Generate Per Object, Quality and Max Thickness tune the 3D look. The result keeps real-time viewport performance when you populate big environments such as forests or cities with many instances.

Key features

  • One-click conversion to low-poly impostors
  • 3D parallax, self shadowing and translucency shader
  • Real-time viewport performance for big scenes
  • Baked ambient occlusion
  • Generate Per Object, Quality and Max Thickness options
