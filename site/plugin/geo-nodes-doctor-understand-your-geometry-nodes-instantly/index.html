What Geo-Nodes Doctor - Understand Your Geometry Nodes Instantly does

Geo-Nodes Doctor helps you make sense of procedural setups, especially ones inherited from someone else. It works inside the Node Editor and focuses on understanding how a graph behaves.

A Node Inspector reports socket values and metadata for the selected node, Execution Order shows the strict order of nodes that feed the output, and Slow Nodes highlights expensive operations with a heatmap. Technical artists tuning performance or troubleshooting broken networks will find it a faster route than guessing.

Key features

  • Node Inspector for socket values and metadata
  • Execution Order display
  • Slow Nodes heatmap
  • Works directly in the Node Editor
