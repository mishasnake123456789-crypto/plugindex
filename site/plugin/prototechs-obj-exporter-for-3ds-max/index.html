What ProtoTech's OBJ Exporter For 3ds Max® does

ProtoTech's OBJ Exporter writes solid bodies from 3ds Max into OBJ files so they can be shared with other applications. Materials can be exported at face or body level, including both colors and textures.

Precision control sets the balance between file size and output quality, and tessellation can be applied per body or per face. An automation license allows an export function on the same host application to be called without user intervention. A free trial of 15 exports over seven days provides access to the full feature set. Useful for moving CAD-derived geometry to other tools.

Key features

  • Solid bodies exported to OBJ
  • Face and body-level colors and textures
  • Precision control for size and quality
  • Body or face tessellation
  • Free trial: 15 exports over 7 days
