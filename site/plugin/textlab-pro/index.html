What Textlab Pro does

Textlab Pro is a YCraft panel that groups text tasks for After Effects. It helps check text quality by finding and fixing typos, detecting outliers and testing contrast accessibility, and it edits text in batch across all comps.

Operations include case modes such as Vowels, Consonants, Edges and Alternating, Match Size for syncing font size, and Fit Comp to Shape. Styling offers Multi-Outline presets, Stroke Reveal and per-character color with offsets. Safe Zone Analysis covers six aspect ratios, and fifteen FFX presets shipped in the first release.

Key features

  • Typo, outlier and contrast checks
  • Batch text editing across all comps
  • Case modes and Match Size
  • Multi-Outline, Stroke Reveal and per-character color
  • Safe Zone Analysis for six aspect ratios
