What Render Frame at Markers does

Render Frame at Markers is an After Effects script by Lloyd Alvarez that exports specific stills based on markers. Each frame flagged within the comp work area goes into the render queue, matching what File > Save Frame As would produce by hand.

It reads both layer markers and comp markers (the latter added in version 1.93) and skips any that fall outside the work area. That saves repeated manual exports when you need a series of reference frames or thumbnails. It works from CS6 through the 2026 release and is free.

Key features

  • Queues marked frames from the work area
  • Reads layer markers and comp markers
  • Matches manual Save Frame As output
  • Ignores markers outside the work area
  • Works with CS6 through 2026
