Blender add-on that queues scenes or cameras and renders them in sequence, aimed at still images.

What Render Queue Manager does

Render Queue Manager adds a batch rendering list to Blender's Output properties. It is designed for artists producing stills rather than animations and want to leave several renders running unattended.

Add the current scene or many cameras at once, reorder or remove entries, then start the queue to render each item in the background. A cancel button stops a running job. Images save according to your Output settings, and dynamic filename keywords such as camera and collection names help organize results.

Key features

  • Add current scene or multiple cameras to a queue
  • Reorder or remove queued entries
  • Sequential background rendering
  • Cancel a job in progress
  • Filename keywords like camera and collection
