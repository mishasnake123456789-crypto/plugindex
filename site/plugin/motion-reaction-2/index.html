What Motion Reaction 2 does

Motion Reaction 2 is a Pixcode plugin that adds motion to layers in After Effects through a dynamic, easy-to-use interface. Fourteen core motion types cover objects that stand still, objects that already move, and text.

Static objects get seven forward actions, and a single motion on a moving object can evolve into seven varied types. Text receives special effects as well. More droplet controllers were added for finer customization. It helps designers produce reactive, polished movement quickly.

Key features

  • 14 core motion types
  • 7 forward actions for static objects
  • Motion evolution on moving objects
  • Motion effects for text
  • More droplet controllers
