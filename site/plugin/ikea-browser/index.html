What IKEA Browser does

IKEA Browser lets Blender users find furniture and bring it into a scene without hunting for downloads. Shish's add-on searches IKEA's catalog and imports the same 3D models used on the retailer's website.

Country and language codes are set in the add-on preferences, and the current region is shown in the panel. Models are fetched over the network and stored locally. Not every product has a 3D model. It works with Blender 4.2 LTS and newer. Interior designers and archviz artists can fill rooms with real products quickly.

Key features

  • Search the IKEA catalog from Blender
  • One-click model import
  • Region and language set in preferences
  • Downloaded models stored locally
