Blender add-on that opens all 3D views in Solid mode on startup or file load to avoid shader compile delays.

What Solid Boot does

Solid Boot avoids the pause Blender can have when shaders compile as soon as it opens. It switches every 3D view to Solid mode rather than Material Preview.

It applies on startup and when new files load, and includes an option to disable Viewport Shadows. Users with heavy scenes or slower GPUs get a smoother start. Because the viewport avoids compiling materials immediately, large scenes open faster and the program feels more responsive, and Material Preview can still be turned on when needed.

Key features

  • Every 3D view starts in Solid mode
  • Applies at startup and new file load
  • Avoids early shader compiling
  • Option to disable viewport shadows
