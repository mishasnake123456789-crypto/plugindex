Auto-grids pre-comp layers and adds text labels that stay synced to layer names in After Effects.

What Layer Name Tag does

Layer Name Tag helps when a composition is made of many precomps and you want an overview that reads clearly. In two clicks it arranges the layers into a grid and attaches a text label above each one.

Labels pull their text from the layer name, so renaming in the timeline or Project panel updates them live. The grid can use two, three or four columns with several gutter widths, and label position, size and color are adjustable. It works with After Effects 2022 and later, and includes license management in its help window.

Key features

  • Auto Grid with 2, 3 or 4 columns
  • Labels generated from layer names
  • Labels update live on rename
  • Adjustable label position, size and color
  • Tested on After Effects 2024 to 2026
