A Blender add-on that streams phone gyroscope and accelerometer data to control objects and properties live.

What Phone Link does

Phone Link turns an iOS or Android device into a motion controller for Blender. Gyroscope and accelerometer data stream in real time, so you can rotate and move the phone to steer one object or many, which is a physical way to perform animation instead of keyframing it.

The motion can drive any property or function, from a light's intensity to layered setups, using raw or processed values exposed as three layers of datapoints with low latency. Linking is done in a click by enabling the add-on and following the connection steps. Animators, virtual camera operators and interactive artists will enjoy the hands-on control.

Key features

  • Real-time control from an iOS or Android device
  • Drives any property with motion data
  • Low-latency gyroscope and accelerometer data
  • Raw or processed values in three data layers
  • One-click linking
