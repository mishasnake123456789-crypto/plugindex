What Jmesh Tools does

JMesh Tools is a Blender addon by Jayanam for drawing 2D outlines straight onto mesh surfaces and converting them to boolean cutouts, extrusions or paneling lines. Shape Mode is usable in Object, Edit and Sculpt modes, so you never leave the viewport.

A Boolean Toolkit gathers union, difference, slice and intersect into one panel. Shapes stay editable with full vertex control, and pressing B in the shape's Edit Mode adds bevels. A Shape Library exports and imports custom shapes. It is well suited to hard surface detailing.

Key features

  • Draw 2D shapes on mesh surfaces
  • Extrude and apply booleans in the viewport
  • Union, difference, slice and intersect panel
  • Editable shapes with bevels via B
  • Shape Library for custom shapes
