What Aviation Skies Lighting Addon does

The Aviation Skies Lighting Addon helps you set up skies and weather quickly in Blender. Six presets cover weather from sunny blue skies through overcast to storms, as well as sunrise and sunset, and each one can be customized.

The overcast preset exposes cloud color and density along with overall sky brightness. A fully textured aircraft model comes with the add-on, which makes it easy to try the lighting straight away. It suits aviation renders and any outdoor scene needing mood.

Key features

  • Six sky and weather presets
  • Clear, overcast, stormy, sunrise and sunset looks
  • Adjustable cloud color, density and brightness
  • Includes a textured aircraft model
