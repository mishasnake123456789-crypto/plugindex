What MildStyle Font Family does

MildStyle Font Family by Highground offers a simplified interpretation of graffiti Wildstyle lettering for After Effects and Premiere Pro. It is built as a layered type system, so styles can be stacked to build up dimensional hip-hop inspired titles.

The family has four styles, plus a color SVG version that combines all four into a single multicolor font. It works in other Adobe applications too, with listed compatibility for Premiere Pro 12.0, Illustrator 17.0, InDesign 9.0 and Audition 11.0 or later. Designers can use it for posters, intros and any project with a street-art feel.

Key features

  • Four layered styles
  • Color SVG style combining all four
  • Graffiti and hip-hop look
  • Works across multiple Adobe applications
