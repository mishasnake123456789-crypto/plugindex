Blender add-on that assigns Bezier curves to a target curve as shape keys, from the View 3D sidebar's Edit tab.

What Assign Shape Keys does

Assign Shape Keys turns one or more Bezier curves into shape keys on a target curve in Blender. It was formerly included with Blender 4.1 and is now provided with limited support.

The tool lives in the Edit tab of the View 3D sidebar. It supports Blender 4.2 LTS and newer, is released under GPL v2 or later and needs no special permissions. Animators who morph curve shapes, such as for logos, lettering or line art, can use it to set up the keys without manual work.

Key features

  • Turns Bezier curves into shape keys
  • Accessible in sidebar Edit tab
  • Formerly bundled with Blender 4.1
  • Works with Blender 4.2 LTS and newer
