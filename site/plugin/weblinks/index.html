Blender add-on for storing categorized URLs to documentation, tutorials and images inside a project.

What Weblinks does

WebLinks keeps reference links within your Blender file, so resources travel with the project.

Add, categorize and delete URLs from the N panel without switching to a browser bookmark list. It is useful for documentation, tutorials and reference images in large, intricate 3D projects. The add-on supports Blender 3.0 through 4.3, installs through add-on preferences and uses a royalty-free license. Keeping links in the same file makes it easier to hand a project to a colleague with all of its supporting material.

Key features

  • Add, categorize and delete URLs
  • Organize docs, tutorials and images
  • Available in the N panel
  • Blender 3.0 to 4.3
  • Royalty-free license
