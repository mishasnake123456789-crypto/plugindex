What Loft Kit does

Loft Kit, by Pixel Egg Studio, helps Blender users model shapes that follow curves, such as lofted forms, using accurate parameters. The developer built it around two priorities: speed and accuracy.

It is compatible with Cycles and Eevee and supports Blender 2.9 through 4.3. Documentation is included and it is released under the GPL.

Key features

  • Models curve-shaped objects
  • Accurate modeling parameters
  • Works with Cycles and Eevee
  • Blender 2.9 to 4.3
