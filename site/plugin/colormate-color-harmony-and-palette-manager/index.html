What Colormate - Color Harmony And Palette Manager does

Colormate, from Edgeflow, calculates color harmonies live in Blender, using both mathematical and perceptual approaches. It also manages palettes, reading and writing formats from Photoshop, Illustrator, Krita and Gimp, including .aco, .ase and .gpl.

Two libraries are provided: a Scene Library stored with the blend file, plus a Persistent Library that carries over between files. A scratchpad holds twelve quick swatches, ColorRamp nodes can be built from library colors, and the panel docks in the Node Editor or 3D View. Colors sort by value, with drag and drop and list or grid views.

Key features

  • Live color harmony calculation
  • Import and export .aco, .ase, .gpl and more
  • Scene and Persistent libraries
  • Scratchpad with 12 swatches
  • ColorRamp creation from library colors
