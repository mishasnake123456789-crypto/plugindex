A script that builds social-style photo grids around a centered profile picture in After Effects.

What GridTrend does

GridTrend generates the popular layout of many images surrounding a central profile photo. Set up your composition, choose a profile image, and the script assembles a grid from the media you have imported.

Separate buttons place the person and create the grid, and you can choose custom dimensions, including odd row and column counts that keep the portrait centered. Strokes, backgrounds and masks can be added, and color labels, organizing, swapping and deleting are built in. It is aimed at social video creators who need this look quickly.

Key features

  • Places a chosen profile picture at the center
  • Builds grid from remaining imported media
  • Custom grid sizes with odd rows and columns
  • Strokes, backgrounds and masks
  • Swap, delete and organize items
