Builds Blender math node networks automatically from a typed formula.

What Expression Nodes does

Expression Nodes saves the tedium of placing and wiring math nodes one at a time. You type a formula, press Create Nodes, and the add-on produces the matching node setup for you.

It works in any Blender node editor that offers a math node, so shader, geometry and compositor trees can all benefit. That is useful whenever an equation needs to be implemented as nodes and doing it manually would take many clicks. The add-on is documented, has a demo video, and is listed for Blender 3.0 and 3.1.

Key features

  • Formula to math node conversion
  • Single Create Nodes button
  • Works in any editor with a math node
  • Documentation and demo video included
