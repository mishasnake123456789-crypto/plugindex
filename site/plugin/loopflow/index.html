After Effects plugin that animates still photos into seamless looping cinemagraphs using two masks.

What loopFlow does

loopFlow creates cinemagraphs and plotagraphs from still images in After Effects. Two masks describe where motion happens and in which direction, and the plugin produces continuous fluid movement within that area.

Looping is seamless, with the cycle able to start or stop, and the motion able to run the animation forward or backward. The blend can be linear, soft noise or a wipe, with transition curves set for each layer. Optional distortion makes motion look more natural, Speed Ramp changes flow speed dynamically, and version 1.3 added a Flow Map. It suits water, smoke, fire, hair, fabric and patterns.

Key features

  • Flow area and direction set by two masks
  • Seamless loop with forward or backward motion
  • Linear, soft noise or wipe blends
  • Speed Ramp and optional distortion
  • Flow Map added in version 1.3
