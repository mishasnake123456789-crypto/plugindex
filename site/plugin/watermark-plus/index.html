Blender compositor add-on that stamps a custom image watermark on renders, in a simple or a fully tunable mode.

What Watermark Plus does

Nikita Akimov's Watermark Plus helps you brand preview renders. Working through the Compositor's N-panel, it places your own image, set in the Image node or as a default in the add-on preferences.

Level 1 is the quick option that processes fast, while Level 2 can be fine-tuned according to render intensity through an Additional Parameters section on its node. Basic settings handle size and position. Freelancers who send previews to clients and want protection against reuse will find it convenient.

Key features

  • Two modes: simple Level 1 and full Level 2
  • Custom image via the Image node
  • Default image in add-on preferences
  • Size and position parameters
  • Adjustment by render intensity level
