What Simple Object Cutter does

Simple Object Cutter divides any mesh into multiple parts. Enter the number of segments along X, Y and Z, using 1 for no cut in a direction, or enter a segment width and the add-on works out how many cuts are needed to get nearly equal pieces.

Five accuracy levels from 0 to 4 trade processing time for cleaner results. It is convenient for fracturing, preparing models for 3D printing in sections or building modular parts.

Key features

  • Cuts per axis or by segment width
  • Five accuracy levels
  • Nearly equal piece sizes
  • Quick mesh slicing
