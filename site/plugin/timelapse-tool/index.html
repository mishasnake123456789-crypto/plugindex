What Timelapse Tool does

Timelapse Tool, from Fwiller, quietly records your Blender session so you can show how a project came together. It grabs screenshots of the whole window at a fixed interval and can later assemble the image sequence into a video.

You can also capture from scene cameras instead, including animated ones and several at once. Lock Shading keeps viewport settings consistent across captures, while Idle Detection saves a frame only when the project actually changes. Output can be JPEG, and image names support zero padding for tidy sequences.

Key features

  • Interval screenshots of the full project window
  • Capture from one or several scene cameras
  • Idle detection skips frames with no changes
  • Lock Shading keeps viewport look consistent
  • Generates a timelapse video from the sequence
