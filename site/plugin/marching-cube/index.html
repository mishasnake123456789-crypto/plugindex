What Marching Cube does

Marching Cube, by Thomas-Berger, creates 3D surfaces in Blender from mathematical definitions. You describe a level set equation using modular helper functions, and the add-on extracts the iso-surface mesh with the marching cubes algorithm.

Performance relies on vectorized NumPy computation and a compiled Cython marching cube library. It appeals to technical artists, mathematicians and generative designers who want to explore implicit surfaces and complex organic shapes that are awkward to model manually.

Key features

  • Marching cubes iso-surface generation
  • Level set equations built from helper functions
  • Vectorized NumPy computation
  • Cython-compiled marching cube library
