What Startendframe For Dope Sheet And Graph Editor does

StartEndFrame saves a trip back to the Timeline when you need to set the frame range. It places the same start and end frame fields in the Dope Sheet and in the Graph Editor.

The fields behave exactly as they do in the Timeline. The add-on works with Blender 2.93 through 4.1, ships with documentation and is distributed under the GPL license. Animators who spend most of their time in curves and keys will find it convenient.

Key features

  • Start and end fields in the Dope Sheet
  • Start and end fields in the Graph Editor
  • Same behavior as the Timeline
  • Blender 2.93 through 4.1
