3ds Max script that selects objects by whether they are visible, hidden or covered by chosen obstacles in the viewport.

What miauu's Select by visibility does

Select by visibility by miauu picks objects according to how they appear in the 3ds Max viewport. It can select everything in the current view, including objects hidden behind others, or just the ones that can or cannot be seen, either in one viewport or across all of them at once.

You can also pick obstacle objects and then select the objects fully covered, partially covered, or both. A feature shows levels of visible objects. Only geometry and shapes or splines are selected; lights, cameras and helpers are skipped. It is useful for cleaning large scenes by finding hidden items that never appear in a render.

Key features

  • Select visible or hidden objects in the current viewport
  • Visibility check across all viewports at once
  • Pick obstacles and select covered objects
  • Show levels of visible objects
  • Selects geometry and shapes only
