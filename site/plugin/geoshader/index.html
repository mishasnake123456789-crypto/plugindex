What Geoshader does

Geoshader bridges Geometry Nodes and Shader Nodes, two areas that are awkward to connect by hand. It generates ready-made node groups, letting distance-driven procedural effects feed into materials in a few clicks.

One click generates a Geometry Node group that writes a named attribute from an object's distance to a target. Another click builds an Attribute node and Mix Shader in the Shader Editor and links them. Material artists making proximity-based reveals, dirt or wear get working setups in seconds.

Key features

  • One-click distance attribute node group
  • Auto-created Attribute and Mix Shader nodes
  • Connects procedural effects to materials
  • Distance to a target object
