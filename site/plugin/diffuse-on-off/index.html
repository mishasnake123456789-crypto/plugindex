Diffuse On-Off

Developer: Chuggnut

Free3ds Max

3ds Max script that turns viewport diffuse texture display on or off for the selected objects, skipping the material editor.

What Diffuse On-Off does

Diffuse On-Off controls whether diffuse textures show in the 3ds Max viewport. The change is applied to the current object selection, and there is no need to open the materials panel to flip the setting.

Turning texture display off can speed up viewport navigation in heavy scenes, while turning it on lets you check mapping and appearance. Doing it by selection means the heavy objects can be isolated from the rest. The script is by Chuggnut and is available at version 2.3.5.

Key features

  • Toggles diffuse texture display in the viewport
  • Applies to the current selection
  • No need to open the materials panel
  • Version 2.3.5
