What RXXR does

RXXR, developed by R/L, produces ASCII and pixel-based glitch visuals inside After Effects. It turns source layers into grids of characters or blocks, giving motion pieces a techno, terminal-inspired look.

A Mix Style option combines the built-in character styles into new hybrids, while Edge Detect mode draws elements only along object edges, with a Dark Outlines variant. Colour comes from gradient presets and a Gradient Shift control. You can add custom elements and preview the selected step, tune the grid with Line Size and Expand Markers, and use reworked offset parameters that include a Wrap Edges option.

Key features

  • ASCII and pixel techno-glitch generator
  • Mix Style blends built-in character styles
  • Edge Detect mode with Dark Outlines
  • Gradient presets and Gradient Shift
  • Custom elements, grid controls, Wrap Edges
