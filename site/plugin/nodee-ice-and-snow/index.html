A Blender add-on with geometry node setups for snow, ice, icicles, frost and snowdrifts on any object.

What Nodee: Ice&Snow does

Nodee: Ice&Snow adds wintry coverings to models in Blender through geometry nodes. Four setups are included: Ice & Snow, Icicles, Snow and Frost, and each is created with one click from a pie menu, N panel buttons or the Asset Browser.

Parameters control snow thickness, melting slopes, and icicle size, length and density, along with random seeds for variation. The effects work on anything from small sculptures to large buildings, and a debug mode allows dynamic real-time changes. Environment artists and architectural visualizers building winter scenes can cover objects quickly without hand-modeling drifts.

Key features

  • Ice & Snow, Icicles, Snow and Frost setups
  • One click via pie menu, N panel or Asset Browser
  • Controls for thickness, melt slopes and icicle size
  • Works on any object
  • Debug mode for real-time changes
