LODGen

Developer: F1dg3t

FreeBlender
Download Free

Blender add-on that generates progressively decimated LOD meshes for game assets in the 3D View.

What LODGen does

LODGen creates levels of detail for game assets without manual decimation passes. Select one or more objects, add them to the list, set a decimation scale and the number of iterations, which defaults to six, and generate.

Reduction is applied cumulatively, so each level builds on the last. LOD0 is a clean base with modifiers applied, the originals are kept hidden to prevent data loss, and a dedicated LOD collection is created and reused for each object.

Key features

  • Add multiple objects to the list in one click
  • Decimation scale per LOD step
  • Adjustable iteration count, default six
  • Original meshes kept hidden
  • Dedicated LOD collection per object
