What YY_Voronoi does

YY_Voronoi from Andrew Yang generates Voronoi diagrams, also called Worley or cell noise, as procedural textures in After Effects. It suits terrain maps, water caustics and abstract backgrounds.

Color can be computed in several modes, including square, absolute and edge distance, and Euclidean or Manhattan metrics define cell boundaries. Cell dispersion can even use the layer's own pixels, Repeat X and Y tile the grid, and Evolution with a period loops seamlessly. A blend mode and an RGB Only option control compositing, and native code improves speed.

Key features

  • Multiple color calculation modes
  • Euclidean and Manhattan distance metrics
  • Cell dispersion, including from layer pixels
  • Repeat X/Y tiling and seamless Evolution loops
  • Blend mode and RGB Only option
