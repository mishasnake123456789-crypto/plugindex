What Uv King - Smart Uv Packing does

UV King is a UV packing add-on for Blender 4.0 and above. A single click packs a large number of islands while making better use of texture space than basic packing.

It uses heuristic packing that tests different layouts to find the best one, works across several UDIM tiles, and stacks identical UVs automatically. You can also fine-tune grouping, scale, rotation and placement. Texture artists handling large asset sets can pack efficiently.

Key features

  • One-click packing for thousands of islands
  • Heuristic layout search
  • Multiple UDIM tiles
  • Automatic stacking of identical UVs
  • Control over grouping, scale, rotation
