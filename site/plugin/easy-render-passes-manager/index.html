What Easy Render Passes Manager does

Easy Render Passes Manager centralizes pass export in Blender. From a single panel you add passes from a list, set output folders and file formats, and the add-on builds the compositor output node structure automatically.

Common passes such as Beauty, Z Depth, Normal, Diffuse and Glossy are available. It spares compositors the repetitive node setup and keeps outputs organized for later editing. Among its tools are add passes from a list and folder and format settings per pass.

Key features

  • Add passes from a list
  • Folder and format settings per pass
  • Automatic compositor output nodes
  • Beauty, Depth, Normal, Diffuse and Glossy passes
