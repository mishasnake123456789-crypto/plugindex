What Screen Saver Exporter does

Late for Dinner Studios' Screen Saver Exporter converts finished video into a working screen saver. A single plugin handles Mac and Windows, with audio and video supported.

Output can go straight to a .scr file or an .msi installer, and a macOS screen saver can even be exported from a Windows machine, for Intel and Apple Silicon Macs alike. The engine in version 2.0 (MovieSaver2.saver) is natively Apple Silicon, cuts CPU use roughly tenfold and reduces file size. Motion designers delivering branded loops or showreels as desktop screen savers get a quick route.

Key features

  • One-click screen saver export
  • Audio and video support
  • Exports .scr or .msi installer
  • macOS screen saver from Windows
  • Apple Silicon native engine in version 2.0
