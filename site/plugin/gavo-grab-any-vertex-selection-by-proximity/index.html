Selects vertices by proximity in Blender and assigns them to named vertex groups and modifiers.

What Gavo - Grab Any Vertex Selection By Proximity does

Gavo grows or shrinks a vertex selection based on how close points are to a starting selection. Once you have the set you want, it names the group and assigns it automatically.

Vertices can also be grabbed by index number. A modifier is picked and named, then the vertex group is loaded into it from a dropdown, with a live readout of the current choices. Riggers and modelers who frequently create vertex groups for modifiers will cut down repetitive selection work.

Key features

  • Proximity-based select and deselect
  • Grab vertices by index number
  • One-button group naming and assignment
  • Load groups into modifiers from a list
