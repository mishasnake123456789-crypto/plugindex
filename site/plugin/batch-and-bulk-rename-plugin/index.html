What Batch and Bulk Rename Plugin does

The Batch and Bulk Rename Plugin gives Premiere Pro editors a faster way to organize naming. Select clips and sequences, then rename them all in one pass.

You can replace words in source file names, add dates or custom text to clip names, ignore bins via a settings option, and optionally update the XMP Dublin Core title when renaming. It is designed for assistant editors and large productions. Consistent naming helps with relinking, searching and handoffs.

Key features

  • Batch rename clips and sequences
  • Find and replace in source file names
  • Add dates and custom text
  • Option to ignore bins
  • Optional XMP Dublin Core title update
