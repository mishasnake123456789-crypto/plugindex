What Gn Rolling Shutter does

GN Rolling Shutter generates metal curtain doors in Blender procedurally, using Geometry Nodes. Select a mesh and it creates a roller shutter sized to match, which is useful for shopfronts and street scenes.

You can change width and height, how far the door is open, the slat style, the colors and whether padlocks appear. The result is prepared for rendering in both Eevee and Cycles. It was designed with architectural visualization in mind, saving modelers from building repetitive shutter geometry by hand.

Key features

  • Procedural roller shutter built from a selected mesh
  • Adjustable width, height and door opening
  • Choice of slat type
  • Optional padlocks and custom colors
  • Set up for Eevee and Cycles rendering
