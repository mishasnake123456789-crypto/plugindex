What Texcraft does

Texcraft is a texture baking tool for Blender that covers every shader node, including Mix Shader and Add Shader setups. It gathers jobs that normally need several add-ons into one place.

Features include atlas baking of many objects with merged UVs, selected-to-active baking from high-poly to low-poly with custom cages, and packing up to four maps into the R, G, B and A channels with optional inversion. Automatic UV detection and smart unwrapping repair problem layouts, and UDIM generation and Unity import are supported.

Key features

  • 142 bake types across all shader nodes
  • Atlas baking of multiple objects
  • Selected-to-active baking with custom cage
  • Channel packing with per-channel invert
  • Auto UV unwrapping and UDIM generation
