Blender add-on that sets all selected Bezier curve handles to one size.

What Normalize and Resize Curve Handles does

Normalize and Resize Curve Handles adds a simple but missing operation for Bezier curves in Blender: giving every selected handle the same length. It can also resize them together.

Run from Quick Favorites (Q) or Menu Search (F3), it displays a resize gizmo in the viewport. It works on Blender 4.2 LTS and newer, needs no special permissions, and installs by drag and drop or from disk.

Key features

  • Equalizes selected Bezier handle sizes
  • Resizes handles together
  • Visible resize gizmo
  • Run from Q menu or F3 search
  • Blender 4.2 LTS and newer
