3ds Max utility with several ways to select and manage scene objects: categories, stored lists, selection sets and path lists.

What Quick Selection does

Quick Selection from lbrooks provides multiple methods for picking objects in a 3ds Max scene. You can select by category, by stored objects, by selection sets that live independently of any Max file, or by pathname literals kept in a text file.

Storing a selection saves the object names to an INI data file so they persist between sessions. Selection set items can be renamed, the list can be sorted, and a thin bar button opens the INI file for browsing or editing. It is helpful for production scenes with many objects where Max's native selection sets are not enough.

Key features

  • Selection by category, stored objects and selection sets
  • Selection by pathname literals in a text file
  • Store Selection saves names to an INI file
  • Rename and sort selection set entries
  • Button to open the INI data file
