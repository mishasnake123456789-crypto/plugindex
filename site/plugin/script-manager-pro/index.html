What Script Manager Pro does

Script Manager Pro is a Blender add-on by CemilBerk for keeping external Python scripts organized and launching them from a sidebar panel. Any script runs with one click, and scripts can also be opened in Blender's built-in Text Editor.

You can mark favorites and filter by them, assign custom tags and display names, and edit script metadata without leaving the panel. Favorites, tags and names are stored in a local JSON file, so they persist. Developers and technical artists with many utility scripts benefit most.

Key features

  • One-click script execution from the sidebar
  • Open scripts in the Text Editor
  • Favorites and custom tags
  • Display names and metadata editable in the panel
  • Settings saved in a local JSON file
