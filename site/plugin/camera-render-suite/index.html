What Camera Render Suite does

Camera Render Suite covers photography-style setup and rendering in Blender. Its seven modules include studio setup, lighting tools, DSLR-style controls, object rotation, camera navigation and animation.

Clay Render Mode swaps scene materials for a neutral clay shader to test lighting, with an optional wireframe overlay for technical presentations. HDRI management and batch rendering round out the set. It suits product, architecture and portfolio artists who want a camera-first workflow. Taken together, the modules let one add-on take a scene from lighting test through to a finished batch of renders.

Key features

  • Clay Render Mode with wireframe overlay
  • HDRI management
  • DSLR-style camera controls
  • Studio lighting tools
  • Batch rendering and camera animation
