Generates game-ready LOD chains in Blender up to LOD4 with smart decimation and export for Unreal, Unity and Godot.

What Lod Architect does

LOD Architect automates the creation of levels of detail for game assets. It builds a chain up to LOD4, using a ratio per level or a target vertex count, and can process several meshes in one batch.

Decimation is guided to preserve normals and UVs, and the workflow is non-destructive, keeping the source mesh with live modifiers so ratios can be tweaked later. One-click export targets Unreal Engine, Unity and Godot. Game artists optimizing large asset sets will save repetitive work.

Key features

  • One-click LOD chain up to LOD4
  • Per-LOD ratio or vertex count targets
  • Normal transfer and UV preservation
  • Non-destructive with live modifiers
  • Export for Unreal, Unity and Godot
