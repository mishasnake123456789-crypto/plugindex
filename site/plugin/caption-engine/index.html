What Caption Engine does

Caption Engine, from Dorian's lab, is an After Effects CEP panel that converts caption files into editable subtitle graphics. It reads SRT, WebVTT and TTML files and builds a single text layer rig driven by layer markers.

Revised files can be imported again to update timing and wording while styling stays untouched. Source text can be cleaned by removing formatting tags, bracketed sound notes and extra whitespace, and timing is frame accurate with snapping, minimum durations and auto-trim for overlaps. Styling covers margins, offsets, box, padding, corner radius and opacity. Cues can be split to individual layers, with an import log of stats and warnings.

Key features

  • Imports SRT, WebVTT and TTML
  • Single text layer rig driven by markers
  • Re-import keeps styling in place
  • Text cleanup and frame-accurate timing
  • Box, padding and safe margin styling
