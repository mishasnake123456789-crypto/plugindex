After Effects tool for shape-layer cleanup with onion skinning, shade groups, path tweaking and mask creation.

What Cleanup Master does

Cleanup Master from Gareso speeds up routine cleanup work on shape layers in After Effects. It bundles several helpers that otherwise require manual steps, and it supports versions from CC 2018 up to 2026.

Onion Skin shows ghosted frames before and after the current one as animation reference, without appearing in renders. Create Shade Group duplicates artwork with chosen properties kept linked to the original. Tweak Paths helps edit shape paths with better shape recognition, and selected paths can be converted to masks, with an option to subtract.

Key features

  • Onion skin overlays excluded from renders
  • Shade groups with selectable linked properties
  • Tweak Paths with improved shape recognition
  • Masks from selected paths, with subtract option
  • Compatible with AE CC 2018 through 2026
