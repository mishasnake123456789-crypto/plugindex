What Runic - Rune And Glyph Library does

RUNIC is a Blender plugin from Blue Nile 3d for carving symbols into models. It offers a library of rune fonts and can also convert images you draw yourself into geometry, making it simple to add inscriptions to stone, metal or props.

It is sold in tiers going up to 80 rune types, includes documentation and is distributed under the GPL license. Fantasy and game artists can use it to decorate swords, tablets, walls and magical items without modeling each character manually.

Key features

  • Library of rune fonts
  • Converts hand-drawn images to geometry
  • Tiers up to 80 rune types
  • GPL licensed with documentation
