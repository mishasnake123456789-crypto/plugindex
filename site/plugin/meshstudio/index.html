Renders custom object previews for Blender's Asset browser from a chosen camera and world environment.

What Meshstudio does

MeshStudio generates and assigns thumbnail previews for assets in the Asset browser, replacing the default look with ones you control. Select the objects in the viewport, choose a camera and a world environment, then render.

Camera zoom and preview resolution are adjustable, and the output folder can be set, otherwise defaulting to //object_previews beside the .blend file. It is helpful for asset library builders who want consistent, attractive thumbnails. It helps asset libraries stay visually consistent.

Key features

  • Custom previews assigned in the Asset browser
  • Choose camera and world environment
  • Adjustable zoom and preview resolution
  • Custom output folder
  • Defaults to //object_previews
