What Motion Subtitle Maker does

Motion Subtitle Maker automates animated subtitle creation in After Effects. Feed it an SRT file and it builds styled subtitles, then renders them as QuickTime video or PNG files for use in an edit.

To get the subtitles back into a timeline with frame-accurate placement, it generates fcpxml and xml files for DaVinci Resolve, Premiere Pro and similar editors. Compositions can be re-exported from their xml files without starting again from the SRT. Fonts for the templates are fetched from Adobe Fonts on their own, a French interface is included, and it works with After Effects 2022 through 2026.

Key features

  • Builds animated subtitles from an SRT file
  • Renders to QuickTime or PNG files
  • Frame-accurate fcpxml and xml for the timeline
  • Re-export from xml without redoing the SRT
  • French interface; Fonts fetched from Adobe Fonts
