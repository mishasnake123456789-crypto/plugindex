What ALE Metadata Toolkit does

ALE Metadata Toolkit brings Avid Log Exchange files into Premiere Pro more completely than the built-in route. Every column is imported, including those that Premiere would normally skip.

The plugin can also update metadata in an existing ALE file and merge the ALE values with the metadata already held by Premiere Pro. An option creates subfolders according to the Tape Name. Editors who receive lab or dailies data in ALE form, and who need all of it available alongside their clips, will find it a handy way to reconcile the two sources.

Key features

  • Imports all ALE columns, including skipped ones
  • Updates metadata in an existing ALE file
  • Merges ALE data with Premiere Pro metadata
  • Optional subfolders by Tape Name
