Blender add-on for painting soft body simulation zones onto a mesh in weight paint mode.

What Soft Body Painter does

Soft Body Painter lets you define where a soft body simulation applies by painting it in weight paint mode in Blender. Then apply the setup and run it on the timeline.

The panel provides stiffness, bending stiffness, damping and push or pull forces, along with self, face and edge collision options. Weld Points to the Original keeps parts fixed, and Follow Original Object blends the motion with the source mesh. Physics runs on duplicates, so the original is untouched, and the area is controlled by a named vertex group.

Key features

  • Paint simulation zones in weight paint mode
  • Stiffness, bending, damping and force settings
  • Self, face and edge collision options
  • Weld points and follow original object
  • Non-destructive, works on duplicates
