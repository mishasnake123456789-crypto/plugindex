Blender add-on that bakes scale-correct displacement maps from high-poly meshes onto low-poly ones.

What Displacement Baker - Industry Standard Displacement does

Displacement Baker automates a fiddly part of sculpt-to-game workflows in Blender: projecting detail from a dense mesh into a displacement texture for a lighter one. It uses raycasting so the result keeps correct scale.

A helper matches selected meshes into low and high pairs using bounding boxes, names them by polygon count and places them in collections. Ray distance can be set manually or estimated, a nearest-border option avoids spikes at edges, and boundary smoothing and sampling speed are adjustable. Images are created at bake time with UDIM detection, size, margin and mid-value options, and results can stay inside the file for quick testing.

Key features

  • Raycast displacement baking
  • Auto pairing and renaming of low and high meshes
  • Ray distance with auto estimate
  • Spike prevention at border edges
  • UDIM-aware image creation
