What Light Array does

Light Array speeds up scene lighting in Blender with a large library of prepared setups. More than forty-five arrangements are ready to use, and twenty different light types can be chosen, so you can try varied moods without placing each lamp.

A documentation section includes a lesson explaining how to use it. It is released under a royalty-free license and supports Blender 3.6, 4.0 and 4.1. Professionals who want to work faster and hobbyists exploring lighting for personal projects can both use it as a starting point for studio and product renders.
