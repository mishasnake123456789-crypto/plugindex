What Fast Image (Search & Download) does

Fast Image saves you the trip to a web browser when you need reference pictures or textures. Queries go out to Pexels, Pixabay, Bing and Google Images without leaving Blender.

Once you copy an image address, the add-on downloads the picture and packs it into your .blend file. By default Shift+Ctrl+I searches and Shift+Ctrl+Alt+I downloads, and both hotkeys can be changed in the preferences. Handy for quickly sourcing reference and texture material.

Key features

  • Searches four image sources from Blender
  • Downloads and packs images into the .blend
  • Default search and download hotkeys
  • Hotkeys editable in preferences
