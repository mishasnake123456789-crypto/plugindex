What Holmes does

Holmes is a scene analysis add-on for Blender, built for users who want to know what is going on inside a heavy file. It looks at scenes and objects in real time rather than leaving you to dig through properties.

It offers tailored suggestions for improving a scene, estimates how long a render will take, and exports statistics so they can be reviewed later. It supports Blender 3.0 through 5.0, ships with documentation from the developer, and is released under the GPL.

Key features

  • Real-time scene and object inspection
  • Render time estimation
  • Improvement suggestions for the scene
  • Statistics export, Blender 3.0 to 5.0
