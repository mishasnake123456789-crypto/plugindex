What Find Duplicate Meshes does

Spencer Magnusson's Find Duplicate Meshes detects meshes in a scene that are exact copies. It can auto-select every mesh that matches what you have selected, or match and link duplicates in one step.

Sharing mesh data between objects lowers memory use and can improve viewport and render performance. Afterwards, editing one linked mesh updates all objects or instances that share it. Scenes built from imported or kitbashed parts, where copies became unique, can be tidied and lightened.

Key features

  • Selects all meshes matching the selection
  • Matches and links duplicates in one step
  • Reduces memory use
  • Edit one mesh to update all linked objects
  • Improves viewport and render performance
