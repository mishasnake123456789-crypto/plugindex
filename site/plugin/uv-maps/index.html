Blender extension that lifts the 8 UV map limit and adds reordering and batch tools for UV maps.

What UV Maps+ does

UV Maps+ expands how Blender handles UV maps. It removes the limit of eight UV maps per object and lets you reorder them with arrows or send them straight to the top or bottom.

A specials menu offers sort, reverse, duplicate and delete. Batch commands for several selected objects align map order, copy distinct map names and carry UV data across when topology matches, and Edit Mode tools copy and paste UV coordinates between selections. A warning system highlights problems. Texture artists with complex multi-UV assets stay organized.

Key features

  • Removes the 8 UV map limit
  • Reorder maps with arrows or jump to top or bottom
  • Sort, reverse, duplicate, delete
  • Batch sync and transfer across objects
