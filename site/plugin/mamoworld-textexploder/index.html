What mamoworld TextExploder does

mamoworld TextExploder breaks text layers into separate, clean layers without using expressions or text animators. Each character stays in its precise original position.

Splits can target characters, words or lines, a single custom word, or any pattern defined by regular expressions. Per-character text styles keep multi-colour and multi-font text intact on After Effects 24.3 or newer. KBar support runs saved settings from a toolbar button, a scripting API allows automation, and 3D layers, bounded text, animated position and separated dimensions are handled. Animators needing letter-level control for kinetic type get dependable results.

Key features

  • Split into characters, words or lines
  • Custom splits via regular expressions
  • Per-character text styles on After Effects 24.3+
  • KBar support and scripting API
  • 3D layers, box text and separated dimensions
