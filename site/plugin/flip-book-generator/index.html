What Flip Book Generator does

Flip Book Generator turns a set of still images into a flipping book animation in Blender. It sets up pages, camera movement and timing, so all you need to do is supply pictures and render.

The flip book size and position are customizable, the camera moves automatically to capture it from a good angle, and a Create Flip Book item appears in the Object menu after installation. Each page can have an optional background picture beneath images with transparency, and an optional back-face picture. Motion designers making portfolios or photo reels will find a ready-made effect.

Key features

  • Flip book from still pictures
  • Customizable size and position
  • Automated camera motion
  • Optional page background and back-face pictures
  • Create Flip Book in the Object menu
