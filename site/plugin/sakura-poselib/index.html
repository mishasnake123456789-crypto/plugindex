What Sakura Poselib does

Sakura Poselib is a pose library built to replace Blender's phased-out one. Poses are created from the current armature and managed in a library you can organize.

Poses can be imported from the legacy pose library, mmd_tools and PMX Editor, categorized and batch renamed, blended with sliders and keyed in the timeline. Export to MMD formats is included. Character animators and MMD creators can reuse poses efficiently. The library is useful for repeatable character setups, keeping a collection of reusable stances available inside the file rather than scattered across scenes.

Key features

  • Create poses from the current armature
  • Import from old pose library and mmd_tools
  • Categorize and batch rename
  • Blend poses with sliders
  • Export to MMD formats
