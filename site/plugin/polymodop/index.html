What PolyModOp does

PolyModOp, a MAXScript struct by Swordslayer, gives Edit Poly modifier methods the same signatures as polyop. Scripts written for Editable Poly can therefore handle the Edit Poly modifier as well, instead of needing two separate code paths.

A scripter checks the object type once, chooses polyop or polymodop, and the rest of the code stays the same. It favors ease of coding and maintainability over raw speed on complex meshes. The Border Fill script is included as an example, a missing_methods text file lists what is not implemented, and it is released under the permissive ISC license for 3ds Max 9 and later.

Key features

  • Wraps Edit Poly modifier methods with polyop-style signatures
  • Check object type once and reuse the same code
  • Border Fill script included as an example
  • missing_methods file lists unimplemented functions
  • ISC license, works with 3ds Max 9 and later
