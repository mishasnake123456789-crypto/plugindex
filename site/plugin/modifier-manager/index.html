Blender add-on adding right-click tools to select, apply, remove and copy modifiers in bulk across scene objects.

What Modifier Manager does

This Blender add-on takes some of the tedium out of managing the modifier stack. Its commands live in the right-click menu, so bulk actions are always close at hand without opening extra panels.

You can select modifiers on many objects at once, apply them together, remove them in a single step, or copy them from one object to others in the current scene. This is helpful for scenes with many similar objects, where repeating the same operation per object wastes time. The add-on needs no special permissions and is licensed under GPL v3 or later, so it can be used and adapted freely.

Key features

  • Right-click menu access to modifier utilities
  • Bulk selection of modifiers across scene objects
  • Bulk apply and bulk remove
  • Copy modifiers across objects in the scene
  • GPL v3 or later licensed
