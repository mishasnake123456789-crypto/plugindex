What Blendbook: Note Taking, To-Do Lists And Cross Platform Collaboration does

Project notes scattered across apps get lost. Pixel Vampire's BlendBook stores notes, comments and lists in the .blend file, so they travel with the scene between Windows, Mac and Linux.

Reminders and to-do items can be ticked off when completed, and whoever opens the file is able to add to the lists. Feedback from teammates stays inside the project rather than in separate chat threads. A good fit for freelancers and small studios that want lightweight task tracking without leaving Blender.

Key features

  • Notes, reminders and to-do lists in Blender
  • Stored inside the .blend file
  • Works on Windows, Mac and Linux
  • Tick off completed tasks
  • Shared lists via the .blend file
