What MAD (Microphone Audio Driver) does

MAD, the Microphone Audio Driver, is a Blender add-on by F1dg3t that converts a live microphone signal into an animation driver. Target bone rotations, shape keys or custom properties, and they respond to sound as it comes in.

In the MAD panel you pick a microphone, choose the target object with an eyedropper and enter the data path. The response is tuned with Tunable with scale, default value and interval, and Start and Stop buttons control the driver. It is a fun way to make lip-sync-like or reactive characters.

Key features

  • Drives any keyable rig property from a microphone
  • Microphone selection and eyedropper target
  • Volume Scale, Default Value and Update Interval
  • Start and Stop Audio Driver buttons
  • Real-time response
