Blender add-on for stamping decals via automated material-based projection with layering and noise-based fading.

What Stamp Master does

Stamp Master by CGMatter adds images and decals to objects in Blender. Choose a target, pick a stamp, then set coordinates and apply.

Shift+Ctrl+D starts the tool, guided placement positions the stamp, fading is adjusted with the mouse wheel, and layering and noise-based fading are built in. Texture artists can add dirt, labels and wear without UV editing. Layering lets several stamps build up on the same surface, and noise-based fading blends the edges so decals look worn into the object rather than pasted on top.

Key features

  • Material-based projection
  • Shift+Ctrl+D shortcut
  • Guided placement
  • Layering and noise-based fading
