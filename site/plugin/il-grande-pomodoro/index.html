What Il Grande Pomodoro does

Shawn Blanch's Il Grande Pomodoro brings the Pomodoro technique into Blender, splitting work into timed sessions and breaks. Goals are set in minutes, globally or per file.

A compact menu in the 3D Viewport Header starts, stops and monitors the clock. A Project Tracker saves total, current and previous session time with three header display styles. Notifications mark each Pomodoro, and autosave options plus a ranking system round it out. Artists who struggle to pace long sessions get structure.

Key features

  • Work and break timer in minutes
  • 3D Viewport Header menu
  • Project Tracker for session time
  • Notifications for each Pomodoro
  • Autosave options and ranking system
