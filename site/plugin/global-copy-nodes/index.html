What Global Copy Nodes does

Global Copy Nodes, by hisanimations, creates a copy buffer for nodes that outlasts the current file. Nodes copied with Ctrl+Shift+C can be pasted with Ctrl+Shift+V into other .blend projects, new sessions or a separate running Blender.

An optional custom copy path stores the buffer in a folder you choose, which allows copying between Blender versions. Attached objects or collections can be linked to the active scene automatically, with a default collection if wanted, and nodes can also go to the internal buffer. References to data-blocks are kept so nothing is lost.

Key features

  • Copy and paste nodes between blend files
  • Works across sessions and instances
  • Custom copy path for cross-version use
  • Auto link attached objects to the scene
  • Ctrl+Shift+C and Ctrl+Shift+V shortcuts
