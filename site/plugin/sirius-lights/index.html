Blender lighting system for generating and managing arrays of lights in circles, grids, spheres, curves or on meshes.

What Sirius Lights does

Sirius Lights builds large groups of lights quickly and keeps them organized in collections. It targets complex lighting jobs where placing each light manually would be tedious.

Lights can be arranged in circles, grids, spheres, along Bezier curves, or on object vertices and face centers. Randomization of position, rotation and color uses reproducible seeds. A color system and dynamic FX allow fine tuning afterward. The result is a controllable setup for stage, product or abstract lighting.

Key features

  • Circle, grid, sphere, curve and mesh placement
  • Lights organized into collections
  • Randomized position, rotation and color with seeds
  • Color system and dynamic FX
  • Manage large groups instantly
