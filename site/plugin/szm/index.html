Blender add-on that improves search in add-node and modifier menus using Chinese pinyin initials, full pinyin, characters or English.

What szm/首字母 does

SZM adds smarter search to Blender's Add Node and modifier menus for users who work with Chinese interfaces. Items can be found by pinyin initials, complete pinyin, Chinese characters or the English name.

The search index can be customized in the add-on preferences. Chinese-speaking artists can locate nodes and modifiers by typing a few initial letters instead of scanning long lists. Typing a few letters is much quicker than scrolling through long English menus for users who think in Chinese.

Key features

  • Search by pinyin initials
  • Full pinyin, characters and English name search
  • Works in node and modifier menus
  • Customizable search index
