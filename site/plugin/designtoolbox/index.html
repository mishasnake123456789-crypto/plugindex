What DesignToolBox does

DesignToolBox from Atelier Bump speeds up basic modeling in 3ds Max, especially for architectural models, furniture and other work where dimensions must be exact. Transformation tools will feel familiar to CAD users, including reference-based rotation, scale and position.

The set also covers measurement tools and reference guides, snapping points at line intersections, visual rulers, fast UVW mapping with randomization, cloning tools, scene management, panel grids, quick pivot placement and work planes. Designers and archviz modelers who want precision without long menu sequences will appreciate the shortcuts.

Key features

  • CAD-familiar reference rotation, scale and position
  • Measurement tools and visual rulers
  • Snapping at line intersections
  • Fast UVW mapping and randomization
  • Cloning, panel grids, pivots and work planes
