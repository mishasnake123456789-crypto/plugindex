What Ebbawt - Accurate Weight Painting With Armature does

EBBAWT helps riggers get repeatable skin weights in Blender. You prepare a special armature, save it, and reuse it on other jobs, so the Set Parent With Automatic Weights command reproduces the same weight painting each time instead of varying with each setup.

The add-on includes tools to retrieve a normal armature together with a mesh object that carries the weight painting, along with extra tools for working with vertex groups. It is distributed under the GPL. Character artists rebuilding similar rigs or iterating on a mesh will find it reduces repeated weight painting.

Key features

  • Prepare, save and reuse a special armature
  • Automatic weights reproduce the same painting
  • Retrieve a normal armature with weighted mesh
  • Extra vertex group tools
