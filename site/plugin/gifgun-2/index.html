What GifGun 2 does

GifGun 2 is Nik Ska's updated exporter for turning After Effects compositions into short web animations. The first-generation GIF creation is joined by WEBP rendering and MP4 export, and companion standalone and web apps sit alongside the plugin.

WEBP output can loop and has a Sharp YUV mode. MP4 uses two-pass rendering for better quality at a given size. GIFs gain an Alpha Matte feature that handles semi-transparent pixels around alpha edges, and a size optimization algorithm trims file weight. Settings can be saved as presets.

Key features

  • One-click animated GIFs
  • WEBP with looping and Sharp YUV
  • MP4 with 2-pass rendering
  • Alpha Matte for clean GIF edges
  • Standalone and web apps; savable presets
