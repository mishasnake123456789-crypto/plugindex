Blender hard-surface boolean add-on to create, manage and clean cutters with Exact and Fast Destructive modes.

What Nurc Boolean Core does

Nurc Boolean Core streamlines boolean work in Blender, giving direct access to cutter creation and management.

Difference, Union, Intersect and Slice are available, and the stack can be handled with Apply Last, Apply All, Remove Last and Remove All. Cutters can be shown, hidden, selected, organized and cleaned, in a dedicated collection with consistent naming. Access comes from the sidebar, popup or menu. Hard-surface modelers can keep cutters tidy and apply or undo them predictably.

Key features

  • Difference, Union, Intersect and Slice
  • Apply and Remove stack controls
  • Cutter show, hide, select and clean
  • Dedicated cutter collection
  • Exact and Fast Destructive modes
