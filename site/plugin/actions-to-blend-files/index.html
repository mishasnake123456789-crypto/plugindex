What Actions to Blend Files does

Actions to Blend Files, by William-Leong, writes each Action in the current file out to a separate .blend, which makes animation libraries easier to share and reuse. It is listed under Import-Export.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.

Key features
