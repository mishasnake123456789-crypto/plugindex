What Masks to Cropped Layers II does

Masks to Cropped Layers II is an After Effects utility by Chris Zwar for layers that carry many masks, such as artwork pasted from Illustrator or areas tracked in Mocha. It copies each mask to a new solid or precomp cropped to that mask's size, which helps vector animation and compositing speed.

Sizes can be calculated from basic rectangles, which is fast, or from bezier paths, which is slower but pixel-accurate, measured from a single frame, the work area or the layer duration. It uses all masks or only selected ones, with buttons to select open or closed masks, optional padding and rounded positions, and label colors for each mask type. Extra neon light elements are included.

Key features

  • One cropped layer per mask
  • Rectangle or bezier size calculation
  • Measure from frame, work area or layer duration
  • Select all open or closed masks
  • Padding option and label colors
