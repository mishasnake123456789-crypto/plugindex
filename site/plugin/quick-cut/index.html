A Blender Edit-mode add-on that cuts a mesh along selected edges with a Shift-Q shortcut.

What Quick Cut does

Quick Cut lets you slice a Blender mesh along edges you have already selected. Instead of using separate knife or loop-cut steps, you select the edges in Edit mode, press the shortcut and fine-tune the result in the operator settings.

It adds a Mesh Cut operation with adjustable options and runs entirely in Edit mode. The add-on supports Blender 2.93 through 4.3, is released under the GPL and includes documentation. Hard-surface modelers and anyone cleaning up topology who wants a fast, repeatable way to cut along existing edges will find it handy.

Key features

  • Cuts along selected edges
  • Shift-Q shortcut
  • Adjustable Add Mesh Cut settings
  • Runs in Edit mode
  • Supports Blender 2.93 to 4.3
