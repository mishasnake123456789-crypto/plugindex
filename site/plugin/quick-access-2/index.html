What Quick Access 2 does

Quick Access 2 from R-Smart saves time hopping between folders in After Effects. It lists recent import, render and project paths, your last path and favorites, so common locations are a click away.

An effects history lets you start typing a name to find one, favorites can be created on the fly, and the recent list stays tidy through an algorithm that trims extras. It can also render selected layers to PNG with post-render actions, and a comp to JPG when a JPG preset exists.

Key features

  • Recent import, render and project paths
  • Favorite paths created on the go
  • Searchable effects history
  • Self-trimming recent paths list
  • Render selected layers to PNG
