What Mesh Magnet - Surface Deform Toolkit does

Mesh Magnet extends Blender's Surface Deform modifier using Geometry Nodes and custom attributes. It handles meshes, curves, groom guides, pinned objects and procedural geometry.

Four binding modes are provided: Mesh/Curve Elastic, Mesh/Curve Rigid, Groom Curve and Procedural (Scatter), with Groom Curve tuned for hair and fur transfer. The modifier method stays non-destructive for use with simulations or armatures, while the attribute method applies the bind pose for Edit Mode. Select by Deform Mesh, Clean and Refresh Bind Pose help manage bindings.

Key features

  • Four binding modes including groom curves
  • Modifier and attribute methods
  • Select by Deform Mesh and Clean
  • Refresh Bind Pose recalibration
