What Smart Keyframe Navigator does

Smart Keyframe Navigator extends the default keyframe jumping in After Effects with context awareness. With nothing selected it works like the usual K and J keys across all keyframes.

Select one or more layers and it moves only through their keyframes; select specific properties and only those count, even across several layers. That makes precise timing work faster in dense comps. It supports After Effects from CS5.5 up to 2020.

Key features

  • Keyboard-based keyframe navigation
  • Acts like K and J when nothing is selected
  • Limits to selected layers
  • Limits to selected properties across layers
  • Supports CS5.5 through 2020
