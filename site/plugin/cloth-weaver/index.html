What Cloth Weaver does

Cloth Weaver by Xanderak builds clothes and accessories for characters and scenes in 3D in Blender. It comes with template libraries as well as tools for custom garments.

The Ultimate set holds 29 templates and the Basic set 9, spanning tops, bottoms, formal wear, swimwear, underwear, accessories and fabrics. For custom clothing, create an outline and define which sections get sewn together. Costume and character artists can dress models quickly. Garments are built from a sewn outline, so custom designs follow the logic of real pattern making and can be draped on a character with cloth simulation.

Key features

  • Ultimate set of 29 and Basic set of 9 templates
  • Tops, bottoms, formal wear and swimwear
  • Custom garments from outlines
  • Accessories and fabrics
