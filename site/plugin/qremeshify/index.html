What Qremeshify does

QRemeshify is a Blender extension by Ksami that converts models into good-quality quad topology. It is based on QuadWild with a Bi-MDF solver, and it works without any external program to download or run.

Symmetry is supported, and the edge flow can be guided by edges flagged as seams or sharp, or boundaries between materials and face sets. Results are good even with basic use, and advanced options allow fine-tuning. It runs on Windows, Linux and macOS and you use it from the N-Panel of the 3D view while in Object mode.

Key features

  • Quad remeshing based on QuadWild
  • Symmetry support
  • Edge flow guided by seams, sharp edges and boundaries
  • No external programs needed
  • Runs on Windows, Linux and macOS
