What Shirakumo SF3 IO does

Shirakumo SF3 IO, developed by shinmera, lets Blender read and write the Simple File Format Family. It supports three kinds of file: models, images and archives, covering meshes, materials and textures.

Model files (.mod.sf3) store a single mesh with its material, image files (.img.sf3) hold textures, and archive files bundle the pieces together. The add-on is useful for pipelines or projects that use this format and need a way to move assets between it and Blender.

Key features

  • Imports and exports .mod.sf3 model files
  • Imports and exports .img.sf3 texture images
  • Handles SF3 archive files
  • Covers meshes, materials and textures
