Blender add-on for batch importing Mixamo FBX animations and baking root motion onto a new root bone.

What Import Mixamo - Root Motion does

Import Mixamo - Root Motion streamlines using Mixamo animations in Blender. It imports multiple FBX files at once from File > Import > Mixamo Fbx and prepares them for game or animation use.

Batch tools strip the mixamorig: prefix from bone names, rename animations by file name, apply transforms while fixing animation strength, and remove redundant skeletons. A root bone is then created to record the character's displacement, with keyframes baked onto it. Game developers and animators preparing locomotion clips save much repetitive work.

Key features

  • Multi-file Mixamo FBX import
  • Removes mixamorig: prefix in batch
  • Batch rename and transform apply
  • Root bone with baked root motion
