What Print To Python Console does

Print To Python Console is a Blender plugin by Nikita Akimov that sends print output and errors to the Python Console instead of only the system console. Scripters can see results in the interface.

A PtoPC panel has buttons to turn redirection on or off temporarily: one enables output to the Python Console, and the other returns it to the system console. This keeps feedback in the same window as your script, which is convenient when testing code and tracing problems.

Key features

  • Redirects prints and errors
  • Toggle buttons in the PtoPC panel
  • Return to the system console
  • Useful for script debugging
