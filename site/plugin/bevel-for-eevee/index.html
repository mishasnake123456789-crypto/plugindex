What Bevel For Eevee does

Bevel For Eevee recreates the Cycles-only Bevel node so Eevee users can get softened edges. It is a node group that fakes the bevel by changing surface normals, without altering the geometry.

It works from ambient occlusion values and also functions in Cycles. Useful for adding highlights on edges of hard surface models in real-time renders. It gives Eevee users convincing edge highlights without modeling real bevels, which keeps meshes light for real-time work.

Key features

  • Node group replicating the Bevel node
  • Works in Eevee and Cycles
  • Normal-based fake bevel
  • No change to geometry
