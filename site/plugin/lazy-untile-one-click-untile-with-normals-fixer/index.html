What Lazy Untile (One-Click Untile With Normals Fixer) does

Lazy Untile tackles repeating patterns in image textures in Blender. Select Image Texture nodes in the Shader Editor, click once, and the tiling is broken up.

It also includes a normals fixer node group: select the normal map and apply the fix. The panel lives in the Shader Editor's N sidebar. It is listed for Blender 4.1 through 4.4, and in Blender 4.2 it installs as an extension by dragging the zip into the window. The license is royalty free.
