What RMB Sort View Layers Alphabetically in Outliner-Scenes does

This compact Blender extension by RobWu brings order to a long list of view layers. Right-click within the Outliner under Scenes > View Layers and choose the sort option to arrange the layers alphabetically or numerically.

It does one job and stays out of the way, which suits productions with many render layers or passes where names need to follow a consistent order. No setup is needed beyond installing the extension.

Key features

  • Sorts view layers A-Z and/or 0-9
  • Right-click access in Outliner Scenes
  • Small, single-purpose extension
