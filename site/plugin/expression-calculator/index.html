What Expression Calculator does

Expression Calculator is a helper for people building templates with expressions. It works out the difference in a selected property's value before and after an expression is applied, which saves guesswork when matching offsets.

It can also bake a property with an expression at the current frame and insert a selected property's value into an expression. It supports After Effects from CC 2014 through 2022. This takes the trial and error out of building flexible templates where several expressions interact with the same property.

Key features

  • Calculates a property's value difference around an expression
  • Bakes an expression property at the current frame
  • Adds a property's value into an expression
  • Supports CC 2014 through 2022
