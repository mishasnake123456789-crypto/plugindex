What Drone Show does

Drone Show from SMUELDigital builds on the drone show tool in Blender 4.5 and later, adding a prototype show compiler and a MAVSDK Offboard export bundle for PX4-based testing.

Animated show data is compiled into a generic bundle with trajectory and light information, producing a show_bundle.json with positions, velocities, accelerations and RGB values for all drones, plus a CSV per drone. Show designers can move from Blender previews toward testing.

Key features

  • Compiles animation into a generic show bundle
  • show_bundle.json with positions and RGB values
  • One CSV file per drone
  • MAVSDK Offboard export for PX4 testing
