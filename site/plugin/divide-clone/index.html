Quick 3ds Max script that fills the gap between two objects with clones of geometry, lights, cameras, shapes or groups.

What Divide Clone does

Divide Clone fills the space between two objects in 3ds Max with copies. What gets cloned can be either of the two endpoint objects or another object of your choice, so the series is flexible.

It works with lights, shapes, cameras and geometry, and supports cloning groups as well. This is handy for placing row of lamps, columns, fence posts or any repeating element evenly from one point to another without calculating spacing manually. It works with 3ds Max 2016 and later.

Key features

  • Creates clones between two objects
  • Clone source can be either object or a separate pick
  • Works with lights, shapes, cameras and geometry
  • Supports cloning groups
  • Works with 3ds Max 2016 and later
