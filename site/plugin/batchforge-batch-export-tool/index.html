Blender add-on that exports every object as its own file with custom naming, origins, transforms, formats and FBX presets.

What BatchForge: Batch Export Tool does

BatchForge exports scenes piece by piece. Each object is written individually, with a configurable naming convention, a choice of origin point for its pivot, and control over whether transforms are reset or customized.

Formats and output paths are configurable, and FBX presets are included for Unity, Unreal or your own axis settings. Game artists with modular kits can export dozens of props in a single pass.

Key features

  • Per-object export
  • Configurable naming and origin points
  • Transform reset or customization
  • FBX presets for Unity and Unreal
  • Configurable formats and paths
