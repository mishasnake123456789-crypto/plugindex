A Blender plugin that streamlines Rigify setup and animation retargeting with a non-destructive workflow.

What Retargify does

Retargify reworks how Rigify is used in Blender, aiming to keep the original armature structure intact so rigs stay compatible with game engines and other software. It works non-destructively, using automatically created armature duplicates and constraints so you can add, move and remove bones without altering the base data.

One-click baking transfers animation from the animation armature to the base armature with 1:1 accuracy, with control over which animations to bake. Motion-captured data can also be baked backwards onto the rig. Character animators and game developers who retarget mocap will find the process simpler.

Key features

  • Non-destructive duplicate armatures and constraints
  • One-click baking with 1:1 accuracy
  • Choose which animations to bake
  • Backwards baking of mocap data
