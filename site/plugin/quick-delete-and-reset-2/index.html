What Quick Delete & Reset 2 does

Quick Delete & Reset 2 is a cleanup script from Motion Embassy. It can enable, disable or delete expressions and effects, remove keyframes, masks and layer markers, and reset transformations, with a Reset All option.

Scope is selectable: chosen layers, the active comp, selected comps or the entire project. Shift-click deletes only disabled expressions or effects. The interface adapts to window size, has a customizable toolbar and icon or text buttons, and handles newer layer types like environment lights and 3D objects.

Key features

  • Enable, disable and delete expressions and effects
  • Delete keyframes, masks and layer markers
  • Reset transformations
  • Scope from layers to entire project
  • Responsive UI with customizable toolbar
