What Vse Archiver - The Videoproject Back Up Kit does

Vse Archiver gathers the footage used by a Blender video project into one archive location. It builds an ordered folder structure and saves a new blend file with the media relinked.

Collect Sources copies the original files, while Collect Snippets renders sequence strips into the archive. You can choose copy or render per media type or per strip. Images, image sequences, video, audio and fonts are found in sequencer strips or blend data, and a file used by several strips is copied only once.

Key features

  • Collect Sources copies original files
  • Collect Snippets renders strips
  • Copy or render chosen per type or strip
  • Gathers images, video, audio and fonts
  • Shared sources copied only once
