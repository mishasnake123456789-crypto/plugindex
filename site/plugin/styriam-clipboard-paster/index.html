What Styriam Clipboard Paster does

Styriam Clipboard Paster lets you paste what is on your clipboard directly into Blender on Windows. Images can land in the 3D Viewport as a plane or reference, the Image Editor, or the Node Editor for shader, compositor and texture graphs, skipping the save-and-import step.

In sculpt and texture paint modes, pasted images become stencils with alpha support. Existing image pixel data can be replaced in place when dimensions match, or an Image Node swapped for a new data block. SVG pastes through Blender's default SVG importer, and text is supported too. Reference-heavy texture and concept workflows will move faster.

Key features

  • Paste images into the viewport, Image Editor or Node Editor
  • Stencils for sculpt and texture paint with alpha
  • Replace image data in place or swap an Image Node
  • Paste SVG and text
  • Windows only
