Blender add-on that extrudes a chosen face along the path of an edge loop, with caps and end rotation.

What Extrude Path does

APEC's Extrude Path pushes a detached face along a path defined by an edge loop. Select one detached face and the loop, then launch it from the lower part of the Edge menu or the context menu.

Release 0.0.2 added caps for open extrusion loops and rotation of the final extrusion. Documentation is included, and Blender 3.6 through 5.1 are supported. Pipes, rails, cables and architectural trims that follow a profile are natural uses.

Key features

  • Extrudes a face along an edge loop
  • Edge and right-click menu access
  • Caps for open loops
  • Rotates the final extrusion
  • Blender 3.6 to 5.1
