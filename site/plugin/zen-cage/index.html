What Zen Cage does

Zen Cage manipulates objects using a bounding-box cage that has interactive handles. Seven modes are combined in a single tool: Align, Fit, Distribute, Array, Clamp, Rotate and Scale.

Three cage modes are available, including a Dynamic mode that adjusts automatically to the selected objects. Layout artists and modelers who regularly align and space objects can handle these jobs without switching between several operators. Instead of moving objects by trial and error, the cage shows the extents being used and makes alignment visible.

Key features

  • Seven transformation modes
  • Interactive cage handles
  • Dynamic cage mode
  • Align, Fit, Distribute and Array
