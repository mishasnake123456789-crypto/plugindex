Finds keyframes with a given value and swaps them for a new one across layers or comps in After Effects.

What Find & Replace Keyframes does

Built by Jordan Steele, Find & Replace Keyframes is a tool running inside After Effects that works like search and replace for animation data. Specify the value to find and the value to put in its place, and every matching keyframe is changed.

The search can cover selected layers, the current comp, selected comps or every comp. You pick the keyframe type, such as value, position, color, text or any, and matched keyframes can be selected right in the timeline. Version 2.0 brought a redesigned interface, a rebuilt framework and support for all applicable property types.

Key features

  • Global search and replace of keyframe values
  • Scope: layers, current comp, selected comps or all
  • Filter by value, position, color or text
  • Select matches in the timeline
  • Redesigned UI in version 2.0
