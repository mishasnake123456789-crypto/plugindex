Blender add-on that removes unused empties and materials while protecting data in use.

What Cleand does

CleanD tidies Blender scenes before rendering or exporting. It removes clutter without putting needed objects, materials or images at risk.

Delete Unused Empties skips empties referenced by modifiers, used by other add-ons, or serving as parents. Smart Material Cleanup clears materials that no object uses while keeping active ones, and image data is preserved. Ctrl+Alt+X runs it from the 3D View. Detection of empties used in modifiers, parenting and third-party add-ons is more stable in this release.

Key features

  • Deletes unused empties safely
  • Smart cleanup of unassigned materials
  • Preserves image data
  • Ctrl+Alt+X shortcut in the 3D View
