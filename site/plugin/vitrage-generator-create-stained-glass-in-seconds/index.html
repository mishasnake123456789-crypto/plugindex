What Vitrage Generator - Create Stained Glass In Seconds does

PeakDreams Studio's Vitrage Generator produces stained glass windows automatically in Blender. A picture is converted using Geometry Nodes and Shader Nodes, with settings adjustable throughout.

Shapes aren't restricted to ordinary windows; most silhouettes and meshes work. You choose glass piece size and form, set the resolution of inner and outer frame geometry, and add random color variation. Architectural, church and fantasy scene artists get detailed windows without cutting each piece.

Key features

  • Image to stained glass conversion
  • Works on almost any silhouette or mesh
  • Adjustable piece size and shape
  • Frame geometry resolution controls
  • Random color variation
