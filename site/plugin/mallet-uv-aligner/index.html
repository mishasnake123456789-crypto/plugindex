What Mallet: Uv Aligner does

Inlet's Mallet: UV Aligner supplies quick edits for tidying UV maps in Blender. World Align reads world coordinates for a chosen object or faces, adjusting the texture mapping with a single click.

Alignment choices include Top, Bottom, Left, Right and Center. Justify arranges UVs to cover space according to those options, Fill stretches them across the whole image area, and transform, flip and scale tools handle the rest. Texture artists fixing misaligned or stretched layouts save time.

Key features

  • World Align based on world coordinates
  • Top, Bottom, Left, Right and Center alignment
  • Justify UVs for coverage
  • Fill the UV space
  • Transform, flip and scale tools
