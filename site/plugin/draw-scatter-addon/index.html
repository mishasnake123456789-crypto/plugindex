What Draw Scatter Addon does

Draw Scatter distributes objects along a curve you sketch in Blender. You select the object, draw the path and then change the count and size to control how the copies fill the line, a fast way to build patterns and flowing arrangements.

It can also produce abstract curves with objects rotating around them. Controls sit in the N-panel with tweakable settings, documentation is included, and it runs on Blender 2.93 through 4.0. Motion graphics artists making decorative shapes and anyone populating a path with repeated elements will appreciate how little setup it needs.

Key features

  • Scatters any object along a drawn curve
  • Count and size controls
  • Abstract curves with rotating objects
  • N-panel controls
  • Supports Blender 2.93 to 4.0
