Tool connecting Blender Geometry Nodes to Unity for procedural meshes and levels, with Sverchok, terrain and curve support.

What Bengine For Unity does

Bengine For Unity runs Blender's procedural node setups inside the Unity engine. Geometry Nodes can generate meshes and levels there, and Sverchok nodes work alongside them.

It also supports Unity Terrain and Unity Curve objects, including splines and polylines, and provides networking between Blender and Unity. Game developers who prefer to design procedural content in Blender can iterate without constantly exporting and re-importing assets.

Key features

  • Geometry Nodes procedural meshes in Unity
  • Sverchok node support
  • Unity Terrain and Curve support
  • Networking between Blender and Unity
