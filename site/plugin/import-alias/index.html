Turns Autodesk Alias NURBS data into meshes and brings surfaces, curves and subdivision data into Blender.

What Import Alias does

Import Alias brings Autodesk Alias data into Blender. NURBS surfaces become meshes, NURBS curves stay NURBS curves, and Alias subdivision data arrives as subdivision data.

A tolerance setting controls deviation between the original NURBS and the mesh, with lower values giving a finer result, and an autoflip normals option tries to orient surfaces correctly. Industrial and automotive designers moving concepts between the two programs get a more direct path. Lower tolerance values keep more of the original surface shape at the cost of denser meshes.

Key features

  • Alias NURBS to mesh conversion
  • Curves and subdivision data imported
  • Tolerance setting for mesh fineness
  • Autoflip normals option
