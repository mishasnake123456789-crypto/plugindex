What System Monitor Pro does

System Monitor Pro puts hardware readouts directly in the After Effects interface, so you can see what a heavy comp is doing to your machine without opening a separate utility. The panel refreshes every second while you work.

It reports used RAM, CPU load with live clock speed, and VRAM per GPU with temperatures, and handles any number of NVIDIA GPUs. It is built for Windows and is useful for artists tuning previews, renders and multi-GPU workstations.

Key features

  • Real-time RAM, CPU and GPU monitoring
  • Live CPU clock speed
  • VRAM and temperature per GPU
  • Dockable panel updating every second
  • Supports multiple NVIDIA GPUs
