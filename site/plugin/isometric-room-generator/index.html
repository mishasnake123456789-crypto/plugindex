What Isometric Room Generator does

Isometric Room Generator creates room shells, square or round, with adjustable width, depth, height and wall and floor thickness, all from a sidebar panel.

Windows can be added to one or both walls with configurable count, shape (sash, round or square) and size, and each window panel is its own object with a render-ready glass material. It suits isometric illustrations and diorama scenes. Day to day, that covers square or round room shells, dynamic windows with count, shape, size and separate window objects with glass.

Key features

  • Square or round room shells
  • Dynamic windows with count, shape, size
  • Separate window objects with glass
  • Wall and floor thickness control
