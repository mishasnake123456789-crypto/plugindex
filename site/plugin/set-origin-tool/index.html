Places Blender object origins using a 3x3 bounding-box grid, one-click tools and a pie menu.

What Set Origin Tool does

Set Origin Tool simplifies pivot placement. A 3x3 grid, laid out with symbols, sets the origin to the top, center, bottom, left, right or corners of an object's bounding box.

Quick tools handle common cases with one click: Geometry to Origin, Origin to Geometry, 3D Cursor, Center of Mass, Center of Volume, Selection and Bottom. A pie menu opens with Ctrl + Alt + Z. It is a handy shortcut when preparing assets for animation or export.

Key features

  • 3x3 bounding-box origin grid
  • One-click origin operations
  • Center of mass and volume options
  • Pie menu on Ctrl + Alt + Z
