What Smart Render Profile does

Smart Render Profile simplifies output settings in Blender's Video Sequencer. Presets cover YouTube at 1920x1080, TikTok at 1080x1920 and Instagram at 1080x1080.

Custom profiles can be saved and loaded, batch export runs all saved profiles, and everything is managed from a sidebar. Handy for editors delivering one video in several formats. The profiles help keep exports consistent when the same project goes out to different services. Editors preparing clips for different social channels can avoid redoing output settings for every upload.

Key features

  • Presets for YouTube, TikTok, Instagram
  • Save and load custom profiles
  • Batch export of all profiles
  • Sidebar interface
