What Drawcallanalyzer does

DrawCallAnalyzer is a Blender add-on for checking game-readiness before export. It inspects a scene the way an engine would and reports draw calls, texture memory, batching and instancing opportunities, and overdraw.

Each material slot counts as one draw call, so totals and per-material breakdowns can be compared with a platform budget. Static and dynamic batching analysis identifies candidates that share materials and fit vertex count limits. Technical artists and game developers can spot performance problems early rather than after importing into an engine.

Key features

  • Draw call estimates per material
  • Comparison against platform budgets
  • Static and dynamic batching analysis
  • Texture memory and overdraw reports
