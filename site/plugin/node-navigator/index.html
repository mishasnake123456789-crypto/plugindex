Blender add-on that finds and zooms to nodes, lists frames and auto-formats shader and geometry node graphs.

What Node Navigator does

Node Navigator helps Blender users find their way around large node trees. It works in both shader and geometry node editors and removes the endless panning that complex graphs demand.

You can jump to and zoom on any node, browse a categorized list of frames with a filter, and tidy the whole graph with automatic formatting. Extra conveniences include instant solo previews, loop-back socket routing, direct muting and an active-node outline similar to the active object highlight. A sync mode keeps the sidebar current and can be disabled to save resources in heavy graphs.

Key features

  • Locate and zoom to any node
  • Lists and filters frame groups
  • Auto-formats the whole node graph
  • Solo previews, loop-back routing and muting
  • Active outline and optional sync mode
