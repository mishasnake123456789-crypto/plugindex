What Uv Quick Tool does

UV Quick Tool combines two steps: applying object scale and generating UVs using cube projection. Doing so keeps UV density consistent with real-world dimensions across a scene.

It works with Blender 2.8 through 4.4, is GPL-licensed and includes documentation. It speeds up texturing prep for architectural and environment assets. Among its capabilities are apply scale in one operation, cube projection UVs and world-scale UV density. The package also offers blender 2.8 to 4.4.

Key features

  • Apply scale in one operation
  • Cube projection UVs
  • World-scale UV density
  • Blender 2.8 to 4.4
