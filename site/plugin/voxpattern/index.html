What VoxPattern does

VoxPattern is a grape design plugin for creating geometric patterns that exist in three-dimensional space inside After Effects. Rendering is GPU accelerated for responsive previews.

Five pattern types are available, and the plugin is camera aware so the patterns react naturally as the view moves. Randomization produces diverse designs, and crop controls limit where the pattern appears. It suits abstract backgrounds, title sequences and tech visuals that need volumetric repeating structures.

Key features

  • Geometric patterns in 3D space
  • Five pattern types
  • Camera-aware rendering
  • Randomization for varied designs
  • Crop controls
