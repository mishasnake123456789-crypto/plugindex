A Blender add-on that reshapes mesh geometry through custom parameters you slide interactively.

What Parametrizer does

Parametrizer introduces parametric control to Blender meshes. You build a set of parameters that regulate sizes and ratios, then reshape the geometry by sliding the parameter fields, so adjusting a design becomes a matter of dragging values rather than moving vertices.

Each parameter can work in Translation, Rotation or Scale mode, with axis selection and application to selected vertices. Orientation and origin of its transformation are adjustable. This is useful for designers who need variable dimensions on products, furniture or mechanical forms, and want to experiment quickly with proportions.

Key features

  • Custom parameters regulate sizes and ratios
  • Translation, Rotation and Scale modes
  • Axis selection per parameter
  • Adjustable orientation and origin
