What Curve Generator does

Curve Generator creates float curves for Blender's Shader, Geometry and Compositor editors, starting from a chosen FloatCurve node. Instead of dragging control points by hand, you pick the curve style you want.

Slider-based options define the shape. Spring, Elastic, Stairs and Bounce curves are available, along with presets, random curves and custom CSS input. Technical artists shaping remaps, falloffs and easing can generate precise curves quickly. Because the curves are created from sliders and presets, it is easier to experiment than adjusting individual points on a FloatCurve widget.

Key features

  • Works in Shader, Geometry and Compositor editors
  • Spring and Elastic curves
  • Stairs and Bounce curves
  • Presets and random curves
  • Custom CSS input
