Enters colors in RGB or CMYK in Blender and applies them to objects, faces or lights with automatic materials.

What Adobe Style Color Input does

Adobe Style Color Input gives Blender a color entry system familiar from design software. You can work in RGB from 0 to 255 or CMYK in percentages, with conversion between the two happening live.

Views can show RGB only, CMYK only, or both side by side. One click applies a color to an object, to faces in edit mode or to a light, creating a material or updating an existing one. Useful for designers matching print colors in 3D.

Key features

  • RGB (0-255) and CMYK (0-100%) with live conversion
  • RGB, CMYK or side-by-side view
  • Apply to objects, faces or lights
  • Automatic material creation and update
