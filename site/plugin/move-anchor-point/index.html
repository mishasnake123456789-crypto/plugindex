What Move Anchor Point does

Move Anchor Point is a script from BatchFrame Software for After Effects. It relocates a layer's anchor point to any spot while leaving the layer visually where it was, solving a small but constant annoyance when setting up rotations and scales.

Positions are chosen on a grid you can customize, and the modular panel displays just the controls you need. Favorite placements can be stored as presets for reuse. A search-matching feature moves anchor points on layers based on their names, which saves time when handling many layers in a single comp.

Key features

  • Moves anchor points without moving the layer
  • Customizable grid for placement
  • Modular interface showing only needed controls
  • Reusable position presets
  • Match layers by name to move in bulk
