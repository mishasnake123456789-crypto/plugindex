What Origin_move_like_maya (Press D) does

Origin_move_like_maya is a Blender add-on by deepak756 that brings Maya's way of moving a pivot into Blender. Press D to enter pivot mode, drag the origin independently with a gizmo, and press D again to leave.

Pressing S while in this mode toggles snapping on or off. It is meant for Object mode and does not operate in Edit mode, supports Blender 4.2 LTS and newer, and requires no special permissions. It saves several steps for artists used to Maya's pivot workflow.

Key features

  • D key enters and exits pivot mode
  • Gizmo moves the origin independently
  • S key toggles snapping
  • Works in Object mode
  • Supports Blender 4.2 LTS and newer
