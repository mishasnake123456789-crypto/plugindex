Switches the 3ds Max MAXScript listener to dark mode automatically at startup.

What Dark Listener does

Dark Listener changes the look of the 3ds Max listener window to a darker scheme. After installation it turns on by itself every time the program launches, so there is nothing to configure each session.

The darker background is easier on the eyes and aims to reduce eye strain, which is especially welcome when scripting late at night. It is a simple cosmetic tool for script writers and technical artists who spend long hours in the listener.

Key features

  • Dark mode for the 3ds Max listener
  • Activates automatically at startup
  • No setup needed after install
  • Easier on the eyes at night
