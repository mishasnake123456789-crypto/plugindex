Blender UV toolset adding shortest path, spread, smooth, circle, transfer selection, randomize, boundary select and gridify tools.

What Zuv Tools does

Zuv Tools extends the UV editor with operators that Blender lacks. Transfer Selection, Circle, Smooth, Spread and Shortest Path operators help select and shape UVs in various ways.

Version 2.5 added Randomize, Boundary Select, an improved Hide and Gridify Islands, and default keymaps are supplied for common copy and paste operations. Texture artists unwrapping complex models can arrange islands and clean layouts faster.

Key features

  • Shortest Path, Spread, Smooth and Circle operators
  • Transfer Selection
  • Randomize, Boundary Select and Gridify Islands in 2.5
  • Default keymaps
