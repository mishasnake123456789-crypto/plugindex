What Blender Terrain Engine does

Blender Terrain Engine (BTE) streamlines terrain material creation. It automates PBR mixing, anti-tiling and masking, and is controlled from the BTE N-Panel.

The interface follows the workflow of Textures, Blending, then Look & Feel. Each layer has an eye icon to toggle visibility and compare combinations, and Batch PBR Import auto-assigns selected textures to the right slots from their filenames. Native Asset Browser support makes terrain materials easy to reuse.

Key features

  • Automated PBR mixing and anti-tiling
  • Masking tools
  • Native Asset Browser support
  • Layer visibility toggles
  • Batch PBR import by filename
