Lightweight 3ds Max asset library manager with drag-and-drop import and offline AI visual search by reference image.

What CoreLink does

CoreLink lets artists browse, preview and drag assets from a library straight into a 3ds Max scene. The AI visual search works offline on your own computer: paste a reference picture with Ctrl+V or upload one to find similar assets, or right-click an asset to re-sort by visual likeness.

Drag and drop repairs missing texture paths automatically. Text search combines with color filters, file-type toggles, tags and favorites, and health tools hunt for missing thumbnails, duplicates and unused files. The AI model needs a one-time download and then works fully offline. A central index can be shared over network storage with background indexing. A free Standard License and a Pro tier exist.

Key features

  • Offline AI visual search by reference image
  • Find Similar re-ranking by visual similarity
  • Drag and drop with automatic texture path repair
  • Filtering by text, color, file type, tags and favorites
  • Library health scans and shareable network index
