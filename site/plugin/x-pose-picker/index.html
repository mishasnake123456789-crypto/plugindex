What X-Pose Picker does

X-Pose Picker lets riggers lay out clickable picker panels for characters and other 3D objects in Blender. It works with any rig, from Rigify, Auto-Rig Pro and Blenrig5 to Mixamo and custom setups, on Mac, Linux and Windows.

Buttons can use custom SVG shapes and be copied between tabs, and a single click handles x-mirroring for repetitive symmetrical work. An embedded simplified Python option extends behavior. Animators get a faster way to select controls, and studios can give a consistent interface to different characters.

Key features

  • Works with Rigify, Auto-Rig Pro and custom rigs
  • Custom SVG button shapes
  • Copy and paste buttons between tabs
  • One-click x-mirror
  • Embedded simplified Python
