What AE Work Manager does

AE Work Manager is a panel from Power Robot for tracking how long a project takes and what it costs. With one click you start logging time against an activity such as editing, tracking, color grading, VFX or rendering, and the panel keeps recording quietly in the background.

When the project wraps, a single action produces a breakdown of times and costs, and the report can be exported. Everything happens inside After Effects, so freelancers and studios do not need spreadsheets or separate timers. It is compatible with After Effects versions from CC 2014 through 2026.

Key features

  • One-click time logging per activity
  • Silent background recording
  • Instant time and cost breakdown
  • Exportable project cost report
