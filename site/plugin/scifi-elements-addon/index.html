What Scifi Elements Addon does

From EdenWeby 3D, Scifi Elements Addon builds sci-fi HUDs, environments and further VFX in Blender. It ships with more than 30 elements and premade combos, with additional ones in the Pro and Ultimate editions.

An Element Animation Panel animates rotation, location and reveal using Constant, Function or Reveal modes. A material editor provides a realistic glow with a Noise Value control. The elements work with Eevee and Cycles, and the Cycles glare filter can add bloom. It suits motion designers making futuristic interfaces and title sequences.

Key features

  • 30+ elements and premade combos
  • Animation panel with Constant, Function and Reveal modes
  • Material editor with glow and noise
  • Works with Eevee and Cycles
  • More elements in Pro and Ultimate editions
