What Qol Tools: Polypal does

Qol Tools: Polypal helps you sketch shapes quickly in Blender by drawing polygons directly. No starting object is needed, which makes it ideal for building silhouettes.

Chamfering and filleting can be applied on the fly with Ctrl plus a middle mouse drag, switching using the C and F keys. Any edge can become the new leading edge, or you can scroll through edges with the mouse wheel. It speeds up early blockouts for concept models.

Key features

  • Draw polygons without creating objects
  • On-the-fly chamfer and fillet
  • Choose any edge as the leading edge
  • Quick silhouette drawing
