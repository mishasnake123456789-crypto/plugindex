What Moiré does

Moire, by WAINE, creates interference patterns in After Effects using only native effects. It can look modern or retro and fits well with CRT screens and VHS-style treatments.

Simple sliders control how the pattern looks. When working with tracked footage, the plugin can parent or corner pin the pattern automatically and animate it to the track with a click. kBar icons and a toolbar are included, and 32-bit support was added in version 1.5. It is useful for screen replacements, glitchy overlays and abstract textures.

Key features

  • One-click moire pattern creation
  • Slider controls for pattern appearance
  • Auto parenting or corner pinning to tracked footage
  • Built on native After Effects effects
  • kBar toolbar and 32-bit support
