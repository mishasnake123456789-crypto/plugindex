What Usync - Blender To Unreal Made Easy Pipeline does

USync, from James Guard Studios, links Blender to Unreal Engine across a production, from early prototype levels through final art. It transfers characters, animations, caches, static meshes and whole levels.

Level Sync works in two clicks with instanced transfer for static meshes and Blueprints, and Static Mesh Sync handles collision shapes named with the _UCX convention. Teams building games or virtual production scenes can reduce manual FBX handling.

Key features

  • Level Sync with instanced transfer
  • Static Mesh Sync with _UCX collision
  • Character and animation syncing
  • Cache transfer to Unreal
