What Smooth Rounder does

Smooth Rounder is a grape design tool for After Effects that draws curves smoother than the normal corner rounding of ellipse and rectangle shape layers. It matches modern interface styles such as super ellipse icons.

It creates controller effects for size, round and corner radius, all of which can be keyframed, and the smoothness of the curve can be animated as well. Fill, stroke and other shape layer controls remain available as usual. UI designers and motion artists can use it to build and animate app icons and buttons.

Key features

  • Curves smoother than standard corner rounding
  • Super ellipse icon styles
  • Keyframeable size, round and radius controllers
  • Animatable curve smoothness
