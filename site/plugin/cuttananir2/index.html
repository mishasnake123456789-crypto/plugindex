What CuttanaNir2 does

CuttanaNir2, from Terrible Junk Show, is a set of tools for making handwriting-style write-on animation in After Effects. It breaks text into the individual shapes that need to be revealed one after another, then carries them through a series of stages until you have animated lines.

The workflow converts text to character paths, divides those into stroke paths, separates strokes onto their own layers, and builds line animations driven by a path-trimming expression with slider keyframes. Layers can then be arranged into sequences by name. Newer additions include automatic line making, rounded tips, trails from Bones and an exit animation. Artists producing explainer-style handwriting effects can edit timing and speed afterwards.

Key features

  • Text to character paths for one-at-a-time reveals
  • Stroke paths split into single-path layers
  • Line animation via path trimming and slider keyframes
  • Sequences arranged by layer name
  • Rounded tips, trail paths and animate-out options
