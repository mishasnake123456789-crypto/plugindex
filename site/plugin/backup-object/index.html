What Backup Object does

Backup Object is a workflow add-on for Blender. One button duplicates the selected objects fully, including mesh data, into collections created for them, so you can compare or return to earlier versions.

Every object type works, such as meshes, cameras, Grease Pencil and image empties. A cheap safeguard before risky edits. This makes it safe to experiment with destructive edits, since the untouched originals are always organized and ready for reference.

Key features

  • One-click backups
  • Duplicates mesh data completely
  • Any object type supported
  • Own collection for each backup
