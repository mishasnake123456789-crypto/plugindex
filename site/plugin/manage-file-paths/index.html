What Manage File Paths does

Manage File Paths is a Blender add-on by GregZaal that shows every image file path and cache file in one list, with indicators for files that are missing. It also gives shortcuts to Blender functions such as finding missing files and removing unused datablocks.

A Find & Replace panel adjusts all image file paths in bulk, which helps after moving folders. It supports Blender 4.2 LTS and newer and is released under the GNU GPL v3 or later. Anyone passing projects between machines will find it useful.

Key features

  • Single list of image and cache paths
  • Missing file indicators
  • Shortcuts to find missing files and purge unused data
  • Find & Replace for bulk path edits
  • Supports Blender 4.2 LTS and newer
