Blender add-on that assigns materials and attributes to objects by naming rules in a node editor.

What Palette Nodes - Rule Based Assignment Tool does

Palette Nodes assigns materials, subdivisions and visibility attributes to a collection of objects automatically using naming rules. It is useful for caches and larger scenes.

The rules are built in a custom node editor and applied across the collection, replacing manual assignment on many objects. Documentation is included and the add-on is released under the GPL.

Key features

  • Assigns materials, subdivisions and visibility
  • Rules based on object names
  • Custom node editor
  • Suited to caches and large scenes
