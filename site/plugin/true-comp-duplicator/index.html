True Comp Duplicator

Developer: Brennan Chapman

An After Effects script that duplicates a comp together with all of its nested subcomps.

What True Comp Duplicator does

True Comp Duplicator solves a familiar After Effects annoyance: duplicating a composition normally leaves its nested subcomps shared with the original. This script makes a full copy of the selected comp hierarchy, subcomps included, so changes to the copy don't leak back.

A depth limit controls how far down the nesting it goes, and footage items can optionally be duplicated as well. Expressions in the new comps are updated to point at the copies. An include and exclude filter, with regex support, picks which items get copied. You can make several copies in one pass, work on multiple comps at once, and rely on improved naming.

Key features

  • Duplicates entire comp hierarchies with subcomps
  • Depth limit for nested levels
  • Updates expressions in the copies
  • Include/exclude filter with regex option
  • Multiple copies and multiple comps in one pass
