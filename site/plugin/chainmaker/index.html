3ds Max script that builds a chain along a spline from a single link object, scaling it to fit the path.

What Chainmaker does

Chainmaker by Chuggnut creates a chain system in 3ds Max from two inputs: a link object and a spline path. The link is scaled to fit exactly along the path, so the chain ends where the spline ends.

Custom script look-at controllers are set up so the links orient themselves along the chain as it moves. For better speed, those controllers can be dumped to normal keys afterward. It is a useful shortcut for chains, ropes of linked parts and similar mechanical items that would otherwise require placing and rotating many links by hand.

Key features

  • Builds a chain from a link object and a spline
  • Scales the link to fit the path exactly
  • Custom script look-at controllers
  • Option to bake controllers to normal keys for speed
