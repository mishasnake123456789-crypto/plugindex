What Pixel Art Renderer does

Pixel Art Renderer turns a scene into pixel art live in the 3D viewport, using stylized controls. You see the result while you work rather than waiting for a render.

The color palette is customizable, and output can be an image or an animation with a custom base file name. An alpha channel is available for the background. It suits retro games and pixel-style animation. Seeing the pixelated result live makes it easy to tune scale, palette and lighting until a scene reads clearly at low resolution.

Key features

  • Real-time pixel art in the viewport
  • Custom color palette
  • Image and animation output
  • Alpha background option
