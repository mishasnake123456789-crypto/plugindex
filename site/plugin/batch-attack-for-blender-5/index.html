What Batch Attack For Blender 5+ does

Batch Attack imports PBR materials from a chosen directory in one click. It finds maps by naming convention, renames each material after its Albedo map and builds the node trees automatically for Eevee and Cycles.

Ten map types are supported: Albedo, Normal, Roughness, Metal, Bump, Displacement, Specular, Emissive, AO and Opacity. It is built for Blender 5 and cuts the grind of setting up large texture libraries. Among its capabilities are one-button directory import, naming-based map detection and 10 supported map types.

Key features

  • One-button directory import
  • Naming-based map detection
  • 10 supported map types
  • Automatic node tree setup
