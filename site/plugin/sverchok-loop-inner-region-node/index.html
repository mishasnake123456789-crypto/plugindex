What Sverchok Loop Inner Region Node does

Sverchok Loop Inner Region Node gives Sverchok users a counterpart to Blender's Select Loop Inner Region from Edit Mode. Give it a loop edge index and it works out which faces lie inside or outside that loop.

Inputs accept vertex, edge and face data plus the loop_edge_ind value, and separate outputs return the inside or external face indices. It is aimed at procedural modelers building node setups that need to isolate regions bounded by an edge loop.

Key features

  • Selects inner or outer region faces
  • Inputs for vertices, edges and faces
  • loop_edge_ind input
  • Inside and external face index outputs
  • Mirrors Blender's loop inner region tool
