What Multilattice - Quick Setup Lattice Deformation does

Multilattice by Orcavia removes the manual steps of creating a lattice for deformation in Blender. One click builds a lattice that fits the dimensions and rotation of the selected objects automatically.

Several objects can share a single lattice, and it works in both Object Mode and Edit Mode. This makes it easy to bend, squash or stylize a group of parts together, for example when shaping a character's clothing or a set of props.

Key features

  • One-click lattice setup
  • Auto-fits dimensions and rotation
  • Multiple objects under one lattice
  • Works in Object and Edit Mode
