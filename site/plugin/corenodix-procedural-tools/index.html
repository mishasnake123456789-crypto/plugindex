Serves as C-You FX's tool hub for Blender, with material copy, paste and clone plus a procedural materials demo for Cycles.

What Corenodix - Procedural Tools does

COREnodix works as the central engine and demo area for C-You FX's procedural tools, meaning one installed copy serves them all. Tool content is limited and locked until you purchase the corresponding tool.

Included utilities copy, paste and clone materials between selected objects. A demo of the procedural materials creator for Cycles shows how materials can be built without nodes or code, combining premade components. It is relevant for artists exploring the C-You FX range.

Key features

  • Single hub for all C-You FX tools
  • Locked content unlocks on purchase
  • Copy, paste and clone materials between objects
  • Procedural materials creator demo for Cycles
  • No nodes or code needed for the demo
