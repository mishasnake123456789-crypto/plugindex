What Text Chain does

Text Chain, by Braindot Design, connects separate text layers so they behave as one string. When one changes, the others follow, and the whole line can be held inside a chosen width.

This is handy for titles made of differently styled words, such as a bold name followed by a lighter title. Version 2.1 supports After Effects 2020 and CC 2019, works on macOS Catalina and fixes a problem with international versions.

Key features

  • Dynamic linking of separate text layers
  • Keeps the full string within a width
  • Supports After Effects 2020 and CC 2019
  • macOS Catalina compatible
