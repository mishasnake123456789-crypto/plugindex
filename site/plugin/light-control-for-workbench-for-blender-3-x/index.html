What Light Control For Workbench (For Blender ≤ 3.X) does

MST ARQUITECTURA's Light Control For Workbench sets shadow direction numerically in the Workbench engine instead of by dragging a lamp. Show Shadows enables viewport shadows.

Azimuth gives the clockwise angle from north (the Y axis) and Elevation the angle upward from the horizon; North Offset corrects for the project's true north. Presets can be saved and parameters animated. Architects making sun studies in the viewport will find it useful. Because values are numeric, a sun position can be reproduced exactly later or shared with colleagues.

Key features

  • Show Shadows toggle
  • Azimuth and Elevation parameters
  • North Offset for true north
  • Save your own presets
  • Animatable parameters
