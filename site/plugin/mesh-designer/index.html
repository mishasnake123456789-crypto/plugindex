What Mesh Designer does

jkdesign's Mesh Designer builds objects, designs and characters from procedural primitives that keep a construction history, comparable to Maya. Parameters remain adjustable throughout.

The shape list has grid, cube, circle, ICO and UV sphere, cylinder, cone, torus, gear and folder. Every dimension, from vertex count to hole size and axis, stays editable, and you can replace or copy a primitive mid-project. The Studio version adds pre-built extras. Good for iterative blockouts and parametric modeling.

Key features

  • Procedural primitives with history
  • Gear, torus, cone and more shapes
  • Edit size, vertex count and radius anytime
  • Replace or duplicate primitives
  • Studio version adds extras
