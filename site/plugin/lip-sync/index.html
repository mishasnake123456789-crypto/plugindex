Blender add-on that analyzes audio and generates phoneme-based mouth keyframes automatically.

What Lip Sync does

Lip Sync automates mouth animation in Blender. It analyzes a voice recording, extracts phonemes and writes keyframes for a character's mouth so you do not need to key each sound by hand.

Over twenty-five languages work, among them English, French, Spanish, German, Russian, Hindi and Mandarin. It can drive 3D shape keys or 2D spritesheet mouth shapes and integrates with the Video Sequencer. Vosk language models are cached locally for faster reanalysis and offline use. Animators and indie creators save many hours on dialogue.

Key features

  • Automatic phoneme extraction from audio
  • 25+ languages
  • Shape key and 2D spritesheet animation
  • Video Sequencer integration
  • Local model caching for offline use
