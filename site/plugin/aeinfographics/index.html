After Effects extension that converts CSV or typed data into animated infographic charts from twelve templates.

What AEInfoGraphics does

AEInfoGraphics by Cihan Balunak turns data into animated charts in After Effects. Import CSV files or build a table in its interface, then choose from twelve chart templates to generate a composition.

Some templates support multiple data sets for comparing two sets in one chart. A preview shows the final output and color themes before you create anything, and there are nine themes to choose from. Animation and composition durations are adjustable, labels can show values or percentages, and data and settings can be saved and loaded.

Key features

  • CSV import or in-panel data tables
  • Twelve chart templates
  • Preview with nine color themes
  • Value or percentage labels
  • Save and load data and settings
