What Tool Hub does

Tool Hub is a Blender add-on by Mr.Bir that lets you search for operators and pin your favorites, including adding meshes, modifiers and constraints. Pinned tools are available in a pie menu in the 3D view, opened by pressing U.

Edit-mode support came in version 1.0.2, adding Face, Edge and Vert commands for mesh editing. It supports Blender 4.2 LTS and newer, needs no special permissions and installs by drag and drop or from disk. It brings the commands you use most within one gesture.

Key features

  • Search and pin favorite operators
  • Pie menu opened with the U key
  • Edit-mode Face, Edge and Vert commands
  • Supports Blender 4.2 LTS and newer
  • Requires no special permissions
