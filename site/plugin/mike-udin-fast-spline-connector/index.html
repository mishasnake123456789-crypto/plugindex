What Mike Udin Fast Spline Connector does

Mike Udin Fast Spline Connector links separate segments of one spline into a continuous curve. Select two points, set a distance tolerance, and choose whether to join or weld them.

A Get button reads the right tolerance from the two points you picked, and minimum and maximum values help locate points more accurately. Join mode adds a new segment between the connected points, while Weld mode merges two spline points into one. It helps with cleaning up imported vector artwork and broken outlines in Cinema 4D.

Key features

  • Get button sets tolerance from two points
  • Adjustable minimum and maximum tolerance
  • Join mode creates a segment between points
  • Weld mode merges two points into one
