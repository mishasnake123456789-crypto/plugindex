What Blocksurfaceslite does

BlocksurfacesLITE is a blocking tool for characters in Blender 4. Instead of sculpting from a sphere, you assemble the main volumes from branches made of simple shapes such as cubes and spheres.

Objects in a branch can be edited, moved, rotated, scaled and sculpted, and a branch connects its shapes from one to the next. Branches can be duplicated to test different compositions, then a mesh is generated for sculpting or retopology. Character artists exploring proportions early will find it quick.

Key features

  • Build volumes from cubes, spheres and branches
  • Edit and sculpt branch objects
  • Duplicate branches to test designs
  • Generates a mesh for sculpting or retopology
