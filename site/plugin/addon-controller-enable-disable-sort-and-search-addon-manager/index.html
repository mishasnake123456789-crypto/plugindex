What Addon Controller - Enable/Disable, Sort & Search Addon Manager does

Addon Controller moves add-on management out of the preferences window and into the 3D View sidebar. The list shows each add-on's name, author, version and category, enables or disables with one click, and visually separates official from community add-ons.

Real-time search combines with filters for category, state, type and favorites. Batch operations, snapshots of enabled sets and performance monitoring are included. Artists with many add-ons installed can keep startup lean and switch collections for different projects.

Key features

  • Sidebar add-on list with one-click toggles
  • Search with category, state and favorite filters
  • Batch operations and snapshots
  • Performance monitoring
