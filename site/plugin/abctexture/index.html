Blender add-on that stores texture assignments as attributes for reapplication in Maya.

What Abctexture does

Abctexture solves the loss of texture links when models travel from Blender to Maya. One button writes every texture on the selected objects into attributes, and a companion Maya script reads them back.

Base color, roughness, metallic, normal, opacity, emissive and bump textures are covered. Because the data rides in extra attributes, it works through Alembic and other formats. The button is in the sidebar of the 3D view, and documentation is included.

Key features

  • One-button texture assignment to attributes
  • Maya script reapplies textures
  • Covers common PBR texture types
  • Works with Alembic and other formats
