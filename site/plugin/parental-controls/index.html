After Effects tool that attaches layers to the actual path, shape or text of a parent rather than the whole layer.

What Parental Controls does

Parental Controls from AE Screens lets After Effects artists parent a layer to something inside another layer: its path, shape or text, instead of the layer as a whole. The child follows that exact element as it animates.

Version 2.0 added batch processing, support for separate dimensions, a responsive interface and retina icons. A button removes the controls when no longer needed. It helps with callouts, labels and rigs where one element has to track the outline of another.

Key features

  • Attach to a path, shape or text of a parent
  • Batch processing
  • Separate dimensions support
  • Responsive UI with retina icons
  • Button to remove controls
