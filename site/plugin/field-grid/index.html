What Field Grid does

Field Grid is a Blender extension that fills a mesh with a 3D grid of spheres, cubes or points. Raycast detection tells which points lie inside the object and which lie outside, and each group can be styled differently.

Everything is built with Geometry Nodes, so it is procedural and non-destructive, and parameters stay editable in the modifier. Motion designers can use it for tech visuals, data-style displays and abstract shapes.

Key features

  • Lattice of spheres, cubes or points
  • Raycast inside versus outside detection
  • Procedural Geometry Nodes setup
  • Editable parameters in the modifier
