A Blender add-on that rebuilds the Color Ramp node with input sockets so its colors can be driven by other nodes.

What Super Color Ramp does

Super Color Ramp addresses a limitation of Blender's standard Color Ramp: its stop colors cannot be connected to other nodes. This add-on recreates the node with input sockets for every color stop and color value, allowing dynamic control through the node graph.

It behaves like the standard node, with a slightly different look and feel, and is available in the Shader Editor and the Geometry Node Editor. It works with Cycles, Eevee and the Blender Game Engine, and documentation includes a step-by-step guide. Shader and procedural artists who want data-driven gradients will find it opens new options.

Key features

  • Input sockets for all color stops and values
  • Same functionality as the standard Color Ramp
  • Available in Shader and Geometry Node Editors
  • Works with Cycles, Eevee and the Game Engine
