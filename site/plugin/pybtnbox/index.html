Blender add-on that runs your Python scripts from buttons arranged in custom menus and panels.

What PyBtnBox does

PyBtnBox, by Ou_Chiang, turns scripts into buttons in Blender. You arrange buttons into menus and panels, and clicking one runs the matching Python script. Scripts launched this way do not register a class.

Layout components such as Label, Panel and Return help organize button sets. Icons, searchable areas, layout, display text and tooltips are stored in a _menuData.json file, and an editor in the Text Editor sidebar lets you add, remove and update menus and buttons.

Key features

  • Click buttons to run Python scripts
  • Menus and panels for organizing buttons
  • Label, Panel and Return layout components
  • Settings stored in _menuData.json
  • Editor in the Text Editor sidebar
