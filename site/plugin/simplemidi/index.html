Blender MIDI add-on that links knobs, faders and keys to any property, with Set and Motor modes plus math expressions.

What SimpleMIDI does

SimpleMIDI connects a MIDI controller to Blender and lets you map controls to almost any property, such as object transforms, modifier settings and colors. Set mode ties a knob to a value between a minimum and maximum, while Motor mode treats input as a velocity that accumulates as the knob turns.

Math expressions can reshape the signal with x, time and frame available as variables, with basic operators, trigonometry and functions like min, max, abs, round, sqrt and pow. A Move to Nodes step maps Geometry Nodes inputs via the Group Input node, and target maps import and export as JSON.

Key features

  • Map MIDI controls to any property
  • Set and Motor modes
  • Math expressions with x, time and frame
  • Geometry Nodes input mapping
  • JSON import and export of maps
