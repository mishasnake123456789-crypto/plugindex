What Super Duper Batch Exporter does

Super Duper Batch Exporter splits Blender scenes into multiple exported files with a single click. It builds on the standard Blender export presets, so formats such as FBX, glTF, USD and OBJ are covered.

Export modes write a file per object, per parent object, per collection or for the whole scene, and collections can become sub-directories. Output directory and naming are configurable. Game artists and asset creators handling many separate props can avoid exporting each one manually.

Key features

  • One-click export to multiple files
  • Uses standard Blender export presets
  • Per object, parent, collection or scene modes
  • Collections as sub-directories
  • Configurable output settings
