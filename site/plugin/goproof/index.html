A proofing extension that sends proofs from Premiere Pro and brings requested changes back into the document panel.

What GoProof does

GoProof is a Creative Cloud extension for reviewing and proofing across Adobe apps, here listed for Premiere Pro. Proofs go out and changes come back into the document panel, so there is no need to export PDFs.

Writers edit the same document in a browser and lock passages while working, and designers can click to flow submitted copy in. Every change is tracked down to a single space, previous comments can be compared, and clients, projects, reviews, proofs and versions are managed together.

Key features

  • Send proofs and receive changes in the panel
  • Browser collaboration with text locking
  • Click to flow copy into a document
  • Full change tracking and history
  • Manages clients, projects and versions
