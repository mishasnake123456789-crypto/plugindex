What omUlete does

omUlete, by Jackson-Sutherland, writes Blender geometry into the .egg format of the Panda3D game engine. It appears as an egg (panda3d) export option and needs neither Panda3D nor any other dependency installed.

Collision shapes export through custom properties like collisionbox, collisionsphere or collisiontube, and buttons in the object properties panel add these quickly. An imageDir variable sets the texture directory. It is useful for Panda3D developers who model in Blender.

Key features

  • Exports to Panda3D .egg files
  • No Panda3D or other dependencies needed
  • Collision shapes via custom properties
  • Buttons to add collision properties
  • imageDir variable sets the texture folder
