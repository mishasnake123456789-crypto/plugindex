What Blender To Rizomuv Live Link does

Blender To RizomUV Live Link joins the two programs for UV editing. Send the selected model across, edit in RizomUV, and bring the UVs back.

On Blender 5.0 it uses an IPC connection through the RizomUVLink API and loads the model in the same RizomUV window, with no new instances or file dialogs. Only UV data returns, so geometry, materials and modifiers stay as they are. A file watcher updates UVs on every Ctrl+S in RizomUV, and multiple UV sets transfer.

Key features

  • One-click Send and Update UVs
  • Live IPC link on Blender 5.0
  • Only UV data returns
  • Auto update on each RizomUV save
  • Multiple UV sets
