What Essential Namer 2 does

Essential Namer 2 speeds up Essential Graphics template creation. It lets you add frequently used layer properties to the panel without opening the active comp, and names them as you go.

You can control whether the layer name is included, add a text layer's source text in one click, apply a custom prefix, and name the template after your comp. Separate position dimensions and all 3D transform properties are supported. A compact UI and KBar icons are included.

Key features

  • Adds properties without navigating to the comp
  • Source text added with one click
  • Custom prefix for property names
  • Auto-names the template after your comp
  • KBar support with icons
