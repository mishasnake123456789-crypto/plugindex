Adjusts object origins in real time with X, Y and Z sliders from a Blender sidebar panel.

What Origin Box does

Origin Box places a panel in the sidebar of the 3D Viewport for moving an object's origin interactively. X, Y and Z sliders update as you drag.

Ctrl+O opens a popup with all origin tools. Operations include applying the origin, centering it and dropping the object to the floor, and world or local modes handle global or local transforms. Convenient when preparing assets for export or animation. Interactive sliders make it easy to place pivots exactly where needed, which helps with rotations, scaling and game asset preparation.

Key features

  • Real-time origin sliders on X, Y and Z
  • Ctrl+O popup menu
  • Apply, center and drop to floor
  • World and local modes
