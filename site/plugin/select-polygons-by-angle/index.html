Blender add-on that selects polygons by the angle between face normals using flood fill, live preview and selection sets.

What Select Polygons By Angle does

Select Polygons By Angle, from 3D CADence, grows a selection outward from the active face while neighboring faces stay within an angle you choose. The flood-fill algorithm stops where the surface bends too sharply.

An interactive preview shows the result before it is applied, and a selection set system lets you store and recall groups. It is helpful for isolating flat regions, panels and sharp-edged parts of CAD-style and hard-surface models.

Key features

  • Flood-fill selection from the active polygon
  • Angle threshold between face normals
  • Interactive angle preview
  • Selection set management
