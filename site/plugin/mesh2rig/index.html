What Mesh2Rig does

Mesh2Rig, by 3DemFX, moves animation that lives on a mesh, such as simulations and shape keys, over to a rig, so it can be exported to game engines. It is tagged under Rigging, Animation, Bake, Game Engine and Pipeline.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.

Key features

  • Transfers simulation to rig animation
  • Handles shape keys
