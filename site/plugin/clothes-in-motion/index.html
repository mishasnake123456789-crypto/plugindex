What Clothes In Motion does

Clothes in Motion focuses on cloth design and simulation in Blender, combining an add-on with tutorials and assets. It supports adding detail after a simulation has been baked.

You can place decals and objects like zips, buttons, thread and pockets on cloth, slow or speed up baked simulations, and edit baked simulations in Sculpt and Edit Mode. Ready-made accessories and a rigged character are included. Character and fashion artists get a complete starting set.

Key features

  • Decals and accessories on cloth sims
  • Retime baked simulations
  • Edit baked cache in Sculpt and Edit Mode
  • Includes rigged character
