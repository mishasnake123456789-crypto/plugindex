What Edit Operator Source does

Edit Operator Source helps developers find out how a Blender operator is defined. Choose an operator and open its source file or locate where it is called.

It appears in the Edit Operator panel in the Text Editor sidebar, is version 1.2.4, and supports Blender 4.2 LTS and newer under the GNU General Public License. Add-on writers can reverse-engineer built-in tools faster. Jumping straight to source code speeds up learning from Blender's own scripts and helps when debugging how an operator behaves.

Key features

  • Opens an operator's source file
  • Reveals call locations
  • Text Editor sidebar panel
  • Supports Blender 4.2 LTS and newer
