What Stereo 3D Toolkit 3 does

Stereo 3D Toolkit 3, by Ryan Cashman, helps artists build stereoscopic compositions in After Effects. It keeps a true left and right channel hierarchy so both eyes stay in step as you work.

It works with 3D effects and plug-ins, accepts camera footage and renders from outside 3D packages, and can host several stereo workflows in one project. Any precomp can be converted into a stereo precomp. It is aimed at compositors delivering S3D content.

Key features

  • True left and right channel hierarchy
  • Compatible with 3D effects and plug-ins
  • Works with footage and external 3D renders
  • Multiple stereo workflows per project
  • Converts any precomp to stereo
