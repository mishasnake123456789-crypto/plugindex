What Industrial Light AOV Splitter does

Industrial Light AOV Splitter is a Blender add-on by Roland-Vyens that separates light groups into four channels with one click: diffuse, specular, transmission and volume. This gives compositors the kind of controllability found in professional pipelines.

Naming follows patterns like diffuse_env and specular_env. A Nuke Python script on GitHub automatically shuffles and combines the light group AOVs, but only handles EXRs produced by Industrial AOV Connector, which the author recommends using alongside. No special permissions are required.

Key features

  • One-click split into four light channels
  • Naming like diffuse_env and specular_env
  • Nuke script for auto shuffle and combine
  • Recommended with Industrial AOV Connector
  • Requires no special permissions
