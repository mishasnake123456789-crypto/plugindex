What Face Shape Key Rig does

Face Shape Key Rig helps build expressive faces for 3D characters using sprite face parts. It combines the sprites with shape keys and controllers so expressions can be adjusted from a simple interface.

This is a good fit for stylized characters, such as anime-inspired looks, where facial features are flat images placed on the model. Animators get easy control over eyes, mouths and other parts without building a complex facial rig.

Key features

  • Sprite-based face parts
  • Shape key controllers
  • For stylized 3D characters
