NURBS2MESH

Developer: Brrainz

Blender add-on that keeps a live mesh copy of any NURBS, curve or surface so mesh-only tools can be used non-destructively.

What NURBS2MESH does

In Blender, NURBS2Mesh maintains a polygon twin for each NURBS, curve or surface object and refreshes it whenever the original changes. Because the copy follows its source, you can apply Boolean modifiers, physics or polygon-based export formats without giving up the parametric original.

Updates are debounced with an adjustable delay, 0.25 seconds by default, so heavy recomputation is limited while editing. The source's evaluated modifier stack can be folded in, and UV maps, vertex groups and further data layers survive wherever possible. Each mesh has its own auto-update and refresh controls, one source can feed several linked meshes, and an Object menu entry duplicates a linked mesh, optionally parenting copies.

Key features

  • Auto-updating mesh mirrors of curves, NURBS and surfaces
  • Debounced updates with configurable delay
  • Optional inclusion of the source modifier stack
  • Keeps UVs, vertex groups and other data layers
  • Multiple linked meshes per source with manual refresh
