What Relativity does

Relativity is a layout plugin from Freshmograph for After Effects. It places layers in rows, columns, grids and circles, or scatters them randomly, based on how they relate to other layers and the composition.

It includes mirror commands, independent offsets for random position, scale and rotation, auto row and column layout, and an option to use a layer as a custom pivot. Grids and radial arrays can create controllers for extra animation options. Utilities select work area keyframes for easing changes and turn curved spatial keys into linear paths. Sliders respond to Ctrl/Alt for plus or minus one and Shift to reset.

Key features

  • Rows, columns, grids and circular arrays
  • Mirror commands and random offsets
  • Auto Row and Auto Column layouts
  • Controllers for grids and radial arrays
  • Work area key and linear spatial key utilities
