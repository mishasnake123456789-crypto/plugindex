Blender add-on that draws the full keyboard on screen with color-coded shortcuts, search and right-click rebinding.

What Keymap Visualizer does

Keymap Visualizer shows every shortcut on its physical key in an on-screen keyboard. Keys are color-coded by function, hovering shows details, left-click locks a key and right-click lets you rebind it.

A reverse lookup helps find who owns a combination: press ? followed by the combo to highlight the matching key. Searching is built in. Users learning Blender or resolving conflicts in a custom keymap can see the whole layout at once.

Key features

  • On-screen keyboard with all shortcuts
  • Color coding by function
  • Search and reverse shortcut lookup
  • Right-click rebinding
