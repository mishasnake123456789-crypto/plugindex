What Lorenz System does

Lorenz System generates After Effects paths from mathematical strange attractors, producing swirling, chaotic curves that work well for abstract graphics and generative art. Version 2.0 added a user interface.

Both static and expression-based path versions are offered. Attractor types include Lorenz, Rossler, Aizawa, Thomas, Halvorsen, Chen-Lee, Arneodo, Sprott B and F, Dadras, Rucklidge, Newton-Leipnik and Genesio-Tesi. It works with After Effects CC 2017 through 2026. The expression version keeps the shape adjustable, while the static version gives a lightweight path to use as-is.

Key features

  • Strange attractors converted to paths
  • Static and expression path versions
  • 13 attractor types
  • User interface in version 2.0
  • CC 2017 through 2026
