Blender add-on for building lofted meshes from curves and NURBS with twist, shrinkwrap and low or high poly output.

What Curve Loft does

Curve Loft by Vovrzull creates and edits complex, flexible shapes from curves in Blender. It lofts meshes quickly, with high-poly and low-poly output a couple of clicks apart.

A path function lofts along a curve and can be shared with the Link Curve add-on, while Twist and Shrinkwrap tools project curves onto surfaces and help with retopology. A zero-index option controls how evenly the mesh follows complex transitions, and an extension panel converts mesh lines or loops into curves with a bevel. Lofts group into a Loft Collection, with tutorials in English and Japanese.

Key features

  • Loft from curves and NURBS
  • High-poly and low-poly output
  • Path, Twist and Shrinkwrap functions
  • Zero-index control for transitions
  • Loft Collection with tutorials
