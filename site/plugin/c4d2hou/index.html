Two-way bridge between Cinema 4D and SideFX Houdini for geometry, splines, cameras and volumes.

What C4D2HOU does

C4D2HOU links Cinema 4D with SideFX Houdini so data can travel in both directions. Geometry, splines, cameras and volumes move across, and the bridge handles several Houdini connections at once.

Operations run asynchronously, so the interface stays responsive during transfers. Alembic, FBX and VDB formats are supported, centimetres and metres are converted automatically, and a structured folder system provides version control, incremental file names and overwrite options. Artists who model or animate in Cinema 4D but simulate in Houdini can pass assets back and forth with less friction.

Key features

  • Bidirectional Cinema 4D and Houdini pipeline
  • Multiple simultaneous Houdini connections
  • Geometry, splines, cameras and volumes
  • Alembic, FBX and VDB support
  • Versioned folder structure and unit conversion
