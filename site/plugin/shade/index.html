What Shade does

Shade for Premiere Pro keeps review feedback within the editor. Editors manage the comments and version lifecycles of assets stored in their Shade account without leaving the timeline.

Comments are timestamped and marked up, so they stay tied to specific points in the footage. Versions of an asset can be linked together, and a preview panel is provided for reviewing material. It needs Premiere Pro 25.0 or later. Editors can respond to notes in context rather than switching to a browser.

Key features

  • Manage Shade comments and versions in Premiere
  • Timestamped, marked-up comments
  • Link versions of assets
  • Preview panel
  • Premiere Pro 25.0 and later
