Blender add-on that pastes a clipboard image into the active brush texture with Ctrl+V in Texture Paint and Sculpt modes.

What Anypaste does

Anypaste adds a Ctrl+V shortcut to Blender that places an image from your clipboard straight into the current brush texture, skipping the file browser.

It works in Texture Paint and Sculpt modes, in both 3D and 2D, and accepts images copied from a web browser, Photoshop, other graphics programs or within Blender. Transparent images are supported. It is available for Windows x64 and works with Cycles and Eevee. Handy for quickly testing stamps and alphas.

Key features

  • Ctrl+V pastes into the brush texture
  • Texture Paint and Sculpt modes
  • Accepts images from browsers and graphics apps
  • Supports transparency
  • Windows x64
