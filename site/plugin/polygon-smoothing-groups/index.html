What Polygon Smoothing Groups does

Polygon Smoothing Groups is a Blender plugin for controlling shading, sharp edges and UV seams. Smoothing groups are created with live previews, and separate tools handle sharp and seam boundaries.

With Auto Sharp and Auto Seam, borders between groups turn sharp or get seams while interior edges stay smooth. Group By Angle forms groups according to the angle separating neighbouring polygons. Familiar to artists coming from other 3D packages. This workflow will feel familiar to artists used to smoothing groups elsewhere, and it makes control of hard and soft edges more visible.

Key features

  • Auto Sharp and Auto Seam modes
  • Group By Angle
  • Interactive previews
  • Tools for sharp and seam boundaries
