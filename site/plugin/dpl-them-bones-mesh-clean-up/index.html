What Dpl - Them Bones + Mesh Clean Up does

DPL - Them Bones renames armature bones following Blender's naming conventions, useful when characters arrive from other tools. It handles armatures from Character Creator, AccuRig and Mixamo.

A Rig List covers several armature types, with presets planned for later, and bone names can be imported from the list or a file name. On the mesh side, a single click strips out vertex groups and armatures. Riggers and animators preparing imported characters will save time.

Key features

  • Bone renaming to Blender conventions
  • Supports Character Creator, AccuRig and Mixamo
  • Rig List with bone name import
  • One-click removal of vertex groups
  • One-click armature removal
