What Console Controller Pro For Blender 5.X does

Console Controller Pro is a Windows-only add-on for Blender 5.x that manages the system console window. It keeps the console above other windows so printed output and errors stay visible while you work.

You can set its X and Y position and its width and height, and settings are saved automatically. Global hotkeys for Restore, Hide and Toggle are provided, set by default to Win+F7, F8 and F9. Script and add-on developers who watch console output benefit most.

Key features

  • Always-on-top system console
  • Set position and size
  • Auto-saves settings
  • Global hotkeys: Restore, Hide, Toggle
  • Windows only
