Blender UV Editor add-on from Oxicid with context-sensitive operators that respond to modifier keys and selection mode.

What UniV does

UniV adds a collection of UV operators to Blender's UV Editor. Many respond to the Sync state, the selection mode (vertex, edge, face or island) and combinations of Ctrl, Shift and Alt.

Modifier keys keep steady meanings: Ctrl selects To Cursor or Deselect, Alt gives an alternate action, and Shift gives Individual, Inplace or Extend. A panel in the lower left corner changes operator properties without the keys, and optional hotkeys can be enabled. UV artists who like fast keyboard-centered editing get consistent behavior.

Key features

  • Operators react to Sync and selection mode
  • Consistent Ctrl, Alt, Shift logic
  • Panel for adjusting operator properties
  • Optional hotkeys
