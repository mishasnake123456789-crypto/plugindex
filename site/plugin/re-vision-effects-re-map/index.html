What RE:Vision Effects RE:Map does

RE:Map gives compositors a set of mapping and distortion tools. Its main trick is texture mapping in post: using a UV pass from a 3D render, you can fix or swap textures in the compositing program with no new render.

It also works in reverse, producing the texture map a 3D renderer requires out of a photograph and a matching model. Other features include corner pinning with inverse mapping, 2D displacement mapping with deeper filtering controls, and a caricature effect that distorts colour images by their features. Supersampling and mismapping handle antialiased UV edges. It is GPU accelerated.

Key features

  • Retexture from UV maps in post
  • Inverse UV mapping from a photo and 3D object
  • Corner pinning with inverse mapping
  • 2D displacement with advanced filtering
  • Caricature effect and GPU acceleration
