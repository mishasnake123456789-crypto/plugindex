What Show Object/Data Users in Viewport does

Show Object/Data Users in Viewport, by 1P2D, displays how many users an object and its data have, right in the Blender viewport, which helps spot linked duplicates. It is listed under User Interface.

Open source under GPL-3.0-or-later, it requires Blender 4.2.0 or newer.
