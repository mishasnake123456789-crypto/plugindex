What Any Shake does

Any Shake, by Anymates, was made by editors for editors who want camera shake without exporting to another app. It shakes footage in Premiere Pro, and edge mirroring fills empty borders that appear when the frame moves.

Motion blur is optional, and since version 1.5.0 both can run at once. It supports Premiere Pro 2023 through 2026, useful for impacts, hits and handheld looks. It is made for quick, adjustable shakes on impacts and transitions without leaving the timeline.

Key features

  • Shake effect for Premiere Pro
  • Edge mirroring option
  • Motion blur option
  • Both options together from 1.5.0
  • Supports Premiere Pro 2023 to 2026
