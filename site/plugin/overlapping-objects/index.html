3ds Max script that finds overlapping faces, polygons and shape segments across meshes, polys and splines.

What Overlapping Objects does

Overlapping Objects checks scenes in 3ds Max for geometry that lies on top of other geometry. Both mesh faces or polygons and spline segments are checked, on Editable Mesh and Poly objects, their Edit modifiers, and shapes, and 3ds Max 2018 or later is required.

An All checkbox runs a full comparison between segments of all scene or selected shapes, and a companion script checks self-overlap of selected objects only. The installer MacroScript runs on selected objects normally and opens the UI version with Alt. Right-clicking the Self Segment Select button selects only overlapping splines. It is helpful for cleaning CAD imports and preparing plans.

Key features

  • Detects overlapping faces, polygons and shape segments
  • Covers editable meshes and polys, their edit modifiers and shapes
  • Full compare mode for all or selected shapes
  • Companion self-overlap check
  • MacroScript with Alt for UI version
