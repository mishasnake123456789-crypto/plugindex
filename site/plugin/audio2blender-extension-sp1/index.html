What Audio2Blender Extension + Sp1 does

Audio2Blender samples sound in real time and hands the values to Geometry Nodes inside Blender. That makes it possible to build visuals, games or installations that react to music or other audio.

A microphone or another connected audio device can serve as the source. Volume mode returns one float, while FFT mode, in linear or logarithmic form, returns a series of values across frequency bands. Motion designers and creative coders can wire these numbers into animation and simulation setups.

Key features

  • Real-time sampling from microphone or sound device
  • Volume mode outputs a single float
  • Linear and logarithmic FFT modes
  • Drives Geometry Nodes animation and simulation
