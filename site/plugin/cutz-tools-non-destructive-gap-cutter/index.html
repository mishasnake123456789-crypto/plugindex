What Cutz Tools - Non-Destructive Gap Cutter does

Cutz Tools combines seam cutting and beveling into a single step for hard-surface work in Blender. Everything is done in Edit Mode, so the original mesh stays editable and no modifier stack builds up.

Bevel styles include Sharp, Patch and Arc. Seam depth, bevel thickness and profile offset are tweaked interactively in the viewport, with a live parameter HUD. Gap width can be set per segment, arc corners can be switched to sharp right angles, and cut regions can be split into separate objects when modifiers are applied.

Key features

  • One-click seam cutting and clearing
  • Sharp, Patch and Arc bevel styles
  • Interactive depth, thickness and offset
  • Live parameter HUD
  • Per-segment gap width
