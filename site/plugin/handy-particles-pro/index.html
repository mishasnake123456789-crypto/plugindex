What Handy Particles Pro does

Built by PENCIL Park, Handy Particles Pro is an extension running inside After Effects aimed at making particle animation with shape layers. It uses primitives like ellipses and stars, or your own shapes, and can send the result to Rive for use in interactive designs.

Size and movement are adjustable, and burst presets create explosions and implosions. Color can be customized, and a BURST option supports Rive and Lottie usage. You choose the folder where JSON particles are saved, and a helper with respawn for loops arrived in version 1.0.3. Motion designers targeting interactive or web delivery get the most out of it.

Key features

  • Particles from primitive or custom shapes
  • Size and movement controls
  • Burst, explosion and implosion effects
  • Export to Rive with a BURST option
  • Respawn helper for loops
