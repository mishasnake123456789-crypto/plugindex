What Atlasflow - Ultimate Color Atlasing does

Atlasflow is a Blender add-on that cuts down draw calls by letting one material carry per-face PBR values. It targets game assets, stylized models and fast, optimized production.

Values are stored in two 128x128 textures under 16kb, using up to four UV channels per material. Faces or groups of faces are edited in Edit Mode through UV manipulation instead of shader nodes, covering properties such as base color, metallic, roughness and emission with Color and Gray atlas types. Add Atlasflow Material copies existing PBR defaults while leaving originals intact, and glTF 2.0 export is supported.

Key features

  • Per-face PBR values in a single material
  • Two 128x128 textures under 16kb
  • Color and Gray atlas types
  • glTF export without custom shader nodes
