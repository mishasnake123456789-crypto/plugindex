Blender exporter that sorts scene objects into assets and LODs, then writes them out one at a time or in bulk.

What Eksporteur - Batch Exporter does

Games rarely ship a single mesh, and keeping every asset with its LOD variants in one Blender scene gets messy when exporting. Eksporteur organizes the scene objects into assets with their LODs so you can see what has gone out already.

You can send one LOD or the whole batch. Linked collections are understood, curves can be exported as curves rather than converted, and an empty mode shifts each asset to the world origin for the duration of the export. A modal panel opens with F7, and the destination folder is optional.

Key features

  • Groups objects into assets and LODs
  • Export single LODs or the whole set
  • Supports linked collections
  • Empty mode places assets at world origin
  • Exports curves without mesh conversion
