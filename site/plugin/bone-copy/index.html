What Bone copy does

Bone copy is a script by Chuggnut for 3ds Max that swaps skinning weights between bones inside a Skin modifier. You choose a source bone and a target bone, and the weight assignment from the first is transferred to the second.

This is helpful when a rig is rebuilt, a bone is replaced or weights were painted on the wrong joint, since redoing the painting by hand would take much longer. It runs as a script, the current release is version 2.3.5, and it is free. Riggers and character artists working with Skin will find it a quick fix.

Key features

  • Swaps skinning weights from one bone to another
  • Moves weighting from a chosen source bone onto a target bone
  • Works within the Skin modifier
  • Version 2.3.5
