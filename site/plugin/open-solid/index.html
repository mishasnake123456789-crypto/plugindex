Blender add-on that forces every .blend file to open in Solid viewport mode to avoid slow material loading.

What Open Solid does

Files saved in Material Preview mode can take a long time to become usable. Nikita Akimov's Open Solid makes each .blend open in Solid mode regardless of how it was saved.

It operates quietly in the background and flips the viewport whenever a new file loads, so you never sit through texture and material loading. Blender 2.93 and 3.0 through 3.2 are supported, and installation is from a .zip via Add-ons preferences. Anyone with heavy scenes benefits.

Key features

  • Forces Solid mode on file open
  • Avoids texture and material loading delays
  • Runs in the background
  • Blender 2.93 and 3.0 to 3.2
  • Installs from a .zip archive
