Blender add-on that attaches technical fields to objects and collections and exports a specification table as HTML or CSV.

What Specification Sheet does

Nikita Akimov's Specification Sheet assembles a table of specs from a Blender project. Define the fields you need, give them to meshes and collections, and enter technical data for selected objects.

One button exports the table as HTML or CSV, and total quantities are calculated for object and collection instances. Everything is reached in the 3D Viewport N-panel. Product designers, architects and fabricators who must supply bills of materials can generate them without leaving Blender.

Key features

  • Custom specification fields
  • Assign to objects and collections
  • Fill selected objects with data
  • Export to HTML or CSV
  • Item counts for instances
