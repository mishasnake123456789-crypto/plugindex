What SmoothSpline does

SmoothSpline by Jon Seagull creates a smoothed copy of a spline object in 3ds Max. For each vertex, it averages the position with those of its neighbors, which softens kinks and jitter in hand-drawn or imported curves.

You run the script and then pick the spline to process. The original stays untouched while the new copy carries the smoother shape. It runs on 3ds Max 5, 6 and 7 and carries version number 0.1. Modelers working with paths, motion trails or outlines that look rough can use it for a quick cleanup.

Key features

  • Makes a smoothed copy of the picked spline
  • Averages vertex positions with neighbors
  • Run the script, then pick a spline
  • Works with 3ds Max 5, 6 and 7
  • Version 0.1
