Blender add-on that adds an interactive minimap overlay for navigating large node graphs in the Node Editor.

What Nodemap does

Nodemap gives Blender's Node Editor a bird's-eye minimap, so you do not get lost in sprawling trees. It works across Shader, Geometry Nodes and Compositing editors.

You can pan and zoom the main view from the minimap and click nodes on it to select them. The overlay can be resized and follows the active theme. Anyone building complex materials or procedural systems can find nodes much more quickly.

Key features

  • Interactive minimap overlay
  • Pan and zoom from bird's-eye view
  • Click nodes to select them
  • Resizable and theme-aware
  • Shader, Geometry Nodes and Compositing support
