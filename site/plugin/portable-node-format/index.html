What Portable Node Format does

Portable Node Format makes Geometry Node groups easy to share. Right-click and choose Export Node Groups to save any group as a .node file, then drag the file into another Blender window to import it.

The format preserves node properties, connections and interface definitions in one file, structured as a ZIP archive. Geometry Nodes creators can pass setups to colleagues or reuse them between projects without appending from .blend files.

Key features

  • Export node groups via right-click
  • Import by dragging a .node file into Blender
  • Keeps properties, connections and interface
  • ZIP-based package structure
