What Gemgen - Parametric Gem Mesh Generator does

Gemgen generates gems in Blender from a selected cut, producing render-ready geometry without manual modeling.

Parameters update the mesh in real time, and viewport gizmos let you change size and proportions visually. Set Good Proportions resets to jeweler-standard ratios, and an n-gon option gives cleaner topology. Everything is animatable. The Full edition offers ten cut types with sample scene, while the Lite edition has Round only. Jewelry designers and product artists can iterate on proportions quickly before sending a model to render.

Key features

  • Real-time parametric updates
  • Interactive viewport gizmos
  • One-click good proportions
  • Animatable parameters
  • Ten cuts in Full, Round in Lite
