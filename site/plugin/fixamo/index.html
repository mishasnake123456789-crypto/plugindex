What Fixamo does

Fixamo is a plugin from BOSSposes that smooths over Mixamo animation problems in Blender. One Fix button, located in the viewport's Tool panel, readies armatures for merging and retargeting.

It renames armatures so the next import won't clash, merges Mixamo animations without the NLA editor, retargets them onto any armature or rig, and loops animations by running the fix again. Good for game animators reusing Mixamo clips. This makes it far easier to assemble longer sequences from separate Mixamo downloads and reuse them across characters in games and animation projects.

Key features

  • One-click Fix button
  • Renames armatures to prevent conflicts
  • Combines animations without NLA
  • Retargets to any rig and loops clips
