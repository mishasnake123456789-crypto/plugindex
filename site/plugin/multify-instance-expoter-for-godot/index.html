What Multify - Instance Expoter For Godot does

Multify moves duplicators and instances from Blender into Godot so scattered trees, grass and similar objects keep the same transforms.

It supports Blender's built-in Scatter Objects add-on and multiple duplicators, with Particle or Face export types per object and custom export names that match Godot instance names. The included GDScript duplicates instances, converts them to a MultiMeshInstance and sets scale per child. The package has a Blender add-on, a GDScript and a test scene.

Key features

  • Exports duplicators and instances to Godot
  • Particle or Face export types
  • Custom export names
  • GDScript builds MultiMeshInstances
