What Data Glitch 2 does

Data Glitch 2 from Rowbyte produces believable digital image corruption in After Effects and Premiere Pro. Rather than faking it with overlays, it manipulates the picture in four ways: Scan, Block, Offset and Rect glitches, each controllable alone or per channel.

Colour handling covers YUV and RGB, and compression controls with an optional image map create artifacts on the fly. Each channel has its own random seed, alpha support allows glitching of type and logos, and animations can react to audio through expressions. Image Type and Strip Type glitches include quality settings. It works well for transitions as well as direct glitching.

Key features

  • Scan, Block, Offset and Rect glitch types
  • YUV and RGB colour spaces
  • Compression control with optional image map
  • Per-channel random seed and alpha support
  • Audio-reactive animation via expressions
