What Object nudger does

Object nudger is a 3ds Max script by Chuggnut that shifts objects by precise increments. Moves and rotations can be made in whichever unit size you need, so tiny adjustments are repeatable and exact.

It operates in both local and world coordinates, which means you can nudge an object along its own axes or along the scene's axes. This is handy for fine positioning where dragging with the mouse or typing values is clumsy, such as aligning parts, tweaking a camera, or adjusting a prop against a surface.

Key features

  • Precise move in any unit size
  • Precise rotate in any unit size
  • Local coordinate operation
  • World coordinate operation
