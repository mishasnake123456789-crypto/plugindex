Toggles Blender materials between UV projection and blended box mapping for live-boolean concepting.

What Projection Switcher does

Projection Switcher swaps a material's mapping between UV projection and blended box mapping. That lets PBR materials stay applied to objects with live boolean modifiers, where UVs would break.

Once concepting is done you can switch back to UV mode. Texture scaling is adjusted interactively in the viewport through a physical scale system. It is useful for hard-surface exploration and kitbashing. Highlights include UV and blended box mapping toggle, works with live boolean modifiers and interactive texture scaling.

Key features

  • UV and blended box mapping toggle
  • Works with live boolean modifiers
  • Interactive texture scaling
  • Physical scale system
