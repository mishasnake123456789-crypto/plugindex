What Expert Curve Modeling does

Expert Curve Modeling by Vovrzull is a curve-driven way to build flexible models in Blender. Four modes of work (vertex, curve, segment, model) let you edit at different levels, and mesh objects can be converted to ECM objects.

Point Deformation manipulates the ECM grid by hand, and curve tools cover filling, extruding, bridging, merging, replacing and duplicating. Boolean operations, n-gon segments, and triangle and segment extrusion are added, along with a Parallel Model System that smooths curves and segments. Beginners can use it but should expect to work through the video tutorials.

Key features

  • Bezier curve based modeling
  • Vertex, Curve, Segment and Model modes
  • Mesh to ECM conversion
  • Fill, extrude, bridge, merge and Boolean tools
  • Parallel Model System with smoothing
