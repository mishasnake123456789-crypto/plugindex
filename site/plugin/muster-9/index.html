What Muster 9 does

Muster 9 is a render farm management system used in film production, game development and visual effects, with integration for 3ds Max. It monitors farm resources automatically, recovers from faults, and assigns rendering tasks to hosts on the fly.

Hosts can be added or disconnected, and renders can start when nobody is logged in or a screen saver kicks in. It runs natively on Windows, Linux and Mac OS X, with a substitution path engine for mixed environments. A template system with a macro language integrates render engines, and single frames for Maya and 3ds Max can be sliced across hosts and reassembled. It is free for up to four concurrent nodes.

Key features

  • Automated farm monitoring and fault recovery
  • Native Windows, Linux and Mac OS X support
  • Path substitution for mixed environments
  • Template system with macro language
  • Frame slicing across hosts, free for four nodes
