What PAWS: Bakery does

PAWS: Bakery is a Blender add-on by Steve-Paws for baking textures for game-ready assets. It sets up materials for baking automatically and can bake atlas textures and per-object textures in batches.

Many high-poly meshes can be baked onto a single low-poly mesh, and materials can be created in batches. Maps produced include material ID, AORM, ambient occlusion, normal, metalness, roughness, color and more, with anti-aliasing through supersampling. Workflow helpers round out the tool for game and real-time artists.

Key features

  • Automatic material setup for baking
  • Batches atlas and per-object bakes
  • Many high-poly meshes onto one low-poly
  • Color, roughness, metalness, normal, AO, AORM, ID maps
  • Supersampling anti-aliasing
