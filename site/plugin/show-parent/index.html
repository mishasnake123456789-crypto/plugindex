Blender add-on that draws object and bone parent relationships as colored arrows in the 3D Viewport.

What Show Parent does

Show Parent visualizes hierarchies in Blender. Yellow arrows mark object parents and blue arrows mark bone parents, so relationships are visible without checking the Outliner.

Bone and object modes are separate, and a filter limits the display to the current selection. Optional camera-facing markers appear as billboard circles at the start of each arrow, with adjustable size and color. Controls are under View3D > Sidebar > Tool. Handy for rigging and scene debugging.

Key features

  • Yellow arrows for object parents
  • Blue arrows for bone parents
  • Separate bone and object modes
  • Only-selected filter
  • Adjustable billboard start markers
