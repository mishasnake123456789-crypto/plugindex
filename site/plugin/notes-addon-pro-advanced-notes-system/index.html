What Notes Addon Pro - Advanced Notes System does

Notes Addon Pro gives Blender a built-in notepad so reminders stay with the project. You can create as many notes as you need and pin the important ones to the top.

A live search filters the list, notes can be color-coded and moved up or down, and a quick draft field speeds up capture. Contents can be copied to the clipboard or exported to a .txt file. It suits freelancers and teams who track to-dos and settings directly in the scene.

Key features

  • Unlimited notes with pinning
  • Real-time search and filtering
  • Color coding and reordering
  • Quick draft input
  • Clipboard copy and .txt export
