What Object renamer does

Object renamer is a long-standing 3ds Max script from Chuggnut for renaming objects in a scene. It is distributed as version 2.3.5 and listed as free to use, available from the developer's site.

Consistent naming matters in game pipelines, exports and large scenes, where default names such as Box001 make assets hard to find. A dedicated renaming script gives a straightforward way to tidy names without clicking through each object individually. It is suitable for anyone who wants a simple, no-frills renamer inside 3ds Max.
