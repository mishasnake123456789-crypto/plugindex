What N-Panel Search - Find Your Addon Tabs Fast does

N-Panel Search addresses a common Blender annoyance: a sidebar crowded with tabs from many add-ons. Click the search icon in the 3D viewport header, type part of a name, and the matching tab opens right where you are working.

The search is fuzzy, so inexact names still match, and recently used tabs appear at the top of the list. It works across the 3D View, UV Editor, Compositor and Video Sequencer, supports an assigned hotkey, works alongside Simple Tabs and keeps a clean, unobtrusive interface. Power users with large add-on collections will save time hunting through the panel.

Key features

  • Fuzzy search for add-on tabs
  • Search icon in the 3D viewport header
  • Recently searched tabs listed first
  • Works in 3D View, UV Editor, Compositor and VSE
  • Assignable hotkey
