Blender add-on that turns fonts into dense meshes and bends them with lattices, letter by letter or all at once.

What Deformatext does

Deformatext converts text objects in Blender into proper meshes, then lets you distort them for logos, titles and stylized lettering. Because the result is real geometry with a density you choose, it holds up better under deformation than plain curve-based text.

Lattice modifiers are applied for you, with control over the number of lattice points, interpolation type and deformation strength. You can edit an entire text object together or adjust each letter separately, and letters can be split apart or merged back. This is handy for artists who want organic, warped typography without setting up the rig manually.

Key features

  • Font-to-mesh conversion with adjustable mesh density
  • Built-in lattice deformation
  • Control over lattice points, interpolation and intensity
  • Edit letters individually or globally
  • Split and merge letters
