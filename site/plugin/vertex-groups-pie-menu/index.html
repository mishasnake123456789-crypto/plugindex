What Vertex Groups Pie Menu does

Vertex Groups Pie Menu puts everyday vertex group tasks in a pie menu. The main operator adds, removes, selects and deselects groups, with automatic naming that can be turned off in preferences.

You can set vertex weight from the pie, view and rename the active group, separate an object by its vertex groups and remove empty groups. It speeds up skinning and mesh organization work for riggers. Among its capabilities are add, remove, select, deselect groups, set weight from the pie and separate objects by vertex group.

Key features

  • Add, remove, select, deselect groups
  • Set weight from the pie
  • Separate objects by vertex group
  • Remove empty groups
