Microscopy Nodes

Developer: Aafke-Gros

FreeBlender
Download Free

Blender add-on to visualize multi-dimensional microscopy datasets up to 5D, importing TIFF and OME-Zarr files.

What Microscopy Nodes does

Microscopy Nodes brings microscopy datasets into Blender as accurate, animatable visualizations. It supports up to 5D volumes from fluorescence, electron microscopy and other imaging.

Loading handles .tif and .zarr files with any axis order, covering XYZ plus time and channels, and a channel interface defines how each channel loads, for example as a volume. Scientists and science communicators can create figures and videos of their data. The import produces results that can be animated, lit and rendered in Blender, so researchers can create clear figures, videos and presentations from raw scientific imaging data.

Key features

  • 5D data from TIFF and Zarr files
  • Any axis order such as tzcyx
  • Per-channel loading options
  • Animatable results
