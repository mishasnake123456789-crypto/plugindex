What 🔖 Fuzzy Master: Realistic Felt Effects does

Fuzzy Master, from Lazy3D, adds procedural felt to objects in Blender. It covers both stop-motion style looks and fuzzy fabrics for garments, accessories and soft furnishings, and it assigns procedural materials automatically.

Sliders adjust color, density and fluffiness quickly, so you do not need to understand complicated node networks. A stop-motion option animates the felt with stepped interpolation for that handmade, jittery feel. The same tool works for whimsical animation and photoreal clothing.

Key features

  • Procedural felt textures with auto assignment
  • Color, density and fluffiness sliders
  • Stop-motion option with stepped interpolation
  • Suits stylized and photorealistic work
  • No complicated node setup
