Blender add-on for marking favorite objects and selecting them from a viewport pie menu without the Outliner.

What Favorite Objects does

Favorite Objects gives quick access to key scene objects in Blender, which is handy in fullscreen or maximized viewports where the Outliner is hidden. Right-click an object in Object Mode to add or remove it from your favorites.

The default Ctrl+Alt+LMB shortcut opens a pie menu listing the first seven favorites, with a More submenu once there are over eight. Ctrl+Alt+RMB adds selected objects and a double-click removes them. A Frame Selected Favorite option and icons round it out.

Key features

  • Right-click to add or remove favorites
  • Pie menu with More submenu
  • Configurable shortcut, default Ctrl+Alt+LMB
  • Frame Selected Favorite option
  • Works without the Outliner
