What Easyvfx Lip Sync Plugin does

The EasyVFX Lip Sync Plugin automates a time-consuming part of character animation in Blender. It generates lip sync and facial animation from speech so the mouth movement does not have to be keyed by hand.

It is described as an all-in-one facial animation toolkit that needs no extra add-ons, works in any language, and supports the ARKit blendshape standard for rigging. Setup is token-based through easyvfx.ai, and a demo project with a ready-made model is included to try it out. It runs on Windows 10 and 11 and Ubuntu 20.04 and 22.04 LTS.

Key features

  • Automated lip sync and facial animation
  • Multilingual support for any spoken language
  • ARKit blendshape standard supported
  • Included demo project with a ready model
  • Runs on Windows 10/11 and Ubuntu 20.04/22.04
