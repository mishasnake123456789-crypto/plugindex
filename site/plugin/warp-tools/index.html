What Warp Tools does

Warp Tools gathers several handy utilities for Blender modelers into one add-on. It deals with material management, UV selection, reference handling, cleanup and quick shortcuts.

A material reassign tool replaces one material with another across the scene, optionally deleting the original. A Material List purges unused materials, force-deletes any material and selects objects using a given one. Multi edit UV select picks a chosen index across all selected meshes, and a reference collection tool binds a set of collections together. A shortcuts popup rounds it out.

Key features

  • Material reassign across the scene
  • Material list with purge and force delete
  • Multi-mesh UV index selection
  • Reference collection tool
  • Quick shortcuts popup
