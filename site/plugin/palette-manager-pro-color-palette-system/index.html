What Palette Manager Pro - Color Palette System does

Palette Manager Pro adds a palette system to the Material tab of the Properties panel. Colors have names rather than raw hex codes, which makes picking the right one faster.

Apply to Object sets the material's base color right away with no shader editor needed; an eyedropper picks a color from an object into a palette slot, and palettes save themselves and travel between projects. Artists keeping a consistent color scheme across scenes, logos or stylized assets will find it handy.

Key features

  • Named colors in palettes
  • Apply to Object in one click
  • Eyedropper samples from objects
  • Automatic saving between projects
