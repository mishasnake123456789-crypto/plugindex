What ProtoTech's OBJ Exporter For 3ds Max® - Trial does

ProtoTech's OBJ Exporter trial writes solid bodies from 3ds Max directly into OBJ files for use in other applications. The trial grants 15 exports across seven days with the full feature set available.

Materials can be exported at face or body level, including colors and textures. Precision control balances file size against quality, and tessellation can be done per body or per face. An automation license allows an export function to be called without user intervention. It supports 3ds Max 2023, 2024, 2025 and 2026, and fits pipelines moving CAD-derived bodies into other tools.

Key features

  • Exports solid bodies to OBJ
  • Face and body-level materials with textures
  • Precision and tessellation controls
  • Automation license for unattended exports
  • Trial: 15 exports over 7 days
