What Smart Selection Propagation does

Smart Selection Propagation by atrxi finds repeating geometry in a mesh without requiring exact matches. It selects features similar or dissimilar to your current selection, using edge connectivity, length and angle, and face area, perimeter and normal direction.

The selection can be grown or shrunk by similar topology, reduced to its boundary, or extended to mirrored features and similar island meshes. A rigor factor controls how strict the match is and can be tuned by pressing F9.

Key features

  • Select similar or dissimilar features
  • Grow or shrink by similar topology
  • Boundary-only selection
  • Mirrored features and similar islands
  • Tunable match strictness
