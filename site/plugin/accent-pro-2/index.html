What Accent Pro 2 does

Accent Pro 2 from Minimalist Soft brings layers to mesh editing. They are available in Edit Mode and save with your project file.

The interface is minimalist and the add-on stays transparent to Blender's normal operation, promoting a low-to-high polycount workflow. Documentation is included. Modelers who want layered edits can iterate more cleanly. It is meant to feel unobtrusive, so it fits into normal editing habits without extra windows. Layers allow rough forms to be built up and refined gradually, which helps when working from simple shapes to detail.

Key features

  • Mesh editing layers in Edit Mode
  • Layers saved with the project
  • Minimalist interface
  • Low to high polycount workflow
