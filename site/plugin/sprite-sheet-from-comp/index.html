What Sprite Sheet From Comp does

XiongMiao's Sprite Sheet From Comp is a script built for After Effects that turns a composition into a sprite sheet. Game developers and web animators often need frames laid out in one image, and this saves manual assembly.

It can also generate frame-by-frame animation from the composition. The script works with After Effects from CC 2015 through 2026. Version 1.0.1 fixes connection issues in license activation and updates the framework to 4.4.2, and a demo video is available.

Key features

  • Renders a comp as a sprite sheet
  • Generates frame-by-frame animation
