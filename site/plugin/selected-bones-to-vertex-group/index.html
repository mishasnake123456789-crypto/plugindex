What Selected_Bones_To_Vertex_Group does

Selected_Bones_To_Vertex_Group is a Blender add-on by mochi_Lin that creates vertex groups from the bones you have selected, or removes them again. A single operation handles one armature together with several meshes, all from a right-click menu in Object mode.

If a mesh has no armature modifier yet, the add-on adds one so the selected armature can deform it. This takes the repetitive clicking out of preparing meshes for rigging or weight painting. No special permissions are required.

Key features

  • Creates vertex groups from selected bones across meshes
  • Removes selected bones from vertex groups
  • Adds a missing armature modifier
  • One armature and several meshes per operation
  • Available from the right-click menu in Object mode
