What Origin To Selected does

Origin To Selected, by sum studio, repositions origins precisely in Blender. In Edit Mode select a vertex, edge or face and press Shift+Q, and the object's origin jumps to that spot.

It works on mesh, curve, surface, armature and lattice objects. The shortcut can be reassigned in preferences, Auto Clear Location puts the object at the world origin using its new origin as the anchor, and Auto Go to Object Mode switches back after the operation. Install from a zip in the Add-ons tab.

Key features

  • Origin to selected vertex, edge or face
  • Mesh, curve, surface, armature and lattice objects
  • Shift+Q shortcut, reassignable
  • Auto Clear Location option
  • Auto switch to Object Mode
