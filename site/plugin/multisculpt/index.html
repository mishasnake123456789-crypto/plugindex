Blender add-on to sculpt, paint and weight several objects simultaneously while preserving modifiers and data.

What Multisculpt does

Multisculpt makes it possible to sculpting, vertex painting, texture painting and weight painting over several objects at the same time in Blender.

Each object keeps its modifiers (Multires included), transforms, materials, UVs, vertex colors, shape keys and further custom attributes. Character artists working on separate parts such as clothing and body can treat them together. Working on several objects at once keeps proportions consistent between parts, which can be hard when each piece must be sculpted or painted separately.

Key features

  • Sculpt and paint across multiple objects
  • Preserves modifiers including Multires
  • Keeps UVs, shape keys and attributes
  • Weight painting support
