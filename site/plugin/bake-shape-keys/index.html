Blender add-on to duplicate, merge and split shape keys and bake shape key actions while controlling interpolation and frame rate.

What Bake Shape Keys does

Bake Shape Keys serves artists who work heavily with shape keys and their animations in Blender. It can duplicate, merge and split keys while retaining data and animation.

Bake Shape Key Action writes keyframes for every shape key on each frame, with settings for interpolation, step size and frame rate. Facial animators and technical artists preparing assets for export or simplification gain precise handling. Baking animation into per-frame values is a common step before exporting facial animation to game engines or other applications that handle keys simply.

Key features

  • Duplicate, merge and split shape keys
  • Retains animation down to handle positions
  • Bake action on each frame
  • Settings for interpolation, step and frame rate
