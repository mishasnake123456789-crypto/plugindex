What SUGARfx Rolling Credits does

SUGARfx Rolling Credits provides text generators for scrolling credits in After Effects, DaVinci Resolve and Premiere Pro. Drag a generator onto the timeline, import your text, and adjust speed, style and colour with on-screen controls.

The Inspector offers full customisation of colour palette, font and size. Styles run from conventional and modern to creative and off-the-wall, one title holds one set of credits, and several styles and sections can be layered. Sample text files can be downloaded to try it at once. Editors finishing films and other projects can generate credit rolls quickly.

Key features

  • Drag-and-drop credits generator
  • On-screen controls for text, speed, style and colour
  • Inspector control of palette, font and size
  • Conventional to off-the-wall styles
  • Downloadable sample text files
