Extracts perspective-corrected patches from images in Blender's Image Editor and arranges them on a canvas.

What Image Remap Canvas does

Image Remap Canvas is an Image Editor extension for Blender that straightens parts of photographs. Draw a four-point quadrilateral over a region, and it is flattened into a perspective-corrected patch, handy for textures taken from walls, signs or floors.

Results preview in real time using GPU textures. Several patches can be arranged on a canvas placed beside or below the source image, which stays visible, and the final canvas is saved as an image datablock for use in materials.

Key features

  • Four-point selection with perspective correction
  • Real-time GPU texture preview
  • Canvas placed beside or below the source
  • Saves result as an image datablock
