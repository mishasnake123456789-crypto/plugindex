What Content Cloud Plugin does

Content Cloud Plugin brings cloud storage into the Adobe workspace. It connects to Box, Dropbox, Google Drive, Google Photos and Microsoft OneDrive, so assets stored there can be pulled into a project, or finished work pushed back, without opening a browser.

Files can be dragged and dropped, and previews cover formats including PSD, audio and video. Several accounts can be added and switched between quickly. The panel also offers ChatGPT-based writing, with or without your own OpenAI key, and image search via Lexica.art. It contains no analytics or tracking code and is GDPR compliant.

Key features

  • Connects Box, Dropbox, Google Drive, Photos and OneDrive
  • Drag-and-drop download and upload
  • Previews PSD, audio and video
  • ChatGPT writing and Lexica.art image search
  • Multi-account; no tracking code
