What Sp2Blend: Substance Painter Shader does

Sp2Blend is a single node group that sets up textures exported from Substance Painter's metallic/roughness workflow in Blender.

Load the base color, metallic, roughness, MixedAO and OpenGL normal maps, connect them and tweak using built-in options, with no texture alterations needed. Texture artists save time rebuilding shaders after export. Using one node group instead of hand-wired networks reduces setup time, and it keeps the look of textures from Substance Painter close to what was painted.

Key features

  • All-in-one Substance Painter node group
  • Works with default metallic/roughness export
  • Base color, metallic, roughness, MixedAO, normal
  • Built-in tweak options
