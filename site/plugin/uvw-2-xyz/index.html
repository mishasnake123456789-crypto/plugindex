3ds Max script that converts a mesh's UV layout into a flat mesh while copying 3D vertex normals so it lights realistically.

What UVW 2 XYZ does

UVW 2 XYZ turns the UV layout of an object into a real mesh in 3ds Max. The flattened geometry mirrors the unwrap, which is useful when you need to see or work with UV shells as ordinary polygons.

The 3D vertex normals are copied onto the flat mesh as well, so in renders it is shaded as if it still had the original 3D form. This is the key trick for texture baking or preview work based on unwrapped shapes. The mesh is always created, but the normals are not always transferred, which the author flags as a possible bug.

Key features

  • Converts UVs into a mesh
  • Transfers 3D vertex normals onto the flat mesh
  • Flat mesh lights like the 3D object in renders
  • Always creates the mesh, normals copying may occasionally fail
