What Copy Text Settings (Plus Svg And Curves) Addon does

When several text or curve objects need to share the same look, matching their settings by hand is slow. This Blender add-on copies those properties from one object to others in a few clicks.

It transfers values such as resolution, extrusion, bevel depth, fill mode and alignment, and works with text, curves and imported SVG shapes. A checklist decides which properties are transferred, and undo or redo choices are offered around the operation. Useful for title design and logo work.

Key features

  • Copies resolution, extrusion, bevel and alignment
  • Supports text, curve and SVG objects
  • Choose which settings to transfer
  • Undo and redo options
