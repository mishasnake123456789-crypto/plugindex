Blender add-on that produces a one-click diagnostic report on file contents, memory, unused data and textures.

What Blend Inspector does

Blend Inspector analyzes a .blend file and summarizes its condition in one click. The report is split into File Overview, Memory Breakdown, Unused Data, Texture Audit and Scene Health.

Polycounts take modifiers into account, showing base and evaluated vertices after Subdivision, Mirror and similar. Texture problems are ranked by severity with a suggested fix for each. You can purge unused data blocks, apply transforms or remove unused materials with quick actions. It is useful before handing off or archiving a file.

Key features

  • One-click file analysis in five sections
  • Modifier-aware polycount
  • Texture audit sorted by severity
  • Purge unused data blocks
  • Quick fix actions
