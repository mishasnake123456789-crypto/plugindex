What Renamer does

Renamer is a free extension from Bending Spoons for After Effects. It renames items in the project panel in bulk, using case-sensitive Find and Replace or a custom function that follows an editable naming convention, with an example script included.

Renaming applies to the selected items, or to every item when none are selected. A Render button chooses an output folder and sends comps to the Adobe Media Encoder queue, with output-path tokens such as [root] for the project path, [YYMMDD] for the date, and .. to go up a folder. It opens from the Window > Extensions menu.

Key features

  • Case-sensitive find and replace renaming
  • Custom function renaming with example script
  • Applies to selection or all items
  • Render button queues comps to Media Encoder
  • Path tokens for root, date and parent folder
