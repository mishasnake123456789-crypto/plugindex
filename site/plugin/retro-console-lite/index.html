Blender add-on that converts image textures to the look of a Game Boy Color game with 64x64 size, limited palette and dithering.

What Retro Console Lite does

Retro Console Lite gives modern textures the look of old handheld games. With one click it reduces an image texture to 64x64 pixels, limits it to four colors per channel and applies Floyd-Steinberg dither pass to keep gradients readable.

Batch conversion handles several textures together, which is convenient when restyling a whole model or scene. It suits artists making retro-styled renders or low-fi game assets who do not want to process every image in an external editor.

Key features

  • Game Boy Color style conversion
  • 64x64 resolution and 4 colors per channel
  • Floyd-Steinberg dither pass
  • Batch conversion of multiple textures
