What Face Cap X does

studioromanrec's Face Cap X brings live face tracking into Blender. It works with any webcam your computer supports, on Windows and macOS Apple Silicon.

It is designed for rigs built with the Auto-Rig Pro add-on. Documentation is included and the license is GPL. Animators and streamers who want to act out expressions in front of a webcam and record them on a character avoid dedicated capture hardware. No special camera is needed, so testing a performance takes only a laptop or desktop with a webcam.
