What NLA Batch Editor does

NLA Batch Editor makes the Nonlinear Animation workflow practical for scenes with many objects. Actions from multiple selected objects can be pushed down to NLA strips together, with tracks and strips renamed during the push.

Options include random start frames and control over mute states. Animators arranging crowds or repeated assets can offset and organize many strips in a single step rather than editing each separately.

Key features

  • Batch pushdown of actions to NLA strips
  • Track and strip renaming
  • Random start frame options
  • Mute state control
