Blender add-on for bulk selecting, muting, resetting, copying, deleting and renaming shape keys across multiple objects.

What Multi-Shape Keys does

Multi-Shape Keys handles shape keys on several selected objects together, rather than one key at a time. That is a big saver when characters carry long lists of facial or corrective shapes.

Selection controls include select all, deselect all and invert. Selected keys can be muted or unmuted, reset to zero, copied or deleted in a single step, and renamed in a batch. Filtering narrows the list first, so you act only on what you intend. It suits character artists who maintain many shapes across multiple meshes.

Key features

  • Select all, deselect all and invert
  • Mute and unmute selected keys
  • Reset values to 0
  • Copy and delete any number of keys
  • Batch rename
