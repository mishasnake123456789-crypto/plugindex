What French Keyboard Shortcuts - Hotkeyboard Azerty does

French Keyboard Shortcuts - HotKeyboard displays an interactive keyboard on screen for AZERTY users. It covers 500+ shortcuts across modes and shades them by importance.

Keys highlight in yellow when pressed with a 250 ms decay. The layout is available for Mac and Windows with platform detection, and the interface is bilingual. Useful for learners and teachers. It doubles as a visual learning tool, since you can press keys and see what they do in each mode.

Key features

  • AZERTY layout for Mac and Windows
  • Pressed keys highlight with 250 ms decay
  • 500+ shortcuts color-coded by importance
  • English and French interface
