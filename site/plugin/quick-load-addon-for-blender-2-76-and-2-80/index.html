What Quick Load (Addon For Blender 2.76+ And 2.80+) does

Quick Load, by Vladimir Spivak, speeds up trying different images on a model by using Blender's File Browser with image previews. It works in Blender 2.76+ and 2.80+ and suits anyone auditioning many textures.

Press a panel button or the Q key to pick a file. In Blender 2.80+ an Image Texture node is created automatically from the selected file. Alt+Q puts the image onto selected faces and Shift+Q onto a node. It can also load objects and scene elements, and change a brush texture or the world texture.

Key features

  • Loads images via the File Browser with previews
  • Q shortcut, Alt+Q for faces, Shift+Q for nodes
  • Auto-creates Image Texture nodes in 2.80+
  • Also changes brush and world textures
