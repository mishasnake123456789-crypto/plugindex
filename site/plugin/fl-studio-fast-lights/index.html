What Fl Studio "Fast Lights" does

FL Studio Fast Lights offers built-in lighting presets covering cinematic, natural, studio and stylized looks for Cycles and Eevee.

Lights are adjusted in real time from the sidebar without an Apply step, color swatches can be customized, and setups can be saved as JSON files for reuse. A quick way to light scenes consistently. The feature set spans cinematic, natural, studio and stylized presets, real-time sidebar controls and customizable color swatches.
