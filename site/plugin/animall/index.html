Blender add-on that inserts keyframes on mesh, curve, surface and lattice data normally not animatable.

What AnimAll does

AnimAll lets you keyframe geometry-level properties in Blender that are not usually animated directly. Vertices, edges, faces and control points of meshes, curves, surfaces and lattices can be keyed and then edited in standard animation editors.

The panel lives in the sidebar's Animation tab, offering data-type choices and keyframe insertion buttons. A Key Selected Only option limits keying to selected vertices. Animators can create morphing or deforming effects without shape keys.

Key features

  • Keyframes mesh, curve, surface and lattice data
  • Panel in Animation sidebar tab
  • Key Selected Only option
  • Edit keys in standard animation editors
