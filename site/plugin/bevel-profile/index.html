What Bevel Profile does

This 3ds Max script gives you more command of the Bevel Profile modifier. A Sweep modifier can be converted to Bevel Profile, a chosen shape applied as the profile, and that profile moved, rotated, scaled or swapped for another section.

It hooks into Kstudio's Sweep Profile with a pair of dedicated buttons. Fast Min/Max alignment and quick 90-degree turns speed up adjustment, and the S button applies an Edit Poly modifier that separates the object into elements per section ID. Profiles sit in a hidden layer, each applied modifier remembers its shape, and selected objects are detected automatically.

Key features

  • Converts Sweep modifiers to Bevel Profile
  • Move, rotate, scale or replace the profile section
  • Integration with Kstudio's Sweep Profile
  • Fast alignment and 90 degree rotation
  • Split results into elements by section IDs
