What XFormer does

XFormer from PolyTools3D restores the transformation of an object when it has been lost. Typical cases include a model whose matrix was reset with Reset XForm, an object created by detaching part of another object, and an imported model that does not align as expected.

Once its original orientation and pivot are recovered, the object can be rotated, scaled or edited sensibly again. The tool works with 3ds Max 2016 through 2027. Modelers who inherit messy files or fix pivots after detaching will find it avoids rebuilding from scratch.

Key features

  • Recovers an object's transformation
  • Fixes results of Reset XForm
  • Handles detached object parts
  • Corrects misaligned imported models
  • 3ds Max 2016 through 2027
