Extends a path into a new animated shape layer in After Effects by selecting two path points.

What Exte does

Terrible Junk Show built Exte to lengthen paths in After Effects. Choose two points on a path and it produces an extended line, taken from a shape with an animation, as a new shape layer.

An extended path can be converted into a bendable one, and multiple path points can be manipulated together using a single null. Documentation exists in English and Japanese, and a trial version is limited to creating one extended path. Artists building flowing lines and tentacle-like movements from existing paths gain a quicker way to work than manual construction.

Key features

  • Create an extended path from two selected points
  • Output as a new shape layer
  • Convert to a bendable extended path
  • Control multiple points with one null
  • English and Japanese documentation
