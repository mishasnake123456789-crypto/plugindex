What Goblend: Export to Godot does

Goblend: Export to Godot streamlines moving a finished Blender scene into the Godot engine. One button runs the whole export, so there is no need to manually prepare each asset.

Materials are baked automatically into textures that Godot can use directly, nested scenes are exported by instantiating child scenes, and collisions can be defined as primitives. Shader conversion is handled as well. Developers who build levels in Blender and iterate often will save repetitive export steps.

Key features

  • Single-button export to Godot
  • Automatic material baking to textures
  • Nested scenes exported as instanced child scenes
  • Collision definitions as primitives
  • Shader conversion
