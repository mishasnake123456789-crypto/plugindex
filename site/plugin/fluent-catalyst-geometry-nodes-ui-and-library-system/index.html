What Fluent Catalyst - Geometry Nodes Ui And Library System does

Fluent Catalyst is a Blender add-on from CG Thoughts for controlling geometry nodes assets straight from the viewport and for building reusable asset libraries. It includes 13 parametric hard surface assets.

A menu and a simple horizontal mouse movement adjust parameters, which are grouped into sub-menus by theme, with sensitivity adjusting itself for scale values. A Reuse function copies settings from any asset already added, and a one-click reset restores defaults. The built-in library has pieces such as a potentiometer, fan and vent, ideal for sci-fi and machinery details.

Key features

  • Adjust parameters with a menu and mouse move
  • Thematic sub-menus with automatic sensitivity
  • Reuse settings from added assets
  • One-click reset
  • 13 parametric hard surface assets
