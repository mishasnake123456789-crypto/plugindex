Blender add-on that ties keyframes to dope sheet markers so the markers follow when keys are moved.

What Key To Marker does

DIA EID's Key To Marker binds keyframes to markers in Blender's dope sheet. Move a keyframe and its marker comes along, so there is no separate marker adjustment.

This keeps timing notes and cue points aligned as animation is retimed. Documentation is included, versions 2.9 through 4.1 are supported, and a Creative Commons license applies. Animators who label poses or beats with markers avoid fiddly work. Because the link is automatic, shots with many markers no longer fall out of sync after every timing adjustment.

Key features

  • Bind keyframes to markers
  • Markers follow keyframe movement
  • No separate marker adjustment
  • Blender 2.9 to 4.1
  • Documentation included
