3ds Max script that gathers selected objects and their bitmaps into one folder, relinks the paths and saves the result.

What Save Selected With Maps does

This script gathers the bitmaps of selected objects, relinks them into a folder you choose, and saves the objects there too. Bitmaps the asset tracker marks as found are included, so a clean, self-contained slice of a scene is easy to share.

It handles V-Ray and Corona bitmaps, IES files on standard, photometric, V-Ray and Corona lights, displacement modifiers, proxies, Hair and Fur maps, VRayFur maps and OSL files. Options reset material editors to cut file size, clear render output and elements, archive as zip, rar or 7zip, and save to an earlier Max version. It detects installed renderers, not just the active one.

Key features

  • Collects and relinks bitmaps of selected objects to a folder
  • Covers V-Ray and Corona bitmaps, IES files, proxies and displacement
  • Optional material editor reset and render output clearing
  • Archive as zip, rar or 7zip
  • Save to a previous 3ds Max version
