What Super3D Import & Export .Igs does

Super3D Import & Export .Igs is a Blender add-on for working with IGES CAD files. It adds File menu entries for import and export, with conversion carried out by the Super3D cloud service.

On import, the file is uploaded to the service, then the converted result is downloaded and merged into the active scene. On export, the scene is written out as OBJ, converted to .igs through Super3D and saved to disk. This lets product and engineering visualization artists exchange CAD interchange data with Blender without separate converters.

Key features

  • File menu entries for .igs import and export
  • Import merges converted result into the scene
  • Export goes through OBJ then .igs
  • Cloud-based conversion
