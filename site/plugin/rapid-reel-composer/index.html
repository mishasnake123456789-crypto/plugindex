What Rapid Reel Composer does

Rapid Reel Composer helps turn long recordings into social-ready shorts. While playing a selected layer, press the asterisk key wherever you want a split, and the script divides the layer into separate clips based on those markers.

An In-Out button defines clip start and end points, and a Lazy button cuts automatically to a chosen clip length. Reels, short videos or tutorials can be produced in a few clicks. It works with After Effects CC 2019 through 2025.

Key features

  • Asterisk key places split markers
  • Divides a layer into multiple clips
  • In-Out button for clip ranges
  • Lazy button for automatic cuts
  • Supports CC 2019 to 2025
