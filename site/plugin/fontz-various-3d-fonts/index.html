What Fontz - Various 3D Fonts does

Building decorative 3D letters from scratch is slow. ThreeDee's Fontz provides finished alphabets for Blender in eleven styles that include Cyber, Balloon, Candy, Neon, Rock and Fluffy.

Each style comes both as source .blend files and as PNGs with transparent backgrounds, covering upper and lower case letters, digits and special characters. Every glyph is exported individually, so images work in Figma or Photoshop too. Title designers and social content creators get playful type immediately.

Key features

  • Eleven 3D font styles
  • Source .blend files and transparent PNGs
  • Letters, numbers and special characters
  • Each letter exported separately
  • PNGs usable in other design tools
