What Draw Animation does

Draw Animation lets animators sketch f-curves by hand in Blender's graph editor, shaping keyframes the way one would draw on paper.

It works with f-curves, supports Blender 4.0 through 4.3, and is also offered as a feature inside the Clean Graph add-on. Documentation, a demo video and tutorials are available under a GPL license.

Key features

  • Draw keyframes in the graph editor
  • Works with f-curves
  • Blender 4.0 to 4.3
  • Demo video and tutorials
