Removes hidden interior faces and fully enclosed objects in Blender using visibility ray-casting.

What Insideout - Delete Inside Geometry does

InsideOut deletes geometry that can never be seen, such as interior faces and objects entirely enclosed by others. It fires visibility rays at the scene to decide what is hidden, and leaves the visible surface, UVs, normals and materials untouched.

Three buttons control how thorough it is. Coarse removes objects that are completely hidden, Fine clears interior faces, and Precise carefully validates tightly packed CAD geometry. Select mode previews what will be removed first. It is useful for lightening CAD imports and game assets.

Key features

  • Ray-cast visibility analysis
  • Coarse, Fine and Precise modes
  • Select mode previews removals
  • Keeps UVs, normals and materials
  • Handles tight CAD geometry
