What Faster FBX Exporter does

Faster FBX Exporter, by Dan-Gry, branches off Blender's built-in .fbx exporter with the aim of running considerably quicker. It focuses on static objects that use modifiers.

Export Selected is enabled by default, and a parameter named names_of_objects_to_export picks objects by name, whatever is selected or visible. Version 0.3.0 fixed a performance problem. Game artists who export many assets repeatedly can shorten waiting time. Skipping unneeded work in the standard exporter shortens waits when assets are re-exported many times during iteration.

Key features

  • Forked, faster FBX exporter
  • Focused on static objects with modifiers
  • Export Selected on by default
  • Export by object name
