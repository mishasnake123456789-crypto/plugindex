What KeyTweak does

From mamoworld tools comes KeyTweak, a plugin for After Effects aimed at fixing animation with numerous keyframes, especially tracked or rotoscoped masks. Instead of correcting each keyframe individually, you adjust one or two and the remaining ones follow.

A local mode handles two-dimensional properties such as corner pin points, and the chosen mode is saved in After Effects preferences and restored next time. If applied to a mask whose vertex count changes, it shows a clear error message. It works with After Effects from CS3 through 2026, which makes it useful for roto cleanups.

Key features

  • Adjust one or two keys and the rest update
  • Works on masks with many keyframes
  • Local mode for 2D properties
  • Mode remembered between sessions
  • Clear error for changing vertex count
