What One-Step Copy & Relink (Bitmap Path Manager) does

One-Step Copy and Relink searches a 3ds Max scene for bitmap-based maps, duplicates their source files into a chosen folder, and repoints the materials at a target folder with a new extension. It handles standard Bitmaps, VRayBitmap and VRayHDRI in one pass.

The copy and relink destinations are separate, and a custom output extension applies to all relinked paths. A Skip Existing Files toggle avoids overwriting earlier copies, and a cache ensures shared textures are copied once. Silent mode, disabled redraw and undo keep it fast. A report lists maps updated, unique files processed and skipped. It suits batch texture conversion ahead of an external converter.

Key features

  • Handles Bitmap, VRayBitmap and VRayHDRI maps
  • Separate copy and relink folders
  • Custom extension for relinked paths
  • Skip Existing Files option and duplicate path caching
  • Completion report with counts
