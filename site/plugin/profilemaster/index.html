What Profilemaster does

ProfileMaster generates architectural profiles like coving, moulding, trim and skirting. Pick an edge or face, press Create Profile and choose from over 170 designs.

Width and height can be adjusted in real time without remodeling, and complex curves and thicknesses are handled, with smart even thickness. A practical tool for interior visualization. Because profiles follow edges and faces, trims and mouldings can be applied around rooms quickly and revised easily.

Key features

  • 170+ profiles
  • Create from an edge or face
  • Real-time width and height changes
  • Handles complex curves
