Retopology toolkit for Blender that builds clean low and mid poly meshes over sculpts or scans inside Edit Mode.

What Retopoflow 4 does

Retopoflow 4 helps create tidy quad topology over detailed sculpts or scans. This version is a full rewrite that integrates the tools into Blender's own Edit Mode rather than running as a separate mode.

Contours places loops around cylindrical forms by dragging with Ctrl, with the vertex count changed by scrolling. PolyStrips sketches strips and bridges, treating quads like a Bezier curve, and Strokes lays down rows of edges and links nearly parallel strokes with interpolated quad grids. Character modelers and game artists can produce clean, animation-ready meshes.

Key features

  • Contours for loops around cylindrical forms
  • PolyStrips for sketching quad strips
  • Strokes for edge rows and quad grids
  • Integrated into Blender's Edit Mode
