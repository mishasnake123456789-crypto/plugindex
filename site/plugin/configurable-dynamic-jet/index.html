What Configurable Dynamic Jet does

Configurable Dynamic Jet is a Blender add-on by Mark Kingsnorth that builds a fighter jet or starfighter mesh and adds it through Blender's standard Add menu. A set of options shapes the overall design.

You can include or omit engines and tail wings, and change wing span, wing angle and cockpit size. The Mirror and Subdivision Surface modifiers are left active, so you can still edit the base mesh underneath. The base mesh is built from quads, which makes it easy to extend. It's a fast way to prototype spacecraft and aircraft.

Key features

  • Adds a jet mesh from the Add menu
  • Optional engines and tail wings
  • Wing span, wing angle and cockpit size controls
  • Mirror and Subdivision modifiers left editable
  • Quad-based base mesh
