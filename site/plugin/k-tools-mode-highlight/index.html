What K-Tools: Mode Highlight does

K-Tools: Mode Highlight makes it obvious which mode you are in. The 3D Viewport and Properties headers change color across Object, Edit, Sculpt, Pose, the paint modes and Grease Pencil Draw.

During playback, the NLA, Graph Editor, Dope Sheet and Timeline headers are tinted, and a pulsing red dot with a live frame counter appears at the top of the viewport. Contrast adapts for legibility, overlays follow your theme, each editor can be toggled separately, and color setups can be saved as JSON presets.

Key features

  • Header colors per mode
  • Playback highlighting in animation editors
  • Pulsing record dot and frame counter overlay
  • Adaptive contrast and theme syncing
  • JSON presets for color setups
