Blender add-on for scattering trees and plants with size, amount and randomness controls and a thumbnail library.

What Deezl Sequoia does

Deezl Sequoia helps Blender artists fill scenes with vegetation and similar assets. You browse a thumbnail library, pick an element, and see the scene populate in real time.

Sliders control the size of the elements, how many appear and how random the arrangement is, so patterns look organic instead of uniform. Color and subsurface settings tweak appearance, and a light path control is available. You can add your own trees, plants or other models to the Sequoia database with custom thumbnails. It suits natural landscape building.

Key features

  • Size, amount and randomness controls
  • Real-time scene population
  • Thumbnail browser for assets
  • Color and subsurface editing
  • Add your own assets to the database
