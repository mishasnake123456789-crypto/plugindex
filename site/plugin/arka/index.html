What Arka does

Arka is a small Blender plugin for people who need to plan cutting of flat parts, such as furniture designers building box-style cabinets. It keeps the focus on simple rectangular shapes.

The interface has only a few options, and bin-packing choices are built in so you can quickly test how pieces fit on a sheet. It supports Blender 3.6 and 4.0, comes with documentation, and uses the MIT license.

Key features

  • Cut lists for rectangular shapes
  • Built-in bin-packing options
  • Simple interface with few settings
  • Supports Blender 3.6 and 4.0
