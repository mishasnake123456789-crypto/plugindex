Writes 3ds Max render elements plus anti-aliased object and material masks into layered PSD files for post work.

What cebas psd-manager does

cebas psd-manager takes the render elements from a 3ds Max scene and writes them into a layered PSD, ready for adjustment in After Effects, Photoshop or any program that reads PSD. Every element can become a layer or a channel, and you decide per element whether and how it is exported.

Deep-Data Masks (MatteShooter) yield hundreds of anti-aliased masks from objects, materials, layers or named selection sets with little memory, and need V-Ray or Scanline. V-Ray users get direct framebuffer access, split MultiMattes and raw or denoised saves. Save Now stores results before a render finishes. Corona, FStorm, Redshift and mental ray are also supported, with presets and automatic layer sorting.

Key features

  • Render elements written as PSD layers or channels
  • Deep-Data anti-aliased masks (MatteShooter)
  • Direct V-Ray Framebuffer access and MultiMatte splitting
  • Save Now at any time during rendering
  • V-Ray, Corona, Scanline, FStorm, Redshift, mental ray
