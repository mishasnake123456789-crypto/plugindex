What Particle test code does

Particle test code is a script-driven particle system for 3ds Max from Chuggnut, shared as test code rather than a finished product. It generates particles of different types and accounts for gravity and wind resistance in how they move.

Since the particles are made entirely through script, it gives a look at how a basic system can be put together without the built-in particle flow tools. It is aimed at scripters who want to experiment with particle generation, and at developers who may wish to build on existing test code for their own effects.

Key features

  • Script-based particle system
  • Generates different particle types
  • Gravity affects particle behavior
  • Includes wind resistance
  • Shared as test code
