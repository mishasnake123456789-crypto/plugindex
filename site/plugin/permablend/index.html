What Permablend does

Permablend is a Blender plugin that creates transitions between materials where objects come close. Instead of painting masks or building elaborate node trees, the blend is generated automatically from distance.

It updates in real time, shows a viewport preview and renders in Cycles and Eevee. Moving an object changes the transition dynamically. It's useful for rocks half-buried in soil, props resting on ground and other places where surfaces should merge naturally.

Key features

  • Proximity-based material blending
  • Real-time updates as objects move
  • Cycles and Eevee rendering support
  • No manual painting needed
