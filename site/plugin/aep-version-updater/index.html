What AEP Version Updater does

AEP Version Updater is a script from GatoDoMato Scripts for After Effects that converts older .AEP projects to the version you are running. Choose individual files or an entire folder tree and let it work through them without dialog boxes interrupting.

Originals can be kept or overwritten, and a custom suffix can be added to updated files. Folder and Files tabs offer an Include subfolders option, and the script reports files it cannot handle, such as corrupted projects or versions that are too old. Studios with large archives will find it useful.

Key features

  • Batch updates files or whole folders
  • Keep or overwrite original projects
  • Custom suffix for updated files
  • Reports corrupted or too-old projects
  • Include subfolders option
