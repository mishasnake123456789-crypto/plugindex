What Blender Git does

Blender Git brings Git-based version control into the 3D Viewport sidebar. A dedicated Git tab lets you commit, branch, merge, view history, resolve merge conflicts and connect to remote repositories without leaving Blender.

Scene snapshots convert binary .blend changes into plain-English descriptions. Teams collaborating on scenes get a history of work and safe ways to experiment. The feature set spans git tab in the 3D Viewport sidebar and commit, branch, merge and history.

Key features

  • Git tab in the 3D Viewport sidebar
  • Commit, branch, merge and history
  • Merge conflict resolution
  • Plain-English scene snapshot descriptions
  • Remote repository connection
