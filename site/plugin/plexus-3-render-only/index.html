What Plexus 3 Render Only does

Plexus 3 Render Only is a licensing option from Rowbyte intended for machines that only render, without a full interface. It lets the command line renderer use Plexus 3 on those nodes.

To buy it you need to own at least one full Plexus 3 license. A command line licensing tool is included, and compatibility reaches from After Effects CS6 through 2025. It is meant for studios and render farms.

Key features

  • License for headless render machines
  • Works with the command line renderer
  • Requires one full Plexus 3 license
  • Includes command line licensing tool
  • Supports After Effects CS6 to 2025
