What Skelsketch does

Skelsketch pairs a VR application with a Blender add-on. You build and block out 3D models in virtual reality, then import them into Blender as rigged meshes.

The shape hierarchy is preserved and an animatable rig is generated automatically. The VR app is for Windows 64, with a Meta Quest standalone version planned, and the add-on handles tasks like rigging and simplification. Handy for quick character and creature concepts. The feature set spans VR application for Windows 64 and import as rigged meshes.

Key features

  • VR application for Windows 64
  • Import as rigged meshes
  • Shape hierarchy preserved
  • Automatic animatable rig
