What Flow - Animation Curve Editor does

Flow is a curve editor that gives Blender animators a more visual way to shape easing. A GPU-accelerated modal interface shows a 2D graph with draggable Bezier control points.

Auto Apply sends handle changes to the Graph Editor immediately, and quick presets such as Ease In-Out, Ease In and Linear speed up common choices. The approach mirrors easing tools in After Effects. Motion designers and character animators wanting precise control over speed will find it intuitive.

Key features

  • Visual Bezier curve editing
  • Auto Apply updates the Graph Editor
  • Quick presets: Ease In-Out, Ease In, Linear
  • GPU-accelerated modal interface
  • After Effects-style easing
