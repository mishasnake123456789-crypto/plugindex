Blender surface design add-on with .step import and export that stores shapes as Geometry Nodes.

What Surfacepsycho does

SurfacePsycho supports surface-based design in Blender, including import and export of .step files for CAD exchange.

Shapes are stored as Geometry Nodes, so blend files containing them stay openable, shareable and archivable even if the add-on is not installed. Documentation is provided and it is distributed as a Blender extension under the GPL license. Suited to hard surface, car, industrial, architectural and product design. Designers who exchange CAD data with other programs will find that useful for round trips.

Key features

  • .step import and export
  • Shapes stored as Geometry Nodes
  • Files open without the add-on
  • Documentation provided
  • Blender extension under GPL
