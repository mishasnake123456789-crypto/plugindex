What Mass Text Editor does

Mass Text Editor handles scenes that contain lots of Blender text objects. Instead of editing each one, you apply changes to a selection or to everything in the scene.

It can add a prefix or suffix to the text, and it copies properties such as font and text size from a reference object onto the others. The add-on works with Blender 2.93 through 3.x up to 4.2, and documentation plus a demo video are included. It is useful for titles, labels or signage repeated many times.

Key features

  • Add prefixes or suffixes in bulk
  • Apply to selected or all text objects
  • Match font and size to a reference object
  • Supports Blender 2.93 to 4.2
  • Documentation and demo video included
