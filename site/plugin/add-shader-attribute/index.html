FreeBlender

Blender add-on for adding vertex group, modifier and geometry attributes directly in the shader editor.

What Add Shader Attribute does

Add Shader Attribute spares you from switching views to look up attribute names while building materials in Blender. Instead, attributes are added right inside the shader node tree.

It supports vertex groups, geometry nodes modifier attributes normally defined in the properties panel, and final geometry attributes including stored named attributes, UVs and hidden ones, as well as instance attributes. Version 0.3.0 adds searching attributes from an instance. Use Shift+A, then Attribute, in the shader editor.

Key features

  • Add attributes inside the shader node tree
  • Vertex group attributes
  • Modifier and final geometry attributes
  • Instance attribute support
  • Shift+A, Attribute menu entry
