Builds named color palettes in Blender, saved globally or inside the .blend file.

What Color Palettes does

Color Palettes lets you create libraries of colors with meaningful names. Each palette holds up to ten colors, and you can run several palettes at once.

Colors are picked with Blender's native color wheel, palettes can be stored within a .blend file for project-specific use, and saved palettes are also globally available in any project. Designers needing consistent brand or scene colors get quick access. Naming colors helps teams communicate which shade belongs where, and palettes carry over between files.

Key features

  • Multiple palettes of up to 10 colors
  • Native color wheel picking
  • Custom color names
  • Project-specific or global saving
