What NURMS Toggle does

NURMS Toggle is a simple macro by Martin Breidt for 3ds Max. One action flips an Editable Poly between its smooth-shaded NURMS result and the base cage drawn with a wireframe overlay.

This lets modelers compare the smoothed result and the control cage without opening the object's subdivision rollout each time. The macro is version 0.1 and is shared free through ScriptSpot. It can be attached to a hotkey or toolbar button for fast switching while editing polygons.

Key features

  • Toggles NURMS subdivided view and base view with wireframe
  • Works with Editable Poly objects
  • Single macro action
  • Version 0.1, distributed through ScriptSpot
