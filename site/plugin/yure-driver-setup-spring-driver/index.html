What Yure Driver [Setup Spring Driver] does

YURE Driver, by Bookyakuno, creates a springy follow-through for bone chains. A driver moves child bones late based on the rotation value of their parent, so a single keyframe on the parent makes every child spring and wave.

There are options to adjust how the setup behaves. Animators working on hair, tails, ribbons and accessories save time compared with posing each bone, and the result stays editable.

Key features

  • Driver-based delayed child bone motion
  • Springs a whole chain from one parent keyframe
  • Adjustable setup options
