What Light Patterns does

Light Patterns, made by aeHamid, is a tool for After Effects aimed at animating moving lights. A library of controllable patterns provides the movement, and everything is summarized in a single layer to keep the project organized and uncluttered.

Start and end points of the light travel can be adjusted, and In and Out markers set the time range. Settings are simple, and the shadow map can be changed, as covered in the included tutorial. It fits stage lights, scanning beams and decorative light sweeps.

Key features

  • Library of light movement patterns
  • Everything contained in a single layer
  • Adjustable start and end points
  • In and Out markers set timing
  • Changeable shadow map
