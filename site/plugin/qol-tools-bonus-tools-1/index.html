What Qol Tools: Bonus Tools 1 does

QOL Tools: Bonus Tools 1 bundles several single-purpose Blender add-ons in the 4.2 extension format. Each one handles a minor annoyance in mesh cleanup or transform handling.

HoleFiller finds and repairs open holes from the right-click menu in Object Mode, and FlipFaces detects wrongly oriented faces. MatchTransform copies rotation, location and scale from a target, ResetTransform restores defaults, OriginToBase puts the origin at the lowest point, and MatchOrigin aligns origins to the active object. A context menu add-on groups these tools into a submenu.

Key features

  • HoleFiller and FlipFaces for mesh cleanup
  • MatchTransform and ResetTransform
  • OriginToBase and MatchOrigin
  • Tools grouped in a right-click submenu
