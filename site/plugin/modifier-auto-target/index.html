What Modifier Auto Target does

Modifier Auto Target removes a repetitive chore: choosing a target object after adding a modifier. Select the target first, then Shift-click the object that should receive the modifier.

Pick a modifier from a list and the add-on adds it with the correct target already assigned. A custom shortcut can be assigned to trigger it. Useful for modifiers that rely on another object, such as Boolean, Shrinkwrap or Curve, and for modelers who set these up dozens of times a session.

Key features

  • Adds a modifier with target assigned automatically
  • Selection-order workflow
  • Modifier chosen from a list
  • Assignable custom shortcut
