Standalone Blender add-on for linking or appending collections from blend files in a directory, a companion to PowerSave.

What Powerlink does

PowerLink streamlines bringing assets from other blend files into your scene. It lists the blend files in a directory and lets you insert collections into your file quickly. It is built as a standalone add-on to work alongside PowerSave.

Linking keeps a live connection to the original file, so updates carry through, while appending copies in all connected data such as materials. This helps teams and asset library users reuse content efficiently.

Key features

  • Lists blend files from a directory
  • Rapid collection insertion
  • Linking keeps connection to the source file
  • Appending brings in connected data like materials
