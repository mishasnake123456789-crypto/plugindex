What MusicFinder does

MusicFinder puts a library of more than 400,000 production tracks in a panel beside the timeline, so music can be found, auditioned, licensed and imported without switching windows.

Search can be by genre, mood and theme, by lyrics, or with an AI prompt describing the scene. Previews include shorts, loops, alternate versions and individual stems such as drums, bass and vocals, and Track Matcher suggests pieces with a similar sound, mood and energy. Full tracks and their versions can be imported with a click, helping editors who score projects quickly.

Key features

  • 400,000+ production tracks in a panel
  • Search by genre, mood, lyrics or scene description
  • Preview shorts, loops, versions and stems
  • Track Matcher finds similar-sounding music
  • One-click import of tracks and versions
