Blender add-on that builds colored cubes or flat squares from pixel art, one per pixel.

What Import Pixel Art does

Import Pixel Art turns images into 3D or flat geometry in Blender, creating one element per pixel. Fully transparent pixels are skipped.

Two modes exist: individual 1x1x1 cubes as separate objects or one flat mesh of planes. Pixels with the same color share a material, so editing it changes all matching pixels, and cubes are parented to an empty for easy moving. Handy for voxel-style art and sprites. Since colors share materials, a palette swap or color change takes a single edit, which suits voxel-style scenes built from small sprites.

Key features

  • Cube or flat plane import modes
  • Shared material per color
  • Cubes parented to an empty
  • Transparent pixels ignored
