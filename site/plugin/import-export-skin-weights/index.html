What Import Export Skin Weights does

Import Export Skin Weights is a Blender add-on by Nguyen-Phuc-Nguyen that transfers skin weights between meshes. It writes the vertex groups, UV positions and influences of every vertex into a JSON file, then reads them back onto any mesh that shares the same hierarchy skeleton.

Two mapping methods are offered: Position matches by closest vertex, and UV uses the vertex UV coordinates. Results are best when meshes share the same topology or UVs. It supports Blender 4.2 LTS and newer and requires no special permissions.

Key features

  • Exports vertex groups, UVs and influences to JSON
  • Reimports onto meshes with the same skeleton
  • Position mapping by closest vertex
  • UV mapping by vertex UV coordinates
  • Supports Blender 4.2 LTS and newer
