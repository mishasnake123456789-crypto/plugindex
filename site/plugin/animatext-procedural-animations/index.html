What Animatext Procedural Animations does

Animatext Procedural Animations gives Blender objects algorithmic movement without hand-keying. Choose an effect, apply it, and tweak the result using sliders.

The effect list includes wave, circular, spiral, tornado, vortex swirl, pendulum, elastic bounce, helix, jitter, parabolic jump, ease in/out and sound wave motion. Speed, intensity, frequency, gravity and randomness can be adjusted. It acts on mesh objects and on animated transforms, and keeps the object's starting position intact. The add-on is compatible as a Blender Extension for versions 4.0 to 4.4 and pairs well with the author's Text Remesher.

Key features

  • Thirteen procedural motion effects
  • Speed, intensity, frequency and gravity controls
  • Randomness slider
  • Keeps starting position
  • Blender 4.0 to 4.4 extension
