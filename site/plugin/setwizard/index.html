Creates and manages object selection sets in Blender with visibility, holdout, camera and outliner tools.

What Setwizard does

SetWizard organizes scenes around selection sets. You can create sets, reuse them and add or remove objects, then control the members together.

It switches per-object viewport selection, viewport visibility and render visibility, can set Holdout on an object even if its collection is not a holdout, and recolors objects in the viewport. A customizable interface also brings camera switching, frame range changes, outliner filtering and Python commands. Scene managers handling many objects get quick group control.

Key features

  • Reusable object selection sets
  • Selection, visibility and render toggles
  • Holdout without collection holdout
  • Camera switching and frame range tools
  • Outliner filtering and Python commands
