What Sketchfab for Autodesk® 3ds Max® does

Sketchfab for Autodesk 3ds Max uploads your model to the Sketchfab web service without the manual routine of exporting, compressing and uploading it. A few clicks complete the process.

Before publishing, you can fill in the title, description and other metadata and adjust texture and lighting settings. Objects can be unwrapped automatically, with materials and lights baked into new textures, and the finished model opens in a browser when done. 3D artists sharing portfolio pieces or client previews will find it saves time.

Key features

  • Publish to Sketchfab in a few clicks
  • Automatic export, zipping and upload
  • Optional auto-unwrap and baking of materials and lights
  • Title, description and metadata fields
  • Opens the published model in a browser
