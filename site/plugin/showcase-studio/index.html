What Showcase Studio does

Showcase Studio from 3DQuads speeds up presenting models. The camera frames automatically to different model sizes, with eight angle presets, and lighting presets are applied from one panel, up to eighteen depending on the edition.

Backgrounds can be solid, gradient or transparent, a floor plane can be added, and renders are output from the same panel. Artists can produce consistent portfolio renders quickly. The feature set spans auto-frame camera with eight angle presets and up to eighteen lighting presets.

Key features

  • Auto-frame camera with eight angle presets
  • Up to eighteen lighting presets
  • Solid, gradient or transparent backgrounds
  • Floor plane and render output
