What Responsive Tools does

Responsive Tools is a Pixcode toolkit that makes compositions react when sizes change. It is meant for designers who build templates which must survive different text lengths and aspect ratios.

Text layers can auto-adapt using four modes: Comp, Layer, Target and Size. Anchor points can be locked at nine positions, and layers can be locked to eight points of the composition to keep them responsive. The tool works without creating extra layers and without affecting existing animation, so it can be added to finished work.

Key features

  • Four auto-adapt modes for text layers
  • Anchor point locking at 9 points
  • Layer locking to 8 composition points
  • No extra layers created
  • Existing animation unaffected
