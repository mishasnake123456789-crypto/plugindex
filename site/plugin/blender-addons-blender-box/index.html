What Blender Addons | Blender Box does

Blender Box from VFX Grace bundles a rename and weight pie menu, a Rocks Factory, a Material Preset library and a Material Manager.

The pie menu batch renames models, materials, particle systems, textures and weights, with replacement and prefix/suffix tools. A Weight Tool generates weights from slope and converts weight to vertex color and back, and object index tools plus batch modifier toggling are included. Day to day, that covers batch renaming pie menu, slope-based weight tool and rocks Factory.
