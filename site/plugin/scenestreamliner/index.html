What Scenestreamliner does

SceneStreamliner is a Blender add-on that lightens viewport load in dense scenes. It duplicates high-poly meshes into low-poly versions using the Decimate modifier, labels them with a .LOW suffix and places them in a dedicated Low Poly (Viewport) collection.

The original high-poly objects stay hidden in the viewport but remain active for final renders, so output quality is unaffected. You can process all objects, only the selection, or a specific collection. It helps animators and layout artists who need smoother playback when working with heavy assets.

Key features

  • One-click proxy generation with Decimate
  • Proxies placed in a dedicated collection
  • Originals stay active for final renders
  • Scope: all, selected or one collection
