Blender add-on showing every scene camera in a clickable viewport grid for quick switching and multi-selection.

What Camera Grid does

Camera Grid places an interactive overlay in the Blender viewport that lists all the cameras in your scene as tiles. This makes it easy to move between many camera angles without digging through the outliner.

Tiles can be plain solid blocks or cached viewport thumbnails. Switch cameras by clicking, dragging, using the scroll wheel or arrow keys, and select several at once by painting with a right-click drag. The grid scrolls when there are more cameras than fit, so large shot lists stay manageable.

Key features

  • Solid tile or cached thumbnail display modes
  • Switch cameras by click, drag, scroll or arrow keys
  • Right-click drag paint selection
  • Scrollable grid for many cameras
