What Mesh Writer does

Mesh Writer from Mytner turns symbols into usable geometry in Blender. It includes a searchable library and a built-in SVG editor.

More than 5,000 symbols and 3,700 SVGs are bundled, and you can import your own. Output can be Geometry Nodes curves, 3D meshes or 3D curves. Browsing is categorized with support for nine or more languages, and one-click Geometry Nodes integration keeps results editable. This is useful for logos, icons, math notation and decorative lettering.

Key features

  • Searchable symbol library with SVG editor
  • Symbols, SVGs, math characters and emojis
  • 5,000+ symbols and 3,700+ SVGs
  • Curves, meshes or Geometry Nodes output
  • Multi-language interface
