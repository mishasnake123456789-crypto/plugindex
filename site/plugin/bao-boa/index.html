What BAO Boa does

BAO Boa is a plugin for After Effects that makes a layer follow a mask path, like a texture wrapping a snake. Any source can be distorted along the curve, with rotation and twist applied along its length.

You can control start, end, scale and Z position, and move or rotate the spline in 3D space. A stretch mode keyed to mask vertices works like Puppet Pins, giving each segment its own distortion, so a bent arm can leave the hand untouched. Mesh definition and sub-sampling govern quality, extrude and contour add depth, and the result reacts to the composition's camera and lights. It is fully native, so rendering stays quick.

Key features

  • Warp any source along a mask path
  • Twist, rotation, scale and Z placement along the path
  • 3D rotate, scale and move for splines
  • Per-segment distortion using mask vertices
  • Extrude and contour with camera and light response
