An After Effects script that copies keyframe eases and values separately so pasting one never overwrites the other.

What EaseCopy does

EaseCopy is a script by Mike Overbeck for After Effects animators who spend time fixing keyframe curves. Normally, pasting keyframes replaces both timing values and easing, but this tool lets you separate the two.

You can copy and paste eases while keeping your existing values, or paste values while leaving eases untouched. Shortcut scripts allow each function to be assigned to a keyboard shortcut, and KBAR is supported without the memory limits of earlier versions. Installation is automated through the aescripts and aeplugins manager app, and it works from After Effects CS6 up to the 2026 release.

Key features

  • Paste eases without changing values
  • Paste values without changing eases
  • Shortcut scripts for keyboard binding
  • KBAR support
  • Compatible from CS6 to the 2026 version
