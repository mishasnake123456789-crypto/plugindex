What Logonodix - 3D Logo And Text Creator does

Logonodix is a node-based Blender add-on for 3D logos and short text. It takes any 2D SVG vector file or typed text and builds a 3D version, then converts it to real mesh objects.

Three tool modes cover logo, text or combined designs, and logos have Body, Design and Plate sections with several parts each. Use is allowed for private and commercial projects. Because it is node-based, designs can be tweaked repeatedly before conversion, making it practical for brand intros and title treatments.

Key features

  • SVG or text to 3D logo
  • Three tool modes
  • Body, Design and Plate sections
  • Converts to mesh objects
