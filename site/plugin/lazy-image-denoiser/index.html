What Lazy Image Denoiser does

Lazy Image Denoiser takes a pile of grainy images and cleans them in one go, so you avoid setting up the compositor for each file. It relies on the Denoise node that already exists in Blender's Composite Editor.

Multiple images are processed together rather than one at a time, which fits rendered frames and baked texture outputs. Bookyakuno supplies a Japanese description alongside documentation, and the add-on is distributed under the GPL license. Useful for anyone with large sets of Cycles renders or bakes.

Key features

  • Batch denoising of many images
  • Uses Blender's Denoise compositor node
  • Handles rendered and baked outputs
  • Documentation and Japanese description
  • GPL license
