Object-Bound Camera Clipping

Developer: rode3d

Free3ds Max
Download Free

3ds Max script that drives a camera's near and far clipping planes from objects you pick in the scene.

What Object-Bound Camera Clipping does

Object-Bound Camera Clipping adds controls to the selected camera in 3ds Max so its clipping planes follow scene objects. One picked object defines the near clipping distance and another defines the far distance, each with an optional offset.

The near plane sits on whichever face of the picked object is nearest the camera, falling back to the pivot for surfaceless objects such as helpers. Custom attributes are written to the camera, so it keeps working in other projects or Max versions without the script installed. Physical Camera and VRay Physical Camera are both supported, which suits section views and interior shots.

Key features

  • Pick objects to control near and far clipping
  • Optional offset for each picked object
  • Near plane placed on the closest face automatically
  • Pivot used when the object has no surface
  • Custom attributes keep working without the script
