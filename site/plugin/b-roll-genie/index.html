Generates AI B-roll images and videos in Premiere Pro based on spoken narration.

What B-Roll Genie does

B-Roll Genie listens to narration and makes pictures to go with it. Select audio or video containing speech, click generate, and the plugin analyzes the content, writes contextual prompts and creates matching visuals in the timeline.

It works with any narrated audio or video on Windows and macOS. You need your own OpenAI API key and a Replicate API key. It can be useful for explainers and commentary videos that need visuals to illustrate what is being said.

Key features

  • AI images and videos from narration
  • Writes contextual prompts automatically
  • Works inside the timeline
  • Windows and macOS
  • Requires OpenAI and Replicate API keys
