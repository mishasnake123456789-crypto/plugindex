What Parametric Pilot does

Parametric Pilot is a Blender add-on for accurate pivot placement and alignment. It moves the 3D cursor to calculated positions and shifts object origins, working across multiple objects and supporting both curves and meshes.

Placement can be fine-tuned by dragging or with arrow keys, and interactive visual guides show where things will land. A preview mode lets you test a placement before committing. Several orientation methods are offered. Modelers and architects who need exact origins for rotating, snapping or exporting parts will find it dependable.

Key features

  • Precise pivot placement across many objects
  • 3D cursor moved to calculated positions
  • Drag and arrow-key fine-tuning
  • Preview mode with visual guides
  • Curve and mesh support
