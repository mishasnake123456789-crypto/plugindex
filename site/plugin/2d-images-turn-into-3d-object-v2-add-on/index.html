What ❤️2D Images Turn Into 3D Object V2 Add_On does

Studioromanrec's second-generation tool converts flat pictures into 3D geometry in Blender. Draw your artwork, bring it into Blender, and the add-on performs the conversion for you.

It reads JPG and PNG files, works with Blender versions 3.1 through 4.3, includes documentation and is released under the GPL license. It is helpful for turning sketches, logos and simple illustrations into objects without modeling them from scratch.

Key features

  • Converts 2D images into 3D objects
  • Accepts JPG and PNG input
  • Starts from artwork brought into Blender
  • Supports Blender 3.1 to 4.3
