What X-Over (Automatically Fix Curve Intersections) does

CGMatter's X-Over is a live intersection solver for curves in Blender. Where a curve crosses itself, it lifts one section over the other so shapes pass without clipping, helpful for rope knots, bandages and similar forms.

Problems are found and fixed on the fly, even after later edits. Several splines in one curve object interact, with reversible stacking order. It works on any surface and inherits its normals, with output as a mesh, the changed curve, or the intersections.

Key features

  • Live curve intersection solver
  • Multiple interacting splines
  • Invertible stacking order
  • Inherits surface normals
  • Mesh, curve or intersection output
