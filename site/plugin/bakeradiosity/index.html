What BakeRadiosity does

BakeRadiosity is a 3ds Max plugin that converts the result of an Adaptive Subdivision calculation into a new mesh object. Lighting data is then baked onto that mesh's vertices.

The global illumination effect carries into real-time viewing and walk-throughs through the Nitrous viewport feature. Output can be used to produce background data for games or for Design Visualization previews, and the latest update added 2024 support. It helps artists who want radiosity-quality lighting in an interactive setting.

Key features

  • Converts Adaptive Subdivision results to a mesh
  • Bakes lighting onto vertices
  • GI visible in Nitrous real-time views
  • Suited to game backgrounds and DV previews
  • Updated for 3ds Max 2024
