What Super3D Import & Export .Sat does

Super3D Import & Export .Sat handles ACIS SAT files, the kernel format used by AutoCAD 3D, BricsCAD and ZWCAD. Dedicated File menu entries manage import and export, converting through the Super3D cloud service.

No local ACIS install is required. On import, solid bodies are tessellated to clean polygon meshes. Useful for CAD-to-visualization workflows. The feature set spans file menu entries for .sat, cloud conversion, no ACIS install and solid bodies tessellated to polygon mesh.

Key features

  • File menu entries for .sat
  • Cloud conversion, no ACIS install
  • Solid bodies tessellated to polygon mesh
