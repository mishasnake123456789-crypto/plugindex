Sorts the Blender outliner by polygon count so heavy meshes are easy to find with a click.

What Sort By Polycount does

Sort By Polycount reorders the outliner by how many polygons each object has, putting the heaviest geometry at the top. Anything that is not a mesh is filtered out, so the list shows only relevant items.

Object information remains intact after filtering, and the whole thing runs with one click. Installation is done by dropping the .zip onto the viewport, and the license is royalty-free. Optimizers tracking down the culprits behind a slow scene will find it far quicker than checking each object.

Key features

  • Outliner sorted by polygon count
  • Non-mesh objects filtered out
  • One-click operation
  • Install by dragging the .zip
