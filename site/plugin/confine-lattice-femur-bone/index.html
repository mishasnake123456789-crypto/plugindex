What Confine_Lattice_Femur_Bone does

Tom Paul's Confine_Lattice_Femur_Bone is a bundle of four blend files, each carrying a Python script that builds a lattice and fits it to a femur. Run the script from the Text Editor.

Variants include a lattice within the bone volume, a version with a skin giving wall thickness at the outer boundary, a surface texture pattern on the bone, and a porous design. They serve biomedical researchers and engineers exploring implants or scaffold concepts.

Key features

  • Four blend files with scripts
  • Lattice confined within the bone volume
  • Skinned version with wall thickness
  • Surface texture on the bone
  • Run from the Text Editor
