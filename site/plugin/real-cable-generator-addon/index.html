What Real Cable Generator Addon does

Real Cable Generator makes cables in a few clicks from a selected curve or object. It runs on geometry nodes behind the scenes, so users do not need to understand them.

Cable Curve and Cable Object modes turn the selection into a cable, the result can be converted to a mesh, and shader materials are adjustable in the modifier properties. It suits wiring, power lines and tech props. Notable points: curve and object cable modes, geometry nodes without node knowledge and convert to mesh option.

Key features

  • Curve and object cable modes
  • Geometry nodes without node knowledge
  • Convert to mesh option
  • Material controls in the modifier
