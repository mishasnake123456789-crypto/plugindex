What Drop and Slide does

Drop and Slide, from Gary Reisman, builds dropdown menu controls that can drive layers, layer time remapping and source text. A single menu then switches between options such as different graphics, clips or text strings.

Null controls and menu items can be named, and basic controls cover opacity, position, scale and rotation, plus text layers with list options. Combination options allow sliding to change selections in several ways. Advanced checkbox and slider controls are available, along with text opacity, time remap opacity expressions and a frame offset slider. Expressions can be removed again.

Key features

  • Dropdowns drive layers, time remap and source text
  • Naming for nulls, menus and items
  • Basic transform and opacity controls
  • Slide-based selection changes
  • Option to remove expressions
