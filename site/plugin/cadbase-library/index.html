What CADBase Library does

CADBase Library links Blender to the CADBase platform so you can pull component files from a remote library straight into your scene. Favorite components, their variants and sets of Blender files are arranged in a navigable hierarchy.

The root level lists every local library component, the component level shows modifications of a chosen part, and the file set level lists the files contained in a modification's Blender set. Engineers and designers who keep parts in CADBase can reuse them in Blender without manual downloading.

Key features

  • Downloads components from the CADBase platform
  • Root level lists local library components
  • Component level shows modifications
  • File set level lists Blender files
