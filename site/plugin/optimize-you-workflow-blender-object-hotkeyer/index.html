What Optimize You Workflow! - Blender Object Hotkeyer does

Object Hotkeyer binds any object to a key so a press selects it immediately. Each object can be paired with a mode: Object, Pose, Edit or Weight Paint.

That makes it easy to jump between animating a character, moving the camera or DOF point, and editing lights, curves or empties. A weight painting setup is included as well. It helps animators who constantly change selection and mode. Notable points: hotkey-to-object assignment, object, Pose, Edit and Weight Paint modes and quick switching between camera, rig, light.

Key features

  • Hotkey-to-object assignment
  • Object, Pose, Edit and Weight Paint modes
  • Quick switching between camera, rig, light
  • Weight-painting setup
