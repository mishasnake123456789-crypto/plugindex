What fr Defaults fix does

fr Defaults fix is a small startup script for 3ds Max users of finalRender. By default, finalRender makes new objects with GI disabled, which means they quietly fail to take part in global illumination until fixed by hand.

This script changes that behavior so new objects are created with send and receive GI and receive caustics turned on. Install it by placing the file in the scripts/startup folder; versions 4 and 5 are listed as supported. Artists who build scenes with finalRender will avoid an annoying surprise and a repetitive correction step.

Key features

  • New objects created with send/receive GI enabled
  • Receive caustics turned on for new objects
  • Corrects finalRender's GI-disabled default
  • Installs in the scripts/startup folder
  • Works with versions 4 and 5
