What Sculpt Toolkit - Mesh Processing For Sculptors does

Sculpt Toolkit from Jeacom puts a set of sculpting support tools into one add-on for Blender. Most features are reached through the ALT+W shortcut.

An optimized Remesh rebuilds a model from quads and can add multiresolution without losing detail. Basemesh generation uses an envelope builder with commands to add envelope armatures and bones and convert them. Booleans, manipulation tools and light controls are also included. Sculptors speed up blockouts and cleanup.

Key features

  • Optimized quad Remesh with multires
  • Envelope-based basemesh generation
  • Booleans and manipulation tools
  • Viewport light controls
  • ALT+W shortcut access
