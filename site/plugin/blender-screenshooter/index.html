What Blender Screenshooter does

Blender Screenshooter saves a separate image for each object in your scene with a single click. It is useful when you need a quick catalog of individual assets instead of rendering them one at a time.

Each capture is a transparent PNG, and you can choose front, back, left, top or bottom views, or capture every supported angle for each object. Meshes and armatures are included while empty objects are skipped. Quality and capture settings can be adjusted, and a multiview mode combines the active view with a multi-selection.

Key features

  • One-click capture of every object in the scene
  • Transparent PNG output
  • Front, back, left, top and bottom views
  • Handles mesh and armature objects, skips empties
  • Adjustable image quality settings
