What Vrtoon Shader Manager does

Vrtoon Shader Manager provides non-photorealistic rendering tools centered on Eevee. Two shaders, Cel Look and Semi Real, can be switched quickly, and both generate their results parametrically for flexibility.

One-click setup prepares a model, batch parameter editing adjusts many materials together, and an advanced outline generator adds line work. Anime-style and VTuber model creators can get consistent toon shading across characters.

Key features

  • Cel Look and Semi Real shaders
  • Model setup in one click
  • Batch parameter tweaking
  • Advanced outline generator
  • Built around Eevee
