What Hawaiki AutoFix does

Hawaiki AutoFix is a repair plugin for After Effects, DaVinci Resolve and Premiere Pro, also usable in Final Cut Pro and Motion. It identifies dead pixels in footage and fills them in using content-aware technology, then gives you tools to refine the repair or paint in the pixels yourself.

A dedicated HUD focuses on the repair area at any ratio, including square and vertical, and a Navigation View keeps the wider frame in sight. Match Swatch and Graph modes highlight problems, while Repair Mask and Replace tools offer a manual fix. Sampling comes with prebuilt methods and saved custom combinations, and the interface can be tailored.

Key features

  • Content-aware dead pixel restoration
  • HUD for precise repair area view
  • Navigation View for the full frame
  • Match Swatch and Graph problem modes
  • Repair Mask, Replace tools and sampling presets
