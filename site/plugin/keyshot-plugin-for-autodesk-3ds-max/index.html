What KeyShot Plugin for Autodesk® 3ds Max® does

The KeyShot Plugin for 3ds Max renders, updates and exports geometry to KeyShot using Luxion's LiveLinking technology. The link keeps the two programs separate while allowing changes to flow from one to the other.

A single click sends all edits to KeyShot without losing the views, materials, textures or animations already applied there. The plugin supports 3ds Max 2025 and runs with any KeyShot version that has an active lifecycle. It uses a custom installer. Product visualizers who model in 3ds Max and render in KeyShot can iterate without re-importing.

Key features

  • Render, update and export geometry to KeyShot
  • LiveLinking between 3ds Max and KeyShot
  • One-click updates keep views, materials, animations
  • Support for 3ds Max 2025
  • Works with actively supported KeyShot versions
