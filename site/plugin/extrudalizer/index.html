What Extrudalizer does

Extrudalizer, by IVG Design, is an After Effects script that gives flat shape layers depth. It extrudes them into virtual 3D space and offers control over depth, position, rotation and scale while you keep editing the original 2D path.

Animating the 2D path translates into 3D animation on the result. Artwork can be mapped onto any face, appearance controls include wireframe, edge stroke, translucency and front, back and side color and gradients, and pre-extrusion options set sections per curved segment. Export is fully Lottie compatible for web without baking, and baking supports iOS and Android. Version 1.2.0 added origin anchor tools and centroid crosshairs.

Key features

  • Extrudes shape layers into virtual 3D
  • 2D path animation drives the 3D shape
  • Artwork mapping to any face
  • Wireframe, translucency and gradient appearance
  • Lottie-compatible export
