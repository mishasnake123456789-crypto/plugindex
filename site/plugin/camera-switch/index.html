What Camera Switch does

Camera Switch is a Blender plugin that moves a view through the cameras placed in a scene. It switches automatically from one camera position to the next, producing a morph-like effect.

All scene cameras are managed from one panel, where you can pick, hide and change the active camera. You can add multiple cameras, set their order and frame the keys you want. Good for fly-throughs and showcases. The result is a smooth path through a sequence of viewpoints, useful for product showcases, architectural walkthroughs and presentation reels.

Key features

  • Manage all cameras from one panel
  • Automatic switching between positions
  • Set camera order
  • Add cameras at any time
