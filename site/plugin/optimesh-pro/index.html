What Optimesh Pro does

OptiMesh Pro brings a full game asset pipeline into Blender so assets can be prepared without leaving it. It covers optimization, LOD generation, UV unwrapping, texture baking, collider creation, asset analysis and export to multiple engines.

Smart optimization decimates by ratio or target polygon count, preserves sharp edges and UV seams, offers Mobile, Indie, AA and Hero presets and monitors the poly budget live. Game developers can handle most prep in one add-on.

Key features

  • Decimation by ratio or target count
  • Mobile, Indie, AA and Hero presets
  • Automatic LOD generation
  • UV unwrapping, baking and colliders
  • Export to multiple engines
