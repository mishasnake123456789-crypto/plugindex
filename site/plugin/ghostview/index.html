Blender extension putting see-through window controls in the top bar, so reference material behind the app stays visible.

What GhostView does

GhostView, by JR3DFUL, makes the entire Blender window see-through, letting you trace or compare against reference material displayed behind the application.

The top bar gains a ghost toggle, an opacity slider spanning 10 to 100 percent plus a lock against accidental edits. Ctrl+Alt+Shift+H switches transparency on and off globally, so you can flip between normal work and reference viewing quickly.

Key features

  • Top bar ghost toggle
  • Opacity slider ranging 10-100 percent
  • Lock to prevent accidental changes
  • Ctrl+Alt+Shift+H global shortcut
