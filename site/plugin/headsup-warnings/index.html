Blender add-on that displays on-screen warnings in the viewport and compositor for potentially destructive settings.

What HeadsUp Warnings does

HeadsUp Warnings surfaces common mistakes in Blender before they cause trouble, using color-coded borders and on-screen messages in the 3D viewport and compositor.

More than fifty conditions can be warned about, and each is toggleable via the add-on preferences. Feedback is shown in real time. Newer users and busy production artists benefit from reminders about settings like leftover modes or render options. Each warning can be switched on or off in the preferences, so the add-on can be tuned to the kinds of mistakes a particular user tends to make.

Key features

  • Warnings in viewport and compositor
  • Color-coded borders and messages
  • 50+ toggleable conditions
  • Real-time feedback
