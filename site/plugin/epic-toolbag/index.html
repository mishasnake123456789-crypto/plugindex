Workflow toolkit for Blender with preset shaders, asset management, camera and lighting presets, and remeshing.

What Epic Toolbag does

Epic Toolbag combines several scene-building helpers inside Blender. Ready-made shaders, asset import and management, camera and light presets, and post-processing controls are gathered together.

A Remesh! operator uses Blender's native Quadriflow algorithm for automatic retopology, and more than 25 HDRIs are included. Artists wanting a Marmoset-like quick presentation setup, or a faster way to light and render models, will find a lot packed into one add-on. Everything is controlled from within Blender, so a scene can go from imported model to lit, rendered preview with few steps.

Key features

  • Pre-configured shaders
  • Camera and lighting presets
  • Remesh! operator using Quadriflow
  • Over 25 included HDRIs
  • Asset import and management
