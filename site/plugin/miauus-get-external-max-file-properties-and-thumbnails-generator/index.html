What miauu's Get External .MAX File Properties & Thumbnails Generator does

This miauu tool inspects .max files from within 3ds Max without having to open them. It reads a file's properties and displays its thumbnail directly, which is quick when looking through a folder of unfamiliar scenes.

It can also extract thumbnails from chosen .max files and save them, again without opening the scenes, so an image library for a project archive can be built easily. It supports 3ds Max and 3ds Max Design releases from 2013 to 2023. Studios keeping large archives of scenes will find it saves time and avoids loading heavy files.

Key features

  • Reads .max file properties without opening
  • Displays thumbnails without opening files
  • Extracts and saves thumbnails from selected files
  • Runs in 3ds Max and Max Design 2013 to 2023
