What Modern Primitive does

Modern Primitive supplies thirteen procedural shapes for Blender, built with Geometry Nodes so they remain editable. They include Cube, Deformable Cube, UV Sphere, Ico Sphere, Quad Sphere, Cylinder, Cone, Capsule, Tube, Torus, Gear, Spring and Grid.

On-screen handles change radius, height, divisions and similar settings, while a heads-up display reads out values and snapping as you drag. Because shapes are parametric, dimensions can be changed any time. Modelers who need quick, adjustable base forms can skip modifier stacking.

Key features

  • 13 procedural primitives
  • Viewport gizmos for parameters
  • HUD with live values and snapping
  • Non-destructive Geometry Nodes build
