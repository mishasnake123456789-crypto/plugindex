MaxScript controller that reports how far an object has traveled, usable in wire parameters and expressions.

What Travel Distance does

Travel Distance, a MaxScript controller, works out how far an object has moved in 3ds Max and makes the figure available as a value. In the modify panel, a Pick Reference button chooses the object being measured.

As the object is animated in autokey, the reported value changes accordingly, and it can be used in wire parameters, expressions or script controllers. That makes it possible to drive wheel rotation, counters or other motion-linked behavior from actual travel. It works with all versions of 3ds Max and is a tiny file of roughly 1.25 KB.

Key features

  • Controller that measures distance traveled
  • Pick Reference button in the modify panel
  • Value updates while animating in autokey
  • Usable in wire parameters, expressions and script controllers
  • Works with all 3ds Max versions
