Lightweight Blender extension that shows custom visual cues while Local View, a camera lock or certain modes are on.

What Themeable Modes and Views does

Themeable Modes and Views, by 1P2D, makes it obvious which viewport state you are in. When Local View is active, four corner markers appear with a color and thickness you choose, and the viewport background color can change as well.

Optional borders are also available for Lock to Object and other interaction modes. These visual signals prevent confusion when working in isolation or locked views.

Key features

  • Local View corner borders with custom color and thickness
  • Background color change in Local View
  • Borders you can enable for Lock to Object
  • Cues for specific interaction modes
