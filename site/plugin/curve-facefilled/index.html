What Curve Facefilled does

Curve Facefilled is a Blender plugin that creates faces from outlines. Intricate outlines drawn with curves, mesh lines or grid lines get filled with an editable face as you work.

Curves can be drawn on a set area so strokes remain straight, and a Facefilled button separates the selection and creates an editable result. Useful for logos, plans and 2D-to-3D shapes. It simplifies turning outlines into surfaces, which can otherwise require several manual steps like joining, filling and cleaning up.

Key features

  • Real-time face fill for curves and lines
  • Draw curves onto a defined area
  • Facefilled button creates editable mesh
  • Works with grid lines
