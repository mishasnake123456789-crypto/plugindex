Blender add-on for measuring vertex distances, edge lengths and angles within Edit Mode, respecting scene units.

What SCO EdgeWise does

SCO EdgeWise reports measurements while you model in Blender's Edit Mode, following the unit system set for the scene.

It measures distances between two vertices, individual edge or edge group lengths, angles between two selected edges and offsets from the 3D Cursor to a vertex. Modelers working to precise dimensions can verify them quickly. Having measurements in Edit Mode saves switching to separate measuring tools, and unit-aware values help when modeling to real-world dimensions.

Key features

  • Vertex distance measurement
  • Edge and edge-group lengths
  • Angles between edges
  • Offsets from the 3D Cursor
