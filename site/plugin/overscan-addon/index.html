Blender add-on that adds per-edge render overscan and writes the values into EXR metadata for Nuke.

What Overscan Addon does

Overscan Addon extends Blender renders beyond the frame so compositors have extra pixels to work with, for example when applying lens distortion or camera shake in post. Left, right, top and bottom edges are controlled independently, in pixels or percentages, with a live viewport preview.

After rendering, the overscan values are written directly into the EXR metadata, so Nuke can set its bounding box without a reformat node. A global toggle enables or disables it, and a persistent handler applies the overscan to the camera when a file opens.

Key features

  • Independent left, right, top and bottom overscan
  • Pixel or percentage values
  • Live viewport preview
  • Overscan values saved in EXR metadata
  • Nuke bounding box without a reformat node
