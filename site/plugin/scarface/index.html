What Scarface does

Scarface is a small Premiere Pro extension for refreshing media that has changed on disk. Select a clip on the timeline, press the button, and the clip is updated without a trip through the Project panel.

A Force update option briefly takes the clip offline and reconnects it, which helps when a normal refresh does not pick up the new file. An Info option shows the file name, modification date and time, and full path inside the panel, so you can confirm which version of a file the clip points to. It is free and works with Premiere Pro 8.0 and later.

Key features

  • Update a selected clip with one button
  • Force update toggles offline then reconnects
  • Info shows file name, modified time and path
  • Works with Premiere Pro 8.0 and later
