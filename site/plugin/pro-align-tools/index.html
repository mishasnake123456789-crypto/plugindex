Blender add-on for interactively aligning many objects at once in Object Mode with gizmos.

What Pro Align Tools does

Pro Align Tools aligns multiple objects interactively in Blender's 3D viewport in Object Mode. It provides auto-alignment plus control over projection plane, origin point and orientation.

With one click, auto-alignment selects a ready combination of projection plane, origin, direction, orientation and depth. Gizmos combine three axes to choose the alignment side and base point, while sidebar buttons handle negative, center and positive directions. Layout and set artists arrange props and parts neatly.

Key features

  • Interactive multi-object alignment
  • One-click auto-alignment
  • Gizmos for side and base point
  • Sidebar direction buttons
