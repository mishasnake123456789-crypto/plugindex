Renders a Blender viewport animation to MP4 with a click, using automatic FFmpeg settings and numbered filenames.

What Fast Preview Render does

Fast Preview Render turns a viewport animation into a video without fiddling with output settings. Smart defaults configure FFmpeg automatically and produce an MP4.

Filenames count up on their own, such as preview_001.mp4 and preview_002.mp4, so earlier previews are never overwritten, and the render scale can be adjusted. A button opens the output folder. Animators sharing quick review videos and checking timing will save a lot of setup. Because it needs almost no configuration, it also suits quick client previews between longer final renders.

Key features

  • One-click viewport render to MP4
  • Automatic FFmpeg defaults
  • Auto-incremented filenames
  • Adjustable render scale
