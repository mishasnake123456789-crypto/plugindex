What 3DBrowser Pro R17 does

3DBrowser Pro R17 by Mootools is software for organizing, previewing and optimizing 3D content, which works with 3ds Max through a provided plugin. It combines a 3D file explorer with a scene viewer and image viewer.

It reads a wide range of formats, among them 3ds Max, Maya, FBX, glTF, USD, E57 point clouds, Blender, SketchUp, Cinema 4D, Collada and STL. Thumbnails use controllable viewpoints and display modes. Pro adds polygon reduction through Polygon Cruncher with automatic MagicCruncher settings, plus atlas creation that groups textures by PBR type and detects duplicates. Studios with large multi-format libraries can manage them from one place.

Key features

  • 3D file explorer, scene viewer and image viewer
  • Reads FBX, glTF, USD, E57, Blender, SketchUp and more
  • Controllable preview thumbnails
  • Polygon reduction with Polygon Cruncher in Pro
  • Texture atlas creation by PBR type
