What Treebox For Blender - A Tree Generator For Indie Games does

Treebox generates procedural trees and bushes for game developers and artists in Blender, producing anime-inspired trees and other nature assets via an adjustable Geometry Nodes menu.

Settings include branch splitting, leaf scatter, normal smoothing and volume creation. A preset material library finishes the models, and the Geometry Nodes menu allows fine-tuning. Trees can be converted into optimized, game-ready meshes in one click, which suits indie projects needing plenty of foliage.

Key features

  • Procedural tree and bush generation
  • Branch splitting, leaf scattering and normal smoothing
  • Preset material library
  • Geometry Nodes menu for fine-tuning
  • One-click conversion to game-ready meshes
