What Precision Weight Editor Pro does

Precision Weight Editor Pro is a Blender add-on for vertex weight work in character rigging and weight painting. It focuses on quick, accurate edits rather than manual painting passes.

A Max Groups Per Vertex setting caps how many non-zero weight groups each vertex keeps, and a refresh button applies the change. Bone selection mode switches the active vertex group by clicking a bone, with an adjustable pick radius. Mirroring, transfer and import/export tools round out the set. Riggers and character artists can use it to clean up skinning for game engines and animation.

Key features

  • Max Groups Per Vertex limiting
  • Bone click selection with pick radius
  • Weight mirroring and transfer
  • Weight import and export
