What Polytools does

PolyTools helps you draw quad topology directly onto a surface in the 3D Viewport. A focused set of sub-modes covers building, adjusting, merging and cleaning.

Dragging out quad strips spaces them according to the surrounding edge length, and guide points go down with Ctrl and a left click. Loop Mode builds neat edge loops around curved, cylinder-like surfaces, with segment count adjusted by holding S while moving the mouse, and brush-style tools help refine the result. Retopologists working on characters and props will find the live preview intuitive.

Key features

  • Live quad strip preview with adaptive spacing
  • Guide points with Ctrl + LMB
  • Loop Mode for cylindrical surfaces
  • Brush-style refinement tools
