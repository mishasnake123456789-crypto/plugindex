What MVRK does

MVRK helps filmmakers and colourists check composition. It overlays dynamic symmetry guides in DaVinci Resolve, built as an OpenFX plugin by aeriform, so framing can be judged against classical proportions.

Version 1.1.3 brought Apple Silicon support in the OpenFX build and two new guides, Harmony and Horizon. Version 1.1.2 added support for Assimilate SCRATCH and LIVE FX. It is listed as compatible with DaVinci Resolve 17 and 16, and the guides are intended as a non-destructive aid while framing and grading shots.

Key features

  • Dynamic symmetry composition guides
  • OpenFX plugin for Resolve
  • New Harmony and Horizon guides
  • Apple Silicon support in 1.1.3
  • Assimilate SCRATCH and LIVE FX support
