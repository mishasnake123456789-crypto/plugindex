Distributes trees or other objects over a target surface in Blender via a hair particle system.

What Garden Scatter does

Garden Scatter lets you fill an area with objects using Blender's hair particle system, but with far fewer manual steps. It was made mainly to speed up planting trees.

The add-on counts the vertices of the target and uses that number as the particle count, and it can place objects on the target's faces too. The source can be a single object or a whole collection. Landscape and environment artists get a faster start than configuring the particle settings themselves.

Key features

  • Scatters objects with the hair particle system
  • Auto particle count from target vertices
  • Can distribute on faces
  • Source can be an object or a collection
