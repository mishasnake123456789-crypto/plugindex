What Mesh Filters does

Mesh Filters is a Blender plugin from Hartface that refines mesh selection through filters. Instead of selecting by hand, you build a stack of criteria that narrows the selection down to the faces, edges or vertices you want.

Filters can be combined freely and nothing is changed in the mesh itself, so you can adjust or remove them later. Controls sit in the Mesh Filters tab of the viewport's N panel, and the add-on asks for no special permissions. It helps modelers working on dense geometry.

Key features

  • Combinable filter stack
  • Selects faces, edges and vertices
  • Completely non-destructive
  • Lives in the N panel Mesh Filters tab
