What ShapeKeySwapper does

ShapeKeySwapper is a small Blender add-on from Maro3D for people who work with shape keys. A single click exchanges the vertex positions stored at the 0 value and the 1 value of the active shape key.

The command is added to the Shape Key Specials drop-down under the name Swap Vertices at Shape Key Value. One practical use is flipping outfit shape keys on VRChat avatars. The add-on is written in Python, needs no special permissions, and supports Blender 4.2 LTS and newer.

Key features

  • Swaps vertex positions between shape key values 0 and 1
  • Entry in the Shape Key Specials menu
  • Single-click operation
  • Written in Python
  • Requires no special permissions
