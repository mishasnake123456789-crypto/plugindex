What Lk Driver Master does

LK Driver Master makes drivers approachable for people who do not want to write code. You build connections step by step with modular nodes, picking from dropdowns and linking sockets, so no expression has to be typed.

Live viewport overlays animate the connection paths in real time, and Smart Nodes isolate breaks so errors are flagged before anything runs. Its audience is technical artists, riggers and animators who link properties across a scene. Complex rigs become easier to read and debug.

Key features

  • No-code driver creation with dropdowns and links
  • Animated live connection overlays
  • Smart Nodes flag errors before execution
  • Modular step-by-step node workflow
