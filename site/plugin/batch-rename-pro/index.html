What Batch Rename Pro does

Batch Rename Pro is a naming system for Blender that handles far more than objects. It renames and organizes meshes, collections, materials, textures, armatures, bones, shape keys, actions, node groups, cameras, lights and other datablocks.

Operations can be combined into reusable workflows, and every change is displayed before being committed. Technical artists and studios enforcing naming conventions can clean up large projects in a controlled way. Among its tools are works on many Blender data types and preview of every change before applying.

Key features

  • Works on many Blender data types
  • Preview of every change before applying
  • Combine operations into reusable workflows
