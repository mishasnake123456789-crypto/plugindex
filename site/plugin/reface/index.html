Precision modeling kit for Blender with measurement overlays, CAD-style edits, cleanup and isolation tools.

What Reface does

Reface is built for exact work on hard-surface meshes. A ViewMode overlay displays edge lengths, angles, circle radii, face areas, normals, loop perimeters and min/max edge indicators, with toggles for Show All, Drag Handles and Face Info.

CAD-style editing lets you drag selected edge lengths and adjust angles, and the toolkit adds mesh cleanup, reference-based editing, retopology helpers and object isolation. It helps inspect geometry and repair meshes with accurate dimensions.

Key features

  • Measurement overlay for lengths, angles, areas
  • CAD-style edge length and angle editing
  • Mesh cleanup and repair
  • Retopology helpers and object isolation
