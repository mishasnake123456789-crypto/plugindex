Generates code-based animations from text prompts in After Effects and Premiere Pro using Three.js, GSAP, Pixi.js and p5.js.

What Sandbox does

Sandbox is an extension from Othman Ahmed that turns written prompts into animations built with code. It runs inside After Effects and Premiere Pro and uses engines such as Three.js, GSAP, Pixi.js, p5.js and plain HTML5 to produce results.

Output can be 3D models, physics scenes, moving type and charts, delivered as editable assets that are ready to render. Smart Labeling lets you click parts of an SVG and name them, like HEAD, LEFT_ARM or BODY, and AI Context sends those labels to the AI so character animation prompts are more accurate.

Key features

  • Natural language prompts create code-based animation
  • Uses Three.js, GSAP, Pixi.js, p5.js and HTML5
  • 3D models, physics, moving type and charts
  • Editable, render-ready output
  • Smart Labeling of SVG parts for character prompts
