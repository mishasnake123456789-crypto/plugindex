What Sequence Hub does

Sequence Hub by Leyero helps when a project contains many sequences nested inside each other. It presents the structure so you can navigate through it, and refreshes automatically as sequences are added, removed or changed.

Arrows jump back through previously opened sequences, and an optional minimal interface shows only the arrows. It supports Premiere Pro 2021 through 2025. This keeps track of where you are in projects built from many nested timelines.

Key features

  • Navigate nested sequence structure
  • Auto-updating data
  • Arrows for previous sequences
  • Minimal arrows-only UI
  • Premiere Pro 2021 to 2025
