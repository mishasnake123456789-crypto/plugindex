What Mesh Painter does

Mesh Painter, by Egret Studios, makes placing objects feel like painting. You brush meshes straight into the Blender viewport, aligning and scattering them as you go, so dressing a scene with rocks, plants or props needs no manual copying.

Placement is shown in real time. The add-on supports Blender 4.0 through 5.1, works with Cycles and Eevee, fits the extension system, includes documentation and is released under the GPL. Environment artists and set dressers who populate scenes with many repeated objects will save time over placing each item individually.

Key features

  • Paint, align and scatter meshes in the viewport
  • Real-time placement
  • Blender 4.0 to 5.1
  • Cycles and Eevee support
  • GPL licensed with documentation
