3ds Max tool for sorting, filtering and diagnosing large Multi/Sub-Object materials together with their Face IDs.

What MultiSub Organizer does

MultiSub Organizer manages large Multi/Sub-Object materials in 3ds Max along with the Face IDs they use in EditPoly or EditMesh. Everything appears in one list, and several Multi/Sub-Object materials can be shown at once.

Changing an ID updates both the material and the linked Face IDs together. The list can be sorted by slot, ID, name, material name or class in one click, and filtered by the current selection or by materials active in the Material Editor. Selection works both ways: select faces by ID or find objects linked to a material. The tool displays face counts for each ID and object counts for each material, and marks unassigned Face IDs in red.

Key features

  • Synchronized material and Face ID updates
  • Sorting by slot, ID, name or material class
  • Filtering by object selection or Material Editor
  • Select faces by ID and objects by material
  • Statistics and red highlighting of unassigned IDs
