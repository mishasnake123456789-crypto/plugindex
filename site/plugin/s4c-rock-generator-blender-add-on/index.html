What S4C Rock Generator (Blender Add-On) does

S4C Rock Generator makes rocks in Blender without any sculpting. It is built on Geometry Nodes, so every rock stays editable and nothing is baked until you decide to.

Start from a cube, icosphere or UV sphere and shape the result with controls for scale, detail, roughness, noise and distortion in the S4C Rock panel of the sidebar. A procedural rock material is assigned automatically, and Smart UV Project creates UVs for texturing. The download includes an assets file with the node setup, documentation and a quick start guide. It suits environment work, game props and quick scene dressing.

Key features

  • Choose cube, icosphere or UV sphere as the base
  • Controls for shape, detail, roughness, noise and distortion
  • Procedural rock material assigned automatically
  • Auto UVs through Smart UV Project
  • Non-destructive Geometry Nodes workflow
