A Blender add-on that generates all 52 ARKit blendshapes on rigged characters, with CSV animation import.

What Shape Key Gen does

Shape Key Gen creates the full set of ARKit facial blendshapes on a rigged Blender character, which is the standard needed for face tracking and iPhone-driven animation. It also adds special extra facial expressions for AutoRig.

It works with Auto-Rig Pro, Rigify's metarig and custom rigged characters. CSV animation data can be imported onto the character, with a test CSV included, and a Transfer Animation function moves the result onto the character after the rig is renamed and registered. Avatar creators and facial animators avoid sculpting dozens of shapes by hand.

Key features

  • Generates all 52 ARKit blendshapes
  • Extra special facial expressions for AutoRig
  • Works with Auto-Rig Pro, Rigify and custom rigs
  • CSV animation import with a test file
  • Transfer Animation to the character
