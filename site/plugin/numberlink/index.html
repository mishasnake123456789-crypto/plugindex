Creates number counting animations in After Effects by linking text to slider values.

What NumberLink does

NumberLink, from Hype Stride Media, makes animated counting numbers in one click. Numbers are tied to slider values and the text is re-written instantly as the slider moves, so animating a count means animating a slider.

Stroke color and width can be controlled, color labels change to match the selected color, and a pseudo effect gives a friendlier set of controls. The interface is smaller and resizable. It is a good fit for statistics, scoreboards and data-driven graphics.

Key features

  • One-click number counting animations
  • Text rewritten from slider values
  • Stroke color and width control
  • Pseudo effect controls
  • Smaller, resizable interface
