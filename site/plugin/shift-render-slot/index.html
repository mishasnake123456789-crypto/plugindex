A Blender add-on that moves to a new render slot automatically so test renders never overwrite each other.

What Shift Render Slot does

Shift Render Slot saves earlier renders from being replaced by newer ones. When you do repeated test renders or several shots, it advances the active render slot for you in the UV/Image Editor, so each result is preserved for comparison.

The shift can be triggered on four render events: before, after, complete or cancelled, and it can move forward to the next slot or back to the previous one. Shortcuts include Alt with the up or down arrow and Ctrl with the mouse wheel. The behavior can be switched on or off in the editor, and its state is stored with the scene.

Key features

  • Advances render slots automatically
  • Triggers on Before, After, Complete or Cancelled events
  • Increase or decrease slot direction
  • Keyboard and wheel shortcuts in the Image Editor
  • Toggle stored per scene
