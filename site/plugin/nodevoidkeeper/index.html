Blender add-on that re-centers node editor contents around the origin each time a file is saved or loaded.

What NodeVoidKeeper does

NodeVoidKeeper stops node trees from wandering across the endless node canvas in Blender. Each time you save or load a file, it moves the nodes back around the origin point at (0,0).

The node editor view pans along with them, so everything looks unchanged from your perspective, and each node keeps its offset to the snapping grid so alignment is retained. It works on all operating systems, needs no special permissions and is released under GPL v3.0 or later.

Key features

  • Re-centers nodes on save and load
  • View pans with the nodes
  • Preserves offsets to the snapping grid
  • Works on all operating systems
  • GPL v3.0 or later
