What Startup Scenes Manager does

Startup Scenes Manager is a Pitiwazou add-on for handling the scenes that Blender opens with. It supports Blender 4.3 through 5.1, is GPL-licensed and includes documentation.

Licensing tiers exist for a single user and for teams of up to five or ten, so studios can standardize starting scenes across artists.

Key features

  • Startup scene management
  • Blender 4.3 to 5.1
  • Documentation included
  • Single and team licenses
