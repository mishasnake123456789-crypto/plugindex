What Blockout Pro does

Blockout Pro is a sculpting assistant for the early shaping stage. It generates shapes between two objects, which you can then edit, sculpt and reshape freely while keeping smooth transitions between forms.

A posing system lets you test stances and movement using simple primitives, and the workflow builds forms from primitives as a foundation for detailed sculpting. Character and creature artists who want to settle proportions before committing to detail can move quicker.

Key features

  • Dynamic bridging shapes between two objects
  • Free editing and sculpting of generated forms
  • Smooth transitions between forms
  • Posing system using simple primitives
  • Built around primitive-based blockouts
