What Light Array Tool does

Light Array Tool creates and manages many lights at once in Blender. It helps lighting artists and motion designers build studio setups, LED grids, rim lights and showcase lighting.

Lights are laid out as rows, grids or volumes with control over spacing, color, intensity and layout, including exact counts per axis and local or global alignment. The lights are parented to a controller light so they can be moved together, and a Remove Lights Array button deletes them. It works with Cycles and Eevee.

Key features

  • Rows, grids and volumes of lights
  • Spacing, color and intensity control
  • Controller light for moving the array
  • Remove Lights Array button
