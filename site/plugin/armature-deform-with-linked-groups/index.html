What Armature Deform with Linked Groups does

Armature Deform with Linked Groups, by Suchaaver, is aimed at mechanical rigs where one mesh is built from several separate pieces. It creates an armature deformation and assigns each bone's vertex group to the closest vertex island automatically.

An island is whatever Blender's select linked (Ctrl-L) would pick up. Bones with no island nearby get an empty vertex group, which is handy for control bones. Find it under Object, Parent. It works with Blender 4.2 LTS and newer.

Key features

  • Automatic vertex groups per vertex island
  • Uses select-linked definition of islands
  • Empty groups for control bones
  • Found under Object, Parent menu
  • Blender 4.2 LTS and newer
