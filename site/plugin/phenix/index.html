Runs particle emission, fluids, constraints and collisions on the GPU in Blender through WGPU compute shaders.

What Phenix does

Phenix is a GPU-native particle system for Blender. Emission, integration, neighbour lookups, constraints, fluids, collisions and procedures all run via WGPU compute shaders, using Vulkan, Metal or DX12.

Because the work happens on the graphics card, it can handle vastly more particles than a CPU-based pipeline. It is aimed at artists and technical directors who need dense particle effects, liquids or soft connected systems without long simulation times. Technical artists can use it to explore dense simulations.

Key features

  • GPU compute pipeline via WGPU
  • Vulkan, Metal and DX12 backends
  • Fluids, constraints and collisions
  • Far more particles than CPU pipelines
