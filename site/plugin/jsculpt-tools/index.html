What Jsculpt Tools does

Jsculpt Tools, by Jayanam, trims routine steps out of digital sculpting in Blender. Spheres, cubes and tori can be added directly in Sculpt Mode, aligned to the surface, with a mirror modifier when an axis is chosen.

Paint a mask and extract it as a new mesh with set thickness and offset, optionally voxel remeshed. Selected objects can be joined and remeshed for sculpting in one action. A retopology button creates a mesh snapped to the target, using a vertex or plane type with optional mirror and subdivision modifiers.

Key features

  • Add sphere, cube or torus in Sculpt Mode
  • Extract mesh from a mask with thickness and offset
  • Optional voxel remesh after extraction
  • Join and remesh selected objects
  • One-click retopology setup
