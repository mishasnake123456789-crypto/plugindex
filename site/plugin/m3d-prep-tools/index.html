What M3D Prep Tools does

M3D Prep Tools bundles bake-preparation steps for game artists. Name Tagger renames and sorts meshes into low-poly and high-poly bake families and moves them into target collections.

Mesh Group Hub looks after the MG1 (low) and MG2 (high) collections and offers a compare view and a retopology helper. The package also includes viewport coloring and FBX export for bake families. It streamlines the repetitive setup before baking normal maps. Having the preparation steps in a single place reduces mistakes that cause bad bakes, such as mismatched low and high poly names.

Key features

  • Name Tagger for low/high bake families
  • Mesh Group Hub with Compare View
  • Retopology helper
  • Viewport coloring
  • FBX export for bake families
