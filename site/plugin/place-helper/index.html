Blender add-on combining surface placement, drag duplication, brush scattering and physics-driven placement.

What Place Helper does

Place Helper gathers object placement tools into one Blender package. Objects can be dragged onto surfaces, duplicated, scattered with brushes or dropped using physics.

The Place Tool snaps objects to surfaces with normal alignment and collision detection, and Shift-drag duplicates them. Transform Pro moves objects by dragging in the viewport and extrudes geometry in Edit Mode. A scatter tool offers brush-based placement, and physics placement uses gravity and force fields. Set dressers and environment artists arrange props quickly.

Key features

  • Surface placement with normal alignment
  • Drag duplication
  • Brush-based scatter
  • Physics placement with gravity and force fields
