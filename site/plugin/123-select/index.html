What 123 Select does

123 Select is a very small Blender add-on by Fisch_Tu that lets the 1, 2 and 3 keys pick vertex, edge or face select mode even when you are in Object Mode.

The package is only about 2 KB, installs by drag and drop or from disk and asks for no special permissions and works with Blender 4.2 LTS and newer. It is released under the GNU GPL v3 or later. It is a simple shortcut for people who prefer number keys over mode buttons.

Key features

  • Keys 1, 2 and 3 switch select modes
  • Works in Object Mode
  • Supports Blender 4.2 LTS and newer
  • Tiny 2.1 KB package
  • No special permissions needed
