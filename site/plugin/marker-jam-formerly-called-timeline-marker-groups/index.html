What Marker Jam (Formerly Called Timeline Marker Groups) does

Marker Jam helps manage busy timelines. A panel in the Dope Sheet Editor saves chosen markers as named groups you can reuse.

Loading a group restores the markers with their original frame positions and camera bindings, and visibility can be toggled so you can hide markers without deleting them. Configurations can be imported and exported. Animators who mark several shots, takes or versions in one file will find it far tidier.

Key features

  • Save markers as named groups
  • Restore frame positions and camera bindings
  • Toggle group visibility
  • Import and export configurations
