Syncs Blender with Keyframe Pro so animators can drive reference footage playback from inside Blender.

What Keyframe Pro Sync does

Keyframe Pro Sync connects Blender to Keyframe Pro, helping animators who work against reference footage. Scrubbing and playback follow each other in both directions, and footage and offsets can be controlled without leaving Blender.

Clips are picked from a dropdown, and actions remember their assigned clip and switch to it automatically, with an option to pin one clip across actions. Bookmarks import as frame markers or, with a bone selected, as keyframes. One button matches the preview range to a clip's length. It simplifies reference-based animation.

Key features

  • Two-way scrub and playback sync
  • Footage dropdown with per-action clips
  • Pin a clip across actions
  • Bookmark import as markers or keyframes
  • Preview range matched to clip length
