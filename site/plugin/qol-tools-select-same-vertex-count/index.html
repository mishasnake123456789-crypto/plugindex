What Qol Tools: Select Same Vertex Count does

Spotting duplicate or related meshes among hundreds of objects is tedious. This small add-on from QOL Tools puts a Select same vertex count command into Blender's Select menu, so one click finds every object with the same number of vertices as the active one.

Results can be added to a multi-object selection already in place, and a wiggle room slider tolerates objects with a handful of extra vertices. It arrives in Blender 4.2's extension format, with documentation and a GPL license.

Key features

  • Adds a Select same vertex count menu entry
  • One-click selection by vertex count
  • Extends an existing multi-object selection
  • Wiggle room slider for near matches
  • Blender 4.2 extension format
