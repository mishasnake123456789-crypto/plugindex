What Ui Skin & Productivity Workspaces Layout does

This pack gives Blender's interface a light purple palette with golden text on functions and buttons. It also supplies a set of Productivity Workspaces.

The workspaces are for animation, modeling, texturing and rendering. The texturing one covers sculpting, texture painting and UV editing, while the rendering one includes compositing. Users wanting a refreshed appearance and ready-made layouts for each stage can load them directly. Switching tabs then gives a layout already arranged for the task.

Key features

  • Light purple UI with golden text
  • Animation and modeling workspaces
  • Texturing workspace with sculpt, paint and UV
  • Rendering workspace with compositing
