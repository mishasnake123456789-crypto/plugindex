What Pin Key does

Pin Key shows details about your selected keyframes on screen while you work in the Graph Editor. Frame number and value are tracked and displayed, so there is no need to open a sidebar panel to read them.

It works with Blender 3.0 through 4.3, is marked as Extension compatible, comes with documentation and is released under the GPL license. Animators polishing curves with precise values will appreciate instant feedback.

Key features

  • Shows frame number and value
  • Displays in the Graph Editor
  • Blender 3.0 through 4.3
