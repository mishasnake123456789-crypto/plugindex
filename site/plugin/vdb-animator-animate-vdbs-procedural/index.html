What Vdb Animator - Animate Vdbs Procedural does

VDB Animator builds and animates VDB scenes procedurally in Blender, handling up to 188 VDBs. Volumes animate in real time and changes appear directly in the viewport with no baking.

A Mountains function slides VDBs along mountain shapes and can create the mountains. Up to 188 turbulences per VDB continuously reshape it into timelapse clouds, explosions, fire and smoke, while generators duplicate and transform a VDB to produce cloud formations from a single source. It suits atmospheric and weather scenes.

Key features

  • Up to 188 VDBs animated procedurally
  • Real-time viewport results, no baking
  • Mountains function
  • Turbulence for smoke, fire and explosions
  • VDB generators for cloud formations
