What Light Master Pro does

Lazy3D's Light Master Pro is a creative lighting toolkit for Blender, packing 560 light textures, the complete lighting asset set, advanced placement tools and a Paint Mask workflow.

It supports both Cycles and Eevee, includes documentation and is distributed under the GPL license as a Blender Extension. It is meant for artists wanting a stock of light textures such as gobos and patterns, plus tools to position them in a scene.

Key features

  • 560 light textures
  • Complete lighting asset set
  • Advanced placement tools
  • Paint Mask workflow
  • Works with Cycles and Eevee
