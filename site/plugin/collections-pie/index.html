Blender pie menu for creating, nesting, isolating and moving objects between collections without using the Outliner.

What Collections Pie does

Collections Pie puts common collection chores into a pie menu in Blender. Instead of dragging things around the Outliner, you add collections to specific levels of the hierarchy, isolate objects, and shuffle objects between collections from one radial menu.

You can isolate everything in the active selection's collection without selecting each item, create a collection inside, below or beside the selection's parent, and send an object to the active collection or its parent. Blender's default collection menu is still included at the top. The menu can also be opened from the N panel, and documentation comes with it.

Key features

  • Add collections at chosen places in the outliner
  • Isolate the active selection's collection
  • Nest a collection inside or below another
  • Move objects to the active or parent collection
  • Default collection menu included at the top
