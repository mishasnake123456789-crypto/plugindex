Blender add-on that saves and switches between full scene states with thumbnails and batch-renders them.

What Renderscenes does

Renderscenes stores complete snapshots of a Blender scene so you can jump between setups quickly. Each state has a thumbnail, making variations easy to identify.

A snapshot records resolution, camera settings, materials, lighting, world settings, object transforms and visibility, modifier states and collection visibility. Several snapshots can be updated in one go, and the tool can create a RenderScene per camera or convert a camera into a scene. All scenes can then be rendered with whatever passes you need.

Key features

  • Save, restore and switch scene states
  • Captures camera, lighting, materials and visibility
  • Batch-update saved snapshots
  • One RenderScene per camera
  • Render all scenes with any passes
