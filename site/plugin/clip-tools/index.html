Blender add-on for motion tracking that bridges track gaps and quickly sets up camera and object solver constraints.

What Clip Tools does

Clip Tools, by K_Naoki, adds time-savers to Blender's Movie Clip workflow. Bridge Gap interpolates new marker positions across a missing or disabled stretch of a track, using your chosen interpolation, and a Join option bridges short enabled islands as part of the same gap.

The start frame can be set automatically from the sequence number in the footage filename. It also adds a Camera Solver constraint to the active camera without the extra objects of Setup Tracking Scene, and creates an Object Solver constraint with an ObjectTrack empty when a tracking object exists.

Key features

  • Bridge Gap interpolates missing markers
  • Join option across short islands
  • Start frame from footage filename
  • Camera Solver constraint on active camera
  • Object Solver setup with ObjectTrack empty
