What Ai Render - Stable Diffusion In Blender does

AI Render brings Stable Diffusion into Blender. It produces an AI-generated image from your scene and a text prompt, so a rough 3D layout can guide the final look.

Cloud rendering uses a free DreamStudio account, with nothing to install or code to run, while an optional local setup uses the Automatic1111 web interface for Stable Diffusion. Animation is supported too. Concept artists and designers can explore styles quickly from simple blockouts.

Key features

  • Prompt plus scene to AI image
  • Cloud rendering via DreamStudio
  • Optional local Automatic1111
  • Animation support
