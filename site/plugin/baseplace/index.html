What Baseplace does

Baseplace provides ready-made terrain and surface relief for base meshes in Blender. Twenty-four heightmaps are included to displace geometry, giving instant variety.

Displaced areas can be removed in weight paint mode, so you can keep the effect only where you want it, and adjustable modifiers let you tune the result. It is distributed as a Blender Extension with documentation. Handy for rocks, landscapes and decorative surfaces. Combining several heightmaps on different areas lets you build varied shapes from one starting mesh.

Key features

  • 24 included heightmaps
  • Erase displacement in weight paint mode
  • Adjustable modifiers
  • Blender Extension with documentation
