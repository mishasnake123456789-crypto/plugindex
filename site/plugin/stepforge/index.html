Blender add-on for importing and exporting STEP/STP CAD files, written in pure Python.

What StepForge does

StepForge, by Blenderhead-engineer, reads and writes STEP (STP) files in Blender, a common format for exchanging CAD models. It is implemented in pure Python. It is listed under Import-Export.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.

Key features

  • STEP/STP import
  • STEP/STP export
