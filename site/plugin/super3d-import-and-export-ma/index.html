What Super3D Import & Export .Ma does

Super3D Import & Export .Ma adds Maya ASCII support to Blender. Dedicated File menu entries handle import and export, and conversion runs on the Super3D cloud service, so a Maya installation is not needed.

Import preserves mesh geometry with baked skinning, hierarchy, naming and baked F-curves where they can be resolved. Export writes polygon meshes into a .ma file. It is a practical bridge for teams that exchange assets between Maya and Blender.

Key features

  • One-click import and export from the File menu
  • Cloud conversion, no Maya install needed
  • Keeps baked skinning, hierarchy and naming
  • Baked F-curves where resolvable
  • Exports polygon meshes to .ma
