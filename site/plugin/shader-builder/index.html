A Blender add-on that derives normal, roughness and displacement maps from a single diffuse texture.

What Shader Builder does

Shader Builder builds a full set of surface maps from one image in Blender. Given a diffuse texture, it generates normal, roughness and displacement maps and creates the material automatically, saving a trip through external texture software.

Results preview in real time in the viewport, with and without lighting, and post-processing such as gamma and blur can be set per map. Map size and type are customizable, and the finished maps can be baked and saved to disk for reuse. Artists with only a photo or flat color texture who need a quick PBR approximation will find it convenient.

Key features

  • Normal, roughness and displacement from a diffuse map
  • Automatic material creation
  • Real-time viewport preview
  • Per-map gamma and blur
  • Bake and save maps to disk
