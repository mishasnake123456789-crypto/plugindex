What Simple F-Curves: This Tool Makes Animation Easier does

Simple F-Curves lets animators shape curves without opening the Graph Editor, which serves only as a preview. In the Timeline, click an icon and move the mouse to bend the curve, with no handle hunting required.

The preview zooms into the relevant part of the curve automatically, changes apply to all selected keyframes at once, and X, Y and Z behavior stays in sync whatever the curve direction. Cinema 4D or Maya mode and Armature mode alter keyframe deselection. Extra tools include Keyframe Shaping, Smoothen, Exaggerate, Channel Cleanup, Auto-Bounce, Quick noise and Extrapolate.

Key features

  • Shape F-curves from the Timeline
  • Live preview with automatic zoom
  • Bulk edits on selected keyframes
  • Cinema 4D, Maya and Armature modes
  • Quick noise, Auto-Bounce, Smoothen and more
