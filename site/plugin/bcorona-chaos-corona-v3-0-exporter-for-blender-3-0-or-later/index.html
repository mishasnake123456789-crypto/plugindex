What Bcorona - Chaos Corona V3.0 Exporter For Blender 3.0 Or Later does

BCorona is an unofficial exporter add-on that moves Blender scenes into the Chaos Corona renderer's version 3.0 Standalone scene format. It is developed by Odilkhan for Windows and requires Blender 3.0 or later.

A converter translates basic Cycles shaders into Corona materials, default material presets help build new ones, and basic Geometry Nodes export is supported. Documentation is provided. It suits artists who model in Blender but render with Corona.

Key features

  • Exports to Corona 3.0 Standalone format
  • Cycles to Corona material converter
  • Basic Geometry Nodes export
  • Default Corona material presets
