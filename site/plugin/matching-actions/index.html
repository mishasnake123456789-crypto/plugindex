Blender add-on that offsets one Action to begin where another ends, aligned on chosen bones, for smoother NLA blends.

What Matching Actions does

Matching Actions solves a common headache when stringing together Mixamo or mocap clips in Blender: the second clip rarely starts where the first one finished. This add-on shifts one Action so its start lines up with the end of another, using bones you select as the reference, such as a planted foot.

The workflow is quick: choose the rig, pick both actions and the bones, and press Match. You can match position only or include Z rotation so the character faces the same way. A copy of the original action is saved automatically. The panel lives in the N sidebar, and it targets Blender 3.6 to 4.2.

Key features

  • Aligns one Action to the end of another
  • Reference bone selection, such as a planted foot
  • Optional Z rotation matching
  • Automatic backup of the original Action
  • Panel in the N sidebar
