What Geonode To Shapekey does

Jan-Hendrik-Müller's Geonode To Shapekey bakes animated Geometry Nodes setups down to shape key animation. The motivation is glTF export, since that format carries shape keys but cannot carry Geometry Nodes.

At chosen time steps it copies the selected GeoNodes object and applies its modifiers, then combines the copies into shape keys, keyframing absolute or relative keys automatically. Renaming and scene cleanup are part of the conversion.

Key features

  • Converts animated Geometry Nodes to shape keys
  • Duplicates the object at set time steps
  • Merges results into shape keys
  • Absolute or relative shape key keyframing
  • Cleans up and renames the scene
