What Batch Bake Addon does

Batch Bake streamlines the preparation of complex environments. Select models, choose bake type and resolution, and it optimizes UVs and creates game-friendly versions of the models with baked textures.

Texture sets and the resulting models export automatically to a folder you designate. It runs on a selection and lets you set options before baking. Handy for game asset pipelines. Among its capabilities are game-friendly model versions, UV optimization and texture baking and automatic export to a folder.

Key features

  • Game-friendly model versions
  • UV optimization and texture baking
  • Automatic export to a folder
  • Choice of bake type and resolution
