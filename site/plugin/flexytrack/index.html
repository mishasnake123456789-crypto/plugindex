Rigs bone chains using Damped Track instead of physics, so following bones lag the main bone for natural delay.

What FlexyTrack does

FlexyTrack automates a simple follow-through rig in Blender. Chains of bones are set up with Damped Track constraints instead of physics, so animating the main bone makes the following bones trail it with a slight offset.

The resulting delay gives tails, antennae, cables and similar moving elements a natural feel while remaining easy to control and bake. Riggers and animators avoid heavy simulations for secondary motion.

Key features

  • Physics-free Damped Track rigging
  • Delay along the bone chain
  • Automated chain setup
  • Main bone drives following bones
