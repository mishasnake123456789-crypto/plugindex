What Auto-R Addon does

A.T Design Studio's Auto-R creates rotation animation for many object types in Blender. It is built on geometry nodes, but you don't have to understand them: select something in the right 3D view panel and press Rotate.

More than twenty asset types are included, and parent objects remain unaffected. Documentation is provided. Motion designers who need spinning logos, gears, props or ornaments can add motion in seconds. Because it uses a geometry nodes setup, the result can be tuned further by anyone comfortable with nodes.

Key features

  • One-button Rotate
  • Geometry Nodes without node knowledge
  • 20+ included asset types
  • Parent objects unaffected
  • Documentation included
