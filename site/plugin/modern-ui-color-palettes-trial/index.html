What Modern UI Color Palettes Trial does

This is the trial version of Modern UI Color Palettes, an extension by Vakago Tools for After Effects and Premiere Pro. It lets designers test palette and interface-colour features before deciding on the full release.

Functionality is limited and the trial expires after 60 days. It installs separately under Window > Extensions with the label TRIAL. Compatible hosts include After Effects 18.0, Premiere Pro 15.0, Illustrator 25.4, InDesign 16.0 and Dreamweaver 21.0 or newer.
