Blender add-on for non-destructive model splitting with connectors for 3D printing.

What EasySlice Print does

EasySlice Print, by Rafael-Omodei, splits a model into pieces without altering the original and adds connectors for assembling the printed parts. It is listed under Mesh and Object.

It is open source under GPL-3.0-or-later and needs Blender 4.2.0 or newer.

Key features

  • Non-destructive model splitting
  • Connectors for 3D printing
  • Open source, GPL-3.0-or-later
  • Requires Blender 4.2.0 or newer
