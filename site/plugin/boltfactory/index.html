Blender add-on that generates bolts and nuts with configurable thread, head and drive types.

What BoltFactory does

BoltFactory makes fasteners in Blender, both bolts and nuts. A panel has a dropdown to pick the type and number fields for dimensions, with choices for thread, drive bit and head style.

A limited set of metric presets is included, though the developer advises checking them before using them in production. A Change Bolt entry in the context menu reloads the original parameters and rebuilds the mesh. Parts are produced at real-world dimensions. Mechanical modelers and product visualization artists can add convincing hardware without sculpting threads manually.

Key features

  • Bolts and nuts with thread and head options
  • Panel with type dropdown and numeric inputs
  • Some metric presets
  • Change Bolt regenerates the mesh
  • Real-world dimensions
