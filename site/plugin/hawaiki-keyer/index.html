What Hawaiki Keyer does

Hawaiki Keyer pulls keys from green and blue screens in After Effects, Premiere Pro and DaVinci Resolve. Version 5 adds AI-based face and object tracking and real-time edge tracking, which can drive garbage mattes that follow the subject.

A secondary keyer acts as a second pass, handy for hair. Screen Clean analyses the backing to even out defects, and edge controls include Background Match, Edge Replace, Fine Edge, Edge Blend, Premultiply and Light Wrap. Spill suppression has its own Spill Map view, with Crop, Outer Matte and Matte Cleaner options, plus colour correction and white balance. GPU acceleration supports real-time playback.

Key features

  • AI face and object tracking for moving garbage mattes
  • Secondary keyer for hair
  • Screen Clean evens out the backing
  • Edge tools including Light Wrap
  • Spill Map view and GPU acceleration
