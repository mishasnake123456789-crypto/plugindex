What Tiles does

Tiles is an Nx Color effect for DaVinci Resolve that repeats an image across the frame as a grid of copies. It is meant for building patterns and backgrounds, as well as for creative motion graphics work that relies on repetition.

The developer describes it as flexible, and it is available for macOS, Windows and Linux, working with DaVinci Resolve 20 and 19. Version 1.0 launched in April 2025. Editors and motion designers can use it to create wallpapers, kaleidoscopic looks or stylized transitions without leaving the Resolve timeline.

Key features

  • Tiles an image into repeating patterns
  • Pattern generation for backgrounds
  • Suited to creative motion graphics
  • Runs on macOS, Windows and Linux
