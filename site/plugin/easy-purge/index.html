Blender add-on that removes unused orphan data recursively, with preview and history.

What Easy Purge does

Easy Purge cleans .blend files by deleting unlinked data. It loops through the project to catch deeply nested orphans and reports what was removed.

It tracks 12 categories including meshes, materials, textures, images, armatures, actions and node groups, with a Dry Run Preview before deleting and per-category toggles in the N-Panel. Name exclusion ignores chosen keywords, Auto-Purge on Save runs silently, and a history log keeps the last 50 purges with disk space saved.

Key features

  • Recursive purge of orphaned data
  • Dry Run Preview
  • Per-category toggles and name exclusion
  • Auto-Purge on Save and history log
