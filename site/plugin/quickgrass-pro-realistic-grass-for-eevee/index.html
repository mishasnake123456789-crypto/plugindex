What Quickgrass Pro (Realistic Grass For Eevee) does

Quickgrass Pro is a Blender add-on by SoyKhaler that fills scenes with grass and other vegetation. Meadows, fields and natural landscapes can be built without manually placing or modeling plants.

You add the grass in a few clicks and then adjust the result to fit your scene. The output works in both Eevee and Cycles, so it fits real-time previews as well as high-fidelity final renders. Documentation is included and the add-on is released under the MIT license.

Key features

  • Generates grass and vegetation in a few clicks
  • Works in both Eevee and Cycles
  • Suited to meadows, fields and landscapes
  • Result stays editable after creation
