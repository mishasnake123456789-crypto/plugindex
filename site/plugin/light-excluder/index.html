What Light Excluder does

Light Excluder simplifies setting up light inclusion and exclusion in 3ds Max. Select the lights and the object concerned, press the button, and the object is included in or excluded from those lights.

This avoids opening the include and exclude dialog for each light and hunting through a long object list. Lighting artists who need to keep a prop or character out of certain lights, or limit lights to specific objects, can apply changes in seconds. It is free, currently at version 2.3.5, and made by Chuggnut.

Key features

  • Includes or excludes objects from selected lights
  • Select lights and object, then press a button
  • Runs inside 3ds Max
  • Version 2.3.5
