What Flatten Layers 2 does

Flatten Layers 2, by MotionCodes, simplifies busy timelines by merging groups of layers into one. Flattening happens in the background, so you can keep working, and no pre-render is required.

Output is a lossless PNG sequence generated automatically, so there is no quality loss, and you can toggle between the original and flattened layers at any time. The process is simple: select layers, set frame rate and quality, and click Create. A custom temp folder can be used, and the PNG sequence folder path can be opened or changed.

Key features

  • Flattens layers without pre-rendering
  • Lossless PNG sequence output
  • Background processing while you work
  • Toggle between original and flattened layers
  • Custom temp folder and path options
