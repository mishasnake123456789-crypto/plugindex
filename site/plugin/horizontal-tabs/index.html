What Horizontal Tabs does

Horizontal Tabs moves sidebar panels into the header so they appear as tabs across editors. You can also assemble custom headers that behave like native Blender headers.

Headers can be laid out like a workspace with labels and separators, saved as presets for different workflows, and stacked to fit more tools. Panels can be renamed and resized individually. It suits users who want more viewport space and faster access to frequently used panels.

Key features

  • Sidebar panels mirrored into headers
  • Custom headers with labels and separators
  • Presets per workflow
  • Stackable headers, rename and resize panels
