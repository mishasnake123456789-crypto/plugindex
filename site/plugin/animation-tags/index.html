What Animation Tags does

Animation Tags helps animators keep track of large libraries of actions in Blender by labeling each with tags.

Any animation can carry several tags, and you can build your own tag hierarchies, for instance by character, by action type or by both. Search and filter then narrow the list to the animation you need. It works with Blender 3.0 through 5.0 and comes with documentation. Useful for studios and game teams with many actions.

Key features

  • Multiple tags per animation
  • Custom tag hierarchies
  • Search and filter animations
  • Organize by character, action type or both
  • Blender 3.0 to 5.0
