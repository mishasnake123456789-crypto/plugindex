Blender add-on that turns an image into a displaced relief mesh and sets up a depth map compositor pipeline.

What Bas Relief does

Bas Relief converts a picture into a carved-style 3D surface in Blender. Running it produces a finely divided plane whose Displace modifier is already set up, with the aspect ratio matching your source image.

An Adjust Last Operation panel exposes the subdivision and other settings, and a depth map compositor pipeline can be built to render the result. It's handy for coin, plaque, emblem and texture-style relief work from artwork or photos.

Key features

  • Image to displaced relief mesh
  • Subdivided plane with configured Displace modifier
  • Aspect ratio matches the image
  • Adjustable settings after running
  • Depth map compositor pipeline
