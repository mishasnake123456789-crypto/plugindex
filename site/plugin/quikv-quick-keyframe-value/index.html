What Quikv - Quick Keyframe Value does

Quikv speeds up precise animation editing. Double-click a keyframe and a dialog lets you enter its exact value, with no need to move the playhead first.

It finds related channels from the selected keyframe so several can be edited together, and keyframes can be added or removed per axis without destroying other data. Jump Selection moves between keyframes without reopening the dialog, an eye icon toggles a live viewport preview, and per-channel undo restores the original state. It is a time saver for animators who tune curves numerically.

Key features

  • Double-click keyframe value editing
  • Multi-channel editing with auto-detected channels
  • Per-axis add and remove keyframes
  • Live preview toggle and per-channel undo
