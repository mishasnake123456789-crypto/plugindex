What Extra Mesh Objects does

Extra Mesh Objects lengthens the list of shapes available in Blender's Add > Mesh menu. Once part of Blender 4.1, it is now a separate extension for Blender 4.2 LTS and later.

New primitives appear directly in the 3D viewport's Add menu, so they are created like any default shape. Version 0.4.1 introduced an equilateral grid object. The extension asks for no special permissions and is released under GPL version 3 or later. Modelers who regularly need unusual starting shapes can save time compared with building them by hand.

Key features

  • Extra primitives in View3D Add > Mesh
  • Equilateral grid object in 0.4.1
  • For Blender 4.2 LTS and newer
  • Needs no special permissions
