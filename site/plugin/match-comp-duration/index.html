What Match Comp Duration does

Match Comp Duration, from Salt Media, is an After Effects script for the tedious job of lining up durations in nested compositions. Select layers or pre-comps, click, and their lengths follow the active composition, including everything nested inside them.

A second command matches the current time indicator instead, and Set Custom Duration lets you type any length. Nested locked layers are included, and layer timing is changed without shifting where layers sit. Nested comps can also be resized to match the current one, choosing fit, width or height. Anyone who regularly extends a project and then chases short pre-comps will cut the busywork considerably.

Key features

  • Match selected items to comp duration in one click
  • Match to the current time indicator
  • Custom duration option
  • Includes nested and locked layers to the deepest pre-comp
  • Resize nested comps with fit, width or height
