What Visual States does

From Leandro Salerno comes Visual States, a panel for After Effects aimed at managing several versions of one composition. Layer visibility is stored as named states that load instantly with a click, avoiding duplicate comps.

Unlimited states can be saved per composition, multi-selected and deleted together. Include and Exclude Layers edits specific or all states without reloading, Comp Navigator moves between comps that have states, and states can be copied between comps. They are stored in a plain .visualstates.json file next to the .aep for sharing. The panel docks, and renaming or reordering layers does not break saved states.

Key features

  • Unlimited named states per comp
  • Include/Exclude layers across states
  • Comp Navigator for comps with states
  • Copy states between comps
  • Plain JSON storage beside the project
