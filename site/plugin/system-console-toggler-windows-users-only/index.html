What System Console Toggler (Windows Users Only) does

System Console Toggler is a convenience tool for add-on developers on Windows, putting the system console toggle in Blender's top header.

A preferences panel adds a settings button near the operator, the button name can be changed, and a keymap shortcut can be assigned for hotkey access. Documentation is provided by the developer.

Key features

  • Toggle the Windows system console
