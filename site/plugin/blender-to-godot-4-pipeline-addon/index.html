What Blender To Godot 4 Pipeline Addon does

This pipeline add-on prepares game assets inside Blender and moves them to Godot using the GLTF standard along with a companion Godot-side addon.

Colliders, multimesh, scripts, custom materials and NavMeshes can be configured in Blender, with nested colliders and automatically generated primitive colliders. PBR materials and animation carry across. Godot developers can shorten asset import setup. Doing the setup before export reduces the need to fix imported assets by hand inside the engine.

Key features

  • Collisions, multimesh, scripts and NavMeshes
  • Nested and automatic primitive colliders
  • PBR materials and animation via GLTF
  • Matching Godot-side addon
