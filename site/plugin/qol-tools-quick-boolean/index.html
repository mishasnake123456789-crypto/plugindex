What Qol Tools: Quick Boolean does

Qol Tools: Quick Boolean speeds up boolean operations in Blender. Select the objects you want to combine with the active object, right-click, and choose the entry; the operation runs using Blender's own boolean algorithm.

Several selected objects are handled in one go. A material transfer option creates material slots on the active object and assigns them so combined parts keep their materials. It trims repetitive modifier setup for hard surface modelers.

Key features

  • One click from the right-click menu
  • Multiple selected objects in one pass
  • Material transfer to the active object
  • Built-in boolean algorithm
