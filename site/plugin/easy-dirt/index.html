What Easy Dirt does

Easy Dirt is a Blender plugin for adding grime to specific areas of a model. Pick an object and an image, then sketch a bounding box in Edit Mode to mark where the dirt should appear in 3D space.

It is applied to the active material, with a blend parameter for mixing against the original texture, and noise scale, noise detail and factor sliders that govern the multiplicative noise in the blend. A quick way to add localized staining and wear.

Key features

  • Dirt images in localized 3D areas
  • Bounding box placement in Edit Mode
  • Blend parameter for mixing
  • Noise scale, detail and factor controls
