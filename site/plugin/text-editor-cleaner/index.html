Cleans up Blender's text editor with menu commands to delete text files in bulk and switch fake users on or off.

What Text Editor Cleaner does

Text Editor Cleaner is a Blender add-on by KS that tackles the clutter of leftover text datablocks. Its commands sit right in the text editor menu, so housekeeping takes a click instead of a trip through the outliner.

You can remove every text file, remove all except the one currently open, or delete those without a fake user. Two more commands turn fake users off or on for all text files at once. It helps scripters and add-on developers who accumulate many scratch files in a project.

Key features

  • Delete all text files in one click
  • Delete all except the open file
  • Delete text files lacking a fake user
  • Turn fake users on or off for every text file
  • Commands placed in the text editor menu
