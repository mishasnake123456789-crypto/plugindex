What Pose Library Thumbnails [Ver2.0.4~] does

Pose Library Thumbnails is a plugin from Bookyakuno that gives the pose library pictures. Instead of reading pose names, you choose from a list of thumbnails and apply the pose to the selected bones.

Thumbnails are rendered automatically from the menu, with actions for creating a pose, rendering, and updating either. Output path, file format and resolution are configurable. Animators with big pose collections find it much faster to browse.

Key features

  • Automatic thumbnail rendering
  • Create and update poses from the menu
  • Configurable path, format and resolution
  • Visual pose selection
