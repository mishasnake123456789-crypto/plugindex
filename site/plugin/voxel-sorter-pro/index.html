What Voxel Sorter Pro does

Voxel Sorter Pro takes the voxel effect, which rebuilds footage as a tiny tiltable, lightable world of cubes, and adds camera-style finishing tools. It works in After Effects, DaVinci Resolve and Premiere Pro.

On top of the base tilt, lighting and 3D pixel sorting, the Pro edition adds depth of field and motion blur. It can also generate a depth pass, which functions in 16-bit. Blend parameters let the effect fade in and out cleanly, and GPU memory usage was reduced for DaVinci Resolve's 16-bit paths.

Key features

  • Footage rebuilt as a lightable voxel world
  • Depth of field in the Pro edition
  • Motion blur in the Pro edition
  • Depth pass generation in 16-bit
  • Blend parameters and lower Resolve GPU memory use
