Blender add-on that types text onto the screen like a retro terminal, fed from a text file you write.

What Text Typer 3000 does

Inlet's Text Typer 3000 recreates the look of typing seen in vintage terminals and hacker movies. Rather than keying each letter, write a text file, adjust a few values and press the buttons; the words type themselves.

It supports Blender 2.93 through 5.0, ships with documentation and is GPL licensed. Motion designers building tech-flavoured titles, UI shots or code-on-screen scenes can create the effect quickly and revise it just by editing the file.

Key features

  • Terminal-style typing effect
  • Driven by a text file
  • Adjustable values and buttons
  • Blender 2.93 to 5.0
  • Documentation included
