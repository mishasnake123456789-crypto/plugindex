What Styriam Icc Image Compressor does

Styriam ICC Image Compressor is a Blender plugin that cares about color accuracy and file size. It can embed a display color profile, or convert images to sRGB, so they look the same across applications that honor profiles.

Profiles can be attached to WebP, JPEG2000, TIFF, JPEG and PNG files, and JPEG and PNG can also be converted. Size is reduced with OptiPNG or MozJPEG, and animations can be exported as GIF. Taken together, these options help artists deliver files that look consistent on different displays while keeping download sizes small for the web or clients.

Key features

  • Embed ICC profiles or convert to sRGB
  • Supports PNG, JPEG, TIFF, JPEG2000 and WebP
  • OptiPNG and MozJPEG optimization
  • GIF export for animations
