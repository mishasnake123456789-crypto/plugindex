What Noise Nodes does

Noise Nodes expands Blender's shader editor with fourteen custom nodes for procedural patterns. They include Voxel, Perlin, Crackle, Fractal and Step noise types.

Once installed, they are listed in the shader editor's Add Node menu in a Noise Nodes group. No special permissions are needed, the license is GPL v3 or later, and community contributions are accepted through GitHub issues. Material artists building procedural textures get more pattern choices than the built-in noise node offers.

Key features

  • 14 custom noise nodes
  • Voxel, Perlin, Crackle, Fractal and Step noise
  • Appears in the Add Node menu
  • Open to community contributions
