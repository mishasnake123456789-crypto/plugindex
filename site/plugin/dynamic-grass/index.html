What Dynamic Grass 🌱 does

Dynamic Grass is a Blender plugin for living grass. One click adds a grass field to the selected object, and with dynamics enabled the blades react when objects or characters pass through.

Density, length and physical properties can be customized, and several grass types are available. It suits scenes where characters or vehicles move through meadows and need believable interaction. Because the field is built on the surface of any chosen object, it is easy to cover terrain, rooftops or props with interactive vegetation.

Key features

  • One-click grass field setup
  • Reacts to collisions with objects and characters
  • Adjustable density, length and physics
  • Multiple grass types
