Switches multiple assets in Blender based on the active collection, with a thumbnail picker.

What Item Swapper does

Item Swapper lets you change which asset appears in a given place by switching collections, rather than replacing objects by hand. It is meant for showing assets in a particular location, such as furniture variants in a room.

An interactive submenu lets you pick an asset by clicking its thumbnail, and thumbnail renders are stored through the Item Library add-on. Any number of collections can be used with detailed adjustments, and documentation is included. Good for layout and visualization work with interchangeable props.

Key features

  • Swaps assets by collection
  • Thumbnail-click selection submenu
  • Thumbnail storage via Item Library add-on
  • Unlimited collections
