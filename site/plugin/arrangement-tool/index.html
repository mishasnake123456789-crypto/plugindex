What Arrangement Tool does

Arrangement Tool places objects in neat layouts instead of moving them one by one. Choose circular, spiral, linear, grid or random scatter, and set properties for each from a dedicated sidebar tab.

Circles take a customizable radius, spirals adjustable height and radius, lines a user-defined length, and grids rows, columns and spacing. You can arrange whatever is selected in the viewport, or every object in a collection you name. Good for layouts like columns, display shelves, seating or radial patterns.

Key features

  • Circular, spiral, linear, grid and random styles
  • Adjustable radius, height, length and spacing
  • Works on selection or a collection
  • Dedicated sidebar tab
