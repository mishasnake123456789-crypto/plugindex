What Crossphere Bokeh does

Crossphere Bokeh creates out-of-focus bokeh blur in After Effects for artists who want to control precisely where the image is sharp. It is built around a focal distance control, with the range widened in version 1.4.0 to span -1 through 2.

Two focus points can be set and interpolated between, and a composite mode and a Use Focus Point switch select how the result is combined. Edge handling is a strong suit, with Edge Behavior, Remove Edge Leak and Detect Edge Threshold parameters, plus a threshold for the bokeh itself. It supports Apple M1 and works with After Effects CS6 through 2025.

Key features

  • Focal Distance range from -1 to 2
  • Two focus points with interpolation
  • Composite Mode and Use Focus Point options
  • Edge Behavior, Remove Edge Leak and threshold
  • Apple M1 support; CS6 through 2025
