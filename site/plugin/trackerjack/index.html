What Trackerjack does

Trackerjack carries a tracked shot from Adobe After Effects into Blender. An export panel in After Effects uses its built-in 3D Camera Tracker and writes the tracking data to a JSON file.

A Blender import panel reads that file and recreates the tracked camera and its animation, the background footage, the point cloud as points or empties, and planes. The matched scene lets compositors and 3D artists add CG elements to footage tracked in AE.

Key features

  • After Effects export panel using its 3D Camera Tracker
  • JSON file transfer
  • Recreates tracked camera and animation
  • Imports background footage, point cloud and planes
