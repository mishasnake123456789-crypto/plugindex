What Turbo Tools X - Blender 5+ does

Turbo Tools X is a Blender add-on from 3d illusions, rebuilt for Blender 5 and later. It automates render setup, applies advanced denoising, removes temporal flicker and publishes unlimited compositions without re-rendering.

Turbo Render builds sophisticated denoising networks from a few artist-friendly options, so fewer samples render quicker yet keep more detail than ordinary denoisers. Temporal Stabiliser cleans flicker out of animations while publishing, sidestepping render times that might run up to 40 times longer, and it works non-destructively on real renders.

Key features

  • Automated render setup with few options
  • Advanced denoising networks for lower samples
  • Temporal Stabiliser removes animation flicker
  • Non-destructive publishing of unlimited compositions
  • Built for Blender 5 and later
