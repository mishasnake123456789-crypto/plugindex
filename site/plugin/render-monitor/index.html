FreeBlender

Blender add-on that sends render status updates to Discord so you can track renders remotely on mobile or desktop.

What Render Monitor does

Render Monitor lets you leave a machine rendering and check progress from elsewhere. It posts live updates through a Discord bot webhook to your phone or computer.

Each machine gets a Computer ID, so several computers can be watched at once, and the messages carry the essential render information. Mobile and desktop notifications keep you informed. Documentation and a step-by-step video guide help with setup. Freelancers and studios with long render jobs benefit most.

Key features

  • Real-time render status updates
  • Computer ID for each machine
  • Monitor multiple computers
  • Discord webhook integration
  • Documentation and video guide
