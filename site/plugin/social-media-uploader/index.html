What Social Media Uploader does

Social Media Uploader lets you publish from within Blender. Rendered videos go straight to YouTube, TikTok and Instagram, and an Upload to All Platforms option covers all three.

A smart render check can render automatically before uploading and handles default output paths such as //tmp/. Metadata fields such as title and multi-line description are provided, per-platform render profiles set suitable output, and upload progress is displayed. Creators posting animation clips regularly can skip the export-and-upload routine.

Key features

  • One-click upload to YouTube, TikTok, Instagram
  • Upload to All Platforms option
  • Auto-render before upload
  • Title and description fields
  • Per-platform render profiles and progress display
