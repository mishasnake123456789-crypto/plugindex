What Triaxis Modeler does

Triaxis Modeler uses orthogonal projection modeling. One click creates three projection planes, and you draw 2D shapes on them with Blender's native tools.

The shapes are extruded into 3D volumes and boolean intersections carve out the final mesh. This approach suits blueprint-based modeling of vehicles, tools and mechanical shapes from reference drawings. Highlights cover one-click three-plane projection setup, draw shapes with native Blender tools, extrusion into 3D volumes and boolean intersection carving.

Key features

  • One-click three-plane projection setup
  • Draw shapes with native Blender tools
  • Extrusion into 3D volumes
  • Boolean intersection carving
