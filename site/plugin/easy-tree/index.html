Blender add-on for generating procedural trees with Geometry Nodes using presets and modular components.

What Easy Tree does

Easy Tree builds procedural trees in Blender without any hand-wired nodes. A single click makes an object driven by the Simple Tree Generator node group.

Modular Geometry Nodes components add features such as Simple Wind Effects for swaying and Branch Generators for branching structure. Custom Leaf Support lets any mesh object serve as a leaf, and presets provide quick starting points while the node group remains open for exploration. Environment artists and game developers can populate scenes with varied trees.

Key features

  • One-click tree generator
  • Wind effect and branch generator modules
  • Any mesh as a leaf
  • Preconfigured presets
