Compact Blender extension that renders a chosen frame or range straight from the Output panel as a background task.

What Frame Range Renderer does

Frame Range Renderer adds simple controls to render chosen frames from Blender's Output panel. You can render single frames, a range, or both, and the work runs as a background task so the interface remains usable.

Images are written to disk. The extension is only about 7.9 KB and licensed under the GNU GPL. It's useful for re-rendering just the frames that failed or changed in a long animation.

Key features

  • Render individual frames or ranges
  • Controlled from the Output panel
  • Runs as a background task
  • Writes images to disk
  • About 7.9 KB
