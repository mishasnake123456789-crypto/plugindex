3ds Max review script for validating, rejecting and rating scene objects with comments, annotations and an HTML report.

What Rate It does

Rate It is a review tool for 3ds Max that lets you evaluate objects in a scene, validate or reject them, and give ratings. A comment box attaches notes to each object, which helps when feedback has to be passed on to others.

Version 1.1 added an annotation mode, where you click an object to add a note, and a snapshot mode that records several views of an object, annotations included. The finished review publishes as an HTML file for sharing. The interface is light, and installation to a toolbar or keyboard shortcut goes through Customize User Interface. Useful for art directors and team leads.

Key features

  • Validate or reject and rate objects
  • Comment box per object
  • Annotation mode and multiple snapshots
  • Publishes the review as an HTML file
  • Light interface
