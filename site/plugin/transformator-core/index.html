What Transformator - Core does

Transformator - Core handles transform transfer in Blender. Copy a transform from a bone or object and paste it onto another, either as a global transform or relative to the source, on a single frame or across an animation.

It can copy from one element to many, gives per-axis control over what is pasted and offers a temporary pivot for extra flexibility. Animators use this kind of tool for attaching props, re-parenting and fixing alignment between rig parts and scene objects.

Key features

  • Copy and paste between bones and objects
  • Global and relative transform modes
  • Single frame or over-time transfer
  • Per-axis control
  • Temporary pivot
