Blender add-on for animating brick-style models with Flight, Drop and Snap Build modes and no rigging.

What Brick Animate does

Brick Animate animates toy-brick style scenes in Blender without rigs. Select your models, choose a mode and watch the live preview.

Flight, Drop and Snap Build modes cover assembly sequences, exploded views and effects such as reveals. Snap Build can animate from cloud, ring, cube or line shapes. The interface is clean with intuitive controls. It is suited to explainer animations and creative building sequences. Because no rigging is involved, even complicated builds with many separate pieces can be animated quickly.

Key features

  • Flight, Drop and Snap Build modes
  • Cloud, ring, cube and line start shapes
  • Live preview
  • No rigging required
  • Assembly and exploded view animation
