What Simple Bevel Manager does

Simple Bevel Manager gives Blender users a tidier way to handle bevels on complex models. Edges are organized into groups, and each group keeps its own non-destructive bevel settings.

Bevels can be added without ever visiting the Modifiers panel, and individual groups can be selected later for adjustment. A quick Shape control sets the bevel profile, and further options such as weight handling sit in the same interface. Hard-surface modelers juggling many different bevel widths on one object will find it the most useful.

Key features

  • Edge-group approach to multiple bevels
  • Add bevels without the Modifiers panel
  • Select bevel groups on complex models
  • Quick profile Shape setting
