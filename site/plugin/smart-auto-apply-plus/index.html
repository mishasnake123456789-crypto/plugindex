What Smart Auto Apply Plus does

Smart Auto Apply Plus handles the routine of applying transformations in Blender. From the N-panel you can apply location, rotation, scale and origin, and an auto-apply option performs these adjustments in real time as you model.

The default origin auto-apply waits until you adjust the active object and applies when you pause. An 'On selected' option applies the origin instantly to any object you pick, and 'Apply on mode change' does it when switching modes. It helps prevent scale and origin problems before export or modifiers.

Key features

  • Apply transform, rotation, scale, origin
  • Real-time auto-apply while modeling
  • On selected origin application
  • Apply on mode change
