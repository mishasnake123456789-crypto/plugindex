What Lighter Addon does

Lighter Addon, by morelewd, generates lighting procedurally inside Blender. Select an object, press Light it up! in the add-on panel, and a lighting setup is generated around it, which you can then adjust to try many looks quickly.

Version 2.0 introduced a presets system, translation in local space and plug-and-play gobos. The lighter object can be moved freely for placing lights once the point-to-object option is removed. Documentation is included, making it approachable for people who want good lighting without building rigs from scratch.

Key features

  • One-button lighting setup for a selected object
  • Adjustable parameters for quick variations
  • Presets system (version 2.0)
  • Plug-and-play gobos
  • Freely movable lighter object
