Exports a single .glb file while keeping textures as separate image files on disk.

What GLB External Textures does

GLB External Textures is a Blender add-on that changes how glTF binary files are written. Instead of packing every image into the .glb, the textures stay next to it as normal files.

That is handy when you want to swap or edit a texture later without re-exporting the whole model, or when a pipeline expects images on disk. Anyone sending models to web viewers or game tools can keep the geometry file lean and the maps easy to reach.

Key features

  • Single .glb output
  • Textures kept as external files
  • Easy texture swaps after export
  • Lighter model file
