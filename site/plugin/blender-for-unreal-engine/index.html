What Blender For Unreal Engine does

Blender For Unreal Engine exports scene content to Unreal Engine 4 and 5, including static meshes, skeletal meshes, animations and cameras.

Batch Export sends all scene assets at once in a tree layout matching the Unreal pipeline. Sockets and collision shapes are made in Blender, animations to export can be chosen and built-in error checks help catch problems. Unreal game developers streamline asset delivery. Studios and indie developers who move content between the two programs often can reduce manual FBX settings and naming mistakes with a consistent export process.

Key features

  • Batch export of all scene assets
  • Sockets and collision shapes in Blender
  • Animation export selection
  • Built-in error checking
