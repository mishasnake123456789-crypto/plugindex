What aescripts + aeplugins Magnum does

Magnum from aescripts + aeplugins detects cuts in footage within After Effects. Its detection engine works with all footage types and is now over twice as fast.

The visual change threshold is adjustable, a search range compensates for dissolves, and a minimum scene length avoids false cuts in quick pans or strobing. It can detect average scene color and use the first frame of the previous edit as a reference. Resulting clips can be trimmed, named with flexible options, and exported as thumbnails with optional spreadsheet data.

Key features

  • Edit detection for all footage types
  • Adjustable threshold and dissolve search range
  • Minimum scene length setting
  • Trim resulting clips
  • Thumbnail export with spreadsheet data
