What Shape Key &amp; Vertex Groups Utilities Enhanced does

Shape Key & Vertex Groups Utilities Enhanced adds management tools for two of the most fiddly parts of a character mesh in Blender. Shape key tools cover locked key operations, blending, value controls and combining locked keys.

For vertex groups there are Delete All, Delete Unlocked, lock and unlock actions, and Invert Locks, plus Rename to R/L using configurable suffix pairs. Adding [GROUP] to a name lets locking a parent key lock the keys below it. Toggling an animated shape key can insert a keyframe automatically.

Key features

  • Locked shape key operations and blend tools
  • Combine locked shape keys
  • Vertex group delete, lock and invert tools
  • Rename to R/L with configurable suffixes
  • [GROUP] naming for locking key sets
