Blender add-on that smooths selected faces and marks boundary edges sharp, mimicking 3ds Max smoothing groups.

What Set Smooth Group does

Set Smooth Group brings a familiar 3ds Max style of smoothing groups to Blender. For the selected faces it applies smooth shading and marks their boundary edges as sharp in a single action.

The original face selection is restored afterward. The command sits in the Mesh, Normals menu and has an Alt+G hotkey (Option+G on Mac), and an adjust-last-operation panel exposes options. Artists moving from 3ds Max, or anyone shading hard-surface models, can control sharp and smooth regions quickly.

Key features

  • Smooth shading plus sharp boundary edges
  • Restores original face selection
  • Located under Mesh > Normals
  • Alt+G hotkey (Option+G on Mac)
