What Network Clipboard does

Network Clipboard by Matt Tillman moves content between creative applications through a shared network location. Colleagues can copy a scene element on one machine and paste it into their own project on another.

It links After Effects, Cinema 4D and Houdini, with Maya support arriving later, and also handles FBX for After Effects. Items paste into a project or straight into the active comp, and copy history can be kept as long as you like. The clipboard directory can be set with an environment variable, usernames can be overridden, and floating licences are supported. Studios sharing assets across departments will find it practical.

Key features

  • Cross-app copy and paste over a network
  • After Effects, Cinema 4D, Houdini and Maya
  • FBX support for After Effects
  • Persistent copy history
  • Floating licence support
