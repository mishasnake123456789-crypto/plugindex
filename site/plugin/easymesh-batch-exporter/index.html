What EasyMesh Batch Exporter does

EasyMesh Batch Exporter targets game development pipelines in Blender. It exports many assets at once while applying the naming conventions of popular game engines.

Output formats include FBX, OBJ, glTF/GLB, USD and STL, handling meshes, curves and metaballs through automatic conversion. LOD hierarchies can be exported, geometry nodes optimized and textures managed automatically. Game artists shipping large asset libraries can cut down on repetitive export steps. Consistent naming and folder structure also make it easier for teams to hand assets to programmers and other departments without confusion.

Key features

  • Exports FBX, OBJ, glTF/GLB, USD and STL
  • Naming conventions for game engines
  • LOD hierarchy export
  • Geometry nodes optimisation
  • Automatic texture management
