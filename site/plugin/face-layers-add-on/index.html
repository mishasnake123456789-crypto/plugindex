What Face Layers Add-On does

Face Layers Add-On gives Blender users a way to manage faces on dense models, particularly while painting. Selecting or hiding faces quickly provides better control, so you can isolate areas of a complicated mesh and work on them without interference.

It bundles several additional features and comes with documentation. It lists Cycles and Eevee as render engines, works with Blender 4.0 through 5.0, is compatible with the Blender Extension format and is released under the GPL. Texture painters and modelers working on intricate assets will find it helps organize the work.

Key features

  • Quick face selecting and hiding
  • Better control while painting
  • Several additional features
  • Blender 4.0 to 5.0 and Extension format
  • GPL licensed
