What Easy Progress Bar does

Easy Progress Bar builds animatable progress indicators using geometry nodes. Choose from Rect, Stepped, Scaling Circle and Arrow bar types and control progression with a Factor from 0 to 1.

Material, width or radius, and height are adjustable, and you can add a background and a frame, each with its own material and thickness. Everything is edited in the N panel. It suits infographics, loading screens and explainer videos. Notable points: four bar types, factor from 0 to 1 for progression and optional background and frame.

Key features

  • Four bar types
  • Factor from 0 to 1 for progression
  • Optional background and frame
  • Material and size controls in the N panel
