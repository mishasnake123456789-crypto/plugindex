Blender geometry-nodes add-on that applies pixel-sorting glitch art to images and video.

What Pixel Sort does

Pixel Sort, by CGMatter, brings the glitch-art pixel sorting algorithm into Blender. It is built entirely with geometry nodes and has no dependencies, so it runs in Cycles and Eevee.

Parameters are procedural and animatable, including sort metric, direction, reverse sort, and a selection threshold with flip and blur. X-axis resolution is adjustable, and the result is stored in a PixelSort attribute that the material uses for rendering. Animated settings can be exported as an image sequence. A demo video and documentation are included.

Key features

  • Pixel sorting for images and video
  • Sort metric, direction and threshold controls
  • Animatable parameters
  • Pure geometry nodes, no dependencies
