An easing tool for After Effects with a preset library, graph editor and multi-keyframe easing curves.

What Kease does

Kease by Davide Boscolo helps shape keyframe motion beyond the default ease controls. It handles both simple easing between two keyframes and multi-keyframe curves across longer sequences.

A preset library stores any number of presets, with 12 simple ones supplied, and they can be created, imported and exported. The graph editor copies, applies, manipulates and saves curves. Modifier keys target the incoming, middle or outgoing section of a curve, easing and values can be copied and pasted, and the interface can be grouped, resized, recoloured and labelled by name or influence. Keyboard shortcuts speed things up for animators.

Key features

  • Preset library with 12 simple easing presets
  • Graph editor for simple and multi-keyframe curves
  • Modifier keys target incoming, middle or outgoing sections
  • Copy and paste easing and values
  • Customisable UI and shortcuts
