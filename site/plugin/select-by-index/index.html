What Select By Index does

Select By Index, by Eric-Banker, selects mesh elements according to their index numbers in Blender. In Edit Mode choose Select, By Index, then pick vertex, edge or face mode.

The range is defined by start and stop index or by a selection count, and the result can replace the current selection or add to an earlier one. It supports Blender 4.2 LTS and newer, and is handy for debugging meshes and scripting-related checks.

Key features

  • Select by start and stop index
  • Vertex, edge or face mode
  • Range by count option
  • Replace or extend selection
  • Blender 4.2 LTS and newer
