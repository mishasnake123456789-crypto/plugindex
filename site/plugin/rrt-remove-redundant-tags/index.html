What RRT: Remove redundant tags does

RRT: Remove redundant tags is a narrowly focused Adobe extension for Premiere Pro. It cleans up duplicated tags that can end up attached to markers because of a specific, uncommon issue in the application.

It is not a general marker tool and is meant to be installed only when an Adobe representative asks you to. Once installed it runs as a panel and removes the extra tags in place. It is free and supports Premiere Pro 14.0 and later, so it is mainly of interest to users who have been pointed to it during a support case.

Key features

  • Removes redundant tags from markers
  • Runs as a Premiere Pro panel
  • Targets one specific rare issue
