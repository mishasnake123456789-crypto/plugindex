Builds gradient node setups in Blender's Shader Editor, including axis and Empty-driven gradients.

What Make Gradient does

Make Gradient adds a Shader Editor menu that builds gradient node networks for you. Generator Gradient makes directional gradients along X, Y or Z from the selected object's Generated coordinates.

A single click creates a custom node group with Move, Smooth and Rotate controls built in. Origin Gradient creates an Empty parented to the active mesh and uses it to drive linear or spherical gradients. Material artists making fades, falloffs and dirt masks will skip the manual wiring.

Key features

  • Directional X, Y and Z gradients
  • Node group with Move, Smooth and Rotate
  • Empty-driven linear and spherical gradients
  • Menu in the Shader Editor
