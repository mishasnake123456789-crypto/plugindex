What tinyCAD Mesh tools does

tinyCAD Mesh tools places precision modeling commands in the context menu that opens in Edit Mode. Written originally by zeffii (Dealga McArdle), it was once bundled with Blender and is now maintained by the community.

The download is about 36 KB, needs no special permissions and is released under GPL v3 or later. It works with Blender 4.2 LTS and newer. Modelers doing technical drawing or precise, CAD-style construction can use the extra commands without extensive menus.
