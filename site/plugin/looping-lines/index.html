An After Effects script that builds procedural looping line animations from presets with adjustable parameters.

What Looping Lines does

Looping Lines by Manuel does Motion generates seamless line animations procedurally. Pick a preset, apply it, and tweak the result instead of drawing and keyframing every line by hand.

Loop length and speed can be set, along with line count, stroke width and spacing. Global position and rotation offsets, line opacity, rotation and colour are adjustable, wiggle amounts affect rotation and position, and a random seed produces further variations. It suits motion designers needing background patterns, loaders or abstract graphics that cycle cleanly.

Key features

  • Procedural looping lines from presets
  • Loop length and speed controls
  • Line count, stroke width and distance
  • Position, rotation, opacity and colour options
  • Random seed for variations
