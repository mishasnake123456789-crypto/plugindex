What Drag and Drop Support does

Drag and Drop Support improves how Blender handles files dropped into the window and adds more formats. Model files can be dragged straight from disk.

Supported formats include fbx, obj, glb, gltf, stl, ply, usd, svg, abc, bvh and wrl, although dae import is not available in Blender 5.0 and later after Collada's removal. Optional formats such as 3mf, pmx and vrm work with companion add-ons. It detects file handlers from third-party add-ons. Artists with mixed asset folders save time.

Key features

  • Drag-and-drop import of many formats
  • Companion add-ons for 3mf, pmx, vrm
  • Detects third-party file handlers
  • Works on modern Blender versions
