What 3D Wizard does

3D Wizard from MotionCodes converts a 2D picture into a 3D model inside After Effects with AI. Drop an image in, and it removes the background, generates six views of the subject and imports the finished model into your timeline.

Images can come from a layer source, a composition frame, a folder or a dragged file, and text prompts in any language can create or edit images before conversion. It uses several AI models from Hugging Face, accessed with your token. Motion designers can add 3D props without modeling.

Key features

  • 2D image to 3D model conversion
  • Background removal and six generated views
  • Sources: layer, comp frame, folder or drag-and-drop
  • Text prompts in any language
  • Multiple Hugging Face AI models via token
