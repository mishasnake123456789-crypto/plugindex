What 1-Click Lod Generator does

1-Click LOD Generator automates level-of-detail creation for game and real-time assets. Select a mesh, choose decimation ratios and four optimized levels are produced, named and grouped ready for export.

A live polygon count shows the result before generation. Levels are named _LOD0 to _LOD3 under a parent empty, with visibility toggles and a Clear LODs button in the LOD Tools tab. Export goes to FBX or GLB/glTF for Unity, Unreal, Godot and web pipelines, with a custom path and an unsaved file guard. Place at Origin stacks all levels at the source.

Key features

  • Generates four LOD levels in one click
  • Live polygon count preview
  • Auto naming and grouping under an empty
  • FBX and GLB export with custom path
