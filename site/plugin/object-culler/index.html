What Object culler does

Object culler is a 3ds Max script by Chuggnut that selects faces according to how they point relative to a second object. The angle between each face and the direction of that other object decides whether the face is picked.

This is similar to back-face culling driven by an arbitrary reference, which can reveal or remove faces pointing away from a camera, light or direction of interest. It is offered at version 2.3.5 on ScriptSpot, with a developer page at chuggnut.com. Game artists reducing hidden faces on meshes will find the idea convenient.

Key features

  • Face selection from angle against another object's direction
  • Second object acts as the reference
  • Runs inside 3ds Max
  • Version 2.3.5
