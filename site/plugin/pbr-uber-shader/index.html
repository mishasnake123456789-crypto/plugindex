What Pbr Uber-Shader does

PBR Uber-Shader is a node group for Blender Cycles that unites dielectric, metallic and refractive shading inside one shader. Load your texture maps, connect them and start shading.

It accepts maps for Base Colour, Ambient Occlusion, Roughness, Metallic, Normal, Emission, Height (Bump) and Opacity. Material artists get a straightforward, consistent PBR setup for most surfaces. Having one reusable node group keeps materials consistent across a project, and it reduces the clutter of rebuilding the same shader network for each asset.

Key features

  • Single Uber-Shader node group
  • Dielectric, metallic and refractive shading
  • Supports common PBR maps
  • Metal/Roughness workflow in Cycles
