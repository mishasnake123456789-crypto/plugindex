What Working Pivot Placer does

Working Pivot Placer is a simple 3ds Max script that positions the Working Pivot on a surface or using one, two or three points. It bundles macros that speed up coordinate switching, so you can move between systems without opening menus.

Coordinate Center Cycle steps through the three coordinate center types, Coordinate System Cycle changes between View, Local and Working Pivot, and Coordinate System-Pick lets you choose an object as the system. Alt-clicking the button copies a picked object's transform to the Working Pivot, while Ctrl-clicking cycles through the By Surface, By Points and By Object modes. It helps modelers working on angled surfaces.

Key features

  • Position the Working Pivot on a surface or from up to three points
  • Coordinate Center Cycle macro
  • Coordinate System Cycle between View, Local and Working Pivot
  • Pick an object as the coordinate system
  • Alt and Ctrl modifiers for object transform and pivot cycling
