What Compositor File Output Replacer does

Compositor File Output Replacer fixes the tedium of editing many File Output nodes by hand in Blender. A search and replace function renames file paths and filenames, with regular expression support for more complex patterns.

You may limit changes to the Base Path or the File Subpath, and work on all nodes or only the selected ones. Version 1.3.0 added Japanese language support.

Key features

  • Search and replace in File Output paths
  • Base Path or File Subpath targeting
  • All nodes or selected nodes
  • Regular expression support
  • Japanese language support
