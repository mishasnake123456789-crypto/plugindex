What mamoworld CINEWARE Proxy does

CINEWARE Proxy from mamoworld links Cinema 4D and After Effects, so you can flip between live 3D rendering and pre-rendered proxy files. When you switch, effects, masks and other changes stay in place.

It supports multi-pass rendering and works with background rendering, which needs BG Renderer Pro. Proxy files are named automatically, and the tool learns your own naming conventions, including proxies you already rendered another way. Artists with heavy 3D scenes can work quickly on lightweight files, then swap back to the live scene for final output.

Key features

  • Toggle between live 3D and proxy files
  • Multi-pass rendering support
  • Background rendering with BG Renderer Pro
  • Effects and masks preserved when switching
  • Learns your naming conventions
