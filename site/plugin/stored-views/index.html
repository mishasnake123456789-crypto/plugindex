What Stored Views does

Stored Views memorizes 3D viewport setups in Blender so you can come back to them. Saved items include views, viewpoints, layers and display settings.

It is found in the 3D Viewport sidebar under View > Stored Views and reads and writes view presets in a folder on disk, so it needs file access. Formerly bundled with Blender 4.1, it now comes from the community and supports Blender 4.2 LTS and newer. Architectural and product artists revisiting angles will save time.

Key features

  • Saves and restores viewport setups
  • Panel in View > Stored Views
  • Presets stored in a disk folder
  • For Blender 4.2 LTS and newer
