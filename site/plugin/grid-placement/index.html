What Grid Placement does

Grid Placement is a small Blender add-on for tidying objects that have piled up in one spot. After importing a batch of assets, you can select them and lay them out in a neat grid with a single menu command.

The command appears in Blender's object menu and works on regular objects, armatures and empties. You choose the spacing between items and how many sit in each row, so the layout fits whatever you are preparing. Kitbashers and anyone previewing a library of imported pieces will find it handy for getting an overview without placing everything by hand. Documentation is included.

Key features

  • Adds a Grid Placement entry to the object menu
  • Works on objects, armatures and empties
  • Adjustable distance between items
  • Configurable number of items per row
  • Documentation included
