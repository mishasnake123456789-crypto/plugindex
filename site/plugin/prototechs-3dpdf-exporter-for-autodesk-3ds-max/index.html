What ProtoTech's 3DPDF Exporter For Autodesk® 3ds Max® does

ProtoTech's 3DPDF Exporter turns solid and wire geometry from 3ds Max into lightweight 3D PDF files that open in free Adobe Reader, so anyone can rotate and inspect the model. Face-level colors are kept for visual accuracy.

Precision control balances file size against quality, password protection restricts access to the exported documents, and default compression reduces size. An optional automation license exports files without user intervention on standalone PCs. Designers sending models to clients or colleagues without 3D software can share them in a familiar format.
