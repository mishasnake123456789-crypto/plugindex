What 2Dfactory does

Tamara's 2DFactory turns 3D models into 2D game assets. Features include texture baking, modular sprite sheets, pivot placement, pixel measuring right in the camera view, and GIF and JSON output.

The modular design renders characters and their gear as separate yet compatible components for a full 2D character pipeline. Camera positions are defined by Radial Distance, Polar Angle, Azimuthal Angle and Camera Offset values, which keeps angles repeatable, and a 2D ruler measures in pixels. Indie developers get a path from model to sprite.

Key features

  • Modular sprite sheets for characters and gear
  • Repeatable camera angle variables
  • 2D Ruler for pixel measurement
  • Pivot placement
  • GIF and JSON output
