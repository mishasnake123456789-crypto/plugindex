What Icon Viewer does

Icon Viewer shows Blender's built-in icons in the Text Editor, and clicking one copies its name to the clipboard for use in scripts. It sits under the Dev tab and was originally one of the add-ons bundled with Blender 4.1.

The download is tiny, about 3.7 KB, requires no special permissions, and works with Blender 4.2 LTS and newer. It is distributed under the GNU General Public License version 2 or later. Add-on authors and technical artists writing interface code no longer need to look up icon identifiers by hand.
