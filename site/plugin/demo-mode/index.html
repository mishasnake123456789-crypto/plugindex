Blender add-on that loops through multiple selected blend files, formerly a bundled add-on and now a standalone extension.

What Demo Mode does

Demo Mode allows you to pick several blend files and cycle through them automatically. It used to be a bundled add-on in Blender 4.1 and now ships separately as an extension.

You reach it from File, Demo Menu inside Blender. It requires no special permissions, works with Blender 4.2 LTS and newer, and is released under GPL v2 or later. It suits presenters, trade-show displays and anyone who wants to loop a series of scenes unattended.

Key features

  • Loops over several blend files
  • Opens from File > Demo Menu
  • No special permissions required
  • Supports Blender 4.2 LTS and newer
