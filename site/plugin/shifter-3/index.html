What Shifter 3 does

Shifter 3 arranges selected items in a stepped sequence, a task editors and animators do constantly when stacking layers or clips with consistent offsets. It works in After Effects and Premiere Pro.

This release can offset in and out points as well, has a more responsive interface and a more visual graph display, and integrates with Spell Book. Presets can be exported and imported, which lets teams share the same stepping patterns across projects and machines.

Key features

  • Staircases layers and clips
  • Offsets in and out points
  • More visual graph display
  • Spell Book integration
  • Preset export and import
