A Blender add-on that adds bone property baking and strip operators to the NLA Editor.

What Nla Tools does

NLA Tools adds utilities that Blender's NLA Editor lacks, especially for rigged characters. A bake operator handles custom bone properties such as a Rigify IK/FK switch, and a Restrict Bake mode tries to preserve keyframes you inserted yourself.

For strips it offers a blend operator, with Shift-click to add the default NLA blend, removal of keyframes on locked properties for selected clips, X-mirroring of a strip, and linking selected strips' actions to the active strip's action. A bone extraction function is also included. Animators who layer and reuse actions in the NLA will find it eases tedious cleanup.

Key features

  • Bakes custom bone properties like IK/FK switches
  • Restrict Bake keeps user keyframes
  • Blend operator for NLA strips
  • Deletes keyframes of locked properties
  • X-mirror strips and link actions
