What Add Light To A Selected Object does

This add-on adds light that affects only the objects you assign, so one or several can be highlighted separately from the rest of the scene. It works in Cycles only.

It supports Blender 4.0 through 4.3, is Extension compatible, GPL-licensed and documented. It suits product shots and hero object emphasis. Notable points: light limited to selected objects, cycles only and blender 4.0 to 4.3. It also brings extension compatible. It is meant for artists who want to work faster inside Blender.
