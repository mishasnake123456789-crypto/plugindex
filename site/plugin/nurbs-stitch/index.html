What NURBS stitch does

NURBS stitch is a script by Chuggnut for combining NURBS surfaces in 3ds Max. It stitches two surfaces with tangent alignment so the join looks smooth, and it does this without losing edges on either surface.

The script connects the two nearest edges automatically, and it includes functions for surface edge indexing and finding the edge center. Artists building organic or automotive forms from separate NURBS patches can use it to merge them into a continuous shape, instead of fixing the seam manually with point and curve controls.

Key features

  • NURBS surface stitch with tangent alignment
  • Joins surfaces without losing edges
  • Connects the two nearest edges
  • Surface edge indexing function
  • Edge center function
