What Ditto - V3.4.2(Free On Gumroad) does

Ditto merges custom objects into smooth blends. It projects and smooths shapes through voxels in a way similar to SDF modeling.

A layer system combines multiple objects in a single collection while keeping their shapes, the blending remains adjustable, and results combine with Blender's modifiers for varied outcomes. Version 3.4.1 added further improvements. It suits organic and abstract modeling. Notable points: SDF-like voxel blending, layer system within a collection and shape retention with adjustable blend.

Key features

  • SDF-like voxel blending
  • Layer system within a collection
  • Shape retention with adjustable blend
  • Works with Blender modifiers
