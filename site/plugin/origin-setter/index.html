A lightweight Blender add-on that moves an object's origin to a vertex, edge or face with Alt+7.

What Origin Setter does

Origin Setter solves a small but frequent need in Blender: placing an object's origin exactly where you want. Select a vertex, edge or face in edit mode, press Alt+7, and the origin relocates to that point.

It operates on a selected mesh object in edit mode, installs from a zip through the Add-ons preferences, and supports Blender 3.0 through 3.5 under the GPL. Documentation is included. Modelers who set pivots for rotation, scaling or game engine export will find it much faster than snapping the 3D cursor first.

Key features

  • Moves origin to a vertex, edge or face
  • Alt+7 shortcut
  • Works in edit mode
  • Blender 3.0 to 3.5
  • GPL licensed with documentation
