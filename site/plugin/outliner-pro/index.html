Blender add-on with Outliner tools for moving items between collections, syncing colors and renaming.

What Outliner Pro does

Outliner Pro bundles tools that make handling objects and collections in Blender's Outliner easier. It can send items into the active collection from either the Outliner or the viewport, bringing children along by default, and centers the active object in the list.

Create and Move to Active Collection makes a new collection first and puts objects inside, and an Alt-click opens a popup with extra choices, including naming the new collection. Colors can be synced between collections and objects, and items can be renamed based on the name of the collection they sit in.

Key features

  • Send objects and collections to the active collection
  • Create and Move to Active Collection with naming popup
  • Color syncing
  • Center the active object in the Outliner
  • Rename items from collection name
