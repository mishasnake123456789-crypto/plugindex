AI plugin that estimates depth maps from video in After Effects and Premiere Pro.

What Depth Scanner 2 does

Depth Scanner 2 uses machine learning to guess how far away each part of a video frame is, producing a depth map without needing a 3D scene. That map can then drive effects like fog, depth-based colour grading or transitions.

Eight AI models ship with the plugin, including Depth Anything v3, and a video model keeps results stable over several frames to avoid flicker. Both AMD and NVIDIA graphics cards are supported. A Stop Processing button cancels long calculations, and a CUDA Memory Sharing option speeds up rendering above 4K. It works in After Effects and Premiere Pro.

Key features

  • Generates depth maps from video
  • Eight AI models including Depth Anything v3
  • Multi-frame model for flicker-free results
  • AMD and NVIDIA GPU support
  • Stop Processing button and CUDA Memory Sharing
