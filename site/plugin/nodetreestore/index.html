What Nodetreestore does

Nodetreestore saves node trees as presets so you can bring them back into any project. It loads trees in full, across projects and different Blender versions, and covers shader, geometry, compositor and texture nodes.

Nodes of the same type whose interfaces changed between versions can still be reused, from Blender 2.8 onward. It acts like a personal library of node setups and speeds up repeated material and effect building. Highlights include store and reload node trees, shader, geometry, compositor, texture nodes and cross-version compatibility from 2.8.

Key features

  • Store and reload node trees
  • Shader, geometry, compositor, texture nodes
  • Cross-version compatibility from 2.8
  • Reuse across projects
