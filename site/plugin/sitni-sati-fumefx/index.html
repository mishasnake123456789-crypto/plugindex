Voxel-based fluid dynamics plugin for simulating and rendering fire, smoke and explosions in Cinema 4D.

What Sitni Sati FumeFX does

Sitni Sati FumeFX simulates gaseous phenomena such as fire, smoke and explosions inside Cinema 4D using physics-driven voxel grids. Pyro Vorticity with Surface Breaker adds detail to the interior and edges of the flow for pyroclastic-looking results.

Explosion preprocess options support cinematic shading with the Arnold renderer, and adaptive grid attributes control expansion by velocity and added pressure. Sources can add pressure to create low and high-pressure regions, the GPU viewport shows render-like previews, and simulations can run on another computer through Deadline. VFX artists and game developers use it for realistic effects.

Key features

  • Pyro Vorticity with Surface Breaker detail
  • Explosion preprocess for Arnold shading
  • Adaptive grid controls and pressure sources
  • GPU-accelerated viewport with PNG export
  • Network simulation via Deadline or remote desktop
