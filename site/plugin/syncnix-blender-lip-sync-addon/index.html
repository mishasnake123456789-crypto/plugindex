What Syncnix: Blender Lip Sync Addon does

Syncnix pairs a lip sync tutorial with an add-on for Blender. After linking your model, it drives shape keys to animate speech.

Shape keys are driven for smooth transitions, and a navigation tool helps move among them while animating. Documentation is included, it covers Blender 2.8 through 3.2 and is released under the GPL license. Animators can speed up dialogue scenes. The tutorial component explains the method behind the setup, which helps newer animators understand why mouth shapes are driven this way and adapt it to their own characters.

Key features

  • Tutorial and add-on in one product
  • Shape keys driven by the tool
  • Shape key navigation tool
