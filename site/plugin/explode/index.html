expLODe

Blender add-on that exports FBX files with automatically generated LOD levels, including a Unity-compatible variant.

What expLODe does

expLODe adds two new entries to Blender's File > Export menu for producing FBX files that contain level-of-detail versions of a model. One is a standard export and the other is tuned for Unity, so exported files arrive with a zero rotation in the respective program.

The LOD levels are specified on the export screen. The first level is created with a Planar Decimate modifier at ten degrees, and the second with five iterations of Unsubdivide. A Smart UV Unwrap step and further customization options are included, with y as up and z positive as forward for Unity.

Key features

  • Standard and Unity-compatible FBX export entries
  • LOD levels set on the export screen
  • Planar Decimate for LOD 1, Unsubdivide for LOD 2
  • Smart UV Unwrap included
  • Zero-rotation import in Blender or Unity
