What Pie Menu Editor does

Pie Menu Editor lets Blender users design their own interface elements without programming. It makes pie menus, regular menus, popup dialogs, side panels and toolbars, and supports Blender 2.79 through 4.3.

Individual editors handle pie menus (even those with eight or more slots), ordinary menus, popup dialogs, macros, modal operators, properties, side panels and toolbars. It can hide, extend and float panels and provides sticky keys, stack keys and custom icons. Artists tuning Blender to their habits can streamline frequent actions.

Key features

  • Pie menu editor with 8+ button support
  • Menu, dialog, panel and toolbar editors
  • Macro and modal operator editors
  • Sticky keys, stack keys, custom icons
