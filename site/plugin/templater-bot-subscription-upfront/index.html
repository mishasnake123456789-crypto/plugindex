What Templater Bot Subscription Upfront does

Templater Bot is Dataclay's automation layer for After Effects, producing batches of unique videos from a data source, from about fifteen up to many thousands. This listing is the upfront subscription option.

It can generate a video from web form input and run a script to upload it, fit into an automated production pipeline, and execute scripts after each render job or once all jobs finish. Activation and license checks need an online system. Studios running high-volume personalized video will use it.

Key features

  • Batches of 15 to 15,000+ videos from a data source
  • Video creation from web form input
  • Fits into automated production pipelines
  • Runs scripts after each or all render jobs
  • Requires online activation
