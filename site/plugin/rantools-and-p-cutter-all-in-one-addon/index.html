What Rantools (And P-Cutter) All-In-One Addon does

Rantools and P-Cutter combines many utilities for hard surface modeling and rendering in Blender. At its center are a boolean and drawing system built on a grid, and a boolean cleanup that runs in one click.

P-Cutter offers two grid styles, boolean and draw modes, inset points, snapping to angles and intersections, mirroring, arrays and a sketch mode. Other tools include cables and wires, modifier presets, lighting, texture baking and a backup manager. Hard surface artists wanting a single package for many tasks can use it.

Key features

  • P-Cutter grid boolean and draw system
  • One-click boolean cleanup
  • Cable and wire tools
  • Modifier presets and backup manager
