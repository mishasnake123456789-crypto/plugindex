Turns any Blender mesh into a stitched pillow after you cut the seams, with optional fuzz.

What Pillow It does

Pillow It from Boars In Rome converts an object into a pillow in a few clicks. Select the mesh, mark the seams, and the add-on stitches everything together.

Automatic fuzz can add fur with a definable amount of hair for fuzzy pillows, and a simple material with a sheen setting is applied on creation, which you can change. Artists making interiors or soft-goods visuals can skip the cloth simulation setup.

Key features

  • Stitches a mesh into a pillow from seams
  • Automatic fuzz with adjustable hair amount
  • Default material with sheen setting
