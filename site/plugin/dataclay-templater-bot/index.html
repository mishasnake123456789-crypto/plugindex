What Dataclay Templater Bot does

Dataclay Templater Bot connects an After Effects master composition to a data source so that many unique videos can be produced automatically, from about 15 up to 15,000 or more. Supported sources are Google Sheets, local JSON files and Google Drive.

It handles generative AI text layers, dynamic subtitles with SRT editing, and Adobe MoGRT and Essential Graphics formats. A command-line interface fits existing production pipelines, scripts can run after each render job or when all are finished, and several targets can be handled in one job. Projects can be prepared for a different computer running Templater Pro or Templater Bot. Studios producing personalised content at scale benefit.

Key features

  • Generates unique versions from Google Sheets, JSON or Drive
  • Generative AI text layers and dynamic subtitles
  • MoGRT and Essential Graphics support
  • Command-line interface for pipelines
  • Run scripts after each render job or after all finish
