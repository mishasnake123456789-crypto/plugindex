What B-Renderon [Standalone Render Manager] does

B-Renderon is a separate application for queuing Blender renders without writing command-line scripts. Through a graphical interface it handles blend files, scenes, view layers, cameras and queued jobs in a list.

Specific collections can be switched on or off for each job, different Blender versions can be assigned to individual jobs, and jobs can run on different devices in parallel. Studios and freelancers with long render queues can keep Blender free for work while renders proceed in the background.

Key features

  • Batch render files, scenes, layers and cameras
  • Per-job collection toggles
  • Assign Blender versions to jobs
  • Parallel jobs on different devices
  • No command-line scripting needed
