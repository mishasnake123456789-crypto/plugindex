Blender add-on that imports UModel .mat and .json exports and builds Principled BSDF materials from the referenced textures.

What MAT Helper does

MAT Helper bridges data extracted with UModel (UE Viewer) and Blender's material system. Point it at a .mat or .json configuration file and it loads every texture referenced from a chosen directory in one batch, then constructs the shader nodes for you.

Diffuse maps feed Base Color, metallic maps feed Metallic, normal maps pass through a Normal Map node, and specular maps pass through an Invert node before reaching Roughness, as many game engine setups expect. Color spaces are assigned automatically, sRGB for diffuse and Non-Color for data maps, and nodes keep their original file names as labels.

Key features

  • Batch import of .mat and .json configuration files
  • Automatic Principled BSDF node wiring
  • Normal map and inverted specular-to-roughness handling
  • Automatic color space assignment
  • Nodes labeled with original filenames
