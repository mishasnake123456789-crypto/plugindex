What Tilles Motion Carousel XPress does

Carousel XPress takes selected layers and arranges them into a functioning carousel immediately. Five types are available: Linear, Circular 2D, Circular 3D, Exponential and Path.

A Control Layer drives the rig with numerous animatable parameters, and each rig layer has a local parameter for fine position adjustment. Holding SHIFT builds the carousel over nulls so items can be controlled individually and animated in and out. The responsive interface fits into your workspace. Use it for product showcases, looping backgrounds and lettering.

Key features

  • One-click carousel from selected layers
  • Linear, Circular 2D, Circular 3D, Exponential and Path types
  • Control Layer with animatable parameters
  • Optional null-based build with SHIFT
  • Responsive UI
