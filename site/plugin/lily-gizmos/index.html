What Lily Gizmos does

Lily Gizmos, by Élie Michel, lets you build interactive handles in the Blender viewport without Python scripting. These gizmos allow direct manipulation of parametric shapes or rigs.

To start, create an Empty and turn on its Lily Gizmo option in the Empty properties, after which the gizmo can be customized from the interface. Riggers and tool makers can give animators friendlier controls than raw property sliders.

Key features

  • Custom gizmos with no coding
  • Enabled through Empty properties
  • Handles for parametric shapes and rigs
  • Customizable from the interface
