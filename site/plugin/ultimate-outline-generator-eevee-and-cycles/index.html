What Ultimate Outline Generator (Eevee & Cycles) does

Ultimate Outline Generator adds outlines to 2D, anime and toon work in Eevee and Cycles. It uses inverted hull outlines built with a Solidify modifier, so you can edit or remove them without touching the original mesh.

Thickness is set per object, and a color index system assigns colors to one object or updates several together. It speeds up stylized rendering setups with a few clicks. Per-object control makes it simple to give a hero character a thicker line than background elements while keeping a unified style.

Key features

  • Inverted hull outlines with Solidify
  • Non-destructive editing
  • Color Index system
  • Per-object thickness
