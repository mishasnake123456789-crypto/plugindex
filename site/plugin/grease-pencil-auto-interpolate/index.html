What Grease Pencil Auto Interpolate does

Grease Pencil Auto Interpolate fills in the frames between your drawn keys in Blender. Built on Grease Pencil Geometry Nodes, it processes in real time during playback and leaves your original keyframes untouched, so you can keep iterating.

An Auto-Link mode matches strokes between keys with one click, working out the correspondences itself, while Manual Link mode offers Manual, Link, Unlink and Done buttons for fixing difficult cases. Traditional and motion graphics animators can speed up 2D animation by drawing fewer frames.

Key features

  • Automatic in-between frame generation
  • Non-destructive, original keys kept
  • Auto-Link one-click stroke matching
  • Manual Link mode with Link and Unlink buttons
  • Real-time playback processing
