Lightweight Blender add-on that attaches props to animated rigs at the moment of contact and releases them cleanly.

What Progrip does

ProGrip sets up grabs between a bone and a prop in character animation. You animate first, and it handles the attachment.

One click creates a clean attachment at exactly the frame of the grab, with precise contact alignment so the object follows the bone from then on. A release system detaches it when the character lets go. A grab helper function simplifies the process. It is helpful for animations where characters pick up, carry and release items.

Key features

  • One-click grab setup
  • Animate first, attach after
  • Precise contact alignment
  • Clean release system
  • Grab helper function
