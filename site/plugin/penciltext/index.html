Blender add-on that converts typed text into Grease Pencil strokes and can trace object outlines as strokes.

What Penciltext does

johnnygizmo's PencilText writes text as Grease Pencil strokes in Blender's 3D viewport, useful for annotations and hand-drawn titles. Size and color of the inserted text can be set first.

A longer passage can be inserted at once from a text block, and a button named Object to Grease follows a chosen object's edges and redraws them as strokes, keeping scene notes neat. Since the output is ordinary Grease Pencil, Blender's existing tools can edit it afterwards. Documentation is included.

Key features

  • Typed text to Grease Pencil strokes
  • Set size and color
  • Insert text blocks at once
  • Object to Grease edge tracing
  • Edit with standard Grease Pencil tools
