Blender add-on that generates normalized driver expressions with easing for Shape Keys and float properties.

What DriverHelper does

DriverHelper writes driver formulas for you in Blender. Working from the Shape Keys panel, it builds expressions based on Location, Rotation or Scale, so you no longer need to calculate the math for range mapping yourself.

Any value range is normalized to 0 to 1, and an optional Power parameter shapes the response as linear, ease-in or ease-out. Rotation input is given in degrees and converted to radians. The Generate Formula button shows the expression in a popup, ready to paste into a driver field, and it works for any float property that accepts drivers.

Key features

  • Formulas from Location, Rotation or Scale
  • Normalizes any range to 0 to 1
  • Linear, ease-in and ease-out via a Power value
  • Degrees converted to radians automatically
  • Copy-ready expression popup
