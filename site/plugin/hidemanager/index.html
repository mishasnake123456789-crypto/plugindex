What Hidemanager does

Hidemanager manages what is shown, hidden or selected in a scene using filters instead of manual clicking. Its ten operations handle selection, visibility, render and viewport toggles, plus Mark, Remove and Mark Ignore.

Filters can match on name text, type, a specific object, hierarchy, collection, material, modifier, vertex group, shape key or constraint. A Lite edition and a Pro edition exist, with Pro adding groups and edit mode filters. Useful for complex scenes with hundreds of objects.

Key features

  • Ten visibility and selection operations
  • Many filter types: name, type, collection, material
  • Modifier, vertex group and shape key filters
  • Lite and Pro versions
