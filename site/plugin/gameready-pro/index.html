Blender add-on that runs validation, lightmap UVs, collision, LODs and export for game assets from one Process All button.

What Gameready Pro does

Gameready Pro chains the tedious steps of preparing a game asset into one run. A Process All button validates the mesh, creates a second lightmap UV set, builds collision, generates LODs and exports, and each step can be switched on or off per object.

LOD generation produces up to three levels, grouped in their own collection. Box, sphere and convex hull colliders are computed in world space and named for the target engine: UCX, UBX or USP for Unreal Engine 5, _collider for Unity, -col for Godot 4. Pre-export checks flag unapplied scale, n-gons, UVs outside the 0 to 1 range, loose geometry and missing materials.

Key features

  • One-click pipeline with per-asset step toggles
  • Up to three LOD levels with adjustable reduction
  • Box, sphere and convex hull colliders
  • Engine-correct collision naming for Unreal, Unity and Godot
  • Pre-export validation of scale, n-gons, UVs and materials
