What Sverchok Blender Object Modifier Add Node does

This Sverchok script node brings Blender's modifier function into the Sverchok node environment. It adds a modifier to an object you feed in.

Parameters set the modifier type and its name, and the node outputs the modified object. It is imported through Sverchok's import function using its .json file, and documentation is included.

Key features

  • Adds a modifier to an input object
  • Modifier type and name parameters
  • Object output with the modified result
  • Imports via Sverchok .json
