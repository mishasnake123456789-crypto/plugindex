What Neotex does

Neotex automates the repetitive path of texturing many objects in Blender 2.8. It runs through the workflow from importing the objects to saving and naming the final texture maps.

Batch tasks include texture catalogs and generating materials, and the package comes with a 20GB library of 4K materials. Documentation is provided. It is for artists who must texture large numbers of objects consistently and want to avoid doing each one by hand.

Key features

  • Mass texturing across a scene
  • Automated import to map saving and naming
  • Batch texture catalogs and material generation
  • 20GB 4K material library included
  • Documentation provided
