What Multi Camera Rendering Addon does

Darth Mickey's Multi Camera Rendering Addon renders from several viewpoints in one operation. Cameras you don't want can be turned off in the list, and results can optionally be written directly to disk.

Saved files receive an automatic suffix, and any camera in the list can become the scene camera or the active object. It works in Cycles and Eevee. Useful for product turntables, interior views and multi-angle deliveries. Cameras can be reordered or disabled between runs, so partial re-renders after a client change stay quick.

Key features

  • Render multiple cameras in one click
  • Optional direct save with automatic suffix
  • Disable specific cameras
  • Set scene camera from the list
  • Cycles and Eevee support
