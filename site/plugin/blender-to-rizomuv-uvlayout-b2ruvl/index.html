What Blender To Rizomuv/Uvlayout [B2Ruvl] does

Blender To Rizomuv/Uvlayout, known as B2Ruvl and made by Titus, bridges Blender with two dedicated unwrapping programs, RizomUV and Headus UVLayout. Send a mesh over, unwrap it there and receive the UVs back without exporting and importing files yourself.

The RizomUV connection is live over TCP with start and close controls and a status indicator, and several RizomUV operations such as Sync UV Sets, Weld All, Cut and Unfold can be triggered from inside Blender. It speeds up UV-heavy asset production.

Key features

  • Live RizomUV link over TCP with status indicator
  • Support for Headus UVLayout round trips
  • RizomUV tools like Sync UV Sets, Weld All, Cut and Unfold
  • No manual export or import of meshes
