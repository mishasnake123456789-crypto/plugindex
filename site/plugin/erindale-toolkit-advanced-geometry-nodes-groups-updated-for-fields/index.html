What Erindale Toolkit - Advanced Geometry Nodes Groups (Updated For Fields) does

Erindale Toolkit is a library of high-end node groups for Geometry Nodes in Blender, updated to work with fields. It ships with more than 130 nodes aimed at building procedural systems efficiently.

Included tools cover camera culling, which limits instances to what the camera can see, level of detail setups with distance controls for different meshes, and generator nodes for procedural points and instancing. Technical artists and environment creators can assemble scattering and optimization setups faster.

Key features

  • LOD tools with distance limits
