What Handy Curve Profile does

Handy Curve Profile is a Blender add-on by young that gives curve objects mesh detail with a button press. It includes over 100 premade shapes in groups like Organic and Connection Segment, and includes tools for bone, edge and surface drawing.

Shapes can be applied along curves, including flexible or rigid shapes at the curve end. Every aspect of a shape can be changed, and length can be set manually or fitted to the curve and segment distance. A sub-panel provides per-point radius and tilt, and a profile can be copied from existing geometry.

Key features

  • 100+ premade mesh shapes
  • Flexible or rigid curve end shapes
  • Manual or fit-to-curve length
  • Per-point radius and tilt
  • Copy profiles from other geometry
