What Global Custom Properties does

Global Custom Properties gives quick access to the metadata you use constantly. A new panel provides a set of predefined input fields that appear on every Object, Collection and Scene, so values can be edited without creating the property each time.

It works with Custom Property data that already exists. Pipeline-minded artists and teams that tag assets with standard information can keep entries consistent across a project.

Key features

  • Panel of predefined global input fields
  • Available on Objects, Collections and Scenes
  • Works with existing Custom Property data
  • Consistent metadata entry
