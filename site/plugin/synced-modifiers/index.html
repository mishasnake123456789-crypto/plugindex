Blender add-on that applies modifiers to many objects at once and keeps their settings in sync through Drivers.

What Synced Modifiers does

Synced Modifiers lets you add the same modifier to several objects and then edit them together. Synchronization happens automatically through Drivers, so changing one object's setting updates the others.

Version 2.0.0 also synchronizes modifiers that already exist on the objects. A panel opens with the J shortcut. Environment and prop artists with sets of matching objects can adjust all of them with one control instead of repeating changes.

Key features

  • Adds modifiers to multiple objects at once
  • Automatic sync using Drivers
  • Version 2.0.0 syncs existing modifiers
  • Panel opened with the J shortcut
