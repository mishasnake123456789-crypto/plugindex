What Blender Tools Addon - Blender Cleaner does

Over time a Blender file collects leftovers. Blender Cleaner, one module of emVi Solutions' multipurpose Blender Tools add-on, sweeps them out.

Unused Materials deletes materials no object needs even when Blender counts them as used, Unused Nodes removes unconnected material and world nodes, and Purge Unnecessary Files clears out idle project files. Both Cycles and Eevee are supported. Running it before archiving a scene or sending it to a collaborator keeps files lean.

Key features

  • Removes unused materials
  • Deletes disconnected material and world nodes
  • Purges unneeded project files
  • Part of the multipurpose Blender Tools add-on
  • Works with Cycles and Eevee
