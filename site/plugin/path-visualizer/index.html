What Path Visualizer does

Path Visualizer is an After Effects plugin from Plugin Everything that exposes the geometry behind text and paths. It draws the vertices, bezier segments and handles of a shape, and the overlay follows any animation applied to the source.

That makes it handy for technical, blueprint and diagram-style visuals, where you want viewers to see how a letter or curve is constructed. A Solo Vertex stroke option adds another way to style the points. It supports multi-frame rendering in After Effects 2022 and ships as a universal binary for Apple Silicon.

Key features

  • Draws vertices, beziers and handles from text or paths
  • Updates live as the source animates
  • Solo Vertex stroke option
  • Multi-frame rendering support
  • Universal binary for Apple Silicon
