Generates Cinema 4D takes that output material, object or texture tag masks as white mattes or a single Color ID pass.

What Mike Udin TakeMatPass does

Mike Udin TakeMatPass builds extra takes in Cinema 4D from the mask of a material, object or texture tag. White matte mode makes a separate take for each selected item, showing it in white while everything else turns black through Material Override.

Color ID mode produces a single take named MaterialID in which each selected item appears in its own unique color. Both feed compositing workflows that need clean selection mattes. Artists rendering for After Effects or Nuke can set up their ID passes in a few clicks.

Key features

  • White matte mode, one take per selection
  • Color ID mode in a single MaterialID take
  • Works with materials, objects and texture tags
  • Uses Material Override for black backgrounds
