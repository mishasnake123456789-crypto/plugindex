What Blender Labelling Tool does

Blender Labelling Tool is a free, open-source add-on that turns Blender into a video annotation tool. You draw bounding boxes on video frames and export the labels in YOLO format.

It works in Blender 3 and later and builds on Blender's video features, including multiple formats, proxies, interpolation, keyframing, curves and collections. Machine learning practitioners creating datasets can benefit from keyframe interpolation between labeled frames. Because it relies on Blender's own tools, existing skills with the timeline and curves carry over directly.

Key features

  • Bounding box annotation on video
  • YOLO format export
  • Uses Blender's video handling and proxies
  • Keyframing and interpolation
  • Free and open source
