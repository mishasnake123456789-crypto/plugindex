What Hotkey Heaven does

Hotkey Heaven, by Galaxy Studios, streamlines tool switching in Blender through a two-press hotkey. First press activates the tool you picked; pressing it again performs an action you chose.

It works with any tool in any mode and is compatible with Blender 3.0 through 4.0. Installation is through the standard Add-ons preferences from a .zip file, and the developer accepts special requests by email.

Key features

  • Hotkey activates a chosen tool
  • Second press runs a chosen action
  • Works with any tool in any mode
  • Blender 3.0 to 4.0
