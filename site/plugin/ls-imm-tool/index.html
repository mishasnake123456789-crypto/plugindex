Blender add-on that merges up to five meshes into one using Geometry Nodes, like ZBrush Insert Multi Mesh.

What Ls Imm Tool does

Ls Imm Tool combines several meshes into a new connected mesh, mirroring the idea behind the Insert Multi Mesh brush in ZBrush. It is built on a geometry node modifier, so the process stays non-destructive.

Up to five input meshes can be joined, and fewer can be used as needed. Parameters adjust the density of the transition mesh and the position of the middle section. IMM objects are created quickly and node groups can be updated. It is helpful for creating limbs, tubes and kitbash assemblies.

Key features

  • Combines multiple meshes into one
  • Non-destructive Geometry Nodes build
  • Supports up to five meshes
  • Control of transition density and mid-section position
  • Quick IMM creation and node group updating
