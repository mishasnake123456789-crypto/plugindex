Standalone converter from GLB and glTF to OBJ that, with the ImportObj script, brings PBR materials into 3ds Max.

What GLB2OBJ does

GLB2OBJ is a separate program that turns GLB and glTF files into OBJ so 3ds Max can use them. One or many files can be converted in a batch to a chosen output folder.

Files holding multiple objects are split out with _part_01 and _part_02 suffixes and matching texture sets, and PBR textures are named accordingly. When combined with the developer's ImportObj script, PBR materials and multi-part objects come into 3ds Max properly set up. Update 1.1 added a new user interface. It helps artists using web or AR-oriented assets.

Key features

  • Converts GLB and glTF to OBJ
  • Batch conversion to a chosen folder
  • Splits multi-object files into numbered parts with textures
  • PBR texture file naming
  • Pairs with ImportObj for PBR material import
