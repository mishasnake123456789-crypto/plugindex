Blender add-on that extends the Mix Color node to 67 blend types with weights and per-channel math actions.

What Mix Color Node does

Mix Color Node by mod3d greatly expands Blender's standard Mix Color node. It offers 67 blend types, from familiar ones like Mix, Divide, Darken, Overlay and Dodge to unusual ones such as Ripple, Pin Light, Polar and Phoenix.

Weight parameters for inputs A and B refine the blend, and 18 math actions such as multiplication, logarithm, power and sine can adjust the red, green and blue channels separately. The effect is chosen through Blend_Type and Math_Action sockets. A documentation text file is included.

Key features

  • 67 blend types
  • Weight inputs for A and B
  • 18 math actions for per-channel adjustment
  • Blend_Type and Math_Action sockets
  • Documentation text included
