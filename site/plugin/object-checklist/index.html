What Object Checklist does

Bookyakuno's Object Checklist presents objects in filterable lists, working as a quality check on finished data before it is exported or moved to other software.

Objects can be filtered by naming scope (selected, scene, all data, or a given collection), by type, visibility, selectability, viewport display and render toggle, and by rotation and scale values, non-rendering modifiers, muted constraints and actions. Mesh data appears as counts per object. Technical artists can catch problems early.

Key features

  • Filter by selection, scene, data or collection
  • Filter by type, visibility and render toggle
  • Rotation, scale, modifier and constraint checks
  • Mesh data counts per object
  • Checklist for pre-export review
