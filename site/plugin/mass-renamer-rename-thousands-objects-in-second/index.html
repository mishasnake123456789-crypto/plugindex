What Mass Renamer - Rename Thousands Objects In Second does

Mass Renamer tackles the chore of cleaning up names in large Blender scenes. Targets include node groups, actions, armatures, textures, materials, collections and objects.

Filters decide which items are affected, with an option to include descendants. Text can be swapped using wildcards or regex patterns, letter case can be converted, and names may be derived from the hierarchy. Pipeline artists enforcing naming conventions will find it a quick way to tidy thousands of datablocks.

Key features

  • Renames many datablock types at once
  • Filtering with optional descendant inclusion
  • Wildcard and regex find-and-replace
  • Case conversion
  • Hierarchy-based naming
