What Goldflow Insole Designer does

GoldFlow Insole Designer is a Blender add-on for building custom orthotic insoles. It follows a four-step workflow from draft creation through custom design and ends with print-ready STL export.

A template library generates left and right base surfaces, foot scans can be imported as STL or OBJ and are placed near the template automatically, and Smart Registration detects scan dimensions and matches them to shoe sizes. It suits orthotics practitioners and makers working with 3D printing.

Key features

  • Template library for left and right insoles
  • STL and OBJ foot scan import
  • Smart Registration matches shoe sizes
  • Print-ready STL export
