What ExpressionUniversalizer 4 does

ExpressionUniversalizer 4 by Lloyd Alvarez fixes expressions that break when a project is opened in a differently localized After Effects. It rewrites them so they work in any language the application supports, including English, Spanish, French, German, Italian, Japanese, Korean, Portuguese, Russian and Chinese.

Version 4 has a new C++ parsing engine, said to be about 10 to 20 percent faster and more accurate, plus batch processing with rename modes and logging options. It handles Data layer references like JSON and CSV, runs natively on Apple Silicon, and skips Duik expressions unless you choose otherwise.

Key features

  • Converts expressions to work in any supported language
  • New C++ parsing engine
  • Batch processing with prefix, suffix or replace renaming
  • Data layer references such as JSON and CSV
  • Native Apple Silicon support
