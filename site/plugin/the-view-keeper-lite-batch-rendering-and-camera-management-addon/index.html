What The View Keeper (Lite) - Batch Rendering And Camera Management Addon does

The View Keeper (Lite) manages camera angles and batch renders in Blender. A single camera can hold unlimited stored views.

Switch between views with a click, and save separate render settings per view, including format, output folder and file type. Several views can be rendered together without reconfiguring anything. Find Camera detects and records every camera in the scene, and a refresh function keeps records current. It is practical for presentations needing multiple angles of one scene.

Key features

  • Unlimited stored views per camera
  • One-click view switching
  • Per-view render settings
  • Batch render multiple views
  • Find Camera and refresh records
