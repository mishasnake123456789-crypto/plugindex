What miauu's Spline Deformer does

miauu's Spline Deformer is a commercial script that treats a row of polygon edges as though it were a spline, so it can be curved and reshaped smoothly. It works with Editable Poly objects and the Edit Poly modifier.

Soft Selection is supported to help during modeling. Compatibility covers 3ds Max and 3ds Max Design from 2009 to 2027. Modelers who need to bend edge loops, refine contours or adjust curved surfaces gain direct control without converting geometry to separate splines.

Key features

  • Manipulate edge rows as splines
  • Soft Selection support
  • Works with Editable Poly
  • Works with the Edit Poly modifier
  • 3ds Max and Max Design 2009-2027
