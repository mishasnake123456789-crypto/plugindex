What Polymating does

Polymating is a real-time retopology helper for Blender. It continually reapplies a projection similar to Shrinkwrap in the background, so mesh wrapping is handled while you use native tools and concentrate on quad flow.

Solver-based projection offers Force Project and Raycast with multi-hit. Hidden vertices are skipped, Sculpt-mode masks and shapekeys are respected, and self projection is possible with collections used as references. Experimental vertex locking comes with global overlay controls, and caching keeps interaction smooth.

Key features

  • Real-time vertex projection
  • Force Project and Raycast solvers
  • Respects masks, shapekeys and hidden vertices
  • Self projection and collection references
  • Experimental vertex locking
