Blender extension that sends alerts when renders start, finish or are cancelled via desktop popups, Discord or webhooks.

What Render Notifications does

Render Notifications lets you step away from long renders and still know what is happening. It notifies you when a render begins, completes or is stopped, via desktop popups, Discord or webhooks to custom platforms such as Home Assistant.

Desktop notifications can play your own .wav sounds, and the first frame completion is announced too. Progress figures are worked out after every frame, so messages carry useful information about how far along the job is.

Key features

  • Desktop notifications with optional custom sounds
  • Discord webhook support
  • Generic webhooks for platforms like Home Assistant
  • Start, finish, cancel and first-frame events
  • Progress details after each frame
