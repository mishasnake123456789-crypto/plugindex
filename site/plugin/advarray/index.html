Parametric array modifier for 3ds Max with advanced options beyond the built-in array tools.

What AdvArray does

3ds Max does not include a parametric array modifier, and AdvArray by Tim Catalano fills that gap. It repeats objects with parameters you can change at any time instead of fixed copies.

It offers advanced array features that go beyond the defaults, including some that the developer says other third-party modifiers lack. Version 1.2.6 was updated for 2024 products, and documentation plus a demo video are available from the developer. Modelers working on repeated structures such as railings, columns or stairs can use it to keep their models editable.
