What LetsMotion Stock Search Pro does

LetsMotion Stock Search Pro puts a stock library inside After Effects and Premiere Pro. You can search and download free videos, images, GIFs and icons without leaving your Creative Cloud project.

Assets carry royalty-free licenses, usable commercially or non-commercially with artist credit. A sound effects library is included, along with a download manager for organizing files and search filter settings. It suits editors who need filler footage, icons and reaction GIFs without browsing websites.

Key features

  • Video, image, GIF and icon search
  • Royalty-free licenses
  • Sound effects library included
  • Download manager
  • Search filter settings
