What Syncaila does

Syncaila, from Coolicove, synchronizes footage from several cameras and separate audio recorders. It works with DaVinci Resolve and Premiere Pro by passing the project through XML rather than needing a plugin panel in the editor.

You export an XML from the editor, run the sync in Syncaila, and bring the result back in. Its algorithms imitate how an editor would line up clips, and four chronology types control the order of clips in the resulting project. Multi-hour recordings from different devices and formats are supported. Documentary, event and interview editors with large amounts of mixed-source material save hours of manual syncing.

Key features

  • Three-step XML export, sync, import workflow
  • Four chronology types for clip order
  • Handles multi-hour multi-camera footage
  • Mixed camera and recorder formats
