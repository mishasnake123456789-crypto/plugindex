What Distributed Rendering Addon does

The Distributed Rendering Addon by CrowdRender shares a render across several machines on your network. It works with Cycles and Eevee, supports all render passes and integrates with the compositor.

Single frames and animations are divided into tasks computed on all computers, and results match rendering without the add-on. It lets studios use idle machines as a mini render farm. You get cycles and Eevee support, splits frames into network tasks and all render passes, along with the rest of the feature set.

Key features

  • Cycles and Eevee support
  • Splits frames into network tasks
  • All render passes
  • Compositor integration
