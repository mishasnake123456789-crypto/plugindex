What Lottie Export does

Lottie Export is a Blender plugin from MultLabs that turns Grease Pencil animation into lightweight vector animation for apps and the web. Drawn content is written as vector shape layers inside a Lottie file.

Output can be .json, .lottie or .tgs. A collection exporter places several Grease Pencil objects in one composition, optionally using only the selection. Three-dimensional points are projected through the camera into 2D composition pixels, and paths can be exported as polylines or beziers, with fill and stroke styles carried across.

Key features

  • Exports to .json, .lottie or .tgs
  • Several Grease Pencil objects in one composition
  • Camera-based projection to 2D
  • Polyline or bezier path export
  • Fill and stroke styles preserved
