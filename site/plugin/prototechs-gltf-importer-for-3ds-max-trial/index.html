What ProtoTech's GLTF Importer for 3ds Max® -Trial does

ProtoTech's GLTF Importer trial brings glTF models into 3ds Max with geometry, scale and textures intact. It supports 3ds Max 2023 through 2027 and reads triangulated, quad and other glTF mesh layouts.

Textures from the source file are applied, original colors are preserved, and a Low-Size Import mode avoids bloating the scene file. An automation license option lets a function be called without user intervention. The trial gives users a way to test the importer in their own pipeline when bringing web, game or AR assets into 3ds Max.

Key features

  • Imports glTF with geometry, scale and textures
  • Triangulated, quad and other mesh formats
  • Color import preserves original colors
  • Low-Size Import avoids file bloat
  • 3ds Max 2023 through 2027
