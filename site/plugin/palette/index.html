What Palette does

Palette turns popular terminal color schemes into Blender themes. More than 600 schemes drawn from iTerm2-Color-Schemes and Gogh can be searched, filtered and previewed live, then applied as a complete UI theme in one click.

A palette editor lets you modify the 16 ANSI colors, background, foreground, selection and cursor before applying. Perceptual OKLCH mapping derives surfaces, borders, text and contrast-checked elements. Themes can be fetched from the upstream repositories and cached, or loaded from a local folder of .itermcolors or YAML files, with Blender's online access setting checked first.

Key features

  • 600+ terminal schemes with live preview
  • Palette editor for ANSI and UI colors
  • OKLCH perceptual color mapping
  • Fetch and cache upstream themes
  • Local .itermcolors and YAML support
