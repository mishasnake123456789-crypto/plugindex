What Ms Super Tools (18 In 1) does

MS Super Tools by Mergim Sahiti collects 18 add-ons into a single Blender install, spanning modeling, animation, effects and scene management.

An Advanced Array live cloner with effectors sits alongside procedural scattering. Align Objects handles precise alignment and snapping, Mesh Tools and Cleanup fix meshes, Object Animator creates quick animation, and Tween and Vertex Jiggle Animator add smooth motion. Generalists get a broad toolkit without installing many separate packages. Under the hood you get advanced Array live cloner with effectors and procedural object scattering.
