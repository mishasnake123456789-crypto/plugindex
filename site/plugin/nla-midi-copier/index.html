What NLA Midi Copier does

NLA Midi Copier ties Blender animation to music data. In the Nonlinear Animation view an action can be copied so that it lines up with the notes of a MIDI file, with filters to choose which notes receive it and quick tools to copy to many notes at once.

In the Graph Editor, keyframes can be generated on existing F-curves from MIDI data, calculated from all pitches, a selected track, a scale, or properties other than pitch. Settings let you override which C is middle C, the file tempo and displayed track names, and an Instruments panel copies several stored actions together.

Key features

  • Copy actions to MIDI notes in the NLA editor
  • Note filters and quick copy tools
  • Generate keyframes from MIDI in the Graph Editor
  • Calculate from pitches, tracks or scales
  • Settings for middle C, tempo and track names
