Projects textures from three axes onto Blender meshes without UV unwrapping to build terrain and rock.

What Triplanar Displace does

Triplanar Displace uses Geometry Nodes to blend a texture projected along the X, Y and Z axes, so displacement works without any UV unwrapping. Flat meshes become terrain, rocks and other organic surfaces.

It is added with one click from the N-panel and appears in the modifier stack, where strength, tiling and orientation can be set per axis. The viewport updates in real time and the result stays non-destructive. Documentation is included. Environment artists and sculptors will find it quick for sculpting-free detail.

Key features

  • Three-axis projection with no UVs
  • Added with a single click in the N-panel
  • Per-axis strength, tiling and orientation
  • Pure Geometry Nodes, non-destructive
