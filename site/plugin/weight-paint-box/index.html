What Weight Paint Box does

Weight Paint Box pairs two tools within a single panel. Draw Bone builds custom armatures with Rigify support, while the weight workflow uses a deformation box in place of the usual brush.

The box reshapes like a normal cube, and each face carries its own smoothing circle that acts independently, with adjustable strength. It offers a more controlled way to skin characters. Together these tools address two common rigging chores, building the skeleton and weighting the mesh, from a single panel.

Key features

  • Deformation box replaces the weight brush
  • Per-face smooth circles
  • Draw Bone for custom armatures
  • Rigify support
