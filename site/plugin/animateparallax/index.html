What AnimateParallax does

AnimateParallax is a panel by TarouTools for building depth with parallax in After Effects. Layers can be positioned in Z by dragging values or markers in a visual view, with Shift for finer steps or by typing a number directly.

Near and Far values define the range, and buttons distribute layers evenly or randomly across it. Apply sets positions and adds parallax expressions, while Ctrl-click sets Z positions only. Bake converts expressions to keyframes, Refresh reloads layer data, and Reset restores original Z positions. Right-clicking a name selects that layer in the composition.

Key features

  • Visual and numeric Z-space placement
  • Distribute evenly or randomly in a range
  • Apply parallax expressions or Z positions only
  • Bake expressions to keyframes
  • Refresh and Reset controls
