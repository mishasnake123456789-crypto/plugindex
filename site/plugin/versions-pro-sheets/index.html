What Versions Pro-Sheets does

Versions Pro-Sheets is a beta tool from VDODNA that connects spreadsheet data to After Effects. It belongs to the Versions Pro-Mo toolset and integrates with Render-Brain.

Text can be injected from sheet tabs and layers switched on or off by tab. Local CSV files update automatically, as does a connected Google Sheet. Sound can be placed automatically, exported files are organised into folders, and batch rendering runs in the background through Adobe Media Encoder or across a network using Render-Brain. Broadcast and promo teams that produce many versions of the same package will save repeated manual edits.

Key features

  • Links Google Sheet or CSV data with layers
  • Text injection and layer toggling by tab
  • Batch rendering via AME or Render-Brain
  • Auto sound placement
  • Folder organisation for exports
