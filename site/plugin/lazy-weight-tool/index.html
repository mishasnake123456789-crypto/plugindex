Blender add-on for weight painting with an editable weight table, numeric weight setting and stronger vertex selection.

What Lazy Weight Tool does

Lazy Weight Tool makes weight painting in Blender more precise by letting you stay in weight paint mode while editing values numerically. A table shows vertex weights and their assigned groups, and can highlight values that match, exceed or fall below a threshold.

Set Weight and Flood functions apply to the current brush settings or to chosen values, and vertex indices can be displayed on the mesh. Riggers and character artists cleaning up skin weights will find numeric control a welcome complement to brush painting.

Key features

  • Weight table for vertex weights and groups
  • Match, More and Less highlighting
  • Set Weight and Flood with numeric values
  • Vertex index display on the mesh
