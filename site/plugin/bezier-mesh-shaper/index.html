What Bezier Mesh Shaper does

Bezier Mesh Shaper lets you shape a mesh by manipulating curves. Select vertices, call the tool and adjust the resulting curve to reshape the surface.

It works for roughing out and refining organic or hard surface models alike. Support spans Blender 2.79 through 5.2, and it is compatible with render engines such as Arnold, Cycles, Eevee, Octane and V-Ray. A documentation tab covers usage. Modelers wanting smooth, controllable deformation get an alternative to proportional editing.

Key features

  • Curve-based mesh deformation
  • Organic and hard surface use
  • Blender 2.79 through 5.2
  • Built-in documentation tab
