What versionUp does

Jeremy Cox's versionUp is a script built for After Effects aimed at artists who work with versioned footage. Click the up or down arrow to step through versions, or Shift-click to jump to the newest or oldest one available.

Option-click, or Alt on PC, increments a letter after the version number, so v001a becomes v001b. It handles stills, movies and image sequences, and can version composition and folder names. All version numbers in the file path are updated, not just the file name, and missing versions are skipped. Non-UI scripts can be assigned to Kbar buttons or custom shortcuts, and a settings panel adjusts behavior.

Key features

  • Step through footage versions with arrows
  • Jump to newest or oldest version
  • Letter increment with modifier click
  • Updates every version number in the path
  • Kbar scripts and custom shortcuts
