What B.B. Nodes Add-On does

B.B. Nodes Add-On extends the Geometry Nodes workspace in Blender with its own submenu in the Add menu. Inside are 98 custom node groups built for procedural modeling, so common operations are ready without constructing them from scratch.

Examples are Bend, Twist, Taper, Stretch, Screw, Solidify, Mirror, Inset, Array, Offset and Extrude along path. A 192-page user guide covers every node. It is marked as Blender Extension compatible and distributed under the GPL license.

Key features

  • 98 custom geometry node groups
  • Submenu inside the Add menu
  • Inset, Array, Bend, Twist, Solidify and more
  • 192-page user guide
  • Blender Extension compatible
