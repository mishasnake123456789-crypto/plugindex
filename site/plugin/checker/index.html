Blender add-on for inspecting UV state with node-based checker textures, part of the Zen UV add-on.

What Checker does

Checker lets you test UV layouts on a Blender model without disturbing existing materials. Checker textures are applied through a node-based system, so no new materials are added and current ones stay intact.

Zen UV Checkers include color and monochrome sets designed to read clearly in several sizes. A filter organizes textures according to resolution and whether they are square or rectangular, and you can add your own checker texture or an entire library. A UV Maps properties tab gives quick access to UV map management. It is part of Zen UV, with documentation on the developer's page.

Key features

  • Node-based checker application
  • Color and monochrome checker sets
  • Filter by resolution and format
  • Add your own textures or libraries
  • UV Maps properties tab
