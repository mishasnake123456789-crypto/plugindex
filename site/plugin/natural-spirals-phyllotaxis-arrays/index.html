What Natural Spirals (Phyllotaxis Arrays) does

Natural Spirals is a Blender add-on that arranges instances of an object in plant-like spiral patterns, the kind seen in sunflowers and pine cones. Parameters update live as you work.

The divergence angle defaults to the Golden Angle and a Parastichy Helper can set it from spiral counts. You choose an exact instance count, a clockwise or counter-clockwise direction, and start and end radius. A finalize step joins the instances into one editable mesh. Modelers and designers can use it for organic and decorative forms.

Key features

  • Golden Angle default with Parastichy Helper
  • Exact instance count and direction toggle
  • Start and end radius controls
  • Finalize step joins instances into one mesh
