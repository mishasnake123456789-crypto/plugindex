What Smart MediaComp Automator does

AE Genius's Smart MediaComp Automator is a tool built for After Effects aimed at repetitive composition work at scale. It places media and text into a large number of comps automatically, which suits template-heavy jobs.

A single click builds 4K videowalls, and animation actions include Scale in, Scale out, Scale and Rotate, Position Up and Position Down. An Automate it action handles repeated tasks. Changes apply across multiple compositions instantly, saving hours of manual copying.

Key features

  • Automates media and text into thousands of comps
  • One-click 4K videowalls
  • Scale and position animation actions
  • Automate it action for repetitive tasks
  • Applies changes across multiple comps
