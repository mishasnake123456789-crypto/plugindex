A floating panel script that sorts and organizes items in the After Effects project panel.

What Unravel does

Unravel brings order to a cluttered Project panel. It sorts content, and a pulldown option lets it sort items inside selected folders while leaving them where they are.

It runs as a floating panel with a responsive layout, and its menu collapses to the main button once the panel is shorter than 200 pixels. To save settings, the preference allowing scripts to write files and access the network must be enabled. It supports After Effects CC 2018 through 2025.

Key features

  • Organizes the project panel
  • Sorts within selected folders without moving items out
  • Responsive floating panel
  • Compact mode below 200 px height
  • Supports CC 2018 to 2025
