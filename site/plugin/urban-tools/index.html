What Urban Tools does

Urban Tools downloads real-world cityscapes from OpenStreetMap by address and radius, all inside Blender without third-party tools or file conversion.

Coordinates are transformed through Web Mercator for consistent metric alignment. The add-on creates building volumes, road curves and color-coded urban diagrams for analysis. It is a quick start for architects and planners needing context models and urban studies. Day to day, that covers direct OSM import by address and radius, web Mercator metric alignment and building volumes and road curves.

Key features

  • Direct OSM import by address and radius
  • Web Mercator metric alignment
  • Building volumes and road curves
  • Color-coded urban diagrams
