What Explode Geometry does

Explode Geometry is an Autodesk plug-in that splits one or more selected nodes into individual faces, either three-sided or four-sided depending on a radio button choice. It tries to convert the source to mesh first and stops if that is not possible.

Resulting faces can receive a Shell modifier with a set offset or an Edit Mesh modifier, and the stack can be collapsed to an editable mesh. Pivots can be centered on every face, the original geometry kept or deleted, and a progress bar with cancel appears during long operations. Useful for shattering and destruction setups.

Key features

  • Explodes nodes into 3- or 4-sided faces
  • Optional Shell or Edit Mesh modifier
  • Collapse stack to editable mesh
  • Center pivot on each face
  • Keep or delete original geometry
