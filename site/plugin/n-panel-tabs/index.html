Adds a header dropdown that jumps to any sidebar tab in Blender, along with options to hide, reorder and group the tabs.

What N-Panel Tabs does

N-Panel Tabs addresses the clutter that builds up in Blender's sidebar when many add-ons are installed. A single dropdown in the viewport header takes you straight to any tab.

You can disable tabs you never use, reorder them by priority, sort everything instantly and create custom groups to structure complex setups. Documentation is included. It helps anyone who spends time scrolling across tabs looking for a tool. It also keeps its interface compact, so the controls stay out of the way when you are just trying to tidy the tab list.

Key features

  • Header dropdown to jump to any N-panel tab
  • Disable unused tabs
  • Reorder tabs by priority
  • Instant sorting
  • Custom groups for complex setups
