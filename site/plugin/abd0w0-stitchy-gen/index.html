What Abd0W0 Stitchy Gen does

Abed al rahman's Abd0W0 Stitchy Gen makes stitch detail for Blender that survives animation, simulation, rigging and shape keys. A layering system keeps stitches organized and the interface stays friendly.

Each stitch set includes a UV map called ASG_UV for use in an attribute node. Documentation is included. Artists adding seams to furniture, clothing, characters and props gain a reliable procedural method. Since stitches follow the underlying surface, they stay attached when the mesh bends, stretches or is simulated.

Key features

  • Works with animation, simulation, rigs and shape keys
  • Layering system for stitches
  • Friendly user interface
  • Generates ASG_UV map
  • Documentation included
