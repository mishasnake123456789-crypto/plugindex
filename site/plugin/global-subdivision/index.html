Adds a Global SubD modifier to Blender that syncs subdivision settings across all objects using it.

What Global Subdivision does

Global Subdivision provides a Subdivision modifier whose settings are shared between objects. Change a core property on one Global SubD modifier and every other one in the scene updates instantly.

There is no master modifier, so any of them can be the source of a change. This avoids opening each object to adjust levels and keeps a set of parts consistent. Modelers working on many subdivided pieces will appreciate the single-point control.

Key features

  • Real-time syncing across the scene
  • No master modifier needed
  • Any instance can drive a change
  • Consistent subdivision across objects
