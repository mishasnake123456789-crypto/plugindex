Blender add-on that copies location, rotation and scale keyframes from a target object onto chosen frames.

What Copy Key Transform does

Copy Key Transform transfers animation keys from one object to another on frames you pick. It helps when you only need part of a motion rather than the whole action.

Toggles decide whether location, rotation or scale keys are copied. The frame field accepts single frames and ranges, for example 1,3,5-10,25-100. A demo video and documentation are included.

Key features

  • Copies location, rotation and scale keys
  • Per-channel toggles
  • Frame field accepts lists and ranges
  • Demo video and documentation
