What ❤️ Control Like In Games does

studioromanrec's Control Like In Games turns Blender into a mini game controller. Pick a character, a car or any animal and steer it with keyboard and mouse, with the response happening live.

Press R to capture your moves as animation, then play them back. Documentation is included, and the add-on covers Blender from 2.93 into the 4.x series. Animators can perform rough blocking instead of keyframing it. Recording happens in the same session, so you can iterate on a performance without leaving the viewport.

Key features

  • Control a character, car or animal
  • Real-time keyboard and mouse control
  • Press R to record as animation
  • Documentation included
  • Blender 2.93 to 4.x
