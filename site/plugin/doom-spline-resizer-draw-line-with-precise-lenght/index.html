What Doom Spline Resizer - draw line with precise lenght does

For 3ds Max, Doom Spline Resizer sets any spline to a precise length. The pivot goes to the shape's first vertex and is aligned with the first segment, and then a small window takes the length you want and scales the spline to match.

It works with any single-spline shape, and on complex splines it sets the total length. Choosing a different line brings up the resize rollout right away, and the tool can sit on a hotkey (D is unused by default) or a toolbar button. A Polar-mode shortcut button is included, and the SET button resizes several selected splines at once.

Key features

  • Pivot set to first vertex and aligned to first segment
  • Window for entering exact spline length
  • Works on any single-spline shape, including complex ones
  • Assignable to a key or toolbar button
  • SET button resizes multiple splines at once
