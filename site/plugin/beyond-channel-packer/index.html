Beyond Channel Packer

Blender add-on for packing and splitting texture channels in the Image Editor, including RGB plus alpha and four-image RGBA.

What Beyond Channel Packer does

Beyond Channel Packer handles texture channel packing without leaving Blender's Image Editor. RGB plus Alpha mode combines a color image with an optional mask, which is flattened to a single grayscale channel for the output alpha.

4-Channel mode combines four distinct images into a single RGBA file, and it can also split a multi-channel image back into individual channel files. Game artists packing roughness, metallic and occlusion into one map can do it in one place.

Key features

  • RGB plus alpha mask mode
  • 4-Channel merge into RGBA
  • Split multi-channel images into files
  • Works directly in the Image Editor
