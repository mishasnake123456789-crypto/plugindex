What miauu's LayerColorizer - color-coded layers does

LayerColorizer by miauu adds color coding to layers in the 3ds Max Layer and Scene Explorers. Any layer can get its own background and text color, independent of the real Layer Color, so scene data is untouched.

The same color can be applied to all child objects of a colored layer for clearer visual organization, and preferred colors can be stored in Color Palettes for reuse. Large scenes with many layers become faster to scan, since categories stand out immediately. Both 3ds Max and 3ds Max Design from 2020 to 2025 are supported.

Key features

  • Custom background and text colors for layers
  • Option to color all child objects too
  • Independent of the actual Layer Color
  • Savable Color Palettes
  • Works with 3ds Max 2020 through 2025
