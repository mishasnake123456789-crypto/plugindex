What Quick Resolution Setup does

Quick Resolution Setup is a Blender add-on by Hades-Su that makes adjusting render resolution a matter of a few mouse clicks. Common resolutions are available as presets, so you do not have to type values for each project.

With the ratio lock on, editing one dimension adjusts the other, and a ratio list is optional. Resolution can be stepped up or down by 1x and swap X and Y without retyping, which is handy for switching between landscape and portrait. The controls live in Output Properties, within the Resolution Format section, and the author name can be hidden through preferences.

Key features

  • Common resolution presets
  • Ratio lock with an optional ratio list
  • 1x zoom in and out
  • Swap X and Y values
  • Located in Output Properties
