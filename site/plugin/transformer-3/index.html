What Transformer 3 does

Transformer 3 from Nataworkstudio is a footage transformation and animation tool for After Effects. This version brings 49 new presets, a redesigned interface, and the formerly separate Transform Pack built in.

Transform animations can be saved and loaded, and rotation radius and arc are adjustable. A Multi FX Selector, Magnetize and Sequence to Keyframes help build complex moves, while a Presets Browser provides control over animation speed. Motion designers can start from a preset and refine it instead of keyframing every transform by hand.
