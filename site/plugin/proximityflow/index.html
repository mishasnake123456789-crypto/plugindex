Proximityflow

Developer: Blender Wave

FreeBlender
Download Free

Blender add-on that drives mesh effects from a target object's distance, with falloffs, motion paths and keyframing.

What Proximityflow does

ProximityFlow activates effects on a mesh wherever a chosen target object comes close. Move the target away and the effect fades, with the viewport updating live.

You can stack several independent proximity layers on one object, each with a different target. A motion path system attaches the target to a curve so the effect travels across the mesh automatically. Five falloff types are available (Linear, Smooth, Sharp, Sphere, Root), and Auto Subdivide adds mesh density up to six levels before effects are applied.

Key features

  • Multiple independent proximity layers
  • Motion path system for the target
  • Five falloff types
  • Auto Subdivide up to 6 levels
  • Live viewport updates
