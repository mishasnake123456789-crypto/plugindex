Blender extension that sends render start, finish and cancel alerts to Discord, desktop popups or webhooks with progress.

What Render Notifications-Frame By Frame Alerts does

Render Notifications keeps you informed about renders in Blender, even when you are away from the screen.

Desktop alerts mark when a render starts, finishes or is cancelled, with optional custom .wav sounds. Frame by frame updates go to a private Discord channel, with the message edited as progress advances, and Discord previews can show a single frame or the first and last frame of an animation. Third-party webhooks are supported.

Key features

  • Desktop alerts for start, finish and cancel
  • Frame by frame Discord updates
  • Progress estimates
  • Preview images in Discord
  • Third-party webhook support
