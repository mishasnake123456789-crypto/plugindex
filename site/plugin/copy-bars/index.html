Copy Bars

Developer: MeguiTaA12

FreeBlender

Acts as a clipboard for Blender armature poses and object transforms that can be keyframed and moved between projects.

What Copy Bars does

Copy Bars stores poses and transformations as bars so they can be reused without building a pose library. Pose Mode captures the pose of a whole armature or only selected bones.

Transform mode records an object's location, rotation and scale, plus any custom properties. Stored items can be keyframed and carried across projects. Animators repeatedly reusing poses will appreciate the simplicity. Compared with a full pose library, it stays lightweight and works well for temporary or cross-project reuse.

Key features

  • Capture full or partial armature poses
  • Save object location, rotation and scale
  • Custom properties stored with data
  • Keyframe stored bars
  • Move between projects
