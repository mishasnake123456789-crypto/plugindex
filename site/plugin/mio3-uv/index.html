What Mio3 UV does

Mio3 UV extends Blender's UV Image Editor with a panel in its sidebar. It focuses on unwrapping, layout, symmetry and selection, with some features chosen especially for character work.

Unwrap commands include one that preserves original position, size and angle, as well as Straight, Normalize, Gridify, Rectify, Projection Unwrap and Virtual Mirror. Layout commands handle aligning, sorting and distributing, and arrange tools offer relax, stack, merge, circle and seam alignment. Symmetry operations are included as well. Character artists and texture artists will speed up UV cleanup.

Key features

  • Many unwrap operators
  • Align, sort and distribute layout tools
  • Relax, stack, merge and seam alignment
  • Symmetry operations
