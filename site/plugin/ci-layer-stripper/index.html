What CI Layer Stripper does

CI Layer Stripper cleans out the clutter that accumulates in After Effects projects. It deletes guide layers, visible nulls nothing refers to, locked layers that are unreferenced, and effects that have been switched off.

The script reads expressions during its scan, recognizing references by layer index and by name, including those pointing into other comps, so it doesn't remove what is still being used. Be careful with locked layers that host plug-ins such as Trapcode Particular. It is a good pre-delivery tidy-up from Creative Impatience.

Key features

  • Removes guide layers
  • Removes unreferenced visible nulls
  • Removes locked unreferenced layers
  • Removes disabled effects
  • Understands expression layer references
