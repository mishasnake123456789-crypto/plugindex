Node-based view of Blender rig parenting and constraints, editable and synced to the scene.

What Schematic Editor does

Schematic Editor shows parenting and constraint relationships as an editable node graph, replacing endless Outliner foldouts.

Objects, bones and constraints connect with node links, including parenting objects directly to bones, and Child Of, Copy Rotation, IK and Pole Vector constraints can be created in the schematic. Edits sync back to the 3D scene. It makes complex rigs easier to read and fix. Highlights include node view of parenting and constraints, link objects, bones and constraints and create common constraints in the graph.

Key features

  • Node view of parenting and constraints
  • Link objects, bones and constraints
  • Create common constraints in the graph
  • Syncs edits to the scene
