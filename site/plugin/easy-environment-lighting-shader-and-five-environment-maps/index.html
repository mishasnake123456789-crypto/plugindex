What Easy Environment Lighting (Shader) & Five Environment Maps does

Phone-captured panoramas often lack the contrast needed for lighting. differentlink's Easy Environment Lighting is a shader whose node setup strengthens contrast, so almost any image can serve as an HDRI.

Five maps of 47 megapixels are included, and the memory footprint is small, about a sixteenth of an equal-sized 32-bit image. The documentation explains how to capture panoramas with the Photosphere app and how to use them. Good for quick custom lighting environments.

Key features

  • Turns any image into an HDRI
  • Contrast boost node setup
  • Five 47 megapixel environment maps
  • Low memory footprint
  • Phone capture guide with Photosphere
