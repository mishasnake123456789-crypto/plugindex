What mamoworld Automation Blocks does

mamoworld Automation Blocks supplies premade one-click tools for After Effects and Premiere Pro, and lets you modify them or assemble new ones from blocks, without writing code. It targets the repetitive chores that eat up production time.

Bundled tools include comp duplication from a spreadsheet, a color palette workflow, an enhanced precompose, project cleanup and randomize. Blocks can read and write spreadsheet and text files, adjust keyframes, show custom dialogs, and manage folders and backups on disk. Tools launch from keyboard shortcuts, Kbar or a quick menu.
