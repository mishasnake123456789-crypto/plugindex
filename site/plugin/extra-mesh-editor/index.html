What Extra Mesh Editor does

EBTRR's Extra Mesh Editor bundles utilities for repairing and analyzing meshes in Blender. It creates convex hulls, strips non-manifold edges and vertices, and closes holes in 2-manifold meshes.

Discrete and principal curvature, each with two calculation methods, can be painted as vertex colors. The tools can be applied to one object or an entire collection, and triangles can be turned into quads. Useful for scan cleanup, 3D printing preparation and procedural shading masks. Results from the curvature tools can feed shaders for edge wear, dirt and other mask-driven effects.

Key features

  • Convex hull generation
  • Non-manifold cleanup and hole closing
  • Curvature painted as vertex colors
  • Runs on objects or collections
  • Tris to quads
