What broadcastGEMS Adaptive Text Tool does

The Adaptive Text Tool is an After Effects-built Mogrt that animates text in Premiere Pro. Its distinguishing trait is that it recalculates text properties when you change between eight frame sizes and aspect ratios.

It includes 65 prebuilt setups and 70 adjustable properties, plus modules such as OutlineFX, animated tracking and scaling, Raised CapFX and Fit-to-Width/Height. Frame size is switched from the Essential Graphics Panel, it supports sizes from 4K to 1080 x 1920, and it works with Auto Reframe.

Key features

  • 65 prebuilt text animation setups
  • 70 adjustable properties
  • Adapts across eight frame sizes and ratios
  • Modular effects like OutlineFX and Fit-to-Width
