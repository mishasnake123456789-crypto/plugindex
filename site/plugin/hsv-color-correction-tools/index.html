What Hsv Color Correction Tools does

SMArchviz's HSV Color Correction Tools gives quick color control over textures and materials in Blender. Hue, saturation and brightness are adjustable, and a color overlay helps a material sit within a scene's tone.

A one-click fix repairs assets brought in with the Megascan add-on, Clone Material copies the material of the selected object, and Arrange Material Nodes tidies the shader editor layout. Archviz and look development artists adapting library materials will save time.

Key features

  • Color overlay to match scene tone

  • Clone Material tool
