What Quick Uv Projector does

Quick UV Projector fits textures to a model by looking at where it sits in 3D space relative to a background image. It detects the background border and projects UVs according to how the model lies within those bounds.

Moving the model over a different texture switches to it, automatically finding the nearest background and creating the material. It works in object, edit and sculpt modes. Artists doing projection painting, photo-based texturing or quick layouts get fast fitting without manual unwrapping.

Key features

  • UV projection from 3D position over a background
  • Texture switching by moving the model
  • Automatic nearest background and material creation
  • Object, edit and sculpt modes
