What Graph Chart Animator does

Graph Chart Animator reads a CSV file and builds an animated 3D bar chart directly in Blender. It reads both 2D and 3D data layouts, including text, value and x-value columns.

Bars can be cubes, cones or cylinders, axes and labels are customizable in size, visibility and format, and bars, labels and other elements have separate color control. Animation can run sequentially or all at once. Motion designers producing data stories and presentations get dynamic charts without leaving 3D.

Key features

  • CSV import to animated 3D bar charts
  • Cube, cone or cylinder bars
  • Customizable axes and labels
  • Sequential or simultaneous animation
