Blender add-on for vertex colors, with preview including alpha plus fill, randomize, gradient and smoothing tools.

What HUE does

HUE helps with vertex color work in Blender. It displays vertex colors, alpha included, from both object and edit modes and provides tools for filling, randomizing, creating gradients, smoothing and coloring by selection.

In edit mode, painting can be restricted to selected points, edges or faces, and RGBA masking limits changes to particular channels. Game artists and procedural-shading users who store data in vertex colors can edit and check it more directly.

Key features

  • Vertex color preview with alpha
  • Fill, randomize, gradient and smooth tools
  • Edit-mode selection restricts painting
  • RGBA channel masking
