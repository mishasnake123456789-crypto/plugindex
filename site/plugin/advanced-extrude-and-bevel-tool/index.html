What Advanced Extrude And Bevel Tool does

The Advanced Extrude And Bevel Tool groups three modeling operations in Blender's sidebar Edit tab.

Edge subdivision cuts edges into multiple segments for smoother surfaces and finer detail. Selective extrusion works on chosen edges or faces with a set amount. Custom bevels provide adjustable width, segments and profile shapes, from smooth to sharp transitions. All parameters are adjustable for each operation. Modelers can refine edges and add detail without moving between several menus, which keeps the process quick.

Key features

  • Edge subdivision with custom cuts
  • Selective extrusion of edges or faces
  • Custom bevel width, segments and profile
  • All controls in the Edit tab
  • Adjustable parameters per operation
