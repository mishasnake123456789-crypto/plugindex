Transfer Images

Developer: Amandeep

FreeBlender

Free Blender add-on that moves image textures from one UV map to another from the Shader Editor's sidebar.

What Transfer Images does

Transfer Images saves effort when a model's UV layout changes. From the N-panel in the Shader Editor, under the Node section, it transfers image content between UV maps for one or several image nodes at once.

A popup panel lets you choose the source and target maps. Texture painters and asset creators who re-unwrap meshes can carry painted work across rather than repainting.

Key features

  • Transfers images between UV maps
  • Runs in the Shader Editor N-panel
  • Single or multiple image nodes
  • Popup for source and target selection
