After Effects tool for recording voice-overs inside the timeline, with speech-to-text, text-to-speech and translation.

What AE Voice Recorder does

AE Voice Recorder from MotionCodes records audio directly in After Effects, using a computer, webcam or external microphone. A simple record button starts and stops capture, which suits voice-overs, scratch tracks, notes and client comments.

Speech To Text turns an audio layer into text in all languages for subtitles, and Set Subtitle builds subtitles from that text or from text entered by hand. Text To Speech does the reverse in all languages, and Text Translator converts text from Voice layers or typed input for subtitles. It also works for voice memos and podcast audio.

Key features

  • Record from computer, webcam or external mic
  • Speech to text in all languages
  • Subtitle creation from extracted or typed text
  • Text to speech in all languages
  • Text translation for subtitles
