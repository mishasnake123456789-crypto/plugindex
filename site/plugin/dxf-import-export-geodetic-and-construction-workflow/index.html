What Dxf Import Export - Geodetic & Construction Workflow does

DXF Import Export is a Blender add-on for geodetic and construction work with CAD drawings. It reads and writes DXF geometry while keeping real-world coordinates and supports reference-point placement.

Imported content is organized by layer. Supported model-space entities include LINE, ARC, CIRCLE, POLYLINE, SPLINE, ELLIPSE, POINT, 3DFACE, SOLID, MESH, DIMENSION, TEXT and MTEXT. Surveyors and engineers can bring plans into Blender and send results back. Among its tools are DXF import and export and layer-based organization.

Key features

  • DXF import and export
  • Layer-based organization
  • Wide range of supported entities
  • Reference-point placement
