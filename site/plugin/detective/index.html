Splits Premiere Pro's clip Enable toggle into separate Enable and Disable actions with in/out range and selection support.

What DÉTECTIVE does

DÉTECTIVE replaces the single Enable toggle in Premiere Pro with two explicit commands, so a clip is set to a known state rather than flipped. That avoids accidentally reversing a selection that mixes enabled and disabled clips.

The state can be applied to the selected clips or to every clip between the sequence in and out points. It can also select just the enabled clips or just the disabled ones, which makes it simple to find, review or delete everything that has been switched off. Editors who clean up long timelines will get the most from it.

Key features

  • Separate Enable and Disable commands
  • Set selected clips directly to either state
  • Apply to clips between in and out points
  • Select only enabled or only disabled clips
