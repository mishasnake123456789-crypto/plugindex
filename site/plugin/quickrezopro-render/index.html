Blender add-on for quick resolution presets, custom sizes, width/height switching, an FPS slider and one-click rendering.

What Quickrezopro Render does

QuickRezoPro Render simplifies output settings in Blender. Resolution changes that normally take several field edits become one click.

Presets span Mobile, Tablet, Laptop, Desktop, Various, Panoramic and social media formats, and you can type a custom width and height. A switch tool swaps them, an FPS slider sets frame rate, and images or animations render with one click. Links to Tri-Vima Studio resources are included. It saves time when the same project must be delivered in several aspect ratios.

Key features

  • Presets for devices and social platforms
  • Custom width and height
  • Switch tool for orientation
  • FPS slider
  • One-click image and animation render
