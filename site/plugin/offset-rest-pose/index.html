Blender add-on that preserves existing animation when you apply a new rest pose to an armature.

What Offset Rest Pose does

Offset Rest Pose, by William-Leong, deals with a common rigging snag: applying a rest pose normally disturbs animation already made on the armature. This add-on offsets the animation so it is preserved when the rest pose changes. It is listed under Animation.

It is open source under GPL-3.0-or-later and requires Blender 5.2.0 or newer.
