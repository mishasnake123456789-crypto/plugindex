What mamoworld QuickImporter does

mamoworld QuickImporter replaces the standard import dialog in After Effects, Premiere Pro and Audition with a quicker browser for big footage libraries. Its fuzzy keyword search scans thousands of files and still returns hits when a term is mistyped.

Hovering over an audio file plays it, and video files can open in a media player for preview. Image sequences appear as one result rather than hundreds of frames. Thumbnails come from macOS Quicklook for most file types on Mac, but only JPG and PNG on Windows. One license covers all three applications, and Audition multitrack sessions are supported.

Key features

  • Fuzzy keyword search across thousands of files
  • Hover-to-play audio preview
  • Image sequences shown as a single result
  • Thumbnails via macOS Quicklook
  • One license for Premiere Pro, After Effects and Audition
