What Node Note/节点随记 does

Node Note is a Blender add-on by W_Cloud for annotating node trees directly. You can attach text notes, images from the clipboard and numbered badges to nodes, and reach everything from the right-click menu or the N-panel.

Text notes have adjustable font size, colors, background, alignment and offset. Image notes can be pasted from the clipboard, including content copied from PowerPoint or Photoshop, with adjustable width and pack and unpack support so files stay portable. Numbered badges are assigned by clicking, have customizable colors, and let you navigate between numbered nodes.

Key features

  • Customizable text notes on nodes
  • Image notes pasted from the clipboard
  • Pack and unpack images for portability
  • Numbered badges with navigation
  • Right-click menu and N-panel access
