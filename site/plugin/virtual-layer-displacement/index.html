What Virtual Layer Displacement does

Virtual Layer Displacement mixes two PBR texture sets inside one Blender material according to their height maps, so one surface naturally appears through gaps in another, like moss in cracks or sand over stone.

Create both texture sets in a material and press the button to set up the layering. A Level slider quickly changes how much of each material shows, an image texture input gives more precise mixing control, and a VarStrength slider adjusts how strongly the surface is deformed.

Key features

  • Mixes two PBR materials using their height
  • Level slider for quick layering
  • Image texture input for precise mixing
  • VarStrength slider for deformation strength
