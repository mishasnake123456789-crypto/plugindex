Blender rigging add-on that draws bones with the curve tool and adds weight paint, mask and constraint helpers.

What Draw Bone does

Animation Store's Draw Bone is for custom rigs in Blender. Draw bones with the curve tool, then clean them and recalculate their roll.

Helpers include a quick weight paint fix for a selected polygon, hiding extra parts with a mask modifier during work, and snapping and constraining a chosen IK bone to an object or an object to a bone. Documentation is included. Riggers building unusual creatures or props will find the workflow direct.

Key features

  • Draw bones with the curve tool
  • Clean bones and recalculate roll
  • Quick weight paint fix for selected polygons
  • Mask modifier for hiding parts
  • Snap and constrain IK bones and objects
