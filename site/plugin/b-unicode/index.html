What B Unicode does

B Unicode is a Blender add-on by Dinesh007 that puts Unicode characters at hand in the Text Editor, the Video Sequence Editor and the 3D Viewport. Categories range from emojis and general symbols to math operators and currency signs, shown in a grid you can browse.

Copy Mode puts a chosen character on the clipboard in one click, while Insert Mode places it directly into a text block, a VSE text strip or a 3D text object. It spares you from searching the web for special characters when titling or annotating.

Key features

  • Categories for symbols, emojis, math and currency
  • Grid display for browsing characters
  • Copy Mode puts a character on the clipboard
  • Insert Mode for text blocks, strips and 3D text
  • Works in Text Editor, VSE and 3D Viewport
