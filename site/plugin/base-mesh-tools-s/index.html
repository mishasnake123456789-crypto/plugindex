What Base Mesh Tools - S does

Kihoon's Base Mesh Tools - S speeds up the first stage of character sculpting in Blender. It generates base meshes fast and reshapes them into assorted body types.

Brush Mode adds or cuts mesh, swaps objects and symmetrizes. Transform tools handle rotation, movement and multi-object work, while Hierarchy Select, Constraint Axis and Set Cursor help with positioning, and Set Parent, Align and Reset Profile finish setup. A separate shortcut sets smooth brush strength. Documentation is included. Sculptors avoid blocking out forms from scratch.

Key features

  • Quick sculpting base meshes
  • Brush Mode to add, cut and symmetrize
  • Move, rotate and multi-object transform
  • Hierarchy Select and Constraint Axis
  • Separate smooth brush shortcut
