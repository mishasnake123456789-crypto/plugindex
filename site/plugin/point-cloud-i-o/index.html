What Point Cloud I/O does

Point Cloud I/O, from StudioMedio, brings scanned and surveyed point data into Blender and back out. Supported file types are E57, LAS, LAZ, PLY, PCD, XYZ and PTS, for both reading and writing.

Rather than falling back to meshes, it creates Blender's own PointCloud objects and can handle datasets with millions of points. PTS import understands the Leica Cyclone format. Architects, surveyors and visual effects artists who work with laser scans will find it useful.

Key features

  • Seven formats: E57, PLY, LAS, LAZ, PCD, XYZ, PTS
  • Uses native PointCloud objects
  • Handles million-point datasets
  • Import and export support
