What Parallax Node (Free) does

Parallax Node gives Blender materials a depth illusion without extra geometry. The height map texture sits inside one node, which also exposes a step parameter that sets the number of iterations.

It connects in the shader node editor, works with custom UV layers, and previews in real time in Cycles and EEVEE. Artists texturing bricks, tiles, cobblestones or windows can add convincing relief cheaply, trading quality against speed with the step value.

Key features

  • Single node containing the height texture
  • Adjustable step parameter
  • Works with custom UV layers
  • Live preview in Cycles and EEVEE
