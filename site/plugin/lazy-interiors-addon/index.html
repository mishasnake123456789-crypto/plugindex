What Lazy Interiors Addon does

Lazy Interiors Addon is a browser-style asset library for room and interior scenes in Blender. 380 curated assets can be added by category without manual Append or Link steps, and 34 ready-made interior scenes import the same way.

Quick Snap Tools make placement simple, and a built-in library supplies materials to apply to furniture and surfaces. Archviz and interior artists can furnish a space quickly and move on to lighting and rendering.

Key features

  • 380 curated interior assets by category
  • 34 ready-to-use interior scenes
  • Quick Snap placement tools
  • Built-in materials library
