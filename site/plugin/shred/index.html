What Shred does

Shred is a utility for people who write MaxScript. It keeps snippets of code in one place so functions and algorithms do not get lost in old scripts or forgotten folders.

Snippets can be tagged, making them easy to find when the same problem comes up again, and they can be retrieved and reused whenever needed. Over time you can improve commonly used pieces, building a personal library of tested code. It supports 3ds Max 2011 and newer and is mainly of interest to technical artists and scripters who want a light way to organize their code.

Key features

  • Stores MaxScript snippets in one place
  • Tags functions and algorithms
  • Retrieves snippets on demand
  • Supports refining snippets over time
  • Supports 3ds Max 2011 and newer
