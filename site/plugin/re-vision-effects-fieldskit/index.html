What RE:Vision Effects FieldsKit does

RE:Vision Effects FieldsKit handles field-based footage in After Effects and Premiere Pro, and Final Cut Pro is supported as well. It includes a Deinterlacer, a Reinterlacer and a Pulldown tool.

The Deinterlacer can build a full frame from each field, while the Reinterlacer offers an option to create motion-estimated fields. GPU processing speeds the work, and Apple M1 systems have been supported since version 4.0. It suits editors and compositors converting between interlaced and progressive material.

Key features

  • Deinterlacer that can create a frame from each field
  • Reinterlacer with motion-estimated fields
  • Pulldown for field-based footage
  • GPU processing
  • Apple M1 support since v4.0
