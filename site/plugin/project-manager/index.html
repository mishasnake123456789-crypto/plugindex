What Project Manager does

Project Manager by Kstudio organizes large 3D libraries in 3ds Max. A local AI engine sorts models by object type, material, form and style with no manual tagging and without sending data off your machine, working in the background at low priority so rendering is not disturbed.

You can search by name, by color palette using perceptual similarity, or find similar assets from a reference image or mood board. Gallery tabs hold models, materials and external links, with live previews of bitmaps, proxies, materials and IES lights. A shared database mode supports teams across workstations, and ZIP, RAR and 7Z archives can be browsed.

Key features

  • Local AI classification by type, material, form, style
  • Color search and Find Similar by image
  • Gallery tabs for models, materials and links
  • Previews of bitmaps, proxies, materials, IES lights
  • Shared database mode for teams
