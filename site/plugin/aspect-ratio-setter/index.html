Assigns render resolutions per camera in Blender 4.4+, with presets for YouTube, Instagram, TikTok and custom ratios.

What Aspect Ratio Setter does

Aspect Ratio Setter avoids resetting render settings whenever you change camera. Each camera can hold its own output size, so widescreen, vertical and square shots live in the same file.

Built-in presets include YouTube, Instagram, TikTok, standard, vertical and cinematic formats, and you can save custom aspect ratios. It requires Blender 4.4 or newer and suits creators delivering the same scene in several formats. Since every camera carries its own format, one scene can deliver widescreen, vertical and square versions without constant resetting.

Key features

  • Per-camera aspect ratios
  • Presets for YouTube, Instagram, TikTok
  • Standard, vertical and cinematic formats
  • Save custom presets
  • Blender 4.4+
