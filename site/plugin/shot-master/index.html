Manages animation shots, cameras and markers in Blender, with batch rendering and automatic camera switching.

What Shot Master does

Shot Master organizes shots in a list. You name each shot, link a camera and set frame ranges by time, value or the current frame.

Selected shots can be batch rendered with automatic camera switching, per-shot checkboxes and a live progress bar (v1.2). A camera list creates named cameras, with marker and camera constraint management. It suits multi-shot animation projects. Notable points: shot list with linked cameras, batch render with camera switching and frame range options.

Key features

  • Shot list with linked cameras
  • Batch render with camera switching
  • Frame range options
  • Camera and marker management
