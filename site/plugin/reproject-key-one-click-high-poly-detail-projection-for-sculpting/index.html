What Reproject Key - One-Click High-Poly Detail Projection For Sculpting does

Reproject Key works in Blender's Sculpt Mode and transfers detail from an underlying high-poly mesh onto the one you are sculpting. One click projects the current surface, and you can paint a mask to limit the effect to the areas that matter.

Several projection modes are offered: Project, Target Normal Project, Nearest Surface Point and Nearest Vertex. After each projection the result is stored as an independent, editable Shape Key layer, available when the mesh has no Multires modifier. Mask-based adding and subtracting, projection-range mirroring and other shape key management tools are handled inside Sculpt Mode, so detail stays non-destructive.

Key features

  • One-click projection onto an underlying high-poly
  • Mask painting to choose projected areas
  • Four projection modes
  • Automatic editable Shape Key layer per projection
  • Shape Key management inside Sculpt Mode
