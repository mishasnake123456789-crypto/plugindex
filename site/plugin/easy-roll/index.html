Turns selected Blender objects into rolling animations, with rotation computed from surface area and optional soft body bulge.

What Easy Roll does

Easy Roll creates rolling motion for objects in Blender. Pick the objects and press Roll Selected Objects, and the add-on works out each one's rotation from its surface area, so movement looks believable.

An Enable Simulation button sets keyframes, and a soft-body bulge effect can add realism. Good for balls, wheels and barrels. Rotation that matches the object's size avoids the sliding or spinning-too-fast look that plagues hand-keyed rolling shots.

Key features

  • Roll Selected Objects button
  • Rotation from surface area
  • Optional soft-body bulge
  • Keyframe setup
