Bookmark View

Developer: waylow

Blender add-on that stores multiple 3D viewport positions as bookmarks you can return to with one click.

What Bookmark View does

Bookmark View saves camera positions of the 3D viewport in Blender so you no longer have to zoom, pan and rotate repeatedly to get back to a spot. Add as many bookmarks as you need, then switch between them with a click.

Bookmarks can be named manually or automatically, deleted, reordered, or replaced with the current view. Only the active 3D view is changed, which makes it convenient for inspecting different parts of a large model or comparing angles.

Key features

  • Unlimited saved view bookmarks
  • Add, delete and reorder entries
  • Replace a bookmark with the current view
  • Manual or automatic naming
  • Only changes the active 3D view
