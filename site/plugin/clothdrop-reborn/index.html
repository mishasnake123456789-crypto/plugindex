Blender add-on that drops a cloth simulation over any object in one click, with a plane you draw or supply.

What ClothDrop Reborn does

ClothDrop Reborn takes the setup out of draping fabric in Blender. Either select a plane and drop it, or sketch a rectangular plane in the viewport above the target object, and the cloth simulation is ready in seconds.

It avoids manual simulation settings and keyframing. Draw Cloth makes the plane for you, while Create and Drop Cloth works with planes you built yourself. Controls are accessible from the interface, making tablecloths, sheets and covers straightforward to produce.

Key features

  • Single-click cloth simulation
  • Draw Cloth makes a plane on screen
  • Create and Drop Cloth for custom planes
  • No manual setup or keyframing
