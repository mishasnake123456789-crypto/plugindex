What R_R_T does

R_R_T is a utility from Adobe that changes a setting inside Premiere Pro to address an issue some users have encountered. Adobe advises installing it only if an Adobe employee points you to it.

It provides a visible panel with a button to toggle the controlled settings. Version 2.0.0 was updated in March 2023, and it supports Premiere Pro 14.0 and later. Only install it if told to, since it has no general-purpose function.
