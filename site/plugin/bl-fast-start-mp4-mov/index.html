Blender add-on that adds a Fast Start copy of MP4 or MOV renders with the moov atom moved to the front.

What BL Fast Start (MP4/MOV) does

BL Fast Start adds a checkbox to Blender's output panel for MP4 and MOV renders. When enabled, an extra copy is written with the moov atom moved to the start of the file so video can begin playing before it has fully downloaded.

The checkbox appears only when the MPEG-4 or QuickTime container is selected. The normal render is untouched, so you end up with two files, and the default suffix -faststart can be changed in preferences. Processing is based on qtfaststart. It is pure Python and tested on Windows 11 and Linux Mint.

Key features

  • Checkbox in the output panel
  • Extra Fast Start copy of MP4 or MOV
  • Original render left untouched
  • Customizable filename suffix
  • Based on qtfaststart
