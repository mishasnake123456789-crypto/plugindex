A Blender add-on that merges a Mixamo character with several animations into one FBX with clean transitions.

What Combinemixamo does

CombineMixamo addresses the clumsy job of joining multiple Mixamo clips on one character. It combines the character with several animations, keeps positions continuous between them, and bakes the result into a single action ready for FBX export.

It uses an NLA-based workflow, baking multiple NLA strips into one action. A keyword search panel finds FBX files by terms such as walk, talk, kick or fly, then a filtered list and a final selection list let you manage which files to combine. Game developers and animators building character move sets will cut a lot of manual stitching.

Key features

  • Combines a character with multiple Mixamo animations
  • Position-accurate transitions between clips
  • NLA strips baked into one action
  • Keyword search and filtered FBX lists
