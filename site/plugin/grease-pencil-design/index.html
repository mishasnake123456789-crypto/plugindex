What Grease Pencil: Design does

Grease Pencil: Design, from Blastframe, brings layout tools familiar from vector design software into Blender's Grease Pencil. It is useful for motion graphics and 2D work that needs precise arrangement of strokes.

Align works on points, strokes or layers in the 2D camera view in Relative or Absolute modes, and can align to the view, the selection or the 3D cursor. Distribute spaces elements by their edges, with a Distribute Space command for equal gaps. 2D Arrange functions even when Stroke Depth Order uses 3D Location. Bevel, Merge Points and an expanded layer context menu add further control.

Key features

  • Align points, strokes or layers in camera view
  • Distribute with equal spacing
  • 2D Arrange with 3D Location depth order
  • Bevel and Merge Points
  • Expanded layer context menu
