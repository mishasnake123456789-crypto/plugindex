What Model Check - Mesh Check And Repair does

Model Check from QKK verifies whether your models meet requirements before they go further down the pipeline. It is commonly used during the modeling phase of game development.

A Model Specification Checker provides a final review before importing into an engine, and batch checking covers many models at once. Documentation is included and it is released under the GPL license, marked Extension compatible. Game artists can catch issues early instead of discovering them in-engine.

Key features
