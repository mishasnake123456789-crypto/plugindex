What Fill Select Between does

Fill Select Between, by lunna-sku, selects the faces that lie between two edge loops, or within a single closed loop, saving manual selection work. It is listed under Modeling and Mesh.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.

Key features

  • Select faces between two edge loops
  • Select inside a closed loop
