What Clean Cycle Bake (Smart F-Curve Bake) does

Clean Cycle Bake works like a smart bake in Maya for looping animation. It converts cycle modifiers on selected bones into real keys, using only keyframes you created rather than adding samples everywhere.

The range can be the scene range or a custom one, bones can be locked or muted to exclude them, and the result can overwrite the current action or form a new one. Leaving Remove Cyclic unchecked retains the cycle modifier. Run it with F3 search or add it to a quick menu.

Key features

  • Bakes cycling F-curves with existing keys only
  • Lock or mute bones to exclude them
  • Scene or custom bake range
  • Overwrite or create a new action
