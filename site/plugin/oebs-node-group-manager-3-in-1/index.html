What Oebs Node Group Manager (3 In 1) does

OEBS Node Group Manager combines three managers into one tool for Blender. A single sortable list shows every Geometry, Shader and Compositor node group, with filters for unused, orphaned, favorite or selected groups.

Groups can be searched, renamed, deleted in bulk, exported, tagged with versions and checked for problems. Each Node Editor gets a matching manager tab, and the 3D Viewport presents all three types together in a tabbed panel. Technical artists with large node libraries can clean up and organize them much faster.

Key features

  • Unified list of all three node group types
  • Filters for unused, orphaned, favorites and selection
  • Rename, search and batch-delete
  • Export, version tagging and validation
  • Panels matched to each Node Editor
