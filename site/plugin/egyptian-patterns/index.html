What Egyptian Patterns does

Egyptian Patterns, by Fertuffo, is a shader node that adds decorative Egyptian motifs to Blender materials. All five patterns live in one node and tile seamlessly.

Color variation runs from the original scheme to entirely different colors, and a seed value produces endless combinations. Scale sets pattern size, a bump factor feeds the BSDF, and a value output isolates each pattern component for further customization. Documentation is included.

Key features

  • Five seamless patterns in a single node
  • Color variation and seed controls
  • Scale and bump factor
  • Value output for isolating pattern parts
