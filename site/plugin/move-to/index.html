What Move To does

Move To is a small utility from Script-Fighter for repositioning layers within the timeline stack. Instead of dragging layers up or down, you use the tool to send them where they need to go.

It runs on Mac and Windows, supports After Effects from CC 2014 through 2022, and uses an internet connection for its license system. Version 1.2 added more settings options. For artists who shuffle layer order constantly, it reduces repetitive dragging in busy timelines.

Key features

  • Fast layer movement within the timeline
  • Mac and Windows support
  • Works with CC 2014 through 2022
  • More settings options in 1.2
