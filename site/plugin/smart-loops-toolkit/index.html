What Smart Loops Toolkit does

Smart Loops Toolkit, by Pawel Wilczewski, is a set of Blender modeling tools that subdivide, unsubdivide, unbevel, rebevel, straighten and repair ngons. It can raise the resolution of geometry without distorting nearby faces.

Subdivide Loops has a closed-curve option and a choice of curve types, and Unsubdivide Loops was introduced in 1.1.0, and the Unbevel and Rebevel tools have a precision parameter for flat surfaces. Further tools fix ngons, recalculate loops, straighten loops and faces, and align the view. It can upscale geometry, including boolean cutouts, in seconds.

Key features

  • Subdivide and Unsubdivide Loops
  • Unbevel and Rebevel with precision parameter
  • Fix ngons and recalculate loops
  • Straighten loops and faces
  • Upscales geometry without distortion
