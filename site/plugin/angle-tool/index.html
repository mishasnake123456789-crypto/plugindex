Blender modeling add-on that builds corner geometry from a selected cross-section about an active edge in Edit Mode.

What Angle Tool does

Angle Tool creates corners in Blender's Edit Mode from a selected cross-section. After you choose part of your mesh and define an Active Edge, you can rotate and extend the geometry about it.

Besides the default Angle Mode there are a Curve Mode plus an Extend Mode, and numeric input allows exact values. Modelers building pipes, frames, rails or architectural trim can create bends and turns without manually rotating and joining pieces.

Key features

  • Corner geometry from a cross-section
  • Angle, Curve and Extend modes
  • Numeric input for exact values
  • Uses a specified Active Edge
