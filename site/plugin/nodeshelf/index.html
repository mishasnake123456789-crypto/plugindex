Blender add-on for storing and organizing reusable node groups in themed packs with thumbnails and colorable notes.

What Nodeshelf does

Ezzahir Anass's NodeShelf helps keep favourite node groups in order. Collect them in custom Node Packs sorted by purpose, say math helpers, custom geometry or patterns, and add, delete or rename packs as needed.

Packs can have thumbnail images. Save groups into a pack and load either one chosen group or an entire pack, with an auto-place option putting it into the active tree. Notes add draggable, colorable comments to your node tree. Shader and geometry node users build a personal toolkit.

Key features

  • Node Packs to categorize node groups
  • Add, remove and rename packs
  • Thumbnails for packs
  • Load a group or a whole pack
  • Draggable colorable Notes
