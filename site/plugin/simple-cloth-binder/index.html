What Simple Cloth Binder does

Simple Cloth Binder is a Blender plugin for fitting garments to rigged characters. One click binds clothing so it follows the character's movements after rigging.

Mask creation uses weight painting tools for precise control, and transformations stay smooth. It helps character artists who need clothes to deform with the body without complicated manual setup. This avoids the time-consuming process of manually parenting and weighting each garment, helping characters get dressed quickly for animation.

Key features

  • One-click clothing binding
  • Mask creation via weight painting
  • Smooth following of character movement
  • Designed for rigged characters
