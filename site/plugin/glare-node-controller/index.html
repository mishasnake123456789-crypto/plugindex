What Glare Node Controller does

Glare Node Controller is a Blender add-on by darkstarrd that adds a panel to Render properties for setting up glare. The aim is a simple workflow for people who would rather not open the Compositor to get a glow effect.

The result resembles the classic bloom effect. At roughly 3.5 KB, the add-on is very light, needs no special permissions, supports Blender 4.2 LTS and newer, and is released under the GNU GPL v3 or later.

Key features

  • Glare controls inside the Render panel
  • Avoids the Compositor
  • Bloom-like result
  • Tiny 3.5 KB download
  • Requires no special permissions
