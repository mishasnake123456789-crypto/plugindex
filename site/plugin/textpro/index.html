Blender typography system with 3D extrusion, bevels, smart materials, procedural animation and native Arabic, Persian and Urdu support.

What Textpro does

TextPro, by dotblend, turns plain text into finished 3D typography. It provides extrusion, bevel controls, smart materials and procedural animation, along with a library of one-click presets that combine shapes, styles and animations.

A native right-to-left engine lets you type Arabic, Persian and Urdu in the viewport with proper letter connections and ligatures, which Blender does not handle by itself. Motion designers and title artists working in these scripts gain a practical tool.

Key features

  • 3D extrusion and bevel controls
  • Smart materials
  • Procedural text animation
  • One-click presets library
  • Built-in right-to-left engine for Arabic, Persian and Urdu
