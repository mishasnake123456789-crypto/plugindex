What Bb Toolkit does

BB Toolkit is a Blender plugin that puts frequently used features within one click. Objects, lights, operations and modifiers built into Blender are gathered in a single place, with Free and Pro versions.

You can drop in a camera matched to the viewport, as well as area, point, spot and sun lights, choose render options for samples, engine and output type, and see real-time detection of non-uniform scale. Handy for speeding up routine tasks.

Key features

  • One-click objects, lights and modifiers
  • Camera aligned to the viewport
  • Render options for samples and engine
  • Non-uniform scale detection
