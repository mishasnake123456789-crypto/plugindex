What Reka Grid does

Built by irrealix, Reka Grid is a plugin running inside After Effects aimed at building grids that can be shaped and animated in detail. It handles 3D grids that react to the After Effects camera, with a billboard mode, X and Y rotation, a Z dimension on transform items and a global scale.

Sprites can fill the grid items, and ramp, gradient and path parameters control variation. Fog and a Z-depth render pass help with compositing. Noise Loop and Noise Offset create custom noise, items can be sorted by Z, and script control supports custom parameter naming with gridWidth and gridHeight parameters.

Key features

  • 3D grids with camera support and Billboard mode
  • Sprites for grid items
  • Ramp, gradient and path parameters
  • Fog and Z-depth render pass
  • Script control of grid parameters
