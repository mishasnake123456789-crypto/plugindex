Blender shot management add-on that keeps cameras, render settings and collection states per shot within a single scene.

What Shot Handler does

dubCUT's Shot Handler stores the complete state of each shot inside one scene. A central list creates, duplicates, reorders and switches shots, with Auto Save and a .bat export for background rendering.

A shot remembers its camera, including motion blur, depth of field and background images, plus render settings, frame range, collection states and custom properties. Output naming is structured with root paths, versions and tags. Teams working on sequences can render every shot from a single file.

Key features

  • Central shot list with reorder and duplicate
  • Per-shot camera state
  • Render settings and frame ranges per shot
  • Structured output naming and versions
  • Auto Save and .bat export
