What NLA Empty Track Cleanup RKNZ does

NLA Empty Track Cleanup RKNZ removes the leftover empty tracks that often clutter the Nonlinear Animation editor, particularly when collections are appended from other .blend files.

A single click in the NLA window's side menu clears all empty tracks, on every object, so you do not have to find and delete them one by one. It is a small housekeeping tool for animators who reuse assets across files and want a tidy timeline.

Key features

  • Deletes all empty NLA tracks in one click
  • Available in the NLA window side menu
  • Cleans tracks across all objects
  • Targets clutter from appended collections
