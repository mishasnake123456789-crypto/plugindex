What Super Bend Tool does

Super Bend Tool extends bending capabilities. You can add unlimited bend modifiers and manage them in a single panel, switching each active or inactive without losing settings.

Inactive bends show a wireframe preview in the viewport, and deformation can be driven by vertex groups or curves for fine control. Useful for cables, pipes, organic shapes and stylized deformations. The wireframe preview helps you remember what each disabled bend will do before turning it back on.

Key features

  • Unlimited bend modifiers
  • Toggle bends without losing settings
  • Wireframe preview for inactive bends
  • Vertex group or curve driven deformation
