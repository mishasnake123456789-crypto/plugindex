What Sound Radix Auto-Align Post does

When a boom and a lavalier record the same dialogue, the small delay between them causes comb filtering and a hollow sound. Auto-Align Post from Sound Radix corrects that timing difference inside DaVinci Resolve and Premiere Pro.

A dynamic mode follows moving actors or cameras and keeps correcting continuously, whereas a static mode suits fixed microphones. The alignment range reaches about 100 ms, roughly 34 meters of distance. A spectral phase module deals with shifts introduced by filters, and a real-time correlation meter shows how well the channels agree. Post-production dialogue editors and location sound mixers get the most from it.

Key features

  • Adaptive time alignment up to about 100 ms
  • Dynamic mode for moving sources, static mode for fixed mics
  • Spectral phase correction module
  • Real-time phase correlation meter
  • Multi-channel support
