What Sculpt Pose Sync does

Sculpt Pose Sync is a Blender plugin for sculpting characters that are already rigged and posed. It sets up a dual-mesh arrangement so symmetrical sculpting happens on the rest pose while the posed mesh updates alongside it.

One click creates a workspace that either divides the view or opens another window, isolating the un-posed model. A Multiresolution modifier is configured automatically, and a panel button raises subdivision levels. This avoids the usual headache of losing symmetry once a model has been posed.

Key features

  • Dual-mesh rest pose and posed preview
  • One-click split view or new window
  • Automatic Multiresolution setup
  • Keeps symmetry on posed models
