What Mike Udin Batch Processor does

Mike Udin Batch Processor automates repetitive file handling in Cinema 4D. It imports and exports any format that Cinema 4D understands, so whole folders of models can be converted without opening each one.

A background mode keeps working through the queue while you carry on with other tasks. Documents in the queue can also be processed with scripts that use the Cinema 4D Python API, and user scripts come with a graphical interface. Pipeline technicians and artists preparing large asset libraries can save a lot of manual work.

Key features

  • Automated import and export of supported formats
  • Background mode that doesn't interrupt work
  • Process queued documents with Python API scripts
  • User Scripts with a GUI
