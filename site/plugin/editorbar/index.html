What EditorBar does

EditorBar is a Blender add-on by atetraxx that converts the stock Outliner and Properties editors into a sidebar that folds away and opens again. It lives inside 3D Viewport areas and is designed for Blender's stock workspace layouts.

There are three ways to toggle it: a 3D Viewport menu entry, a button in the N panel plus the Alt/Opt+Shift+N hotkey. The same shortcut or button moves the sidebar between the left and right sides. The shortcut can be changed under Edit, Preferences, Keymap, and default positions can be set in preferences.

Key features

  • Collapsible sidebar for Outliner and Properties
  • Menu, N panel button and shortcut toggles
  • Switch sidebar between left and right
  • Customizable shortcut
  • Adjustable default position
