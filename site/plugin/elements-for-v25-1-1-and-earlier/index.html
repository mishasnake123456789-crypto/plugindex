What ELEMENTS for v25.1.1 and earlier does

This is the legacy build of the ELEMENTS integration, intended for installations running ELEMENTS version 25.1.1 or earlier. It connects After Effects and Premiere Pro with the ELEMENTS client app.

From within the Adobe applications, you can look through the ELEMENTS Media Library and import assets and rough cuts directly into your project. It needs After Effects 13.5 or later or Premiere Pro 11.0 or later. Teams on newer ELEMENTS versions would use a different build.

Key features

  • Works with the ELEMENTS client app
  • Browse the Media Library from Adobe apps
  • Import assets and rough cuts directly
  • Built for ELEMENTS v25.1.1 and earlier
  • Requires AE 13.5+ or Premiere Pro 11.0+
