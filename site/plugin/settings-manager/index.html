What Settings Manager does

Settings Manager lets you keep several Blender setups and swap between them, rather than reconfiguring preferences each time. Each configuration can be duplicated for experiments and exported or imported as a .zip file or a directory.

A shared add-ons directory holds all your add-ons in one place and keeps them in sync across settings entries and Blender versions. From there you can enable, disable or update add-ons per configuration. The interface is kept simple and sits inside Blender, making it a good fit for people who run different setups for different projects or testing.

Key features

  • Save and switch settings configurations
  • Shared add-ons folder synced across versions
  • Per-configuration add-on enable and update
  • Duplicate, export and import as zip or folder
