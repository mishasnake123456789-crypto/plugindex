Blender add-on that makes a shortcut-driven boolean-style cut and leaves you in edit mode with the result selected.

What Quick Knife does

Cutting one object with another in Blender usually takes several menu trips. Quick Knife from Blender.Fun compresses that into a hotkey: with the cutter chosen, hit Ctrl+Shift+K and click the object you want to slice.

The cut happens at once and Blender drops you into edit mode with the new geometry already selected, ready for further work. The add-on includes documentation, runs on Blender 2.91 through 4.3 and is GPL licensed. Hard-surface modelers who cut panels, vents and openings all day will notice the saved clicks.

Key features

  • Ctrl+Shift+K shortcut for cutting
  • Three-step select, press, pick workflow
  • Enters edit mode automatically
  • Cut is pre-selected
  • Blender 2.91 to 4.3
