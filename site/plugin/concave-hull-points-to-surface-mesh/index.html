What Concave Hull (Points To Surface Mesh) does

Concave Hull from CGMatter is a point-to-mesh operator that reconstructs a surface from scattered points, tracing hollows and indentations rather than wrapping everything in a convex shell.

A Threshold sets the minimum geometry created, Grid Spacing the distance between sample voxels, and Connections densifies the cloud, with Show Connected to display that. It helps with scan data, particle clouds and procedural point sets. Adjusting the threshold and spacing lets you trade detail against smoothness until the shape looks right.

Key features

  • Reconstructs surfaces from point clouds
  • Threshold control
  • Grid Spacing between sample voxels
  • Connections to densify points
  • Show Connected display
