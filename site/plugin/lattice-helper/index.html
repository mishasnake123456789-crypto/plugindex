What Lattice Helper does

Lattice Helper creates lattices that fit selected objects or mesh regions in Blender with one click, working in Object or Edit Mode.

Object mode can use one object, several objects treated as a whole or a lattice per mesh object, and edit mode wraps selected vertices. The lattice can be removed or applied from the right-click menu. Modelers deforming parts nondestructively save setup time. Creating the lattice by hand requires several steps of adding, scaling and assigning modifiers, and this add-on collapses all of that into a single action.

Key features

  • One-click lattice creation
  • Single, grouped or per-object lattices
  • Edit-mode vertex wrapping
  • Apply or remove via right-click
