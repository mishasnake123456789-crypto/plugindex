What Sakura's Rig Interfaces does

Sakura's Rig Interfaces is a companion script for rigs created by Sakura Sedaia. It supplies the interface elements and controls that these rigs rely on.

If you use those rigs, installing it gives you access to their custom settings and animation controls in Blender. Without it, the rigs would be missing the panels needed to operate them comfortably.

Key features

  • Control script for Sakura's rigs
  • Custom rig interface panels
  • Needed for those rigs' controls
