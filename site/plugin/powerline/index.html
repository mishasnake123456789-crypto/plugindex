What Powerline does

Powerline is a production pipeline suite from Jayaarka studios for Blender. It spans file management, motion-capture retargeting, automation and an action coding system for connecting deformations.

The file manager saves incremental versions automatically while keeping earlier files accessible, with notes, stored UI state and version thumbnails on save and export. Import and export cover FBX, blend, OBJ and Alembic, including animation onto a selected armature. A connection manager handles mocap retargeting, and the tools help build Metahuman-compatible rigs.

Key features

  • Automatic incremental version saving
  • Notes, UI state and thumbnails per version
  • FBX, blend, OBJ and Alembic import and export
  • Connection manager for mocap retargeting
  • Metahuman-compatible rig building
