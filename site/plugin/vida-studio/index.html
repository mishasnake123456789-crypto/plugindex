What Vida Studio does

Vida Studio connects After Effects and Premiere Pro to the Vida media library. Individual assets and organised collections can be browsed and located from inside the Adobe application.

Selected media downloads with simple options and can be inserted straight onto the Premiere Pro timeline. The extension talks both ways with the Vida web application, synchronising timecode and updates, and files can be imported from the web app into Premiere Pro. Teams that manage footage through Vida will save trips between browser and editor.

Key features

  • Browse assets and collections in the Vida library
  • Simple download options
  • Insert assets onto the Premiere Pro timeline
  • Two-way link with the Vida web application
  • Timecode synchronisation
