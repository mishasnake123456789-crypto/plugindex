What Mesh Slicer For Parametric Design does

Mesh Slicer For Parametric Design converts 3D models in Blender into flat cutting paths, whatever their polygon count. Slices become curves that export as SVG for CNC machines such as laser cutters, routers and plasma cutters.

You set how many slices and the gap between them before cutting, and slice curves are separated and numbered in a layer. A solidify modifier can add thickness for visualization. The panel is in the 3D view sidebar, useful for designers, decorators and architects creating parametric furniture and decor.

Key features

  • Slices meshes of any polycount
  • SVG curve export for CNC machines
  • Set slice count and spacing
  • Optional solidify for visualization
  • Slices separated and enumerated in a layer
