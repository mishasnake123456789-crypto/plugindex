What Archimesh does

Archimesh produces basic architectural elements in Blender, including rooms, doors and windows. Written by Antonio Vazquez, it was once a bundled add-on and is now community maintained and provided as-is with limited support.

The tools can be reached from the View3D Add Mesh menu and from the Create tab in the sidebar. Installation and use require no special permissions, it works with Blender 4.2 LTS and newer, and it is released under the GPL. Interior visualizers and level designers can block out buildings fast with parametric parts.

Key features

  • Generates rooms, doors and windows
  • Menu in Add Mesh and Create sidebar tab
  • For Blender 4.2 LTS and newer
  • Community maintained
