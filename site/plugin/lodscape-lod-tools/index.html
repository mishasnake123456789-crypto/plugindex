What Lodscape - Lod Tools does

Lodscape handles the tedious preparation of large terrains for real-time use. It divides a landscape, or several objects, into smaller cells and then builds levels of detail for them, aimed at games, architecture, archaeology and topography visualizations.

New cells are renamed automatically, and vertex groups with safe margins keep LODs seamless where chunks meet. You can create several LODs with automatic distances and detail ratios across any number of cells at once, adjust settings all together or in groups, and output packed assets ready for a game engine. Environment artists dealing with large meshes will save considerable manual work.

Key features

  • Slices landscapes into cells
  • Automatic renaming of new cells
  • Safe-margin vertex groups for seamless LODs
  • Several LODs across many cells in one go
  • Output ready for game engines
