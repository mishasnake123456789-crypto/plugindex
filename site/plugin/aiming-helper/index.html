What Aiming Helper does

Aiming Helper is a Blender plugin from Hartface for game artists who model firearms and need the sights to line up correctly. Rather than guessing, you can check how the eye, rear sight, front sight and target line up in the 3D viewport.

Points are picked with an eyedropper cursor clicked onto any mesh surface, and they are stored in local space so they follow the model when it moves. An overlay draws a line through the points, turning green when aligned and red when off, with deviation lines showing how far each point is off.

Key features

  • Pick sight points directly on mesh surfaces
  • Points follow the model in local space
  • Green or red alignment line overlay
  • Deviation lines show the offset
