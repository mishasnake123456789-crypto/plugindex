Blender add-on that copies location, rotation, dimensions and modifiers from a source object to many targets using an eyedropper.

What Interactive Transform Copier does

Interactive Transform Copier transfers an object's transform to several selected objects at once in Blender. Pick a source with the eyedropper, press apply, and every target follows, saving repeated typing of values.

You can copy location, rotation, dimensions or all three, and also the entire modifier stack in one click. Absolute Mode matches the source's exact world position, while Relative Mode applies the source transform relative to the origin. It removes the need to type matching values by hand and keeps duplicated parts consistent.

Key features

  • Eyedropper source picking
  • Copy location, rotation, dimensions or all
  • Copy the whole modifier stack
  • Absolute world position mode
  • Relative origin mode
