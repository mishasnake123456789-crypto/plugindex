Web Preview

Developer: Gabor Kiss

FreeBlender
Download Free

Sends a selected Blender model to a browser viewer to compare web renderers, tune materials and HDR lookdev before handoff.

What Web Preview does

Web Preview is a local add-on that writes the selected object to a temporary glTF and loads it into an actual browser viewer, so you see how it will appear online.

A material panel reviews one material at a time, adjusting surface color, roughness, metalness, emission, double-sided rendering and opacity. HDR lookdev can be adjusted and screenshots saved. It helps web 3D, e-commerce and AR creators catch differences between Blender and browser rendering before delivering.

Key features

  • Direct Preview via temporary glTF
  • Material panel with roughness, metalness, emission
  • HDR lookdev adjustment
  • Compare web renderers
  • Save screenshots
