A Blender add-on for hard-surface game assets that eases edge softening, exports and Substance Painter baking.

What Game Dev Tools For 2.79 And does

Game Dev Tools, by zebus3d, supports hard-surface modeling for video games and smooths the pipeline between Blender and Substance Painter. It organizes edge softening into groups of soft and hard edges, including ridges, so shading behaves as intended.

Global width control applies to split edges, or you can use individual weights. Low and high versions export as FBX and OBJ, vertex color IDs are created automatically, and the mirror modifier can be applied when present. An exploding function helps prevent proximity conflicts when baking in Substance Painter, and poly utilities help daily modeling. Game artists preparing bakes will find it useful.

Key features

  • Soft and hard edge groups, including ridges
  • Low and high export to FBX and OBJ
  • Automatic vertex color IDs
  • Explode function for cleaner Substance Painter bakes
  • Applies mirror modifier when present
