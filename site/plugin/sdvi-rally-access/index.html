A Premiere Pro panel that loads SDVI Rally workorders onto the timeline for QC and compliance edits.

What SDVI Rally Access does

SDVI Rally Access puts Rally workorders in the editor. Choosing one gathers the necessary media and metadata onto the timeline, and new metadata, edits and effects sync back to Rally.

Adobe Media Encoder integration renders new versions while retaining the original content and metadata. It supports manual QC, compliance review and editing, craft edits, content segmentation and caption review, with project and EDL export and cloud render. It is intended for media supply chain teams who need QC and compliance work done in the editor.

Key features

  • Rally workorders inside Premiere Pro
  • Media and metadata compiled to timeline
  • Edits and metadata sync back to Rally
  • Media Encoder renders new versions
  • Caption review and compliance workflows
