Blender add-on that converts hair curves into Groom assets and sends them to Unreal Engine 5.7.

What Groomforge Pro does

Groomforge Pro bridges Blender's hair curves and the Hair Dataflow in Unreal Engine 5.7. It automates the conversion into production-ready Groom assets while protecting data integrity and rigging.

A beta Send to Unreal button creates the Groom inside a running editor, with folder and asset name set in the Blender panel. Clumps are grouped by their actual 3D position with a size slider, and exports include guide-interpolation data for more accurate strand behavior. Hair can be bound to mesh data for animation sync, skeletons can be generated from selected edges, and a Force UE Scale option compensates for centimeter armatures.

Key features

  • One-click Send to Unreal Engine (Beta)
  • Clump grouping with scale slider
  • Hair-to-mesh binding for animation sync
  • Edge-based rig generation
