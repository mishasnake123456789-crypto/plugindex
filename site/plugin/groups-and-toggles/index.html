What Groups and Toggles does

Groups and Toggles from Freshmograph lets you reach layers inside precomps without breaking a procedural project. That makes it easier to build mattes from them, rearrange their order and keep the structure flexible.

It can embed mattes directly in Mogrts and place several Mogrt versions in a single file. It supports After Effects CC 2019 through 2025, and is of most use to template designers. Keeping everything procedural means templates stay flexible, which helps teams that revise graphics often.

Key features

  • Access pre-composed layers procedurally
  • Create mattes from precomp layers
  • Rearrange layer order
  • Embed mattes in Mogrts
  • Multiple Mogrt versions in one file
