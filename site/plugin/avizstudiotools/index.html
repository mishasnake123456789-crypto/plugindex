What AvizStudioTools does

AvizStudioTools is an application that installs and runs the whole suite of AvizStudioTools plugins and scripts for 3ds Max. It checks for updates, manages tool versions, and opens each tool with one button from a single interface.

The collection includes ATiles for roof tiles, floors, brick walls and fences, ATree3D for low and high polygon vegetation, A2Dimage for adding alpha-channel pictures of people or trees, AColorManager for V-Ray ACEScg conversion, ASnapshots for saving object states, ASmartObjects, and AImagine for AI image generation. Archviz artists who use several of these tools benefit from central management.

Key features

  • Installs, updates and manages all tool versions
  • Opens each tool with a single button
  • ATiles and ATree3D for tiling and vegetation
  • AColorManager for ACEScg conversion
  • AImagine AI image generation
