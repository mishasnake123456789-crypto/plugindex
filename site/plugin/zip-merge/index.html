What Zip Merge does

Zip Merge is a Blender addon by hodgson3d that closes gaps the way a zip does, welding vertices of adjacent mesh islands and leaving UVs unharmed. It is meant for situations where merge by distance joins the wrong things or bridging faces causes trouble.

The ZipMerge operator sits in the merge menu, using a start vertex and at least three vertices. The number of merge iterations is adjustable, and an option controls whether merging stops at corner vertices, meaning those with only two neighboring vertices.

Key features

  • Zips vertices between mesh islands
  • Preserves UVs while merging
  • Avoids unwanted joins from merge by distance
  • Adjustable merge iterations
  • Option to stop at corner vertices
