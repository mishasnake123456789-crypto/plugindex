Sets Blender's render output folder from the project path and checks the file is saved first.

What Output Fix does

Output Fix takes care of output path headaches in Blender. It can point the output folder at the project's own directory and file name, so renders land beside the project instead of a random default.

Before executing output actions it checks that the project has been saved and prompts if it has not. A File Folder button confirms the saved state before setting the path, and a text field with a Create Folder option helps. Useful for anyone who has lost renders to unsaved files.

Key features

  • Output folder from project directory and name
  • Checks the project is saved first
  • Prompts to save when needed
  • Create Folder option
