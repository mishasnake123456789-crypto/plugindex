What MoovIT GrowthAccelerator does

MoovIT GrowthAccelerator is for editors who cut with growing clips, files that are still being written while they edit. It adds one button to the Premiere Pro toolbar that reloads the clip currently open in the source monitor.

Instead of leaving the refresh timing to Premiere, you decide when the media updates. It works with Premiere Pro 20.0 and later, and suits live and ingest-heavy workflows. A single button is all it adds, so it stays out of the way until a refresh is needed.

Key features

  • Toolbar button in Premiere Pro
  • Refreshes the clip in the source monitor
  • Built for growing clips
  • Manual control over media updates
  • Premiere Pro 20.0 and later
