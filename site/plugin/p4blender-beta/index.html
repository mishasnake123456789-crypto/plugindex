What P4Blender [Beta] does

P4Blender [Beta] brings version control to Blender users on Perforce Helix. Using the official P4python module, it connects to a server so files tied to your scene can be managed without leaving the window.

Available actions are checkout, add, pull, push, revert, delete and revision fetch, with multi-server support and a file browser tied to P4V and its context menu. Multithreading keeps it responsive. Game studios that store art assets in Perforce will find it spares constant switching to other clients.

Key features

  • Uses the official P4python module
  • Checkout, add, pull, push, revert, delete
  • Multi-server connection
  • File browser with context menu
  • Revision swapping
