What Fleximesh does

FlexiMesh is a Blender tool for building cloth-style media planes from images and videos. As soon as you select a file, it creates a wired cloth asset that is ready for the camera, working in Cycles and Eevee.

A cloth plane spawns between your viewpoint and the target, already facing the camera. The material, UVs and node setup are created automatically, including correct video-texture wiring across Nodes and the VSE. Viewport updates are live. Motion designers can use it for flags, banners, billboards and flowing media displays without hand-wiring each one.

Key features

  • Images and videos become cloth assets
  • Plane spawns facing the camera
  • Automatic material, UVs and node setup
  • Correct video-texture wiring
  • Live viewport updates
