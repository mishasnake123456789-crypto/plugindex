What Hair Proxy does

Hair Proxy combines features of hair curves and meshes. A few clicks are enough to give hair curves shape keys and hair dynamics, which normally lack such options.

Shape keys can hold alternate styles, tweaks or looping animation. It creates a mesh proxy so physics, rigging and mesh modifiers work, and Geometry Nodes update the hair shape. Useful for animating grooms. This approach brings familiar mesh tools to curve-based hair, so styling and animation become much more flexible.

Key features

  • Shape keys on hair curves
  • Hair dynamics in a few clicks
  • Mesh proxy enables physics and rigging
  • Geometry Nodes updates the shape
