What Quick Boolean does

Quick Boolean applies ProBoolean operations to the selected object in 3ds Max using preset profiles, working much like SketchUp's Solid Tools. Available profiles: Knife, Split, Subtract, Trim, Hollow, Intersect and Union.

Quick Union merges selected objects into one mesh, Intersect keeps only the shared volume and Hollow removes it, while Split keeps everything. Trim and Subtract work the selected objects against a picked one, keeping either all pieces or just the result, whereas Knife retains the result together with the overlap. Reverse Knife, Subtract and Trim swap the roles, trimming picked objects against the selection. Complex boolean blocks come together with fewer clicks.

Key features

  • Preset ProBoolean profiles for union, intersect, hollow and split
  • Trim, Subtract and Knife against a picked object
  • Reverse versions of knife, subtract and trim
  • Single-mesh union of selected objects
  • Workflow similar to SketchUp Solid Tools
