What Metaball Skinner does

Metaball Skinner turns thin wireframe structures into printable solids. Metaball rods are laid along every segment of the mesh skeleton to thicken it.

The output is always manifold regardless of how complicated the network is, so heavily branching or lattice-like shapes, for instance neurons, trees and networks can be handled. Useful for makers preparing delicate structures for printing. This is a handy approach for scientific models, sculptures and decorative lattices that would be fragile or non-printable as thin wires.

Key features

  • Metaball rods along skeleton segments
  • Always manifold meshes
  • Handles branching and lattice geometry
  • Aimed at 3D printing
