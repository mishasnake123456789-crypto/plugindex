What Poly Stitch tools does

Poly Stitch tools build faces across selected open edges, or borders, of editable polygon objects in 3ds Max. Their main job is connecting roads to terrain, and they are one feature of the TerrainAxe package.

StitchPoly mode joins separate objects, or borders that cannot be chosen together on one object, driven by its Source Border and Dest Border settings. With Dest->Source the new faces join the source border's object, and Relax opens a dialog for relaxing them. New faces take the source border's Material ID by default, adjustable with a spinner. QuickStitch handles fast stitching on a single object when borders are easy to pick.

Key features

  • Creates faces between open borders on editable poly
  • StitchPoly mode for separate objects with Source and Dest Border
  • Dest->Source option and Relax dialog
  • Material ID control for new faces
  • QuickStitch mode for same-object borders
