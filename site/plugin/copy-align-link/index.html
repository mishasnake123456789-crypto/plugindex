3ds Max script that copies a source object onto many destination objects, aligning and linking each in one step.

What Copy-Align-Link does

Copy-Align-Link handles a three-part chore in 3ds Max with one button. A source object is copied to each of several destination objects, aligned to them and linked, which is handy for attaching accessories, handles or markers to many parents.

The workflow follows a set order: select the source, select the destinations, then apply. Rotation offset values can be entered when the copies need a different orientation, and an Unrenderable Targets option makes the parent objects unrenderable. This removes the need to clone, align and link by hand for every destination.

Key features

  • Copies, aligns and links a source over multiple destinations
  • Select source, then destinations, then apply
  • Optional rotation offset values
  • Unrenderable Targets setting for parent objects
  • Single button runs all steps
