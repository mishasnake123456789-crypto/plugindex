3ds Max script that offsets transform keys across selected objects by each object's distance, color or name.

What KeyShifter does

KeyShifter staggers animation in 3ds Max by shifting the transform keys of several selected objects. The amount of offset for each object comes from a numeric value taken from its distance, its color or its name, so a whole group can be given a cascading timing in one pass.

It handles objects arranged in hierarchies as well as inclined objects, which keeps results sensible on more complex setups. Since version 1.22 it also supports position controllers other than positionXYZ. Artists who build follow-through effects, wave-like motion or delayed reactions across many objects can use it in place of moving keys manually for each one.

Key features

  • Shifts transform keys on selected objects
  • Offset based on distance, color or name
  • Works with hierarchical structures
  • Handles inclined objects
  • Supports non-positionXYZ position controllers since v1.22
