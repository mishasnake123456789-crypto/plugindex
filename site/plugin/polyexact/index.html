What Polyexact does

PolyExact adds precision to freehand modeling in Blender. You set an exact distance and extrudes, moves, duplicates and instances are capped to that length, while a visual guide shows the end point of the action in real time before you commit.

It also supports reference tracing, extruding along an outline from a reference image with consistent vertex spacing, and helps retopology by keeping quads more uniformly sized without stopping to check edge lengths. Duplicates can be placed uniformly too. Modelers working from references or building evenly spaced geometry will find it removes guesswork.

Key features

  • Exact distance cap for extrude, move, duplicate and instance
  • Real-time visual guide to the end point
  • Reference tracing with consistent vertex spacing
  • Helps keep retopology quads uniform
