What Lazy Baker does

Lazy Baker is a Blender plugin from Bookyakuno for organizing texture baking. You keep a list of bake data, with a save path and bake type for each item, and add collections to the list as groups.

Items can be baked one at a time or in a single batch run; if the list is empty, the selected object is baked. Two bake modes are offered. It removes repetitive clicking for assets with many maps.

Key features

  • List of bake items with paths and types
  • Batch bake or bake individually
  • Collections grouped in the list
  • Falls back to the selected object
