What Blender Inflate Addon - Generate Dynamic Cloth Panels does

Blender Inflate Addon, from Blender Procedural, is a geometry nodes add-on for generating dynamic cloth panels. It follows an inflate-based approach, so shapes such as cushions, balloons or fabric pieces can puff out under simulation.

Because it is built on Geometry Nodes, the workflow stays procedural, and cloth physics and simulation supply the dynamic geometry. It works with Cycles and Eevee, supports Blender 4.0 through 4.5, and includes documentation.
