What BlendGuard does

BlendGuard is a free, GPL-licensed security add-on for Blender. It inspects a .blend file to show what would run automatically before you trust it, relying purely on static analysis, without network use or telemetry, so nothing is executed during the scan.

It reports on text-block scripts, driver expressions written in Python, OSL nodes and registered handlers, rating each as clean, info, suspicious or dangerous. To resist obfuscation, it normalizes string tricks, recursively decodes base64, hex, rot13, zlib and gzip content, and flags high-entropy blobs. It helps anyone opening downloaded files.

Key features

  • Finds scripts, driver expressions, OSL nodes and handlers
  • Four-level rating from clean to dangerous
  • Decodes obfuscated payloads recursively
  • Static analysis only, no network or telemetry
  • Free and GPL licensed
