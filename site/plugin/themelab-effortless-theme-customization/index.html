What Themelab - Effortless Theme Customization does

ThemeLab is a Blender add-on for people who want their workspace to look the way they like. It gathers the interface appearance controls in one place, covering icon colors, UI widgets, Edit Mode colors, shading and corner roundness.

A Simplify Mode offers Simple, Balanced and Detailed styles to fine-tune the result, and icon changes come with visual logo previews. Finished looks can be applied, exported, saved and combined, so you can build a personal theme and reuse it across installs. It is aimed at Blender artists who spend long hours in the interface and want it to feel comfortable.

Key features

  • Icon color customization with previews
  • UI widget and Edit Mode color control
  • Shading and roundness adjustments
  • Simple, Balanced and Detailed styles
  • Apply, export, save and combine themes
