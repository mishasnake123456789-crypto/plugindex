What B.B. Tools Add-On does

B.B. Tools is a modeling add-on from Blender Bash that appends its own menu to the 3D View in Edit Mode. Inside sit 31 purpose-built operators aimed at speeding up mesh work.

There are deformers such as Bend, Twist, Taper, Shear and Curve deform, extrusion helpers including extrusion along a path and edges or faces with loop cuts, and shape generators like Circle++, Ellipse++, hexagonal and triangular grids, Quad Sphere and Tubes. A 64-page guide documents each tool. It suits Blender modelers who prefer one tidy menu over many separate add-ons.

Key features

  • 31 tools in one Edit Mode menu
  • Bend, Twist, Taper, Shear and Curve deformers
  • Path and loop-cut extrusion tools
  • Grid, circle, sphere and tube generators
  • 64-page user guide
