What CenterLine does

CenterLine converts bitmap sketches, logos and calligraphy into vector centre-line paths inside After Effects. The result is a native shape layer, which can be revealed with Trim Paths for write-on animations.

The extraction uses Zhang-Suen thinning, then Schneider Bezier fitting and Ramer-Douglas-Peucker simplification. Source settings cover threshold, channels, invert and a map layer, and output styling handles width, colour, gradient, taper, caps and reveal. There are controls for animation, such as chain stagger and path offset, and skeleton cleanup with smoothing and gap closing. Results can be exported as JSON, SVG or shape layers.

Key features

  • Single-pixel skeleton paths from raster artwork
  • Threshold, channel and invert source settings
  • Width, colour, gradient, taper and cap styling
  • Reveal, stagger and offset animation controls
  • Export to JSON, SVG or shape layers
