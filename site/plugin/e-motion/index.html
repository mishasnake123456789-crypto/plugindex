Blender add-on for motion editing with driver time remapping, onion skinning, trajectories and advanced interpolation.

What E Motion does

E Motion collects animation editing tools in an E_Motion tab of the Graph Editor's N panel in Blender. Driver variables can be remapped in time with expression editing and live preview, and curve tools add a glow effect, delete empty curves and modifiers, and jump to animation start and end.

A grid curve editor allows grid-based and Bezier manipulation, onion skinning shows previous and next frames, and interpolation options include noise, sine and other nonlinear types. Trajectory visualization draws object motion paths. The interface supports Chinese, English, Japanese and Russian.

Key features

  • Driver time remapping with live preview
  • Grid curve editor and Bezier tools
  • Onion skinning
  • Noise, sine and nonlinear interpolation
  • Trajectory visualization
