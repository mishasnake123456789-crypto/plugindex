What TinkerType does

TinkerType is a free tool from Neel Motion Works for creating varied text animation from one text layer. Rather than animating separate layers, the controls break the animation up on a single layer.

Position and rotation can be animated, while fill color control needs the Fill effect applied to the layer and blur control needs the Gaussian Blur effect. All controls are handled from that text layer. It is compatible with After Effects CC 2019 through 2025, and is a simple way to add motion to titles and captions.

Key features

  • Animatable position and rotation
  • Fill color control via Fill effect
  • Blur control via Gaussian Blur
  • Everything on a single text layer
  • Compatible with CC 2019 to 2025
