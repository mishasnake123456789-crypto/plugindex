MaxScript that clones and deforms a mesh along a path in the manner of ZBrush's IMM Curve brush.

What Duplicurver does

Duplicurver brings the idea of ZBrush's Insert Multi Mesh Curve brush to 3ds Max. Pick a mesh, set how many clones you want, and adjust the offset between them; the clones are laid along a path and deformed to follow it.

The edges of the clones can be welded automatically. A CurveController rollout manages the thickness of the clones along the path through a curve, and custom rotation and twist can be applied. The selected mesh can be oriented manually along X, Y and Z before cloning. Parameters update in real time with immediate feedback. Chains, cables, fences and ornaments are typical uses.

Key features

  • Clone count and overall offset settings
  • Optional automatic edge welding of clones
  • CurveController for thickness along the path
  • Custom rotation and twist
  • Real-time interactive parameters
