3ds Max selection script for objects, materials, maps, modifiers, layers or properties, plus batch renaming.

What Universal Select By does

Six categories drive the selection in Universal Select By: properties, layers, modifiers, maps, materials and plain objects. An Instance mode extends this to instanced objects, materials and modifiers, look-alike objects and wire color, and results can be narrowed by class, name or bitmap name.

Face count selection matches objects with more, the same or fewer faces than a number you type. Material and Map modes add an [R] button with five remove and replace choices. Objects, materials, maps and modifiers can be renamed with prefixes, suffixes and incrementing numbers, and I-Transform mode selects by transform and local size. A graph function and Maps [M] function distribute values.

Key features

  • Selects objects, materials, maps, modifiers, layers or properties
  • Instance mode by instances, similar objects or wire color
  • Face-count based selection
  • Remove and replace options for materials and maps
  • Batch rename with prefixes, suffixes and numbering
