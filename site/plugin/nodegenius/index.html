AI-assisted Blender add-on that turns a plain-English prompt into a Geometry Nodes setup.

What Nodegenius does

NodeGenius builds Geometry Nodes networks from text descriptions. You describe what you want in plain English, and the add-on generates a working setup inside Blender.

It supports three AI backends, OpenAI GPT-4o, Anthropic Claude, and Ollama for local models, each using your own API key where applicable. More than twenty curated presets cover tasks like scattering on a surface and slope scatter, and a graph explainer describes existing node trees in plain language. It helps newcomers learn Geometry Nodes and speeds up experienced users.

Key features

  • Prompt to Geometry Nodes generation
  • OpenAI, Anthropic and Ollama backends
  • 20+ curated presets
  • Plain-English graph explainer
