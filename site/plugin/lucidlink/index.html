What LucidLink does

The LucidLink panel gives editors control over how a cloud-based filespace behaves while they work in Premiere Pro or After Effects. Instead of leaving the app to manage which files are stored locally, you handle it in the panel on macOS or Windows.

Sequences, folders, clips and proxies can be pinned or unpinned, and clip range caching downloads only the portion of a sequence you need. Real-time cache metrics display usage and pinning statistics, and quick settings apply recommended configurations in Premiere Pro. It is useful for projects with large, dense media.

Key features

  • Pin and unpin sequences, folders, clips and proxies
  • Clip range caching for parts of a sequence
  • Real-time cache and pinning metrics
  • Quick settings for Premiere Pro
  • macOS and Windows
