What Export Render as DNG does

FloBEAUG's Export Render as DNG writes renders and images to Bayer-pattern RAW Adobe DNG files, with an Export as DNG entry under Image in the Image Editor, meant for RAW post-processing.

The files open in RAW developers such as RawTherapee. Embedded metadata covers camera F-stop, focal length, white balance, plus defaults of ISO 100 and a standard exposure. It pairs with the LensSim add-on, and since 1.0.3 the file layout defaults to a standard linear stripped arrangement, for compatibility.

Key features

  • Export as DNG in the Image Editor
  • Bayer-style RAW DNG output
  • Embeds F-stop, focal length and white balance
  • Opens in RAW tools like RawTherapee
  • Pairs with the LensSim add-on
