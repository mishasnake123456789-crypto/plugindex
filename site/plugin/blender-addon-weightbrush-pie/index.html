What Blender Addon | Weightbrush Pie does

Weightbrush Pie is a Blender plugin from VFX Grace that puts weight painting tools into a pie menu. Add, subtract and blur are among the tools, and it can be used in both Weight Paint and Edit modes.

A selected vertex can be given a weight value quickly, and a preset weight value and a built-in weight function appear in the lower sections of the pie. It cuts down on trips to the tool panel when skinning.

Key features

  • Pie menu of weight painting tools
  • Usable in Weight Paint and Edit modes
  • Quick weight value for selected vertices
  • Preset weight slot
