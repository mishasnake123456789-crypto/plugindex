Premiere Pro panel for generating AI images, video and chat through KIE.AI models.

What DreamFerry does

DreamFerry puts generative AI inside Premiere Pro. Rather than exporting stills or jumping to a browser, an editor writes a prompt in the panel, selects a model from the KIE.AI lineup, and receives the output in the project.

References can come from a bin, a timeline frame or an asset library. A single click sends the job to KIE.AI, fetches the finished file, imports it into a dedicated GenAI bin and can place it at the playhead on a video track. The panel expects a personal KIE.AI account with an API key, which goes in Settings, and credits on that account are spent. Windows and macOS are both supported.

Key features

  • Image, video and chat generation
  • Reference input from bin, frame or library
  • Auto-import and optional placement at playhead
  • Uses your own KIE.AI key, stored locally
  • Windows and macOS
