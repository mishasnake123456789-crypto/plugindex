What Node Group Utilities does

Node Group Utilities gives Blender's node editor extra practical commands for node groups. It works with material, geometry and compositing node trees.

Set Default Values copies a group's current input values to become its defaults, saving per-socket configuration, while Reset to Default Values reverts them, and Backspace can reset a group since version 2.1.1. A Socket Maker node is available in the Add menu, and labeling helpers are included. Technical artists building reusable node groups work with less repetitive clicking.

Key features

  • Set Default Values from current inputs
  • Reset to Default Values with Backspace
  • Socket Maker node
  • Works with material, geometry and compositing
