What Image Zoom Overlay does

Image Zoom Overlay adds a readout of the zoom percentage to Blender's Image Editor, something the editor does not clearly show on its own. It also gives quick presets for jumping to common zoom levels.

Texture painters and compositors who check pixel detail will appreciate knowing exactly how magnified an image is. It is a small interface addition that reduces guesswork.

Key features

  • Zoom level overlay
  • Quick zoom presets
  • Works in the Image Editor
