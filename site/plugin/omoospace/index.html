What Omoospace does

Omoospace brings a standard way of organizing project folders into Blender. A shortcut jumps straight to the active project folder, and every input and output location is kept together.

Keeping everything consistent also helps prevent linked libraries from going missing when files move. The add-on follows the Omoospace universal folder structure, which suits freelancers and teams who want predictable project layouts.

Key features

  • Quick access to the project folder
  • All input and output paths gathered together
  • Helps prevent missing linked libraries
  • Follows the Omoospace folder structure
