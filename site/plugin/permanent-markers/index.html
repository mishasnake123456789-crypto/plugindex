What Permanent Markers does

Permanent Markers saves editors from grabbing frames one at a time. It exports multiple stills from a sequence in a single batch, choosing the frames from markers.

You can filter by marker color, export only the span between the sequence In and Out points, and pick file types that include alpha. Resolution presets cover full, half, quarter or custom, and a template builder names files from marker or sequence names. Useful for thumbnails, storyboards and client stills.

Key features

  • Batch still export from sequence markers
  • Filter by one or several marker colors
  • Resolution presets: full, half, quarter, custom
  • Optional export between In and Out points
  • Naming template builder
