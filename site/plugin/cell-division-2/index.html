What Cell Division 2 does

Cell Division 2 is a Pixcode plugin for After Effects that converts the inner and outer areas of any shape into transparent droplet forms. It gives flat shapes a glassy, liquid look suited to bubbly graphics and abstract backgrounds.

Twenty-one droplet styles are included, up from a single design, and more droplet controllers allow finer customization. Default droplet backgrounds help show off the designs, and the interface is dynamic and friendly. Motion artists can drop it onto a shape layer and quickly cycle through the styles.

Key features

  • Converts shapes into transparent droplets
  • 21 droplet styles
  • More droplet controllers
  • Default backgrounds to show designs
