What Caption X - Windows does

Caption X for Windows transcribes dialogue and builds captions within Premiere Pro, without external tools or copy-pasting. Over 57 languages are supported, including right-to-left scripts like Arabic, Hebrew, Urdu and Persian.

Captions arrive styled and ready for presentation, line length is adjustable, and results can be exported as an SRT file or burned into the render. It works with any audio track in the sequence. A free plan exists, and you sign in within the panel.

Key features

  • Automatic captions in the timeline
  • 57+ languages including right-to-left
  • Presentation-ready styled output
  • Short, medium or long line length
  • SRT export or burn-in, free plan available
