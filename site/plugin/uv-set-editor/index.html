3ds Max script, styled after Maya's UV Set Editor, for creating, renaming, copying and clearing UV channels.

What UV Set Editor does

UV Set Editor brings the idea of Maya's UV Set Editor to 3ds Max. Selecting an object loads all of its UV channels into one interface, from which they can be created, renamed, duplicated, cleared or deleted. The first channel is protected from being cleared or deleted.

UVs inside a chosen channel can be edited directly, and they can be copied and pasted between channels. The same copy and paste also works between objects that share identical topology, which helps when moving lightmap or secondary UV layouts from one mesh to another. Artists juggling several UV channels for game assets or baking will appreciate having everything in a single window.

Key features

  • Picks up every UV channel of the selected object
  • Create, rename and duplicate channels
  • Clear or delete channels with the first one protected
  • Copy and paste UVs between channels
  • Transfer UVs between objects with matching topology
