What Fire Box does

Velvum Inc's Fire Box sets flames on objects in Blender, like candles, hearths and wooden logs, and the flame color can be altered for fancy scenes.

It is a simple setup rather than a physics simulation, so it is quick to apply and light on resources. Documentation is included, Blender 2.8 up to 2.93 is supported, and a royalty-free license applies. Cozy ambience needs no baking. The flame look is simple by design, so scenes with many candles remain light to work with.

Key features

  • Fire instances on candles, fireplaces and logs
  • Changeable flame color
  • Simple setup, not a simulation
  • Blender 2.8 to 2.93
  • Royalty-free license
