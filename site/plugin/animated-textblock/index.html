What Animated TextBlock does

Froggy Team's Animated TextBlock is a plugin built for After Effects aimed at typographic layouts that must stay a set width. Lining up text elements in complex compositions is slow work, and this tool automates much of it.

Text is scaled to fit the block width, and tracking, alignment and the vertical anchor point can all be animated. Formatted text is supported, color can respond to size, and everything is driven through pseudo effect controls. That makes it useful for kinetic typography and title designs where lines need to keep their shape while the content or timing changes.

Key features

  • Scales text to fit the block width
  • Animatable tracking, alignment and vertical anchor
  • Supports formatted text
  • Size-dependent color
  • Pseudo effect controls
