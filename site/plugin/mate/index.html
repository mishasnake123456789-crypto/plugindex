What MATE does

MATE from OMATA Labs is an AI agent for After Effects. Instead of clicking through menus, you describe what you want in plain language, and it staggers and reorganizes layers, replaces text, adds animations and manages the render queue.

It can also write scripts and expressions. You choose the AI backend from OpenAI GPT, Claude, Gemini or Mistral; base-model usage is included with an active license, and your own API keys unlock more models. PDF, CSV and JSON files can feed text and project data, and MCP connectors link services such as Notion.

Key features

  • Natural-language task automation
  • Script and expression generation
  • Render queue management
  • Choice of OpenAI, Claude, Gemini or Mistral
  • PDF, CSV and JSON file input, MCP connectors
