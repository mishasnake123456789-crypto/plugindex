What Swappy does

From Hasan Atallah comes Swappy, a tool for After Effects that brings the fill and stroke handling familiar from Photoshop and Illustrator to shape layers. It lets you work with both attributes quickly.

You can add a fill or a stroke, swap the color and properties between fill and stroke, and delete all fills or all strokes. A Show All option came with the initial release. It is useful for artists who regularly restyle imported vector artwork.

Key features

  • Add a fill
  • Add a stroke
  • Swap fill and stroke color and property
  • Delete all fills or all strokes
  • Show All option
