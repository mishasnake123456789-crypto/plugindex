A Blender add-on that turns selected mesh faces into area lights from the N panel in edit mode.

What Area Lights does

Area Lights, by Anthony Aragues, converts faces of a mesh into area lights in Blender. Select an object, enter edit mode, pick the faces you want and press the button in the N panel to generate the lights.

This makes it easy to build lighting that follows the shape of an object, such as panels in a ceiling or the faces of a light box. It targets Blender 2.82 through 2.91, is GPL licensed, includes documentation and is also on GitHub. Interior and product artists who like to model their light sources will find it a direct method.

Key features

  • Generates area lights from selected faces
  • Runs in edit mode
  • Button in the N panel
  • Blender 2.82 to 2.91
  • GPL licensed
