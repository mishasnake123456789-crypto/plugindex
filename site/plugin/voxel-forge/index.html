Organizes high-to-low poly pipelines in Blender with naming presets, collection mappings, name checks and background export.

What Voxel Forge does

Voxel Forge helps keep bake and export setups consistent. Naming presets store suffix rules for low and high poly meshes, such as _low/_high or _lp/_hp, along with custom pairs.

Custom mappings assign presets to collections so correct rules and export behavior apply, names can be checked, and clean files export in the background. Game artists managing many assets avoid naming mistakes. The mappings are applied during export, so naming and file output stay predictable across a whole asset library.

Key features

  • Saved low/high suffix presets
  • Custom collection mappings
  • Name checking
  • Background export of clean files
