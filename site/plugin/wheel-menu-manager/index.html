GPU-drawn radial wheel menu for Blender with custom rings for meshes, brushes, nodes and lights.

What Wheel Menu Manager does

Wheel Menu Manager replaces long menus with a radial wheel drawn by the GPU. Any mesh, brush, node or light can be assigned to a custom ring, and slots can be rearranged by dragging.

Rings stack in multiple layers with eight slots each. A sculpt brush wheel ships with more than 90 brushes and GPU icons, plus an asset brush system. Toggle and Hold modes and a search feature round it out. Sculptors and modelers who like fast gesture-based access will find it handy.

Key features

  • Radial menu for meshes, brushes, nodes and lights
  • Multi-ring layers, eight slots each
  • 90+ sculpt brushes with GPU icons
  • Toggle and Hold modes with search
