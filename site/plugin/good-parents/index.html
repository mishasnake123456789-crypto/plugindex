What Good Parents does

Good Parents is a script by Nik Ska that makes parent relationships animatable in After Effects. Normally a layer has one parent for its whole life, and this tool allows the parent to change over time through keyframes.

It supports 3D layers, and Get and Set features were added in a later update. The script works with After Effects from CS5.5 through 2025. Two limitations apply: controls cannot be copied from one layer to another, and copying layers with controls into another composition requires resetting the parent layers.

Key features

  • Keyframe control of layer parenting
  • 3D layer support
  • Get and Set features
  • Compatible with CS5.5 through 2025
