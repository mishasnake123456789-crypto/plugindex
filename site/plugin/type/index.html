What Type does

Type, from AE Screens, is a toolset for animating text layers in After Effects. It handles common editorial effects such as highlighting, underlining and striking through selected text, with each iteration of a selection targeted.

A blinking cursor works across multi-line text, and Typewriter and Blinky effects keep character styling. Numbers can be formatted with optional leading zeros for time counters, which pause with shift-click, and monospacing is available. Typing tags add markers wherever the text changes, and Create Shapes From Text generates a shape layer for each animation frame needed.

Key features

  • Highlight, underline and strikethrough
  • Blinking cursor for multi-line text
  • Typewriter and Blinky effects preserving styling
  • Number formatting and time counters
  • Text-to-shape conversion
