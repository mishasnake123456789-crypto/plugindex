What Panel Stitcher does

From Witting Graphics, Panel Stitcher procedurally generates rivets, bolts and stitching along edges, useful for metal plating, wood, garment seams and armored vehicles like planes or cars.

Placement can be mixed using options like insetting edges and randomness. Edges can be filtered by automatic limit modes, or you can mark them manually in edit mode to stay in full control. A pattern can be projected onto a different object during generation, which is helpful for high-resolution meshes and sculpts, and included stitch templates add clothing seams with a button press.

Key features

  • Generates rivets, bolts and stitching
  • Inset and randomness placement options
  • Automatic or hand-marked edge selection
  • Project patterns onto another object
  • Stitch templates for clothing seams
