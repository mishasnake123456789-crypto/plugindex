Randomizes the Offset of Noise F-Curve modifiers on selected objects' active actions in Blender, entered in seconds.

What Randomize Noise Offset does

Randomize Noise Offset spreads out noise-driven animation in Blender so that many objects do not wobble in sync. It changes the Offset value of every Noise F-Curve modifier on the active action of each selected object, or of the active object if nothing else is selected.

The offset is entered in seconds and converted into frames automatically, and a seed field makes the result reproducible. Animators using procedural shake or sway on crowds, foliage or props can add variety with one operation.

Key features

  • Randomizes Noise modifier Offset values
  • Applies to selected or active object actions
  • Offset set in seconds, converted to frames
  • Seed field for repeatable results
