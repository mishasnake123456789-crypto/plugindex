What XPS Import/Export does

XPS Import/Export lets Blender read and write XPS (XNALara) models and poses. This version is kept up by maylog as a fork brought up to date for Blender 5.0 and handles armatures, custom normals and materials.

Materials are created on import, a new rest pose can be set easily, and the native .xps binary format is supported. Artists working with XNALara assets, whether for posing or rendering, can move characters between the two tools with fewer manual fixes.

Key features

  • Imports and exports models with armature
  • Pose import and export
  • Custom normals support
  • Materials created on import
  • Easy rest pose setup
