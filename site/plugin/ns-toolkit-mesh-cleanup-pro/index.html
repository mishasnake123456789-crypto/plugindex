What NS Toolkit - Mesh Cleanup Pro does

NS Toolkit highlights topology in real time and provides cleanup tools powered by bmesh.ops in Blender.

Color coding marks N-gons blue, triangles red and quads green. Cleanup covers converting triangles to quads, merging vertices and fixing normals, plus a reset for transforms. Modelers checking meshes before export or sculpting can find and fix problems quickly. Seeing problem areas highlighted while editing makes it easier to keep topology clean, which matters for subdivision, animation and game-ready assets.

Key features

  • Real-time N-gon, tri and quad highlighting
  • Tri-to-Quad conversion
  • Merge Vertices
  • Normal correction
