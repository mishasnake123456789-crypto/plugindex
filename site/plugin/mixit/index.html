Blender lighting add-on that creates, tweaks and mixes lights with automatic lightgroups in Cycles.

What Mixit does

Mixit is a Blender lighting tool made to speed up building and balancing lights. It only works with the Cycles render engine, and it takes care of lightgroup assignment so compositing setups are ready when you are.

New lights are aligned to the selected objects, and a modal control lets you adjust their parameters on the fly. You can spawn lights with random colors in one click, blend lights together with a single action, and generate light group profiles for later compositing. Each light gets its matching lightgroup automatically. Documentation is included.

Key features

  • Creates lights aligned to selected objects
  • Modal editing of light parameters
  • One-click random color lights and light mixing
  • Automatic lightgroups and group profiles
