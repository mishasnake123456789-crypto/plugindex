Lightweight Blender add-on for visualizing, inspecting and editing per-vertex alpha values.

What Alpha Setter does

Alpha Setter gives precise control over vertex alpha in Blender. It displays the values in the viewport so you can see where transparency is applied.

It works across Object, Edit and Vertex Paint modes, shows exact alpha per vertex, and lets you edit values directly in Edit Mode, including a one-click Brightness/Contrast adjustment. It is compatible with both Vulkan and OpenGL backends. Environment and prop artists who bake transparency into vertices will find it handy.

Key features

  • Real-time vertex alpha visualization
  • Works in Object, Edit and Vertex Paint modes
  • Inspect exact per-vertex values
  • Edit alpha directly in Edit Mode
  • Vulkan and OpenGL compatible
