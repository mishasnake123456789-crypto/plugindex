Blender add-on that saves selected Bezier and Poly curves as SVG with projection, fill and stroke options.

What Export Curve as SVG does

Export Curve as SVG writes Blender curve objects out as vector files. Selected Bezier and Poly curves, in 2D or 3D, are saved as .svg from a chosen projection: top, front or side.

A scale slider sets the output size, fills can be off, applied to everything, to closed curves only or to filled 2D curves, and fill color can come from a custom value, the object, the material or a random pick. Stroke width and stroke color offer the same sources, which is helpful for logos, laser paths and 2D illustration.

Key features

  • Exports Bezier and Poly curves as SVG
  • Top, front or side projection
  • Scale slider for output size
  • Fill modes: none, all, closed or filled 2D
  • Custom, object, material or random colors
