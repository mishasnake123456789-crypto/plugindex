What Theme Candy does

Theme Candy changes the look of Blender's interface without hunting through dozens of theme settings. A single color wheel recolors the entire UI.

Viewport selection colors can be synced with the interface, Edit Mode selection colors adjusted separately, and panel colors changed for a different feel. An advanced mode exposes additional controls for fine tuning, while key theme options stay within easy reach. It is made by Armored Colony.

Key features

  • Recolor the whole UI from one color wheel
  • Sync viewport selection colors
  • Independent Edit Mode selection colors
  • Panel color adjustment
  • Advanced mode for fine tuning
