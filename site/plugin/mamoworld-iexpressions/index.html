What mamoworld iExpressions does

mamoworld iExpressions lets After Effects artists use expressions without learning to code. More than 100 are included, and each appears with an adjustable interface that resembles a regular effect.

You can also import your own expressions, and iExpressions reads the code to generate controls for it. Projects keep working on machines without the plugin installed and inside Premiere Pro Motion Graphics Templates. Categories include shape expressions for wavy lines, trails and connecting curves, color expressions, and a React Spring option for physics-style animation.

Key features

  • 100+ expressions with effect-style controls
  • Import your own expressions and get an auto-built UI
  • Shape expressions for waves, trails and connectors
  • Color expressions with brightness and saturation links
