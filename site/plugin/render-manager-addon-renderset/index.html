What Render Manager Addon Renderset does

Renderset from polygoniq creates and manages variations of one Blender scene. Switching camera, HDRI, render and visibility settings does not require duplicating collections or objects.

Contexts store these settings plus custom properties inside the .blend file, and nearly any property can be stored by right-clicking it. Output naming uses variables that pull in scene properties, and batch rendering is supported. Product visualizers and archviz artists producing many angles and lighting variants save setup time.

Key features

  • Renderset contexts stored in the .blend
  • Right-click storage of almost any property
  • Output naming with variables
  • Batch rendering
