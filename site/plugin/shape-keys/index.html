Blender add-on for managing shape keys: duplicate, mirror, invert, blend with vertex groups and apply to basis.

What Shape Keys ++ does

Shape Keys ++ gives Blender animators more control over shape keys without switching modes. Keys can be duplicated, mirrored, inverted and moved, and blended using vertex groups, with a Blend From Shape mode that previews in real time.

Global sliders sit beside lock and mute toggles for all keys. A selected key or all mixes can be applied to the basis while keeping the keys, and batch actions delete keys or remove zero-delta ones. A preset system, shape key order copying and update notifications round it out. It is handy for facial expressions.

Key features

  • Duplicate, mirror, invert and move keys
  • Blend with vertex groups, real-time preview
  • Global sliders and lock or mute all
  • Apply shapes to basis
  • Batch delete and zero-delta removal
