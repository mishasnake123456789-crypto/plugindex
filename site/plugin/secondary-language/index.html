Blender add-on for flipping between a default and secondary interface language with a keyboard shortcut.

What Secondary Language does

Secondary Language helps people who use Blender in two languages. It switches quickly between a default and a secondary interface language, supports any language, and starts with en_US and ja_JP configured.

A translation target setting takes priority, and the add-on remembers your translation choices between sessions. The default keymap is Shift plus the period key, and the interface is deliberately compact with a simple feature set. No special permissions are required.

Key features

  • Toggle between two interface languages
  • Any language supported
  • Remembers settings between sessions
  • Shift and period default shortcut
  • Compact interface
