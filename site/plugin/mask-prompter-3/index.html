What Mask Prompter 3 does

Mask Prompter 3 creates mattes by telling an AI what to select. In After Effects, you can describe the subject in text, draw boxes around objects or click points, and the plugin returns a matte, with every model running fully on your own machine.

It is based on Segment Anything versions 1, 2 and 3, with room for custom additions, and refines mattes using VITMatte. More than ten models ship with it. A Stop Processing button cancels long jobs at once, and a CUDA Memory Sharing option speeds up resolutions above 4K on CUDA. Premiere Pro is mentioned as a supported host too.

Key features

  • Mattes from text, box or point prompts
  • Segment Anything 1, 2 and 3 based
  • VITMatte refinement
  • 10+ models, all local
  • Stop Processing and CUDA Memory Sharing
