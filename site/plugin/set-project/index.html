Maya-style project setup for Blender covering naming, folder structure, presets and save options.

What Set Project does

Set Project brings ideas from Maya's project management into Blender. Through a simple interface you name a project, choose its location and build out the folder structure.

Presets can be the defaults or your own custom ones. Saving options include file names, compression settings and path remapping. Folder lists refresh automatically or manually, and the add-on recognizes folders created outside Blender, for example in Windows Explorer. It suits artists and small teams who want every job organized consistently from day one.

Key features

  • Default and custom project presets
  • Project name, location and folder setup
  • Save options with compression and path remapping
  • Auto or manual folder refresh
