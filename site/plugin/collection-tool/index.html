What Collection_Tool does

Collection_Tool is a bundle of five plugins from Animation Store. They are intended to make character animation, modeling and curve handling quicker, easier and cleaner.

The set includes a snap_object tool with extra features and a hook curve component supported by a tutorial. A newer release for Blender 4 includes many more features. Documentation is included and the license is GPL. Generalists who animate and model in the same file can keep several small helpers together.
