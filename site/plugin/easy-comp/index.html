What Easy Comp does

Easy Comp from Blace Plugins uses an AI backend to process After Effects compositions. It can run in CPU mode or with hardware acceleration on Windows with NVIDIA GPUs and on macOS 12.3 or later with M1, M2 or AMD GPUs.

It handles foreground layers that have masks applied and supports 16-bit compositions. A CUDA Memory Sharing option accelerates renders above 4K and a Stop Processing button cancels long computations immediately. It is aimed at the 2025, 2024 and 2023 releases. Compositors wanting AI-assisted compositing can use it with or without a capable GPU.

Key features

  • AI backend for compositions
  • CPU mode and GPU acceleration
  • CUDA Memory Sharing for above 4K
  • Stop Processing button
  • Foreground masks and 16-bit comps
