Retopology tool for Blender with mesh projection, display controls and a minimal interface with no new shortcuts.

What Retopo_Mat does

Retopo_MAT helps artists create clean topology and tidy meshes in Blender. Made by artists, the interface sticks to what is needed and avoids new shortcuts to learn.

Display options help when working on several objects at once, with adjustable reference or retopo material display, wire thickness and vertex size. Meshes can be projected onto any surface and adjusted in position. A comfortable option for retopology work. Together these options make it easier to see and edit new topology on top of a high-resolution reference without constantly changing view settings.

Key features

  • Display customization for reference and retopo
  • Adjustable wire thickness and vertex size
  • Mesh projection onto any surface
  • No new shortcuts to learn
