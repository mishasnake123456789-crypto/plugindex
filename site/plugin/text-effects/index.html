Blender add-on for animating 3D text with presets such as typewriter, wave, wiggle and scramble, without keyframes or math.

What Text Effects does

Text Effects animates text in Blender with no keyframing or math involved. Convert any text object and apply presets such as typewriter, wave, wiggle, scramble and counters.

Presets can be reused as templates. Version 5 runs on a native, multithreaded Rust engine using all CPU cores, with text creation up to about sixty times faster and real-time editing. Motion designers can build titles and kinetic type quickly. Because effects work without manual keyframes, titles can be changed or retimed easily, and saved templates keep the look consistent across a project.

Key features

  • Presets: typewriter, wave, wiggle, scramble
  • Counter effects
  • Reusable templates
  • Multithreaded Rust engine in v5
