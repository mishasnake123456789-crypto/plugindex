What Toggle Editors does

Pitiwazou's Toggle Editors helps manage the screen layout in Blender. It switches between editors quickly and lets you change the layout while working, without rebuilding areas by hand.

Its emphasis is area management and customizable UI adjustments directly in the workspace, with documentation included. Artists who constantly swap between timeline, graph editor, shader editor and viewport will move between them with less effort. Quick layout changes make small screens and laptop setups more workable, since one area can serve several purposes.

Key features

  • Switch between editors on the fly
  • Edit the layout without reconfiguring
  • Area management tools
  • Fits a customizable UI workflow
  • Documentation included
