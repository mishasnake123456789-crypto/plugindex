What Vdm Brush Importer does

Vdm Brush Importer is a Blender plugin that converts VDM brush files into usable sculpt brushes. Drop in an .exr and the brush is created straight away, with an anchored preset.

Thumbnails are generated automatically, and you can pick a plane or a sphere as the base object, switching between them without renaming or deleting objects. This saves sculptors from manual brush setup when using libraries of vector displacement stamps. Skipping manual brush setup means large collections of displacement stamps can be loaded quickly, ready for adding details like horns, ears and scales to sculpts.

Key features

  • One-click .exr VDM import
  • Automatic thumbnails
  • Plane or sphere base object
  • Anchored brush preset
