What Bevel Weight Manager does

Bevel Weight Manager gives modelers many bevel weight sets in Blender by wrapping the custom attribute system. This helps when several weighted bevel modifiers are layered on one mesh.

Create and delete attributes for bevel modifiers, tag or untag edges, vertices or faces with a value, and control sizes per element within each modifier. A pie menu, ALT+SHIFT+A by default, gives quick access, and attributes can be previewed on the mesh. Documentation is included.

Key features

  • Unlimited bevel weights via custom attributes
  • Tag and untag edges, vertices or faces
  • Pie menu access, configurable hotkey
  • Mesh preview of assignments
