Blender add-on that ranks mesh objects by polygon count, shows a viewport heatmap and batch-reduces heavy geometry.

What Poly Finder - Find The Problem Objects Fast does

Poly Finder shows which objects are weighing down a Blender scene. It lists every mesh sorted by polygon count along with each object's share of the total, and a viewport heatmap colours objects green, orange or red by weight.

You can switch between faces, triangles, vertices and edges, with or without modifiers, and set a per-object polygon budget to select everything over the limit. Batch tools remove Subdivision Surface modifiers, add Decimate modifiers at a chosen ratio and apply them together. The scope can be the whole scene, visible or selected objects, or one collection, which helps with imported marketplace assets and laggy viewports.

Key features

  • Ranked list of meshes with percentage impact
  • Viewport heatmap by geometry weight
  • Faces, triangles, vertices and edges metrics
  • Polygon budget selection
  • Batch Decimate and Subdivision removal
