Tidies Blender node graphs by aligning, auto-laying out, removing unused nodes and cleaning stray links and reroutes.

What Node Organizer does

Node Organizer helps keep complicated node trees readable. Selected nodes can be aligned horizontally or vertically, and an auto-layout arranges whole setups.

It deletes unused nodes, clears dangling links and orphan reroutes, and gives statistics about the graph. It works in Shader, Geometry and Compositing editors. Anyone inheriting messy node networks or building large procedural setups will find cleanup far quicker. Reducing clutter this way makes older or shared files much easier to understand and maintain.

Key features

  • Horizontal and vertical alignment
  • Auto-layout
  • Removal of unused nodes
  • Cleanup of stray links and orphan reroutes
  • Graph statistics
