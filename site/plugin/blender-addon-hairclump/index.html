What Blender Addon | Hairclump does

HairClump is a Blender plugin for styling complex hair through simple guides. It controls randomness in a parametric way, using clump-based length and kink controls.

Virtual parents determine how many clumps there are and change the random seed, with length, curve, shape and noise controls per clump. Kink Random offers curl, radial, wave and braid modes. Particles and instances can be exported to Alembic. Together these controls make it easier to create natural, varied hair and fur while keeping the setup driven by a few simple guides.

Key features

  • Virtual Parents for clump control
  • Length, curve, shape and noise randomness
  • Curl, radial, wave and braid kinks
  • Alembic export
