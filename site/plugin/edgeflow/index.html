EdgeFlow

Developer: Benjamin-Sauder

FreeBlender
Download Free

Blender add-on for fitting edge loops to curvature with Set Flow, Set Linear and Set Curve operators.

What EdgeFlow does

EdgeFlow improves how edge loops follow curved surfaces in Blender. Its main operator, Set Flow, fits a selected loop to the surrounding mesh curvature using spline interpolation.

Mix, Tension, Iterations and Min Angle settings shape the result. Set Linear straightens loops between their endpoints, spacing points evenly or from original distances, and Set Curve bends a loop onto a spline defined by its first and last edge. Subdivision and character modelers can clean up flow and smooth out irregular spacing quickly.

Key features

  • Set Flow fits loops to curvature
  • Mix, Tension, Iterations, Min Angle controls
  • Set Linear straightens loops
  • Set Curve bends loops onto a spline
