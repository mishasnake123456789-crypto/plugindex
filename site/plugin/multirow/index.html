Blender add-on that lets you put several lines of text into a TextStrip using line breaks.

What Multirow does

Multirow, by flakmoppen, removes a limitation of text strips in the Blender Video Sequencer: entering more than one line. With it you can add multiple rows using line breaks.

It works across the Sequencer, the Text Editor and the Blender user interface, requires no special permissions and keeps its defaults, such as the text name, in the add-on preferences. Video editors adding captions, credits or multi-line titles will find it saves workarounds.

Key features

  • Multiple text rows in a TextStrip
  • Line break support
  • Works in Sequencer, Text Editor and UI
  • Default text name in preferences
