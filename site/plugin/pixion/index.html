GPU-accelerated particle system for After Effects driven by pixel data from source layers.

What Pixion does

Pixion is a grape design particle system in which layers do the directing. Particles are emitted from any source layer and shaped by pixel values such as luminance and color, so artwork itself defines where and how they appear.

A separate modifier layer drives behavior, and built-in turbulence is joined by gravity and wind. Particles can use custom shapes, including layers, with auto orientation and camera-facing options. Simulation speed and pre-run are adjustable, and a blend mode manages overlapping particles. GPU acceleration keeps interaction smooth.

Key features

  • Emitter layers using pixel data
  • Separate modifier layer for behavior
  • Turbulence, gravity and wind forces
  • Custom particle shapes and camera-facing
  • Simulation speed, pre-run and blend mode
