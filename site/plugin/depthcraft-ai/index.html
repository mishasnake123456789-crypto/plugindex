What Depthcraft Ai does

DepthCraft AI turns a single photograph into relief geometry with one click. It estimates depth using Depth Anything V2, builds a mesh from it, applies the photo as texture and generates a normal map.

It copes with portraits, animals, landscapes and architecture. Backgrounds can be removed in real time with an Edge Threshold slider, and a Fill by Color mask tool offers adjustable tolerance. Artists making quick 3D from reference photos, parallax scenes or concept pieces will find it a fast starting point.

Key features

  • Depth Anything V2 depth estimation
  • Automatic textured mesh and normal map
  • Real-time background removal with threshold
  • Fill by Color masking tool
