Multi Delta Mush

Developer: Mush3D

FreeBlender

Blender add-on that trains a character deformer from pose examples to improve deformation and reduce corrective setups.

What Multi Delta Mush does

Multi Delta Mush learns how a character should deform from example poses. You give it a bind mesh and corrective samples, and it blends them during animation.

This reduces the need for complex corrective shape keys and drivers. The output mesh updates live as you pose or scrub, and envelope, mask, relax and stack iteration controls shape the result. A compiled C++ core delivers performance, with a CPU backend and optional OpenCL acceleration. Aimed at character artists, riggers and technical artists.

Key features

  • Deformer trained from pose examples
  • Fewer corrective shape keys and drivers
  • Live mesh updates
  • Envelope, mask, relax and iteration controls
  • C++ core with optional OpenCL
