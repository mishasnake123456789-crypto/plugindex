What Web3D X3D/VRML2 format does

Web3D X3D/VRML2 format connects Blender with older web 3D formats. It reads .x3d (Extensible 3D) and .wrl (VRML2) files and writes .x3d, covering X3D 3.3 and VRML 2.0.

It sits under File > Import-Export. Version 2.5.1 import fixes treat color per face separately from vertex color, add a new handler for strings that yields matching X3D and VRML results, and make IndexedShape import tolerate fewer points than coordinate indices. Users working with legacy web or scientific 3D models can rescue them.

Key features

  • Imports X3D and VRML2
  • Exports X3D
  • Supports X3D 3.3 and VRML 2.0
  • Import fixes in 2.5.1
