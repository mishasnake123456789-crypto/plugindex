What Captioneer does

Captioneer generates captions quickly for social video and other projects, working inside After Effects and Premiere Pro. There is no cap on the number of captions, and any language can be handled.

Its Auto-Captions feature lets you select a transcription model, such as Large V3, and choose whether processing runs on the GPU, CPU or automatically. An offline workflow is supported, including SRT import. After Effects users get precomps and a Sync All function, and a caption track can be built from the auto-generated transcript. Motion attributes can be copied and pasted between captions, and MOGRT updates are available.

Key features

  • Auto-Captions with selectable models like Large V3
  • Auto, GPU or CPU processing
  • Unlimited captions in any language
  • Offline workflow with SRT import
  • Copy and paste motion attributes
