What YouTube Chapters does

YouTube Chapters is a Film Tools extension that creates the timestamp list YouTube uses for chapters. It reads the markers in your project and formats them so you can copy and paste the result into the description.

It avoids adding an automatic 0:00 entry when a marker already sits at the start. It works with Premiere Pro 9.0 and later, helping creators who add chapters to every upload. It saves typing out timestamps by hand and keeps chapter titles consistent with the cut.

Key features

  • Chapter list generated from project markers
  • Copy and paste into a YouTube description
  • Skips automatic 0:00 when a marker exists
  • Works with Premiere Pro 9.0 and later
