What Vizual PixelPerfect does

Vizual PixelPerfect, from Autokroma, fills a gap in Adobe's video apps: Premiere Pro has no native nearest-neighbour scaling, so pixel art tends to get blurry when enlarged. This free plugin lets you upscale such graphics cleanly in a couple of clicks.

The Nearest Neighbor algorithm preserves the hard square pixels typical of retro artwork, linear interpolation offers a softer alternative, and a Nearest option with antialiasing can be tuned with the Edge Blur slider. It works in both After Effects and Premiere Pro, and benefits from GPU acceleration in After Effects.

Key features

  • Nearest Neighbor scaling for hard pixel edges
  • Linear interpolation option
  • Antialiased nearest mode with Edge Blur slider
  • GPU acceleration in After Effects
  • Fills the nearest-neighbour gap in Premiere Pro
