What Source Engine Collision Tools does

Source Engine Collision Tools helps Blender users build collision meshes for Source Engine titles including TF2, Garry's Mod and Left 4 Dead 2, and it is intended to be used with the Blender Source Tools.

Several generators are available: bisection that divides a model into sections, creation from faces, creation from rigged weights (useful for Garry's Mod ragdoll physics), from UV islands that each become a separate hull, and via the built-in Cell Fracture addon. Modders preparing props or ragdolls for Source games can speed up collision setup considerably.

Key features

  • Collision generation by bisection
  • Generate hulls from faces or UV islands
  • Weight-based hulls for ragdoll physics
  • Fracture-based generation via Cell Fracture
