What Checkmate Pro does

CheckMate Pro, by Pixel Vampire, keeps a to-do list inside the Blender project it belongs to. It suits freelancers and studio teams who want to track work without leaving the application.

Tasks are grouped into categories by department, project or focus, and a hotkey opens a pop-up checklist for ticking items off. Data is stored per .blend file and can be shared between users and across Windows, Linux and Mac. No outside database, cloud service or account is needed, and the interface stays minimal.

Key features

  • Task categories by department or project
  • Hotkey pop-up checklist
  • Saved per .blend file, shareable across systems
  • No cloud or account required
