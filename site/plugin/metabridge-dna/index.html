What Metabridge_Dna does

Metabridge_Dna connects Blender to MetaHuman characters. It imports and exports MetaHuman DNA files and works with DNA, FBX and glTF formats.

Head and body can be managed separately and assembled into one character. A Face Rig board drives expressions through bone controls with real-time preview, and Rigify integration provides body control rigs for animation. Animators who want to pose MetaHumans in Blender will find it useful. The result is a more direct route from a MetaHuman asset to a character you can animate or render in Blender.

Key features

  • Import and export MetaHuman DNA files
  • DNA, FBX and glTF formats
  • Separate head and body, then assemble
  • Face Rig board with real-time preview
  • Rigify-based body control rigs
