What Andra Uv Rename does

Andra UV Rename is a Blender add-on for standardizing UV map names. Pipelines that move between Blender and other tools often demand consistent naming, and this makes the fix a one-click job across many objects.

Three modes are offered: Blender's default "UVMap", Maya's "map1", or a custom name. Non-mesh objects are skipped automatically, and a report afterward lists processed meshes, skipped items and objects with no UVs. It plugs into Blender's undo system and lives in the sidebar Edit tab. It is a practical helper for artists preparing assets for game engines or other DCC software.

Key features

  • Blender, Maya and custom naming modes
  • Batch processing across many objects
  • Skips non-mesh objects automatically
  • Post-run report of processed and skipped items
  • Full undo support
