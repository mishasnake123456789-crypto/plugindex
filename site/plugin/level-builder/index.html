Blender asset placement toolset for level design, offering grid, surface and scatter modes fed from blend libraries.

What Level Builder does

Level Builder is a collection of placement tools for Blender that shortens the level design process. An asset selector reads models from blend libraries sorted by collection, and you then drop them into the scene using one of three modes.

Grid mode snaps to a configurable grid with hotkeys for rotating and scaling, surface mode places assets on geometry and lets you paint along a stroke, and scatter mode distributes them across an area. Multiple assets can be chosen randomly with weights or in sequence. A batch script imports whole folders and builds previews.

Key features

  • Asset selector reading collections from blend libraries
  • Grid mode with snapping and rotate or scale hotkeys
  • Surface mode with drag-to-paint placement
  • Scatter mode with weighted random or sequential choice
  • Batch import and preview generation for folders
