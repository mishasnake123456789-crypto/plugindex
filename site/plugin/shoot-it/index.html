What Shoot-It does

Shoot-It, by Xane Studios, adds an instantiation workflow similar to what game engines offer. With a button press it spawns objects or fires them into the scene, and this drives the popular motion graphics effect of items accumulating into a build-up.

New objects can spawn with additional properties such as light. Motion designers can create piles, cascades and assembly animations quickly without keyframing each object.

Key features

  • Spawn or fire objects with one button press
  • Game-engine style instancing
  • Build-up motion graphics effect
  • Spawned objects can carry extra properties
