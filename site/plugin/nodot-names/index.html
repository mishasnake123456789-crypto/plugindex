Blender add-on that replaces .001 duplicate suffixes with studio, Unreal or Unity naming conventions, with validation and batch rename.

What NoDot Names does

NoDot Names addresses Blender's habit of adding .001 to duplicates. Built-in naming schemes target Unreal, Unity and studio pipelines, and you can define your own in the Naming Convention Editor.

Live Rename converts new duplicates automatically, validation reports names that break the rules and batch renaming fixes existing assets. Teams delivering to game engines can keep clean, predictable object names throughout production.

Key features

  • Unreal, Unity and Studio Pipeline presets
  • Custom Naming Convention Editor
  • Live Rename of new duplicates
  • Validation and batch renaming
