Blender add-on that positions objects with rigid body physics, with collision shapes, duplication and force controls.

What Kineticmove does

Bevel_3d's KineticMove lets physics place objects in Blender. A sidebar panel in the 3D View offers collision shapes (Box, Sphere, Mesh, Capsule or Cylinder), one-click duplicate-and-lift, and simulation controls.

You can apply forces and watch interactions live, and set an object's origin to its geometry for exact positioning. It suits dropping props naturally onto surfaces, building piles and arranging scenes where believable placement matters. Because it relies on Blender's own rigid body engine, the results behave like any other physics simulation in the scene.

Key features

  • Box, Sphere, Mesh, Capsule and Cylinder collisions
  • Single-click duplication and lifting
  • Rigid body simulation controls
  • Add forces and view interaction live
  • Set origin to geometry
