What MMGpy - Mesh Remeshing does

MMGpy brings adaptive surface remeshing to Blender using the open-source MMG library; pressing Remesh in the N panel regenerates the active mesh where it stands, with undo available.

Fine, Medium and Coarse presets and sliders set density, and a Sphere or Box Empty defines local refinement zones. Shading by quality runs from red for poor to blue for excellent, with live statistics. A confirmation appears before very large results. Scripters get the full mmgpy API and a Medit reader and writer for .mesh and .meshb files.

Key features

  • Adaptive remesh in place with undo
  • Presets and sliders for density
  • Local refinement via Sphere or Box Empty
  • Color-by-quality shading and stats
  • Full mmgpy API and Medit file support
