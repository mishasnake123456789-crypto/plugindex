A Blender add-on for adding your own translations to interface text, including text from other add-ons.

What User Translate does

User Translate lets you translate Blender's interface yourself, manually or semi-automatically, which is especially useful for third-party add-ons that only ship English text. It converts that text into your own language through a dictionary you maintain.

Translations live in a CSV file in the add-on's user_files folder, in a Translated text and English format that opens in spreadsheet software such as Excel. The dictionary reloads every second, so results show immediately, and translation results can be viewed in the interface. Non-English speakers and community translators will find it makes unfamiliar tools easier to use.

Key features

  • Manual and semi-automatic interface translation
  • CSV dictionary editable in spreadsheets
  • Dictionary reloads every second
  • Works on text from external add-ons
