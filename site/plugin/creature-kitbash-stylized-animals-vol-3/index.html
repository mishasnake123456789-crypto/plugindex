What Creature Kitbash - Stylized Animals Vol. 3 does

Creature Kitbash Vol. 3 offers 169 stylized animal pieces that you assemble into new characters. Heads, torsos, limbs, fins, wings, tentacles, beaks and shells can be mixed freely.

The parts load through Asset Manager integration, mirroring and placement tools help position them, and boolean or remesh options merge them into one mesh in a click. Concept artists and game designers can prototype creatures quickly before refining them. Pieces stay editable, so a base creature can be modified later.

Key features

  • 169 stylized body parts
  • Asset Manager integration
  • Mirroring and placement tools
  • One-click boolean or remesh merge
