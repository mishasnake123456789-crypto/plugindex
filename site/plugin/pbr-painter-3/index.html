What Pbr Painter 3 does

PBR Painter 3 brings layer-based texture painting to Blender. From its dedicated workspace you can edit albedo, roughness, normals, emission and other channels simultaneously.

Materials can be created from scratch, built from imported PBR maps or generated procedurally per channel. Node setups are generated and managed automatically, so manual node creation is unnecessary, and normals from stacked layers can be combined. Texture artists get a Substance-like workflow without leaving Blender.

Key features

  • Layer-based multichannel editing
  • Import PBR maps or generate procedurals
  • Automatic node setup
  • Combines normals of stacked layers
