What Animation Utilities does

Animation Utilities collects a range of small helpers for character animators in Blender into one framework. It covers posing, playback, NLA strip handling, keyframing and viewport control.

Posing tools symmetrize a pose from one side to the other, isolate selected bones and reset transforms to rest in a click. Play/Stop runs the whole animation stack even while an NLA strip is in tweak mode, and a dedicated operator toggles tweak mode. The Insert Keyframe button changes icon color to show an active action or NLA strip.

Key features

  • Symmetrize, isolate and reset poses
  • Play/Stop for the full animation stack
  • Toggle NLA strip tweak mode
  • Insert Keyframe button with status color
  • Viewport and view-control operators
