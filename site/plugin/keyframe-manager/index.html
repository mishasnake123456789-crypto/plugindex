What Keyframe Manager does

Keyframe Manager from Pixcode gives After Effects animators a single panel for working with keyframes, rather than hunting through the timeline. It lists keyframe data so values can be read and changed directly.

You can rewrite any value, swap easing types, run search and replace across values, and shift keys by set amounts. Order can be rearranged visually, and values copy and paste between properties. Favorite easing curves are saved for reuse, which speeds up polishing animation on complex comps.

Key features

  • Edit any keyframe value directly
  • Change easing types and save favorites
  • Search and replace values
  • Reorder keyframes visually
  • Shift keys by defined amounts
