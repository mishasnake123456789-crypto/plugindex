What Alt Tab Colorful does

Alt Tab Colorful keeps your favorite colors close at hand in Blender. Rather than hunting through old files for a hex value, you save colors and entire palettes inside the application and call them up when needed.

It is released under the GPL, runs as a regular add-on and is listed as compatible with Blender Extensions, covering versions 4.0 through 5.0. The developer provides documentation and a demo video to help you get started.

Key features

  • Save individual colors for reuse
  • Store complete color palettes
  • Works with Blender 4.0 through 5.0
  • GPL licensed and extension compatible
  • Documentation and demo video provided
