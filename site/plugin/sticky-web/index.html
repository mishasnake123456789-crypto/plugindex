What Sticky-Web does

Sticky-Web is a Stoij tool for parenting and anchoring layers by working directly in the composition viewer. Instead of dragging pick whips in the timeline, you draw the parent chain on screen and move anchors visually.

IK rigs are possible by ending a web with three mask points, giving a two or three bone setup. Auto-Web loads webs from a custom list, Unstack Anchors recenters anchor points and spreads them in a circle when needed, and an option skips full-screen and empty layers. An Undo Sticky-Web button cancels the operation instantly, and separated X and Y position dimensions are supported.

Key features

  • Draw parent chains in the comp
  • IK rigs from three mask points
  • Auto-Web from a custom list
  • Unstack Anchors recenters anchor points
  • Undo Sticky-Web button
