Snap To Custom Grid

Developer: Sidigon

FreeBlender
Download Free

Lightweight Blender add-on that snaps vertices or object origins to a custom grid on chosen axes.

What Snap To Custom Grid does

Snap to Custom Grid aligns geometry to the nearest point of a grid you define. In Edit Mode it moves selected vertices, and in Object Mode it moves the origins of selected objects.

Axis toggles decide whether X, Y and Z are included, and the grid size is custom so it can match your scene scale. Controls are under the Snap Grid tab in the sidebar, undo works for every action, and no external dependencies are needed. It runs on Windows, macOS and Linux.

Key features

  • Snaps vertices or object origins
  • X, Y and Z axis toggles
  • Custom grid size
  • Snap Grid tab in the sidebar
  • Undo support, no dependencies
