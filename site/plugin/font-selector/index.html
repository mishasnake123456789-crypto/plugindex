Font Selector

Developer: tonton_

FreeBlender

Blender add-on for previewing and applying fonts on text objects and video strips, without opening a file browser.

What Font Selector does

Font Selector shows the fonts installed on your system and lets you apply them to the active text object while you watch the result. You no longer need to load each font through the file browser to see how it looks.

Font folders are detected automatically for the host operating system, and it works with both 3D text objects and text strips in the video sequencer. Titling artists and motion designers can browse typefaces right in the 3D viewport.

Key features

  • Automatic font folder detection
  • Works on 3D text and video text strips
  • Live preview on the active text object
  • Browse without leaving the 3D viewport
