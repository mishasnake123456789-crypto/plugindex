Moves the numeric prefix of selected Blender objects up or down with a button.

What Increase Objects Number does

Increase Objects Number adjusts the numbers at the start of object names. Select the objects, press a button, and their prefixes go up or down instead of being retyped one by one.

You can set the separator between name and number, such as a period or underscore, and the tool sits in the Scene panel. New objects can be inserted into a numbered sequence without breaking the order. Handy for ordered parts, shots and sequences.

Key features

  • Raises or lowers numeric prefixes
  • Works on many objects at once
  • Configurable separator
  • Scene panel interface
