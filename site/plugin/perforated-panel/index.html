Geometry Nodes modifier for procedural perforated surfaces on Blender curves with square or hex hole grids.

What Perforated Panel does

Perforated Panel adds real, non-destructive perforation geometry to curve objects. Attach the modifier and customize the pattern without handling node trees yourself.

Controls include hole size, shape, spacing, offset, rotation and grid type, square or hexagonal, with real-time feedback. It suits speaker grilles, vents, industrial panels and architectural screens. You get modifier-based workflow on curves, hole size, shape, spacing, offset, rotation and square or hexagonal grid, along with the rest of the feature set.

Key features

  • Modifier-based workflow on curves
  • Hole size, shape, spacing, offset, rotation
  • Square or hexagonal grid
  • Non-destructive geometry
