What Shape Wave (Pro) does

Shape Wave (Pro) extends Blender's Shape Keys panel for animators who want more expressive blend shape motion. It adds an evaluation-time control that can be keyed or driven by a driver object.

More than twenty interpolation methods are available, including Spring, Bounce Back, Heartbeat and Glitch. Auto-play advances shape key sequences during playback with easy looping, and timing settings customize segment sizes and overlaps between transitions. Because it sits inside the existing panel, it suits facial animation, morphing and motion graphics work.

Key features

  • 20+ interpolation types such as Spring and Heartbeat
  • Keyable evaluation-time sliders
  • Driver object support
  • Auto-play and looping
  • Timing settings for segment size and overlap
