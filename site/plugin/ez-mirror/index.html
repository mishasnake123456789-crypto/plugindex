What Ez Mirror does

Ez Mirror speeds up mirroring in Blender. Press Alt+X, pick an axis, and mirror meshes and curves either with a non-destructive Mirror modifier or directly with Symmetry mode on the mesh.

Orientation options include Local, Global, View and Cursor, and pivot points can be Active, Median, Cursor or Individual. Multiple objects can be mirrored at once with a single command. It helps modelers who mirror often and want fewer menu trips and faster setup.

Key features

  • Alt+X shortcut starts mirror mode
  • Modifier mode and Symmetry mode
  • Local, Global, View and Cursor orientation
  • Multi-object mirroring
