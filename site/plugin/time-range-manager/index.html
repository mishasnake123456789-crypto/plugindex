Time Range Manager

Developer: lbrooks

Free3ds Max
Download Free

3ds Max script for storing named time ranges and using them for FBX export, file splitting and camera switching.

What Time Range Manager does

Named time ranges can be saved and picked from a dropdown, which changes the scene's range instantly. Ranges are stored as sets, and sets can be grouped into projects held in INI files that live outside any maxfile.

The same data drives several tasks. Time tags can be edited from ranges and moved between the scene, loaded ranges and a text file. FBX export can follow ranges or tags for the whole scene or a selection, saving into the current scene folder. Composite maxfiles can be split into separate files by stored range, and the viewport swaps cameras on its own when a range name starts with a camera's name. A compact mode saves screen space.

Key features

  • Named time ranges recalled from a dropdown
  • Ranges saved as sets and projects in INI files
  • Edit and transfer time tags between scene and text file
  • FBX export and maxfile splitting driven by ranges
  • Automatic camera switching by range name prefix
