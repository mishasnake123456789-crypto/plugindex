Defines volumes in Blender from faces with per-vertex radii and offsets, using a Geometry Nodes modifier.

What Vertex Volumes does

Vertex Volumes is a Blender plugin providing a Geometry Nodes modifier that builds volumes from faces. Each vertex can carry its own radius, and values are interpolated across the vertices that form a face.

The radius expands relative to the face normal while the original geometry is kept, and a per-vertex offset moves it along the normal in either direction. Expansion direction is controlled by a value from minus one to one. It is useful for organic forms, thickening and procedural shapes.

Key features

  • Per-vertex radius interpolated across faces
  • Per-vertex offset along the normal
  • Expansion direction from -1 to 1
  • Original geometry retained
