What Batch Bone Constraints does

Batch Bone Constraints applies constraint work to many armatures in one go in Blender. Six modes cover Delete, New, Remove Copy, Copy, Remove Imitate and Imitate, working in Object and Pose mode.

Imitate and Copy match bones by name in the active armature, New puts constraints on every bone in Object mode, or on the selected bones in Pose mode, and Delete removes constraints by type, including invalid ones. Imitate supports Copy Location, Rotation, Scale and Transforms, while other modes handle every bone constraint type. The menu is in the 3D Viewport header.

Key features

  • Six modes from Imitate to Delete
  • Matches bones by name
  • Add constraints to all or selected bones
  • Delete by type with invalid detection
  • Works in Object and Pose mode
