Blender add-on with several methods for assigning color ID materials to scene objects.

What Color Id Composer does

Color Id Composer brings together tools for giving objects ID colors, a common step in film and VFX compositing. It offers several approaches so you can choose how colors are distributed.

IDs can go to all or selected objects, limited to a set count, and can be filtered by type such as mesh, curve, font, surface or meta. Colors may be random in emissive, shaded or contrasting styles, or assigned by polygon count, parent and child relationship, proximity to an object, or camera field of view. Documentation is included.

Key features

  • Assign IDs to all or selected objects
  • Filter by object type
  • Random, poly count, hierarchy and proximity methods
  • Color IDs by camera FOV
