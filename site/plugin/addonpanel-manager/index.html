What Addonpanel Manager does

Addonpanel Manager tames crowded sidebars in Blender. You can set the order of panels using numbers, group them, and view several at the same time instead of scrolling through collapsed sections.

All panels load automatically, and the list of available add-ons can be refreshed on demand. Artists with many add-ons installed can build a layout matched to their workflow and reach tools faster.

Key features

  • Reorder panels with numbers
  • Group panels together
  • View multiple panels at once
  • Automatic loading and refresh
