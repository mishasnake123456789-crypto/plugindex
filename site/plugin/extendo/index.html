Extends footage edges and matches grain on the new area in After Effects and DaVinci Resolve.

What Extendo does

Extendo grows the edges of a clip in After Effects and DaVinci Resolve. When a frame needs to be wider, reframed or stabilized without leaving empty borders, it pushes the edge pixels outward to fill the gap.

Film grain can be added to the extended region so it blends with the original shot, and Knockout Mode outputs only the extension, which lets you add or match grain separately. An Erosion control supports masks and a Keep Original Alpha option. Rendering uses Mercury GPU in After Effects, though software mode is quicker at high erosion values, and OFX support brings Resolve.

Key features

  • Edge extension for footage
  • Film grain matched to the original
  • Knockout Mode isolates the extended area
  • Erosion control with mask and alpha options
  • Mercury GPU acceleration; OFX for Resolve
