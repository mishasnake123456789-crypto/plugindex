What Scanify - Scan An Entire Drive For Missing Blends does

Scanify helps find Blender files you have lost track of. Choose a drive or folder and it searches for all .blend files in a live scanning window with progress updates.

Instant search and filters narrow the list, with recency options for the last day, week, month or everything, and one click opens a file or shows it in its folder. Handy for artists with years of scattered projects. This is useful when you remember what a project looked like but not where on a large drive you saved it.

Key features

  • Scan a drive or folder for .blend files
  • Live progress and instant search
  • Recent-file filters: 24h, 7d, 30d, all
  • One-click open or reveal
