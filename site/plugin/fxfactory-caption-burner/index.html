What FxFactory Caption Burner does

FxFactory Caption Burner places captions directly into the video frame, useful for platforms that ignore caption metadata. It imports iTunes Timed Text, WebVTT, SubRip, SubViewer, Adobe Encore Script and Premiere Pro Markers in CSV form.

Multiple languages can live on one timeline instance, with a menu to choose which is burned in. Captions can also be exported back to many industry-standard formats along with the Caption Converter format, and the interface matches the Caption Converter app. Metal acceleration keeps render time low. The free FxFactory download is required. Editors delivering to social platforms will find it practical.

Key features

  • Burns captions into the frame
  • Imports iTT, VTT, SRT, SUB, Encore Script and Premiere CSV markers
  • Multiple languages on one timeline
  • Export back to standard caption formats
