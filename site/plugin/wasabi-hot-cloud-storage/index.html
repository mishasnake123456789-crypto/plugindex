What Wasabi Hot Cloud Storage does

Wasabi Hot Cloud Storage connects your Wasabi account straight to After Effects and Premiere Pro. Project files can be uploaded, downloaded and shared in the Wasabi cloud without leaving the application.

Uploads are secure and include project data from After Effects, Illustrator, Photoshop and Premiere Pro. The underlying object storage serves file storage, backup, archival and recovery, with no charges for egress or API calls. Teams that move large video projects between locations get a straightforward way to keep them in the cloud.

Key features

  • Direct Wasabi account connection
  • Upload, download and collaborate on projects
  • Secure upload from four Adobe apps
  • Storage for backup, archival and recovery
  • No egress or API call fees
