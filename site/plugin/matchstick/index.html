Generates bending frames and trusses in Blender by running a real structural analysis on a skeletal edge mesh.

What Matchstick does

Matchstick computes how a structure deflects rather than faking it. Feed it a skeletal mesh where each edge represents a log or beam, and it applies nodal displacements and rotations from a structural analysis.

The output is displaced geometry with a radius you specify. Selected Edit-mode elements can serve as inputs for loads and supports. Architects, engineers and artists wanting believable sagging beams or frames can use it. Because the bending is computed, the results respond to the loads and supports you define rather than a decorative curve.

Key features

  • Real structural analysis of the input mesh
  • Edge-mesh skeleton input
  • Nodal displacements and rotations applied
  • Output geometry with user-set radius
