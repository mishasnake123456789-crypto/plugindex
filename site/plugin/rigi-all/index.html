What Rigi-All does

Rigi-All, by hisanimations, accelerates building Rigify rigs in Blender from an existing model and armature. Rigify must be enabled.

Limb tools turn selected bone chains into Rigify arms, fingers, legs, spine, neck and head, shoulders, generic chains and extras. Auto-Complete Other Side builds both sides from one selection when bones are symmetry compatible, Fix Symmetry Name formats bone names, and a Bone Roll tool rotates bones by 90 degrees. Riggers with custom characters save significant time.

Key features

  • Limb generation for Rigify
  • Auto-Complete Other Side
  • Fix Symmetry Name tool
  • Bone Roll tool
