What Reparent Def Bones does

Reparent Def Bones repairs the deformation bone hierarchy in rigs produced by Rigify. It uses a source armature, usually the Rigify metarig or another one you pick, as the guide.

Rather than depending on fixed bone names, it works from naming characteristics, so it handles Rigify segmented limbs. It can also check the DEF hierarchy and strip constraints from the DEF bones. Riggers preparing characters for export to game engines will find it a quick cleanup.

Key features

  • Reparents DEF bones from a source armature
  • Name-characteristic matching for segmented limbs
  • Checks DEF bone hierarchy
  • Removes constraints from DEF bones
