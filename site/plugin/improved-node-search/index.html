What Improved Node Search does

Improved Node Search widens search in Blender's node editors, letting you locate nodes by their name, label or type and highlight the matches. It opens with Ctrl+F in the N-Panel Tool panel.

Text searches can use regular expressions, and geometry nodes support attribute search. Special searches find problem nodes such as unconnected nodes, absent image nodes and absent node groups. Artists maintaining large shader or geometry node trees will find cleanups easier.

Key features

  • Search by name, label or type
  • Regular expression option
  • Attribute search for geometry nodes
  • Finds disconnected and missing nodes
