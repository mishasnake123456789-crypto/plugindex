Blender add-on with box and lasso selection tools that make the object nearest the cursor active.

What Smart Box Select does

Smart Box Select, by R4V3N, adds two selection tools to Blender: Smart Box Select and Smart Lasso Select. Whichever object is closest to the mouse cursor is set as the active object, which is helpful when animating with a pen tablet.

Shift drag extends the selection and Ctrl drag subtracts. Since version 1.0.2, a drag that is too short counts as a click. It needs no special permissions and works with Blender 4.2 LTS and newer.

Key features

  • Box and lasso selection tools
  • Nearest object becomes active
  • Shift to add, Ctrl to subtract
  • Short drags treated as clicks
  • Blender 4.2 LTS and newer
