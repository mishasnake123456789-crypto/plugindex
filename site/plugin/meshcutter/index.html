What Meshcutter does

Meshcutter is a Blender plugin from CreateVisions for cutting meshes quickly. Select the geometry, choose a cutting mode and the tool separates it without a trip to Edit Mode.

Cap faces are generated automatically, cuts work on high-poly meshes, and curves can be drawn right in the viewport. Several cutter modes and enhanced snapping give flexibility. Capping and separation are handled for you, so splitting models into pieces is far faster than cutting and filling by hand.

Key features

  • No Edit Mode needed
  • Automatic cap faces
  • Draw cutting curves in the viewport
  • Works with high-poly meshes
