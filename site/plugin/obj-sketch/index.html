What Obj Sketch does

Obj Sketch lets you paint on an object's texture right in the 3ds Max viewport. The developer positions it as a way to roughly mark out areas on a mesh rather than a precise painting system.

The author warns that texture refresh in 3ds Max is painfully slow, so it is best for quick approximate guides. The current version is 2.3.5, it is free, and a developer page keeps current details. Modelers or texture artists who want to sketch seams, regions or notes onto a model without leaving Max can use it for simple marking.

Key features

  • Draw directly onto an object's texture in the viewport
  • Best for rough marking of mesh areas
  • Developer notes texture refresh can be slow
  • Version 2.3.5
