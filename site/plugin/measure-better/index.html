A Blender add-on with a tape side panel for real-time measurements, CSV export and 3D text annotations.

What Measure Better does

Measure Better displays live measurements of whatever you select in Blender. A custom tape panel shows readings for selected objects in Object Mode and for selected edges in Edit Mode, and it converts between metric and imperial units automatically.

A Set Size function applies exact X, Y or Z dimensions to objects or edges, with buttons for individual or multiple axes. Measurements can be exported to CSV and added as 3D text annotations in the scene. Product designers, architects and makers who need dimensional accuracy within their models will find it more convenient than the built-in measure tool.

Key features

  • Real-time measurements in a tape panel
  • Metric and imperial unit conversion
  • Set Size for exact X, Y or Z dimensions
  • CSV export
  • 3D text annotations in the scene
