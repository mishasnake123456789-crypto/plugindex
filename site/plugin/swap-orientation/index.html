Blender add-on that swaps render X and Y dimensions in one click or with a pie menu.

What Swap Orientation does

Swap Orientation flips a render between landscape and portrait by exchanging the X and Y dimensions, saving you from retyping both values.

The control sits where render dimensions are normally set, and a pie menu on Ctrl+Shift+Q performs the swap without opening the Output tab. Documentation is included and the license is GPL.

Key features

  • One-click X and Y swap
  • Control beside render dimensions
  • Ctrl+Shift+Q pie menu
  • GPL licensed
