What Eye Features Set does

Eye Features Set is a Blender Geometry Nodes add-on for creating eye-area assets. Eyes, eyelashes and eyebrows each come in stylized and realistic forms and stay editable through their own modifiers.

A single control object generates the surrounding geometry, and a sidebar panel plus interactive 3D gizmos let you shape the features in the viewport. The results have generated UV maps and clean quad topology that subdivides and deforms well. A custom shader node group with ready masks and a one-click eye material are included.

Key features

  • Eyes, lashes and brows in two styles
  • Non-destructive Geometry Nodes modifiers
  • Viewport gizmos and sidebar panel
  • Clean quad topology with UVs and eye material
