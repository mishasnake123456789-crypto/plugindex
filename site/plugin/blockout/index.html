Blender add-on for rapid blockouts using boolean operations, shape primitives and keypress-driven modeling tools.

What Blockout does

Blockout, from niewinny, helps you prototype and create base shapes quickly in Blender. Booleans, shape primitives and modeling tools are driven by one key and the left mouse button.

Once a tool is active, D opens its options while the left mouse button does the modeling. Tab starts ngon mode, where ngon points and green midpoints can be undone, and version 1.5.1 added a modal custom plane operator. It suits concept and hard surface artists who want to block forms quickly.

Key features

  • Boolean operations for creating geometry
  • Shape primitives for base forms
  • Press D to pick options, click to model
  • Ngon mode with undo support
  • Modal custom plane operator (1.5.1)
