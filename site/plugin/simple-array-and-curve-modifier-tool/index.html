What Simple Array And Curve Modifier Tool does

This Blender add-on combines two modifiers that are often used together. With one click it arranges an array of an object along a curve, and the objects keep their shape rather than bending with the curve.

Choose between Fit Curve and Fixed Count; only one applies at a time and each has a factor to adjust. Documentation is included. Handy for fences, chains, railings, cables and other repeated elements that follow a path.

Key features

  • Array and Curve modifiers in one click
  • Objects are not deformed along the curve
  • Fit Curve and Fixed Count modes
  • Adjustable factor for each mode
