What Tesselator - Quadrilateral Remeshing does

Tesselator rebuilds sculpted meshes into cleaner topology in Blender. The output can be pure quads, pure triangles or a quad-dominant mix, with strong control over how the edge flow runs.

A particle simulation does the work and can be steered with grease pencil strokes. Tesselator 1.28 for Blender 2.8 added masking density, sharp features and an improved triangle mode, and documentation covers the original 1.0. The add-on is released under the GPL. Sculptors and retopology artists get an organized starting mesh from dense models.

Key features

  • Pure quad, triangle or quad-dominant output
  • Control over topology flow
  • Grease pencil guided particles
  • Masking density and sharp features
