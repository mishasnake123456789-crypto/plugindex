Blender add-on that batch keyframes object visibility for render and viewport using two show and hide modes.

What Keyframe Visibility does

Keyframe Visibility animates when objects appear or disappear in Blender. It keys both rendered and viewport visibility for many objects at once from Object, Show/Hide.

Two modes are offered: "Show now, hide next" and "Hide before, show now". It adds a keyframe at the current frame and one adjacent frame so the object toggles cleanly. Useful for build-ups, reveals and sequenced appearances. Handling many objects in one step removes tedious manual keying of hide and render toggles, which is common in build-up animations and reveals.

Key features

  • Batch visibility keyframing
  • Render and viewport visibility
  • Two show and hide modes
  • Located under Object > Show/Hide
