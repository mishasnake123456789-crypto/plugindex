What Baga Pie does

Baga Pie is a large toolset for architectural and environment work in Blender. It combines scattering, parametric builders, an ivy generator, random arrays and Asset Browser integration in over fifty tools.

The scatter system spreads thousands of objects over any surface and offers painting, camera-based culling, proximity rules, layers, proxies and presets. Generators build stairs, spiral stairs, fences, handrails, tiles, pipes, cables, walls, floors, beams and windows, backed by more than a hundred procedural presets. Archviz artists can assemble detailed scenes quickly.

Key features

  • Scattering with paint, culling and proximity
  • Generators for stairs, fences, walls, windows
  • 100+ procedural presets
  • Ivy generator and random arrays
  • Asset Browser integration
