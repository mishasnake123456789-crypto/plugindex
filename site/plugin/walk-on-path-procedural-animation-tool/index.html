What Walk On Path - Procedural Animation Tool does

Nascore Entertainment's Walk On Path sends characters travelling along Bezier curves in Blender. Curves line up automatically, the legs are synchronized with the motion, and the result is baked into keyframes.

Walk, run and fly cycles are supported, with documentation included. Rather than keyframing foot placement for every stride, you draw the route and the tool handles the cycle. Useful for crowds, background characters and quick previs. Because the route is a curve, changing it later simply means editing the path and rebaking.

Key features

  • Animates characters along Bezier curves
  • Auto-aligns curves
  • Syncs leg motion
  • Bakes animation in Blender
  • Walk, run and fly cycles
