What Bulk Bake does

Bulk Bake simplifies PBR texture baking by wrapping the Cycles baking system in a single action. Instead of configuring and saving every map by hand, you choose an image size and run it.

It exports base color, roughness, metallic, normal and emission maps and saves the images automatically, skipping Blender's per-image save step. Baked images can also be wired into a fresh material on the model, and extra export choices are provided. Useful for game artists baking textures for many assets.

Key features

  • One-button PBR map baking
  • Emission, normal, metallic, roughness and base color maps
  • Automatic image saving
  • Optional new material from baked maps
