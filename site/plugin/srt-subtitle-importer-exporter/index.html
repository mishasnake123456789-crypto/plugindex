What SRT Subtitle Importer/Exporter does

SRT Subtitle Importer/Exporter, by PoYakong, links subtitle files with Blender's Video Sequence Editor. SRT files load as text strips, and existing text strips can be written back out as a standard SRT file, all from the VSE menu under SRT.

The scene's frame rate is read automatically so timing stays accurate. A text strip can be set as a template that every imported subtitle inherits, and titles can include an {index} counter. Export is a single click that gathers all text strips in the scene.

Key features

  • Import SRT files as VSE text strips
  • Single-click export of all text strips
  • Automatic frame rate detection
  • Template strip for styling imported subtitles
  • Index syntax for strip titles
