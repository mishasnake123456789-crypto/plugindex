What Animation Generator does

Animation Generator by kattour applies ready-made animations to objects in a Blender scene, avoiding the need to keyframe common motion by hand. It includes scale animation, a Back Position option for object motion, offset buttons for backward movement and a mirror feature to reverse motion.

A Basic version contains twenty-eight animations while the Pro version has one hundred twenty-six, and Pro buyers receive the Mirror & Offset add-on free. A button inside the add-on lets you view the animations online. Motion designers wanting quick, reusable moves for titles and objects will find it a handy library.

Key features

  • Scale animation and Back Position option
  • Mirror feature reverses motion
  • Offset buttons for backward movement
  • 28 animations in Basic, 126 in Pro
  • Browse animations online from the add-on
