What Easy Rounder does

Easy Rounder by Hassaan Ahmad rounds the corners of shape layers in After Effects relative to size, expressed in percentages rather than pixels. That keeps proportions right when shapes are resized.

Several shape layers can be processed in one go, even with multiple roundness properties selected. It remembers the last used value, has a compact one-line interface, and works with KBar, MoBar and other script runners, plus multilingual After Effects versions. Designers building buttons, cards and UI shapes will find it quick.

Key features

  • Rounds corners in percentages
  • Processes multiple shape layers
  • Remembers last roundness value
  • One-liner UI
  • KBar, MoBar and multilingual support
