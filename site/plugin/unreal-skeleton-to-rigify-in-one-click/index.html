What Unreal Skeleton To Rigify (In One Click) does

This add-on converts characters imported from Unreal into a Rigify rig without manual metarig setup. Select the Unreal rig, press Generate Rigify, and the metarig is created automatically, which spares riggers tedious bone matching.

The resulting Rigify rig includes IK and facial controls. The tool lives in the Rigify from Unreal tab of the N menu, supports Blender 3 and later, and works only on Windows. Animators who want to use Unreal mannequin-style characters with Blender's familiar Rigify controls will save a lot of time.

Key features

  • Generates Rigify from an imported Unreal model
  • Metarig created automatically
  • IK and face included
  • Runs from the Rigify from Unreal tab
  • Windows only, Blender 3+
