What Tile Renderer does

Tile Renderer renders a sequence of frames into one tiled bitmap in 3ds Max. The result is a sprite sheet style image, and the main use named by the author is producing fonts for games from a sequence of rendered images.

One caution applies: safe frame should be turned off, because rendering with it on will not give the correct size. It is a MaxScript made by Chuggnut. Game developers who prepare bitmap fonts, sprite sheets or flipbook textures from 3D renders can use it to assemble frames without a separate image tool.

Key features

  • Renders image sequences to a tiles bitmap
  • Mainly used for creating game fonts
  • MaxScript for 3ds Max
  • Requires safe frame to be off for correct size
