What xCloner does

xCloner from EFEKT multiplies layers in After Effects very quickly. It is intended for patterns, repeating arrays and mass duplication where building copies by hand would be impractical.

Five cloning modes are available, and recent versions also clone paths and objects. The plugin supports multi-frame rendering, works in 32-bit color, runs on macOS and Windows and needs After Effects CS6 or newer. Detailed documentation comes with it, which helps newcomers get set up with the different modes.

Key features

  • Five cloning modes
  • Path and object cloning
  • Multi-frame rendering support
  • 32-bit color support
  • Works on macOS and Windows
