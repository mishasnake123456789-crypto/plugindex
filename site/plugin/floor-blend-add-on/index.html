What Floor Blend Add-On does

Floor Blend lets an object merge naturally into the ground beneath it. One click mixes the object's materials with the floor, and you can flip between blended materials in real time to compare.

Height and edge noise settings shape how the transition looks, and the object's own normal map can be used in the mix. The helper torus and floor controls are stored in separate Floor_Blend and Floor_Control collections, keeping the scene tidy. It is useful for partially buried rocks, props and architecture in environment scenes.

Key features

  • One-click material-to-floor blending
  • Real-time switching of blended materials
  • Height and edge noise controls
  • Uses the object's own normal map
