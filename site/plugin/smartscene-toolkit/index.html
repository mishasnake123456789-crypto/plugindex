What SmartScene Toolkit does

SmartScene Toolkit is a collection of Blender operations by Marcus997 covering parenting, hierarchies and mirroring. Parent to Cursor places an empty where the 3D cursor sits and parents the selected hierarchy under it, which makes repositioning groups of objects easier.

Powerful Select picks an object or its parent and highlights it in the Outliner. Hierarchy Duplicate copies complex hierarchies while keeping the Outliner structure, and Move Hierarchy to New Collection relocates a selected hierarchy. You can also mirror-duplicate across a plane defined by the cursor.

Key features

  • Parent to Cursor with an empty at the 3D cursor
  • Powerful Select with Outliner highlighting
  • Hierarchy Duplicate preserves structure
  • Move Hierarchy to New Collection
  • Mirror-duplicate across a cursor plane
