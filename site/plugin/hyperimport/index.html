What HyperImport does

HyperImport is a script that speeds up everyday housekeeping in After Effects. It pulls assets in from cloud or local libraries, unpacks zip archives on the way, and can swap one asset for another across a project.

Beyond importing, it bundles a large toolkit: selection commands for layer types, project-panel helpers, trimming, renaming, label colors, matte and parenting tools, plus consolidation, font collection and file collection. Shortcut keys, custom functions and custom expressions can be tailored, so editors and animators can shape it around their own routine.

Key features

  • Cloud and local import with automatic zip unpacking
  • Asset replacement and auto-replacement
  • Selection commands by layer type, parent and children
  • Project cleanup: consolidate, reduce, collect fonts and files
  • Customisable shortcuts, functions and expressions
