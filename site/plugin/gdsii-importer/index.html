What GDSII Importer does

GDSII Importer, also called BlenderGDS, visualizes chip layouts in Blender. It reads GDSII semiconductor layout files and builds accurate 3D layer stacks with materials per layer.

PDK layer stack definitions are supported for IHP SG13G2 and CMOS5L, SkyWater SKY130, GlobalFoundries GF180MCU and SiEPIC EBeam, among others. Engineers and educators can produce clear renders and animations of integrated circuit structures.

Key features

  • Imports GDSII layout files
  • 3D layer stack visualization
  • PDK support for SkyWater, GlobalFoundries, IHP and more
  • Per-layer materials
