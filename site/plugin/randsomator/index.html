What Randsomator does

Built by BasedFX, Randsomator is a tool running inside After Effects that gives text the mismatched, clipped-from-magazines look of a ransom note. One click transforms a text layer, so there is no need to style each letter by hand.

The overall look can be adjusted at once, or the design of selected letters can be changed instantly. Controls include capitalization, font style options such as italic and bold, and rotation. It suits horror, true crime and punk-flavored titles where a chaotic, collage-like typographic feel is wanted.

Key features

  • One-click ransom note text generation
  • Adjust the whole look or selected letters
  • Capitalization control
  • Italic and bold font style options
  • Rotation control
