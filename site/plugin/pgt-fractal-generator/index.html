What Pgt Fractal Generator does

Pgt Fractal Generator is a Blender add-on by Jonas Mangelschots that builds fractals out of two chosen input meshes and some adjustable parameters. Before it generates, it estimates the vertex count, and a limiter acts as a safety measure to avoid overloading the scene.

Particle rendering gives more detailed fractals, with instance editing available afterward and a 4X zoom. Random scale and rotation add variety, and a chance-to-spread control shapes how the structure grows. It suits abstract art and sci-fi detailing.

Key features

  • Fractals from two input meshes
  • Vertex count estimate and limiter
  • Particle rendering for finer detail
  • Random scale and rotation
  • Chance-to-spread control
