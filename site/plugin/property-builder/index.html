Rigging helper that builds custom properties for controls, auto-flips Left/Right, and copies them between locations.

What Property Builder does

Property Builder helps riggers create and manage custom properties on rig controls. A single edit automatically generates the flipped Left/Right counterpart, naming the mirror in the opposite direction.

Properties of one location can be transferred to others. Three panels are registered: Property Builder, Transfer Properties and Options, and you can toggle which properties get generated. It cuts repetitive property setup on symmetrical rigs. You get auto-generated Left/Right property pairs, copy properties between locations and three dedicated panels, along with the rest of the feature set.

Key features

  • Auto-generated Left/Right property pairs
  • Copy properties between locations
  • Three dedicated panels
  • Toggle which properties to create
