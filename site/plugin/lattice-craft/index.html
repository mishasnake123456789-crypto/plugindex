In-viewport lattice editing for Blender with draggable handles, live resolution and local deformation.

What Lattice Craft does

Lattice Craft puts lattice editing directly in the 3D view. Colorful control handles set resolution by dragging, interpolation types can be switched, and editing starts with the Alt+C hotkey.

All controls appear on screen without property panels, hover tips highlight interactive elements, and local deformation lets you select vertices in edit mode and deform just those. It makes lattice work faster and more visual. Highlights include on-screen controls, no property panels, drag spheres to set resolution and interpolation switching.

Key features

  • On-screen controls, no property panels
  • Drag spheres to set resolution
  • Interpolation switching
  • Local deformation in edit mode
