What Super3D Import & Export .Stp does

Super3D Import & Export .stp handles STEP CAD data with the older three-letter extension. Dedicated menu entries appear in Blender's File menu.

Import via File > Import > Super3D: STP uploads the file to the cloud-based Super3D service, then downloads the result and merges it into the active scene. Export works similarly. Engineers and designers moving CAD models into Blender can avoid separate converters. Because conversion happens online, a connection is needed, and the benefit is not having to install separate converters.

Key features

  • Dedicated .stp import and export entries
  • Handles ISO 10303 STEP data
  • Cloud-based Super3D conversion
  • Result merged into the active scene
