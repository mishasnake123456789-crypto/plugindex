What Weatherfx Add-On does

WeatherFX is a Blender add-on from LIGHTARCHITECT for adding weather to a scene. After installing it, you select the particles, name the system and add it to the scene, which produces a rain, hail or snow particle system.

Because it is built on Blender's own particle systems, the results remain customizable after they are added, and movement can be baked from the standard particle panel. 3D weather assets are attached to the systems, and documentation is included. Environment and animation artists get convincing precipitation without building particle setups manually.

Key features

  • Rain, hail and snow particle systems
  • Three-step add workflow
  • Built on Blender's particle systems
  • Bake movement from the particle panel
  • 3D weather assets included
