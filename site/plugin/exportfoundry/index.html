What ExportFoundry does

ExportFoundry handles repeated exporting inside Premiere Pro. Sequences, markers, selections, clips and custom ranges go into a queue, and several output versions can be produced from one setup.

It includes a preset and profile selector with custom .epr imports and reusable profiles, duplicate handling, missing-preset recovery, and a button that opens each finished file's folder. It supports Premiere Pro 2022 through 2026. It is useful for delivering several formats or cuts from the same project without repeated manual setup.

Key features

  • Queue sequences, markers, clips and ranges
  • Multiple output versions from one setup
  • Preset selector with .epr import
  • Duplicate handling and missing-preset recovery
  • Open output folder from finished items
