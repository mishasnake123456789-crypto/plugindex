What Better Pie Menus does

Better Pie Menus is a Blender add-on from Pitiwazou that adds pies, smart menus and popups whose contents change with the object type and mode. The goal is to keep frequent commands within a quick gesture.

Pie menus can be customized for meshes, curves, Grease Pencil, editors and workspaces, and each one can be disabled in preferences. The Modifier and Material popups include presets and cover curves and Grease Pencil too. A pie menu creation tool and a PIE Editor help change the view and switch editors, and smart menus adapt to the selected component during mesh editing.

Key features

  • Menus that adapt to object type and mode
  • Customizable pies for mesh, curves, Grease Pencil and editors
  • Modifier and Material popups with presets
  • Pie menu creation tool and PIE Editor
  • Smart mesh-editing menus
