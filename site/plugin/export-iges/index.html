Blender add-on that converts subdivision limit surfaces into IGES files so models can move into CAD software.

What Export Iges does

Digital Sculptors' Export Iges serves people who model in Blender but finish in CAD. It evaluates the subdivision limit surface of a mesh and writes it as an IGES file CAD packages understand.

Choose a subdivision level between 1 and 4 (3 by default). Batch Mode writes each object separately as name_objectname.igs, and Keep Corners decides if boundary corners stay crisp or soften. You can limit export to the selection, set up and forward axes, and apply modifiers first. Builds exist for several operating systems.

Key features

  • Exports subdivision limit surfaces as IGES
  • Subdivision level 1 to 4
  • Batch Mode writes one file per object
  • Keep Corners option for boundary edges
  • Selected-only export with axis and modifier options
