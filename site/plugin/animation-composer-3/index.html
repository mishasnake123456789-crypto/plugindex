What Animation Composer 3 does

Animation Composer 3 is a preset browser from Mister Horse for After Effects. The free version includes over a hundred presets, precomps and sounds, each with a video preview, so you can judge an item before using it.

It works non-destructively: click to add, click again to remove. The grid layout loads previews faster, a separate Edit tab handles customization, and you can add your own items to a user library. Many expansion packs are sold separately. It suits motion artists and editors wanting quick starting points.

Key features

  • 100+ free presets, precomps and sounds
  • Video preview for every item
  • Non-destructive click to add or remove
  • User library for your own items
  • Expansion packs available
