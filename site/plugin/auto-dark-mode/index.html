What Auto Dark Mode does

Auto Dark Mode is a Blender add-on by dprice that keeps Blender's interface matched to your operating system's appearance. You choose one theme preset for light mode and another for dark mode, and Blender follows when the system changes.

It checks for a change every ten seconds using a timer, offers a streamlined interface for picking themes, and can apply themes installed via Blender's Extensions. Permission to read installed themes is requested so they can be applied.

Key features

  • Separate theme presets for light and dark mode
  • Follows OS appearance changes
  • Polls every ten seconds with a timer
  • Works with themes installed via Extensions
  • Simple interface for choosing themes
