What Space colonization tree generator does

Space colonization tree generator is a Blender add-on by LS that creates tree skeletons using the space colonization method. You select an input mesh as the volume into which the tree grows.

It is based on the 2007 algorithm by Runions, Lane and Prusinkiewicz. The package is only 6.6 KB, installs by drag and drop or from disk, requires no special permissions and supports Blender 4.2 LTS and newer. Artists and researchers who want procedural branching structures can start from the generated skeleton.

Key features

  • Generates tree skeletons by space colonization
  • Grows inside a user-selected mesh
  • Based on Runions, Lane and Prusinkiewicz (2007)
  • Supports Blender 4.2 LTS and newer
