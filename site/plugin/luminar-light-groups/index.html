Blender add-on that auto-creates and assigns Cycles Light Groups from your light names, keeping them in sync.

What Luminar Light Groups does

Setting up light groups in Cycles by hand is tedious. ArtTizan's Luminar Light Groups builds them for you, using each light's name as the base for creating and assigning groups.

The index number and separator symbol can follow your naming scheme, and everything updates live when lights are added, deleted or renamed. All Cycles lights are covered, including mesh lights and the world light. Start and stop buttons turn automatic management on and off. Compositors who relight in post will keep passes tidy.

Key features

  • Automatic light group creation from names
  • Custom index number and separator
  • Real-time updates when lights change
  • Mesh and world lights supported
  • Start and stop controls
