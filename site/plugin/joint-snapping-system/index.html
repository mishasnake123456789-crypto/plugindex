What Joint Snapping System does

Joint Snapping System helps artists assemble modular scenes, kitbash and graybox levels from snapped blocks and prefabs. It runs across Blender 3.3 through 4.5.1.

Snapping goes to helper points, with Alt for bounding-box corners and edge centers, Shift for doubled grid density and Ctrl for camera-relative quarter-turn snapping. Prefab Edit Mode edits, tests and saves prefabs from the viewport, custom snap points persist, and file-backed lists keep prefabs and custom items separate. Thumbnails bake incrementally and are cached.

Key features

  • Snap to helper points with modifier-key modes
  • Prefab Edit Mode in the viewport
  • Persistent custom snap points and file-backed lists
  • Cached auto-baked thumbnails
