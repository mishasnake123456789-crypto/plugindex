Captures a Blender mesh's geometry, modifier stack and transforms as restorable checkpoints.

What Mesh Snapshots does

Mesh Snapshots saves the full state of a mesh in a single click, including geometry, modifier stack and object transforms. You can return to any saved checkpoint later, which makes it easier to experiment without fear of losing a good version.

Each object can hold unlimited snapshots, and ones you no longer need can be deleted. Restoring brings back the saved geometry, transforms and modifier settings. Modelers testing alternatives or comparing design directions will find it a lightweight alternative to duplicating objects.

Key features

  • One-click capture of geometry, modifiers and transforms
  • One-click restore of a saved state
  • Unlimited snapshots per object
  • Delete snapshots you no longer need
