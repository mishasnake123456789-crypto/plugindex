What OWM Import does

OWM Import is a Blender add-on that imports files made by the Overwatch extraction tools (DataTool) into a scene, handling owmdl, owentity, owanimclip and owmap files and offering wizards for skins and maps.

Basic additive animation is supported through an Import as additive choice when importing animations. The extension installs by dragging it into Blender or from disk, and it requests file permission to import data from disk. It is meant for fan artists and animators working with extracted game content.

Key features

  • Imports owmdl, owentity, owanimclip and owmap files
  • Import wizards for skins and maps
  • Basic additive animation option
  • Install by drag-and-drop or from disk
  • Requests file permission for imports
