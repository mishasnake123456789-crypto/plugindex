3ds Max script that exports true length, width and thickness of selected panels to Excel as a furniture cutting list.

What FurniList 2 free does

FurniList 2 free extracts manufacturing dimensions from geometry in 3ds Max and prepares them for Excel. Using vertex tensor logic, it reads local coordinates so true length, width and thickness are reported no matter how a part is rotated.

Each object can have its own line, or parts of equal size can be merged into a QTY column using Summation of Identical. Results carry QTY, L, W and T headers so they paste straight into cutting software, a pop-up confirms the clipboard copy, and progress can be followed in the MaxScript Listener. A Remove decimals option rounds to whole numbers. Select panels, click GENERATE LIST, and you have a cutting list for wood, MDF or plexiglass.

Key features

  • True dimensions regardless of object rotation
  • Individual list or grouped quantities
  • Excel-ready QTY, L, W and T columns
  • Clipboard confirmation pop-up
  • Remove decimals option for manufacturing
