What Abd0W0 Stairs Generator does

Abd0W0 Stairs Generator creates stairs by extruding, with a small materials library included. Handrails are adjustable and can use a custom profile, and stairs can be set to turn 90 degrees automatically.

A procedural UV map is generated, and version 2 improved the interface. It is useful for architecture and game environments needing quick staircases. Day to day, that covers extrusion-based stair generation, adjustable handrails and custom profiles and automatic 90-degree stairs.

Key features

  • Extrusion-based stair generation
  • Adjustable handrails and custom profiles
  • Automatic 90-degree stairs
  • Procedural UVs and materials
