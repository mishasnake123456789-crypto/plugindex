What Specio Free does

Specio Free is a set of Blender tools for turning flat vector artwork into 3D. It starts with SVG import, applying corrections over what Blender's bundled importer does and preparing each curve for further work.

Every curve gets its origin set to its own geometry, geometry is reduced where suitable, and objects are grouped into the layers they belonged to in the source file. Objects can also be stacked in depth. Logo designers and motion artists will find it handy for extruding illustrations quickly.

Key features

  • SVG import with corrections to the stock importer
  • Origin placed on each curve's own geometry
  • Geometry reduction where appropriate
  • Objects grouped by original SVG layers
