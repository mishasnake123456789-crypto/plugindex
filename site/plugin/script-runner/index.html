Blender add-on that runs several Python scripts from saved paths with a single button, no text editor loading needed.

What Script Runner does

Script Runner is a Blender add-on for people who keep running external Python scripts. Scripts execute from wherever they live on your computer, with no need to load them into Blender's text editor first and no changes to Blender file paths.

Paths to your favorite scripts are saved and survive new Blender files and new Blender versions. A whole directory of scripts can be loaded into the panel at once, and multiple scripts run with a single press. That fits workflows like SynthEyes-generated exports, or editing scripts in an outside editor such as Notepad++ and testing them directly in Blender. Documentation is included.

Key features

  • Run multiple Python scripts with one button
  • No text editor loading or file path changes
  • Stored script paths persist across files and Blender versions
  • Load an entire directory of scripts
  • Documentation included
