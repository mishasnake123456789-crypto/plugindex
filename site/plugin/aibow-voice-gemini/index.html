What AiBow Voice Gemini does

AiBow Voice Gemini turns written scripts into narration inside Premiere Pro. Type text into blocks, pick a Gemini 2.5 Flash or Pro model and a voice, then click Add to Timeline to place the audio instantly.

Five voices are included: Puck, Charon, Kore, Fenrir and Aoede. Work can be saved as a JSON file and loaded later. No browser tools are needed, and it runs on Windows and macOS with Premiere Pro 2020 through 2026.

Key features

  • Script blocks with Gemini 2.5 model choice
  • Add to Timeline in one click
  • Five voices including Puck and Kore
  • Save and load work as JSON
  • Windows and macOS, Premiere Pro 2020 to 2026
