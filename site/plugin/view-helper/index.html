What View Helper does

View Helper is a Blender add-on for technical visualization. It stores viewport perspectives so you can restore or edit them later, and adds dedicated controls for ISO views and live sync options.

It targets artists, engineers and designers who need consistent, repeatable views of a model. The add-on is compatible with Blender 4.2 through 5.1 and is distributed as a Blender extension-compatible add-on under the GPL license, with documentation included.

Key features

  • Save, restore and edit viewport perspectives
  • ISO view controls
  • Live sync options
  • Blender 4.2 through 5.1
