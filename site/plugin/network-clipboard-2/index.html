What Network Clipboard 2 does

Network Clipboard 2, by Matt Tillman, lets artists move work between applications without saving intermediate projects. It lets you copy comps, layers, nodes and scenes on one machine and paste them on another over a network, linking After Effects with Cinema 4D and Houdini.

Items can be pasted into a project or directly into the active comp. A copy history is kept for as long as wanted and any item can be pasted back. The clipboard directory can be set through an environment variable, usernames can be overridden, FBX support is added for After Effects, and floating licenses are supported. Teams sharing assets across machines benefit most.

Key features

  • Copy and paste across After Effects, Cinema 4D and Houdini
  • FBX support for After Effects
  • Paste into project or active comp
  • Unlimited copy history
  • Floating license support
