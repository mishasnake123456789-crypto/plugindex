What Facial Tools does

Facial Tools from Stellart helps put expressive faces on characters. Its core feature, SNAPPY FACIAL, detects the face automatically in one click so the rig can be set up without laborious placement.

Binding and animation tools are included along with 60 facial animation presets that can be combined into more complex performances. Results export as .fbx or .gltf for engines such as Unity, Unreal Engine and Godot. Game and animation artists who need quick facial setups will benefit.

Key features

  • One-click automatic face detection
  • Binding and animation tools
  • 60 facial animation presets
  • FBX and glTF export for game engines
