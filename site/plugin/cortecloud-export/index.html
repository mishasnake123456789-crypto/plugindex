What CorteCloud Export does

CorteCloud Export is a Blender add-on by Filipe-Rocha-Lopes for furniture makers who model MDF pieces. It exports wood cut lists in the CSV cut-plan format used by CorteCloud, and also prepares the scene for modeling.

Environment Setup configures the scene, Base Material Creation generates common MDF materials automatically, and Example Piece Creation makes a suspended drawer niche useful for prototyping. Since version 1.0.5 the CSV file gets a default name and the .csv extension is added automatically on saving. DIY enthusiasts and makers can go from model to cutting plan.

Key features

  • CSV export compatible with CorteCloud cut plans
  • Environment setup for modeling
  • Automatic base MDF materials
  • Example drawer niche piece
  • Default CSV name with .csv extension
