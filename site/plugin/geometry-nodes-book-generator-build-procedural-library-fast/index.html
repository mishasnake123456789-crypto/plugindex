What Geometry Nodes Book Generator - Build Procedural Library Fast does

Geometry Nodes Book Generator makes a 3D book in Blender with one click, so you can fill shelves and libraries without modeling each volume. No modeling background is required.

Width, height, thickness, cover thickness and page count (10 to 500) update live in the viewport, and the setup stays non-destructive so you can change it anytime. Five presets cover pocket books, paperbacks, hardcovers, textbooks and coffee table books, and custom sizes are possible. Covers can be animated to open and close.

Key features

  • One-click procedural book via Geometry Nodes
  • Live control of size and page count
  • Non-destructive modifier workflow
  • Five book presets plus custom sizes
  • Animated cover opening and closing
