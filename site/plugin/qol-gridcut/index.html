A Blender add-on that slices the active mesh into an even grid of cuts with one click from the right-click menu.

What Qol Gridcut does

Qol Gridcut subdivides the active object with evenly spaced cuts in Blender. Cuts can run along any or all axes regardless of topology, producing a uniform tessellation without manual loop cuts.

The command is added to the standard right-click menu, and refinement options remain available after the cut is applied. It ships in the Blender 4.2 extension format as an add-on, with documentation. Modelers preparing meshes for deformation, displacement, sculpting or simulation, where even density matters, will find it quick and predictable.

Key features

  • One-click slicing of the active object
  • Even cuts on any or all axes
  • Added to the right-click menu
  • Refinement options after the cut
  • Blender 4.2 extension format
