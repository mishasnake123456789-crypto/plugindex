What Unity Rig does

Unity Rig prepares Blender characters for Unity. It can build rigs that match Unity's Humanoid requirements and can convert existing Rigify rigs into a compatible form.

Character artists who animate in Blender but ship in Unity avoid manual bone renaming and setup that often causes import problems. The result is a rig that retargets cleanly and works with Unity's animation system.

Key features

  • Unity Humanoid-compatible rigs
  • Rigify rig conversion
  • Smoother export to Unity
