What Petik - Retopology Patch Maker does

Petik helps build low-poly quad meshes in Blender. Click a high-poly surface to define patches of up to six sides, with a flexible vertex count per side.

Multi patch support controls several patches at once via control lines, and scrolling sets the number of vertices on a side. Retopologists work from sculpts to clean topology with direct control. Defining patches directly over the surface lets artists control edge flow exactly where it matters, such as around eyes, joints and mechanical features.

Key features

  • Patches with up to six sides
  • Variable vertices per side
  • Multi patch support
  • Control lines
