What Still Exporter does

Still Exporter, from mamoworld tools, lets you place markers on the frames you want and export them as images in one go. Output formats are JPG, PNG, TIFF and DPX.

File names are assembled from tokens: marker number with leading-zero padding, marker name, comment, project name and sequence name, and timecode can be added. Pick a destination folder and export. A good fit for stills, thumbnails and review frames. It is aimed at editors who regularly pull frames for review, thumbnails or stills archives.

Key features

  • Frames exported from markers
  • JPG, PNG, TIFF or DPX output
  • Tokens for marker number, name, comment, project and sequence
  • Timecode in file names
  • Choose destination folder
