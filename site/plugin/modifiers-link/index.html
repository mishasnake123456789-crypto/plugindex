Blender add-on that links modifiers across objects and keeps them synced live.

What Modifiers Link does

Modifiers Link adds a panel to the Modifiers tab so several objects can share modifier settings. Change a value on one object and the linked ones update instantly, which beats copying and pasting.

You can link or unlink all modifiers with one click, or work on single modifiers. New objects can be added to an existing group, and dead links are cleaned up automatically when an object or modifier is deleted. It works with Blender 4.5 to 5.0 and is GPL licensed.

Key features

  • Link or unlink all or single modifiers
  • Live sync across linked objects
  • Additive linking to existing groups
  • Automatic cleanup of dead links
