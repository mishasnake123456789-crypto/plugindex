What Merge / Relink does

Merge / Relink is a pixamoon script that deals with broken asset paths when you merge models into a 3ds Max scene. It runs in the background during the Merge process, looking for the merged file's assets in nearby folders or in folders you list.

Auto-Relink can look in the same location, in folders one or more levels down plus their subfolders, in a path that includes a maxFilename subfolder, or in folders you name. Paths are read from top to bottom until every asset is found. The syntax uses .\ for the same folder, ..\ for stepping down, and $scene for the merged filename. Since v1.37 the max file info beneath the thumbnail also shows asset count and file versions.

Key features

  • Background relinking during Merge
  • Searches nearby folders or folders you specify
  • Flexible path syntax with .\, ..\ and $scene
  • Reads path list top to bottom until all assets are found
  • Max file info with asset count and versions
