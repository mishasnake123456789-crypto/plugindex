A Blender add-on that scans a folder for textures by keyword and wires them into a Principled BSDF in one click.

What Easy Pbr Hook does

Easy PBR Hook builds PBR materials in Blender without manually connecting every image. Point it at a folder and it finds textures using keywords you define, then attaches them to the Principled BSDF shader.

The naming convention table is fully editable, per project or globally, with export, import and reset. Searches can be narrowed with keywords and exclusions using a minus sign, including multiple exclusions. Node setup is automatic, such as routing a smoothness map through an Invert node into roughness. Texture artists importing downloaded material packs will save a lot of repetitive node work.

Key features

  • Finds textures in a folder by keywords
  • Editable naming convention table
  • Keyword narrowing with minus-sign exclusions
  • Automatic node setup such as inverted smoothness
