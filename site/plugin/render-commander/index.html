Blender add-on that exports standalone render scripts with embedded settings for parallel rendering on multiple devices.

What Render Commander does

Render Commander, by n4dirp, prepares scripts that render outside the main Blender session. The settings are fully embedded, so jobs can run on several machines at once, with detailed control for Cycles and EEVEE.

Launch modes handle single stills, sequences, and hand-picked frame lists or ranges like 1, 5-10, 25. You can inspect scene and render data of other .blend files without opening them. Small studios can split renders across computers easily.

Key features

  • Standalone render scripts with embedded settings
  • Parallel rendering across devices
  • Still, sequence and custom frame list modes
  • Inspect external .blend files
  • Cycles and EEVEE configuration
