What Normal Brush does

Normal Brush is a Blender plugin from kitfox.com that adds a brush control for mesh normals. Stroking over the model adjusts normals directly, which helps shading tweaks that would otherwise take manual editing.

It supports Blender 2.8 through 4.0, is released under the GPL license, and includes documentation and a demo video. It can also be found on the developer's GitHub. Painting normals this way offers an intuitive method for correcting shading problems or achieving stylized shading on models.

Key features

  • Adjust normals with a brush
  • Blender 2.8 through 4.0
  • GPL license
  • Documentation and demo video
