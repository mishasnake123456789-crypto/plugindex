Shows execution time, time dependency and geometry statistics for a selected node in Blender's Geometry and Shader node trees.

What Node Stats does

Node Stats is a debugging aid for node-based setups. Select a node and the add-on reports how long it took to evaluate, in milliseconds, so slow parts of a network can be found.

It also highlights whether a node is time-sensitive, for example when it uses a frame or time input, and reports statistics about the geometry it outputs. Procedural artists working with heavy Geometry Nodes trees can profile and optimize with it.

Key features

  • Node execution time in milliseconds
  • Time dependency detection
  • Geometry output statistics
  • Works with Geometry and Shader nodes
  • Helps find performance bottlenecks
