A Blender toolset for dynamic parenting, rigid body helpers, compositor output and caching in the properties panel.

What Styriam Toolty does

Styriam Toolty groups productivity helpers for animation, simulation and lighting inside Blender's viewport properties panel. A dynamic parenting picker generates all constraints and keyframes from two selected objects in one click, working with meshes, cameras, lights, empties and bones.

Rigid Body Helpers add simulation to selected shards and keyframe their kinematic property or visibility. Output Helpers manage the compositor File Output and generate layer names, and caching tools are included. Animators handing props between characters and artists running destruction sims will find it takes out a number of repetitive setup steps.

Key features

  • Dynamic parenting with generated constraints and keyframes
  • Rigid Body Helpers for shards
  • Compositor File Output management
  • Caching tools
