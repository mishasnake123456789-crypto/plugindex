What Write-On Animated Typefaces does

Write-On Animated Typefaces gives designers handwritten-style lettering that draws itself on, without tracing letters with the pen tool and keyframing every stroke. The set contains ten styles, each with 84 characters.

Every character offers three layers of customization, so the look can be adjusted to suit a project. Version 2.1 added Universal Expressions, and the typefaces are compatible with Font Manager. Titles, quotes and decorative text sequences become quick to produce.

Key features

  • Ten animated type styles
  • 84 characters per font
  • Three customization layers per character
  • Universal Expressions added in version 2.1
  • Font Manager compatible
