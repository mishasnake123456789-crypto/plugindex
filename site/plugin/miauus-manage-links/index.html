What miauu's Manage Links does

Manage Links by miauu connects BIM and CAD programs such as SketchUp, Rhino and AutoCAD with 3ds Max. It imports models, cleans and repairs the geometry, and divides it so there is one object per material.

The resulting objects are saved as an FBX file that can be linked manually or automatically, using the default 3ds Max file linking. SKP and OBJ file types can be imported. After a link is updated, ForestPack and Multiscatter objects are refreshed too. Architectural visualization artists who regularly bring in design models and revise them will find it keeps scenes in sync with fewer repetitive cleanup steps.

Key features

  • Links SketchUp, Rhino, AutoCAD and other BIM or CAD programs
  • Cleans and fixes imported geometry
  • Splits geometry into one object per material
  • Saves results as FBX using default 3ds Max linking
  • Updates ForestPack and Multiscatter after link updates
