What Easy Text Animation does

Easy Text Animation, from sum studio, builds animated titles in Blender with geometry nodes. Rather than keyframing letters by hand, you control the translation, scale and rotation of every character individually.

The addon ships with documentation and a demo video. Motion designers can use it for kinetic typography, reveal effects and playful titles, and the node-based design keeps the effect adjustable as the text changes.

Key features

  • Geometry nodes text animation
  • Per-character translation, scale and rotation
  • Documentation included
  • Demo video available
