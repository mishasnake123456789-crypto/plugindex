What Alva Sequencer does

Alva Sequencer, from Alva Theaters, repurposes Blender as a lighting cue sequencer. It targets designers using professional consoles, particularly the ETC Eos family.

Sequencing happens against timecode with Blender's video editing and animation tools, and the add-on communicates with Eos consoles using OSC. It is built specifically for timecode work and passes the sequenced data on to the console. Theater and event lighting programmers can use a familiar timeline for show programming.

Key features

  • Sequences lighting against timecode
  • Talks to ETC Eos consoles via OSC
  • Uses Blender's video editing and animation tools
  • Built for timecode-driven shows
