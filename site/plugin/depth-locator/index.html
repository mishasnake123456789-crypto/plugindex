Creates empties on the ray between a Blender camera and a target, with a slider to set depth via drivers.

What Depth Locator does

Depth Locator creates depth-controlled empties in Blender. It draws a ray from the camera to any target object and places an empty on it, and a slider then moves that empty nearer or farther along the ray.

The setup uses pure drivers with no constraints, and rotation stays clean at 0,0,0. Depth values can be animated across keyframes. It is useful for compositing placement, VFX layering and camera-based element positioning where depth must be controlled precisely.

Key features

  • Empties placed on the camera-to-object ray
  • Real-time depth slider
  • Pure drivers, no constraints
  • Depth values animatable with keyframes
