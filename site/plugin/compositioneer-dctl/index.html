What Compositioneer DCTL does

Compositioneer DCTL is a set of cinematic framing aids for DaVinci Resolve Studio. It draws composition guides over the picture so that framing decisions can be checked against classic proportions, and the overlays can be exported with transparency for use elsewhere in a production.

Guides include Golden, Logarithmic and Archimedean spirals, six adjustable circles, and Phi and Bisector grids, each with editable size, position and color. A secondary frame border shows a second aspect ratio at once, and rulers can start from either the timeline frame or the main frame. A Transparent checkbox prepares the overlay for export. Reframing and delivery to multiple formats become easier to judge.

Key features

  • Golden, Logarithmic and Archimedean spiral guides
  • Six circles plus Phi and Bisector grids
  • Secondary frame border for a second aspect ratio
  • Rulers anchored to timeline or main frame
  • Transparent overlay export
