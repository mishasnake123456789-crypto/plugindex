What Tilles Motion Ultra Box 3D does

Ultra Box 3D builds a box out of shape layers and expressions, so it adds no external assets to your project beyond one uniquely named composition. One click creates the rig, and no Cinema 4D renderer is required.

You set width, height and depth in pixels, taper the top or bottom (100% forms a pyramid), and add a chamfer that creates four extra edge faces. Wireframe mode shows strokes only, while Textures mode makes compositions parented to faces that don't distort when the box is resized. The gear button saves defaults for box size, texture size and camera creation.

Key features

  • One-click 3D box rig from shapes and expressions
  • Width, height and depth controls
  • Taper top and bottom, plus chamfer
  • Wireframe mode with adjustable stroke
  • Textures mode that resists distortion
