What Luminar Lights does

Luminar Lights replaces guesswork in Blender lighting with real-world photometric units. Artists can build controlled, realistic setups based on actual fixtures, measurements and color temperatures, which is valuable for architectural and product work.

Lights can use lumens, candelas and lux, and a global energy calculation keeps output consistent when switching units. A luminous efficacy parameter has ready presets and a custom option, Kelvin color temperature is included, and color and size normalization help with area lights. Lighting designers and visualization artists who match renders to physical specifications will find it dependable.

Key features

  • Lumens, candelas and lux units
  • Consistent output when switching units
  • Luminous efficacy presets
  • Kelvin color temperature
  • Color and size normalization for area lights
