What Node Editor Pro does

Node Editor Pro tidies messy node graphs in Blender, particularly in the Shader Editor. It aligns the whole tree or just the selected nodes into a neat grid and deletes orphan nodes that connect to nothing.

Live snapping gives more exact placement, a notes node keeps explanations in the tree, and an automatic statistics tool shows the total node count, connections, orphans and maximum depth. Built-in shortcuts let you organize, snap and clean with a single keystroke.

Key features

  • Grid alignment of whole tree or selection
  • Removes orphan nodes
  • Live snapping
  • Notes node
  • Statistics: node count, connections, depth
