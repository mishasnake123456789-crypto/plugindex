Script that adds, converts, mattes, rounds, inverts and precomps corner pins across many After Effects effects.

What CornerPinner does

Daniel Fredley's CornerPinner is a script built for After Effects that streamlines work with corner pin effects. Tracking and screen replacement jobs often involve moving pin data between different plugins, and this tool automates that conversion.

It can add a simple corner pin, translate values from one corner pin type to another, and build basic mattes from existing pins, with rounding for edges and corners. Corner values can be rotated, and pins can be inverted, for example to stabilize a mocha pin in a precomp. Supported effects include Corner Pin, RG Corner Pin, CC Power Pin, BCC Corner Pin, S_WarpCornerPin, Bezier Warp, Card Dance, Card Wipe and RE:Map Planar.

Key features

  • Add simple corner pins
  • Convert between corner pin effect types
  • Create mattes from pins with rounding
  • Rotate and invert corner values
  • Works with many third-party pin effects
