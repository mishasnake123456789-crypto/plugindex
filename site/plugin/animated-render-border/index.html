What Animated Render Border does

Animated Render Border is a Blender add-on by Ray Mairlot that makes the render region adaptive. During an animation it updates every frame so the border stays around a chosen object or collection, which can cut render times when only part of the frame matters.

A keyframe mode lets you place and keyframe the region manually, and a margin property adds padding around tracked items. Two tracking modes are offered: a precise inner-point method and a faster bounding box method. It handles armatures, bones, meshes, text, curves, lattices, surfaces and metaballs, including modifier-generated geometry.

Key features

  • Render region follows selected objects each frame
  • Keyframe mode for manual border placement
  • Adjustable margin around tracked objects
  • Precise or faster bounding box tracking
  • Supports many object types and modifier geometry
