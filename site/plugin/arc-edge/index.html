What Arc Edge does

Arc Edge, by dartmeadow, is a Blender add-on for generating and measuring finite arcs, aimed at scientific analysis. These are arcs that do not fit neatly into circles or ellipses.

It reports how far an arc's starting point lies from its endpoint, a matching circle at the point where the arc first curves back, and the largest circle whose curvature still touches within the arc. It can also measure Blender's built-in geometry objects when selected. The data can feed other setups for real-world use or simulation feedback, and an example blend file is provided.

Key features

  • Creates and measures finite arcs
  • Start-to-end arc distance
  • 1/8th circle arc match and max circle diameter
  • Measures default Blender geometry
  • Example blend file included
