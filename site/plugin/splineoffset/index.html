What SplineOffset does

SplineOffset by ITOOSOFT is a modifier for procedurally cloning and offsetting any spline in 3ds Max. Each clone steps through incremental offset, translation and rotation, and all settings stay editable at any time because nothing is baked.

Splines that overlap after an offset can be healed automatically, and Material IDs can be set, incremented or patterned across clones. Five end types and three bevel types are offered, along with two algorithms, a 2D mode and a 3D mode. It suits parametric patterns, railings, ornaments and other repeating spline designs.

Key features

  • Procedural cloning and offsetting of splines
  • Incremental translation, rotation and offset
  • Automatic healing of overlapping splines
  • Material ID patterns on clones
  • Five end types, three bevel types, 2D and 3D modes
