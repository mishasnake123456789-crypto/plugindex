What Comp Replicator: CSV Driven Batch Comps does

Comp Replicator turns a single template composition into as many customized versions as your spreadsheet has rows. It reads .csv, .tsv and .txt files and fills in text or swaps media in each copy, which is ideal for personalized or localized deliverables.

Source Swap finds replacements by project name or file path, and the tool can reach nested layers and duplicate whole nested comp hierarchies. Tagging layers in the template speeds up targeting. Finished comps can go to the render queue or Media Encoder, and presets for template names, CSV paths and naming let everything run in one click.

Key features

  • Reads .csv, .tsv and .txt data
  • Source Swap for text and media by name or path
  • Replicates nested comp hierarchies
  • Layer tagging in the template comp
  • Sends to render queue or Media Encoder
