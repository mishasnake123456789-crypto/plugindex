What Swiftopen does

Swiftopen puts your frequently used files and apps a click away inside Blender. Add a path once and it is remembered between sessions, and paths can be changed or deleted whenever needed.

Each path has an Open at startup toggle, and Check/Uncheck All sets every path together. Launch buttons start the items without leaving the program. Artists who rely on reference images, notes or companion software alongside Blender will like not hunting through folders.

Key features

  • One-button opening of programs and files
  • Paths remembered between sessions
  • Open at startup toggle per path
  • Check/Uncheck All
