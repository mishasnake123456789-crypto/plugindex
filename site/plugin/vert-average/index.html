What Vert Average does

Vert Average is a modeling script for 3ds Max by Chuggnut that behaves like the collapse vertex operation but skips the weld. Where a normal collapse joins vertices into one, this script moves them to a shared position while leaving the geometry intact.

The script is at version 2.3.5 and can be found on chuggnut.com and ScriptSpot. Modelers who need vertices lined up at one point without changing topology, for instance before welding with a specific threshold later, can use it for tidy cleanup.
