What ShivaTools: Image to Base64 String does

Image to Base64 String, from ShivaTools, helps MaxScript authors embed pictures inside their scripts. Drag an image onto the macro and it is encoded as Base64 using .NET, with the result placed on the clipboard.

What lands on the clipboard is ready-made code containing a decoder function and a usage example, so it pastes right into a script. The code is unencrypted and open for reading and adaptation. This approach lets scripters ship logos and icons inside a single file rather than distributing separate image files alongside it.

Key features

  • Drag-and-drop image to Base64 encoding
  • Encoding done with .NET inside the macro
  • Result copied to the clipboard
  • Includes decoder function and usage example
  • Readable, unencrypted code
