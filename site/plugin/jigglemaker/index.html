Blender add-on that prepares character jiggle physics in three steps using Surface Deform, pinning and Cloth.

What Jigglemaker does

JiggleMaker adds soft jiggle motion to character parts in Blender with a three-step bind workflow. It wires up Surface Deform, pinning and Cloth between a main mesh and a jiggle mesh.

Three creation modes exist: Preset Mesh Mode with ready-made proxies to bind, Vertex Mode using existing vertex groups, and Custom Mesh Mode, meant for a proxy of your own with a Pin group. Bind then connects the setup. Character animators can add secondary motion without assembling it by hand.

Key features

  • Three-step bind workflow
  • Preset, Vertex and Custom Mesh modes
  • Surface Deform, pinning and Cloth wiring
  • Ready-to-bind proxy library
