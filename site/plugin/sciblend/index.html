Blender extension for importing VTK data, exporting OpenVDB volumes and generating materials and legends from mesh attributes.

What SciBlend does

SciBlend serves scientific visualization in Blender. It imports VTK XML PolyData files (.vtp and .pvtp), splitting vector and tensor arrays into named attributes and adding a Magnitude attribute for vectors, and animation sequences come in with visibility keyframes.

Paraview Macros export volume data to .vtk, .vti and OpenVDB, resampling non-uniform grids. A ShaderGenerator builds materials from any float or vector mesh attribute, and a LegendGenerator reads title, range and colormap from the active material, with font, number format and orientation options. It is released under GPL v3.0 or later.

Key features

  • VTK PolyData import with attribute splitting
  • Animation sequence import
  • Volume export to .vtk, .vti and OpenVDB
  • Materials from mesh attributes
  • Customizable legend overlays
