What Save Objects 2 does

Save Objects 2 from MotionCodes lets you store parts of a project and use them elsewhere. Compositions, layers, even several at once, are saved with all their properties and shown with a live preview.

Presets, fonts, masks, markers, keyframe interpolation, expressions and JSX code can be saved as well, with values still editable. Several comps can be saved separately with GIF previews in one click, and a media browser previews, applies and imports projects, presets and media. Projects can be slimmed down with the Collect Files method, fonts gathered, and a free add-on pack with dozens of layers and presets is included. A solid choice for building a personal asset library.

Key features

  • Store comps, layers and properties with a live preview
  • Presets, fonts, masks, markers, expressions and JSX
  • Batch-save comps with GIF previews
  • Media browser with one-click import
  • Collect Files reduction and bundled add-on pack
