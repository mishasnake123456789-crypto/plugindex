What Grease Mesh does

Grease Mesh is a Blender addon by Tonis that converts Grease Pencil drawings into 3D meshes through Geometry Nodes. Sketch a shape, press a button, and a mesh appears that keeps following your strokes while you edit.

The conversion is non-destructive, leaving the Grease Pencil object editable. Solid Mesh fills closed drawings and extrudes them to a thickness you set; Mirror Mesh makes a mirrored solid out of half a drawing; Path Mesh drags a cross-section profile along a drawn path, keeping path and profile on separate layers.

Key features

  • Non-destructive Grease Pencil to mesh conversion
  • Solid Mesh with adjustable thickness
  • Mirror Mesh from half shapes
  • Path Mesh sweeps profiles along paths
  • Mesh updates as strokes change
