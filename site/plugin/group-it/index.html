Group It

Developer: SimonBourgeois

Free3ds Max
Download Free

3ds Max script that groups selected objects with control over orientation, naming, pivot placement and layer assignment.

What Group It does

Group It builds a group from the selected objects in 3ds Max and takes the group's orientation from the first object selected, which keeps the group aligned the way you expect. Nested groups are supported.

For naming, you can add a layer-name prefix or enter a custom group name, with the standard Max name used when the field is empty. The group pivot can be placed in several locations, and selected objects can optionally be moved to the first object's layer. A separate no-UI version is available, placing the pivot at the base and keeping members in the same layer by default.

Key features

  • Group inherits orientation from the first selected object
  • Supports nested groups
  • Layer-name prefix or custom group name
  • Choice of pivot placement
  • Optional move to the first object's layer, plus no-UI version
