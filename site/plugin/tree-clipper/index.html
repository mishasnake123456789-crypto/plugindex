Blender add-on that exports and imports node trees as JSON or compressed strings for version control and sharing.

What Tree Clipper does

Tree Clipper, by Lars-Helge-Scheel, moves node trees in and out of Blender as text. Geometry, Shader, Compositor and Texture setups are all supported, interfaces included.

Output can be plain JSON, which works well with version control, or a compressed string beginning with TreeClipper:: and a base64 body that is easy to paste in forums or chat. Technical artists can share setups without exchanging .blend files.

Key features

  • Works with four node tree types: Geometry, Shader, Compositor, Texture
  • Plain JSON output
  • Compressed TreeClipper base64 strings
  • Includes node tree interfaces
  • Suited to version control and sharing
