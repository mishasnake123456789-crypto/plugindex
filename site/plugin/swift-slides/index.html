Builds slideshows in Premiere Pro from selected images, timed to a chosen audio track.

What Swift Slides does

Swift Slides assembles a photo slideshow that fits the length of a song or voiceover. Select the images and the audio in the timeline, tweak the settings, and let it generate the sequence.

Zoom can be set by direction and a minimum and maximum range, pan has its own range, and multiple transitions can be ticked on. Keyframes are created only for the options you enable. Optional logging goes to a SwiftSlides_Logs folder in Documents.

Key features

  • Slideshow fitted to an audio track
  • Zoom with direction and range settings
  • Pan with minimum and maximum range
  • Selectable transitions
  • Optional debug logging
