What Boardtyper 3D does

Boardtyper 3D is a Blender extension for people making tabletop game mods. It automates preparing, arranging and exporting 3D components for Tabletop Simulator, producing the .obj files, extracting textures and compiling the final TTS .json save file.

You assign native TTS object types such as Bag, Figurine, Coin, Board, Dice or Chip, plus materials, directly in Blender. A bag system creates containers and fills them with named scene objects in set quantities, and visibility control keeps utility objects out of the export.

Key features

  • Assign TTS types like Bag, Dice, Coin and Board
  • Bags filled with named objects at set quantities
  • Exports .obj files and extracts textures
  • Compiles the final TTS .json save
  • Visibility control for helper objects
