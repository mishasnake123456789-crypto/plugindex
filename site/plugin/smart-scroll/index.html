Animates rolling scrolls in Blender by tweaking spiral parameters and drawing a path curve.

What Smart Scroll does

Smart Scroll makes unrolling parchment animation straightforward in Blender. The spiral shape of the scroll is controlled from a panel, so thickness and winding can be tuned without modeling by hand.

Curve direction and tilt, which define the followed path, are set from the same panel. The stalk turns with the scroll's pivots without needing keyframes of its own, and a switch lets you move either the scroll body or the stalk. Drawing a curve is enough to animate quickly. Motion designers making title reveals or fantasy props will find it handy.

Key features

  • Adjustable spiral parameters
  • Curve direction and tilt controls
  • Stalk rotates with the pivots automatically
  • Animate by drawing a curve
