What [Addon] Different Local View does

Different Local View lets you set a personal theme for local view. The custom look makes it clear when the mode is active, so hidden objects are easier to keep in mind.

Version 1.1 shows the theme in add-on settings right at install. It supports Blender 2.9 through 4.3, is GPL-licensed and has a demo video. Notable points: custom local view theme, clear visual signal and blender 2.9 to 4.3.
