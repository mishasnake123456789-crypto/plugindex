Rotates the Blender viewport to face the selected face, vertex or edge with one key press in Edit Mode.

What View Selected does

View Selected is a tiny Blender add-on that reorients the viewport based on what you have selected in Edit Mode. It saves the fiddling usually needed to look straight at a particular part of a mesh.

Press the backtick key with a face, vertex or edge selected and the add-on offers the available view options to choose from. It needs no special permissions and is only around 4 KB, so it adds almost nothing to your setup. It suits modelers who constantly check surfaces from specific angles.

Key features

  • Handles selected faces, vertices and edges
  • Triggered by the backtick key in Edit Mode
  • Offers view options on activation
  • Needs no special permissions
  • About 4 KB install size
