What LongShadow does

LongShadow from BGRA Entertainment casts customizable shadows from layers in After Effects, giving flat design graphics depth. It runs on the GPU and exposes control over nearly every aspect of the shadow.

Another layer can supply colour and transparency to the shadow, using one-dimensional or two-dimensional texturing. A Brute-Force Directional mode keeps the original layer's semi-transparency and anti-aliasing, and a post-smoothing algorithm cleans the result. Soft shadow options are included, plus a dedicated SoftShadow plugin with simpler controls for a solid-colour soft shadow.

Key features

  • GPU-accelerated shadows
  • 1D and 2D texturing from an external layer
  • Brute-Force Directional mode
  • Soft shadow and post-smoothing
  • Separate SoftShadow plugin
