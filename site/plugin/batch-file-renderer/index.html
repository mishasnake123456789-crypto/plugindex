What Batch File Renderer does

Dani K Daniel's Batch File Renderer queues multiple .blend files and renders each in turn in the background, with start and stop controls in a panel of Blender's Properties window.

Output paths are generated automatically per project, and Stop can halt the process at any time. Version 1.3 added smart frame range detection so start and end frames can be reviewed and changed per file. Artists with many files to deliver can let renders run unattended.

Key features

  • Queue multiple .blend files
  • Background sequential rendering
  • Stop control
  • Automatic output paths
  • Frame range detection per file (v1.3)
