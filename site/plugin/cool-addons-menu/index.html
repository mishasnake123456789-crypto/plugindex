What Cool Addons Menu does

Cool Addons Menu helps tidy up a crowded N-panel in Blender. It detects the add-ons you have enabled and shows them in one sortable list so you can open their panels and preferences without scrolling through vertical tabs.

Only add-ons with an N-Panel panel are included, and the list updates as add-ons are installed, removed or toggled. Entries are alphabetical and show each add-on's version. It suits users with many add-ons installed.

Key features

  • Detects enabled add-ons automatically
  • Dynamic updates on install, removal or toggle
  • Alphabetical list with versions
  • Direct access to panels and preferences
