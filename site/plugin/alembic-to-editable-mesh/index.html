Blender add-on that converts Alembic cache playback into an editable mesh with animation held in shape keys.

What Alembic To Editable Mesh does

Cached Alembic geometry can't normally be edited in Blender. Dani K Daniel's Alembic To Editable Mesh changes that: pick an Alembic object in the 3D View sidebar and click Convert to Editable Mesh.

Motion is rebuilt as shape keys with automatic keyframes that follow the cache frame by frame. The scene range or your own start and end frames can be used, with a frame step. Undo is fully supported and progress is reported. Useful for fixing simulations or imported animation.

Key features

  • One-click conversion from the sidebar
  • Shape key based animation
  • Matches the cache frame by frame
  • Custom frame range and step
  • Undo support and progress feedback
