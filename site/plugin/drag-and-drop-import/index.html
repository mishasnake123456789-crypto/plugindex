Blender add-on to import files by dragging them from the file explorer into the 3D Viewport or Outliner.

What Drag & Drop Import does

Drag & Drop Import lets you drop files from your operating system straight into Blender. It supports over thirty file types spanning models, images and video.

Dragging with the left button imports using defaults, whereas right-button dragging, or Ctrl plus left-drag, brings up import options. Supported types include FBX, GLB, GLTF, OBJ, USD, BLEND, PNG, VDB, HDR and EXR, and an image drop menu offers choices for how pictures are brought in. Artists handling mixed asset folders import faster than via menus.

Key features

  • Drop files into Viewport or Outliner
  • 30+ supported file types
  • Import options on right-click drag
  • Image drop menu
