What Fs Align And Outset Tool does

Fs Align And Outset Tool solves a particular modeling annoyance: an object's axes not lining up with its geometry. It aligns the pivot axis, or two axes, to an edge or a pair of perpendicular edges in the mesh, which also helps when the object's axis differs from an array's axis.

It can also realign an object's rotation. Version 1.30 introduced an Outset operation built on Blender's standard inset, started with the I key and right-click, with its value adjustable in the dialog at the lower left of the viewport. Hard-surface modelers cleaning up transforms will find it handy.

Key features

  • Aligns pivot axes to an edge or two perpendicular edges
  • Fixes mismatched axes with arrays
  • Realigns object rotation
  • Outset operation built on inset (v1.30)
