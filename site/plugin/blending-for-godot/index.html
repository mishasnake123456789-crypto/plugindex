What Blending For Godot does

Blending For Godot is a Blender add-on by Rafael that simplifies sending assets to the Godot Engine. It offers a straightforward export workflow run in a safe, sandboxed process.

You can batch export selected objects, collections or whole scenes. Smart Mesh Batching merges objects on export to reduce draw calls while keeping your Blender organization and data intact, and there is a pipeline for animated characters and collisions. Indie game developers using Blender and Godot can cut export friction.

Key features

  • Batch export of objects, collections or scenes
  • Smart Mesh Batching to reduce draw calls
  • Animated character and collision export
  • Sandboxed export process
