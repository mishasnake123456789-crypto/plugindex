What Object Checkpoint Versioning Addon does

Object Checkpoint Versioning Addon lets you snapshot an object during development and return to it whenever needed, so you do not have to duplicate objects by hand.

Use Add Checkpoint to save the state, Load Checkpoint to roll back, and Delete Checkpoint to remove one, all from the List CP panel. Checkpoints persist after the project closes, and the file stays free of unused development copies. Documentation is included.

Key features

  • Add, load and delete checkpoints
  • Checkpoints survive closing the project
  • No manual duplicate objects
  • List CP panel
