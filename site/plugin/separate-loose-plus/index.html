Blender add-on to pull a loose mesh part out as a separate object, edit it, then fold it back in.

What Separate Loose Plus does

Separate Loose Plus gives Blender a more convenient way to work on one piece of a multi-part mesh. Select a loose part with link selection, and the Separate and Edit command turns it into its own object for immediate editing.

When you are finished, Merge Back to Object recombines it with the original while keeping your changes. The commands appear in the Mesh menu, shortcuts can be remapped, and suggested assignments are offered. It needs no special permissions.

Key features

  • Separate and Edit for loose mesh parts
  • Merge Back to Object keeps changes
  • Object tracking between parts
  • Commands in the Mesh menu
  • Remappable shortcuts
