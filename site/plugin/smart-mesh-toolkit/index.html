Blender modeling toolkit with primitive editing pop-ups and a Maya-style target merge tool.

What Smart Mesh Toolkit does

Smart Mesh Toolkit combines two tools, both opened with the Y hotkey, to speed up modeling in Blender. Smart Mesh Tool detects cubes, spheres and cylinders and offers radius, segments and depth in a pop-up, or location, rotation and dimensions for other meshes.

Changes stay temporary until confirmed. Target Merge Tool merges vertices interactively in Edit Mode, drawing lines to show the result, with Target and Center modes switched by C, and it can stitch vertices from two objects. Standard, Pro and Studio licenses are offered.

Key features

  • Primitive-aware pop-up parameters
  • Non-destructive confirm or cancel
  • Interactive Target Merge with Target and Center modes
  • Multi-object vertex stitching
