Turns the Blender sidebar into a configurable workspace with custom N-panels, grouped tabs and JSON saves.

What Supertabs does

Supertabs reorganizes the sidebar in Blender. You can create unlimited N-panels as main groups and tab groups as sub groups, reorder them, rename them and give them icons.

Several add-ons can be merged into one N-panel and their sub-panels hidden. Configurations are saved as JSON and restored automatically at startup. Useful if many add-ons clutter your interface. A tidy, saved layout reduces scrolling and tab hunting, so the tools you use most are always where you expect them.

Key features

  • Unlimited N-panels and tab groups
  • Merge add-ons into one panel
  • Reorder, rename and add icons
  • JSON save with auto-restore
