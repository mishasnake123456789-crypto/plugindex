What Robot Designer - Procedural Robot Character Creator does

Robot Designer is a Blender add-on by Alexis.egi that creates a full humanoid robot in a pipeline of geometry, materials, rig, UVs, baking and export; choose a preset, drag some sliders, and the tool takes over.

The procedural geometry runs on geometry nodes and exposes more than 800 parameters in six categories per body part, non-destructive and with per-limb asymmetry. A PBR smart material treats screws, cables, details, eyes, joints, plates and the base mesh as separate zones in Cycles and EEVEE. A Rigify IK/FK rig and a Mixamo rig are included.

Key features

  • Five-step pipeline from geometry to export
  • 800+ procedural parameters via geometry nodes
  • Per-limb asymmetry, non-destructive edits
  • PBR smart material with per-zone control
  • Rigify IK/FK and Mixamo rigs
