Rigging helper set for Blender: bone arranging, armatures from origins, weight transfer, mirroring and vertex groups.

What Rigo does

Rigo automates repetitive rigging chores in Blender, with extras that are useful outside rigging too. Auto-Bone Arranger positions bones on a model using vertex groups that share names with the bones, and Armature from Origins builds an armature from object origin points.

Other tools assign custom bone shapes, transfer weights from a rigged object to another via the data transfer modifier, mirror selected objects in one click and manage vertex groups. It suits riggers who want to cut down on manual setup for characters and props.

Key features

  • Auto-Bone Arranger from vertex groups
  • Armature from object origins
  • Custom bone shape assignment
  • Weight transfer between objects
  • One-click mirroring and vertex group tools
