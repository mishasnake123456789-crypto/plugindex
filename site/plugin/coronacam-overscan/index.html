What CoronaCam Overscan does

CoronaCam Overscan widens the rendered area of a Corona Camera in 3ds Max without changing the framing of the original view. Width and height can both be increased, and the script automatically adjusts the camera's focal length or FOV to match.

Overscan only needs a selected CoronaCam. The render setup window closes by itself for safety, and a refresh option lets you switch between cameras. Installation is by drag and drop, with a toolbar button added through Customize User Interface. Compositors benefit from the extra pixels around the frame for effects such as lens distortion or camera shake in post.

Key features

  • Overscans Corona Camera width and height
  • Focal length or FOV adjusted automatically
  • Works with just a selected CoronaCam
  • Refresh option for switching cameras
  • Drag-and-drop installation with toolbar setup
