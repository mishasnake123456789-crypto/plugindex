A Blender add-on that puts the main snapping tools into one radial menu using Blender's own settings.

What Native Snapping does

Native Snapping collects Blender's primary snapping options in a single radial menu. Choose the movement you want, and the add-on configures the relevant default settings for you, so you stop digging through the snap dropdown for each task.

Because it relies on Blender's own tools, it does not hurt performance in large scenes. The shortcut is configurable in the preferences, defaulting to Shift+X, and a free high-resolution infographic is offered. Modelers and layout artists who snap frequently between vertices, edges, faces and grids will find the workflow quicker.

Key features

  • Primary snapping tools in one radial menu
  • Auto-configures Blender's default settings
  • Uses native tools, safe for large scenes
  • Shortcut set in preferences, default Shift+X
