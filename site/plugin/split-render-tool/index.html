A Blender add-on that renders large images in small pieces and merges them, avoiding GPU memory limits.

What Split Render Tool does

Split Render Tool lets you render big images in Blender on graphics cards that would otherwise run out of memory. It splits the final image into small pieces, renders them and merges the result automatically, with no manual stitching.

It handles single frames and full animations. Animated Border and Object Border methods render only a chosen part of the frame, with keyframing, a bake system and timeline preview of the crop region. An optional new Blender file blurs image edges through an ellipse mask with adjustable blur size. Artists producing high-resolution output on modest GPUs will benefit.

Key features

  • Splits renders into pieces and merges them
  • Single frames or animations
  • Animated Border and Object Border methods
  • Bake system and crop region preview
  • Optional ellipse mask edge blur
