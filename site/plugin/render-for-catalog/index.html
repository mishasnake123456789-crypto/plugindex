Renders each object in a Blender group with identical lighting and framing for catalog images, thumbnails or icons.

What Render For Catalog does

Render for Catalog produces separate renders for a set of objects while keeping the look consistent, which is what catalog photography needs. Each object is shot with the same lighting and framing.

Several cameras can show an object from different angles, and each camera's index or name is added to the file name so results remain separate. It also works with fileoutput compositor nodes through the add-on's _RFC_viewlayer to save extra images. E-commerce artists and asset creators can batch thumbnails easily.

Key features

  • Separate renders per object with consistent setup
  • Multiple cameras per object
  • Camera index or name in file names
  • Supports fileoutput compositor nodes
  • Suited to catalogs, thumbnails and icons
