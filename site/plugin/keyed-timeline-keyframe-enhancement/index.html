What Keyed - Timeline Keyframe Enhancement does

Keyed, from Toon Ups, brings quick keyframe control to the Timeline. One click on the current frame adds a keyframe if none exists and removes it if one does.

You choose which channels to affect: Location, Rotation, Scale, or LocRotScale combined. It works with the active object, header buttons show icons that change depending on whether keyframes exist, and the Dopesheet and Timeline update in real time.

Key features

  • One-click keyframe toggle
  • Location, Rotation, Scale or combined
  • Context-aware for the active object
  • Dynamic header icons
