Blender add-on that exports geometry node toolpaths as G-code for CNC, 3D printing, laser cutting and plotting.

What Fabnodes does

Fabnodes connects Blender's geometry nodes to physical fabrication. It writes toolpaths from node graphs out as G-code in .nc files, ready for CNC machines, 3D printers, laser cutters and pen plotters.

Separate modes exist for CNC, 3D printing, drawing and laser cutting, with adjustable feed rates, extrusion values and power. Custom start and end G-code can be added, positions can be exported globally or from an attribute, and a draw attribute option is available. A help panel is built in.

Key features

  • Exports geometry node paths to G-code
  • CNC, 3D printing, drawing and laser modes
  • Adjustable feed, extrusion and power
  • Custom start and end G-code
  • Global or attribute position export
