What Proxy Interface does

Proxy Interface, by LingQS, lets you organise Blender's own controls into custom layouts that you can reuse, so the properties you need are gathered in one panel. It is listed under User Interface.

Open source under GPL-3.0-or-later, it requires Blender 4.5.0 or newer.
