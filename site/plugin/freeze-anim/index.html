3ds Max script that converts stack-based animation into vertex-based animation, without preserving space warp links.

What Freeze anim does

Freeze anim, by Chuggnut, seals animation that is driven by the modifier stack into vertex-based animation in 3ds Max. The result no longer depends on the original modifiers.

Space warp links do not survive the conversion, so plan scenes accordingly. It is available at version 2.3.5 and listed on ScriptSpot with a link to the developer's website. Artists who need to bake the result of procedural deformation, for example before exporting or handing a scene to someone without the same plugins, can use it as a simple solution.

Key features

  • Seals stack-based animation into vertex animation
  • Space warp links not saved during conversion
  • Designed for 3ds Max
  • Version 2.3.5
