Open-source Blender add-on with true 3D onion skinning in the viewport and an inbetweening mode separating key and interpolated frames.

What Animation Extras does

Animation Extras brings convenience features to Blender animation, headlined by genuine 3D onion skinning drawn right into the viewport using Blender's BGL and GPU modules.

No additional meshes or materials get created for the onion skin effect. An inbetweening mode colors keyed frames differently from interpolated ones. Animators judging arcs, spacing and timing can see ghosted poses without cluttering the scene. Because the onion skin is drawn by the GPU, it avoids adding objects to the scene that need to be cleaned up later.

Key features

  • True 3D onion skinning
  • No extra meshes or materials
  • Inbetweening color mode
  • Open source
