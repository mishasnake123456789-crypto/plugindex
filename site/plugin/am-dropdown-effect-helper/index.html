What AM Dropdown Effect Helper does

AM Dropdown Effect Helper is a script by Adirai Maji for people who use the Dropdown Menu Control effect in After Effects. Setting up menu items and linking expressions to them takes repeated manual steps, and this script automates them.

It uses universal expressions, so it supports non-English versions of After Effects. The listing shows compatibility with After Effects 2020, and a demo video is available. Template builders and rig designers will find it useful for switchable options.
