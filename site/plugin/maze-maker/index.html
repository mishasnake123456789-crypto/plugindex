Generates procedural mazes in Blender from your own wall objects, with rooms, loops and a path curve.

What Maze Maker does

Maze Maker builds mazes procedurally using wall objects you supply. Width and height are adjustable, and entrances and exits are set by count and side.

A loop probability option creates isolated, non-continuous walls, random interior rooms can be added, and corridor sizes widen the pathways. A floor is created automatically, and a BFS path curve is generated that a camera can follow through the maze. Single objects or random object choices can be used for walls, making it flexible for games and fly-through animations.

Key features

  • Procedural maze from your own walls
  • Entrances, exits and loop probability
  • Random rooms and adjustable corridors
  • Automatic floor
  • BFS path curve for camera
