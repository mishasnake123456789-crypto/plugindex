What Ghost Script does

Ghost Script, from BirdAid, tackles the problem of seeing through clutter. Instead of applying X-ray to the whole scene, it ghosts only the models you select and leaves the active object solid and clear.

Because the effect is a display toggle, geometry and materials remain untouched and you can switch it off again at will. There is no complicated setup, and it fits modeling, rigging, level design and architectural scenes where you need to focus on one thing while keeping the surrounding objects visible as context.

Key features

  • X-ray only on selected models
  • Active model stays fully visible
  • Non-destructive toggle on and off
  • Lightweight, no complex setup
  • Useful for modeling, rigging and level design
