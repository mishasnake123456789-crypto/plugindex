Shows object statistics in the Blender viewport, including collections and parent info from depsgraph data.

What Live Inspector does

Live Inspector displays information about an object directly in 3D space, so you do not have to open the Outliner or Properties editor. It lists every collection the object belongs to and shows its parent.

Data is read from depsgraph evaluation. The floating interface can be brought to the front with Shift and snapped to the mouse with Ctrl. Documentation is included. Handy for understanding complicated hierarchies and linked setups at a glance.

Key features

  • Lists all collections of an object
  • Shows parent information
  • Reads depsgraph evaluation data
  • Shift to bring forward, Ctrl to snap to mouse
