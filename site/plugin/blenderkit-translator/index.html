What Blenderkit Translator does

Blenderkit Translator lets people search the BlenderKit asset library in their own language. Since the library is searched in English, the add-on handles translation inside Blender.

Pick a source language from Arabic, French, Spanish, German, Italian, Russian, Chinese, Portuguese, Korean, Turkish or Japanese, then choose a category such as Models, Materials, Scenes or HDRs. The interface is simple, it runs on Blender 3.0 through 4.2, and it is distributed under the GPL.

Key features

  • Translates search text from 11 languages
  • Category choice: models, materials, scenes, HDRs
  • Simple in-Blender interface
  • Works with Blender 3.0 to 4.2
