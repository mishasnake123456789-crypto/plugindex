What Scale Checker does

Scale Checker is a scene-checking utility for 3ds Max by Sergio Mucino. It scans the scene for objects that carry non-uniform scaling and writes the flagged objects to a script file so they can be analyzed.

Non-uniform scale often causes problems with modifiers, rigging, exports and rendering, so catching it early prevents trouble later. The tool is small and single-purpose, and a demo video is available. Technical artists, riggers and game artists who prepare clean assets can use it as a quick quality check before handing scenes on.

Key features

  • Scans for non-uniform scaled objects
  • Writes flagged objects to a script file
  • Lightweight single-purpose utility
  • Built for 3ds Max
  • Demo video available
