What Utilities Gadget does

Utilities Gadget is a streamlined Blender add-on from HurcaGuari built around two buttons. One sends every active camera in the scene through a render to the default output folder, and the other converts all visible models into geometry in one go.

The conversion includes geometry nodes, and it outputs instance objects while leaving out instances that have no implementations. Camera filtering controls whether cameras within a collection take part in rendering. It saves time when a scene has many viewpoints or procedural objects to bake down.

Key features

  • Batch-renders all active cameras
  • Output goes to the default render location
  • Batch-converts visible models to geometry
  • Includes geometry nodes in conversion
  • Camera filtering by collection
