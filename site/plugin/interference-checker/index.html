What Interference Checker does

Interference Checker helps verify fit between parts, especially for 3D printing. It detects and visualizes interference and clearance using real-time GPU overlays, without running Boolean operations.

Three detection modes are provided: AABB for speed, BVH for precision, and a combined mode. Overlays highlight intersecting faces, boundary points and intersection segments, and multiple objects are supported. Makers can catch collisions before printing. Key capabilities include AABB, BVH and Combined modes and GPU overlays for faces, points and segments.

Key features

  • AABB, BVH and Combined modes
  • GPU overlays for faces, points and segments
  • No Boolean operations
  • Multiple object support
