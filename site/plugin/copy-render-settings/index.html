What Copy Render Settings does

Copy Render Settings lets you transfer selected render options between scenes in Blender. It is placed in the Render section of the Properties window.

Once bundled with Blender 4.1, it is now a standalone extension with limited support. It is about 8 KB, needs no special permissions, and is released under GPL v2 or later for Blender 4.2 LTS and newer. Artists managing several scenes for a project save time keeping settings consistent.

Key features

  • Copies selected render settings
  • Panel in Render properties
  • Compact download
  • For Blender 4.2 LTS and newer
