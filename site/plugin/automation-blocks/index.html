What Automation Blocks does

Automation Blocks supplies ready-to-run tools for repetitive tasks in After Effects and Premiere Pro. Each block works with one click, and each can be modified, or you can assemble your own from nothing.

Teams benefit from standardized, shareable automation processes. Block scripts can be launched remotely over HTTP requests, triggered by hotkeys, a phone, a Stream Deck or other software, and a dedicated block executes JSX code. Premiere Pro versions 2023 through 2026 are supported. The tool is made by mamoworld tools.

Key features

  • Premade one-click tools
  • Customize any tool or create your own
  • Standardized automation for teams
  • Remote execution via HTTP, Stream Deck or hotkeys
  • Block for running JSX code
