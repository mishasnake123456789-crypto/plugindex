Blender add-on that inserts or deletes keyframes on a property for all selected objects through a right-click menu entry.

What Key Selected Objects does

Key Selected Objects makes keyframing several objects at once as simple as keying one. With several objects selected, right-click any property and pick the Keyframe All Selected Objects entry to add or remove keys on every one of them, no Keying Sets needed.

Multi-value properties are keyed as a whole, for example location, rotation or scale, and works with materials that share matching surface shaders like the Principled BSDF. Several pose bones or objects can be added to your Keying Sets, and it also copes with custom properties and layers of Grease Pencil. Documentation is included.

Key features

  • Keyframe all selected objects from the right-click menu
  • Insert and delete keys through the interface
  • Keys whole multi-dimensional properties together
  • Also handles custom properties and Grease Pencil layers
  • Works with matching material surface shaders
