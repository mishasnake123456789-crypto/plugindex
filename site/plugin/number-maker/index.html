What Number Maker does

Number Maker from MotionDesk builds numeric text that moves. It is designed for counters, timers and any graphic where a number should follow time, speed, a marker or another property.

Animation modes include By Time, By Speed and By Marker, and Follow Property links values to any property. Map Range, Multiplier and Offset adjust the numbers, and formatting supports prefixes, suffixes and symbols. It handles progress bars, percentages and custom formats, and everything stays editable through layer controls after creation. UI and HUD designers and infographic creators benefit most.

Key features

  • By Time, By Speed and By Marker modes
  • Follow Property and Map Range
  • Multiplier, offset and formatting options
  • Counters, percentages and progress bars
  • Editable via layer controls
