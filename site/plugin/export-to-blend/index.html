Blender add-on that saves selected objects, collections or nodes into a new blend file, optionally as assets.

What Export To Blend does

Export to Blend splits parts of a scene into separate blend files. It handles selected objects, collections chosen in the Outliner, and nodes picked in a node editor.

Exports can be wrapped in a new collection first, marked as assets for the Asset Browser, or backlinked so that your current file points to the exported one by library link. It runs from File, Export and the Outliner context menu, which makes it handy for building an asset library while you work.

Key features

  • Export objects, collections or nodes
  • Works from the Outliner and node editors
  • Optional asset marking
  • Optional backlink to the exported file
  • File menu and context menu access
