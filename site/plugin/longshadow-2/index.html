What LongShadow 2 does

LongShadow 2 from BGRA Entertainment is a shadow plugin for After Effects offering control over every part of a shadow. It extends the familiar flat-design long shadow with anti-aliasing and a post-smoothing algorithm for cleaner edges.

Shadows can be textured with an external layer in 1D or 2D modes, giving precise control of color and transparency. A Brute-Force Directional mode keeps the original layer's semi-transparency and anti-aliasing, and a soft shadow feature adds blur. It supports After Effects from CC 2014 up to 2026, with native M1 support.

Key features

  • Shadow anti-aliasing and post-smoothing
  • 1D and 2D shadow texturing from a layer
  • Brute-Force Directional mode
  • Soft shadow option
  • Native M1 support
