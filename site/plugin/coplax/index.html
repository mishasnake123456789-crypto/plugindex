Color palette toolkit for Blender: import web palettes, extract image colors and generate harmonies.

What Coplax does

Coplax organizes color decisions for materials. Palettes can be imported from the web straight into Blender, or colors can be extracted from an image to build one.

Color harmonies are generated automatically for material work, and it supports the internal renderer, Cycles and Eevee. The Studio Pro tier also provides a gradient and pattern generator. Documentation is included. Artists wanting cohesive palettes without leaving Blender save trips to color websites. It is a handy way to keep a project's colors consistent.

Key features

  • Web palette import
  • Image color extraction
  • Color harmony generation
  • Studio Pro adds gradients and patterns
