Blender add-on for grouping installed add-ons into collections you can enable or disable together.

What Addon Collections Manager does

Addon Collections Manager lets you bundle add-ons into named groups inside Blender's Preferences, then switch workflow setups with one click.

Create as many collections as you like from selected add-ons, add more later and rename them anytime. Enable or disable an entire group instantly. A shortcut button sits under the toolbar for quick access. It runs fully offline with no data collection, which helps keep Blender lean when working on different task types.

Key features

  • Unlimited add-on collections
  • Enable or disable a group instantly
  • Add to and rename collections
  • Shortcut button below the toolbar
  • Fully offline, no data collection
