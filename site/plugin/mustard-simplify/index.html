What Mustard Simplify does

Mustard Simplify improves viewport performance in Blender by turning off features that slow it down. One click simplifies the scene, and nothing is permanently altered.

Original settings return when Simplify is switched off. You decide which features get disabled, such as particular modifier types and driven or undriven shape keys, and an exceptions list spares chosen objects. Animators handling heavy rigged characters get smoother playback. Since nothing is edited permanently, it is safe to switch on while animating and switch off again before final rendering.

Key features

  • One-click Simplify Scene
  • Non-destructive with settings restored
  • Choose modifier types and shape keys to disable
  • Exceptions list for objects
