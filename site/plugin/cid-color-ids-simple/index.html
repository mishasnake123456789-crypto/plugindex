Blender add-on that makes Material and Object ID passes by assigning random indices and matching compositor colors.

What Cid - Color Ids Simple does

Cid - Color Ids Simple generates ID render passes in Blender, the flat-color masks used to select parts of an image during post-production. One click gives materials and objects randomly chosen index numbers.

It then builds the matching setups in the internal compositor and produces colors that correspond to those indices, so each material or object gets a distinct mask color. Compositors can use these to isolate and adjust elements without re-rendering the scene.

Key features

  • Material and Object ID pass setups
  • One-click random index generation
  • Compositor colors matching the indices
  • Built on Blender's internal compositor
