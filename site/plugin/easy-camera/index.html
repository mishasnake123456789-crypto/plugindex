What Easy Camera does

Easy Camera helps create smooth cinematic camera movement and keeps scene cameras organized. Draw an orbit path, click Finish Orbit to attach the selected camera, pick a target and keyframe the motion.

In mesh target mode the camera stays focused on the object's geometric center while following the path. Orbit target mode adds sliders for camera position, rotation and direction for manual control. An Along Object option keeps the camera parallel to the target surface as it tracks. It suits product shots, turntables and fly-around animations.

Key features

  • Draw an orbit path and attach a camera
  • Mesh target mode keeps focus on object center
  • Position, rotation and direction sliders
  • Along Object surface-parallel tracking
  • Keyframe the camera motion
