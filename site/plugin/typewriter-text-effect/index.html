Blender add-on for animating typing on text objects with a blinking cursor and manual progress control.

What Typewriter Text Effect does

Typewriter Text Effect creates a typing animation on text objects in Blender and plays it back in real time in the viewport.

A cursor with adjustable blink speed follows the letters, and progress can be set by hand. An Instant Update button changes the text without restarting, while Clear All deletes keyframes and resets settings. Text, typing progress and cursor speed are adjustable from the panel. It is suited to titles, interfaces and explainer scenes.

Key features

  • Real-time typing preview
  • Blinking cursor with adjustable speed
  • Manual progress control
  • Instant Update button
  • Clear All resets keyframes
