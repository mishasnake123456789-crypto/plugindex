What pt_TextEdit 2 does

pt_TextEdit 2 by Paul Tuersley is an After Effects script that finds and changes text properties everywhere in a project at once. It searches nested comps and all text keyframes, so nothing hides in a precomp.

You can search and replace wording, fonts and colors, with color values shown as 8-bit, hex or decimal. It also converts text to upper or lowercase, edits tracking and leading, and locates missing fonts on newer versions. Results can be sorted by layer, font size and color, which helps when cleaning up a large template or enforcing brand styling.

Key features

  • Search and replace text, fonts and colors
  • Find missing fonts
  • Color values as 8-bit, hex or decimal
  • Upper and lowercase conversion
  • Edit tracking and leading, sort results
