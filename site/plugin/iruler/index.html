What Iruler does

Iruler lets you measure inside Blender with real-time feedback. It tracks distances between objects with a ruler-style display, analyzes coordinates and converts units automatically to follow your scene settings.

It works in Object and Edit modes, measuring vertices, edges and faces, and shows position vectors and displacement for studying object movement. Metric and imperial values update instantly when scene units change. It is useful for architectural, product and technical modeling.

Key features

  • Real-time distance measurement
  • Automatic metric and imperial conversion
  • Vertex, edge and face measurements in Edit mode
  • Position vectors and displacement tracking
