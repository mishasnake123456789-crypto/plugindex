What Ivypen Add-On does

Ignacio Matey's Ivypen Add-On adds procedural ivy to Blender. After clicking create ivy, you draw on the selected object using the pen tool and the ivy grows along your curve. It is built on Geometry Nodes and works across many surfaces.

Branch and leaf density can be raised for more detail, at the cost of more calculation. An ivy trim value from 0 to 1 cuts the growth back toward the length of the curve, and maximum and minimum leaf size, branch radius and branch extension are adjustable. Useful for overgrown walls, ruins and environments.

Key features

  • Draw ivy on a surface with the pen tool
  • Branch and leaf density controls
  • Ivy trim from 0 to 1
  • Adjustable leaf size and branch radius
  • Built on Geometry Nodes
