What FAST ARCHITECTURE Trial does

FAST ARCHITECTURE Trial adds a procedural building object to 3ds Max. FA_Building produces architectural structures from parameters that update in real time, and it behaves like any other object: deformers can be applied, parameters can be animated, and it converts to mesh.

Windows, frames, balconies, columns, the roof and a curved facade can be customized. Material IDs are assigned per part, with six for windows, and tiles, windows and balconies carry their own UV mapping. An Optimize option reduces mesh weight, and settings can be saved to a file. Best for simple city backgrounds.

Key features

  • Procedural FA_Building object
  • Customizable windows, balconies, columns, roof, facade
  • Per-part material IDs and built-in UVs
  • Optimize option for lighter meshes
  • Save and load parameters from a file
