What Sloth Batch Render does

Sloth Batch Render automates product variant rendering. You define color variants and camera angles once, click Render All, and each combination renders with clean, organized filenames.

Variants can be created from a color picker with surface types, or by scanning existing material slots, with one variant per color or multi-slot setups. Color, roughness and metallic values can be edited live from the panel. Useful for product configurators and e-commerce imagery.

Key features

  • Color variants with surface types
  • Scan existing material slots
  • Live color, roughness and metallic editing
  • Render All with organized filenames
