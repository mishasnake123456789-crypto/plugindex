What CI HUB Connector does

CI HUB Connector is a single plugin that lets creative teams reach their digital asset management system, stock agencies and cloud storage from within After Effects and Premiere Pro. Assets stay governed by the permissions you already have, and every file format is supported.

You can link to assets and relink them later, switch between versions and high or low-resolution renditions while working with placeholder media, and open or save Premiere Pro projects through the panel. It checks placed assets for updates and warns if licensing permissions change. The plugin is built without C++, so support for new Adobe versions arrives without delay.

Key features

  • Browse DAM, buy stock and share via cloud storage
  • Link and relink assets, Premiere Pro included
  • Switch between versions and renditions
  • Warns when licensing permissions change
  • Mirrors user permissions; supports all file formats
