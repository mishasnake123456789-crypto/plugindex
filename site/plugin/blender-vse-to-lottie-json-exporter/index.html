What Blender Vse To Lottie Json Exporter does

Blender VSE to Lottie JSON Exporter converts animations made in the Video Sequence Editor into Lottie, the open animation format for web and mobile. It requires no external libraries.

Images are embedded as Base64 inside one self-contained JSON file, and the output is optimized by rounding floats and stripping unused keys. You can choose PNG, JPEG or WEBP images and scale to 100, 75 or 50 percent resolution. Each VSE channel can also be exported on its own, which suits UI and web animation work.

Key features

  • Exports VSE animation to Lottie JSON
  • Base64-embedded images in a single file
  • Float rounding and unused key removal
  • PNG, JPEG or WEBP with scaling options
  • Per-channel export
