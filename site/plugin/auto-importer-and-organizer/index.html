What Auto Importer & Organizer does

Auto Importer & Organizer helps artists present or sort many models at once. It imports whole folders, optionally scanning subfolders, and supports OBJ, FBX, GLTF/GLB and STL files.

A grid layout is applied right after import, and the Grid Auto tool can reorganize objects already in the scene. Grid by Material groups objects accordingly, duplicated materials are unified, and scale is standardized for presentation. Asset-pack buyers and environment artists can review libraries quickly.

Key features

  • Batch import with optional recursive scanning
  • OBJ, FBX, GLTF/GLB and STL support
  • Automatic grid layout
  • Grid Auto for existing scene objects
  • Material grouping, merging and scale standardization
