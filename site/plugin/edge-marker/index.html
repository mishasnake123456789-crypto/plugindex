Blender add-on that places markers at exact distances along edges for precise snapping.

What Edge Marker does

Edge Marker places visible markers, or the 3D cursor, at exact distances along a selected edge, with millimeter precision. It suits modelers in arch viz, product design, hard surface and retopology who need exact placement.

Markers can also be set in world space by coordinates or from the cursor. Vertices in Edit Mode or whole objects in Object Mode snap to the active marker, and the cursor can jump to any marker. Markers are saved in the file, color-coded, work across objects with full undo, and can be cleared or hidden.

Key features

  • Markers at set distances along edges
  • World-space markers by coordinates
  • Snap vertices, objects or cursor to markers
  • Saved with the file, color-coded
