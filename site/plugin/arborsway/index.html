What ArborSway does

ArborSway automates wind animation for GrowFX trees in 3ds Max. Select a tree and click Apply Wind: a Wind Helper is created, Wind Modifiers are added to the paths and everything is linked.

Stiffness and amplitude vary with tree structure, so main trunks stay rigid while thin branches and leaves sway more freely. One floating dialog sets overall intensity, stiffness and speed in place of the modifier stack, and checkboxes can leave out trunks or restrict motion to leaves and flowers, protecting viewport performance. Batch processing handles many trees, a looping toggle recalculates values for seamless loops, and version 2.1 can bake a Point Cache to lighten heavy scenes.

Key features

  • One-click wind setup on GrowFX trees
  • Stiffness and amplitude varied by tree structure
  • Single dialog for intensity, stiffness and speed
  • Batch apply or remove on many trees
  • Looping toggle and Point Cache baking in v2.1
