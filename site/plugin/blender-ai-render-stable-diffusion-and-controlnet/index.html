What Blender Ai Render - Stable Diffusion & Controlnet does

Blender AI Render sends your render and a text prompt to Stable Diffusion with ControlNet through an API, so you get a styled image without local AI software. It needs an account at replicate.com and connects with a token.

Because processing happens online, there are no 40GB models to download, no GPU investment and no complex installs. Styles can include landscapes, sci-fi, watercolor and anime. Documentation is included.

Key features

  • Prompt-based image generation from renders
  • Stable Diffusion and ControlNet via API
  • No local models or GPU needed
  • Connects with a replicate.com token
