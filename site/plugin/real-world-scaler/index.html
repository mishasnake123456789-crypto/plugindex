A Blender add-on that scales any object to its real-world size in one click, with human, animal and vehicle categories.

What Real World Scaler does

Real World Scaler fixes scale mismatches in Blender scenes. One click adjusts an object to its true real-world dimensions while maintaining proportions, which matters for lighting, physics and believable compositions.

It also addresses discrepancies between object mode and edit mode that can cause measurement errors. Base categories cover humans, animals and vehicles, with version 2 adding buildings, trees and fairytale creatures. The interface is intended for all skill levels. Artists combining assets from different sources, or working on archviz and simulation, will find it prevents scale problems.

Key features

  • One-click real-world scaling
  • Preserves real-world proportions
  • Fixes object mode and edit mode discrepancies
  • Categories for humans, animals and vehicles
  • V2 adds buildings, trees and creatures
