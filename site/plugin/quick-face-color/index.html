What Quick Face Color does

Quick Face Color is a lightweight Blender add-on for coloring meshes without opening the material editor. Pick a color and apply it to an entire object or only the faces you have selected.

It works in Object Mode and Edit Mode, and handles material slots automatically, creating and reusing materials based on RGB values so duplicates are avoided. You can choose from a custom color picker or a built-in palette of common colors, and a custom PNG logo can be displayed in the panel. It suits quick blockouts, low-poly stylized models and fast visual separation of parts.

Key features

  • One-click color for object or selected faces
  • Works in Object and Edit Mode
  • Automatic material creation and reuse
  • Custom picker plus built-in palette
