What AEJuice Find Missing Files does

AEJuice Find Missing Files is a script for After Effects that repairs broken footage links. Point it at a folder where the media probably lives and it searches through it, then relinks everything it finds automatically.

Search time rises with the number of files, so it works best when aimed at the most likely folder rather than an entire drive. It integrates with kBar. Artists who receive projects with offline footage can restore them far faster than relinking item by item.

Key features

  • Relinks all missing files in one click
  • Searches a selected folder automatically
  • Best used on the most likely folder
  • kBar integration
