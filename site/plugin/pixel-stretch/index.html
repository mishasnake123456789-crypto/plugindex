What Pixel Stretch does

Pixel Stretch smears pixels in organic, nonlinear ways with subpixel accuracy in After Effects and Premiere Pro. The amount of stretch comes from a luminance curve or from another layer, so you decide which parts of the image streak, and in which orthogonal direction.

Channel modes include Luma, RGBA and each single channel, with variants that ignore alpha. Pixel Size and Pixel Stretch set the base and maximum sizes, and stretch profiles are constant or ramp up or down, adjustable with Curve Phase and Start Offset. Shading overlays have interval, phase, channel and opacity controls, and Transparency Edge Mode with feathering smooths the borders.

Key features

  • Stretch driven by luminance or a separate layer
  • Channel modes: Luma, RGBA, single channels
  • Constant and ramp stretch profiles
  • Shading overlays
  • Transparency edge mode with feather
