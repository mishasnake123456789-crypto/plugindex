A Blender add-on that imports PDFs directly as reference images on planes in the 3D workspace.

What Pdf As Reference does

PDF as Reference brings PDF documents into Blender as reference planes without converting them to image files first. This is handy for blueprints, drawings and design sheets that arrive as PDFs.

Several PDFs can be imported at once, each on its own plane and at its original quality for an accurate reference. A unique material is generated and assigned to each, which prevents conflicts between them. It fits into Blender's existing import menu and includes an automated PyMuPDF installation, with manual setup as an alternative. Modelers working from plans will skip a conversion step.

Key features

  • Imports multiple PDFs onto individual planes
  • Original quality preserved
  • Unique material per PDF
  • Integrates into the import menu
  • Automated PyMuPDF installation
