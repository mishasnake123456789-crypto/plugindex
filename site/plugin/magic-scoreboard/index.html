Generates names with star ratings in Blender for leaderboards and scoreboards, with custom fonts, layouts and star styles.

What Magic Scoreboard does

Magic Scoreboard builds rating displays from a simple list. Add names and star ratings with a + interface and the scoreboard is created automatically.

Any font file can be used with size, bevel and extrusion controls, and the star system and layouts are customizable. Good for ranking graphics, review overlays and leaderboards in motion projects. Because the entries are generated from a list, updating scores only requires editing the list.

Key features

  • Add names and star ratings via a list
  • Any font file with size, bevel, extrusion
  • Flexible star system
  • Layout customization
