What Easy Command Line Batch Render does

Easy Command Line Batch Render turns the Video Sequence Editor into a graphical front end for command-line rendering. Your scenes are turned into .bat and .sh files that run on Windows, macOS and Linux.

A batch file can hold several scenes, formats, resolutions, frame ranges and single frames, and separate files can be merged into one. An overview helps you review the plan. Artists running queued renders on farms or overnight avoid hand-writing commands.

Key features

  • VSE as batch file GUI
  • Cross-platform .bat and .sh output
  • Multiple scenes, formats, resolutions and frame ranges
  • Combine batch files
