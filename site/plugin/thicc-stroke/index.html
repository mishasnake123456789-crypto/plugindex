What Thicc Stroke does

Thicc Stroke is a free plugin that draws strokes whose thickness changes along their length. It can be applied to both masks and shape paths in After Effects, giving more expressive lines than a standard stroke allows.

Width is set by adding as many control points as needed with the feather vertex tool. You can pick butt or round caps and colour the line with two, three or four-colour gradients that loop, or use a custom gradient parameter when more colours are needed. Full trim path controls are included, and trimming can optionally affect width, colour or both. Apple Silicon is supported natively.

Key features

  • Variable width from unlimited control points
  • Works on masks and shapes
  • Butt and round caps
  • 2 to 4 colour loopable gradients plus custom gradient
  • Trim paths that can drive width and colour
