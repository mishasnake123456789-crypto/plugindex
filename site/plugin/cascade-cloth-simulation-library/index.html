What Cascade - Cloth Simulation Library does

Cascade is a library of ready-made cloth simulations for Blender, from Limitless Creative. It contains 37 real-time simulations set up with parameters based on real fabrics, with more planned for the future.

Everything works from Blender's asset browser using drag and drop, and the modular design lets you combine pieces. A bonus pack adds 55 textures. Artists who need draped sheets, flags or curtains can skip building and tuning simulations by hand.

Key features

  • 37 real-time cloth simulations
  • Parameters based on real-life fabrics
  • Drag-and-drop through the asset browser
  • Modular design
  • Bonus pack of 55 textures
