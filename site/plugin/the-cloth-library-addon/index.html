What The Cloth Library Addon does

The Cloth Library Addon provides clothes for Blender characters in two ways: premade garments one click away or sewing patterns linked into the scene and fitted to your character.

A simulation system with its own pattern library uses Blender's internal cloth simulation, and a premade pose mode poses garments to match your model. Character artists can dress figures and let fabric settle realistically. Combining ready garments with patterns offers both a fast route for quick dressing and a deeper route for those who want to customize how the fabric is constructed.

Key features

  • Premade garment library
  • Sewing pattern library for cloth sim
  • Premade pose mode
  • Fitting to your character
