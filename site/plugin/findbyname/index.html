3ds Max utility that shows an object's parent groups from its name, to find items inside closed or nested groups.

What FindByName does

FindByName helps locate objects that are hidden away inside closed or nested groups in 3ds Max. Type the object's name and the utility displays its parents, revealing where it lives in the hierarchy.

It runs as a utility script, is currently at version 0.1, and has a demo video on YouTube. The tool is free. Scenes built from imported CAD data or assembled from many group levels can make finding a specific item awkward, and a name-based lookup that reports parents makes it straightforward.

Key features

  • Displays an object's parents from the name entered
  • Finds objects inside closed or nested groups
  • Utility script inside 3ds Max
  • Version 0.1
  • Demo video on YouTube
