What Dynamic Render Border | SE does

Dynamic Render Border, by steveernst117, sets up render borders that change during an animation, so only the region that matters is rendered each frame. It is tagged under Render and Animation.

The add-on is open source under GPL-3.0-or-later and needs Blender 4.2.0 or newer.
