A Blender add-on that exposes the active object's main data, such as camera, light and render settings, in one place.

What Add On The Fly does

Add On The Fly provides quick access to the main data of whatever object is active in Blender, including camera, light, mesh, curve, empty, text and render settings. Instead of navigating through tabs, you reach the properties you need directly.

It can turn a light on or off while keeping it visible in the viewport, currently for Cycles only. A Modal Light function sets main light parameters interactively, with color available through the modal when using Photographer, and camera main parameters can also be set. Artists who adjust lights and cameras often will save repeated clicking.

Key features

  • Reaches camera, light, mesh, curve, text and render data
  • Manages properties of the active object
  • Light on/off while remaining visible in the viewport
  • Modal Light for quick parameter changes
