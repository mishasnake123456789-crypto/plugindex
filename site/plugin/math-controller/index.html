Blender add-on with a formula-driven math node that builds a network of math nodes across node editors.

What Math Controller does

Math Controller adds a node to Blender that evaluates a formula you type, generating the network of math nodes behind the scenes. It is usable in four node editors: Shader, Geometry, Compositor and Texture.

Variables used in a formula appear as input sockets and disappear when unused or disconnected. Fields are named f1, f2 and so on and can be used in other fields. An Advanced Formula Editor helps with long expressions by showing parenthesis nesting and a function list covering arithmetic, comparison, rounding, trigonometry and conversion. A button generates a synchronized standard node group.

Key features

  • Type formulas instead of wiring math nodes
  • Works in Shader, Geometry, Compositor and Texture editors
  • Automatic variable sockets
  • Advanced Formula Editor
  • Generate Node Group button
