What Edge Crease & Bevel Weight Pie Menu does

This add-on gives edge crease and bevel weight controls a place in a pie menu in Blender, so subdivision and bevel prep needs fewer trips through the menus. It triggers the default crease or bevel weight tool, sets values to one or zero, and applies predefined values.

Edges can be marked or unmarked as sharp, and the tool chooses vertex crease or edge crease depending on selection mode. A bevel modifier can be added from the pie with its limit method set to weight, along with controls for basic settings. Hard-surface and subdivision modelers will work more quickly.

Key features

  • Pie menu for crease and bevel weight tools
  • Preset values and zero or one shortcuts
  • Mark and unmark sharp edges
  • Automatic vertex or edge crease
  • Adds bevel modifier limited by weight
