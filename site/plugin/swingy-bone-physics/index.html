What Swingy Bone Physics does

Swingy Bone Physics adds secondary motion to rigged parts in Blender. Hair, accessories, loose cloth, wires and similar chains can be set up as simulated bones with a single click, avoiding hand-keyed follow-through.

Collision volumes can be tied to bones and several colliders added at once, while physics parameters can be edited across many selected bones together. Amplitude constraint profiles shape how far each part of a chain is allowed to swing. Character animators and riggers will find it useful for adding natural, physically based movement.

Key features

  • One-click physical bone chain creation
  • Bone-tied collision volumes
  • Parameters editable across multiple bones
  • Amplitude constraint profiles
