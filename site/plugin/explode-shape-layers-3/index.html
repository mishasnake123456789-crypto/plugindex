What Explode Shape Layers 3 does

Explode Shape Layers 3 is a Zack Lovatt script for working at a finer level with shapes. It splits a shape layer into individual layers and merges them again, giving more precision when animating parts.

A CONVERT action turns text layers into shape layers, and the script works with nested shape groups. You can choose whether EXPLODE affects top-level fills and strokes, and whether CONVERT also removes the artboard. Headless buttons and kbar argument support allow custom toolbars. Artists preparing vector artwork or Illustrator imports for animation will save much manual separation.

Key features

  • Explode shape layers and merge them back
  • CONVERT text layers to shape layers
  • Works with nested shape groups
  • Toggle options for fills, strokes and artboard removal
  • Headless buttons and kbar arguments
