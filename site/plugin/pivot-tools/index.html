What Pivot Tools does

Pivot Tools is a Blender add-on by Quinzy for quick, accurate pivot placement. Auto Pick lets you click geometry to put the pivot there, Bounding Box targets put pivots at familiar spots, and Saved Pivots stores positions for reuse across objects.

The workflow is non-destructive, so objects are not transformed unintentionally. It works in Object and Edit Mode and uses a compact panel in the N-panel. It helps when modeling, blocking out scenes or preparing assets for export.

Key features

  • Auto Pick pivots by clicking geometry
  • Bounding box snap targets
  • Saved pivots reusable across objects
  • Non-destructive, no unintended transforms
  • Object and Edit Mode support
