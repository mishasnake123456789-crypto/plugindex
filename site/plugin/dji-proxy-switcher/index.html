What DJI Proxy Switcher does

DJI Proxy Switcher is a Blender plugin for the Video Sequence Editor that makes editing drone footage lighter. DJI cameras produce small LRF proxy files, and this add-on lets you cut with those, then replace them with the full-resolution MP4s before export.

The swap works in both directions with one click and corrects scale automatically. You can process all clips or only selected ones, and a live counter shows how many clips are affected. The interface is available in English and French.

Key features

  • One-click swap between LRF proxies and MP4s
  • Works in both directions
  • Automatic scale correction
  • All clips or selection only
  • English and French interface
