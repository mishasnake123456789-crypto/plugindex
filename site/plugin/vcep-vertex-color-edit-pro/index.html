A Blender add-on for editing vertex colors in edit mode, with copy, paste and average color functions.

What Vcep - Vertex Color Edit Pro does

VCEP lets you adjust vertex colors in Blender without switching to a paint mode. Working directly in edit mode, you change the colors of selected vertices, faces or edges and see the result update live.

Colors can be set for the whole selection, copied from one vertex or face and pasted to another, and both the face corner and vertex domains are supported, as are byte and float color types. Version 1.1 added getting the average vertex color. Game artists using vertex colors for masks and tinting will find it more precise than brushing.

Key features

  • Live vertex, face and edge color editing in edit mode
  • Copy and paste vertex colors
  • Face corner and vertex domains
  • Byte and float color support
  • Average vertex color tool
