Blender add-on that exports mesh scenes into Defold projects as .glb, .model, .go and .collection files.

What Reforge does

Reforge, by Alexander-Bulatov, moves Blender scenes into the Defold game engine. Each mesh object becomes a .glb file plus a .model file, with .go prefabs and .collection scenes that preserve grouped instances.

Optional convex collision shapes can be exported and textures can be copied into the Defold project folder. Developers who block out levels in Blender can reduce manual setup in the engine.

Key features

  • Exports .glb, .model, .go and .collection files
  • Grouped instances preserved
  • Optional convex collision export
  • Texture copying into the project
