What Browser To Blender In 2 Clicks does

Browser To Blender sends images from the web straight into your active Blender scene. An instant bridge handles the transfer in two clicks.

Reference Mode loads the image as an Empty Object for modeling references and blueprints, Plane Mode creates a textured flat mesh, and the image can also be applied as a material's Base Color. Saves downloading and importing files manually. Among its tools are two-click online image transfer and reference Empty mode.

Key features

  • Two-click online image transfer
  • Reference Empty mode
  • Textured plane mode
  • Apply as Base Color
