What Clay Switch does

Clay Switch is a macro by dangtiendung that flips the 3ds Max viewport between Clay and Default Shading modes. It makes comparing a model's pure form with its textured look instant.

The small clay_switch.mcr file adds a command to Customize User Interface in the D95 DESIGN category. In the Hotkey Editor it is listed as Clay Switch, so it can be bound to any key you prefer. Modelers and visualization artists who often check topology or lighting in a neutral material can use it to avoid menu trips.

Key features

  • Switches between Clay and Default Shading
  • Small clay_switch.mcr macro
  • Found under the D95 DESIGN category
  • Listed in the Hotkey Editor for keyboard binding
