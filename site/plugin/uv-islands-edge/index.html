What UV Islands Edge does

UV Islands Edge draws and analyzes the outlines of UV islands in Blender. It adds a heatmap view and handles UDIM tiles, making it easier to judge how islands are laid out.

Packing options are included too, so you can organize islands without leaving the same tool. Texture artists who juggle multiple UDIM tiles or want a clear overview of UV density will find it useful.

Key features

  • UV island contour display
  • Heatmap visualization
  • UDIM tile support
  • Island packing
