Shifts selected points or whole objects a chosen distance along the direction between two picked points in 3ds Max.

What Distance Shift does

Distance Shift by rusttm moves geometry along a direction you define with two points. It first measures the length between the two selected points, then shifts selected points or whole objects by a distance you provide, measured from the first point.

It works with both Editable Poly and the Edit Poly modifier. Undo works on all input values, and a right-click cancels the operation after the distance selection buttons are pressed. This gives modelers precise, vector-based nudging that is hard to achieve with ordinary move tools, such as offsetting parts exactly along an edge or an angled line.

Key features

  • Measures the length between two picked points
  • Moves points along the vector by a set distance
  • Works with Editable Poly and Edit Poly
  • Moves whole objects along a vector
  • Undo support and right-click cancel
