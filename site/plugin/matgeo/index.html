What MatGeo does

MatGeo links shader node groups to geometry nodes in Blender. It converts a material's Shader Node Group into Geometry Nodes and syncs the group inputs with attributes, which enables material instancing and togglable material application.

Groups on the same material share a single Geometry Node setup, whereas those on another material get their own. Socket properties like description, subtype, default value and min or max carry over to modifier panel parameters for float, integer, boolean, vector and color types. Image textures are not supported yet. Context menu operators convert, update and revert, with warnings for empty or duplicate groups.

Key features

  • Converts Shader Node Groups to Geometry Nodes
  • Inputs synced with stored attributes
  • Socket settings shown in the Modifiers panel
  • Convert, update and revert operators
  • Result works without the add-on installed
