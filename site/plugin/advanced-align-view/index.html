What Advanced Align View does

Advanced Align View from 1P2D keeps your viewport square to what you are modeling, which is hard to do with the default tools on rotated or complex objects that are not aligned to the world axes.

Several modes are available: a legacy Custom mode, 3D Cursor, Selection, based on the active object or chosen Edit Mode geometry, and Advanced Edge Align, which lines the view up with a selected edge. This helps precision modelers who need orthographic-style views of arbitrary surfaces.

Key features

  • Align to selected geometry or active object
  • Align to the 3D cursor
  • Custom orientation mode
  • Advanced Edge Align for a selected edge
