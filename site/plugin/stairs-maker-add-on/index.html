What Stairs Maker Add-On does

Stairs Maker is a button-driven stairs and railings builder for Blender. It applies a Geometry Nodes modifier to the selected object behind the scenes, so no node knowledge is needed.

Customizable options sit in the 3D Viewport side panel, letting you change dimensions and style after the stairs are created. Architectural modelers and game environment artists can generate staircases and railings quickly and adjust them as a layout evolves. Because the underlying modifier remains, you can continue adjusting step count, height and railing details after the first build.

Key features

  • One-click stairs or railings from any object
  • Geometry Nodes modifier applied automatically
  • Options in the 3D Viewport side panel
  • No Geometry Nodes experience needed
