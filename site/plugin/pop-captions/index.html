What POP Captions does

L22Design's POP Captions is a tool built for After Effects aimed at adding energetic, word-by-word caption animation. Select a text layer, click, and the captions pop onto the screen, with every control kept together on a single layer.

Font and font size are synced between the text and its background layer, so the backing shape never needs separate edits. One checkbox works out how many words should pop based on the word count of your text, and another decides whether the caption background animates. Background and text colors can each be set independently, which makes it quick to match a brand palette for social video.

Key features

  • One-click pop animation for text layers
  • All controllers on a single layer
  • Font and size synced with background layer
  • Auto word count calculation
  • Separate background and text colors
