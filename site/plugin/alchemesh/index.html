What Alchemesh does

Alchemesh is a Blender add-on for producing several 3D characters or models from shared assets. Its bone retargeting and mesh deformation are powered by the PyGem library, which helps when one outfit has to fit several different bodies.

Multiple armatures and meshes can be transformed in one pass. Vertex weights and shape keys transfer between meshes so deformation and facial expressions stay consistent. Character artists and game developers who build large casts from a base model are the main audience.

Key features

  • Transform several armatures and meshes at once
  • Retargets bones using the PyGem library
  • Vertex weight transfer between meshes
  • Shape key transfer keeps expressions intact
