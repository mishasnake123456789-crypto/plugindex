Blender add-on that swaps the interface theme from a dropdown panel in the 3D Viewport.

What Theme Changer Addon does

Dhaval's Theme Changer Addon spares you a trip into Preferences when you want a different Blender look. A panel in the 3D Viewport contains a dropdown, and choosing a theme applies the preset instantly.

Looks on offer carry names like Graphite, Amethyst, Choco Mint, Han Purple, Piano White and Steel. It installs via Blender's Add-ons preferences and comes with documentation. Useful for artists who like adjusting the interface to taste or lighting conditions. Changing themes does not affect your scene, only the interface colors you see while working.

Key features

  • Panel in the 3D Viewport
  • Theme dropdown
  • Instant preset application
  • Graphite, Amethyst, Choco Mint and more
  • Documentation included
