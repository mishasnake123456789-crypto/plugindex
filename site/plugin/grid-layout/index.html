What Grid Layout does

Grid Layout is a Blender add-on by Hodgson3d that helps with UV arrangement, especially on high-resolution assets that span many UDIM tiles. Its tools arrange UVs, adjust texel density, and move and select them.

UnStack sorts the UVs of repeated objects into vertical columns, shifting sideways as each column fills and spilling into the next UDIM once a tile is full; padding can be set for both tiles and islands. Stack reverses this by piling the UVs together so global edits are easy, and Shift UVs relocates large numbers of UDIM tiles within UDIM limits.

Key features

  • UnStack lays out repeating objects by columns
  • Continues into the next UDIM tile automatically
  • Stack for global adjustments
  • Shift UVs across many tiles
  • Tile and island padding controls
