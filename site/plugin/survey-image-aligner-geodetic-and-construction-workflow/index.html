What Survey Image Aligner - Geodetic & Construction Workflow does

Survey Image Aligner positions image planes so that they match measured data. Using two known reference points, it rotates, scales and translates an image to line up in world coordinates.

It calculates the transformation needed to bring the image onto the XY plane and works non-destructively on existing image planes. Site plans, scanned drawings and aerial photographs can be georeferenced inside Blender for modeling over them. The same approach suits scanned plans, site photographs and sketches that need to line up with measured coordinates.

Key features

  • Two-point image alignment
  • Rotation, scale and translation in world coordinates
  • Calculates alignment to the XY plane
  • Non-destructive on existing images
  • Built for survey workflows
