What Import-Export 3D Manufacturing File (.3Mf) does

This add-on gives Blender support for the 3D Manufacturing Format, a file type used widely in 3D printing software. Importing preserves the full object hierarchy, transforms and components, and imported objects are sorted into collections, with an option to merge everything into one mesh.

Exporting can cover selected objects or the whole scene, with the choice to apply modifiers during export. That makes moving models between Blender and slicers or printing tools much smoother than using older formats. Makers, product designers and 3D printing hobbyists will find it useful.

Key features

  • Imports 3MF with hierarchy preserved
  • Optional merge into a single mesh
  • Imported objects organized into collections
  • Exports selected objects or the whole scene
  • Option to apply modifiers on export
