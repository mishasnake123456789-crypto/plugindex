Two-part add-on linking Blender and Substance Painter to sync meshes, materials and project files on Windows.

What Bl2Sp2Bl(Blender Connect Substance Painter) does

Bl2Sp2Bl connects Blender with Substance Painter through two components: Bl2SP installs in Blender and SP2Blender goes into Substance Painter's plugins folder. It is intended for Windows users.

Meshes can be exported from Blender, materials and meshes synced both ways, HDRI changed and project files connected. A layer effect uses Base Color, Opacity and Emission channels in Painter. Principled BSDF mode, Only Export Collection mode and sub-collections are supported, and a 2026 update added automatic bakes in Substance Painter.

Key features

  • Export meshes from Blender to Substance Painter
  • Material and mesh sync
  • Principled BSDF and collection export modes
  • HDRI change and project file connection
  • Automatic bake in Painter
