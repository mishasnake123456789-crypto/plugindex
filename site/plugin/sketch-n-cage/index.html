Blender tool that turns Grease Pencil sketches into cage deformers with auto-generated shape keys for mesh and shape animation.

What Sketch N' Cage does

Sketch N' Cage lets you deform objects by drawing. Draw any shape with Grease Pencil and it becomes a cage object that drives mesh or surface deformation, with shape keys created automatically.

Cage shapes can be edited interactively in real time, and a mute button returns you to the sketch to make changes. Animators and modelers get a quick sketch-driven way to bend, squash and animate forms.

Key features

  • Grease Pencil sketches become cage objects
  • Automatic shape key creation
  • Real-time cage editing
  • Mute toggle to go back to the sketch
