What Slothnodevault - Personal Node Group Library does

SlothNodeVault stores node groups for reuse. Every group is stored as a separate .blend file with a name, category and tags, saved right from the Node Editor.

Items can be loaded into the current node tree or located by searching, and Dropbox and iCloud syncing are included. Great for building a toolbox of favorite node setups. Syncing means the library can follow you between computers, so favorite node setups are always available. Dropping a saved group into a new file is a matter of searching for it and loading, rather than rebuilding it.

Key features

  • Geometry, Shader and Compositor node groups
  • Name, category and tags
  • Search and load into active tree
  • Dropbox and iCloud sync
