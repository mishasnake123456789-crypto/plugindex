What Time Tracker 4 Blender does

Time Tracker 4 Blender lets freelancers record work time without leaving the application. The workflow has three steps: track time, enter task information, save times.

Task name, client and cost are stored, cost is calculated for you, recorded times can be viewed in the add-on, and exports go to CSV or JSON. Tools sit in the preferences dropdown and can be used in a separate window. Highlights include three-step time logging, task, client and cost details and automatic cost calculation.

Key features

  • Three-step time logging
  • Task, client and cost details
  • Automatic cost calculation
  • CSV and JSON export
