What Sheetah - Spritesheet Tools does

Sheetah - Spritesheet Tools turns an After Effects composition into one spritesheet image with a single button. Output formats are PNG, TGA and TIF, all with alpha channel, and it works out the best sheet dimensions.

A dockable panel remembers your settings, and Animation Tools help create custom animation sequences that can be exported as a text file. An optional Photoshop script converts image sequences and movies into spritesheets. Game developers and animators preparing assets for engines get a faster pipeline from timeline to sheet.

Key features

  • One-button spritesheet export
  • PNG, TGA and TIF with alpha
  • Calculates optimal sheet dimensions
  • Animation Tools with .txt export
  • Optional Photoshop script
