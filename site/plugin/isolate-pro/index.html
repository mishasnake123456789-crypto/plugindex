Isolates selected objects in the Blender viewport while keeping the active selection and a list of always-visible objects.

What Isolate Pro does

Isolate Pro focuses the viewport on what you are working on. Selected objects are isolated instantly, cutting visual noise during modeling, lighting or layout.

The Active button preserves your selection state when changing the active object, and you can designate objects that always stay visible. Handy in crowded scenes. It is particularly handy when working on one asset inside a busy scene full of other objects. Because the selection state survives, you can hide the rest of the scene temporarily and carry on without losing your place.

Key features

  • Instant viewport isolation
  • Selection state preserved
  • Always-visible objects list
