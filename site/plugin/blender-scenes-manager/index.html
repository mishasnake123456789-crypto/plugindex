What Blender Scenes Manager does

Blender Scenes Manager collects scene, view layer and collection controls in one place. Its key idea is that you can change settings on a different scene or view layer without making it the active one.

You can switch between scenes and view layers, reorder view layers, and create a new view layer from selected objects or the active collection. Compositors and artists working with multi-layer renders in large projects avoid constant context switching.

Key features

  • Edit scene options without switching scenes
  • Edit view layers without making them active
  • Reorder view layers
  • Create view layers from selection or collection
