What OffVoice Marker does

OffVoice Marker is an assistant panel that reads written edit notes and converts them into markers on the timeline. It understands single points, ranges, entries with several timecodes and dash syntax.

Markers are color-coded by label, with yellow for regions that can be muted automatically and red for items that need a person to look. A review card has previous and next buttons, arrow-key shortcuts, Space to play, and clickable rows, with an indicator that follows the current item. The panel also inserts room tone in bulk across muted audio regions, helping dialogue editors clean up speech tracks.

Key features

  • Converts text notes into timecode markers
  • Handles points, ranges and dash syntax
  • Yellow and red marker coding by review need
  • Review card with keyboard shortcuts
  • Bulk room tone insertion in muted regions
