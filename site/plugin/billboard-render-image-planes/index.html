What Billboard Render - Image Planes does

Billboard Render - Image Planes swaps heavy objects for flat textured planes. With an object selected, pressing the Render button renders it and creates a rectangular plane placed so it appears the same from the camera's point of view.

In Cycles the render becomes the plane's texture, and only the chosen objects appear in it. The result is an ordinary Blender object with a regular material and image texture, so you can keep editing it freely afterward. The technique cuts scene complexity for distant elements and other cases where a 3D version is overkill.

Key features

  • One-click Render in the BillboardRender tab
  • Plane matches the object from camera view
  • Cycles render isolates the selected objects
  • Result is a normal editable plane, material and texture
