Quickclick

Developer: Vaguely Butter

FreeBlender

A Blender add-on that changes interaction modes with double-clicks: edit, pose or texture paint.

What Quickclick does

Quickclick lets you change object modes in Blender using the mouse rather than keyboard shortcuts or the mode dropdown. Double-click an object to enter edit mode, Alt plus double-click for pose mode, and Shift plus double-click for texture paint mode.

The add-on supports Blender 2.83, 2.9x and 3.0, is released under the GPL and includes documentation. Artists who move between modes often, especially those who prefer to keep a hand on the mouse or tablet pen, will find it cuts out the keyboard trips.

Key features

  • Double-click to enter edit mode
  • Alt + double-click for pose mode
  • Shift + double-click for texture paint
  • Blender 2.83 to 3.0
