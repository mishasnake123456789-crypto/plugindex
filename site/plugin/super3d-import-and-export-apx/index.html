What Super3D Import & Export .Apx does

Super3D Import & Export .Apx opens NVIDIA APEX physics asset packages inside Blender. Dedicated File menu entries handle import and export, with conversion carried out on the Super3D cloud service.

Blender stays lightweight and no NVIDIA APEX or PhysX installation is needed locally. On import the file is uploaded to the service for conversion. It is useful for artists working with older game physics assets who need to inspect or reuse their geometry.

Key features

  • File menu entries for .apx import and export
  • Cloud conversion via Super3D
  • No APEX or PhysX install needed
