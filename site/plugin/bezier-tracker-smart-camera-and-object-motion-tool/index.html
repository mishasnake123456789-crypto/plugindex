What Bezier Tracker - Smart Camera & Object Motion Tool does

Bezier Tracker takes any keyframed animation in Blender and converts it into a Bézier curve with one click. The result is a visible motion path you can edit and reuse, instead of a tangle of keyframes.

Once the path exists, an object or camera can be animated along it, with control over speed, direction and orientation. That makes it handy for cinematic camera moves, flying objects and general motion design, where reshaping a curve is far quicker than retiming individual keys. Documentation and a demo video come with it.

Key features

  • Converts keyframed animation to a Bézier curve in one click
  • Visible, editable and reusable motion path
  • Animates any object or camera along the path
  • Control over speed, direction and orientation
  • Documentation and demo video included
