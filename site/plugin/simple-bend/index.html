Blender add-on that bends subdivided meshes by dragging an on-screen axis, with an Edge Axis mode.

What Simple Bend does

Simple Bend makes bending meshes direct in Blender. After adding edge loops or subdividing and selecting faces, you drag a yellow axis shown on screen to bend the geometry.

Edge Axis mode takes the two most recently selected edges, which cannot lie on one line, as the bend axis and direction for custom angles. Pressing C bends only the selected part while connected geometry follows, and on-screen keys control additional options. Modelers curving pipes, cables, paper or panels avoid setting up deform modifiers.

Key features

  • Drag an on-screen axis to bend
  • Edge Axis mode for custom angles
  • Bend only a selected part with C
  • On-screen key controls
