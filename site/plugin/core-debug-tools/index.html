What Core Debug Tools does

Core Debug Tools, by JacquesLucke, is intended for people working on Blender's own code. With one click it visualizes dependency graph relations and the lazy-function graphs behind geometry nodes.

A bundled dot graph viewer needs only a web browser, and the operators build temporary HTML files to display results. They are found under Topbar, Help, Debug and in the Node Editor under Node, Debug. A Blender build newer than 2024-09-14 is required.

Key features

  • One-click dependency graph visualization
  • Lazy-function graph view for geometry nodes
  • Bundled browser-based dot viewer
  • Operators in Help and Node Editor menus
  • Needs Blender build newer than 2024-09-14
