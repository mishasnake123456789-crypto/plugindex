A Blender add-on that builds procedural windows from faces, cutting matching holes in walls.

What Window Maker Add-On does

Window Maker builds windows on any object's faces in Blender with one click, following the shape of each underlying face. Settings are managed in the BB Windows panel in the 3D Viewport, so changes happen right where you are modeling.

Three modes are provided: Multiple Window, Double Wing Window and Fixed Window. Holes in a wall object, or a collection of wall objects, are created automatically as windows are added and update when windows are moved or resized. Architects and visualization artists blocking out buildings will save time on repetitive window openings.

Key features

  • Procedural windows from any face
  • Multiple, Double Wing and Fixed window modes
  • Automatic wall holes that update with the window
  • Controls in the BB Windows panel
