What Eyelashes & Eyebrows Generator does

Dean Zarkov's Eyelashes & Eyebrows Generator is a procedural Blender tool. Select a line of mesh along the lid or brow and the tool grows eyelashes or eyebrows from it, so you avoid modeling each hair arrangement for every character.

Both node groups can be imported and edited from a tabbed interface panel, giving you control over style. The result uses the material assigned in the object's properties, includes a generated UV map, and a Fix Twisting button corrects twisted lashes. It is distributed under the MIT license.

Key features

  • Procedural eyelashes and eyebrows via Geometry Nodes
  • Built from any selected mesh line
  • Tabbed panel to import and edit node groups
  • Generated UV map
  • Fix Twisting button for the lash generator
