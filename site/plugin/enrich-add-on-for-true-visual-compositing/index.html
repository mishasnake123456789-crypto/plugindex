What Enrich - Add-On For True Visual Compositing does

Enrich is a Blender add-on from Akash Hamirwasia that provides a layer-based compositing experience, cutting down the node setup normally required for each effect. You focus on the look you want while it builds a readable node tree automatically.

Effects such as Mist, Vignette and color grading have dedicated controls and can be stacked. Masks based on Cryptomatte restrict an effect to chosen colors. Ready-made presets modeled on filters from well-known photo apps can be combined, and your own node setups can be saved as presets.

Key features

  • Stackable effects with dedicated controls
  • Cryptomatte-based masks
  • Presets inspired by photo-editing filters
  • Save your own setups as presets
  • Automatically builds an understandable node tree
