What Instant Stairs does

Instant Stairs is a Blender addon by kitfox.com that adds two options to the Add Mesh menu for making staircases. After setting a few parameters, you get straight or spiral stairs in a few clicks.

Soft maximum limits let you go beyond 100 steps and use large values in other fields. Documentation is included, it works with Blender 2.8 up to 4.0, and it is distributed under a Creative Commons license. Good for quickly adding a regular, evenly measured staircase to an architectural or game scene.

Key features

  • Two staircase options under Add Mesh
  • Straight or spiral stairs
  • Soft limits allow more than 100 steps
  • Works with Blender 2.8 to 4.0
  • Documentation included
