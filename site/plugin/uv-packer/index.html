What UV-Packer does

UV-Packer from 3d-io arranges unwrapped polygons into UV sheets with one click. It was built for high-polygon assets and thousands of UV clusters, packing them with minimal wasted area and no overlaps while keeping padding exact.

It can pack several objects together independently of resolution, uses multithreading, and supports UV tiles. The interface is customizable with MAXScript support, documentation and statistics, and an SDK library is offered for developers. Game studios, archviz teams, photogrammetry operators and industrial designers can use it to speed up texture layout.

Key features

  • One-click packing with minimal waste
  • Exact padding and no overlaps
  • Multi-object, resolution-independent packing
  • Multithreading and UV tile support
  • MAXScript support and SDK library
