What Easeam 2 - Fast Uv Seam Marking Toolkit does

Easeam 2 is a Blender plugin for marking UV seams without leaving the 3D View. Modal tools preview what will be marked as you hover, including edge loops, flat region boundaries, tube-like forms and shortest paths between two vertices.

One-shot operators work from your selection for flat regions and loop seams, and UV utilities manage maps and run unwrap actions. A good fit for texture artists preparing many models. Hover previews let you see the outcome before committing, which cuts trial and error when preparing complex models for unwrapping.

Key features

  • Modal seam tools with hover previews
  • Shortest-path seams between vertices
  • One-shot selection operators
  • UV map management utilities
