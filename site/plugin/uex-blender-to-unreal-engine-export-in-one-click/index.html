What Uex - Blender To Unreal Engine Export In One Click does

UEx is a Blender add-on for moving assets into Unreal Engine without fuss. It exports any number of objects as separate FBX files, detects asset types automatically, and avoids scaling and import errors.

Animations are exported as their own files, and LODs, sockets and collisions follow Unreal naming conventions so assets can be dragged straight in with no settings changes. Selection sets group objects for repeated exports, origin adjustment resets mesh or armature location, and a clipping adjuster updates all workspaces after a unit scale change.

Key features

  • Batch FBX export with asset type detection
  • Separate files for assets and animations
  • LOD, socket and collision naming for Unreal
  • Selection sets for repeat exports
  • Origin and clipping distance adjustment
