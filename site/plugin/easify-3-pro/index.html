What Easify 3 Pro does

Easify 3 Pro helps animators refine the timing of keyframes. In After Effects it applies, copies and pastes Bezier easing on keyframes, and it brings a graph editor for animation into Premiere Pro, where such a tool is otherwise limited.

The Pro version can combine Bezier curves with mathematical curves. Preset libraries can be created, imported and exported without a limit on presets. Useful actions include moving keyframes to the playhead, mirroring a curve, roving across time and reversing keyframes in time. Spell Book integration enables keyboard shortcuts, and the interface is flexible.

Key features

  • Bezier easing applied, copied and pasted on keyframes
  • Premiere Pro gets its own graph editor
  • Pro: mix Bezier and mathematical curves
  • Unlimited preset libraries, importable and exportable
  • Mirror, rove, reverse and move keys to playhead
