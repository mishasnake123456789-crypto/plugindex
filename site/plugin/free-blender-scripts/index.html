What Free Blender Scripts does

Free Blender Scripts from ThreeDee bundles fifteen small utilities aimed at the repetitive parts of scene management. Several deal with the Outliner: sorting collections and objects alphabetically, deleting empty collections and toggling visibility with one click.

Others handle naming and transforms, such as adding prefixes or suffixes, batch renaming by type, applying transforms across a collection, moving objects to the origin and aligning to the active object. There are also tools to keyframe objects appearing one at a time, convert curves to meshes, apply all modifiers in bulk, generate simplified LODs and select by shared material.

Key features

  • Sort collections and objects alphabetically
  • Batch rename by prefix, suffix or object type
  • Apply transforms and align objects across a collection
  • Sequential visibility keyframer
  • LOD generation and bulk modifier application
