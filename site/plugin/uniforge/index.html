What Uniforge does

UniForge moves assets from Blender into Unity without repeated FBX round trips. One click exports meshes, materials and shader node setups into a self-contained .unif file with textures embedded, and dropping that file into Unity builds a prefab, meshes and materials automatically.

PBR materials map onto Unity's Lit shader, and procedural nodes such as Noise and Color Ramp are baked to textures. Multiple objects keep their hierarchy and transforms, and multi-material meshes are supported. The flow also works in reverse, since a .unif can be imported back into Blender. A built-in ambientCG CC0 browser lets you search and apply free materials with a tiling configurator.

Key features

  • One-click export to a self-contained .unif file
  • Auto-import in Unity creates prefab, mesh and materials
  • PBR materials mapped to Unity's Lit shader
  • Procedural nodes baked to textures
  • Import .unif back into Blender
