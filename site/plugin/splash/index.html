What Splash does

Plugin Play's Splash is a plugin built for After Effects that grows liquid shapes from your layers. Blobs and trails are created procedurally, with fine control over how the fluid looks and behaves, and it works with After Effects from CC 2017 through 2025.

A Speed Threshold setting ties splash generation to how fast an object is moving, while Gravity Angle sets the direction liquid falls, with a Manual Mode and its own direction angle. Default presets can be restored, and the interface supports languages other than English. It is useful for fluid logos, paint-like motion and playful transitions.

Key features

  • Procedural liquid trails and blobs
  • Speed Threshold ties splashes to motion
  • Gravity Angle and Manual Mode
  • Restorable default presets
  • Non-English language support
