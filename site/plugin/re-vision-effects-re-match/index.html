What RE:Vision Effects RE:Match does

RE:Match transfers the colour and tonal character of one image to another in After Effects, DaVinci Resolve and Premiere Pro. It helps fix mismatches that come from multicamera and stereo shoots, and also pre-grades clips to simplify the colour workflow.

Matching can use the full frame or part of it, at any moment in time. A Colour Correction Dissolve blends between reference frames along the timeline, and stills can be references. Corrections can be reused by copying the plugin to another clip. It handles over-bright values and HDR ranges, and several cuts in a sequence. RE:Match Pro adds optical-flow registration and occlusion handling for stereo pairs.

Key features

  • Automatic colour matching between takes or cameras
  • Match whole image or a region
  • Colour Correction Dissolve between references
  • Reusable stored corrections
  • Pro: optical-flow registration for stereo
