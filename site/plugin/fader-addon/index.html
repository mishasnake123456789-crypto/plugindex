A Blender add-on that sets object transparency with a slider to reveal interiors or fade parts.

What Fader Addon does

Fader Addon controls how transparent one or more objects appear in Blender. It is useful when you need to see inside a model, reach hidden parts for editing, or render a gradient of visibility, and a single Fader Strength slider sets the level.

The Object Fader button creates a material if there is none, or applies fifty percent transparency while keeping an existing one. Multi Object Fader handles several selections with individual strength values and resets when pressed again. A Fade All Materials option affects every material on an object, and a separate color can be shown in solid mode without altering the material.

Key features

  • Fader Strength slider for transparency
  • Object Fader creates or reuses a material
  • Multi Object Fader with per-object strength
  • Fade All Materials option
  • Solid mode color that leaves the material untouched
