Converts shape paths into animated waves in After Effects, with randomised length, height and roundness.

What Tilda does

Tilda is an After Effects plugin by Denis Mozgovoy that takes a shape path and turns it into a wavy, moving line. It accepts both Bézier and parametric paths, the latter without needing conversion since version 1.3.

A Random tab brings irregularity to wave length, height and roundness, while wave speed is set in pixels per second and stays independent of wavelength. The Same Path creation mode keeps an expression pointing at itself even when paths are duplicated. Motion designers building water lines, squiggly borders or animated outlines from existing shapes can get organic movement without hand-keying.

Key features

  • Converts any shape path into moving waves
  • Bézier and parametric path support
  • Random tab for length, height and roundness
  • Wave speed in pixels per second
