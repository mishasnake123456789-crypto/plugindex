Scripted 3ds Max modifier built on XForm that scales single objects, multiple objects or groups to exact real-world sizes.

What Rapid Resize Modifier does

Rapid Resize Modifier extends the XForm modifier in 3ds Max so objects can be brought to precise real-world dimensions without destructive changes. It applies to a single object, a selection of several, or groups, which helps when imported models arrive at the wrong size.

The pivot anchor for scaling can be set at any of 27 positions around the bounding box, without altering the object's own pivot, and spinners fine-tune that anchor. With one object, scaling follows its local bounding box; with several, it follows their combined world bounding box. Because it stays in the modifier stack, the size remains editable later.

Key features

  • Non-destructive scaling to exact real-world dimensions
  • Handles one object, several objects or groups
  • 27 anchor positions around the bounding box
  • Spinners to fine-tune the anchor point
  • Local bounding box for one object, world box for many
