What 2DFbend does

Built by 2DeadFrog, 2DFbend is a tool running inside After Effects that bends flat layers. It cuts a layer into slices and arranges them along a curve, producing smooth bends, rings and more intricate curved structures.

The process takes three steps: select a layer, choose the number of segments, and click Apply. You can reapply later to change the segment count, and more than one bend can be stacked on a single layer. Additional options sit in the effect panel and interface settings. Motion designers get a fast, precise route to curved typography and warped graphics.

Key features

  • Three-step select, segment, apply workflow
  • Smooth bends and circular layouts
  • Reapply to change the segment count
  • Multiple bends on one layer
