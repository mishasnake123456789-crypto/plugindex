What Shotpath does

ShotPath is a camera workflow add-on that covers the process from blocking to final render in a single N-panel. For path rigs you drop shot markers in the viewport and it builds a smooth path through them, which you can reorder, nudge and retime without rebuilding the move.

Preset rigs cover Orbit, Dolly, Crane and Slider moves, and free rigs handle stationary or mountable cameras and handheld follows. Directors and animators planning several shots will find it keeps things organized.

Key features

  • Path rigs built from viewport shot markers
  • Reorder, nudge and retime shots
  • Orbit, Dolly, Crane and Slider presets
  • Free rigs for stationary and handheld cameras
  • Multi-shot sequencing in one N-panel
