What REACH Pro does

REACH Pro by PENCIL Park is an After Effects extension centered on a search bar that finds and bookmarks commands, effects, presets, scripts and expressions. Around it sits a broad toolkit.

It can generate bones from a Pen Tool path with sliders for distance, angle limits and bending. Text tools slice by words, characters or lines and do project-wide replacements. Keyframe utilities duplicate, mirror, remove redundant keys and bake expressions. Layout tools cover centering, staggering, grids and golden-ratio guides, audio tools create reactors and beat markers from BPM, and an AI assistant supports eight providers with your own API key.

Key features

  • Search bar for commands, effects, presets and scripts
  • Bones generated from a Pen Tool path
  • Text slicing and project-wide search and replace
  • Keyframe, layout and guide tools
  • AI assistant using your own API key
