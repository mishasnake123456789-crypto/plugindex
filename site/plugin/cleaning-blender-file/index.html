Removes orphaned data and geometry junk from a Blender file to free memory and tidy scenes.

What Cleaning Blender File does

Cleaning Blender File purges leftover clutter such as deleted materials, meshes, lights, node groups and images, freeing RAM and optimizing the scene from one button.

It can also clean geometry on selected objects through merge by distance, deleting loose parts and interior faces, filling holes and making faces planar. A later update adds removal of empty material slots across the scene. It is useful when inheriting heavy files or before sending a project to someone else or a render farm.

Key features

  • One-button file cleanup
  • Merge by distance and loose geometry removal
  • Delete interior faces, fill holes, planar faces
  • Empty material slot removal
