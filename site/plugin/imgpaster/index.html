What imgPaster does

imgPaster, by GothLab, removes the save-then-import step for screenshots and copied pictures. Copy an image anywhere, then paste it straight into After Effects or Photoshop.

The pasted file has to be stored somewhere, so you can choose the Documents folder, the folder of the open project file (the project must be saved first), or a custom path. It works with After Effects and Photoshop from CC 2018 through 2024. It is handy when you grab reference shots or screenshots and want them in a composition fast.

Key features

  • Pastes copied images directly
  • Save to the Documents folder
  • Save next to the open project
  • Save to a custom path
  • Works with CC 2018 to 2024
