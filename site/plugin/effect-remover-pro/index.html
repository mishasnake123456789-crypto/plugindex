What Effect Remover Pro does

Effect Remover Pro is a Medhat Mounier extension for managing effects in After Effects. It scans every selected layer and lists the effects applied, so you can see what is on a complex stack at a glance.

A specific effect can be removed from all selected layers, or everything can be cleared in one click. Effects can also be hidden and shown without deletion. A favorites system stores common effects, including third-party plugins, for instant reapplication, and a real-time search filters the list. Auto Refresh and Manual Refresh handle selection changes, and the tool works offline with no data collection.

Key features

  • Real-time effect detection on selected layers
  • Remove one or all effects in a click
  • Hide and show effects without deleting
  • Favorites for quick reapplication
  • Real-time search and offline operation
