Blender add-on that saves transforms, visibility and view settings as scene layouts you can switch between.

What Simple Layouts does

Other Realms' Simple Layouts preserves arrangements of a 3D scene. Each layout stores an object's location, rotation, rotation mode and scale, plus its visibility and selection toggles, and does the same for collections.

Every layout can be given a 3D view taken from presets, custom viewport coordinates or a camera. It began as a way to move between modelling and print-ready arrangements. Anyone who rearranges one scene for different purposes, such as exploded views, can change state in a click.

Key features

  • Layouts store transforms and visibility
  • Collection visibility and selection toggles
  • Assign a 3D view to each layout
  • Preset, custom or camera views
  • Built for switching modelling and print layouts
