What XROMM toolkit does

The XROMM toolkit makes X-ray Reconstruction of Moving Morphology (XROMM) available in Blender. It is a port of Prof Peter Falkingham's XROMM Maya Tools, built for researchers who reconstruct moving anatomy from X-ray data.

It includes a CT marker creator and exporter, and imports and exports motion data, handling NaN values without crashing, frame numbers and multiple objects. A relative motion function arrived in version 0.9.8, and marker positions can be computed from averaged locator vertices or from a bounding box. Sample input data is on the GitHub releases page.

Key features

  • CT marker creator and exporter
  • Motion data import and export
  • Handles NaN values, frame numbers and multiple objects
  • Relative motion function since 0.9.8
  • Marker position by vertex average or bounding box
