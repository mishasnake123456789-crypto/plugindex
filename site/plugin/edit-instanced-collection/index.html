What Edit Instanced Collection does

Edit Instanced Collection helps you locate where an instanced collection actually comes from. In scenes with many linked copies, finding the original to edit it can take several steps.

This add-on shortens that to a quick action, so changes to the source are easy to make. It is useful in scenes built from reusable pieces, where editing one source updates all instances.

Key features

  • Locates the source collection
  • Quick jump to edit
  • Useful in instance-heavy scenes
