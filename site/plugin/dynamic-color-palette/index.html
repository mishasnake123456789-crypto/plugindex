What Dynamic Color Palette does

Dynamic Color Palette, by fwdotcom, supports stylized and low-poly game production in Blender. It creates two GPU-rendered textures and assigns colors to faces using UV lookup, so one tiny texture can drive the whole model's colors.

The HSV palette lets you set columns, rows, pastel saturation and a shadow row. A second PBR data texture offers three independent quadrants, Solid, Metal and Emission. This keeps materials lightweight while retaining flexibility.

Key features

  • HSV palette texture with configurable grid
  • Pastel saturation and shadow row
  • PBR data texture with Solid, Metal and Emission quadrants
  • Face color assignment via UV lookup
