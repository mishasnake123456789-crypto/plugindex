What BAO Bones does

BAO Bones handles rigging and animation as a native After Effects plugin, so no expressions are needed. IK chains can be set up in as few as three clicks, and a whole character can be controlled from one layer with no extra nulls or controllers.

It does not rely on expressions and is GPU accelerated. A distortion mesh fits joint bending and stays editable, with masks for smooth skinning. The workflow is fully keyframable, with Automatic and Manual IK modes and keyframable Parenting and Selection points. Limbs need not be straight, which avoids unbending layers in Photoshop, and a Puppeteer module controls many Bones instances from one layer. Ideal for 2D character animation.

Key features

  • IK setup in as little as three clicks
  • Whole character on a single layer
  • Native and GPU accelerated, no expressions
  • Editable distortion mesh with masks
  • Puppeteer module for multiple instances
