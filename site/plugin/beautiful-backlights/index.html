What Beautiful Backlights does

Beautiful Backlights is a Blender addon from studioromanrec meant to speed up decorating scenes rendered with Cycles. It fits atmospheric environments like night-time cities and nightclubs.

The goal is a fast way to add stylish lighting accents instead of building each one by hand. It is compatible with Blender 4.0 and 3.6, comes with documentation, and is released under the GPL license. Artists working on moody urban or club scenes in Cycles are the main audience.

Key features

  • Designed for the Cycles render engine
  • Quick scene decoration
  • Suited to night cities and nightclubs
  • Works with Blender 4.0 and 3.6
  • Documentation included
