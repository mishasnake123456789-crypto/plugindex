Show It Off

Developer: OffTheClock Studios

FreeBlender
Download Free

Blender add-on that spins objects like a turntable while you work, then restores transforms.

What Show It Off does

Show It Off rotates your objects so you can inspect them from every side without orbiting the viewport. When you stop it, everything returns to its original transforms, so nothing in the scene is changed.

You can keep sculpting, modeling, editing materials or scrubbing the timeline while the object turns, much like a pottery wheel. An adjustable interval timer matches the rotation to your brush rate. Controls sit in a header button and a Tool panel, with keymapping for start and stop, and version 2.0 removed the old rotation cap.

Key features

  • Non-destructive rotation that resets on stop
  • Keep working while the object turns
  • Adjustable event interval timer
  • Header button, tool panel and key mapping
