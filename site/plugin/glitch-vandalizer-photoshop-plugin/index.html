What Glitch Vandalizer Photoshop Plugin does

Glitch Vandalizer is a Photoshop plugin for compressed glitches, digital distortion and datamosh looks. It generates melt and slit-scan looks, damaged analog TV, scanlines and channel shifts, all customisable.

Tabs for Glitches, Offsets and Overlays organise the effect modules, checkboxes in Filter Nodes pick active filters, and solo mode toggles them one at a time. Glitch Map and Datamosh filters build data corruption from a source image. Intelligent Optimization checks the open document and applies needed settings. It comes as a single ZXP file with an illustrated PDF guide, ideal for stills and frames bound for animation.

Key features

  • Glitch, Offset and Overlay effect modules
  • Filter Nodes with solo mode
  • Glitch Map and Datamosh filters
  • Melt, slit-scan, analog TV, scanline and channel-shift looks
  • Single ZXP file with PDF guide
