Blender add-on that marks image planes as sprites which keep turning to face the active camera.

What Sprite Cloud does

Nikita Akimov's Sprite Cloud produces billboard-like sprites in Blender. Select image planes, press the button in the add-on panel to mark them, and they rotate toward the camera in use.

If the scene camera changes, they reorient automatically. Controls sit under the SpCl tab of the 3D Viewport's N panel, and it installs from a .zip like any add-on. Useful for faking trees, crowds and 2.5D scenes using flat images.

Key features

  • Marks image planes as sprites
  • Faces the active camera
  • Reorients when the camera changes
  • SpCl tab in the N panel
  • Standard .zip installation
