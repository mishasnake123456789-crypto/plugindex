Makes a 3ds Max point helper that mirrors an Unreal skeleton or mesh socket and attaches it to the parent bone.

What Add Unreal Socket does

Add Unreal Socket helps with attaching props to characters across 3ds Max and Unreal Engine. A point helper is created with the same transform as an Unreal skeleton or mesh socket, and it is then linked to that socket's parent bone.

Socket data is copied from Unreal with a mouse and keyboard shortcut and pasted into the script UI, avoiding manual string parsing. It can be saved and loaded as text files in a folder you choose, named after the socket. A link constraint is applied to the helper with the parent bone as its target, and transforms are locked. The Y-axis flip between 3ds Max and Unreal is handled automatically.

Key features

  • Point helper matching an Unreal socket
  • Copy socket data from Unreal and paste into the UI
  • Save and load socket data as text files
  • Link constraint to the parent bone with locked transforms
  • Handles the Y-axis flip between Max and Unreal
