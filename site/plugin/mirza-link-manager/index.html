What Mirza Link Manager does

Link Manager connects BIM and CAD applications to 3ds Max so that a model is brought in once and refreshed whenever the source changes. Instead of passing everything through FBX, it lets you pick the best available format from your architecture software and keeps the connection alive.

Links can be duplicated, merged or used as references, including references from other 3ds Max scenes, which makes alternatives and templates easy to maintain. Multiple links can be refreshed in one go, and the tool also checks for updates automatically. Forest Pack, Railclone, V-Ray, FStorm and Corona are integrated, with references kept inside scatterers. A built-in converter handles Autodesk materials, and Revit imports run faster with improved layer and property management.

Key features

  • Import once and update from BIM or CAD sources later
  • Duplicate, merge and reference links, including external scenes
  • Batch updates with automatic change checking
  • Works with Forest Pack, Railclone, V-Ray, FStorm and Corona
  • Built-in Autodesk material converter
