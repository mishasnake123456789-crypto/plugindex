What Smart Swatch .Pro does

Smart Swatch .Pro manages color palettes in Blender, so favorite colors are always available.

You can keep up to 20 swatches with up to 512 colors each, import and export them as .gpl files, and view them as grid or list. The menu adds, removes, duplicates, resets, renames and organizes slots. A lock icon prevents deletion of a swatch while it remains editable, and a Favorite Swatch star adds one to the panel for quick access.

Key features

  • Up to 20 swatches with 512 colors each
  • Import and export .gpl palettes
  • Grid and list views
  • Add, duplicate, rename and organize slots
  • Lock and favorite swatches
