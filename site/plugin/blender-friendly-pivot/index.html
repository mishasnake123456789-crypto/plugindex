What Blender Friendly Pivot does

Blender Friendly Pivot borrows much of Maya's Pivot Transform behavior for Blender. Pivot orientation, origin and 3D cursor placement can be changed with fewer keystrokes.

Using the D shortcut, point at a highlighted component and click with a mouse button to apply the change. A pivot gizmo moves the origin in 3D space and sets a custom orientation, and incremental snapping is supported. Artists moving from Maya will find pivot editing familiar. Keeping the keystroke count low makes it practical to reposition pivots repeatedly while modeling or rigging.

Key features

  • D shortcut sets orientation, origin or cursor
  • Pivot gizmo for origin and orientation
  • Incremental snapping
  • Maya-style pivot workflow
