What Quick Landscape does

Quick Landscape, by Anindya Jana, supplies natural terrain for Blender scenes without sculpting it yourself. The library holds 152 landscapes sorted into 38 categories, and each one comes in four variants.

A separate scatter library offers 16 tree types that are fully customizable and can be switched in real time through Geometry Nodes, with controls over how they are distributed. It is helpful for environment artists who need believable backdrops fast, whether for stills or animation.

Key features

  • 152 landscapes across 38 categories
  • Four variants per landscape
  • 16 customizable tree types for scattering
  • Real-time tree switching via Geometry Nodes
  • Tree distribution controls
