What Pixy Halftone does

Pixy Halftone, by Motion FX, applies a chunky halftone pattern to whatever sits below it in After Effects. Footage, animation, type and graphics can all be given a retro print-and-pixel feel.

It copes well with alpha channels, so transparent areas behave as expected. Apple Silicon support was added in version 1.1, and the plugin is compatible with After Effects versions from CC 2014 up to 2026, so it fits both older and current setups.

Key features

  • Pixelated halftone style
  • Works on video, animation and text
  • Handles alpha well
  • Apple Silicon support since 1.1
  • Compatible with CC 2014 to 2026
