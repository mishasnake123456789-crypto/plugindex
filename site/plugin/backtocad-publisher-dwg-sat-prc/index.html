What BackToCAD Publisher (DWG, SAT, PRC) does

BackToCAD Publisher is a stand-alone 64-bit Windows converter, listed in the 3ds Max app library, for processing hundreds of DWG and DXF files at a time. Output can be 2D PDF, 3D PDF, or PRC for use as 3D PDF or CAD input.

3D PDF or PRC can be built from net models or B-Rep models, and 2D elements like text, lines, polylines, dimensions and hatches are supported inside 3D PDF. Colors and line weights follow AutoCAD CTB plot style files or an internal table. It handles paper space, model space and layouts, embeds searchable text, binds external references and adds watermark protection.

Key features

  • Batch DWG/DXF to 2D PDF, 3D PDF and PRC
  • Net or B-Rep model options
  • Color and line weight via CTB files
  • Handles paper space, model space and layouts
  • Searchable text and watermark security
