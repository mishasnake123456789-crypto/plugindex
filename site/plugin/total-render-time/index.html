What Total Render Time does

Total Render Time is a small Blender add-on for answering one question: how long did this animation take to render? Instead of timing it by hand, you let it read the information already stored in your frames.

A single button scans your render directory, lists the files, and adds up the render time found in each image header. It reads JPEG, PNG and OpenEXR sequences. That makes it handy for freelancers estimating costs or anyone comparing the effect of settings changes. Documentation is included.

Key features

  • Calculates total render time in one click
  • Scans and lists files in the render folder
  • Reads JPEG, PNG and OpenEXR headers
  • Sums time across the whole sequence
