Add-on offering a database of camera sensors for quickly setting sensor size and render resolution.

What Camera Sensor Database does

Camera Sensor Database lets you choose a real camera sensor from a list and apply its size to a Blender camera, along with a matching render resolution. It is based on the Camera Sensor Database by EmberLightVFX.

The database is saved locally and can be refreshed by downloading the newest version over the network. This is useful when matching CG to live footage shot on a known camera. It installs by dragging into Blender or from disk.

Key features

  • Pick from a database of camera sensors
  • Sets sensor size and render resolution
  • Based on EmberLightVFX's database
  • Saved locally with network update
  • Drag-and-drop installation
