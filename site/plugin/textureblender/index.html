Collection of Blender node groups built around a Texture Blend node, which blends textures via a mask, plus a PBR texture manager.

What Textureblender does

Textureblender supplies shader node groups for combining surface textures. Its main Texture Blend node takes a mask input, which can come from procedural textures, alpha maps or vertex paint, to blend single textures, full PBR sets, puddles and scattered textures.

An Untiler helps reduce visible repetition, and the bundled QP_Tools add-on manages PBR textures. Environment and material artists can build varied, non-repeating surfaces quickly.

Key features

  • Texture Blend node with mask input
  • Blends single textures and PBR sets
  • Puddle and scattered texture support
  • Untiler node
  • QP_Tools PBR texture manager
