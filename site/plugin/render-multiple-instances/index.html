What Render Multiple Instances does

Render Multiple Instances, or RMI, is a Blender add-on by DShot92 that shortens animation render times by launching several background instances of Blender at once. It reads the output settings already defined in your scene, so there is little to configure before you start.

Beyond the parallel rendering, it can produce flipbook previews, whether drawn from the viewport or split across several instances, with an optional frame range override and a resolution percentage. Finished PNG or JPG sequences can be encoded to MP4 through FFmpeg, and flipbook output goes to an incrementing custom directory.

Key features

  • Renders animations with a chosen number of background instances
  • Uses the scene's own render output settings
  • Flipbook previews with frame range and resolution override
  • Encodes PNG or JPG frames to MP4 via FFmpeg
  • Incremental output folders for flipbooks
