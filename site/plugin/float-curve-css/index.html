What Float Curve CSS does

Float Curve CSS is a Blender plugin for moving Float Curve data around. It can read a curve and turn it into CSS easing, which is handy for designers who share animation curves with web developers.

You can copy output as linear() functions or sampled values, copy a curve and apply it to another Float Curve node, or paste from a JSON text field. A Curve object can be registered as a profile and converted into a normalized Float Curve node, bridging modeled shapes and node-based control.

Key features

  • Copies curves to the clipboard as CSS
  • Copy and apply points between Float Curve nodes
  • Apply from JSON text
  • Convert Curve objects into normalized Float Curves
