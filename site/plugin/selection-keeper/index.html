Saves and recalls selection sets across Blender's object, pose, edit and paint modes.

What Selection Keeper does

Selection Keeper stores selections so you can return to them later. It works in many modes: Object, Pose, Edit Armature, Edit Mesh, Edit Curve, Edit Surface, Weight Paint and Vertex Paint.

Batch operations select or delete multiple sets together, and custom groups, type filtering and search keep large collections of sets manageable. Selection sets can be exported and imported. Riggers, modelers and animators who repeatedly pick the same bones or components can recall them instantly.

Key features

  • Selection sets in eight modes
  • Batch select or delete sets
  • Groups, type filter and search
  • Import and export of sets
