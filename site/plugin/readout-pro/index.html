Blender add-on that animates 3D measurement labels and bakes them into per-frame meshes.

What Readout Pro does

Readout Pro creates technical text labels in Blender that display live measurements such as distance, velocity or acceleration. Values come from evaluated transforms and meshes, so modifiers, constraints and animation are all respected.

Any number of independent sets can be added, each with its own source object, measurement type, units, precision, sampling, placement, rotation and style. Previews update non-destructively while you tweak. Baking produces one clean mesh per sampled frame, keyed so only the right label appears in playback and renders. An every-N-frames setting trades fidelity for speed, and text supports any font plus extrusion, bevel and shared materials.

Key features

  • Unlimited independent readout sets
  • Distance, velocity and acceleration data
  • Live non-destructive preview
  • Bake to keyed per-frame meshes
  • Placement modes including face camera
