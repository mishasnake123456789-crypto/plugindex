What Animate With Curves And Paths does

Animate With Curves And Paths builds curve-based motion quickly. In three clicks it creates a template and moves an object along a curve using a follow path constraint with an offset factor.

Curve templates include Line, Circle, Spiral, Wave and Wave with drop-off, and timing templates include Balanced, Fast to slow and Slow to fast. Curves can be extruded, moved and reshaped, direction reversed, and animations removed, duplicated or applied to existing curves, all without the graph editor.

Key features

  • Template and animation in three clicks
  • Line, Circle, Spiral and Wave curve templates
  • Balanced, fast-to-slow and slow-to-fast timing
  • Reverse, duplicate or reapply animations
