One-button 3ds Max script that converts selected groups, including nested ones, into editable poly objects.

What Group to EditablePoly does

Group to EditablePoly turns groups in 3ds Max into single editable objects, one per group. It is especially useful with imported models from SketchUp and other CAD programs, which often arrive as many nested groups.

Groups nested inside groups are fine; results take over the original group names and layers and stay within any parent group. Pivots are placed at the object base. If a mesh in the group is already an editable mesh, it stays a mesh instead of being converted to poly. There is no interface and no options, just one button that does the work on the current selection.

Key features

  • Converts one or many groups to editable poly, one object each
  • Keeps editable meshes as editable mesh
  • Supports nested groups
  • Preserves group names and layers
  • Pivot placed at the object base
