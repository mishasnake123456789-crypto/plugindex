What Duplicate Finder And Remover - Clean Imported Cad Files From Duplicate Meshes does

Duplicate Finder and Remover scans selected, visible or all mesh objects and groups the results in the 3D Viewport sidebar. It finds exact geometry duplicates and also similar objects using adjustable similarity settings.

Strict, Balanced and Loose detection modes control how aggressive the search is, and evaluated meshes can be compared. Imported CAD scenes often include repeated parts stacked in the same place, which this tool reveals before you remove them.

Key features

  • Scan selected, visible or all meshes
  • Exact duplicates and similar-object detection
  • Strict, Balanced and Loose modes
  • Evaluated mesh comparison
  • Results grouped in the sidebar
