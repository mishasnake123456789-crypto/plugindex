Blender add-on for native SketchUp (.skp) import and export without SketchUp installed.

What OpenSKP Import/Export does

OpenSKP Import/Export, by Ahsan-Mehmood, reads and writes SketchUp .skp files natively in Blender, so SketchUp itself is not required. It is listed under Import-Export.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.

Key features

  • Native .skp import
  • Native .skp export
  • No SketchUp required
