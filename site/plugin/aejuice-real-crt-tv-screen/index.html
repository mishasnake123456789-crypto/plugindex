What AEJuice Real CRT TV Screen does

AEJuice Real CRT TV Screen is a pack of 22 scene templates that recreate the look of an old tube television. It is built for After Effects and Premiere Pro and lets you drop your own picture into a convincing CRT display.

Each scene can be customized, so editors and motion designers can nostalgically frame logos, footage or stills without building the screen effect by hand. Plugin versions cover recent releases of both apps on Windows and macOS, including Apple silicon, while older After Effects versions receive a plain project file instead.

Key features

  • 22 ready-made CRT TV scenes
  • Drop any image into the display
  • Customizable per scene
  • Works in After Effects and Premiere Pro
  • Windows and macOS, including M1 and M2
