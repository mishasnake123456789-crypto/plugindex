What Emoji Library does

Emoji Library puts a huge emoji collection inside After Effects and Premiere Pro, so reactions and decorative icons can be dropped into a video without hunting for images online. More than 9,000 official emojis are available.

One click adds an emoji to your project, and if nothing in the catalogue fits you can generate a custom emoji with AI. The plugin works with host versions from CC 2019 through 2026. It is aimed at social video, explainers and lighthearted edits that benefit from expressive icons.
