What synthetick GradientHub does

GradientHub from synthetick is a panel that applies gradients across several After Effects tools. More than 500 curated presets are included, and GRD, CSS and SVG gradient files can be imported.

Gradients can be sent to Colorama, Color Shift, shape layer fills and strokes, or layer styles, either updating an existing effect or adding a new one. Custom gradients are saved into categories and subcategories with generated thumbnails, and thumbnails switch between wheel and linear styles. Designers who want consistent colour palettes and fast gradient swaps will find it saves repeated gradient editing.

Key features

  • 500+ gradient presets
  • Feeds Colorama, Color Shift, shape layers and layer styles
  • Imports GRD, CSS and SVG files
  • Custom gradients in categories
  • Wheel and linear thumbnail views
