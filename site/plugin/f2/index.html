Blender add-on that extends the F key in Edit Mode to create edges and faces more flexibly.

What F2 does

F2 enhances Blender's standard Make Edge/Face command, which is run with the F key while in Edit Mode. It was formerly one of the add-ons shipped with Blender 4.1 and is now looked after by the community.

The add-on is tiny, around 5 KB, needs no special permissions and is released under GPL version 3 or later. It supports Blender 4.2 LTS and newer. Anyone who spends a lot of time cleaning up topology, filling holes or building faces vertex by vertex can work with fewer steps.

Key features

  • Extends Make Edge/Face on the F key
  • Works in Edit Mode
  • For Blender 4.2 LTS and newer
  • Tiny download, no special permissions
