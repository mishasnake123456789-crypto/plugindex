What Arch Generator does

Arch Generator creates architectural elements inspired by historical styles from around the world. Arches, pillars, bases, capitals and repeating structural arrays all come from a parametric, non-destructive process with real-time geometry updates.

It is built on Blender's BMesh API and is open source. Environment artists making temples, bridges, cloisters and fantasy structures can adjust proportions at any time rather than remodeling.

Key features

  • Arches, pillars, bases and capitals
  • Structural arrays
  • Parametric and non-destructive
  • Real-time geometry updates
  • Open source, built on BMesh
