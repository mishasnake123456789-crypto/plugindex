What Quick Location does

Quick Location Popup is a lightweight Blender add-on for nudging an object's position. A popup menu shows X, Y and Z sliders, and it remembers the original position so a Reset button restores it in one click.

The default hotkey is Shift+V, and modifier keys can be added or removed in the add-on preferences. It works in Object Mode. This is a handy shortcut for artists who want a small floating control instead of opening the sidebar.

Key features

  • Popup X, Y, Z location sliders
  • One-click Reset to the original position
  • Default Shift+V hotkey, customizable
  • Works in Object Mode
