What Render Queque does

Render Queque lets you line up multiple .blend files and render them one after another in Blender. Each file runs in its own process, so a crash or memory problem in one job does not take down the rest of the queue.

This suits artists with overnight renders, animation shots split across files, or any batch of scenes that would otherwise need to be started by hand. It is a simple way to leave a set of renders running unattended.

Key features

  • Batch queue of .blend files
  • One process per file
  • Isolates failures between jobs
  • Good for unattended renders
