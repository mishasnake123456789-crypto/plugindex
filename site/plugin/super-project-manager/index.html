What Super Project Manager does

Super Project Manager is a Blender add-on for keeping project organization out of your way. Setting up directories, naming files and remembering which scenes you left half-finished are chores it handles from inside Blender.

With one click it builds a folder structure along with its files, names the project and its folders, and saves the project straight from the add-on's panel. A tracking list reminds you which projects are still unfinished. It is compatible with the Blender Extension system and includes documentation.

Key features

  • One-click folder and file creation
  • Saves the project from the add-on
  • Names project and folders automatically
  • Tracks unfinished projects
