What Fastest Render does

Fastest Render from Divine Animation Studio cuts render time in Blender with one button. It was built for simple animations, and the developer states it can render up to eighty percent quicker.

It checks whether a GPU is available and uses it instead of the CPU when possible, then retunes a range of settings in a way meant to maintain quality while reducing time. Documentation is included. Hobbyists, students and animators with simple scenes who do not want to study render settings will find it an easy way to speed up their output.

Key features

  • Checks for GPU support and uses it
  • Retunes settings while preserving quality
  • One-button operation
  • Up to 80% faster on simple animations
