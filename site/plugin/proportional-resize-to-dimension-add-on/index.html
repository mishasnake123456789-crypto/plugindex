What Proportional Resize To Dimension Add-On does

The Proportional Resize To Dimension Add-On resizes a Blender object so that one chosen axis reaches a precise measurement, with the other axes following proportionally. The shape stays the same, only its overall size changes.

It runs from the Search Menu (F3) as Resize to Dimension, using a modal interface so you do not need to adjust values afterward. Undo is supported for corrections. Built for Blender 4.3 and offered under a royalty-free license, it suits modeling work that needs exact real-world dimensions.

Key features

  • Exact dimension on X, Y or Z
  • Keeps proportional scaling on all axes
  • Modal interface without follow-up edits
  • Undo supported
  • Run from the F3 Search Menu
