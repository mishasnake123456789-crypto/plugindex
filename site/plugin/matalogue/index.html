Blender add-on that lists materials and node trees in the Node Editor's toolbar for quick switching and object selection.

What Matalogue does

Matalogue adds a catalogue of materials and other node trees to the Node Editor toolbar. Clicking an entry switches the editor over to that tree and selects the objects that use it, which saves time hunting through large scenes.

It collects trees from material and light shader nodes, geometry nodes, node groups and compositing. Filters for materials let you narrow the list to what matters. Shading artists and technical directors working with many materials and node groups will find navigation noticeably easier.

Key features

  • Lists materials and node trees in the toolbar
  • Click to switch tree and select related objects
  • Covers shader, geometry, group and compositing trees
  • Material filters
