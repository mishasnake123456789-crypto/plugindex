What Clothfx - Dynamic Cloth Tearing does

Clothfx is a Blender add-on by AlbertoFX that simulates cloth being torn in real time. Tearing runs live and is baked after the fact, so there is no need to pre-bake before you see the effect.

Edge splitting can be triggered by collider objects using several modes: contact with a mesh volume, distance-based proximity, both together, or particles. Collision values and a stress parameter control when the cloth starts reacting dynamically. You can also use generated tears or custom tear maps for more control, and tears can be viewed in the viewport.

Key features

  • Real-time tearing without pre-baking
  • Triggers: mesh volume, proximity, combined and particles
  • Stress parameter and collision settings
  • Generated tears and custom tear maps
  • Bake the result after the live run
