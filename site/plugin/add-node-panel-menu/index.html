What Add Node Panel Menu does

Add Node Panel Menu is a Blender add-on for the Node Editor that reorganizes the Add menu by how nodes relate to one another and gives each node an icon. This makes scanning for the right node faster than reading long lists.

It covers shader and composite nodes. You can use a panel under the N sidebar's Add Node tab, a pop-up menu on Alt+Ctrl+A, or a pie menu on Shift+Right Mouse. Documentation is provided.

Key features

  • Nodes grouped by relationship with icons
  • Supports shader and composite nodes
  • Sidebar panel, popup and pie menu access
  • Alt+Ctrl+A and Shift+RMB shortcuts
