Bakes, edits and transfers RGBA channels between images and mesh color attributes in Blender.

What Rgba Transfer does

RGBA Transfer extends Blender's native bake function with tools for color and alpha channels. It can bake into images and mesh color attributes and transfer data between them.

Images can be transferred across similar meshes with different topology, and the add-on speeds up bakes. This helps technical artists and game developers working with vertex color data and texture channel packing. Under the hood you get wraps and extends Blender's native baking and transfers color and alpha channels.

Key features

  • Wraps and extends Blender's native baking
  • Transfers color and alpha channels
  • Transfers images across different topology
  • Bakes to images and color attributes
