What Object Color Rules does

Object Color Rules assigns viewport colors to objects in Blender through rules. It covers both object color and wireframe color and is in Properties, Object Buttons.

It was previously bundled with Blender 4.1 and now comes as a small 4.0 KB add-on needing no special permissions, supporting Blender 4.2 LTS and newer. Layout and modeling artists can color-code scenes for readability. Viewport colors are a lightweight way to visually classify objects without editing their materials.

Key features

  • Rules for object color
  • Rules for wireframe color
  • Found in Object properties
  • Small 4.0 KB download
