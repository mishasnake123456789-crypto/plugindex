What Topovision - See Your Topology Before It Exists does

TopoVision is a Blender add-on for automatic retopology that shows the result before it exists. You adjust density and edge flow and see the topology update in real time.

Visual feedback covers polygon distribution, a wireframe view lets you inspect the mesh during preview, and the mesh is generated once you are satisfied. It reduces trial and error compared with generating, checking and undoing. The feature set spans real-time topology preview and visual feedback on density and edge flow.

Key features

  • Real-time topology preview
  • Visual feedback on density and edge flow
  • Wireframe inspection
  • Generate when satisfied
