Blender script that imports or merges whole collections with their data blocks under a new Merged Collection.

What Import Full Collections does

Import Full Collections brings content from other files into Blender while preserving its organization. Data blocks stay linked and appear under a new super collection called Merged Collection.

An incremental number is added to each merged collection name, and complete scenes, objects or specific geometry nodes can be handled in one click. A collection is also created for objects that do not belong to any. It's helpful for combining assets from several .blend files without a mess.

Key features

  • Imports collections with their data blocks
  • Groups results under Merged Collection
  • Incremental naming
  • Handles scenes, objects or geometry nodes
  • Collection for unassigned objects
