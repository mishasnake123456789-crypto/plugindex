What Monster Matte does

Monster Matte, by LoneRobot, simplifies setting up background plates in 3ds Max. You browse for a rendered background, and the utility configures it as a mental ray matte material that can be assigned to background objects and rendered immediately.

Everything revolves around the mental ray matte material, which handles contact shadows and masking. The interface was written with HitchHiker, a custom dotnet control. Artists who consolidate complex sets into background renders, then place new elements in front of them, can avoid wiring up the matte network manually each time.

Key features

  • Browse for rendered backgrounds as the source
  • Configures a mental ray matte material automatically
  • Ready to assign to background objects
  • Used for contact shadows and masking
  • Interface built with the HitchHiker dotnet control
