Blender add-on that automates proxy rigs and decimated proxies to speed up viewport performance, keeping full-quality renders.

What Proxy Plus does

Proxy Plus manages lightweight stand-ins in Blender so heavy animation scenes stay responsive. Final renders still use the full-fidelity models.

Generate Proxy Rig splits a deforming mesh into pieces that each follow a bone directly. Generate Decimated Proxy copies non-rigged objects and reduces them. Proxies are set and toggled easily. Animators working on dense scenes get smoother playback. Lower-detail stand-ins keep playback near real time, and switching back to full detail takes only a toggle before rendering.

Key features

  • Generate Proxy Rig
  • Generate Decimated Proxy
  • Set and toggle proxies
  • Full fidelity in final renders
