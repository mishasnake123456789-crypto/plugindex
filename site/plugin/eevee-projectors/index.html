What Eevee Projectors does

Eevee Projectors is an add-on that gives Blender an imitation of imitates projector lights inside the Eevee render engine, where true projection lighting is otherwise awkward to set up. A dynamic image projector is created through a simple two-step process.

New projectors are added from the create tab in the side panel and can be animated in real time. The add-on requires Blender 4.2 LTS or newer and is released under GPL v3 or later. Lighting artists, motion designers and scene dressers can use it for gobo effects, screens and light patterns cast onto surfaces.

Key features

  • Fake projector lights for Eevee
  • Two-step projector setup
  • Real-time animation of the projected image
  • Add projectors from the side panel
  • Supports Blender 4.2 LTS and newer
