Blender add-on that converts many pictures into texture-paint brushes and sculpt brushes in one pass.

What Batch Import Images to Brushes does

Batch Import Images to Brushes saves the tedium of setting up brushes one at a time in Blender. Select hundreds of image files and it generates textures, brushes and 256 by 256 preview thumbnails automatically.

You can make texture paint brushes, sculpt brushes or both, with size, strength and tool type set per mode. Many formats load, including PNG, JPEG, TIFF, WEBP and HDR. Brushes are marked as assets, names can use prefixes and suffixes, existing brushes are skipped, and images are packed into the blend file.

Key features

  • Import hundreds of images at once
  • Texture paint brushes, sculpt brushes or both
  • Auto previews and asset marking
  • Custom prefix and suffix naming with duplicate skip
  • Images packed into the .blend file
