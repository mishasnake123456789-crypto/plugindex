Blender add-on from CGMatter that applies procedural erosion damage to any model with a node-free interface.

What Erode It does

Erode It adds weathered, damaged edges to models in Blender using geometry nodes. One click applies the erosion, and no node building is needed, though the underlying setup is left open for editing.

The Erode It modifier controls resolution, detail, seed, erosion properties, smoothing and cuts, with an optional randomized bevel beforehand. It handles several selected objects at once, Apply bakes the result for faster performance, and Copy Erosion carries settings from the active object to others.

Key features

  • One-click procedural erosion
  • Modifier with detail, seed and smoothing controls
  • Optional randomized bevel
  • Apply to bake the erosion
  • Copy Erosion across objects
