What Additional Batch Rename does

Additional Batch Rename is a Blender add-on by Endertainer007 that extends batch renaming to modifiers, constraints and vertex groups. Open it from the context menu in Object, Edit or Pose Mode.

Renaming can be limited to objects only or bones only, and bone targets switch to constraints automatically. Find and Replace has an Exact Match toggle that restricts results to identical strings, and prefix and suffix options add text at the start or end of an existing name. Scope controls decide which items are affected.

Key features

  • Batch rename modifiers, constraints and vertex groups
  • Object-only or bone-only targeting
  • Find & Replace with Exact Match toggle
  • Prefix and suffix options
  • Scope control for affected items
