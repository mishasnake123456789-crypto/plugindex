Blender Graph Editor toolkit with 17 features for aligning, tweening, looping and randomizing F-Curves.

What Graphkit does

Graphkit packs 17 animation features into Blender's Graph Editor. Curve shaping commands include Align, Amplify, Arcs, Distribute, Offset and Overlap, while timing tools cover Divide, Hold, Flatten Holds, Overshoots and Fade.

A tween slider offers Blend to Default, Blend to Neighbor and Breakdown modes with preset percentages. Looping tools make perfect loops, convert a range to a loop, repeat and randomize for organic variation. Selection modes work by object type, side or random, and one-button toggles mute, lock or hide all curves. Selected keyframes can mirror around the playhead.

Key features

  • Align, Amplify, Arcs, Distribute, Offset, Overlap
  • Hold, overshoot and fade timing tools
  • Tween slider with blend types
  • Perfect Loop, Repeat and Randomize
  • Mute, lock and hide toggles for all F-Curves
