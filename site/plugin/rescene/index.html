Saves, switches and restores Blender scene states including transforms, visibility, lights, cameras and render size.

What Rescene does

Rescene captures the state of a Blender scene so you can return to it later. It records transforms, visibility, materials, lights, cameras, world settings and render resolution, either for the full scene or only selected objects.

Saved states carry notes, timestamps, lock status and thumbnail previews. Restoring brings back object transforms, rotation modes, visibility and collection membership within the current scene, and light and camera setups can be recalled too. It is useful for comparing layout options, lighting variations or client revisions inside one file.

Key features

  • Named states with notes and thumbnails
  • Restore transforms, visibility and collections
  • Recall light and camera setups
  • Full scene or selected objects only
