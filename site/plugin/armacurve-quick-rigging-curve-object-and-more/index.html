Blender add-on that converts Bezier curves into armatures, mesh rigs and helper setups with optional cloth motion.

What Armacurve - Quick Rigging Curve Object And More does

Armacurve rigs curve-based shapes in Blender without building bones by hand. A selected Bezier curve becomes an armature in one click, with settings for bone division, B-Bone subdivisions, display type and size, and a curve-to-mesh workflow can act on a connected section of a spline.

Head and tail pin offsets and weight thresholds refine how the mesh responds. Add Object Helper places empties at curve points and attaches the curve to them with hooks, and a Tweaker panel edits the armature, parent controls and physics helpers. Cloth-based physics with collision is optional. Open it from the sidebar Tool tab or with Shift+Alt+C.

Key features

  • Curve to armature in one click
  • Curve-to-mesh rig workflow
  • Pin offsets and weight thresholds
  • Empty helpers hooked to curve points
  • Optional cloth physics with collision
