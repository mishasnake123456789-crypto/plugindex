Creates one sequence per clip in a bin, each matching the source clip's frame size, rate and audio settings.

What Clip to Match Source Sequences does

Clip to Match Source Sequences scans any bin in a Premiere Pro project and builds a separate sequence for every clip in a single pass. Each sequence inherits the clip's frame size, frame rate, pixel aspect ratio and audio settings, so nothing needs to be configured by hand.

New sequences can go into the same bin as the clips, a freshly named bin or the project root. An optional name prefix is available, and duplicate names are handled automatically to avoid overwriting existing items. It is useful for reviewing many differently shot clips or preparing individual sequences for later work.

Key features

  • One match-source sequence per clip in a bin
  • Inherits frame size, rate, aspect and audio settings
  • Choose same bin, new bin or project root
  • Optional name prefix
  • Avoids overwriting duplicate names
