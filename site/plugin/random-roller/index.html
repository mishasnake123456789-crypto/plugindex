What Random Roller does

Random Roller, made by Rob Barrett, is a script for After Effects that brings chance into layer selection and arrangement. It can pick a random subset of layers, shuffle their order, or divide them into groups, which is useful for varied animation setups.

Re-rolling narrows a previous random selection, and the current one can be inverted. Selected layers can be sorted into a chosen number of groups, each given a slider control holding its group number, with optional label colors, name prefixes and comments. A specific group can be selected later. A randomized selection order also works with Quick Offset.

Key features

  • Random layer selection with re-roll and invert
  • Randomize layer or selection order
  • Sort layers into groups
  • Group slider, label color and name prefix options
  • Select or add a group to the selection
