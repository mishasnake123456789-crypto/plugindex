What Lazy Shapekeys [Shape Keys Folder & Utility] does

Lazy Shapekeys, by Bookyakuno, helps manage large shape key lists. Keys can be divided into folders, shown in a collapsible list and in a two-column Folders tab.

Utilities include forced transfer, left and right separation, applying modifiers while retaining shape keys, and spawning an individual object per shape key. Facial animators and character artists with dozens of expressions can keep everything organized.

Key features

  • Shape key folders with collapsible list
  • Forced shape key transfer
  • Left/right separation
  • Apply modifiers while keeping shape keys
  • Separate object per shape key
