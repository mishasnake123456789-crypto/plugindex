What Script2Sequence does

Script2Sequence converts a script spreadsheet into an editable sequence. It reads a local .csv, optionally with a media path column, fetches the referenced videos, and arranges them into a timeline.

Downloads work from Frame.io, Google Drive and images, with automatic mp4 conversion. A script cell may hold several comma-separated videos, a voice-over line may use multiple clips, and audio can drive the timing. An asset database remembers media paths by URL, and various timestamp formats are accepted.

Key features

  • Reads scripts from .csv with media path column
  • Batch downloads from Frame.io and Google Drive
  • Multiple videos per cell and clips per line
  • Asset database keyed on URLs
  • Audio-first timing option
