What Autolipsync Pro does

AutoLipSync Pro creates mouth animation from speech without needing an internet connection. It maps phonemes to viseme shape keys or pose actions, and needs only 13 of them to work.

Transcription runs in real time while keeping the interface responsive, with multi-language phoneme matching. It adds automatic eye blinking, a built-in audio converter and VSE integration with start and end frame control. New audio can be layered after existing lip sync at any frame. Reference guides explain building the visemes.

Key features

  • Offline lip sync from audio
  • Shape keys or pose actions with only 13 targets
  • Automatic blinking and audio converter
  • VSE integration and layering
