What Perfect Decal does

Perfect Decal by Kromines installs a complete decal system on any existing Blender material in one click. It works on any object, supports unlimited decal layers and lets you change stacking order.

Per-layer controls cover opacity, normal intensity and scale, and HSL adjustments tune the colors. Because the workflow is non-destructive, original materials stay intact. Surface detailing, labels and wear are quick to add. The feature set spans one-click decal setup on any material and unlimited layers with adjustable order.

Key features

  • One-click decal setup on any material
  • Unlimited layers with adjustable order
  • Opacity, normal intensity and scale per layer
  • HSL adjustments, non-destructive
