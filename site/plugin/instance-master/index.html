Detects repeating Blender meshes, merges them into instances and exports an optimized GLB for Unreal Engine.

What Instance Master does

Instance Master finds duplicated meshes in a scene and turns them into clean instanced groups. It analyzes geometry, topology and affine similarity, recognizing copies made via Array, Mirror or Geometry Nodes and ignoring differences in names and vertex order.

The optimized scene can then be exported to a single GLB for Unreal Engine. Environment artists get lighter scenes and fewer unique meshes with less manual work. Key capabilities include duplicate detection by geometry and topology and recognizes Array, Mirror and Geometry Nodes copies.

Key features

  • Duplicate detection by geometry and topology
  • Recognizes Array, Mirror and Geometry Nodes copies
  • Merges into instanced groups
  • Single GLB export for Unreal
