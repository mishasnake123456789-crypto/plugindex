What Sox Biped Assist does

Sox Biped Assist gathers frequently needed biped animation functions into one 3ds Max script. Selecting biped parts uses hotkeys: Ctrl to add, Alt to subtract and Shift to straighten the joint.

Keyframe Assist can key every biped part at once and apply IK or FK keys to the selection or to all keys. Loop tools include Trim, which deletes keys outside the loop range, and Sel. which picks the keys within it; Mirror takes you to the mirrored frame. Get and Set buttons handle the animation range, eight shortcut buttons store and jump to frequent frames, a drop-down controls playback speed, and a play button shows blocking in step style based on selected keyframes.

Key features

  • Hotkey biped selection with add, subtract and straighten
  • Keyframe Assist with IK and FK key application
  • Loop tools to trim, select and mirror within the loop range
  • Eight timeline shortcut buttons and playback speed control
  • Blocking playback in step style
