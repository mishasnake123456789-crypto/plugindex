What FontShaper does

FontShaper is a GothLab script that makes fonts usable in Adobe apps without installing them on the system. It works in After Effects, Illustrator and Photoshop, and can draw on Google Fonts or a local fonts folder.

Google Fonts access uses a Google API, with a tutorial for setup, and the local folder supports one level of subfolders; digits should be avoided in font names. Temporary folder settings are available, along with controls for font style, fill rule and line position. It installs through the aescripts + aeplugins manager or the ZXP installer.

Key features

  • Use fonts without installing them
  • Google Fonts via Google API
  • Local fonts folder support
  • Font style, fill rule and line position controls
  • Works in After Effects, Illustrator and Photoshop
