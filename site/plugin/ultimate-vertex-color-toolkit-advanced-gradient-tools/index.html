What Ultimate Vertex Color Toolkit - Advanced Gradient Tools does

Ultimate Vertex Color Toolkit gives Blender a broad set of tools for creating vertex color data with full RGBA channel support. It targets game and real-time work where vertex colors carry masks for shaders, such as foliage wind movement.

A hierarchical gradient system builds wind masks and weighted gradients from the material hierarchy, with unlimited levels and per-material controls for trees, palms and plants. Ambient occlusion and curvature can be baked straight into vertex colors with distance, strength, contrast and threshold settings, and an Edge Wear tool, linear and radial gradients and procedural noise round it out. Environment artists will find it comprehensive.

Key features

  • Hierarchical gradient system for wind masks
  • AO and curvature baking to vertex colors
  • Edge Wear tool
  • Linear and radial gradients with procedural noise
  • Full RGBA channel support
