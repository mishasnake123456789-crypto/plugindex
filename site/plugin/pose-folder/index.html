Blender pose manager that keeps poses in nested folders and blends them onto bones with the mouse.

What Pose Folder does

Pose Folder by Bookyakuno organizes character poses in nested folders and plain lists rather than a wall of thumbnails, giving a compact interface that saves screen space.

Saving the selected bones creates a pose as separate action data, and an active entry can be overwritten. Applying works by pose mixing, where mouse movement sets how strongly the pose is blended, and a flip option mirrors across the X axis. A small file browser lists other blend files in a folder, so poses travel between projects.

Key features

  • Hierarchical folders and lists for poses
  • Save selected bones as a pose
  • Mix poses by mouse movement
  • X-axis flip option
  • Browse external blend files for poses
