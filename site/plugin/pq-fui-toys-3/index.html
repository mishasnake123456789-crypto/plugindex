What PQ FUI Toys 3 does

PQ FUI Toys 3 by Peter Quinn is a collection of fake user interface graphics for After Effects, the kind seen in sci-fi screens and tech displays. Each is a pre-animated, sometimes looping, editable composition.

A Script UI panel lets you search, browse and generate the comps, and every asset has customizable parameters. Version 3 added 40 new toys and hundreds of expression updates, and the panel was rebuilt. It supports After Effects from CS6 through 2026, and PQ FUI Toys 2 owners get a free upgrade.

Key features

  • Pre-animated fake UI assets as editable comps
  • Search, browse and generate from a panel
  • Customizable parameters per asset
  • 40 new toys in version 3
  • Free upgrade for Toys 2 customers
