What Ezdepth - Ai Depth Map Generator does

EZdepth uses AI to estimate depth from a single image, turning an ordinary photo into a relief surface inside Blender. It runs Meta's Depth Anything Small model in ONNX form, so a depth map is a single click away.

Results can be output as a geometry displacement modifier, a full shader displacement setup (Cycles only), or a plain grayscale image. You can pick Simple or Catmull-Clark subdivision and switch the displacement coordinates between UV, Local and Global. A bump map is derived from the source image too, and can be layered in shader mode for fine surface detail.

Key features

  • One-click depth from any image
  • Modifier, shader or grayscale output
  • Simple or Catmull-Clark subdivision
  • UV, Local or Global displacement coordinates
  • Bump map built from the original image
