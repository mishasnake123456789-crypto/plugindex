What Sprite 2D does

Sprite 2D produces 2D sprite animation out of animated 3D models. The same animation is rendered from as many angles as you specify, which helps 2D game developers.

It suits side-scroller, top-down and isometric games, outputs an image sequence and builds a sprite sheet automatically with configurable settings. Outputting finished sprite sheets removes manual assembly, speeding up the path from animated model to game-ready art. It saves manual rendering for each angle.

Key features

  • Renders animation from custom angle counts
  • Side-scroller, top-down and isometric use
  • Image sequence output
  • Automatic sprite sheet
