What Bonerng - Randomize Bones Pose Blender Addon does

BoneRNG generates dynamic poses on a selected armature in one click, handy for character and particle-style animations.

It randomizes rotation, location and scale, inserts keyframes automatically, and either adds to the current transform or replaces it. The noise scale of each channel is tuned separately, and looping animations are supported. It is available from the N panel in Object Mode, with documentation.

Key features

  • One-click random bone poses
  • Automatic keyframes
  • Add to or replace current transforms
  • Separate noise scale and looping support
