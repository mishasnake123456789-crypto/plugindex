What Ray Projector does

Ray Projector is a plugin from irrealix for After Effects that detects edges in an image and extrudes them into three-dimensional forms. Rendering is GPU accelerated, so the results update quickly.

Edge detection drives the extrusion, and the models are shaded with environment maps, either presets or a custom layer. Gradient coloring can be applied along the extrusion axis. It works with After Effects 2020 through 2026, and suits abstract graphics, glowing light-ray looks and stylized 3D logos.

Key features

  • GPU-accelerated edge extrusion
  • Edge detection drives the 3D shape
  • Environment-map shading with presets or custom layer
  • Gradient coloring along extrusion axis
