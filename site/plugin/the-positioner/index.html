What The Positioner does

Motion Embassy's The Positioner is a script built for After Effects aimed at building layouts that adapt as a design changes. Layers can be pinned to the edges of the composition or to the edges of other layers, using a visual interface for fast placement.

Ten scale modes cover Fit, Fill, Stretch and Shrink in width, height and combined forms. Padding can be uniform or set separately for each side, and Limit Size keeps dimensions within a percentage. Box It! produces self-resizing text boxes, lower thirds and chat bubbles. Pinned layers stay locked to edges when rotated, with offsets following the rotation axis.

Key features

  • Pin layers to comp and layer edges
  • Ten scale modes including Fit, Fill and Shrink
  • Uniform or per-side padding
  • Box It! for self-resizing text boxes
  • Rotation-aware edge locking
