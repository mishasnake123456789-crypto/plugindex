Blender add-on for managing custom properties in bulk, selecting by filters, labeling the viewport and exporting CSV summaries.

What Object Reporter does

Object Reporter turns custom properties into a searchable, reportable system. Add or replace properties in bulk using named presets, with options to skip existing values or overwrite them.

Select by Properties applies AND/OR conditions with exact, contains and numeric matching. Viewport labels, grouping, CSV export and a summary table make inventory, quantity takeoffs and data checks possible. Technical artists and architectural users managing large scenes can keep metadata organized.

Key features

  • Bulk add or replace custom properties with presets
  • Select by properties with AND/OR filters
  • Viewport labels and grouping
  • Summary table and CSV export
