What FAST ARCHITECTURE does

Fast Architecture is a custom procedural mesh object that produces an architectural structure in 3ds Max. Adjust a parameter and the building updates immediately, a quick way to make simple buildings for city backgrounds.

The FA_Building object accepts deformers, animatable parameters and conversion to mesh, like any native object. Windows, frames, balconies, columns, roof and a curved facade are all customizable. Every part has its own material ID, with six IDs available for the windows, and UV mapping is included for tiles, windows and balcony fills. An Optimize option lowers mesh weight on the principal parts.

Key features

  • Procedural FA_Building object
  • Windows, frames, balconies, columns, roof, curved facade
  • Own material ID for every part
  • UV mapping for tiles, windows and balcony fills
  • Optimize option for lighter meshes
