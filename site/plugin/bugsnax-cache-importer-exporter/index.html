Blender add-on that imports and exports Bugsnax .objcache, .daecache and .xcache files through File menu entries.

What Bugsnax Cache Importer/Exporter does

The Bugsnax Cache Importer/Exporter lets Blender read and write cache files used with Bugsnax. Each of the three formats, .objcache, .daecache and .xcache, has its own entry under File > Import and File > Export.

This makes it possible to bring cached data into a Blender scene for editing and send the results back in the same type. It is aimed at modders and artists who work with assets from that game.

Key features

  • Imports .objcache, .daecache and .xcache
  • Exports the same three formats
  • Dedicated File menu entries per type
