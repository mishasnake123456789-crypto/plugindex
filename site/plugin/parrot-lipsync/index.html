What Parrot Lipsync does

Parrot Lipsync generates mouth animation automatically from an audio track. It suits both 2D and 3D characters and relies on the Allosaurus engine to approximate syllables, so it is not tied to one language.

The result is a set of lip-synced keyframes you can refine by hand. Documentation is included. A time saver for dialogue-heavy animation. Because it is not language specific, it opens up lip-sync automation for projects in many languages, including stylized 2D work.

Key features

  • Automatic lip-sync keyframes
  • 2D and 3D animation
  • Allosaurus syllable approximation
  • Works with any language
