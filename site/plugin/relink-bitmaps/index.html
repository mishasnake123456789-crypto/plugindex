MAXScript tool that relinks missing bitmaps, V-Ray proxies, HDRIs and IES files after folders or computers change.

What Relink Bitmaps does

Relink Bitmaps repairs broken file paths in 3ds Max scenes. When assets are moved to another directory or a project lands on a new computer, the script finds the missing files and reconnects them.

It covers all supported bitmap texture types, Mental Ray proxies, V-Ray proxies in .vrmesh format, VRayHDRI and IES files, including VRayIES, along with Substance sbsar files and OSL files with an OSLPath parameter. A command-line mode automates repeated jobs, user defaults can be configured, updates are checked automatically, and the speed is 250 percent faster than earlier versions.

Key features

  • Relinks all supported bitmap types
  • V-Ray and Mental Ray proxies, VRayHDRI, IES
  • Substance sbsar and OSL file support
  • Command-line mode for automation
  • 250% faster than previous versions
