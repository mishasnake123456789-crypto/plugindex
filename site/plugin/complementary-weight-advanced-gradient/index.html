Blender weight-painting add-on that ties two bones' weights together and refines gradient shape and offset.

What Complementary Weight / Advanced Gradient does

Kihoon's add-on improves rigging in Blender with two helpers. Complementary Weight connects two adjacent bones so that painting weights on bone A automatically adjusts bone B, following WB = 1 - WA.

Advanced Gradient gives intuitive control over how a weight gradient is shaped, offset and strengthened, and includes an edge loop mode. Sidebar tabs can be renamed in the Add-ons tab of Preferences. Riggers handling elbows, knees and other bending joints can reach smooth deformation sooner.

Key features

  • Complementary Weight modifier for two bones
  • Advanced Gradient with shape and offset
  • Intensity control
  • Edge loop mode
  • Renamable sidebar tabs
