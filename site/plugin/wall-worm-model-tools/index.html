What Wall Worm Model Tools does

Wall Worm Model Tools brings together importers, exporters and workflows for building assets for Goldsrc, Source and Source 2 games in 3ds Max. Source 2 support covers VMDL, VMAT and VMAP, and Source exporters include DMX, SMD, VTA, QC, VTF, VMT, VMF, MAP and RMF.

It adds a native MDL Loader for 3ds Max 2015 and later, a VMT Browser, wrinklemap export, and an Asset Browser reading models, materials, textures, particles, sounds and sky assets from game directories, including VPK archives. Game textures load without extracting to disk, convex collision hulls and LODs can be generated, and QC automation handles sequences and batch export.

Key features

  • Source 2 VMDL, VMAT and VMAP import and export
  • Source exporters including DMX, SMD, QC and VMF
  • Native MDL Loader and VMT Browser
  • Asset Browser reading VPK archives
  • Auto collision hulls, LODs and QC automation
