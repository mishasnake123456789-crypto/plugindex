Applies editable punch-in zooms to Premiere Pro clips from a chosen focus point and style preset.

What ZoomAssist Pro does

ZoomAssist Pro speeds up the creation of punch zooms in Premiere Pro. You pick a clip, grab a frame, click the point you want to zoom toward, choose a preset and apply it, and the result is built from ordinary keyframes you can tweak afterwards.

Presets include Cinematic, Smooth, Punch and Instant, and the zoom scale can be set by hand. Motion blur and timeline markers for each zoomed range are optional. Nothing is baked in, so tutorial makers, screen-recording editors and social content creators can repeat zooms quickly and still adjust them later. The plugin is free.

Key features

  • Focus-point based zoom placement
  • Cinematic, Smooth, Punch and Instant presets
  • Custom zoom scale
  • Optional motion blur and range markers
  • Output stays as editable keyframes
