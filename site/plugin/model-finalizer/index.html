Blender batch utility for applying modifiers, building shape keys from poses and cleaning vertex weights before export.

What Model Finalizer does

Getting a character or prop ready to leave Blender usually means a pile of repetitive steps. Model Finalizer groups several of them as batch operations so they can be done for many objects together.

It can turn poses saved in the Pose Library into shape keys, collapse modifiers on a whole selection, and do so without losing existing shape keys. A refined weight transfer can limit itself to selected vertices and wipe old vertex groups, a cleaner tidies weights, and extra tools help with rest poses and face sorting that avoids transparency glitches.

Key features

  • Batch shape keys from Pose Library poses
  • Apply modifiers on many objects at once
  • Apply modifiers while keeping shape keys
  • Weight transfer with selected-vertex option
  • Vertex group cleaner and face sorting
