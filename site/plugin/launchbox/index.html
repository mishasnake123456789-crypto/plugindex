What LaunchBox does

LaunchBox is a no-cost launcher from Ebberts + Zucker that offers fast access to the studio's full set of After Effects tools. Instead of hunting through menus, you start each tool from one place.

It works with After Effects from CC 2015.3 to 2026. Support has grown to include tools such as MonkeyWords, TypeMonkey3D, Vybe, MonkeySauce, GoType and EZMarkerAlign; version 1.07 added the last two. It suits artists who already use these tools.

Key features

  • Free launcher
  • One place for the Ebberts + Zucker tool set
  • After Effects CC 2015.3 through 2026
  • Covers MonkeyWords, TypeMonkey3D, Vybe, MonkeySauce, GoType, EZMarkerAlign
