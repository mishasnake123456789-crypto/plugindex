One-line 3ds Max startup script that turns off the Scene Converter's Backup Original Files option so merges stop saving backups.

What Faster File merging into 3ds max does

This startup script for 3ds Max turns off the Scene Converter's Backup Original Files option. As a result, 3ds Max does not save a backup file every time a scene is merged into it, which speeds up merging.

On Max versions that do not remember the setting, it removes the need to re-check it for each scene. The script is a single line of MAXScript, installed by saving an .ms file in the 3ds Max startup scripts folder. It works with 3ds Max 2012 and later. Artists who merge many files regularly will notice the difference.

Key features

  • Disables Scene Converter's Backup Original Files at startup
  • Stops backup files being saved on merge
  • No need to re-check the setting per scene
  • Single line of MAXScript
  • Works with 3ds Max 2012 and later
