What Interactive Physics Editor - Real-World Object Arrangement does

Interactive Physics Editor helps lay out models that stand for real objects. As you move one object, others shift out of the way, preventing collisions and overlaps in Blender, so the result could be reproduced in reality.

Objects can be locked on any axis for location or rotation, static ones set to Passive, and collision margin, friction and gravity direction and intensity adjusted. Concave or convex collisions are selectable. The session has no time limit, and you can accept or abandon it whenever you like. Daily support arrives through email and the Blender Market inbox.

Key features

  • Objects shift aside as you move others
  • Axis locks for location and rotation
  • Passive objects, friction and gravity controls
  • Concave or convex collisions
  • Commit or cancel the session anytime
