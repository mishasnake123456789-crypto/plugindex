Converts audio into Blender animation using six analysis methods that drive scene properties.

What Sound Reaktor does

Sound Reaktor analyzes an audio file and uses the results to animate Blender scenes in time with the music. It offers six analysis methods: FFT, Onset Detection, RMS Energy, Spectral Centroid, Spectral Flatness and Spectral Rolloff.

The output can drive location, rotation, scale or almost any numeric property through a Custom Property target, covering shaders, textures, lights, modifiers, Geometry Nodes, cameras and compositor nodes. A Spectral Bins mode splits the spectrum into bands. It is aimed at music visuals and audio-reactive motion graphics.

Key features

  • Six audio analysis methods
  • Drives transforms or any numeric property
  • Targets shaders, lights, modifiers, nodes
  • Spectral Bins mode
