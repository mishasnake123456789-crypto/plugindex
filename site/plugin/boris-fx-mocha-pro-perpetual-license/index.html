What Boris FX Mocha Pro - Perpetual License does

Mocha Pro is a tracking and roto system from Boris FX that can run inside After Effects, Premiere Pro and OFX hosts, or as its own application. This listing is the perpetual licence option.

It is built on planar tracking, used for roto, object removal and screen replacements. PowerMesh tracks deforming surfaces, and Point Track ML helps when surfaces turn away, change lighting or get covered, with AdjustTrack offering Auto Nudge and refinement modes. SynthEyes powers 3D camera solves, and there are stabilization tools for 360 and VR. AI mattes come with Auto ROI, Search Area and Matte Refine controls, which help with soft edges, blur and fine hair.

Key features

  • Planar tracking, roto and object removal
  • PowerMesh with Point Track ML and AdjustTrack
  • SynthEyes-powered 3D camera solves
  • Image and camera stabilization, 360/VR support
  • AI mattes with Auto ROI and Matte Refine
