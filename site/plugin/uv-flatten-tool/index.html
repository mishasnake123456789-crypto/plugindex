Blender add-on that lays a mesh flat according to its active UV layout and saves the result as a shape key.

What UV_Flatten_Tool does

UV_Flatten_Tool unwraps a mesh in the actual 3D scene by moving its vertices to match the active UV coordinates. The flattened shape is stored as a shape key, so it can be animated or blended with the original form.

Two options control seams: use existing marked seams, or let the tool generate them (older files may need to be copied to a new scene). It starts from the Object menu with the Flatten UV to SK command. Texture painters, cloth pattern makers and animators who want an unfold-to-flat transition can apply it quickly.

Key features

  • Flattens a mesh to active UV coordinates
  • Result saved as a shape key
  • Use existing seams or generate seams
  • Runs from the Object menu
