Blender add-on that automatically moves the viewport to frame the selected object, mesh element or bone.

What Auto-Frame does

Auto-Frame keeps your view on whatever you select in Blender, so you stop pressing the numpad period key between objects.

It frames objects, mesh elements and bones, offers customizable zoom modes, and helps avoid the Camera Zoom Lock that appears when moving between very small and very large distances. Documentation is included. It saves effort when working on detailed models that require frequent view changes. This is particularly useful for artists who jump back and forth between small details and the wider scene.

Key features

  • Frames the selected object, element or bone
  • Works like the numpad period key, automatically
  • Customizable zoom modes
  • Avoids Camera Zoom Lock
  • Documentation included
