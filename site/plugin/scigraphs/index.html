Visualizes and analyzes graph data (nodes and edges) inside Blender.

What SciGraphs does

SciGraphs lets you work with network and graph data in Blender. You can bring in graph structures and view them as 3D objects, with analysis tools alongside the visuals.

Scientists, students and data visualization artists who think in nodes and connections can use it to explore datasets in a flexible 3D environment. It combines import capabilities with node-based tooling, making Blender a practical place to present graph results.

Key features

  • Graph visualization in 3D
  • Graph analysis tools
  • Imports graph data
  • Node-based tooling
