Blender add-on that remeshes meshes into quad topology with Instant Meshes or Quadriflow, keeping the original hidden.

What Jremesh Tools does

JRemesh Tools rebuilds existing meshes with quad-based topology in Blender. It supports Instant Meshes (a separate download) and a built-in Quadriflow operator.

The workflow is non-destructive: it creates a new remeshed object and hides the original. Sculptors and modelers cleaning scans or dense sculpts can get usable topology for animation or further editing. Quad-based topology is easier to deform, subdivide and texture than dense triangulated surfaces, making this a handy step before animation or UV work.

Key features

  • Quad-based remeshing
  • Instant Meshes and Quadriflow support
  • Non-destructive new object
  • Original kept hidden
