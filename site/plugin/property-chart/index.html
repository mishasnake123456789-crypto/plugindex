What Property Chart does

Property Chart is a Blender add-on that lets you edit properties across several selected objects, or across the sequencer, at the same time. Its panel lives in the 3D View sidebar under the Item tab, and it installs without asking for any special permissions.

The tool was originally written by Campbell Barton, known as ideasman42, and is distributed under the GNU GPL. It works with Blender 4.2 LTS and later. In version 0.1.2 the default value switched to show_wire, replacing the deprecated auto smooth setting. It is handy for anyone tired of changing values one object at a time.

Key features

  • Edits properties across multiple selected objects
  • Also works with the sequencer
  • Panel in the 3D View sidebar's Item tab
  • Requires no special permissions
  • Supports Blender 4.2 LTS and newer
