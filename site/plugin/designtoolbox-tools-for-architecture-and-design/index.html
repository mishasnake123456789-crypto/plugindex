What DesignToolBox - tools for architecture & design does

This DesignToolBox edition from Atelier Bump collects tools meant to speed up and simplify basic modeling in 3ds Max, with architectural models and furniture design as prime uses. Reference-based transformation tools handle rotation, scale and position relative to a chosen reference.

Additional helpers include measurement tools and guides, snapping points at polyline intersections, visual rulers, fast UVW mapping with random transform, cloning tools, scene management, panel grids, quick pivot placement and workplanes. It is for designers and visualizers who need dimensions to be right the first time.

Key features

  • Reference rotation, scale and position
  • Measurement tools and reference guides
  • Snapping at polyline intersections, visual rulers
  • Fast UVW mapping and random transform
  • Cloning, panel grids, pivots and workplanes
