Blender add-on that generates clean, customizable mesh-based trails from curves, as UV unwrapped geometry.

What Mesh Trails does

Mesh Trails creates animation trails in Blender as meshes rather than particles or curves. A UV unwrapped mesh is built at the click of a button.

Any Bezier or Poly curve can emit, including cyclic ones, and the curve can be parented, animated or rigged with hook modifiers. Because the trail is UV unwrapped it works with custom shaders. Motion designers and VFX artists can add swooshes and ribbons easily.

Key features

  • Mesh trails with UV unwrap
  • Any Bezier or Poly curve as emitter
  • Supports cyclic curves
  • Compatible with custom shaders
