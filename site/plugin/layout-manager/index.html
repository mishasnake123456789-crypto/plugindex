What Layout Manager does

Layout Manager stores the arrangement of your Blender workspaces as presets and brings them back whenever you switch tasks. Presets can be moved up and down in the list with dedicated operators.

Dopesheet attributes for the Dopesheet Editor can be saved and loaded, add-ons can be handled in the workspace tab, and presets export to a JSON file and import back. An N panel is available in the 3D view. It is useful if you flip between modeling, animation and other interface setups.

Key features

  • Save and load workspace layouts
  • Reorder presets
  • Dopesheet attribute presets
  • JSON export and import
