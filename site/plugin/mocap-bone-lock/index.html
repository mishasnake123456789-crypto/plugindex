What Mocap Bone Lock does

Mocap Bone Lock cleans motion capture by pinning bones in place over time, removing foot and hand sliding that appears after retargeting. It works non-destructively through the NLA, so the original motion is kept and every change can be reversed.

Manual Mode allows precise placement, while Auto Mode handles long clips using Dip Detect, based on Z position, or experimental Velocity Detect. A shared frame lock range and fade in/out controls smooth the transitions.

Key features

  • Manual and Auto locking modes
  • Dip and Velocity detection
  • Non-destructive NLA workflow
  • Fade in and out controls
