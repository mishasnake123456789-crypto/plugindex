What Mesh Vault does

Mesh Vault combines four mesh utilities in one Blender add-on. A seeded generator prototypes meshes using randomized or parameter-driven seeds, Select Reverse Normals finds faces with flipped normals, and Smart Hole Filler closes gaps with context-aware topology.

Array tools round out the set for creating and cleaning meshes. Modelers who want a handful of dependable helpers in one place will find it practical. Key capabilities include seeded Mesh Generator and select Reverse Normals.

Key features
