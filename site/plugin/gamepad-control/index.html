Blender add-on for navigating and controlling the 3D viewport in real time with a game controller.

What Gamepad Control does

Gamepad Control lets you move around the Blender viewport with a PlayStation, Xbox or compatible controller. Real-time input drives orbit, pan, dolly and direct view switching.

Mappings for buttons and axes are configurable in customizable gamepad modes, switchable by button, with a temporary switch while holding one. An on-screen overlay displays the current mappings and a header indicator shows the active mode. Settings can be exported and imported to share. Mouse emulation currently works on Windows, with macOS and Linux planned.

Key features

  • Real-time gamepad viewport navigation
  • Orbit, pan, dolly and view switching
  • Customizable button and axis mappings
  • Overlay showing current mappings
  • Export and import of settings
