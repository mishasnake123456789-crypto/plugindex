What shareIO does

shareIO is a collaboration plugin for Cinema 4D teams. It passes objects, materials, render settings, documents and complete projects, with their assets, between users over a local network or services such as Dropbox, Google Drive or OneDrive.

Any importable file can be dragged into a project, and holding Alt exports the project with its assets. The Overview window filters, searches and marks favorites. Doc-Helper commands tidy documents by colorizing objects and deleting invisible objects or material tags, Recent-Files finds recent work by extension, and Py-Tools lists a project's Python scripts so everyone can run them.

Key features

  • Share objects, materials, render settings and projects
  • Works over local networks and cloud folders
  • Alt-drag exports project with assets
  • Doc-Helper cleanup commands
  • Recent-Files and Py-Tools utilities
