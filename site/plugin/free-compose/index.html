What Free Compose does

Built by Steven Twigg, Free Compose is a script running inside After Effects that groups layers in a way familiar from Photoshop. A normal pre-compose can break expressions, parenting or cropping, whereas this works like a pre-compose you can toggle open within the same layer stack.

Track mattes are supported: set a matte for a group and layers inside without one update to match on refresh. There are three layouts, row, column and 2-up, switchable from the help menu, and show/hide and select/deselect controls are condensed into two toggles. Version 2.0 introduced redesigned icons and a smaller interface.

Key features

  • Photoshop-style layer grouping
  • Keeps expressions, parenting and cropping
  • Track matte support for groups
  • Row, column and 2-up UI layouts
  • Compact toggles and redesigned icons
