What Polygon Cruncher V15 for Autodesk® 3ds Max® does

Polygon Cruncher V15, by Mootools, simplifies heavy meshes without ruining their appearance. It preserves texture information, vertex colors and user-defined normals, protects object borders, material boundaries and UV seams, and respects symmetry.

It comes as a modifier for real-time optimization with MagicCruncher automatic settings and a MaxScript interface, a utility with an OpenGL view, batch processing and LOD generation, and a standalone application for folder batches. Ambient occlusion and normal map baking and GLB export with textures for the web are included. Artists preparing models for games, production or the web will use it.

Key features

  • Polygon reduction that preserves appearance
  • Border, UV seam and symmetry protection
  • Modifier, utility and standalone versions
  • LOD generation and batch processing
  • AO and normal map baking, GLB export
