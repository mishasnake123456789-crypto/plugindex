What Typo Text Addon does

Typo Text Addon is a Blender plugin from EdenWeby 3D for making animated typography. It ships with over 28 presets, so a title or kinetic text scene can start from a ready design instead of an empty viewport.

Controls are simple for customizing the result, and the text arrives already shaded and textured. A video tutorial and documentation explain usage. It suits creators building intros, lyric videos and social clips.

Key features

  • 28+ text motion graphics presets
  • Simple customization controls
  • Text arrives shaded and textured
  • Video tutorial and documentation
