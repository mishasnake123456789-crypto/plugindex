What Rigged Scroll Plan does

Blenderthings' Rigged Scroll Plan is a prepared rig for the unrolling of a scroll. It deals with the curves, tilts and orientations such motion requires, which are awkward to animate manually.

Use it for scrolls, building plans or promotional visuals; it is set up for Cycles and Eevee. It was built for Blender 2.8 and 2.81, includes documentation and has a royalty-free license. Motion designers needing a quick reveal of documents or blueprints can start from it.

Key features

  • Rig for unrolling scrolls and plans
  • Handles curves, tilts and orientation
  • Cycles and Eevee setup
  • Documentation included
  • Royalty-free license
