Blender add-on that drives several shape keys from a draggable 2D joystick HUD for facial rigging.

What ShapeKey Axis Control does

ShapeKey Axis Control maps shape keys onto a joystick-like HUD in Blender. Drag a point across the X and Y axes and multiple shape keys blend together at once, which suits faces, eyes, mouths and mechanical animation.

Box, radial and single-axis modes shape the influence area, and controls can be organized in groups such as Eyes or Brows. Global presets record joystick positions with Set, Call and Key buttons, Auto-Mirror creates .L and .R mappings, animation can be baked to shape key keyframes, and group setups can be exported and imported.

Key features

  • 2D joystick HUD driving multiple shape keys
  • Box, radial and single-axis blend modes
  • Named control groups
  • Animation presets and bake to keyframes
  • Auto-Mirror and export or import of groups
