Exports all or selected NLA animations from a Blender armature to FBX files named after each action.

What Nla Batch Exporter does

Nla Batch Exporter automates a tedious step in game animation pipelines. With one button, every NLA action on a chosen armature is exported as its own FBX file.

If you prefer, only the NLA strips you have selected are exported. The tool lives in the 3D viewport's N panel, and each output file is named after its NLA action automatically. Game developers sending animation sets to Unity, Unreal or similar engines avoid exporting clip by clip.

Key features

  • One-click export of all NLA actions
  • Selective export of chosen strips
  • Located in the N panel
  • FBX files named after each action
