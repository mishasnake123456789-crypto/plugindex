What Open Edge Select does

Open Edge Select, from 3D CADence, automates a tedious part of mesh cleanup in Blender: finding open edges. One click detects and selects only the open edges across a model, making holes and gaps easy to spot when preparing clean topology.

Fill Edge Loop closes loops with geometry, using triangles, or quadrilaterals when you select an active edge. Auto Loop helps select looped open edges. Modelers repairing imported meshes, CAD conversions or 3D print models will find the single-click checks quicker than hunting visually.

Key features

  • Selects only open edges in one click
  • Fill Edge Loop closes loops
  • Triangle or quadrilateral filling
  • Auto Loop selection of looped open edges
