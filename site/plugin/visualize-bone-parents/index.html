What Visualize Bone Parents does

Visualize Bone Parents is a Blender add-on for checking rigs where objects are attached to bones. Tracking those relationships in the outliner can be confusing, so it shows them directly.

With one click, the object and its parent bone are identified by matching colors. It supports Blender 2.93 and 3.0 through 3.4, includes documentation and is released under the GPL.

Key features

  • Color-coded object to bone parenting
  • Single-click visualization
  • Supports Blender 2.93 to 3.4
  • Documentation included
