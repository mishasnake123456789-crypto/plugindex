Generates node networks that switch or blend between datatypes in Blender shaders.

What Node Switcher does

Node Switcher builds node setups for switching and blending between different datatypes. Every shader socket type used in Cycles and Eevee is supported, and there are several switching methods.

Color ID switching reads colors from an input image, for example a material ID map, detecting them automatically, and Hard Switcher handles hard switching of arbitrary inputs. Useful for variant materials and masks. Instead of wiring complicated mix and switch networks manually, you get a ready setup that can be adjusted afterwards.

Key features

  • Switch and blend across socket types
  • Color ID switching with auto detection
  • Hard Switcher
  • Works in Cycles and Eevee
