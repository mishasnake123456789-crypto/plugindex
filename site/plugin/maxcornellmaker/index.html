3ds Max script that rebuilds the Cornell Box from Cornell University's original measurement data for render testing.

What maxCornellMaker does

maxCornellMaker recreates the well-known Cornell Box inside 3ds Max. It is not an approximation: the scene is built from the measurement data Cornell University originally published.

The Cornell Box is a standard environment for testing and validating rendering algorithms, so having it match the original data makes comparisons more meaningful. The script targets 3ds Max 5, 6 and 7 and is distributed as version 1. Artists and researchers evaluating renderers, global illumination settings or materials can start from a trustworthy test scene.

Key features

  • Recreates the Cornell Box in 3ds Max
  • Built from original Cornell University measurements
  • Benchmark scene for rendering tests
