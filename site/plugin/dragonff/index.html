Blender add-on for importing and exporting RenderWare-based GTA files including DFF models, TXD textures and collisions.

What DragonFF does

DragonFF connects Blender with the RenderWare file formats used by Grand Theft Auto games. It supports files for models (.dff), textures (.txd), collisions (.col) and maps (.ide/.ipl).

Skinned meshes and multiple UV maps are handled, and mass export is available. Model import and export are complete, texture files import fully with partial, experimental export, and collisions can be read and written, including those packed inside DFF files. Modders building or editing GTA vehicles, characters and maps can work in Blender instead of older tools.

Key features

  • Import and export of DFF models
  • TXD texture import with experimental export
  • COL collision support, including inside DFF
  • IDE and IPL map file import
  • Skinned meshes and mass export
