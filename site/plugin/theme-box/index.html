What Theme Box does

Theme Box puts interface theme switching in the 3D Viewport header. You can apply one of the built-in styles, import a theme from an XML file, or return to the Blender Default at any time.

Documentation is included, and the developer pl_workshop provides support and updates. It is aimed at users who change their look to suit lighting conditions, tasks or personal taste, and want to do it without opening Preferences.

Key features

  • Theme switching from the viewport header
  • Built-in theme styles
  • XML theme import
  • Return to Blender Default anytime
