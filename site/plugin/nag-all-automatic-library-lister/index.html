What NAG ALL - Automatic Library Lister does

NAG ALL automates the tedious preparation of digital asset libraries for 3ds Max. One click pairs each 3ds Max file with its preview image, leaving the library prepared for dragging into scenes or linking in an asset manager.

It works on compressed archives such as RAR, 7Z and ZIP as well as already extracted files, and renames files to match their preview while keeping release year or render engine information. Optional folders for Sources, Extensions, Trash and Textures keep things clean, with healthy and damaged sorting. Three maps options handle textures differently by library, missing previews are searched for and reported, and a batch mode covers very large collections.

Key features

  • Handles RAR, 7Z, ZIP and extracted files
  • Renames files to match preview images
  • Optional Sources, Extensions, Trash and Textures folders
  • Three texture collection options
  • Recovers missing previews and supports batch mode
