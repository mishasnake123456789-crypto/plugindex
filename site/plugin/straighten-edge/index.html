What Straighten Edge does

Straighten Edge from Royal Ghost projects chosen vertices or edges onto a line in 3ds Max. It works on Editable Poly objects, Edit Poly modifiers, Editable Spline objects and Line objects.

Holding Shift straightens with axis constraints in the selected Reference Coordinate System, and holding Alt straightens while normalizing vertices or edges by their distances or lengths. Supported coordinate systems include World, Working Pivot, Parent and Screen. Modelers cleaning up uneven edge loops, hard-surface details or imported geometry can fix them in one action.

Key features

  • Projects vertices or edges onto a straight line
  • Editable Poly, Edit Poly, Spline and Line support
  • Shift for axis-constrained straightening
  • Alt to normalize by distance or length
  • Multiple Reference Coordinate Systems
