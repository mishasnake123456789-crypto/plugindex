What Quick Image Vectorizer Pro does

Quick Image Vectorizer Pro traces 2D artwork inside Blender and turns it into 3D geometry. Drop in a PNG, JPG or BMP and a threshold preview updates live in the viewport, so you can dial in the shape before generating the object.

Output can be a mesh or a curve, with an optional Solidify for thickness. A batch mode processes whole folders, naming each result and sorting it into collections. An experimental colour trace splits an image into layers with matching materials, and results can be exported as SVG with real-world millimetre sizing. Icon, logo and illustration work is the obvious use.

Key features

  • Live threshold preview in the 3D viewport
  • Single-image and batch folder modes
  • Mesh or curve output with optional Solidify
  • Experimental colour trace with per-layer materials
  • Calibrated SVG export in millimetres
