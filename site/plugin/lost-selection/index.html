What Lost Selection does

Lost Selection is a Blender add-on by niewinny that extends Blender's selection with additional operators in Object and Edit modes. In Object mode you can select by display type, material, material viewport color (with a tolerance value) and matching rotation, plus modifiers.

Edit mode adds selection by crease, sharp edges, bevel weight, seam and edge length. Options such as Match All, Match Any and Extend refine the results. It helps clean up large scenes and detailed meshes where picking elements one at a time is slow.

Key features

  • Select by display type, material and viewport color
  • Tolerance control for color matching
  • Select by rotation and modifiers
  • Edit mode: edge length, seam, bevel weight, sharp, crease
  • Match All, Match Any and Extend options
