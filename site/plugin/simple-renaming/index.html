What Simple Renaming does

Simple Renaming changes the names of many Blender items in one go, whether they are objects, materials, collections, node groups, point clouds or other data. It can apply changes to every item or only the selection.

One-click case changes include upper, lower, title, sentence, camel and Pascal case. Search and replace supports regular expressions, sequential numbering is available, and dynamic @-variables insert scene information for automatic naming. Pipeline-minded artists keep scenes organized and consistent.

Key features

  • Rename many kinds of data in bulk
  • Case transformations in one click
  • Search and replace with regex
  • Sequential numbering and @-variables
