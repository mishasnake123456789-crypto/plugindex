What GPUDog does

GPUDog is a growing collection of GPU effects, called gpuppies, for After Effects. They run live through WebGPU or Metal, covering glitch, distort, colour and generative looks.

The Pro tier adds a built-in WGSL shader editor and an importer that recognises Shadertoy, ISF and plain GLSL, converting only syntax and types while keeping your variable names. Imported code is checked with the same compiler the plugin uses, and any parameters you add turn the shader into a new effect. The free tier gives all 13 gpuppies at full quality, while Pro unlocks all 34 without a watermark. Shader-curious motion designers can experiment directly.

Key features

  • Real-time effects via WebGPU or Metal
  • Live WGSL shader editor in Pro
  • Importer for Shadertoy, ISF and GLSL
  • Custom parameters turn shaders into effects
