What Mesh Attribute Utils does

Mesh Attribute Utils is a Blender add-on by Hannah-Pascal-Noël that lets you inspect and edit custom attributes on meshes. Mesh > Show Attributes prints a chosen vertex, edge or face attribute's values as text inside the 3D view, capped at 100 values to keep big meshes from crashing.

Mesh > Batch Set Attributes edits many attributes for the selection together, a richer version of Set Attribute, and Object > Rename Attribute relabels an attribute across selected meshes without losing data. Procedural artists working with geometry nodes will find debugging attributes easier.

Key features

  • Show attribute values as text in the viewport
  • Limited to 100 values to avoid crashes
  • Batch Set Attributes for a selection
  • Rename Attribute across selected meshes
  • Useful for Geometry Nodes debugging
