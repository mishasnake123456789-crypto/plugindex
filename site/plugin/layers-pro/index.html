What Layers Pro does

Layers Pro is a script from Sanlion Studio for global changes across an After Effects project. Instead of opening comps one at a time, you can copy, replace or delete layers in many compositions at once.

It also copies, replaces and removes effects, properties and masks on selected layers, and changes composition duration, size, frame rate and switches in bulk. Targets can be chosen with built-in search or by manual selection. It is compatible with After Effects CC 2018 through 2023 and suits template and versioning jobs.

Key features

  • Bulk copy, replace and delete layers
  • Bulk effect, property and mask editing
  • Bulk duration, size and frame rate changes
  • Built-in search or manual selection
