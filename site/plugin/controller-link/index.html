What Controller Link does

Controller Link is a Blender add-on by globglob3D that uses a game controller or gamepad as a real-time input device. Sticks and buttons turn into animatable properties able to control bones, geometry nodes, object transforms and more.

Inputs can be recorded into keyframes, linked to Geometry Nodes through the CL node group, or connected to any property by copying a driver and using Paste Driver. Any gamepad is usable on Windows, Mac and Linux, and recordings can be kept with Blender's native Bake Animation operator. Great for performing animation instead of keying it.

Key features

  • Gamepad joysticks and buttons as inputs
  • Record input into keyframes
  • CL node group for Geometry Nodes
  • Copy and paste drivers to any property
  • Works on Windows, Mac and Linux
