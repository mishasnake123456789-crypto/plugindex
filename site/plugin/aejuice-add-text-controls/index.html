What AEJuice Add Text Controls does

AEJuice Add Text Controls is a script for After Effects that builds control handles for text layers. It can process several compositions in a single run and attach controls to every text layer inside them.

Controls cover scale, position, rotation, skew, anchor point, opacity and on/off, along with color controls, and text can be edited using either the added controls or the native properties. This makes it a good starting point when preparing templates for MOGRTs or handing projects to other After Effects users.

Key features

  • Adds text controls to all selected layers
  • Works across multiple compositions
  • Controls for scale, position, rotation, skew, opacity and on/off
  • Color, position, scale, anchor and rotation controls
  • Edit text via controls or native properties
