What Shape It does

Xane Studios' Shape It is a motion design bundle for Blender: an add-on plus a collection of 100+ 3D motion elements, 35-plus animation presets, basic shaders, the DynaString cable and PNG sequences that can go into video work.

The add-on imports elements, materials and presets. Shape to Balloon inflates shapes, groups and lettering into soft, floating balloons with detail and helium settings, and Cloth Pinning drives cloth and balloons by pin objects, no Edit Mode required. DynaString is a simulated cable, and a six-material shader set is included.

Key features

  • Over a hundred 3D elements and dozens of presets
  • Shape to Balloon for shapes and text
  • Cloth Pinning without Edit Mode
  • DynaString simulated cable
  • Simple shaders and PNG sequences
