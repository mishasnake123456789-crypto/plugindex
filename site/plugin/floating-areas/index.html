What Floating Areas does

Floating Areas is a small Blender add-on for opening an editor area in its own window. That is handy on multi-monitor setups where you want a timeline, node editor or viewport on another screen.

Shortcut keys trigger the action quickly. It supports Blender 3.0 through 4.1, ships with documentation and a demo video, and is distributed under the GPL.

Key features

  • Opens any area in a new window
  • Shortcut keys for quick access
  • Supports Blender 3.0 to 4.1
  • Demo video and documentation included
