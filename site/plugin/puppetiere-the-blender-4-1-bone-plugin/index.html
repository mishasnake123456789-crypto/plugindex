What Puppetiere: The Blender 4.1+ Bone Plugin does

Puppetiere is a rigging and animation plugin for Blender 4.1 and above, gathering armature tools across object, edit and pose modes.

Its Bone Director toggles between native and Puppetiere UI with display options and deform filtering. Edit mode adds renaming, Z axis forcing, flipping, name swapping and incremental chain renaming; pose mode clears modifications and copies constraints. Snaps store mesh points and align bones, heads, tails or the cursor, and Collection Tools export the previewed UI to a Python script for animators.

Key features

  • Bone Director with deform filtering
  • Rename, flip and swap bone tools
  • Mesh point snapping for bones
  • Export the UI as a Python script
