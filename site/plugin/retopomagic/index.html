What Retopomagic does

RetopoMagic is a retopology tool that works directly in the 3D Viewport. Using gestures and real-time visual feedback, you draw new topology that is projected onto a high-resolution target.

It is accessible from the N-Panel or through a Ctrl+Shift+R pie menu. A floating HUD shows contextual hints and an opacity slider adjusts edge brightness. New points snap onto the target surface, and dropping one point on another welds them together. Character and prop artists can build clean quad layouts.

Key features

  • Gesture-based retopology in the viewport
  • Points snap to the target surface
  • Auto-weld when dragging points together
  • Floating HUD with hints and opacity slider
  • N-Panel tab or Ctrl+Shift+R pie menu
