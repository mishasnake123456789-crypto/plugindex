What Export Curve To Json does

Export Curve To Json, by Quint-Vrolijk, exports curve data from Blender as JSON and reads it again later. Poly, Bezier and Nurbs curves are supported, and the commands appear in the File Import and Export menus.

Export options cover world-space coordinates, up and forward axes, and scale, and the files record details such as the object name. It is useful for passing path data to external code, games or custom tools that read JSON.

Key features

  • JSON import and export of curves
  • Poly, Bezier and Nurbs support
  • World space, axis and scale settings
  • Records object names
  • Available in File menus
