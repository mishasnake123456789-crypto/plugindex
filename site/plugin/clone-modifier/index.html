What Clone Modifier does

Clone Modifier from ITOOSOFT procedurally duplicates any geometry object. Choose how many clones you want, then adjust displacement, rotation and scale; the settings remain editable at any time so nothing has to be redone.

Copies can be given random rotation, translation and scale, and material IDs can be randomized using a seed value. Several Clone modifiers stack to build one, two or three-dimensional arrays. It suits artists making repeated elements such as tiles, railings, shelves and architectural patterns, who prefer a parametric approach over manual copying.

Key features

  • Procedural cloning of any geometry
  • Incremental translation, rotation and scale
  • Random transforms and material ID randomization
  • Fully non-destructive
  • Stackable for 1D, 2D and 3D arrays
