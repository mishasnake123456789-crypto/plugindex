What Caption Cat does

Caption Cat from mamoworld tools creates animated social media captions without leaving DaVinci Resolve. Transcription happens inside the application with AI speech-to-text supporting 112 languages, so nothing needs to be uploaded to third-party services, and there is no subscription.

A range of animated caption presets give different styles, and social media safe zones appear as visual overlays in the viewer to prevent captions from clashing with platform UI elements. Designs can be saved as reusable presets, which keeps branding consistent across videos. Editors making short-form content for social platforms will find the process much faster than building captions manually.

Key features

  • In-app captioning inside DaVinci Resolve
  • AI speech-to-text in 112 languages
  • Animated caption presets
  • Social media safe-zone overlays
  • Reusable presets for consistent branding
