What Gh Script Manager does

GH Script Manager is a lightweight add-on for people who write and run Python scripts in Blender, including technical artists and add-on developers.

Create new scripts with a click, browse and launch them from the N-panel, open the script folder, and refresh the list on demand. External editors such as Notepad++ and VS Code are supported. The UI uses collapsible sections and works on Windows, macOS and Linux.

Key features

  • Create and launch scripts from the N-panel
  • External editor support
  • Open script folder and refresh list
  • Windows, macOS and Linux
