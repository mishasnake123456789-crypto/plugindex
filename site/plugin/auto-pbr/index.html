What Auto-Pbr does

Auto-PBR is a Blender add-on that creates seamless PBR textures from text prompts, using ComfyUI with the Flux 2 Klein backend.

It produces full sets: Albedo, Normal, Roughness, Metallic, AO and Height, tileable for game and real-time use, and builds the shader automatically. Useful for fast material concepts. Under the hood you get prompt-based AI texture generation, albedo, Normal, Roughness, Metallic, AO and Height, seamless tileable outputs and automatic shader building.

Key features

  • Prompt-based AI texture generation
  • Albedo, Normal, Roughness, Metallic, AO and Height
  • Seamless tileable outputs
  • Automatic shader building
