What Legacy Ci Workspace does

Legacy Ci Workspace connects Premiere Pro to Sony's Ci Media Cloud. Editors can bring files from Ci Workspace into project bins and send sequences, project files or bins back up.

Sequences can be rendered through Adobe Media Encoder with preset or custom profiles. Comments from Ci turn into timeline markers, and markers can be exported back or saved to a text file. Edits can be shared for review through Ci MediaBox, with enterprise content management features available.

Key features

  • Import from Ci Workspace into bins
  • Upload sequences, projects or bins
  • Render via Media Encoder profiles
  • Comments as timeline markers
  • Share for review using Ci MediaBox
