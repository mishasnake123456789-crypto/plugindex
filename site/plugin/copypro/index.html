MaxScript that moves objects between 3ds Max files while keeping asset paths intact, including proxies, textures and IES.

What COPYPRO does

COPYPRO moves objects from one 3ds Max file to another while keeping asset paths intact, so you do not have to relink anything after pasting. It supports the V-Ray, Corona and FStorm renderers.

Proxies, textures and IES files travel with the objects, and RailClone objects and Forest Pack trees are also handled. The tool displays the size of the temporary folder it uses. Testing covered 3ds Max 2022 to 2024. Visualization artists who assemble scenes from several sources can save a lot of the cleanup that normally follows copying.

Key features

  • Copies objects between files without relinking
  • Works with V-Ray, Corona and FStorm
  • Handles proxies, textures and IES files
  • Supports RailClone objects and Forest Pack trees
  • Shows temporary folder size
