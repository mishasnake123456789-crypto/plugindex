Lets you view and change Blender attribute data in a table, with bulk value entry and formula-based editing.

What Attribute Manager does

Attribute Manager shows Blender attributes in a table where values can be typed directly. Domains include points, edges, faces, corners and whole objects, which covers most of the data Geometry Nodes artists deal with.

A single value can be applied to every row at once across many elements, and expression-based editing allows arithmetic on the values. Changes show up instantly. Technical artists building procedural setups will find it faster than editing attributes one at a time.

Key features

  • Spreadsheet-style attribute table
  • Vertex, edge, face, corner and object modes
  • Batch value application
  • Expression-based editing
