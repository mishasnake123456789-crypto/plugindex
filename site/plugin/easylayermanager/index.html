A Blender viewport HUD for creating, ordering and toggling layers instead of using the Outliner.

What Easylayermanager does

Easy Layer Manager provides a layer system inside the Blender viewport, offered as an alternative to working in the Outliner. A clean HUD can be dragged and resized, so you control layers without opening another editor.

Layers are created without setup and reordered by drag and drop. Shift and Ctrl multi-selection allows batch toggling of visibility, render visibility, selection and lock, there is search, and selected objects can be assigned to a layer in one click. Artists who prefer a layer workflow similar to other 2D and 3D programs, and who manage busy scenes, will find it a lighter option.

Key features

  • Draggable, resizable viewport HUD
  • Drag-and-drop layer ordering
  • Batch toggle of visibility, render, selection and lock
  • Layer search
  • One-click assignment of selected objects
