Offline Blender add-on that runs modeling, animation and render commands by voice using the Vosk speech engine.

What Audio Assistant does

Audio Assistant lets you speak commands to Blender. Recognition runs offline on your machine with Vosk, so no internet connection or cloud service is involved.

Commands cover modeling, transforms, modifiers, viewport navigation and rendering, with phrases such as ADD CUBE, ROTATE, ADD MIRROR MODIFIER and RENDER IMAGE. A commands.json file maps spoken phrases to Blender Python code, so you can define your own. It can help hands-busy workflows and accessibility.

Key features

  • Offline voice control with Vosk
  • Commands for modeling, modifiers, navigation and rendering
  • Custom phrases via commands.json
  • No internet needed
  • Phrases mapped to Python code
