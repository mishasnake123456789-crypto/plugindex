What Easy Fishes does

Easy Fishes animates a fish along a path you sketch yourself. Draw a curve in the viewport, import your fish model, set start and end frames and press Animate Fish.

The body bends naturally along the curve, orientation and belly-down posture are corrected automatically, and the output is organized into tidy collections. It saves animators from rigging fish for simple swim cycles in scenes such as aquariums and underwater shots.

Key features

  • Freehand path drawing in Edit Mode
  • Body bends naturally along the curve
  • Automatic orientation and posture
  • Auto-organized output
