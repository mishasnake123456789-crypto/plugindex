What Data-Block Utilities does

Data-Block Utilities lives in Properties, Scene Overview and helps you clean up Blender files.

It lists which data-blocks use others in a filterable tree, combines redundant node groups, materials, images, meshes and lights, and ranks node trees by how alike they are. Clicking a data-block jumps to where it is used. Useful for tidying merged or imported scenes. Large projects that have grown through appending and linking often accumulate duplicates, and this tool makes it easier to find and consolidate them safely.

Key features

  • Filterable data-block users tree
  • Merge duplicates of many data types
  • Node tree similarity scoring
  • Click to jump to usage
