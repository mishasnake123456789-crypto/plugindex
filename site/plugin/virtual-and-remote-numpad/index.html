What Virtual And Remote Numpad does

Virtual And Remote Numpad is designed for laptop users without a physical numpad. A virtual numpad in the N-panel gives one-click view navigation.

A lightweight local server also opens a responsive web numpad on a smartphone, tablet or browser on the same network, so you can control viewport navigation remotely. Standard numpad functions are included. Highlights cover virtual numpad in the N-panel, web numpad for phones and tablets and local server on the same network.

Key features

  • Virtual numpad in the N-panel
  • Web numpad for phones and tablets
  • Local server on the same network
  • Standard numpad functions
