Socket-based node extrusion for Blender with a context menu of the most common connectable nodes.

What Node Extrude Addon does

Node Extrude brings the node-dragging convenience of other node-based packages to Blender. Pull from a socket and a dynamic, categorized context menu lists the nodes most often connected to that socket type.

Suggestions are socket-aware, for example Separate XYZ for a vector output or Combine RGB for a color input. This reduces searching through menus when building shader, geometry or compositor trees. Day to day, that covers extrude nodes from sockets, categorized context menu and socket-aware suggestions.

Key features

  • Extrude nodes from sockets
  • Categorized context menu
  • Socket-aware suggestions
  • Speeds up node tree building
