Auto instances

Developer: Osetrov

Free3ds Max
Download Free

3ds Max script that finds objects with identical geometry and converts them to instances to cut RAM and file size.

What Auto instances does

Auto instances scans a 3ds Max scene for objects whose geometry is exactly the same and turns them into instances. The result is lower RAM consumption, smaller scene files and faster saving and opening.

Rotation and scale are preserved during conversion. A Just Select Preview option highlights instantiable objects without changing the scene and reports object and triangle counts. TurboSmooth modifiers at the top of the stack are kept, and the modifier stack can optionally be collapsed first. It works only with geometric objects, not splines or lights. It is handy for optimizing downloaded models and heavy scenes.

Key features

  • Converts identical geometry into instances
  • Preserves rotation and scale
  • Preview selection with object and triangle counts
  • Keeps top-of-stack TurboSmooth modifiers
  • Optional modifier stack collapse
