What Replace With Copy does

Replace With Copy by Brrainz substitutes many objects with duplicates of a chosen template in a single step. Select the template first, then Shift-select the targets and choose the command from the Object menu while in Object Mode.

Each replacement keeps the original's transform and scene position. Copies carry separate mesh data by default, and holding Alt makes them share linked data instead. It is handy for swapping placeholder blocks with final assets or updating repeated props.

Key features

  • Template-first selection workflow
  • Keeps transforms and scene placement
  • Unique data by default, linked with Alt
  • Runs from the Object menu
