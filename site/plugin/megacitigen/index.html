What Megacitigen does

MegaCitigen builds sprawling cities in Blender from lines and planes that you provide, using displacement maps to add detail and populating the result with crowds and traffic.

The package includes the CEL environment tool for seas, deserts and clouds with animated sun and cloud movement, a camera system with one-click setup, and an import/export tool for custom assets and exporting a city to Unreal Engine 5. A compositor module handles atmosphere. It suits establishing shots, skylines and large environment projects.

Key features

  • City generation from lines and planes
  • Crowds and traffic
  • CEL sky, sea and desert tool
  • One-click animation camera system
  • Custom asset and Unreal Engine 5 export
