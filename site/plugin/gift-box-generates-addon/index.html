What Gift Box Generates Addon does

Gift Box Generates Addon, by Togsdesign, produces gift boxes quickly for seasonal scenes. You add a box, choose a cube or cylinder shape, and then randomize its dimensions and a decorative flower.

Version 1.5 includes 30 random textures across several themes, and you can use your own image textures, including seamless ones. Themes can be mixed in a single scene. Documentation is included.

Key features

  • Cube or cylinder gift boxes
  • Random dimensions and flower options
  • 30 textures in multiple themes
  • Supports your own seamless textures
