Blender add-on for displaying, editing, filtering, rendering and converting colored point clouds with hundreds of millions of points.

What Point Cloud Visualizer does

Point Cloud Visualizer lets Blender handle colored point cloud data from scans. The viewport can show hundreds of millions of points, bounded only by available system and graphics memory.

Points live on any Blender object and stay outside Blender data until converted, for maximum performance. Supported inputs include PLY, LAS/LAZ, E57, PCD and text types such as PTS, XYZ, TXT and CSV, and several can be written back out. Editing, filtering and rendering are supported. Surveyors, archviz artists and VFX teams working with LiDAR or photogrammetry gain a practical viewer.

Key features

  • Hundreds of millions of points in the viewport
  • Imports many scan formats, from PLY to E57 and CSV
  • Edit, filter, render and convert
  • Points stay outside Blender data for speed
