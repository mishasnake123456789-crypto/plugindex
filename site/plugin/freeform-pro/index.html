What FreeForm Pro does

FreeForm Pro is Mettle's professional 3D mesh warp plugin for After Effects. It bends and deforms layers as three-dimensional meshes, and it pairs with GEOlayers to build 3D terrains based on real geographic data.

Multi-frame rendering is supported, along with native Apple Silicon, and the Primitives section includes an interval frame texture sampling mode. It is compatible with After Effects 2020 through 2026 and several CC versions. Motion designers can use it for warped surfaces, flags, cloth-like shapes and map-based visuals.

Key features

  • Pro-level 3D mesh warping
  • Works with GEOlayers for real-data terrains
  • Multi-frame rendering
  • Native Apple Silicon
  • Interval frame texture sampling in Primitives
