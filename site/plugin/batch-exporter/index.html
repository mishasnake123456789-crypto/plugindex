3ds Max script for exporting many objects at once, merging meshes parented to helpers into single named objects.

What Batch Exporter does

Batch Exporter by N00BYZOR speeds up exporting numerous objects from 3ds Max. Meshes parented to a point helper or dummy can be merged and exported as one object, while instances are kept non-destructively, and the merged result takes the helper's name and pivot location.

A Merge All Nodes option decides whether such objects are merged before export. Formats include OBJ, MAX and VRSCENE, a keyboard shortcut can be bound to exporting the selection, and files can go to the folder of the current scene. Objects whose names start with an underscore are skipped. Handy for game asset and kitbash pipelines.

Key features

  • Merges meshes parented to points or dummies
  • Merged objects take helper name and pivot
  • Exports OBJ, MAX and VRSCENE
  • Keyboard shortcut for exporting the selection
  • Underscore-named objects ignored
