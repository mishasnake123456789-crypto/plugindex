What Vertex Group Assistant does

Vertex Group Assistant is a Blender add-on by Maro3D that helps move rigging data from one object to others, with VRChat avatar outfits in mind. It copies vertex groups off the active object and parents the selected objects to its armature, handling several targets together.

It can also tidy up afterward by deleting vertex groups with no weights and bones that no vertex group uses, with an option to duplicate the armature before bones are removed. Everything lives in the Vertex Group Assistant submenu of Object, Vertex Groups.

Key features

  • Transfers vertex groups to multiple targets
  • Parents selected objects to the armature
  • Deletes vertex groups without weights
  • Removes bones unused by any vertex group
  • Optional armature duplicate before cleanup
