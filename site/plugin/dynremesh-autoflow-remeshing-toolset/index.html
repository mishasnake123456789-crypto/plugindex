What Dynremesh/Autoflow- Remeshing Toolset does

DynRemesh/AutoFlow helps with retopology of triangle-heavy sculpts and 3D scans in Blender. It performs the required quad-remeshing steps with a single click.

A preset bar detects the polygon count and suggests an option, and density can be set through Density, Decimation and Subdivision controls. A weight paint operator defines density by painting, QuadriFlow works on Windows and Linux, and Relax and Smooth options are included. Auto-Update refreshes the mesh when settings change. Sculptors preparing models for rigging or game use gain a faster start.

Key features

  • Single-click quad remeshing
  • Preset bar recommends options by poly count
  • Density, Decimation and Subdivision control
  • Weight paint density
  • QuadriFlow on Windows and Linux
