What Fluidlab does

FluidLab, from BeFX Studios, helps create fluids in Blender. Release 1.2 brought Foam, Bubbles and Spray systems on top of the core fluid tools.

It includes documentation and runs on Blender 4.1 through 5.1. VFX artists producing water, splashes and similar liquid effects can add secondary detail like foam and spray without building the setups from scratch. Secondary effects like foam and spray are what make a fluid read as water in motion, so having them in one add-on is convenient.

Key features

  • Foam creation system
  • Bubbles creation system
  • Spray creation system
  • Supports Blender 4.1 through 5.1
