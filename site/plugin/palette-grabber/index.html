Extracts color palettes from reference images with k-means and applies them as Principled BSDF materials.

What Palette Grabber does

Palette Grabber creates palettes from pictures and from color theory. Using k-means clustering, it finds the dominant colors of a reference image, with an adjustable color count of 3 to 32 and a seed for repeatable results.

Swatches can be edited in the N-panel through Blender's color picker, and palettes are applied as Principled BSDF materials to selected objects. It can also generate harmony-based palettes. Handy for stylized scenes and concept color matching.

Key features

  • K-means dominant color extraction
  • 3 to 32 colors with reproducible seed
  • Editable swatches in the N-panel
  • Harmony-rule palette generation
