Manages UV layers across many selected Blender objects: set, create, delete, copy and reorder channels.

What Batch Uv Tools does

Batch UV Tools applies UV map operations to several objects at once. Set or Create Active Map activates a UV map on each selection and creates it if it is missing.

Delete Active Map removes a UV channel by name from all selected objects, and Set Active Render Map picks the render channel everywhere. Copying and reordering of UV channels are included. It saves time on scenes where imported assets use inconsistent UV layers.

Key features

  • Set or create UV maps on all selected
  • Delete a UV channel by name
  • Set active render map
  • Copy and reorder UV channels
