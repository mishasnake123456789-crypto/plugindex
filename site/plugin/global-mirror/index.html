What Global Mirror does

Global Mirror tackles the hassle of keeping many Mirror modifiers consistent in Blender. The Global Mirror modifier on the active object acts as the master and pushes its settings to all other instances in the scene.

Set the mirror object once and every part mirrors around it. Axis, bisect, flip, merge limit and related options all sync from the active object. A Global Mirror entry appears in the Add Modifier menu under Generate, and it covers every mesh in the file carrying the modifier. Hard-surface modelers building symmetrical vehicles, robots or weapons, archviz artists and character artists doing armor will benefit.

Key features

  • Master modifier drives all linked ones
  • Single mirror object for the whole scene
  • Syncs axis, bisect, flip and merge limit
  • Available from Add Modifier menu
  • Covers every mesh in the file
