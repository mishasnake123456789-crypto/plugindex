What Data Viewer - Attribute Visualizer For Blender Geometry Node does

Data Viewer displays Geometry Nodes data in the viewport so values can be checked without opening the spreadsheet editor. From the geometry node editor, it previews IDs, indices, positions and other attributes right on the model.

IDs or indices of vertices, edges and faces appear directly, a gradient option colors values from small (blue) to large (red), and an axes display maps red, green and blue to X, Y and Z, with darker shades marking lower values. Procedural modelers debugging node trees will find it far quicker than comparing numbers in a table.

Key features

  • Attributes shown directly in the 3D view
  • Vertex, edge and face IDs and indices
  • Blue-to-red gradient for value size
  • Axes display mapping RGB to XYZ
