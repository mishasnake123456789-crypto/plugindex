What Objswapper does

Objswapper exchanges object locations in Blender with a single click from its panel.

It works with two or any number of objects and supports Empty objects, so keyframed animations can use it. It runs in Blender 3.0 through 3.5 with Cycles and Eevee and is GPL licensed. Useful for product animations and motion graphics where items trade places. The panel keeps the operation simple, so exchanging the places of several props takes seconds instead of manual moves and keyframe edits.

Key features

  • Swap two or more objects at once
  • Panel-driven swap
  • Supports Empty objects for keyframes
  • Blender 3.0 to 3.5
  • GPL license
