What pt_EffectSearch 3 does

pt_EffectSearch 3 by Paul Tuersley is a script for After Effects that locates effects throughout a project. Search for a specific effect by name, find those that are missing or come from third parties, and enable or disable them in bulk.

Another feature links other effects to a chosen control effect: pick an effect in the list and use Set Control Effect from the link menu. Version 3.6 added support for pseudo effects. It runs on After Effects releases from CS4 up to 2026, helping troubleshoot inherited projects with unknown plugin dependencies.

Key features

  • Search for effects within a project
  • Find missing or third-party effects
  • Turn effects on or off
  • Link effects to a control effect
  • Pseudo effect support, CS4 through 2026
