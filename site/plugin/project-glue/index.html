Refactors multi-file Blender projects: rename or move files and data-blocks while references update automatically.

What Project Glue does

Project Glue makes reorganizing multi-file projects safer. Renaming or moving a file updates every reference to it, and renaming a data-block remaps its users.

Data-blocks can be moved to other files even when those files already use them. Quick Link lets you type what you need and pick from matching data-blocks to link. It suits pipelines with linked libraries and shot files. You get reference updates on rename or move, data-block renaming with user remap and quick Link search, along with the rest of the feature set.

Key features

  • Reference updates on rename or move
  • Data-block renaming with user remap
  • Quick Link search
  • Move data-blocks between files
