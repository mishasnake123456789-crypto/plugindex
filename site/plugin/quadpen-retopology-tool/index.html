What Quadpen - Retopology Tool does

QuadPen is a retopology tool for Blender based on drawing. You paint quads and guides directly over a high-resolution mesh while adjusting segments, edge flow and density along the way.

Guides and quads are generated automatically as you stroke, segment count can change mid-stroke for fine control, and guides can be straightened or rerouted so topology follows the flow you want. It suits character artists building clean production meshes. Working by drawing feels natural compared with placing vertices one by one, and it helps keep edge loops flowing where they matter for deformation.

Key features

  • Draws quads and guides over the mesh
  • Adjustable segments while drawing
  • Straighten and re-route guides
  • Control of edge flow and density
