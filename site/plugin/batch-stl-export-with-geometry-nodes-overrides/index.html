What Batch STL Export with geometry nodes overrides does

This Blender add-on automates STL export for several collections at once. You map collections to output files, and it writes each one without repeating the export dialog.

Its distinguishing feature is support for geometry nodes overrides during export, so parametric variations can be applied to the objects as they are written. People who 3D print families of parts or produce many variants from a node setup can generate every file in one pass.

Key features

  • Batch STL export
  • Maps collections to output files
  • Geometry nodes overrides applied
  • Useful for 3D printing variants
