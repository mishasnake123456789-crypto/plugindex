What Export Autocad DXF Format (.dxf) does

Export AutoCAD DXF Format sends Blender geometry out as DXF R12 files. It was a bundled add-on in Blender 4.1 and is now a standalone extension provided with limited support.

The command is in File > Export > AutoCAD DXF. It supports Blender 4.2 LTS and later, is licensed under GPL v2 or later, installs by drag and drop or from disk, and asks for file access to write into your export folder. Designers handing models to CAD or laser-cutting software can use it to share shapes.

Key features
