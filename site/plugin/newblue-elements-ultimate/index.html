What NewBlue Elements Ultimate does

NewBlue Elements Ultimate brings together tools for keying and compositing in After Effects, DaVinci Resolve and Premiere Pro. It pairs Chroma Key Pro with the Alpha Blend and Energize sets, adding presets for green screen, overlays and creative effects.

Chroma Key Pro keys green or blue backgrounds using presets or full manual controls, with one-click visualisation masks and built-in extras such as drop shadows and outlines. Alpha Blend offers eight compositing tools and over 80 presets, including Garbage Matte, Luma Key and Viewfinder, while Energize adds six tools and more than 60 presets, such as Active Camera and Reflection. Editors handling green screen work get a broad toolkit.

Key features

  • Chroma Key Pro with presets and manual controls
  • Alpha Blend: 8 tools, 80+ presets
  • Energize: 6 tools, 60+ presets
  • Garbage Matte for cleaning keys
  • Presets for common green screen cases
