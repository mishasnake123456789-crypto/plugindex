Blender add-on with an F6 pie menu that collects buried operators and multi-step actions for Object and Edit Mode.

What Fastactions does

Noodleware's Fastactions gathers hard-to-find Blender operators in a pie menu on F6. It also merges tasks that would otherwise require several separate operator calls in Object and Edit Mode.

One example creates a collection from the selection, named for the active object, linking or moving contents and optionally compensating instancing offsets. Transform tools help align objects. Modelers and layout artists who repeat such actions will keep their hands near the mouse and work faster.

Key features

  • F6 pie menu for buried operators
  • Collection creation from selection
  • Instancing offset compensation
  • Alignment and transform tools
  • Combines multi-step operations
