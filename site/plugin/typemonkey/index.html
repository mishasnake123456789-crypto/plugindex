What TypeMonkey does

TypeMonkey by Orrin Zucker generates kinetic type animation inside After Effects. Rather than hand-keyframing every word, you enter parameters in a control panel and it produces a random layout complete with a camera that follows the text.

Timing is tied to markers, so adjusting the pacing means sliding a marker instead of editing keyframes. Words spread evenly across the comp or work area, and size, position, rotation and opacity can be tweaked afterward. A range of type transitions are chosen randomly or set manually, and Marker Sync matches existing marker layers.

Key features

  • Generates kinetic type layouts from panel settings
  • Keyframe-less, marker-driven timing
  • Parented camera that tracks each new word
  • Randomly chosen or manual type transitions
  • Marker Sync to existing marker layers
