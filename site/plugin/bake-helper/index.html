What Bake Helper does

Bake Helper simplifies texture baking in Blender. It creates and assigns image maps automatically and can bake a separate map for each material.

It works with both Blender Render and Cycles, with a button to choose the engine, and bakes all objects marked in its list or a single selected object. Good for reducing repetitive setup. Automating the repetitive image creation and assignment speeds up preparing texture maps for game assets and lighting bakes.

Key features

  • Auto-create and assign image maps
  • Separate map per material
  • Blender Render and Cycles support
  • Bake a list or a single object
