A creative coding plugin for After Effects that runs Processing-like code, GLSL and Lua.

What PixelsWorld does

PixelsWorld brings code-driven visuals into After Effects. You can write Processing-like scripts, GLSL shaders (including code taken from shadertoy.com) and Lua, then render the results as layers.

Lua gained lighting functions in later updates, 3D geometry can be rendered through a spreadsheet, and code presets are easy to apply and share. Built-in effects include Flares, 3D Cloud, 3D Ocean, Toon Cloud, a filtered checker and Colorful tris. Great for generative art and procedural backgrounds.

Key features

  • Processing-like code support
  • GLSL including shadertoy.com code
  • Lua scripting with lighting functions
  • 3D geometry through SpreadSheet
  • Built-in effects and shareable presets
