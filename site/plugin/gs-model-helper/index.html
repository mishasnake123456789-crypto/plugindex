What GS Model Helper does

GS Model Helper by DaKashi gathers the small chores involved in preparing Goldsource, the Half-Life engine, models in Blender. Instead of renaming and fixing pieces manually, you run them from one set of tools.

It includes a prefix renamer covering skeletons and vertex groups, a left and right swapper, and a converter between Valve and Gearbox limb naming. Texture interpolation can be switched between closest and linear, materials can be renamed with the .bmp extension enforced, and a vertex cleanup option helps tidy meshes.

Key features

  • Prefix renamer for skeletons and vertex groups
  • Left/right and Valve/Gearbox limb name swappers
  • Closest or linear texture interpolation controls
  • Material renamer enforcing .bmp
  • Vertex cleanup tool
