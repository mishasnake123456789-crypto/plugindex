What Bodymovin - Lottie does

Bodymovin is the After Effects extension that created the Lottie workflow. It exports a composition as a JSON file that the bundled lottie.js player can render in a browser using SVG, canvas or HTML, and the same files can play natively on iOS and Android.

Only a subset of After Effects features can be exported. That subset includes shape paths, ellipses, stars, rectangles, fills, strokes and gradients, standard transforms, trim paths, masks, rounded corners, drop shadows and text, which can be exported as shapes or live text. Expressions are partly supported, along with expression sliders and time remapping.

Key features

  • Exports Lottie animations as JSON
  • Renders in browsers via SVG, canvas or HTML
  • Shapes, gradients, transforms, masks and trim paths
  • Text exported as shapes or live text
  • Partial expression and time remap support
