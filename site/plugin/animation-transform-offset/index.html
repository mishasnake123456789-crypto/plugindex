What Animation Transform Offset does

Animation Transform Offset transforms an object and shifts its entire animation at once in Blender.

Shift+G, Shift+R and Shift+S move, rotate or scale while animation curves are offset by the same delta, so each keyframe keeps its relative value. Animators repositioning a finished animated asset avoid re-keying. Offsetting the animation together with the object keeps motion intact, which is useful when relocating a cycle, a prop or a whole shot element.

Key features

  • Shift+G, R and S shortcuts
  • Offsets entire animation curves
  • Keeps relative keyframe values
  • Works on move, rotate and scale
