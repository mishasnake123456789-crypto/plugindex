What Mouse-Look Navigation™ Addon does

Mouse-Look Navigation reworks how you move around the Blender viewport. As an alternative to the default orbit, pan, zoom, dolly, fly and walk controls, it adds ZBrush-style navigation and first-person-like movement, with isometric view snapping on top.

ZBrush mode is aimed at tablet users: the same button paints or sculpts when you click on geometry and navigates when you click the background. You can switch between navigation modes without leaving the operator, cancel viewport changes from any mode, and use FPS-like movement in all modes. Sculptors and anyone arriving from other 3D packages will find the controls more familiar.

Key features

  • ZBrush-style navigation mode for tablets
  • FPS-like movement in all navigation modes
  • Switch modes without exiting the operator
  • Cancel viewport changes from any mode
  • Isometric view snapping
