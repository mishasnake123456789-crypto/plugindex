3ds Max script that builds animated presentations of scenes or models by generating entry, exit and turntable keyframes.

What Showcaser does

Showcaser creates animated project presentations in 3ds Max from static scenes or models. You choose objects, order and parameters, press Build Animation, and position, rotation and scale keyframes are generated.

In Scene mode the scene builds up object by object; Model mode shows elements singly, each with an entry and exit animation. Movement, rotation, scale and abrupt appearance can be combined with easing from linear to spring inertia. Turntables can be parametric or custom, objects are loaded by selection, name, layer or group and sorted automatically, and sets animate together according to size, layer or quantity. Timing and overlap are configurable, and proxies and plugins are supported.

Key features

  • Scene mode and Model mode presentations
  • Combinable move, rotate, scale and pop animations with easing
  • Parametric or custom turntable
  • Load and order objects by name, size, position or layer
  • Group animation and timing/overlap controls
