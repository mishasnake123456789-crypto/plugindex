Scans pasted text for time values and turns each into a button that moves the Premiere Pro playhead there.

What Jumper does

Jumper, made by REDDESK, reads text and finds anything that looks like a time. Each match becomes a clickable button, and pressing it moves the playback point in the sequence to the same time.

It understands several ways of writing timecode, with colons, semicolons or no separators, and handles patterns made of hours, minutes, seconds and frames as well as shorter minute-and-second entries. That makes it handy for working through client notes, transcripts or review emails full of timestamps. It works with Premiere Pro 23.0 and later.

Key features

  • Finds time values in text data
  • Turns each match into a clickable button
  • Jumps the playhead to the matching time
  • Accepts colon, semicolon or no-separator formats
  • Hour/minute/second/frame and shorter patterns
