What NodeKit does

NodeKit by Ebberts + Zucker is an After Effects toolset for graphics built from nodes and connections. It helps motion designers assemble flowcharts, network diagrams and infographics without constructing each piece by hand.

Nodes can be created and arranged with layout tools, connected together within a chart, and then animated. The system is designed to be simple, flexible and intuitive. It works with After Effects CC 2018 through 2026 and suits explainer videos about systems, data or organizational structures.

Key features

  • Create node-based charts and diagrams
  • Layout tools for arranging nodes
  • Connect nodes within a chart
  • Animate the finished graphic
  • Compatible with CC 2018 to 2026
