What Folder Fanatic does

Folder Fanatic from BPMograph helps After Effects users keep project panels tidy. You can create custom folder structures, manage them, and reuse them across projects so every file starts from the same layout.

Rule sets define how items are organized, and a one-click action sorts assets into place. This standardizes how teams build projects and cuts down on manual dragging. It works with After Effects 2024, 2025 and 2026.
