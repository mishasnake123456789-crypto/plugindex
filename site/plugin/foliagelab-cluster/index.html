What Foliagelab - Cluster does

FoliageLab Cluster builds foliage clusters from existing meshes. It reads meshes from any Blender collection, treats LOD0 objects as actors, and stores higher LOD levels automatically using a naming convention such as Leaf_A_LOD0 and Leaf_A_LOD1.

Meshes are assigned to buckets and placed on anchor points, with rotation, scale, deformation and vertex normals controlled per group. A clean LOD chain is then baked. Real-time artists making tree and bush assets can iterate quickly.

Key features

  • Detects meshes from any collection
  • LOD groups recognized by naming convention
  • Buckets and anchor point scattering
  • Per-group rotation, scale, deformation and normals
  • Bakes a clean LOD chain
