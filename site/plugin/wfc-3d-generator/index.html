What WFC 3D Generator does

WFC 3D Generator is a free Blender add-on that runs the Wave Function Collapse algorithm to generate 3D structures from building blocks stored in a source collection. A constraint editor panel assigns supported constraints to objects, using geometry and connector types.

A render delay lets you watch the generation unfold, and you can pause or cancel it whenever you wish. Layout is controlled through grid size, cell size, and an offset applied between even and odd rows, columns and files, and a cherry-picking function starts generation from selected pieces. It suits procedural levels, buildings and tile-based assets.

Key features

  • Wave Function Collapse generation
  • Constraint editor with geometry and connector types
  • Pausable, cancelable generation view
  • Grid, cell size and offset controls
  • Cherry-picking to seed the result
