Saves snapshots of After Effects effect stacks so you can switch between states quickly.

What Snapshot FX does

Snapshot FX lets artists capture an effect stack at a given moment and return to it later. This is helpful during look development, when you try several variations and want a safe way to compare or roll back.

You can apply a full snapshot or update only chosen components. Snapshots are managed with search, filtering and tags, and a directory jump-list helps build a library or keep project-specific settings. Lists sort by name, time, layer or comp, and Boolean search with NOT is supported. Layers stay linked through markers, even after renaming.

Key features

  • Snapshots of whole effect stacks
  • Apply fully or update selected components
  • Search, filtering and tagging
  • Directory jump-list for libraries
  • Boolean and scoped search
