What Spatial Reality Display Plugin for Preview (3ds) does

Spatial Reality Display Plugin for Preview lets 3ds Max users see their 3D creations on Sony's Spatial Reality Display, working directly from 3ds Max. It loads scenes and transfers them to the display.

Animation of an object can be started or stopped, the camera position for the display is adjustable, and Spatial Clipping clips the front and top planes of the view space. Position, angle and other properties of the shown model can be changed following the operation guide, and a PDF manual explains general usage. Designers can check depth and form on a physical 3D display.

Key features

  • Load and transfer scenes to the Spatial Reality Display
  • Start and stop object animation
  • Camera position setting
  • Spatial Clipping of front and top planes
  • PDF manual with usage instructions
