3ds Max script by Chuggnut that warps and scales an object, or a camera, by typing its matrix directly in local space.

What Matrix demon does

Matrix demon lets you enter an object's transformation matrix directly in 3ds Max and see the object change accordingly. This makes it possible to shear, warp and scale objects in ways that the ordinary transform tools do not offer.

It works in local space and can also be applied to cameras, which opens possibilities for matching specific projections or distortions. The script is free and runs inside 3ds Max. Technical artists comfortable with matrices, as well as those experimenting with unusual transforms, can use it to achieve exact numeric results.

Key features

  • Direct matrix input to warp and scale objects
  • Works in local space
  • Can be applied to cameras
  • Runs as a 3ds Max script
