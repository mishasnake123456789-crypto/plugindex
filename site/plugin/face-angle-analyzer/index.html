What Face Angle Analyzer does

Face Angle Analyzer, by Astralis, measures how selected faces are oriented in Blender. In Edit Mode it draws angle readouts and arcs over the viewport, showing the angle from each global X, Y and Z axis.

It can also display the Euler rotation needed to align a face to a reference plane that you set to X, Y or Z. Axes are color coded and can be toggled individually, line thickness and arc radius are adjustable, and several faces can be recalculated in a click. Handy for technical and architectural alignment work.

Key features

  • Angles from global X, Y and Z axes
  • Euler rotation to align with a reference plane
  • Color-coded axes and angle arcs
  • Adjustable line thickness and arc radius
  • One-click recalculation for multiple faces
