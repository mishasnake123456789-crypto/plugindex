What Pipeline Manager does

Pipeline Manager by active clay adds production pipeline basics to Blender, especially for freelancers and small studios. One click builds a full studio folder structure for a project.

Ghost sync copies stray textures into the project every time you save, and iterative saving increases the version number automatically so earlier work is not overwritten. It also generates lightweight proxies. Teams that lack a dedicated pipeline get organization with little setup.

Key features

  • One-click studio folder structure
  • Ghost sync copies stray textures on save
  • Iterative saving with version increments
  • Lightweight proxy generation
