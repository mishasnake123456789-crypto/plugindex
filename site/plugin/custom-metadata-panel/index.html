What Custom Metadata Panel does

The Custom Metadata Panel lets teams edit the metadata that matters in one tailored panel inside Premiere Pro, without coding XML. Tabs can follow schemas such as IPTC, PLUS and the Astronomy Visualization Metadata Standard.

Form fields include text, numbers, URLs, tags, dropdowns, dates, checkboxes, tables, calculations and maps from GPS. Adobe Experience Manager fields are supported, along with a form editor with import, export and presets. It can also read and write non-XMP metadata from MP4, MOV and Office files. DAM managers will find it useful.

Key features

  • Customizable tabs for IPTC, PLUS and other schemas
  • Many form field types including GPS maps
  • Adobe Experience Manager fields
  • Built-in form editor with presets
  • Reads and writes non-XMP metadata
