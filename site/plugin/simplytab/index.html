What Simplytab does

SimplyTab tames a crowded N-panel sidebar. You can build custom tab groups, pin the tabs you need most, and hide or reorder others with one click, while the tab order stays synchronized with the sidebar.

Layout settings can be exported and imported between projects, and documentation is included. It suits anyone running many add-ons who wants a tidy, personalized interface. Day to day, that covers custom tab groups, pin essential tabs and hide and reorder with one click.

Key features

  • Custom tab groups
  • Pin essential tabs
  • Hide and reorder with one click
  • Import and export layouts
