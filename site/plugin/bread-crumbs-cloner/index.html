What BREAD CRUMBS CLONER does

Bread Crumbs Cloner is a 3ds Max script for planning motion. It clones or marks an object and places the clone as far from the original as the original is from another specified object, along the same vector, leaving a trail like bread crumbs.

This makes it handy for spacing animation of walks, runs, slow ins and slow outs. Version 3 can capture and mark distance from any position, and the distance can be divided or multiplied by any amount, with clones or markers placed at those distances. The script was written in 3ds Max 8 and appeals to animators who rely on spacing charts.

Key features

  • Clones or marks objects at equal offsets along a vector
  • Helps space walks, runs and slow ins and outs
  • Version 3 captures distance from any position
  • Divide or multiply distances by any amount
  • Scripted in 3ds Max 8
