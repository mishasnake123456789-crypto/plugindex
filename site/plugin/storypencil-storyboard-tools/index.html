What Storypencil - Storyboard Tools does

Storypencil prepares Blender for storyboarding with Grease Pencil. By antoniov, it was part of the Blender 4.1 bundle and is now offered separately with limited support.

A Setup Storyboard Session command in the Draw menu configures the project. Version 1.2.0 repairs breakage from Blender API changes and targets Blender 4.4 and newer; older releases have earlier versions. It needs no special permissions. Animators and directors planning shots can sketch boards and keep them linked to scenes.

Key features

  • Setup Storyboard Session in Draw menu
  • Works with Blender 4.4 and newer
  • 1.2.0 fixes for API changes
  • Earlier versions for older Blender
