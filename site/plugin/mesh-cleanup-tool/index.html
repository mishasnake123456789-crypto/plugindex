What Mesh Cleanup Tool does

Mesh CleanUp Tool collects common repair operations in one Edit Mode interface so meshes are ready for production or export. It runs in Edit Mode.

Remove Doubles merges overlapping vertices using an adjustable distance, Dissolve Degenerate Geometry clears zero-area faces, stray edges and loose elements, and Smart Dissolve removes redundant edges and vertices past an angle threshold. Further fixes are included. Modelers handling imported or scanned geometry can tidy it in one place.

Key features

  • Remove Doubles with merge distance
  • Dissolve Degenerate Geometry and loose elements
  • Smart Dissolve by angle threshold
  • Single Edit Mode interface
