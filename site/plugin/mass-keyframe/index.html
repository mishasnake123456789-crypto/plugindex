What Mass Keyframe does

Mass Keyframe, by StratosDerg, removes the repetition of animating the same property across many objects in Blender. Select the objects, right-click a property, and choose an option to keyframe all of them.

Add Keyframe to Selected Objects inserts a key on each using their own values, while Duplicate Keyframe to Selected Objects copies the active object's value onto all. Version 1.1.8 supports more properties, including physics. It is pure Python and needs no special permissions.

Key features

  • Keyframe one property on all selected objects
  • Add Keyframe to Selected Objects
  • Duplicate Keyframe copies the active value
  • Right-click property menu
  • Physics properties supported since 1.1.8
