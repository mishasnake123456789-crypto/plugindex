What Id Map Maker For Substanace Painter does

This Blender add-on prepares models for ID map baking used in Substance Painter. It gives every selected object its own unique color, which saves manual material setup.

Apply ID MAP Colors creates non-overlapping materials, Material Cleanup strips existing materials from the selection, and the objects can be arranged in a non-overlapping grid around the world origin. Back to Original returns them to their starting positions in one click, and the ID map itself is baked right in Blender. It speeds up texturing prep.

Key features

  • Unique color per selected object
  • Non-overlapping material setup
  • Material cleanup
  • Grid layout with one-click restore
  • ID map baking inside Blender
