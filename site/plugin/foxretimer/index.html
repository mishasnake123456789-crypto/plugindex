What foxRetimer does

From foxScripts comes foxRetimer, a script for After Effects that handles speed changes of nested compositions. Retiming precomps normally means adjusting layers and keyframes inside, and this script makes the job easier.

It supports After Effects from CS6 through 2026. Version 1.3 introduced speed enhancements, the latest release adds macOS Tahoe 26 support, and fixes address hidden keyframes and locked layers. A demo video is available. Animators who need to speed up or slow down nested animations will find it useful.

Key features

  • Retiming for nested compositions
  • Compatible with CS6 through 2026
  • Speed enhancements since version 1.3
  • macOS Tahoe 26 support
  • Fixes for hidden keyframes and locked layers
