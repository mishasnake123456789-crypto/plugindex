What Horde Add-On: Procedural Crowd Tools does

Horde Add-On brings configurable crowd systems with animated 3D characters into Blender scenes. It is built on geometry nodes and boids and uses a four-step setup with a clear panel.

Crowds can be drawn directly into the scene, with Walk, Run and Static animation modes. Four character sets are included: Human Professional, Human Casual, Zombie Bare and Zombie Clothed. Filmmakers and environment artists can populate streets, events and zombie scenes.

Key features

  • Draw crowds into the scene
  • Walk, Run and Static modes
  • Four character sets
  • Geometry nodes and boids based
