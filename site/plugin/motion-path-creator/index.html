What Motion Path Creator does

Motion Path Creator is a Blender add-on by Blenderbob that builds motion paths for objects, bones, empties and vertices. Select one and click its button in the viewport's animation tab.

A checkbox toggles between the whole timeline and a custom start/end range. The size of path dots is adjustable, each path can have its own color, and one reset command clears every path made. It supports Blender 4.2 LTS and newer. Animators can use it to check arcs and spacing.

Key features

  • Paths for objects, bones, empties, vertices
  • Full timeline or custom frame range
  • Adjustable path dot radius
  • Color per path
  • Reset deletes all generated paths
