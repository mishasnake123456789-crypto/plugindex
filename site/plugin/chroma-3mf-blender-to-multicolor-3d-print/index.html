What Chroma 3Mf - Blender To Multicolor 3D Print does

Chroma 3Mf is a Blender extension that carries color from Blender to the .3mf format so slicers and printers see the same colors. It targets multicolor FDM and full-color printers.

Texture to Face Color conversion happens in two stages: an analysis and baking step reads the material nodes, samples colors and converts them into face color attributes. A real-time preview material is generated automatically for checking results before export. Makers can print textured models without manual repainting.

Key features

  • Texture to Face Color conversion
  • Samples colors from material nodes
  • Automatic preview material
  • Exports color data to .3mf
