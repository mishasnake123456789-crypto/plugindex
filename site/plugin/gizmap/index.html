A Blender add-on for adjusting material mapping translation, rotation and scale with a viewport gizmo.

What Gizmap does

GizMap lets you control a material's mapping directly in the 3D viewport rather than typing values into a Mapping node. Moving the cursor over a mesh drives a vector gizmo, which is linked to the mapping node either automatically or one you choose.

It handles translation, rotation and scale, supports both UV and Object mapping, and centers UV rotation and scaling on the gizmo location. A dedicated Object mapping mode helps with decals when UV mapping falls short, and mapping can be adjusted across several materials on one mesh. Texture and lookdev artists placing patterns on surfaces will find it quicker than node editing.

Key features

  • Control mapping from the 3D viewport
  • Translation, rotation and scale
  • UV and Object mapping support
  • Special Object mapping for decals
  • Works across multiple materials on a mesh
