What 3D Cursor Tools: Draw Axis, Draw Grid, Align, Transform, Viewpoints, List does

APEC's collection focuses on the 3D cursor. It can draw a cursor axis and a cursor-aligned grid in the viewport, with grid spacing connected to the scene's Unit System and Length.

Cursor alignment uses the selection and offers location, rotation or both, with tweaking afterwards, and works across multiple objects in object mode. Further tools tweak the cursor's angles so the X or Y axis can be lined up again, switch viewpoints, provide a tools pie and keep a list of stored cursor positions. Precision modelers can place new geometry more easily.

Key features

  • Draw cursor axis and aligned grid
  • Align cursor to selection
  • Tweak cursor angles
  • Tools pie menu
