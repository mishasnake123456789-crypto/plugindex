What AEJuice Loop does

AEJuice Loop is an After Effects script for making things repeat. Select what you want to loop, click, and it detects the selection type and applies the most suitable method.

It works on layers, footage, compositions, paths and masks, with cycle and pingpong options. It also corrects a time remap bug present in some After Effects versions, and integrates with kBar. Animators needing seamless background motion or repeating cycles can skip hand-written loop expressions.

Key features

  • Loops layers, footage, comps, paths and masks
  • Cycle and pingpong types
  • Automatic selection detection
  • Fixes a time remap bug in some versions
  • kBar integration
