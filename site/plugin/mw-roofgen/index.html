Generates hip roofs from any closed spline outline in 3ds Max, with roof angle and optional tile UVs.

What MW RoofGen does

MW RoofGen 2 makes hip roof geometry from a closed spline. Pick a shape, set the roof angle and press Create. Rectangles, L-shapes and freeform outlines all work, and the ridge intersections for each shape are resolved automatically.

Several selected splines can be processed in one pass. Optional UV generation uses a grounded slope projection with bottom edges at V=0 and U=0 at the edge start, and width and height inputs in world units set the real tile size and drive UV scale. Architectural modelers get a faster way to roof irregular footprints.

Key features

  • Hip roof from any closed spline
  • Handles rectangles, L-shapes and freeform outlines
  • Automatic ridge intersection solving
  • Multiple splines in one pass
  • Optional tile UVs in world units
