What Voxel Sorter does

Voxel Sorter converts video into a miniature voxel landscape built from small cubes. You can tilt the view, add lighting and apply pixel sorting in three dimensions, giving ordinary footage a distinctive blocky, sculpted appearance.

Blend parameters fade the effect in and out smoothly. A Generate Depth feature, part of the Pro tier, creates depth maps and works in 16-bit. The plugin runs in After Effects, DaVinci Resolve, Premiere Pro, Media Encoder and Nuke or NukeX, and its latest update lowered GPU memory use on Resolve's 16-bit paths.

Key features

  • Converts footage into a 3D voxel world
  • Tilt, light and pixel-sort the result
  • Blend parameters for smooth transitions
  • Generate Depth (Pro) with 16-bit support
  • Lower GPU memory use in Resolve 16-bit
