What three.js ObjectLoader does

three.js ObjectLoader, by crwde, moves geometry between Blender and the web library three.js using its JSON object scene format, version 4 and later. Both import and export are supported.

Exports include vertices, UVs, normals and vertex colors along with the full object hierarchy, and coordinate conversion between the two systems happens automatically. Web developers who model in Blender can get assets into their scenes without writing converter scripts.

Key features

  • Direct three.js JSON import and export
  • Vertices, UVs, normals and colors
  • Full object hierarchy support
  • Automatic coordinate conversion
