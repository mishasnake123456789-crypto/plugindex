What Shape Key Manager - Advanced Shape Key Workflow does

Shape Key Manager helps keep large sets of shape keys under control. You can create unlimited custom groups, mute or unmute keys instantly to reduce clutter, and remove empty or unused ones.

Batch renaming handles many keys at once, and the tools are optimized for large shape key lists. Facial animators and character artists dealing with hundreds of blendshapes can navigate them more easily. In practice that means unlimited custom groups and instant mute and unmute.

Key features

  • Unlimited custom groups
  • Instant mute and unmute
  • Remove empty and unused keys
  • Batch rename
