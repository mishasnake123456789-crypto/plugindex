What Foliage Paint Tool does

Foliage Paint Tool recreates Unreal Engine's foliage painting in Blender. It uses weight paint so you draw where you want an object placed, and it is scattered over the target surface.

Any object can be scattered onto any other object, which suits environments, sci-fi scenes and similar uses. A direct way to populate terrain with plants and props. Painting is faster than placing objects by hand and makes it easy to adjust density, so forests, debris fields and sci-fi detail can be arranged quickly.

Key features

  • Unreal-style foliage painting
  • Uses weight paint
  • Scatter any object onto any object
  • Suits environments and sci-fi scenes
