What Layer Random Shifter does

Layer Random Shifter is an After Effects script that scatters the timing of several layers at once. Select your layers, set a range, and each one is offset randomly within it.

It works across versions from CS6 through 2026, and a UI issue in After Effects 2026 was fixed in version 2.2. It is free. Animators building staggered, organic starts for particles, text pieces or repeated elements avoid nudging each layer manually.

Key features

  • Random time offsets for selected layers
  • User-defined shift range
  • Operates on multiple layers at once
  • After Effects CS6 through 2026
  • Free
