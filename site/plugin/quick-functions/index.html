Three-in-one Blender add-on with a Shift+Q pie menu, one-click sky or volumetrics, and a context object panel.

What Quick Functions does

Quick Functions gathers shortcuts into one add-on. A Shift+Q pie menu offers context-dependent options that normally take several clicks across tabs.

You can add volumetrics, a sky texture or an infinite plane in one click, reach commonly used object properties in a context panel, and control sky rotation and elevation using a sun object. It streamlines scene setup. Day to day, that covers shift+Q context pie menu, one-click volumetrics, sky, infinite plane and context object panel.

Key features

  • Shift+Q context pie menu
  • One-click volumetrics, sky, infinite plane
  • Context object panel
  • Sun-based sky control
