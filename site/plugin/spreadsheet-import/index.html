What Spreadsheet Import does

Spreadsheet Import is a Blender add-on by smonbrogg that brings CSV or JSON data into Blender's spreadsheet, where geometry nodes can process and display it. Before importing, you declare field names and data types by hand with the plus icon.

Each import yields a new object named for the file, holding mesh data called csv_data or json_data. For CSV you set the delimiter and can skip lines above the header; JSON import takes field names from the objects in a data array you specify. This lets you build charts and data-driven visuals directly from your own datasets.

Key features

  • Imports CSV and JSON into the spreadsheet
  • Manual field names and data types
  • New object named after the file
  • CSV delimiter and header-skip options
  • JSON field names read from a data array
