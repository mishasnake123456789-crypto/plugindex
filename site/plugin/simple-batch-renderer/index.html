What Simple Batch Renderer does

Simple Batch Renderer works from collections. Each batch setup picks collections or object hierarchies to show, a camera angle to use, and its own resolution and world, so one file can produce many different images.

You can keep unlimited batch setups. Output names are generated automatically with optional date prefixes, and every batch can write to its own subfolder. Product visualizers and archviz artists producing variations of one scene will avoid repeated manual switching and rendering.

Key features

  • Renders collections or hierarchies per camera
  • Unlimited setups with own resolution and world
  • Automatic naming with optional date prefix
  • Per-batch subfolders
