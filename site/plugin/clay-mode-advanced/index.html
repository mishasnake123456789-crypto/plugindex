3ds Max script that applies a ZBrush and Mudbox style matcap clay look to the viewport through an on-the-fly ShaderFX override.

What Clay Mode Advanced does

Clay Mode Advanced mimics the viewport shading found in sculpting applications like ZBrush and Mudbox. A ShaderFX shader with matcap UVs is generated on the fly and set as the viewport override material, and the rendering-setting override mode is switched on.

It works as a toggle from a button or an assigned shortcut. Thirty matcaps come with the download, and you can add your own through the Matcaps textures folder. The chosen matcap path is stored so it persists between sessions. Modelers get a clearer view of form and surface detail than the default shaded view provides.

Key features

  • ZBrush and Mudbox style clay shading in the viewport
  • ShaderFX matcap shader built on the fly
  • Toggle via button or shortcut
  • 30 included matcaps plus custom ones
  • Matcap choice persists between sessions
