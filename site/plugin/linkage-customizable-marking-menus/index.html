What Linkage Customizable Marking Menus does

Linkage Customizable Marking Menus gives Blender a set of radial-style menus you summon right over the viewport, so frequently used tools are a gesture away rather than buried in header menus.

There are three separate menus: two for Object Mode and one for Edit Mode. Shift plus Ctrl with the left mouse button opens the first Object menu and the Edit menu, while the right button opens the second Object menu. Each can be filled from the add-on preferences with preset tools or a searchable Custom Operator. It supports Blender 4.2 to 4.4 under the GPL license.

Key features

  • Marking menus that open directly in the viewport
  • Three menus: two for Object Mode, one for Edit Mode
  • Fill menus with preset tools or custom operators
  • Shift + Ctrl + mouse button hotkeys
  • Compatible with Blender 4.2 to 4.4
