What Node Align(节点对齐) does

Node Align tidies node layouts from a pie menu that appears on Shift+Q or Ctrl+Q. It handles edge alignment, even distribution, grid layouts and tidy links.

Nodes can be aligned to left, right, top or bottom edges, or matched in height and width. Distribution works vertically, horizontally and evenly, including in relative or absolute grids where rows or columns can be changed, and custom spacing is allowed. Shader and compositing artists keep large graphs readable.

Key features

  • Pie menu on Shift+Q or Ctrl+Q
  • Edge alignment and size matching
  • Vertical, horizontal and grid distribution
  • Custom spacing
