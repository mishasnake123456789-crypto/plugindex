What BVE Import/Export does

BVE Import/Export is a Blender add-on by Kusaanko for railway simulator content. DirectX X (.x) files for BVE can be imported and exported, and CSV can be written for BVE and OpenBVE alike.

X files are handled with vertices, faces, normals, materials and textures, in text, binary or zipped binary form. OpenBVE CSV features include SetColorAll, LoadTexture, SetBlendMode, SetWrapMode, NighttimeTexture, SetDecalTransparentColor and EnableCrossfading, and an OpenBVE CSV Properties material node sets them. Route and train object creators can model in Blender.

Key features

  • Imports and exports DirectX .x for BVE
  • CSV export for BVE and OpenBVE
  • Text, binary and zipped-binary X formats
  • OpenBVE features like SetBlendMode and NighttimeTexture
  • OpenBVE CSV Properties material node
