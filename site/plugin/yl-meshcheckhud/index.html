What YL MeshCheckHUD does

YL MeshCheckHUD highlights topology problems right in the Blender viewport, so you can repair a model and see the issues disappear as you work. Three parts make up the tool: Check Mode, a Heatmap Preview and a Realtime HUD.

Check Mode marks common issues on the mesh and lists a count per issue type in the sidebar, refreshing on its own. Detected problems include ngons and overlapping vertices, among others. It suits modelers preparing clean meshes for animation, games or export.

Key features

  • Check Mode shows topology issues on the model
  • Sidebar counts per issue type, updated live
  • Heatmap Preview
  • Realtime HUD
  • Detects ngons and overlapping vertices
