What Ragdoll Tools does

Ragdoll Tools creates ragdoll physics for armatures in Blender. A ragdoll can be added to simple armatures and many commonly used rigs with one click, and the setup is non-destructive so it can be deleted whenever needed.

Hitboxes can follow bones softly, animation can be transferred to bones in one click, and ragdolls can be selected, copied and given constraint limits. Left-right symmetry is easy to maintain. Animators and game artists can produce falling or collapsing character physics quickly.

Key features

  • One-click ragdoll on common rigs
  • Hitboxes follow bones softly
  • Animation transfer to bones
  • Constraint limits and ragdoll copying
