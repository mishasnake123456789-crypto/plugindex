What Custom Theme Settings does

Custom Theme Settings lets you tailor how Blender looks without digging through the Preferences themes.

Button, text and background colors can be changed, along with header and tab appearance, button roundness and text size. You can also set the emission colors used for selected and active objects in the 3D viewport. All options sit in one panel with real-time preview, and the add-on is light on performance. Changes can be previewed instantly, so finding a comfortable look is straightforward.

Key features

  • Customize button, text and background colors
  • Header and tab appearance
  • Button roundness and text size
  • Viewport selection emission colors
  • Single panel with live preview
