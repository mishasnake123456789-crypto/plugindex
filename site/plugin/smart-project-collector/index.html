What Smart Project Collector does

Smart Project Collector gathers everything a scene depends on. It looks across all Blender data types for external references and copies them into a new organized structure.

Assets are categorized as Images, Videos, Audio, VDB, Alembic and Cache, with support for custom categories and handling of FLIP Fluids cache. Paths are updated automatically. It is useful for archiving, handing projects to collaborators and moving a job to a render farm.

Key features

  • Detects assets across all data types
  • Sorts by Images, Videos, Audio, VDB, Alembic, Cache
  • Custom folder categories
  • Paths updated automatically
  • FLIP Fluids cache handling
