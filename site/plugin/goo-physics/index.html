What Goo Physics does

Goo Physics from DillonGoo Studios adds one-click secondary physics to Blender, tuned for stylized movement while leaving artists in control.

A custom geometry nodes setup offers anime-style motion, including collisions and wind, and a cloth setup built on Blender's native cloth suits lengthy bone chains such as ponytails, braids and tails. Character animators can add follow-through quickly. Setup is intended to be fast, so animators can get convincing swaying hair, fabric and tails in a few moments and then refine the settings by eye.

Key features

  • Geometry nodes setup with collisions and wind
  • Native-cloth-based bone chain simulation
  • Hair, props and soft bodies
  • Stylized movement with artist control
