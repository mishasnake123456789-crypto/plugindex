What Marker Conductor 3 does

Marker Conductor 3, made by SUNRISE MOON, is a plugin for After Effects that lays down markers at regular spacing. Whether you are cutting to a tempo or dividing a timeline evenly, it saves placing each marker by hand.

Separate Time and BPM tabs each provide a Duration field. A Setting tab defines the marker comment template, using placeholders for count, time, frame, BPM and beat, and composition-time comment options are available. The plugin works with After Effects from CC 2017 through 2026.

Key features

  • Markers at time or BPM intervals
  • Time and BPM tabs with Duration field
  • Comment templates with count, time, frame, bpm and beat
  • Composition-time comment options
