Blender add-on that drops each newly added object at the location of the selected object.

What Instant Placer does

Instant Placer changes where new objects appear in Blender. Rather than landing at the 3D cursor, an object added with Shift-A is placed at the selected object's position.

You can also choose to copy location, rotation and scale from the selection. Options sit in the viewport under Tools > Instant Placer, and the behavior can be turned off at any time. Documentation is included. It saves repeated moving when you build a scene from many parts.

Key features

  • Places new objects at the selected object
  • Works with the normal Shift-A menu
  • Optionally copies location, rotation and scale
  • Settings under Tools > Instant Placer
  • Can be disabled anytime
