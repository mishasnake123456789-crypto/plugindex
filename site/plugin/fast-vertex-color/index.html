What Fast Vertex Color does

Fast Vertex Color (FastVC) assigns vertex colors in Blender without entering Vertex Paint mode. It works in Object and Edit mode and handles multiple objects.

A swatch palette supports fill, pick, select by color and randomize, and fills adapt to vertices, edges, faces, face corners or whole objects. Selection tools include select similar and gradient faces. It also bakes per-material ID mask textures by direct UV rasterization with no cages or rays, accelerated by Numba, which helps texturing in Substance Painter and InstaMAT.

Key features

  • Swatch palette with fill, pick and randomize
  • Works in Object and Edit mode
  • Selection by color and similarity
  • Per-material ID mask baking
