What Mirror To Instance does

Mirror To Instance, by Oleksii Sereda, replaces mirror modifiers with instanced copies of the object. It was written with game development pipelines in mind.

A single button performs the conversion, carrying over the same settings except for geometry merging and clipping. Documentation is provided by the developer.

Key features

  • Converts mirror modifiers to instances
  • One-button operation
  • Keeps the same mirror settings
  • Targets game development pipelines
