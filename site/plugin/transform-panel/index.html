What Transform Panel does

Transform Panel by shigeru ozawa gathers object manipulation commands in one place for a tidier workflow. Apply Armature applies an armature to objects, and Apply Transform handles location, rotation and scale.

Transform Reset returns values to their defaults, origin tools reposition an object's pivot, and further options deal with animation-related transformations. It is aimed at everyday modeling and animation tasks where the same cleanup steps recur. Gathering these commands into one panel cuts down on hunting through menus during repetitive object cleanup.

Key features

  • Apply Armature
  • Apply location, rotation and scale
  • Transform Reset
  • Origin adjustment
  • Animation-related transformations
