3ds Max 4.x quad menu script that resizes the width, height and taper of many bone objects in one operation.

What BoneSizer does

BoneSizer adds a quad menu option to 3ds Max for resizing bones. Rather than adjusting each bone individually, it changes width, height and taper of many bone objects in a single operation.

This is a great help on rigs that contain dozens of bones, where uniform display sizing makes the skeleton readable. The script is by Chuggnut, was built for 3ds Max 4.x, is at version 2.3.5 and is free. Riggers and character artists who tidy up skeletons will use it to get consistent bone shapes quickly.

Key features

  • Quad menu option for resizing bones
  • Adjusts width, height and taper
  • Resizes many bones in one operation
  • Built for 3ds Max 4.x
  • Version 2.3.5
