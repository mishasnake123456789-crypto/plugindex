What B Palettes does

B Palettes is a Blender add-on by Dinesh007 for moving color palettes in and out of Blender. It reads GPL, ASE, ACO, PAL, CLR, CSV, CSS and TXT files, and exports palettes in the GPL format for use in other applications.

Version 1.1.0 brought batch import and export for GPL files. CSV reading copes with hex codes, RGB values or a mix, skipping text that isn't a color, and CSS parsing recognizes hexadecimal, RGB and HSL colors, converting HSL to RGB. Painters can reuse palettes from other software.

Key features

  • Imports GPL, ASE, ACO, PAL, CLR, CSV, CSS and TXT
  • Exports palettes as GPL
  • Batch import and export since 1.1.0
  • Flexible CSV parsing
  • CSS parsing with HSL to RGB conversion
