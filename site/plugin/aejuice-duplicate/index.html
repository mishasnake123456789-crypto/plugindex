What AEJuice Duplicate does

AEJuice Duplicate is an After Effects script for copying compositions that contain nested compositions. Normal duplication leaves nested comps shared with the original, which can cause surprises; this script makes everything independent.

After copying, it updates and relinks expressions automatically so they point at the new copies. It integrates with kBar and runs on After Effects CC 2015 through CC 2022 and newer. It helps artists building variations from complex templates without breaking the originals.

Key features

  • Fully independent comp copy with nested comps
  • Automatic expression relinking
  • kBar integration
  • Compatible with CC 2015 and newer
