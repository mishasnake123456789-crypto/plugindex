What Cut-n-Paste does

Cut-n-Paste is a Quadmenu item from Chuggnut that transfers a transform from one object to another in 3ds Max. Copy from the source, then paste onto the target, and the target takes on the transform.

It makes use of Chugg_globals, which is described in the help text that comes with it, and was written for 3ds Max 4.x. The version is 2.3.5. It is useful for matching positions and orientations between objects quickly without typing numbers or using the Align tool, and fits naturally into the right-click menu workflow.

Key features

  • Copies a transform and pastes it onto another object
  • Runs from the 3ds Max Quadmenu
  • Uses Chugg_globals, explained in the help text
  • Written for 3ds Max 4.x
  • Version 2.3.5
