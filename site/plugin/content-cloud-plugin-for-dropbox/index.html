What Content Cloud Plugin for Dropbox does

Content Cloud Plugin for Dropbox places your Dropbox files inside After Effects and Premiere Pro through a dedicated panel. Instead of switching to a browser or file manager, you can find an image, audio clip or video and bring it straight into your project.

Assets can be previewed in the panel, dragged into the app, uploaded back, or linked. It handles several Dropbox accounts and supports Teams folders. The developer states it carries no analytics or tracking code and collects no usage data, which suits teams with strict privacy rules.

Key features

  • Preview images, audio and video in the panel
  • Download, upload and drag-and-drop handling
  • Multi-account switching
  • Teams Folder access
  • No analytics or tracking code
