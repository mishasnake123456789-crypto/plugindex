Exports videos from Premiere Pro or After Effects and uploads them to a Slack channel or user.

What SlackOut does

SlackOut combines export and delivery. It names the file with an automatic incrementing scheme, lets you pick an export preset, including custom ones, and writes to an export folder beside the project or a folder of your choice.

The video can then be uploaded to Slack, either to a channel or a person, with an option to delete the local file afterwards. Settings are remembered per sequence. It works in both Premiere Pro and After Effects.

Key features

  • Automatic incrementing file names
  • Quick export preset selection
  • Export folder beside project or custom
  • Upload to a Slack channel or user
  • Settings stored per sequence
