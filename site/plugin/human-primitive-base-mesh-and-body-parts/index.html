What Human Primitive - Base Mesh And Body Parts does

Human Primitive is a Blender addon by TinkerBoi that makes human base meshes and typical body parts available as primitives in the Shift+A Add menu. It leans toward lower-poly models and offers several detail levels and topology styles to begin from.

Bodies can come with either a Rigify rig or a metarig, and hands come with a basic rig for posing. Fiddly parts like hands, feet, eyes and ears are provided, along with a simple unoptimized UV map for basic texturing. It gives character artists and game developers a quick start for figures.

Key features

  • Base bodies and body parts added as primitives
  • Several detail levels and topology styles
  • Optional Rigify rig or metarig
  • Hands with a basic posing rig
  • Basic UV map for texturing
