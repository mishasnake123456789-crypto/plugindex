What Batch Operations™ Smart Data-Manager does

Batch Operations is a data manager for Blender that lists and manages data such as modifiers, materials and collections throughout the open file, the scene or visible objects. It is built for cleaning up large scenes.

Select, add, remove, apply, copy and paste actions run on many items at once, and results can be filtered and searched with your own settings. The tools appear as an add-on tab, floating panel, pie menu or right-click menu. Version 1.2.0 supports Blender 5.x and 1.1.7 covers 3.6 through 4.5, with full online documentation.

Key features

  • Bulk operations on modifiers, materials and collections
  • Scope: file, scene or visible objects
  • Filtering and search with custom settings
  • Tab, floating panel, pie menu or context menu
  • Versions for Blender 3.6 through 5.x
