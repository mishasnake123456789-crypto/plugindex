Adds a review system inside Blender where comments attach to objects, collections or the whole project with snapshots and status.

What Viewnotepro does

ViewNote Pro brings feedback into the scene itself. Comments can be attached to individual objects, entire collections or the project as a whole.

Each note has open or resolved status, can store a viewport snapshot, and can show overlays highlighting the areas that need attention. Supervisors and artists reviewing work can leave clear, located notes without exporting images or writing separate documents. Because the notes live in the scene itself, they remain attached to the objects they describe as the project moves between people.

Key features

  • Notes on objects, collections or the project
  • Open and resolved status
  • Viewport snapshot capture
  • Overlays highlighting problem areas
  • Feedback stays in the Blender file
