What Camera Tracker 6 (New Features!) does

Camera Tracker 6 from CGMatter solves camera movement from footage inside Blender. It relies on photogrammetry for automatic camera and tripod solves, avoiding the manual marker work of the built-in tracker.

Beyond basic solves it supports rotomation, variable focal length, dense point clouds, pinning, undistortion and object tracks. Documentation is included. VFX artists matching CG elements to live-action plates can set up scenes faster, even when the lens zoomed during a shot.

Key features

  • Automatic camera and tripod solves
  • Variable focal length support
  • Dense point clouds
  • Pinning and undistortion
  • Object tracks
