What 2D To 3D Logo + Dissolving Module does

This Blender add-on converts a 2D logo into a 3D-looking one and then dissolves it away. Rather than tracing the image into a model, it duplicates the logo picture across several layers to build depth.

You set the thickness and the number of layers, customize the material quickly, and use noise settings for a logo overflow look. The dissolving module links to a chosen mask, with controllable glow strength, a gradient ramp for glow color and animatable masks. A hundred masks come included to save and reuse. It is meant for fast logo intros and title reveals.

Key features

  • 2D logo to layered 3D with quick materials
  • Adjustable thickness and layer count
  • Noise-based overflow effect
  • Mask-driven dissolve with gradient glow
  • 100 reusable masks
