What Templater Bot Subscription Recurring does

Templater Bot Subscription Recurring from Dataclay extends Templater Rig in After Effects with full server automation. It lets you build applications that version, render and distribute custom video on demand, and this listing is the yearly recurring subscription.

A project can produce anywhere from 15 to over 15,000 unique videos from a data source, or generate one from web form input and then run a script to upload it. Scripts can fire after each render job or after all finish. Release 3.8.0 added per-target output configurations and footage validation for multi-target jobs.

Key features

  • Server automation for versioning, rendering and delivery
  • 15 to 15,000+ videos from a data source
  • Video from web form input with upload scripts
  • Scripts after each render job or the whole batch
  • Per-target outputs and footage validation (3.8.0)
