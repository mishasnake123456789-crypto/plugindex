What Stylized Toolkit: Create does

Stylized Toolkit: Create packs STK Lines, STK Color, STK Bake and Simplify, and STK Normal Map for non-photoreal styles.

STK Lines adjusts line width by depth, distance to the camera and focal length so lines read as 2D. A binding system attaches curves to a mesh and re-fits them with one click after it moves or deforms, and a snapshot feature captures perspective and deformation. It targets stylized animation and illustration.

Key features

  • STK Lines with depth-aware width
  • Curve binding to deforming meshes
  • Color, bake and normal map tools
  • Comic and hand-painted styles
