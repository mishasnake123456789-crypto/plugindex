What Blend-X-Web does

Blend-X-Web previews 3D scenes in a web browser with one click and exports them as standalone web packages. Blender projects become interactive viewers you can publish as a website.

Its lightweight design keeps performance smooth, and it is open source under the MIT license. It is helpful for showcasing models and portfolios online. You get one-click browser preview, standalone web package export and interactive viewers, along with the rest of the feature set.

Key features

  • One-click browser preview
  • Standalone web package export
  • Interactive viewers
  • MIT-licensed open source
