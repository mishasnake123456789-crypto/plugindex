Blender addon that adds overshoot and follow-through to keyframes directly in the Graph Editor, without simulation or baking.

What Momentum does

Momentum, by Isaac-Burke, introduces configurable follow-through to animation using only keyframes. There is no viewport simulation and nothing to bake, so the overshoots remain editable like any other animation data.

It is applied through a Momentum submenu within the Graph Editor's curve tools. Animators polishing a pass can add secondary motion such as settling and swing on controls and objects while staying in a standard curve-based workflow.

Key features

  • Follow-through built only from keyframes
  • No viewport simulation or bake
  • Applied from a Graph Editor submenu
  • Configurable overshoot
