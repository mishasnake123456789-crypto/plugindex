What MotionX does

MotionX from Oxygen Art provides a browsable catalogue of motion designs for presentations, social media and other video work. Pick one and it goes onto the timeline immediately, which spares you from building common animations yourself.

It can apply After Effects .ffx presets, plays preview sounds where available, such as transition previews with sound effects, and one package installs across several Adobe apps while showing only what the running application can use. Imported compositions can be retimed with In-Out, Stretch, Loop, Cut or None modes. Recent versions also support Adobe Audition.

Key features

  • One-click import and apply
  • Applies .ffx presets
  • Preview sounds for transitions
  • One package for several Adobe apps
  • Timing modes: In-Out, Stretch, Loop, Cut, None
