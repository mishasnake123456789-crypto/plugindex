What Quick Detail It does

Quick Detail-IT adds surface wear to materials without rebuilding node trees by hand. Wear effects like scratches, rust, dust, fingerprints and your own textures are layered using node routing that leaves the base material intact.

Noise-driven procedural details expose seed, scale and intensity settings in the sidebar. There are ten material categories, each with its own set of pre-packaged PBR textures. Texture artists and look-development specialists can age props quickly while keeping the original shader intact.

Key features

  • Non-destructive stacked surface details
  • Procedural noise with seed, scale and intensity
  • Ten material categories
  • Pre-packaged PBR textures
