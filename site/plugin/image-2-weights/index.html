Creates vertex weights in Blender by sampling image values through UV maps.

What Image 2 Weights does

Image 2 Weights lets you paint weights in an image editor and apply them to a mesh. It uses an object's UV map to read values from an image and writes them into vertex groups.

The result is weighted vertex groups that can drive armatures or object physics. It is released under the GPL license and includes documentation. Riggers and technical artists who prefer image-based control over brush painting can get repeatable weight maps from a texture.

Key features

  • Samples images through UV maps
  • Generates weighted vertex groups
  • Usable for armatures and physics
  • GPL license with documentation
