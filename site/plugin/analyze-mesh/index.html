What Analyze Mesh does

Analyze Mesh gives a quick topology report from Blender's side panel. One click returns snapshot counts of vertices, edges, faces, triangles, quads, ngons and edge poles.

In Edit Mode it analyzes the base mesh elements, while Object Mode includes modifiers for a result that matches the evaluated geometry. Modelers checking quality for games, animation or subdivision can assess meshes without third-party tools.

Key features

  • One-click topology check
  • Counts of verts, edges, faces and tri, quad, ngon and pole types
  • Edit Mode analyzes base mesh
  • Object Mode includes modifiers
