What Custom Graphic User Interface Modifier does

A 3ds Max plugin built as a scripted modifier lets you design a picker panel of your own, no MaxScript required. It is aimed at riggers and animators who want clickable controls for selecting parts of a character or triggering actions, without coding them by hand.

As many as 100 buttons can be added, each with its own size, placement, color, label, style and function. MaxScript and grouping features extend what a button can do. Setups can be imported and exported, a drop-down list switches between several CGUI modifiers in one scene, and a minimize option keeps the panel compact when it is not needed.

Key features

  • Build picker GUIs without MaxScript knowledge
  • Up to 100 customizable buttons
  • Adjustable size, placement, color, label and style per button
  • Import and export of setups
  • Drop-down to switch between multiple CGUI modifiers
