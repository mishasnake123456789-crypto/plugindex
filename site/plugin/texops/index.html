Blender add-on that bundles a channel packer, SVG rasterizer, image tools and folder-wide batch processing for textures.

What TexOps does

TexOps, by JR3DFUL, collects several texture chores in one Blender add-on. Instead of leaving the program to pack channels, convert vector art or invert maps, you can handle them from a single panel.

It includes a channel packer, an SVG rasterizer and an Image Tools section with invert operators and a dilation tool. In Current mode the tools act on the image open in the Image Editor, while Batch mode runs the chosen operation across every image in a folder, saving time on large texture sets.

Key features

  • Channel packer for texture maps
  • SVG rasterizer
  • Invert and dilation image tools
  • Current mode edits whichever image is active
  • Batch mode processes a whole folder
