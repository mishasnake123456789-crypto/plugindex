What Img2Pbr does

Img2Pbr is a Blender plugin that builds physically based materials from ordinary images. An Image to PBR Texture node does the conversion inside the Shader Editor, so you do not need a separate texturing app.

The workflow covers base color, metallic, specular, roughness, emission, normal, alpha, ambient occlusion and displacement. Procedural textures made with math and shader techniques are included as well, and everything works in both EEVEE and Cycles.

Key features

  • Image to PBR Texture node
  • Covers color, metallic, roughness, normal and displacement
  • Procedural textures included
  • Works in EEVEE and Cycles
