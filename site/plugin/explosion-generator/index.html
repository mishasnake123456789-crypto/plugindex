A Blender add-on that creates fully procedural, parameter-driven explosions with Eevee previews.

What Explosion Generator does

Explosion Generator builds explosions in Blender from parameters rather than a manual simulation setup. Because the effect is fully procedural, it responds to changes in the scene, which makes iterating on timing and scale faster than baking and re-baking.

You can set blast intensity, debris dispersion, speed and duration, preview the result in real time with Eevee, and use curve objects to control the shape and trajectory of the blast. Documentation is included. VFX artists and motion designers who need convincing blasts without deep simulation knowledge are the intended audience.

Key features

  • Procedural explosions that adapt to the scene
  • Blast intensity and debris dispersion parameters
  • Speed and duration per explosion
  • Real-time Eevee preview
  • Curve objects shape the trajectory
