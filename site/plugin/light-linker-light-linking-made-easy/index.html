What Light Linker - Light Linking Made Easy does

Light Linker from Oculis Studio simplifies a feature that can be fiddly to configure by hand. You pick an object and add a linked light, and the add-on arranges the link so that only that object receives the light.

It builds on Blender's own light linking system rather than replacing it, stays non-destructive and supports both Cycles and Eevee. Documentation is included. It is well suited to cinematic and product lighting where you want controlled highlights without spill onto the rest of the scene.

Key features

  • Uses Blender's native light linking
  • Automatic link setup from selected object
  • Light affects only the chosen object, no spill
  • Non-destructive workflow
  • Supports Cycles and Eevee
