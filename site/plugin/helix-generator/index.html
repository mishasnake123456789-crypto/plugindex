What Helix Generator does

Helix Generator, from Pixel Egg Studio, builds spirals and twisted forms in Blender with a few clicks. It wraps a helix around a straight line or along a bezier curve, which is useful for springs, coils, cables, ropes and braids that would be tedious to model by hand.

When the source curve is closed, the result is a closed curve too. Bezier curves are solidified only if you tick the option, and settings can be saved as presets. A preference lets you rename the N panel tab, and documentation is provided. Modelers creating cables, threads or decorative twists will find it quick.

Key features

  • Helixes around lines or bezier curves
  • Ropes and braids
  • Closed output for closed curves
  • Optional solidify and saved presets
  • Custom N panel tab name
