After Effects script that adds swaying motion to layers using Puppet Pins and a control layer.

What AutoSway does

AutoSway automates the gentle swaying of objects such as plants, banners or hanging items. Developed by ada scripts, it places Puppet Pins along the target layer between a start point and an endpoint, and then creates a SwayControl layer where the motion is tuned.

Options include a decay setting, converting curves to straight lines, curve adjustment and rotation, plus Bake and UnBake. It handles PseudoEffects itself, and a Help function is available from the question-mark button in the option menu.

Key features

  • Applies Puppet Pins from start to end point
  • SwayControl layer for adjustments
  • Bake and UnBake
  • Decay setting and curve options
  • Built-in PseudoEffects handling
