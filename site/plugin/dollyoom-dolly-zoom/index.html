What Dollyoom [Dolly Zoom] does

Dollyoom is a Blender add-on that creates the classic dolly zoom effect interactively. By dragging the mouse you change the camera's focal length while the subject holds a constant apparent size, shifting the background perspective.

It lives under 3D View > View > Navigation and starts with Alt+M. Shift gives finer adjustment, number keys set the focal length numerically, and C switches the focus point between the active object and the 3D cursor. Documentation is available from the developer. Animators and cinematographers can use it to test dramatic perspective shifts quickly.

Key features

  • Mouse-gesture dolly zoom on the scene camera
  • Alt+M shortcut to start
  • Shift for fine adjustment
  • Numeric focal length entry
  • Focus on active object or 3D cursor
