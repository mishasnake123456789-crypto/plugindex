What Fusion Nodes does

Hamen's Fusion Nodes adds shaders from Blackmagic Fusion to Blender. Nine nodes are provided for building realistic renders in your node setups.

They include Class and Master Shaders for general use, Reflect Shader, CTR Shader, Cook Torrance, GP/PB, Olympic, Phong and Ward shaders. After installation they work inside existing Blender node workflows, with documentation. Artists familiar with these shading models from Fusion can reuse that knowledge. Using familiar shaders can also help when recreating looks that were first developed in a compositing workflow.

Key features

  • Nine Fusion shader nodes
  • Phong, Ward and Cook Torrance
  • Class and Master shaders
  • Reflect and Olympic shaders
  • Works in existing node workflows
