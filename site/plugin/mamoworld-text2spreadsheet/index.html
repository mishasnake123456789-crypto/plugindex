What mamoworld Text2Spreadsheet does

Text2Spreadsheet moves the wording of an After Effects project into a spreadsheet, so translators or clients can edit it in Excel, Numbers or OpenOffice. Afterwards, one click writes the changes back into the project. No layers need renaming or marking beforehand.

The tables are simple and hold only text. The tool keeps track of where each string belongs even after layers and comps are renamed or moved, and picks up text added later. Multiple versions go in extra columns, with one text per row, and colour-coded status shows what changed. Output can be CSV or Excel XML, with filters, full UTF-8 and multi-line text.

Key features

  • One-click export and import of project text
  • Spreadsheet-friendly, text-only tables
  • Tracks texts through renamed or moved layers
  • Versions in extra columns, colour-coded status
  • CSV or Excel XML with filtering and UTF-8
