What Mgf Tools does

MGF's MGF Tools collects workflow utilities for 3D modeling across viewport display, object editing, UVs, scene optimization and import/export, and it supports Blender 3.0 to 4.2.

Quick origin moves an origin to the bottom, center or head in a click, while a custom origin gives 27 combinations. Object tools rename, select by type, apply transforms and set or clear parents; shading controls flip normals, set autosmooth and mark or clear sharp edges. Modelers get many small time savers in one place.

Key features

  • Quick origin with 27 custom combinations
  • Rename, select by type and parent tools
  • Flip normals, autosmooth and sharp edge controls
  • UV tools
  • Scene optimization and import/export helpers
