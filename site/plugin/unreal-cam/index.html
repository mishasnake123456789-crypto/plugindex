What Unreal Cam does

Unreal Cam adds a floating camera preview to the Blender viewport, so you can frame shots without leaving the viewport you are working in.

You can switch between cameras, adjust lighting from the preview and preview Cycles renders, and it works with both Cycles and Eevee. This helps layout and lighting artists who would otherwise jump between camera view and viewport. The feature set spans floating live camera preview and switch between cameras.

Key features

  • Floating live camera preview
  • Switch between cameras
  • Adjust lighting from the preview
  • Cycles preview, works with Eevee too
