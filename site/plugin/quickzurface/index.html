What Quickzurface does

Quickzurface is a utility pack from CG-Mechanics that combines ready-made shading assets with quick functions for Blender. It includes nine smart materials, usable from the node editor or the viewport, each with its own setting options, plus six node groups.

Quick functions include a one-click smooth bevel, a viewport quality feature, edge detection and a parallax setup. Documentation is included. It suits artists who want to apply attractive surfaces and finishing touches fast, without assembling nodes, especially for product shots and hard-surface renders.

Key features

  • Nine smart materials
  • Six node groups
  • One-click smooth bevel
  • Edge detection and parallax setup
  • Viewport quality feature
