What Hair Net does

Hair Net is a Blender plugin that turns guide geometry into hair particle systems. It is a complete rewrite of the earlier HairNet by Jandals, and speeds up groom creation by letting you shape hair with proxy meshes and curves.

Several proxy types can be converted in one go. Results can be added to an existing hair system or placed in a new particle system that links to or copies settings from another one. Root snapping moves hair roots onto the surface mesh without changing the guide shape.

Key features

  • Converts proxy meshes and curves to hair particles
  • Add to an existing system or create a new one
  • Link or copy settings from another system
  • Root snapping to the mesh surface
