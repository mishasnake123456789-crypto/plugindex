Blender add-on for animating flipping book pages from your own images, with adjustable size, speed and cover pages.

What Flip My Page does

Flip My Page builds page-turning animations in Blender. You can set the page width and height, flip speed, number of pages, start frame and the pause between flips, and add cover pages.

Pictures are loaded from a folder of sequentially named JPG or PNG files and placed on the front or both sides, with several optional effects available. Designers making photo albums, books and portfolio reveals can generate the animation without rigging each page.

Key features

  • Adjustable page size, speed, count and start frame
  • Reads numbered JPG or PNG pictures from a folder
  • Front-side or both-side image placement
  • Cover pages and optional effects
