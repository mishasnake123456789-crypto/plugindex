What Easy Modifier does

Easy Modifier from CG Tools manages modifiers in bulk. Four modes (Add, Change, Apply and Remove) work across objects according to selection options.

You can target all objects including inactive ones, the selection, a collection, or visible objects. A backup keeps a copy of the object from before modifiers get applied. It removes repetitive clicking in scenes with many objects. Working on groups of objects at once saves time when cleaning up scenes or preparing assets for export.

Key features

  • Add, Change, Apply and Remove modes
  • All, Selected, Collection or Visible targets
  • Backup before applying
  • Bulk modifier handling
