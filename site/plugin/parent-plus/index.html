A Blender add-on that selects parent and child chains and parents objects to a new Empty.

What Parent Plus does

Parent Plus adds small but useful tools for handling parent-child hierarchies in Blender. Two buttons, mapped to Ctrl+[ and Ctrl+], select the whole chain of parents or all children of the selected object, and multiselect is supported.

Parent Selection To Empty creates an Empty and parents all selected objects to it. The Empty can be placed at the 3D cursor, the world center, or the center of the selected objects. Riggers, animators and layout artists who regularly group objects under controllers will find it removes several manual steps.

Key features

  • Select All Parents with Ctrl+[
  • Select All Children with Ctrl+]
  • Multiselect support
  • Parent Selection To Empty
  • Empty placement at cursor, world or selection center
