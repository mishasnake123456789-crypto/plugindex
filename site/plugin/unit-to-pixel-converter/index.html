Blender add-on that works out render resolution from print sizes in metric or imperial units using PPI, bleed and paper presets.

What Unit to pixel converter does

Unit to pixel converter bridges physical dimensions and pixel counts for print-ready renders. Pick metric or imperial units, enter the size and pixel density in PPI, and it computes the render resolution to use in Blender.

A bleed field accounts for the extra margin in your print layout, and paper-format presets avoid retyping common sizes. Designers producing posters, covers and packaging renders can set resolution correctly the first time.

Key features

  • Metric and imperial units
  • Resolution from PPI/DPI
  • Bleed field
  • Paper-format presets
