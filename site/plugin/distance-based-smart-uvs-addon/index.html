Blender add-on that unwraps faces with Smart UV Project and scales islands by camera distance so near surfaces get more texels.

What Distance-Based Smart-Uvs Addon does

Distance-Based Smart-Uvs Addon makes UV space follow camera proximity. Surfaces close to the camera receive larger islands, which concentrates texture detail where it will be seen.

It unwraps selected faces with Smart UV Project, then scales each island according to four distance groups: close (default 2.0x), medium (default 1.5x), far (default 1.25x) and very far, which keeps its scale. Thresholds and scale factors can be customized per group, and islands are packed into 0-1 space afterward.

Key features

  • Camera-distance-based island scaling
  • Four distance groups with default factors
  • Custom thresholds and scale values
  • Uses Smart UV Project to unwrap
  • Automatic packing into 0-1 space
