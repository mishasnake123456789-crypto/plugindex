Generates seamlessly looping procedural noise animation for Blender objects and bones using Perlin, Simplex or Voronoi noise.

What Loop Noise Generator does

Loop Noise Generator adds organic movement that repeats without a visible seam. It animates objects and armature bones, which suits idle animations, breathing, swaying plants and chain or tentacle motion.

Noise can be Perlin, Simplex or Voronoi, and per-channel controls cover Strength, Speed, Seed, Roughness, Phase and Offset, with global multipliers available. Because the result loops, it works well for game cycles and endless background motion. Because the cycle repeats without a seam, the same clip can run indefinitely in games, loops or background animation.

Key features

  • Perfectly looping noise animation
  • Perlin, Simplex and Voronoi noise
  • Per-channel Strength, Speed, Seed, Roughness, Phase, Offset
  • Works on objects and bones
  • Global multipliers
