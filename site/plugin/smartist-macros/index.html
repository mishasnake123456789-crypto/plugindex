Blender extension that records and replays multi-step operations and asset appends as macros.

What Smartist Macros does

Smartist Macros turns repeated sequences into a single click. It records operations, property changes and asset appends, so render pipelines, Edit Mode operations, custom themes and add-on presets can be replayed.

Right-clicking any button or property adds it to a macro, with default, minimum, maximum or random values on recall. Assets can be appended from .blend files, and a Last Touched feature adds recent actions from the Info area. A no duplicates mode avoids redundant modifiers, macros can run on all selected objects, and legacy V1 sets import into the JSON format.

Key features

  • Record via right-click on any property or button
  • Min, max, default or random value recall
  • Asset appending from .blend files
  • No duplicates mode and legacy import
