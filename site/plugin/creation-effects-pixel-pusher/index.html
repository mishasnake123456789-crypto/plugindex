What Creation Effects: Pixel Pusher does

Creation Effects: Pixel Pusher forms patterns and animations out of small spheres, using no plugins. It suits abstract designs and animations as well as ball-based effects on footage.

There are 41 presets with unique animations, including everything seen in the demo video, each customisable with sliders and documented by instructions inside the template. Optional effects per preset can be unhidden for new looks. Separate project files come in HD and 4K, and it runs in any language version of After Effects. A video tutorial and a PDF preview of the presets help you browse.

Key features

  • 41 design presets
  • Slider-based customisation
  • Optional hidden effects per preset
  • HD and 4K project files
