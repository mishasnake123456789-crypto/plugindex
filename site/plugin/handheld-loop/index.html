What Handheld Loop does

Handheld Loop, by krystofjezek, generates procedural handheld camera shake that loops seamlessly, so it can run under any length of shot. It is listed under Animation.

Open source under GPL-3.0-or-later, it requires Blender 4.2.0 or newer.
