Blender add-on that renders stills or animations from a set of cameras one after another, with reusable render presets.

What Render Manager does

JSoftWorks' Render Manager automates rendering from many viewpoints in Blender. Choose any number of cameras and it produces an image or animation from each in sequence, with no waiting between jobs.

Render settings can be saved to a file and loaded later, which lets you build a library of presets for different projects. It handles Eevee and Cycles settings, and documentation is included. Architectural and product artists delivering many angles of one scene can leave it running unattended.

Key features

  • Series rendering across selected cameras
  • Images or animations per camera
  • Save and load render settings
  • Reusable preset library
  • Eevee and Cycles settings
