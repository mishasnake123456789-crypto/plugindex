A compact keyframe easing tool for After Effects with cloneable curves and a vertical mode.

What Arc does

Arc applies and manages easing on keyframes through a small interface. You can clone an easing curve from one keyframe and paste it onto others, instead of fiddling with the graph editor.

Vertical Mode creates curves that move fastest at the keyframes and slowest between them, with optional overshoot. You can pick between Arc keyframes and native ones, and paste as Ease In, Ease Out, Ease In and Out or values only; Paste Value Only keeps existing curves, either Relative or Absolute.

Key features

  • Compact easing UI
  • Clone and paste easing curves
  • Vertical Mode with optional overshoots
  • Arc or native keyframes
  • Paste as Ease In, Out, both or values only
