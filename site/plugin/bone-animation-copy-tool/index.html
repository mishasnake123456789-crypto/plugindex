What Bone Animation Copy Tool does

Bone Animation Copy Tool, by maylog, retargets animation from one skeleton onto another in Blender. It uses bone constraints driven by a mapping table in which you define how each target bone corresponds to a source bone.

The table can be filled in batches from bones selected in pose mode, or sped up with name similarity and mirror mapping. Four editing modes handle rotation mapping, rotation correction for differing bone axes, position mapping and IK correction. Mappings can be saved as presets and reused across characters.

Key features

  • Mapping table for target-to-source bones
  • Rotation, position and IK correction modes
  • Batch generation from pose-mode selection
  • Name similarity and mirror mapping
  • Preset saving for reuse
