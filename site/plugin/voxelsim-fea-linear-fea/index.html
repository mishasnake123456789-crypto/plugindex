What VoxelSim FEA - Linear FEA does

VoxelSim FEA brings linear-elastic finite element analysis into Blender, so you can check how a mesh responds to load without leaving the application. Material presets for steel, aluminum and plastic make it quicker to get started. It is listed under Mesh and Physics.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.
