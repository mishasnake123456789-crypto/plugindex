What Maxon Cinema 4D File Import-Export (.C4D) does

Maxon Cinema 4D File Import-Export is a Blender addon from blenderVfxMaster that opens chosen .c4d project files directly, so Cinema 4D need not stay running. Animations, geometry, materials, rigged characters and splines all come across.

Keyframed and procedural animation transfer with their timing and motion curves intact. Native geometry arrives with support for standard and Redshift materials, rigged characters come with their associated assets, and splines and curves are imported for modeling and motion graphics. Studios moving projects between the two programs can skip intermediate format conversions.

Key features

  • Imports .c4d projects directly in Blender
  • Keyframed and procedural animation with curves
  • Geometry with standard and Redshift materials
  • Rigged characters with assets
  • Splines and curves
