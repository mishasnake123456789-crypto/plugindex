Blender add-on that makes transparent backgrounds from image files and adds roughness, normal and emission shader controls on mesh planes.

What Mesh Planes Pro does

Mesh Planes Pro creates transparency from image files like JPGs inside Blender, with no manual cutout in an external editor. Imported planes also get shader controls.

It works with both colored and black-and-white backgrounds, offers inversion of the input image, and exposes controls for roughness, normals, emission and HDR emission. Artists placing photos, sprites or cutouts in 3D scenes save masking time. Emission and HDR emission options also make flat images usable as glowing signs, screens and lights in a scene.

Key features

  • Transparent backgrounds from images
  • Colored or black-and-white background support
  • Invert options
  • Roughness, normal and emission controls
