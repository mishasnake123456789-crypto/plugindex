Blender add-on that imports real-world-sized reference meshes to check scale.

What Banana For Scale does

Banana For Scale adds reference objects of known real-world size to Blender scenes so you can judge whether your models are true to life.

Objects appear in the Add menu under Mesh > For Scale. Meshes come from a directory of .obj files set in preferences, which you can extend or trim by adding or deleting files. It installs from a standard .zip, works with Blender Internal, Cycles and Eevee, and includes documentation.

Key features

  • Real-world scaled reference meshes
  • Add menu under Mesh > For Scale
  • Customizable .obj directory
  • Works with Blender Internal, Cycles and Eevee
