What Animography Controller does

Animography Controller is a free utility from MotionLand for working with characters in After Effects. Instead of setting up each individual letter or piece, you operate the whole set from a single layer.

Version 1.8 puts the controller layer on top of the selected layers, and 1.8.1 brought precomp checks plus fixes for layers that were duplicated. Characters that weren't supported before are now handled, and the interface supports several languages. It works with After Effects from CS6 through 2024.

Key features

  • Control characters from one layer
  • Controller placed at the top (v1.8)
  • Precomp checks, duplicated-layer fixes (v1.8.1)
  • Multi-lingual support
  • After Effects CS6 through 2024
