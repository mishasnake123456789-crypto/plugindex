What Mallet: Geometry Builder For Map Creation does

Mallet is a Blender add-on for building level geometry directly in the viewport, in the spirit of brush-based map editors. It suits game level design, architectural visualization and hard-surface blockouts.

Add cubes, spheres, cylinders and stairs in a few clicks and drag them out in 3D or 2D quad views, snap-drawing to the grid for accuracy. The stair step count changes with the mouse scroll, and an object's height can be matched to a selected object for consistent dimensions. Documentation is included.

Key features

  • Cubes, spheres, cylinders and stairs on click
  • Drag shapes in 3D or quad views
  • Grid snap-drawing
  • Stair steps via mouse scroll
