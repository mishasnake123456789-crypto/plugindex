What Quick Ref does

Hamen's Quick Ref streamlines collecting reference material for 3D work. It brings reference photos and background images into Blender straight from their source, skipping the save-to-disk step.

Because nothing needs to be downloaded, your folders stay uncluttered. Documentation is included, versions 2.9 through 3.3 are listed, and a Creative Commons license applies. Modelers who start each project with photographic references can set up faster. Keeping references inside Blender also helps when you work on several projects in parallel and need tidy folders.

Key features

  • Imports reference photos
  • Imports background photos
  • No prior download required
  • Keeps files organized
  • Blender 2.9 to 3.3
