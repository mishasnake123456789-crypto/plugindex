What Update-Run: Debug & Programme does

Update-Run folds three script-development steps, reloading from disk, settling conflicts and executing, into one Text Editor button.

Scripts run as normal Blender would when the button is not red. Terminal clearing helps keep output readable, and a timestamp with a message tells you when execution finished. An Update-Run Plus variant adds benchmarking tools. Add-on developers editing in an external editor will get a faster test loop. It speeds up the edit, reload and test loop for scripts kept on disk.

Key features

  • Update, resolve and run in one click
  • Terminal clearing
  • Finish timestamp and message
  • Plus variant with benchmarking
