What Easy Soft Body does

Easy Soft Body is a Blender plugin, made with Serpens, that simplifies soft body setup. It works on any mesh and includes cube, sphere and torus presets to get a jiggling result quickly.

Ten question mark buttons explain what each parameter does, which helps beginners understand the settings. Depending on scene complexity and polygon count, results can be seen in real time with a single object. Documentation is included. It suits users who want bouncy, squishy motion without digging through physics panels.

Key features

  • Works with any mesh
  • Cube, Sphere and Torus presets
  • Ten help buttons explaining parameters
  • Real-time results on single objects
