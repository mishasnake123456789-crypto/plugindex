A fully automatic, curvature-based UV unwrapping add-on for Blender, suited to batch processing.

What Okunwrap does

OKUnwrap automates UV unwrapping in Blender using a curvature-based method. It is meant for cases where unwrapping by hand would take too long or is impractical, and it scales to batches of assets across many meshes.

The developer states it beats the built-in solutions and often proprietary ones. It handles any geometry, including meshes triangulated by automatic poly reduction, and tries to create few small islands that waste packing and baking space. It is fully multi-threaded, and a test mesh of 335 thousand triangles is cited as processing quickly. Game artists with large asset sets will gain the most.

Key features

  • Fully automatic curvature-based unwrapping
  • Works on any geometry, including triangulated meshes
  • Minimizes small wasteful islands
  • Multi-threaded for large meshes
  • Batch asset processing
