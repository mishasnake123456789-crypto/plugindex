A floating command palette for After Effects to search and run layer, effect, script and preset actions.

What Command Frame does

Command Frame brings a command-palette style launcher to After Effects. Open it with a shortcut, type what you want to happen, and run it straight away, or chain several actions in sequence. One search box reaches layers, effects, presets, toolbars, scripts and actions from plugins.

Built-in actions cover selecting layers by range, parent, track matte source, label colour or type, jumping to the previous or next comp, renaming timeline and project items, and moving the playhead to a given time. Dismiss behaviour, query restore and pinned filters are configurable, and a bundled Action Catalog documents every action.

Key features

  • Floating search box for layers, effects, scripts, presets
  • Open by shortcut, type, chain and run
  • Selection and navigation actions
  • Rename and playhead time actions
  • Action Catalog and configurable behaviour
