What Rbf Drivers does

Rbf Drivers is a rigging add-on for Blender built on radial-basis function interpolation. Choose the inputs, list the properties to drive, record some poses, and the driver calculates all the values in between while you animate.

A single driver can handle several inputs and outputs, controlling bones, objects and shape keys. There is no runtime Python, and it uses Blender's dependency graph across cores. Because it relies on native tools, end users do not need the add-on installed. It suits shape-key interpolation, awkward anatomy and secondary deformation bones, with documentation and Discord support.

Key features

  • Pose-based driver setup
  • Multiple inputs and outputs per driver
  • No runtime Python execution
  • Rigs work without the add-on installed
  • Full documentation and Discord support
