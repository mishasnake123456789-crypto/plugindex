What Shapekeypro does

Shapekeypro is a Blender add-on that gathers shape key management into a single panel. Characters with dozens of keys quickly become hard to navigate, and this tool tackles that with bulk editing and a live-filtered list instead of scrolling and renaming one key at a time.

Batch operations cover blending, merging, renaming, value gradients, duplicating, mirroring, resetting and muting. Keys can be sorted into color-coded groups with master controls, previewed through a generated thumbnail or tile sheet, and moved to other meshes using four transfer methods with topology analysis and scale compensation. Facial riggers and character artists get the most from it.

Key features

  • Batch blend, merge, rename, delete, mirror and reset
  • Real-time search with combined filter criteria
  • Thumbnail and tile sheet generator
  • Four transfer methods with topology analysis
  • Color-coded groups with master controls
