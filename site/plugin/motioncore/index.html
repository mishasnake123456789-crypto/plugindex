What Motioncore does

MotionCore helps video editors and motion designers assemble animations in Blender quickly. Pre-built animation styles are applied to objects with one click.

Each style can be customized for axes, easing, duration and random variation, and a looped preview plays in real time for testing. A full reset returns objects to their original position, rotation, scale and material properties. It works with the Cycles and Eevee render engines. Users can build a sequence quickly and then refine the timing for the final edit.

Key features

  • Pre-built animation styles
  • Custom axes, easing, duration and randomness
  • Looped real-time preview
  • One-click application
  • Full reset to original state
