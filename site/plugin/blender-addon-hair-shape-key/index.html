What Blender Addon | Hair Shape Key does

Hair Shape Key, from VFX Grace, brings the shape key idea to hair. Add keys to a hairstyle and then switch between the shapes freely, keyframing the changes to make transition animations.

It works with the Noise modifier and uses a driver-based setup. Character artists can animate hair blowing, settling or changing style without separate hair systems for each state.

Key features

  • Shape keys for hair
  • Free switching between hair shapes
  • Keyframeable transitions
  • Works with the Noise modifier
