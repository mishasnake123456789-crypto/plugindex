What Super Easy Analytics does

Super Easy Analytics measures how much time you spend in Blender, in real time. It breaks that down per file and adds freelancer and rendering statistics.

Extras include a save reminder with autosave, tools for highlighting parts of your scene, and a Default Cube Cemetery that tallies how many default cubes you have deleted. It is useful for freelancers who bill by time or for anyone curious about their habits.

Key features

  • Real-time daily usage tracking
  • Per-file analytics
  • Freelancer and rendering statistics
  • Save reminder and autosave
  • Default Cube Cemetery counter
