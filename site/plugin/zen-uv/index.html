What Zen Uv does

Zen UV is a complete UV workflow add-on for Blender. It handles unwrapping, transformation, stacking, texel density and trimsheets through one add-on that has its own gizmo and display tools.

The Zen Gizmo handles moving, rotating, scaling, fitting, aligning and flipping islands from either the 3D View or the UV Editor. Zen Unwrap adapts to context, honoring seams and sharp edges, and Zen Relax suits organic models. A stack system manages similar and non-similar islands, and a trimsheet system with hotspot mapping matches islands by area. Game artists and asset teams get consistent, efficient UV layouts.

Key features

  • Zen Gizmo for island transforms
  • Context-sensitive Zen Unwrap and Relax
  • Stack system for similar islands
  • Trimsheet system with hotspot mapping
