What Photorealistic Eye Generator does

Photorealistic Eye Generator creates eyes for characters entirely with procedural nodes in Blender. You tweak parameters, press F12, and the full set of eye textures renders out, covering both iris and sclera.

A random mode makes a fresh eye in less than a second by stepping a frame forward or back. The iris bump map doubles as displacement for close-ups, the node tree is editable, and it runs in Cycles and Eevee. Documentation is included. Character artists needing distinct eyes will find it useful.

Key features

  • Procedural iris and sclera
  • Iris bump usable as displacement
  • Random mode makes a new eye in under a second
  • F12 renders the texture set
  • Editable node tree
