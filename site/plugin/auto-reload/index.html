Blender add-on that automatically reloads changed external files such as images, clips, libraries and caches.

What Auto Reload does

Auto Reload keeps an eye on external files used by a Blender scene and refreshes them whenever they are modified on disk, including pictures, video clips, linked libraries, audio and caches.

A timer checks for changes every set number of seconds. A menu on the right side of the top bar offers a stopwatch button to start or stop it, and a popover selects which file types to reload. Artists editing textures in outside paint programs or updating linked assets see changes immediately without manual reloads.

Key features

  • Refreshes pictures, clips, linked libraries, audio and caches
  • Timer checks every n seconds
  • Stopwatch toggle in the top bar
  • File type selection popover
