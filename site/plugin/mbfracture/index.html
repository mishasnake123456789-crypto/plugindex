What mbFracture does

mbFracture is a macroscript by Martin Breidt for 3ds Max that splits a mesh object into solid, volumetric fragments automatically. It is labeled version 0.1 alpha, which marks it as an early experiment instead of a finished fracture system.

An option controls the crack width between pieces. It works as a macroscript, which means it can be added to a toolbar or menu and run on a selected object. It works with 3ds Max 9. Artists who need a quick way to shatter a model for destruction shots or props may find it a handy starting point.

Key features

  • Automatically fractures a mesh into volumetric pieces
  • Adjustable crack width
  • Runs as a 3ds Max macroscript
  • Works with 3ds Max 9
