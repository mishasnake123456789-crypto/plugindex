Changes settings across many Premiere Pro sequences at once by search, selection or the whole project.

What Change it does

Change it, from Kabansky, edits sequence settings in bulk. Rather than opening each sequence in turn, choose which ones to alter: those matched by the search fields, those selected in the Project panel, or every sequence when the search fields are blank.

It also organizes the project alongside settings changes. This helps editors standardizing frame size, frame rate or other properties across large projects. That kind of consistency is time-consuming to do by hand when a project has dozens of sequences.

Key features

  • Change settings of searched sequences
  • Change settings of selected sequences
  • Empty search applies to all sequences
  • Project organization alongside changes
