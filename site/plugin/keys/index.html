Edits several keyframes and handles together in Blender's Graph Editor from one panel.

What Keys does

Keys is a Graph Editor add-on for changing many keyframes and their handles in one action. Box select the keys, then adjust them from a dedicated panel in the interface.

There is control over interpolation, whether constant, linear or Bezier, and keyframes can be edited as whole or sub frames along with their values. Both left and right handles expose type (Free, Aligned, Vector, Automatic, Auto Clamped), frame, value and length. It saves animators from fiddling with each key individually when polishing curves.

Key features

  • Box-select multi-key editing
  • Constant, Linear and Bezier interpolation
  • Whole and subframe key editing
  • Left and right handle type, frame, value, length
