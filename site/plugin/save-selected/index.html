What Save Selected does

Save Selected is a small Blender add-on by Nikita Akimov that writes only the objects you have selected into a new .blend file. It is handy when you need to break apart a complicated scene into individual asset files.

The command lives under File > Export > Save Selected, so there is no new panel to learn. It supports Blender versions from 2.83 through 5.1, is marked as compatible with Blender's extension system, comes with documentation and is released under the GPL.

Key features

  • Exports selected objects to a separate .blend file
  • Found under File > Export > Save Selected
  • Supports Blender 2.83 through 5.1
  • Compatible with the Blender extension format
  • GPL licensed with documentation
