Blender add-on that shows what a shader node outputs right in the Node Editor, no Material Output switch needed.

What Shader View does

Shader View lets you see what a node produces without rewiring the material. Real-time previews appear in the Node Editor, with thumbnails for shader nodes, in both Cycles and Eevee.

The Pro version adds scalar readouts with a Scalar Grid and Min/Max modes, along with vector splitting and extra settings. Documentation is provided by the developer, ShaderError.

Key features

  • Real-time node output previews
  • Thumbnails for shader nodes
  • Cycles and Eevee support
  • Pro scalar display with Min/Max modes
  • Pro vector splitting
