What Lattice Magic does

Lattice Magic by Mets adds two lattice-driven deformation tools to Blender plus small lattice utilities, built with production character animation in mind.

Tweak Lattice deforms a set of meshes in a way comparable to Proportional Editing, driven by a 3D object that can be parented, ride along with armature deformation and be keyframed. Camera Lattice deforms a collection of objects from the viewpoint of the camera, helping shape perspective. Animators can add stylized adjustments on top of rigs.

Key features

  • Tweak Lattice deforms like Proportional Editing
  • Lattice can be parented and animated
  • Camera Lattice for view-dependent deformation
  • Lattice utilities
