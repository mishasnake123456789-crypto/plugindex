What AM Select And Set does

AM Select And Set by Adirai Maji is an After Effects script for working with layers in bulk. It selects layers according to their attributes, then lets you set or change values on them in one go.

Version 1.0.1 added selection of guide layers and environment layers. It is compatible with After Effects from CC through the 2024 version, and a demo video is available. It is helpful in big comps where picking matching layers by hand takes too long.

Key features

  • Selects layers by attributes
  • Sets and changes layer values
  • Guide and environment layer selection (v1.0.1)
  • Works with CC through 2024
  • Demo video available
