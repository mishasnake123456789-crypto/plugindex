What Neat Video Pro does

Neat Video Pro removes visual noise from footage in After Effects, Premiere Pro and DaVinci Resolve. It deals with the pixel noise of modern camera sensors, but also with film grain from digitized film and with dust, scratches and electric interference on analog video.

Beyond noise, it addresses flicker from lighting, jitter caused by compression, compression artifacts and colour banding. A Default Noise Profile and Default Filter Preset load automatically for clips from the same series, and the filter uses full frame data when sources are scaled or cropped. Version 6 introduced a faster render engine, and reset controls cover both noise profile and preferences pages.

Key features

  • Reduces sensor noise and film grain
  • Handles dust, scratches, flicker and banding
  • Default profile and preset load for clip series
  • Uses full frame data on scaled or cropped sources
  • Faster render engine since version 6
