What Blender Slides does

Blender Slides lets you make presentations inside Blender with a workflow similar to PowerPoint, while using 3D elements and animation.

Text, objects and images can be added quickly to slides, individual slides can be animated, and transitions between slides are dynamic. The interface is built inside Blender and documentation is provided by the developer.

Key features

  • Quick-add text, objects and images
  • Slide animation options
  • Dynamic transitions
  • 3D elements in presentations
