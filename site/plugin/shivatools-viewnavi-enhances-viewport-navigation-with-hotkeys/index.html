What ShivaTools: ViewNavi (enhances viewport navigation with hotkeys) does

ViewNavi is a macro from ShivaTools that changes how you switch viewport views in 3ds Max. Instead of assigning a key to every view, you bind a small number of keys and tap them repeatedly to cycle through related views.

For example, the first tap of T selects Top and the second selects Bottom, with similar behavior for the other keys. In the example setup, three actions sit on the F, T and L keys. It installs as a macro in the user_macros folder and is configured in the Hotkeys Editor. It requires 3ds Max 2015 or later and frees up keyboard space for other commands.

Key features

  • Reach all views with fewer hotkeys
  • Cycle views by tapping the same key repeatedly
  • Three bindable actions, e.g. F, T and L
  • Installs into user_macros, set up in Hotkeys Editor
  • Works with 3ds Max 2015 and later
