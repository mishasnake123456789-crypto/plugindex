An auto-save and backup manager for After Effects with incremental versions and file cleanup.

What Auto Savior does

Auto Savior protects After Effects work from crashes and lost hours. It can save the original project at regular intervals like a repeated Ctrl + S, or generate hourly and daily backups, with options to keep an incremental history of versions.

The Save Time slider runs up to 60 minutes, and the version limit slider goes as high as 60. Save One Copy keeps a single updated daily file, which suits large multi-day projects, and saving can pause when nothing has changed for a minute. Custom options help manage older files.

Key features

  • Saves the original project without making copies
  • Hourly and daily backup generation
  • Incremental versions, up to 60 kept
  • Save interval up to 60 minutes
  • Pauses when no changes are made
