What Gif Maker does

Gif Maker is a Blender plugin that makes GIFs without leaving the program. It takes rendered output, folders of images or video files and produces looping animations.

Optional captions offer font, size, color and position controls, RGBA transparency works with PNG sequences, and compression, reversed loops and capturing the timeline UI are supported. Useful for sharing quick previews. Producing the GIF in-app avoids exporting to external converters, which is convenient for sharing work in progress, tutorials and social posts.

Key features

  • Renders, image folders and videos to GIF
  • Text captions with font controls
  • RGBA transparency
  • Compression, reverse loops and timeline capture
