What ASCII Scene Export (.ase) does

ASCII Scene Export writes Blender scenes to the .ase format, which older Unreal Engine versions (1 and 2) use. It gives you a path from Blender to those classic engines.

Modders and developers working on legacy Unreal projects can build maps and models in a modern tool and still deliver in the format those engines expect.

Key features

  • Writes .ase files
  • For Unreal Engine 1 and 2
  • Useful for legacy modding
