What Units does

Units, formerly called Unit Switcher, is a Blender add-on by Jarek Dudzinski for changing measurement and snapping setups quickly. It is built around Increment snapping mode and helps anyone who alternates between metric and imperial projects.

Each preset stores the unit system, length unit, grid scale, unit scale and the Separate Units option. You can add, remove, rename and reorder presets in the add-on preferences, save them across sessions, and export or import them as JSON. Reset to Defaults restores the built-in set, and optional header extras include a display type dropdown and an Affect Only Origins toggle.

Key features

  • One-click switching of units and grid snapping
  • Editable presets stored as exportable JSON
  • Reset to Defaults for built-in presets
  • Optional Display Type and Affect Only Origins controls
