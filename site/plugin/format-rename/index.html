What Format Rename does

Format Rename is a Blender add-on aimed at renaming many objects in one pass. Instead of editing names by hand, you build a format from tokens that insert numbers, letter sequences, context, object type or bone information.

It can follow the order in which items were selected, split objects into two teams to swap or copy names between them, and run search and replace using regular expressions. Options let you limit matching to the selection, restrict it to ASCII, or ignore case, which suits large scenes with strict naming rules.

Key features

  • Format tokens for numbers, letters, type and bones
  • Replacement follows selection order
  • Team A and Team B name swapping and copying
  • Regex search and replace
  • Selection-only, ASCII-only and ignore-case flags
