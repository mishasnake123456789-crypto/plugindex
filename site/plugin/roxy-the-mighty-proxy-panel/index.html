What Roxy the mighty Proxy Panel does

Roxy is a proxy panel from MoovIT. When high-resolution files are imported, it can generate proxies matching the picture, audio and channel count but with heavier compression or lower resolution.

Editors can switch between originals and proxies while working. Edit data is saved and carried across to the project files for both versions. Lighter proxy files move faster, locally or in the cloud, supporting collaborative workflows. It targets teams dealing with heavy source files who want editing to stay responsive.

Key features

  • Automatic proxy creation on import
  • Higher compression or lower resolution
  • Switch between original and proxy
  • Edit data transferred to both versions
  • Suits local and cloud collaboration
