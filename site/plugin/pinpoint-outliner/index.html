Blender add-on that auto-expands the parent chain of the active bone in the Outliner in Pose and Edit modes.

What Pinpoint Outliner does

Pinpoint Outliner keeps the selected bone visible in Blender's Outliner, even when it sits deep in a nested armature. It opens the whole chain of parents for you in both Pose Mode and Edit Mode.

An optional setting collapses every unselected hierarchy so the list stays focused on the current bone or object. A debounce timer prevents lag or freezing during rapid selections and drags, and a button in the Outliner header turns the feature on or off. Riggers working with complicated skeletons spend less time clicking through folders.

Key features

  • Expands the full parent chain of the active bone
  • Works in Pose Mode and Edit Mode
  • Optional auto-collapse of unselected hierarchies
  • Debounce timer to avoid Outliner lag
  • Toggle button in the Outliner header
