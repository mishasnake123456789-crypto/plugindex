What COMP-O-RAMA does

COMP-O-RAMA is a script from jon hanlan for generating many compositions in one pass. Add items to a queue from presets or custom templates, press create, and every comp is made, which is helpful for multi-format delivery.

It includes over 30 built-in formats for social, HD, 4K, cinema, broadcast and animation. A Render Queue Audit flags duplicate names, bad folders, missing output modules and sequence naming issues with one-click fixes. Multi-Output adds PNG, MP4, ProRes and custom stacks, Smart Naming uses tokens, and Matrix Preview shows each comp against each output before committing.

Key features

  • Batch comp creation from queue
  • 30+ built-in formats
  • Render Queue Audit with one-click fixes
  • Multi-Output per comp
  • Smart Naming tokens and Matrix Preview
