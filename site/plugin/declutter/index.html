After Effects extension that sorts project panel assets into reusable, filter-based folder structures automatically.

What Declutter does

Declutter by Rodrigo Dominguez organizes the After Effects project panel by sorting assets into folders according to filters. You can build and save several custom folder structures with names, color labels and multiple filters per folder.

Sorting recognizes audio, video and image files, image sequences, data files, specific extensions and missing files, and works by name search without prefixes or by composition. Selective targeting lets you organize chosen assets or the whole project, with up to three times faster sorting for thousands of assets. Structures can be imported and exported, and preferences handle auto-save, empty folders and uncategorized items.

Key features

  • Custom folder structures with color labels and filters
  • Filters for audio, video, images, sequences and missing files
  • Selective asset targeting
  • Up to 3x faster sorting for thousands of assets
  • Import and export folder structures
