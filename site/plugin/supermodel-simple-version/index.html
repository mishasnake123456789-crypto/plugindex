What Supermodel (Simple Version) does

SuperModel (Simple Version) by Londa trims repetitive Blender operations down to one click each. Tools are grouped under Modeling, UVs and Pipeline headings.

Loop Bevel applies a fixed bevel around a whole edge loop starting from one chosen edge. N-Pole Loop locates a vertex where three edges meet and builds an edge loop from it, while N-Pole Seam Loop marks that loop as a UV seam without visiting the UV menu. Documentation is provided, and the plugin works with Blender versions 2.93 through 4.0.

Key features

  • Loop Bevel in a single action
  • N-Pole Loop creation
  • N-Pole Seam Loop marking
  • Modeling, UV and pipeline groups
  • Blender 2.93 to 4.0
