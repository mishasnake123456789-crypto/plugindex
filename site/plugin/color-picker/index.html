A Blender painting add-on with SV, SV+H and HS color pickers plus a weight paint widget.

What Color Picker does

Color Picker by jfmatheu improves color selection when painting in Blender. It offers three picker types, SV, SV+H and HS, along with HSV and RGB graphic sliders, a color preview and a list of recent colors for texture paint and vertex paint.

A slicing feature crops SV pickers to a rectangular area marked by gizmos, and a visual widget controls the weight value in weight paint mode. Widget size per mode, picker type, keymaps, text DPI and whether a widget closes on release are all configurable. Texture painters and riggers who paint weights will find it faster than the default picker.

Key features

  • SV, SV+H and HS picker types
  • Slicing to crop the picker area
  • HSV and RGB sliders and recent colors
  • Weight paint value widget
  • Configurable size, keymaps and DPI
