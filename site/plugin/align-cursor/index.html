What Align Cursor does

AR Utilities' Align Cursor moves and orients the 3D cursor according to what is selected, covering objects, vertices, edges, faces and spline knots, for single or multiple selections.

Location and rotation can be controlled individually per axis. Face Bias picks which adjoining face to follow when only one edge is chosen (0.5 by default), and Create Grid builds a grid mesh at the cursor's position and orientation. Precision modelers placing new geometry on angled surfaces get a quick setup.

Key features

  • Aligns to objects, vertices, edges, faces and knots
  • Separate location and rotation per axis
  • Face Bias for edge selections
  • Create Grid at cursor
  • Works with multiple selections
