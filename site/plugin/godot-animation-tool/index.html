A Blender add-on for preparing animations for Godot with batch stashing, root motion and bone renaming.

What Godot Animation Tool does

Godot Animation Tool smooths the path from Blender to Godot by batching the chores that usually come with exporting character animation. Operations are non-destructive, so original keyframes remain safe.

Fast Stash stashes and exports the actions you pick, and batch root motion works on the full XYZ axes or just the XY plane. Armature rotation and scale can be applied in bulk, and a bone rename kit supports single or batch renaming with regular expressions and rename rules that can be imported and exported as files. Indie developers using Godot will gain a tidier pipeline.

Key features

  • Fast Stash for batch stashing and exporting actions
  • Batch root motion on XYZ or XY
  • Batch apply of armature rotation and scale
  • Bone rename kit with regular expressions
  • Non-destructive to original keyframes
