What Auto Light does

Auto Light speeds up lighting setup in 3ds Max by offering automatic tools to add and position lights. It is intended for interior lighting, architecture and other complex scenes, and works with both V-Ray and Corona lights, with additional light classes planned.

When you prefer manual control, lights can be set up using light profiles, and a settings panel exposes most of the basic light parameters in one place. This avoids creating and tuning each light individually through separate dialogs. It supports 3ds Max 2013 onward and suits visualizers who place many ceiling fixtures or similar lights in a project.

Key features

  • Automatic tools to add and place lights
  • Manual light setup with profiles
  • Settings panel for most basic light parameters
  • Supports V-Ray and Corona lights
  • Supports 3ds Max 2013 onward
