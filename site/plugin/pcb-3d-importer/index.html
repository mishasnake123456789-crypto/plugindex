What PCB 3D Importer does

PCB 3D Importer brings circuit boards designed in KiCad into Blender through the pcb2blender workflow. Export a .pcb3d file from KiCad, import it in Blender, then compose and light the product render.

Transfers are fast, so unfinished boards or revised designs can be re-rendered without fuss, and no cleanup is needed beforehand. A PCB shader node setup is included. Electronics designers and product visualizers make renders of boards without manual modeling.

Key features

  • Imports KiCad .pcb3d files
  • Fast export and import
  • Included PCB shader setup
  • No manual cleanup before rendering
