What Motion Tools Pro does

Motion Tools Pro, by Motion Design School, collects several small utilities into one After Effects panel. It aims to remove the need for separate scripts by grouping widgets for easing, GIF export, cropping and layout.

The Easings Manager provides presets and a Speed Graph, Ease Copy moves easing via the clipboard, and SuperGif exports GIFs on macOS and Windows. A Selector handles paths, Crop Comp trims compositions, and a Distribution widget manages overlap and path order. Share Center imports and exports configuration packages and styles, and panels synchronize with customizable layouts and a Color Collect palette. It supports After Effects 2022 through 2026.

Key features

  • Easings Manager with Speed Graph
  • Ease Copy through the clipboard
  • SuperGif export and Crop Comp
  • Distribution widget for paths
  • Share Center for style packages
