What View Layer Plus does

View Layer Plus is a Blender add-on by Trukas that widens View Layer handling in the compositor, layer management and outliner, adding compositor menus, a list-style manager and render-setting copy tools.

In the compositor, menu and right-click entries switch View Layers on or off for the selected render layer nodes. Bulk operators toggle every View Layer, or target only unmuted nodes, and you can jump to the View Layer of a selected node. A manager lists layers so you can switch, enable, disable, add and remove them.

Key features

  • Compositor menu to toggle View Layers for nodes
  • Bulk enable or disable for all View Layers
  • Switch to a selected node's View Layer
  • List-style View Layer manager
  • Render-setting copy tools
