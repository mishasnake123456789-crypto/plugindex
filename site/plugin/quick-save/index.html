What Quick Save does

Quick Save from Edyn shortens the save routine in Blender. A single click writes the current project immediately, with no menus or dialogues.

An autosave option stores the project at a regular interval you can set to suit your pace. Both controls live in a dedicated 3D view panel. It works with Blender 4.0 and later, is distributed under the GPL license, and buyers receive free future updates as more features are added.

Key features

  • One-click save without dialogues
  • Automatic saving at set intervals
  • Customizable autosave interval
  • Dedicated panel in the 3D view
  • Works with Blender 4.0 and later
