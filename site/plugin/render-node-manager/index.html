Network utility for 3ds Max that starts, stops and monitors distributed rendering services on remote render nodes.

What Render Node Manager does

Render Node Manager helps 3ds Max users run distributed rendering across several machines. Octane Daemon, Corona DrServer and VRaySpawner can all be started, restarted or stopped from one window on any chosen node, so nobody needs to log into each machine.

The main list shows each node's status, CPU load, RAM use and distributed renderer state, refreshed in real time, with progress bars for CPU and memory in version 0.75. Nodes can be reached through an RNM Server on the local network or through classic Remote Desktop. An option also lets VRaySpawner accept jobs only from specific senders, which suits small studios running a render farm.

Key features

  • Start, restart and stop VRaySpawner, DrServer and Octane Daemon
  • Real-time node status, CPU, RAM and DR columns
  • RNM Server or Remote Desktop connection methods
  • Restrict VRaySpawner to chosen job senders
  • CPU and RAM progress bars in version 0.75
