Face2Face

Developer: Neo Lekker

FreeBlender
Download Free

A Blender add-on that projects and aligns objects onto target faces by picking a few faces.

What Face2Face does

Face2Face places one object against another by selecting faces rather than fiddling with origins and transforms. You pick a face on the source and one or more faces on the target, and the source is projected into position, even when many objects are involved.

Multiple projected objects can be altered together, and the tool helps set up hard-surface boolean modifiers across several faces or objects at once. It works with the Geometry Nodes modifier and keeps the process non-destructive. Hard-surface modelers assembling parts and kitbashers attaching details will find it saves repeated manual alignment.

Key features

  • Projects single or multiple objects onto target faces
  • Set by picking source and target faces
  • Edits many projected objects together
  • Speeds up hard-surface boolean setup
  • Non-destructive, works with Geometry Nodes
