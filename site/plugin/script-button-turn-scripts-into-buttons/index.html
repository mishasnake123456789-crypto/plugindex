Turns Blender Python scripts from a chosen folder into clickable N-panel buttons.

What Script Button - Turn Scripts Into Buttons does

Script Button saves a trip to the Text Editor each time you want to run a custom script. It scans a folder you choose for .py files and creates a button for each one in the N-panel.

Scripts run with a single click, favorites can be added to Quick Favorites for instant access, and the panel category is customizable to keep the sidebar tidy. Scripts can also be opened and edited from the panel. Technical artists with a personal toolbox of utilities will find it convenient.

Key features

  • Scans a folder for .py scripts
  • One-click script execution
  • Quick Favorites for frequent scripts
  • Custom folder and panel category
  • Open and edit scripts from the panel
