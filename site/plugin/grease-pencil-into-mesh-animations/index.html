What Grease Pencil Into Mesh Animations does

AHK's add-on carries frame-by-frame Grease Pencil drawings into 3D in Blender, with choices for source layers, output collections and mesh detail.

Default mode makes flat planes from strokes, Curves mode makes curves, and Line Mode is available from Blender 3.4.0. A subtraction layer cuts holes in the meshes, with adjustable extrusion and a separate output. Artists who animate in 2D but want to light and render with 3D materials can use it.

Key features

  • Grease Pencil to mesh, curve or geometry
  • Flat planes, curves or line mode
  • Subtraction layer for holes
  • Adjustable extrusion
  • Source layer and output collection control
