What Advanced Weight Slider does

Advanced Weight Slider brings a spreadsheet-like weight view to Blender's N-panel sidebar. It is aimed at character riggers, game developers and animators who need exact control of skin weights, and it will feel familiar to Maya users switching over.

A table lists bone influence across the selected vertices with live totals. Values can be assigned precisely with one click, vertex groups can be locked so normalization leaves them alone, and weights are normalized to sum to 1.0. It works in Edit Mode and Object Mode, and documentation is provided in English and Traditional Chinese.

Key features

  • Visual table of bone influence per vertex
  • Precise weight assignment in one click
  • Lock vertex groups during normalization
  • Works in Edit and Object Mode
