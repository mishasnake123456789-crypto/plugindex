What Eznormal - Ai-Powered Normal Map Generator does

EZnormal turns an ordinary picture into a normal map in one click. A bundled ONNX model runs fully offline, so there are no API keys, cloud services or extra setup.

It accepts JPG and PNG, builds the shader nodes with proper BSDF-to-Output connections and applies them to the selected object. An Invert Y-Channel toggle covers OpenGL and DirectX conventions, and a side-by-side preview helps judge the result. Texture artists and game developers can add surface detail to flat images quickly.

Key features

  • One-click normal maps from JPG or PNG
  • Offline ONNX model, no API keys
  • Automatic shader node setup
  • Invert Y toggle for OpenGL and DirectX
