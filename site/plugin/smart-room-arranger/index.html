What Smart Room Arranger does

Smart Room Arranger furnishes empty rooms for you. You specify a room object and a collection of furniture, and the add-on places items according to rules while it checks dimensions and avoids intersections in the background.

Rules can be set per object name: corner, back against a wall, parallel to a wall, free placement or clustered groups. Linked rules tie items together, such as a chair facing a table, with parameters you can adjust. Interior designers and archviz artists can generate layouts quickly and iterate on them.

Key features

  • Rule-based placement by object name
  • Corner, wall-parallel, free and cluster modes
  • Linked rules such as chair in front of table
  • Dimension checks and collision avoidance
