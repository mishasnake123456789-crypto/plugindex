What Kit Ops 2 Pro: (Deprecated) does

Kit Ops 2 Pro, by Chipp Walters, is a kitbashing tool for Blender that stores reusable inserts and applies them to other objects. It is no longer supported and has been superseded by Kit Ops 3 Pro.

Pro inserts include boolean union and difference modifiers that can be linked to the target or the insert to cut holes. Snapping features and wire object types help position parts, factory mode allows full editing and custom thumbnails, and a favorites menu gives shortcut access. Hard surface artists who still use this version can keep libraries of detail parts.

Key features

  • Inserts with boolean union and difference
  • Snapping and wire object types
  • Factory mode with thumbnails
  • Favorites menu with shortcuts
