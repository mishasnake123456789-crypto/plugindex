What Ultibridge does

Ultibridge is a Blender extension that bridges scenes into three game engines, Godot, Unity and Unreal, rather than requiring separate export routines for each.

It is built for Blender 4.5 through 5.1, is released under the GPL license, and ships with documentation. It is also a project supported by a development fund. Game developers working across more than one engine, or testing the same content in several, will gain a more uniform workflow.

Key features

  • Single exporter for Godot, Unity and Unreal
  • Blender extension for 4.5 through 5.1
  • GPL license
  • Documentation included
