What CI Move Anchor does

CI Move Anchor from Creative Impatience repositions a layer's anchor point in After Effects without disturbing the motion already animated. Normally moving the anchor shifts the layer or breaks its path; this script keeps that path intact.

The panel includes Save and Move buttons, and the anchor can be placed anywhere using the Pan Behind tool. Version 2.0 added support for 3D layers and for separated coordinates. Animators adjusting pivots late in a project will find it saves rework.

Key features

  • Moves the anchor point while keeping the animation path
  • Save and Move buttons on the panel
  • Works with the Pan Behind tool
  • 3D layer support (v2.0)
  • Separated coordinates support (v2.0)
