Free Blender add-on that computes the path length needed for a car's speed, frame count and FPS and keyframes the motion.

What SPEEDZONE does

SPEEDZONE makes vehicle animation match real velocity. Give it a speed (MPH or km/h), a frame count and the frame rate, and it calculates the exact path length required, then keyframes the motion.

Two workflows exist: Create Linear Path builds a path with evenly spaced points, while Rescale Selected Curve fits any curve you have drawn. Motion designers and previs artists get physically believable car moves without trial and error.

Key features

  • Path length from speed, frames and FPS
  • MPH or km/h input
  • Create Linear Path option
  • Rescale Selected Curve option
  • Automatic keyframing
