What Catenary Cables does

Catenary Cables produces believable sagging cables by evaluating real catenary curve equations instead of running a simulation. Cables can be created between points, faces, objects or vertices and in other ways, including sagging cables, default cables and cable masses.

You can also draw and edit cables, place segments along them and use curve tools to split, merge and insert vertices. It suits power lines, wiring, bridges and industrial or sci-fi scenes where cables need to droop naturally.

Key features

  • True catenary curve math
  • Create between points, faces, objects, vertices
  • Sagging cables and cable masses
  • Draw, edit, split, merge curves
