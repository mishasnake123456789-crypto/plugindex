Blender animation add-on with 23+ editable presets, 14 motion paths and a text animation generator for one-click motion.

What Stack Motion does

Stack Motion applies animation to objects, lights, cameras and text in Blender with a single click, and removes it just as quickly so you can iterate.

More than 23 editable presets let you tune intensity, direction and cycles, and multiple presets can be stacked to layer movement. Fourteen motion paths provide travel, custom pivot points control rotation centers, and every animation has precise start and end frames. A text animation generator is included, aimed at quick motion graphics.

Key features

  • One-click apply and remove
  • 23+ editable presets
  • 14 motion paths
  • Stack presets and set custom pivots
  • Text animation generator
