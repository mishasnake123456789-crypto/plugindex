What Animator’S Glove Suite does

Animator's Glove Suite is a modal operator for building hand gestures live in the 3D viewport. Moving the mouse blends a character's hands between custom poses live, which suits animators, game developers and VRChat avatar creators.

Its seven-node radial system, one center and six outer, blends poses by cursor proximity and draws connecting lines showing the influence. Complex animations become fluid performances rather than a sequence of manual pose edits.

Key features

  • Puppeteering modal system
  • 7-node radial pose blending
  • Real-time viewport gestures
  • Node-based interface
