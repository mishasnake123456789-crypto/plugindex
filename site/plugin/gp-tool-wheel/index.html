What GP Tool Wheel does

GP Tool Wheel is a Grease Pencil helper for Blender that merges mode switching and tool selection into one radial wheel. It lets 2D animators move between modes and tools quickly.

The wheel opens with F8 by default and can be changed in the add-on preferences, and shows up when a Grease Pencil object is active and the cursor is over the 3D viewport. It reduces trips to the header menus for people drawing frequently.

Key features

  • Mode and tool selection in one wheel
  • F8 default shortcut, configurable
  • Appears for active Grease Pencil objects
  • Quick switching in the 3D viewport
