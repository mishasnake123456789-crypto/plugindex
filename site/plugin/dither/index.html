What Dither does

Dither is a DCTL from Nx Color that gives DaVinci Resolve a retro, screen-printed look by reducing an image to a pattern of dots. It can work in a strict 1-bit mode or keep full color, depending on the style you want.

Pattern detail is set by choosing a 2x2, 4x4 or 8x8 Bayer matrix, while sliders and combo boxes handle intensity, brightness, contrast and exposure. A posterize option cuts the number of colors for flatter, bolder tonal steps. It suits colorists and editors chasing lo-fi, game-style or print-inspired looks without leaving the Color page.

Key features

  • 1-bit and full-color dithering modes
  • Bayer matrix sizes of 2x2, 4x4 and 8x8
  • Brightness, contrast and exposure controls
  • Posterize option to reduce color depth
