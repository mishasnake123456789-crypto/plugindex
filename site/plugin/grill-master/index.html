What Grill Master does

Grill Master is a Bending Spoons plugin for After Effects that remembers guide layouts. Rather than drawing the same rulers again for each composition, you save a preset and copy it across different project items.

It needs permission for scripts to write files and access the network, supports After Effects 17.0 and later, and is limited to Bending Spoons employees. It is aimed at in-house designers who want consistent alignment guides across many comps.

Key features

  • Saves guide presets
  • Reuses rulers across project items
  • Requires script file and network permission
  • After Effects 17.0 and later
  • Restricted to Bending Spoons employees
