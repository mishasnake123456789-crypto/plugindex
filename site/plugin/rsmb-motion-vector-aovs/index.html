What Rsmb Motion Vector Aovs does

RSMB Motion Vector AOVs is a node group that prepares Blender's raw motion vector passes for use with Reel Smart Motion Blur, a plugin used in external compositing software. It works with both Cycles and EEVEE.

Correct pixel math handles the conversion, labelled inputs and a range slider make setup straightforward, and the result is exported for compositing elsewhere. VFX artists who add motion blur in post can use it to avoid guessing at vector scaling.

Key features

  • Converts Cycles and EEVEE motion vector passes
  • Output compatible with Reel Smart Motion Blur
  • Correct pixel math
  • Labelled inputs and range slider
  • Export for external compositing
