Blender shader-based terrain generator for Cycles that mixes up to nine height inputs and bakes heightmaps.

What Terrain Mixer does

Terrain Mixer builds realistic or abstract terrains in Blender using nodes in Cycles and Geometry Nodes, created by zets. It works from the 3D Viewport.

Custom node groups mix and blend up to nine height inputs, and Erosion Mixer simulates erosion by combining heightmaps. Terrains can be baked out as heightmaps and diffuse textures for use in game engines and other programs, and image masks allow further customization. Landscape artists can iterate on large terrain designs quickly.

Key features

  • Mix up to nine height inputs
  • Erosion Mixer in Geometry Nodes
  • Bake heightmaps and diffuse textures
  • Image mask customization
