What Uvexport does

UVExport is a Blender add-on for getting UV layouts out as image files, handy for texture painting in other programs. It can export from selected objects or batch export every object in a collection.

You can pick a specific UV map by name or export them all, choose raster formats such as PNG, JPEG, BMP, TGA, TIFF and WEBP, and control colors, resolution and stroke widths. Workflow presets let you save, load, update and delete any number of configurations. Texture artists benefit from consistent templates.

Key features

  • Export UV layouts from selection or a whole collection
  • Export one UV map by name or all of them
  • Raster formats including PNG, TGA, TIFF and WEBP
  • Control of colors, resolution and stroke width
  • Unlimited saved workflow presets
