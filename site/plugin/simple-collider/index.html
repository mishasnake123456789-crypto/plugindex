What Simple Collider does

Simple Collider is a Blender addon by Matthias Patscheider for making collision shapes for games. Choose from box, sphere, capsule, convex, convex cylinder, K-DOP, re-meshed and mesh types, and is meant for engines such as Unreal, Unity and Godot.

An oriented minimum bounding box generator produces an automatically aligned box with the lowest volume. V-HACD powers automatic convex decomposition on Windows, Linux and macOS, Apple Silicon included. Colliders can be created in Object and Edit mode, including from multiple objects.

Key features

  • Mesh, K-DOP, convex, capsule, sphere and box colliders
  • Oriented minimum bounding box generation
  • Auto convex decomposition with V-HACD
  • Object and Edit mode creation
  • Targets Unreal, Unity and Godot
