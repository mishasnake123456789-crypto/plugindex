What Auto-Save File Checker - Browse All The Temp Files does

Auto-Save File Checker locates the temporary files Blender leaves behind, so recovering lost work or reclaiming disk space is straightforward. It finds Blender's temp and auto-save folders and scans system temp locations without configuration.

Both .blend and .blend1 backups are detected. You can search by name, sort by date, size or name, filter live, view statistics and delete in bulk. Anyone who has crashed mid-session and needs to find the last auto-save will appreciate it.

Key features

  • Auto-detects temp and auto-save folders
  • Finds .blend and .blend1 files
  • Search, sort and live filtering
  • Recover or bulk delete files
