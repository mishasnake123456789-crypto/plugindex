What Sitob Camera Tools does

SItoB Camera Tools helps artists coming from Softimage (XSI) feel at home in Blender. It reproduces familiar camera behavior for zooming, framing, remembering views and resetting the camera.

Camera Zoom View works around the selected object or element, using mouse movement for focal length, the wheel for zoom and right-click for rotation. Frame Selected Plus improves framing, including single-vertex selections, and MemoCam stores and recalls up to four camera settings. An AutoHotkey script is included to mimic Softimage navigation.

Key features

  • Softimage-style camera zoom and rotation
  • Frame Selected Plus with better vertex framing
  • MemoCam saves and recalls four camera settings
  • Camera reset command
  • AutoHotkey script for Softimage-like navigation
