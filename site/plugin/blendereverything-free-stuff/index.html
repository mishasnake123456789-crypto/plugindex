What Blendereverything Free Stuff does

Blendereverything Free Stuff contains a free Blender add-on called Extra Keyframes. It copies keyframes across several objects and shifts their timing while keeping everything in sync.

Instead of duplicating animation one object at a time, you can batch-copy and offset in one step. Documentation is included, and it is compatible with Blender 3.0, 2.93 and 2.92. Handy for staggered animations. It is a simple utility for animators and motion designers who regularly repeat the same animation across many objects with small timing differences.

Key features

  • Batch copy keyframes across objects
  • Offset timing in one step
  • Keeps animation in sync
  • Documentation included
