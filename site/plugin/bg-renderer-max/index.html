What BG Renderer MAX does

BG Renderer MAX, by Nik Ska, speeds up After Effects output by using true multiprocessing, with the render going on in the background. A custom Render Queue view gives visual control, including a render time column.

When a render finishes, files can be converted automatically, producing both a sequence and a video. Notifications can go out through Slack and email, or via services such as Zapier, Microsoft Flow, IFTTT and Pushover for wider automation. It supports After Effects CC 2018 through 2025 on macOS 10.13 and later or Windows 10.

Key features

  • True multiprocessing renders
  • Slack and email notifications
  • Hooks into Zapier, Flow, IFTTT and Pushover
  • Automatic post-render file conversions
  • Custom Render Queue view with render time
