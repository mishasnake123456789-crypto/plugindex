What Vertex Reader does

Vertex Reader shows which objects weigh your scene down. It builds a list of objects, curves and text sorted from the highest vertex and face counts to the lowest.

You can select any item directly from the list rather than searching the outliner, and both vertex and face counts are displayed for meshes and curves. Documentation and a how-to video walk through usage and the calculations. Optimizers and game artists hunting for heavy meshes will locate problem objects at once.

Key features

  • Objects ranked by vertex and face count
  • Select directly from the list
  • Counts for meshes and curves
  • Documentation and how-to video
