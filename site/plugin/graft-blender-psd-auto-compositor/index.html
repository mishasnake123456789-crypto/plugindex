What Graft - Blender Psd Auto-Compositor does

Graft is built for architectural and interior visualization, where renders usually end up in Photoshop. As soon as a render completes, it produces a PSD containing Beauty (graded), Raw (ungraded), ObjectID and MaterialID layers, the last two from Cryptomatte.

Setup is a single button in the Graft tab of the 3D Viewport sidebar, which enables the passes and adds the node set. It picks up existing compositing such as Glare and Color Correction and wires them in. A Beauty JPG is saved alongside the PSD, and different camera angles can be assigned to separate frame numbers. ImageMagick is needed, with a Windows installer in Preferences and Homebrew on Mac.

Key features

  • PSD created automatically after each render
  • Beauty, Raw, ObjectID and MaterialID layers
  • Detects existing Glare and Color Correction chains
  • Beauty JPG saved with the PSD
  • Multi-angle workflows via per-camera frame numbers
