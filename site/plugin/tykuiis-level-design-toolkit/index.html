What Tykuii's Level Design Toolkit does

Tykuii's Level Design Toolkit is made for greyboxing and blocking out environments. Modal drawing tools create planes, boxes, stairs and ramps, cylinders, walls, curved walls and Bezier roads.

Arch profiles include Arc, Semi-Circle, Gothic, Lancet, Tudor, Ogee, Bell Curve, Catenary and a custom option, modular kits can be instanced, and 22 greybox-suitable textures speed up iteration. Level designers can block out spaces quickly. Among its tools are modal drawing tools for blockout shapes and many arch profiles.

Key features

  • Modal drawing tools for blockout shapes
  • Many arch profiles
  • Modular kit instancing
  • 22 greybox textures
