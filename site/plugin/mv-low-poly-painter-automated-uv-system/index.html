What Mv Low Poly Painter (Automated Uv System) does

MV Low Poly Painter automates color work for low-poly assets. Select faces, pick a color or gradient from your libraries, and the add-on plots it into the UV map and calculates the UV positions.

Color and gradient libraries are organized and labelled, can be saved with projects and shared with others, and can be built by extracting colors from images, downloading online palettes or importing palettes. Game artists using small palette textures can skip manual UV placement.

Key features

  • Assign colors and gradients to selected faces
  • Automatic UV plotting and positioning
  • Labelled color and gradient libraries
  • Save, load and share projects and libraries
  • Extract colors from images or import palettes
