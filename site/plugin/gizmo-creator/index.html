What Gizmo Creator does

Gizmo Creator lets Blender users design their own viewport gizmos and the tools behind them. Instead of relying only on built-in handles, you can assemble interactive controls suited to your own workflow, which is helpful for technical artists building custom interfaces.

It supports Blender 4.5 through 5.1 and includes documentation and a demo video. A reader-only mode loads presets made with the full version, and licensing tiers scale by number of users and cover commercial projects. Technical artists, add-on developers and studios wanting bespoke controls will find it of most interest.

Key features

  • Creates custom gizmos
  • Builds tailor-made tools
  • Reader-only mode loads full-version presets
  • Licensing tiers by number of users
  • Supports Blender 4.5 to 5.1
