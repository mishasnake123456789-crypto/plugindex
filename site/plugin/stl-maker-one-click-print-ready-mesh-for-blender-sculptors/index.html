What Stl Maker - One-Click Print-Ready Mesh For Blender Sculptors does

STL Maker targets sculptors preparing miniatures for 3D printing. One click produces a mesh ready for printing, and it can be exported as an STL file.

It is packaged as a Blender extension for 4.5, with documentation, under the GPL. It reduces the number of cleanup and export steps between a finished sculpt and a slicer. The format is the standard one accepted by slicers, so the model can go straight into print preparation.
