Adds expressive overshoot and bounce to animated After Effects properties through a dedicated panel.

What OverAct does

OverAct, by Adam Sacks, creates exaggerated settle-and-rebound motion on keyframed properties, a style he describes as bending physics. It is applied and managed from its own panel.

Overshoot and bounce each have dedicated controls, and the effect can go on one property or several at once. Default settings can be changed and saved as presets, a graph editor overview shows the result, and the effect can be removed from a layer when finished. Animators wanting lively, elastic motion without hand-tweaking curves will find it fast.

Key features

  • Dedicated overshoot and bounce controls
  • Single or multi-property application
  • Dedicated panel
  • Save default settings as presets
  • Graph editor overview and effect removal
