What Connect Layers PRO does

Connect Layers PRO from Motion Boutique draws lines between layers and keeps them attached as the layers move. Chains, branching trees, triangulation and complex web diagrams can be generated with a single click.

Styles, curviness and dynamic motion can be tweaked on the fly. A Dynamic Verlet option adds physical movement, and step connection can flip direction. It uses a native plug-in interface and runs natively on Apple Silicon. Motion designers creating infographics, network diagrams, constellations or tech visuals will find it cuts out manual line animation.

Key features

  • One-click layer connections
  • Chains, branching trees, triangulation and webs
  • Adjustable styles and curviness
  • Dynamic Verlet option
  • Native interface with Apple Silicon support
