What LODify does

LODify optimizes huge Blender scenes, including archviz, expansive game environments and intricate kitbash builds. It manages textures, geometry, shader detail and viewport performance.

A smart scanner ranks scene textures by size or VRAM cost, and a hybrid resizing engine offers a Native mode using the Blender API and a Performance mode using a PIL backend bundled and run in a subprocess. Camera-based optimization works out the resolution each object needs from how much of the active camera's view it covers.

Key features

  • Texture scanner sorted by size or VRAM
  • Native and Performance resizing modes
  • Camera-based texture resolution from screen coverage
  • Geometry and shader detail management
  • Improves viewport performance in huge scenes
