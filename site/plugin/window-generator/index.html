What Window Generator does

Window Generator adds windows to buildings in Blender by working directly on selected faces. Choose faces and a configurable pattern is added across them.

Controls cover coverage, randomness and how many windows span across and down each face. Window width and height are adjustable, with optional random jitter for variation. Architectural and city modelers can populate facades quickly. Randomness settings help avoid a repeated, artificial look, which matters when a facade has dozens of openings.

Key features

  • Window patterns on selected faces
  • Coverage and randomness controls
  • Count across and down each face
  • Width and height with random jitter
