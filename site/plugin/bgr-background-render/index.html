Blender add-on that renders images and animations in the background without freezing the file.

What Bgr Background Render does

Bgr Background Render lets you keep working in Blender while a render runs separately. The current file is not locked up during the render.

Start from the properties panel with Render Image or Render Animation, and hold Ctrl to open options such as current frame and output path or a frame range and path. The output directory can be opened to check progress, and a .bat file can be generated to render without launching Blender. Documentation is included.

Key features

  • Background image and animation rendering
  • Ctrl for frame range and path options
  • Open output folder to monitor progress
  • Generate a .bat file for headless rendering
