What Custom Output File Manager does

Custom Output File Manager automates naming and paths on File Output nodes in the compositor. Instead of typing paths into each node, you use predefined setting words that start with "$" and can be customized.

The replacement can be plain text or a single line of short Python code, and many File Output nodes can be configured at the same time. A list view shows each setting description, its $ word and the replacement. Compositing artists with multi-pass renders benefit.

Key features

  • Custom $ setting words for paths and names
  • Single-line Python replacements allowed
  • Configure many File Output nodes at once
  • List view of words and replacements
  • Designed for compositor output
