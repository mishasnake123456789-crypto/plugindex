What Deform Pro: Mesh Deformation Tool For 2.9+ does

Deform Pro, from AlbertoFX, provides two ways to reshape assets in Blender 2.9 and newer. A Dynamic Lattice works in Object mode, letting you push and pull a lattice cage around a model.

A Surface Constraint generator deforms assets onto surfaces using a Laplacian-based method. Options such as uvwMode set values across all grid parameters and DeformMode eases lattice point selection. Hard-surface and environment artists can conform parts to shapes.

Key features

  • Dynamic Lattice in Object mode
  • Surface Deformation Constraints
  • Laplacian-based deformation
  • uvwMode and DeformMode helpers
