Blender add-on that packs multiple materials into one baked trimsheet texture set.

What Trimsheet Express does

Trimsheet Express builds trimsheets by packing several materials and all their texture channels into a single sheet, with baking handled inside the add-on. It helps game artists who need to reduce material counts.

Source materials built from Principled, Glossy, Diffuse and Transparent shader outputs are supported. Each patch can be transformed and scaled separately, with a live preview in Edit mode. You can set the output resolution, and batch-export textures in any format with customizable naming patterns.

Key features

  • Packs materials and all channels into one sheet
  • Integrated baking for complex setups
  • Per-patch transform and scale with live preview
  • Batch export with naming patterns
