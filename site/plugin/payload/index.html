What Payload does

Payload is a Blender plugin from SweetBoy for managing materials. It assigns a material to all selected objects in one click, including active faces in Edit Mode, and sorts materials into categories.

Materials can be deleted outright or set as scene overrides, and cleanup utilities remove unwanted ones. Triplanar switching makes texturing easier. It helps keep material-heavy scenes organized. Bringing these tasks into one place helps keep material lists clean and reduces the time spent hunting through slots in busy scenes.

Key features

  • One-click assignment to selections or faces
  • Create and sort materials by category
  • Delete or set scene overrides
  • Triplanar switching
