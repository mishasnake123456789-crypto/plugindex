What Mask & Layer Splitter does

From Poly Artboard comes Mask & Layer Splitter, a script for After Effects aimed at breaking a multi-mask layer apart. Each mask can become its own layer, which is useful for artwork pasted from Illustrator or shapes drawn for rotoscoping.

The script also renames the new layers, crops precomps to fit, and applies layer offsets so animation can be staggered. Version 1.2.1 added a Separate/Sequence naming option that names layers character by character or with a shared base name and zero-padded numbers. KBar is supported, with icons and a .kbar file included.

Key features

  • Separates masks into layers
  • Renames layers and crops precomps
  • Applies layer offsets
  • Separate/Sequence naming options
  • KBar icons and .kbar file included
