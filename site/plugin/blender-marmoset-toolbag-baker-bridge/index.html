What Blender <-> Marmoset Toolbag - Baker Bridge does

Baker Bridge is a Blender plugin that handles the groundwork before you bake textures in Marmoset Toolbag. Preparing high and low poly models correctly is repetitive, and this tool automates it.

It takes care of model naming, grouping and output configuration so the scene arrives ready in Marmoset. Documentation is included, and it runs on Blender 2.8 through 3.2. It is aimed at game and asset artists who bake regularly and want fewer manual setup steps.

Key features

  • Automated model naming
  • Grouping for bake sets
  • Output setup for Toolbag
  • Runs on Blender 2.8 to 3.2
  • Documentation included
