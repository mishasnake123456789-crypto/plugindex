What Nebulalink I/O - Smart Import/Export Pipeline does

NebulaLink I/O is an import and export pipeline for Blender covering OBJ, FBX and glTF/GLB. It recognizes the format of a file and applies the matching handler and preset.

Pipeline presets aim at Unity, Unreal and WebGL and take care of scale, recalculating normals and tangents, bone roll and rewiring materials. A modular fixer stack cleans normals and makes other fixes, and assets are validated before export. Game developers moving content between Blender and engines can reduce manual correction.

Key features

  • Automatic OBJ, FBX and glTF/GLB format detection
  • Presets for Unity, Unreal and WebGL
  • Fixer stack for normals and engine compatibility
  • Material rewiring and bone roll handling
  • Asset validation before export
