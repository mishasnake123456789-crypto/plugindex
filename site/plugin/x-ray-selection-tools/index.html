What X-Ray Selection Tools does

X-Ray Selection Tools extends Blender's selection tools with box, circle and lasso modes that can toggle X-Ray shading automatically. They also allow selecting through geometry.

Selection can be set to pick objects fully enclosed or merely overlapping the area, and the behavior changes on the fly with the direction you drag. Modelers who often need to select hidden elements will find selection faster and less error-prone. Choosing between enclosed and overlapping selection modes helps when picking dense geometry with accuracy.

Key features

  • Box, circle and lasso with X-Ray
  • Automatic X-Ray toggle
  • Select through geometry
  • Enclosed or overlapping selection modes
