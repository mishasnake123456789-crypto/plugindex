Blender add-on with a real-time preview of which side will be mirrored for Mirror and Symmetrize operations.

What SymTrz does

SymTrz shows you the outcome of symmetry before you commit, in Blender's 3D View. A live preview indicates which side will be mirrored, which is particularly useful for rotated objects where the direction is hard to judge.

Mirror works in Object Mode, and Symmetrize and Remove work in Edit Mode. The hotkey and color are customizable, and version 2.2.4 added an Apply Modifier option for Mirror Mode. It runs on Blender 4.2 LTS and newer and needs no special permissions.

Key features

  • Real-time symmetrize preview
  • Directional handling for rotated objects
  • Mirror in Object Mode
  • Symmetrize and Remove in Edit Mode
  • Custom hotkey and color
