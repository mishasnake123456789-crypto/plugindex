Blender add-on that turns any mesh into a woven wicker surface based on its UV map.

What Wicker does

Wicker, made by CGMatter, converts a mesh into a basket-like woven surface with one button. Because the weave is computed from the UV map, you can keep modeling and simply recalculate after adding faces.

Controls include resolution for the maximum detail, density for the number of waves, and height, thickness and width for the shape of the strands. An experimental Cull option cleans degenerate geometry. Documentation is included.

Key features

  • One-button wicker conversion for any mesh
  • Dynamic recalculation from the UV map
  • Density, height, thickness and width controls
  • Experimental Cull for degenerate geometry
