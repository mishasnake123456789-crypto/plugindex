What Brandy 2D Link does

Brandy 2D Link is a Blender add-on for 2D game artists building sprites, billboards, cutout characters and layered assets while painting textures in Adobe Photoshop.

You create and manage project folders, open the active Blender texture in Photoshop, and reload textures manually or automatically when they are saved. Matching Blender materials refresh, so you see changes without re-importing. The feature set spans project folders to create, link and recover and open active texture in Photoshop.

Key features

  • Project folders to create, link and recover
  • Open active texture in Photoshop
  • Manual or save-triggered Auto Reload
  • Materials refresh to match files
