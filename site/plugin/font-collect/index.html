What Font Collect does

Font Collect is a script by Meng Zhiqun that copies the fonts used in an After Effects project, similar to how Collect Files treats footage. This helps when sending work to another machine.

It handles fonts in languages other than English and writes a log with the number collected and the number of Adobe fonts found. It only collects local fonts, not Adobe fonts. Shift-click turns on a debug mode, and an installation guide is included.

Key features

  • Collects fonts used in the project
  • Handles non-English fonts
  • Log of collected and Adobe font counts
  • Shift+click debug mode
  • Local fonts only
