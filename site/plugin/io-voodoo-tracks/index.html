What Io Voodoo Tracks does

Io Voodoo Tracks fixes a compatibility gap between Voodoo Camera Tracker and recent Blender releases. It lets camera tracking data exported from Voodoo come into the scene again.

A Voodoo Camera Track (.py) entry is added to File > Import, so bringing the script in takes one click. It is Blender Extension compatible, distributed under the GPL license and includes documentation. Compositors and VFX artists who still rely on Voodoo for match-moving can keep that workflow on a modern Blender.

Key features

  • Restores Voodoo Camera Tracker compatibility
  • One-click import of tracking scripts
  • Adds an entry to File > Import
  • Blender Extension compatible
  • Documentation included
