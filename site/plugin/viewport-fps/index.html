Blender add-on that shows a live frames-per-second readout in the 3D Viewport, with color warnings when performance drops.

What Viewport FPS does

Viewport FPS adds a persistent frame-rate counter to Blender's 3D Viewport, so you can see how smoothly a scene is running without starting animation playback. After installation it appears as a small gray label beneath the Snapping toggle.

The readout can be tuned to your taste: show or hide the text label and decimals, set how many frames pass between refreshes, and adjust font size, corner and offset. A warning threshold switches the label to a different color when the rate falls too low, which helps when optimizing heavy scenes.

Key features

  • Real-time FPS label inside the 3D Viewport
  • Warning threshold that changes the display color
  • Refresh interval setting, down to every frame
  • Font size, corner and X/Y offset controls
  • Custom colors for normal and warning states
