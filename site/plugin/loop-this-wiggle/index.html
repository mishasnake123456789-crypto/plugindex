What Loop This! Wiggle does

Loop This! Wiggle by Gregor Urabl generates wiggle motion that loops cleanly and can be reproduced exactly thanks to seeded randomness. It works on any numeric keyframeable property, from position and rotation to text animators, Puppet pins and plugin parameters.

Frequency and amplitude are set per axis with optional clamps, and noise can be Perlin, with one to eight octaves, or Random Walk. Start and end times accept seconds or timecode. Output can stay as an expression or be baked with additive or clean options, and several properties across layers can be processed in one pass using identical seeds.

Key features

  • Seamless loops from seeded randomness
  • Works on any numeric keyframeable property
  • Per-axis frequency and amplitude with clamps
  • Perlin or Random Walk noise
  • Expression or baked keyframe output
