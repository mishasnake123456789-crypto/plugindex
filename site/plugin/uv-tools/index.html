Set of UV helpers for 3ds Max covering checker assignment, alignment, randomizing, texel density and tile fitting.

What UV Tools does

UV Tools by NiK684 collects UV editing helpers for 3ds Max, originally with architectural visualization in mind. Checker assignment can create one material per checker by default, or a single material per assignment, which lets the viewport redraw much faster across many objects.

Align functions use Ctrl+Click to align by subselection and Shift+Click to align to zero. Other tools include a reworked randomizer, fitting a selection's height or width to a tile, and distributing elements along an axis with exact spacing. Texel density controls include setting density from a custom point, and the status bar copies its text on right click.

Key features

  • Checker material assignment, one material optional
  • Align by subselection or to zero
  • Reworked randomizer
  • Fit height or width to a tile, distribute elements
  • Texel density controls
