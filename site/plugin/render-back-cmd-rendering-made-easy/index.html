Blender add-on that renders from the command line through a generated batch file, with shutdown and notification options.

What Render Back : Cmd Rendering Made Easy does

Elton Matiwane's Render Back lets you render in console mode without writing a script for each project. It creates a batch file and manages options from a panel inside Blender.

When the job ends, the computer can hibernate, sleep or shut down, the output folder can open, and a system notification can appear. There are also options for keeping the terminal open. Artists rendering long animations overnight free their interface and resources.

Key features

  • Command line rendering without scripts
  • Hibernate, Sleep or Shutdown on completion
  • Open output folder automatically
  • System notification when done
  • Panel inside Blender
