What G-Ready - Game Ready Modeling Tools does

G-Ready packs a game asset pipeline into one Blender add-on. It targets hard-surface modelers who move from blockout to finished, exportable asset, covering cleanup, UV preparation, trim sheets, high-to-low baking, LOD generation, vertex colors and smart renaming.

A radial menu launches the main tools in the viewport, among them Boolean Cleanup for messy cuts, loops and intersections, UnBevel to remove or rebuild bevels, Auto UV, Offset, Trim Sheet tools, Easy Loop and Select Surface. Offset cuts can be made around selected elements. Game artists get a single toolkit that replaces several smaller utilities.

Key features

  • Radial menu for the main viewport tools
  • Boolean Cleanup for cuts and intersections
  • UnBevel removes or recreates bevels
  • Auto UV and trim sheet tools
  • LOD generation, baking and smart renaming
