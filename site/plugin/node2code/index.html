What Node2Code does

Node2Code is a Blender plugin by Thatimster that converts node setups into add-ons of their own. If you have built a shader or node tree worth distributing, it packages that work so others can install it like any other add-on.

It handles Material, World, Compositing and Geometry nodes, individually or combined. The result can be offered as a panel, a menu item or both, and external data such as images, text and values is bundled automatically. The process takes a few steps, with metadata you can customize.

Key features

  • Works with Material, World, Compositing and Geometry nodes
  • Deploy as a panel, menu entry or both
  • Bundles images, text and external values
  • Customizable add-on metadata
