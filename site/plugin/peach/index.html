What Peach does

Peach is a panel created by Bending Spoons that adds a modern file explorer to After Effects. It lets users move files out of any folder and tidy up project contents without leaving the application.

It supports After Effects 17.0 and later, and access is limited to Bending Spoons employees. The panel is meant for in-house motion teams who want a consistent way to bring assets into projects and keep structures organised.

Key features

  • File explorer panel inside After Effects
  • Migrates files from any folder
  • Project organising tools
  • After Effects 17.0 and later
  • Restricted to Bending Spoons employees
