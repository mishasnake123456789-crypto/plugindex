Blender add-on that copies mesh detail from a closed edge ring or face onto selected target faces.

What Mesh Copier does

Mesh Copier reproduces geometric detail from one area of a mesh on another in Blender. The source comes from a chosen edge ring or a single face, and the destination by the faces you select.

Set Source, Copy and Paste are chosen directly from the menu at the lower left, and the copied detail can include separated meshes that are pasted together. Orientation can be adjusted. Hard-surface modelers repeating panels, bolts or recesses will save time versus rebuilding them each time.

Key features

  • Copies detail enclosed by a closed edge ring
  • Single face can act as the source
  • Includes separated meshes in the copy
  • Set Source, Copy and Paste from on-screen menu
