What Dimensions does

Dimensions, by Cynic.Wild, provides tools for exact dimensions, guides and measurements in the Blender viewport, useful when modeling to precise sizes. It is listed under 3D View.

The add-on is open source under GPL-3.0-or-later and requires Blender 5.1.0 or newer.

Key features

  • Guides in the viewport
