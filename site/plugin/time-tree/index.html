Node-based shot sequencing for Blender, with per-shot scene, camera, frame range and speed.

What Time Tree does

Time Tree replaces the usual linear timeline with a node graph for sequencing shots. Each node is a camera shot with its own scene, camera, frame range, duration and speed.

Shots connect through previous and next sockets, and you can reuse any range of the same scene to build alternative sequences without destroying the original. Start and end frames can run backward, and speed or duration changes produce slow motion, fast motion, reversed playback or better timing. Audio sync is maintained, which suits previs, animation editing and multi-camera projects.

Key features

  • Shot nodes with scene, camera and frame range
  • Previous and next sockets chain shots
  • Speed and duration changes for slow, fast or reverse
  • Non-destructive alternative sequences
