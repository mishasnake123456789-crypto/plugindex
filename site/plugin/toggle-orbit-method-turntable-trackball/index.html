Tiny Blender add-on that swaps the orbit style, Turntable or Trackball, with one shortcut instead of the Preferences.

What Toggle Orbit Method (Turntable / Trackball) does

Toggle Orbit Method saves a trip to Blender's Preferences whenever you want to change how the viewport rotates. A single shortcut switches between Turntable and Trackball orbiting.

The default shortcut is Alt + O and it can be customized. The add-on has no dependencies and operates in every scene, which suits modelers who prefer different orbit styles for different tasks, such as sculpting versus hard-surface work.

Key features

  • Toggle between Turntable and Trackball
  • Default Alt + O shortcut, customizable
  • No dependencies
  • No need to open Preferences
