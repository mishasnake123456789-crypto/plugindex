Shortcut-driven After Effects tool that duplicates precomps, including nested comps, as fully independent copies.

What DeepCopy does

DeepCopy by Charchit Goyal solves a familiar After Effects headache: duplicating a precomp that still shares nested comps with the original. With a single assignable keyboard shortcut, it makes copies from the Timeline or Project panel that are independent all the way down.

Footage and solids can optionally be duplicated as well, so every copy stays separate. Smart naming, automatic folder organization, label color assignment and filtering keep the project tidy, and a Preserve Animation option retains existing motion. It helps artists building variations of complex comps without breaking the originals.

Key features

  • Duplicates via an assignable keyboard shortcut
  • Independent copies of nested comps
  • Optional footage and solids duplication
  • Smart naming, folders and label colors
  • Advanced filtering and Preserve Animation
