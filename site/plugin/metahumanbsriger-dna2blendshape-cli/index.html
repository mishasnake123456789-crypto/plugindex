What Metahumanbsriger+Dna2Blendshape_Cli does

MetahumanBSriger+DNA2BlendShape_CLI brings MetaHuman facial data into Blender as a usable rig. A command-line tool first extracts FACS data from the DNA file, and the plugin then connects a controller panel to shape keys.

The result is a FACS-based face binding produced in a few minutes. It is meant for DNA files generated with UE5.5 or earlier, includes documentation and is distributed under the GPL.

Key features

  • Builds FACS facial rigs from MetaHuman DNA
  • DNA2BlendShape command-line extractor
  • Controller panel linked to shape keys
  • For DNA from UE5.5 or earlier
