What BombSquad Tools does

BombSquad Tools is a Blender add-on by aryan02420 for creating assets for the BombSquad game. It reads and writes .bob, .cob and .json files, accepting drag and drop into Blender as well as batch imports of several meshes at once.

Export can be configured to include or skip object transforms and modifiers. A one-click automatic setup lays out character parts and prepares collection exporters, and a UI panel adds map locations. Modders and level designers can work in Blender instead of handling the formats manually.

Key features

  • Import and export .bob, .cob and .json
  • Drag-and-drop and batch imports
  • Export with or without transforms and modifiers
  • One-click character and collection exporter setup
  • Panel for adding map locations
