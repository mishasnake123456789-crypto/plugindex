After Effects panel for selecting layers by row using ranges and repeating steps, driven by the keyboard.

What Select Every Other Layer does

Select Every Other Layer by Scott Black selects layers in After Effects through a flexible text syntax. You can type single numbers for every Nth layer, offsets, lists, or ranges such as 4-7, 10, 18-20.

Three modes replace, extend or subtract from the current selection, and it can select parent, child and track matte source layers. Quick up and down selection, keyboard shortcuts including custom global ones, a compact mode, real-time readouts and optional sound effects make it fast to use. It suits artists staggering or editing alternating layers.

Key features

  • Range and step syntax for layer selection
  • Selection, Add and Deselection modes
  • Selects parents, children and matte sources
  • Keyboard-driven with custom global shortcuts
  • Compact Mode and configurable sound effects
