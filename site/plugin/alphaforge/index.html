What AlphaForge does

AlphaForge from Forge Systems builds animated mattes, graphics and transitions in After Effects from a library of 200 presets, with no keyframing required. It lives in a dockable panel in your workspace.

Dynamic mode delivers fast randomized results that can be reshuffled endlessly, while Signature mode gives precise, hand-tuned looks to save and recall. A non-destructive Rebuild function lets you change anything and regenerate in place. Favorites and keyboard shortcuts speed up repeated use for artists who prefer presets to hand animation.

Key features

  • 200 presets across Dynamic and Signature modes
  • Randomized results you can reshuffle
  • Savable hand-tuned looks
  • Non-destructive Rebuild
  • Favorites and keyboard shortcuts
