What Infiniterator - Geometry Machine does

Infiniterator is a procedural geometry generator for Blender with more than 200 sliders and functions. It covers 4D rotations, raymarching, randomization and node-based symmetry, and version 3.0 runs on Blender 4.2 and later.

Generators and fractal subdivision make new forms, a camera-based path tracing fractal developer is included, and symmetry can be distorted into new patterns, with the original mesh used as an instance. You can draw shapes and run the machine on them. One slider iterates all changes, a button keyframes every changed value, and the randomizer, interface and presets were revamped.

Key features

  • 200+ sliders and functions
  • 4D rotation and fractal subdivision
  • Symmetry distortion and instancing
  • Run on your own drawn shapes
  • Keyframe all changed values with one button
