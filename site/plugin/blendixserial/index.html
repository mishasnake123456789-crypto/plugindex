Blender add-on for real-time serial communication with microcontrollers and devices over COM ports, driving objects and text.

What blendixserial does

blendixserial connects Blender to hardware through serial UART links. It sends and receives structured data with microcontrollers and embedded systems, enabling live interaction between a scene and a connected device.

Incoming values can control 3D objects, and text from the device can be displayed in the scene. Makers, researchers and interactive installation designers can prototype hardware-driven animation and visualization with Blender as the front end.

Key features

  • Real-time serial communication over COM ports
  • Structured data exchange with microcontrollers
  • Control 3D objects from device data
  • Display device text in Blender
