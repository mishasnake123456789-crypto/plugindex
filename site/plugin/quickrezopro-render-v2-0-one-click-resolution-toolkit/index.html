What Quickrezopro Render V2.0 - One Click Resolution Toolkit does

QuickRezoPro Render V2.0 is a Blender add-on for changing output size without typing numbers. Presets cover mobile, tablet, laptop and desktop screens, as well as panoramic and 360-degree formats.

Cinema options include IMAX Digital, IMAX Enhanced, DCI 2K and 4K, CinemaScope, 35mm and 70mm film, and camera presets follow Sony, Canon, Panasonic and Kodak formats. FPS control and render triggers are also provided. It helps artists delivering the same project to several platforms.

Key features

  • Mobile, tablet, laptop and desktop presets
  • IMAX, DCI and CinemaScope formats
  • Camera-maker format presets
  • FPS control and render triggers
