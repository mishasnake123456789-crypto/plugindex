What Fix Renaming Objects In Blender 4.1+ does

Fix Renaming Objects In Blender 4.1+ brings back how renaming worked before version 4.1, where assigning an existing name swapped the two names. It overrides the default F2 hotkey.

You are notified when another object's name was changed by a rename. It works when renaming from the viewport and for IDs selected in the Outliner Blender File view, including materials and meshes. Documentation is included.

Key features

  • Restores pre-4.1 name swapping
  • Overrides the F2 rename hotkey
  • Notifies when another name changes
  • Works for objects, materials and meshes
