What Digizuite Connector for Adobe Creative Cloud does

This extension from Digizuite links After Effects, Premiere Pro and other Adobe programs to the Digizuite DAM platform. Teams no longer need to leave the application to find approved material.

You can search, filter and browse folders and assets, preview any item alongside its metadata, and insert images, graphics and video straight into the project. Changes made in Adobe apps are saved back to the DAM automatically, and check-in and check-out stops people overwriting each other. InDesign, Illustrator and Photoshop are supported too. Organisations that already run Digizuite benefit most.

Key features

  • Search, filter and browse the Digizuite DAM
  • Insert rich media directly into Adobe apps
  • Preview assets with metadata
  • Edits saved back to the DAM automatically
  • Check-in and check-out to avoid overwrites
