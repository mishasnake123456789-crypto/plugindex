Places support pillars for SLA/DLP resin prints inside Blender with automatic and manual editing.

What Print Support Pro does

Print Support Pro handles supports for resin 3D printing. Pillars are placed automatically with one click, then adjusted graphically, along with bridging and duplication, and one side can be mirrored to the other.

Three pillar types, Auto, Manual (bendable) and FIX, can be switched at any time. Thickness and base shape can be adjusted in bulk, with reinforcement pillars, and edited objects can be swapped after placement. Day to day, that covers automatic pillar placement, auto, Manual and FIX pillar types and bulk thickness and base editing.

Key features

  • Automatic pillar placement
  • Auto, Manual and FIX pillar types
  • Bulk thickness and base editing
  • Mirror and swap edited objects
