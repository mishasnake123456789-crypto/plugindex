Blender add-on that merges several particle systems into one group to duplicate, loop and time together.

What Particle Groups For Particle Systems does

Inlet's Particle Groups for Particle Systems gives centralized command over multiple particle systems. Merge them into a single group that can be altered, copied and looped.

Decide when certain particles start and set the overall length of the group. To change a particular system, edit the original that built the group. Duplicates take on the original's settings, so a change made to the source or to a duplicate spreads through every linked group. Effects artists can design a burst once and reuse it throughout a scene.

Key features

  • Combine particle systems into one group
  • Duplicate and loop groups
  • Set particle start times and total length
  • Edit through the original system
  • Linked copies update together
