What Style Thief does

Style Thief is a Blender plugin by Blue Nile 3d, aimed at intelligent image color matching. It helps you borrow the look of a reference and apply it to your own image or render.

It ships as an extension of the add-on kind, works with Cycles and Eevee on Blender 4.3 through 5.1, and is released under the GPL license with documentation included. Helpful for consistent grading across shots. This is helpful for matching renders to reference images, unifying a set of shots, or exploring different color moods without manual node work.

Key features

  • Smart image color matching
  • Cycles and Eevee support
  • Blender 4.3 through 5.1
  • GPL licensed extension
