Creates and manages nulls in After Effects by clicking in the comp, with snapping and quick parenting.

What Power Null does

Power Null makes nulls interactive. Click in the composition to drop one, drag it into place, and snap it to edges, corners and anchor points. A single step adds a null at the centre of the comp.

Selected layers can be parented to the null, and chosen properties can be linked to it or to an existing null. Shape layers can substitute for nulls in settings, path properties link to masks, and text properties link to marker comments on the null. The panel docks, accepts keyboard mapping and has customisable names. Animators building rigs and controllers will save repeated menu trips.

Key features

  • Click in the comp to add a null
  • Snaps to edges, corners and anchor points
  • Parent layers and link properties
  • Shape layer option instead of nulls
  • Dockable, keyboard-mappable panel
