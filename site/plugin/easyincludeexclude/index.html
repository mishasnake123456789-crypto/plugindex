3ds Max script that includes or excludes selected objects from selected lights with add, replace or remove options.

What EasyIncludeExclude does

EasyIncludeExclude removes the need to scroll through long object lists when managing light links in 3ds Max. Choose objects and lights in one selection, then hit Include or Exclude.

Every action may extend the current list, overwrite it, or take the selected objects out, and several lights can be handled in one go. A button selects objects found in the include or exclude list, undo is supported, and existing settings can serve as the default. Selection sets can be used instead of the current selection. Standard, V-Ray and Corona lights were used for testing, FStorm and Corona cameras are covered, and it suits scenes with many lights.

Key features

  • Select objects plus lights, then press Include or Exclude
  • Add, replace or remove modes
  • Works with multiple lights at once
  • Button to select listed objects, with undo support
  • Checked with Corona, V-Ray and standard lights
