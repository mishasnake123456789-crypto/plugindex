Blender add-on for non-destructive material blending between objects, live in the viewport, Eevee and Cycles.

What Blendit does

Blendit helps objects blend into one another visually. Using the active object as a source, it creates material blends on selected objects in one click, and the blends can be applied or removed without damaging the original setup.

Results are dynamic in the viewport, Eevee and Cycles. Styles include blending by height map, noise, or a custom texture mask, and materials are created automatically from the blended objects. Normals can blend too, and texture scale is preserved through world space, object space or UV mapping.

Key features

  • One-click blends from the active object
  • Create, apply and remove non-destructively
  • Height map, noise and texture mask styles
  • Normal blending
  • World, object or UV mapping options
