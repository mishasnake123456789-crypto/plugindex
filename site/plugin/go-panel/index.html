Blender add-on with a customizable button panel for one-click mode and tool switching, aimed at tablet users.

What Go Panel does

Go Panel from Blastframe puts mode and tool switching on large buttons, which is especially convenient when working with a pen tablet and no keyboard in reach. Each button can be set up by mode or by an individual tool.

You can assign keyboard shortcuts as well, and adjust the panel's name, button size and number of columns to fit your screen. A custom tray lets you organize the tools you use most, giving a personal command surface inside Blender.

Key features

  • Switch modes and tools with a single click
  • Buttons customizable by mode or tool
  • Adjustable panel name, size and columns
  • Keyboard shortcut assignment
  • Custom tray for favorite tools
