Developer: Lucas Vera

FreeBlender

Places lights of any type at selected vertices on a Blender object and edits them all at once.

What Vertex2Light does

Vertex2Light puts lights exactly where your vertices are. Select one or more vertices on an object and the script adds your chosen type of light at each one.

Properties of all added lights, including rotation, intensity and color, can be changed together. It is ready for Blender 3.6x and lists compatibility with 2.93 through 3.5. Useful for rows of lamps, building windows, signs or any pattern of lights that follows a mesh.

Key features

  • Adds any light type at selected vertices
  • Edits rotation, intensity and color for all lights
  • Blender 3.6x ready
  • Compatible back to 2.93
