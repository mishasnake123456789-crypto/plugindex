What AE Sheets does

AE Sheets from Sidequest Plugins handles video localization in After Effects. It manages text layers, applies language presets and creates many localized versions of a composition from a single panel.

Text can be translated using your Google Gemini or OpenAI API key, with an auto-translate option. Rigging tools such as Auto Resize, Dynamic Anchor Points and Pinning keep layouts responsive to changing text length. There are 64 language presets with per-language font settings, right-to-left support, Font Maps, and spreadsheet exchange through TSV or copy and paste to Google Sheets and Excel.

Key features

  • AI translation via Gemini or OpenAI key
  • Auto Resize, Dynamic Anchor Points and Pinning
  • 64 language presets with custom overrides
  • Right-to-left text flow and Font Maps
  • TSV spreadsheet import/export and batch generation
