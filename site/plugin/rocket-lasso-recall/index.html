Stores object, rig, camera and simulation states in Cinema 4D tags so they can be restored instantly.

What Rocket Lasso Recall does

Rocket Lasso Recall saves the state of an object inside a tag and brings it back on demand. That works for objects, rigs, cameras and simulations, making it easy to keep backups, iterations and experiments within the scene.

A double click restores a saved state, which suits everyday use such as camera positions. A Recall tag can be copied onto another object to turn one into another. A Notes tab shows a preview image, date, notes and a list of stored objects, and one-click numbering, lettering and colorizing give instant feedback in the Object Manager. Compatible with R18 to 2025.

Key features

  • Stores object state in a tag for instant recall
  • Double-click restore, including camera positions
  • Backups and experiments kept inside Recall tags
  • Copy a tag to turn one object into another
  • Notes tab with preview and object list
