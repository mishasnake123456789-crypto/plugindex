Modular Blender add-on that derives normal, roughness, AO, displacement, metallic, specular and height maps from a diffuse texture.

What GeneradorMapsPbr does

GeneradorMapsPbr creates a set of PBR texture maps starting from only a diffuse image. From the diffuse alone it produces a normal map, plus roughness, occlusion and displacement textures, along with metallic, specular and height maps.

The add-on is built in a modular way. Texture artists and hobbyists who only have a color texture can quickly obtain a usable material set inside Blender instead of using external converters.

Key features

  • Normal, roughness, AO and displacement maps
  • Metallic, specular and height map output
  • Built from separate modules
  • Works from a single diffuse texture
