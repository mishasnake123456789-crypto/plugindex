What Magicavoxel Vox Exporter does

Magicavoxel Vox Exporter moves Blender models into voxel editors. It exports to the .vox, .qb and .schematic formats, so work can continue in MagicaVoxel, VoxEdit, Qubicle and similar tools.

Exporting takes a few clicks through a simple interface. It is powered by the free, open-source Vengi voxel editor and is stated to run on Windows, macOS and Linux. Documentation is included. Artists building voxel art, games or Minecraft-style schematics from Blender meshes will find it avoids intermediate conversions.

Key features

  • Exports .vox, .qb and .schematic
  • Works with MagicaVoxel, VoxEdit and Qubicle
