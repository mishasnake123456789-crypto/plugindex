What Autobackup Starter does

Autobackup Starter solves a small but annoying issue in 3ds Max: autobackup does not begin until a first save has happened. This script performs that save automatically so backups start right away.

It runs as a startup script placed in the 3dsmax\scripts\startup folder, and it is a small .ms file. It works with 3ds Max 7 or higher, and a demo video is available. Anyone who has lost work because they started modeling before saving will appreciate having protection from the very beginning.

Key features

  • Performs the first save required for autobackup
  • Runs from the startup scripts folder
  • Works with 3ds Max 7 or higher
  • Small .ms file
  • Demo video available
