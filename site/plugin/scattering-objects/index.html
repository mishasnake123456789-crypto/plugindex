Scatters objects over a Blender mesh using rigid body physics, with random rotation, scale and optional harmonic gravity.

What Scattering Objects does

Scattering Objects populates a target mesh with rocks, trees, props or any assets, applying random rotation and scale. Rigid body physics provides realistic placement as objects settle.

An optional harmonic gravity pull has customizable strength and distance to draw objects in. You designate a target mesh for distribution. Handy for natural-looking piles and debris fields. Randomness in rotation and scale keeps the result from looking repetitive, even with a small set of source objects.

Key features

  • Scatter multiple objects with random rotation and scale
  • Choose a target mesh
  • Rigid body placement
  • Optional harmonic gravity pull
