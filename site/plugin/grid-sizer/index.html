A Blender add-on that doubles, halves or resets the viewport grid size with hotkey-assignable buttons.

What Grid Sizer does

Grid Sizer gives you precise control of the Blender viewport grid. Three buttons double, halve or reset the grid size, and each can be bound to a hotkey, so scale changes while modeling take a keystroke.

An increment mode raises or lowers the grid by a constant value, in addition to the multiply and divide scaling. Changes apply across all viewports at once, or each viewport can resize independently. An on-screen Display Size indicator shows the current grid size in meters or feet. Modelers working at varying scales, from small parts to buildings, will find snapping easier to manage.

Key features

  • Double, halve and reset buttons with hotkeys
  • Increment mode for constant steps
  • Applies to all viewports or independently
  • On-screen grid size indicator in meters or feet
