What Skip Redundant Steps In Rigging does

This add-on removes repetitive rigging steps. Constraints and bendy bone targets are set from your current bone selection rather than by typing names, and new constraints receive the same parameter values automatically.

A Bendy Bones panel assigns Auto, Absolute, Relative and Tangent handles at the start and end, and macros clear and symmetrize constraints. It suits riggers building many bones with similar settings. Day to day, that covers targets set from selection, automatic matching parameters and bendy Bones handle panel.

Key features

  • Targets set from selection
  • Automatic matching parameters
  • Bendy Bones handle panel
  • Clear and symmetrize macros
