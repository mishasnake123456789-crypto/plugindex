What GeoNode Shape Keys does

GeoNode Shape Keys by Mets lets you deform linked or overridden meshes in Sculpt Mode, a situation where normal shape keys are unavailable. It suits small fixes to animated characters in a production setup.

The panel appears only for linked or overridden meshes, in Properties, Object Data, Shape Keys. Sculpting takes place on an automatically created duplicate while the original is hidden. Animators and riggers can tweak library characters without breaking links.

Key features

  • Sculpt corrections on linked meshes
  • Works with overridden meshes
  • Automatic duplicate for sculpting
  • Interface only on relevant meshes
