Blender add-on that stores animations and poses in a tidy library and applies them to a rig with one click.

What Studio Library Animation does

Re-posing a character or re-creating a walk cycle eats time. Studio Library Animation, by raha realistis studio, lets you keep poses and animations in a library inside Blender and bring them back whenever you need.

Both saving and applying take a single click, and the interface is kept plain and well organized so it does not distract from animating. Blender 4.0 through 4.5 are listed as supported, the add-on is released under the GPL, and a documentation set helps you get started.

Key features

  • One-click save and apply for poses and animations
  • Organized, simple interface
  • Blender 4.0 to 4.5 support
  • Documentation included
  • GPL licensed
