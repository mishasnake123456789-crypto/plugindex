Displays spline lengths of the active curve object right in the Blender 3D View (5.0+).

What Show Curve Length does

Show Curve Length reports how long a curve is, directly in the Blender 3D View. It measures the active Curve or Curves object and gives the length of its splines, so you do not need a script or modifier to find out.

It requires Blender 5.0 or newer, needs no special permissions and is licensed under the GNU General Public License version 3 or later. It's useful for cable, pipe and path modeling, where the real-world length of a curve matters.

Key features

  • Measures the active Curve or Curves object
  • Reports spline lengths
  • Displays in the 3D View
  • Requires Blender 5.0 or newer
