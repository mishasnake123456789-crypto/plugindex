What Curve Spirograph Addon + Extend File does

smice's Curve Spirograph Add-on generates intricate Spirograph designs as curves in Blender. This Python tool sits in the interface for creating and adjusting geometric curve patterns.

Radius, frequency and curve style control the look and complexity, and image previews help when picking patterns. An extend file adds more options. Designers making ornamental, abstract or mechanical graphics can generate them procedurally. Because the output is curve geometry, it can be bevelled, converted to mesh or animated like any other curve.

Key features

  • Spirograph patterns from curves
  • Radius, frequency and curve style
  • Image previews for pattern selection
