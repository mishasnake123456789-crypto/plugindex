What PDFin (Trial) does

PDFin from Visual Integrity is a plug-in for AutoCAD on Windows that turns vector PDF files into editable CAD drawings. It pulls out entities, layers, objects and text from computer-generated PDFs, and places images from scanned PDFs on a non-editable tracing layer.

It copes with CAD drawings, floor plans, network diagrams and organization charts, and was built for AutoCAD 2012 and later along with other Autodesk programs that support the extension API. The latest update adds 2025 support. It is helpful to those on older AutoCAD versions without a built-in PDF import.

Key features

  • Converts vector PDFs to editable CAD drawings
  • Extracts entities, layers, objects and text
  • Scanned PDF images placed on a tracing layer
  • Handles floor plans, diagrams and charts
  • AutoCAD 2012 and higher, 2025 support
