What Grabdoc does

GrabDoc is a Blender add-on by Ethan Simon-Law made for baking trim sheets and tileable textures. After installation, a one-click setup creates the scene, including a camera object used to preview rendered maps.

Custom shaders show map previews in real time across Workbench, EEVEE and Cycles, so you can judge the result before committing to a bake. When ready, you can bake all maps with Blender's default baker or hand the job to Marmoset Toolbag. It is GPL licensed, hosted on GitHub, and supported by email and Discord.

Key features

  • One-click scene setup
  • Real-time map previews in Workbench, EEVEE and Cycles
  • Bake with the default baker or Marmoset Toolbag
  • Camera object for previewing texture maps
  • GPL licensed with email and Discord support
