What Rocklab does

Synthomesh's Rocklab creates rock assets inside Blender procedurally. Within a few clicks you get many kinds of realistic stones that you can then adjust to taste, and no photoscanning is involved.

A gallery of rocks arrives with shaders for more realism, designed for Cycles from Blender 3.4. Documentation is included, it is distributed under the GPL and forms part of the HIVE Bundle from Synthomesh. Environment artists populating landscapes, caves or game levels can skip scan libraries.

Key features

  • Procedural rock generation
  • Customizable shapes
  • Gallery with shaders for Cycles
  • No photoscanning needed
  • Documentation included
