After Effects script that batch-toggles continuous rasterization on layers, comps, nested layers or a whole project.

What AEJuice Set Rasterize does

AEJuice Set Rasterize switches continuous rasterization on or off for many layers at once in After Effects, rather than one by one. This setting keeps vector artwork sharp when it is scaled.

Scope choices include selected layers, the entire project, selected compositions, and selected layers along with their nested layers. It is useful after importing Illustrator or shape artwork that needs to scale without losing quality, where flipping the switch manually would take ages.

Key features

  • Rasterization for selected layers
  • Rasterization for the entire project
  • Rasterization for selected comps
  • Includes nested layers option
  • Batch setting in one pass
