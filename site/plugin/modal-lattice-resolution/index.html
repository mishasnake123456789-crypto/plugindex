What Modal Lattice Resolution does

Modal Lattice Resolution by Tyo79 makes a lattice that matches the location, scale and rotation of the active object, then lets you tweak resolution and interpolation directly in the viewport.

It works with meshes, curves, surfaces, Grease Pencil, text or any selected objects, and can run on an existing lattice. It enters the lattice's Edit Mode automatically. Modelers deforming shapes get quicker lattice setup. Adjusting resolution while looking at the model avoids the usual cycle of opening the properties panel, changing numbers and returning to the viewport.

Key features

  • Lattice fitted to the active object
  • Works with mesh, curve, text and more
  • Modal resolution and interpolation controls
  • Enters lattice Edit Mode automatically
