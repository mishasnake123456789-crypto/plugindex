What Simple Gcode Importer does

Simple Gcode Importer, by kmnunley, brings Gcode from 3D printers into Blender as path geometry. It plugs into the File, Import menu and adds no extra panels or windows, so there is nothing new to learn.

All extrusion moves become fully editable Bezier curves, and their thickness can be set using the Extrusion and Bevel options in the Geometry section of Object Data Properties. It is released under the GNU GPL v3 or later, needs no special permissions, and supports Blender 4.2 LTS and newer.

Key features

  • Import menu integration with no extra panels
  • Extrusion moves become editable Bezier curves
  • Thickness via Extrusion and Bevel settings
  • Requires no special permissions
  • Supports Blender 4.2 LTS and newer
