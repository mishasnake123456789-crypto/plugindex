What CoreMelt V2 Plugin Set does

CoreMelt V2 Plugin Set groups a wide range of effects for After Effects and Premiere Pro. It includes transitions, advanced vignettes with luma curves, glows, blurs, a sky replace filter, and VeeYou meters that react to audio within the project.

Shape Masks limit any plugin to a custom area, with a use-mask checkbox opening an on-screen editor in Editors Tools V2 and Motion Graphics Box V2. Three C2 Gadget plugins add Shape Mask Layer, Directional Spotlight and Local Contrast. An on-screen curve overlay interface helps editing, and the set can be bought in a bundle with SliceX, TrackX, DriveX and Lock & Load.
