Blender add-on that builds 3D fractals from any base object as a nested tree of copies you reshape with native transform tools.

What Fractal Explorer does

Fractal Explorer creates self-similar structures in Blender starting from whatever object you provide. It builds a nested tree of copies that are parented and constrained to inherit transforms from their parent.

You shape the fractal using Blender's regular rotate, translate and scale tools, and can adjust the depth of the tree and the number of branches per copy. Generative artists and educators get an interactive way to explore recursive forms.

Key features

  • Nested tree of copies from any object
  • Shaped with native rotate, translate and scale
  • Adjustable depth and branch count
  • Copies inherit parent transforms
