What Blender Addon | Checktoolbox does

Checktoolbox, from VFX Grace, helps modelers inspect topology inside Blender. In Edit Mode it highlights issues through shading colors, and an overview counts objects, points, edges, polygons, doubles, isolated elements and n-gons.

Detection covers doubles, loose geometry, triangles, poles, non-manifold edges, boundaries, intersections, distortion and degenerate polygons, plus face orientation. A Details window shows per-object breakdowns, Select jumps to errors, and the display refreshes manually or automatically every three seconds.

Key features

  • Object and mesh element counts
  • Detects poles, n-gons, non-manifold and doubles
  • Color-coded error shading in Edit Mode
  • Details window and Select button
  • Manual or three-second automatic refresh
