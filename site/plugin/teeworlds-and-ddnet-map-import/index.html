What Teeworlds and DDNet Map import does

This add-on by Patiga lets Blender open map files from the games Teeworlds and DDNet. It registers the .map format under File, Import, so level layouts from those games can be brought into a scene.

Version 0.4.1 uses node groups to simplify the materials. It requires Blender 4.2 LTS or newer, runs on Windows and Linux, and installs by drag and drop or Install from Disk.

Key features

  • Imports Teeworlds and DDNet maps
  • Adds .map under File, Import
  • Node group based materials
  • Blender 4.2 LTS and newer
  • Windows and Linux
