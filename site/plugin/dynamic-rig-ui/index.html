What Dynamic Rig UI does

Dynamic Rig UI, by Samy_Rodriguez, creates a control panel for armatures that responds to the rig's bone collections and custom properties, so animators get a tidy interface that follows the rig. It falls under Workflow.

The add-on is open source under GPL-3.0-or-later and requires Blender 5.0.0 or newer.

  • UI driven by bone collections
