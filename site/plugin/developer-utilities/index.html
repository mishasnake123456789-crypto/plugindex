Developer: scorpion81

Blender extension combining operator source editing, add-on source editing and Python API lookup, plus docs generation.

What Developer Utilities does

Developer Utilities by scorpion81 bundles three formerly separate tools for add-on authors: Edit Operator Sources, Edit Addon Sources and Python API Lookup. All three were fixed to run on Blender 4.3 and newer.

It also generates documentation for a whole add-on with one click using the pdoc module, which needs no configuration and handles type annotations, cross-linked identifiers and numpydoc or Google-style docstrings. A helper installs pdoc through pip when it is missing, and another stops the HTTP server that can start automatically to preview the docs in a browser.

Key features

  • Three developer tools in one extension
  • One-click add-on documentation with pdoc
  • Installs pdoc through pip if missing
  • Stop button for the preview HTTP server
  • Runs on Blender 4.3 and newer
