AI plugin that turns sequence audio into animated, emotion-aware subtitles as editable Motion Graphics Templates.

What PHONT Studio does

PHONT Studio transcribes the audio in a Premiere Pro sequence and builds animated subtitles from it. The animations respond to the emotion in each line, and manual animation styles are also available.

Output comes as fully editable Motion Graphics Templates, with control over font, text color, highlight color and intensity. A visual word-timing editor fine-tunes timing and emphasis, translation is optional, and custom vocabulary and reusable presets speed up repeat work. Social video makers and editors who want expressive captions without keyframing each word can use it.

Key features

  • AI transcription with optional translation
  • Emotion-aware animation styles
  • Editable MOGRT output
  • Font, color, highlight and intensity controls
  • Visual word-timing editor and presets
