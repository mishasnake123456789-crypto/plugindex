What Ghostool does

Ghostool is an animator's aid in Blender. It creates ghosts, meaning onion skins plus static meshes at selected frames, directly in the 3D viewport.

Animated frames can be frozen to compare poses, supporting work on in-betweens, timing and spacing. It supports Blender 3.3 through 5.1. Character animators can see earlier and later poses together while refining motion. Seeing earlier and later poses together makes spacing problems and timing issues easier to spot than scrubbing the timeline.

Key features

  • Onion skin ghosts in the viewport
  • Static meshes at chosen frames
  • Freeze frames to compare poses
  • Supports Blender 3.3 through 5.1
