Blender add-on that tracks and organizes textures, videos and linked libraries and shows where each is used.

What Resources Manager does

Aderemi Adesada's Resources Manager keeps a project's external files under control. For each resource it shows which materials and objects refer to it, so you know at once whether a texture is in use and where.

Resources can be gathered into a folder relative to the blend file, renamed with a double click, or removed when unneeded. Documentation is available. Artists preparing projects for sharing or archiving avoid missing-file errors.

Key features

  • Tracks material and object references
  • Shows whether a texture is used
  • Consolidates resources relative to the blend file
  • Rename by double click
  • Delete unneeded resources
