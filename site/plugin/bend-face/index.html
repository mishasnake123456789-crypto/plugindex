Bend Face

Developer: KushiroCG

FreeBlender
Download Free

Blender tool for rotating or moving selected faces around any edge or along their normal, with numeric input.

What Bend Face does

Bend Face lets modelers fold chosen faces in Blender. Drag to swing or shift faces about any edge, with the closest edge marked in yellow, or key in precise values.

Face Normal Mode on the F key moves faces along their normal. Rotate Extrude builds edge loops between the starting and final face using a set number of copies, and the Left-Bottom menu takes numeric angle or distance, which can also change the last action. Quick rotation hotkeys speed up hard surface modeling.

Key features

  • Rotate or move faces around any edge
  • Face Normal Mode on F key
  • Rotate Extrude with copies
  • Numeric angle and distance input
