What Shapekey Cleaner Pro - Fix & Clean Shape Key Deformations does

ShapeKey Cleaner Pro fixes stray deformation without hand-editing vertices or rebuilding shape keys. Select an area and Clean Selected Area resets that region to the Basis shape with a click.

Vertex groups act as reusable masks so one area can be cleaned across several shape keys, and a current selection can become a mask directly. Facial riggers and character artists with noisy corrective or expression shapes will save plenty of time.

Key features

  • Clean Selected Area with one click
  • Vertex-group masks reusable across shape keys
  • Create Mask from Selection
  • Restores deformation to the Basis
