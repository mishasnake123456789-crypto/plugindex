What Easy Model Compositing Addon does

This Blender add-on, Easy Model Compositing, is meant for placing 3D models into live-action footage. After a render, it writes separate Object, Shadow, Reflection and ambient occlusion passes and sorts them into folders as image sequences, set up for dropping into a compositing app.

It handles still frames and full animations. Shadows are captured whether they come from an HDR environment map or from lamps in the scene. Everything is produced in one pass, which can cut render time compared with rendering each layer separately.

Key features

  • Object, Shadow, Reflection and AO passes
  • Organized folders of image sequences
  • Shadows from HDR maps and lamps
  • Single-pass output for stills and animation
