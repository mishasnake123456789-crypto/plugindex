What circuitFX does

circuitFX is Real Creations's tool for After Effects that draws circuit board graphics for you. Each press of the button builds a new random layout of lines, circles, chips, resistors and capacitors, so you can generate many designs quickly.

Parts can be placed on one shape layer or split into separate layers per component. Grid X and Grid Y adjust density, and a masks mode lets you draw guides and generate a circuit from them. A static seed repeats an identical circuit when other values remain the same. It is a good fit for technology and sci-fi projects, animated backgrounds and HUDs.

Key features

  • Random circuit generation per click
  • Lines, circles, chips, resistors and capacitors
  • One shape layer or separate layers per part
  • Grid X and Grid Y density controls
  • Mask-driven mode and static seed
