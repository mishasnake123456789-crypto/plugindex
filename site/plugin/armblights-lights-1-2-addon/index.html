What Armblights Lights 1.2 Addon does

Armblights supplies thirty IES lights that can be placed with a single click. Each pattern follows IES standards, giving the realistic spread of real fixtures such as downlights, wall washers and spotlights.

The IES nodes are linked automatically for each choice, and a panel lists all thirty options. It is built for the Cycles render engine. Interior and architectural visualizers who want believable lamp falloff without hunting for files will set up lighting faster.

Key features

  • 30 IES light types
  • One-click placement
  • IES nodes linked automatically
  • Made for Cycles
