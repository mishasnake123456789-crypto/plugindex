What Nature Clicker - Free Addon does

Nature Clicker is a free Blender add-on for placing nature assets by clicking, giving more control than a particle system. By default, copies are instances, keeping memory use low, and it works with libraries such as Grasswald and Botaniq.

You can move around the scene and change panel sliders without ending the placing operation. An optional setting moves placed objects to a CLICKR collection so hiding that collection hides them all. Enter confirms the placement. It suits environment artists who want art-directed foliage and rocks.

Key features

  • Click-to-place nature assets
  • Instances by default for low memory
  • Keep placing while adjusting sliders
  • Optional CLICKR collection for placed assets
  • Works with Grasswald and Botaniq
