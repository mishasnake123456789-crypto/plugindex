What Dynamic Render Border does

Dynamic Render Border sizes the render region to follow your subject in Blender, so only the needed part of a scene is rendered. It tracks individual mesh objects from an Object List or whole collections, sub-collections included, and updates on frame changes when enabled.

Padding around the computed border is adjustable, a button refreshes it immediately, and a toggle switches the function off. Controls sit in the DynBorder tab of the 3D Viewport sidebar. It switches itself off if it cannot find a valid target or the targets leave the frame.

Key features

  • Border follows objects or collections
  • Updates on frame changes
  • Adjustable padding
  • Update Border Now button
  • Automatic disable when targets are off-screen
