What PQ Mo•Bits does

PQ Mo•Bits is an icon library for motion designers who need familiar everyday symbols already animated. Search or browse inside a dockable After Effects panel and drop what you need directly into the project.

Controllers let you tweak a range of parameters so each icon matches your design. It supports After Effects from CS6 through 2026, so it works with long-standing installs as well as current ones. Good for explainers, interfaces and social graphics.

Key features

  • Library of pre-animated everyday icons
  • Dockable search and browse panel
  • Drop icons straight into projects
  • Controllers for parameter tweaks
  • Supports After Effects CS6 to 2026
