What Max Stack - Max Modifiers And Stack does

Max Stack recreates a set of 3ds Max style modifiers for Blender and makes them work as one system. Selections flow down the stack, and a single panel shows the logic.

The 27 modifiers cover deform, select, UV and array operations, each added as a Geometry Nodes modifier under its own category in the Add Modifiers menu. Spatial modifiers have viewport gizmos, such as cages and slices, that can be dragged and rotated. Artists coming from Max will find the stack-driven approach familiar.

Key features

  • 27 Max-style modifiers
  • Each is a Geometry Nodes modifier
  • Draggable viewport gizmos for spatial modifiers
  • Selections flow down the stack
  • Single panel shows the modifier logic
