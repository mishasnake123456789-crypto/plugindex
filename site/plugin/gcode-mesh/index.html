Imports G-code into Blender as a 3D-printed mesh, with an optional printing animation that follows the toolpath.

What Gcode Mesh does

Gcode Mesh converts machine toolpaths into visible geometry. It reads .gcode, .bgcode and .gcode.3mf files and builds a mesh that looks like the printed object.

An animation option shows the print progressing along the G-code, with its duration set in the object's Modifiers tab, where layer height, nozzle diameter and material can also be adjusted. Good for 3D printing product videos and previews. The preview approach is helpful for showing how a part was built, layer by layer, without recording the real printer.

Key features

  • Reads .gcode, .bgcode and .gcode.3mf
  • Printing animation follows the G-code
  • Layer height and nozzle diameter controls
  • Settings in the Modifiers tab
