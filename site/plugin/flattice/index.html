Controls perspective distortion at the object level using a lattice-like approach.

What Flattice does

Flattice gives Blender users control over how strongly perspective distorts an individual object. Normally perspective is a property of the camera, so changing it affects everything in the frame equally.

With this add-on, the effect can be adjusted per object, which is useful for flattening wide-angle stretching on a prop or character without changing the whole shot. Artists tuning product shots, close-ups or stylised scenes can fine-tune the look of one object while leaving the rest alone.

Key features

  • Per-object perspective control
  • Reduces wide-angle stretching
  • Leaves the rest of the scene untouched
