What Cracks Damage Addon💥Windows, Linux, Mac Approved does

Cracks Damage Addon uses geometry nodes to add fractures to meshes and curve objects in Blender with one click. Three crack types are offered: Fast Cracker with clean topology, Glass Cracker, and Simulation Cracks for animated breaking.

An Explode Mesh islands modifier produces exploded views, built-in UV unwrapping covers inside and outside surfaces, and built-in remeshing handles individually cracked pieces. An empty can be placed to target damage, masking can be generated and loaded, and Rapid mode turns off UVs and materials for speed.

Key features

  • Fast, Glass and Simulation crack types
  • One-click damage on meshes and curves
  • Explode Mesh islands modifier
  • Built-in UV unwrap and remesh
  • Empty-based targeting and Rapid mode
