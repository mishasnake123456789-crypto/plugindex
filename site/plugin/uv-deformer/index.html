What Uv Deformer does

UV Deformer lets you push and pull UVs using a simple lattice placed directly in Blender's UV Editor. It is meant for correcting distortion, adjusting selections and getting precise layouts without moving vertices one at a time.

A mesh can carry several lattices, each tied to a particular UV selection. In warp mode you hover, pick and drag control points, with Ctrl+click for multiple points, and the grid resolution can change between 2 and 10 in each direction while keeping your deformation. Individual lattices can be hidden, deleted or confirmed from the sidebar, and cancelling restores the original UVs.

Key features

  • Multiple lattices per mesh, each on its own UV selection
  • Interactive warp mode with drag and multi-select
  • U/V grid resolution from 2 to 10
  • Smooth bilinear interpolation with undo support
  • Per-lattice show, delete and bake controls
