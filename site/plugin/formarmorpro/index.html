What Formarmorpro does

FormArmor Pro puts mold-making steps into one workflow. It generates outer mold shells around a selected object with control over wall thickness and clearance.

You can make single or multi-part molds using automatic or manual split planes, add alignment features, check draft angles, estimate silicone volume and export STL files in batches. Handy for makers and prop casters. The feature set spans mold shell generation with wall thickness and automatic or manual split planes.

Key features

  • Mold shell generation with wall thickness
  • Automatic or manual split planes
  • Draft angle check and silicone volume estimate
  • Batch STL export
