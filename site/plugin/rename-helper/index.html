What Rename helper does

Rename helper is a script from Chuggnut that speeds up naming multiple distinct objects in 3ds Max. Select the objects, run the macro, type a name and press return; a yellow box in the viewport marks the object being named.

The highlight is a yellow box drawn around the object, which prevents mistakes when scenes contain many similar items. It suits workflows where every object needs a unique name rather than a numbered series, such as rigging controls, props or level pieces. The script is at version 2.3.5 and is free.

Key features

  • Renames multiple unique objects from one selection
  • Macro workflow: select, click, type, return
  • Current object shown with a yellow box
  • Version 2.3.5
