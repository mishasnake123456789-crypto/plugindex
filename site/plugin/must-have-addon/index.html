Blender add-on that packs a scene's external files into one folder with a path-corrected blend copy.

What Must-Have Addon does

studioromanrec's Must-Have Addon prepares a Blender project for moving or sharing. It collects every outside file the scene depends on, whether materials, textures, assets, VDB files or sound effects, into one folder.

A duplicate of the blend, named with _copy appended, is saved in that folder and every path inside it is updated to the collected files. A text file notes where each file originally came from. Useful for handoffs, archiving and render farms.

Key features

  • Collects materials, textures, VDBs and sounds
  • Saves a _copy blend in the same folder
  • Updates file paths automatically
  • Text file listing original locations
  • Single folder output
