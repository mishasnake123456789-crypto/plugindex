Blender modifier that keeps Solidify thickness and offset in sync across many objects.

What Global Solidify does

Global Solidify links Solidify settings across a Blender scene so a single change updates everything. Change thickness or offset on a single modifier and each linked instance follows in real time, while every object keeps its own vertex group.

It appears directly in the Add Modifier menu, spans all mesh objects in the file without grouping, linking or parenting, and runs lightly in the background. Numeric values sync globally while vertex group assignment stays per object. Anyone needing uniform wall thickness across many objects, such as archviz, motion design, hard-surface or product work, will find it handy.

Key features

  • Real-time sync of thickness and offset
  • Per-object vertex groups preserved
  • Available from Add Modifier menu
  • No linking or parenting needed
  • Lightweight background operation
