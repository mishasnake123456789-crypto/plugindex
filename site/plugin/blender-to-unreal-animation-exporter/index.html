What Blender To Unreal Animation Exporter does

Blender to Unreal Animation Exporter shortens the trip from Blender to Unreal. It carries over scenes, FBX files, character folders, animations, materials, textures, static collision and PhysicsAssets.

Common character package layouts are detected, so the base skeletal mesh comes in ahead of the animations, and animation-only imports reuse the same Unreal Skeleton rather than creating duplicate, broken skeletal meshes. Game developers with many animation files will find the repeated steps handled for them.

Key features

  • Detects common character package layouts
  • Imports base skeletal mesh before animations
  • Reuses the same Unreal Skeleton
  • Brings in materials, textures and collision
  • Supports PhysicsAssets
