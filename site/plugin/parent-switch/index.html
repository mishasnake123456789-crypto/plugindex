What Parent Switch does

Parent Switch, by zakrich, lets you change what an object follows over time, creating and animating switches between Child Of constraints. That suits props that move from one parent to another. It is tagged under Animation and Rigging.

Open source under GPL-3.0-or-later, it requires Blender 4.2.0 or newer.

Key features

  • Creates Child Of constraint switches
  • Animates the switches
