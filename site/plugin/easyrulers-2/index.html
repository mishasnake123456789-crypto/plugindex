What easyRulers 2 does

From Real Creations comes easyRulers 2, a plugin for After Effects aimed at quickly building rulers of any kind. It is aimed at gauges, scopes, speedometers, equalizers, HUDs, UI elements, historical timelines, instrument layouts, infographics and audio interfaces.

It includes a date function with several output formats and can loop through weekdays and months. The pointer can blink or be locked, completion percentage is supported, and wiggle options have speed, from, to and seed controls. Text prefixes and suffixes get separate size, offset and tracking. It is ready for Apple Silicon, with a multithreaded flag added for After Effects 2022.

Key features

  • Any type of graphical measuring ruler
  • Date function with multiple formats
  • Weekday and month looping
  • Pointer blink, lock and wiggle options
  • Separate prefix and suffix text controls
