What Step Motion does

Step Motion is a Blender addon by YONK for stop-motion style animation. While editing or sculpting, you create, duplicate and add frames with hotkeys, and you can preview the animation in real time.

To insert an in-between, select an earlier frame and run New Frame or Duplicate Frame, then set where the frame goes. With onion skinning the active frame stays clear, older frames tint red and upcoming ones tint blue. It fits animators who want a pose-to-pose workflow with objects or sculpts.

Key features

  • Create, duplicate and add frames with hotkeys
  • In-between frame insertion
  • Onion skinning with red past and blue future frames
  • Real-time animation preview
  • Works while editing and sculpting
