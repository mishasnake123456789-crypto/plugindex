An After Effects extension for drawing, editing and exporting storyboards as PDF without leaving the app.

What Storyboard Maker does

Storyboard Maker brings storyboarding into After Effects, so you can plan scenes next to the project that will realize them. A drawing panel is used for the frames, and a built-in image editor helps modify artwork.

Images can be applied as layers, the number of columns is customizable, a button clears photos, and the finished board is exported to PDF. It suits motion designers and directors pitching ideas. It is intended for motion designers and directors who want to sketch ideas and share them as a document.

Key features

  • Drawing panel for frames
  • Built-in image editor
  • Apply images as layers
  • Custom column count
  • PDF export
