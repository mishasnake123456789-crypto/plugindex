What Zaebects Oscilloscope does

Zaebects Oscilloscope imitates the look of a CRT oscilloscope beam. Feed it a picture, audio, a path or a test signal, and it draws glowing analog traces with the character of old phosphor screens.

Gain and threshold settings shape the signal, trace controls set resolution, steps and beam point density, and timing controls adjust scan speed and phosphor persistence. Beam width, brightness, flicker and curvature complete the look, and output is transparent for overlays. Use it for retro titles, contour graphics and abstract beam motion.

Key features

  • Picture, audio, path and test signal sources
  • Gain and threshold controls
  • Trace resolution and beam density settings
  • Scan speed and phosphor fade timing
  • Beam width, flicker and curvature, transparent output
