3ds Max script that improves dropping textures into Slate, picking the right bitmap node for V-Ray, Corona, Redshift or FStorm.

What DropToSlate does

DropToSlate extends how the Slate Material Editor in 3ds Max handles textures dragged into it. It detects the active renderer and creates the appropriate node: VrayHDRI for HDR and EXR files in V-Ray, CoronaBitmap in Corona, and RS_Bitmap in Redshift, with FStorm bitmaps given gamma 2.2.

HDR and EXR files also receive spherical mapping automatically, and bitmaps can be dropped with relative paths. Shift, Ctrl or Alt modifiers override gamma or open Resize at the moment of the drop. After a drop, the first texture opens in the Parameter Editor and Slate takes focus. The script also turns off Auto Open Nodeslots when 3ds Max starts.

Key features

  • Right bitmap node chosen per renderer (V-Ray, Corona, Redshift, FStorm)
  • HDR and EXR files mapped spherically on drop
  • Shift, Ctrl or Alt modifiers to override gamma or open Resize
  • Relative path support for dropped bitmaps
  • Opens first texture in Parameter Editor and focuses Slate
