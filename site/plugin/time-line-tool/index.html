Randomizes Blender animation timing with a random offset and sets the timeline range from keyframes.

What Time-Line _Tool does

Time-Line _Tool helps vary repeated animation. A Random Offset feature shifts animations in time, which allows endlessly different variations from the same motion.

Auto Range sets the timeline start and end from the first and last keyframes, saving a manual step. Documentation is included, it is released under the GPL license, and an updated version for Blender 4 is available on the developer's page. Handy for crowds, background elements and copies of the same cycle.

Key features

  • Random Offset for varied timing
  • Auto Range from first and last keyframe
  • Documentation included
  • GPL license
