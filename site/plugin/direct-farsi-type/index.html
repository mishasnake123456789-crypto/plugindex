What Direct Farsi Type does

Direct Farsi Type is a script that makes typing Farsi directly into the 3ds Max viewport possible, which is otherwise awkward. It is intended for artists who need Persian lettering in their scenes.

Update V01.1.0 made the script ignore upper modifiers, and it runs on 3ds Max 6.0 or later. It is a free script, and a demo video is available on YouTube. Designers working with Persian titles, signage or typography can use it to produce text more naturally.

Key features

  • Types Farsi text directly in the viewport
  • Ignores upper modifiers since V01.1.0
  • Runs on 3ds Max 6.0 or later
  • Free script with a YouTube demo video
