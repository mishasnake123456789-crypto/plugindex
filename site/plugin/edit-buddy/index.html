Edit Buddy

Developer: Tiramisu

FreePremiere Pro

An AI assistant for Premiere Pro that proposes interview edits from a transcript and applies them to the timeline.

What Edit Buddy does

Edit Buddy reads a transcript generated from a captions file and, given a prompt such as finding the most emotive moments, suggests which dialogue to keep. Once you approve, the Edit Buddy Executor extension edits the timeline to match.

It needs an OpenAI API to function. Editors working on interview footage can use it to speed up selects. It is a way to find soundbites quickly in long interviews, with the editor approving what gets cut.

Key features

  • Reads interview transcripts from captions
  • AI edit suggestions from a prompt
  • Automatic timeline edits
  • Works with Edit Buddy Executor
  • Requires OpenAI API
