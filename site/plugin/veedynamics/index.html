What Veedynamics does

VeeDynamics is a connection from Blender to the Gaia Vertex Block Descent simulator, aimed at high-performance elastic body simulation. It can handle thousands of elastic objects, with speed measured in seconds per frame.

The package has two components: the Blender add-on, released under the GPL, and the VeeDynamics solver side. Simulation-heavy projects such as piles of soft objects benefit from this setup. Offloading the heavy calculation to a dedicated solver keeps Blender responsive while still letting you set up and view the results in familiar scenes.

Key features

  • Link to the Gaia Vertex Block Descent solver
  • Thousands of elastic objects
  • Seconds-per-frame performance
  • GPL-licensed Blender add-on
