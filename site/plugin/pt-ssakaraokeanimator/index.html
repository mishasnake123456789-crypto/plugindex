What pt_SSAKaraokeAnimator does

pt_SSAKaraokeAnimator is a script by Paul Tuersley that converts karaoke subtitle files into animated text in After Effects. It reads Substation Alpha .ssa and .ass files as well as KaraFun Studio .kfn files.

Version 3.5 added faster basic presets and an animated text crawl option, along with fixes to highlighting, timing and non-English handling. Bouncing ball options are available, and a user presets folder is supported. It is aimed at artists producing lyric videos and sing-along clips who prefer not to time every syllable manually.

Key features

  • Imports KaraFun Studio .kfn files
  • Reads .ssa and .ass subtitle formats
  • Faster basic presets
  • Animated text crawl and bouncing ball options
  • User presets folder support
