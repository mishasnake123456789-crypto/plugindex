What MoleculeGen° does

MoleculeGen° from GothLab is an After Effects extension that calculates and builds intricate circle-pack arrangements, then animates them. It gives you control over the number of circles and whether they share a uniform size.

Each element's position, rotation, fill and stroke can be adjusted individually, while batch placement manages groups of circles across multiple layers at once. More than 200 color themes and extra strokes add variety. For 3D output it exposes extrusion and other parameters, which need the Cinema 4D renderer enabled, so motion designers can work in both 2D and 3D.

Key features

  • Circle-pack shape calculation and generation
  • Per-element position, rotation, fill and stroke
  • Batch placement with adjustable batch size
  • Over 200 color themes
  • 3D extrusion for the Cinema 4D renderer
