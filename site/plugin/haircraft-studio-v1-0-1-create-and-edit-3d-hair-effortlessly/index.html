What Haircraft Studio V1.0.1 - Create And Edit 3D Hair Effortlessly does

Haircraft Studio is a Blender add-on that brings ready-made hair into a scene so you do not have to build it from scratch. Its library holds 113 hairstyles, with more planned, and a summon command adds a chosen style within seconds.

Once a hairstyle is in the scene you can change its color, curve and shader, apply a twist tool to alter the strands, set a custom curve and convert the hair to a mesh. It suits character artists who want fast, editable hair for their models, and documentation is included.

Key features

  • Library of 113 hairstyles
  • Summon a chosen hairstyle in a few seconds
  • Recolor hair and adjust its curve and shader
  • Twist tool for strand editing
  • Convert hair to mesh
