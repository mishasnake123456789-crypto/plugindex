Three-part Blender foliage pipeline: texture atlas baking, mesh cutting from opacity maps and cluster growing.

What Foliagelab - Complete Suite does

Foliagelab combines Atlas, Cutter and Cluster into one pipeline for production-ready foliage. Together they take textures and meshes through to composed plants.

Atlas scans a folder of PBR textures, places the assets and bakes a clean atlas. Cutter builds a mesh from an opacity map without retopology or manual cleanup. Cluster grows foliage from anchor points. Environment artists building vegetation libraries for games will find the stages connected. Each stage hands its result to the next, which keeps plant production consistent.

Key features

  • Atlas scans PBR textures and bakes an atlas
  • Cutter makes meshes from opacity maps
  • Cluster grows foliage from anchor points
  • Single production pipeline
