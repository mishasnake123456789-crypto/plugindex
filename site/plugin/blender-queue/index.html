Blender batch rendering and project management add-on that queues files and scenes for sequential rendering.

What Blender Queue does

Blender Q's Blender Queue lines up several projects and scenes to be rendered automatically one after another. Samples, output format and other settings can be set for many files together.

Shortcodes handle batch renaming and building render output paths. Edit Item changes a display name or points an item at another file. Projects are also organized as independent, reloadable files. Studios and freelancers with long render lists can manage them from one interface.

Key features

  • Sequential batch rendering
  • Set samples and format for multiple files
  • Shortcodes for names and output paths
  • Edit Item to retarget files
  • Reloadable project files
