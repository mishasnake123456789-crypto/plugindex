Organizes Blender shape keys into folders and subfolders and lets you view up to three keys together.

What Shape Key Collections does

Shape Key Collections adds a folder structure for shape keys. You can rename each key and place it into folders and subfolders, taming long lists on character meshes.

Split Keys combines up to three shape keys and shows each value in one place, which is convenient for related expressions. A cleaner way to manage facial shape sets. Better organization reduces errors on rigs with large expression libraries, and makes it easier to find the key you want.

Key features

  • Folders and subfolders for shape keys
  • Rename and assign keys
  • Split Keys view for up to three keys
  • Duplicate folders
