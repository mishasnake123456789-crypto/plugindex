Blender add-on for timestamped saves, timed rolling backups and quick reverts.

What Smart Save Pro does

Smart Save Pro adds structured versioning on top of Blender's default autosave. One click creates a timestamped save of your file.

Rolling backups can be generated automatically on a timer, and earlier versions are restored from a dedicated versions folder that keeps files organized. It is distributed as a Blender Extension with documentation.

Key features

  • One-click timestamped saves
  • Timed rolling backups
  • Instant revert to earlier versions
  • Dedicated versions folder
