What Printing Helper does

Printing Helper is a Blender add-on by ACGGIT_LJ that derives a print-ready render resolution from physical size and DPI. It lives in a panel in Render Properties and converts in both directions between resolution and physical print size.

Paper sizes include North American formats (Letter, Legal, Ledger, Tabloid), ANSI A to E, Architectural Arch A to E3 and the ISO A, B and C series. DPI presets cover 72, 150 and 300, with custom values allowed, and a real-time preview shows the output at different DPI. Useful for posters and print illustrations.

Key features

  • Converts between resolution and print size
  • North American, ANSI, Arch and ISO paper standards
  • 72, 150 and 300 DPI presets, custom values too
  • Real-time preview at different DPI
  • Panel in Render Properties
