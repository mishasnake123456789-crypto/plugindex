What Split - Real Time Comparison does

Split lets you see before and after at the same time. A draggable split line in the 3D Viewport divides a saved state from the current one.

Line thickness and color are adjustable, and it is built on Blender's real-time compositor for interactive changes. The panel is in the Sidebar under Split, and it works with Cycles, Eevee and Octane. Useful for judging lighting, materials and color tweaks. Notable points: draggable split line, adjustable thickness and color and real-time compositor based.

Key features

  • Draggable split line
