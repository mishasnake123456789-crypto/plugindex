What Trickshots does

Trickshots takes a described scenario, such as a trickshot, and searches for scene settings that make it happen. It runs many simulations and adjusts parameters until the outcome matches what you wrote.

A unique solver creates variables and optimization tasks as the scenario unfolds, using genuine Blender physics without fakes. Helper functions set initial object velocity and detect events. Simulation fans and animators creating chain reactions can get there without long trial and error.

Key features

  • Real physics simulation, not fakes
  • Solver creates variables and optimization tasks
  • Initial velocity and event detection functions
  • Iterates until the scenario is satisfied
