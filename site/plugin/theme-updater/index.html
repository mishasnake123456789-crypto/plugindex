Blender add-on for theme authors that migrates custom themes from 4.5 LTS to Blender 5.0 properties.

What Theme Updater does

Theme Updater is for people who maintain custom Blender themes. Blender 5.0 generalized several theme properties, such as sidebars, panels and curves, so older themes need their colors carried over.

An operator in the add-on preferences reads the XML file of a 4.5 LTS theme and fetches colors from similar properties to update the active theme. A Custom File mode lets you choose an older theme XML yourself. No special permissions are needed, and it installs by drag and drop or from disk.

Key features

  • Updates the active theme to Blender 5.0
  • Reads a 4.5 LTS theme XML
  • Custom File mode for older themes
  • Maps to generalized properties
  • Operator in add-on preferences
