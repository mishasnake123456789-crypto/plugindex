Blender add-on that renders 3D objects into alpha brushes, trims, masks, decals and texture maps.

What Z-Shot does

Z-Shot, from Shape-Shift, turns models into flat image assets without requiring you to build a render setup. Pick a mode, adjust output settings and render; camera placement and shader work are handled for you.

modes cover BSDF channels, opacity, vertex color, ambient occlusion, curvature, normal and height, with a custom mode for hand-built shots and a channel packing mode for combining maps. Batch rendering outputs several images at once, and files can be written as EXR, TIFF or PNG. A Trimflow helper renders trim sheets and writes a JSON file for that tool.

Key features

  • Render modes for height, normal, AO, curvature and BSDF channels
  • Custom mode where you frame the shot
  • Channel packing of existing maps
  • One-click batch rendering
  • EXR, TIFF and PNG output with Trimflow JSON
