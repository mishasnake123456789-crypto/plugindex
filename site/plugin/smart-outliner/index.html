Blender add-on that automatically scrolls the Outliner to reveal whichever object you select in the viewport.

What Smart Outliner does

Smart Outliner keeps Blender's Outliner in step with your selection. Click an object in the 3D Viewport and the Outliner scrolls to show and highlight it.

Syncing updates in real time as you move between objects, and it starts automatically when a file loads, so no button needs pressing each session. It runs quietly in the background and works with Blender 3.6 and 4.x. It is most helpful in large scenes with many nested collections.

Key features

  • Reveals the selected object in the Outliner
  • Real-time syncing
  • Auto-start on file load
  • Lightweight background operation
  • Supports Blender 3.6 and 4.x
