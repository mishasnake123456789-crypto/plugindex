What Icon Library 2 does

Icon Library 2 puts a huge collection of open source icons and emojis into After Effects. Pick one from the searchable library and it is inserted as a native shape layer you can edit and animate straight away.

Browsing includes colour selection, favourites and recents, and emojis arrived in Version 2. You can drag and drop custom SVGs, import several icons at once in an automatic grid, pick a random icon, or right-click to see an icon's name, tags, repository and licence. A UXP version supports Photoshop, and native SVG processing and gradient support work in After Effects 2026 and newer.

Key features

  • 86,000+ icons and emojis
  • Inserted as editable shape layers
  • Search, colour, favourites and recents
  • SVG drag and drop and grid import
  • Icon info with licence; Photoshop UXP version
