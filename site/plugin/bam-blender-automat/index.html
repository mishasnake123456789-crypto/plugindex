A Blender add-on that batch creates or updates materials from a texture folder, with a built-in Material Manager.

What Bam Blender Automat does

Bam Blender Automat builds materials from folders of textures in Blender in one pass. It can create or update many materials directly, including subfolders, custom suffixes, color spaces, presets and OpenGL or DirectX normals, then manage them through its Material Manager.

Existing texture data-blocks are reused rather than duplicated, with materials identified by their BaseColor texture. Custom presets handle packed maps such as ARM, with per-texture color channel selection. Artists processing large texture libraries or scanned material packs will save a lot of manual node setup.

Key features

  • Batch create or update materials from a folder
  • Subfolders, suffixes, color spaces and normal formats
  • Reuses existing texture data-blocks
  • Presets for packed maps such as ARM
  • Built-in Material Manager
