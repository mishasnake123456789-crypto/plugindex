What Palette_One does

Palette_One is a node preset tool for Blender. Select a group of nodes, register it under a name, and it can be placed from the N-panel in the Shader, Geometry, Compositor and Texture editors.

Placing is interactive. Once you click Place Preset the nodes trail the cursor until a left-click drops them, or right-click or Esc cancels. It saves rebuilding common node setups repeatedly and suits anyone with favorite arrangements of nodes.

Key features

  • Register any node selection as a named preset
  • Works in Shader, Geometry, Compositor and Texture editors
  • Modal placement following the cursor
  • Left-click to confirm, Esc to cancel
  • Access from the N-panel
