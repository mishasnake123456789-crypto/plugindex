What Sublender: Substance does

Sublender: Substance brings .sbsar materials into Blender. Parameters can be edited right in Blender, and materials generated, with no need for the Substance Automation Toolkit.

Changes update live as you tweak, and it has been tested on Windows and Linux. Texture artists can use Substance libraries in Blender without round-tripping through other programs. Drawing on Substance content inside Blender makes it simple to tweak looks quickly without leaving the viewport. It saves repeated trips between applications when iterating on materials.

Key features

  • Edit Substance parameters in Blender
  • Live updates
