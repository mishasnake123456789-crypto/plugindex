Draws dynamic lines between After Effects layers for flowcharts, diagrams and network graphics.

What Easy Connect does

Easy Connect links layers with lines that follow them as they move, which removes a lot of manual path work from diagram animation. It is made by Motion Embassy for After Effects.

Lines can have dashes and arrowheads, and several connection types are on offer. Master controls manage all connections together, while a path tracer provides trace and follow-path options. Typical jobs include flowcharts, process animations, infographics and network visualizations where nodes need to stay attached to one another.

Key features

  • Dynamic line connections between layers
  • Customizable dashes and arrowheads
  • Multiple connection types
  • Master controls for all connections
  • Path tracer with trace and follow-path options
