What Snapshot 6 Tools does

Snapshot 6 Tools from JMS Tools makes preview images of your objects directly in Blender. It generates front, back, left, right, top and bottom orthographic views using the lighting and materials already in your scene.

It can also produce a fake 3D turntable image sequence from a controlled rotation around the object and process multiple objects in a batch. Useful for asset catalogs, sprite sheets and quick presentation images. The feature set spans six orthographic views automatically and fake 3D turntable image sequence.

Key features

  • Six orthographic views automatically
  • Fake 3D turntable image sequence
  • Uses existing scene lighting and materials
  • Batch processing of multiple objects
