Blender add-on for developers to import, edit and save .zip archives and test add-ons in the Text Editor.

What Ziplab Pro does

Ziplab Pro treats zip archives as editable projects inside Blender's Text Editor. Developers can open an archive, change its contents and save it back.

Files and folders are managed without leaving Blender, and add-ons can be tested there too. It can add and edit .toml files, which are used by extensions. A quick tutorial and documentation cover the core functions. It works with Blender 4.2 through 4.5. This keeps packaging and testing of extensions within a single window.

Key features

  • Import, edit and save .zip archives
  • Manage files and folders
  • Test add-ons inside Blender
  • Add and edit .toml files
  • Blender 4.2 to 4.5
