What Uv-Outfit Smartr90 does

Uv-Outfit SmartR90 straightens UV islands in Blender. It orients all selected islands vertically or horizontally.

The longer side of each island's bounding box determines orientation, and a smart method corrects islands that are rotated the wrong way. It supports Blender 2.8 through 2.91, includes documentation and is offered under a royalty-free license. Good for tidying layouts before packing. Consistent island orientation also makes texel density and later packing more predictable across many meshes.

Key features

  • Orients islands vertically or horizontally
  • Uses bounding box size
  • Smart correction of rotated islands
  • Blender 2.8 to 2.91
  • Documentation included
