What Take This does

Take This is a modest script for moving transform data around. It captures a layer's transform values and expressions, keeps them for later, and lets you apply or exchange them between layers.

That helps when you need to swap positions, rebuild a setup on another layer or reuse an expression without copying properties individually. It runs on After Effects CC 2015 through 2020, macOS Catalina support arrived in version 1.0.1, and the developer provides a demo video.

Key features

  • Stores layer transforms and expressions
  • Swaps stored data between layers
  • Supports After Effects CC 2015 to 2020
  • macOS Catalina support from 1.0.1
