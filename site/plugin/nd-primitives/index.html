Blender add-on for non-destructive parametric primitives that stay editable in Edit Mode and Object Mode.

What ND Primitives does

ND Primitives adds parametric shapes to Blender whose parameters remain adjustable. They can be edited in Edit Mode without applying the modifier, and the modifier can be re-enabled later in Object Mode.

Materials and UVs work out of the box, and new objects size themselves to the current viewport view, and origin can sit at the bottom or a corner. Pivot placement, adaptive resolution and gizmos are supported. The set of primitives includes Grid, Cube, UV Sphere, Ico Sphere, Cylinder and more. Modelers get flexible base shapes.

Key features

  • Parametric non-destructive primitives
  • Material and UV support
  • Auto-scaling to viewport
  • Gizmos and adaptive resolution
