Blink BG

Developer: K_Naoki

FreeBlender
Download Free

Blender add-on that flips a camera background image between two opacity values like a blink, with depth and size matching.

What Blink BG does

Blink BG makes comparing a model to its background reference quick. It stores two opacity values, a base and a target, and flips between them at once; a swap button trades their roles.

The blink action has a customizable shortcut, Ctrl + Alt + V by default, and depth can be controlled. The render size can also be matched to the loaded image. Modelers tracing photos or blueprints can check alignment by flashing the reference on and off.

Key features

  • Two opacity values switched instantly
  • Swap button
  • Ctrl + Alt + V default shortcut
  • Depth control and render size matching
