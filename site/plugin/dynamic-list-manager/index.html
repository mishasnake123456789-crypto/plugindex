Blender add-on that groups mesh objects into visual states and switches them with one animatable group number.

What Dynamic List Manager does

Dynamic List Manager organizes meshes into groups where each group represents a state, such as a character version or a set of assets. Activating a group shows its objects and hides everything else.

Visibility can be animated with a single keyframe on the group integer rather than keying each object separately. Animators building outfit swaps, mouth shapes or scene variations get a simple control for many objects.

Key features

  • Groups represent visual states
  • Activating a group hides all others
  • Single keyframe animates visibility
  • Manages mesh object lists
