What Quick Cycle does

Quick Cycle makes repeating motion easy to set up in Blender. Choose how many repeats you want and it duplicates your keyframes into a cycle, handy for walks, runs and other loops.

Another action copies a pose from every left-side bone onto the right-side bones with a single click. The same feature is also found in the Clean Graph add-on, and documentation is included. Character animators blocking out symmetrical poses or cyclic motion will save a lot of manual copying.

Key features

  • Repeats keyframes into cycles
  • Selectable number of repeats
  • Copies left-bone pose to right bones
  • Documentation included
