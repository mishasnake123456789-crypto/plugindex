Five procedural mask node groups for Blender shaders: coverage, damage, edge, ground dirt and leaks.

What Masknode does

Masknode is a set of custom node groups from CGCocktail that generate black-and-white textures procedurally. These masks are used to add wear and variation to materials without painting maps.

After installation a Mask category appears in the shader editor's Add menu, opened with Shift+A. The groups are named Coverage, Damage, Edge, Ground Dirt and Leak. Material artists can blend them into shaders to create realistic grime, scratches and weathering on objects.

Key features

  • Five masks: coverage, damage, edge, ground dirt, leaks
  • Procedural black-and-white output
  • Mask category added to the shader editor's Add menu
  • No hand-painted textures required
