What Panel Cutter - Non Destructive Panel Cuts (Subd Ready) does

Panel Cutter is a Blender plugin that automates panel line cutting on hard surface subjects like vehicles, ships and planes. The cuts stay procedural, so you can change or remove them later without permanently altering the underlying topology.

Lines are driven by vertex groups together with bevel and mask modifiers. For subdivision surface workflows, support loops come from bevel segments set to four or a subdivision checkbox. Running the tool again adds or removes edges from panel lines, and a remove option clears them. A solidify option is also available.

Key features

  • Non-destructive cuts from vertex groups and modifiers
  • Support loops ready for subdivision surfaces
  • Add or remove edges by running the tool again
  • Remove Panel Lines option
  • Optional solidify
