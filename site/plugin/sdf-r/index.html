A Blender add-on for signed distance field modeling with GPU previews and mesh generation via a Rust backend.

What Sdf.R does

SDF.R lets you model with signed distance fields inside Blender's viewport. Shapes combine smoothly, and a custom Rust-GPU backend computes them quickly, giving interactive previews through Blender's GPU module and then producing real mesh geometry.

Two topology engines are available: Marching Cubes, the default for organic, sculpt-like work, and GPU-accelerated Dual Contouring introduced in a later release. It relies on GPU support from dedicated NVIDIA hardware, among others. Concept modelers and sculptors who like blending primitives into organic forms, rather than editing vertices, are the main audience.

Key features

  • Signed distance field modeling in the viewport
  • Rust-GPU backend for fast calculation
  • Real-time GPU previews
  • Marching Cubes and Dual Contouring mesh engines
