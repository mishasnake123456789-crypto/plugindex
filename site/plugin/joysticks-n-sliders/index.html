What Joysticks n Sliders does

Joysticks n Sliders, by Mike Overbeck, is a rigging system built around poses. You define poses and then blend between them with on-screen joysticks and sliders, a technique used widely for character and shape animation in After Effects.

Properties can be bound and unbound individually instead of only whole layers. It can rig shapes and path shapes, warning when vertex counts are inconsistent, and supports joysticks with separated dimensions. It works with After Effects releases from CC through 2026.

Key features

  • Pose-based rigging
  • Joystick and slider control
  • Bind and unbind individual properties
  • Shape and path rigging with vertex count checks
  • Separated-dimension joysticks
