What Modulare Toolset does

Modulare Toolset supports modular environment creation in Blender with mesh operations and a strict UV grid system for trim sheets.

Dynamic Central Split bisects a mesh at the center of its bounding box. Smart Pivot snaps the origin to top, center or bottom, and Quick Instance Array offsets instances by exact dimensions without gaps. The Strict Grid Generator unwraps into grids from 1x1 to 16x16, and Pixel Bleed Fix applies a small automatic scale reduction.

Key features

  • Central split by bounding box center
  • Smart pivot snapping
  • Gapless instance arrays
  • UV grids from 1x1 to 16x16
  • Pixel Bleed Fix
