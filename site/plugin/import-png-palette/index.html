Blender add-on that turns PNG images, including Lospec palettes, into Blender color palettes.

What Import PNG Palette does

Import PNG Palette, by Ruuubick, reads a PNG and creates a color palette from it in Blender. It understands Lospec's horizontal, vertical and grid palette layouts at 1x, 8x and 32x resolution.

Similar colors can be merged automatically with adjustable tolerance, a Max Colors setting limits the count, and transparent pixels and blank regions are skipped. It shows up in Properties, Tool Settings, Palette under the image's file name. It supports Blender 4.2 LTS and newer.

Key features

  • Import any PNG as a palette
  • Lospec horizontal, vertical and grid formats
  • Merging of similar colors with tolerance
  • Max Colors limit
  • Palette named after the image file
