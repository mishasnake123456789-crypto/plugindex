What Blender Distribute & Sort Tool Addon does

This add-on spreads selected objects over a grid, around a circle, along a line, or between the two most distant points, snapping them to the closest positions. Gap spacing accounts for each object's rotation and scale.

Objects can also be ordered by material, name, pass index or scale, or shuffled randomly. It is helpful for lining up product displays, asset sheets and repeated elements. Combining arrangement and ordering in one tool makes it easier to organize large sets of objects cleanly.

Key features

  • Grid, circle, line and extreme-point layouts
  • Gap spacing considers rotation and scale
  • Sort by material, name, pass index or scale
  • Random sorting
