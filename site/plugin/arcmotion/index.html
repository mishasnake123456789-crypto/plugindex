Blender add-on that animates many objects along adjustable arcs toward one or more targets.

What Arcmotion does

ArcMotion moves groups of objects along arc paths to targets in Blender, with live control over how high the arcs rise.

Target rotation can be set on X, Y and Z, random frame offsets stagger the motion, and randomized timing gives variety. Targets can be generated as empties from faces, edges and vertices into a targets collection, group formations keep relative positions, and smart duplication matches objects to targets.

Key features

  • Arc motion to single or multiple targets
  • Live height control
  • Target rotation and random frame offsets
  • Targets from mesh faces, edges and vertices
