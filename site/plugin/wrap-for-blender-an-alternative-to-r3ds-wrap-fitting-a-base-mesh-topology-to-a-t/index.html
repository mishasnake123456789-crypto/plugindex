What Wrap For Blender - An Alternative To R3Ds Wrap - Fitting A Base Mesh (Topology) To A Target does

Wrap for Blender, from TECA 3D, is an add-on for Blender that transfers the shape of a target mesh onto a base mesh with standard topology. It addresses the retopology chore of getting a scan or sculpt onto a production-ready layout, in the spirit of R3DS Wrap.

You place matching point pairs between source and target, then run the wrap and refine it with a fine-tune step. The wrap lines up facial landmarks, including eye corners, tear ducts and the lips, and one universal algorithm avoids the need for templates per model. Character modelers working from scans benefit most.

Key features

  • Projects a base topology onto a target mesh
  • Source-to-target point pairs guide the fit
  • Aligns facial landmarks like eye corners and lip lines
  • Fine-tune step for detailed adjustment
  • One algorithm, no per-model templates
