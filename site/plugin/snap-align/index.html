Brings six scene-tidying tools together in one Blender panel, from alignment and distribution to snapping, materials and renaming.

What Snap Align does

Snap Align gathers six object-organizing tools into a single Blender interface, so arranging and tidying a scene does not require several separate add-ons.

Alignment runs on any of the three axes and offers five reference modes, among them bounding box, 3D cursor, active object and median point. Distribution calculates gaps automatically or accepts custom values, and pattern tools lay objects out in circles, grids or diagonal lines. Surface snapping, material cleanup and batch renaming round things out for layout and set dressing.

Key features

  • Align on X/Y/Z with five reference modes
  • Distribute with automatic or custom gaps
  • Circular, grid and diagonal patterns
  • Surface snapping
  • Material cleanup and batch renaming
