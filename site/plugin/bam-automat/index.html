What [BAM] AutoMat does

[BAM] AutoMat by AlexeyHRDesign builds materials in Blender directly from a folder of textures. It can create new materials in bulk and update existing ones when textures change.

Subfolders and custom texture suffixes are supported, color spaces are set automatically, and presets keep material setups consistent. OpenGL and DirectX normal maps are handled, and a Material Manager helps with scenes holding many objects and materials. Useful for asset libraries and environment production.

Key features

  • Batch material creation from a texture folder
  • Subfolders and custom suffixes
  • Automatic color space handling
  • Preset system for consistent setups
  • OpenGL and DirectX normal maps
