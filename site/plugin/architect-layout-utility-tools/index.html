What Architect Layout Utility Tools does

Architect Layout Utility Tools is a Blender add-on for environment artists and architectural visualization professionals. It collects material management, object organization, transformation operations and asset preparation into one N-Panel under View3D > Architect.

Material Control batch renames and applies materials using Pascal_Snake_Case formatting. Center Control manipulates origins precisely, and Transform Control batch scales and rotates objects. Having these chores in a single panel suits teams preparing large scene layouts and assets.

Key features

  • Batch material renaming in Pascal_Snake_Case
  • Center Control for origin manipulation
  • Batch scale, rotation and transforms
  • Single N-panel under View3D > Architect
