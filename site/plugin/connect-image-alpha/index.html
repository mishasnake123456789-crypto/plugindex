What Connect image alpha does

Connect image alpha is a Blender add-on by Snakyboopface that plugs the alpha output of image textures into the Principled BSDF node on each active material of a chosen collection. That removes the repetitive node wiring needed when importing many textured assets.

It prefers image nodes with labels such as alpha, base color or color, and the matching is not case sensitive. Since version 1.0.6 you can choose which labels take priority. The add-on also prioritizes the Principled BSDF node itself, rather than simply connecting to whichever image node it finds.

Key features

  • Connects image alpha to Principled BSDF
  • Works on all active materials in a collection
  • Prioritizes labels like alpha and base color
  • Case-insensitive matching
  • Selectable label priority since 1.0.6
