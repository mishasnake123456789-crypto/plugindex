3ds Max script that adds assignable actions to cycle snap modes and to open the Snaps dialog.

What Snap Tools does

Snap Tools by Jon Seagull places two useful actions into the Customize menu of 3ds Max. One cycles through snap modes, skipping 2D by default, a behavior that can be adjusted. The other opens the Snaps dialog directly.

Because both are exposed as actions, they can be bound to keyboard shortcuts or added to a quad menu, so changing snap settings no longer requires hunting through toolbars or dialogs. Modelers who switch snap types frequently while placing and aligning objects will find the shortcuts a small but steady time saver.

Key features

  • Cycle snap mode action
  • 2D skipped by default and adjustable
  • Open Snaps dialog action
  • Bindable to keys or quad menus
