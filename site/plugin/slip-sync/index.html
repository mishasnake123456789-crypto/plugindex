What Slip Sync does

Slip Sync, by Leyero, solves a common timeline annoyance: when you offset footage, keyframes normally travel with it or fall out of sync. This plugin shifts the media but keeps the keyframes fixed in place.

It is free, the first release was 1.0.0 in October 2024, and it supports Premiere Pro 2021 through 2026. A demo video is available. It helps when adjusting which part of a clip plays without disrupting animation already built around it.
