What Frame By Plane does

Frame By Plane is a free add-on from Alessandro-Pannoli. The available notes describe its availability more than its functions, so the description is limited to what is confirmed: it is a Blender extension for version 5.1.2 and newer.

Native builds cover Windows on x64 and Arm, macOS on Intel and Apple Silicon, and Linux on x64. It installs by dropping onto a Blender window, or from disk via the extension preferences, and it is distributed under the GNU GPL version 3 or later.

Key features

  • Builds for Windows, macOS and Linux
  • Requires Blender 5.1.2 or newer
  • Drag-and-drop or from-disk install
  • GPL v3 or later license
