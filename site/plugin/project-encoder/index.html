What Project Encoder does

Project Encoder, by 884tak, creates a converted copy of a project. It turns Motion Crop into the traditional Crop effect and changes audio Custom Fade into Default Transition.

Version 1.2.0 added the ability to downgrade a project from 2026 to 2023 or earlier. It supports Premiere Pro 14.4 and later, useful when sharing with colleagues on older versions. The conversions run on a copy, so the original project stays untouched.

Key features

  • Motion Crop to Crop effect
  • Custom Fade to Default Transition
  • Downgrade projects from 2026 to 2023 or earlier
  • Premiere Pro 14.4 and later
