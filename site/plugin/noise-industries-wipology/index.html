What Noise Industries Wipology does

Wipology provides a set of wipe transitions for After Effects, Premiere Pro and DaVinci Resolve, plus Final Cut Pro X and Motion. Each pairs a basic wipe with an effect, from the familiar to the unusual.

Styles run through Comicbook, Defocus, Edges, Film Effect, Glow, Halftone, Kaleidoscope, Pixelate, Spot Light and Star. Over 100 presets are included, parameters can auto-animate so no keyframes are needed, and Object and Title wipes link a graphic to the transition. Built-in motion blur works at any frame rate, Metal GPU acceleration shortens renders, and wide-gamut colour is preserved in Final Cut Pro X. Editors get distinctive scene changes quickly.
