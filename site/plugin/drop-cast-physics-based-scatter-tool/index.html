Blender add-on that fills scenes by dropping collections of objects with physics-based scattering.

What Drop Cast - Physics-Based Scatter Tool does

Drop Cast populates a Blender scene by letting objects fall into place with physics. Choose an asset collection, set the drop area, and scatter the contents in a few clicks.

Each asset can be given its own spawn probability, and sizes can be randomized for natural variation. Because it relies on physics, heavy scenes may demand more system performance. A bonus pack of trash assets is included, along with documentation. It suits environment building and adding clutter to concept art.

Key features

  • Scatter whole collections with physics
  • Per-asset spawn probability
  • Randomized sizes
  • Adjustable drop area
  • Bonus trash asset pack
