What Photomesh does

Egret Studios' PhotoMesh turns flat pictures into mesh outlines in Blender with a single button; the interface is built around one big button.

It aims at artists and designers wanting quick visualization, rapid prototyping and unique elements for concept art, and supports Blender 3.0 through 4.4. Logos, silhouettes and sketches become geometry with very little effort. Because the result is a real mesh, it can be extruded, shaded and animated like any other object, and the interface keeps the process to a single action.

Key features

  • One-click image to mesh trace
  • Simple large-button interface
  • Suited to concept art and prototyping
  • Blender 3.0 to 4.4
  • Detailed mesh outlines
