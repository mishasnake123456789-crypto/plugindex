What Eevee Dynamic Lighting does

Eevee Dynamic Lighting is a Blender plugin for animations that need updating indirect light. It auto-bakes indirect lighting on each frame while writing out an image sequence, so you do not need to bake manually.

Renders can be aborted with ESC, and Blender's step frames are supported. It improves lighting in moving scenes rendered in Eevee. This helps animated scenes keep convincing bounced light in Eevee, particularly when objects or lights move during the shot.

Key features

  • Auto-bakes indirect light each frame
  • Outputs an image sequence
  • ESC to abort renders
  • Supports step frames
