What Rigimap does

Rigimap from Picto Filmo maps motion capture onto Rigify rigs in Blender. Pick a mocap format, select and connect, then edit and bake the motion into a regular Rigify action.

Supported sources include Mixamo, Actorcore, Rokoko, iPisoft, Mocaponline, Perception Neuron, Xsens, DeepMotion, Radical, Sony Mocopi, Quick Magic and Rigify's own Meta Rig. A two-button workflow keeps things simple for animators reusing mocap data. Retargeting through Rigify allows animators to edit mocap using the same controls they use for hand-keyed animation.

Key features

  • Many mocap formats supported
  • Two-button workflow
  • Bakes to standard Rigify action
  • Works with Mixamo, Rokoko, Xsens and more
