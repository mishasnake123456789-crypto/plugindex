What Infinite Kicks - Pitch Perfect Procedural Soccer Balls does

Infinite Kicks is a procedural generator for soccer balls in Blender. It uses nodes behind a simple interface to create balls in different patterns and from different soccer eras.

Balls come UV-ready with suitable geometry so they can be unwrapped instantly, and the topology can be optimized for production. An option generates a rig for each ball. Sports game developers and visualization artists can produce varied balls quickly. Among its tools are node-based procedural generation and patterns from different soccer eras.

Key features

  • Node-based procedural generation
  • Patterns from different soccer eras
  • UV-ready geometry
  • Optional rig for each ball
