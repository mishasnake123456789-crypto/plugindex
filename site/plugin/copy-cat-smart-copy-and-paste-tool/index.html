What Copy Cat - Smart Copy & Paste Tool does

Copy Cat is a Blender add-on that speeds up moving settings from one object to another. A checkbox panel lets you decide exactly what to carry across, so you can paste only what is needed without touching the rest.

It can transfer location, rotation and scale, modifiers such as Mirror, Array and Subdivision, and materials and UV maps, using a Data Transfer step so objects with different topology still work. Extra helpers set an object's origin to its geometry or the world center, and Make Center and Make Ground snap items to the grid. Undo and redo buttons sit in the panel for quick corrections.

Key features

  • Copy and paste location, rotation and scale
  • Transfer modifiers like Mirror, Array and Subdivision
  • Materials and UV maps via smart Data Transfer
  • Auto Origin plus Make Center and Make Ground
  • Undo and redo buttons in the panel
