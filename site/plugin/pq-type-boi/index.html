What PQ Type Boi does

PQ Type Boi offers a gallery of ready-made animated typography layouts for After Effects. Browse the animated thumbnails in the panel and click one to build its composition.

Each comp has a control layer for changing color, line width and animation delay, so you don't need to dig through layers. Expressions are universalized to support non-English languages. It works with After Effects CS6 through 2026, useful for quick kinetic text.

Key features

  • 120+ pre-animated type arrangements
  • Animated thumbnail browser panel
  • One-click comp generation
  • Control layer for color, line width and delay
  • Non-English language support
