What Output Setup Helper does

Output Setup Helper automates the compositing output stage of a Blender project. A single click assembles a complete node tree from nothing, including Render Layers, File Output nodes and links for every enabled pass.

Output is split between beauty and utility multi-layer EXR files, and paths, filenames and versions are configured for you. It keeps the setup updated as passes change, saving production artists from wiring outputs manually.

Key features

  • One-click compositor setup
  • Builds from enabled Render Layer passes
  • Beauty and utility multi-layer EXR split
  • Configures paths, filenames and versions
