What Camcontrol - Camera Setup & Framing Tools does

CamControl is a Blender add-on for fast camera setup. Setup Camera creates a camera if none exists and places it around the selected object.

Track creates a target and makes the camera follow it, Turntable adds a 360-degree or custom rotation animation, and a simple shake adds handheld movement. These actions avoid manual constraint setup and are suited to product shots, model showcases and quick previews. Among its tools are setup Camera around the selected object and track To target creation.

Key features

  • Setup Camera around the selected object
  • Track To target creation
  • 360-degree or custom turntable
  • Simple camera shake
