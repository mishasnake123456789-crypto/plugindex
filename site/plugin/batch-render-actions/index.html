Blender add-on that renders every animation action in a file into its own named folder.

What Batch Render Actions does

Batch Render Actions saves effort when a character has many animations. It renders each action in the current Blender file as a separate animation, placing the frames in a subfolder named after the action.

Filename templates and the output directory are configurable, and since version 1.0.2 a single action can be rendered on its own. The panel is in the Render Actions tab of the 3D Viewport sidebar. It fits game workflows with idle, run and walk cycles.

Key features

  • Renders all actions as separate animations
  • Subfolder named for each action
  • Customizable filename template
  • Single action rendering
  • Sidebar Render Actions tab
