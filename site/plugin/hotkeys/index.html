What Hotkeys does

CG Toon Studio's Hotkeys organizes keyboard shortcuts for every Blender workspace. Version 2.0 works with Blender 4.0.x up to 4.3 and has documentation.

A Sample Color shortcut on Ctrl + X on S is included for Blender 4.3. A demo and tutorial video are available, updates are free for life, and the MIT license applies. Beginners and veterans who want a tidier, faster keyboard-centered workflow can adopt it. Consistent shortcuts across workspaces reduce the pause of remembering which editor uses which key.
