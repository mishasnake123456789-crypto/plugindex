What Easy Gobo Lights 💡 does

Easy Gobo Lights is a Blender plugin for light patterns. It can generate a new gobo light tailored to the scene in a few clicks, or apply a gobo texture to an existing light.

Textures are applied by drag and drop without node setups. The library has 118 patterns, including natural effects such as foliage shadows and abstract designs, and updates are shown in real time. Good for atmospheric lighting.

Key features

  • Generate new gobo lights in clicks
  • Drag-and-drop texture application
  • 118 built-in textures
  • Real-time preview
