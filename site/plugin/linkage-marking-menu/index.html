Blender add-on that adds customizable marking menus for activating tools in the viewport in Object and Edit modes.

What Linkage Marking Menu does

Linkage Marking Menu brings quick radial-style menus to the Blender viewport so tools can be triggered without hunting through panels. Menus exist for both Object and Edit mode and can hold built-in tools or your own operators.

Three menus are provided, two for Object Mode and one for Edit Mode, opened with hotkey combinations built around Shift, Ctrl and the left mouse button. Everything is customizable, so each artist can arrange the menus around their habits.

Key features

  • Quick-access marking menus in the viewport
  • Separate menus for two Object Mode sets and Edit Mode
  • Preset tools or custom operators
  • Shift + Ctrl + left mouse hotkeys
  • Fully customizable
