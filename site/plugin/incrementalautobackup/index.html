Backs up Blender projects automatically at set intervals into a chosen folder, keeping a limited number of copies.

What Incrementalautobackup does

IncrementalAutoBackup saves copies of your project without manual effort. You set the interval in seconds and a folder for the backups.

You also choose how many backup files to retain, and the oldest is deleted once the limit is reached. It guards against crashes and bad edits while keeping disk usage in check. It fits long modeling sessions, where saving versions at regular intervals protects against lost work. Keeping a rolling set of copies in one place makes it simple to recover from a crash or an edit you regret.

Key features

  • Automatic incremental backups
  • Interval set in seconds
  • Designated backup folder
  • Retention limit deletes the oldest
