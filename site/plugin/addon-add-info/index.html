Blender add-on that overlays names, poly counts, materials, transforms and UV data for selected objects in the viewport.

What [Addon] Add Info does

Aleksandr Podoprigora's add-on shows object details right in the Blender viewport, so extra tabs stay closed. Readouts include names, triangle and n-gon totals, materials, transforms, texture info, vertex data and UV metrics.

Information appears for every selected object, along with collection names, and n-gon counts above zero are colored differently. Several materials stack in a column. Modelers checking topology and asset readiness get a quick audit. Seeing this data beside the model avoids repeated trips to the statistics overlay and spreadsheets.

Key features

  • Info for all selected objects in the viewport
  • Tris and n-gon counts with highlights
  • Material and collection names
  • Transform values
  • UV and vertex data
