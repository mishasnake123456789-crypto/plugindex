What Anti-Seam does

Anti-Seam fixes visible seams in image textures in Blender with a single click. By Thatimster, it works on any UV size and is deterministic, meaning it uses no procedural randomness.

It uses triple layered blend masks, offers a debug mode with simple controls, supports Super Texture and Anti-Tile through Texture-Tools, and handles video textures for dynamic maps. The result is ready to bake. Environment and texture artists tiling materials across large surfaces get cleaner transitions.

Key features

  • One-click seam removal
  • Deterministic, no procedural textures
  • Triple layered blend masks
  • Works with any UV size
  • Video texture support
