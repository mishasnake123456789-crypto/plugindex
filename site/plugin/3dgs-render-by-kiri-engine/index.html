What 3Dgs Render By Kiri Engine does

3DGS Render from KIRI Engine brings Gaussian Splatting scans into Blender, where they can be rendered, edited and animated like other scene content. It works with both the Cycles and Eevee render engines.

Version 5.0 introduced experimental rigging and light baking, and the developer provides a separate demo file along with video tutorials for trying those features. It is recognised as a Blender Extension, comes with documentation, and is released under the GPL license. Anyone working with photogrammetry-style captures of real places or objects can use it to bring those scans into a normal Blender workflow.

Key features

  • Render Gaussian Splatting scans inside Blender
  • Edit and animate splat data
  • Works with Cycles and Eevee
  • Experimental rigging and light baking since 5.0
  • Demo file and tutorials provided
