What Super Easy Render does

Super Easy Render collects Blender's scattered output and render options into a single section. It is meant for users who find the default interface sprawling.

From one place you set file type, output location, resolution and aspect ratio, toggle metadata, motion blur and depth of field, and control shadows, volumetrics and samples. It can also change a scene's speed and framerate without the animation problems of editing the default framerate. Two script versions exist: one adds the panel to the existing UI, the other hides the default render UI, for Blender 3.0+.

Key features

  • Single panel for render and output settings
  • Toggles for metadata, motion blur and DOF
  • Framerate and speed change without breaking animation
  • Choice of add-on or replace-default scripts
