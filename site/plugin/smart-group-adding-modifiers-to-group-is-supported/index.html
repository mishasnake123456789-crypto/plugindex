What Smart Group - Adding Modifiers To Group Is Supported does

Smart Group is a Blender add-on for treating several objects as one managed unit. It helps with scenes where many pieces need shared treatment but should stay separate underneath.

Groups can receive any modifiers, including geometry nodes, and carry a material override, with a Fix Group operator for shading issues when objects lack UV maps. A Ctrl+G pie menu and the N panel handle creating, dissolving, duplicating and applying groups. An edit mode adds or removes members, offers display options and a customizable bounding box, and linked duplicates share mesh data.

Key features

  • Group objects and apply modifiers, including geometry nodes
  • Group-wide material override
  • Pie menu and N panel controls
  • Edit mode with custom bounding box and display options
