Renders transparent orthographic images from many model files in one run, covering six directions per model.

What Orthobatch - Bulk Render Models does

OrthoBatch searches a folder you choose for FBX, OBJ, GLB and glTF models and renders each one without manual setup. It can also use meshes already in the open .blend file.

Every model is rendered orthographically from six directions (-X, +X, -Y, +Y, -Z, +Z), producing transparent images. Models can come from any directory in any number. It is suited to making reference sheets, sprite sources and catalogue images of asset collections.

Key features

  • Scans folders for FBX, OBJ, GLB and glTF
  • Six orthographic directions at once
  • Transparent image output
  • Imports from any directory or uses open scene
  • One-button batch operation
