Scale Move Tool

Developer: Gravey

Free3ds Max

3ds Max script that repositions a group of objects with the scale tool while leaving each object's own scale untouched.

What Scale Move Tool does

Scale Move Tool lets you move many objects together using the regular scale tool in 3ds Max, much like scaling vertices in sub-object mode, but without changing the scale of the objects themselves. Distances between them stay proportional.

Internally it creates a point per object, instances the objects' position and rotation controllers onto those points, then removes them when done. A Skewing Mode takes two master points so all others shift in proportion to where they began. Filters deal with hierarchies and groups, and a Quick Align section lines selected objects up along X, Y or Z. It works with 3ds Max 8 or higher.

Key features

  • Moves object groups with the scale tool without changing object scale
  • Temporary points with instanced position and rotation controllers
  • Skewing Mode driven by two master points
  • Filtering for hierarchies and groups
  • Quick Align along X, Y or Z
