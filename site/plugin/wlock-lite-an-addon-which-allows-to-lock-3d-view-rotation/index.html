What Wlock Lite - An Addon Which Allows To Lock 3D View Rotation does

WLock Lite prevents accidental viewport rotation. Press Alt+W, the default hotkey, and the current 3D view stops rotating until you unlock it again.

Every 3D view can be locked or unlocked independently, and the lock works from any user camera view, not just orthographic ones. An on-screen lock icon shows the state and can be configured or disabled in Preferences. The lock only affects the 3D view. It is useful when drawing, sculpting or tracing over a fixed angle. Documentation is included.

Key features

  • Alt+W lock toggle
  • Independent lock per 3D view
  • Works in any camera view
  • Optional on-screen lock icon
