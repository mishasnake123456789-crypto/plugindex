What 1-Click Multi Shot (Batch Render Addon) does

1-Click Multi Shot prepares a Blender file for batch rendering several camera angles. It scans collections for camera objects, treating any camera with render enabled in the outliner as a shot, or searches a single collection if you prefer.

It sets the end frame from the number of cameras found, reports how many were detected so you can verify, adds timeline markers and associates each camera with a marker. Rendering then runs through the shots in order. Archviz and product artists who deliver multiple views of a scene will skip repetitive setup.

Key features

  • Scans collections for render-enabled cameras
  • Optional single-collection search
  • Sets end frame by camera count
  • Adds markers bound to each camera
