What Flare V1.1 The Lighting Add-On does

Flare simplifies HDRI lighting in Blender. With three simple controls you import your favorite HDRIs and keep them handy.

Imported HDRIs are saved through a startup file, so they are ready in every new project, and version 1.1 added categories for organizing them. Documentation is included and the add-on is offered under a royalty-free license. It is a quick way to switch environment lighting while testing a look. Highlights include three-control interface, HDRI import and saved via startup file for new projects.

Key features

  • Three-control interface
  • HDRI import
  • Saved via startup file for new projects
  • Categories for organization
