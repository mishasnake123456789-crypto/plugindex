Blender add-on that sets up layered compositor rendering and writes each layer's passes to its own folder.

What Ez Render Pass does

Ez Render Pass automates per-layer batch rendering through Blender's compositor. It prepares the project, creates the node tree and sends each layer to an organized output location.

A Quick Setup button creates FX, Characters and Background collections, configures view layers and builds the compositor network in a single click. Essential passes include Color, Alpha, Depth, Normal, Mist, Position and Vector. Each layer gets its own pass group, and File Output nodes are configured to match your render settings.

Key features

  • Quick Setup builds collections, view layers and compositor nodes
  • Color, Alpha, Depth, Normal, Mist, Position and Vector passes
  • Pass groups for each layer
  • File Output nodes set from render settings
  • Per-layer folders for organized output
