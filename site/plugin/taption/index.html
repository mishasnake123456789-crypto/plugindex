A UXP plugin for transcribing, translating and creating multilingual subtitles in Premiere Pro through Taption.

What Taption does

Taption lets editors generate transcripts, translations and subtitles from the Premiere Pro workflow, using Taption's web platform. Dictionaries, speaker handling and subtitle formatting can be customized there.

Edits made in the browser sync back without manually saving, fixing timestamps or reimporting from scratch. Sign in with a Taption account to access professional localization features. Suited to creators and enterprise teams producing multilingual video. The cloud editor and the Premiere panel work together, which supports professional localization workflows.

Key features

  • Transcription and subtitle generation
  • Translation for multilingual subtitles
  • Web editor with custom dictionaries
  • Sync edited subtitles back to Premiere
  • Account sign-in and localization features
