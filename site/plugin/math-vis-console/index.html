What Math Vis (Console) does

Math Vis (Console) shows mathutils variables from the console right in Blender's 3D view. The original add-on was written by Campbell Barton and shipped with Blender up to 4.1.

It now ships as an extension with limited support, and sits under Properties, Scene, Math Vis Console. Scripters and educators visualizing vectors, matrices and quaternions can understand their data spatially. Seeing values in space makes it easier to debug transformations and understand how vectors, matrices and quaternions behave while experimenting with code.

Key features

  • Displays mathutils variables in 3D
  • Originally by Campbell Barton
  • Properties > Scene > Math Vis Console
  • Offered as an extension
