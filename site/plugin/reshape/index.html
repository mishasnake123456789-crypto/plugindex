A Blender add-on that changes segments and rings of existing cylinders and spheres, with a backup option.

What Reshape does

Reshape lets you change a primitive's parameters in Blender after you have created it. Cylinders and spheres can have their segments and rings adjusted later, which normally requires deleting and recreating the shape.

A backup option stores the original mesh so you can return to it. The add-on can appear in either the Edit or Tools panel, and it generates a new mesh using the original's local axis information. It supports Blender 4.2, 4.1, 4.0 and 3.x. Modelers who block out forms and then refine resolution will find it convenient.

Key features

  • Adjust segments and rings after creation
  • Backup restores the original mesh
  • Show in Edit or Tools panel
  • Uses the original's local axis
  • Blender 3.x to 4.2
