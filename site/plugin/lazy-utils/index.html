A Blender add-on that smooths edge loops, pose bones and armatures by fitting them to a virtual curve.

What Lazy Utils does

Lazy Utils smooths edge loops in Blender by shaping them along a curve. The edges are corrected to follow the curve, which is created virtually so it does not clutter your data, and its control points can be adjusted while the operation runs.

It works with mesh edges, geometry, pose bones and armature editing. Geometry Mode targets the whole selected geometry when selection mode is set to Face, placing a curve at the core of the shape. Modelers cleaning up edge flow and riggers aligning bone chains will find it provides a controlled alternative to manual adjustment.

Key features

  • Smooths edge loops with curves
  • Virtual curve with adjustable control points
  • Works with mesh, pose bones and armatures
  • Geometry Mode for whole selections
