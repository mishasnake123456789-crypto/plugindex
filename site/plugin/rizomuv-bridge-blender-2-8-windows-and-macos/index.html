What Rizomuv Bridge - Blender 2.8+ (Windows & Macos) does

RizomUV Bridge connects Blender with the RizomUV unwrapping program. Through a button-driven interface, objects and UV maps move between the two applications in both directions.

Original objects stay untouched; only UV data returns to Blender. Multiple UV sets are supported, and FBX, OBJ and USD formats work, with USD preserving Rizom attributes such as pins and groups. Preferences let you exclude linked instances from export. UV artists who prefer RizomUV's tools get a smooth round trip.

Key features

  • Two-way object and UV transfer
  • Original objects left untouched
  • Multiple UV sets
  • FBX, OBJ and USD support
