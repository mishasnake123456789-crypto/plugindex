What Truevault does

Truevault places an asset library inside Blender so you can browse 3D objects, materials and heightmaps without leaving the application. Items can be searched, filtered and previewed.

Purchases use credits, either for individual assets or bundles with discounts, and there is no subscription. Assets import and place in one click and receive automatic updates. Artists building scenes quickly can pull in production-ready content. Because everything is searchable from inside the interface, picking up a prop, a material or a displacement source during a project does not interrupt the creative flow.

Key features

  • Browse, search, filter and preview in Blender
  • Credit-based purchases, no subscription
  • Bundle discounts
  • One-click import and placement
  • Automatic updates
