What Light Director 2.0 - Procedural Lighting System does

Max Miles' Light Director 2.0 remembers the state of every light and HDRI setup in a Blender scene and brings any back with a single click, without destroying anything.

Visibility, names and transforms of lights are held internally, so a single blend file can contain any number of rigs. Synced World Nodes recreate the saved World Node Tree, keeping HDRI and Sky values consistent with your lamps, and a gallery view helps browse setups. Lookdev and product artists compare lighting ideas quickly.

Key features

  • Save and restore light and HDRI setups
  • Unlimited rigs in one file
  • Stores visibility, names and transforms
  • Synced World Nodes
  • Gallery view
