What Greezybears Gb_Scifitech Kpack does

Greezybears Gb_Scifitech Kpack provides 25 detailed sci-fi models for Blender, built as inserts for the KIT OPS add-on. They are untextured, which leaves texturing choices to you, and each piece is separated to make that easier.

A folder of reference renders shows the kit without textures or decals. Documentation is included and the pack uses a royalty-free license. It suits hard-surface artists who use KIT OPS.
