Sverchok node group for Blender that constructs spider webs with contour, spiral, radial and anchor-point controls.

What Sverchok Spider Web Generator does

vkter's Spider Web Generator is a node group asset that creates web structures through Sverchok in Blender, producing vertices, edges and weights.

Settings cover the outer contour, including polygon count, random offsets, seed, bump strength and accuracy, plus an anchor range with radius, precision and offset strength. The spiral (screw) and radial thread structures are adjusted independently. Environment artists and procedural modelers can make varied webs for horror or nature scenes.

Key features

  • Contour controls with random seed
  • Sticking points with radius and precision
  • Spiral and radial ray structure
  • Outputs vertices, edges and weight
  • Sverchok node group
