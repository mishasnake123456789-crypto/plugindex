Blender add-on that posts render status messages to a Discord or Slack webhook when jobs are created, finish or fail.

What Render Webhook does

Render Webhook sends notifications from Blender to a chat service so you do not have to watch a long render. After render events it posts a status message to a webhook, using either Discord or Slack message formats.

The endpoint address and webhook type are entered in the add-on preferences, and a test button confirms the connection works. Messages fire when a render job is created or completes, along with other render events, making it useful for artists who leave machines rendering overnight or manage a remote farm.

Key features

  • Discord and Slack webhook formats
  • Endpoint and type set in add-on preferences
  • Test button to verify the connection
  • Notifications on render job creation and completion
