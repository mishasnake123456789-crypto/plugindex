What Forts Map Importer does

Forts Map Importer adds an import entry in Blender for loading Forts Maps (.fwe) from the Steam game Forts. It is developed by Gonnetz.

It imports mesh data, supports Blender 4.2 LTS and newer, needs no special permissions and remains under development. Modders and fans can bring maps into Blender for editing or rendering. This is a specialized tool for players and modders of that game who want to inspect or reuse its map data in a 3D application.

Key features

  • Imports Forts .fwe maps
  • Added to the import menu
  • Supports Blender 4.2 LTS and newer
  • No special permissions
