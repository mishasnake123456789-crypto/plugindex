What Rg Cad Tools does

RG CAD Tools brings command-based drafting and editing to Blender. It lets you draw and refine linework in a manner familiar from CAD software.

Line draws single edges while Polyline draws connected segments as one object. Snapping covers endpoints, midpoints, intersections and nearest points, with per-type toggles and a global F3 switch. Basepoint tools copy, move and rotate objects, and modify tools include explode, break, fillet, trim and extend. People used to drafting commands from CAD software can work in a familiar way for plans and technical layouts.

Key features

  • Line and Polyline drawing
  • Endpoint, midpoint, intersection and nearest snaps
  • Basepoint copy, move and rotate
  • Fillet, trim, extend, explode and break
  • F3 global snap toggle
