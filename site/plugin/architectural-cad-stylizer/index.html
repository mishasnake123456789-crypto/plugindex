What Architectural Cad Stylizer does

Architectural CAD Stylizer from active clay restyles the Blender viewport so a model reads like a technical drawing, without building materials or choosing a render engine. Seven presets are included: Classic Clay, AutoCAD Blueprint, Technical Draft, Dark Mode, Najdi Adobe, Desert Sandstone and Terminal Green.

Switching presets is live, cavity depth controls how strongly edges show up, and a colour override covers cases the presets do not. A capture button hides the interface and writes the frame to your output folder. It is useful for architects who need quick presentation frames, and it supports Blender 4.2 through 5.2.

Key features

  • Seven hand-tuned viewport presets
  • Live switching between presets
  • Adjustable cavity depth for edge definition
  • Colour override
  • Capture button that saves a clean frame
