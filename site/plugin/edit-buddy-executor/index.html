What Edit Buddy Executor does

Edit Buddy Executor is a free Premiere Pro extension that acts on edit instructions saved as JSON files. It finds the files written by a companion UXP plugin and applies them to the active sequence, trimming and reordering clips accordingly.

Because of current UXP limitations it only works in the Premiere Pro Beta, and it is released as an early alpha build. It suits editors who want to experiment with an automated, file-driven editing workflow and are comfortable testing pre-release software. Premiere Pro 12.0 or later is listed as the compatible range.

Key features

  • Finds JSON files created by the companion UXP plugin
  • Edits and reorders clips within a sequence
  • Runs only on the Premiere Pro Beta
  • Alpha build, free on Adobe Exchange
