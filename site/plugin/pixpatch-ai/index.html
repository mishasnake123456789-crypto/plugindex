3ds Max script that uses Google Gemini to edit and fix finished renders from the frame buffer by masking an area and describing the change.

What PixPatch AI does

PixPatch AI links 3ds Max with Google's Gemini so finished renders can be changed without rendering again. It captures directly from the Corona VFB, the V-Ray Frame Buffer or the native Render Window; you mask an area, describe the change, and the AI handles the edit.

Difference-aware blending widens the blend when an added object goes beyond the mask, and an interactive eraser brush refines masks and results. Smart prompting reads scene context for photorealistic output, and patches match the render's resolution and position. It uses your own Gemini API key, stored locally. Version 2.1 added Inspiration Lab for lighting and weather variants, Motion Lab for image to animation, and Style Transfer.

Key features

  • Captures from Corona VFB, V-Ray frame buffer or Max Render Window
  • Mask an area and describe a change
  • Difference-aware blending and eraser brush
  • Bring your own Gemini API key, stored locally
  • Inspiration Lab, Motion Lab and Style Transfer in v2.1
