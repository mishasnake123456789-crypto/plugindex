Blender add-on that automates multi-layer EXR pass setup and compositor networks for Cycles across several view layers.

What AutoAOV does

AutoAOV handles the tedious configuration of render passes in complex Blender scenes. Each view layer has its own collapsible tab so its AOV setup can be managed independently.

Global one-click Rebuild Templates cover light ray passes and other categories, creating the compositor node networks and multi-layer EXR outputs that downstream compositing needs. VFX and lookdev artists rendering with Cycles save considerable manual node wiring.

Key features

  • Per-view-layer collapsible AOV setup
  • One-click Rebuild Templates
  • Automatic compositor node networks
  • Multi-layer EXR output
  • Built for Cycles
