What Individual Camera Properties does

Individual Camera Properties is a Blender add-on by Alexander-Bicukow that keeps separate Scene, Render and Resolution settings on every camera. When you switch the active camera, its stored parameters are applied to the scene automatically.

Changes to render settings are saved into the active camera's properties. You can register properties by marking them in the UI, adding them to a list or building a custom property path, and an optional debounce is available. Useful for projects with several shots that need different resolutions or render settings.

Key features

  • Per-camera Scene, Render and Resolution properties
  • Auto-saves render setting changes to the active camera
  • Reapplies settings on camera switch
  • Register properties from the UI or custom paths
  • Optional debounce
