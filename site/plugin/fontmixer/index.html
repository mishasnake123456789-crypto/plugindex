What FontMixer does

FontMixer, from GothLab, combines many fonts into a single file so they can be previewed and used in Adobe apps with ease. You drop in TTF, OTF, WOFF or WOFF2 files, name the result, then build, save and install an fmx_ file.

The Text tab lists installed fmx_ fonts with live preview, and you can create a text layer with the selected font or inject an expression into an existing one. A layer effects slider switches typefaces. Selecting a text layer and clicking a font applies it. In Photoshop, the Create Text Layer functions build text in the basic workspace and do not work with Artboards.

Key features

  • Merge up to 100 fonts into one file
  • Supports TTF, OTF, WOFF and WOFF2
  • Live preview of styles
  • Slider to switch typefaces on a layer
  • Works across several Adobe apps
