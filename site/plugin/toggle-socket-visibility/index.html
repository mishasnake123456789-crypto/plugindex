What Toggle Socket Visibility does

Toggle Socket Visibility is a Blender add-on by quackarooni that lets you decide which sockets on a node are shown. Either a foldable section of the N-Panel sidebar or a hotkey pop-up lists the inputs and outputs of the active node.

A checkbox icon switches each socket between hidden and visible. A chain icon flags sockets with links, which cannot be edited, and a lock icon flags read-only ones (reroutes at the moment). The column orientation is configurable, including an automatic setting, which keeps cluttered node trees easier to read.

Key features

  • Sidebar panel listing the active node's sockets
  • Hotkey-triggered pop-up panel
  • Checkbox toggles socket visibility
  • Icons for linked and read-only sockets
  • Configurable column orientation
