What Stop-Mo does

Stop-Mo is a free plugin from SouthernShotty LLC that gives smooth animation a stop-motion feel. One click converts existing motion into stepped poses.

Frame rates and ranges are adjustable, a real-time preview shows the result, and textures can be rotated and animated with a click. The effect can be removed again through the add-on. Great for claymation-inspired looks. Because it works on animation you already have, it offers a quick way to experiment with the stepped, handmade look.

Key features

  • One-click stop-motion conversion
  • Adjustable frame rates and ranges
  • Real-time preview
  • One-click texture animation
