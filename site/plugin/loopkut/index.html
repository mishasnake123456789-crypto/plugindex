What Loopkut does

Loopkut is a Blender add-on by KewlSheet that rethinks loop cutting in Edit Mode. The loop preview follows your mouse position along the edge instead of jumping to the midpoint, so you see exactly where the cut lands before you commit.

Snapping works against divisions, fixed distances, vertices and increments. You can insert several loops with offset and mirroring, apply edge-flow smoothing with Set Flow mode, or switch to bisect for planar cuts through the mesh. Keymaps and preview colors are fully customizable, all inside one modal tool.

Key features

  • Live loop preview at the cursor position
  • Snapping to divisions, distances, vertices and increments
  • Insert several loops at once, with offset and mirror options
  • Set Flow mode smooths edge flow
  • Bisect mode for planar cuts
