What Auto Image Importer does

Auto Image Importer turns the clipboard into a source for Blender images. Copy a picture from a web page, a screenshot, a file or another application, and it is imported without saving or browsing first.

Browser image data in formats such as .jfif, .webp and .jpg is converted to PNG on import. Screenshots from built-in OS tools or third-party apps are accepted. It is useful for moving references and textures into a scene quickly.

Key features

  • Imports images copied from web pages
  • Screenshot import from clipboard
  • Converts browser formats to PNG
  • Imports from files and other apps
  • No manual saving step
