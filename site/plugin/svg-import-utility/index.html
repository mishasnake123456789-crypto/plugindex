What Svg Import Utility does

SVG Import Utility makes imported vector graphics easier to handle in Blender. A tool panel lets you scale, move and center SVG objects, and put extrude and bevel curve settings on every object in one step.

An updated version for Blender 3.1 extrudes and bevels only selected splines. Documentation is included. Handy for turning logos and illustrations into 3D shapes. It removes the usual follow-up steps after importing artwork, helping turn logos and vector illustrations into solid 3D objects quickly.

Key features

  • Scale, move and center imported SVGs
  • Extrude and bevel all curves at once
  • Selected-spline option for Blender 3.1
  • Documentation included
