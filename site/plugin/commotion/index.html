Blender motion graphics add-on for offsetting animation across objects, with proximity effector and NLA support.

What Commotion does

Commotion makes staggered animation easy in Blender. Timing is shifted across many objects according to different sorting methods, on F-Curves as well as NLA strips.

Animation can be copied or linked between objects, a Proximity Effector changes properties based on distance to other objects, and utility tools handle absolute shape keys. It supports Blender 4.4 and newer and the Slotted Actions system. Motion designers build cascading and ripple effects without keying each element.

Key features

  • Offset animation with sorting methods
  • F-Curve and NLA strip support
  • Copy and link animation
  • Proximity Effector
  • Slotted Actions compatibility
