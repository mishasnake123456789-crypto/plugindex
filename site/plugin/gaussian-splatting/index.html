What Gaussian Splatting does

This plugin from irrealix lets you load 3D Gaussian Splatting scans straight into DaVinci Resolve and render them live on the GPU. Instead of preprocessing a capture elsewhere, you can drop the .ply file into a compositing project and work with it there.

Splats can be cropped with spherical, box or Y-plane shapes, up to ten models can share a scene, and colour ramps or opacity ramps help tint or reveal them. Scale can be animated and each model distorted with noise. A depth pass can be rendered for 3D compositing, and scenes can be exported.

Key features

  • Direct .ply import in DaVinci Resolve
  • Crop with sphere, box or Y-plane shapes
  • Combine up to 10 models in one scene
  • Colorize, reveal, scale and noise-distort models
  • Depth pass output and scene export
