What Export Pointcache Format(.pc2) does

Export Pointcache writes mesh point cache data in the .pc2 format. The command is in File, Export, Pointcache (.pc2), and it was originally one of Blender's bundled add-ons.

It supports Blender 4.2 LTS and newer, is released under GPL v2 or later and requests access to a directory for the output. Pipeline artists moving vertex animation into other software that reads PC2 can use it. The format stores per-frame vertex positions, which is helpful for exchanging deforming meshes with software that reads point caches.

Key features

  • Exports to .pc2
  • File > Export entry
  • Supports Blender 4.2 LTS and newer
  • GPL v2 or later
