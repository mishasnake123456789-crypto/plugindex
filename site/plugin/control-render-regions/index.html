What Control Render Regions does

Control Render Regions is a Blender add-on by nukkio for handling render regions. It supports Blender 4.2 LTS and newer and ships builds for Windows, Linux and macOS (both Intel and Apple Silicon).

Installation works by dragging the file into a Blender window or choosing it from disk in the preferences. It is released under the GNU GPL v3 or later. The listed release is version 1.0.12, last updated on September 28, 2024.
