What Character My Curves: 3D Objects To Abstract Curves does

Giambattista Von Nettesheim's Character My Curves renders 3D objects as abstract line art using Geometry Nodes in Blender. It works especially well with MB Lab characters but can be applied to other objects.

The interface is built into Blender and installation is a normal ZIP. It also serves as a guided tour of what Geometry Nodes can do. Documentation is included. Motion designers and illustrators wanting stylized, line-based figures can experiment quickly.

Key features

  • 3D objects to abstract curves
  • Works well with MB Lab characters
  • Built on Geometry Nodes
  • Integrated interface
  • Standard ZIP installation
