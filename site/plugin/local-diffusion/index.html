Generates images from text prompts inside After Effects using Stable Diffusion running locally.

What Local Diffusion does

Local Diffusion brings text-to-image generation into After Effects. It is based on Stable Diffusion and powered by blace.ai, so artists can type a prompt and receive an image in their composition.

A Stop Processing button cancels long computations, CUDA Memory Sharing accelerates rendering above 4K on CUDA hardware, and out-of-memory situations are reported. Recent updates moved to a new AI backend and improved stability with multiple instances. It requires After Effects 2022 or newer.

Key features

  • Stable Diffusion text-to-image
  • Stop Processing button
  • CUDA Memory Sharing for resolutions above 4K
  • Out-of-memory reporting
  • Requires After Effects 2022 or later
