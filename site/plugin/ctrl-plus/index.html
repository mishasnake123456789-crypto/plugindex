What Ctrl Plus does

Ctrl Plus from Watermelon packs a set of small convenience features into Blender. Each button or shortcut can be switched on or off.

A Location button opens the file browser at the saved file's folder. A Base Color Pass toggle gives a simplified Shader Editor view for sampling base colors without lighting, and Save Viewer Node Image saves the viewer image without re-rendering. Snap Pivot Point and other snapping, camera and viewport splitting shortcuts are included.

Key features

  • Open the file location
  • Base Color Pass toggle
  • Save Viewer Node Image without re-rendering
  • Snap Pivot Point
  • Individually toggled buttons and shortcuts
