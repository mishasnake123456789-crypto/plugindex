What VoxFerry does

VoxFerry lets editors use ElevenLabs voices from within Premiere Pro. Generate narration from text, change an existing voice, and keep everything in the project, with no need to export audio, process it elsewhere and re-import the result.

An AI script director helps produce expressive narration using the v3 model. It is built for Premiere Pro 2026 and suits editors who need voiceover quickly. This keeps voiceover production in one place, which suits editors working on explainers and social clips.

Key features

  • ElevenLabs text-to-speech in Premiere Pro
  • Voice changing from within the editor
  • AI script director for expressive v3 narration
  • No export and re-import
  • Compatible with Premiere Pro 2026
