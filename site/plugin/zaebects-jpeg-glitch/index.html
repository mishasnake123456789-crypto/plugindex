What Zaebects JPEG Glitch does

Zaebects JPEG Glitch runs inside After Effects and Premiere Pro and deliberately injects mistakes while an image is being JPEG-compressed. The outcome is a distinctive broken-image aesthetic, while crash protection keeps rendered files working as normal.

Controls cover compression ratio and a broken-bytes setting, which behaves differently on macOS and Windows, along with quantization table adjustments across all 64 coefficient positions and random value replacement within a chosen range. Processing is fast, so you can experiment without long render waits, and no programming knowledge is needed. Motion designers and editors can use it to add digital corruption to titles, transitions or footage.

Key features

  • Glitches every level of the JPEG pipeline
  • Compression ratio and broken bytes controls
  • Quantization table edits across 64 coefficients
  • Random value replacement within a range
  • Crash protection for rendered files
