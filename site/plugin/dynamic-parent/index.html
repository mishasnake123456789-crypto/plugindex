Blender add-on that creates and disables animated Child Of constraints while preserving the child's position.

What Dynamic Parent does

Dynamic Parent helps animators pass objects between parents in Blender, such as a character picking up a prop. It builds animated Child Of constraints and turns them off again without the child jumping, because its position relative to the parent is retained.

Select two objects with the child last and Create adds the constraints and keys. Disable switches them off at the current frame, while Clear deletes every DP constraint along with its keys, and Bake and Clear commits object or bone animation to keys before deleting them.

Key features

  • Create animated Child Of constraints from a selection
  • Disable parenting on the current frame
  • Keeps the child's position when released
  • Clear removes constraints and keys
  • Bake and Clear for object or bone animation
