What Shockwave Addon does

Shockwave Addon, by EdenWeby 3D, creates expanding shockwave rings using Blender's particle system. A Generate button produces a simple version that is positioned and rotated through a parent Shockwave Empty.

Color, size, shape and speed can all be adjusted, and duplicating emitters builds up more elaborate, layered effects. It is suited to explosions, impacts and sci-fi blasts in motion graphics and VFX shots.

Key features

  • One-click Generate button
  • Particle-system based shockwave
  • Adjust color, size, shape and speed
  • Duplicate emitters for advanced results
  • Positioned via a parent Empty
