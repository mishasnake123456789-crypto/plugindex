Render Task List

Developer: Bookyakuno

FreeBlender
Download Free

Blender add-on that stores several render configurations as tasks and runs them together as a batch.

What Render Task List does

Bookyakuno's Render Task List treats each render setup as a separate task. A task remembers its file path, frame range, file format, engine, sample count and color management among other options, so different outputs can wait in one queue.

Specify scenes, view layers and cameras and then export every task together. Extra features include temporarily hiding objects or collections, material overrides that also work in Eevee, a pseudo normal map, a compositor cross line and a camera list. Handy for delivering variations to clients.

Key features

  • Per-task render settings
  • Choose scenes, view layers and cameras
  • Export all tasks at once
  • Temporary object and collection hiding
  • Material overrides including Eevee
