What Distribute Objects Addon does

Distribute Objects Addon is a Blender add-on by Duarte Ramos that separates objects that already exist into a grid-like arrangement with configurable spacing. It does not duplicate or generate anything; it moves the selected set so objects no longer overlap.

A selection can be spaced out along one axis by a length you specify, starting from a definable point (the 3D cursor, say, or the active object). Overlapping items are separated incrementally in just two mouse clicks. It also handles linked and appended collections, helpful for laying out imported asset libraries.

Key features

  • Arranges existing objects in a grid
  • Configurable spacing along one axis
  • Start from the 3D cursor or active object
  • Incremental separation in two clicks
  • Handles linked or appended collections
