What Solid Color Randomizer - Addon does

Solid Color Randomizer, from Nanomanpro, gives selected objects random colors in Solid Mode. One click is enough to make the elements of a complicated scene easy to tell apart.

A Select Grouped by Color command picks parts sharing a color, and a side-panel tab has saturation and brightness settings for the generated colors. Good for organizing kitbashed models and busy scenes. This is especially useful when sorting out kitbashed assets or checking separate parts before assigning final materials.

Key features

  • Random viewport colors in one click
  • Select Grouped by Color command
  • Saturation and brightness settings
  • Side-panel controls
