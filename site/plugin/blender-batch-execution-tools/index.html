What Blender Batch Execution Tools does

Blender Batch Execution Tools automates repetitive work across many files. You point it at a folder, choose a Python script, and it processes each .blend in turn, handy for batch rendering, mass renaming or uniform scene setup.

It can recurse into subfolders for whole project trees and lets you set how many versions to keep, with zero skipping backups. Options pack external resources for portable files and purge unused data blocks. Progress reporting and logs show which files were handled.

Key features

  • Runs any Python script on many .blend files
  • Optional subfolder recursion
  • Save-version control
  • Packs external resources and purges unused data
  • Progress reporting and logging
