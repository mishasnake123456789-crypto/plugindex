Blender add-on that cuts geometry along a drawn spline, giving a bumpy noisy edge with unwrapped UVs.

What Noisy-Cutter does

Noisy-Cutter slices geometry along a hand-drawn spline in Blender. Instead of a flat cut, the result has an irregular, bumpy edge and an unwrapped UV.

Displacement can be noise-based or texture-based using bundled textures, and a cut material is applied automatically. The workflow has three steps: draw the line, then set mesh density and displacement type. Several meshes can be cut together. Useful for torn, rocky or broken edges. Since the result includes UVs and a material, the torn or rough face is ready to texture straight away.

Key features

  • Noise-based displaced cut
  • Texture-based displacement with included textures
  • Automatic cut material
  • Three-step draw and adjust workflow
