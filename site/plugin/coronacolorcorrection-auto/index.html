What CoronaColorCorrection-Auto does

CoronaColorCorrection-Auto adds Corona Color Correct nodes to selected material slots in 3ds Max and sets them to values you specify. It handles Diffuse, Bump, Roughness, Translucency and Self Illumination, and any existing bitmaps are kept inside the color correct node.

After the node is added, every parameter remains adjustable, and each one has its own randomization. Randomize applies a random value to the existing material, which updates every object using it, while the New material option spreads random values across the selected objects and gives each its own material. It suits Corona users who need variation across repeated assets.

Key features

  • Adds Corona Color Correct nodes to chosen material slots
  • Covers diffuse, bump, roughness, translucency and self illumination
  • Keeps existing bitmaps inside the node
  • Randomization per parameter
  • New material option for per-object variation
