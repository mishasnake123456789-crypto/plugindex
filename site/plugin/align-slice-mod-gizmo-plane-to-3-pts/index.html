Aligns a 3ds Max Slice modifier's plane to the normal of a plane defined by three picked points.

What Align Slice Mod Gizmo(Plane) to 3 pts does

This miauu script rotates the slice plane of the Slice modifier so it matches a plane you define with three points. Run it, pick the points, and the gizmo aligns; snapping switches on automatically when the script starts.

Holding Shift aligns the slice plane to the currently active grid, or to the home grid if no custom grid is active. Errors that appeared when the script ran with no object selected or with a Slice modifier in certain states have been fixed. Modelers cutting objects along arbitrary angles gain precision without manual gizmo rotation.

Key features

  • Aligns slice plane to a three-point plane
  • Pick three points to set the orientation
  • Shift aligns to the active or home grid
  • Snap enabled automatically
  • Fixes for no-selection and modifier errors
