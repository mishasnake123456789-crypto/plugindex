What AEJuice Add Typing Cursor does

AEJuice Add Typing Cursor is an After Effects script that produces a real-time typing look for text. It adds a cursor that blinks and travels along with the characters as they appear.

It works with any language and font and supports multiline text. Cursor speed, color and size can be customized, and an optional sound effect can accompany the cursor. It suits terminal-style titles, search-bar animations and explainer videos where typing needs to look believable without manual keyframing.

Key features

  • Typing animation in one click
  • Blinking cursor follows the text
  • Any language and font
  • Multiline text support
  • Adjustable cursor speed, color and size
