FreeBlender

Blender add-on that deletes duplicate images, reconnects the materials using them and purges orphan data.

What Image Cleanup does

Appending files into big projects leaves duplicate images behind. The 3D Advantage's Image Cleanup removes redundant copies and re-points the materials that used them to the remaining image.

Duplicates are spotted by Blender's suffix pattern, for instance image_name.png.001, and orphan data is cleared to free memory. It adds an N panel tab in the 3D view with a single Cleanup button. A fast maintenance step before saving, sharing or rendering heavy scenes.

Key features

  • Removes duplicate image copies
  • Reassigns materials to the original
  • Clears orphan data
  • Detects names like image.png.001
  • Single Cleanup button in the N panel
