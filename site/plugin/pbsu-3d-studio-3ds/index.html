What PBSU 3D Studio (.3ds) does

PBSU 3D Studio is a Blender add-on by Arturo-Cervantes that reads and writes 3D Studio (.3ds) files and copes with entire scenes, including meshes, cameras, lights and basic animations, and is aimed at old 3DS assets and Proton Bus Simulator Urbano work.

Geometry smoothing is applied automatically through shade_smooth, and an optional geometry fix during import addresses common errors found in old files. It supports Blender 4.2 LTS and newer, making it useful for modders and anyone converting older assets into a modern pipeline.

Key features

  • Imports and exports full 3DS scenes
  • Handles meshes, cameras, lights and basic animation
  • Automatic smoothing with shade_smooth
  • Optional geometry fix on import
  • Supports Blender 4.2 LTS and newer
