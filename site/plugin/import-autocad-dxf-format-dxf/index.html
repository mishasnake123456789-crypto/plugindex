What Import AutoCAD DXF Format (.dxf) does

Import AutoCAD DXF Format lets Blender read drawings saved as .dxf files. It is a community-maintained add-on that previously came with Blender 4.1 and is found under File > Import > AutoCAD DXF.

It works with Blender 4.2 LTS and newer, is licensed under GPL v2 or later, and asks for file access to the folder holding your DXF files. Architects, engineers and visualization artists can bring floor plans or CAD geometry into Blender as a base for modeling.

Key features

  • Imports AutoCAD DXF files
  • Found in File > Import
  • Requests access to the DXF folder
  • For Blender 4.2 LTS and newer
