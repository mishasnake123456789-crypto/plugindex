What Cross Select does

Cross Select is a Blender add-on by RARA that brings Rhino- and CAD-style box selection to the viewport. Dragging from left to right selects only items fully inside the box, while dragging from right to left selects anything the box touches.

It works on vertices, edges and faces in Edit Mode and on meshes and other objects in Object Mode, with both Box Selection and Lasso modes. Shortcut keys are configurable in preferences, and a Perspective Selection parameter allows see-through selection. Good for users coming from CAD tools.

Key features

  • Left-to-right full match, right-to-left partial match
  • Works for vertices, edges, faces and objects
  • Box and Lasso selection modes
  • Configurable shortcut keys
  • Perspective Selection for see-through picking
