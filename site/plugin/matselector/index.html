Selects all Blender objects with similar materials and swaps them to a chosen material in one click.

What Matselector does

MatSelector speeds up material cleanup in large scenes. Pick one object with the material you care about and it selects every object using a similar one.

The selected objects can then be changed to another material at once, moved into a collection or otherwise used further. The panel is simple and operated with clicks. Scene organizers replacing placeholder or duplicate materials will avoid hunting through the outliner. This is especially useful after importing assets with many near-identical materials.

Key features

  • Select Similar by material
  • Change Materials for all selected
  • Simple panel interface
  • Move selected objects to a collection
