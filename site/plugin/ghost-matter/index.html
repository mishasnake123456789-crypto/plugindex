What Ghost Matter does

Ghost Matter is a Blender plugin that provides a separate node editor for blending materials. Materials need no special configuration to work in it.

It includes Blender's standard material nodes apart from shader nodes, along with nodes for mixing materials and utility nodes. Texture baking export, decal projection and templates for beginners are also included. Handy for layered surfaces and quick look development. Having mixing, baking and decals in one editor keeps material work organized and helps newcomers learn through the supplied templates.

Key features

  • Dedicated material mixing node editor
  • Standard nodes plus mix and tool nodes
  • Bake to textures
  • Decal projection and beginner templates
