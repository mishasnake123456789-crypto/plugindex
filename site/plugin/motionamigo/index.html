What MotionAmigo does

MotionAmigo adds AI agent control to After Effects. Its CEP panel launches Claude Code or Codex inside the application on your own AI subscription, so you can describe what you want in plain language.

The agent connects to a remote MCP server and acts as an After Effects scripting expert, with more than 300 tools covering compositions, layers, shapes, keyframes and expressions. The panel docks beside your other extensions and writes straight to the timeline, with no separate app, web tool or cloud round trip. Motion designers wanting to delegate repetitive building work can try it.
