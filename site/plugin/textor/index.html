Slider-based text animation builder for After Effects with savable presets and a random generator.

What Textor does

Textor is Marco Sanasi's script for After Effects that animates text without keyframes. Sliders control transformations, effects and behavior, and results appear instantly as you adjust them.

A one-click random generator proposes animations for selected properties. The Presets tab lets you save, remove, rename, export and import animations for reuse on any text layer. Presets are size independent, taking the composition size and text scale into account when applied. It suits designers who need many text styles quickly.

Key features

  • Slider control instead of keyframes
  • Controls transforms, effects and behavior
  • One-click random animation generator
  • Preset save, rename, export and import
  • Size-independent presets
