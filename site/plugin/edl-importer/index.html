What EDL Importer does

EDL Importer brings edit decision lists straight into After Effects, so conforming an edit no longer means rebuilding it by hand. Drag an EDL in, and the tool searches for the source media and links it automatically.

Three build modes let you choose how compositions are assembled, and custom composition settings and optional clip handles are available. Timecode and edit points are preserved, and EDL markers and CDL color data come along too. Editors and finishing artists moving cuts from an NLE into After Effects will find it most useful.

Key features

  • Drag-and-drop EDL import
  • Automatic source media search and linking
  • Three composition build modes
  • Precise timecode and edit points
  • Imports markers and CDL data
