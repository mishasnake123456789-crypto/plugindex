What Amaranth does

Amaranth gathers assorted small productivity boosts for Blender that touch the 3D View, compositing, lighting, rendering, scenes and the interface. It is released under GPL v3 or later.

One example is a set of Jump Frames buttons in the playback Time Jump popover; another lists everything using an image datablock, even when Cycles is not active. It needs no special permissions. Everyday Blender users who like small time-savers will find a lot here.

Key features

  • Productivity tools across many editors
  • Jump Frames in Time Jump popover
  • List Users for image datablocks
  • No special permissions
