Generates mattes from text, box and concept prompts using Segment Anything 3 in After Effects and Premiere Pro.

What Mask Prompter does

Mask Prompter creates masks by describing what you want rather than tracing it by hand. Built on Segment Anything 3, it can generate a matte from a text prompt, a drawn rectangle or a concept, and handles multiple objects in one pass.

A detection threshold slider tunes how strict the selection is, a rectangle scale slider adjusts drawn boxes, and several object detection models are available. A CUDA Memory Sharing option speeds up rendering above 4K on CUDA hardware, and a Stop Processing button cancels long calculations. It works in After Effects and Premiere Pro and comes from Blace Plugins.

Key features

  • Text prompting for mattes
  • Box and concept prompting with threshold slider
  • Multi-object mattes from text
  • Choice of object detection models
  • CUDA Memory Sharing and Stop Processing button
