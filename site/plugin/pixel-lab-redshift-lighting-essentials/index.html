What Pixel Lab Redshift Lighting Essentials does

Pixel Lab Redshift Lighting Essentials is a library of 20 ready-to-use studio lighting setups for Cinema 4D with Redshift. Each scene carries a full Xpresso rig so lights and colors can be modified without digging through the object tree.

The pack is delivered as a .lib4d file and opens from the Cinema 4D content browser. Setups cover products, vehicles, jewelry, portraits and cinematic looks, and a Disco Studio scene offers adjustable colors and animation. Artists who need good lighting quickly for product or portrait renders can drop one in and tweak it.

Key features

  • 20 customizable studio lighting scenes
  • Xpresso rig in every scene
  • Delivered as .lib4d for the content browser
  • Product, vehicle, jewelry, portrait and cinematic setups
  • Disco Studio scene with animation
