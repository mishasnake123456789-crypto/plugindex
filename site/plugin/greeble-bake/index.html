Blender add-on that bakes geometry details into normal, AO and depth maps using a plane as the canvas.

What Greeble Bake does

Greeble Bake converts modeled detail into texture maps in Blender. Using a primitive plane as a canvas, it produces depth, normal and ambient occlusion maps from geometry, with one button generating all of them.

Detail can be derived from geometry, or from a colored pass plus an emission. You may build directly on the bake origin object or canvas, or bake objects sitting above it, which makes it simple to assemble a library of patterns, stencils and greebles. It runs on Cycles, works alongside Random Flow, or can be used independently.

Key features

  • Bakes normal, AO and depth maps
  • Primitive plane as the baking canvas
  • All maps with a single button
  • Patterns and greebles for a texture library
  • Works with Random Flow or alone
