What CorVex does

CorVex is a 3ds Max geometry plugin written in script, meant for rapidly blocking out game levels and walls. Geometry is driven by spline bases, so changing a spline reshapes the walls built on it, and planar mapping parameters are built in for convenient UV control.

Settings are split into main and wall groups, with extra planar UVW options, material ID assignment and a stack selection feature. Wall and mapping changes display in real time. On Max 2016 SP2 and newer, a CorVex Spline can build splines from sections of CorVex objects or Wall Worm Arch Primitives. Level designers and environment artists benefit from the quick iteration.

Key features

  • Spline-controlled wall and layout geometry
  • Built-in planar mapping with advanced UVW controls
  • Main parameters and wall settings
  • Material IDs and stack selection
  • CorVex Spline generates splines from CorVex and Wall Worm Arch sections
