CAD-style snapping for Blender that locks to vertices, midpoints, centers, perpendiculars and intersections.

What Osnap+ Snap System does

Osnap+ brings the precision of CAD to Blender's viewport. All tools share a single snapping engine that grabs vertices, edge midpoints, face centers, perpendicular points, intersections and projected alignment guides.

A raycast engine using a C-level BVH keeps the response instant even on dense meshes. Architects, product designers and hard-surface modelers who need accurate placement and measured geometry will notice the difference compared with the default snapping. The guides make it easy to continue lines and align new geometry to existing features without measuring by hand.

Key features

  • Unified snap system for all tools
  • Midpoint, center, perpendicular and intersection snaps
  • Projected alignment guides
  • Fast raycast engine for dense meshes
