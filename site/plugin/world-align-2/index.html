What World Align 2 does

World Align 2 applies consistent texture adjustments based on world coordinates. Select an object or just some faces, press a button, and alignment is fixed instantly.

It addresses UV distortion that appears when objects have different rotations and positions, and it copes with angled surfaces and individual faces where Cube Project tends to fail. A single button performs the correction, and documentation is included. Texture artists can use it to get uniform scale across a set of props.

Key features

  • Texture alignment from world coordinates
  • Fixes UV distortion from rotation and position
  • Whole object or selected faces
  • Single-button correction
  • Handles angled surfaces
