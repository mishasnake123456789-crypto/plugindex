What Buddycode Gpt: Blender Copilot - Powerful Coding Companion does

Buddycode Gpt: Blender Copilot adds AI help to Blender's Text Editor, producing code from prompts and completing text as you type.

It works with Ollama, Google Gemini and LM Studio. Features include real-time context-aware completions, generation from natural language, text completion for sentences or paragraphs and multi-pair execution for running several prompts concurrently.
