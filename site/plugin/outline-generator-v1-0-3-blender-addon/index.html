What Outline Generator V1.0.3 [Blender Addon] does

Outline Generator creates a stylized outline around objects in Blender, a look common in toon and illustrative renders. It combines modifiers and shaders to produce the effect and manages it for you, so each object does not need to be set up separately.

Select several objects and the outline is applied to all of them at once. The effect uses the Eevee render engine, and the add-on supports Blender 2.93 through 5.1, is released under the GPL and includes documentation. Stylized artists, motion designers and anyone wanting consistent outlines across a scene will find it saves time.

Key features

  • Creates outlines on selected objects
  • Applies the effect to many objects at once
  • Built from modifiers and shaders
  • Eevee based
  • Supports Blender 2.93 to 5.1
