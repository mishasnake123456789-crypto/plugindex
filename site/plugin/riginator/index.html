What Riginator does

Riginator from U mocap produces armatures in Blender based on images. It also creates image files that can rebuild an armature automatically, which makes rigs easy to repeat.

The image-to-armature workflow is meant to streamline rigging for 3D character animation, so you do not have to place every bone by hand. Documentation is included and the add-on is released under the GPL license. It suits users who prefer a visual shortcut for starting a rig.

Key features

  • Armature generation from images
  • Images that recreate armatures
  • Image-to-armature workflow
  • Streamlines character rigging
  • Documentation included
