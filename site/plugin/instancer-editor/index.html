What Instancer Editor + does

Instancer Editor + is a Blender add-on for working on collection instances without digging through the outliner. Double-click any instance to open it for editing, and press Esc to leave.

Edit Instance mode hides everything else so only the block stays in view. Edit in Place leaves the scene showing but locked, and its display style can be flipped between wireframe, solid color and box. All instances update live as you change the source. It handles native instances and Asset Library instances, and linked instances can be localized for editing.

Key features

  • Double-click to enter instance editing, Esc to exit
  • Isolated Edit Instance mode
  • Edit in Place with wireframe, solid or box display
  • Live updates across all instances
  • Works with native and Asset Library instances
