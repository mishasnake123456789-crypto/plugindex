What Duplicator does

Duplicator is a Blender plugin that offers six ways to make copies: Circular, Array, Randomize, along a Curve, to Mesh and to Cursor. Two more utilities come along with it.

Align to surface is supported in the Array method, toggled with S during the operation, and in Randomize. Duplicate to Cursor drops copies where the 3D cursor sits. It simplifies repetitive layouts such as fences, rings and scattered props. Each method suits a different layout need, so one tool replaces several modifiers or manual copy-and-move routines in everyday scene building.

Key features

  • Six duplication methods
  • Align to surface option
  • Duplicate to Cursor
  • Two extra utilities
