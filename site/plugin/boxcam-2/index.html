What Boxcam 2 does

Boxcam 2, by Rebane, gives flat 2D compositions a camera-like way to frame a scene, similar to a traditional 3D camera. A Create Comp button produces the output composition.

Version 2.1 added KBar support, and it runs on After Effects from CS6 through 2024. A help and activation button appears in the main interface and can be hidden through a preferences parameter. Note that the product is currently discontinued. It can suit designers who prefer 2D layers but still want camera-style moves, though availability is now limited.

Key features

  • 2D camera that behaves like a 3D camera
  • Output comp via Create Comp button
  • KBar support from version 2.1
  • Works with CS6 through 2024
  • Currently discontinued
