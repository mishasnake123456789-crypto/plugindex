Replaces selected Blender objects using the object list of an active category, for fast level blockouts.

What Quick Replace does

Quick Replace swaps selected objects for others drawn from the list of the active category. That makes it practical for blocking out layouts, particularly game level design, and any task where placeholder objects are replaced with final ones.

It supports Blender 3.3 through 5.1, is marked extension compatible and is released under the GPL license. You get replace objects from a category list, suited to level blockouts and blender 3.3 to 5.1, along with the rest of the feature set.
