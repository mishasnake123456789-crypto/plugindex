Extends Blender's Set Random with two object modes and Edit Mode support for randomizing transforms within ranges.

What Set Random Plus does

Set Random Plus builds on Blender's default Set Random utility. Location, rotation and scale can be randomized for selected objects, vertices, edges or faces, within ranges of your choosing.

In Object Mode, the "*" function resets each object's transform to a random value in the range, while "+" adds a random increment. Edit Mode support applies random transforms to mesh elements. Useful for breaking up uniformity in scatter-like layouts and organic variation.

Key features

  • Two Object Mode functions: set or increment
  • Edit Mode support
  • Works on objects, vertices, edges and faces
  • Custom ranges for transform, rotation and scale
