What Gobos Hands Gestures does

Gobos Hands Gestures supplies hand-shaped light cutouts for Blender product presentation scenes. There are 34 gobo textures showing a woman's hands in different gestures, plus 6 textured 3D hand assets as a bonus.

The content is delivered as Blender assets that you drag in from the asset manager, so no add-on is needed. It works with Blender 3.0 and later, and documentation is included.

Key features

  • 34 hand gesture gobo textures
