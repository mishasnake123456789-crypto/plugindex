What Tensor-Cloth The Bidirectional Physics Engine does

Tensor-Cloth is a Blender add-on that simulates fabric through the Rigid Body system, so soft materials can push and pull on rigid objects in the same scene. That two-way interaction is the main difference from regular cloth.

Bags, ropes, straps, hanging cloth and similar soft items are covered, and it can be used with various render engines such as Cycles. Motion designers and VFX artists who need cloth reacting to solid props can set it up without leaving Blender's physics tools.

Key features

  • Cloth built on the Rigid Body system
  • Two-way interaction with rigid objects
  • Straps, ropes, bags and hanging fabric
  • Works with Cycles and other engines
