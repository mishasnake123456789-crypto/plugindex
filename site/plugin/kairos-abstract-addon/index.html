What Kairos Abstract Addon does

Kairos Abstract Addon is a Blender plugin from EdenWeby 3D that uses Geometry Nodes to build sci-fi visuals. It can be applied to any mesh object and offers more than 17 presets that each carry their own settings.

Effects are animatable through the node system, and a customizable reveal animation is provided. Documentation is included, and the workflow is designed to be easy to learn. Motion graphics artists can generate futuristic backdrops quickly.

Key features

  • 17+ presets with adjustable settings
  • Works on any mesh object
  • Animatable via Geometry Nodes
  • Customizable reveal animation
