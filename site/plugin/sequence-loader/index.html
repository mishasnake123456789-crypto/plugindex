Blender add-on that loads meshio-supported mesh sequences frame by frame to keep memory use low.

What Sequence Loader does

Sequence Loader, by Stefan-Jeske, loads sequences of mesh files into Blender just in time. Data is read when the frame changes rather than all at once, which avoids heavy memory use, and it is useful for rendering simulation results.

Vertices, lines, triangles and quads import by default, and triangle and quad surfaces are extracted from tetrahedral and hexahedral volume meshes. Scalar and vector vertex attributes come in for visualization, and extra data arrives as geometry node attributes for shading. It bundles meshio and is confirmed with .obj, .ply and .vtk files.

Key features

  • Just-in-time loading per frame
  • Vertices, lines, triangles and quads
  • Surface extraction from volume meshes
  • Vertex attributes as geometry node attributes
  • Bundled meshio with .obj, .ply and .vtk support
