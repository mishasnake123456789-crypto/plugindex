What Shot Manager does

Shot Manager, from Other Realms, is a Blender addon for planning shots and managing renders. Each shot remembers its frame range, camera, view layer and output path, and the system handles serial, overlapping and pass-based setups without leaning on camera markers.

A timeline overlay inside the 3D window lets you re-time, trim, slice, join and ripple-edit shots interactively. Batch rendering can go through SM Batch Render, Playblast, B-Renderon, Flamenco or Deadline, while batch export handles BAT, BLEND, DAE, ABC, OBJ, FBX and USD. Output paths are assembled automatically.

Key features

  • Stores frame ranges, cameras, view layers and paths per shot
  • Interactive overlay to trim, slice, join and ripple-edit
  • Batch rendering via Flamenco, Deadline and others
  • Batch export to formats such as USD, FBX and ABC
  • Auto Output Generation for file paths
