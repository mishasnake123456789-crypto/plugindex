3ds Max script that batch imports chosen file types from folders and saves them as Max files in a selected version.

What Batch Import Convert does

Batch Import Convert processes entire folders in 3ds Max. Chosen file types are imported from a folder and everything beneath it, then written out as Max files in the version you pick, optionally capturing a viewport preview along the way.

Four working modes cover importing or opening files and then either exporting or saving them under a new name. Max and Mat files can be opened and saved to an older version, material libraries included. MS or MSE scripts can run in order beforehand, and a checkbox converts poly objects to mesh in Max 2021 and later when saving to previous versions, avoiding vertex distortion. Output goes into a new Max folder.

Key features

  • Imports chosen file types from folders and subfolders
  • Saves as Max files in a selected version
  • Four modes combining import or open with export or save
  • Runs MS and MSE scripts in order beforehand
  • Poly to mesh conversion for older version saves
