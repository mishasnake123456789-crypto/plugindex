What Quick Measure2 does

Quick Measure2 adds measurement tools to Blender's 3D viewport. You can check the distance between objects, vertices or points without leaving the scene.

The on-screen display is designed to be fast and readable, which helps during modeling, rigging and layout work where sizes and spacing matter. It supports Blender 2.93 through 5.1, is distributed as a Blender Extension under the GPL license, and includes documentation. It is a handy companion when checking sizes, clearances and spacing without leaving the working view.

Key features

  • Measures distances between objects, vertices and points
  • In-viewport display
  • Useful for modeling, rigging and layout
  • Works with Blender 2.93 to 5.1
  • Blender Extension, GPL license
