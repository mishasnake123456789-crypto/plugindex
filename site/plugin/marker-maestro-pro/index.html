What Marker Maestro Pro does

Marker Maestro Pro is a markers panel from Rob Womack for After Effects. It lists all comp and layer markers in one place, showing timecode, comment, color and layer number, so you no longer need to hunt through the timeline.

Marker properties can be edited in the panel, including batch edits. Markers can be shifted in time or moved to another layer, and a double-click on a row jumps to it. Timecode shorthand like 1.2.0 or 010200 works for entering positions. Markers can be copied to many layers or comps, and the work area can be set to a selected marker.

Key features

  • All comp and layer markers in one panel
  • Batch edit of marker properties
  • Shift in time or move to another layer
  • Timecode shorthand entry
  • Copy and paste across layers and comps
