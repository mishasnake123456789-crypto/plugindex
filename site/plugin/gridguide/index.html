What GridGuide does

GridGuide is a tool from mamoworld tools for building layouts inside After Effects, with a focus on motion design rather than static page layout. It provides automatic layouts, grids that elements can snap to, and shape layer guides that can be modified.

A Convert Grids to Guides command may take a few seconds to take effect. The tool needs Photoshop installed and launches it automatically if it is not running. It works with After Effects from CS4 through 2026, helping designers keep elements aligned.

Key features

  • Automatic layouts for arranging elements
  • Snappable guide grids
  • Modifiable shape layer guides
  • Convert Grids to Guides command
  • Requires Photoshop installed
