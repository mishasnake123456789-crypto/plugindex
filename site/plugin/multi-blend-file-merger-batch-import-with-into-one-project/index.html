What Multi Blend File Merger - Batch Import With Into One Project does

Combining work from several .blend files normally means appending them one by one. Multi Blend File Merger handles the whole job in a single operation, whether you have a handful of files or hundreds.

Each file arrives in a collection named after it, and a live progress bar shows how far the import has got. Rigs, animations, shape keys, materials, textures and modifiers come along intact. It is handy for studios consolidating asset libraries or artists assembling a large scene from separate shots.

Key features

  • Batch import of dozens or hundreds of .blend files
  • Live progress bar during import
  • One named collection per source file
  • Keeps rigs, animations, shape keys and materials
