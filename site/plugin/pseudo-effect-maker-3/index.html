What Pseudo Effect Maker 3 does

Pseudo Effect Maker 3 is the third generation of the After Effects tool for creating custom effect control sets. Controls are added with a click and arranged by dragging, and the improved interface has a cleaner, more organized layout.

Changes apply without restarting After Effects, so you can keep refining while you work. Swapping a selected control for the updated one preserves expressions and keyframes on your pseudo effect. Better warnings and errors point out conflicts before you start, and the interface can be customized to keep frequently used features close.

Key features

  • Add controls with a click
  • Faster drag-and-drop organization
  • Live changes without restarting After Effects
  • Replace controls without losing expressions or keyframes
  • Improved warnings and a redesigned interface
