A Blender add-on that provides a to-do list in the header, N-panel or a floating hotkey panel.

What To-Do Task Manager does

To-Do Task Manager keeps daily tasks inside Blender so you do not need a separate note app. The list can be placed in the 3D view header, the N-panel or the main header through preferences, and a floating panel opens anywhere with a hotkey combination.

Each task can have subtasks, there is a view mode and icon indicator, and a count of completed and total tasks is shown. Popover width is adjustable, and a status indicator warns about unsaved or modified files. Tasks are stored in the project. Freelancers and studio artists tracking per-scene to-dos will find it convenient.

Key features

  • List in the 3D header, N-panel or main header
  • Floating panel via hotkey
  • Subtasks and completion counts
  • Unsaved file status indicator
  • Tasks stored with the project
