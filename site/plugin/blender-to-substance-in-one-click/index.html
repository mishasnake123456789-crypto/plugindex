What Blender To Substance In One Click does

Blender To Substance In One Click removes the manual steps between Blender and Substance Painter. One button exports the mesh as FBX, launches Painter and imports the mesh into a new project automatically.

It can also generate random vertex colors that serve as ID maps for masking, and its footprint in the N-panel is small. Texture artists who move assets back and forth often will save repeated clicks. Among its tools are one-click FBX export that launches Painter and automatic import into a new project.

Key features

  • One-click FBX export that launches Painter
  • Automatic import into a new project
  • Random vertex color ID maps
  • Minimal N-panel footprint
