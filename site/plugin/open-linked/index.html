What Open Linked does

Open Linked is a small Blender add-on from polygoniq that saves a few steps when you work with linked libraries. It adds a right-click option in the Outliner so you can open the selected linked blend files without leaving that window.

Supported systems are Windows, macOS 10 and Linux; install it from the Blender Extensions platform or a ZIP you download. The add-on requests a Files permission for filesystem access and is open source under the GNU GPL v3 or later. Anyone managing scenes built from linked assets benefits most.

Key features

  • Opens linked blends from the Outliner
  • Right-click menu for selected libraries
  • Windows, macOS 10 and Linux supported
  • Install via Extensions platform or ZIP
  • Open source under GPL v3 or later
