Pixelization effect that subdivides the image into variable-size blocks, useful for mosaics and JPEG-artifact looks.

What Recursive Mosaic does

Recursive Mosaic divides a frame into a grid and then keeps subdividing cells where detail should be kept, so some areas become coarse blocks while others stay fine. It runs in After Effects and Premiere Pro and is handy for unusual pixelation or simulating compression damage.

You can process luminosity, RGB, or a single red, green, blue or alpha channel. Mosaic intensity sets how blocky things get, and another layer or Premiere track can serve as an intensity source. Grid width and height set the starting cells, Maximum Iterations caps recursion, and curve modulation reshapes the mapping. Multi-frame rendering and Apple Silicon are supported.

Key features

  • Recursive grid subdivision
  • Luminosity, RGB or single channel modes
  • Intensity source from another layer or track
  • Maximum Iterations and starting grid controls
  • Multi-frame rendering and Apple Silicon
