What MASKit does

LUN Studios's MASKit is a script built for After Effects that turns shape layers into masks. It handles custom shapes drawn with the Pen Tool, and it can process several shape layers at the same time.

SNAPit orients the new masks to match the original shape's structure, and masks are created with the Add setting so they can be adjusted afterward. CENTERit centers the selected shape layers. SNAPit is optional when you intend to move masks individually. The script does not work with the built-in Ellipse, Rectangle or Polygon shapes.

Key features

  • Converts custom vector shapes into masks
  • SNAPit matches original shape structure
  • Masks several shape layers at once
  • CENTERit centers selected layers
