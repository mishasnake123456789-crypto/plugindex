What Free Addon Autouv does

Free Addon AutoUV is a Blender plugin that unwraps a model with a single click. It spares beginners and fast-moving artists from manual seam placement when a quick UV map is all that is needed.

It is GPL licensed, includes documentation and is compatible with Blender 3.4 through 4.4. It is meant for scenes rendered in Cycles or Eevee. Because it needs no manual seam work, it also gives quick, usable unwraps for test scenes, prototypes and anyone who just needs texture coordinates fast.

Key features

  • One-click automatic UV map
  • Automatic unwrapping
  • Blender 3.4 through 4.4
  • GPL licensed
