What ScorePlay does

ScorePlay gives editors access to their ScorePlay media library from inside Premiere Pro. Photos, videos and live stream content can be searched and imported to a timeline or bin.

Low-resolution proxies keep editing light, a cloud file gateway makes remote files behave like local ones, and high-resolution versions are downloaded only when needed to save bandwidth. Remote rendering runs on hardware near data centers for speed. It suits sports and media teams whose assets already live in ScorePlay and who want them in the cut quickly.

Key features

  • Library access in the editing interface
  • Import to timeline or project bin
  • Search for media
  • Low-res proxies with selective high-res download
  • Remote rendering
