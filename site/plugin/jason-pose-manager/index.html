What Jason Pose Manager does

Jason Pose Manager works like the built-in Pose Library but stores poses as JSON files in any folder you pick, rather than inside the Blend file.

Poses can be loaded between different rigs, a Bone Manager panel sets the active bone when you select a bone item, and mirror name rules handle hyphen and whitespace separators and trailing numbers. It helps animators share and reuse poses across projects. You get JSON pose files in any folder, inter-rig pose loading and bone Manager panel, along with the rest of the feature set.

Key features

  • JSON pose files in any folder
  • Inter-rig pose loading
  • Bone Manager panel
  • Mirror bone name rules
