What Select panel does

Select panel is a Blender add-on by xdanic that puts every built-in selection command, along with a few extras, in a single place. That saves you from hunting through menus whenever you need to grow, invert or otherwise adjust a selection.

It also introduces some viewport shortcuts: double-click picks an island, Shift plus scroll selects the next item, and Ctrl plus Shift plus scroll grows or shrinks the selection. Additional behavior is available via a companion add-on called Adjacent-Selection. It works with Blender 4.2 LTS and newer and needs no special permissions.

Key features

  • All built-in selection tools in one panel
  • Double-click to select an island
  • Shift+scroll to select next
  • Ctrl+Shift+scroll to grow or shrink selection
  • Optional extras via Adjacent-Selection add-on
