What Exact Decimate: Triangle Count Precision does

Exact Decimate lets you reduce a mesh to a target triangle count in Blender, which is more useful than guessing at ratios. Select an object, enter the count and press Decimate.

The result matches the count or comes in lower, depending on the starting mesh. Entering a new number and decimating again updates the mesh. It works through a created Decimate modifier and appears under the Tool tab. Real-time artists, designers and 3D printing users will find it practical.

Key features

  • Decimate to an exact triangle count
  • Select, enter count, decimate
  • Update by entering a new count
  • Uses a created Decimate modifier
  • Located in the Tool tab
