What Shadingmod - Various Tools For Fixing Shading Issues does

ShadingMod is a Blender plugin from Orcavia that bundles fixes for common shading issues. It can transfer normals between meshes, apply weighted normals, reset shading and convert N-gons into triangles.

Transfer Data Normal corrects inconsistent normals by copying shading data, and Weighted Normal+ smooths surfaces with an optional one-step bevel for hard surface models. Handy for cleaning up imported or booleaned geometry. Having these fixes together means you can diagnose and resolve smoothing artifacts quickly without hunting across separate menus.

Key features

  • Transfer Data Normal
  • Weighted Normal+ with optional bevel
  • Reset shading
  • N-gon to triangle conversion
