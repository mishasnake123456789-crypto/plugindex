What AEJuice Add Glow does

AEJuice Add Glow is a script for After Effects that sets up a glow with a single action. Select one or more layers, run it, and each receives a soft luminous halo.

Color, radius and intensity are adjustable, so the result can range from a faint shimmer to a strong neon look. Because it handles several layers at once, it saves repeated effect setup on busy compositions. It supports After Effects CC 2015 through CC 2022 and later.

Key features

  • One-click glow creation
  • Adjustable color, radius and intensity
  • Works on one or many layers
  • Soft glow applied to selected layers
  • Compatible with CC 2015 and newer
