What Find My AEP does

Find My AEP is a small After Effects plugin from Mograph Mindset that opens the folder holding your project file. Hunting for where a project was saved is a frequent annoyance, especially across drives and synced folders, and this makes it one click.

It runs on Windows and macOS and works with cloud storage such as Google Drive and Dropbox. Apple Silicon is supported from version 2.3, KBar integration has been available since version 1.1, and the interface supports international languages.

Key features

  • Jumps to the project file in Finder or Explorer
  • Works on Windows and macOS
  • Handles Google Drive and Dropbox locations
  • Apple Silicon and KBar support
  • International language support
