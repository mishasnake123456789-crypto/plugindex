What SolariText does

SolariText by NickolasM turns a selected text layer into an animated 3D split-flap display, the clacking board seen in old airports and train stations. Version 3.0 added a fixed-rig engine, wall grid mode and baked render copies.

Wall mode builds display walls, with optional empty filler cards. Animation can start simultaneously, sequentially or randomly, with seed and lock seed controls for repeatable patterns. Fast Preview mode and a full 3D workflow let cameras, lights and shadows interact. A baked copy keeps the editable setup intact, and the fixed rig makes boards lighter and more scalable.

Key features

  • Animated 3D split-flap boards from text
  • Airport/Wall Grid Mode with filler cards
  • Simultaneous, Sequential and Random starts
  • Seed controls for repeatable patterns
  • Baked render copies
