What Quick Menu 3 does

Quick Menu 3 by Edgar Huanca is a launcher that lets After Effects users find and apply nearly anything by typing. It searches effects and plugins, presets, scripts, extensions, menu commands, shape layer filters and expressions from one panel.

The panel opens with a shortcut of your choice and uses no screen space when hidden. A new search engine finds items from a few letters, with recent, favorite, static and custom command groups. Installed extensions are detected automatically. Effects can be applied to a new solid, adjustment, null, shape or text layer, or to all layers sharing a label color, and expression controls can be created.

Key features

  • Search effects, scripts, presets and commands
  • Opens with a custom shortcut, no UI footprint
  • Recent, favorite and custom command groups
  • Auto-detects installed extensions
  • Apply effects to new layers or label-color groups
