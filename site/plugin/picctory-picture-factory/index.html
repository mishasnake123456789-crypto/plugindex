What Picctory - Picture Factory does

Picctory builds framed wall pictures that can show any image. You can search AI-generated artwork through a Stable Diffusion prompt search on lexica.art or pick a file from your own computer.

The frame moulding profile is shaped by editing a curve, and frame color is adjustable. A passepartout with its own size and color is available, as is a glass pane in front of the picture that can be hidden in the viewport yet still show in renders. Frame and picture sizes are adjustable, making it useful for interiors and architectural visualization.

Key features

  • Image search or local image selection
  • Curve-based frame moulding
  • Passepartout with size and color
  • Glass pane hideable in viewport
  • Adjustable frame and picture sizes
