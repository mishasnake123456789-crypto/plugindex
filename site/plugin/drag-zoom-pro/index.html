What Drag Zoom Pro does

Drag Zoom Pro makes punch-in zooms a matter of dragging a rectangle. Draw a box around the area of the frame you want to magnify, and the tool sets up the move for you in After Effects or Premiere Pro.

Keyframes are created automatically, rotation can be manipulated, and the resulting keyframes get Bezier easing for smooth motion. A Portuguese interface is included. It is useful for tutorials, screen recordings and any edit where you want to direct the viewer's eye to a detail.

Key features

  • Draw a box to define the zoom
  • Automatic keyframing
  • Rotation control
  • Bezier easing on keyframes
  • Portuguese language support
