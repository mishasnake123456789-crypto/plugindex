What Point Animate By Kiri Engine does

Point Animate by KIRI Engine converts static 3D models into point cloud animations. It works with mesh and point cloud objects without conversion.

Animations can be added in fewer than five clicks from quick presets, and modifiers can be driven by attributes, masked by objects and stacked. Bake functions lock in results. Great for scan reveals and particle-like transitions. Highlights cover animations in under five clicks and stackable modifiers driven by attributes.

Key features

  • Animations in under five clicks
  • Stackable modifiers driven by attributes
  • Object masking
