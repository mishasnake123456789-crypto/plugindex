Blender add-on that builds radial and circular arrays in one click with the modifier, helpers and drivers set up.

What Circular Array does

Circular Array saves time on a common modeling setup in Blender. Normally a radial array requires an Array modifier, a helper object and drivers; this add-on creates all of them in a single click.

It also manages the dependencies and hierarchy in the background so the arrangement stays tidy and easy to edit. Documentation is included, the license is GPL, and the code is also available on GitHub from WiresoulStudio.

Key features

  • One-click radial and circular arrays
  • Builds Array modifier, helpers and drivers
  • Handles dependencies and hierarchy
  • Documentation included
  • GPL licensed
