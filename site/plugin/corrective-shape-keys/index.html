What Corrective Shape Keys does

Corrective Shape Keys builds a corrective shape key that fixes deformation in the pose currently held by a rig. It was previously bundled with Blender 4.1 and is now distributed as a separate extension under limited support.

The command is reachable from Object Data, under Shape Keys Specials, or through Blender's Search. It is a tiny download of about 4.7 KB, needs no special permissions, and supports Blender 4.2 LTS and newer. Character riggers fixing joint collapses at elbows or shoulders can use it to capture the correction quickly.

Key features

  • Creates a corrective key for the current pose
  • Found in Shape Keys Specials or Search
  • Tiny 4.7 KB download
  • Supports Blender 4.2 LTS and newer
