What Strokes Font Family does

Strokes Font Family by Highground supplies four capital-letter typefaces that imitate fast strokes from a broad paint brush or chisel-tip marker. They are intended for titles and lettering in After Effects and Premiere Pro that need a street-art character.

The set contains Strokes, Strokes Wide, Strokes Rough and Strokes Sharp. The main style carries heavy spatter and is tuned for speed, Wide adds detail and sharpness, Rough looks like dry brush, and Sharp ends its strokes in tapered streaks. Each has roughly 250 glyphs, including basic multilingual support, numbers, punctuation and symbols, built with few paths so large sizes still look realistic.

Key features

  • Four styles: Strokes, Wide, Rough and Sharp
  • About 250 glyphs per style
  • Basic multilingual, number and symbol support
  • Low path count stays realistic at large sizes
