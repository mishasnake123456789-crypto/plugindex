What Swift Pie Menu V.2.0.3 (Beta) does

3D CADence's Swift Pie Menu centralizes access to functions, properties and scripts in Blender through pie menus, popup panels and vertical menus that you design yourself.

A pie can have up to 18 blocks, each with one to ten action buttons and individual visibility, labels, icons and color coding. Buttons can run any bpy.ops operator, drive animatable properties by data path, show standard Blender panels in a popup, or launch external scripts. Power users can tailor the interface to their workflow.

Key features

  • Pie menus, popups and vertical menus
  • Up to 18 blocks with 1 to 10 buttons each
  • Execute any bpy.ops operator
  • Control properties by data path
  • Per-block icons, labels and colors
