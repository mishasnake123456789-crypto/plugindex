What Batch Render Pro does

Batch Render Pro automates pass saving and batch jobs in Blender. Press F12 and it writes the beauty render plus every enabled pass without any compositor setup.

Passes include Depth, Normal, Position, Mist, Diffuse and Glossy. You can choose which cameras to render from one button, with each camera saving into its own subfolder. It can also point at a folder of model files, reload each one and render it in turn. Good for turntables and asset catalogs.

Key features

  • F12 saves beauty and all enabled passes
  • No compositor setup required
  • Multi-camera batch rendering into subfolders
  • Batch model reload and render
  • Depth, Normal, Position, Mist, Diffuse and more
