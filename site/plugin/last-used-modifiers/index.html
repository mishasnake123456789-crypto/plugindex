Blender add-on that surfaces your most recently used modifiers right in the Add Modifier menu.

What Last Used Modifiers does

Digging through submenus to add the same few modifiers again and again gets old. Jishnu Jithu's Last Used Modifiers puts your recent picks directly in the Add Modifier menu, updating its button once you have added something.

How many recent items appear is adjustable from the options menu in the properties panel. If you miss the classic menu with its type-to-search field, it can be restored, and you can use the old menu, the new one or both side by side. Modelers who stack the same toolkit constantly benefit most.

Key features

  • Recent modifiers shown in the menu
  • Configurable number of items
  • Optional old menu with type-to-search
  • Switch between old, new or both menus
  • Button updates after each use
