What Shape Shifters does

Shape Shifters, by Motion by Nick, is a deliberately frivolous plugin: a designers' virtual pet that burns time instead of saving it. It runs in After Effects 2025 and Premiere Pro 2025, along with Illustrator 2025 and Photoshop 2021.

The pet levels up as you look after it, up to a maximum, and progress is kept in a save file. Neglect it and it can die. A tongue-in-cheek Unlimited PTO perk can be unlocked. It is meant for creatives who want a companion sitting beside their work, not a production tool.

Key features

  • Virtual pet inside Adobe apps
  • Pet levels up to a set maximum
  • Progress stored in a save file
  • Pet can die if neglected
  • Unlockable Unlimited PTO perk
