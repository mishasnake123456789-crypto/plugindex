Syncs colors, vectors and textures from a template material across many Blender materials at once.

What Materialsync does

MaterialSync saves the effort of editing a family of materials one by one. Choose a base material as the template, select an edit mode, and its settings are pushed to your target materials.

The three modes work with node groups, node names or custom parameters, and image textures can be loaded, replaced and tweaked. Smart targeting detects the nodes to change automatically. Artists maintaining variations of a look, such as a set of colorways, can update everything together.

Key features

  • Template material synced to many targets
  • Edit modes: Node Groups, Node Names, Custom Parameters
  • Image texture loading and replacement
  • Smart target detection
  • Syncs colors, vectors and textures
