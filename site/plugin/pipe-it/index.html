What Pipe It does

Pipe It is a Blender plugin from Blender Bits for creating pipes procedurally. Built on Geometry Nodes, it targets industrial and pipeline scenes where lots of piping is needed.

It renders with Cycles and Eevee, works with Blender 4.0 through 5.0 and is available as a Blender Extension released under the GPL license. Documentation is included. Useful for refineries, factories and sci-fi corridors. Because everything is procedural, routes and sizes can be revised later, which is far faster than modeling and bending each section by hand.

Key features

  • Procedural pipes with Geometry Nodes
  • Cycles and Eevee compatible
  • Blender 4.0 through 5.0
  • GPL licensed extension
