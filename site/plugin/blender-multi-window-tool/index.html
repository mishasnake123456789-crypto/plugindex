What Blender Multi-Window Tool does

Blender Multi-Window Tool makes working across several monitors or floating panels easier. In one click it opens an individual editor in its own popup window, so you do not have to rearrange your workspace layout.

Hotkeys can be assigned to launch windows quickly, and the window size is adjustable when opening one. Support covers many editors, including the 3D Viewport, node editors and Video Sequencer. It is reached from the Topbar under Window, then Layouts, works on Windows and Linux and is released under the GPL. Artists with multi-monitor setups will benefit.

Key features

  • One-click popup windows per editor
  • Assignable hotkeys
  • Adjustable window size on open
  • Works for the 3D Viewport, node editors and VSE
  • Windows and Linux
