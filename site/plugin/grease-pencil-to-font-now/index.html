Converts Blender Grease Pencil handwriting into TrueType fonts you can export with one click.

What Grease Pencil To Font - Now does

This utility turns Grease Pencil strokes into a working TrueType font. Pick the Unicode characters you need, write each one in Blender, and export a TTF file in one click.

Any Unicode character is supported, including emojis. A character component system, with an included table of Chinese radicals that also helps with Japanese, and linked component data, speeds up building large character sets. Five charsets come included. It suits designers creating custom handwriting or CJK fonts.

Key features

  • One-click TTF export
  • Unicode support including emojis
  • Character component system with Chinese radicals
  • Five included charsets
