What Dynamic Shapekeys does

Dynamic Shapekeys is a Blender plugin for quickly animating with shape keys. It works in Edit and Sculpt Mode, in either relative or sequential mode.

Keyframes can be placed on the current frame or arranged in groups of dozens, bounding groups of vertices can be set, and key minimum and maximum values can be changed. It cuts down the manual setup for morph animation. It speeds up creating morph targets and expression animations, which is useful for characters and motion design alike.

Key features

  • Edit and Sculpt Mode support
  • Relative and sequential modes
  • Flexible keyframe placement
  • Bounding vertex groups
