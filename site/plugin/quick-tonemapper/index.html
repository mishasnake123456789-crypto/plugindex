What Quick ToneMapper does

Quick ToneMapper, from PixelGym, is made for compositors working with unclamped CG output. It compresses bright values so blown highlights come back and adds contrast to flat renders.

It expects 32-bit or 16-bit float files in a project set to 32 bits per channel. A plugin setting can disable linearization, avoiding double linearization when the Linearize working space option is enabled. It is a free option for compositors who want a fast first pass before further grading of their render passes.

Key features

  • Tone maps CG renders
  • Recovers overblown highlights
  • Adds contrast
  • Works with 32-bit or 16-bit float files
  • Option to avoid double linearization
