Blender add-on that cleans up animation channels with no animation data, while keeping FCurves with modifiers like Noise.

What Remove Static FCurves does

Remove Static FCurves clears out animation channels that hold no real animation. It is by lokimckay and is run from the Graph Editor via Blender's search.

Version 0.4.0 preserves FCurves that have modifiers like Noise, even if they hold no keyframes. Animators importing mocap or baked data can strip clutter and keep dope sheets and graph editors manageable. Removing empty channels keeps editors smaller and easier to navigate, particularly on files with many animated objects.

Key features

  • Cleans channels without animation data
  • Keeps FCurves with modifiers (v0.4.0)
  • Run from Graph Editor search
  • Reduces animation clutter
