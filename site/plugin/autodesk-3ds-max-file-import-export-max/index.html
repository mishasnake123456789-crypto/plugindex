What Autodesk 3Ds Max File Import-Export (.Max) does

This add-on moves native 3ds Max files in and out of Blender, bridging two applications that otherwise rely on intermediate formats. Models, materials, animations and scene hierarchy can pass in both directions, reducing the loss that comes with repeated conversions.

Imports are selective, covering models, lights, cameras, splines, animations, materials and armatures. Coordinate adjustments include an optional 180 degree X-axis rotation and a 0.01x scale conversion so units match. Exports can be filtered by object type. Studios and freelancers who exchange assets with 3ds Max users will find it convenient.

Key features

  • Imports .max files into Blender
  • Exports Blender scenes to .max
  • Selective import of models, lights, cameras and rigs
  • Coordinate and scale conversion
  • Export filtering by object type
