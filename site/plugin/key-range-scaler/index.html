Scales a range of keyframes from its start or end in Blender while keeping the other end fixed.

What Key Range Scaler does

Key Range Scaler retimes a block of keyframes without moving the current frame. Scaling can happen from the start or from the end of the range, and the opposite end stays locked in place.

Modifier keys fine-tune the behavior: Alt snaps the range end to the cursor, Ctrl snaps to exact frames and Shift slows scaling for finer control. Bezier handles are scaled at the same time so curves keep their shape. Animators adjusting timing of shots will find this faster than dragging keys manually.

Key features

  • Scales from range start or end
  • Opposite end stays fixed
  • Alt, Ctrl and Shift modifiers for snapping and precision
  • Scales Bezier handles too
