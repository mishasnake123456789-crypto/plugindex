What Smart Flow does

Smart Flow collects utilities for placing, aligning, duplicating and sorting objects in Blender. Eight tools are included, among them Smart Origin, Smart Transform, a Universal Manipulator and a Collection Batcher.

Smart Origin sets an object's origin to any component in one click, with held keys adding control over position and orientation. Smart Transform changes position, rotation or scale while the origin stays put, and ordinary Blender navigation still works. The Universal Manipulator offers a Maya-style approach. Layout artists and modelers will find placement tasks faster.

Key features

  • Smart Origin snaps origins to any component
  • Smart Transform preserves the origin
  • Universal Manipulator
  • Collection Batcher
  • Eight tools in total
