Links an empty with an object's origin so that origin can be moved, snapped or animated with ordinary Blender tools.

What Flexorigin does

Flexorigin links an empty with an object's origin, and moving the empty shifts the origin. That lets you reposition it with the usual transform tools instead of special operators.

You can move the origin with G or the manipulator, snapping options include volume, face, edge, vertex or increment, and rotate the same empty to control local orientation. It's useful for precise pivots and animation. Because the empty uses normal transform tools, there is no new interface to learn, which makes pivot setup comfortable and precise.

Key features

  • Origin coupled to an empty
  • Snapping to volume, face, edge or vertex
  • Control local orientation by rotating
  • Animate the origin
