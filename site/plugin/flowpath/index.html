What FlowPath does

FlowPath from Pixalogic animates layers along motion paths using expressions, so nothing has to be baked into keyframes. A single 0 to 100 slider drives the movement along a native mask path.

It supports one layer following several paths, multiple layers moving in sync, and live switching between paths. Motion types include looping, ping-pong and roundtrip, with offset, reverse and an Auto Orient toggle available. Because everything is procedural and real-time, animators can adjust routes and timing at any point without rebuilding the setup.

Key features

  • Single 0-100 slider drives motion
  • Animates along mask paths without baking
  • Multi-path and synced multi-layer setups
  • Looping, ping-pong and roundtrip motion
  • Offset, reverse and Auto Orient toggle
