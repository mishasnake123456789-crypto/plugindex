What Renderingtools - Retain Previous Render does

RenderingTools by Recta3D streamlines render management from the 3D view. A pie menu lets you pick any camera in the scene and send renders to a chosen slot.

When you use a render border, the previous render image is retained rather than replaced, and the border can be displayed in the Image Editor. You can also set a local camera for a 3D view area. The pie menu also indicates which camera is active and whether a given RT_Slot already contains a render. Look-development artists iterating on regions benefit most.

Key features

  • Retains previous render with a render border
  • Render border shown in the Image Editor
  • Pie menu to switch to any camera
  • Local camera per 3D view area
  • Render to any slot
