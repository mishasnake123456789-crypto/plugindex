Stores Blender subdivision levels as linked layers so sculpting on any level updates the others.

What Retopo Linked Subdivision does

Retopo Linked Subdivision keeps subdivision levels as linked layers instead of applying them to the mesh. The original object stays untouched while the levels sit above it.

Sculpting on any level propagates changes to higher and lower levels in real time, and each level keeps its own poly count. Levels adapt to the highest subdivision shape. Retopology and sculpting artists get a non-destructive way to refine across levels. Highlights cover original object stays intact and sculpting propagates across levels.

Key features

  • Original object stays intact
  • Sculpting propagates across levels
  • Each level keeps its poly count
  • Levels adapt to the highest shape
