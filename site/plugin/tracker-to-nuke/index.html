What Tracker to Nuke does

Tracker to Nuke, by K_Naoki, bridges Blender's Movie Clip Editor and Foundry's Nuke. It moves 2D tracking data across through the clipboard, so you can paste it straight into a Nuke Tracker node.

You can send all trackers, only the selected ones, pattern corners or plane tracks. Lens distortion transfers as well, using Nuke's default model with K1 and K2, plus the anamorphic P1 and P2 coefficients on Blender 5.1 and later. When pasting parameters, Blender's distortion model switches to Nuke automatically. Controls sit in the Track tab sidebar and the header.

Key features

  • Copies 2D tracks to a Nuke Tracker node via clipboard
  • Exports all, selected, pattern corners or plane tracks
  • Transfers lens distortion K1 and K2
  • Anamorphic P1 and P2 support on Blender 5.1+
  • Switches Blender's distortion model to Nuke on paste
