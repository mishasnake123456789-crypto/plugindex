What Open In does

Open In is a small Blender add-on by Jishnu Jithu for people who keep several Blender versions installed. It adds an entry to the File menu that reopens your current scene in a different release.

Installed versions are detected automatically on Windows, with experimental detection on macOS and Linux, and you can register extra executables by path. If the project has never been saved, it is stored temporarily before the switch, and the original file is left untouched. It is handy for testing compatibility, checking regressions between releases or finishing a job in a specific build.

Key features

  • Detects installed Blender versions automatically
  • One-click reopen from File > Open In
  • Temporary save for unsaved projects
  • Original file stays unmodified
  • Add custom Blender executables manually
