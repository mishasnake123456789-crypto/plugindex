What Cgal Boolean does

CGAL Boolean brings the CGAL library's boolean operations to Blender. Union, Difference and Intersection are available through an editable stack of result layers.

Layers reference objects or collections and can be added, removed, reordered, enabled or disabled. Multiple cutters can be added at once, and a Live Update preview rebuilds as sources change. Self Union cleans disconnected components inside a single mesh. It suits hard-surface modelers who need robust booleans.

Key features

  • CGAL Union, Difference and Intersection
  • Editable result layer stack
  • Multi-cutter workflows
  • Live Update preview
  • Self Union for disconnected components
