Pastes clipboard images, vectors and files into After Effects without a save-and-import routine.

What JustPaste does

JustPaste shortens the path from copied asset to After Effects layer. Copy an image or vector from a browser, Illustrator, Photoshop, Figma or nearly any app, press Ctrl or Cmd + V, and it lands in your composition. Auto mode picks a suitable file format, and SVGs become editable shape layers.

Files are saved beside the project, optionally in a custom folder, using file-name templates. You decide layer placement, timing, and what happens if a name already exists. Animated GIFs from the web keep their animation, and Finder or Explorer files, including MOV, MP4, WAV and MP3, can be pasted in bulk.

Key features

  • Paste from the clipboard straight into a comp
  • Auto format choice; SVGs become shape layers
  • Animated GIFs paste with full animation
  • Saves beside the project with naming templates
  • Control placement, timing and duplicate handling
