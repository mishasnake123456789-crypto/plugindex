What Squash & Stretch Pro does

Squash & Stretch Pro from mamoworld tools is an animation assistant for After Effects that writes keyframes for you based on chosen behaviors. The results stay editable, so you can tweak timing afterward instead of building every move by hand.

The Pro version unlocks the whole library of behaviors and adds advanced text options for motion design. It works across After Effects versions from CC 2015 up to 2026. Motion designers looking to avoid repetitive keyframing can use it to get lively, elastic movement quickly.

Key features

  • Generates editable keyframes from behaviors
  • Full behavior library in the Pro version
  • Advanced text options
  • Works from CC 2015 through 2026
