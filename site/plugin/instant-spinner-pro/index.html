What Instant Spinner Pro does

KING ZEN STUDIOS' Instant Spinner Pro creates rotating animations on 3D meshes without keyframing by hand. Choose how many full turns to make, over how many frames, and around which axis.

One rotation or many is fine, and X, Y or Z can be the axis. Linear interpolation keeps speed constant so loops are smooth. Product turntables, logos and icons are the obvious uses. The settings can be changed afterward, so tempo and direction are easy to revise for a client.

Key features

  • Set number of full 360-degree rotations
  • Total frame count control
  • X, Y or Z axis selection
  • Linear interpolation for constant speed
  • Automatic keyframes
