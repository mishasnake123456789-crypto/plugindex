An AI green screen keyer based on Corridor Digital's CorridorKey, running in After Effects, Resolve and Premiere Pro.

What CorridorKey does

CorridorKey packages Corridor Digital's keying model as a plugin so it can be used directly in After Effects, DaVinci Resolve and Premiere Pro, with Nuke also supported. It aims to make pulling a clean key from footage far less of a manual chore.

To handle large frames, it can process the image in 256x256 tiles, which raises the effective resolution while lowering memory use. Auto Crop limits calculations to the area around the mask, skipping empty transparent regions, and an optional QuickMatte input lets you supply your own alpha hint. Version 1.3.0 added a roughly 30 percent speed gain.

Key features

  • Tiling mode with 256x256 tiles to save memory
  • Auto Crop around the mask bounding box
  • Optional QuickMatte input for a custom alpha hint
  • Works across After Effects, Resolve, Premiere Pro and Nuke
  • About 30% faster in version 1.3.0
