What Baker: Gpu Lightmapper does

Baker: GPU Lightmapper is a Blender add-on that handles the whole lightmap pipeline in one place, for game developers, 3D artists and architects. It replaces a chain of manual steps with a single N-panel workflow.

It generates UVs, packs them into a shared atlas and bakes with GPU Cycles in Full GI, Indirect Only, Ambient Occlusion or Emissive modes. Denoising uses OptiX on NVIDIA cards with an OIDN fallback elsewhere. Extras include directional lightmaps, LOD UV propagation, light probe baking exported as JSON, VRAM estimates, and PNG or EXR output. Material and render settings are restored after every bake.

Key features

  • Automatic UV atlas generation and packing
  • GPU Cycles baking in four bake modes
  • OptiX denoising with OIDN fallback
  • PNG and EXR export, light probes as JSON
