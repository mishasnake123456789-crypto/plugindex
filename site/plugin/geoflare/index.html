A Blender geometry nodes object that creates real-time lens flares, streaks, dirt and glow with occlusion.

What Geoflare does

Geoflare produces lens effects directly in the Blender viewport using geometry nodes. It is added as an X_Geoflare object with a geometry nodes modifier and covers flares, streaks, camera dirt and glow, working in both Eevee and Cycles.

Objects in the scene can occlude the source light, lens dirt is widely customizable, and presets are available through the asset browser. General parameters include global power, flicker, field and render distance, with per-element color controls. Motion designers and renderers wanting photographic lens artifacts without compositing will find it responsive.

Key features

  • Real-time flares, streaks, dirt and glow
  • Object occlusion of the source light
  • Customizable lens dirt
  • Asset browser presets
  • Eevee and Cycles compatible
