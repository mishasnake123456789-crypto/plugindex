A visual grid layout designer for After Effects that exports layouts as shape layers, solids, masks or comps.

What Grid Composer does

Grid Composer lets motion designers sketch layouts visually inside After Effects. Grid, split, random and custom layouts are edited by drag and drop with a live preview.

The custom builder sets rows, columns and per-cell sizes, a random generator provides several styles, and blocks can be split horizontally, vertically or into sub-grids. Snap to Blocks and alignment guides help placement. Five export modes give compositions, shape layers, solids, masks on a solid, or comps with an alpha matte, and built-in IN and OUT animations come in multiple styles, orders and easings. Ideal for bento layouts, collages and multi-panel designs.

Key features

  • Visual layout designer with live preview
  • Custom grid builder and random generator
  • Split blocks horizontally, vertically or with sub-grids
  • Five export modes
  • Built-in IN/OUT animations
