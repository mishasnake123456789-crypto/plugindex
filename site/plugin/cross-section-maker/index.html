Blender add-on that slices a mesh with a cut plane and projects the section flat so it exports cleanly to DXF for CAD.

What Cross Section Maker does

Cross Section Maker, by Tiemen's addons, extracts outline sections from meshes. A cross-section is produced where the cut plane sits; the plane is created fresh in Object mode or copied in Edit mode.

The section can be projected onto the XY plane so it can be exported as a clean DXF for CAD programs. Engineers, architects and fabricators who need 2D profiles from 3D models can obtain them without leaving Blender.

Key features

  • Section generated at the cut plane
  • Cut plane creation in Object and Edit modes
  • Projection to the XY plane
  • Clean DXF export for CAD
