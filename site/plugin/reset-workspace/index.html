What Reset Workspace does

Reset Workspace, by Trukas, puts Blender's interface back to its default startup layout after you have rearranged it. Choose Window, Reset Workspace and the current file is reloaded with the startup file's UI.

Internally it loads the startup file's UI and then reopens your current file with Load UI unchecked. It requires Blender 4.2 LTS or newer, needs no special permissions, and installs by drag and drop or from disk.

Key features

  • Resets the UI to the startup layout
  • Window, Reset Workspace menu entry
  • Reopens the file without loading its UI
  • Blender 4.2 LTS and newer
  • Drag-and-drop installation
