What Hyper Shot: State Manager & Batch Render Addon does

Hyper Shot stores visibility, cameras and overrides as isolated Shots. Each one captures a complete scene state, so you can flip between presentations of the same file instantly.

Because the setups are saved, complex scenes can be batch rendered without manually changing anything between frames or views. It works with both Cycles and Eevee. Product visualization artists, architects and anyone producing multiple angles or variants from one scene will cut repetitive switching.

Key features

  • Shots store visibility, cameras and overrides
  • Instant switching between setups
  • Batch rendering of saved shots
  • Cycles and Eevee support
