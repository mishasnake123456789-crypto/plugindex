What R3F JSX/TSX Exporter does

R3F JSX/TSX Exporter, by Tom-Heeley, speeds up getting Blender models into React Three Fiber projects. A single click writes the .glb file and a component that matches it to project folders you choose.

The output can be JSX or TSX, and the TypeScript variant adds a typed GLTFResult describing precisely the nodes and materials the component references. Front-end developers working with 3D on the web avoid running a separate conversion tool after every change.

Key features

  • One-click GLB and component export
  • JSX or TSX output
  • Typed GLTFResult for TypeScript
  • Writes to project folders you choose
