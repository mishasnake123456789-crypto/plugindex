3ds Max plugin that builds a runnable menu from any folder of MaxScripts, sorted into macroScripts, plugins and utilities.

What Script Box does

Script Box from DMZScripts creates a dynamic menu for any folder of MaxScript files in 3ds Max, so downloaded scripts can be run without a complex installation. Loading is multi-threaded and can include subfolders, and scripts are sorted into macroScripts, plugins, utilities and plain scripts.

Each macroScript, plugin and utility gets its own button, with extended tooltips giving type, file name and parameters. Dialogs are dockable, resizable and minimizable, with one per folder structure. It also ties into 3ds Max by launching at startup, helping create and archive MaxScripts, opening scripts in the editor and jumping to folders in Explorer. Releases from 2021 to 2025 are covered, along with .ms, .mse and .mcr script files.

Key features

  • Dynamic menu from any selected script folder
  • Multi-threaded loading with optional subfolders
  • Grouped by macroScript, plugin, utility and regular scripts
  • Extended tooltips with type, file name and parameters
  • Supports .ms, .mse and .mcr in 3ds Max 2021 to 2025
