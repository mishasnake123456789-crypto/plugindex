What Objdata Batch Renamer does

Objdata Batch Renamer covers a gap in Blender's built-in renaming: data types that the standard batch rename does not touch. Vertex groups, UV maps, vertex colors, shape keys, attributes, grease pencil layers and bone collections can all be renamed together in bulk, and a Bones mode handles armatures.

Four rename types are available: New, Replace, Prefix and Suffix. Search strings accept regular expressions with optional case sensitivity, and captured groups can be reused in the replacement with \1, \2 and so on. A preview shows the matches and processed text before anything is applied, which makes cleanup of imported assets safer.

Key features

  • New, Replace, Prefix and Suffix rename types
  • Regular expressions with reusable capture groups
  • Preview before executing
  • Handles vertex groups, shape keys, attributes and more
  • Dedicated bones mode
