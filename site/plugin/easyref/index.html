What Easyref does

Easyref is a Blender add-on from Pitiwazou for working with image references inside your projects. It saves a trip to a separate viewer by putting references where you model, sculpt or paint.

It supports Blender versions 2.9 through 5.1, is released under the GPL license, and includes documentation and a demo video.

Key features

  • Image references inside Blender projects
  • Blender 2.9 through 5.1
  • Documentation provided
  • Demo video available
  • GPL license
