Blender add-on that writes mask images into the vertex-color alpha of models, one at a time or in batches.

What MaskToVertexColorPro does

MaskToVertexColorPro transfers black-and-white or alpha-channel mask images onto the vertex color alpha of 3D models in Blender. It suits game development and rendering pipelines that need mask data stored on the mesh.

Masks can be read from alpha, grayscale or the RGB channels. Objects are processed one at a time or in batches, with UV coordinate repair and validation, several processing options and blend modes. The interface offers Simplified Chinese, Traditional Chinese for Blender below 4.0, and English.

Key features

  • Mask images to vertex color alpha
  • Alpha, grayscale and RGB sources
  • Single object and batch processing
  • UV repair and validation
  • Chinese and English interface
