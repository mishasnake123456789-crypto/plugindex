Blender add-on with a header folder button that opens the blend's folder, plus a menu of other blend files in the same directory.

What Path Actions does

Path Actions makes working with file locations relative to the current blend easier in Blender. A header folder button opens the folder holding the blend in your system's file browser.

Ctrl, Shift, Alt and Ctrl+Alt clicks trigger further actions, and a side Blend menu shows the other blend files sharing that folder so you can open them in place. Useful for project organization and versioned files. Quickly opening folders and neighboring files reduces time spent navigating the file system, and it fits workflows with many versions of a scene.

Key features

  • Header button opens the blend's folder
  • Modifier-click extra actions
  • Menu of blend files in the folder
  • Open files in place
