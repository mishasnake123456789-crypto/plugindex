What Molecule Library Add On does

Conceptualized.tech's Molecule Library Add On offers ready-made molecular models for Blender. At present there are 83, ranging from simple hydrogen to elaborate compounds like morphine and adrenaline.

Four looks are offered, split as 25 ball and stick, 25 volumetric, 15 chemistry set and 18 grease pencil models. Ball and stick draws atoms as spheres joined by rods, volumetric shows an electronic cloud, and chemistry set mimics plastic classroom kits. Teachers and science communicators can drop accurate molecules into animations.

Key features

  • 83 molecule models
  • Ball and stick, volumetric, chemistry set and grease pencil styles
  • From hydrogen to morphine
  • Spheres and rods or electron cloud views
  • Ready to use in scenes
