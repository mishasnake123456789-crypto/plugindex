Blender extension that exports Movie Clip Editor lens distortion as STMap images for Nuke, Fusion or Natron.

What STMap Exporter does

STMap Exporter takes the lens distortion solved in Blender's Movie Clip Editor and turns it into STMap images that external compositors can use. Both Undistort and Redistort maps can be exported, along with optional grayscale checkerboard guide images that illustrate the distortion.

Blender's Polynomial and Division models, as well as Nuke and Brown-Conrady, are computed into 32-bit maps. Compositors can apply the same lens correction in Nuke, Fusion or Natron that they tracked in Blender.

Key features

  • Undistort and Redistort STMap export
  • Optional checkerboard guide images
  • Polynomial, Division, Nuke and Brown-Conrady models
  • 32-bit output for Nuke, Fusion and Natron
