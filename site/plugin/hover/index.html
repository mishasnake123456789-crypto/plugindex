After Effects tool that automates cursor icons, click animations, hover pointer hands and grab states.

What Hover does

Hover by Breton Brander automates interface cursor animation in After Effects. It builds a cursor icon, produces click animations that can be retimed by dragging a single layer, and switches the cursor to a pointer hand whenever it passes over a button.

Layers can be grabbed and released while the cursor becomes a grabbing hand, and button brightness updates automatically on hover at an adjustable level. Changing the cursor icon only requires editing the cursor precomp. Motion designers creating app demos and UI walkthroughs benefit most.

Key features

  • Creates a cursor icon
  • Retimable click animations
  • Auto pointer hand over buttons
  • Grab and release layers with a grabbing hand
  • Automatic hover brightness
