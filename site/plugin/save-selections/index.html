Stores and recalls vertex, edge, face, object and armature selections in Blender with one click.

What Save Selections does

Save Selections keeps selections you will need again. VEF mode stores vertex, edge and face selections, and object sets hold multiple objects together; version 1.1 added an armature category for rigging selections.

Custom icons make saved selections easy to identify, and any of them can be recalled with a single click or renamed. It saves time on complex meshes where reselecting the same regions is tedious. Notable points: vertex, edge, face and object sets, armature selections and custom icons and renaming.

Key features

  • Vertex, edge, face and object sets
  • Armature selections
  • Custom icons and renaming
  • One-click recall
