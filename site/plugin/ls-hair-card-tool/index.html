What Ls Hair Card Tool does

Ls Hair Card Tool generates hair card geometry for real-time characters in Blender. It builds the cards from curves or meshes through geometry node modifiers, so everything stays non-destructive and can be revised, and it is compatible with Hair Chunk.

Three brush tools are included: a mobile brush, a property brush and a smooth brush. Mesh-based generation gives more modeling control than curves and can be used with sculpting mode. Cards can be remade, with adjustable horizontal and vertical segment counts. Game character artists who create hairstyles for engines will gain flexibility.

Key features

  • Non-destructive hair cards from curves or meshes
  • Mobile, property and smooth brushes
  • Mesh-based generation usable with sculpting
  • Adjustable segment counts
  • Hair Chunk compatible
