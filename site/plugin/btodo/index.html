Manages notes, todos and texts in Blender's text editor, with categories, tags and per-object notes.

What Btodo does

Btodo lets you keep notes and to-do lists inside Blender. Its interface is integrated into the properties panel of the text editor, so everything stays in one file.

You can create categories and notes within them, attach custom notes to any object in the scene, import an existing text data-block as a note and use tags to organize them. Handy for tracking tasks in larger projects. Keeping project notes next to the work helps with long-running scenes and collaboration, because reminders live with the file.

Key features

  • Categories and notes
  • Notes attached to scene objects
  • Tags assignable to notes
  • Uses existing text data-blocks
