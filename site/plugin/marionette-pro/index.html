What MARIONETTE Pro does

MARIONETTE Pro is the fuller version of 884tak's clip-positioning extension. It snaps clips within an area according to their size, horizontally or vertically, and places multiple selected items together while considering the Crop effect.

Alpha Crop and Smart Scaling are included, and AddKey and All Keyframe Control snap keyframed clips to a position or center without disturbing the motion. An input box accepts numeric values, and shortcut keys select panels.

Key features

  • Horizontal and Vertical Snap
  • Alpha Crop and Smart Scaling
  • Keyframe-safe snapping
  • Motion effect control for multiple selections
  • Numeric input box and shortcut keys
