What Check Mesh does

Check Mesh is a diagnostic overlay for Blender that flags topology issues while you model. It sits inside the native Overlays menu, so there is nothing separate to open.

It spots N-gons, triangles, non-manifold geometry, difficult poles, uneven faces, sharp edges, seams, plus intersecting or overlapping faces, with customizable highlight colors. Useful for keeping meshes clean for subdivision, animation and export. Seeing problems highlighted as you model avoids surprises later during subdivision, texturing, simulation and export.

Key features

  • Real-time topology monitoring
  • N-gons, poles and non-manifold detection
  • Intersecting and overlapping face detection
  • Customizable highlight colors
