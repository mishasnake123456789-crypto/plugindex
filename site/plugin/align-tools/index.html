What Align Tools does

Align Tools is a Blender extension that lines up the selected objects with the active one. It used to ship inside Blender 4.1 and is now offered separately with limited support.

It appears in the 3D Viewport sidebar under the Item tab and includes an advanced mode, which received a bugfix in version 0.3.6. It works with Blender 4.2 LTS and newer, needs no special permissions and is released under the GNU General Public License version 3 or later. Artists arranging models, props or kit pieces can use it for quick alignment.

Key features

  • Aligns selected objects to the active object
  • Found in the sidebar Item tab
  • Advanced mode included
  • Works with Blender 4.2 LTS and newer
