What Mike Udin Custom Buttons does

Mike Udin Custom Buttons lets artists assign Python scripts to buttons, folding repetitive sequences of operations into a single click. One button can contain as many presets as you like.

Buttons or shortcuts can create custom objects, tags, materials and layers, and icons can come from any loaded image, from Cinema 4D functions or from a rendered picture. This is aimed at users who want a personal toolbar tuned to their own habits, whether in modeling, lookdev or scene setup.

Key features

  • Python scripts assigned to custom buttons
  • One button can hold many presets
  • Buttons and shortcuts for objects, tags, materials, layers
  • Icons from images, C4D functions or renders
