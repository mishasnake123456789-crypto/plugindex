What Themify - Blender Theme Editor does

Themify moves theme editing into a well-organized sidebar in Blender. Instead of digging through Preferences, you change colors from the 3D Viewport.

General and Individual tabs cover global changes and specific interface elements using collapsible sections and color pickers, previews update in real time, and a theme can be exported as a preset or XML. Good for personalizing the interface. Having everything in one organized panel makes it far easier to experiment with colors and share looks with others.

Key features

  • Theme editor in the viewport sidebar
  • General and individual element tabs
  • Real-time preview
  • Export to presets or XML
