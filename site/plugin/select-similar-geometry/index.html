Select Similar Geometry

Developer: JuanRomero

FreeBlender
Download Free

Blender add-on that selects objects sharing a percentage of matching vertex positions with the active one.

What Select Similar Geometry does

Select Similar Geometry finds objects that resemble the active object, even when they are not exact duplicates. It measures what percentage of vertex positions match, so moved, scaled and slightly altered copies can be caught.

Tolerance and minimum similarity are adjustable, comparison can happen in world space, and differing location, rotation and scale are handled. Vertex count filtering skips unrelated objects, and a KD-tree generated a single time from the reference object speeds up large scenes. It was written by JuanRomero.

Key features

  • Selection by vertex match percentage
  • Adjustable tolerance and similarity threshold
  • Optional world space comparison
  • Handles different transforms
  • KD-tree for faster large scenes
