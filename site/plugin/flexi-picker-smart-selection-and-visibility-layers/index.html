What Flexi Picker - Smart Selection & Visibility Layers does

Flexi Picker gives animators a customizable picker interface in Blender, so rig controls can be selected without using the Outliner.

You can create and organize picker layouts, select bones quickly, control visibility of custom groups and mark groups for export. The interface is clean and the add-on is lightweight and stable. It works with any rig type, which makes it a flexible choice for characters, props and other animated objects.

Key features

  • Fast bone selection
  • Visibility control for custom groups
  • Create your own picker layouts
  • Mark groups for export
  • Works with any rig type
