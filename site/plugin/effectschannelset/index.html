Kstudio script for managing Material and Object IDs and automating render elements for V-Ray, Mental Ray and Corona.

What EffectsChannelSet does

EffectsChannelSet helps set up masks and ID passes in 3ds Max. It manages Material and Object IDs, assigns wirecolors to objects, and creates render elements automatically for V-Ray, Mental Ray and Corona.

Elements it can build include MultiMatteElement for V-Ray, MatteRenderElement for Mental Ray and CMasking_Mask for Corona. V-Ray users can also render a mask for selected objects by material, with RGB pass 1, RGB pass 2, RGBYCMW and Random modes, and IDs can be assigned to materials by material type. Compositors who need clean selection mattes will save time.

Key features

  • Manages Material and Object IDs
  • Assigns object wirecolors
  • Auto-creates MultiMatte, Matte and CMasking elements
  • Material masks with several V-Ray modes
  • IDs assigned by material type
