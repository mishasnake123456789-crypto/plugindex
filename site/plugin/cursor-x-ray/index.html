What Cursor X-Ray does

Cursor X-Ray is a small Blender add-on that reveals hidden geometry only where you point, instead of switching the whole viewport to X-Ray. It is useful in dense meshes, intricate rigs and crowded scenes.

The effect follows the cursor within an adjustable circular area, and the radius can be changed interactively with the mouse. Focus can be pinned on several mesh areas, it works for meshes and armatures, and it can be limited to selected objects. Colors can be custom or assigned per object, and a cache updates only changed objects to keep the viewport responsive.

Key features

  • Circular X-Ray area follows the cursor
  • Pin focus on several mesh regions
  • Supports meshes and armatures
  • Interactive radius adjustment in the viewport
