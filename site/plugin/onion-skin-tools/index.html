Blender add-on that adds onion skinning for objects in the viewport so animators can compare poses across frames.

What Onion Skin Tools does

Onion Skin Tools shows ghosted copies of objects at other frames in Blender's viewport. Animators can visualize motion without moving the timeline cursor and compare previous and later poses while posing the current frame.

It works for any mesh-able objects, including multi-object characters, on arbitrary frames or a chosen range, with rendering in Eevee and Cycles. Character Sets group objects through a scene-wide list or define them individually. Animators checking arcs and spacing gain a classic hand-drawn animation aid.

Key features

  • Object onion skinning in the viewport
  • Arbitrary frames or ranges
  • Eevee and Cycles viewport rendering
  • Character Sets for grouping objects
