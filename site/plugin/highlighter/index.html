What Highlighter does

Highlighter is a Blender add-on by pioverfour that converts code into colored 3D text in the viewport. Syntax is detected automatically, and if detection fails you can pick the style yourself.

Several highlighting styles are available, you can re-highlight existing text objects from the F3 menu or, in Edit mode, the Text menu, and default fonts can be set in the preferences. The coloring is done by the Pygments library. Educators and motion designers can use it for code-based titles and tutorials.

Key features

  • Converts code to colored 3D text
  • Automatic syntax detection with manual override
  • Multiple highlighting styles
  • Re-highlight existing text objects
  • Default fonts set in preferences
