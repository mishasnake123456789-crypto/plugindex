What Toggle Language does

Toggle Language swaps Blender's interface between two chosen languages with one click and a hotkey. It supports seventeen languages.

It also gives single-click access to the user preferences with hotkey support, single-click setup of personal Blender settings, and a switch for the hint mode. Multilingual users, translators and educators can flip the interface quickly. The extra one-click utilities cover common setup chores that people repeat whenever they install Blender on a new machine.

Key features

  • One-click UI language toggle
  • 17 languages with hotkey
  • One-click Preferences access
  • One-click personal settings setup
