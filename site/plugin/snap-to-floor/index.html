What Snap To Floor does

Snap To Floor is a Blender plugin from Pixel Egg Studio that holds an object on the ground. As you move or rotate it, the object stays snapped to the floor, including during animation, with real-time feedback.

A rolling-away behaviour is included, and you can align to the 3D cursor's height or apply snapping to every mesh in the scene. Documentation is included. It is useful for staging props and characters.

Key features

  • Stays on the floor when moved or rotated
  • Works while animating
  • Rolling-away behaviour
  • Snap to 3D cursor Z or all meshes
