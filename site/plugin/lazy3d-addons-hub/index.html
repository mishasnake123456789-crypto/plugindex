What 🔖Lazy3D Addons Hub does

Lazy3D Addons Hub helps users with many add-ons keep their N-Panel under control. It provides a single place to organize, pin and switch between tabs.

Tabs can be searched by name, module, description, version or tab. You can pin unlimited add-ons, assign any built-in Blender icon, make unlimited custom categories saved between sessions, and open the five most recently used ones in a click. It can sit in the Toolbar, a 3D View header button or a hotkey. Optional internet access shows product info and can be disabled.

Key features

  • Search and switch between N-Panel tabs
  • Pinned add-ons with custom icons
  • Custom categories and recent list
  • Toolbar, header button or hotkey access
