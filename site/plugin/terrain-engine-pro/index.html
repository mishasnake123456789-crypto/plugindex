Blender add-on that converts 2D curve boundaries into topographic terrain meshes with a live-updating preview.

What Terrain Engine Pro does

Terrain Engine Pro generates terrain surfaces in Blender from flat curves, such as contour lines or plot outlines. It uses Delaunay triangulation with IDW interpolation, giving an even distribution of polygons across the surface.

Once a terrain exists, editing the source curve updates the mesh live. Sidebar controls adjust grid spacing, relax force and edge stiffness, and the output arrives with smooth shading already applied, ready for textures, grass scattering or further modifiers. It is designed for architectural visualization, site planning and environment modeling, and works with Blender 4.0 and 5.0 in Cycles and Eevee.

Key features

  • Builds terrain from 2D curve boundaries in one click
  • Delaunay triangulation with IDW interpolation
  • Live preview that follows edits to the source curve
  • Grid spacing, relax force and edge stiffness controls
  • Output mesh already shade-smoothed
