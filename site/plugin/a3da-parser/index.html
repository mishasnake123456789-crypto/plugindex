What A3DA Parser does

A3DA Parser is a Blender plugin that reads and writes Auth3D files, the animation format used by the Project Diva rhythm games. It lets you bring scenes from those games into Blender, or send your own animation back out as text-based .a3da files.

Import covers camera motion with depth of field, object transforms and visibility, and texture transformations, with looping handled through F-Curve modifiers. A full PV import mode loads an entire song scene at once, and extra utilities help prepare models, adjust animation and convert assets for MMD. Skeletal and morph support is partial and needs some retargeting afterwards.

Key features

  • Import and export of text-format .a3da files
  • Full PV import that loads a whole song scene
  • Camera and object animation with visibility
  • Texture transforms with looping via F-Curve modifiers
  • Helper tools for MMD asset conversion
