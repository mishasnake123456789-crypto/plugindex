What Freezer does

Freezer is a macro for 3ds Max by Chuggnut that locks animation in place. It rewrites Chuggnut's earlier freeze anim tool as a macro that can go on a toolbar or a shortcut.

Space warp effects are covered as well, and a bomb is handled properly if the freeze begins on the detonation frame. This is useful for capturing a moment of an animated or simulated result and turning it into static geometry, for example a frame of an exploding object, which can then be modeled further or rendered.

Key features

  • Freezes animation within 3ds Max
  • Supports space warp effects
  • Delivered as a macro, rewritten from the earlier tool
  • Handles bomb effects starting on the detonation frame
