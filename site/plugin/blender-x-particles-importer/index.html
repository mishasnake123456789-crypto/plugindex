What Blender X-Particles Importer does

Blender X-Particles Importer lets artists who simulate in Cinema 4D finish their work in Blender. It reads particle data exported from X-Particles so the simulation can be rendered and animated in a different application.

Standard and generator emitters are supported through JSON or CSV files. You can import specific frames or ranges, offset playback, and adjust frame-step sampling for large simulations. A real-time preview shows particles in the viewport, position, scale and rotation can be controlled per particle, and it is optimized for high counts with low memory use.

Key features

  • Imports standard and generator emitters
  • JSON and CSV formats
  • Frame range, offset and sampling control
  • Real-time viewport preview
