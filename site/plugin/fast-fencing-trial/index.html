What FAST FENCING Trial does

FAST FENCING Trial creates architectural fences through a custom FA_Fence procedural object in 3ds Max. The object behaves like a native one: deformers can be applied, it renders and it converts to mesh.

The fence adapts to any 3D spline, with main poles at each knot and intermediate poles at every subdivision. Parameters update in real time, segments and poles can be selected and modified individually, and each part of the geometry has its own material ID, some with UV mapping and tiling. Distances can be multiplied to match scene units and parameters copied and pasted. A simple way to build urban background fencing.

Key features

  • Procedural FA_Fence object
  • Adapts to any 3D spline
  • Real-time parameter changes
  • Individually editable segments and poles
  • Per-part material IDs and UVs
