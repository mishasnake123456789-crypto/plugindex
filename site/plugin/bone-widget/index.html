Blender add-on for custom bone shapes, with a library of ready shapes you can edit and bone color management.

What Bone Widget does

Bone Widget helps riggers make custom bone shapes in Blender. A library of ready-made shapes is included, can be applied to any rig and can be extended with your own.

An Auto-Render option renders the object as a wireframe picture saved in the add-on's data folder, and a placeholder option applies a stand-in. Bone colors are managed as well. Riggers creating readable animator-facing controls will find it speeds up setup.

Key features

  • Editable shape library
  • Auto-Render wireframe thumbnails
  • Placeholder option
  • Bone color management
