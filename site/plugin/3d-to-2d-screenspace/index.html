What 3D to 2D ScreenSpace does

3D to 2D ScreenSpace is a Julian Herrera tool that converts a 3D position into a 2D screen location. Starting from a selected 3D layer, it creates an animated 2D null that sits where that point appears on screen.

The Link option ties the new null to the 3D point with an expression, while Bake turns that expression into keyframes immediately. This is handy for attaching 2D graphics, labels or effects to objects moving in 3D. The listed compatibility runs from After Effects CS3 to CS6.

Key features

  • Creates a 2D null from a 3D position
  • Link option uses an expression
  • Bake converts to keyframes
  • Works from a selected 3D layer
