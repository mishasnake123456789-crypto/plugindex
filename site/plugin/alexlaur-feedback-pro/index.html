What AlexLaur Feedback Pro does

AlexLaur Feedback Pro helps editors keep revision rounds organized without leaving Premiere Pro. Paste feedback from any text source and the panel detects the timecodes in it, turning each note into a link that jumps the playhead to the right spot.

Notes are stored in order so the history of a project stays intact, and they can be sorted however you like. A one-click version button duplicates the sequence with a date prefix and a V+1 suffix, both customizable. The panel can also move between sequences or projects and export the current sequence as a consolidated project.

Key features

  • One-click new sequence versions with date and V+1 naming
  • Auto-detects timecodes in pasted feedback
  • Jump to each note on the timeline
  • Sort and store all feedback in order
  • Consolidate the sequence as a project
