What Unreal Engine To Blender Batch Exporter does

This exporter, built by Kia Armani, brings Unreal Engine assets into Blender all at once instead of one by one. Baked textures come with them and materials are created automatically, so imported items are ready to look at straight away.

Original path structures are preserved, which keeps assets in the same folders they occupy in Unreal. Texture resolution is detected automatically so each material's textures export at native size, saving memory and disk space. Artists working between Unreal and Blender, such as those retopologizing, kitbashing or reusing environment pieces, will find it removes tedious manual transfers.

Key features

  • Bulk transfer of all Unreal assets
  • Baked textures and automatic materials
  • Asset path structure preserved
  • Native texture resolution detected automatically
