What AErmes does

AErmes is a script from Bending Spoons that handles localisation of After Effects projects. It exports content to Lokalise, where it can be translated, and imports the translated strings back to build localised compositions in a few clicks.

Access is limited to Bending Spoons employees. The script requires turning on the preference allowing scripts to write files and access the network, and works with After Effects 17.0 and later. It is intended for in-house teams who want to avoid manually duplicating comps for every language.

Key features

  • Exports projects into Lokalise for translation
  • Imports translations to create localised comps
  • Restricted to Bending Spoons employees
  • Needs script file and network access enabled
  • After Effects 17.0 and later
