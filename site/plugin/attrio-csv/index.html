Blender add-on that exports per-frame evaluated mesh or point cloud attributes to CSV and reimports them via Geometry Nodes.

What Attrio CSV does

Attrio CSV moves evaluated geometry data between Blender and spreadsheets or outside scripts. It writes the evaluated geometry of mesh or point cloud objects, frame by frame, to a numbered series of CSV files, so values can be inspected, analyzed or altered externally.

Choose an attribute domain, pick any mix of attributes, and optionally write one file for each frame in a range. Floats, integers, vectors, colors and booleans are supported, with vectors split across columns, and you can pick Float64 or smaller Float32 precision. A CSV Import node and supplied Geometry Node trees return the data to Blender as a point cloud.

Key features

  • Per-frame CSV export of evaluated attributes
  • Attribute domain selection with refresh
  • Frame range export, one file per frame
  • Full or reduced numeric precision
  • CSV Import node for point cloud reimport
