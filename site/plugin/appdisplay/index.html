What AppDisplay does

AppDisplay is a 3ds Max platform where scripted modules sort scene objects into groups and visualize them by coloring each group differently. Each module brings its own grouping algorithm, and MaxScript users can write modules of their own.

A category drop-down chooses the module. A materials toggle shows data at render time with a more elaborate shader than plain wirecolor, an identity toggle colors selected groups white and the rest black, and a time update toggle refreshes the list as the time slider moves. Buttons select group members in the scene or add a new row, and a filter drop-down narrows predefined collections.

Key features

  • Scripted modules with their own grouping algorithms
  • Category drop-down to choose the module
  • Materials toggle for render-time visualization
  • Identity toggle and time update toggle
  • Select-in-scene button and filter drop-down
