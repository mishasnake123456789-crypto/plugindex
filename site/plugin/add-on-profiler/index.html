Blender Python utility that logs execution and captures profiling data for add-on developers from the 3D viewport sidebar.

What Add-on Profiler does

Add-on Profiler helps developers analyze Blender add-ons. It watches code execution and records profiling data while you work.

Execution logging watches calls in the running Python session, output can be filtered by function names and source files, and version 2.1.0 added a Filter Time option. Everything is reached from the 3D viewport sidebar. Add-on authors tracking down slow code will benefit. Seeing which functions run and how long they take helps developers spot bottlenecks, remove wasted calls and keep their own tools from slowing the interface.

Key features

  • Execution logging of Python calls
  • Filter by function name and source file
  • Filter Time option (v2.1.0)
  • Profiling from the sidebar
