Blender add-on that generates tileable height-based bump, normal and depth maps from a texture node and wires up the shader.

What Shader Shaper does

Shader Shaper takes a texture node in Blender and produces bump, normal and depth maps from it, then connects the shader to use them. The output tiles cleanly because height data matches at the seams.

The workflow is simple: select a texture node and click generate. Interactive controls adjust map resolution and related settings, so you can preview changes in the shader as you go. Material artists who need quick relief detail for surfaces, without leaving Blender for another map-making tool, are the main audience.

Key features

  • One-click map generation from a texture node
  • Bump, normal and depth maps
  • Seamless tileable output
  • Interactive resolution control
  • Shader set up automatically
