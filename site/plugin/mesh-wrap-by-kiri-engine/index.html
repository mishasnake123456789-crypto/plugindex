What Mesh Wrap By Kiri Engine does

Mesh Wrap by KIRI Engine projects scanned terrain and surfaces onto base meshes while preserving detail. It is built for photogrammetry and environment modeling.

It is compatible with Blender 4.4 through 5.0, is distributed as an add-on that works as a Blender extension and is GPL licensed, with documentation included. Useful for turning raw scans into clean topology. In practice that means wraps scans onto base meshes, preserves detail and blender 4.4 through 5.0.
