What View Xport (Addon): Saver, Locker And Better Quad View does

UV Tofu's View Xport, once called View3D Exponent, extends the Blender 3D viewport for rapid view handling. View Channels store and restore viewpoints instantly through a menu, button or hotkey, and a channel's label can show as HUD text.

Lock View Rotation has a soft lock that stops middle-mouse orbiting while still allowing numpad viewpoint and perspective changes, plus a stricter quad lock applied to region data. Toggle Quad View keeps the viewpoint and behaves the way CAD programs do. Hard-surface modelers get consistent views.

Key features

  • View Channels save and load views
  • Soft and hard view rotation locks
  • CAD-style quad view toggle
  • Channel label as HUD info
  • Menu, button and hotkey access
