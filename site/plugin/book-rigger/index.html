What Book Rigger does

Book Rigger creates a complete book rig in 3ds Max with a single click, whatever the page count. The rig offers interactive controls for page curvature, turning, landing and shuffling, plus a global speed multiplier for adjusting timing.

Pages can use single or double-sided materials with diffuse textures driven by animated sequences, and an Oldness attribute adds per-page noise with a Reset to Defaults button. Expression-based turn, shuffle and multiply functions and animatable attributes such as Flex Crease and Flex Angle give detailed control. It suits catalogues, magazines, notebooks, flipbook UI mockups and title sequences.

Key features

  • One-click rig for any number of pages
  • Controls for curvature, turn, land and shuffle
  • Single or double-sided page materials
  • Oldness attribute with reset
  • Animatable flex and crease attributes
