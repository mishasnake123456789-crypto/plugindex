What Fibonacci Spiral Script+Addon+Gn Tools does

This Blender package, from Blendisar, adds an object that creates a Fibonacci spiral and supplements it with Geometry Nodes tools. It is offered as an installable add-on and also as scripts for those who prefer not to use the add-on.
