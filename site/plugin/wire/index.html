A Blender add-on that generates a wireframe render and adds it to the main render from the N-panel.

What Wire does

Wire provides a quick way to produce wireframe renders in Blender. It generates the wireframe pass and adds it to the main render, controlled from a Wire tab in the 3D Viewport's N-panel.

An Add wireframe to render button starts the process, a color picker adjusts the wireframe color for better contrast, and an optimal display checkbox chooses between an optimal mode and the full mesh wireframe. Documentation is included. Modelers showing topology in portfolios and presentations will find it far faster than building a wireframe composite manually.

Key features

  • Wireframe added to the main render
  • Add wireframe to render button
  • Wireframe color picker
  • Optimal display or full mesh option
  • N-panel Wire tab
