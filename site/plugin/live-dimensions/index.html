Live Dimensions

FreeBlender

Shows live object dimensions in Blender Edit Mode with one-click mm, cm and m conversion.

What Live Dimensions does

Live Dimensions displays an object's size in real time as you edit. Values update with each change in Edit Mode, and units switch between millimeters, centimeters and meters with one click.

Dimensions come from the current selection, or from the whole mesh when nothing is selected. Several objects can be measured together, including mesh, plane and bezier types. It is useful for precision modeling, product design and anything built to real dimensions.

Key features

  • Real-time Edit Mode dimensions
  • One-click mm, cm, m conversion
  • Selection-based with whole-mesh fallback
  • Multi-object support
