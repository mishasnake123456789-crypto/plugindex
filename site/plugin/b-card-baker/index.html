What B- Card Baker does

B- Card Baker is a Blender add-on for producing foliage cards and trim sheets. Overlapping transparent planes normally cause black clipping artifacts in baked opacity masks; this tool uses a tailored render setup to avoid them.

It allows up to 128 transparent bounces with unified Soft Alpha, and bakes a collection's contents non-destructively, including splines, curves, hair and live Geometry Nodes results. Game and real-time artists can generate card textures directly in Blender.

Key features

  • True overlapping opacity from a custom render setup
  • 128 transparent bounces with Soft Alpha
  • Non-destructive collection baking
  • Meshes, curves, hair and Geometry Nodes
