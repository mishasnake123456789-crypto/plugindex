A Blender add-on that turns CSV data into animated 2D charts, with an experimental 3D chart type.

What Bchart: Chart Generator In Blender does

Bchart creates charts inside Blender from CSV files, useful for infographics, explainer videos and data-driven motion graphics. Charts can be created and removed from the add-on interface, and the data can be refreshed at any time without losing settings.

More than five 2D chart types and variants are included, plus a 3D type that is still in testing and not meant for production. You can switch chart type whenever you wish, tweak over thirty parameters and animate with one click. An origin point moves, rotates and scales each chart. Motion designers presenting data will find it faster than drawing charts manually.

Key features

  • Imports CSV data into charts
  • 5+ 2D chart types and an experimental 3D type
  • 30+ adjustable parameters
  • One-click animation
  • Refreshable data without losing settings
