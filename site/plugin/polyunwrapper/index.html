What PolyUnwrapper does

PolyUnwrapper from PolyTools3D adds a set of professional UV features to 3ds Max, written for texture artists in architecture and games. It aims to make the unwrapping workflow inside the program quicker.

Tools include Multi Stitch for joining many shells at once, a custom packing algorithm with extra packing tools, matching of shell width and height, and simple grid spacing. UV tiles (UDIM) and open edges can be rendered, a Cycle Checker map helps verify layouts, and a toolbar stays on top of the Unwrap Editor for easy reach.

Key features

  • Multi Stitch for several shells at once
  • Custom packing algorithm and tools
  • Match shell width and height
  • Render UV tiles (UDIM) and open edges
  • Cycle Checker map and always-on-top toolbar
