What Auto Image Strip Generator does

Auto Image Strip Generator works inside Blender's Video Sequence Editor. It looks through a folder you select, finds the image sequence and creates a named strip so you do not have to add frames manually.

It also adjusts the render size and end frame to fit the images, using pattern recognition to build the strip. You can run it from a menu entry or a keyboard shortcut, and it is compatible with Blender Extensions. Photographers, animators and video editors working with rendered frames can load sequences in a single step.

Key features

  • One-click import of the latest image sequence
  • Smart pattern recognition for strips
  • Sets render size and end frame to match
  • Menu entry or keyboard shortcut access
  • Compatible with Blender Extensions
