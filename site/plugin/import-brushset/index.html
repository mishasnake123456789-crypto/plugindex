What Import BrushSet does

Import BrushSet loads all the image files in a folder at once. It is available from File, Import, BrushSet and started life as one of the add-ons bundled with Blender 4.1.

It is now provided as-is, with limited support, compatible with Blender 4.2 LTS and licensed under the GNU General Public License. It asks for access to a directory of image textures. Artists assembling brush textures or sets of reference images can bring them in without loading each file individually.

Key features

  • Imports all images in a folder
  • Located at File > Import > BrushSet
  • Works with Blender 4.2 LTS
  • Originally a Blender 4.1 bundled add-on
