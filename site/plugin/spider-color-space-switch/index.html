What Spider Color Space Switch does

Spider Color Space Switch handles the awkward part of changing between ACES and sRGB workflows. The choice is stored per project inside the .blend file.

When you open a file saved in a different color mode, it can automatically relaunch Blender with the correct OCIO environment, using a timer system that waits at the right moment. This helps VFX and compositing artists who move between color-managed pipelines and standard displays.

Key features

  • One-click ACES and sRGB switching
  • Color mode saved in the .blend file
  • Auto-relaunch with correct OCIO environment
  • Smart timer waits before relaunching
