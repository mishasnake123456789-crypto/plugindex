What Gis2Blend does

Gis2Blend turns map data into 3D scenes. It combines online OpenStreetMap download, satellite overlays, terrain generation and import of GIS data that respects coordinate reference systems.

A guided interface of ten collapsible sections walks through each step. OSM data can be fetched for a map extent or read from local files, using search, coordinates or a bounding box to set the area, and you can pick which categories to include. Urban planners and environment artists building cities or landscapes from real data benefit.

Key features

  • Guided 10-section interface
  • Online OSM download or local OSM files
  • Satellite overlay and terrain generation
  • CRS-aware GIS import
