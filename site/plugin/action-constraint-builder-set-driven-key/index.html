What Action Constraint Builder - Set Driven Key does

Action Constraint Builder simplifies driven-key rigging using an interface inspired by Maya's Set Driven Key. The process takes four steps: load the driver object or bone, load the target, pose it, then set the driven key.

Typical uses include wing folding, facial rigging, mechanical transformations and hand gestures. It only sets up the Blender constraint itself, so there is no vendor lock-in. Riggers coming from Maya will feel at home.

Key features

  • Four-step Set Driven Key workflow
  • Maya-inspired interface
  • Wing, face, mechanism and hand rigs
  • Standard Blender action constraints
