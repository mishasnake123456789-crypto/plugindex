3ds Max script that imports several Illustrator, DXF, DWG or SVG files at once as welded, named splines.

What Import Illustrator Files does

Import Illustrator Files brings vector artwork into 3ds Max with one click. Several files can be chosen directly in the browser, and on import the splines are attached and their vertices welded, while the objects are named after the files.

Shift-clicking the button also adds an Extrude modifier to the splines. Supported formats are .ai, .dxf, .dwg and .svg, with SVG available on 3ds Max 2025.2. The settings dialog appears for the first file and the same settings apply to the rest. If a file is not saved as Illustrator version 8, the script shows a message instead of crashing. Logo and graphic designers will find it helpful.

Key features

  • Imports multiple files in one click
  • Attaches splines and welds vertices
  • Renames objects from file names
  • Shift-click adds an Extrude modifier
  • Supports .ai, .dxf, .dwg and .svg
