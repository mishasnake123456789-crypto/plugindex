What Manage Blender Projects - Mbp does

Manage Blender Projects, or MBP, brings light project tracking inside Blender. Freelancers and small studios can keep records in the N-Panel instead of juggling a separate spreadsheet, storing status, start and finish dates, income and the client's name for each job.

Project files or folders open straight from the list, and starting a new project automatically creates the folders and places files correctly. A timer records time spent on each job, and all project data exports to CSV. It suits independent artists who handle several client jobs and want billing information near their work.

Key features

  • Project and client records in the N-Panel
  • Stores status, dates, income and client name
  • Opens project files or folders from the list
  • Automatic folder creation for new projects
  • Time tracking and CSV export
