A Blender add-on for managing union and subtract booleans in object mode with positive and negative parts.

What Bool It - Quick Booleans does

Bool It lets you build shapes with booleans in Blender by arranging parts in the viewport and marking each as positive or negative. Union and subtraction are applied for you, so hard-surface forms come together without manually adding modifiers.

A Quick Edit panel offers shortcuts for editing edges (green icons) and faces (pink icons). Modifiers such as bevel, panel cut and array can be applied to parts quickly, parts can be added from the asset browser while in object mode, and results can be converted when you are done. Hard-surface modelers and concept artists will work faster.

Key features

  • Union and subtract in object mode
  • Mark parts as positive or negative
  • Quick Edit panel for edges and faces
  • Fast bevel, panel cut and array modifiers
  • Add parts from the asset browser
