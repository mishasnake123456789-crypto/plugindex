Blender add-on for building data visualizations on country meshes from CSV files.

What Smartist Mapper does

Smartist Mapper turns spreadsheet data into 3D maps in Blender. It ships with 255 country meshes converted from Natural Earth Data in 10m, 50m and 110m scales, and a panel in the 3D View.

A Geometry Nodes setup extrudes and translates countries by value, with custom value and name labels. Material presets and a quick setup panel help styling, and projections include Flat, Sphere, Disc and Tube. CSV files can be imported and exported using a starter template.

Key features

  • 255 country meshes in three resolutions
  • Geometry Nodes extrusion by data value
  • Flat, Sphere, Disc and Tube projections
  • CSV import and export with template
