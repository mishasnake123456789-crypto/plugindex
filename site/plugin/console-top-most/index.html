What Console Top Most does

Console Top Most is a plugin by Sergey Tyapkin for Windows users. It toggles the System Console to be the topmost window, so output stays visible while you work.

It also remembers and restores where the main and preferences windows sit, and how big they are, when you switch scenes. Controls are in the Window menu. Useful for developers and multi-monitor setups. Keeping the console visible makes it simpler to watch logs and errors while using Blender, especially during scripting or debugging.

Key features

  • Console always on top
  • Toggle from the Window menu
  • Save and restore window size and position
  • Main and Preferences windows
