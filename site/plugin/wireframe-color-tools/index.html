Blender add-on that sets object colors in several ways to make overlapping wireframes in the viewport easier to read.

What Wireframe Color Tools does

Wireframe Color Tools changes object display colors in Blender to keep crowded viewports legible. When wireframes overlap, distinct colors make individual objects readable again.

Set Color applies one color to many objects, Set Color Range spreads a range of colors, Random Color assigns random values, and a material-based option pulls colors from materials. Modelers and layout artists working with many objects get clearer viewport feedback. These color changes only affect how objects display in the viewport, so they help organization without altering materials or renders.

Key features

  • Set one color on many objects
  • Color range assignment
  • Random colors
  • Get colors from materials
