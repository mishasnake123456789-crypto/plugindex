What Fixamo 2 does

Fixamo 2 is a Blender plugin from BOSSposes for working with Mixamo clips. It lets you chain, loop and create animations through copy and paste, so you can skip the NLA editor.

A Fix button renames animations automatically to avoid conflicts and strips positional drift while keeping vertical motion. A Physics button adds gravity as passive or active in a click. It benefits game developers and animators reusing Mixamo motion.

Key features

  • Combine and loop Mixamo animations
  • Fix button renames and removes root drift
  • One-click gravity physics
  • No NLA editor needed
