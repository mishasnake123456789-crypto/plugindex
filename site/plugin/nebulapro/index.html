Blender add-on that builds EXR space backdrops from blended nebula layers, controlled in World Properties.

What Nebulapro does

NebulaPro creates space environments in Blender from EXR nebula images and lights them cinematically. All controls sit in the World Properties panel, which keeps setup close to the background it affects.

Two nebula layers can be mixed with Mix, Add, Screen, Overlay or Multiply modes and a per-layer amount. EXR files can be downscaled to full, 4K, 2K or 1K with local caching and automatic image cleanup, and GPU buffers are managed with explicit VRAM freeing for stability. Artists, VFX users and motion designers can adjust the result in real time.

Key features

  • Dual-layer nebula blending with five modes
  • EXR downscaling to Full, 4K, 2K or 1K
  • Local caching and automatic image cleanup
  • GPU buffer management with VRAM freeing
  • Real-time controls in World Properties
