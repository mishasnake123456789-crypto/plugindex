What Bmesh Clean Add-On does

Bmesh Clean automates routine mesh cleanup for imported models in Blender. A single pass can run limited dissolve, merge by distance, delete loose geometry, normal fixes and smoothing on one object or many.

Individual operations are also available, including Tris to Quads, Triangulate and Recalculate or Flip Normals. Shade Smooth with an Auto Smooth Angle can be applied across several objects so shading stays consistent. Artists receiving CAD or scanned assets can prepare them quickly for further work.

Key features

  • One-click cleanup sequence on one or many objects
  • Limited Dissolve, Tris to Quads, Triangulate
  • Normal recalculation and flipping
  • Shade Smooth with Auto Smooth Angle
