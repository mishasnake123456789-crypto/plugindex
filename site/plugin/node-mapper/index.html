What Node Mapper does

Node Mapper adds a minimap to Blender's node editors so you always know where you are in a large graph. It works in shader, geometry, compositor and custom node trees.

Left-click on the map to jump instantly, or click and drag to pan, and active and selected nodes are highlighted. Artists with sprawling node trees can move around quickly rather than scrolling and zooming. Highlights cover minimap overlay in node editors and click to jump, drag to pan.

Key features

  • Minimap overlay in node editors
  • Click to jump, drag to pan
  • Highlights active and selected nodes
  • Shader, geometry, compositor and custom trees
