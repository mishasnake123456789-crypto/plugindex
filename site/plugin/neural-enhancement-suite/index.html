What Neural Enhancement Suite does

Neural Enhancement Suite packages several AI models for repairing and improving footage. Blace Plugins built it for After Effects and Premiere Pro, giving editors one place to handle noisy, soft, dark or black-and-white clips.

Separate models address denoising, deblurring and low-light enhancement, and colorizing is included, with an example-based option in Premiere Pro. Processing can run on the GPU or CPU, and a CUDA Memory Sharing setting speeds up renders above 4K. A Stop Processing button cancels a long job immediately.

Key features

  • AI denoising and deblurring
  • Dedicated low-light enhancement model
  • Colorizing, with example colorizing in Premiere Pro
  • GPU or CPU processing
  • CUDA Memory Sharing; Stop Processing button
