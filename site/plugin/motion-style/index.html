Blender add-on that brings an After Effects-style speed curve and easing sliders to the Graph Editor.

What Motion Style does

Motion Style gives Blender animators the speed curve workflow familiar from After Effects. A visual speed curve is drawn inside the Graph Editor, with minimalist easing sliders and one-click interpolation for adjusting keyframes.

It is useful for motion graphics, character animation and mechanical movement. The graphics draw handler registers dynamically, so resources are used only while Enable Speed Curve is on. The interface is fully localized in English since version 1.0.2, and the extension is a lightweight 6.3 KB.

Key features

  • AE-style speed curve in the Graph Editor
  • Easing sliders
  • One-click interpolation
  • Draw handler active only when enabled
  • Lightweight 6.3 KB extension
