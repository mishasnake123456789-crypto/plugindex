Gives a single After Effects layer multiple anchor points for position, rotation and scale animation.

What Add Anchor Point does

Add Anchor Point is a Pixcode script that breaks the one-anchor limit in After Effects. A layer can carry as many anchor points as you like, which makes complex movements such as pivoting around different locations easier.

Positions of each anchor point are customizable, and position, rotation and scale animation can be based on different anchor points. There is no cap on the count, and the interface is easy to use. It helps character and mechanical animation where parts rotate around several pivots.

Key features

  • Multiple anchor points on one layer
  • Customizable anchor point positions
  • Animate position, rotation and scale from any anchor
  • No limit on number of anchor points
