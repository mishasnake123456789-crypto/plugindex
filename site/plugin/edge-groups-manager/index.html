Blender add-on for organizing the edge and vertex float attributes that drive bevel weights, with overlays and a pie menu.

What Edge Groups Manager does

dgtl-graphics' Edge Groups Manager helps handle the attributes controlling Bevel Modifier weights in Blender. You can create, manage and rename edge and vertex float attributes, editing the name right in the list.

When you rename one, Bevel and Geometry Nodes modifiers that reference it update automatically. Overlays highlight non-zero values, optionally through geometry with X-Ray, and weight labels show the numbers. A quick-access pie menu speeds things along. Hard-surface modelers get a visual way to manage bevel groups.

Key features

  • Create and rename edge and vertex attributes
  • Auto-sync with Bevel and Geometry Nodes modifiers
  • Overlays for non-zero values
  • Weight labels
  • Quick-access pie menu
