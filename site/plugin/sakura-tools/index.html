What Sakura Tools does

Sakura Tools focuses on batch operations for character modeling. It can process multiple objects or an entire model, including the armature and related objects, in one go.

It applies a whole modifier stack or chosen modifiers regardless of count, keeps mesh operations compatible with shape keys, and provides enhanced weight transfer with weight blending for deform bones. Normal transfer, pose baking and model management are included as well. It cuts down on repetitive cleanup before exporting characters.

Key features

  • Batch processing across objects and armatures
  • Apply full or selected modifier stacks
  • Shape key compatible operations
  • Weight blending transfer
  • Normal transfer and pose baking
