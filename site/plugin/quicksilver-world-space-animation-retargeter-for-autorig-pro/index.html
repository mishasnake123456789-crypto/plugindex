What Quicksilver - World Space Animation Retargeter (For Autorig-Pro) does

Quicksilver retargets animation in Blender for Auto-Rig Pro using visual markers positioned in world space, so you need not map every bone by name.

You match the source motion visually, then bake it onto a clean Auto-Rig Pro rig. It is built for messy sources such as Mixamo, Rokoko, DeepMotion, Sketchfab animations, mocap files and custom FBX rigs, and it copes with odd scales and broken rest poses. It suits animators who regularly inherit imperfect motion data from other sources.

Key features

  • World-space markers instead of bone mapping
  • Visual match, then bake
  • Handles Mixamo, Rokoko and DeepMotion sources
  • Copes with odd scales and broken rest poses
  • Targets Auto-Rig Pro rigs
