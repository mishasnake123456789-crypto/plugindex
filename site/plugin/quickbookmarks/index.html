Puts folder shortcut and website link menus in Blender's 3D Viewport header for one-click access.

What Quickbookmarks does

QuickBookmarks is a lightweight Blender add-on that keeps frequently needed locations close. Two menus in the 3D Viewport header hold your folder shortcuts and your website links, so reference sites and project directories are a click away.

Folders open in the system file explorer and links open in the default browser. Buttons can show icons only or icons with text, and entries can be added, renamed, reordered and removed whenever needed. It is useful for artists who bounce between asset folders, documentation and online references during a project.

Key features

  • Folder and website menus in the viewport header
  • Folders open in the system file explorer
  • Links open in the default browser
  • Icon-only or icon-and-text display
  • Add, rename, reorder and remove entries
