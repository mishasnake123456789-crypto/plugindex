What Simple Colorizer does

Simple Colorizer offers a fast way to color faces in Blender without building materials. It is meant for prototypes and low poly models, where flat color is enough, with eight colors and eight brightness levels available from a panel in the 3D View N panel.

In Edit mode you select a face and click a color; in Object mode the color applies to all faces at once. Brightness buttons fine-tune the result. Note that it changes the first material slot to an add-on-specific material and scales all UVs to zero. Game prototypers and blockout artists will find it handy.

Key features

  • 8 colors and 8 brightness levels
  • Face coloring in Edit mode
  • Whole object coloring in Object mode
  • Panel in the 3D View N panel
