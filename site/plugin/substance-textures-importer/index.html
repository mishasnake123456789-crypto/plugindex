What Substance Textures Importer does

Substance Textures Importer reads textures exported from 3D painting software such as Substance and hooks them up to materials. It identifies map types and builds the node connections for you.

This removes the manual step of loading each image and wiring it into a shader. Texture artists exporting from paint tools can have a material ready in a few clicks.

Key features

  • Imports exported texture sets
  • Auto-assigns maps to nodes
  • Builds material connections
