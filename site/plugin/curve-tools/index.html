What Curve Tools does

Curve Tools extends Blender's handling of Bezier and NURBS splines and surfaces. It used to be a bundled add-on and is now available separately, with its panel in the 3D View Tool Shelf under the Edit tab.

Operations include fillets, handle projection, divide, remove doubles and tilt adjustments. No special permissions are needed. Modelers who work with spline-based shapes, such as pipes, logos or wires, get more precise editing than the default tools provide.

Key features

  • Fillet and Handle Projection options
  • Divide and Remove Doubles
  • Tilt option
  • Panel under Tool Shelf Edit tab
