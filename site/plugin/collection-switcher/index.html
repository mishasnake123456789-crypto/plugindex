What Collection Switcher does

Collection Switcher, by Valentin-Komkov, toggles which sub-collection is visible by using switchers, so alternate versions of a scene can be flipped quickly. It is listed under Workflow.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.
