What Character Renderer For 2D Games does

Character Renderer For 2D Games produces sprite images from 3D characters, the approach used in classic isometric games like Diablo 2. The output suits 2D engines such as GameMaker.

It can render every action in a file or only those you specify, using Blender's fake-action mechanism to mark them. The number of directions is configurable, for example eight angles for isometric games, and render layers can be output separately so character parts can be handled apart. Indie developers can turn a model into complete animation sheets.

Key features

  • Renders all or chosen actions
  • Fake-action marking
  • Configurable directions, such as 8 angles
  • Renders all or selected render layers
