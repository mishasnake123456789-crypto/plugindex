What True Image Editor V2 Update does

True Image Editor V2 builds a layer-based workspace inside Blender's Image Editor. It lets you stack layers and blend them, paint or generate masks, crop, tile, grade color, set text and bake out a finished image, all without leaving the editor.

Layers can be added, reordered, renamed and duplicated along with their masks, transforms and blending. Masks come from selections or direct painting, and procedural masks are available. It's a convenient way to make texture edits and composites in one place.

Key features

  • Layer stack with blending and duplication
  • Painted, selection and procedural masks
  • Crop, tile and color adjustments
  • Text layers and bake to final image
