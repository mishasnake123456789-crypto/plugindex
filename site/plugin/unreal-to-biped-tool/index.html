3ds Max script that retargets Unreal 4 or 5 Mannequin animation to a Biped, for one file or a whole folder.

What Unreal To Biped Tool does

The tool brings animation built on the Unreal 4 or 5 Mannequin over to a 3ds Max Biped. Any UE4 or UE5 Mannequin animation will do, and no elaborate setup is needed.

Single animations can be converted, or whole folders processed in a batch, with .BIP files saved automatically. It works with 3ds Max 2010 and later, is unencrypted and DRM-free, and includes a quickstart PDF guide. Animators who want to edit or reuse game animation using Biped tools will find it speeds up the retargeting process.

Key features

  • Transfers UE4 and UE5 Mannequin animation to Biped
  • No complex setup required
  • Single or whole-folder batch conversion
  • Automatic .BIP saving
  • Quickstart PDF guide, unencrypted and DRM-free
