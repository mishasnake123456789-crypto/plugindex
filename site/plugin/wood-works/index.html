What Wood Works does

Wood Works from Meta Meow is a procedural toolkit that turns a scene into a wooden world. One panel controls everything, driven by an included Python script.

A single four-layer material lets you paint and mix four wood textures together in painting mode, while the Carved Wood style creates a procedural carved appearance through geometry nodes. A 2D cutout style is also available, and the add-on deals with materials, textures and UVs for you. It suits artists making toy-like or craft-inspired scenes.

Key features

  • Single panel controls all features
  • Four-layer wood material with painting mode
  • Carved Wood style via geometry nodes
  • 2D cutout style
  • Handles materials, textures and UVs
