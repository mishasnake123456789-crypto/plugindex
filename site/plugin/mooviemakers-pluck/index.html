A panel for importing and exporting compositions between After Effects projects by drag and drop.

What Mooviemakers Pluck does

Pluck lets you reuse work across projects without opening them. Drop an .aep onto the panel and it lists each composition with its size, frame rate and duration, so you can import only the ones you need.

Dependencies such as precomps and footage are resolved and relinked without duplicating existing items, and expression warnings flag broken references. Imports can mirror folders, sort by type or go flat. You can also drag comps out as a standalone .aep or a zip, with token-based file names. Handy for motion designers sharing scenes.

Key features

  • Reads any .aep without opening it
  • Drag-and-drop comp import with search
  • Automatic dependency resolution and relinking
  • Expression warnings before import
  • Export as .aep or self-contained .zip
