What Blender Render Queue does

Blender Render Queue (BRQ) automates batch rendering outside Blender. You queue shots, pick which scenes and cameras to render, and let the machine shut down when finished.

Scenes, cameras and view layers can be selected for multi-shot workflows, and output presets save engine, samples and format. A full-resolution live preview with remaining time estimate is shown, and a web app permits remote monitoring from desktop and mobile. Freelancers and small studios can render overnight without babysitting.

Key features

  • Scene, camera and view layer selection
  • Reusable output presets
  • Live preview with time estimate
  • Remote monitoring web app
  • Auto power-down after queue
