3ds Max toolbar script that converts imported AutoCAD .3ds meshes to Editable Mesh and runs Auto Edge in one click.

What AutoEdge Selected does

AutoEdge Selected is a cleanup script for geometry that arrives in 3ds Max from AutoCAD as .3ds files. Select the imported Mesh objects, press the toolbar button, and it takes care of the routine steps for the whole batch.

Each object is converted to an Editable Mesh, all edges are selected, and Auto Edge is performed at the current threshold, so hard and soft edges are sorted out without opening each object. This removes a repetitive chore from CAD import workflows, particularly when many pieces of imported geometry need identical treatment.

Key features

  • Batch converts imported Mesh objects to Editable Mesh
  • Selects all edges on converted objects
  • Runs Auto Edge at the current threshold
  • Single toolbar button for a whole selection
  • Aimed at .3ds files exported from AutoCAD
