What Super Shine does

Super Shine, by aeHamid, applies a moving glint across any layer in After Effects. It is the familiar shimmer used on logos, text and product shots, with settings that are easy to adjust.

Start and end times can be driven by markers, and start and end points position the sweep. Several shines can sit on one layer, a mirror mode duplicates the sweep, and an effect mode lets other effects such as glow be added to the shine. These options give designers a flexible way to add polish to reveals and titles.

Key features

  • Marker-based start and end timing
  • Start and end point control
  • Multiple shines on one layer
  • Mirror mode
  • Effect Mode for glow and others
