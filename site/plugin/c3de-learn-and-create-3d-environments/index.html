What C3De - Learn And Create 3D Environments does

C3DE gathers preset materials, props and a rubble generator into a starting point for 3D environments, drawn from content made for the Creating 3D Environments courses.

The rubble generator uses a built-in simulation to create piles that adapt to your scene's shape and scale. Different rubble types can be mixed into natural formations with automated placement. A Factory pack adds further assets. It helps environment artists populate scenes faster while learning the course techniques.

Key features

  • Preset materials and props
  • Simulated rubble generator
  • Mixable rubble types with auto placement
  • Factory pack
