Blender add-on bringing non-destructive layers, filters, masks and baking to PBR texture painting in the 3D viewport.

What HAS Paint Layers does

HAS Paint Layers adds a layer-based workflow to texture painting in Blender, much like the stacks found in dedicated painting software. Edits stay non-destructive, so changes can be reordered or reversed.

Each layer can hold any number of filters and masks, and PBR painting includes channel setup and blending modes. Bake tools and paint helpers round out the toolset, all inside the 3D viewport. Texture artists who want to avoid round-tripping to other applications will find it convenient.

Key features

  • Create and organize paint layers
  • Unlimited filters and masks per layer
  • PBR channel setup and blending modes
  • Bake tools
