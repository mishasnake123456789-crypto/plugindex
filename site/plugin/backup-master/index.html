What Backup Master does

Backup Master is a Blender add-on for keeping deliberate snapshots of your work rather than relying on autosave. Each backup is saved with an incremented filename so versions stay in order.

A thumbnail is captured automatically, and a visual list shows name, date, size, note and thumbnail for every backup. Notes can be written or edited at any time, and thumbnails can be refreshed on demand. It suits artists who want to mark milestones in a project and find the right version again later.

Key features

  • Incremented .blend backup filenames
  • Automatic thumbnail screenshot per backup
  • Visual list with name, date, size and note
  • Editable notes for each version
  • On-demand thumbnail updates
