What Osc Controller For Blender - Real-Time Animation Over Osc does

OSC Controller for Blender maps Open Sound Control messages to properties in real time. Apps such as TouchDesigner, Pure Data and Max can send values that control shape keys, bones, cameras, lights, geometry nodes and nearly any property.

A one-click operator creates 50 standard ARKit-style facial shape key mappings for a mesh, and bone rotations can use Euler or Quaternion modes. Performers, installation artists and motion designers can link live input to Blender.

Key features

  • OSC message mapping to properties
  • Shape key control with 50 ARKit-style mappings
  • Bone rotation in Euler or Quaternion
  • Works with TouchDesigner, Pure Data and Max
