What Positive Cube does

Positive Cube, by Jeff Lange, inserts a cube with its origin in the bottom left corner. When you scale it, the base stays anchored instead of growing outward from the center.

This is useful for placeholder and reference objects, architectural blocks where base alignment matters, and scenes that need accurate measurements and proportions. Stacking and organizing several objects becomes easier because edges line up predictably. Documentation is included. Designers, modelers and animators who want consistent origin placement benefit most.

Key features

  • Cube with origin at the bottom-left corner
  • Stays anchored when scaled
  • Helpful for architectural base alignment
  • Easier stacking of multiple objects
  • Documentation included
