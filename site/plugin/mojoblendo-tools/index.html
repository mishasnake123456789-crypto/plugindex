What Mojoblendo Tools does

Elevons, LLC built Mojoblendo Tools to carry optimizations familiar from Modo into Blender, across modeling, UV unwrapping and rendering. From version 1.1 everything arrives in one plugin installation.

A custom View pie menu on Ctrl-Space lets you look through the camera or an object, orient normal to a selection, or toggle orthographic. Save Mesh Select Modes retains your selection while changing modes, and the Shift-Q Selection Style pie gives quick access to options. Tool Unifiers put related tools on single keys. Former Modo users will feel at ease.

Key features

  • View pie menu on Ctrl-Space
  • Save Mesh Select Modes across switches
  • Selection Style pie menu on Shift-Q
  • Tool Unifiers with single-key access
  • All tools in one install
