What Editnote does

Editnote is a plain note-taking panel from Rightscrew that sits within Premiere Pro. It gives editors a place to keep correction instructions and to-do items visible without switching to a different application.

A Load File button opens a text file into the panel, and a Save button writes the notes back out. That makes it easy to start from a list sent by a client or colleague and to keep your own updates. It is a simple utility for anyone who works through feedback rounds one change at a time.

Key features

  • Memo panel on the Premiere Pro screen
  • Load File button opens a text file
  • Save button writes notes back to a file
  • Keeps corrections and to-dos in view
