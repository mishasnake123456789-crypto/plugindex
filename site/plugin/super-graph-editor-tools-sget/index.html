What Super Graph Editor Tools (Sget) does

Super Graph Editor Tools brings several Maya-inspired animation features into Blender's Graph Editor: ReTime, a TweenMachine and lattice deformations, along with dynamic parenting, timing edits, curve tools and timeline bookmarks.

Grab & Bake lets you parent and unparent objects or pose bones without constraints or popping, then bakes the motion to plain keyframes with the constraints removed, and a Simplify slider reduces the baked key count. Bookmarks mark animation phases with colored blocks. It is aimed at animators who want a smoother polishing workflow.

Key features

  • Grab & Bake dynamic parenting
  • Simplify slider for baked keys
  • Maya-style ReTime and TweenMachine
  • Colored timeline bookmarks
