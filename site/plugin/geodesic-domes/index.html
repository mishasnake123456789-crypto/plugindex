What Geodesic Domes does

Geodesic Domes generates dome-shaped objects built from triangular facets in Blender. It once shipped inside Blender 4.1 and is now distributed separately with limited support.

The tool is found under Add > Mesh in the 3D View, is about 25 KB, requires no special permissions, and is released under GPL v2 or later. It supports Blender 4.2 LTS and newer. Designers of greenhouses, shelters, game structures or sci-fi spheres can generate base geometry quickly.

Key features

  • Creates geodesic dome objects
  • Found in Add > Mesh
  • Compact download
  • For Blender 4.2 LTS and newer
