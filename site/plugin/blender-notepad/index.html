What Blender Notepad does

Blender Notepad keeps notes and tasks in the same window as your work. You can create pages, put notes on them, and build lists of to-dos, all saved into the Blend file so they are there when you reopen it.

The notepad resizes from a small box to the full window, opens with Shift+N or a custom shortcut from preferences, and works in any editor area. It is handy for tracking tasks, reminders and project details without switching to another application.

Key features

  • Pages, notes and to-do lists
  • Stored in the Blend file
  • Resizable up to full window
  • Shift+N or custom shortcut
  • Usable in any editor area
