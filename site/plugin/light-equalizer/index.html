What Light Equalizer does

Light Equalizer smooths out lighting shifts within a clip, such as changing exposure or color temperature as a cloud passes. It analyzes the footage and sets Lumetri keyframes for exposure, temperature and tint.

The interface is available in German, French, Spanish, Italian, Japanese and Chinese, and it supports Premiere Pro 2020 through 2025. It saves colorists and editors from keyframing corrections by hand. The correction is built from standard Lumetri keyframes, so you can still adjust the result by hand afterwards.

Key features

  • Automatic clip analysis
  • Evens brightness and white balance
  • Sets Lumetri keyframes for exposure, temperature and tint
  • Multilingual interface
  • Supports Premiere Pro 2020 to 2025
