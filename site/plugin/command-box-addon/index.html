What Command Box Addon does

Command Box Addon combines 424 small plugins into one suite for Blender, so you do not need to install and manage them one by one. Extensions are loaded only when needed and cleared from memory afterward, keeping the session light.

Press Alt+X, type a command name and hit Enter; there are no tabs or categories to browse. Ctrl+Alt+X opens the CommandBox panel and F5 runs the current script. Ready-made functions include a three-point light setup, UV tools, boolean unions and generators. Commands can be customized in their files, and adding #Autorun=True as a file's third line runs it at startup.

Key features

  • 424 commands in one on-demand suite
  • Alt+X type-and-run launcher
  • Commands unload from memory when idle
  • Autorun support for custom scripts
