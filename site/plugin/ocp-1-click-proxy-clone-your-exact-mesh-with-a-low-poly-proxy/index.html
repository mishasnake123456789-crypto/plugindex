What Ocp "1-Click Proxy" Clone Your Exact Mesh With A Low Poly Proxy does

OCP 1-Click Proxy is a Blender plugin that makes complex scenes manageable. It clones exact meshes as lightweight proxies and substitutes them for the high-poly originals, which stay intact along with their materials.

An automatic scan uses face-count thresholds you can adjust to find the heaviest objects, and several proxy types are offered, including category presets that load automatically. The result is smoother viewport performance when working with dense models.

Key features

  • Auto scan by face-count thresholds
  • Proxies keep originals and materials intact
  • Multiple proxy types and category presets
  • Render-safe replacements
