What Inward Extrude does

Inward Extrude is a Blender plugin that carves into a model from the faces you select. It is meant for fast hard surface work, where you want to push a recess or opening into a shape without building a separate cutter by hand.

Select one or more faces in Edit Mode and press Ctrl+Shift+E, or reach it from the Extrude menu with Alt+E. Behind the scenes it runs a boolean operation using a cutter that is slightly larger than the selected face, and the cut is applied to the mesh rather than kept as a modifier.

Key features

  • Destructive cut driven by the selected faces
  • Shortcut Ctrl+Shift+E in Edit Mode
  • Also reachable through the Extrude menu
  • Boolean cutter slightly larger than the face
