3ds Max script that assigns random material IDs across an Editable Poly while leaving chosen polygons on a fixed ID.

What EPoly MatID Randomizer does

EPoly MatID Randomizer assigns random material IDs to the polygons of an editable poly object in 3ds Max. Combined with a multi-material, it varies each face quickly, for example to give paving stones different looks.

Certain polygons can be excluded by assigning them an ID outside the range of random values, which handles cases such as random stones set in uniform grout. It works with editable poly objects. For anyone who needs variety across a surface without manually selecting faces and setting IDs, it speeds up the task considerably.

Key features

  • Randomizes material IDs on an editable poly
  • Excludes polygons with an ID outside the random range
  • Suited to stones set in uniform grout
  • Works with editable poly objects
