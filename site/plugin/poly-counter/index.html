What Poly Counter does

Poly Counter is a compact script for 3ds Max by Chuggnut. Pick the objects to count, press the button, and the combined polygon total shows up in the prompt line.

Because it handles several objects at once, it saves the trouble of adding up numbers by hand or enabling statistics for each selection. Game artists working to polygon budgets and anyone optimizing scenes can use it for fast checks. It is at version 2.3.5 and runs entirely inside 3ds Max.

Key features

  • Counts polygons across multiple selected objects
  • Single-button operation
  • Result shown in the prompt line
  • Version 2.3.5
