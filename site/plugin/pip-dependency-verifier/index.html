What Pip Dependency Verifier does

Pip Dependency Verifier lists, checks and installs Python packages needed by your add-ons. It automatically scans bl_info for declared pip_dependencies.

Installed packages show normally while missing ones are red with a one-click install. Add-on developers and users can solve dependency issues from one place. It is relevant for developers who distribute add-ons relying on third-party Python packages. The one-click install is helpful where manually running pip inside Blender's Python would otherwise be required.

Key features

  • Scans bl_info for pip_dependencies
  • Missing packages shown in red
  • One-click install
  • Central dependency UI
