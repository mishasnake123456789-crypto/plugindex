What Development Kit Tool does

Development Kit Tool is a Blender add-on by 小萌新 for people who write scripts and add-ons. It streamlines the edit-and-test loop by combining script loading, restart options and handy shortcuts.

From an add-on's expanded panel you can open its script or folder in your default program. Holding modifier keys changes what the reload tool does: it can start a fresh Blender, restart with or without asking to save, run two copies side by side, or keep relaunching in a loop. Extras include Alt+Space for full screen and Ctrl+Alt+Middle Mouse to show the console.

Key features

  • Open an add-on's script or folder from its panel
  • Reload and restart tool with modifier-key variants
  • Open two Blender instances or loop-launch
  • Alt+Space toggles full screen
  • Ctrl+Alt+Middle Mouse shows the console
