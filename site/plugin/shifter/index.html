What Shifter does

Shifter from Leyero offsets items in a staircase pattern: clips in Premiere Pro, and layers or keyframes in After Effects. Easing is customized through an intuitive graph, and the orientation can be ascending, descending or random.

In and out points set the duration or interval for each item, items can be reordered, and a live preview reflects changes at once. Version 3 supports unlimited presets with import and export. Editors and motion designers use it to create cascading animations without nudging each element manually.

Key features

  • Staircase offsets for clips, layers or keyframes
  • Easing graph
  • Ascending, descending or random orientation
  • Live preview and item reordering
  • Unlimited presets with import/export (v3)
