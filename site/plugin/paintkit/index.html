What Paintkit does

PaintKit is a toolset for artists chasing a painterly style in Blender. It provides procedural node groups for both the shader editor and the Geometry Nodes graph that produce painted-looking textures and effects.

Brush generation in Geometry Nodes scatters cards over a mesh, with noise-based displacement and controls over size, aspect ratio and frame-rate. This suits stylized renders that imitate brush strokes and hand-painted animation. The results can mimic hand-painted illustration or concept art, which is useful for stylized shorts, game environments and any project avoiding photorealism.

Key features

  • Node groups for shaders and Geometry Nodes
  • Brush card generation across a mesh
  • Noise displacement, size and aspect controls
  • Stylized painterly look
