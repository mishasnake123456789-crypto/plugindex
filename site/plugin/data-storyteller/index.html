What Data Storyteller does

Data Storyteller is a set of data visualization tools for After Effects from Digital Anarchy. It aims to take a table of numbers and make animated graphics with less manual work, which is helpful for explainers, reports and news segments.

It is delivered as a collection of tools rather than a single plugin, and is also compatible with Premiere Pro. Detail on individual chart types is limited in the source information, so check the developer's page for the full list of included components.
