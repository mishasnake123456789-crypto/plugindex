What Snapmesh - Blender Photogrammetry Workflow For Mac Os does

Snapmesh connects Apple's Object Capture APIs to Blender so photos become photorealistic 3D models on macOS. Computation runs in the background and the finished model is imported straight into Blender.

Automatic scaling and alignment can match a target bounding box or follow the cameras, and output can be saved as GLB, USDZ or FBX, with textures embedded or kept in folders. Presets assist the computation. Useful for scanning real objects. It brings scanning into a single workflow on Mac, sparing users from juggling separate capture applications and manual imports.

Key features

  • Apple Object Capture photogrammetry
  • Background processing with direct import
  • Auto scale and align
  • Export to GLB, USDZ or FBX
