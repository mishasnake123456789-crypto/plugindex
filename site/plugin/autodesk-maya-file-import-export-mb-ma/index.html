What Autodesk Maya File Import-Export (.Mb .Ma) does

This add-on brings Maya-native file handling to Blender. You can bring in and send out .mb and .ma assets directly, without conversion through another format first.

It works by launching Maya's mayapy.exe Python interpreter behind the scenes, so Maya must be installed locally, though it does not need to be open. Geometry and related scene data move between the two programs. Useful for pipelines that mix Maya and Blender. It is a practical bridge for studios and freelancers who receive Maya files but prefer to work in Blender.

Key features

  • Direct .mb and .ma import and export
  • Uses Maya's mayapy.exe in the background
  • Maya need not be open
  • Requires a local Maya install
