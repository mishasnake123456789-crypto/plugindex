What Voxel Animater does

Voxel Animater converts an image sequence into a field of animated 3D shapes inside 3ds Max. A primitive is generated for every pixel, and its length changes according to the pixel's value, producing a moving bar-graph or pixel-sculpture effect across the frames.

You can choose the voxel shape, either Box, Chamfer Box, Capsule or Spindle, and adjust size, spacing, base height and maximum height. Color can be solid or randomized per pixel. It is aimed at motion designers who want to build stylized data-like visuals or abstract displays from footage and graphics without constructing each element by hand.

Key features

  • Box, Chamfer Box, Capsule or Spindle voxels
  • Adjustable voxel size and spacing
  • Base height and maximum height controls
  • Solid or per-pixel random color
  • Animates a primitive per pixel across an image sequence
