Presets and a Geometry Nodes setup for drawing with radial and mirror symmetry in Blender Grease Pencil.

What Grease Pencil Radial Symmetry does

This pack lets you draw with several symmetry modes in real time using Grease Pencil, producing complex mandala-like artwork quickly. A Geometry Nodes setup handles radial symmetry, with segments and orientation changeable on the fly.

It offers up to 20 radial segments, mirror presets on the X and Z axes and a frame symmetry preset. Two versions are supplied: a basic one for GPv2 (Blender 2.9 to 4.4+) and an advanced one for GPv3 (Blender 4.3+). An 18-page PDF guide, four demo files and future updates come with it.

Key features

  • Radial symmetry up to 20 segments
  • Real-time X and Z mirror presets
  • Frame symmetry preset
  • GPv2 and GPv3 versions
  • PDF guide and four demo files
