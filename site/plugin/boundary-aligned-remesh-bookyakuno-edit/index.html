What Boundary Aligned Remesh [Bookyakuno Edit] does

Boundary Aligned Remesh is a Blender plugin edited by Bookyakuno. It remeshes while preserving open edges, sharp angles and other defining edges, so important shapes survive.

It works well for meshes taken from high poly sources and geometry generated from cloth, text or vector curves. The tool is found under Mesh Data properties, in the Sculpt menu, and in the 3D View's right-click menu. Useful for cleaning up dense or irregular meshes.

Key features

  • Keeps open edges and sharp angles
  • Good for cloth, text and curve-derived geometry
  • Available in several menus
  • Option-driven remeshing
