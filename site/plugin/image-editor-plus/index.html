Blender add-on that adds fills, color adjustments, filters and normal map generation to the Image Editor.

What Image Editor Plus does

Image Editor Plus extends Blender's UV/Image Editor so common image edits no longer need Photoshop or GIMP. Operations include clearing, filling, cropping, flipping, rotating, resizing the canvas and offsetting.

Color adjustments cover hue and saturation, brightness and contrast, gamma, curves and color replacement. Filters offer blur, sharpen, noise, pixelize, make seamless and normal map conversion from a height map. Rectangle selections can be copied and pasted as movable, rotatable, scalable layers. Edits work on packed or unpacked images and show on the 3D model immediately.

Key features

  • Clear, fill, crop, flip and rotate tools
  • Hue, brightness, gamma and curve adjustments
  • Blur, sharpen, noise and pixelize filters
  • Make seamless and normal map generator
  • Selection copy and paste as layers
