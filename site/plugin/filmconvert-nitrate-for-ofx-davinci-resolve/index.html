What FilmConvert Nitrate for OFX (DaVinci Resolve) does

FilmConvert Nitrate gives DaVinci Resolve footage the appearance of photographic film. It provides nineteen motion and still film stocks, each adapted to the color science of the camera used so the result stays believable.

Cineon log emulations let you reduce contrast and saturation while preserving the stock's color character. Grain is modeled according to color and exposure, with a response curve for highlights, midtones and shadows, and each stock has curve controls for roll-off and per-channel tweaks. It is delivered as an OFX plugin, so colorists can add it to a node like any other effect and finish a grade with an analog feel.

Key features

  • 19 motion and still film stocks
  • Cineon log emulations
  • Grain modeled by color and exposure
  • Custom curves per stock
