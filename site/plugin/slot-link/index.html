What Slot Link does

Slot Link, by mars, helps manage Blender projects that contain multiple separate animations. It handles the repeated work of unlinking and linking Actions and Slots, and lets you specify which actions and slots are animating each item.

An action can be re-applied at any time with the Link Slots button. No special permissions are needed to install or run it, and it requires Blender 4.5 LTS or newer.

Key features

  • Automates Action and Slot linking
  • Re-apply with Link Slots
  • Specify what each action animates
  • Suited to multi-animation projects
  • Blender 4.5 LTS and newer
