What Lazy Keyset does

Lazy KeySet speeds up simple keyframe animation in Blender. It builds motion graphics style movements in a few clicks, using stepping, sync key tools and two-point animation between transform values.

Stepping offsets selected keys, with an option that follows selection order for a chosen sequence. Sync Key Tools edit keys at the current frame or over a range without selecting them in the dope sheet. Shape keys can be edited indirectly through bones sharing their names, and a button creates those bones. It suits quick motion design and staggered animations.

Key features

  • Stepping of selected keyframes
  • Selection-order sequencing
  • Sync Key Tools for current frame or range
  • Shape key control via named bones
