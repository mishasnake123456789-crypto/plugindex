What Sapling Tree Gen does

Sapling Tree Gen builds procedural trees in Blender from adjustable parameters. Written by Andrew Hale, Aaron Buchler and CansecoGPC, it was part of the add-ons bundled with Blender 4.1 and is now offered as an extension with limited support.

The generator is found in the 3D viewport under Add > Curve. Version 0.3.7 moved to action slots and requires Blender 4.4 or newer. No special permissions are needed and the license is GPL v3 or later. Environment artists and game developers can generate varied trunks and branches for foliage instead of modeling every tree.

Key features

  • Parametric tree generator
  • Found in Add > Curve
  • Version 0.3.7 uses action slots
  • Requires Blender 4.4 or newer
