What gizmoControl does

gizmoControl is a macroscript by Martin Breidt for 3ds Max. It ties a modifier gizmo's transform to a separate scene object, so the gizmo follows that control object even when it is keyframed or becomes a child of another node.

It works with any modifier gizmo, such as the ones on Slice, UVW Map, Displace or Symmetry, which opens up complex modifier animation. Holding Shift on the Link button preserves the initial offset, and holding it on Reset keeps the current transformation while dropping the link. Another button removes the scripted controller. Merge and Xref links behave correctly, as does copying and pasting a modifier, and the tool installs under the MB Tools category.

Key features

  • Links any modifier gizmo to a control object
  • Control object can use any controller or be linked to any node
  • Shift on Link keeps the initial offset
  • Shift on Reset keeps the current transform while unlinking
  • Works with Merge, Xref and modifier copy and paste
