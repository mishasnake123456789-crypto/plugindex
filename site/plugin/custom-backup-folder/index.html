What Custom Backup Folder does

Custom Backup Folder, by FrankWE, adds tools that improve how Blender's Save Version backups are handled, including where they are kept. It is listed under System.

Open source under GPL-3.0-or-later, it requires Blender 4.2.0 or newer.
