What Procedural Uv To Real Uv does

Procedural UV to Real UV bridges procedural UVs, such as those from Geometry Nodes, and real UV maps that can be edited in the UV Editor. It runs across every mesh in the scene or on selected objects only.

Make Real adds Texture Coordinate and Mapping nodes to materials, and Make Procedural reverts them. It is useful when exporting procedural models or finishing textures by hand. Day to day, that covers convert all or selected meshes, make Real adds mapping nodes and make Procedural reverts.

Key features

  • Convert all or selected meshes
  • Make Real adds mapping nodes
  • Make Procedural reverts
  • Editable in the UV Editor
