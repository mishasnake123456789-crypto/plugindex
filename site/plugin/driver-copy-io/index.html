What Driver Copy IO does

Driver Copy IO makes drivers portable. It exports driver data as JSON files, or places it on the clipboard as text, and pastes it onto other objects or into separate Blender files using full data paths.

All variables and settings are preserved, so the transferred driver behaves like the original. Riggers who reuse control systems between characters or projects can avoid rebuilding them by hand.

Key features

  • JSON export and import of drivers
  • Clipboard copy and paste as JSON strings
  • Uses full data paths
  • Preserves variables and settings
