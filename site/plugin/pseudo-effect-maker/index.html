What Pseudo Effect Maker does

Pseudo Effect Maker from BatchFrame Software helps After Effects artists assemble their own effect control sets. Controls are added with a click and arranged by drag and drop, which beats editing XML by hand.

Changes apply without restarting After Effects, and controls can be modified while you work. A selected control can be replaced by the updated version without losing expressions or keyframes. Warnings and errors flag issues or conflicts early, and the interface is customizable for fast access. It suits anyone who relies on expression controls and wants them in organized groups.

Key features

  • Add controls with a click
  • Drag-and-drop organization
  • Apply changes without restarting After Effects
  • Replace controls while keeping expressions and keyframes
  • Warnings for conflicts before you start
