Selects the mirrored counterpart of a Blender mesh selection across X, Y or Z, with tolerance control.

What Mirror Helper does

Mirror Helper aids symmetrical modeling. Mirror Select instantly selects the mirrored version of what you have selected across any axis.

Select All Mirrored locates every vertex that has a mirror partner, even on complex meshes, with a tolerance setting for slightly asymmetrical models. Useful for symmetry cleanup and selective editing. It saves effort in cases where a model is almost symmetrical and you need to see where it is not. Modelers fixing asymmetry, checking symmetry or selecting matching parts for edits will use it often.

Key features

  • Mirror Select across any axis
  • Select All Mirrored
  • Adjustable tolerance
  • Works on complex meshes
