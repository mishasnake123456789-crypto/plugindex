A set of four Blender sapling presets that generate realistic trees, each randomizable with one value.

What Unlimited Trees does

Unlimited Trees extends Blender's Sapling add-on with presets for realistic tree species. By changing a single value, each preset produces a different tree, so a scene can be filled with natural variety instead of repeated copies.

The species provided are Linden, Oak, Ash and Dawyck, each with leaf and bark materials that vary randomly. One slider prepares the foliage for an autumn look. In total there are sixteen trees: four presets plus four render-ready trees per species. Documentation and tutorials are included. Environment artists and archviz designers populating landscapes will find it useful.

Key features

  • Four presets: Linden, Oak, Ash and Dawyck
  • Random variation from changing one value
  • Leaf and bark material for each species
  • Autumn slider
  • 16 trees including render-ready versions
