What theSauceCode does

theSauceCode from Leshone Limited transforms footage in an After Effects comp into ASCII art made of characters. It captures frames from the comp and opens a dedicated editor where adjustments appear in real time.

Results export as PNG sequences with alpha transparency, ready to composite. Procedural animation effects and an Evolution system interpolate parameters across the timeline. Characters can be customized with fills and strokes, and each effect instance has an isolated session, so several ASCII treatments can run at once with 1:1 rendering.

Key features

  • Footage to character-based ASCII art
  • Dedicated real-time editor
  • PNG sequence export with alpha
  • Procedural animation and Evolution system
  • Isolated sessions per effect instance
