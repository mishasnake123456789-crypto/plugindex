Blender precision drawing tool for Edit Mode with a full snapping system plus edge divide and 3D cursor orientation.

What Geosketch does

GeoSketch lets you sketch and modify geometry precisely in Blender, backed by a complete snapping system.

The Draw tool works in Mesh Edit Mode, handling intersections and overlaps automatically and making precise cuts on existing geometry. Snapping covers a Dominant Plane, object snapping, direction snapping, distance unit snapping and angle snapping. Holding Shift locks line direction, and Edge divide and Orient 3D Cursor utilities are included. It is aimed at modelers who want CAD-like accuracy while drawing directly in the viewport.

Key features

  • Draw tool in Mesh Edit Mode
  • Automatic intersection and overlap handling
  • OSNAP, DSNAP, USNAP and ASNAP snapping
  • Shift to lock direction
  • Edge divide and Orient 3D Cursor
