Brings Mocha planar tracks into After Effects for stabilized precomps, corner pins, masks and 2D property tracking.

What mamoworld MochaImport+ does

mamoworld MochaImport+ links the Mocha planar tracker to After Effects. It can build stabilized precomps in which the tracked region stays still, so retouching, clone-brush work or inserted objects reapply to the original perspective afterward.

Tracking data is expression driven, so one keyframe holds the movement and extra keyframes tween automatically. It moves masks and 2D properties with a track, applies corner pins including a bezier warp version for curved surfaces, and supports many third-party corner pin plugins. A Stabilize Rig smooths clips, and KBar and scripting support allow button access.

Key features

  • Stabilized precomps for retouching and re-lighting
  • Expression-driven tracking data
  • Moves masks and 2D properties with a Mocha track
  • Bezier Warp Corner Pin for curved surfaces
  • Supports popular corner pin plugins and KBar
