What Blender-Hopper does

Blender-Hopper connects Blender to the Grasshopper plugin, opening a data channel for parametric modeling workflows. Instead of exporting files back and forth, geometry and information can be read and written across both applications.

You can read, write and edit objects with their location, rotation and scale, handle mesh vertices, edges and faces, and reach neighbors, vertex groups and attributes. Multiple geometries can be added through rules, and it can be combined with other Blender add-ons and Grasshopper plugins. Architects and designers using parametric tools alongside Blender will find it streamlines iteration.

Key features

  • Read, write and edit objects and transforms
  • Mesh vertices, edges and faces access
  • Vertex groups and attributes control
  • Add multiple geometries through rules
