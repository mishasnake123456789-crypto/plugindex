What ShotList Creator 3 does

ShotList Creator 3 converts markers on a DaVinci Resolve timeline into an Excel shotlist, complete with thumbnail stills. It is meant for editors and VFX teams who need to hand off lists of shots with the relevant metadata.

Metadata columns are selected freely and ordered by drag and drop, and layouts can be stored as presets with a default setup. An optional TrackDetails sheet reports overlap diagnostics per marker and per track, and an Advanced mode allows strict manual track targeting. Marker processing is API based for stable results, and the exported file is size-optimized and simple to convert to PDF or Google Sheets.

Key features

  • Marker-to-Excel export with thumbnail stills
  • Drag-and-drop metadata column ordering
  • Savable layout presets
  • Optional TrackDetails sheet with overlap diagnostics
  • API-based marker processing and compact export
