Developer: Akimbo Studio

FreeAfter Effects

After Effects script that inserts or removes time across keyframes, comp durations and layer endpoints.

What Add Time does

Add Time by Akimbo Studio helps After Effects artists change the length of a project after the fact. It injects time at any level, moving keyframes, adjusting composition durations and extending layer endpoints, and it can also subtract time.

Add Time markers appear in green and Subtract Time markers in red. You can choose to ignore locked layers or guide layers, and switch between working in frames and in time. The interface is text-based, suited to making last-minute changes to timing without re-timing everything manually.

Key features

  • Inject time into keyframes, comps and layer endpoints
  • Add and subtract time
  • Green and red markers show the operation
  • Ignore locked or guide layers
  • Switch between frames and time
