Blender material node that generates seamless Greek ornamental patterns with color, seed and bump controls.

What Greek Patterns does

Greek Patterns packs decorative designs into a single material node. Five distinct patterns are on offer, and the node makes them seamless so they can cover surfaces without visible repeats at the edges.

Color variation runs from 0, which keeps the original scheme, to 1, which gives wholly different colors. A seed input yields different combinations, scale sets the pattern size, and a bump factor feeds the BSDF output. Useful for architecture, pottery, borders and stylized props.

Key features

  • Five Greek ornamental patterns
  • Color variation and seed controls
  • Scale parameter
  • Bump factor for BSDF output
