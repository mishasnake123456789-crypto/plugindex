What Add Bloom Back [Blender 5 Update] does

Add Bloom Back is a Blender extension from Canopy Games that returns a feature removed in Blender 4.2: the bloom toggle. It works for both Eevee and Cycles renders.

One click enables the effect, and pressing the Render View button switches it on automatically. Behind the scenes it adds a glare node set to bloom in the compositor and checks first whether one already exists, so nothing gets duplicated. Changing the add-on parameters updates those compositor settings. This version is rewritten for Blender 5 and still supports 4.2 through 4.5, with documentation included.

Key features

  • One click enables bloom in Eevee and Cycles
  • Adds a compositor glare node set to bloom
  • Detects an existing glare node first
  • Render View button turns bloom on automatically
  • Works on Blender 4.2 through 5
