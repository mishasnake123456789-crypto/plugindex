Binds keyboard shortcuts to Blender N-panel tabs so a key press opens the chosen sidebar panel.

What Panelpilot does

PanelPilot is a Blender extension that gives N-panel tabs their own hotkeys. Press the assigned key and the tab opens, and the sidebar appears automatically if it was hidden.

Shortcuts are rebound by clicking and pressing the new key, with no key codes to type, and each row has a reset button that turns red once modified. It helps artists who use many add-ons with sidebar panels and want to reach them without hunting through tabs.

Key features

  • Hotkeys for specific N-panel tabs
  • Sidebar opens automatically if hidden
  • Click-and-press shortcut capture
  • Per-row reset that turns red when changed
