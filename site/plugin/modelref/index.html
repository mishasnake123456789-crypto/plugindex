Blender add-on that manages reference images through dedicated cameras, each with its own opacity, scale and offset controls.

What Modelref does

ModelRef organizes reference material in Blender by giving each image its own camera. From one panel you assign images and adjust opacity, scale, rotation, X and Y offset and focal length for each camera.

Front, side and custom reference views can be switched quickly, and cameras can be created, duplicated or deleted from the panel. The Pro edition removes the camera limit and adds near and far movement, move and rotate on each axis, precision mode, and model controls for a selected object or group, along with reorderable sections. It is aimed at bust sculpting, likeness work and anatomy studies.

Key features

  • One reference camera per image
  • Per-camera opacity, scale, rotation, offset and focal length
  • Front, side and custom views with quick switching
  • Create, duplicate and delete cameras from the panel
  • Pro: unlimited cameras and precision controls
