What Shotstack: The Ultimate One-Stop Shot & Render Manager does

Shotstack is a camera and render management add-on. Its virtual camera system gives each camera its own resolution, automatic switching, token-based naming, Quick Focus and a radial pie menu for selecting cameras.

A batch render queue and headless CLI rendering handle output, with light linking and GPU assignment per shot. It suits animators and studios managing many shots in a single file. Because it covers many shot-level controls in one place, it suits productions with long shot lists.

Key features

  • Virtual cameras with independent resolutions
  • Token-based naming and Camera Pie Menu
  • Batch render queue and CLI rendering
  • Light linking per shot
  • GPU assignment per shot
