Applies live procedural animations such as wave, bounce and noise to many Blender objects, with optional baking to keyframes.

What Object Animator does

Object Animator runs over thirty live animation types on many objects together, such as wave, bounce, float, shake, pulse, spiral, jitter and noise.

You can preview results in real time, fine-tune phase, offset and axis, and randomize speed and amplitude per object. Once satisfied, the animation can be baked to keyframes. Motion designers can create organic, staggered movement across groups without keyframing each item. Since the animation runs procedurally, changes to settings update immediately instead of requiring repeated keyframe edits.

Key features

  • 30+ procedural animation types
  • Live preview across multiple objects
  • Phase, offset and axis control
  • Randomized speed and amplitude per object
  • Bake results to keyframes
