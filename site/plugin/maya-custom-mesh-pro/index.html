What Maya Custom Mesh Pro does

Maya Custom Mesh Pro puts a set of enhanced primitives at the top of Blender's Add Menu. The shapes come with built-in controls so you can set up geometry before you start modeling.

The cube accepts width, height, depth and subdivisions, the sphere can be cut in half with gap filling, and the cylinder has open ends, height subdivisions and poking options. The cone has a beveled top and poked bottom, and the torus offers radius, thickness and subdivision settings. Subdivision, bevel and face poke tools are built in.

Key features

  • Adjustable cube with width, height, depth and subdivisions
  • Sphere that can be sliced in half
  • Cylinder with fill gap and poking options
  • Cone and torus with editable parameters
  • Appears in the Add Menu
