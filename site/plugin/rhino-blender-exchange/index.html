What Rhino Blender Exchange does

ShoeMaster's Rhino Blender Exchange (RBE) lets modelers pair Rhino's precision with Blender's rendering and animation. Meshes travel between programs in either direction with one click.

Updates can target all meshes or specific ones, simple PNG texture maps are preserved, and curves move both ways. Intermediate folders can be cleaned or deleted, and the UP axis between the two is configurable. It targets Rhino 8 with Blender 4.4 and 4.5. Designers and architects skip manual exporting and importing.

Key features

  • One-click mesh export and import
  • Selective mesh updates
  • Preserves PNG texture maps
  • Curves in both directions
  • Configurable UP axis
