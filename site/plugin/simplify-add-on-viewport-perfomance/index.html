What Simplify+ Add-On - Viewport Perfomance does

Simplify+ builds on Blender's own Simplify to make heavy scenes easier to handle. It works with all modifiers except Grease Pencil ones, and an Expose Wizard button reveals every modifier toggle from active view layers in one click.

Shift+click a toggle to select the objects carrying that modifier, or use Select All by Modifier from the Select menu, F3 search or Quick Favorites. Restore to Collection can be limited to the selection with Shift+click, modifiers can be renamed without losing their state, and shortcuts are customizable.

Key features

  • Expose Wizard for all modifier toggles
  • Select objects by modifier
  • Select All by Modifier menu entry
  • Restore to Collection selection only
  • Rename modifiers while keeping status
