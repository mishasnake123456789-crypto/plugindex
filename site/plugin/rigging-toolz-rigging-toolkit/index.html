What Rigging Toolz - Rigging Toolkit does

Rigging Toolz collects a rigger's recurring chores into one Blender add-on. It targets character artists, riggers, animators and game developers who spend long hours on weights, bones and export prep.

One click sets up a weight-paint session with X-Ray on, deform bones visible and the character isolated, and extra operators transfer, merge or clear weights. For Rigify, constraints, drivers and custom shapes survive regeneration because the add-on reapplies them. Batch commands change rotation modes or B-Bone scaling rig-wide. A cleanup pass strips unused vertex groups, stale UV maps and custom normals that cause export trouble.

Key features

  • One-click weight paint setup
  • Weight transfer, merging and cleanup operators
  • Non-destructive Rigify regeneration
  • Batch bone operations across the rig
  • Scene cleanup for export-ready files
