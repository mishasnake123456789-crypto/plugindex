What Cad_Dimensions does

Cad_Dimensions adds CAD-style dimensioning to Blender for measuring models. Buttons for the X, Y and Z axes create measuring tools aligned to each one.

Text location, size and orientation are adjustable, and a Cadify button changes the viewport look to resemble ArchiCAD. Version 2.0.0 added rudimentary imperial unit conversion. No special permissions are needed and Blender 4.2 LTS or newer is required. Architects and product designers annotating models gain clear dimensions.

Key features

  • Axis-aligned dimension tools
  • Adjustable text location, size and orientation
  • Cadify viewport look
  • Basic imperial conversion in 2.0.0
