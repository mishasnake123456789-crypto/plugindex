What Null Game Toolkit does

Null Game Toolkit covers collision generation, LOD creation and export for game assets. It offers six collision types: Box, Sphere, Capsule, Convex Hull, Mesh and Accurate.

Smart shape detection analyzes mesh geometry and suggests the best collision type for one-click generation. LODs are made with custom reduction settings, and bulk export supports FBX, OBJ and GLTF. Game artists can handle these steps in one place. Key capabilities include six collision types and smart shape detection.

Key features

  • Six collision types
  • Smart shape detection
  • LOD generation with custom reduction
  • Bulk FBX, OBJ and GLTF export
