What Setup Static Object does

Setup Static Object, by Bookyakuno, converts edited objects into static meshes suitable for games. It applies all edit states and integrates multiple objects along the way.

Modifiers, linked duplicates and transforms are fully applied, and each process can be switched on or off. A Remove the Feature Edge option strips feature edges to help build a low-poly model, with edge types including Select, Crease, Bevel, Seam, Sharp and Freestyle. It is found under File > Export or with Alt+Ctrl+E in Object Mode.

Key features

  • Applies edit states into one static mesh
  • Merges multiple objects, applying modifiers and transforms
  • Optional feature edge removal for low poly
  • Alt+Ctrl+E shortcut
