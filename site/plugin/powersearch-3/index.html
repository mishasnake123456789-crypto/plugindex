A search engine for Premiere Pro projects that indexes captions and transcripts so you can find content fast.

What PowerSearch 3 does

PowerSearch 3, by Digital Anarchy, indexes a Premiere Pro project so everything in it becomes searchable, much like a web search. SRT files are indexed, which lets you search all captions at once.

Adobe Sensei transcripts are supported through SRT import into Premiere or Transcriptive Rough Cutter, and quotes give more precise matching. Productions are supported, with buttons to switch between indexed projects, and Instant Loading skips re-indexing. Indexing and search are faster in this version.

Key features

  • Indexes projects and SRT captions
  • Supports Adobe Sensei transcripts
  • Quoted search
  • Premiere Productions support
  • Instant Loading without re-indexing
