What UI Animation Render does

UI Animation Render records an animation of the Blender user interface. It was a bundled add-on in Blender 4.1 and is now offered as a standalone extension with limited support.

It is available in the View3D sidebar's View tab, or with Ctrl+Shift+F12, and supports Blender 4.2 LTS and newer. Tutorial makers and documentation authors capturing workflow demos can use it instead of screen recorders. It is aimed at people who document or teach Blender workflows and want an animation of the interface itself.

Key features

  • Renders animations of the UI
  • Sidebar View tab or Ctrl+Shift+F12
  • Standalone extension
  • Supports Blender 4.2 LTS and newer
