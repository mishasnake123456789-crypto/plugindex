What Bake Geometry Animation does

Bake Geometry Animation converts procedural motion into real mesh data. It bakes a single geometry motion object, handles the motion of instances inside the node tree and supports curved objects.

Results can be exported to glTF, which makes it possible to move animation produced by geometry nodes into game engines and other software that cannot evaluate Blender's node systems.

Key features

  • Bakes Geometry Nodes animation to mesh
  • Single object and instance baking
  • Curved object support
  • glTF export
