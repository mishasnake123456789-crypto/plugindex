What Ultimate Vertex Color Pro does

Ultimate Vertex Color Pro is a Blender add-on for working with vertex colors on many objects. A Turbo Mode handles thousands of objects and is described as much faster than standard methods, and colors are preserved through mesh operations.

One-click options color entire scenes with unique, random, polycount-based or per-polygon values, and per-face editing applies custom colors to individual faces. Game artists and technical artists can use it for masks, ID maps and stylized shading.

Key features

  • Turbo Mode for thousands of objects
  • Unique, random, polycount and per-polygon coloring
  • Per-face color editing
  • Colors preserved through mesh operations
