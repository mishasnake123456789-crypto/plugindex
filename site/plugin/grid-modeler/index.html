Blender add-on for grid-based modeling with boolean cuts from drawn shapes and stacking geometry.

What Grid Modeler does

Grid Modeler lets you build 3D models in Blender by working on a grid. Shapes drawn on the grid plane cut into objects with booleans, and new mesh can be created on top of existing surfaces.

Features include boolean slicing, face creation, construction lines and pipes. The grid plane can face any direction, and the arrow keys spin it so connected geometry can be built around an object. It is meant for fast hard surface work such as game props and backgrounds.

Key features

  • Boolean cuts from drawn shapes
  • Boolean slicing
  • Grid plane that orients in any direction
  • Construction lines and pipes
