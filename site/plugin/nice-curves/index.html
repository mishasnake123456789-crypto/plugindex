What Nice Curves does

Nice Curves is a plugin by Nick Hill that creates elegant rounded paths in After Effects. Control points are nulls, so you reshape the curve by moving them, and the original geometry is never altered.

You can add as many control points as you need, edit each one separately or change them all together, and build several paths in one composition. Nick describes it as offering more command than the round corners option in Illustrator. It is handy for flowing lines, connectors and graphic shapes that need soft, consistent corners.

Key features

  • Rounded paths controlled by nulls
  • Nondestructive path rounding
  • Per-point or global adjustment
  • Unlimited control points
  • Multiple paths per composition
