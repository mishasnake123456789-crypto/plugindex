Blender add-on that automatically selects, moves and spaces keyframes in the dopesheet using three modes.

What Autokeyframe does

Autokeyframe automates common keyframe edits in Blender's dopesheet through Select, Move and Spacing modes.

Select mode picks alternating or larger-gap keyframes, such as every third one, and a stop frame ends the selection. Selections can stack without clearing earlier ones, so repeated runs create complex patterns. Move mode shifts selected keys by an amount, and Spacing mode adjusts the distance between keyframes. Handy for retiming. This can speed up cleanup and timing adjustments on long animations.

Key features

  • Select every nth or larger-gap keyframe
  • Stop frame setting
  • Additive selections for patterns
  • Move mode shifts keys
  • Spacing mode adjusts distances
