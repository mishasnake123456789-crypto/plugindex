What Batch Renamer I Octopus does

Batch Renamer I Octopus handles scene-wide object renaming. It supports find-and-replace, regular expressions, prefixes, suffixes and filtering by object type, and shows a live preview before changes are applied.

Prefix and suffix choices include SM_, BP_, PROP_, ENV_ and _LOD0, _LOW, _HIGH, _COL and _BAKED, and you can rename the selection or the entire scene. Great for game asset naming conventions. Under the hood you get find and replace with regex and game-style prefixes and suffixes.

Key features

  • Find and replace with regex
  • Game-style prefixes and suffixes
  • Object-type filtering
  • Live preview before applying
