Blender add-on that brings vertex weight editing to Edit Mode, using selections instead of brushes.

What Handy Weight Edit does

Handy Weight Edit lets you set weights in Blender's Edit Mode without painting. Select vertices with loop select, lasso or hide and unhide, then adjust values directly.

The mouse wheel changes weights uniformly or by a per-vertex gradient, with customizable hotkeys. It includes Smooth Weight, a Copy Weight that reads the last selected vertex, and a simple Normalize, along with Mirror Weight in symmetric and asymmetric modes with custom naming, and bone influence switching. Riggers needing precise control of skin weights work faster.

Key features

  • Edit weights on selected vertices
  • Uniform or gradient mouse wheel adjustment
  • Smooth, copy and normalize weights
  • Mirror Weight with custom naming
