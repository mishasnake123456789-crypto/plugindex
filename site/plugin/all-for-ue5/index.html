What All for UE5 does

All for UE5 is a MaxScript that smooths the path between 3ds Max and Unreal Engine 5. It builds a folder structure from layer names and exports all or selected scene objects to Unreal as FBX.

Position, rotation and scale can be copied both ways between the two applications, and cameras and lights transfer too, including VRayPhysicalCamera, CoronaCam, VRayLight, CoronaLight, VRaySun and CoronaSun. Colors are copied with optional gamma adjustment. Separately or together, it can create UVW Map and Unwrap UVW modifiers, and it configures Luoshuang's GPULightmass INI file. Archviz and game artists moving scenes into Unreal can cut down the manual steps.

Key features

  • Folder structure built from 3ds Max layer names
  • FBX export of all or selected objects to Unreal
  • Two-way copy of position, rotation and scale
  • Camera, light and color copying with gamma option
  • UVW Map and Unwrap UVW creation plus GPULightmass INI setup
