What Selects all UV islands on one UDIM does

This small Blender add-on highlights all islands, shells and their matching faces on a particular UDIM tile. It removes the guesswork when you need to grab everything that lives in one tile of a multi-tile layout.

Press Alt+L in the UV Editor or use the Select menu entry named Select UDIM Faces & Islands. Negative UDIM regions are handled too. Texture artists working with multi-tile UV layouts on film or game assets can isolate a tile quickly.

Key features

  • Selects all islands on a chosen UDIM
  • Alt+L shortcut in the UV Editor
  • Menu entry under UV Editor Select
  • Handles negative UDIM regions
