Blender add-on for generating dynamic physics-driven curves, ropes and rigid-body structures by pressing J and Y.

What Attachify Pro does

Attachify Pro creates physics-driven connections in Blender with simple keystrokes. Hit J while hovering an object to create dynamic curves that tie objects together, and press Y to draw lines that wrap around them.

More than 25 curve types cover ropes, plants, chains and sci-fi forms, each with adjustable parameters. Passive and active rigid bodies let you build bridges, structures and dynamic environments, and simulations can be hidden or revealed for a clear view. It works with Cycles and Eevee and includes documentation.

Key features

  • Press J to connect objects with dynamic curves
  • Press Y to wrap objects
  • 25+ curve types such as ropes and chains
  • Passive and active rigid body structures
  • Hide and reveal simulations
