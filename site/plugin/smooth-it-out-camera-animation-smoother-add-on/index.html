What Smooth It Out - Camera Animation Smoother Add-On does

Smooth It Out cleans up shaky or jerky camera motion. A single click adds in-between keys and smooths every keyframe of the active camera.

A Smooth Passes slider sets the number of iterations, and Revert returns to the original keyframes from the backup taken before the last smoothing. An Erase option removes only the added keys. Animators refining handheld-style or recorded camera moves can iterate safely. Since the backup is kept, you can experiment with stronger settings without fear of losing the original motion.

Key features

  • One-click smoothing with in-betweens
  • Smooth Passes slider
  • Revert from backup
  • Erase option for added keys
