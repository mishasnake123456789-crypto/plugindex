What 3MF Import/Export does

3MF Import/Export, by Clonephaze, lets Blender exchange geometry, materials, textures and metadata through the 3MF format used in 3D printing. It follows the 3MF Core Specification v1.4.0 in both directions.

Packaging is correct, and parsing recovers from imperfect or partly invalid files. Base Materials and PBR Materials extensions map to Principled BSDF nodes, with textured PBR maps preserved across round-trips, and multi-color slicer paint workflows are covered. Makers using multi-material printers can move colored models between Blender and slicers.

Key features

  • 3MF Core Spec v1.4.0 import and export
  • Recovery-oriented parsing
  • Base and PBR materials mapped to Principled BSDF
  • Multi-color slicer paint support
