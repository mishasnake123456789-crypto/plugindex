What QuickImporter does

QuickImporter from mamoworld tools replaces the standard import window with a quicker one. Fuzzy keyword search sorts through thousands of files and still finds matches when the search term contains typos.

Hovering over a file icon plays audio, a media player previews video, and image sequences show as one result instead of hundreds of frames. Thumbnails use Quick Look on Mac for most file types, while Windows shows JPG and PNG only. One licence covers After Effects, Premiere Pro and Audition. Editors and artists who import from large drives will find assets faster.

Key features

  • Fuzzy keyword search tolerant of typos
  • Hover-to-play audio preview
  • Video preview player
  • Image sequences as a single result
  • One licence for three Adobe apps
