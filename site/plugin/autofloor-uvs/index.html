3ds Max script that maps tiled or parquet surfaces with randomized per-element UVs to hide visible texture repetition.

What AutoFloor UVs does

AutoFloor UVs deals with surfaces assembled from many separate pieces, such as tiles or parquet, in 3ds Max. It applies planar mapping and edits each element's UVW coordinates so the same texture does not look repeated across the whole surface.

Each element can receive a random shift on the U and V axes, random mirroring on U and V, and random rotation on the W coordinate. Interactive resizing offers a lock for the height to width ratio, and settings used previously on the same object can be reloaded. It works on vertical and horizontal surfaces, whether generated by Floor Generator or modeled by hand.

Key features

  • Planar mapping that removes visible repetition
  • Random shift, mirror and rotation per element
  • Interactive resizing with locked aspect ratio
  • Reload settings used earlier on the same object
  • Works on Floor Generator or handmade geometry
