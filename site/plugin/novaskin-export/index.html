What NovaSkin Export does

NovaSkin Export is a Blender plugin from Saviski for scenes that use the Minecraft-style Thomas Rig Legacy. It turns the scene into a browser wallpaper usable in the NovaSkin tool, so the finished look can be changed without rendering again.

Characters leave Blender as meshes that can be re-skinned, carrying a baked light atlas. In the browser, any skin can be dropped in and lit using the scene's baked light, with classic or slim arms and toggles for hat, jacket, sleeve and pants overlays. Scenery objects can also be marked for export.

Key features

  • One-click export of re-skinnable characters
  • Baked light atlas for consistent lighting
  • Classic or slim arms and overlay toggles
  • Mark scenery objects for export
