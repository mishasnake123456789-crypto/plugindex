Blender add-on that packs UV islands at uniform scale and generates a stretch checker texture.

What Tidy Uv does

Tidy UV cleans up UV layouts in Blender. It resizes and packs all islands to a consistent scale and fits them within the 0 to 1 space, reducing wasted area and overlap.

A built-in checker texture generator reveals stretching and distortion, and Quadrify Islands converts complex islands into cleaner quad-based layouts. It is compatible with Blender's native tools and renders with Cycles and Eevee, making it useful for game assets and texture artists.

Key features

  • Uniform island scale and packing
  • Packs within 0-1 UV space
  • Checker texture for stretch detection
  • Quadrify Islands for cleaner layouts
