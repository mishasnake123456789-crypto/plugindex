3ds Max script replacing the default Measure Tools with modes for distance, angle, length, area and object size.

What Smart Measure does

Smart Measure is built to take the place of the default Measure Tools in 3ds Max. Separate modes cover distance between two points or objects, the angle formed by picked points, the total length of a polyline, the area enclosed by points, and the dimensions of chosen objects.

Live Measure reads values automatically as soon as you select an object. Auto Memory stores measured values in a history, while Auto Clipboard copies the result when a command finishes, which makes it easy to paste numbers into notes or spreadsheets. Architects, product visualizers and modelers can use it for quick, repeatable dimension checks.

Key features

  • Measure distance, angle, length, area and objects
  • Live Measure on object selection
  • Auto Memory keeps a history of values
  • Auto Clipboard copies results when a command ends
  • Replaces the default Measure Tools
