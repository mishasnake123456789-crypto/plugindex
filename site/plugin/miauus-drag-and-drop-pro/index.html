What miauu's Drag&Drop Pro does

Drag&Drop Pro by miauu adds smart handling of files dropped into 3ds Max from Windows Explorer. Dropping a file automatically relinks all missing textures, and dropped proxy files open in the viewport, with V-Ray, Corona and FStorm formats supported.

Matching .mat files are assigned to proxies, and dropping .mat, .jpg or .png files loads matching proxies. A .mat dropped on an object applies to it, or opens in Slate. Shortcuts are resolved to their targets, and .7z, .zip and .rar archives are extracted for processing. Create Layer Per File puts merged objects in a layer named for the file, and contents are grouped and offset to avoid overlap.

Key features

  • Auto relink of missing textures on drop
  • Opens V-Ray, Corona and FStorm proxies
  • Auto-assigns matching .mat files and proxies
  • Resolves shortcuts and extracts 7z, zip and rar archives
  • Layer per file, grouping and offsetting of merged content
