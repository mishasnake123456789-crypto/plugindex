Color Palette

Developer: MingWitty

FreeBlender
Download Free

Blender add-on that stores Shader Editor node colors on sticky notes so they can be reapplied to other nodes, models or files.

What Color Palette does

Color Palette lets you collect colors from material nodes. Dropping a node's color on a sticky note saves it, and the color can be picked up and applied again afterward.

Saved colors can be used on nodes in other models or other files, which supports consistent palettes across a project. There is also a GPU palette option, which the developer warns can affect performance. Stylized artists keep color schemes together.

Key features

  • Records material node colors
  • Drag a color to a sticky note to save
  • Reapply saved colors in other models or files
  • Optional GPU palette
