What Lm Studio Gobos & Volumetrics does

Lm Studio Gobos & Volumetrics is a lighting extension for Blender covering gobo projection, quick light rigs and volumetric atmosphere. It handles the node work of projecting patterns through a light, so setting up window shadows or colored projections takes seconds.

Gobos can be crisp black-and-white shadow masks or full-color image projections via emission. An Icon Gallery imports your own image or MP4 libraries from a zip, and one click creates Key, Fill and Rim lights tracked to the active subject. Dynamic fog is controlled inside the 3D viewport. Lighting artists and product renderers will find it speeds up studio setups.

Key features

  • Standard and color gobo projection
  • One-click three-point lighting tracked to the subject
  • Icon Gallery for image or MP4 libraries from a zip
  • Automated gobo node generation
  • Procedural atmospheric fog in the viewport
