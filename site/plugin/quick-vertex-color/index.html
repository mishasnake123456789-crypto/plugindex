What Quick Vertex Color does

Quick Vertex Color generates vertex colors automatically for every submesh or loose part of your objects. Parts are grouped by dimensions, so similar-sized pieces share one color.

Colors persist: regenerating recolors only edited objects and leaves the rest unchanged, even if they are selected. The output is useful for ID masks and other workflows. Texture artists and technical artists working with kit pieces get quick color coding. Re-running it after edits keeps earlier assignments stable, so mask references do not change unexpectedly.

Key features

  • Vertex colors for all loose parts
  • Groups parts by dimensions
  • Color persistency on regeneration
  • Useful for ID workflows
