What Boundary Fill does

Boundary Fill, made by RePiece, is a plugin for After Effects aimed at decorating the edges of text. It applies effects directly to text layers and can be driven by text animators, so the decoration follows letters as they animate.

Dynamic Opacity ties fill opacity to the pixels inside the boundary, and Dynamic Size scales the fill with the boundary. Scale By Saved Ratio uses the size stored by Text Save to scale a texture to 100 percent. Position and Opacity let the texture influence text placement and transparency, while Overlap Distance and Overlap Smoothness prevent and soften lines around the boundary.

Key features

  • Applies fills directly to text layers
  • Dynamic Opacity and Dynamic Size
  • Scale By Saved Ratio texture scaling
  • Texture-driven text position and opacity
  • Overlap Distance and Smoothness
