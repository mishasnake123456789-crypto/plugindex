What Shelfmaster - Batch Import & Project Panel does

ShelfMaster is an asset manager for Blender that loads whole folders in a single action. It supports FBX, OBJ, glTF, GLB and .blend files, with guards so that a corrupt glTF does not crash the session.

Imported items are renamed by a {file}_{type}_{idx} rule and grouped into collections per file or type, with smart materials assigned by name or built from textures. A Project panel inspired by Unity provides search, tags and thumbnails. It helps artists dealing with large asset packs.

Key features

  • Bulk folder import for FBX, OBJ, glTF and .blend
  • Safeguards against corrupt files crashing Blender
  • Auto-rename and collection organization
  • Smart materials assigned by name
  • Project panel with search, tags and thumbnails
