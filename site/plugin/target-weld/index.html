Blender modeling add-on for interactively merging vertices or edges by picking a source and target in the viewport.

What Target Weld does

Target Weld brings an interactive welding workflow to Blender. Pick a source component, then choose the target in the viewport, and the two merge, in either vertex or edge mode.

Real-time visual feedback highlights what is being merged so you can see the result before committing. Behavior is configurable, such as how the pick is triggered. It's a fast way for modelers to clean topology and close gaps without using the merge menu repeatedly.

Key features

  • Interactive vertex and edge merging
  • Source and target picking in the viewport
  • Real-time visual highlighting
  • Configurable behavior
