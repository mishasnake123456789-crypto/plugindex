Blender add-on for panel-based parenting with a toggle revealing the parent and a quick children selector.

What Easy Parent does

KVD's Easy Parent simplifies setting parents in Blender. In the panel, pick the children first and the parent last, choose a type and press PARENT.

A toggle reveals which object currently acts as the parent by adding a name suffix in the outliner while on. A select-children button highlights everything belonging to a chosen parent, and clear options with a selectable type work with or without the toggle. Rigging and hierarchy work gets less error-prone.

Key features

  • Panel-based parenting
  • Toggle to reveal the parent object
  • Select children button
  • Clear options with selectable type
  • Name suffix in the outliner
