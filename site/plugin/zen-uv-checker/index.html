What Zen UV Checker does

Zen UV Checker helps spot stretching and scale problems in UV maps. It applies checker textures through a node system, leaving existing materials untouched and without creating new ones.

Setup is one click, with Alt+T as the default shortcut. Color and monochrome checker sets come in various sizes, and a filtering system narrows textures by resolution and by whether they are square or rectangular. You can also import your own checkers. Texture artists verifying unwraps get quick feedback.

Key features

  • One-click checker setup
  • Node system leaves materials intact
  • Color and monochrome sets
  • Filter by resolution and format
  • Import your own checkers
