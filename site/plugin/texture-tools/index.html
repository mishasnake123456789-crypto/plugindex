Blender add-on that keeps UVs and materials inside generated grid meshes so trims and decals are quick to reuse.

What Texture_Tools does

Amal David's Texture_Tools organizes how materials, trims and decals get applied. UV coordinates and a material are saved in a grid mesh generated by the add-on, and these grids can be taken to other projects.

Controls live in the N panel of the 3D Viewport and operate in edit mode; the design assumes quad meshes. A demo video and documentation are provided, with GPL licensing. Environment artists working with trim sheets can apply them across many pieces rapidly.

Key features

  • Stores UVs and material in a grid mesh
  • Quick material, trim and decal application
  • Grids reusable across projects
  • N panel access in edit mode
  • Built for quad meshes
