What Import .PSD as Mesh Planes does

Import .PSD as Mesh Planes, by byebyeLAN, brings layered Photoshop documents into Blender. Each layer becomes a separate mesh plane, so you can build parallax scenes or 2.5D setups straight from the artwork.

Import options include Scale and Z-offset, and it appears under File, Import. Version 1.1.0 parses non-English layer names properly. It is only 5.1 KB, needs no special permissions, works on Blender 4.2 LTS and newer and is released under GPL v3.0 or later.

Key features

  • Each PSD layer becomes a mesh plane
  • Scale and Z-offset options
  • Found under File, Import
  • Non-English layer names supported
  • Only 5.1 KB
