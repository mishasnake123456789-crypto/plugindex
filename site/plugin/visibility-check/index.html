Blender add-on that lists objects and collections whose viewport visibility differs from render visibility, and can equalize them.

What Visibility Check does

Visibility Check flags mismatched visibility settings in Blender before you hit F12 and render a frame with missing objects.

A Check Visibility pass lists objects and collections whose viewport and render visibility differ, covering collections as long as they are not excluded from the Render Layer. Equalize to Render makes settings match across the list. Prevents costly render mistakes. Hidden objects that still render, or visible ones missing from the output, are a frequent source of wasted render time, and this check catches them early.

Key features

  • Lists viewport and render mismatches
  • Collections covered
  • Equalize to Render
  • Check before rendering
