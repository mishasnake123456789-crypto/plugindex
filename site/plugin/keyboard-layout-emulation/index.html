What Keyboard Layout Emulation does

Keyboard Layout Emulation lets people who use layouts like AZERTY or Dvorak keep Blender's default shortcut positions. It emulates the QWERTY shortcuts on the physical keys while text input remains in your preferred layout.

That means tutorials and documentation that refer to default hotkeys still apply, and you do not have to relearn them. It's especially helpful for artists who write in a non-Latin or non-QWERTY layout but model in Blender daily.

Key features

  • Emulates QWERTY shortcuts on other layouts
  • Typing stays in your preferred layout
  • Keeps Blender's default shortcut positions
  • Remaps keymap automatically
