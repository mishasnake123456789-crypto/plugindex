Blender sidebar for managing actions as large buttons that set the frame range and enter Pose mode when switched.

What Animer does

Animer adds a sidebar to Blender for animators who juggle many actions. Each action appears as a button, and choosing one sets the playback range and puts you in Pose mode.

A search field filters the list, and an edit toggle reveals fake user, rename, duplicate and delete tools. You can add a new action that starts with a keyframe at frame 0. Frame rate options, playback controls and an autokey button sit in the same panel, reducing trips to other editors.

Key features

  • Large buttons to switch between actions
  • Auto frame range and Pose mode on switch
  • Search field for actions
  • Toggleable fake user, rename, duplicate and delete
  • New action with keyframe at frame 0
