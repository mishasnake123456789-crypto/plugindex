Blender add-on that applies modifiers to a mesh while keeping its shape keys and drivers intact.

What SKkeeper does

SKkeeper from Nidus automates collapsing a modifier stack on meshes that carry shape keys, something Blender does not allow out of the box. Shape key data and drivers are preserved rather than discarded.

Options include applying every modifier, applying only the topmost subdivision modifier while leaving the rest, or applying a hand-picked selection, each keeping the shape keys. Character modelers preparing meshes for export or further editing can finalize geometry without rebuilding facial or corrective setups.

Key features

  • Apply all modifiers and keep shape keys
  • Apply only the top subdivision modifier
  • Apply chosen modifiers while preserving keys
  • Drivers remain intact
