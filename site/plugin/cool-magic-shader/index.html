What Cool Magic Shader does

Cool Magic Shader lets one scene be rendered in either a realistic or a toon style in Blender. It adds a Magic shader node and N-Panel controls that handle materials, outlines and lighting together, so changing the look does not mean rebuilding shaders.

The node holds a shared object base color, toon settings such as shadow intensity, highlight color and intensity and global light color, and realistic settings for metallic and roughness. A toggle button switches render mode, and an initialization feature imports the toon lights setup and shader node automatically. Stylized renderers wanting both options will save effort.

Key features

  • Magic shader node with toon and realistic properties
  • Toggle button switches render mode
  • Initialization imports the toon lights setup
  • Outline controls in the N-Panel
