Blender add-on that converts particle systems into keyframed objects.

What P2O Converter does

P2O Converter turns particle systems into real objects that can be edited, exported and animated. It saves location, rotation, scale and visibility keyframes across the timeline.

Visibility can use true visibility or scale-to-zero, and Mesh, Armature and Empty types are supported for any system using object instancing. Apply Transforms with optional Make Single User runs in one click, particle sampling converts a percentage for speed, and FBX export is tuned for particle animation. The caching system was rewritten for better performance in large scenes.

Key features

  • Particles to keyframed objects
  • Mesh, Armature and Empty types
  • Particle sampling for faster processing
  • FBX export for particle animation
