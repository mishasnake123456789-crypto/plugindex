Blender add-on that makes orthographic front, top and side reference sheets with UV maps and baked textures in Cycles.

What Orthosnapshot does

OrthoSnapshot creates orthographic views of a model in Blender and turns them into reference sheets. Technical grid overlays appear right in the viewport.

It renders front, top and side views with Cycles, generates optimized UV maps with proportional scaling, and bakes viewport-ready textures using Ray Portal BSDF. The grid has controls for line opacity, scale and thickness, plus XYZ-axis tinting. A base resolution setting is tied to the shortest edge. Concept and modeling reference are the main uses.

Key features

  • Front, top and side orthographic renders
  • Automatic UV maps with proportional scaling
  • Texture baking via Ray Portal BSDF
  • Grid overlay with opacity and scale controls
  • XYZ-axis tinting
