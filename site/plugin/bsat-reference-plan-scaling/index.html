What Bsat - Reference Plan Scaling does

Starting an architectural model with a plan that is the wrong size causes trouble later. Bsat - Reference Plan Scaling fixes the scale first and is the first public piece of the BSAT system, short for Blender Smart Architectural Tools.

Open BSAT > Scale Reference Image in the 3D viewport, click two points on the plan, enter the true length between them and confirm. The reference is scaled accordingly. It is marked Blender Extension compatible and includes documentation.

Key features

  • Scale a reference plan to real dimensions
  • Click two points and type the length
  • Runs from BSAT > Scale Reference Image
  • Blender Extension compatible
  • Part of the BSAT toolset
