Free MaxScript that reminds you to save at a set interval, only when the scene has changed, with a countdown.

What EReminder does

EReminder protects your work in 3ds Max by prompting you to save at an interval you choose. It speaks up only when the scene has actually changed, so there are no unneeded popups during long renders or idle periods.

A countdown shows when the next reminder will arrive, and the timer resets automatically if you save manually. When the interval is reached, a pop-up offers Save and Reset or Snooze. It supports Autodesk 3ds Max 2020 through 2026 and is free. Anyone who has lost progress to a crash will appreciate the nudge.

Key features

  • Configurable reminder interval
  • Reminds only when the scene has changed
  • Timer resets on manual save
  • Countdown to the next reminder
  • Save and Reset or Snooze pop-up
