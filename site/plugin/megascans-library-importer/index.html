Browses and imports a locally downloaded Megascans library in Blender, with automatic PBR material setup.

What Megascans Library Importer does

Megascans Library Importer scans your downloaded Megascans folder and opens a browsing window inside Blender, so you do not have to import manually from disk.

All eight Megascans categories work: 3D Assets, 3D Plants, Surfaces, Decals, Atlases, Imperfections, Displacements and Brushes. Nested subcategory filtering has adjustable depth, and imports set up PBR materials automatically. Environment artists with a big local library will find it quick. Import is meant to be quick enough that browsing and placing assets feels like using a built-in library.

Key features

  • Covers all eight Megascans asset types
  • Nested subcategory filtering
  • Instant import
  • Automatic PBR material setup
  • Browse without leaving Blender
