What Modular Medieval House Creator does

Modular Medieval House Creator builds historical cottages and town centers in Blender from snapping modular parts.

Components align as you assemble them. The library covers roofs and chimneys, exterior and interior walls, beams, gables, floors, platforms, stairs and ladders. You can add your own parts with Create New Part and give them thumbnails through Import Icon. Placement is grid snapped. It is useful for game environments and quick historical scene prototyping where speed and consistency matter.

Key features

  • Modular snapping system
  • Roofs, walls, beams, floors and stairs
  • Add custom parts
  • Custom thumbnails
  • Grid-snapped placement
