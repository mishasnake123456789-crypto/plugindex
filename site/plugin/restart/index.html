Blender add-on that adds a Restart command to the File menu with save and discard prompts.

What Restart does

Restart adds a quick way to relaunch Blender from the File menu. A Ctrl+Alt+Shift+R shortcut is included and can be changed in the keymaps.

If there are unsaved changes, a dialog offers Save, Don't Save or Cancel, new files get a Save As dialog, and unsaved files are highlighted in red as a warning. Add-on preferences set the default behavior to Prompt, Save and Restart, or Discard and Restart. It targets Blender 4.2 LTS and newer.

Key features

  • Restart entry in the File menu
  • Ctrl+Alt+Shift+R shortcut
  • Save, Don't Save, Cancel dialog
  • Unsaved files flagged in red
  • Default behavior set in preferences
