What Co-Dependencies does

From Andrew Hildebrand comes Co-Dependencies, a script for After Effects aimed at tidying up the files that surround a project. When a folder fills with assets that are no longer used, it helps you decide which to keep and which to delete.

Selection can take into account file extension, the number of characters in the file path and data size. It runs on both Mac and Windows and is compatible with After Effects 2023, 2024 and 2025. It is useful when archiving or handing off a job and you want a lean set of dependencies.

Key features

  • Keeps required files and removes the rest
  • Filters by extension
  • Considers path character count and data size
  • Works on Mac and Windows
  • Compatible with After Effects 2023 to 2025
