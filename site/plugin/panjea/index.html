What Panjea does

Panjea is a node-based logic editor inside Blender for creating animations and interactive experiences.

It adds Python scripting with a custom-node API that hides differences between Blender versions, and optional export to THREE.js on Panjea.com. A mapping micro language based on Rich Text Format is included, along with import from LibreOffice, CalligraWords and MS Office, and Pyrillic, a simplified Python dialect for learning to code. It is aimed at creators who want logic and interactivity without leaving a visual node workflow.

Key features

  • Node-based logic editor
  • Python scripting with custom-node API
  • Optional THREE.js export
  • Rich Text Format mapping language
  • Pyrillic simplified Python for learners
