Blender add-on that bends an object onto a four-cornered surface or cylinder guided by a flat reference grid.

What Flowify does

Flowify, by Mark Kingsnorth, deforms an object so it follows a target surface in Blender. The target can be a surface made of evenly spaced quads with four corners, or an open cylinder, and a flat reference grid guides the bend.

The result refreshes itself whenever the source or the target changes, and materials carry over to it. It works with regular objects, instanced objects and text with deformable topology. Modelers wrapping panels, pipes or lettering around curved forms can iterate without redoing the work.

Key features

  • Bends objects onto quad surfaces or cylinders
  • Automatic update on source or target edits
  • Copies materials to the result
  • Works with instances and text
