Vertex-level curve and surface tools for Blender, including Bezier editing, auto-updating fills and loop projection.

What Vertexflow does

VertexFlow from Colimata offers tools for creating and adjusting curved loops and surfaces while working directly on vertices. The aim is tighter control over geometry and topology.

EDIT Bezier and EDIT Spline let you shape curves without leaving Edit mode. Re-Build keeps a surface up to date, via grid fill, whenever a border vertex moves. Project merges aspects of two vertex loops into a new one, useful for closing gaps or blending surfaces, and Create loop helps pick the vertex count on a loop. It suits modelers building clean, flowing topology.

Key features

  • EDIT Bezier and EDIT Spline in Edit mode
  • Re-Build refreshes surfaces after border edits
  • Project combines two vertex loops
  • Create loop sets vertex count
