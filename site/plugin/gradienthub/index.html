What GradientHub does

GradientHub is an After Effects tool from synthetick for browsing and applying gradients. It ships with more than 500 built-in presets that can be applied to Colorama, Color Shift, shape layers, layer styles and proGradient from one place.

You can save your own gradients in a user section, sort them into categories with custom thumbnails, and switch thumbnails between color wheel and linear views. Gradients can also be imported from Photoshop GRD, CSS and SVG files. Built-in help is reachable without leaving the panel, making it a central library for color work.

Key features

  • 500+ built-in gradient presets
  • Applies to Colorama, Color Shift, shapes and layer styles
  • Import GRD, CSS and SVG gradients
  • User presets with categories and thumbnails
  • Color wheel or linear thumbnail view
