Blender color management add-on with an image-based interface for importing, editing and saving looks as presets.

What Colormaster does

ColorMaster adds a visual front end to Blender's color management tools, so choosing a look is based on image previews rather than guesswork. You can import your own looks and edit existing ones.

Adjustments cover view transform, exposure, gamma and curves, and the finished setup can be saved as a preset for reuse across projects. It is useful for artists who grade their renders inside Blender and want consistent, repeatable color treatment.

Key features

  • Image-based GUI over Blender color management
  • Import your own looks
  • Edit view transform, exposure, gamma and curve
  • Save setups as presets
