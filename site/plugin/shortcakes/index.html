Builds split-screen grids from selected clips in Premiere Pro and After Effects, with borders and numbering.

What Shortcakes does

Shortcakes turns selected timeline clips into a split screen with a few clicks. For each video track, you decide how many clips line up horizontally and vertically, press Cake Out, and the layout is generated in Premiere Pro or After Effects.

Size and spacing of the cells can be adjusted, and optional borders and numbers can be added. The Save Option exports border, numbering and shape settings as a PNG, with an importFile checkbox to bring it back into the project. It copes with different clip sizes and sequence sizes, which makes it useful for reaction videos, comparisons and gallery layouts.

Key features

  • Split screen from selected timeline clips
  • Set X and Y counts, then Cake Out
  • Adjustable size and spacing
  • Optional borders and numbers
  • PNG export of border and number layouts
