What Curl The Path does

Curl The Path is a tool from François Lefebvre for animating a path as if it curls up. It was released as version 1.0 on January 22, 2025, and works with After Effects 2020 through 2025.

The curling effect can be applied to lines and shapes for decorative loops, reveals and abstract motion. A demo video is available on YouTube so you can see the behavior first. It is an approachable option for motion designers who want to add curling movement to path-based artwork.
