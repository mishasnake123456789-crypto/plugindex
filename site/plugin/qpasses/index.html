Blender add-on that sets up all shader AOVs and render passes in one click and adds a compositor control panel.

What Qpasses does

Preparing render passes in Blender involves a lot of repetitive toggling. QPasses by Mskins configures every shader AOV output and pass at once and gives the compositor its own panel for handling them.

If you later turn passes off, the file output slots that were made for them are removed automatically, and single shader AOV passes can be deleted individually, taking their slots with them. An internationalization module is built in. Compositors who split renders into many layers will save the most effort.

Key features

  • One-click shader AOV and pass setup
  • Compositor function panel
  • Auto-removal of unused file output slots
  • Delete individual AOV passes
  • Built-in internationalization module
