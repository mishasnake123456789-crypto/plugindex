What Local View Manager does

Local View Manager is a Blender plugin by 3DDinosaur that extends the built-in Local View, which isolates selected objects. It lets you control it from the Outliner as well as the 3D viewport, which makes managing large scenes quicker.

You can toggle Local View, remove objects from it, add objects to it, and recover a previous state, using the slash key and its Alt, Shift and Ctrl variations. Outliner actions affect the first or primary viewport only. Its recovery memory is written only by the extension's own operators, so Blender's defaults do not pollute it.

Key features

  • Toggle, remove, add and recover Local View
  • Available from the Outliner and the viewport
  • Slash-key shortcuts with Alt, Shift and Ctrl
  • Recovery memory written only by its own operators
