Blender add-on that converts horizontal CJK text to vertical writing and back with two buttons.

What Cjk Pseudo Vertical Writing does

Cjk Pseudo Vertical Writing makes vertical Chinese, Japanese or Korean text in Blender by inserting a newline after each character, so a normal horizontal text object reads top to bottom.

One button performs the conversion, and a second reverses it to the original horizontal form. It works well for Taiwanese Mandarin written in Traditional Chinese. It supports Blender 2.9 through 2.93, ships with documentation and is GPL licensed. Handy for titles, signs and posters that are set vertically.

Key features

  • One-button vertical conversion
  • Reverse conversion to horizontal
  • Newline-based approach
  • Suited to Traditional Chinese in Taiwan
  • Supports Blender 2.9 to 2.93
