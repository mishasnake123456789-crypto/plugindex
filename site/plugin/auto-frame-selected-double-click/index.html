What Auto Frame Selected - Double-Click does

Auto Frame Selected - Double-Click, by Catra, recenters the 3D view on the selected object using the mouse instead of a shortcut.

Double-click in the 3D View or the Outliner to frame the selection, or switch on one-click framing from a camera icon in the Outliner header, which can also be hidden. The double-click delay, framing distance and animation duration in milliseconds can be tuned, and zero makes the move instant. Defaults work immediately after install.

Key features

  • Double-click framing in viewport and Outliner
  • Optional single-click mode
  • Adjustable delay, distance and animation time
  • Works out of the box
