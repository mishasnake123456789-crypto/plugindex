What Vertex Color Selector does

Vertex Color Selector is a Blender add-on by D31 that finds the colors painted on a mesh and selects every face using a chosen one. It operates in Vertex Paint mode, which makes it handy for ID map painting workflows.

Find Colors builds a list of every vertex color in use, Select This Color picks all matching faces at once, and Pick Vertex Color offers an eyedropper you click on a face. Holding Shift allows choosing several colors together. A built-in Fix button and conversion tools help with problem meshes.

Key features

  • Lists all vertex colors on a mesh
  • Selects every face with a chosen color
  • Eyedropper to pick a color from a face
  • Shift to select multiple colors
  • Built for ID map painting workflows
