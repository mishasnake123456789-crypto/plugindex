3ds Max script that repeats the keyframes of selected objects into a loop for position, rotation and scale.

What Loop Animation does

Loop Animation finds the first and last animation keys on selected objects in 3ds Max, then copies those keys and moves them to the last key location, extending the sequence into a loop. It handles position, rotation and scale keys.

An Iteration parameter applies the loop repeatedly with an exponential effect, so 50 keys can become 100, 200 or 400 frames. An Offset parameter, added in version 1.2, introduces a pause between loops. It comes as a compact .mcr macroscript installed by drag and drop, then listed in Customize User Interface under SimonScript. Useful for repeating motion graphics and idle animation.

Key features

  • Loops keys between first and last animation key
  • Works on position, rotation and scale
  • Iteration parameter multiplies the loop length
  • Offset parameter adds a pause between loops
  • Drag-and-drop .mcr install
