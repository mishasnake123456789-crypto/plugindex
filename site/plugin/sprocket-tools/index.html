Blender add-on for importing and exporting Sprocket game .blueprint files through the 3D Viewport sidebar.

What Sprocket Tools does

Sprocket Tools, by Brian-Marshall, connects Blender to the game Sprocket by handling its .blueprint data. It can import blueprints for both Plate Structures and Vehicles, while export works for Plate Structures alone.

Blueprints that are imported keep the original thickness in a face attribute named sprocket_thickness, so that information is preserved. The tools live in the 3D Viewport sidebar, helping players and modders who want to design or edit vehicles in Blender.

Key features

  • Imports Plate Structure and Vehicle blueprints
  • Exports Plate Structure blueprints
  • Stores original thickness in a face attribute
  • 3D Viewport sidebar panel
