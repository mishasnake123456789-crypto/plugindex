A text toolkit for After Effects covering type-on, cursors, highlights, number formatting, monospacing and text splitting.

What AE Screens Type does

AE Screens Type collects many everyday text jobs into one After Effects toolset. It animates type on by character, word or line, adds a blinking cursor that follows the text, and draws highlights, underlines or strikethroughs over a whole layer or a chosen range.

It also includes a number rig that formats values for any locale, adds symbols and shortens large figures, plus an automatic time counter. Monospacing works with any font, using a technique by Thor Sarup, and a smart rectangle or track matte resizes as the text changes. Text can be split by word, line or character into editable layers that keep their position and effects. UI and explainer animators will find it a major time saver.

Key features

  • Type-on by character, word or line with blinking cursor
  • Highlight, underline and strikethrough on ranges
  • Number rig with locale formatting and time counter
  • Monospacing for any font
  • Smart text boxes and splitting into editable layers
