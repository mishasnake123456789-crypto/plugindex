What Tryrock Studio does

Tryrock Studio generates procedural rocks inside Blender using Geometry Nodes. The meshes have clean topology and realistic surface detail, and every setting stays editable.

A triplanar displacement system avoids UV seams and stretching, and you can supply your own textures or use Blender's texture nodes for displacement. Presets switch quickly between rock styles, and a User Mesh Collection lets you insert your own meshes as a base for generation. Good for environment artists who need varied boulders.

Key features

  • Procedural rocks via Geometry Nodes
  • Triplanar displacement without UV seams
  • Custom displacement textures
  • Rock style presets
  • User mesh collection as input
