What Drag[en]gine Import/Export does

Drag[en]gine Import/Export from DragonDreams connects Blender with the Drag[en]gine Game Engine. It writes engine resource files and offers helper tools for common tasks.

Export covers models (.demodel), rigs (.derig), animations (.deanim), nav spaces (.denavspace) and occlusion meshes (.deoccmesh), while rigs and animations can also be imported. Developers building content for this engine can keep their pipeline inside Blender. Because the formats are specific to that engine, the add-on is mainly of interest to teams building games or tools around Drag[en]gine.

Key features

  • Exports models, rigs and animations
  • Navigation space and occlusion mesh export
  • Imports rigs and animations
  • Workflow helper tools
