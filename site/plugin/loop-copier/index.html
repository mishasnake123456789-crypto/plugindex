Blender add-on that repeats a mesh along chosen edge loops with no deformation, for closed, open and existing edges.

What Loop Copier does

Loop Copier distributes copies of a mesh along edge loops in Blender while keeping the source parts undeformed. It works on closed loops, open lines of edges and existing mesh edges.

You set the number of copies and control rotation, scale and offset. A follow-curve style option makes pieces align to the path. Modelers building chains, fences, rivets and trim rings can avoid array modifier workarounds. Controls such as offset and rotation let each copy sit correctly on the loop, which is tedious to do with manual duplication.

Key features

  • Copies mesh along edge loops
  • Count, rotation, scale and offset controls
  • Closed, open and existing edge support
  • No deformation of source parts
