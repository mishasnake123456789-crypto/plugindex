Generates Cinema 4D terrain from real map data using Google Maps and MapBox coordinates and GPX routes.

What Terrain Builder Cinema does

Terrain Builder Cinema creates landscapes from actual places. It takes coordinates from Google Maps and MapBox to define the area, and can import GPX routes from a Google Maps link, aligning them to the terrain automatically.

A KML to GPX converter handles route data in other forms, locations can be saved for later, and the TB Manager window loads quickly with an updated interface. The plugin uses the aescripts licensing framework. Artists making maps, travel visuals, route animations or geographic backdrops can start from real topography.

Key features

  • Google Maps and MapBox coordinate support
  • GPX import from a Google Maps link
  • Automatic route alignment
  • KML to GPX converter
  • Saved location coordinates
