Adds global and per-scene folder bookmarks to 3ds Max's file dialogs for opening, saving, importing, exporting, merging and replacing.

What miauu's Folder Bookmarks does

Folder Bookmarks by miauu adds shortcuts to the native file dialogs in 3ds Max, so frequently used locations are a click away. Global bookmarks work across every scene and dialog, while local bookmarks are stored in the .max file and show only when that scene is open.

A Current File Folder shortcut jumps to where the open scene lives. A Bookmark Manager lets you rearrange, sort alphabetically, add, remove and clear invalid bookmarks in one go. Global and local lists display separately, invalid entries appear in red, and right-clicking a bookmark opens its folder in Windows File Explorer. Recently opened and pinned files can be sorted by name or access date.

Key features

  • Global bookmarks for all scenes and dialogs
  • Local bookmarks stored in the .max file
  • Current File Folder shortcut
  • Bookmark Manager with sorting and invalid cleanup
  • Right-click opens the folder in File Explorer
