What Gn Escape - Control Any Value From Geometry Nodes does

GN Escape lets Geometry Nodes control things outside the geometry itself. It exposes node attributes as usable parameters in Blender, so they can drive any animatable property.

Transforms such as location, rotation and scale can be driven procedurally, along with camera and light parameters and meshes. The result is a general-purpose procedural control engine for reactive, procedural and interactive setups. Technical artists and motion designers who already build in Geometry Nodes can use it to animate a whole scene from one network.

Key features

  • Geometry Nodes attributes as real parameters
  • Procedural location, rotation and scale
  • Camera and light parameter control
  • Reactive and interactive setups
