A Blender add-on that keeps motion paths for empties, cameras, meshes and bones updated in real time.

What Motion Path Pro does

This Blender add-on keeps animation motion paths current as you work, rather than requiring manual recalculation. It supports empties, cameras, meshes and bones.

Version 3.1.0 added control handles on the motion path. It needs Blender 5.0 or newer, requires no special permissions, and is released under the GNU General Public License v3.0 or later. Animators polishing arcs and spacing can see the effect of each edit immediately.

Key features

  • Real-time motion path updates
  • Supports empties, cameras, meshes and bones
  • Control handles on the path (3.1.0)
  • Blender 5.0 and newer
  • GPL v3 or later
