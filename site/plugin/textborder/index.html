Developer: Plugin Everything

FreeAfter Effects

After Effects plugin that draws an auto-fitting, animatable border around text.

What TextBorder does

TextBorder adds a customisable frame to text layers in After Effects and keeps it sized to the words as they change. Because it's applied directly to the text layer, there's no need for parenting, mattes or expressions to keep the box fitted.

Expansion can be set globally or separately for width, height and each side. Edges can be rounded selectively, and the border supports solid or gradient fills as well as dashes. Its own transform controls animate it independently from the text. Motion blur, built-in text animators, paragraph text and vertical text all work with it. It comes from Plugin Everything.

Key features

  • Auto-fitting border applied to the text layer
  • Global and per-side expansion
  • Selective rounded edges, gradients and dashes
  • Independent border transforms
  • Works with paragraph and vertical text
