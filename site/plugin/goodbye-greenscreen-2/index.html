What Goodbye Greenscreen 2 does

Goodbye Greenscreen 2 from Blace Plugins mattes human subjects automatically, so you can separate a figure from a background without a green screen or hand keying. It is powered by blace.ai and now integrates BiRefNet, a leading image segmentation model, as the default.

It can build mattes that separate a fixed background from a moving foreground. Windows users with some models can use AMD GPUs, CUDA Memory Sharing helps renders above 4K on CUDA, and a Stop Processing button cancels long computations at once. Artists needing quick cutouts of people can avoid manual rotoscoping.

Key features

  • Automatic matting for people
  • Separates static background from moving foreground
  • BiRefNet model as default
  • AMD GPU acceleration for some models on Windows
  • CUDA Memory Sharing and Stop Processing button
