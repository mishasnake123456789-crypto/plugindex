What FXAA does

FXAA is a free After Effects effect by Plugin Everything that smooths jagged edges in a layer using fast approximate anti-aliasing. It is a quick fix for aliased renders, game footage or graphics that show hard stair-stepped edges.

Support for Multi-Frame Rendering arrived in version 1.1, and a universal binary runs natively on Apple Silicon. It is compatible with releases from CS6 to 2025, and a demo video is available online.

Key features

  • Fast anti-aliasing effect
  • Multi-Frame Rendering support since 1.1
  • Universal binary for Apple Silicon
  • Compatible from CS6 to 2025
  • Free, with a demo video
