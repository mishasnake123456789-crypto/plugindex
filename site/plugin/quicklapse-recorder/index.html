Blender add-on that records timelapses by grabbing screenshots at regular intervals inside the 3D View.

What Quicklapse Recorder does

KING ZEN STUDIOS' Quicklapse Recorder captures the progress of a scene without outside screen recording software. It takes screenshots automatically at set intervals while you work in the 3D View.

Filenames can carry custom prefixes, and a pivot object can rotate a bit with every shot through a pivot increment. Action steps and minimum time between captures are adjustable, and output is JPEG or PNG. Artists sharing process videos can assemble the frames afterwards.

Key features

  • Automatic interval screenshots
  • Custom filename prefixes
  • Pivot object rotation per capture
  • Adjustable steps and minimum time
  • JPEG or PNG output
