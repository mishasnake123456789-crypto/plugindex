What Copy Pivot From Active does

Copy Pivot From Active is a small Blender add-on by 6cto for matching origins across objects. It takes the relative pivot of the active mesh and gives every other selected mesh the same offset.

It runs from Object, Transform in Object Mode, and works with source and target both being meshes. This is useful when a set of parts needs identical hinge or rotation points, for example when preparing modular assets or objects that will be animated the same way.

Key features

  • Copies relative pivot offset to all selected meshes
  • Runs from the Object, Transform menu
  • Object Mode operation
  • Meshes as both source and targets
