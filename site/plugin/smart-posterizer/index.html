What Smart Posterizer does

Smart Posterizer, by Ian Pinder, is a script that watches an animation, spots when it visibly changes, and uses that information to control time posterization on other properties. The result is stepped, hand-animated rhythm that follows the artwork.

It runs as a ScriptUI panel from the Window menu and has optimized scanning and baking. A beta feature can automatically pin textures to rendered animation with squash and stretch. This suits artists who want choppy, hand-drawn timing across several properties without setting each step by hand.

Key features

  • Automatic detection of visual change
  • Drives time posterization on other properties
  • ScriptUI panel from the Window menu
  • Faster scanning and baking
  • Beta texture pinning with squash and stretch
