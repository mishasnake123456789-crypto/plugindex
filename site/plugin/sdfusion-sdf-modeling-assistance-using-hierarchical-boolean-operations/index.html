What Sdfusion | Sdf Modeling Assistance Using Hierarchical Boolean Operations does

SDFusion is a Blender plugin for modeling with booleans in a way that resembles signed distance field tools. It runs from rapid blockout through to a final mesh, and keeps everything editable.

One click sets up Boolean, Remesh and Smoothing modifiers in a sensible order. A layer-based workflow stacks ADD and SUB collections, with no limit on additional detail layers, and assets can be integrated into the stack. This suits concept and hard surface artists.

Key features

  • One-click Boolean, Remesh and Smooth setup
  • ADD and SUB collection layers
  • Unlimited detail layers
  • Non-destructive editing
