What Easy Vdb Addon does

Easy Vdb Addon supplies ready-made volumetric fire and explosion assets for Blender. Twenty VDB models import in a single click, saving you from running simulations.

Each model offers several shaders, including ones that add detail, a smoke-only version and one built for better scene performance. Four color settings cover smoke and fire, and one-click controls adjust smoke density and flame amount. Detail such as sparks can be added by changing shaders or in the Materials tab. Documentation is included.

Key features

  • 20 fire and explosion VDB models
  • Multiple shaders per model
  • Four color settings for smoke and fire
  • Density and flame amount controls
