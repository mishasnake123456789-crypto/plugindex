Blender add-on that remembers resolution, frame range, output location and format per camera, with snapshot, playblast and batch rendering.

What Cameraide does

Cameraide keeps render settings with each camera in Blender. Switch cameras and their resolution, frame range, output location and file format switch too.

Resolution options include custom width and height, a percentage, a one-click landscape or portrait swap and presets. Snapshot, playblast and batch rendering are built in. Artists with multi-shot scenes can handle several outputs without changing settings manually. Storing these values with each camera avoids the common mistake of rendering a shot at the wrong size or frame range after switching views.

Key features

  • Per-camera render settings
  • Landscape and portrait swap
  • Snapshot and playblast
  • Batch rendering
