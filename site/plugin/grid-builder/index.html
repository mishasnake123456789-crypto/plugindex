Grid engine for After Effects that builds and animates layouts from one null in four grid modes.

What Grid Builder does

Grid Builder manages complex arrangements of layers in After Effects through a single null object. Instead of positioning dozens of assets, you set up a grid and let the engine place and animate them.

It offers rectangular, radial, path and spherical grids, and proximity effects with custom proximity, several effectors and multiple proximity groups; the grid can still be altered while those effects run. A Morph mode animates between layouts in both directions, and Twist and Stagger controls adjust each asset. Versions 2022 to 2026 of After Effects are supported.

Key features

  • Rectangular, radial, path and spherical grids
  • Proximity effects with multiple effectors and groups
  • Morph mode between layouts
  • Twist and Stagger per asset
  • Everything driven from a single null
