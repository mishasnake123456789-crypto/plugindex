Blender geometry nodes add-on that creates rain affecting only exposed surfaces, with a procedural rain shader.

What Baga Rain Generator does

Baga Rain Generator adds rainfall to Blender scenes with geometry nodes, so only surfaces actually exposed to the rain get wet. A procedural shader overlays rain effects onto existing materials.

Two distribution methods are offered: surface-area-based for smaller scenes with greater accuracy, and per-object for larger scenes with more speed. Splashes use points, so Cycles can handle very large numbers of them. Archviz and environment artists can create rainy-day versions of existing scenes without remaking materials.

Key features

  • Rain via geometry nodes
  • Affects only exposed surfaces
  • Two distribution methods
  • Procedural rain shader overlay
  • Point-based splashes for Cycles
