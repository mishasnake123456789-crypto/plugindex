What Generate Tree Plugin does

Generate Tree Plugin, by YGForge, creates low-poly trees procedurally, so you can fill a stylized scene or a game level with varied trees without modeling each one. It is listed under Add Mesh.

Open source under GPL-3.0-or-later, it requires Blender 5.0.1 or newer.
