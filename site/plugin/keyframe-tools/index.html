What Keyframe Tools does

Keyframe Tools by Hydrocallis handles keyframe operations in Blender. It adds, removes and shifts keyframes controlling rotation, scale and location of chosen objects at any location.

It is made to tie an object or other parameter to a camera, which eases changing the camera's target between objects, and the keymap display in its panel is simplified. Animators and motion designers building simple move sequences can set timing with fewer clicks. The panel keeps keymap hints simple, which helps newer users remember which shortcut does what when blocking out simple animations.

Key features

  • Insert, delete and move keyframes
  • Rotation, scale and location support
  • Camera linking and switching
  • Simplified keymap display
