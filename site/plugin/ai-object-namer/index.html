What Ai Object Namer does

AI Object Namer is a Blender extension that uses AI to name objects automatically. It is for Blender 5.0 through 5.2 and works with the Cycles and Eevee render engines.

It is released under the GPL license, includes documentation, and comes with updates and support from the developer. Artists with scenes full of default names such as Cube.001 can organize them faster. Key capabilities include AI-driven object naming and blender extension for 5.0 to 5.2.

Key features

  • AI-driven object naming
  • Blender extension for 5.0 to 5.2
  • Cycles and Eevee compatible
  • GPL license with documentation
