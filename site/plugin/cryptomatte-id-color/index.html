Blender add-on that builds real-time Cryptomatte ID color compositor nodes for objects and materials.

What CryptoMatte ID Color does

CryptoMatte ID Color creates compositor setups that display ID masks as colors. Node groups are built and wired up to match how many objects or materials the scene contains.

The Object ID group gives each visible renderable object its own ID color, and the Material ID group does likewise for materials. Colors can be edited live. Compositors can quickly pick out items for grading and masking.

Key features

  • Object ID node group
  • Material ID node group
  • Real-time color editing
  • Nodes built from scene contents
