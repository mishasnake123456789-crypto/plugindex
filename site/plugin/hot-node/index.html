Blender add-on for saving and adding edited nodes across files, with node packs and a Shift+A menu.

What Hot Node does

Hot Node stores customized nodes so they can be brought into other Blender files rapidly. Saved nodes appear in the Shift+A menu or can be stored from the right-click context menu.

Further functions include image matching, node sharing and undo/redo, importing and exporting node packs, and a node tree reuse mode. The extend menu can be disabled to restore the standard Blender menu. The interface is available in English and Simplified Chinese. Shader and geometry node artists reuse their favorite setups without hunting for old files.

Key features

  • Store edited nodes and reuse them in any file
  • Node packs import and export
  • Shift+A menu integration
  • English and Simplified Chinese interface
