What Anypass does

Anypass is a render pass manager for Blender that lets one scene produce several passes, each with its own settings. This removes the need for duplicate scene files or flipping configurations by hand between renders.

Each pass can override environment, output format, color management, samples and Blender's native passes. A partition system groups objects and lights with independent visibility, materials, ray visibility and mask settings, and results can be previewed in real time. An auto render queue then renders the passes one after another. It benefits artists producing layered output for compositing.

Key features

  • Multiple passes within one scene
  • Per-pass overrides for output, color and samples
  • Partitions with independent visibility and masks
  • Real-time pass preview
  • Automatic sequential render queue
