What Decalify - Raycast Decals Made Easy does

Decalify is a Blender add-on that places decals which conform to the surface beneath them. It relies on the RayCast node, and the projection holds even when the surface is displaced.

That makes it useful for adding labels, damage or markings to uneven or sculpted objects without manual bending. It works with Cycles, is built on Blender 5.1's RayCast Node, is registered as a Blender extension and ships with documentation. Environment and prop artists can use it to detail surfaces quickly.

Key features

  • Decals that take the surface shape
  • Projection holds on displaced surfaces
  • Built on the RayCast node in Blender 5.1
  • Works with Cycles
  • Blender Extension with documentation
