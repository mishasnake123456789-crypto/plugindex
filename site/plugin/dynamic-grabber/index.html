Blender add-on for physically based object placement: grab, drop and paint copies that fall and settle naturally.

What Dynamic Grabber does

Ilyasse's Dynamic Grabber makes placing objects in Blender behave like the real world. Instead of nudging items into position, you pick up, release and brush copies that tumble, collide and come to rest.

A Physics Brush paints copies of one object or a collection. Stack Mode puts copies at the right height whatever their origin or rotation, with a Gap dial. Dynamic Grab moves the selection as if it had mass, with 90-degree snapping, while layout shapes and water buoyancy extend the toolset. Set dressers can scatter realistic piles.

Key features

  • Physics Brush paints settling copies
  • Stack Mode with a Gap dial
  • Weighted Dynamic Grab with 90 degree snapping
  • Layout shapes
  • Water buoyancy
