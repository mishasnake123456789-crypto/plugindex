Brush-based prop scattering and layout tools for Blender, with alignment, spacing and randomization.

What Propscatter does

Propscatter helps dress scenes by painting props across surfaces. A brush scatter workflow uses source lists and targets, with distribution settings, live preview, overlap cleanup and a final bake to duplifaces.

Sources can be organized in folders, and separate tools handle alignment, spacing, randomization and pivots. Typical jobs are kitbashing, dressing environments, building asset libraries and populating architectural scenes. Environment artists populating large areas with rocks, furniture or clutter can iterate without rebuilding particle systems.

Key features

  • Brush-based scatter with live preview
  • Source folders and ordering
  • Alignment, spacing and randomization tools
  • Pivot tools and bake to duplifaces
