3ds Max script that applies align, bind, link, mirror and constrain between matched object sets through a mapping file.

What Mapping Operations does

Mapping Operations relates one set of selected objects to another in 3ds Max using a mapping text file, then applies Align, Bind, Link, Mirror or Constrain across the pairs. A mapping file is built automatically from separate source and target lists, and those lists may be reordered in a text editor first.

Saved mapping files reload later so the same operations can be reapplied. Mirror places source objects at the mirrored positions of their targets, across a world axis or the local axis of a picked object, with optional baking through the time range. The floater remembers its position between sessions, and error handling for missing mapped objects has been improved.

Key features

  • Align, Bind, Link, Mirror and Constrain operations
  • Auto-generated mapping text file from source and target lists
  • Reloadable mapping files for repeat use
  • Mirror across world or local axis with optional baking
  • Floater position persists between sessions
