What Pataz Notes does

Pataz Notes, from PATAZ Animation, is an annotation system for blend files. Each note records the state of the scene at creation and returns you to it when selected.

Clicking a note brings back the frame, the active camera, and the viewport's angle and zoom. Notes can be attached to many types of data, including scenes, objects, materials, node trees and actions. Reviewers and collaborators can leave context-rich remarks inside the file itself.

Key features

  • Notes restore frame, camera and viewport
  • Supports scenes, objects, materials, node trees and actions
  • Captures scene state on creation
  • Annotates blend files in place
