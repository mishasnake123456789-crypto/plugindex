Blender add-on that writes object transforms, mesh data and Geometry Nodes attributes out as CSV or JSON.

What Csv Exporter does

Captain Pixel's CSV Exporter moves Blender data into spreadsheets and structured files. Transforms, evaluated mesh data and Geometry Nodes attributes can go to CSV, as a flat table, or to JSON, with numbers kept numeric.

Two modes exist. Data mode exports transforms from several objects and evaluated attributes from one object. BOM mode builds bill-of-materials style data with grouped object counts, materials, dimensions, area and volume. Useful for analysis and fabrication planning.

Key features

  • Export to CSV or JSON
  • Data mode for transforms and attributes
  • BOM mode with counts and dimensions
  • Geometry Nodes attribute export
  • Area and volume values
