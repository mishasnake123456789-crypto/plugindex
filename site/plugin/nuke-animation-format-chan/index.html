What Nuke Animation Format (.chan) does

Nuke Animation Format moves object animation between Blender and Nuke using the .chan format. The entries are named Nuke (.chan) in the File, Import and Export menus.

It needs no special permissions, supports Blender 4.2 LTS and newer and is published under the GNU General Public License. Compositors and VFX artists passing camera or object motion to Nuke can keep pipelines consistent. Exchanging .chan files is a lightweight way to hand tracked or animated transforms between a 3D scene and a compositing script.

Key features

  • Import and export .chan animation
  • File menu entries
  • No special permissions
  • Supports Blender 4.2 LTS and newer
