What miauu's PinMyFiles does

PinMyFiles by miauu extends the recent files list in 3ds Max with pinning. Pinned files remain listed after dropping off the default recent list, and any that were deleted, renamed or moved show in red.

Recent and pinned files can be sorted by name or last-accessed date and show thumbnail previews. A right-click menu offers open, merge or XRef, including without dialogs for quicker access, and a file's folder can be opened from the menu or with the middle mouse button. It suits artists who return to the same project files repeatedly.

Key features

  • Pin files so they stay in the list
  • Missing, renamed or moved files shown in red
  • Sort by name or last accessed date
  • Thumbnail previews for recent and pinned files
  • Right-click open, merge or XRef, and open containing folder
