Blender add-on that adds import, export and append commands to the viewport Add menu.

What Import&Export does

Import&Export, from CGCocktail, puts file transfer commands where you already work. Rather than going through the File menu, you use the 3D viewport's Add menu (Shift+A).

It handles import, export and append for formats including .dae, .abc, .usd, .obj, .ply, .stl, .bhv, .svg, .fbx, .glb/.gltf and x3d/.wrl. It installs as a zip through Preferences. It was written for Blender 3.6 and runs on earlier versions with different labels, under the GPL.

Key features

  • Import, export and append from the Add menu
  • Supports a broad list of 3D formats
  • Installs as a zip add-on
  • Written for Blender 3.6, GPL licensed
