What Autokroma BRAW Studio does

BRAW Studio opens Blackmagic RAW footage in After Effects, Premiere Pro, Media Encoder and Audition, giving the same RAW colour parameters you'd find in DaVinci Resolve, built on the official Blackmagic colour science. A standalone desktop player can open, play and grade .braw files straight from Finder or Explorer.

Settings are stored in a sidecar file that applies automatically across Resolve, Premiere Pro, After Effects and Media Encoder. Tools include a white balance picker, A/B comparison, 20 global presets, custom LUTs and a Trim tool that removes unused frames without recompressing. Metadata can be read, and macOS from Monterey to Sequoia is supported on Intel and Apple Silicon.

Key features

  • Resolve-style BRAW colour parameters
  • Standalone player and grader
  • Sidecar settings shared across hosts
  • White balance picker, A/B compare, presets, LUTs
