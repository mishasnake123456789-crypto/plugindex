What EFX Render Elements Z Depth Tools does

EFX Render Elements Z Depth Tools, from reduxFX, is a group of After Effects plugins that exploit the per-pixel distance data in a ZDepth pass rendered from a 3D application. That data lets 2D compositing respect depth in the original scene.

Z_Depth Compose merges two layers by their depth maps, Z_Depth Cut selects pixels based on depth, and Z_Depth Shadow projects a layer onto a depth map. Compositors who receive passes from 3D artists can use them for integration work. The tools are compatible with After Effects from CC 2014 through 2024.

Key features

  • Z_Depth Compose merges layers by depth
  • Z_Depth Cut selects pixels by depth
  • Z_Depth Shadow projects onto a depth map
  • Compatible with After Effects CC 2014 to 2024
