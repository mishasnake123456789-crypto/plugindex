What Voxelity Pro: Voxel File Format Exchange does

Voxelity Pro is a Blender plugin for voxel art pipelines. It can read and write Minecraft .schematic, Qubicle .qb and MagicaVoxel .vox files, and can convert polygonal objects into voxel form directly.

Texture colors are retained when meshes are voxelized. It lets voxel artists move content between Blender and dedicated voxel tools. It opens Blender up to voxel-based workflows, letting artists render and refine voxel models in a full 3D environment.

Key features

  • MagicaVoxel, Qubicle and schematic formats
  • Mesh voxelization
  • Texture color preservation
  • Import and export
