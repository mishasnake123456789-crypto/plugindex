What ExtendScript Hotkey Manager does

ExtendScript Hotkey Manager by Vakago Tools lets you attach custom key combinations to ExtendScript scripts and JSX files. It runs in After Effects, Premiere Pro and other Adobe applications that support ExtendScript.

Shortcuts are recorded within the tool, and a built-in script editor allows quick edits and adaptations. You can trigger larger automation scripts or simple one-line commands the same way. In Premiere Pro, hotkeys can also be assigned to Lumetri Color settings such as contrast, exposure, shadows, highlights and saturation, speeding up repetitive adjustments.

Key features

  • Record hotkeys for ExtendScript and JSX files
  • Built-in script editor
  • Run scripts or simple commands by key combo
  • Works across ExtendScript-capable Adobe apps
  • Lumetri Color hotkeys in Premiere Pro
