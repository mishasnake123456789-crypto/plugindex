Copies all shape keys between Blender objects with matching polygon counts in one operation.

What Shape Key Transfer does

Shape Key Transfer moves shape keys across objects in a single operation. Both objects must have the same number of polygons.

A filter decides which shape keys go across and which stay behind. Documentation is included. Saves time when sharing expressions between similar meshes. This helps when several characters or variations share the same topology and you do not want to recreate each shape manually. Rigging time drops when expressions are shared between meshes.

Key features

  • Transfers all shape keys at once
  • Requires matching polygon counts
  • Filter for transferred keys
  • Documentation included
