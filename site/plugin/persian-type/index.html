Blender add-on for typing Persian and Arabic text with right-to-left input and quick font selection.

What Persian type does

Developed by Damyar, Persian Type lets Blender handle Persian and Arabic text. Typing runs right to left, and a toggle changes between RTL and LTR.

A one-click Normalize paste converts Arabic variants of ye and kaf to their Persian forms, removes tatweel and ZWJ characters, and keeps ZWNJ. On Windows, a cached dropdown of system fonts makes picking typefaces quick, while a custom fonts folder works on every operating system. You can also bookmark the current font for reuse.

Key features

  • Right-to-left typing with direction toggle
  • One-click Normalize paste for Persian characters
  • Cached Windows fonts dropdown
  • Custom fonts folder on all systems
  • Save current font as a bookmark
