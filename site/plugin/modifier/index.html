Copies all modifiers to selected objects and prepares hard-surface meshes for external baking.

What Modifier++ does

Modifier++ adds two time savers. Add To Selected copies every modifier from the active object to all selected objects, working on meshes, curves and others, and skipping any modifier an object already has.

Export Modifier prepares a mesh for export to other programs so it can be baked. It is handy for hard-surface workflows with repeated modifier stacks. Day to day, that covers copy all modifiers to selection, skips duplicates and works on meshes and curves.

Key features

  • Copy all modifiers to selection
  • Skips duplicates
  • Works on meshes and curves
  • Export Modifier for baking prep
