What Animation Tools - Beat does

Animation Tools - Beat is a Blender add-on from Nascore Entertainment that aims to make everyday animating smoother. It takes inspiration from AnimBot for Maya, so animators moving over from that tool will find a familiar philosophy within Blender.

The interface is designed to be easy to use, documentation is included, and it supports Blender 3.0 through 4.4. It is distributed under the GPL. Character and general animators who want a simpler, more efficient way to handle keys and poses in the timeline will be the most likely to benefit from it.

Key features

  • User-friendly animation interface
  • Inspired by AnimBot for Maya
  • Compatible with Blender 3.0 to 4.4
  • Documentation included
