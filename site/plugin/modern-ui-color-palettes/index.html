What Modern UI Color Palettes does

Modern UI Color Palettes from Vakago Tools is a color picker extension for After Effects and Premiere Pro. It presents popular palettes such as Material UI and Flat UI so you can choose a swatch and send its code to the clipboard.

Codes can be copied as HEX, RGB or RGBA, and the tool can generate a set of shades from a color you already have. It also runs in Photoshop and Illustrator, making it handy for keeping colors consistent across products, websites, UI screens and animations.

Key features

  • Material UI and Flat UI palettes
  • Copy HEX, RGB or RGBA codes
  • Generate shades from an existing color
  • Works in After Effects, Premiere Pro, Photoshop and Illustrator
