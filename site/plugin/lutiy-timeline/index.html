What Lutiy Timeline does

Lutiy Timeline groups frame ranges, cameras and render resolution into presets for quick switching in Blender. A preset can be created in one click from the active camera and timeline, or built manually with every value set by hand.

Applying a preset selects the camera, sets the frame range and resolution, and jumps to the start frame. A visual list supports inline editing and reordering, and an info panel displays the active preset's details. It fits scenes with several cameras or ranges at different resolutions.

Key features

  • One-click preset from active camera and timeline
  • Switch between scene cameras
  • Stores frame ranges and resolutions
  • Jumps to start frame on apply
  • Reorderable preset list with inline editing
