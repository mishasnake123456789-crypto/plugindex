What Default Cube: The Game does

Default Cube: The Game turns deleting Blender's startup cube into a small horror game. Once it is gone, the cube returns to bother you with random incidents.

Twelve kinds of haunt can fire, such as the cube speaking, image pop-ups, loud sounds and UI changes. Everything is non-destructive and cleans up afterward, each lasting under thirty seconds, and auto-save pauses meanwhile. You can start and end the game at any time, and it ends on its own when a new file opens.

Key features

  • 12 types of haunted events
  • Non-destructive, effects clean up afterward
  • Auto-save paused during haunts
  • Start and end the game anytime
  • Ends when a new file is opened
