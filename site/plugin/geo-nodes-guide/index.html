What Geo Nodes Guide does

Geo Nodes Guide is a Blender add-on by Addonyte that puts documentation inside the editor. Hover over a Geometry Node and a tooltip appears with a description, common uses, pitfalls and examples, so you need not leave Blender to look things up.

In total 332 nodes are explained, from mesh operations and curves to instances, volumes and simulation. Each entry includes a practical workflow example, not only a technical definition, and warnings about frequent mistakes, such as which inputs expect radians. It helps beginners learn node behavior and reminds experienced users of the details.

Key features

  • Hover tooltips on any Geometry Node
  • 332 nodes documented
  • Real workflow example for each node
  • Warnings about common pitfalls
  • Covers mesh, curves, instances, volumes and simulation
