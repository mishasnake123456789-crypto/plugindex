What Root does

Root is an asset organizer for After Effects by James Ronan. Projects tend to depend on files scattered around a computer, and sharing or archiving them risks missing footage, so Root gathers everything the project actually uses.

It packages media into the project, searches the system for missing files, and builds tidy folders you can hand to someone else. Multiple compositions can be packaged into individual project packages. Assets can be gathered from downloads, the desktop or any external drive. It is compatible with After Effects 2025 and 2026.

Key features

  • Gathers and packages used media
  • Finds missing media across the system
  • Builds tidy, shareable asset folders
  • Packages multiple comps as separate projects
  • Collects from downloads, desktop or external drives
