What AEJuice Replace Expressions does

AEJuice Replace Expressions swaps expression code in After Effects with one click. Choose the scope, type what to look for and what to put in its place, then press Replace.

Scope can be the whole project, the current selection, the active composition, selected layers or selected properties, with an option to run through nested compositions. It is optimized for speed. Artists updating variable names or fixing syntax across many layers can avoid editing each expression individually.

Key features

  • Find and replace across expressions
  • Scope: project, selection, comp, layers or properties
  • Option to include nested comps
  • Simple search and replacement fields
  • Optimized for speed
