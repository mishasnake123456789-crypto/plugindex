Generates LOD sets from a high-resolution Blender model and switches levels based on the camera.

What Lodgenerator does

Lodgenerator creates level-of-detail versions of an existing high-resolution model so scenes stay light at a distance. The levels change automatically depending on the current camera.

One decimation method and ratio is chosen and applied evenly to every object in the LOD collection. A LodRangeVisualization toggle makes it easier to judge where each range should begin and end. Game artists and scene builders preparing optimized assets can test behavior directly in the viewport.

Key features

  • Creates a set of LODs from one model
  • Automatic switching by camera distance
  • Uniform decimate method and ratio
  • LOD range visualization toggle
