What Bullet Time does

Bullet Time, from Blace Plugins, is an AI-based effect for After Effects and Premiere Pro. Its processing is handled by an AI backend, and it can run in CPU mode on any supported Windows or macOS machine.

Hardware acceleration is available on Windows with an NVIDIA GPU and on macOS 12.3 or later with M1 or M2 chips or Intel systems with an AMD GPU, and runs orders of magnitude faster than CPU. A CUDA Memory Sharing option speeds up resolutions above 4K, a Stop Processing button cancels long calculations, and 16-bit compositions are supported.

Key features

  • AI backend for processing
  • CPU mode on supported Windows and macOS
  • GPU acceleration on NVIDIA and Apple Silicon
  • CUDA Memory Sharing for above-4K frames
  • Stop Processing button and 16-bit support
