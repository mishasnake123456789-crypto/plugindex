What Super3D Import & Export .Wrl does

Super3D Import & Export .Wrl adds VRML 97 support to Blender via dedicated File menu entries. Conversion happens on the Super3D cloud service, and the add-on is released under a GPL license.

Import keeps IndexedFaceSet meshes, including per-vertex and per-face color, along with object hierarchy and group nodes, and export writes polygon meshes in the same format. It helps people dealing with older scientific, CAD or web-3D files that arrive as .wrl.

Key features

  • File menu entries for .wrl import and export
  • Cloud conversion via Super3D
  • Keeps IndexedFaceSet meshes and vertex or face colors
  • Preserves hierarchy and group nodes
