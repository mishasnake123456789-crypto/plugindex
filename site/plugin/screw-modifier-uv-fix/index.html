Blender add-on that repairs the UVs created by the Screw modifier, which leave ground-parallel faces with no area.

What Screw Modifier Uv Fix does

The Screw modifier's cylindrical projection collapses faces that lie parallel to the ground to zero-area UVs. Styriam's Screw Modifier UV Fix repairs this.

From the edit-mode context menu, right-click and choose Fix Screw Modifier's UV. The replacement UV is scaled proportionally to edge lengths in the main edge loop. It is intended for meshes created by applying the Screw modifier, such as lathe-style vases, bottles and columns, and works with Blender 3.0 and later.

Key features

  • Repairs zero-area UV faces
  • Edit-mode context menu command
  • UV scaled by main edge loop lengths
  • For meshes made with the Screw modifier
  • Blender 3.0 and later
