What Auto Modeller Pro does

Auto Modeller Pro lets you paint 3D geometry or textures directly onto surfaces in Blender using UV-based instancing. A performance baking step locks in UV placement before you start painting, keeping the viewport responsive.

A UV Scale slider resizes the instanced pieces on the fly, and any imported or custom mesh can serve as the deforming shape. Several object slots can be assigned and toggled during painting, so details vary across a surface. The panel sits in the 3D Viewport sidebar with a simple layout, useful for greebles, panels and surface detail.

Key features

  • UV-based painting of geometry or textures
  • Pre-bake for performance
  • UV Scale slider
  • Deform with any custom mesh
  • Multiple toggleable object slots
