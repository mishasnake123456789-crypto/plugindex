What Synctools Pro For Unreal Engine 5 does

SyncTools Pro for Unreal Engine 5 moves static mesh actors, with transforms, materials and properties, between UE5 scenes using copy and paste. It also brings in layouts from Blender, Maya and other DCCs through a shared protocol.

You can choose which actor types and properties transfer, units are matched automatically on cross-DCC imports, and shortcuts default to Ctrl+Shift+C and V but can be remapped. A SyncTools menu appears in the editor menubar, Nanite-enabled meshes are preserved, and a cache folder in Documents clears itself.

Key features

  • Static mesh actor transfer with materials
  • Selective transfer of types and properties
  • Automatic unit matching across DCCs
  • Nanite-friendly, remappable shortcuts
