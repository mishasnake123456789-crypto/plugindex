A Blender add-on that gathers shape keys and custom properties into slider panels attached to an armature.

What Gui Slider does

GUI Slider collects controls into slider panels that live on your armature, so important parameters are always close by in the viewport. It works with Auto Rig Pro, custom rigs and scenes with multiple armatures, with no rebuild required.

Sliders can connect to shape keys, custom properties, node parameters, modifier and constraint parameters with on or off, object visibility, and camera and light settings, which covers any property that allows Add Driver, including booleans, floats and integers. A Quick View Mode shows all sliders at once. Riggers and animators working with facial shapes will find it cleans up their controls.

Key features

  • Slider panels attached to the armature
  • Works with Auto Rig Pro and custom rigs
  • Controls shape keys, custom properties and more
  • Any property that supports drivers
  • Quick View Mode
