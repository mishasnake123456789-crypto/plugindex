What Limber 2 does

Limber 2 by Animatable speeds up character rigging in After Effects by building limbs for you. Rigs are drawn from a Limb Library, now with support for three-bone limbs, so arms and legs with elbows or knees are easier to set up.

The library is accessed through REST, or offline from a locally installed copy of its repository. Button groups in the panel can be disabled or re-enabled in Settings, the Rename button swaps names between two selected limbs, and locators rotate via the shortest route. It also works with Bodymovin for web.

Key features

  • Limb rigs from a Limb Library
  • 3-bone limb support
  • Offline library via local repository copy
  • Rename button swaps names of two limbs
  • Compatible with Bodymovin for web
