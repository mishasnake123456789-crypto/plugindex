What Strange Attractor Blender Add-On + Bonus does

This add-on by smice produces strange attractors, the looping chaotic curves from dynamical systems, directly inside Blender. 75 attractors, famous and obscure, are available.

A gallery shows every attractor as an image, and a blend file holds them in an asset box for dropping into a scene as adjustable curve objects (not dynamic). A bonus file adds animation and gradient materials for the round curves. Documentation and FAQs are provided, with Blender 2.93 to 5.1 support in Cycles and Eevee under the MIT license.

Key features

  • 75 dynamically generated attractors
  • Gallery and asset box blend file
  • Bonus animation and gradient material file
  • Blender 2.93 to 5.1, MIT licensed
