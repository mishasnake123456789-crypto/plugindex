What MoovIT VFX Panel does

MoovIT VFX Panel supports handoff from editing to compositing. It exports either the clips selected in the timeline or everything on a chosen track into an export folder, optionally in subfolders, and writes a description file that any text app or browser can read.

It scans an input folder for new versions, recognizing them by filename and swapping them in for the original clips. Subfolder structures are supported. A recent update added a Create Track for Imports function and a new interface.

Key features

  • Export selected clips or whole tracks
  • Description file written to export folder
  • Version checking in the input folder
  • Filename-based replacement of clips
  • Create Track for Imports function
