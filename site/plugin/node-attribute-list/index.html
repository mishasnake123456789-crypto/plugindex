What Node Attribute List(节点属性列表) does

Node Attribute List by W_Cloud speeds up adding attribute nodes in Blender's Geometry Nodes and Shader Nodes. A shortcut-driven menu lists what is available and adds the right node.

The Named Attribute List opens with 2 or Shift+2 and covers named attributes, vertex groups, UV maps, color attributes and attributes on objects. Clicking adds a node by default. Procedural modelers and shader artists can stop typing attribute names. The result is less memory strain and fewer typing errors when a project uses many custom attributes, which is common in procedural setups.

Key features

  • Named Attribute List menu on 2 / Shift+2
  • Lists vertex groups, UV maps and color attributes
  • Object attributes included
  • Works in Geometry and Shader nodes
