Mirrors Blender keyframes and applies time offsets to build symmetrical, dynamic motion.

What Mirror & Offset Keyframes does

Mirror & Offset Keyframes reflects animation on a selected object and lets you shift it in time. This turns a single motion into a mirrored counterpart or a staggered sequence.

It is bundled with Animation Generator Pro, includes documentation from the developer and is distributed under the GPL license. Motion designers and character animators can quickly create alternating limbs, echoed movements or paired objects without re-keying. It works directly on existing keys, so adjustments can be made at any stage of animation.

Key features

  • Mirrors keyframes on a selected object
  • Applies offsets
  • Builds dynamic mirrored sequences
  • Bundled with Animation Generator Pro
