What Anim Offset Pro does

Anim Offset Pro is designed for animating rigged characters in Blender. You edit a pose in the 3D Viewport in Pose Mode, and the add-on propagates that transformation offset across the selected keyframes of the active Action Slot.

A side-panel dropdown selects the action and slot, showing the slot's users, and start and end frame inputs define the range. Offsets are applied automatically across the range. Pressing Ctrl+Z twice undoes an edit and removes the propagation.

Key features

  • Propagates pose offsets across keyframes
  • Works directly in Pose Mode
  • Action and Action Slot dropdown
  • Start and end frame range
  • Undo with Ctrl+Z twice
