What Plotter does

Plotter, from Motion Boutique, turns raster footage and images into vector graphics inside After Effects using a choice of algorithms. The output looks like plotted or traced artwork and stays editable.

A range of settings fine-tune the result, the vector layer can be composited over the original footage, and colors can be taken from the source. Both RGB and CMYK color modes are offered. When ready, the result can be exported to an SVG file or converted into a shape layer, which suits stylized looks and print-style graphics.

Key features

  • Converts footage and images to vector art
  • Several algorithms with fine-tuning settings
  • RGB and CMYK color modes
  • Colorize from source colors
  • Export to SVG or convert to shape layer
