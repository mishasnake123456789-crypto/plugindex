What Auto Crop 3 does

Auto Crop 3, from aescripts batchframe, is a native After Effects plugin that shrinks compositions to the area their layers cover. The current composition can be cropped as it is, with no precomposing step, and several comps selected in the project panel can be processed together.

If layers sit outside the frame, an option expands the comp before cropping so they are included. A customisable Script UI panel and KBar support provide quick access, and Apple Silicon is supported. Artists preparing assets, exporting elements or trimming oversized comps will get tidy bounds with little effort.

Key features

  • Crops compositions to fit contents
  • No precomposing needed for the current comp
  • Batch crop of comps selected in the project panel
  • Expand before cropping to include outside layers
  • Script UI panel, KBar and Apple Silicon support
