Windows batch script built on Robocopy that previews changes and asks for confirmation before mirroring a folder backup.

What Robocopy Backup Script does

This is a Windows backup script rather than a true Blender add-on, listed for people who want to protect their project folders. It builds on Robocopy to mirror a source folder to a destination, and it runs incrementally, so after the first pass it is usually quick.

Before copying anything it counts files and reports new, newer, older and extra items, warns when older or extra files turn up, and waits for a y or n answer. Choosing n leaves both folders untouched. Robocopy parameters can be edited in the script, and backups to a local network are supported. Source and destination must both be on Windows.

Key features

  • Pre-backup summary of new, newer, older and extra files
  • Warning when older or extra files are found
  • y/n confirmation before anything is changed
  • Incremental mirror using Robocopy
  • Editable command parameters, works over a local network
