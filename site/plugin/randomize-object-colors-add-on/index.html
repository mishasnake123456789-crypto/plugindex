What Randomize Object Colors Add-On does

Randomize Object Colors assigns a unique randomly generated color to every selected mesh object. It is a quick way to distinguish many similar pieces or create colorful ID views.

Colors can be removed to restore the original scene, all generated materials can be deleted without touching other materials, and objects can be selected by their random color. Useful for checking separate parts of a model and for building mask references.

Key features

  • Random color for every selected mesh
  • Remove Colors restores the original
  • Delete All Colors clears generated materials
  • Select meshes by random color
