What Totally Random Plus does

Totally Random Plus combines the Select Random+ and Set Random+ add-ons to give Blender more control over randomness. Its tools go beyond the built-in utilities and work in edit mode as well.

You can randomly select objects, vertices, edges or faces with separate sliders, limit the choice to a vertex group or collection, or pick an exact count instead of a percentage. Transforms can reset a value to a random amount within a range or increment it randomly, either uniquely per element or with one shared value. Units convert between metric and imperial.

Key features

  • Random selection of objects and mesh elements
  • Vertex group and collection limits
  • Set or increment transforms randomly
  • Per-element or shared random values
