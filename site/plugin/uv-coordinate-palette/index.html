What UV Coordinate Palette does

UV Coordinate Palette stores positions of the 2D cursor within UV space. Saved coordinates form a palette that you can recall precisely whenever needed.

It works with sample libraries built from color textures and suits smooth gradients where each pixel represents a specific value. Stylized and game artists who map faces to palette texels can place UVs exactly and repeatably.

Key features

  • 2D cursor coordinate palette in UV space
  • Save and recall precise positions
  • Sample libraries from color textures
  • Suited to gradient textures
