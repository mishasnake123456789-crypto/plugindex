Blender add-on that inserts an adjustable cyclorama backdrop in one click, modeled on Cinema 4D's.

What Backdrop does

Backdrop, by Muzammil-Halimov, gives Blender a studio cyclorama similar to the one in Cinema 4D. A single action drops a curved backdrop mesh into the scene for product shots and portfolio renders.

Add it through Shift+A under Mesh, or via the context menu with an object selected; its shape can be modified later. It saves the time of modeling a seamless floor-to-wall sweep.

Key features

  • One-click cyclorama creation
  • Adjustable shape
  • Shift+A Mesh menu entry
  • Right-click menu entry with an object selected
