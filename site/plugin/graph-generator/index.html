What Graph Generator does

Graph Generator is a Blender add-on from TFMSTYLE that builds animation graphs between keyframes. Pick two or more keyframes, store the selection, and generate graphs through sliders across several preset graph types.

Keyframes are created dynamically and update automatically, and a Graph Selector helps when you manage several graphs. Available types are Spring, Bounce, Plateau and Pulse, plus a Random Graph preset that offers Repeat and Continuous settings. It gives motion designers expressive easing without drawing every curve manually.

Key features

  • Generates graphs between saved keyframes
  • Slider-based graph options
  • Dynamic keyframe creation with auto updating
  • Spring, Bounce, Plateau, Pulse and Random types
  • Graph Selector for multiple graphs
