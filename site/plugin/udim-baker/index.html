Blender script that bakes onto every UDIM tile carrying UVs with a single button.

What Udim Baker does

Udim Baker removes the repetitive part of baking with UDIMs in Blender. Instead of re-targeting each tile in turn, one button bakes to every tile the current object has UVs on.

It reads the UDIM setup of an Image Texture node in the Shader Editor and ships with documentation. Texture artists producing high-resolution multi-tile maps can bake detail from high-poly sources in one pass.

Key features

  • One button bakes all UDIM tiles
  • Bakes every tile that has UVs
  • Uses the UDIM data of an image texture node
  • Documentation included
