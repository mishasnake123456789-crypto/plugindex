What History Bookmark Pro - Track, Rollback, And Bookmark Your Blender Workflow does

History Bookmark Pro makes experimenting in Blender less risky. It shows recent operations as a readable timeline and lets you return to any recorded step with Undo to Selected, with Redo Last Undo for recovery.

Scene bookmarks save full snapshots of the blend file as restore points before destructive operations. Auto mode records every compatible action, while manual mode records only chosen steps. Object bookmarks can be temporary or persistent across restarts, and temporary session data can be cleaned up when Blender closes.

Key features

  • Visual history timeline
  • Undo to any selected step
  • Scene state bookmarks as restore points
  • Auto and manual recording modes
