What Palettegrid does

Palettegrid is a Blender plugin from SavedPixel for palette-based texturing. You build flat-color and gradient strips inside a single texture, choose a resolution from 32px up to production sizes, and avoid round trips to an external image editor.

UVs can be snapped to any strip in one click, with UVs created automatically if the mesh has none, even across hundreds of faces. UVs can additionally be projected onto a gradient strip as seen from whatever viewport angle you like, place radial gradients from the 3D cursor, and edit colors live while looking at the model.

Key features

  • Flat and gradient strips in one texture
  • Resolution from 32px to production sizes
  • One-click UV snapping to any strip
  • Project UVs onto gradients from the viewport
  • Radial gradients placed at the 3D cursor
