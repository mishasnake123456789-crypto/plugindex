What GothLab GridGen does

GridGen from GothLab builds grid-based shape layouts procedurally inside After Effects. More than 16 generative tools draw the structure, while 200-plus colour themes can be regenerated, randomised, recoloured and applied.

Sixty-plus presets cover effects, animation and Element 3D templates, and parameters such as balance, contrast and symmetry are fully adjustable, with batch generation and custom presets. Output can be exported as PNG up to 16K, SVG or AI. Master controllers manage layout, colour, animation and 3D extrusion, while Tiler places layers in rows and columns and Stacker piles them along Z. Ideal for HUDs, tech backdrops and symmetrical designs.

Key features

  • 16+ generative layout tools
  • 200+ colour themes
  • 60+ presets including Element 3D templates
  • Export to PNG up to 16K, SVG or AI
  • Tiler and Stacker layer arrangement tools
