What Blecolac - 3Dprinter Cnc/Laser Gcode Exporter/Controller Blender 3D Addon does

Blecolac turns Blender models into G-code for fabrication. It supports CNC drilling and carving, laser engraving and cutting, and 3D printing, with configurable sizes, origins and passes. G-code can be sent straight to a printer.

It cuts bezier paths, engraves images, includes a Bottle tool for cylindrical objects, and an inset solution for filling shapes with curves. A built-in G-code viewer previews the toolpath before running it. It suits makers who design in Blender and want to machine or print directly.

Key features

  • G-code from 3D objects for CNC
  • Laser engraving and cutting
  • Bottle tool for cylinders
  • Inset curve fill
  • Built-in G-code viewer
