A Blender add-on that adds soft body jiggle and bounce to mesh regions defined by an edge loop.

What Easy Jiggle does

Easy Jiggle creates physics-driven bounce on parts of a Blender mesh. Select a closed edge loop in Edit Mode and a configured jiggle region is generated immediately, with soft body physics that reacts to movement and gravity.

Strength, damping, stiffness and goal weights can be tuned for each effect, and a dedicated panel with collapsible sections manages several effects. Naming and syncing are automatic, so renaming a region updates the associated vertex group. Animators who want secondary motion on bellies, cheeks or props without full simulation setup will find it convenient.

Key features

  • Region-based jiggle from a closed edge loop
  • Strength, damping, stiffness and goal weights
  • Panel with collapsible sections for many effects
  • Automatic naming and vertex group syncing
