What RE:Vision Effects Twixtor Pro does

Twixtor Pro retimes footage, creating new in-between frames so clips can be slowed down, sped up or ramped smoothly. It works in After Effects, Premiere Pro and DaVinci Resolve, and across other Adobe, Apple, Avid and OFX hosts, with Resolve Studio 15 or later.

A DNN mode uses a deep neural network to improve results. Other options are Global Motion and a Smart Blend setting for the Vectors In input. Time remap mode in Premiere Pro includes an embedded speed ramp keyframe editor. GPU processing is available, and recent releases cut the VRAM it needs.

Key features

  • Slow-motion and speed change interpolation
  • DNN deep neural network mode
  • Global Motion and Smart Blend options
  • Embedded speed ramp editor in Premiere Pro
  • GPU processing with lower VRAM needs
