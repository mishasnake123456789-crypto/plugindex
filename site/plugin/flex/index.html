Builds dynamic grid and line layouts for After Effects layers that realign themselves when content changes.

What Flex does

Flex by Zack Lovatt creates layouts in After Effects that rearrange themselves when layers change size or number. Instead of nudging items into place, you set up a rig and let it keep everything aligned.

Grid Mode places layers in a grid, and Line Mode offers row and column arrangements. Gutter controls, measured in pixels, handle the spacing between items. Matte Mode and the inner and outer stroke options for shape layers are not enabled. Flex works with After Effects from CC 2015.3 to 2026. Designers building menus, lower thirds or infographic layouts that change often will save considerable manual tweaking.

Key features

  • Dynamically realigning layouts
  • Grid Mode rigs
  • Line Mode offering row and column layouts
  • Pixel-based gutter spacing
  • Supports After Effects CC 2015.3 through 2026
