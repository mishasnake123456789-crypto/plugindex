What Realtime Endframe Add-On does

The Realtime Endframe Add-On keeps Blender's timeline from stopping at a fixed end frame while you are still working. As playback gets close to the end, it pushes the end frame forward.

It lives in a tab of the 3D Viewport sidebar, where a Start Recording button begins playback and begins extending the range. This is useful for open-ended performances, simulations and live recording of motion, where you do not know the final length ahead of time.

Key features

  • Auto-extends the timeline during playback
  • Tab in the 3D Viewport sidebar
  • Start Recording button
  • Pushes the end frame as it nears
  • Suits open-ended takes
