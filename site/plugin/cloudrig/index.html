What CloudRig does

CloudRig is a rigging add-on for Blender, developed by Blender Studio. You draw a simple armature called a Metarig, and the generator produces the helper bones, constraints and drivers needed for a full animation rig.

Component types include Toon and Layered chains, Shoulder and Curve IK, and a Component Instance type lets one bone chain borrow another chain's type and parameters. Optional extras such as pie menus and improved operators speed up daily animation tasks. Character riggers, especially on stylized productions, can set up flexible rigs repeatably.

Key features

  • Generates rigs from a Metarig
  • Chain, Shoulder and Curve IK components
  • Component Instance type
  • Optional pie menus and improved operators
