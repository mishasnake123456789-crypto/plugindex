What mxseditor code snippet generator does

This code snippet generator extends mxseditor for people who write MaxScript in 3ds Max. It executes custom MaxScript through a shortcut, inserting your own snippets into the editor as you work.

The developer built it by combining mxseditor_calltips with mxseditor. To define snippets you edit the codeSnippet function in the script file; the tool itself is pure MAXScript. Setup involves removing the Ctrl+Tab hotkey through the global options file, and a demo gif is included. Scripters who retype the same boilerplate regularly can save time.

Key features

  • Runs custom MaxScript by shortcut inside mxseditor
  • Combines mxseditor_calltips and mxseditor
  • Snippets defined in the codeSnippet function
  • Written entirely in MAXScript
