What Set Opacity - Make Blender Transparent does

Set Opacity places a slider in the viewport header that makes Blender's window see-through. References such as concept art or mood boards stay visible behind the interface as you work, an idea borrowed from ZBrush.

The range runs from 50 to 100 percent, responds as you drag, and needs no setup after installation. Sculptors, modelers, animators and texture artists can trace or compare against a picture without juggling windows. It is lightweight and adds no reported performance cost, so it can stay enabled throughout a session.

Key features

  • Opacity slider in the viewport header
  • 50 to 100 percent range
  • Instant response
  • No setup required
