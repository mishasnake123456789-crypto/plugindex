What Quick Floor Pro 1.2.5 - Efficient Wood Floor Installation Workflow does

Quick Floor Pro creates floors for interior visualization and ArchViz in Blender. From one texture it can produce up to 16 distinct looks, using UV rotations, mirroring and random offsets.

Hue, saturation and brightness can be randomized for subtle differences, and a neighbor exclusion algorithm keeps planks with the same texture from touching. One-click patterns include Herringbone, Chevron, Basketweave, Hexagon and Flat layouts. A Plank/Tile Manager overrides individual textures. The package includes a Quick Start PDF and a demo scene.

Key features

  • Up to 16 variations from one texture
  • Hue, saturation and brightness randomization
  • Herringbone, Chevron, Basketweave and more
  • Plank and tile manager, non-destructive
