Blender add-on that automatically tracks camera motion from footage and sets up the 3D scene.

What Easy Camera Tracker does

Easy Camera Tracker extracts camera movement from video inside Blender so you can place 3D elements into a shot. Tracking takes a few clicks and runs in the background.

The scene is prepared for you with a keyframed camera, the footage as a background sequence, a point cloud, and render settings that match the clip's resolution, frame rate and color profile. Object tracking uses an implementation of the Polychase add-on with automatic masking. It can export undistorted video, reapply distortion, handle rotation-only and zoom shots, and build dense point clouds on Windows with an Nvidia GPU.

Key features

  • Automatic background camera tracking
  • Scene setup with camera, background and point cloud
  • Object tracking with automatic masking
  • Undistort export and distortion reapply
  • Manual tracking settings and video trimming
