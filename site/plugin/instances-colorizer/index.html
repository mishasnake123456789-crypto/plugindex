Blender add-on that tints objects sharing one data block so linked instances stand out in the viewport.

What Instances Colorizer does

In a big scene it is hard to tell which objects are true instances of the same mesh. Instances Colorizer by Nikita Akimov paints them automatically: press Colorize Instances in the panel, and the colors show up when viewport shading is set to Object.

Multi-Color mode gives each group its own color, which you can change per group, while Single-Color mode uses one color for all instances. Objects instanced later pick up the existing color. Useful for cleanup and optimization passes.

Key features

  • Automatic colors for instance groups
  • Multi-Color mode with per-group editing
  • Single-Color mode for all instances
  • Visible when viewport shading is set to Object
  • New instances inherit existing color
