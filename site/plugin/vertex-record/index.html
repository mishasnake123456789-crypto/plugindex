Vertex Record

FreeBlender

Records vertex space transformations in Blender and converts them into script code that can be applied to another object.

What Vertex Record does

Vertex Record captures what you do to vertices and outputs it as code. Lock a main object, press record, and the change can be carried to a second object.

An Alignment Table Generation tool helps with scaling and moving, and bone-related support is included. Technical artists can reproduce geometry edits via script rather than repeating them manually. This is useful for repeating the same adjustment on other models or keeping a record of how a shape was changed.

Key features

  • Records vertex transformations as script code
  • Lock onto a main object
  • Apply recorded changes to another object
  • Alignment Table Generation
