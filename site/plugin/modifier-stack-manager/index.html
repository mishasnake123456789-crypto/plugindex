What Modifier Stack Manager does

Modifier Stack Manager gives Blender's modifier stack a list view similar to those for Materials, UV Maps and Vertex Groups.

The list lets you create, delete, duplicate, reorder, rename and apply modifiers, flip their render, viewport and edit-mode visibility, apply or clear everything at once, and open the selected modifier's settings. Modelers with long stacks gain a compact, easier overview. Seeing the stack as a list also helps when many modifiers exist, because you can rename, reorder and toggle them without scrolling through the long properties panel.

Key features

  • Add, remove, duplicate and rearrange
  • Rename modifiers
  • Toggle render, viewport and edit visibility
  • Apply or remove all
