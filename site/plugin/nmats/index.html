What Nmats does

Nmats is a Blender add-on that generates materials in bulk. Select several objects, enter how many materials you want, and the add-on creates them without repetitive clicking in the material panel.

Shared mode makes that number of materials used by every selected object, while Unique mode creates the entered number for each object, so the total is the count multiplied by the objects selected. Unique materials are renamed from the object name and optional custom suffixes can be used. It helps with large scenes and asset sets needing consistent material setup.

Key features

  • Generates a chosen number of materials
  • Shared mode for common materials
  • Unique mode per selected object
  • Automatic renaming with optional suffixes
