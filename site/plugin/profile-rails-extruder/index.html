Blender addon that sweeps a flat face profile along a rail in any direction without tapering the profile shape.

What Profile Rails Extruder does

Profile Rails Extruder extends a flat face in Blender along a path of your choosing. Unlike a curve bevel, which can pinch or taper the section as the path turns, this keeps the profile's shape constant regardless of the rail direction.

The rail can run in any direction in 3D space. Modelers building pipes, trims, railings and architectural moldings can create consistent sections without correcting distortion manually.

Key features

  • Extrudes a face profile along a rail
  • Rail can go in any direction
  • Profile shape stays unchanged
  • Avoids the tapering of curve bevels
