Image-based layer texturing for Blender with reorderable layers, blending, procedural masks and optional paint tools.

What Layer Creator 2 does

Layer Creator 2 builds a texture from stacked image layers inside Blender. Layers can be reordered, deleted and saved from the panel, and each one has adjustable color.

Blending between layers uses custom images or built-in procedural node settings, and procedural textures work as textures or masks for individual or all layers. A separate optional Paint Tools add-on adds brushes. It suits artists who prefer a layer workflow like image editors for materials.

Key features

  • Image-based reorderable layers
  • Per-layer color and blending
  • Procedural textures and masks
  • Optional Paint Tools add-on
