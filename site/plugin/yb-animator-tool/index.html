What YB Animator Tool does

YB Animator Tool is a Blender add-on by YB_ for 2D animators working with grease pencil. It turns the drawings on grease pencil layers into a keyframe sequence and writes a CSV timing sheet next to them.

The CSV follows the sorting and file format of Clip Studio Paint timing sheets, which means it can be imported into After Effects in the same way. Select a grease pencil object, then pick the matching keyframe render entry in the render menu to run it. Layers whose names end with Hide are skipped, and it supports Blender 4.2 and newer.

Key features

  • Exports grease pencil layers as sequenced keyframes
  • Generates a CSV timing sheet
  • CSV matches Clip Studio Paint timing sheet format
  • Imports into After Effects like a Clip Studio sheet
  • Layers with a Hide suffix are skipped
