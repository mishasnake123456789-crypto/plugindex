Adds a Scripts icon to Blender's toolbar for quickly loading, reordering and editing multiple scripts.

What Script Manager does

Script Manager is a small add-on that puts a 'Scripts' icon in the Blender toolbar. Click it, enter a script path, and you can manage several scripts from one place.

A supplementary menu lets you reorder, delete, locate or open scripts in an editor for on-the-fly changes, and edits apply instantly. New scripts can be created and are saved automatically. It is helpful for developers and technical artists who test or switch between many utilities.

Key features

  • Scripts icon in the toolbar
  • Load multiple scripts by path
  • Reorder, delete, locate and open
  • Instant application of changes
