Selects layers relative to the play-head in After Effects and shifts them together for quick re-timing.

What SLCTR does

SLCTR is a script by Tim Bywater for re-timing compositions using selection. Choosing the right group of layers in a long timeline is tedious, so it selects by position relative to the play-head.

You can select all layers of a chosen type, layers behind or ahead of the play-head within a type scope, or layers sharing the same label color as the current selection. SHIFT moves the selected layers to the play-head while retaining relative timing, FLIP reverses their top-to-bottom order, and any selection can be restricted to the current workspace.

Key features

  • Select by layer type scope
  • Select layers behind or ahead of the play-head
  • Select by shared label color
  • SHIFT to the play-head keeping relative timing
  • FLIP layer order
