Cleans and profiles Blender Shader Editor graphs: auto layout, node grouping, Eevee optimization and performance profiling.

What Node Master does

Node Master serves material artists and technical directors working with big shader networks. Clean Up Graph arranges nodes in a structured layout following dependency hierarchy, with inputs positioned relative to outputs.

Group Nodes finds related nodes such as Image Texture and Environment setups, and materials can be optimized for Eevee. Performance profiling covers Cycles and Eevee. It makes complex materials easier to read and cheaper to render. Cleaner graphs make handoffs easier, and the profiling highlights which parts of a material are expensive to render.

Key features

  • Clean Up Graph by dependency hierarchy
  • Group Nodes for related node sets
  • Eevee optimization
  • Performance profiling for Cycles and Eevee
