What Boxcutter 26 : Stiletto does

Boxcutter 26: Stiletto, from TeamC, lets you draw shapes directly on a mesh to cut, join or inset it. Shapes remain live until you decide to apply them, so both non-destructive and destructive approaches are possible.

Cut types include Cut, Slice, Inset, Join, Knife, Extract and Make. Custom cutters can be extracted, and Self.Cut turns the mesh that is being cut into the cutter itself. A snapping system offers several options, including ctrl dot snapping that fades with distance, and an on-the-fly edit system provides dots and helpers while drawing. Hard surface modelers get fast, sketch-like shaping.

Key features

  • Cut, Slice, Inset, Join, Knife, Extract, Make
  • Non-destructive or destructive workflow
  • Self.Cut and custom cutters
  • Advanced snapping options
  • On-the-fly edit dots and helpers
