Blender add-on that combines several images into one using square, row, column or next-fit packing.

What Image Packer does

Image Packer merges multiple images into a single image from a panel in Blender's Image Editor. Four packing algorithms are available.

Square produces a 1x1 result, Row keeps heights equal, Column keeps widths equal, and Next Fit leaves image sizes untouched at the cost of occasional gaps. Images can be scaled to the average, median, minimum, maximum or a custom side length, with padding, background color and ordering options. Game and web artists building texture atlases get quick sheets.

Key features

  • Four packing modes
  • Flexible image scaling
  • Padding and background color
  • Image ordering options
