What Animation Library Export & Import Clips does

Animation Library Export & Import Clips, by za studio, keeps a shared repository of animation actions for Blender. It is aimed at animators reusing clips, such as those producing cartoon series from an archive.

One click exports an object's actions into a library folder, each stored as a .blend with the action and a reference empty, alongside mp4 previews and JSON bone selection sets. The Anim Lib panel in the sidebar browses and refreshes in real time. Loading validates data for rigs in Pose Mode, bone mirroring maps names like .L to .R, and selection sets filter where animations land.

Key features

  • One-click export of actions into a library
  • Mp4 previews and JSON selection sets
  • Bone mirroring for symmetrical rigs
  • Pose Mode loading with data validation
