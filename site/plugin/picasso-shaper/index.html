After Effects tool that creates shape layers with expressions so they resize to fit their content.

What Picasso Shaper does

Picasso Shaper generates shape layers that adapt to what is inside them. Expressions are written into the shape's size and position attributes, so the shape grows or shrinks automatically whenever its content changes. That avoids manually adjusting backgrounds behind text or graphics.

The Snug Fit option hugs the line structure of a text layer, and a Colors option lets you build custom palettes that Picasso uses when producing shapes. Version 2.0.0 introduced a reworked interface.

Key features

  • Shape layers with built-in size expressions
  • Automatic resizing to content
  • Snug Fit follows text lines
  • Custom colour palettes for generated shapes
  • Reworked UI in version 2.0.0
