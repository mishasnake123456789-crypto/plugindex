What QuickScript does

QuickScript is a small code editor panel meant for trying out ExtendScript snippets, such as free scripts from forums or ones produced by ChatGPT, without setting up a separate development environment. It runs inside After Effects and Premiere Pro.

A built-in JavaScript linter catches mistakes, Shift+Tab indents code automatically, and the $$.log() method prints messages or variables to the console. You can search application commands by name or ID and retrieve a property's path, which is handy when writing scripts that target specific properties.

Key features

  • Built-in JavaScript linter
  • Shift+Tab auto-indent
  • $$.log() console output
  • Search app commands by name or ID
  • Get property path
