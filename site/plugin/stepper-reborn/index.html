What STEPper Reborn does

STEPper Reborn brings .STEP CAD models into Blender, preserving the assembly hierarchy and tessellating the geometry with OpenCascade. It forks the original STEPper add-on by Ambi.

Components can be instanced through collections or meshes, and resolution is set through angular and linear deviation limits that can differ per component. A simple mode offers range adjustment and toggles. Built on cadquery-ocp, it is a lighter add-on that runs on macOS Apple Silicon and Intel, Windows and Linux.

Key features

  • STEP import with preserved hierarchy
  • OpenCascade tessellation
  • Instancing via collections or meshes
  • Angular and linear deviation controls
  • Cross-platform builds
