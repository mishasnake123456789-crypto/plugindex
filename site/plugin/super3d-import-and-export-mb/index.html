What Super3D Import & Export .Mb does

Super3D Import & Export .Mb brings Maya Binary scenes into Blender and writes them back out. Dedicated File menu entries trigger the process, and conversion happens on the Super3D cloud service, which removes the need for an Autodesk Maya seat.

Import preserves mesh geometry with baked skinning, hierarchy and naming, plus baked F-curve animation. It helps studios that receive .mb deliverables and want to open them directly in Blender. Highlights cover file menu entries for .mb import and export and cloud conversion without a Maya seat.

Key features

  • File menu entries for .mb import and export
  • Cloud conversion without a Maya seat
  • Keeps baked skinning, hierarchy and naming
  • Baked F-curve animation on import
