What Shaping Recorder does

Shaping Recorder captures the modeling process in Blender so it can be played back later. It records mesh edits over time, including topology changes, and recognizes undo and redo, along with the 3D viewport's location, rotation and zoom.

The recording is replayed with interpolation, and an optional frame sequence can be exported. Modeling tutors, timelapse creators and portfolio artists can show how a form developed without screen capture.

Key features

  • Records mesh edits and topology changes
  • Detects undo and redo
  • Records viewport location, rotation and zoom
  • Interpolated replay
  • Optional frame sequence export
