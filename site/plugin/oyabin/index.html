What OYABIN does

OYABIN is a REDDESK extension for Premiere Pro that tidies label colors in the Project panel. Select an item, run the tool, and its label color is set to match the color of the item that contains it.

That saves editors from recoloring individual clips by hand after moving them into a color-coded bin or sequence. The extension is free, requires Premiere Pro 23.0 or later, and the listed release is version 1.0.0, last updated April 9, 2024.

Key features

  • Matches item label color to its parent
  • Works on a selected project item
  • Runs as a Premiere Pro extension
  • Requires Premiere Pro 23.0 or later
