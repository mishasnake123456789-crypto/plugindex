Blender add-on that insets faces while keeping their rounded corners and avoiding overlaps.

What Round Inset does

Round Inset extends the usual inset operation in Blender so that a face keeps all its rounded corners. The result can be beveled afterward for clean, smooth panels.

An overlap prevention option stops corners from colliding on any face, including ones without rounded corners. A size threshold decides which parts remain corners and which long edges shrink, corner scale changes the corner shape, and merge vertices with an adjustable distance cleans up collapsed geometry. Hard surface modelers get tidy rounded insets quickly.

Key features

  • Inset that keeps original round corners
  • Prevent Overlap option
  • Size Threshold and corner scale
  • Merge Vertices with adjustable distance
