What VDM Brush Baker does

VDM Brush Baker turns a sculpted plane into a vector displacement brush in Blender. A single button bakes the displacement and creates a brush ready for sculpt mode.

A Create Sculpting Plane button provides a starting setup. The map is saved as an OpenEXR file next to the blend file, or in a temp folder if the file is unsaved, and new brushes appear as Draw brushes. The panel is in the 3D Viewport sidebar's Tool tab. Sculptors can make stamps such as scales, ears or rivets and reuse them.

Key features

  • One-click VDM bake and brush creation
  • Create Sculpting Plane starter
  • Saves OpenEXR displacement map
  • Brush appears in sculpt mode
