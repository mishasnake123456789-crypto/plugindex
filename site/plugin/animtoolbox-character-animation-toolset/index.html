What Animtoolbox - Character Animation Toolset does

Animtoolbox by Tal Hershko bundles tools for character animators in Blender, organized under the headings Temp Controls, Anim Tools and Display Tools.

An editable motion path lets you edit curves in the viewport, move keyframes or Bezier handles and add or remove keys, with proportional editing and smoothing. Retime Markers, Copy Paste Matrices and Temp Pivot are also included. Animators gain a Maya-like toolset. The toolset is grouped by purpose, so animators can find temporary controls, curve helpers and display options without searching through scattered menus.

Key features

  • Retime Markers
  • Copy Paste Matrices and Temp Pivot
