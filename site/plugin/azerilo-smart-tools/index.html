What Azerilo Smart Tools does

Azerilo Smart Tools is a bundle of eight utility add-ons for Blender, aimed at game developers, character artists and generalists handling modeling and export chores.

Rig Remover strips armatures, vertex groups and shape keys while keeping mesh transforms intact, which suits static exports. Symmetry Checker detects and fixes asymmetry in real time with a threshold system, and Fast Texture Bake produces Normal and Diffuse maps. Further tools cover outliner organization and rendering. Having them in one package saves hunting for separate scripts.

Key features

  • Rig Remover for static exports
  • Real-time Symmetry Checker
  • Fast Texture Bake for Normal and Diffuse
  • Outliner organization and render tools
