What Set Exact Edge Length does

Set Exact Edge Length is a Blender add-on for precision modeling in CAD-style and architectural work. It adds length and angle commands to the right-click context menu so you can type exact values.

It is a Blender extension-compatible add-on, works with Blender 3.6 through 5.1 under Cycles and Eevee, and is released under the GPL license. Anyone building to specific dimensions can correct edges without calculations or scaling workarounds. Key capabilities include set exact edge length from the context menu and set exact angle from the same menu.
