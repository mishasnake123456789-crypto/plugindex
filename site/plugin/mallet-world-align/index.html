What Mallet: World Align does

Mallet: World Align fixes textures that do not line up by projecting them from world coordinates. Select an object or particular faces and apply the alignment in a single click, without manual tweaking.

It copes with angles and avoids problems where Cube Project struggles. It is part of the developer's UV Aligner toolset and documentation is provided. Environment and architecture artists texturing large surfaces with consistent scale will find it useful.

Key features

  • World-coordinate texture adjustment
  • Whole object or selected faces
  • Single-click alignment
  • Handles angles where Cube Project struggles
