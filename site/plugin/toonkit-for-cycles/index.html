What Toonkit For Cycles does

Toonkit for Cycles provides OSL shader nodes that let Cycles produce non-photorealistic images, from anime looks to technical illustration and expressive art. The nodes are integrated into the Cycles node system and viewport.

The shaders reach clean, noiseless results in roughly four to thirty-two samples. Every output is a color, such as shading, shadows or specular, which can be mixed freely, and face paint tools use vertex colors in Edit Mode. Stylized animators and architectural visualizers can build custom looks.

Key features

  • OSL shader nodes for Cycles
  • Noiseless results in about 4 to 32 samples
  • Color outputs for shading, shadows and specular
  • Face paint with vertex colors
