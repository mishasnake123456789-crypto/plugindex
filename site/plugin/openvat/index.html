Blender tool for creating vertex animation texture bakes, with normal data options and animation metadata exported as JSON.

What OpenVAT does

OpenVAT produces VAT bakes in Blender, turning mesh animation into textures for real-time engines. It is listed in the blender_extensions library.

Normal data can be omitted, packed into the shared RGBA texture or kept in a dedicated one. An Animation Data panel writes each animation's name, frame ranges and loop designation into exported JSON. Game artists can define several clips for one bake. These baked textures let game engines play back complex deformation cheaply on the GPU, so crowds, cloth and other effects can run without heavy simulation at runtime.

Key features

  • Normal data: none, packed or separate
  • Animation Data panel with JSON export
  • Name, frame ranges and loop flags
  • Multiple animations per bake
