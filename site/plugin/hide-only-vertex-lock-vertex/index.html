What Hide Only Vertex [Lock Vertex] does

Hide Only Vertex is a Blender add-on by Bookyakuno that hides vertices while leaving faces visible, which effectively locks those points against editing. It also works on curves, hiding only the curve's points.

It appears in the Mesh, Show/Hide menu and the matching Curve menu. Ctrl+Shift+H hides the selection and Alt+Ctrl+Shift+H hides unselected vertices, and hidden points return with the usual Reveal Hidden command (Alt+H). Documentation and a GitHub link are provided for reference.

Key features

  • Hides only vertices while faces remain visible
  • Also works on curve points
  • Menu entries under Show/Hide
  • Shortcuts for selected and unselected vertices
  • Restore with Reveal Hidden (Alt+H)
