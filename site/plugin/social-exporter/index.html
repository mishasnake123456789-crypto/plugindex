What Social Exporter does

From Medhat Mounier comes Social Exporter, a plugin for After Effects that prepares one video for several social media platforms. Instead of setting up each render by hand, you choose from presets and export in a few clicks.

Three export modes are offered: Individual, All Duplicate and All Nest. Custom presets can be created, edited and deleted, a set of export options is available, and a global frame rate setting applies across outputs. Editors and motion designers who deliver the same piece in many formats save repeated setup.

Key features

  • Presets for various social platforms
  • Individual, All Duplicate and All Nest modes
  • Create, edit and delete custom presets
  • Global frame rate setting
