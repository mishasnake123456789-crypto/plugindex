What File Wrangler - Batch Processor does

File Wrangler automates maintenance of Blender project files. It processes many files together to remove clutter and repair broken references.

One click deletes backup files, purges unused data-blocks and compresses the files. A relinking scan finds missing files across the whole project, and path conversion and custom Python scripts can run on each file automatically. Studios and freelancers archiving or handing over projects will save a lot of housekeeping time.

Key features

  • One-click cleanup of backups and unused data
  • Project-wide relinking of missing files
  • Path conversion
  • Custom Python run on every file
