What Outliner Model Preview does

Outliner Model Preview by Shuimeng displays a rotating view of the selected object or collection directly in Blender's Outliner, so models can be recognized at a glance.

A preview toggle button switches it on, and Shift plus Left Click on that button opens the add-on's function panel. It supports Blender 4.2 LTS and newer. Artists managing scenes with many similarly named objects can identify them visually. A visual preview is especially useful when object names are generic or when a collection holds many similar items.

Key features

  • 360 degree preview in the Outliner
  • Preview toggle button
  • Shift+Left Click opens options
  • Supports Blender 4.2 LTS and newer
