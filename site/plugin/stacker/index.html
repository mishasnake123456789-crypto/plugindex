What Stacker does

Stacker is a script from KiwiVFX that organizes layers into neat stacks. Layers can be gathered toward the bottom, top, left or right sides, with options for alignment, a fixed starting position and keyframes.

It supports scale, can ignore a parent's rotation and connect to a parent's opacity, and has an anchor point option for fixed X and Y positions. Settings save automatically and can be saved, loaded or reset, even between PC and Mac. A lighter composition sorting function is included, helping artists maintain order across many comps.

Key features

  • Stacks layers in four directions
  • Alignment, fixed start and keyframe options
  • Scale, parent rotation and opacity options
  • Save and load settings across computers
  • Lightweight composition sorting
