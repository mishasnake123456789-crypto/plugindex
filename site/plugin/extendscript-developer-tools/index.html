What ExtendScript Developer Tools does

ExtendScript Developer Tools by Vakago Tools puts a console and editor inside After Effects and Premiere Pro. You can type ExtendScript commands, see results at once and avoid juggling external tools.

It inspects the Adobe API, including parts beyond the documentation such as the QE API, and analyses the global namespace or lets you click objects in the console to inspect variables. A JSX Editor runs, loads and saves scripts at runtime, and extensions can be debugged. A free trial is offered. Plugin developers, automation engineers and curious Adobe enthusiasts will find it useful for exploring hidden functionality.

Key features

  • Developer console for ExtendScript commands
  • Adobe API inspection including QE API
  • Variable inspection of the global namespace
  • Run, load and save scripts in the JSX Editor
  • Free trial available
