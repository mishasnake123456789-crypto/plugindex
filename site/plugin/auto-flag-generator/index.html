Generates sets of waving flags for data columns or object groups in Blender, with cloth physics baking.

What Auto Flag Generator does

Auto Flag Generator creates a flag for each data column or group of objects, making it useful for 3D data visualizations and world comparison videos. Cloth physics is baked to bring the flags to life.

Operator options set flag length, width, height, direction and wind strength, and flag images come from a folder where files are numbered sequentially. A fast way to build many flags consistently. The flags look physically animated rather than static, which gives infographics and comparison videos a more dynamic feel.

Key features

  • Flags for data columns or object groups
  • Length, width, height, direction and wind options
  • Images loaded from a numbered folder
  • Cloth physics baking
