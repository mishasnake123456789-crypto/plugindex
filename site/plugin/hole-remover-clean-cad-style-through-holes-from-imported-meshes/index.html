What Hole Remover - Clean Cad-Style Through-Holes From Imported Meshes does

Hole Remover detects circular, or nearly circular, through-holes in CAD meshes brought into Blender and removes them. Cutting out that detail lowers polygon counts for easier editing and faster rendering.

Holes can be filtered by maximum diameter and previewed before removal. It works on one or several selected mesh objects, offers a duplicate mode that keeps the original, and reports what was removed and how topology changed. Useful for hard-surface preparation and real-time assets.

Key features

  • Detects circular through-holes
  • Filter by maximum diameter
  • Preview before removal
  • Multiple objects supported
  • Duplicate mode keeps the original
