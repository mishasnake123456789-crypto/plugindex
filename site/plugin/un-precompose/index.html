After Effects script that pulls layers out of a pre-comp and back into the parent composition.

What Un-PreCompose does

Un-PreCompose reverses the Pre-compose command in After Effects. Select a nested composition and the script moves its layers into the parent comp, keeping their effects and other properties intact, which saves rebuilding a timeline you flattened too early.

Several pre-comps can be processed in one run. Layers that use randomized expressions can be adjusted so their placement stays correct, and extracted layers can carry the pre-comp's name as a prefix to keep the stack readable. The script runs natively on Apple Silicon.

Key features

  • Extracts layers from nested comps into the parent
  • Preserves effects and layer properties
  • Handles several pre-comps in one run
  • Optional fix for randomized expression layers
  • Prefixes extracted layers with the pre-comp name
