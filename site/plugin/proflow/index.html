What Proflow does

ProFlow is a Blender add-on from Pitiwazou for adding floaters to objects, including welds, custom assets and moldings. Choose an asset in the library, a target object, and the tool that places it.

Assets can be positioned where several objects meet, configured for dependable results, replaced with others from the library or scene, and cut with the Cut tool. Edges can be extracted from objects for reuse. You can also create your own assets, manage them, use collection instances and transfer or convert assets with random values.

Key features

  • Place assets at intersections of objects
  • Replace assets from library or scene
  • Cut tool and edge extraction
  • Create and manage your own assets
  • Collection instances and random-value conversion
