Strips the frame-number suffix from image files rendered out of After Effects.

What SuffixSlayer does

SuffixSlayer solves a narrow but irritating problem: rendering a single still from After Effects appends a frame number to the filename. This utility removes that suffix so the file ends up with the clean name you intended.

It is a single-purpose tool with a name-your-own-price licensing approach, and it works across a very wide range of versions, from After Effects CC 2014 up to 2025. A demo video is provided for anyone who wants to see it before using it on delivery stills.

Key features

  • Removes the frame number suffix from image renders
  • Name-your-own-price licensing
  • Works with After Effects CC 2014 to 2025
  • Single-purpose render naming utility
  • Demo video available
