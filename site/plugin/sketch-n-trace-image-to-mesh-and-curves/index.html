What Sketch N' Trace: Image To Mesh (& Curves) does

Sketch N' Trace is a Blender add-on by Sahin Ersoz that converts images such as JPEG or PNG into 3D mesh or curve objects. The mesh resolution is adjustable, and the image itself can be edited during conversion with tools to erase, draw, deform, smooth, modify and simplify.

You can invert the image, adjust its boundaries and extrude it. Outlines have adjustable thickness and resolution, including sketchy 2D thick and thin styles, and bevel and automatic materials are supported. Edit Trace provides further refinement. Good for logos, illustrations and sketches.

Key features

  • Traces images to mesh or curve objects
  • Edit the image during conversion
  • Extrude, bevel and invert options
  • Adjustable outlines including sketchy styles
  • Automatic materials
