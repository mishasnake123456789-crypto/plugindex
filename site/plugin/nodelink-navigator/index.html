Blender extension that highlights and follows connected nodes in Shader, Geometry Nodes and Compositor editors with theme-aware colors.

What NodeLink Navigator does

NodeLink Navigator makes node networks easier to read by emphasizing connections. It highlights the nodes tied to a selection and lets you move along the links in Shader, Geometry Nodes and Compositor editors.

Colors match the active Blender UI theme automatically so the look stays consistent across editors, and high-saturation highlights add stronger contrast. Artists debugging dense node graphs can trace data flow without scrolling around.

Key features

  • Highlights connected nodes
  • Navigates along node links
  • Theme-aware coloring
  • High-saturation highlight contrast
  • Shader, Geometry Nodes and Compositor support
