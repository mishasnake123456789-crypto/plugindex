What Batch Render does

Batch Render uses Blender from the command line to render multiple objects from multiple angles. It renders recursively through the current folder and subfolders and reads .obj and .fbx files.

Materials are created and assigned automatically from albedo, opacity, emissive, metallic, roughness, normal and height maps, the camera is fitted to each model, and turntables with custom frame counts can be generated. It is ideal for building preview image sets.

Key features

  • Recursive folder rendering
  • OBJ and FBX support
  • Automatic material creation
  • Camera fitting and turntables
