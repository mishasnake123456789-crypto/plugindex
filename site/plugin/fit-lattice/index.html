Blender add-on that wraps a lattice around one or more meshes with control over rotation, subdivision and cleanup.

What Fit Lattice does

Fit Lattice builds a deformation cage around meshes in Blender automatically. It aligns and resizes the lattice at any rotation, so objects that are not axis aligned are still tightly enclosed.

It works on selected faces, edges or vertices while staying in Edit Mode, and one-click options apply the deformation and delete the lattice, modifiers and vertex groups afterward. Interpolation is set to B-Spline. Modelers using lattices for bending, tapering and shaping save setup steps.

Key features

  • Aligns and resizes lattices at any rotation
  • Works in Edit Mode on selections
  • One-click apply and cleanup
  • B-Spline interpolation
