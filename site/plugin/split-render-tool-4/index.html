What Split Render Tool 4 does

Split Render Tool 4 divides a render into tiles so you can produce larger images on the same hardware and sidestep the "System is out of GPU memory" error. In split mode it merges the tiles automatically in the Compositor and creates a new Blender file containing a group node per View Layer with all passes.

Animated Border Render keyframes the border region along the timeline and outputs a file with a composition group for each enabled View Layer, while Object Border Render targets on-screen objects. It helps with large prints and heavy scenes.

Key features

  • Tile-based split rendering with auto merge
  • Animated Border Render
  • Object Border Render
  • Group node per View Layer with passes
