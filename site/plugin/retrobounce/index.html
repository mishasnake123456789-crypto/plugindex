What RetroBounce does

RetroBounce, made by loophouse, is a plugin for After Effects that recreates the nostalgic motion of a bouncing logo drifting around a screen. It can also drop objects under gravity so they fall and rebound off the walls.

Bounce Mode reproduces the classic corner-hitting drift, while Gravity Mode exposes gravity, speed and wall collision settings. Color can change on every hit, echo trails can be customized, and an Outline Mode is available. Loops come out seamless, and several objects can be animated at once with a single click, which is handy for playful intros and retro-themed edits.

Key features

  • Bounce Mode with classic screensaver motion
  • Gravity Mode with adjustable collisions
  • Color change on every hit
  • Echo trails and Outline Mode
  • Seamless loops for multiple objects
