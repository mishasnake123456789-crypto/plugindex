What Blendshape Master Pro - Advanced Shape Key Manager does

BlendShape Master Pro is a Blender add-on that makes long lists of shape keys manageable. Facial rigs and stylized characters often carry dozens of morph targets, and finding the right one in the default list is slow.

Keys are sorted automatically into groups such as Face & Head, Body, Stylized/Anime, Emotions, Mouth/Lips and Other. A live search narrows the list as you type, a favorites panel pins the ones you use most, and one click toggles a morph fully on or off for preview. Current values can be saved as JSON presets, and morph data exports to JSON or FBX for Unity, Unreal or custom pipelines.

Key features

  • Automatic category grouping of shape keys
  • Live search and a favorites panel
  • One-click morph preview toggle
  • JSON presets and JSON or FBX export
