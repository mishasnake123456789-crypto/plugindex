What Bulk Mesh Analysis Addon does

Impression Sunrise's Bulk Mesh Analysis Addon writes a thorough report on mesh objects from Blender's Export menu, ready to open in spreadsheet software.

It lists vertex, face and edge counts, volume, bounding box volume and detail density, along with transforms, materials and textures. It finds intersecting faces, distinguishes manifold from non-manifold objects and flags missing textures. Technical artists auditing many assets for a game or archive can compare them in one table.

Key features

  • Exports mesh properties to CSV
  • Vertex, face and edge counts
  • Volume and detail density
  • Detects intersecting faces and non-manifold meshes
  • Flags missing textures
