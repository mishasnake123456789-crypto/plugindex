What Kushiro Tools does

Kushiro Tools bundles more than twenty-four modeling add-ons from KushiroCG into a single Blender menu with a two-column layout. Instead of managing many small installs, you get topology helpers collected in one tidy place.

Included tools range from Even Loop, Outset Boundary, a non-AAQP quad tool, Trim Mesh and Safe Inset to recent additions such as Align Edges, Quad Adder, Unbend Mesh and Ngon Loopcut. It is free, works as a Blender extension with versions 2.83 through 5.1, and is released under the GPL. Modelers who like small, focused utilities will find a lot here.

Key features

  • 24+ modeling tools in one menu
  • Even Loop, Outset Boundary, Trim Mesh, Safe Inset
  • Recent Align Edges, Quad Adder and Unbend Mesh
  • Blender 2.83 to 5.1 as an extension
