What Stroky does

Matin Kazerooni's Stroky is a tool built for After Effects aimed at outlining things properly. A single click applies strokes to PNG, shape or text layers, and the corners come out clean, even at large widths.

You can stack as many strokes on an object as you like, and existing effects on the layer stay intact because the strokes are created without disturbing them. All strokes can be animated from one place, so building outlined titles, sticker looks and layered borders is quick.

Key features

  • One-click strokes on PNG, shape and text layers
  • Multiple strokes per object
  • Clean corners with unlimited width
  • Keeps existing layer effects intact
  • Animate strokes from a single place
