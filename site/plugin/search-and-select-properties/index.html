What Search and Select Properties does

Search and Select Properties is a panel from Airweb that makes it easier to find things in crowded layer stacks. Type a property name and the matching properties are picked out for you, even several at once.

Results are listed alphabetically, and a Strict option narrows matching when you need exact names. Once selected, properties can be copied and pasted while avoiding the duplicate group problems that often appear with the normal approach. It benefits animators and riggers who regularly move settings between layers.

Key features

  • Search properties by name
  • Select multiple matches at once
  • Alphabetical results list
  • Optional Strict matching mode
  • Copy and paste without duplicate groups
