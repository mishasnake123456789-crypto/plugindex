What Loopy does

Loopy by Rob Barrett puts loop options for After Effects into a single panel. It works on keyframes, paths, pre-comps and footage, offering Cycle, Ping Pong, Offset and Continue modes.

Alt-clicking the Cycle button applies Time Remap to AV or pre-comp layers with no expression, setting keyframes to the trimmed duration. Direction can be changed, a keyframe modifier can be set and limited to existing keyframes, and existing expressions on a property are retained. Options and a user guide are within reach. Animators needing seamless repeats will save time.

Key features

  • Cycle, Ping Pong, Offset and Continue modes
  • Expression-free Time Remap on Alt-click
  • Change loop direction
  • Keyframe modifier with existing-keyframe option
  • Retains existing expressions
