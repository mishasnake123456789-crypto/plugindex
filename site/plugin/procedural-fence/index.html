Blender add-on that generates four styles of fence without overlapping geometry, with optional low-poly output.

What Procedural Fence does

Procedural Fence builds fence meshes in Blender that avoid overlapping geometry. You pick a style and set the dimensions.

Styles are Diamond Shaped, Diagonal Twisted Wires, Simple Iron Rod and Old Style Wooden. Fields control length and height, a Scale Factor sets pattern density, and Thickness adjusts rods, wires or wood. Sample materials for the frame and netting can be added and edited, and a low-poly version is available. The result is useful for yards, farms, industrial sites and game levels.

Key features

  • Four fence designs
  • Length and height fields
  • Scale Factor for density
  • Thickness setting
  • Optional sample materials and low-poly mode
