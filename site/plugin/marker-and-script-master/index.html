One After Effects panel for creating markers, running saved .jsx scripts and sending renders to Media Encoder.

What MARKER and SCRIPT MASTER does

MARKER and SCRIPT MASTER combines three routine tasks in a single panel. You can create markers from text, split comma-separated phrases into several markers, or add one marker per character, and also place them at set intervals from the playhead.

Markers on a second layer can be aligned to those on the first. You may load .jsx scripts, give them icons and save them for quick access, and a Render button hands the comp to Media Encoder for choosing presets, names and destination. It suits animators who like having everything within reach.

Key features

  • Markers from text, phrases or single characters
  • Interval-based marker placement
  • Align second-layer markers to the first
  • Saved .jsx scripts with icons
  • Render button sending comps to Media Encoder
