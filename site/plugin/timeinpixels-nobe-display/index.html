Virtual display plugin that mirrors the DaVinci Resolve preview to an external monitor without extra hardware.

What timeinpixels Nobe Display does

Nobe Display mirrors the viewer of DaVinci Resolve into a window that can sit anywhere on the desktop, including on a second monitor. This means a clean preview output is possible without buying a dedicated video interface.

Mirroring runs in real time with GPU acceleration on both the Edit and Color pages. The picture can be calibrated using an ICC profile and a display 3D LUT, and gamma, gain and RGB channels can be tweaked quickly. A separate NDI version adds network streaming. Home studios, freelance colorists and editors on laptops can set up a basic reference display cheaply.

Key features

  • Real-time GPU-accelerated preview mirroring
  • Place the preview anywhere on the desktop
  • ICC profile and display 3D LUT support
  • Gamma, gain and RGB adjustments
  • Edit and Color page support
