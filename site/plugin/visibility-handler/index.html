What Visibility handler does

Visibility handler is a Blender add-on from DanielBystedt that transfers visibility settings between the viewport and the render. It covers objects, modifiers and modifier settings, and can work from viewport to render or from render to viewport.

Run it from View > Visibility handler in the 3D View, or find it through the F3 search menu. Install by dropping the .zip in or using Install from Disk; no special permissions are needed, and saves time when the viewport and render settings must match across a big scene.

Key features

  • Copies object and modifier visibility
  • Viewport to render or render to viewport
  • Located in View > Visibility handler
  • Reachable through F3 search
  • Requires no special permissions
