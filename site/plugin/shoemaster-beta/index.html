What Shoemaster_Beta does

Shoemaster is a Blender plugin for footwear designers and 3D artists. It carries a project from a 2D sketch to a production-ready 3D shoe, whether the design is a leather dress shoe, a sneaker or high-fashion footwear.

Industry-focused automation handles repetitive tasks, and the models it produces are aimed at manufacturing or visualization. It works with both Cycles and Eevee. This is a beta release, so expect it to evolve.

Key features

  • Sketch-to-3D footwear workflow
  • Automated tools for repetitive tasks
  • Dress shoes, sneakers and fashion footwear
  • Cycles and Eevee compatible
