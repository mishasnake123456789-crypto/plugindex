What Vox - Voxel Tools And Tile Map Generator does

Vox is a Blender plugin for voxel editing, in which each voxel can be swapped for a tile. It adds drawing tools plus a tile map designer which positions tiles by rule.

Three edit-mode tools add, paint and remove voxels, with standard draw and draw-and-extrude modes. Painting works per voxel or with a brush, offering strength, falloff and spacing controls. It suits game designers creating blocky worlds and tiled environments. Voxel editing combined with tile placement rules lets small hand-made edits expand into complete structures for stylized games and diorama scenes.

Key features

  • Add, paint and remove voxel tools
  • Draw and draw-and-extrude modes
  • Brush painting with strength and falloff
  • Rule-based tile map designer
