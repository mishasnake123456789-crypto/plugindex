What Id Color Pass does

Id Color Pass is a ready-made node group for creating colored ID mattes in Blender. ID passes help compositors isolate objects or materials for grading, so this saves building the color mapping manually.

You append the id_pass node tree to your file and assign an ID to each object or material. It requires IndexOB or IndexMA to be enabled in the Render Layers properties, and the group connects after that output on the Render Layers node to produce the colored pass. Documentation is included. Compositors who want selective color work or masks from a render will find it useful.

Key features

  • Appends an id_pass node tree
  • Assign IDs per object or material
  • Works with IndexOB or IndexMA
  • Outputs a colored ID pass
  • Documentation included
