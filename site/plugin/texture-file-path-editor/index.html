What Texture File Path Editor does

Texture File Path Editor, by BHiMAX, helps tame the image paths that accumulate in a Blender project. You can inspect where textures live, relink missing ones and gather them in one place. It is categorised under Workflow.

The add-on is open source under GPL-3.0-or-later and requires Blender 4.2.0 or newer.

Key features

  • Manage all texture paths
  • Relink missing textures
