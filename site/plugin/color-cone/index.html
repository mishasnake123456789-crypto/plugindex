What Color Cone does

Picture Instruments' Color Cone is a colour tool that uses Color Warp technology to shift colours smoothly rather than with hard edges. It corrects colour and creates looks for video.

It helps reconcile mixed white balance and restore or adjust skin tones, and an Auto-Radius function speeds selection. The effect opens inside the host and drops onto a clip like a native effect, with every parameter animatable by keyframes. Settings are stored in the project and presets in the host. Colourists using After Effects, Premiere Pro or Final Cut Pro X get precise control.

Key features

  • Color Warp technology for smooth transitions
  • Correction and look creation
  • Mixed white balance reconciliation
  • Skin tone restoration and adjustment
  • Keyframable parameters and Auto-Radius
