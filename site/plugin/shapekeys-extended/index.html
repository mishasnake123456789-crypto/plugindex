A Blender add-on that replaces the shape key panel with a hierarchy layout, edit-mode support and face tracking presets.

What Shapekeys Extended does

Shapekeys Extended reworks Blender's shape key system while keeping the standard options. Keys appear in a hierarchy with collapsible groups that you can move and reorganize, which keeps large facial rigs readable.

New shape keys are added below the current selection, and everything works in Edit Mode. A Copy Shapekey button duplicates data into a new key, extra menu tools include Invert, Copy and Split and Remove Empty Shapes, and presets are provided for face tracking standards such as ARKit and MMD. Character riggers and VTuber model makers will benefit.

Key features

  • Hierarchy layout with collapsible groups
  • Edit-mode support
  • Copy, Invert, Split and Remove Empty Shapes
  • ARKit and MMD face tracking presets
  • New keys added below the selection
