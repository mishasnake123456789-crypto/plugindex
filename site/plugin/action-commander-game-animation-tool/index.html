Blender add-on for managing many actions, switching animations, importing FBX actions and exporting to FBX.

What Action Commander - Game Animation Tool does

Action Commander is built for game artists whose characters carry lots of animations. A panel gathers all actions in one view, and switching animation adjusts the frame range, since actions live on the object, only the relevant ones are listed.

FBX actions can be imported without bringing in meshes or armatures, wrapping Blender's own importer and cleaning up extras. Shadow Rig support bakes actions from a control rig, an Action Bin shows every action in the file, and an experimental export writes selected actions to single or multiple FBX files.

Key features

  • Action management panel
  • Frame range updates on animation switching
  • Import FBX actions without mesh or armature
  • Shadow rig baking
  • Experimental multi-action FBX export
