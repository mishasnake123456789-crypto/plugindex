Blender 3D Viewport reference board for images and notes, with up to four boards and saved layouts.

What Board Ref does

Board Ref adds a reference board workflow to Blender so images and notes sit beside your work.

Version 1.1 supports up to four independent boards, each with its own images, notes, appearance, layout, visibility and position, and boards can be hidden without losing content. Boards, notes, layouts, colors and image links are restored with the saved project, and a control chooses which 3D Viewport shows them. It keeps reference visible while modeling, so you do not switch to another window.

Key features

  • Up to four independent boards
  • Images and notes
  • Saved with the Blender project
  • Hide boards without deleting
  • Choose which viewport displays boards
