Relinks many Premiere Pro clips at once by find-and-replace on file names, then renames them to match.

What Batch Relinker does

Batch Relinker deals with media that has moved or changed version. Tell it which part of a filename differs, point it at the new folder, and it relinks the selected clips and updates their names in the Project panel.

The folder search is recursive, and failed files are listed with detailed error messages so problems are easy to trace. It was built with multilingual projects and versioned deliveries in mind, where the same clip may exist under slightly different names in several folders. The plugin runs on both Windows and macOS.

Key features

  • Batch relink using find and replace on filenames
  • Renames relinked clips to match new media
  • Recursive folder search
  • Failed file reporting with error details
  • Works on Windows and macOS
