3ds Max script that adds Color Correction nodes to VrayMtl slots and can randomize their parameters across objects.

What VrayMtl Color Correction does

VrayMtl Color Correction inserts Color Correction nodes into VrayMtl materials in 3ds Max using whichever values you choose. It targets five slots (diffuse, bump, glossiness, translucent, self illumination), leaving any existing bitmap inside the node it adds.

After application, every parameter can still be changed, and each has an option for randomization. The New Materials option makes one material per selected object so random values are spread across them. This allows variation on repeated assets, such as slightly different tones for tiles or furniture, without editing each material by hand.

Key features

  • Adds Color Correction nodes to VrayMtl slots
  • Covers diffuse, bump, glossiness, translucent and self illumination
  • Keeps existing bitmaps in the node
  • Parameters adjustable after applying
  • New Materials option for per-object random values
