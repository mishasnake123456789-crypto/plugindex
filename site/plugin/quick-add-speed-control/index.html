What Quick Add Speed Control does

Quick Add Speed Control is a Video Sequence Editor add-on that saves repeating the same step for each clip. Select multiple strips and it adds a speed control effect to each of them.

The speed is set automatically across all strips. Documentation is included, and support is listed for Blender versions from 2.83 upward. Video editors changing the pacing of many clips at the same time will find it quicker than adding effects individually.

Key features

  • Adds speed control strips to all selected strips
  • Sets speed automatically across strips
  • Works in the Video Sequence Editor
  • Documentation included
  • Lists support from Blender 2.83
