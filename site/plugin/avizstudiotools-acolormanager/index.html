What AvizStudioTools - AColorManager does

AColorManager is part of the AvizStudioTools suite for 3ds Max. With version 2.0 it gained the ability to convert V-Ray scenes from sRGB to ACEScg, supporting a move to an ACES-based color workflow.

It loads through the AIO App interface, which offers a version drop-down with load and open buttons and shows the tool name, version label and description. Colored status dots flag outdated versions in blue, and unloaded or subscription-only versions in red. A help link opens the tool's webpage with details on functions and parameters. It suits V-Ray users standardizing their color management.

Key features

  • V-Ray sRGB to ACEScg scene conversion in v2.00
