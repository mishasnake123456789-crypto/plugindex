What Dissolve 2-Edge Vertices does

Dissolve 2-Edge Vertices is a lightweight Blender add-on by Jackal for cleaning up meshes. It finds the selected vertices that connect to only two edges, which add nothing to the shape, and dissolves them.

The command appears in the Vertex menu while in Edit Mode on mesh objects and has no settings to configure, so it is a single quick action. It supports undo and runs on Windows, Linux and macOS, making it a convenient helper after booleans, imports or retopology work.

Key features

  • Dissolves selected vertices with exactly two edges
  • Added to the Edit Mode Vertex menu
  • No settings required
  • Full undo support
  • Works on Windows, Linux and macOS
