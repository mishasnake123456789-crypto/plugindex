What Auto Vertex Painting does

Auto Vertex Painting prepares a model for texturing by turning materials into vertex color IDs. Each face gets its own color ID derived from the material assigned to it.

It covers every separated mesh and keeps the assignments consistent between them. A single click does the job, automatic material cleanup is included, and the result is ready to use in Substance. Texture artists who rely on ID maps for masking can skip painting them by hand.

Key features

  • Unique vertex color per material
  • Works across separated meshes
  • One-click texturing prep
  • Automatic material cleanup
  • Substance-ready output
