What Meshstats does

Meshstats is a Blender add-on by muhuk that reports topological statistics for your meshes. It shows how many tris, quads and ngons there are, and tracks vertex poles: e-poles with five edges, n-poles with three, and star-poles with six or more edges, which sit at fan centers.

You can set a polygon budget for each mesh object and see how much of it is used. In Object Mode the add-on highlights tris, ngons and the various poles in the viewport. It helps modelers keep topology clean for animation and subdivision.

Key features

  • Counts of tris, quads and ngons
  • E-pole, n-pole and star-pole counts
  • Per-object polygon budget display
  • Viewport highlighting in Object Mode
  • Panel for quick topology checks
