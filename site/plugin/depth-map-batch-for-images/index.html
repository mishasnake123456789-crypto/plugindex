What Depth Map Batch For Images does

Depth Map Batch For Images is a Blender add-on from Viz Life Studio that creates depth maps from a folder of images, a single image or a video file. Everything runs on your own machine, with no web services or external APIs, and you do not need to configure a Python environment of your own.

The nine models on offer include Depth Anything V2, MiDaS (3.0 and 3.1), Zoe Depth and Depth Pro. It offers 20 depth map styles, with grayscale and 16-bit options, and a 16_BIT style that produces 16-bit output from 8-bit sources. Batch processing handles bulk jobs in one click.

Key features

  • Batch depth maps from folders, images or video
  • Runs fully local with no external services
  • Nine models including Depth Anything V2 and Zoe Depth
  • 20 depth map styles with 16-bit output
  • Converts 8-bit images to 16-bit depth
