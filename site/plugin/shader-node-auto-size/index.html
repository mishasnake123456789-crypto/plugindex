What Shader Node Auto Size does

Shader Node Auto Size tidies image texture nodes in Blender's shader editor. Nodes with long filenames often show truncated names, which makes it hard to tell textures apart in a busy material.

The add-on adjusts node widths to fit each filename, so labels are readable at a glance. Material artists working with many texture maps benefit from a cleaner node tree without resizing each node manually.

Key features

  • Fits node width to filename
  • Reads image texture nodes
  • Cleaner shader graphs
