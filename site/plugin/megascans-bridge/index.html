What Megascans Bridge does

Megascans Bridge is a Blender add-on from B3dHub that brings Quixel Megascans assets into Blender directly from the interface. It imports assets that you downloaded using Quixel Bridge.

It works with Blender 4.2 through 5.1, is distributed as a Blender extension with documentation, and is released under the GPL license. Artists and studios using Megascans libraries can skip manual material and mesh setup.

Key features

  • Imports assets downloaded via Quixel Bridge
  • Works from the Blender interface
  • Supports Blender 4.2 to 5.1
  • Distributed as a Blender extension
  • Documentation included
