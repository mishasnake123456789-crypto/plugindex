What Coacd does

CoACD is a Blender plugin that builds convex collision shapes for complex models. It relies on collision-aware concavity and tree-search decomposition to approximate a model with several convex parts.

It installs as an extension on Blender 4.2 through 5.1, is released under the GPL license and includes documentation. Game developers use such meshes for physics. Good collision shapes keep physics fast and reliable in game engines, so this is useful for preparing props, level pieces and characters for export.

Key features

  • Advanced convex decomposition
  • Collision-aware concavity
  • Blender 4.2 through 5.1
  • GPL licensed
