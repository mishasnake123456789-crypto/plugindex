What Two Images does

EBTRR's Two Images (TI) is a comparison tool for Blender. A slider across the x or y axis reveals one picture over another, and it works for images, render slots and the viewer output.

Axis, slider position and separator color are adjustable. Color correction using Saturation, Value and Linear interpolation helps match the pictures, and a fast selector swaps in the Render Result or Viewer. A warning shows when a slot is empty. Good for before-and-after checks during lighting and denoising.

Key features

  • Slider comparison on the x or y axis
  • Compare images, render slots and viewer
  • Adjustable separation line color
  • Saturation, Value and Linear adjustment
  • Quick Render Result and Viewer selector
