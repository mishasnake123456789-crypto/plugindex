What Robotic Arm does

studioromanrec's Robotic Arm supplies a finished arm model for Blender, already set up for animation and for rendering in Cycles, with documentation.

It supports Blender 4.0 and the 3.1 through 3.6 releases, is GPL licensed and is part of the Studioromanrec Blender Add-Ons bundle. Factory, sci-fi and technology scenes can use it directly without building the mechanism. The model arrives ready to pose and animate, and it renders in Cycles, so shots can be assembled around it right away.

Key features

  • Blender 4.0 and 3.1 to 3.6
