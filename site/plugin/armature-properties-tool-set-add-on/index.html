What Armature Properties Tool Set (Add-On) does

The Armature Properties Tool Set promotes custom properties on an armature into an interface you can use without leaving your current work. You can keyframe or add drivers without changing selection or mode.

Properties can be filtered through the interface, a pose bone selection function is included, and a beta search filter helps find items. Riggers and animators with many custom controls on a rig will avoid constantly switching between bones and modes.

Key features

  • Procedural UI for custom properties
  • Keyframe and driver support without mode changes
  • Property filtering
  • Pose bone selection function
  • Search filter (beta)
