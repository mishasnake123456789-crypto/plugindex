What Profiler 2.0 Advanced Curve Beveling does

Profiler 2.0 turns curves into architectural moldings and other profiled shapes in Blender. Pick a cross-section from the visual gallery, apply it to a curve, and get crown molding, casings, handrails and similar parts.

The gallery holds 76 profiles. Mesh edges, faces or edge loops can be converted into curves first, and a 3x3 origin pad handles rotation, mirroring, flipping and offset with live dimension fields. You can save your own profiles with thumbnails or import SVG drawings from Illustrator or Inkscape. Two installers cover Blender 4.2 and up and 3.6 through 4.1.

Key features

  • Gallery of 76 ready-made profiles
  • One-click Apply to any curve
  • Convert mesh edges and loops to curves
  • Save custom profiles and import SVG
  • Extension for 4.2+ and add-on for 3.6 to 4.1
