What PropLine does

PropLine is a 3ds Max geometry plugin, written in script, that distributes props along splines by parameters rather than one-off operations. It stands in for the Spacing Tool but keeps everything adjustable, so changing the spline or settings updates the result.

Placement modes include Knot for each vertex, Interpolation for each interpolated corner, Spacing for regular intervals and Size based on prop dimensions. Source props can follow list order or random order with a seed, be randomly flipped 180 degrees on Z, and be progressively scaled. It also has its own Divide amount, copes with CorVexSpline and BorderSpline, and lets you pull prop transforms back out later for game engine export.

Key features

  • Knot, Interpolation, Spacing and Size placement modes
  • List order or seeded random prop selection
  • Random 180 degree flip and progressive scaling
  • CorVexSpline support and better BorderSpline handling
  • Retrievable prop transforms for game engine export
