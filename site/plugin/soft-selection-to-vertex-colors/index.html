What Soft Selection to Vertex Colors does

Soft Selection to Vertex Colors converts the falloff of a soft selection in 3ds Max into grayscale vertex color values written directly onto the geometry. It works on Mesh and Poly objects.

Four modes control how the selection is applied: replace, add, darken and subtract. That makes it possible to build up vertex color masks gradually, for example to drive shaders, blend weights or ambient occlusion-style shading in game assets. The current version is 0.4, and it is a small, focused utility for anyone using soft selection as a painting tool.

Key features

  • Converts soft selections to grayscale vertex colors
  • Works on Mesh and Poly objects
  • Replace, add, darken and subtract modes
  • Writes values directly onto the geometry
  • Version 0.4
