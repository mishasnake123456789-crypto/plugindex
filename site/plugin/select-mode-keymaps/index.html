What Select Mode Keymaps does

Select Mode Keymaps, by 1P2D, saves a few steps when modeling in Blender. It binds keys that toggle between Object and Edit Mode and lets you jump straight into Face, Edge or Vertex select from Object Mode.

By default the comma key toggles the mode, and combining it with Ctrl, Shift or Alt picks the select type. Modes are not combined. The keymap can also be assigned to a mouse button, handy with gaming or productivity mice. It needs no special permissions and works with Blender 4.5 LTS and newer.

Key features

  • Toggle Object and Edit Mode by key
  • Enter Face, Edge or Vertex select directly
  • Default comma-based bindings
  • Can be bound to a mouse button
  • Blender 4.5 LTS and newer
