Blender add-on that runs Python scripts from your Script Directories with proper window context.

What Run Scripts From Folder does

Run Scripts From Folder lets Blender users pick and execute a script stored in the folders listed under Preferences, File Paths, Script Directories. Because it runs from the correct window context, bpy.ops operators work without overriding the area context.

It is reachable from the Edit menu in the top bar and the F3 search, and you can put it in the Q quick menu or bind a shortcut. This helps when building your own operator macros. It reads .py files from disk, for which it asks for file permission.

Key features

  • Choose and run scripts from configured folders
  • Avoids area context overrides
  • Edit menu and F3 search access
  • Quick menu or shortcut assignment
  • Supports custom ops macros
