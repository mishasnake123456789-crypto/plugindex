Blender mesh-editing add-on using mouse shortcuts to connect vertices, delete edges and extrude wide lines from edges.

What Mesh Thikuthiku does

Bookyakuno's Mesh Thikuthiku shortens routine edit-mode operations into mouse gestures. Hold Ctrl+Shift+Alt and drag with the middle button to join vertices with an edge.

Using the left button with the same modifiers removes an edge by clicking, or whole loops by dragging. A loop edge option chooses loops as the target, and Target only edges, on by default, restricts deletion to edges and falls back to vertices if needed. It can also turn selected edges into extruded wide lines. Handy for retopology and cleanup.

Key features

  • Drag to connect vertices
  • Click to remove edges
  • Drag to remove edge loops
  • Target only edges option
  • Extrude wide lines from edges
