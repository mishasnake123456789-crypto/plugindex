What Animated Animals For Blender Add-On does

Animated Animals for Blender is a browser-and-placer for a large set of animated models. You browse, select and drop more than 900 animals into a 3D scene.

The models come from curated Sketchfab playlists, and each has at least one animation, often a full set. Before placing one you can preview vertex count, animation count and license details. It suits architectural, game and film scenes that need living background elements without custom character work.

Key features

  • Browse and place 900+ animated animals
  • Curated Sketchfab playlists
  • Every model has at least one animation
  • Preview vertex count, animations and license
  • Drop into scenes directly
