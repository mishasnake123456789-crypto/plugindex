Removes Blender objects in bulk from a sidebar panel by name, material, type, visibility or collection, with a count shown first.

What Remover does

Remover provides flexible deletion for scene management. Objects can be removed according to what is selected, their name, material, type, hidden state or collection.

You see how many objects will go before running anything, a single click can clear the whole scene, and undo still works. Helps clean cluttered files. Since there is a count before deletion and undo afterwards, bulk removal is less risky. The tool is meant for quickly pruning imported scenes, stray helpers or leftover test objects.

Key features

  • Delete by selection, name, material, type, hidden or collection
  • Preview of deletion count
  • Remove all objects in one click
  • Undo support
