Blender add-on that saves node trees with their settings and reapplies them in one click.

What Nodecustombuilder does

NodeCustomBuilder lets Blender artists store node setups and bring them back with a single mouse click. Unlike a plain copy of the nodes, it keeps the settings of every individual node as well.

It works in the shader and compositing editors and also supports geometry nodes. You can organize saved trees into your own folders, which makes it practical as a personal library of reusable looks and effects across projects. The interface is available in English and Chinese, and documentation is included.

Key features

  • Save and reload node trees in one click
  • Stores each node's settings, not only the nodes
  • Shader, compositor and geometry node support
  • Custom folders for organizing presets
  • English and Chinese interface
