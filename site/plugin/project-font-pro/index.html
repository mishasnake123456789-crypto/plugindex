What Project Font Pro does

Project Font Pro by Dotanscripts tackles font management in After Effects. It can swap all fonts or only chosen ones, uses filters to target fonts by name, and changes weight, size, colour or alignment individually.

A text layer's style can be picked up and applied to any font, searches cover the full project, particular comps or the active one, and missing fonts can be found and replaced in one step. It reports how many layers use each font and how many remain affected after filtering, and shows the comp containing a font with one click to open it. Great for inherited or cross-platform projects.

Key features

  • Replace all or selected fonts with filters
  • Change weight, size, colour or alignment
  • Grab and apply a text layer's style
  • Find and fix missing fonts in bulk
  • Usage counts and one-click comp opening
