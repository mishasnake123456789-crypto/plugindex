Blender add-on that draws adjustable-colour toon outlines on selected objects using a solidify modifier and a rim material.

What Stylized Outline does

Stylized Outline is a Blender add-on for giving 3D models a bold, hand-inked edge. Instead of a post-process trick, it builds the outline from a solidify modifier paired with a rim material, so the result lives in the scene like any other geometry.

You pick the objects you want outlined and tune the line thickness and colour to suit the shot. It behaves the same in Cycles and Eevee, which makes it handy for toon shading, concept art and any render that needs a graphic look. It supports Blender 4.0 through 5.1 and ships as a GPL extension.

Key features

  • Outline built from a solidify modifier and rim material
  • Adjustable line thickness and colour
  • Applies only to the objects you select
  • Works in both Cycles and Eevee
  • Supports Blender 4.0 to 5.1
