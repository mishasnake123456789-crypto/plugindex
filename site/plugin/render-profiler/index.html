What Render Profiler does

Render Profiler is a Blender add-on from MultLabs that analyzes how scenes perform in the viewport and in renders. A live HTML report opens in the browser, mirrors what Blender is doing and refreshes on its own.

Three profiling modes, Off, Viewport and Render, can be switched from the report. Tabs show modifier times, heavy meshes, memory, textures and statistics; modifier run times are listed per object, longest first and an estimated memory table for meshes and textures. Technical artists can find what slows a scene down.

Key features

  • Live HTML report in the browser
  • Off, Viewport and Render profiling modes
  • Per-object modifier timings
  • Estimated memory table for meshes and textures
  • Tabs for heavy meshes, textures and statistics
