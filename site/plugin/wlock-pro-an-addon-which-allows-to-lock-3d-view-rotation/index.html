What Wlock Pro - An Addon Which Allows To Lock 3D View Rotation does

Wlock Pro, from CGjazziQ, prevents accidental viewport rotation in Blender. Alt+W toggles the lock by default, and every 3D view is locked or released individually, whether you are in an orthogonal view or looking through a user camera.

The PRO release offers custom hotkeys, and a status icon or button, with colors you can set, shows the lock state. Modelers working from reference views or carefully set angles can keep their framing.

Key features

  • Lock rotation with Alt+W
  • Independent lock per 3D view
  • Custom hotkey in the PRO release
  • Configurable status icon or button
