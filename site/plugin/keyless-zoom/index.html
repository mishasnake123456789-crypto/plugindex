What Keyless Zoom does

Keyless Zoom is a Scrigins tool for After Effects that produces smooth zoom moves without hand-setting keyframes or easing curves. A precise overscan slider controls how much of the frame the move covers and delivers Zoom-to-Fit framing.

Four easing styles give each move its own character, and start and end previews let you check the result before committing. The move can be baked into a fully keyframed camera with no procedural dependencies, and the easing-control null is removed automatically. Status messages guide each step.

Key features

  • Precise overscan slider
  • Zoom-to-Fit framing
  • Four easing styles
  • Start and end previews
  • Bakes to a fully keyframed camera
