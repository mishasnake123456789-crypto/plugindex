What JTB AutoClose freeware does

JTB AutoClose is a freeware helper for AutoCAD users who work with borrowed network licenses. It closes the License Borrowed dialog that appears at startup so that AutoCAD loads without waiting for a click.

It also dismisses the warning that AutoCAD requires a resolution of 1024 by 768 or higher, whether that message is raised by AutoCAD or by the Autodesk Desktop App. It works with AutoCAD and its vertical products, version 1.4.0 added AutoCAD 2026 support, and it is installed with a custom installer rather than the standard App Store one.

Key features

  • Closes the License Borrowed dialog automatically
  • Closes the minimum-resolution warning
  • Works with AutoCAD and vertical products
  • AutoCAD 2026 support since 1.4.0
