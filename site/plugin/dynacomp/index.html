A Blender add-on for real-time viewport compositing with basic color correction and 12+ presets.

What Dynacomp does

Dynacomp offers compositing inside the Blender viewport as you work. Basic color corrections can be applied on the go, so judging the look of a scene does not require a full render and compositor setup.

A set of twelve or more ready-to-use presets and effects, including cinemascope bars and lens dirt, comes as a separate download. It installs as an add-on through user preferences and is a beta version that the developer uses daily. Artists who want immediate feedback on grading and finishing effects will find it a convenient way to iterate.

Key features

  • Real-time viewport compositing
  • Basic color correction on the go
  • 12+ presets including cinemascope and lens dirt
  • Installs as a standard add-on
