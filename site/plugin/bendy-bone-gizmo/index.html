What Bendy Bone Gizmo does

Bendy Bone Gizmo is a Blender plugin for riggers and animators. It adds gizmo handles for the curve, scale and roll values of B-Bones, replacing the need to type each parameter by hand.

Smooth curves can be built in a few clicks while working in Edit Mode. It is particularly suited to toon-style rigs where expressive, bendy limbs are important. Direct manipulation makes it far quicker to dial in smooth, cartoon-style deformation than editing numeric fields on every bone.

Key features

  • Gizmo for curve, scale and roll
  • Smooth curves in a few clicks
  • Works in Edit Mode
  • Suited to toon-style rigs
