What Curve Profile Creator does

Curve Profile Creator, by M.Kumaran, produces parametric curve profiles and sweeps them along edges to create moldings, rails and similar shapes. It is tagged under Modeling, Add Curve and 3D View.

It is open source under GPL-3.0-or-later and requires Blender 5.2.0 or newer.

Key features

  • Parametric curve profiles
