Blender add-on that stores object and 3D cursor positions and returns them on demand.

What Locationsaver does

Locationsaver remembers where things were. It stores the location and rotation of selected objects, so you can move them freely and send them back later.

Each saved position gets a visible marker. Entries can be chosen by checkbox to return objects, and objects can be moved to a chosen location. The 3D cursor position and rotation can be stored too. Markers can be set to zero rotation, hidden, deleted individually or cleared all at once. Documentation is included.

Key features

  • Saves location and rotation of objects
  • Stores 3D cursor positions
  • Return one or many objects from a list
  • Hide, delete or clear markers
