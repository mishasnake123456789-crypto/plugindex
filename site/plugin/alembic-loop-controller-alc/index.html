What Alembic Loop Controller (Alc) does

Alembic Loop Controller (ALC) helps animators reuse cached motion. It makes a short .abc clip repeat forever by defining a start frame and length, with a driver injected into the MeshSequenceCache modifier.

Playback speed can be changed without re-exporting, whether normal, double, half or slow motion, and a time offset delays the start. Flock-style randomization spreads offsets and speeds across many objects so duplicated cycles do not move in lockstep. It is especially useful for crowds and background populations.

Key features

  • Infinite loop from start frame and length
  • Driver injected into MeshSequenceCache
  • Speed control without re-exporting
  • Time offset per object
  • Randomized offsets and speed across many objects
