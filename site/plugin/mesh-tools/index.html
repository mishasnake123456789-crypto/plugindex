Gathers Edit Mode tools in one Blender sidebar panel: bending, relaxing, displacement, twisting, hole filling and mesh stats.

What Mesh Tools does

Mesh Tools combines a range of advanced mesh operations into one panel so they are always close at hand during Edit Mode work. It includes Super Bend XYZ for bending selected vertices along each axis and Edge Twister for twisting edges.

Other tools relax a mesh with adjustable strength, apply random displacement, extrude, fill holes and triangulate, and live statistics keep you informed about the mesh. It is useful for general modeling, cleanup and organic deformation.

Key features

  • Super Bend XYZ and Edge Twister
  • Relax Mesh with adjustable strength
  • Random Displace and extrusion
  • Hole filling and triangulation
  • Live mesh statistics
