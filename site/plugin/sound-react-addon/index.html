Blender add-on that animates any property from an audio file, reacting to bass, highs or a chosen frequency.

What Sound React Addon does

Sound React Addon drives animatable properties in Blender from audio, provided the data path is reachable. Objects can follow the bass, the highs or any chosen frequency through presets or custom paths.

A Basic tab handles quick setup and an Advanced tab targets one specific frequency. Presets include Bass, Kicks, Mild, High, Treble and Full. Scale or a custom data path copied from any property can be driven, Max Size sets how far the object scales, and an Add Sound option brings in background audio. Version 1.2 added an Active Keyframe reaction, and documentation is included.

Key features

  • Properties driven by audio
  • Basic and Advanced tabs
  • Bass, Kicks, Mild, High, Treble and Full presets
  • Scale or any custom data path
  • Active Keyframe reaction
