Drive

FreeAfter Effects

Links one After Effects property to another so a value on one layer controls a property on a different layer.

What Drive does

From Freshmograph comes Drive, a plugin for After Effects aimed at connecting properties together. Instead of writing expressions, you set one property to be controlled by another, making relationships easy to build.

Examples include rotating a layer based on the x position of another layer, changing a particle emitter's rate based on a layer's scale, or shifting a layer's hue according to the opacity of another. It works with After Effects CC 2019 through 2026, and the current version is 1.02, updated in October 2022.

Key features

  • Controls one property with another
  • Rotation driven by another layer's position
  • Emitter rate driven by scale
  • Hue driven by opacity
  • Compatible with CC 2019 to 2026
