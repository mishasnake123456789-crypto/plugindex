What Bounce Keyframe does

Bounce Keyframe, by sum studio, shapes an existing keyframe into a bounce in Blender. Bounce motion usually requires hand-tuning several keys and curves, so a one-step conversion saves time when animating things that drop, hop or settle.

It works for both 2D and 3D animation. The add-on is compatible with Blender 3.0 through 4.3, comes with documentation and a demo video, and is released under a Creative Commons license. Animators and motion designers wanting a quick physical-feeling bounce without building a rig or simulation are the intended users.

Key features

  • Turns a keyframe into a bounce shape
  • Suitable for 2D and 3D animation
  • Compatible with Blender 3.0 to 4.3
