What Quick Reload does

Quick Reload is a lightweight Blender add-on for developers and testers who change add-ons often. It reloads any add-on on demand, so changes can be checked without closing Blender.

A single click or F8 reloads everything at once. Add-on Sets let you group add-ons by name, then enable, disable or reload the group in bulk; sets persist across restarts. The interface is a simple sidebar panel. In practice that means reload any single add-on and reload all with one click or F8.

Key features

  • Reload any single add-on
  • Reload all with one click or F8
  • Add-on Sets for bulk actions
  • Sets persist across restarts
