What YY_Voronoi 2 does

YY_Voronoi 2 is a texture generator by Andrew Yang that draws cell-based Voronoi patterns inside After Effects. Layering different patterns gives results ranging from terrain maps and water caustics to abstract backgrounds.

Color can be calculated several ways, including square, absolute and edge distance, plus a discrete mosaic mode. Euclidean distance gives organic boundaries while Manhattan gives sharp 45-degree ones. Cell dispersion can use the layer's own pixels, evolution animates cells with a period for seamless loops, and repeat, offset, grid size, contrast, brightness, seed and blend mode are adjustable. The algorithm was redesigned in native code with backward compatibility.

Key features

  • Multiple color calculation modes
  • Euclidean and Manhattan distance metrics
  • Layer-driven cell dispersion
  • Evolution with seamless loop period
  • Native code algorithm, backward compatible
