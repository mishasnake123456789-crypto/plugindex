What Marking Menus does

ODI's Marking Menus gives Blender pie-style menus following the concept used in Autodesk Alias. They appear in the 3D view when you hold Ctrl+Shift and press one of three mouse buttons.

Left opens a pick menu to flip between Object and Edit mode and change selection type. Middle shows contextual actions that depend on the active mode. Right brings an interface menu with settings like gizmo visibility and face orientation. Modelers keep their hands near the mouse.

Key features

  • Pie menus on Ctrl+Shift plus mouse button
  • Pick menu for modes and selection
  • Context-sensitive action menu
  • Interface menu for gizmos and overlays
  • Alias-inspired workflow
