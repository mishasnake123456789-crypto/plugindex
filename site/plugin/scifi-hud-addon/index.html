What Scifi Hud Addon does

Scifi Hud Addon from EdenWeby 3D gives Blender users a ready library of futuristic interface graphics. In total there are more than 160 items: over a hundred elements, forty props and twenty premade HUD layouts, so a convincing display can be assembled without drawing every line.

A material editor provides a glow effect that works with Eevee and Cycles, the latter using the glare filter for bloom. The Element Animation Panel offers Constant, Function and Reveal modes, and a noise value control and default flicker animate the glow strength. Documentation is included. It suits motion designers creating sci-fi titles and cockpit screens.

Key features

  • 160+ HUD elements, props and layouts
  • 20 premade HUD layouts
  • Glow material editor
  • Constant, Function and Reveal animation modes
  • Noise value and default flicker
