Blender add-on for batch rendering that runs animation or still jobs, external files and network renders with notifications.

What Render+ does

Render+ handles batch rendering in Blender. A batch panel sets up and executes render jobs for animations or stills at custom frames or ranges, and each job can control its own world, camera, scene, view layer and resolution.

It can render from external blend files, supports network rendering, sends notifications and can power off the machine when finished. Artists who queue overnight renders or work with several scenes and cameras can avoid babysitting the machine.

Key features

  • Batch panel for animation and still jobs
  • Per-job world, camera, scene and size
  • Render from external blend files
  • Network rendering and notifications
  • Power-off on completion
