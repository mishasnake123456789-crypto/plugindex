What OTRN - Open Timecode-Related Notes does

OTRN is a free EditingTools.io tool that reads and writes sequence markers as Open Timecode-Related Notes files. The format is a JSON structure for exchanging comments, annotations, markers, subtitles or messages that are tied to a point in time, so notes can move between applications.

A file can carry an optional metadata object describing its origin, a sequence object with a list of time-stamped notes, and an optional list of files for attaching notes to clips outside the sequence range. Editors and reviewers who share notes across tools get a standard way to do it from Premiere Pro.

Key features

  • Import and export sequence markers as .OTRN
  • Standardized JSON structure in three sections
  • Optional metadata describing file origin
  • Notes array with time-stamped entries
  • Optional file-level notes outside the sequence
