Captioning tool for DaVinci Resolve with Whisper-based speech-to-text and animated caption presets.

What mamoworld Caption Cat does

Caption Cat lets editors create subtitles and stylish captions without leaving DaVinci Resolve. Speech-to-text is performed locally using OpenAI's Whisper models, so footage is never uploaded to outside services.

It supports 112 languages with the Whisper small and large models. A library of animated caption presets is offered in landscape and in vertical and square formats, and these behave as regular Resolve items that can be adjusted afterwards. Social media creators, interview editors and anyone producing accessible video can go from raw audio to styled captions inside one program.

Key features

  • Local Whisper speech-to-text
  • 112 supported languages
  • Animated presets for landscape, vertical and square
  • Fully integrated in Resolve
