Blender cleanup add-on that locates objects using five criteria and clears them through a trash bin with restore.

What Smart Mesh Cleaner Pro does

Smart Mesh Cleaner Pro finds unwanted objects in a Blender scene using five tests, namely naming prefix, object volume, polygon count, distance to the origin and empty geometry. It is made for cleaning imported or messy files.

Three action modes keep you safe: Select Only for previewing, Move to Trash for reversible removal and Delete for permanent removal. A trash bin with restore lets you reverse mistakes, so large cleanups feel less risky.

Key features

  • Five filters including volume and polygon count
  • Select Only, Move to Trash and Delete modes
  • Trash bin with restore
  • Finds empty geometry and distant objects
