What Breakdowner does

Breakdowner is an animator's onion skinning add-on for Blender. It displays guides for key poses, displaying just the previous and next key rather than interpolated frames.

Ctrl-E starts a quick breakdown and an Alt-E pie menu offers options for displaying guides, which can be shown or hidden on the fly. Animators judging poses between keys get clearer references. Showing only the nearest keys keeps the viewport readable, so it is easier to judge how a breakdown pose relates to the poses on either side.

Key features

  • Breakdown guides for key poses
  • Ctrl-E quick breakdown
  • Alt-E pie menu options
  • Only nearest previous and next frames shown
