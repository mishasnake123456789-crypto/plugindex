Blender add-on that swaps between light and dark interface themes automatically at times you choose.

What Time Theme Switcher does

Time Theme Switcher, by CosmoMídias, changes Blender's interface theme on a schedule. A background timer applies your selected preset at the time you set, so the UI turns dark in the evening and light in the morning without any manual steps.

Activation times for light and dark are independent, with defaults of 07:00 and 19:00, and you can assign any XML interface preset, either one shipped with Blender or one you have made. It's convenient for those who work long hours.

Key features

  • Scheduled light and dark theme switching
  • Independent activation times, defaulting to 07:00 and 19:00
  • Any XML interface preset can be assigned
  • Runs from a background timer
