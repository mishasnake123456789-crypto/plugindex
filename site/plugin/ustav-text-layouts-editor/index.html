What Ustav - Text layouts editor does

Ustav is a text layout editor for After Effects by Kabansky. It lets you assemble documents-style screens from blocks instead of positioning separate text layers by hand.

Eight block types are supported: headers, paragraphs, numbered lists, bulleted lists, to-do lists, quotes, dividers and callouts. Blocks can be added, moved and removed, layout width adjusted and settings copied. Text controls cover size, leading, tracking, spacing and color, with dedicated settings for each block kind. A selection tool targets headers, paragraphs or all text layers, and selections can be updated or expressions removed.

Key features

  • Eight block types for structured text
  • Add, move and remove blocks
  • Layout width and copy settings
  • Size, leading, tracking, spacing and color
  • Selection tool for headers and paragraphs
