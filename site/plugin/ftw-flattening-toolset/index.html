What FTW Flattening Toolset does

This UV editing suite for Blender was created with footwear design in mind. It takes a model from unwrap to flat pattern while keeping the shapes measurable.

Tools include angle-based unwrap with a live toggle, pinning, flatten to center with edge preservation, minimize stretch and mirror pairs for symmetric unwrapping. The canvas is scaled in real-world centimeters, distortion can be checked, and UV boundaries can be exported as 2D curves, which suits pattern makers and other product designers.

Key features

  • Angle-based unwrap with live toggle and pinning
  • Flatten to center with edge preservation
  • Mirror pairs for symmetrical UVs
  • Canvas scaled to real centimeters
  • Distortion check and UV boundary export as 2D curves
