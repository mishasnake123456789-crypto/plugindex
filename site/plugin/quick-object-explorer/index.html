What Quick Object Explorer does

Quick Object Explorer is a Team Blender add-on that collects frequent object and mesh operations into one panel. You can pick any object by name and make it active, then act on it.

One-click tools duplicate objects, mirror them along the X-axis, subdivide meshes and apply Cast and Array modifiers. A Send to Floor command makes objects rest on the ground. It suits beginners and fast layout work where common steps should take a single click.

Key features

  • Select any object by name
  • One-click duplicate and X-axis mirror
  • Subdivide meshes
  • Apply Cast and Array modifiers
  • Send to Floor
