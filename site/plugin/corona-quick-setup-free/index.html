What Corona Quick Setup (free) does

Corona Quick Setup trims the default Render Setup dialog in 3ds Max down to the settings most people actually touch when using Corona. Ordinary users can prepare a scene faster without hunting through the full set of rollouts.

Preserve options for Displacement, Light, Glass and Other Materials are placed in a separate floater that opens with the minus button, and the lock aspect ratio state is remembered when the script closes. The author developed and tested it with Corona 6 and 3ds Max 2019 upward, and it costs nothing. It suits artists who want a lean control panel for everyday rendering.

Key features

  • Simplified panel of commonly used Corona parameters
  • Condensed alternative to the Render Setup dialog
  • Preserve options in a separate floater
  • Lock aspect ratio state saved on close
  • Built and tested on Corona 6 with 3ds Max 2019 or newer
