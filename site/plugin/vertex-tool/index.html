What Vertex Tool does

Vertex Tool is a Rendertom script that rounds corners on masks and shape layers with a click. It adds new vertices at the selected corner based on a chosen line length, and offers 12 algorithms for the curve.

You can target a single vertex or all vertices on several selected shapes together, set the amount in pixels or percent, and animate from the original state to the modified one. Rounding can be removed using the Find intersection point option. Live vertex coordinates, including in and out tangents with custom editing, are shown, and shape data can be stored and restored.

Key features

  • 12 corner rounding algorithms
  • Single vertex or all vertices of many shapes
  • Pixels or percent values
  • Animate from initial to modified shape
  • Store and restore shape data
