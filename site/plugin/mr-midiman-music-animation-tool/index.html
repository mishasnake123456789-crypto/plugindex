What Mr. Midiman: Music Animation Tool does

Mr. Miniman's Mr. MIDIman translates MIDI data into exact keyframes in Blender, replacing manual timing with animation that tracks your audio. Data is organized in Channels.

Instead of the usual attack, hold, decay and base/peak settings, you can draw your own curve for each note. An Accumulator builds up values over time for smooth, growing effects, and Timeline Markers flag every note event as a reference. Music visualizers and motion designers can lock visuals to a track.

Key features

  • MIDI to keyframe conversion
  • Channels organize animation data
  • Custom curves per MIDI note
  • Accumulator for cumulative effects
  • Timeline markers at note events
