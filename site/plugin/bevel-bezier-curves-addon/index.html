What Bevel Bezier Curves Addon does

The Bevel Bezier Curves Addon rounds corners on Bezier curves. Select points on a curve and it applies a bevel with controllable radius and profile shape.

Multiple points can be beveled in a single operation, and handles remain smooth afterward. This helps with logos, vector-style shapes and curve-based modeling where Blender's own curve tools lack corner rounding. The feature set spans adjustable bevel radius, profile shape control and bevels multiple points at once.

Key features

  • Adjustable bevel radius
  • Profile shape control
  • Bevels multiple points at once
  • Keeps smooth handles
