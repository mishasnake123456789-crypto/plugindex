What Frame.io V4 Comments does

Frame.io V4 Comments links Premiere Pro to Frame.io for review. Editors can export a sequence, upload it, send review links to clients and read replies without leaving the timeline.

Clicking a comment jumps to its timestamp, and comment markers can be toggled on the timeline. A new version can be uploaded with one click, several sequences can be queued through Send to Media Encoder, and the three-dot menu offers Create New Version, Create New File and Link Manually.

Key features

  • Export and upload sequences to Frame.io
  • Send review links to clients
  • Click a comment to jump to its timestamp
  • One-click new version upload
  • Queue multiple sequences via Media Encoder
