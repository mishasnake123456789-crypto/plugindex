What PCamSolver does

PCamSolver is a Blender plugin for situations where full camera solving is not possible because there are too few tracks. It turns tracker motion from a clip into practical camera or object animation, working with one, two, three or many tracks depending on the shot.

An optional depth reference object provides spatial context. Z-Depth mode converts changes in scale into travel along the camera's depth direction, while Focal Length mode converts them into focal length animation instead. This gives compositors and VFX artists a fast option for simple shots.

Key features

  • Works with one to many clip tracks
  • Optional depth reference object
  • Z-Depth mode for scale to camera movement
  • Focal Length mode for zoom-style shots
