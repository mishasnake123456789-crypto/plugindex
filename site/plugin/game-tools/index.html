Blender add-on that bakes animation and other data into textures, plus signed distance fields and a flexible data baker.

What Game Tools does

Game Tools by Cremuss collects techniques from the video game industry in one Blender add-on. Animation can be baked into textures per vertex, per object or per bone, and object attributes can be baked into textures, a feature previously known as Pivot Painter 2.0.

It also bakes signed distance fields and includes a Data Baker that writes various kinds of data into UVs, vertex colors or normals using advanced bit-packing. About 150 pages of documentation and theory come with it, including a Technical Art Compendium. Game artists and technical animators can prepare real-time-friendly effects such as crowds, foliage and destruction.

Key features

  • Vertex, Object and Bone Animation Textures
  • Object Attributes Textures (Pivot Painter 2.0)
  • Signed Distance Field baking
  • Data Baker for UVs, vertex colors and normals
  • 150 pages of documentation
