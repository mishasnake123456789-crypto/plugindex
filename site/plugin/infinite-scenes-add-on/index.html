What Infinite Scenes Add-On does

Infinite Scenes Add-On turns a compact scene into a large one in Blender by repeating it through instancing. It targets cities, terrains and procedural landscapes.

Setup is one click from the N-Panel. Instancing grows the scene without extra memory use or a slower viewport. Rotation can snap to 90 degrees or run free, scale can vary per axis or uniformly, and height has random and inverse sliders. Grids switch between custom spacing and perfect squares. It is MIT licensed and works with Cycles and Eevee.

Key features

  • Instanced scene expansion in one click
  • Random rotation and scale variation
  • Height controls and grid options
  • No memory or viewport penalty
