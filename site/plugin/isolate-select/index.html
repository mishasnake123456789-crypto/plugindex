A Blender add-on that adds Maya and 3ds Max style isolate select without altering stored display states.

What Isolate Select does

Isolate Select brings the familiar isolate command from Maya and 3ds Max to Blender. It temporarily shows only the objects you want to work on, without changing the display state saved on the data, so nothing needs to be reset afterwards.

Local view isolation can be repeated any number of times, and isolation levels can be moved up and down with undo of the separated state and an option to return to global view. Display options keep lights, image empties and collections visible, allowing work in Render View on Eevee with an unchanged appearance. Artists who switch between DCC tools will feel at home.

Key features

  • Repeatable local view isolation
  • Isolation level up and down with undo
  • Display Lights keeps lighting visible
  • Keeps image empties and collections shown
