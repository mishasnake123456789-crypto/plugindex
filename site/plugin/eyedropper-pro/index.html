What Eyedropper Pro does

Eyedropper Pro picks colors from any place on your screen: browsers, reference images, other software and second monitors. A full-screen preview with a live swatch appears; Ctrl + Shift + P starts it, left click confirms and right click or ESC cancels.

It also includes a viewport color picker, a history of recent picks, automatic HEX copying and clipboard image pasting into the 3D Viewport. You get screen-wide color sampling, full-screen preview with live swatch and pick history and HEX copy, along with the rest of the feature set.

Key features

  • Screen-wide color sampling
  • Full-screen preview with live swatch
  • Pick history and HEX copy
  • Clipboard image paste
