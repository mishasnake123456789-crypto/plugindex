Geometry Nodes decal system for Blender that projects non-destructive mesh decals onto curved surfaces with libraries.

What [BAM] Decalit does

[BAM] Decalit is a decal system built on Geometry Nodes that conforms mesh decals to curved surfaces. Because it is non-destructive, decals can be edited and adjusted after placement.

You hover a surface in the viewport to position, move, scale and rotate each decal, with advanced snapping to the surface. Decals are stored in reusable libraries with preview thumbnails. Hard-surface artists can add panel lines, labels and details quickly and keep the base model clean.

Key features

  • Non-destructive Geometry Nodes decals
  • Projection onto curved surfaces
  • Viewport placement by hovering
  • Advanced surface snapping
  • Reusable libraries with thumbnails
