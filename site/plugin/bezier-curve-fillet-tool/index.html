What Bezier Curve Fillet Tool does

Bezier Curve Fillet Tool turns pointed bezier corners into smooth ones. A modal operator shows the result live as you change the radius and the handle ratio.

Press Ctrl+F to set the radius quickly, then keep Ctrl held and move the mouse to change the handle ratio according to distance. Designers shaping logos, outlines and paths get rounded corners without calculating handle lengths.

Key features

  • Live modal fillet preview
  • Ctrl+F for quick radius
  • Ctrl and mouse movement adjusts handle ratio
  • Converts sharp bezier corners to rounded
