What MarkerMover does

MarkerMover is a marker-management toolset for After Effects by Rob Barrett. Anyone who leans on markers for timing, cues or notes knows how fiddly it is to shift them by hand, and this panel gathers the common operations in one place.

Markers can be nudged by a set amount in frames or seconds, copied, cut, pasted at the current time and deleted, with options for split markers and protected regions. Work area settings can be stored and reapplied, and a marker trigger expression can be attached to keyframed properties so animation fires from marker positions. Memory Banks hold marker sets for later use, and KBar icons plus an import file are supplied.

Key features

  • Move markers by a set value in frames or seconds
  • Copy, cut, paste and delete comp or layer markers
  • Marker-triggered animation expression for properties
  • Save and apply work area settings
  • Memory Banks and KBar support
