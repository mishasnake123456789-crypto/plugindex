What Trimotion-Animation Optimizer does

Null Station's Trimotion-Animation Optimizer cleans dense motion capture so the result behaves like hand-keyed animation. Five algorithms are offered: RDP (Smart) takes out roughly 50 to 70 percent, Key Pose 70 to 90, with Decimate, Adaptive and Blender Clean as alternatives.

Smooth Curves removes jitter and noise. A Frame Rate Converter handles 24, 30, 60 and 120 fps clips, a Frame Range Limiter simplifies just a section, and Batch Processing treats several rigs together. Animators tidying captured data get lighter curves.

Key features

  • Five simplification algorithms
  • 50 to 90 percent keyframe reduction
  • Smooth Curves removes jitter
  • Frame rate converter and range limiter
  • Batch processing of multiple rigs
