What Octane Light Studio does

Octane Light Studio is a lighting manager for Blender users rendering with Octane. Lights are created, sorted into layers and positioned by clicking directly on scene surfaces, then fine-tuned from a sidebar in the viewport.

Each layer has a master intensity slider and an on/off switch. Six placement tools cover moving, aiming, lifting, sliding, rim and front lighting. Real-world slider values control rotation, height, distance and size, while eight preset buttons jump to common angles. Orbit modes, viewport labels and saved lighting setups round it out, and it works with the free Octane version.

Key features

  • Layered light groups with master intensity
  • Six click-to-place light tools
  • Sliders showing absolute values
  • Angle presets and orbit modes
  • Saved lighting setups for reuse
