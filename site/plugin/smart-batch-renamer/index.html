What Smart Batch Renamer does

Smart Batch Renamer is a sidebar add-on for tidying names across a scene. Select items, choose an operation, preview before and after, then apply with a click.

Find and Replace supports plain text or full regex with a case toggle, prefix and suffix operations add or remove text at either end, and Clean Names strips .001, .002 style suffixes. It works on objects, meshes, materials and collections. The preview step means mistakes show up before names are changed, which matters on large scenes.

Key features

  • Find & Replace with regex
  • Prefix and suffix operations
  • Clean Names strips .001 suffixes
  • Before/after preview
  • Objects, meshes, materials and collections
