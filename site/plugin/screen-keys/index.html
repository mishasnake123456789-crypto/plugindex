What Screen Keys does

Screen Keys is a Blender add-on from Egret Studios that draws your keyboard and mouse input directly over the viewport as you work. Viewers of a recording or live stream can see exactly which shortcuts and clicks produce each result.

Place the overlay in any corner of the screen, then tune key size, opacity, fade-out time and colors for text, background and highlights. You can limit how many keys remain visible at once and switch the display on or off from a sidebar panel. It suits tutorial authors, trainers and anyone reviewing a workflow.

Key features

  • Shows key presses, Shift/Ctrl/Alt combos and mouse clicks
  • Tracks mouse position and scroll wheel use
  • Four screen corners to place the overlay
  • Adjustable size, opacity, fade timing and colors
  • On/off toggle in a sidebar panel
