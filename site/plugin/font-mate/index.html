Font Mate

Developer: Jishnu Jithu

FreeBlender
Download Free

A Blender add-on that previews, filters and applies fonts to text objects from a pop-up in the viewport.

What Font Mate does

Font Mate gathers system and user fonts in one place inside the Blender viewport. Rather than browsing file dialogs to change a text object's typeface, you open a pop-up with a configurable Ctrl+F hotkey, or a Font button in the header when a text object is selected.

Source toggles switch between all fonts, system fonts, user fonts and a custom directory for project or downloaded files, and a keyword box filters the list as you type. Selected fonts are previewed and applied to the chosen text objects. Motion designers and titlers who experiment with typography will find it faster.

Key features

  • Pop-up opened by Ctrl+F or a header button
  • All, System, User and custom folder sources
  • Live keyword filtering
  • Preview and apply fonts to selected text
