What BirdDog Connect Post Production does

BirdDog Connect Post Production is a panel that lets directors, producers and clients watch an edit as it happens. The timeline output travels through BirdDog's secure cloud at full quality and low latency, with timecode and audio embedded so everyone is frame-accurately in sync.

Sessions begin and end inside Premiere Pro. The editor chooses whether remote viewers see the Program view, Timeline view or an Edit Suite camera, and can combine them or switch between sources. Viewers join through BirdDog Connect apps on web, macOS, Windows or other devices, so no exporting or uploading is required before feedback.

Key features

  • Start and stop live review sessions in Premiere Pro
  • Low-latency full-quality timeline streaming
  • Timecode and audio embedded automatically
  • Program, Timeline and Edit Suite Cam views
  • Join from web or native apps
