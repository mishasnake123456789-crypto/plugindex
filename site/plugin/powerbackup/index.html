Blender add-on that backs up and restores Blender and add-on preferences as JSON files inside an archive, with selective restore.

What Powerbackup does

PowerBackup saves your Blender and add-on preferences so you can recover your setup after a reinstall or on another machine.

Chosen preferences are stored as JSON files inside an archive, and restoring lets you pick items in a few clicks. It enables an add-on automatically when you load that add-on's preferences. Users with elaborate configurations avoid rebuilding settings. It is useful when reinstalling Blender, moving to a new computer or sharing a studio configuration, since settings do not need to be rebuilt manually.

Key features

  • Backs up preferences into an archive
  • Selective restore
  • Enables add-ons when loading their preferences
  • JSON-based storage
