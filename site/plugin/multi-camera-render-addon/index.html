What Multi Camera Render Addon does

Multi Camera Render Addon lets you render more than one camera without queuing each manually. It integrates with Blender's Output Properties tab and helps with product shots, multi-angle animations and VFX deliveries.

Render all cameras or only those in a chosen collection, set a custom prefix and folder so files and subfolders are named per camera, and render the full range or the current frame. ESC cancels, an on-screen overlay shows progress, and it is compatible with the Per Camera Resolution add-on.

Key features

  • Render all cameras or a chosen collection
  • Custom prefix and per-camera folders
  • Full range or current frame, cancelable
  • On-screen progress overlay
