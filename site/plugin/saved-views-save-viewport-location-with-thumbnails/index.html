What Saved Views - Save Viewport Location With Thumbnails does

Saved Views is a Blender add-on by Amandeep that remembers where the viewport sits and how it is rotated, so any view can be brought back. A thumbnail is captured automatically for each saved view, and you pick views from the N-Panel by thumbnail or by name.

Each entry also keeps its local view state, letting you go back into local view from a stored view. A camera list allows fast switching between camera views, and a search function helps find entries in long lists. It helps when moving between detailed areas of a large scene.

Key features

  • Saves viewport location and rotation
  • Automatic thumbnail for every view
  • Select by thumbnail or name
  • Remembers local view state
  • Camera list for quick camera switching
