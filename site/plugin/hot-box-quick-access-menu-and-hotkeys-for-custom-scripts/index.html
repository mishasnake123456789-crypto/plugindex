What Hot Box - Quick Access Menu And Hotkeys For Custom Scripts does

Hot Box turns your Python scripts and macros into one-key tools or a popup menu in Blender. You don't need to write add-on code to use them.

The popup can be called from any workspace. Folders, names, menu visibility and tool layout are customizable, and each script can be edited in the Blender script editor. Layouts, hotkeys and tools can be exported and imported as JSON files to back up or share. Scripts run through exec.

Key features

  • Hotkey management for scripts and macros
  • Popup menu available in any workspace
  • Customizable folders, names and layout
  • Edit scripts in the script editor
  • Export and import JSON layouts
