What R2Murugan does

R2Murugan moves tabular data in and out of Blender. CSV files can be imported and used to drive animations or build visualizations, and project data can be exported back to CSV for other programs.

The updated version has a spreadsheet interface and a live editor for bone and animation data. It carries an MIT license and includes documentation. Useful for data visualization, charts and rigs where animation values are easier to edit in table form.

Key features

  • CSV import for animation and visualization
  • CSV export of project data
  • Spreadsheet-style interface
  • Live bone and animation data editor
