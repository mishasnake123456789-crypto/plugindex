What Pcm_Clean - Advanced Point Cloud Cleaning & Optimization does

PCM_Clean prepares scanned point clouds for use in Blender. It is aimed at architects, surveyors and LiDAR specialists who receive noisy, oversized datasets and need them lighter and tidier before modeling or BIM work.

Statistical filtering strips stray noise from raw scans, clustering methods separate structures, and voxel simplification lowers density while holding on to the original geometry. These steps can be chained into a multi-stage cleaning pipeline. For importing the clouds in the first place, it is designed to work alongside PCM_Core. Documentation is included.

Key features

  • Statistical noise removal
  • Clustering to isolate structures
  • Voxel density reduction
  • Multi-step cleaning pipeline
  • Pairs with PCM_Core for import
