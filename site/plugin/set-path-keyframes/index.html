After Effects script for adding, removing and revealing path keyframes on shape layers with shortcuts.

What Set Path Keyframes does

Set Path Keyframes, from Mograph Mindset, speeds up shape path animation in After Effects. Select shape layers and a shortcut places path keyframes at the current time, saving a trip to the timeline to stopwatch each path.

If every path already has a keyframe at that time, running it again removes them. Pressing U reveals every modified property, while SS shows just the selected keyframes. Since version 1.1, the new keyframes are selected automatically after being added, making follow-up edits easier.

Key features

  • Adds path keyframes at the current time
  • Removes them when all paths already have keys
  • U reveals modified properties
  • SS shows only selected keyframes
  • Auto-selects new keyframes (v1.1)
