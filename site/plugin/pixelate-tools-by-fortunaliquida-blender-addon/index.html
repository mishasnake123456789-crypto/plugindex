What Pixelate Tools By Fortunaliquida (Blender Addon) does

Pixelate Tools applies shader-based pixelation to your camera in Blender. It suits PS1 and N64 style visuals, low-res dioramas, old-school cutscenes and stylized previews.

A slider changes pixel size live, from a soft 480p feel to chunky 32-bit. Apply Pixelate builds the nodes through the compositor in one click without destroying anything, and Clean Pixelate restores the original look. It works with Eevee, Cycles and Workbench, from a native sidebar panel, and arrives as a single zip.

Key features

  • Live pixel size slider
  • One-click apply and clean
  • Non-destructive compositor setup
