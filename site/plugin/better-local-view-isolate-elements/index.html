Extends Blender's Local View to isolate faces, vertices and edges in Edit Mode, like Maya's Isolate.

What Better Local View - Isolate Elements does

Better Local View expands the standard Local View so it also works on mesh components. In Edit Mode, the same button isolates selected faces, vertices or edges instead of only whole objects.

Behavior is modelled on Maya's Isolate Object, and it works on objects as well as elements. It is distributed as a Blender extension with documentation. Modelers working inside dense meshes can hide distractions with a single key. Leaving isolation restores the full view just as easily.

Key features

  • Isolates faces, vertices and edges
  • One button for objects and elements
  • Modelled on Maya's Isolate Object
  • Blender extension
