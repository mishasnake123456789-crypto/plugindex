Blender add-on with a Predator View that shows poly counts and colors objects by weight to spot heavy meshes.

What Poly Hunter does

Poly Hunter helps find over-detailed meshes in Blender. Toggle Predator View from the JunoTools N panel to display polygon counts in the viewport.

A full list of counts is shown, and objects are tinted with familiar weight colors so the high-poly ones stand out for optimization. It works with Blender 4.0 through 4.5 and includes documentation. Useful for game artists keeping scenes within budget. The overlay makes optimization passes faster because you do not have to inspect each object's statistics one by one.

Key features

  • Predator View toggle in the N panel
  • Poly counts displayed in the viewport
  • Weight-style color coding
  • Highlights high-poly meshes
  • Blender 4.0 to 4.5
