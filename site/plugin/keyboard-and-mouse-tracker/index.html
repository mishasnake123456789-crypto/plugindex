What Keyboard and mouse tracker does

Keyboard and mouse tracker is a Blender plugin that lets Geometry Nodes respond to the user in real time. Mouse motion and key presses are routed into node trees, so what you do while the scene runs can change the geometry.

It uses event-driven logic, which opens the door to interactive systems, prototypes and game-like mechanics that stay inside Blender's node editor. Hobbyists and technical artists exploring interactivity can experiment without writing separate scripts.

Key features

  • Real-time mouse input in Geometry Nodes
  • Keyboard input in Geometry Nodes
  • Event-driven node logic
  • Suited to prototypes and game-like mechanics
