What Atomic Blender PDB/XYZ does

Atomic Blender PDB/XYZ brings atomic structure files into Blender, taking the position of every atom from .pdb and .xyz files and displaying each as a ball in the scene.

Molecules, crystals, clusters, particles and surfaces can be loaded. Sticks appear when listed explicitly in a PDB file, and the structures are built with Blender's instancing method for efficiency. Scientists, teachers and visualization artists can create images and animations of molecules and materials.

Key features

  • Imports PDB and XYZ files
  • Atoms shown as balls
  • Sticks from PDB files
  • Efficient instancing
