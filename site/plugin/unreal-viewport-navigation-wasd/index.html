What Unreal Viewport Navigation - WASD does

Unreal Viewport Navigation - WASD brings engine-style flying to Blender's 3D viewport. Hold the right mouse button to look around, and a quick click still opens the usual context menu, with an adjustable threshold for how long counts as a hold.

Move with WASD, the arrow keys or both, plus Q and E for vertical motion. Level artists and game developers used to Unreal can navigate scenes without changing habits.

Key features

  • RMB hold to look, short click for context menu
  • Adjustable hold duration
  • WASD and arrow key movement
  • Q/E vertical movement
