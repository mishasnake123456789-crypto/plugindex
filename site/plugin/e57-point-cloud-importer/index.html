Blender extension that imports .e57 scan files as native PointCloud objects with color, normals and material handling.

What E57 Point Cloud Importer does

E57 Point Cloud Importer, by Quentin Misslin, converts laser scan files directly into Blender's own PointCloud geometry instead of heavy meshes. RGB colors are extracted and mapped to the points automatically.

Surface normals are extracted as well, with a toggle for using them in a shader, and material handling is set up on import. Surveyors, architects and visual effects artists working with scanned environments can load their data without conversion tools.

Key features

  • E57 to native PointCloud geometry
  • RGB colors pulled from the scan automatically
  • Surface normal extraction with shader toggle
  • Material setup on import
