What Color Creator does

Color Creator generates matching color schemes from a single starting color, helping you pick palettes without leaving Blender. It produces monochromatic, complementary and triad harmonies.

A random color generator tries out different styles, and with an RGB node selected you can add a harmonious ColorRamp from the W or right-click menu, with no dedicated panel needed. Documentation and unlimited updates are included.

Key features

  • Monochromatic, complementary and triad schemes
  • Random color generator
  • Adds ColorRamps from the node context menu
  • No separate panel needed
