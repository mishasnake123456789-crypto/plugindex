What Node Color Tools Pie does

Node Color Tools Pie manages node colors in Blender using pie menus. It applies color to several selected nodes at once, helping node trees stay readable.

A Quick Color pie offers preset colors, random assignment, removal, and copying of the active node's color. A Precise Color pie lets you define and store five custom colors. Shader and geometry node artists who label graphs by color can organize them quickly. Consistent node colors make shared files easier to read, since teammates can tell input, utility and output sections apart at a glance.

Key features

  • Quick Color pie with presets
  • Random color assignment
  • Copy the active node's color
  • Five saved custom colors
  • Colors many nodes at once
