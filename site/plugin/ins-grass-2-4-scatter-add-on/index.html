What Ins Grass 2.4 Scatter Add-On does

Ins Grass is a scattering plugin which spreads lifelike grass and plant assets across surfaces. It is built with game-ready content in mind.

Colorizing options create color variation from a single asset, linked to density and scale patterns, and the link can be inverted or broken. Camera-based culling and a level-of-detail scheme keep scenes manageable by swapping to lighter versions of assets. Good for large environments. Together these features let artists fill large areas with believable ground cover while keeping memory use and viewport speed under control.

Key features

  • Color variations tied to density and scale
  • Camera culling system
  • Level-of-detail system
  • Realistic grass and plant assets
