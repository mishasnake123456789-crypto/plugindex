Blender add-on that fixes backwards right-to-left text in one click for Arabic, Hebrew, Persian and similar scripts.

What Blender Rtl Text does

Writing in Arabic or Hebrew inside Blender normally yields reversed letters. GilaDDD's Blender RTL Text corrects the direction with a click, covering Arabic, Hebrew, Pashto, Persian, Urdu and Sindhi.

It works with fonts for right-to-left and Middle Eastern scripts, is listed for Blender 2.8 through 2.93, and comes with documentation under the GPL. Video makers and title designers producing content in these languages can type naturally without outside tools. Posters, subtitles and logos in these languages no longer need to be flipped in other software first.

Key features

  • One-click right-to-left correction
  • Arabic, Hebrew, Pashto, Persian, Urdu, Sindhi
  • Handles Middle Eastern fonts
  • Blender 2.8 to 2.93
  • Documentation included
