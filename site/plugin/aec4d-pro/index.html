What AEC4D PRO does

AEC4D PRO by Lasse Lauch is a bridge between Cinema 4D and After Effects. It exports scene data from Cinema 4D into an After Effects composition so layers line up with your 3D camera, and it can bring textures, stills and renderings the other way.

Transferred data includes stage objects, text layers, camera film offset and composition markers. Existing layers in the active composition can be overwritten, or only the current frame can be exported. The interface was redesigned and exports run much faster than before.

Key features

  • Exports cameras with film offset
  • Handles stage objects and text layers
  • Exports composition markers
  • Imports textures, stills and renderings
  • Overwrite layers, or export just one frame
