What Shots Shuffler does

Shots Shuffler is a Blender add-on from Unkredible Studios that suggests camera views for you. It creates a batch of randomized static shots, which is useful when you are blocking a scene or hunting for composition ideas.

You set ranges for movement on the X, Y and Z axes, or have them calculated from a selected object's dimensions. Shot settings cover the number of frames, zoom from close-up to wide, and a tilt range for random Z rotation. It works even in empty scenes under development, so layout and cinematography exploration can start early.

Key features

  • Randomized static camera positions
  • Adjustable X, Y and Z movement ranges
  • Auto range from a selected object's size
  • Zoom range from close-up to distant
  • Random tilt via Z-axis rotation range
