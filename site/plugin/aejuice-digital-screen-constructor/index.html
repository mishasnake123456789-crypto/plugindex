What AEJuice Digital Screen Constructor does

AEJuice Digital Screen Constructor helps you display web-style information within footage. Elements include web pages, headlines, searches, tweets, buttons and photos, rendered realistically for news-style presentations.

It was built entirely in After Effects and auto-resizes to any resolution. Colours, text, camera and screen effect intensity are editable, and the screen effect can be switched off. The Pack Manager provides quick previews, drop-in import and favourites, and output suits Instagram, YouTube, Facebook and Snapchat. After Effects and Premiere Pro editors making news items, ads and tutorials can mock up screens quickly.

Key features

  • Web pages, headlines, searches, tweets, buttons, photos
  • Editable colours, text, camera and effect intensity
  • Screen effect can be disabled
  • Auto-resize to any resolution
  • Pack Manager with preview and favourites
