What Majik Blender Edu does

Majik Blender Edu helps teachers verify that submitted Blender work is genuinely a student's own. It records Blender-specific actions and stores them in logs that are encrypted and tamper-evident, readable only with the teacher's key.

Logged activity covers mesh edits, modifier use, imports and scene statistics, gathered through Blender's native Python API, and the records are chained in a blockchain-like way to expose alterations. Instructors of 3D courses gain a view into how an assignment was produced.

Key features

  • Logs mesh edits, modifiers, imports and scene stats
  • Encrypted logs decryptable only by a teacher's key
  • Blockchain-style integrity chain
  • Built on Blender's native Python API
