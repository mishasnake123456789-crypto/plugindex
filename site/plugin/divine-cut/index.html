What Divine Cut does

Divine Cut by Xane Studios helps build clothing for characters in Blender. It starts from simple cloth shapes and moves them toward more complex garments using a set of styling tools.

DivineCircles shape each section of a generated cloth, and sliders cover neck, sleeves, hem drop and trouser widths. Divine Presets turn a generated cloth into a finished garment ready for simulation, such as a puffer jacket, varsity jacket or shirt, with collar, hoodie, material and open or closed options. Painting tools support shrinkwrap work. Character artists save tailoring time.

Key features

  • Cloth generation with DivineCircles
  • Presets for puffer, varsity jackets and shirts
  • Neck, sleeve, drop and trouser controls
  • Painting tools for shrinkwrap
