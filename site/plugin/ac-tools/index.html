Blender add-on for building Assetto Corsa tracks: AC objects, start positions, physical materials and FBX export.

What AC Tools does

PhinDev's AC Tools helps build Assetto Corsa tracks in Blender, taking care of AC-Objects, start and timing positions, physical materials, project folder layout and FBX export with track-specific settings.

AC-Objects are created and placed with the right axis, numbering and naming, plus a default mesh. Start positions support left or right alignment with an adjustable offset for grid lineups, with left and right timing positions. Physical AC-materials such as road, kerb, grass, sand, pit, wall and out can be assigned, and custom materials managed.

Key features

  • AC-Objects placed with proper naming
  • Start and timing position builder
  • Physical AC-materials like road, kerb and grass
  • Project folder setup
  • FBX export with track parameters
