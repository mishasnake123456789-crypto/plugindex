What LetsMotion Subtitle Pro does

LetsMotion Subtitle Pro is a subtitle plugin for After Effects and Premiere Pro. You can bring in SRT files or type text directly, then translate selected sentences inside the panel, including into Chinese and other East Asian languages.

Export supports popular formats with UTF-8, UTF-8 with BOM, ANSI and UTF-16 encodings. A table view offers autosave, quick search and row shifting. In After Effects only, subtitles can sync with markers and use different subtitle templates. Editors and motion designers can build and translate captions in one place.

Key features

  • Import SRT or type subtitles
  • In-panel translation including East Asian languages
  • Export with UTF-8, UTF-8 BOM, ANSI and UTF-16
  • Table view with autosave, search and row shifting
  • Marker sync and templates in After Effects
