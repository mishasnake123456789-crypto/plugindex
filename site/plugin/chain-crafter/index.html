Blender add-on that builds procedural chains with posable, animatable control handles.

What Chain Crafter does

Chain Crafter generates chains in Blender that can be posed and animated without leaving object mode. Control handles attached to each chain handle positioning and tilting.

A chain can be drawn, stretched between two objects, or converted from a curve. Keyframes can be set or removed for all controls at once, a default pose is saved in the file, and appearance is adjusted through modifier parameters. Extract Mesh makes mesh copies without changing the originals. More than 75 assets are bundled in the Asset Browser: 50 links and 25+ clasps.

Key features

  • Chains from drawing, two objects or a curve
  • Control handles for posing and animation
  • Extract Mesh for static copies
  • 75+ links and clasps in the Asset Browser
