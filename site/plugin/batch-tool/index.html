What Batch Tool does

Batch Tool applies the same Python fix or modification to a whole set of .blend files. Instead of opening each one, you point the add-on at your script and a folder, and it processes everything automatically.

An optional setting includes files in subdirectories, and a Run button starts the job. Documentation is included. Pipeline technical directors and studio artists who need to update old libraries, rename data or change settings across hundreds of files will find it saves hours.

Key features

  • Applies a custom Python script to many files
  • Panel for script path and folder
  • Optional subfolder inclusion
  • One-click Run button
