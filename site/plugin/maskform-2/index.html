What Maskform 2 does

Maskform 2, by Hassaan Ahmad, brings numeric transformation to masks in After Effects, where you would otherwise drag handles by eye. You enter exact values instead.

Controls cover anchor point, position and rotation in precise degrees, independent X and Y scale, and skew with a skew axis for perspective effects. Transformations can be toggled to preview the mask with or without them, baked to apply permanently, or removed with one click. This release has a complete interface redesign.

Key features

  • Numerical anchor, position and rotation
  • Independent X and Y scale
  • Skew and Skew Axis controls
  • Toggle, bake or remove transformations
  • Redesigned UI
