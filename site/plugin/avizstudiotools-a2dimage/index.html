What AvizStudioTools - A2Dimage does

A2Dimage, from the AvizStudioTools set, is a scripted plug-in for 3ds Max that places flat images carrying transparency, such as cut-out people or plants, in architectural renders. The image height is read from the end of its file name.

At render time it generates shadows from the alpha channel automatically, so previews and final images come out with correct shadows in one pass and nothing has to be composited afterwards. It needs 3ds Max 7 or later, and the Pro version can be tried free for 15 days. It suits visualization artists who want quick entourage without building geometry.

Key features

  • Places 2D images with alpha into 3ds Max scenes
  • Reads image height from the file name
  • Automatic shadows from the alpha channel
  • Correct shadows in one render pass, no compositing
  • Works with 3ds Max 7 or later
