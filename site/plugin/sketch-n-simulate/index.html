What Sketch N' Simulate does

Sketch N' Simulate prepares physics simulations with a single click for Rigid Body, Soft Body and Cloth. It can optionally separate all loose parts of an object before assigning physics, then gives each part correct mass.

The simulation environment is set up automatically, and an optional ground surface is created below the simulated objects. It saves the repetitive setup for demolition, falling objects and fabric tests. Notable points: rigid, soft body and cloth setup, loose-part separation and mass assignment.

Key features

  • Rigid, soft body and cloth setup
  • Loose-part separation
  • Mass assignment
  • Automatic ground plane
