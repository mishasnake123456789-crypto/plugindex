Blender UV add-on with a Cut UV seam tool, auto unwrap, seam layers and per-material packing.

What Uv Flow does

UV Flow adds a streamlined seam and unwrap workflow to Blender. Its Cut UV tool lives in the toolbar, highlights candidates before you click, and marks edges, loops or shortest paths as seams, or lets you draw seam paths.

Auto Unwrap only re-unwraps UVs affected by a new seam, leaving straightened or projected work intact. Unlike Blender's Mark Seam, the tool respects Edit Mode symmetry, and it adds straightening that reacts to context, seam layers and packing per material. UV artists marking many seams save considerable time.

Key features

  • Cut UV toolbar tool with preview highlight
  • Auto Unwrap limited to affected UVs
  • Works with Edit Mode symmetry
  • Seam layers and per-material packing
