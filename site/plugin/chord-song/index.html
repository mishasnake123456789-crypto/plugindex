Blender add-on that adds a Vim-style leader key system for triggering operators and scripts through key sequences.

What Chord Song does

Chord Song brings the leader key idea from Vim editors into Blender, inspired by the Neovim plugin which-key.nvim. Press the leader and follow with a sequence of keys to run an operator, execute a script or change a property.

A single tap starts a chord, a double tap shows recent ones and a triple tap repeats the last. You can right-click any interface element to add a mapping immediately, and context awareness keeps the available chords relevant to the current editor. Keyboard-centric users can build compact shortcuts.

Key features

  • Leader key chord system
  • Tap patterns for recents and repeat
  • Add mappings by right-clicking interface elements
  • Context-aware key sequences
  • Runs operators, scripts and property changes
