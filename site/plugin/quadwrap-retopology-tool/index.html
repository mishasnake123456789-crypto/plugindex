What Quadwrap - Retopology Tool does

Quadwrap focuses on retopologizing tubular forms like arms, fingers, legs and horns in Blender. A click-and-drag workflow creates quads and wraps them around the underlying mesh.

Edge loops are easy to control, end caps fill instantly and loops bridge automatically. A simplified interface shows a dynamic hotkey help panel, and symmetry, bisect and loop relax are supported. Character modelers cleaning up sculpts for animation will benefit. Compared with placing every vertex manually, this approach keeps loops even along limbs and tubular parts of a character.

Key features

  • Click-and-drag quad wrapping
  • Instant end cap filling
  • Automatic edge loop bridging
  • Symmetry, bisect and loop relax
  • Dynamic hotkey help panel
