What Khaos Fire Shader: Straightforward Fire Shading (Free 2024 Update!) does

The KHAOS Fire Shader, from LIGHTARCHITECT, is a fire shader for Blender volumes. Originally the stock domain material of the KHAOS explosion add-on, it now ships separately and revolves around two adjustable nodes.

Controls cover smoke color, density and contrast, along with flame color, brightness, contrast and color ramp values. Custom input nodes can be attached for alternative results. A single install button imports the material, which then appears in a dedicated tab of Blender's right tool panel, and documentation is included.

Key features

  • Two adjustable shader nodes
  • Smoke color, density and contrast controls
  • Flame color, brightness, contrast and ramp controls
  • Optional custom input node connections
  • One-click material import
