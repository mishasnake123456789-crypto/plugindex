What Anim Curve Sorter does

Anim Curve Sorter is a Blender add-on by Duncan-Readle for keeping animation curves organized. Groups can be sorted by name or following the rig hierarchy, and the resulting order can be copied from one action to several others.

Curves that belong to no group can be placed under their bone name, and object-level custom properties are grouped together. The add-on is a 17 KB Python script, needs no special permissions and supports Blender 4.4 and newer. Animators dealing with cluttered Graph Editor lists will find it helpful.

Key features

  • Orders curve groups by name or rig structure
  • Copies group order between actions
  • Groups orphaned curves under bone names
  • Groups object-level custom properties
  • Supports Blender 4.4 and newer
