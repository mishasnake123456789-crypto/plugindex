What Armscale Fixer does

Armscale Fixer solves a familiar problem: applying scale to an armature usually wrecks its animations. This add-on applies the scale and keeps the animation intact.

The Fix Armature Scale button lives in the Properties panel under Armature, and Ctrl + A also reaches it, matching the usual apply-scale shortcut. It repairs all animations at once when an armature carries many actions. It requires Blender 3.5.0 or newer. Useful for riggers fixing imported or scaled characters.

Key features

  • Apply armature scale safely
  • Button under Armature properties
  • Ctrl + A shortcut
  • Fixes all actions at once
