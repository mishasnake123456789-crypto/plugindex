What Autodesk 3D Studio (.3ds) does

Autodesk 3D Studio (.3ds) lets Blender exchange files in the classic .3ds format. Maintained by NRGSille, it reads and writes meshes, materials, textures, cameras, lights, ambient and atmosphere settings, and animation.

Each ambient block becomes a world node setup on import, and ambient animation keyframes come into the timeline. Background images and fog are read into the world nodes, and the exporter uses a specific node per chunk. Artists dealing with older assets or legacy pipelines can move them in and out of Blender.

Key features

  • Two-way .3ds scene transfer
  • Ambient chunks become world nodes
  • Background and fog import
  • Cameras, lights and animation support
