What Unreal PSK/PSA (.psk/.psa) does

Unreal PSK/PSA moves meshes and animations between Blender and the formats used in many versions of Unreal Engine. Both import and export are fully supported for PSK and PSA.

Non-standard .pskx data such as vertex normals, extra UV channels, vertex colors, shape keys and scale keys can be imported. Large PSA files can be imported sequence by sequence, with batch import by drag and drop, and sequence metadata like frame rate is preserved for reuse on export. Collection exporters keep outputs reliable. Game artists working with Unreal assets benefit.

Key features

  • PSK and PSA import and export
  • Support for .pskx extra data on import
  • Selective PSA sequence import
  • Preserves frame rate metadata
  • Collection exporter workflow
