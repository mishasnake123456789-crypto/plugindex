What Hextractor does

Hextractor is a color-extraction script from YB Motion for After Effects. When a client sends brand colors in an email or style guide, retyping each hex value is slow, and this script collects them all at once from pasted text.

Palettes can also be built from selected layers or images, saved as schemes and switched quickly between clients or projects, and shared with a team. Guide layers can include every extracted color, even near-white and near-black tones, and color mosaics can be generated from them.

Key features

  • Paste text to grab all hex codes
  • Build palettes from layers or images
  • Save, switch and share color schemes
  • Guide layers with all extracted colors
  • Color mosaic generation
