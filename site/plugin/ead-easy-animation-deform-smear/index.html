What Ead Easy Animation Deform (Smear) does

Ead Easy Animation Deform places a grid in the camera view so you can bend and stretch objects by animating its control points. It is built for smear deformation, the stylized trick that smooths out very fast movements in animation.

You decide which objects the grid influences, adding or removing them as needed, and further grids can be created for more specific deformations. Because the deformation is set up in camera view, it behaves like a 2D-style effect. Documentation is included, and animators working on stylized or cartoon motion will find it a quick route to smears.

Key features

  • Adds a deformation grid in camera view
  • Animate control points to deform objects
  • Add or remove objects from a grid's influence
  • Multiple grids for targeted deformation
  • 2D-style result for smear frames
