What Blueprint Importer & Cropper Tool does

The Blueprint Importer & Cropper Tool prepares reference images for blueprint-based modeling of vehicles, architecture and mechanical subjects. It pairs a Blender add-on with a separate cropping app.

The add-on detects and places images from their filename suffixes and aligns them in the 3D View using empties, with orientation set for all major views. The standalone cropper trims image borders with precise mouse-guided lines, resizes its window to the image, scrolls with the mouse wheel, and has a manual mode.

Key features

  • Auto-detects views from filename suffixes
  • Aligns images with empties in all main views
  • Standalone interactive cropper
  • Manual cropping mode
