What Blend Append does

Blend Append lets you look inside any .blend file from the N-panel and append only what you need. A Scene Collection-aware browser moves from a list of collections to a list of objects, with live solid-mode previews.

Appending respects hierarchies, and objects targeted by modifiers such as Boolean or Shrinkwrap come along with their hosts, with control over modifiers. It is quicker than the built-in append dialog for pulling parts from asset files.

Key features

  • Collection and object browser
  • Live solid-mode previews
  • Hierarchy-aware append
  • Modifier target objects included
