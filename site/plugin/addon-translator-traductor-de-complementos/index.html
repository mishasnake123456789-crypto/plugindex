What Addon Translator - Traductor De Complementos - 애드온 번역기 - 插件翻译器 does

Addon Translator lets Blender users read add-on interfaces in their own language. It translates installed add-ons and extensions from within Blender, which helps when the original text is only in English or another unfamiliar language.

You can translate everything at once or choose specific add-ons, and the change is non-destructive, so reverting is a single click with functionality unaffected. Several engines are available: Deep Translate (online, Google-powered), MarianMT (offline, open-source AI) and MyMemory (online). Any add-on's text can also be exported to a file for use with other translation services.

Key features

  • Translates add-ons into 40 languages
  • Translate all at once or per add-on
  • Non-destructive with one-click restore
  • Online and offline translation engines
  • Export add-on text to a file
