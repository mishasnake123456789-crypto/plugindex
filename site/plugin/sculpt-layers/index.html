What Sculpt Layers does

Sculpt Layers lets sculptors keep a base mesh and add detail as individual layers in Blender. It comes from Yey!, the creator of MiraTools.

Layers can be added, removed, joined and erased, and each has an opacity value and can be duplicated. It works with the Multires modifier, supports shape keys and offers subdivide and unsubdivide. Layers can also be imported from ZBrush. Sculptors get non-destructive control over detail passes.

Key features

  • Base mesh with separate detail layers
  • Add, remove, join and erase layers
  • Per-layer opacity
  • Multires, shape key and ZBrush layer import
