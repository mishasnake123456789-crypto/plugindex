What LoopMaster does

From NirinA comes LoopMaster, a script for After Effects aimed at animations that repeat without a visible seam. It targets formats that loop, including GIFs, NFTs, Lottie animations and social media posts.

It loops keyframes, items, wiggle, spin and orbit. The keyframe and path loop and the LoopItem tool both offer a PingPong option, and LoopItem can handle media whose start or end is cut by automatically precomposing it. The time reference for a loop can be set to the composition, a layer or markers, and a button adds markers for that purpose.

Key features

  • Seamless loops for keyframes, wiggle, spin and orbit
  • PingPong option
  • LoopItem handles cut media with auto precomp
  • Composition, layer or marker time reference
