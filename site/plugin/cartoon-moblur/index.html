What Cartoon Moblur does

Cartoon Moblur from Plugin Everything gives animated graphics a stylish trailing smear in After Effects. It works like ordinary motion blur but produces a cartoonier result.

Shutter angle sets the length, color can be a solid fill or gradient ramp, and Opacity Samples controls quality. It handles all transformations including 3D, parented animation and bezier path animation, and an alternate motion source parameter lets you apply it to an adjustment layer so every layer beneath is affected.

Key features

  • Shutter angle for blur length
  • Solid or gradient ramp color
  • Opacity Samples for quality
  • Works with 3D, parenting and bezier paths
  • Alternate motion source for adjustment layers
