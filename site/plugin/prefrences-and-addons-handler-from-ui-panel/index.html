What Prefrences And Addons Handler From Ui Panel does

This Blender add-on puts commonly needed preference controls into a panel in the 3D view, so you do not have to open the Preferences window each time. It is meant for users who often change their setup while working.

From the panel you can import add-ons and switch them on or off, edit themes, and reach a few viewport settings. Interface preferences can be saved and loaded, which lets you flip between different configurations quickly. A demo video and documentation are included.

Key features

  • Import and toggle add-ons from the 3D view
  • Edit themes inside the panel
  • Access selected viewport settings
  • Save and load interface preference sets
