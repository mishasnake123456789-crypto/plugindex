Color Helper

Developer: atticuslv

FreeBlender

Blender add-on for building, extracting, editing and exporting color palettes, with shader node and Pantone tools.

What Color Helper does

Color Helper manages palettes inside Blender. You can create, copy, reorder and group them in collections, pull colors from clipboard images or palette PNGs, and paste hex or RGB values with gamma correction.

Generators build random palettes and harmony schemes such as complementary and triadic, with hue, saturation and value offsets. Shader node groups outputting each color and a ColorRamp can be inserted into materials, colors can be matched to the nearest Pantone, converted to Blender paint palettes, and exported as PNG.

Key features

  • Palette collections with full management
  • Extract colors from images and text
  • Harmony schemes and random palette generation
  • Shader node groups with ColorRamp output
  • Pantone matching and PNG export
