What Pixelocybe does

Pixelocybe, developed by Satori, blends mosaic blocks with displacement in a single filter for After Effects and Premiere Pro. It uses a flexible two-input pipeline, so one layer can steer how another is chopped up.

Processing can follow luma, RGB or one of the Red, Green, Blue or Alpha channels. Mosaic Width and Height set maximum block size, Curve Phase and Curve Floor shape the distortion, and Horizontal and Vertical Offset move the point where intensity is sampled. Transparency Below and Above knock out pixels beyond chosen luminosity limits, with phase and smoothing to ease the transitions. Glitch-minded motion designers get plenty to explore.

Key features

  • Luma, RGB or single-channel processing
  • Mosaic width and height limits
  • Curve phase and floor controls
  • Horizontal and vertical sampling offsets
  • Luminosity-based transparency with smoothing
