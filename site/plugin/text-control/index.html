Creates and animates text in Blender with a single-letter system, layers, font management and a dedicated animation toolset.

What Text Control does

Text Control is a text add-on built on handling every letter individually, which allows detailed styling and animation. Work is non-destructive and organized in layers so words and groups stay manageable.

A built-in bar loads all system fonts in one click, styling controls adjust the look, and a dedicated animation system brings letters to life. Motion designers creating titles and kinetic typography can get further than with Blender's default text tools.

Key features

  • Single-letter text system
  • Layer-based, non-destructive workflow
  • One-click loading of system fonts
  • Styling controls
  • Dedicated text animation system
