What Bevelled Extrude does

Bevelled Extrude, by Mark Kingsnorth, produces extrusions in Blender that include a bevel without extra manual steps. It is well suited to smooth recesses and protrusions.

Bevel can be configured on the base, corners and tops. Edge Weight Mode alters edge bevel weights so the Bevel Modifier can use them, which makes the operation less destructive. An interactive mode allows pushing extrusions in or out. Hard-surface modelers can create panels and cutouts faster.

Key features

  • Bevel on base, corners and tops
  • Edge Weight Mode for Bevel Modifier use
  • Interactive in or out extrusion
  • Smooth recesses and protrusions
