Tools for Blender Bezier curves: real-time mirroring, handle alignment and point merging.

What Curve Beautifier does

Curve Beautifier addresses typical annoyances when modeling with Bezier curves. It mirrors in real time without a mirror modifier, so you need not convert the curve into a mesh first.

Points can be merged with an intermediate point acting as the merge location, handles can align to axes or specific angles like 45 and 135 degrees, and equidistant adjustments and view locking are included. Logo designers and curve-based modelers get cleaner shapes.

Key features

  • Real-time mirroring without a modifier
  • Merge points
  • Handle alignment to axes or angles
  • View locking
