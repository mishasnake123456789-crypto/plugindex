What Flip Animation does

Flip Animation, by aeHamid, groups three tools for transforming Position keyframes. Flip Animation mirrors motion, Scale Animation changes its size, and Create Animation generates new movement. Each has three modes.

Options include fixed and mirror faces, an amount control for scaling, and after or before choices when creating. It is useful for reversing a path or producing the opposite version of an existing move. It supports After Effects 2021 through 2023.

Key features

  • Flip Animation with three modes
  • Scale Animation with amount control
  • Create Animation with after and before options
  • Works on Position keyframes
  • Supports After Effects 2021 to 2023
