What Motion Manager does

Motion Manager is a Cinema 4D plugin by Kengo Ito for shaping animation curves without fiddling in the curve editor. Copy and Paste Easing lets you grab selected keyframes, edit them and apply them to other curves, whether a single easing or a long run of keys.

Bounce and elastic animations are generated from three parameters and can drive deformer intensity. Frequently used curves, including ease, bounce and elastic settings, can be named and stored in a preset library for one-click recall, and motion can be previewed before it is applied. Animators and motion designers gain a faster way to keep timing consistent.

Key features

  • Copy and paste easing between curves
  • Bounce and elastic from three parameters
  • Preset library for named curves
  • Preview motion before applying
  • Works with deformer intensity
