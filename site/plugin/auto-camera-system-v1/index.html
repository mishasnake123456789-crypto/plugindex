What Auto Camera System V1+ does

NENGHUO Studio's Auto Camera System V1+ animates cameras in Blender using geometry nodes, with no keyframes involved. It has path curve movement in Point to Point and Linear modes, plus a generator for making paths.

Noise movement imitates things like handheld shake, Free Cam Movement records your motion onto a curve, and auto-focus keeps subjects sharp. Eight demo tutorial videos and documentation are included. Motion designers get complex camera moves from a setup that is easy to adjust.

Key features

  • Point to Point and Linear path movement
  • Path curve generator
  • Noise movement for hand shake
  • Free Cam Movement recording
  • Auto-focus
