Blender add-on that builds drivers automatically by detecting which axis changed between two positions and recording min and max values.

What Easy Driver does

Easy Driver cuts the manual work of setting up drivers in Blender. Shift a bone or object from one position to another and it works out the axis that changed most, recording the min and max range.

It supports armature bone transforms and object sources, then maps the driver values automatically. Riggers building corrective shape key drivers, controls and automated mechanisms can set them up in fewer steps. Setting limits by demonstration is more intuitive than typing expressions and remapping ranges by hand.

Key features

  • Automatic axis detection
  • Records min and max transform range
  • Bone and object sources
  • Automatic driver mapping
