What SlabText does

SlabText is a script from Froggy Team that makes each line of a paragraph the same width, a classic typographic look. It works in After Effects, Illustrator and Photoshop.

Several alignment modes are available, with an adjustable threshold deciding when to use scale versus tracking, plus adjustable leading and automatic coloring. The original formatting is preserved. Start SlabText and Clear SlabText commands apply and undo the layout, with an option to also clear the transformation. Designers can use it for posters, titles and quote graphics.

Key features

  • Equalizes line width across paragraphs
  • Several alignment modes
  • Adjustable scale versus tracking threshold
  • Leading control and automatic coloring
  • Preserves original formatting
