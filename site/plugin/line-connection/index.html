Cinema 4D tool that draws connection lines between objects with control handles and ripple effects for infographics.

What Line Connection does

Line Connection creates lines linking selected objects in Cinema 4D, useful for infographics and animated maps. Each line carries a control handle, and every point automatically generates a ripple object.

Objects can be connected in the order selected or separately. Controls cover thickness, density and dashed or solid lines, along with ripple segment count and style and timing. Bezier mode adds line curvature. Motion designers making route maps and network graphics get animated connections quickly.

Key features

  • Connect objects in order or separately
  • Control handle on each line
  • Ripple objects at points
  • Thickness, density, dashed or solid lines
  • Bezier curvature
