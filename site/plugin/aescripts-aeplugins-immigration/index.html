What aescripts + aeplugins Immigration does

Immigration from aescripts + aeplugins streamlines importing files, sequences and deeply nested hierarchies into After Effects. Sequences appear as single line items while browsing, rather than as long lists of frames.

A custom scanning algorithm is reported to open a 30,000-file server folder in twelve seconds, including sequence detection. You can import or batch replace many items at once, set one frame rate for all, and use Auto-Match Replace, which previews matches color-coded by closeness. Folder hierarchy is preserved in the project, with filters for extension, file age and folder names.

Key features

  • File sequences shown as single items

  • Batch import and replace of multiple items
