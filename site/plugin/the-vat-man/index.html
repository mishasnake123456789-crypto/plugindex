Bakes animation, simulation and particles into Vertex Animation Textures playable in Cycles via a material.

What The Vat Man does

The Vat Man converts motion into Vertex Animation Textures so it can be replayed using nothing more than a material. This works in Cycles, which makes heavy animation lighter to handle in a scene.

Baked motion can go onto a new object or morph an existing one; several VAT objects can be merged and animations managed with smooth loops. Per-animation material settings, a UV map combiner and a texture atlas creator are included, and rigged characters can be baked too. Good for crowds and repeated simulated elements.

Key features

  • VAT baking and playback in Cycles
  • Bake to new object or morph an existing one
  • Merge multiple VAT objects
  • Tools to combine UV maps and build texture atlases
  • Looping animation management
