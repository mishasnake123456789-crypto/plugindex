Blender add-on that makes all selected linked duplicates single users in one click.

What Multiple Single Users does

Multiple Single Users unlinks data on many objects at once. Select the linked duplicates you want to separate and a single click gives each its own data.

It can handle selections of hundreds or thousands of objects that share linked data. Documentation is included, and the add-on is distributed under a Creative Commons license.

Key features

  • Unlinks data on all selected objects
  • Handles hundreds or thousands of duplicates
  • One-click operation
  • Creative Commons license
