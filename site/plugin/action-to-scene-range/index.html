Blender add-on that sets the scene frame range automatically when you switch Actions.

What Action to Scene Range does

Action to Scene Range, by dr.sybren, updates the scene's frame range to match whichever Action you switch to, so you do not need to adjust the timeline by hand. It is listed under Animation.

Open source under GPL-3.0-or-later, it requires Blender 4.2.0 or newer.

Key features

  • Sets the scene frame range from the Action
  • Works when switching Actions
  • Open source, GPL-3.0-or-later
  • Requires Blender 4.2.0 or newer
