Blender add-on that captures a dragged screen region in dark and mockup themes for pasting into Penpot.

What Mockup Screenshoter does

Mockup Screenshoter helps interface designers present Blender UI work. From the Window menu, run the Mockup Screenshot operator and drag a rectangle over the region to capture.

It produces two screenshots, one using the Blender Dark theme and one using a Mockup theme, and combines both into a group so the result can be pasted into Penpot ready to use. Add-on authors and documentation writers can produce clean UI illustrations quickly.

Key features

  • Mockup Screenshot operator under Window
  • Drag a rectangle to capture
  • Two captures in dark and mockup themes
  • Grouped result for Penpot
