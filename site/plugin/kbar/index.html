Customizable button toolbars for After Effects that launch scripts, effects, shell scripts and extensions.

What KBar does

KBar lets After Effects users build their own toolbars of buttons. Each button can apply an effect, run a script file, execute a shell script or call an extension with custom arguments, putting favourite tools within a single click.

Up to four toolbars can be reached through keyboard modifiers, and up to four toolbar windows can be open at once. Toolbars are shareable, with bulk button import and export, and buttons can be reordered by dragging or cloned with shift-drag. A bar can snap to the left or right edge for a vertical layout, text buttons hold 16 characters, and spacer buttons help arrange them.

Key features

  • Buttons for effects, scripts, shell scripts and extensions
  • Four toolbars via keyboard modifiers
  • Shareable toolbars with bulk import and export
  • Drag to reorder, shift-drag to clone
  • Vertical mode snapped to either edge
