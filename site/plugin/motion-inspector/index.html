What Motion inspector does

Motion inspector is a Blender add-on from Chalouek-RGBit for examining how curves and objects move. Instead of judging an animation by eye, you can observe changes in speed and acceleration directly.

An acceleration vector indicates how strongly something is pushed, and a countergravity vector reveals how far a character, plane or motorbike is leaning. Minimizing that vector helps you build correct freefall acceleration. Parented objects have been supported since version 0.2.9. Animators can use it to verify that motion feels physically believable.

Key features

  • Inspect speed and acceleration of curves and objects
  • Acceleration vector shows movement force
  • Countergravity vector shows tilt
  • Helps build correct freefall
  • Supports parented objects
