Renames source files to match their Premiere Pro clip names and relinks them, plus move and copy tools.

What Game Changer does

Game Changer makes file names on disk agree with the names used in the project. ClipName to FileName renames a material's file to its Premiere clip name and relinks the new path automatically.

Move and Copy transfer or duplicate files between folders, working on clips selected in the Project panel or the Timeline. Version 2.0.0 added Sync Folder, Release Bin and Collection. That keeps your disk organization consistent with your project, which helps with archiving and handoff.

Key features

  • ClipName to FileName with auto relink
  • Move files between folders
  • Copy files
  • Works from Project panel or Timeline
  • Sync Folder, Release Bin and Collection in 2.0.0
