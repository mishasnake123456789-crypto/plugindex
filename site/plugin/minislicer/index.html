What MiniSlicer does

MiniSlicer turns Blender into a simple slicer for resin 3D printing. It cuts a model into layers and writes files in .phz and .ctb formats, which Phrozen printers read.

Makers who design miniatures or parts in Blender can go straight to print files without opening a separate slicing program. It suits a compact workflow where modeling and print preparation happen in the same place.

Key features

  • Slices models into layers
  • Exports .phz files
  • Exports .ctb files
  • Targets Phrozen resin printers
