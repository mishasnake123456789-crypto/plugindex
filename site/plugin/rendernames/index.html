What RenderNames does

RenderNames is a Blender plugin that replaces the plain output path field with a template system. You compose names using variables such as scene, camera, date, resolution, engine and sample count, and see the resulting path update as you type.

It can also arrange renders in folders per scene, camera or date. Ready-made presets named Simple, Professional, Archival, By Camera and Minimal give quick starting points, and you can create your own. The tool is aimed at artists who produce many renders and want consistent, searchable file organization.

Key features

  • Template variables for scene, camera, date and more
  • Live preview of the output path
  • Automatic folders by scene, camera or date
  • Built-in and custom presets
