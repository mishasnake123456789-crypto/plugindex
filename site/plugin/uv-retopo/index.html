What Uv Retopo does

UV Retopo lets you construct quad topology on a flat surface and then project, snap and stitch it onto a 3D high-poly target using math instead of manual vertex pushing.

A live mode uses a rewritten projection algorithm so dense meshes can be edited without frame drops. Holes such as pockets and buttonholes are detected automatically, creating perimeters and Coons patches around them. A one-click Prepare Highpoly step finds borders, computes endpoints, creates 3D attachment curves and applies a UV checker material.

Key features

  • Quad layout on a 2D plane projected to 3D
  • Zero-lag live projection mode
  • Automatic hole detection with Coons patches
  • One-click Prepare Highpoly
  • Snap and stitch onto the target
