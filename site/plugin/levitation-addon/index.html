What Levitation Addon does

Levitation Addon applies a gentle floating effect to a selected Blender object, with a touch of random rotation for a natural look.

Levitation Height sets the maximum rise, Rotation Intensity controls the spin, Start and End Frame define the range, and a Seed value changes the randomness. Apply and Reset buttons create or remove the location and rotation keyframes automatically. It is a quick way to animate floating props, logos or magical items.

Key features

  • Adjustable levitation height
  • Rotation intensity control
  • Start and end frame settings
  • Seed for random rotation
  • Apply and Reset buttons
