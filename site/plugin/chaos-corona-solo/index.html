What Chaos Corona Solo does

Chaos Corona Solo is a rendering plugin for Cinema 4D that runs completely on the CPU. It offers both unbiased and biased rendering, and Chaos describes the setup as being as simple as pressing Render.

A CPU supporting the SSE 4.2 instruction set is required. An optional AI denoiser can run on an NVIDIA GPU with Maxwell or newer architecture and the latest driver. It is a good fit for artists who want realistic visuals, especially architectural scenes, from a simple interface without tuning many technical settings.

Key features

  • Entirely CPU-based rendering
  • Unbiased and biased modes
  • Optional NVIDIA GPU AI denoiser
  • Simple render setup
  • Needs SSE 4.2 CPU support
