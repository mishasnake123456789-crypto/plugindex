Blender add-on that non-destructively projects objects onto another surface using shrinkwrap or grid modes.

What Conform Object does

Conform Object places smaller objects onto the surface of a larger one in Blender. It uses the source object's position and orientation to project it in one direction without altering the geometry permanently.

A right-click menu entry performs the operation in one step, and you can choose between Grid Mode and Shrinkwrap Mode. The effect can fade from bottom to top, surface normals can be transferred to blend shading, and a deformation lattice stretches an object around the target. Several objects can be conformed together and settings saved as presets. Useful for decals, panels, rivets and clothing details.

Key features

  • One-step right-click conform
  • Grid and Shrinkwrap modes
  • Normal transfer to blend shading
  • Deformation lattice
  • Presets for saved settings
