What Vantage Submit Panel does

The Vantage Submit Panel links Premiere Pro to Telestream's Vantage, an enterprise transcoding and orchestration system that runs on Windows servers. Material being worked on in Premiere Pro can be sent to a chosen Vantage workflow for processing.

The panel talks to the Vantage API to submit clips and whole sequences straight from the editor. It is supported on Windows only and lists compatibility with Premiere Pro 26.0.0 and later. Facilities that already use Vantage for transcoding and delivery can avoid exporting files manually before processing.

Key features

  • Submits clips and sequences to Vantage
  • Targets a specific Vantage workflow
  • Uses the Vantage API
  • Windows only
  • Premiere Pro 26.0.0 and later
