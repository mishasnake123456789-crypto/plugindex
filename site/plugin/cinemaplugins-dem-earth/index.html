What CinemaPlugins DEM Earth does

CinemaPlugins DEM Earth builds terrain in Cinema 4D from real-world elevation data, which it downloads and caches automatically for the entire globe. Landscapes update in real time as you change the area.

A Smart OSM Object brings in and manages OpenStreetMap data, a PinPoint Object places any 3D object on the terrain with dynamic scaling and movement, and Route Object and Track Graph generate splines for paths. Geo-coding is included too. Visualization artists, map-based motion designers and anyone needing accurate geography can create it without outside GIS software.

Key features

  • Real-time landscape from worldwide DEM data
  • Smart OSM Object for OpenStreetMap data
  • PinPoint Object placement on terrain
  • Route Object and Track Graph
  • Geo-coding tools
