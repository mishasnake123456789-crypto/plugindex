Blender add-on that reshapes edge loops to any number of segments while keeping mesh attributes intact.

What Loop Resample does

Loop Resample by YLIANG changes how many segments an edge loop has without throwing away the attributes attached to the mesh. It is listed under Modeling and Mesh.

It is open source under GPL-3.0-or-later and needs Blender 4.2.0 or newer.

Key features

  • Reshapes edges to any segment count
  • Preserves mesh attributes
