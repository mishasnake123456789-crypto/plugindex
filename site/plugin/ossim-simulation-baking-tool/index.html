Blender add-on that bakes rigid body and cloth simulations into armatures and skinned geometry for game engines.

What Ossim - Simulation Baking Tool does

Ossim turns a Blender physics simulation into an armature with skinned geometry, making the result usable in realtime engines such as Unreal Engine, Godot and Unity.

It includes a faster, simplified procedure for rigid body generation, cloth simulation baking, transformation cleaning options and automatic keyframing. This lets destruction or cloth effects authored in Blender travel to a game as ordinary skeletal animation.

Key features

  • Generates armature and skinned geometry from simulation
  • Fast rigid body procedure
  • Cloth simulation baking
  • Transformation cleaning options
  • Output for Unreal, Godot and Unity
