What Nuke Style Color Grade Tool (Ca Grade) does

CA Grade brings the familiar Nuke Grade node to Blender. All controls sit in a single node in the Shader Editor, so grading no longer needs a chain of separate color nodes.

Blackpoint, whitepoint, lift, gain, multiply, offset and gamma are included, with independent control per R, G, B and A channel just as in Nuke. Control names follow Nuke's. Compositors and colorists who know Nuke can grade renders and textures with familiar behavior.

Key features

  • Blackpoint, whitepoint, lift, gain, multiply, offset, gamma
  • Per-channel RGBA control
  • Nuke-matching control names
  • Single node in the Shader Editor
