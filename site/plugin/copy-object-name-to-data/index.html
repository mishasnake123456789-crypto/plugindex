Blender add-on that copies an object's name to its data from the Outliner right-click menu.

What Copy Object Name to Data does

Copy Object Name to Data renames object data to match the object name. The operator is available in the Outliner's right-click context menu.

An inverted option, added in version 1.1.1, copies the data's name back onto the object. It supports Blender 4.2 LTS and newer and needs no special permissions. Pipeline-minded artists keeping outliner names consistent can fix naming mismatches quickly. Matching names makes outliner trees and exported files easier to navigate, especially after duplicating or importing many objects.

Key features

  • Copies object name to data
  • Outliner context menu access
  • Inverted option from 1.1.1
  • Supports Blender 4.2 LTS and newer
