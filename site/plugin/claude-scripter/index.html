What Claude Scripter does

Claude Scripter by S1lencio is a scripting helper inside After Effects. Describe what you want in ordinary language and it generates ExtendScript (JSX), runs it and lets you save the result.

It connects to a range of language models, with cloud providers Anthropic's Claude, Google's Gemini, OpenAI's GPT and xAI's Grok on the list, and also supports local models and offline use. Code can be edited by hand or with AI help, and AI edit diff highlighting marks changed lines before you accept them. A script library keeps generated code on hand. Artists with no scripting background can automate tasks quickly.

Key features

  • Generates, runs and saves ExtendScript from prompts
  • Multiple cloud LLM providers
  • Local model and offline support
  • AI edit diff highlighting
  • Script library
