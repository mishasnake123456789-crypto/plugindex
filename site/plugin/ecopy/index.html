What ECopy does

ECopy from EKDtools adds a copy and paste feature to the 3ds Max main menu, allowing objects to travel between separate scene files and even between computers on the same network. It is useful for teams passing assets back and forth.

Twenty slots are available, browsed by scrolling with the mouse. Each copy records a timestamp, the username of whoever made it and a large centered preview. The copy path can be set anywhere, including a network location. It also works with two 3ds Max instances open together, where making a copy in one shows its preview in the other, which eases collaborative work.

Key features

  • Adds copy and paste to the 3ds Max main menu
  • 20 slots navigated with the mouse
  • Works between files and networked computers
  • Timestamp, username and large preview for each copy
  • Configurable copy path including network locations
