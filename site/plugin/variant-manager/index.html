Turns Blender scene collections into switchable variants so one shows while the others hide automatically.

What Variant Manager does

Variant Manager from Techqon core lets you present alternatives, such as colorways or layouts, by treating collections as variants. Click a variant and it appears while all the others are hidden.

Collections following a Group_var_Name naming convention are detected automatically, and several can be combined into grouped variants or variant groups for different setups. Sections and variants can be renamed in the interface, and batch actions help manage many at once. It is helpful for product visualization and design presentations that need fast switching.

Key features

  • One-click variant switching
  • Automatic hiding of other variants
  • Auto-detection via Group_var_Name naming
  • Grouped variants and variant groups
  • Rename sections and variants in the UI
