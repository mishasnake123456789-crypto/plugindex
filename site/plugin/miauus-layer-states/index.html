What miauu's Layer States does

Layer States by miauu organizes layers into several saved configurations inside one 3ds Max scene, switched through a tab-based interface. Tabs can be added, renamed, deleted and rearranged.

A state remembers every layer with its properties and objects, viewport visibility included, and brings the scene back exactly as saved. Because states live in the MAX file, each team member can keep a personal layer arrangement inside one project. Tabs can have unique background and text colors, the active tab is highlighted, and the UI can dock into the Layer or Scene Explorer or float. States can also be saved as Scene States. Good for modeling, rendering and export tasks.

Key features

  • Multiple layer snapshots in tabs
  • Stores layer properties, objects and viewport visibility
  • Saved with the MAX file for team use
  • Custom tab colors and docking into the Explorer
  • Save layer states as Scene States
