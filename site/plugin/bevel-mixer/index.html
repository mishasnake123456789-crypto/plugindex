Blender add-on for creating and editing the attributes behind the Mesh Bevel node introduced in Blender 5.2.

What Bevel Mixer does

Bevel Mixer is built for the new Mesh Bevel node in Blender 5.2. That bevel system depends on mesh attributes, and this add-on lets you add and edit them quickly instead of setting them up by hand.

It recreates the behaviour of the classic Bevel modifier and extends it with secondary bevel and loop support, proportional bevel editing, affector flip and propagate attributes, edge bevel editing on a vertex, and a relax bevel option. It is meant for users who want a faster, more intuitive route to the new system.

Key features

  • Quickly add and edit attributes needed by the new bevel system
  • Recreates the classic Bevel modifier
  • Secondary bevel and loop support
  • Proportional bevel editing
  • Affector flip and propagate attributes
