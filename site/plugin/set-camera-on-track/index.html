A Blender add-on that creates camera paths around a model or across a series of objects automatically.

What Set Camera On Track does

Set Camera On Track generates camera movement in Blender without drawing paths by hand. Choose a camera, set a target object and an optional collection, and it makes a circular path for a 360-degree view or a linear path across the objects in a collection.

Objects are taken in the alphabetical order of their names. A comparison mode handles a target outside the collection, with focus set by relative position, for 3D data comparison videos, and a Smooth Levels field from one to ten smooths zigzag motion. Product showcase and presentation artists will get camera moves quickly.

Key features

  • Circular path around a target object
  • Linear path across a collection in name order
  • Comparison mode for data comparison videos
  • Smooth Levels from 1 to 10
