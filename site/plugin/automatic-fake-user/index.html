What Automatic Fake User does

Automatic Fake User protects your Blender data from being discarded. Whenever you save, it turns on the fake-user flag for actions, materials, geometry nodes, shader groups and worlds, so they survive even when nothing is currently using them.

Behavior is controlled from the add-on preferences. You can skip datablocks by exact name, prefix or suffix, and change the exclusion marker to a symbol such as "!" or "#". A manual mode turns off the on-save assignment and offers a button in the File menu instead. It supports Blender 3.6 up to 4.4.

Key features

  • Fake user applied on every save
  • Covers actions, materials, node groups and worlds
  • Exclude by name, prefix or suffix
  • Optional manual mode via File menu button
