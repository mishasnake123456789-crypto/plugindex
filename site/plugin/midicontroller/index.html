Blender add-on that maps MIDI controller inputs to object properties, geometry nodes, brush settings and the timeline.

What MidiController does

MidiController connects a hardware MIDI device to Blender so knobs and faders drive your scene. Location, rotation and scale can be mapped, as can geometry node inputs and brush settings.

Two mapping methods exist: Object Property Mapping for values shared across the selected objects, and Full Data Path Mapping to target a single property. Selection Groups switch sets of objects with a button, Fine and Coarse factors adjust sensitivity, buttons insert keyframes, and a control can scrub the current frame. It runs on Blender 4.2 LTS and newer on Windows, macOS and Linux.

Key features

  • Map MIDI inputs to object properties
  • Full Data Path mapping for nodes and brushes
  • Selection Groups switched by button
  • Fine and Coarse sensitivity factors
  • Keyframe insertion and timeline control
