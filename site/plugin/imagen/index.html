A free Adobe extension connecting Premiere Pro to Imagen-managed media libraries for search and download.

What Imagen does

Imagen links Premiere Pro to media libraries managed with Imagen. Editors search by text, narrow results by date, category or media type, and download selected files directly into the project clip bin.

Any media type Premiere can use is supported, and assets convert to high resolution when the edit is ready to export. It serves content owners and production teams reusing archive material. It suits teams that keep their archive in Imagen and want to reuse that material without extra steps.

Key features

  • Text search across Imagen libraries
  • Filters by date, category and media type
  • Downloads into the clip bin
  • High-resolution conversion at export
  • Free extension
