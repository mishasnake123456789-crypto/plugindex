What Mike Udin Flash Buffer Pro does

Mike Udin Flash Buffer Pro simplifies Object Buffer passes in Cinema 4D by letting you work with names rather than channel numbers. Passes are created from name tokens, and the plugin finds the first unused buffer and applies it to a new or existing Compositing tag.

Separate mode gives every selected object its own pass, whereas single group mode merges selected objects into one. Passes can also be assigned, deleted and selected by name, and rendered sequences can be renamed and sorted into folders. Compositors who break scenes into many mattes will find the bookkeeping much faster.

Key features

  • Create Object Buffer passes from name tokens
  • Finds the first unused buffer automatically
  • Separate and single group modes
  • Assign, delete and select passes by name
  • Rename and sort rendered sequences into folders
