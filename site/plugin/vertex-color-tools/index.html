What Vertex Color Tools does

Vertex Color Tools by IllusionBug collects the steps for producing vertex color in 3ds Max into one rollout. The rollout spans lighting and environment setup, picking geometry, radiosity rendering, and assigning and cleaning vertex color.

SkyLight adds a sample sky light and Ground a floor mesh, both for baking occlusion; GeomList picks all meshes of the Geometry class; and AO assigns the Default Material across the scene before starting an Advanced Radiosity render. Brightness controls the radiosity output. Assign and ClearV write and delete vertex color channel 0, VertBloat welds UV seams to avoid vertex bloat, and Clean removes the sky light, floor and collapses modifiers.

Key features

  • Sample Sky Light and ground mesh for AO setup
  • AO function starts an Advanced Radiosity render
  • Assign and ClearV write or delete vertex color channel 0
  • VertBloat welds UV seams to prevent vertex bloat
  • Clean removes helper lights, floor and collapses modifiers
