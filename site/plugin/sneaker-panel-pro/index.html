Supports footwear design in Blender with UV and surface pattern workflows, sketch projection and curve-based panels.

What Sneaker Panel Pro does

Sneaker Panel Pro was created by a footwear designer with more than 20 years of experience, and it targets shoe patterning from sketch to 3D model. It combines a 2D UV workflow with a direct 3D surface workflow, and you can switch between them.

Auto UV unwraps and orients base meshes in a click, and Reference Projection places 2D sketches or artwork over the 3D shell so you can scale and trace them. Curve-based tools build the panels. Footwear designers and product modelers are the intended audience.

Key features

  • UV (2D) and Surface Direct (3D) workflows
  • One-click Auto UV with orientation
  • Project sketches onto the 3D shell
  • Curve-based panel creation
  • Built by a footwear designer
