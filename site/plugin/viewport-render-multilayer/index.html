Blender add-on that renders every view layer as a fast viewport animation for compositing.

What Viewport Render Multilayer does

Viewport Render Multilayer renders all enabled view layers as viewport animations, giving a preview in minutes instead of hours. You add a view layer, set output options and run it from the View menu of the 3D Viewport.

It creates an output folder structure named after the layers, and the results can be combined in the Video Sequence Editor. Quality can be improved with Eevee's ambient occlusion, screen space reflections or motion blur, and overlays can be disabled to remove lines and empties.

Key features

  • Renders all view layers in one run
  • Auto-generated folders named by layer
  • Composite results in the VSE
  • Eevee AO, SSR and motion blur options
