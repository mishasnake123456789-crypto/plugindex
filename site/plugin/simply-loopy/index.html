What Simply Loopy does

Simply Loopy, by Memm, reduces the edge loops that build up through subdivision surface modeling in Blender. It collapses loops to simplify a mesh while keeping the important details intact.

Since version 1.2.0 you can also keep certain edges during simplification. It is in Edit Mode's Mesh menu, and can also be found by operator name search. It needs no special permissions and supports Blender 4.2 LTS and newer.

Key features

  • Simplifies meshes by edge loop collapse
  • Keeps important details
  • Option to keep chosen edges
  • In the Edit Mode Mesh menu
  • Blender 4.2 LTS and newer
