What rBMultiMat does

rBMultiMat gathers the varied materials used by selected objects in 3ds Max and combines them into one multimaterial. The result is sorted by name, much like the multimaterial created when attaching editable poly objects.

The default mode is non-destructive and puts an Edit_Poly or materialID modifier on the stack, chosen by the earlier material. Shift+click starts the fast mode, which converts nodes to editable poly, skips modify mode and collapses the stack. Install it by dragging it in, or simply run the script. Useful for tidying scenes with many materials or condensing an existing multimaterial.

Key features

  • Combines materials of selected objects into one multimaterial
  • Non-destructive mode with Edit_Poly or materialID modifier
  • Fast mode with Shift+Click that collapses the stack
  • Multimaterial sorted by name
  • Drag-and-drop or direct script run
