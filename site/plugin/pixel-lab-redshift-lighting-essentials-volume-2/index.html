What Pixel Lab Redshift Lighting Essentials Volume 2 does

This second Redshift lighting collection from Pixel Lab contains 18 studio scenes for Cinema 4D, each equipped with a full Xpresso rig for modifying lights and colors. It is delivered as a .lib4d file that opens in the Content Browser.

Named studios cover interiors, product shots, space, logo reveals and more. Buyers receive free updates for at least a year, with roughly one new studio setup added each month. Redshift 2.5 or above is required. Artists can pick a setup, tweak it with the rig, and move on to rendering.

Key features

  • 18 customizable studio lighting scenes
  • Full Xpresso rig in every scene
  • Delivered as .lib4d for the Content Browser
  • About one new studio per month for a year
  • Requires Redshift 2.5 or above
