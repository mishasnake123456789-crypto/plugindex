What Pixel Pusher does

Pixel Pusher is a script from KiwiVFX for moving layers in precise steps. After Effects arrow-key nudging is limited, and this tool lets you define the pixel distance used for each push.

Z position is supported, a multiplier scales the pixel values, and keyboard shortcuts can be set, with the current key value displayed. Keyframe support was added in version 1.2.0. If the project panel is empty, a dialog appears, and the script checks that the selected item is a composition. It runs on After Effects from CS5 through 2024.

Key features

  • Moves layers by a user-defined pixel amount
  • Z position support
  • Multiplier for pixel values
  • Settable keyboard shortcuts
  • Keyframe support
