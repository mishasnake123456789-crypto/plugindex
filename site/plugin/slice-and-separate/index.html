What Slice & Separate does

Slice & Separate cuts selected meshes along an axis, either at a set distance or into a number of slices, and turns each slice into its own object.

Axis detection aligns the cuts parallel to the object's longest side, a Grid Mode can be enabled in preferences, several objects can be sliced at once, and performance is improved on high triangle counts. Progress is displayed. It suits 3D printing, laser-cut layers and stylized effects.

Key features

  • Slice by distance or number
  • Each slice becomes an object
  • Automatic longest-side axis detection
  • Multi-object slicing
