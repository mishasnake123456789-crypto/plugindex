Transfers vertex group weights from a mesh to a Grease Pencil object so drawings follow mesh animation.

What Gp Transfer Weights does

GP Transfer Weights lets a Grease Pencil drawing follow an animated, rigged mesh. After painting over the mesh in its rest pose, one click transfers its vertex group weights to the drawing.

An Each Frame option evaluates the source weights at every keyframe and skins strokes accordingly, which supports separate drawings on different keyframes. Documentation is included. It is useful for 2D-over-3D animation hybrids. Among its capabilities are weight transfer mesh to Grease Pencil, one-click rig following and each Frame evaluation.

Key features

  • Weight transfer mesh to Grease Pencil
  • One-click rig following
  • Each Frame evaluation
  • Works with drawings on separate keyframes
