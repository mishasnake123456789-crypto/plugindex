Blender color add-on that adjusts saturation using a LAB-like algorithm so hue stays stable.

What Colorista does

Colorista changes saturation in Blender without the unwanted color shifts typical of simple saturation tools. It uses a LAB-like algorithm along with clamping to keep hue steady as saturation rises.

It requires Blender 4.2 LTS or newer and is released under the GPL v3 or later, installing by drag and drop. Artists polishing renders or grading images in the compositor get more predictable vibrance, particularly in strongly colored areas. Its approach is useful when a render looks flat and needs more color without turning skin tones or skies a different hue.

Key features

  • LAB-like saturation algorithm
  • Hue stays stable as saturation increases
  • Clamping mechanisms
  • For Blender 4.2 LTS and newer
