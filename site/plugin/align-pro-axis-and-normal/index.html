Blender add-on for aligning, orienting, scaling and evenly spacing objects by axis or normal.

What Align Pro: Axis And Normal does

Align Pro handles the placement jobs Blender leaves to repeated manual tweaking. Objects can be lined up to another object, the world origin, the 3D cursor or the floor, using minimum, maximum, center or pivot reference points.

In Active mode, the active object serves as the target for the rest of the selection, and orientation or scale can be matched to it too. Normal alignment moves and rotates one object so a chosen face point meets a point on another surface, with flip and offset controls and a gizmo display. An equal-spacing option distributes objects along X, Y and Z. Controls live in the 3D view sidebar.

Key features

  • Axis alignment with selectable reference points
  • Active-object target mode
  • Orientation and scale matching
  • Normal-based surface alignment with gizmo
  • Equal distribution along any axis
