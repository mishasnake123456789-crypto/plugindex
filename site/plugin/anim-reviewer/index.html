What Anim Reviewer does

Anim Reviewer improves Blender's playblast for reviewing animation. From the 3D Viewport N-panel, one click makes a preview video, using temporary settings that never alter the scene itself.

Codecs include H.264, H.265, MPEG-4 and AV1 with synchronized audio, and resolution, frame range and output location apply only to the playblast. Burn-in overlays in six positions can show scene details, timestamps and frame counts using chosen fonts, colors and margins. Presets and settings files can be shared with a team, and \N creates line breaks.

Key features

  • One-click preview video generation
  • H.264, H.265, MPEG-4 and AV1 with audio
  • Playblast-only resolution and frame range
  • Six-position burn-in metadata overlays
  • Presets and shareable settings files
