What Qol Tools: Link Widget does

QOL Tools: Link Widget stays on screen to help with linked data. It tells you if the active object is an instance and how many instances exist.

One click disconnects all instances, making them independent objects. Shift-click makes the selection instances of the active object, and Alt-click selects all connected instances. It removes menu hunting when managing duplicates. You get instance status indicator and count, click to make instances independent and shift-click to link to active object, along with the rest of the feature set.

Key features

  • Instance status indicator and count
  • Click to make instances independent
  • Shift-click to link to active object
  • Alt-click to select connected instances
