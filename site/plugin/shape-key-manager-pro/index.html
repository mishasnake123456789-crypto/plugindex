What Shape Key Manager Pro does

Shape Key Manager Pro speeds up shape key work in Blender. It duplicates and mirrors keys while keeping their drivers intact and pointing them at the right targets.

Keys can be duplicated by selection or filter, mirrored in one click, and given a selected vertex group. Shape keys transfer between objects with a single click, and copying and renaming is supported. Facial riggers handling dozens of expressions save considerable time. Keeping driver links intact while duplicating or mirroring is the main benefit, since this is the part that normally has to be repaired by hand afterward.

Key features

  • Duplicate keys by selection or filter
  • Mirror keys with drivers retargeted
  • Assign vertex group to duplicates
  • One-click transfer between objects
