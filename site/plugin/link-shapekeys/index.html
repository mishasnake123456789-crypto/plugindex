What Link Shapekeys does

Link Shapekeys from Levonotion Studios connects shape keys across multiple meshes using drivers. You then control all of them from a single mesh, which keeps facial or body parts in sync.

A separate option removes every driver from the selected meshes when you want to undo the setup. It is a Blender Extension compatible add-on, released under the GPL license, with documentation, and works with Blender 4.2 through 5.0. Character artists with split meshes for eyes, teeth and clothing will find it saves repetitive driver setup.

Key features

  • Links shape keys across meshes with drivers
  • Control everything from one mesh
  • Delete all drivers from selected meshes
  • Blender Extension compatible
  • Works with Blender 4.2 to 5.0
