What AutoCollapse does

AutoCollapse is a script for projects where switching on Collapse Transformations layer by layer would take forever. One click applies it everywhere it can, including inside nested precomps and on locked layers, which keeps vector art sharp and avoids pixelation.

Checkboxes decide which kinds of layers are touched: regular, precomp, nested or locked. You can also pick layers manually or lock ones to skip. A report afterwards lists updated, already collapsed and unsupported layers. The window can be minimized, and a help section offers tips and a tutorial video.

Key features

  • One-click Collapse Transformations
  • Includes nested precomps and locked layers
  • Checkboxes to choose affected layer types
  • Post-run report of changes
  • Minimizable interface with help window
