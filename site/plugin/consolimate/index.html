What Consolimate does

ConsoliMate, from MoovIT, packages sequences into self-contained projects ready to hand off or archive. Instead of copying whole files it extracts just the parts of the media that the edit uses and relinks everything in a new project structure.

Several sequences can be processed together, and the active one is detected automatically. WAV and AIFF audio is copied directly, while MXF, MOV, AVI, MP4 and MKV video is re-wrapped without re-encoding. Handle lengths can be customized, with five seconds as the default, and original timecode is preserved. Post teams delivering to colorists and sound studios will use it.

Key features

  • Multi-sequence processing with active sequence detection
  • Extracts only used portions of media
  • Re-wraps MXF, MOV, AVI, MP4 and MKV without re-encoding
  • Customizable handle lengths, default five seconds
  • Original timecode preserved
