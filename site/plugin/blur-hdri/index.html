Blender add-on that blurs HDRI images by creating a new node with a Gaussian blur.

What Blur HDRI does

Blur HDRI, by Jan-Hendrik-Müller, softens an environment map by generating a node that applies a Gaussian blur, which is useful for softer lighting or blurred backgrounds. It is listed under Material and Lighting.

It is open source under GPL-3.0-or-later and needs Blender 5.1.0 or newer.

Key features

  • Blurs HDRI images
  • Creates a Gaussian Blur node
  • Open source, GPL-3.0-or-later
  • Requires Blender 5.1.0 or newer
