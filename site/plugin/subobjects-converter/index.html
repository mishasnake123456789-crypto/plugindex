What Subobjects Converter does

Made for Expert mode, this MAXScript drives sub-object editing from the keyboard. It converts between sub-object levels with shortcuts and layers on extra actions triggered by Esc-key combinations.

Esc+1 switches Soft Selection on and off; at edge level, shortcuts set hard or smooth edges and cap holes, and Esc+4 at face level does the same around polygons. Pressing 5 jumps to the Element level while the Unwrap UVW editor is open, and the Smoothing Groups floater appears once every face is selected in Face or Element mode. To install, drop the .ms file onto the viewport.

Key features

  • Converts between sub-object levels by keyboard shortcut
  • Esc+1 toggles Soft Selection
  • Hard and smooth edge shortcuts plus hole capping
  • Element switching for Unwrap UVW
  • Smoothing Groups floater appears once every face is selected
