What Multi-Viewport Display does

Multi-Viewport Display saves you from changing display options object by object. Select a group of objects and the settings in the Object tab can be applied to all of them together.

Switch names, axes, wireframes, edges, texture space and shadows on or off, pick a display type like Bounds, Wireframe, Solid or Textured, and set viewport colors. It is useful in scenes with many objects where readability in the viewport matters.

Key features

  • Batch-edit Viewport Display settings
  • Toggle names, axes, wireframes, edges, shadows
  • Display modes: Bounds, Wireframe, Solid, Textured
  • Assign viewport colors
  • Operates on all selected objects
