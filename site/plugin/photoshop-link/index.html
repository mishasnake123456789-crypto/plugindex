What Photoshop Link does

Photoshop Link connects Blender with Photoshop. Send the Render Result or a chosen image straight to Photoshop for editing.

Edited images come back into Blender with automatic version control, either overriding the existing image or creating a new version. It removes manual saving and reloading when retouching renders and textures. You get send render or image to Photoshop, import edits back automatically and override or new version control, along with the rest of the feature set.

Key features

  • Send render or image to Photoshop
  • Import edits back automatically
  • Override or new version control
  • Choose which image to send
