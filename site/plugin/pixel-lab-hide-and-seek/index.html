What Pixel Lab Hide and Seek does

Pixel Lab Hide and Seek helps keep large Cinema 4D scenes manageable. When a project has hundreds of objects, it lets you search for a specific item or a whole group by name and find it fast.

You can isolate only the objects you are working on, hiding everything else, and build selection groups that can be recalled whenever you need them. The interface is compact and a quick help document is included. Artists with cluttered hierarchies will spend less time hunting through the Object Manager.

Key features

  • Search large groups or specific scene items
  • Isolate only the objects you are working on
  • Save object selection groups to revisit
  • Compact interface
  • Quick help document included
