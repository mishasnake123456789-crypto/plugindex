What Animates Motion Paths And 3D Onion Skins does

Animates' add-on gives Blender animators a way to refine movement visually. A 3D motion path can be shaped directly in the viewport, with native gizmos to add, delete, move and smooth keys and handles.

A lattice tool reshapes selected keys or path sections along any axis, and a built-in sculpt brush with smoothing sliders refines keys, handles and spacing. Ghosted poses reveal arcs and timing at a glance. Character and object animators will polish motion more precisely.

Key features

  • Editable 3D motion path in the viewport
  • Lattice deformation of keys
  • Sculpt brush with smoothing sliders
  • Ghosted 3D onion skins
  • Native Blender gizmos
