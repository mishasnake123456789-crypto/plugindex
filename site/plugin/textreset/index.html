What TextReset does

TextReset is a Premiere Pro extension that undoes accumulated changes to titles. When text layers have been nudged, scaled and rotated across a project, a single click returns the selected ones to their default parameters.

Position, scale, rotation, opacity and anchor points are all reset together. The goal is consistent text formatting across many clips, such as when captions or lower thirds need to match again after experimenting. It supports Premiere Pro 13.0 and later, and works on whichever text layers you have selected.

Key features

  • One-click reset to default values
  • Covers position, scale, rotation, opacity, anchor
  • Acts on selected text layers
  • Standardizes text across clips
