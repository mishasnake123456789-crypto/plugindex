What Editor Swap does

Editor Swap is a Blender plugin for flipping an area between editors without opening menus. A button on the editor header or a keyboard shortcut makes the switch.

Links between editors are fully customizable, so you can cycle sequentially between two or more of them. The header button can be hidden to work with the shortcut alone, and the shortcut itself is assignable. Helpful on small screens or single-monitor layouts.

Key features

  • Header button or shortcut switching
  • Customizable editor links
  • Cycle between two or more editors
  • Optional hidden header button
