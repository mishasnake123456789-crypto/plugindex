What Blender To Daz Studio Plugin does

This plugin by Matronius sends Blender content into Daz Studio in one export. Objects travel as FBX along with PBR textures, materials, armatures and animations.

Multiple objects can be exported together, and Principled BSDF materials are converted to the Daz UberIray material, with base color, metallic, specular and roughness textures exported. It removes tedious manual rebuilding when moving models between the two programs. Automating material conversion and texture export saves the tedious work of recreating each surface after the transfer.

Key features

  • FBX export to Daz Studio
  • Multiple objects in a single export
  • Principled BSDF to UberIray conversion
  • PBR textures, armatures and animations
