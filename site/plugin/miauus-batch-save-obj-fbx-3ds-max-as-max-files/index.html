What miauu's Batch Save Obj/Fbx/3ds/Max as .Max files does

miauu's Batch Save script opens arbitrary OBJ, FBX, 3DS and MAX files and saves each one as a .max file for a version of 3ds Max you choose. It has a resizable interface and checkboxes, so only files that are ticked get processed.

A Get Directory button lists every supported file in a folder, with an optional prompt to include subfolders, and Get File(s) supports multiple selection. Right-clicking a name opens its folder in Windows Explorer and middle-clicking removes it from the list. Studios converting asset libraries to a single format will find it a time saver.
