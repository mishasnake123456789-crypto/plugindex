Slices selected Blender meshes into cross-sections along chosen axes at a millimetre interval.

What Cross Section does

Digital Sculptors' Cross Section puts a Create Sections command in the Object menu. It cuts the selected mesh into slices, for visualization, fabrication layouts or technical illustration.

You set which axes to cut and the interval in millimetres, with defaults of all axes and 100 mm. The output is sorted into X_sections, Y_sections and Z_section collections to keep the scene organized. It is useful for laser cutting, layered models and slicing studies.

Key features

  • Create Sections command in the Object menu
  • Adjustable axes and interval in millimetres
  • Defaults: all axes, 100 mm
  • Results sorted into X, Y, Z collections
