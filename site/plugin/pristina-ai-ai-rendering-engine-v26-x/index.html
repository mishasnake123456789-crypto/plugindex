What Pristina.Ai® Ai Rendering Engine V26.X does

Pristina.Ai brings AI-assisted rendering into Blender, aimed at architectural visualization, product shots and client deliverables. You steer materials, lighting and mood across the scene, and the result keeps the geometric accuracy of what you built.

Three modes, complete, hybrid and enhance, decide how much the AI changes. Jobs run in parallel on cloud infrastructure, with two times upscaling and object passes up to 4096 by 4096 pixels. Automatic masking supports targeted enhancements and exports transparent PNG masks, and you can attach reference images to individual objects. A Vision MCP skill passes viewport context to your own MCP tools.

Key features

  • Complete, hybrid and enhance render modes
  • Keeps 3D geometric accuracy from the Blender scene
  • Parallel cloud rendering jobs
  • 2x upscaling and object passes up to 4096 px
  • Automatic masking with exportable PNG masks
