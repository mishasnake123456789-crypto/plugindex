What Objects Replacer does

Objects Replacer from Georeality Design swaps placeholders for finished assets. Dummy objects or lights already placed in the scene are exchanged for detailed ones taken from a chosen collection or the active object, which instantly varies the scene.

You can create instances or not, and handle scale in several ways: keep the target's, keep the collection object's or apply random scales. Good for iterating on layouts. Using stand-ins during layout keeps the viewport fast, and swapping in detail at the end gives rapid variations.

Key features

  • Swap dummies for detailed objects
  • Replace lights as well as objects
  • Optional instances
  • Scale options including random
