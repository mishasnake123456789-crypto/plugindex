What Step Importer For Blender - Import Step / Stp Cad Files does

Step Importer for Blender brings engineering CAD models into Blender using the Open CASCADE (OCCT) kernel. STEP and STP files import directly, and the quality of the tessellation can be adjusted from lightweight meshes to highly detailed ones.

A live link to the source file keeps work non-destructive after import, so you can change tessellation and treat parts independently. Per-object optimization increases detail only where needed while the rest stays light, and instances are recognized. Product visualizers and designers who render CAD assemblies will avoid converting files through other software.

Key features

  • Imports STEP and STP using Open CASCADE
  • Adjustable tessellation quality
  • Live link to the source file
  • Per-object detail optimization
  • Instance recognition
