Blender add-on that extends random selection to edit mode and adds vertex group, collection and object count controls.

What Select Random Plus does

Select Random Plus builds on Blender's own random selection. It works for vertices, edges and faces in edit mode as well as objects in object mode.

Separate sliders give distinct random picks for each element type. Vertex group support limits the choice to a chosen group, an object-mode slider selects a specific number rather than a percentage, and collection support restricts random picks to a set collection without hiding anything. Useful for scattering variation across detail work.

Key features

  • Random vertices, edges, faces or objects
  • Vertex group restriction
  • Pick an exact object count
  • Collection-limited selection
  • Works in edit and object modes
