What pt_CropPrecomps does

pt_CropPrecomps, by Paul Tuersley, cleans up Photoshop files imported into After Effects as layered compositions. Each layer sits in its own nested comp at full canvas size, which makes animating awkward, and the script crops those comps to the actual image content.

It expects files imported with the Cropped Layers (CS3/4) or Retain Layer Sizes (CS5) option. Run Crop Precomps from the file's main composition, or limit it to selected precomp layers. Vector masks and non-square pixel aspect ratios are supported, and the script works from CS3 through 2026.

Key features

  • Crops nested comps to image content
  • Designed for layered Photoshop imports
  • Option to crop only selected precomps
  • Supports vector masks and non-square pixels
  • Compatible CS3 through 2026
