What MultiMatte Tamer does

MultiMatte Tamer is a MaxScript that organizes Object IDs and V-Ray MultiMatte Render Elements in 3ds Max. A grid table is where objects get picked, and buttons add IDs, refresh the scene and build elements.

Refresh reloads objects and recognizes IDs changed by hand, adding buttons where necessary. Collect fills every RGB slot instead of going in sequence, Selected restricts the list to chosen objects, and typing in Filter selects all matches in the names column. Elements builds render elements from the selection. A double-click on a cell can select identical OIDs, an entire layer, or related names that end with a digit. Version 1.2.4 added HD mode and unique identifiers instead of names.

Key features

  • Grid table for assigning Object IDs
  • Refresh recognizes manually changed IDs
  • Collect mode uses all RGB slots
  • Filter and Selected views
  • Creates V-Ray MultiMatte render elements from the selection
