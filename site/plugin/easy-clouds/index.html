Blender add-on by LunarKitten that creates procedural, customizable clouds with one button.

What Easy Clouds does

Easy Clouds generates clouds in Blender without manual shader work. One button creates either a single cloud or a whole cloud layer, and node groups are included for those who want to assemble their own.

A Create Sphere button, added in version 2.2, produces spherical clouds, and separate shaders exist for Cycles and Eevee. Its panel is on the Tool tab of the viewport sidebar, and no special permissions are required. Environment artists and animators can add skies and atmospheric backdrops quickly.

Key features

  • One-button cloud or cloud layer
  • Node groups for custom clouds
  • Create Sphere option
  • Separate Cycles and Eevee shaders
