What Propui: Custom Blender Ui Panel Builder does

PropUI lets Blender users design their own control panels without writing any Python. You add controls, give them readable names, and arrange them visually rather than living with the default property order.

Controls can be linked to RNA paths for objects, modifiers, materials, nodes, scene and tool settings. When the layout is done, PropUI generates a real panel that keeps working after the editor is closed, stored in the .blend or exported as a portable script. Riggers and animators will find it useful for rig controls, modifier setups and material tweaks.

Key features

  • Readable control names with safe underlying driver IDs
  • Visual layout instead of default property order
  • Links to RNA paths for objects, modifiers, nodes and more
  • Sliders, fields, labels, row boxes, sub-panels and buttons
  • Panel saved in the .blend or exported as a .py file
