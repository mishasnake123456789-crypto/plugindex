What Batch Fbx Exporter does

Exporting numerous props as individual FBX files by hand is dull. Conner Sinewe's Batch Fbx Exporter does it in one click, giving every selected object a separate file named after it.

Export options adjust scaling and unit application, you choose which objects to include, and it sits inside Blender's interface. Game developers and asset creators who deliver many standalone items save a lot of repetitive work. Pipelines feeding Unity, Unreal or other engines often expect exactly this one-file-per-prop layout.

Key features

  • Separate FBX per selected object
  • Files named after objects
  • Adjustable scaling and units
  • Choose which objects to export
  • Integrated into Blender's interface
