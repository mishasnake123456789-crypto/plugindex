Blender add-on that sets up six product cameras, built-in lighting and a collage render showing every angle.

What Multi View Render does

Multi View Render builds a six-viewpoint camera layout in Blender so a product can be shown from all sides in one go.

All cameras are managed in one place and toggled with a click. A lighting system provides three-point, sky and HDRI environments. The collage feature outputs every camera in a single image for stills and videos, and an enumeration system labels views so feedback can reference them. Documentation is included. It suits product visualization and turnaround presentations.

Key features

  • Six-camera setup for all angles
  • Cameras toggled from one place
  • 3-Point, Sky and HDRI lighting
  • Collage rendering for stills and videos
  • View numbering for feedback
