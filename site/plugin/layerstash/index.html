What LayerStash does

Sarthak Agarwal's LayerStash is a panel built for After Effects aimed at building a personal layer library. Any layer can be saved with its properties and recalled in another project with one click, without recreating it.

Keyframes, effects and expressions are preserved on text, shape, adjustment and precomp layers, while media layers store the source file, interpretation and transforms. Saved layers are grouped by client using profiles, with folders inside each profile. Expressions recompile on load, including in Group Mode, and missing media triggers a prompt to relocate source files.

Key features

  • Save and load layers in one click
  • Keeps keyframes, effects and expressions
  • Media layers retain source and interpretation
  • Client profiles with folders
  • Prompt to relocate missing media
