What Spline Generator does

Spline Generator, from TFMSTYLE, adds parametric curve creation to Blender's Add Curve menu. Splines fall into three categories, Simple, Fractal and Chaotic, each controlled by sliders.

The curve updates dynamically as values change, so you can explore shapes interactively. Presets include the Lorenz, Rossler, Dadras and Halvorsen attractors along with torus and Rhodonea curves. It requires no special permissions, and is useful for motion paths, decorative shapes and procedural modeling.

Key features

  • Simple, Fractal and Chaotic spline categories
  • Slider-based parameters
  • Dynamic updates as values change
  • Attractor presets such as Lorenz and Halvorsen
  • Torus and Rhodonea presets
