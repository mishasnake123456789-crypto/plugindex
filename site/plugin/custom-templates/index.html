What Custom Templates does

Custom Templates, by Francesco-Bellini, adds your own .blend files to the list of project templates in Blender, so new work can start from a setup you built. It is tagged under System and User Interface.

It is open source under GPL-3.0-or-later and needs Blender 4.2.0 or newer.

Key features

  • Use your .blend files as templates
  • Appears as new project options
  • Open source, GPL-3.0-or-later
  • Requires Blender 4.2.0 or newer
