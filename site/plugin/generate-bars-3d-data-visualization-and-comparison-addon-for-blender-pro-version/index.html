What Generate Bars: 3D Data Visualization And Comparison Addon For Blender (Pro Version) does

Generate Bars builds data comparison videos in Blender. Import a CSV file and generate bars in the viewport with one click.

Bar size follows the data with normalization for consistent scaling, and image textures can be assigned from filenames in the CSV. Country names or other titles and custom fields such as company names or revenue figures can be displayed. It also handles materials, camera animation and backgrounds. It suits creators of ranking and comparison videos.

Key features

  • One-click bars from CSV data
  • Data normalization for scaling
  • Image textures from CSV filenames
  • Titles and custom fields
  • Camera animation and backgrounds
