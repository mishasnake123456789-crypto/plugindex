What Blender Auto Lod does

Blender Auto LOD simplifies large scenes by applying level-of-detail logic. It puts a Decimate modifier on each object and calculates the value from how far the object is from a main object you choose, such as the camera.

You can set a minimum decimate value and a range, and remove all decimate modifiers again in one click. It's useful for lightening heavy scenes for viewport work or rendering. This is useful for scenes that include many distant objects, since far-away items receive stronger reduction while nearby ones keep their detail.

Key features

  • Decimate modifier on all objects
  • Value computed from distance to main object
  • Adjustable minimum and range
  • One-click removal
