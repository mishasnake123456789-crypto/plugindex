What Control LMFX does

Control LMFX is a panel from R/L that gathers several housekeeping tools for After Effects projects. It centers on controlling layer and effect groups but also includes utilities for compositions, timing, color and files.

Duplicate Compositions works quickly by holding Shift, and the FPS Editor changes the frame rate of selected media or comps with manual input and filtering. Recolor Keyframes supports text layer keyframes, and Sort Files uses keywords and an Unused Files group. FX Manager and Group Viewer show effects as a list, and Palette Manager can set the default label color for new nulls.

Key features

  • Layer and effect group control
  • FPS Editor for media and comps
  • Recolor Keyframes including text layers
  • Keyword-based file sorting and unused file group
  • FX Manager and Palette Manager
