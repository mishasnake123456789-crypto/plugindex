What Circular Stacker does

Circular Stacker is a Blender add-on by Hydrocallis that spreads selected objects around in rings. Its command sits in the Transform submenu of the Object menu, and it creates as many circles as are needed to fit every object.

Basic controls cover radius, the height step between stacked circles and an overall rotation angle. A face center toggle, per-object Z rotation and Z offset allow spiral-like layouts, and objects can be sorted by name beforehand. Skip patterns provide extra control over spacing, handy for towers, wreaths and arrangements.

Key features

  • Distributes objects in circular stacks
  • Radius, height increment and rotation controls
  • Face Center, Z rotation and Z offset options
  • Sort objects by name before placement
  • Skip patterns for spacing
