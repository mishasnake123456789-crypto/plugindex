What Simple Bounce Curve does

Simple Bounce Curve, by Polyfjord, builds a curve that connects selected objects in Blender according to their origins. The result is a ready-made bouncing path that objects can follow.

Curve height is set by a slider in the redo panel, and a dynamic height option scales with the distance between objects. Control point handles can then be refined in Edit Mode. Animators and motion designers can use it to lay out hops and arcs quickly without drawing each path by hand.

Key features

  • Bounce curve between selected objects
  • Height slider in redo panel
  • Dynamic height based on object distance
  • Handles editable in Edit Mode
