What Test app - ModelSync Pro does

ModelSync Pro, by Super Nova and listed here as a test app, is described as an extension for Fusion 360 rather than for 3ds Max. It synchronizes, manages and shares models and design data with cloud systems and third-party platforms.

Synchronization of files is automated, versions are tracked with change history, and design data can be shared securely. Status notifications and error handling are included, and commands are reachable from the main Fusion 360 interface on supported Windows systems. Design and engineering teams on complex projects can keep their models consistent across services.

Key features

  • Automatic synchronization of Fusion 360 models
  • Version management with change tracking
  • Integration with external cloud services
  • Status notifications and error handling
  • Built into the Fusion 360 interface
