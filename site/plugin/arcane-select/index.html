What Arcane Select does

Arcane Select is a Blender add-on from Pixonix Studio that improves mesh selection. Three shortcut keys switch between box, lasso and circle modes, and each can select elements on the front, back or inside of the selection.

You can limit selection to back faces, let X-ray toggle automatically during selection, and choose between Fast and Precision modes. It works with Blender 4.2 through 4.5. Modelers who select through dense geometry will find it speeds up hidden-element selection.

Key features

  • Shortcut keys for box, lasso and circle
  • Front, back or inside selection
  • Back-face only option
  • Auto X-ray toggle and Fast/Precision modes
