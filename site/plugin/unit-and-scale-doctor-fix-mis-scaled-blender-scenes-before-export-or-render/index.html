What Unit & Scale Doctor - Fix Mis-Scaled Blender Scenes Before Export Or Render does

Unit & Scale Doctor checks a Blender file for the kind of scale mistakes that break assets once they reach a game engine or CAD tool. It reports unapplied, negative or non-uniform scale, scaled parents and mismatched units.

Target profiles for Unity, Unreal, glTF and CAD adapt the checks and export settings. One-click fixes can apply scale on static meshes or align units without rescaling vertices, while viewport overlays show bounds, axes and unit labels. Guarded FBX and glTF export refuses to proceed while violations remain, which suits anyone shipping assets to other pipelines.

Key features

  • Profiles for Unity, Unreal, glTF and CAD
  • Detects unapplied, negative and non-uniform scale
  • One-click repairs with optional armature skipping
  • Live bounds and axis overlays in the viewport
  • Export blocked while violations remain
