Blender add-on that exports node trees as structured text for AI assistants and captures high-resolution node screenshots.

What Node To Talk does

Node To Talk converts Geometry, Shader and Compositor node trees into text reports that AI assistants can read. It also takes high-resolution screenshots of a node tree using a tile-based system.

Reports list connections, settings and execution order in a topology-ordered, connection-mapped format, and you can toggle Instructions, Details, Frames and Materials. Selected-node export supports isolated debugging or modular group development. A Show Node IDs overlay swaps labels for persistent IDs. Useful for asking an assistant to explain or fix a complex graph.

Key features

  • Structured text export of node trees
  • Toggle Instructions, Details, Frames or Materials
  • Selected-node export
  • Node ID overlay
  • Tile-based high-resolution screenshots
