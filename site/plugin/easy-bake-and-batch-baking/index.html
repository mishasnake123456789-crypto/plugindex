What Easy Bake And Batch Baking does

Easy Bake And Batch Baking offers a full baking toolkit inside the N-Panel. Over thirty bake map types sit in Surface, Lighting, IDs & Masks and Material groups and are picked from a Configure Maps popup.

Compute can run on GPU or CPU, with automatic detection of CUDA, OptiX, HIP, Metal and OneAPI, and sample counts range from 1 to 4096. Batch processing and UV analysis are included. Game artists baking many assets will find the options broad.

Key features

  • 30+ bake map types
  • GPU or CPU compute with auto-detection
  • Samples from 1 to 4096
  • Batch processing and UV analysis
