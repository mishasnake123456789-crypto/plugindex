What Data Glitch 2 Render Only does

This is a licensing variant of Data Glitch 2 from Rowbyte, not a separate effect. It lets render machines run Data Glitch 2 headlessly through the After Effects command line renderer.

You must already own a full Data Glitch 2 licence to buy it. It works with After Effects (CS6 through 2024) and Premiere Pro, includes a licensing tool for command line render machines, and version 0.3.3 was updated to include Stipple. Studios with render farms who use Data Glitch 2 can license their farm nodes without paying for a full seat.

Key features

  • Render-only licence for headless machines
  • Requires a full Data Glitch 2 licence
  • Works with After Effects and Premiere Pro
  • After Effects CS6 through 2024
  • Command line licensing tool
