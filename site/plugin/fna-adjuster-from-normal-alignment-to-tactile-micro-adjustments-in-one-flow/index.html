What Fna Adjuster | From Normal Alignment To Tactile Micro-Adjustments In One Flow does

FNA Adjuster is a precision transform utility for Blender. FNA stands for Face Normal Align: it reads rotation from a face and re-orients an object's axes to match.

In Object Mode you click a face, and in Edit Mode you select faces, then adjust with a tactile Jog-Dial where holding the dedicated buttons rotates or moves the object in small steps. It is handy for placing parts on angled surfaces or aligning kitbash pieces exactly.

Key features

  • Align object axes to a clicked face normal
  • Works in Object and Edit Mode
  • Jog-Dial micro-adjustments for rotate and move
