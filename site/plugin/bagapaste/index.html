What BagaPaste does

BagaPaste, by Kiara_Bagattini, removes the save-and-import routine from bringing pictures into Blender. Copy an image, a file, a local path or even a web image URL, then paste it straight into the scene as a textured plane or as a reference image.

When the clipboard contains a link the add-on downloads the picture automatically. You can choose alignment to the world, the view, the 3D cursor or the active object, place the result at the cursor, keep transparency, and decide whether files are stored beside the blend file, in temp or elsewhere. It sits in Add > Image and the N-panel.

Key features

  • Paste images, copied files, paths or URLs
  • Result as plane or reference image
  • Alignment to world, view, 3D cursor or active object
  • Transparency support
  • Configurable storage location
