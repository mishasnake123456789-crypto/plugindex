Blender add-on that lofts a surface between two or more profile curves, controlled by guide curves along with a sweep curve.

What Loft Curves does

Loft Curves builds a surface in Blender from two or more profile curves. It is a modifier wrapping a Geometry Nodes core, so the result stays editable.

Guide curves snap to the profiles, and a separate sweep curve controls and deforms the surface. Edits to profiles and guides in Edit Mode update the surface live. Designers modeling hulls, bottles, vehicle bodies and other organic or mechanical forms can use it to get smooth shapes.

Key features

  • Surface built across two or more profiles
  • Guide curves snapped to profiles
  • Sweep curve deforms the surface
  • Live editing of profiles and guides
