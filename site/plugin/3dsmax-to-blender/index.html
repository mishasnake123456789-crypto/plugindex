Windows Blender add-on that imports 3ds Max .max files directly, with unit detection, material cleanup and import reports.

What 3Dsmax To Blender does

3Dsmax To Blender gives Windows users a way to open .max files in Blender without first exporting FBX or OBJ from Max. It tries a bundled MAX importer first and, if that fails, can call a local 3ds Max command that you configure to export a format Blender can read.

Imports are normalised to Blender's metric scale by detecting millimetres, centimetres, metres or inches where metadata allows. Materials are adapted for Cycles where possible, and a report lists textures found or missing. Files can be dragged in or opened via the import operator, and an optional GLB cache speeds repeated handoffs.

Key features

  • Bundled MAX importer tried first
  • Unit detection with a configurable fallback unit
  • Material normalisation for Cycles
  • Import report listing found and missing textures
  • Fallback bridge exporting OBJ, FBX, glTF or GLB
