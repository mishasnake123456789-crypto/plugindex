What Curve Shapes does

Curve Shapes is a Blender extension for shaping geometry by drawing curves. You work with Bezier and Poly curves, and the add-on produces a mesh with clean topology that updates in real time as the curves change.

That makes it comfortable for organic forms built from flowing lines, such as armature, muscles and similar shapes, where editing a few curves is easier than pushing many vertices. It is released under the GPL, includes documentation and supports Blender 3.6 as well as the 4.0, 4.1 and 4.2 releases. Artists who prefer a curve-driven modeling approach will find it natural.

Key features

  • Mesh generated from Bezier and Poly curves
  • Clean topology
  • Real-time control of the resulting mesh
  • Fits organic armature and muscle shapes
  • GPL licensed with documentation
