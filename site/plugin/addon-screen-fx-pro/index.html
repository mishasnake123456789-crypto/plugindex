What Addon: Screen Fx Pro does

Screen FX Pro is a node tree for giving surfaces the look of digital screens. Use it on billboards, text, UI, holograms and monitors for RGB pixel, procedural halftone, grid and scanline effects in Cycles or Eevee.

It comes as a blend file whose node tree you append into scenes, rather than a typical installed add-on. The RGB/pixel effect works from UVs, while halftone and grid use generated coordinates. This makes it simple to dress up sci-fi interfaces and retro displays.

Key features

  • RGB pixel effect
  • Procedural halftone and grid
  • Scanline effect
  • Works in Cycles and Eevee
  • Appended node tree from a blend file
