What Project Auto Cleaner does

Valentin's Project Auto Cleaner removes clutter from .blend files. A button in the Scene Properties scans the project and automatically deletes unused data.

Out go objects that sit in no scene, orphaned materials, meshes and textures, leftover images and unlinked actions, and a popup reports what was removed. Documentation is included. Anyone managing complex projects can shrink files before saving or sharing. It is a convenient last step before saving, because forgotten leftovers are the usual cause of bloated files.

Key features

  • One-click cleaning in Scene Properties
  • Removes unused objects
  • Clears orphaned materials, meshes and textures
  • Removes forgotten images and unlinked actions
  • Summary popup
