What Foliagelab - Atlas does

FoliageLab Atlas builds foliage atlases with little setup. Point it at a flat folder of PBR textures and it detects assets by filename convention, places them in the scene and bakes them together.

Sizes of Big, Medium or Small are guessed from keywords in the names and can be changed manually. Single-element textures are treated as squares while multi-element textures are packed using a convex outline. Game and real-time artists creating vegetation atlases can save manual layout.

Key features

  • Automatic PBR asset detection from filenames
  • Size detected from keywords, adjustable
  • Single-element textures treated as squares
  • Convex packing for multi-element textures
  • Bakes to a texture atlas
