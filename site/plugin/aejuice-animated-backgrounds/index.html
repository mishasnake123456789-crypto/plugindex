What AEJuice Animated Backgrounds does

AEJuice Animated Backgrounds provides 144 ready-made moving backdrops for After Effects and Premiere Pro. Each is applied with a click or by dragging it into the project, which suits editors who need a quick backdrop for titles, interviews or social clips.

The pack works with the Pack Manager, offering fast previews, favorites and speedy downloads. A pre-rendered version is also supplied, so the backgrounds can be used in any other video editor as well. Designers save time compared with building looping backgrounds from scratch.

Key features

  • One-click or drag-and-drop application
  • Pack Manager previews and favorites

  • Pre-rendered version for any editor
