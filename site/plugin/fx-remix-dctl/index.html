What FX Remix DCTL does

FX Remix DCTL generates glitchy, pixel-sorted imagery in DaVinci Resolve in seconds. It targets digital decay and data-moshing looks, uses the DCTL API present since Resolve 19.1, and runs in versions 19, 20 and 21.

A Normalized Distance parameter from 0.0 to 1.0 is relative to the frame diagonal, so the look stays consistent across timeline resolutions and aspect ratios. Rndm Every X Frame creates new random values every set number of frames for slower randomized animation, and Matte modes are selectable, defaulting to None. Editors making music videos, titles or experimental sequences can use it for distortion.

Key features

  • Glitch and pixel-sorting effect
  • Normalized Distance parameter independent of resolution
  • Rndm Every X Frame for slower random animation
  • Selectable Matte modes
  • Built on the DCTL API from Resolve 19.1
