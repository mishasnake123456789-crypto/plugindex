What LOG does

LOG, from Henry LA, adds a curve editor to Fusion in DaVinci Resolve for shaping keyframe motion. Instead of fiddling with default interpolation, animators can draw smooth easing curves and see how values change over time.

One curve can be applied to several nodes at the same moment, and values can be copied from curves that already exist. Favorite curves are stored as presets and recalled whenever the same feel is needed again. The interface is simple, can be customized to taste, and allows precise editing. Motion designers who animate heavily in Fusion will save time on repetitive easing work.

Key features

  • Curve editor for Fusion keyframes
  • Apply one curve to multiple nodes at once
  • Copy values from existing curves
  • Save and reuse curve presets
  • Customizable interface
