What LoadUP does

LoadUP is a script from Real Creations that builds loading and progress bars quickly in After Effects. It targets people designing HUDs, UI elements, infographics, charts and TV or news graphics.

Any number of bars can be created within one composition, each named uniquely, with a distinct label color per bar. Every numeric box can be adjusted with the arrow keys, and grouped undos remove an entire bar in one click. Text controls cover tracking, offset, size and color. It runs as a dockable panel or floating window, is language independent, and comes with tooltips and a 13-page PDF guide.

Key features

  • Unlimited uniquely named bars per comp
  • Arrow-key numeric adjustment
  • Grouped undo for whole bars
  • Text controls for tracking, size and color
  • Dockable panel or floating window
