What Export to Nuke Script does

Export to Nuke Script moves camera and locator data from Blender to Foundry's Nuke. Cameras become Camera3 nodes and empties become Axis3 nodes, written in a native Nuke Python .py script.

Transformations are baked into the translate and rotate knobs, so animation can be edited fully in the Curve Editor. Blender's conventions are converted automatically. Compositors who finish shots in Nuke can bring over 3D animation accurately.

Key features

  • Cameras as Camera3 nodes
  • Empties as Axis3 nodes
  • Baked translate and rotate knobs
  • Generates a native Nuke Python script
