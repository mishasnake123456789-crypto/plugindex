What Image Blur Node does

Image Blur Node brings an image blur into the Shader Editor, so you can soften a texture without opening an external image program. It is aimed at cases like blurring an HDRI for a world background, and it works with Environment Texture nodes, including in world mode.

A scale slider sets the amount of blur. The result is written beside the source file with a _blurred suffix, or to a custom folder set in the add-on preferences, and the new Image Texture node inherits the original's settings, connections, color and alpha. Updates have kept it current with newer Blender releases.

Key features

  • Blur images directly from the Shader Editor
  • Scale slider controls blur amount
  • Saves with a _blurred suffix or to a custom export path
  • New texture node keeps original parameters and links
