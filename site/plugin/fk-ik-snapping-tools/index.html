Blender add-on that snaps FK and IK controls to match each other on humanoid rigs with one click.

What FK/IK Snapping Tools does

FK/IK Snapping Tools, by atrxi, helps animators switch between forward and inverse kinematics without a visible jump. Two buttons, FK to IK and IK to FK, move one set of bones to match the other.

A Bone Settings panel assigns deform bones, FK bones, and the IK pole and target for each limb, so it adapts to many humanoid rig types. IK matches the FK bone rotation when snapping. The controls sit in the Animation tab.

Key features

  • FK to IK and IK to FK buttons
  • One-click snapping
  • Per-limb bone assignment panel
  • IK matches FK rotation
  • Works across many rig types
