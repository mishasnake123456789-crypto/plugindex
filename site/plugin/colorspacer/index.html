Set colorspaces on image textures in a single action, with ACES, Blender and AGX presets built in.

What Colorspacer does

Colorspacer speeds up fixing color management on textures. Instead of changing each image node, you assign a colorspace to many textures in one action.

ACES, Blender native and AGX are available by default, and a custom menu allows any combination of colorspaces. It can fix the colorspace for selected objects. Artists switching a project between color pipelines avoid opening every material.

Key features

  • Assign colorspaces in a single action
  • ACES, Blender and AGX defaults
  • Custom menu for other combinations
  • Fix colorspaces for selected objects
