Blender add-on that uses a Bezier curve to place vertices when retopologizing soft, organic surfaces.

What Verti-Curve: Vertex To Bezier Pathing does

Counting subdivisions and nudging single vertices makes retopology slow. Inlet's VertiCurve replaces that: create a Bezier curve, line it up so it steers the vertices, then refine them with a click.

It is built for organic, soft surface topology such as faces, creatures and clothing. Documentation is provided, and Blender 2.83 through 5.0 are supported. Retopologists should find that curve-driven placement gives smoother, more even loops. Because the curve stays editable, adjusting the flow of a whole loop becomes a matter of nudging control points.

Key features

  • Bezier curve based retopology
  • Align curve to guide vertices
  • One-click vertex fine-tuning
  • Documentation included
  • Blender 2.83 to 5.0
