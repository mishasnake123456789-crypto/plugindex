What GifGun does

GifGun is an After Effects plugin built for turning compositions into small web-friendly animations. One interface handles GIF, WEBP, WEBM and MP4 output, so there's no need to bounce through extra converters.

Its smart compression produces files about a seventh smaller while looking better, and a target size setting keeps results within limits such as those imposed by email or chat platforms. Several comps can be queued and rendered together. Export settings can be stored as JSON presets for sharing with teammates, and one licence covers the plugin, a desktop app and a web app.

Key features

  • Exports GIF, WEBP, WEBM and MP4 from one panel
  • Compression about 15% smaller with better quality
  • Batch rendering of multiple comps
  • Target file size hit automatically
  • Presets saved and shared as JSON
