What Linkup Pro does

Linkup Pro places a web browser and AI tools inside After Effects so reference gathering and asset import need no window switching. The browser engine is Chromium on Windows and Safari on Mac, with a context menu, find-in-page and search shortcuts.

Downloads go straight to the timeline, files upload from the project panel, and screenshots import automatically. An Ask tab connects to ChatGPT, Claude and Gemini with saved prompt shortcuts, while an AI Agent reads layers, keyframes and effects and carries out tasks in the project. Free and paid API keys work, free models are available, and expressions and scripts can be built or run from the clipboard.

Key features

  • Native browser with Chromium or Safari engine
  • Direct import and screenshot capture
  • Ask tab for ChatGPT, Claude and Gemini
  • AI Agent that acts on layers and keyframes
  • Expression building and clipboard scripts
