Blender add-on that exports cameras, lights, images, object positions and tracking markers to After Effects as a JSX script.

What Export: Adobe After Effects (.jsx) does

Export: Adobe After Effects, by Les Fées Spéciales, moves Blender scene data into After Effects. It writes an ExtendScript .jsx file that After Effects can load to rebuild the setup.

It can send animated cameras and lights, images, positions of other objects and tracking markers. Once enabled in Blender's preferences it appears in the File menu under Export, and it can also be set up from collection properties, with options for file name and exports. Compositors who render in Blender but finish in After Effects keep their layouts matched.

Key features

  • Exports cameras, lights, images and markers
  • Writes an ExtendScript .jsx file
  • Available under File > Export
  • Selectable file name and options
