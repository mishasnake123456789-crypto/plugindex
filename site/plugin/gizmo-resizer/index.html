What Gizmo Resizer does

Gizmo Resizer, by CorentinBileau, makes viewport gizmo scaling instant in Blender, which will feel familiar to users coming from Maya. Numpad + and - enlarge or shrink the manipulator immediately.

Holding Shift changes the step size and sensitivity, while Alt plus the Numpad zooms the viewport, and a minimal HUD shows the current size before fading away. Keymap conflicts are handled automatically, and preferences set HUD position, font size, color theme and display duration. No special permissions are required.

Key features

  • Numpad + and - resize the gizmo
  • Shift adjusts step and sensitivity
  • Minimal fading HUD
  • Automatic keymap conflict handling
  • HUD position, size and theme options
