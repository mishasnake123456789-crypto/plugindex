What Floaty - Open Editors In New Windows does

Floaty is a Blender add-on that brings detachable editors to your workspace. One button opens any editor in a new floating window, helpful on multi-monitor setups or when a panel needs more room.

When you are finished, detailed controls dock the editor back where it belongs. The idea comes from Maya's editor handling, and it lets you rearrange the interface into the layout your current task needs. Documentation is included. Anyone who feels cramped by Blender's fixed area splits may like it.

Key features

  • Open any editor in a floating window
  • Dock editors back with detailed controls
  • Maya-style detachable editors
  • Rearrange workspace layout
  • Documentation included
