What Emg (Edit Mode Guard) does

EMG (Edit Mode Guard) is a tiny safeguard for artists who work with dense meshes. Pressing TAB by mistake on a million-vertex model can freeze Blender for a long time, and this add-on interrupts that.

A warning window appears when TAB is pressed to enter edit mode, letting you cancel or continue. It watches only the TAB key, which is especially useful during sculpting in Blender 2.8x. Documentation is included.

Key features

  • Warning window on TAB into edit mode
  • Cancel or continue choice
  • Useful for very dense models and sculpting
  • Watches only the TAB key
