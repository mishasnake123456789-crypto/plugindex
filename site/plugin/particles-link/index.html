What Particles Link does

Particles Link joins particles, point clouds and Geometry Nodes points points into animated link graphics in Blender. Ten connection styles are generated live in the viewport.

Version 5 uses a GPU-powered engine for faster generation even with very dense simulations. Styles include Flow Line, Network, Tree, Clusters, Hair, Current, Cobweb, Orb Web, Loops and Tracer, and Tracer builds particle trails frame by frame. Motion designers can create techy network and web visuals.

Key features

  • 10 link styles
  • GPU engine in version 5
  • Tracer mode for trails
  • Works with particles, point clouds and Geometry Nodes
