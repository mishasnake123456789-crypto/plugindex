What Crack! - Splitting & Filling Mesh does

Crack! separates an object into two parts without the manual step of rebuilding the missing faces. Select a loop, run the split, and each piece is closed rather than left open.

The approach avoids an internal void, which is helpful for broken-object effects, cutaway views and fabrication. Versions 3.6 to 5.0 are supported, along with the Cycles, Eevee and Blender Game Engine renderers. Modelers who split meshes frequently can skip tedious capping.

Key features

  • Splits an object into two from a selected loop
  • Fills missing faces automatically
  • No internal void left behind
  • Supports Blender 3.6 through 5.0
  • Works with Cycles and Eevee
