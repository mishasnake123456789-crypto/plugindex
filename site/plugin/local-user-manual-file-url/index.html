What Local User Manual File URL does

Local User Manual File URL changes where Blender sends you when you ask for documentation. Rather than opening the online manual, the links can be redirected to a copy stored on your own drive.

This helps when working offline, on slow connections or on a version-matched manual you have downloaded. Anyone who frequently checks operator help from within Blender can get faster, more reliable access.

Key features

  • Override the manual URL
  • Use an offline manual copy
  • Works from Blender's help links
