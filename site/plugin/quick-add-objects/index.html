What Quick Add Objects does

Quick Add Objects is a light Blender add-on that shortens the path to adding a primitive. Press Alt+Q and a pie menu appears with the basic meshes people use most.

It works in object mode and edit mode alike, saving you a trip through the Add menu. It installs like any ordinary add-on through the preferences, and documentation along with a video tutorial is provided. Modelers who place many primitives while blocking out shapes will click far less.

Key features

  • Pie menu opened with Alt+Q
  • Works in object and edit mode
  • Common meshes in one place
  • Documentation and video tutorial
