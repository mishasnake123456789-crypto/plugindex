Blender add-on that applies modifiers to meshes with shape keys while preserving key values, animation data and drivers.

What Apply modifier with shape keys does

Blender normally refuses to apply a modifier on a mesh that has shape keys. This add-on from Orange Turbine removes that restriction by applying the modifiers you pick and then rebuilding the shape key setup on the original mesh.

Values, animation data and drivers are restored afterwards, so rigged or animated facial setups survive the operation. Shape keys are processed one at a time to keep memory use down on dense meshes, and a popup dialog with checkboxes lets you choose exactly which modifiers to bake in. Modelers and character artists finalizing assets will find it handy.

Key features

  • Applies chosen modifiers to meshes with shape keys
  • Restores key values, animation and drivers
  • Processes keys one at a time to save memory
  • Popup dialog with modifier checkboxes
