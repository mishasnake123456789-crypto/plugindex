What Damtools does

DAMTools places over fifty modeling operators behind a single pie menu opened with Shift+W. Sections cover manipulation, editing and drawing, cleaning, transforms and hard surface work, plus a dynamic list of whatever you use most.

For 3D printing, the SlicerExport feature sends models to BambuSlicer or PrusaSlicer. Other pieces include batch import and export, an STL exporter that remembers its folder, interactive face extraction with paint mode, interactive primitives with live dimensions, a TopoCleaner with a recursive aggressive mode, and a revolve tool with selectable origins.

Key features

  • Shift+W pie menu with 50+ tools
  • Slicer export for Bambu and Prusa
  • Batch import and export
  • Interactive face extraction and primitives
  • TopoCleaner and revolve tool
