What LogoSwap does

LogoSwap, from Blace Plugins, is an After Effects plugin that finds a logo in footage and swaps it for another or removes it, without manual tracking. It is powered by blace.ai and aimed at rebranding content.

New logos can be inserted into the footage after removal. A CUDA memory sharing option speeds rendering above 4K on CUDA hardware, and a Stop Processing button cancels long computations immediately. It supports After Effects 2024, 2025 and 2026, and a realtime version is available at logoswap.ai.

Key features

  • Replaces logos without manual tracking
  • Inserts new logos into footage
  • AI removal powered by blace.ai
  • CUDA memory sharing for 4K+ renders
  • Stop Processing button
