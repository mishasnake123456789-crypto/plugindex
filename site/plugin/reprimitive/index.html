What Reprimitive does

RePrimitive is a Blender plugin for revisiting primitive shapes after you have created them. Normally the options for a cube, cylinder or sphere disappear once you move on, but here you can tweak the object data without recreating it.

It works regardless of the object's location and rotation, even after those transforms were applied, and modifiers that have not been applied are carried over. Handy for blockouts where proportions keep changing.

Key features

  • Edit primitive settings after creation
  • Works with applied location and rotation
  • Keeps unapplied modifiers
  • No need to recreate the object
