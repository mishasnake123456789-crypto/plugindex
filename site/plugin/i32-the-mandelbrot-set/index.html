What i32 the Mandelbrot Set does

i32 the Mandelbrot Set is a curiosity and teaching tool for Blender. It calculates a basic Mandelbrot set purely with 32-bit integers, using Integer Math and Bit Math nodes, with each number held as a mantissa, exponent and sign.

Custom nodes handle addition, subtraction, multiplication and power of two, along with overflow and sign control. Results display as a mesh, points, or pixels made from cube instances. It uses the Bit Math node from Blender 4.5 LTS and comes with a tutorial video, useful for fractal imagery and for learning how floating point works.

Key features

  • Mandelbrot set from 32-bit integers only
  • Mantissa, exponent and sign number format
  • Custom add, subtract and multiply nodes
  • Mesh, Points and Pixels display modes
  • Tutorial video included
