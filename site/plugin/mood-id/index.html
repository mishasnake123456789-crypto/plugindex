What Mood-Id does

May3D's Mood-Id applies carefully chosen color palettes to Blender scenes. Selecting one sets up lighting that brings realism and depth.

Over 270 presets are grouped in themes and styles, with an icon gallery for browsing. A custom image option derives a palette from a photograph, and a detailed panel allows precise adjustment. Palettes span natural, urban and stylized lighting. Artists seeking quick atmosphere in a render can try many looks fast. Presets can be browsed visually, so finding an atmosphere is faster than adjusting light colors by guesswork.

Key features

  • 270+ presets in themes and styles
  • Icon gallery browser
  • Palette from a custom photo
  • Detailed adjustment panel
  • Natural, urban and stylized lighting
