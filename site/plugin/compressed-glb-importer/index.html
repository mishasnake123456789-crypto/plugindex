What Compressed GLB Importer does

Compressed GLB Importer, by Wiffzackius, opens glTF binary models that use Meshopt compression or quantization, which Blender's built-in importer may not read. It does the decoding with standalone Python.

The add-on asks for no special permissions inside Blender, requires Blender 4.2 LTS or newer and installs by drag and drop. It is practical for artists who download web-optimized models and want to inspect or edit them in Blender.

Key features

  • Loads Meshopt-compressed and quantized GLBs
  • Runs on standalone Python
  • No special Blender permissions
  • Requires Blender 4.2 LTS or newer
  • Drag-and-drop install
