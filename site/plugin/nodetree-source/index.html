Turns Blender material node trees into Python code and stores them in a built-in material library.

What Nodetree Source does

NodeTree Source converts a material's node tree into Python source code. It is built for add-on and script authors as well as shader artists who want to pass materials around as reproducible code.

A Material to Text button prints the generated script in the Text Editor, and running that script rebuilds the same material in any other project. The code can be embedded straight into your own add-on to ship materials with it. A separate Material to Library button saves the source to a local library so that materials are ready to reuse later.

Key features

  • Material to Text code generation
  • Run Script recreates the material elsewhere
  • Generated code embeddable in add-ons
  • Local library for saved material sources
