Applies a non-destructive Geometry Nodes sweep to any mesh or curve through Blender's modifier stack.

What Sweep Modifier does

Sweep Modifier is a Blender plugin that adds a sweep effect to meshes and curves without changing them permanently. It imports a ready-made node group and applies it, so you do not build the nodes yourself.

Everything is controlled from the usual modifier stack, with the node group coming from a local .blend file. It is a quick way to add swept profiles to paths and objects. Because the effect stays live in the modifier stack, the path and settings can be adjusted at any time without rebuilding geometry.

Key features

  • Non-destructive Geometry Nodes sweep
  • Works on meshes and curves
  • Automated node group import
  • Controlled in the modifier stack
