Object and collection visibility filters in Blender for versioning production scenes, working with linked files.

What Visibility Set Filters does

Visibility Set Filters supports version management in production by letting you toggle sets of content through simple filters. They apply to objects, such as geometry, cameras and lights, or to collections following normal inheritance.

Viewport and render settings are independent, so what you see can differ from what renders. The filters work with the asset browser and remain reachable when a file is linked into another, where library overrides change them. They also work in the Video Sequence Editor. It suits pipelines with several shot or asset versions.

Key features

  • Filters for objects or collections
  • Separate viewport and render settings
  • Asset browser compatible
  • Accessible in linked files via overrides
