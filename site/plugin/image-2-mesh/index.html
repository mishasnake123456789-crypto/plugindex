What Image 2 Mesh does

Image 2 Mesh is a Blender add-on that builds mesh geometry out of image files. It suits concept art, visual effects and photo-mapping work, where a flat picture needs to become something you can model around inside the 3D scene.

A UV projection is set up automatically and stays live while you edit, so textures keep lining up. You can drive color through vertex colors, treat RGB as alpha through the preferences, and process several images in one go. Alpha-border dilation helps keep edges clean around transparent areas.

Key features

  • Converts images to mesh geometry
  • Automatic UV projection that stays live
  • Vertex color mode and RGB-as-alpha option
  • Batch processing of multiple images
  • Alpha-border dilation for cleaner edges
