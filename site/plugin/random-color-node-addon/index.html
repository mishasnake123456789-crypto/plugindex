What Random Color Node - Addon does

Random Color Node by mod3d adds shader nodes written in the Open Shading Language to Blender. They give you several ways to produce random yet repeatable colors for varied materials.

The Rand pattern outputs pseudo-random values within a minimum and maximum range, while Wave creates a smooth color transition along a sine wave. 3Range builds on Rand with three separate ranges and adjustable weighting among them. A lighter edition includes only Rand with limited features. After installation, the node description is copied into the Text Editor, and documentation is included.

Key features

  • Rand pattern for random values in a range
  • Wave pattern for smooth sine-based color shifts
  • 3Range pattern with three ranges and custom distribution
  • Written in OSL
  • Light version and documentation included
