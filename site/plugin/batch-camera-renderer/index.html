What Batch Camera Renderer does

Batch Camera Renderer lets you store viewpoints as shots and render them together. A panel in the 3D viewport manages them, with names like Shot_001 and Shot_002.

The Create button captures the current viewport perspective or the active camera position, and focal length and depth of field can be adjusted per shot. Each output is written to its own automatically named file. Product and archviz artists can produce a set of angles quickly.

Key features

  • Camera positions saved as named shots
  • Capture from viewport or active camera
  • Focal length and depth of field per shot
  • Automatically named output files
