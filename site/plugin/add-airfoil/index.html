What Add Airfoil does

Add Airfoil is a Blender add-on from Nerk that reads airfoil dat files and brings the profile into your scene as mesh. It adds an Add Airfoil entry to the File, Import menu and supports the Selig dat format.

It forms part of a larger project offering a Geometry Nodes toolset for printable RC model planes, so it is most useful to hobbyists and designers heading in that direction. It installs by drag and drop or from disk and requires no special permissions.

Key features

  • Imports airfoil dat files as mesh
  • Entry in the File > Import menu
  • Supports the Selig dat format
  • Part of a Geometry Nodes RC aircraft toolset
  • Requires no special permissions
