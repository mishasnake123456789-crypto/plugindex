A Premiere Pro extension that exports individual clips in one click with templated file names.

What Clips Exporter does

Clips Exporter makes cutting a sequence into separate files fast. One click exports each clip, instead of setting up every export by hand.

File names can use variables for project name, source item name, clip index and a counter, with settable digit counts. Preferences show system presets and user Media Encoder presets, encoding presets can be exported and imported, and disabled clips can be ignored. It works with Premiere Pro 2020 through 2026.

Key features

  • One-click export of single clips
  • File name variables including index and counter
  • System and user AME presets
  • Export and import of encoding presets
  • Filter to ignore disabled clips
