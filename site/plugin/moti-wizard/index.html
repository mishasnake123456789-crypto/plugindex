What MoTi-Wizard does

MoTi-Wizard is a CEP extension by Ti Nyain that links After Effects to Illustrator and Photoshop revisions. It updates artwork that is already animated at the playhead and replaces a source file without recreating the AE layer.

Double-clicking a selected layer opens its original Illustrator or Photoshop file, and Photoshop redraws can be captured as snapshot keyframes. Normal mode keeps the Illustrator source workflow for fidelity and layer order, while Shape mode imports artwork as editable shape layers with path control. Motion designers handling revision-heavy projects and teams wanting a compact PS/Ai-to-AE bridge benefit most.

Key features

  • Updates animated Illustrator art at the playhead
  • Replaces Photoshop or Illustrator sources in place
  • Double-click to open the original file
  • Photoshop redraws captured as snapshot keyframes
  • Normal and Shape import modes
