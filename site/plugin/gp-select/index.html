What Gp Select does

Gp Select is a Blender add-on by HissatsuClaw aimed at Grease Pencil artists who build cut-out or puppet-style animation. Pick a stroke, then run an action on the layer that contains it instead of hunting through the layer list.

Actions include jumping to that stroke's layer, isolating strokes for weight painting while selecting the parented armature, and sending layers or groups to the top, bottom or relative positions. You can also mask, hide, rename, duplicate, delete or group layers based on the strokes you have selected.

Key features

  • Switch to the layer holding the selected stroke
  • Isolate selected strokes for weight painting
  • Reorder layers and groups from a stroke selection
  • Mask, hide, rename, duplicate or group layers by selection
  • Selection by name prefix, infix or suffix
