What Code Completer does

Writing Python inside Blender's text editor usually means typing everything by hand. Code Completer brings the console's autocomplete into that editor and presents suggestions in a style borrowed from VSCode.

Suggestions appear as you type, modules used in the script are imported automatically to feed the hints, and a single line can be run in the console to complete it. The Blender console must stay open for the add-on to work. Text colors and other interface details can be customized, making it useful for add-on developers and technical artists scripting in Blender.

Key features

  • Console autocomplete in the text editor
  • VSCode-style suggestion list
  • Auto-imports script modules for hints
  • Suggestions on every text input
  • Customizable interface colors
