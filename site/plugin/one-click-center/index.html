What One Click Center does

One Click Center, by Jinhwan Yu, is a small After Effects utility that does one job: it moves layers to the middle of the composition. Instead of typing position values or using align controls repeatedly, you select the layer and click.

Several selected layers can be centered at the same time, which is handy for motion graphics and PV projects that stack many shape layers and text layers. It cuts out the repetitive manual position adjustments that add up over a long project. The tool is compatible with After Effects versions from CC 2019 up to 2025.

Key features

  • Centers a layer with one click
  • Handles multiple selected layers together
  • Removes repetitive position adjustments
  • Works with After Effects CC 2019 to 2025
