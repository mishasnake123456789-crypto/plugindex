What Udon Custom Node Builder [Beta] does

UDON Custom Node Builder is a beta Blender add-on that converts node groups into real custom nodes. It works for Geometry, Shader and Compositing node trees and requires no code.

Node groups can be converted with a click and back to plain groups again. Inner node properties can be exposed in a custom node interface. Technical artists can package tools into friendlier nodes. Wrapping logic into a tidy node with its own controls makes complex setups easier to reuse and share with less technical colleagues.

Key features

  • One-click node group to custom node
  • Geometry, Shader and Compositing support
  • Expose inner properties in a custom UI
  • Convert back to plain groups
