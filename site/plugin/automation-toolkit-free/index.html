What Automation Toolkit Free does

Automation Toolkit Free lets After Effects artists create their own buttons that perform whatever sequence of tasks they need. It combines actions on layers, compositions, projects, renders and files, replacing repetitive manual steps.

Layer actions include precomposing, duplicating, moving the anchor point, adding markers or effects and setting properties. Comp and render options cover queue and output module settings, sending to Media Encoder and applying render templates. It can retime, offset and copy keyframes, run JavaScript with variable inputs, read CSV data from Google Sheets or Excel, and open file and folder dialogs.

Key features

  • Custom buttons with chosen actions
  • Layer, comp, project and render actions
  • Keyframe retime, offset and copy
  • JavaScript with variable inputs
  • CSV data from Google Sheets or Excel
