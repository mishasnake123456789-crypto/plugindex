What Cryptomatte Tools does

Cryptomatte Tools simplifies Cryptomatte compositing in Blender. You pick objects or materials for Cryptomatte nodes without selecting them in the Compositor, even if they are not visible in the current frame.

It renders Color ID maps with transparency support for partially transparent shaders that use alpha, updates the Cryptomatte ID in all nodes automatically when an object or material is renamed, and refreshes the Render Result as needed. This saves time when isolating elements for color and effects work.

Key features

  • Pick objects or materials for nodes
  • Color ID maps with transparency
  • Auto-updated IDs on rename
  • Includes objects off-screen
