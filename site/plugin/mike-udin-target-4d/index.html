What Mike Udin Target 4D does

Mike Udin Target 4D places objects directly on the surface of other geometry. Select what you want to place, click on a surface, and the object is moved or copied there.

Hotkeys switch between active objects, and advanced copy modes scatter copies randomly, along a line or by a grid. An interactive interface adjusts brush size and grid shape, while a Bounding Box option detects object dimensions for correct placement. It is a quick way to dress scenes with props, plants or details without precise manual positioning.

Key features

  • Move or copy objects onto any surface
  • Random, line and grid copy modes
  • Hotkeys to switch active objects
  • Interactive brush size and grid shape
  • Bounding Box option for dimensions
