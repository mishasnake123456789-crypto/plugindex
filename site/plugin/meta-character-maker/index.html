What Meta Character Maker does

Meta Character Maker, by Daniel F.R. Gordillo, builds base meshes for characters out of mirrored metaballs. The approach is loosely based on the zSpheres workflow from ZBrush, so blobs of volume merge into a smooth, organic form that serves as a starting point for sculpting.

A library covers dinosaurs, insects, humanoids and Cthulhu. Output can be an array of metaballs or a polygonal base mesh, and separate versions exist for Blender 2.79 and for 2.80 and up. Documentation is included under a GPL license. Sculptors who want quick creature bases will find it a time saver.

Key features

  • Base meshes from mirrored metaballs
  • Library of dinosaurs, insects, humanoids and Cthulhu
  • Metaball array or polygonal mesh output
  • Versions for Blender 2.79 and 2.80+
