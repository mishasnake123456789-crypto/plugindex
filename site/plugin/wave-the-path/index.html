What Wave The Path does

Wave The Path by François Lefebvre converts any path in After Effects into an animated waveform. Processing happens on the GPU, and the plugin works with After Effects 2020 through 2026.

Trim Paths can be set by percentage or by an effector mask, and a Taper control shapes the stroke with separate start and end widths and lengths. Together these make flowing lines, audio-style visuals and stylized ribbons easy to produce. Motion graphics artists who work with animated paths gain a quick way to add oscillation to them.

Key features

  • Turns any path into waveform motion
  • Percentage or effector mask trimming
  • Taper with independent start and end width and length
  • GPU-accelerated
  • Works with After Effects 2020-2026
