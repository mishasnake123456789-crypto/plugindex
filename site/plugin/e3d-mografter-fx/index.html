What E3D Mografter FX does

E3D Mografter FX adds Mograph-style control to Video Copilot's Element 3D inside After Effects, which is required. Cloner, Fracture and MoText generators each work with an Effector layer you move in 3D space.

The Effector animates clones, sub-parts of a model, or extruded letters and paths. Six ready scenes cover Cloner in Linear, Radial, Grid Array and 3D Object modes, as well as Fracture and MoText, and you can swap in your own default objects. Parameter names match the ones in Cinema 4D's Mograph module, and a 50-page guide is included. Particularly handy for artists coming from Cinema 4D.

Key features

  • Cloner, Fracture and MoText generators
  • Movable Effector layer in 3D space
  • Six pre-built Element 3D scenes
  • Cinema 4D-matching parameter names
  • 50-page user guide
