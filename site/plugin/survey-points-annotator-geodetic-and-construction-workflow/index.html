What Survey Points Annotator - Geodetic & Construction Workflow does

Survey Points Annotator is a Blender add-on for geodetic, construction and civil engineering work. It places geometry markers and text labels over survey points so measured data can be inspected inside a 3D scene.

Five marker types are available: circle, sphere, triangle, cross and cross with circle, each adjustable for size, color, line width, rotation and subdivisions. Labels can show the vertex index with 1-based numbering, the object name and the X/Y/Z coordinates, with adjustable font, size, offset, rotation and color. Surveyors and engineers can use it to check and present point data visually.

Key features

  • Five customizable marker types
  • Labels for vertex index, object name and XYZ
  • Adjustable font, size, offset and color
  • Selection modes for annotating vertices
