What Browser Scroll Resize does

Browser Scroll Resize is a Blender add-on by Barrunterio that lets you change the size of content in the file browser by holding Alt and scrolling the mouse wheel. Thumbnails grow or shrink in the Asset and File Explorer, and in the Asset Browser's horizontal list the columns widen or narrow.

The shortcut is registered under Blender's Interface category. It is compatible with Blender 4.2 LTS and distributed under the GNU GPL v3 or later. Anyone browsing big libraries of assets will find the faster resizing handy.

Key features

  • Alt+scroll resizing in the file browser
  • Thumbnail size in Asset and File Explorer
  • Column width in the Asset Browser
  • Registered under the Interface category
  • Compatible with Blender 4.2 LTS
