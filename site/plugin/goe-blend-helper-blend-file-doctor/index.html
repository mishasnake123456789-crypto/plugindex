What Goe Blend Helper - .Blend File Doctor does

GOE Blend Helper acts as a file doctor for .blend projects. From one N-panel it scans for missing textures, duplicate materials, unused data, mesh issues, broken naming and export blockers.

A File Health Dashboard reports file size, texture memory, orphan data, simulation cache size, potential savings and an overall Health Score. Smart cleaning and packaging tools help fix what it finds. Good for tidying projects before archiving, sharing or delivery.

Key features

  • File Health Dashboard with Health Score
  • Finds missing textures and duplicate materials
  • Detects orphan data and mesh issues
  • Cleaning and packaging from one N-panel
