What Face Cutter does

Face Cutter is a modeling aid for slicing faces, including ngons, with precise lines in Blender. You choose how many divisions you want and cut using snapping points rather than eyeballing a knife.

Lines can be perpendicular or rotated, defined by two points, set by angle, or aligned to a nearby element. The cut can pass through the whole mesh using Blender's Knife projection API, optionally restrict it to linked faces. Hard-surface modelers and retopology artists can use it to add clean edge loops where needed.

Key features

  • Cuts ngon faces using snapping points
  • Set a custom number of divisions
  • Perpendicular or rotated cut lines
  • Cut through entire mesh via Knife projection
  • Option to limit to linked faces
