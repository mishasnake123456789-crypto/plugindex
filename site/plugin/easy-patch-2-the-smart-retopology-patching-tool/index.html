What Easy Patch 2 - The Smart Retopology Patching Tool does

Easy Patch 2 lets you sketch a patch boundary at will in Blender and generate quad mesh from it. You control edge flow instead of depending on fully automatic retopology.

Click and drag to draw boundaries, with two to six per patch. Output uses only N-Poles and E-Poles, and you can change the pattern with T, rotate it and move pole position; pattern 0 yields tidy topology. Retopologists get predictable, hand-directed patches.

Key features

  • Draw patch boundaries freely
  • 2 to 6 boundaries per patch
  • Quads from N-Poles and E-Poles only
  • Change pattern, rotation and pole position
