What Master Shape Keys does

Master Shape Keys is a Blender plugin for organizing shape keys on complex characters and meshes. It tackles the clutter that builds up when you have dozens of expressions and corrective shapes.

It can split one key into several using vertex groups, combine keys with additive modes controlling how consecutive shapes open and close, and sync a key between objects. Keys can be arranged into folder-based collections, and merged keys can be baked for export. It is helpful for facial rigs and game-ready characters.

Key features

  • Generate per-vertex-group shape keys from one
  • Combine keys with additive modes
  • Sync shape keys between objects
  • Folder collections and baked merged keys
