What Simple Batch Render does

Simple Batch Render builds a Windows batch file for rendering. The script renders images from any number of .blend files and can be launched inside Blender or by double-clicking it on the desktop.

It detects where Blender is launched from and saves to the desktop by default, though both the .bat location and Blender install path are configurable. Each job gets a frame or range, with other settings left as in the blend file. The file can be opened in Notepad to view or disable jobs with rem, and it can serve as a basic render farm across several Windows machines.

Key features

  • Generates a .bat file for batch rendering
  • Runs from Blender or desktop
  • Per-job frame or range selection
  • Configurable file and Blender paths
  • Usable for a simple multi-machine farm
