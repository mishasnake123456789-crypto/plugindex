What Lightsaber VFX does

Lightsaber VFX lets you produce glowing blade effects entirely in Blender. It comes with a purpose-built rig, a masking system based on primitives and an automated render pipeline, so the whole workflow lives in a single application.

Lightsaber presets can be read from and written to the user data folder, and it is compatible with Blender 5.0.1. Fan filmmakers and compositors can add convincing blades to footage with less manual setup.

Key features

  • Custom lightsaber rig
  • Primitive masking system
  • Automated rendering pipeline
  • Preset files saved in the user data folder
