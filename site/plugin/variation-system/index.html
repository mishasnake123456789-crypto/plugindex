What Variation System does

Variation System by Budo3D manages alternative material setups on a single object. It is aimed at artists who want to compare looks or prepare several colorways without duplicating geometry.

Variations are added, applied and deleted from the Sidebar, and you can swap between them quickly. A variant can also be spread across random faces of the mesh, and all materials already on an object can be gathered as variants. Variant collections can be copied between objects, and Quick Export writes an FBX named from the project and object.

Key features

  • Swap between material setups on one object
  • Apply variants to random faces
  • Copy and paste variant collections between objects
  • Gather existing materials as variants
  • Quick Export to FBX
