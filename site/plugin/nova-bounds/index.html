What Nova Bounds does

Nova Bounds is a Blender add-on that draws a live bounding box around everything you have selected, making group edits easier than juggling individual objects.

You can compute the bounds from the overall extents, box centers or object origins, work in world space or aligned to the active object, and trade accuracy for speed. Dimensions can be adjusted directly using a pivot you pick, and hierarchy-aware selection helps when objects are parented. It suits layout, set dressing and any scene where several objects must be scaled or moved as one.

Key features

  • Interactive bounding box for multi-object selections
  • Bounds from overall extents, box centers or origins
  • Global or active-object orientation
  • Resize and reposition using a selectable pivot
  • Hierarchy-aware bound selection
