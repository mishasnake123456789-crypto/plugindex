What IconDock does

IconDock lets motion designers find icons without leaving After Effects. Search a very large library of icons, choose a result, and import it as PNG, SVG or a shape layer.

Colours can be customised before import. The workflow is light and fast, with no browser tabs or manual downloads. It supports After Effects 2020 through 2026. Designers working on UI animations, explainers, infographics, corporate videos and social content can drop in icons in seconds.

Key features

  • Search hundreds of thousands of icons
  • Import as PNG, SVG or a shape layer
  • Colour customisation before import
  • No browser tabs or manual downloads
