What Import Paint Brushes does

Import Paint Brushes is a Blender add-on by chsh2 that converts brush assets from other painting software into Blender brushes. It reads .abr, .gbr and .gih, .brushset and .sut files and makes them usable while texture painting, sculpting, vertex painting or drawing with Grease Pencil.

A File > Import entry takes multiple files in one go, and image utilities under the brush texture settings help adjust the imported textures. Artists who have large brush collections from other tools can reuse them inside Blender.

Key features

  • Converts brushes from other painting software
  • Reads ABR, GBR, GIH, brushset and SUT files
  • Covers texture painting, sculpting, vertex painting and Grease Pencil
  • Multi-file import from the File menu
  • Image utilities for brush textures
