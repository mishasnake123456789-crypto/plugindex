Blender UI add-on that opens a popup at the cursor to jump between sidebar tabs, with search and filtering.

What Quick Sidebar Switcher does

Quick Sidebar Switcher saves trips to the sidebar edge in Blender. A shortcut, Ctrl+Shift+A by default, opens a popup menu where the cursor is, letting you jump straight to any sidebar tab.

A built-in search finds tabs by name, and whitelist or blacklist filtering modes hide the tabs you never use. Custom layouts let you arrange the menu to suit your workflow, which helps when many add-ons have added panels to the sidebar.

Key features

  • Popup tab switcher at the cursor
  • Default shortcut Ctrl+Shift+A
  • Built-in tab search
  • Whitelist and blacklist filter modes
  • Custom layouts
