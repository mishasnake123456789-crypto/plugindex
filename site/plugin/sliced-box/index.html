What Sliced Box does

Sliced Box produces the popular effect of a box split into moving slices, built from any footage or layer in After Effects. A single click sets up the animation, and every control stays keyframable.

Controls are organized as a pseudo effect, and animation presets store keyframes, values and expressions so they can be reapplied instantly. Presets adapt position and scale to the new comp size and can be imported or exported as one file. Twenty-five ready-made presets are included, helpful for title sequences and promos.

Key features

  • One-click animated 3D sliced box
  • Fully keyframable controls
  • Works with any footage or layer
  • Presets save keyframes, values and expressions
  • 25 bundled presets
