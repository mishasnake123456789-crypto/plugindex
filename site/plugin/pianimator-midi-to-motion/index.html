What Pianimator - Midi To Motion does

Pianimator turns musical data into motion. Import a MIDI file and it generates keyframes for a piano rig, working with any rig that follows standard note naming.

Piano tracks are detected automatically, with a manual override for multi-track files. A one-click installer downloads and configures FluidSynth within Blender, and the add-on renders .wav audio from the MIDI, auto-synced and placed in the Video Sequencer. Musicians, educators and animators making performance videos can avoid hand-keying notes.

Key features

  • Keyframed piano animation from MIDI
  • Automatic piano track detection
  • One-click FluidSynth installer
  • Integrated .wav audio rendering from MIDI
  • Works with any rig using standard note names
