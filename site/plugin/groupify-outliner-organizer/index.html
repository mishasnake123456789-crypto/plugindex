What Groupify - Outliner Organizer does

Groupify helps maintain order in complex Blender scenes. It provides batch renaming, mesh grouping and outliner organization tools, letting you choose which objects get processed so only the selection is affected.

Naming can change case to lowercase, uppercase, title case or capitalized during batch renaming and grouping. Collections can receive random colors on their icons when meshes are grouped, which makes them easy to tell apart, and the batch rename panel displays how many objects are queued for renaming. Artists inheriting messy files or working on large scenes will find cleanup less tedious.

Key features

  • Selective batch renaming and organization
  • Case options: lower, upper, title, capitalize
  • Random colors for collection icons
  • Shows count of objects to rename
