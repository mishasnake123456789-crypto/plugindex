Visual node palette for Blender's Geometry Nodes editor with search, favorites, recents and drag-and-drop placement.

What Node Deck does

Node Deck replaces the usual Add menu in the Geometry Nodes editor with a browsable palette. You can look through nodes, search them, mark favorites and drop them into the graph.

The deck can stay fixed on screen or appear as a popup via a configurable hotkey, and an option keeps it open after each drop. Favorites keep their original group colors, recents update on their own, and search works inside those tabs too. It makes building node trees faster for people who find the menus slow.

Key features

  • Fixed palette or popup with hotkey
  • Drag-and-drop node placement
  • Favorites and Recents tabs
  • Live search filtering
  • Option to keep the deck open
