What Falloff Lens - Proportional Editing Influence Visualizer does

Falloff Lens shows what proportional editing is about to affect, before you commit the move, scale or rotation. A gradient from cold to hot indicates how strongly each area will respond, from faint outer regions to the strong zone around the selection.

It works in Mesh Edit Mode across vertices, edges and faces, and in Object Mode across visible object origins. A radius boundary, optional face tint and bounding boxes make the area clear, and the radius can be changed interactively with Ctrl+Alt+R. The preview is a non-destructive overlay and has throttling and limits to keep large scenes responsive. Organic and environment modelers benefit most.

Key features

  • Real-time influence preview before transforming
  • Cold-to-hot falloff gradient
  • Mesh Edit Mode and Object Mode support
  • Interactive radius adjustment with Ctrl + Alt + R
  • Refresh throttling and vertex/object limits
