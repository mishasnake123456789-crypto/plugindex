Caps Blender's viewport frame rate to reduce GPU and CPU load on laptops and passively cooled machines.

What B- Fps Limiter does

B- FPS Limiter throttles Blender's draw loop so the 3D viewport does not run at full speed all the time. This lowers GPU and CPU load while navigating, which helps laptops and fanless computers stay cool and quiet.

A tab in the 3D Viewport sidebar turns the limiter on or off and sets the target FPS, while global startup preferences store a default state and frame rate across restarts. Highlights cover N-Panel toggle and target FPS and reduces GPU and CPU load while navigating.

Key features

  • N-Panel toggle and target FPS
  • Reduces GPU and CPU load while navigating
  • Persistent startup preferences
