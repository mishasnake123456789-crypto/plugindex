What Node Arrange does

Node Arrange tidies messy node networks in Blender. With a single click it positions, organizes and aligns nodes, whatever the size of the tree, using layout settings you can adjust.

The controls live in the Node Editor sidebar under Arrange. Ctrl+Shift+A (Cmd+Shift+A on Mac) arranges the selected nodes, and Alt+G recenters them. No special permissions are required. Shader, geometry node and compositing artists who build large graphs will find them far easier to read and share.

Key features

  • One-click node tree layout
  • Works on trees of any complexity
  • Adjustable layout settings
  • Keyboard shortcuts for arrange and recenter
