What Battle Axe Anubis does

Battle Axe Anubis is a single export and render panel for After Effects and Premiere Pro. It combines file naming tokens that can build folders from the file name string with background rendering and a Send to App option.

After Effects users can export several comps at once, with all output modules supported when not compressing. Compression offers editable quality settings, resize-to-width and a progress footer. Premiere Pro users get an export preset selector for custom EPRs. A metadata property stores the project path for viewing in Bridge, and the panel announces updates.

Key features

  • Naming tokens with dynamic folder creation
  • Background render and Send to App
  • Multi-comp export in After Effects
  • Compression with resize-to-width
  • Export preset selector for custom EPRs in Premiere Pro
