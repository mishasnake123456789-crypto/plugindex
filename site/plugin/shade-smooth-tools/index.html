What Shade Smooth Tools does

Shade Smooth Tools is a tiny Blender add-on that puts two buttons in a UI panel. One applies Shade Smooth and switches Auto-Shade-Smooth on, the other applies Shade Flat and switches it off.

Both work on one or several selected objects and can be used in either direction, so toggling between smooth and flat looks takes a single click. Documentation is included. Modelers who constantly alternate shading modes will appreciate skipping the menu hunting.

Key features

  • Shade Smooth button enables Auto-Shade-Smooth
  • Shade Flat button disables it
  • Works on multiple selected objects
  • Documentation included
