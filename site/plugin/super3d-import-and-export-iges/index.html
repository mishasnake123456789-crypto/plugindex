What Super3D Import & Export .Iges does

Super3D Import & Export .Iges opens and writes IGES CAD files in Blender with dedicated File menu entries. Conversion runs on the Super3D cloud service, keeping Blender lightweight.

On import, NURBS surfaces are tessellated into clean polygon meshes and assembly hierarchy is preserved where present. Product designers and engineers can bring CAD parts into Blender for rendering and presentation. In practice that means file menu entries for IGES import and export and cloud conversion via Super3D.

Key features

  • File menu entries for IGES import and export
  • Cloud conversion via Super3D
  • NURBS tessellated to polygon mesh
  • Assembly hierarchy preserved where present
