What Stability does

Stability for Blender is an officially supported add-on that connects the Stability SDK to Blender. It adds Stable Diffusion based post-processing effects to renders and generations.

Images and textures can be generated through an image editor integration, with parameters that can be keyframed. It gives artists a way to stylize frames or produce texture ideas without leaving the software. The feature set spans official Stability SDK access and stable Diffusion post-processing for renders.

Key features

  • Official Stability SDK access
  • Stable Diffusion post-processing for renders
  • Texture and image generation in the Image Editor
  • Keyframe support
