Blender add-on that merges objects into non-destructive collection-instance groups with nested, live-updating subgroups.

What Grouppro does

joseconseco's GroupPro treats sets of objects as groups backed by instanced collections. Objects combine into one container non-destructively, and any instance in the scene is editable.

Groups nest: construct a group from subgroups and edit one, and all its instances update in real time. Mirroring of groups is handled, avoiding Blender's own instance mirror bug, and you can change a group's origin or apply transformations without disturbing its content. Level builders reuse complex assemblies this way.

Key features

  • Non-destructive grouping with instance collections
  • Recursive nested groups
  • Real-time updates to all instances
  • Mirroring that fixes the instance bug
  • Change group origin safely
