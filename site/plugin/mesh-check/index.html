Real-time topology validation in the Blender viewport flagging n-gons, open edges, loose geometry and flipped normals.

What Mesh Check does

Mesh Check validates topology in the viewport with color-coded overlays. N-gons show in orange, open edges in cyan, coincident vertices in red with live counts, loose geometry in yellow and inconsistent normals in purple, plus non-applied scale.

Each issue can be fixed in one click. Modelers get immediate feedback while working instead of running separate checks. Highlights cover color-coded overlays, live counts of coincident vertices, flipped-normal detection and one-click fixes.

Key features

  • Color-coded overlays
  • Live counts of coincident vertices
  • Flipped-normal detection
  • One-click fixes
