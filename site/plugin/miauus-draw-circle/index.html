What miauu's Draw Circle does

Draw Circle, by miauu, fixes a limitation of 3ds Max's built-in Circle shape: the number of knots cannot be chosen. This script creates a circle with exactly the number of knots you specify and a radius you set.

The circle is placed at the center of the world. Drag miauuDrawCircle_01.ms onto a viewport to install it, and it will show in Customize User Interface under miauu. It works with 3ds Max 2014 and later. Having control of knot count is useful when circles are used for lofts, sweeps, or as the base for clean topology and deformation.

Key features

  • Circle with an exact number of knots
  • Settable radius
  • Created at the world center
