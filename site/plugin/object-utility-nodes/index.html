What Object Utility Nodes does

Object Utility Nodes, by Bitsqueezer, adds custom node editors to Blender and makes it easy to integrate custom node classes into the editor. The bundle includes a Number Node that outputs a float value, an Object Selector Node and an Object Target Node.

It also builds harmonic color sets (complementary, triad and analogous) and lets you steer the base color, angle and color space dynamically. Technical artists and add-on developers can use it as a base for custom node-based tools.

Key features

  • Easy setup of custom node editors
  • Number Node for float output
  • Object Selector and Object Target nodes
  • Complementary, triad and analogous color harmonies
  • Live base color, angle and color space controls
