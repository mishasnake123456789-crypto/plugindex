What KeenTools GeoTracker does

GeoTracker is a 3D tracking plugin for After Effects from KeenTools, billed as the first of its kind in that application. It follows an object or camera using geometry, so a 3D model can be matched to a moving object in footage.

You place and move the model with pins in the ordinary 2D viewport, without extra windows or gizmos. Cameras with unknown focal length can have it estimated, models can be aligned to objects or cameras, and video-based texturing is available. The 3D scene can be exported as an Alembic file.

Key features

  • Geometry-based object and camera tracking
  • Pin-based model placement in the 2D viewport
  • Focal length estimation
  • Video-based texturing
  • Alembic scene export
