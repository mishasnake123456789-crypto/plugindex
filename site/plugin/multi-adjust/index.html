What Multi Adjust does

Multi Adjust by Brrainz groups common alignment tweaks into a single panel so you do not repeat them element by element. It works across a number of objects, mesh elements or curve points simultaneously.

A click can match the location, rotation, scale or origin of all selected objects; you can also toggle between local and world space, and flatten or line up mesh selections and curve handles. It helps modelers and layout artists tidy up scenes and meshes quickly.

Key features

  • Match location, rotation, scale or origin in one click
  • Local and world space switching
  • Flatten or align mesh selections
  • Align curve handles
  • Works on objects, mesh elements and curve points
