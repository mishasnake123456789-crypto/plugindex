What Node Orthogonalizer does

Node Orthogonalizer, by 孤语, reroutes the links between nodes so they follow right angles, which keeps large node graphs neat. It is listed under Node.

It is open source under GPL-3.0-or-later and needs Blender 5.2.0 or newer.
