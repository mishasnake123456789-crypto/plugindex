What Pivot Transform 5 + Gizmo/Save 3D Cursor does

Pivot Transform 5 changes pivot (origin) positions and the 3D cursor in Blender. A pivot can be aligned to a polygon's normals, then moved and rotated.

BBox moves the pivot to bounding-box points, Pivot Flow follows a Maya-like approach, and Pivot Drop moves it relative to selected items. Pivot Save and 3D Cursor Save panels store positions for reuse, and a gizmo helps with transforms. Modelers and riggers setting up rotation points can do so precisely.

Key features

  • Align pivot to polygon normals
  • Bounding-box pivot placement
  • Maya-like Pivot Flow
  • Save and recall pivot and cursor positions
