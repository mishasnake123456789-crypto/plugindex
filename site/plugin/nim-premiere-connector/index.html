What NIM Premiere Connector does

NIM Premiere Connector links Premiere Pro to NIM, a pipeline and studio management system. Editors can version projects, export sequences for review, and create and rename shots in NIM straight from a sequence.

Shots can be transcoded and After Effects files created during export, and NIM elements can be imported into bins. It fits studios that track shots and reviews in NIM. It keeps editorial and production tracking in step, so shot information does not have to be copied manually.

Key features

  • Project versioning
  • Export sequences for review
  • Create and rename shots in NIM
  • Transcode shots and create After Effects files on export
  • Import NIM elements into bins
