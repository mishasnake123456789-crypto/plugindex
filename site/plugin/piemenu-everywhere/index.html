What PieMenu Everywhere does

PieMenu Everywhere spreads radial menus throughout Blender, covering object mode, edit mode, node editors and animation windows. Frequently used commands are placed a short mouse flick away.

Pies are context specific and cover render engine, shading, applying object data, physics, extras, quick edits, and copy or link. Each has a default hotkey that can be customized. Artists who prefer gestures over menu hunting can speed up routine tasks across many editors.

Key features

  • Pie menus in many editors
  • Context-specific pies for shading and physics
  • Pie for copy and link operations
  • Customizable hotkeys
