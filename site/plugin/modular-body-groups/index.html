What Modular Body Groups does

Modular Body Groups manages interchangeable parts on a character. Objects can be added to and removed from a rig through a UI, so mesh components switch in and out to create variations of a selected object.

Tiers scale from 3 up to 100 body groups per object, and the Pro version adds animation of body groups and can turn them into animatable objects. Character artists making outfits, armor or customization options will switch parts without re-parenting.

Key features

  • Add and remove rig objects through a UI
  • Switch mesh components for variations
  • Tiers from 3 to 100 body groups
  • Pro animates body groups
