What Figaro - Fast Base Meshes does

Figaro is a Blender add-on by 3D Mage that builds base meshes for characters and creatures from simple skeleton-like input. Volumes are added around vertices, edges and faces, and forms are derived by blending the radii given to each vertex.

With stick figure modeling, the form comes from points and edges, and each edge blends between the radii of its neighboring vertices. In Edit Mode, Shift+R adjusts the radius of the selected vertices. Solid faces allow more complex shapes, and one-click voxelization turns the object into a voxel mesh ready for further sculpting.

Key features

  • Stick figure modeling with radius per vertex
  • Edges interpolate between neighboring radii
  • Shift+R changes radius in Edit Mode
  • Solid faces for complex shapes
  • One-click voxelization
