3ds Max plugin that locks .max scenes with a case-sensitive password and a list of trusted workstations that skip the prompt.

What EPassword does

EPassword protects .max scene files in 3ds Max with a case-sensitive password. Machine-based access controls let approved workstations open files while other computers must enter the password.

On trusted hardware the bypass can be silent, or it can show a File locked, access granted notice. The lock reactivates instantly on unrecognized machines. After a set number of wrong passwords the file closes, and machine names are matched without regard to case while passwords remain case-sensitive. It only needs installing on the machine that locks the file, which makes deployment simple. Studios and freelancers guarding proprietary assets are its audience.

Key features

  • Case-sensitive password protection for .max scenes
  • Trusted workstation list for bypass
  • Silent or prompted bypass on approved machines
  • Attempt limits that close the file
  • One-time install on the locking machine only
