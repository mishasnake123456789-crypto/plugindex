renderStacks

Developer: quasiKrystal

Free3ds Max
Download Free

Render pass and task manager for 3ds Max that sets up per-pass scene changes and submits jobs to Backburner or Deadline.

What renderStacks does

quasiKrystal's renderStacks manages render passes and other repeatable tasks in 3ds Max. Each pass gets a sequence of tasks, with no limit on passes per scene, and everything is configured through an artist-friendly interface that needs no scripting.

Pass modifiers can change the camera, resolution, materials, output, renderer or render elements. Objects can get different materials, transforms, alignment, visibility and display or render properties per pass, as can lights, atmospherics, exposure and environment. Jobs go to the farm through Backburner or Deadline. Simulation parameters can be saved with a pass to compare variations, or states like TurboSmooth toggled, reducing manual mistakes.

Key features

  • Unlimited passes with per-pass task sequences
  • Modifiers for camera, resolution, materials and renderer
  • Per-object and per-pass light and environment control
  • Backburner and Deadline submission
  • No scripting required
