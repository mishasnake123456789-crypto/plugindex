What miauu's Extended Clone Tool does

miauu's script builds on 3ds Max's own Clone Options dialog with extra settings. It applies when objects are copied with Shift+Drag, supplying options the stock dialog lacks.

New clones can be moved to a new layer or an existing one, and all of them can be selected automatically once created. Clones may be spaced at even intervals between the original and the first clone, with a total or incremental distance set between created objects. Naming can match the source objects. Artists who duplicate many items regularly will save steps otherwise spent on cleanup afterward.

Key features

  • Send new clones to a new or existing layer
  • Auto-select all created clones
  • Even spacing between original and first clone
  • Total or incremental distance control
  • Name clones after their source objects
