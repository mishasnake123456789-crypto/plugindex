After Effects script that splits a text layer into separate layers per character, word or line.

What DecomposeText does

DecomposeText is nab's After Effects script for dividing a single text layer into many. You choose to split by character, word or line on each run, so every piece can be animated, styled or positioned independently.

Two placement approaches are offered. With expressions, new layers keep the original text with some parts hidden, so they hold their exact original positions. Without expressions, each new layer contains just one character, word or line and positions are approximated. The script runs on After Effects versions from CS6 through 2025.

Key features

  • Splits text by character, word or line
  • Exact positions kept using expressions
  • Approximate positions without expressions
  • Choose split level for each run
  • Works from CS6 to 2025
