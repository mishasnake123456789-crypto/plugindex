What Save & Recall Transform does

3DPRS's Save & Recall Transform keeps position, rotation and scale as reusable snapshots. Name them, update them or delete them, and apply one back to the same object or to a different object with a single click.

For camera work, save several angles and switch between them instantly; an object-specific toggle moves among stored states. Layout artists, product visualizers and anyone who experiments with placements can compare options without losing a good position.

Key features

  • Named transform snapshots
  • Rename, update and delete snapshots
  • Reuse on another object
  • Single-camera angle switching
  • Object-specific snapshot toggle
