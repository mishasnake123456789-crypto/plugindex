What Wonder Panel Pro does

Wonder Panel Pro is a Back to Earth Digital toolbar that gathers frequently used After Effects actions in one place. It aims to speed up routine tasks across color, alignment, keyframing and rendering.

The color palette targets fills and strokes on shape layers and preserves gradients. Align, anchor point and distribute tools respect animated properties and support Parametric Mesh layers. Ease It adds a hold keyframe toggle, and render functions can import image sequences afterward and queue multiple renders. Dynamic tooltips show current settings, with a compact TinyTips mode, and non-English installations work.

Key features

  • Gradient-safe color palette for fills and strokes
  • Align, anchor and distribute tools
  • Ease It keyframe tool with hold toggle
  • Render queueing with sequence import
  • Dynamic tooltips and TinyTips mode
