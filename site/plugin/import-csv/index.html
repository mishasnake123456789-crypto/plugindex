Imports CSV data into a new Blender mesh as one vertex per row with named attributes per column.

What Import Csv does

Import Csv reads a CSV file into the point domain of a newly created mesh, generating one vertex per row. Each column becomes a Named Attribute, stored as float, along with a csv_data_row_index column.

An Export Random CSV button writes a 6x1000 file of random data for prototyping and testing. A CSV panel is added to the 3D view. It suits data visualization and procedural work with Geometry Nodes. Among its capabilities are one vertex per CSV row, named attribute for each column and random CSV export for testing.

Key features

  • One vertex per CSV row
  • Named attribute for each column
  • Random CSV export for testing
  • CSV panel in the 3D view
