What VRM format does

VRM format is an add-on by saturday06 that lets Blender read and write VRM files, a format used for avatar models. Besides transfer, it allows editing of VRM data within the scene.

It can add a VRM Humanoid and configure MToon shaders, and it exposes a Python API for automating tasks with scripts. Version 4.4.0 added a VRM0 material bind interface. VTubers, game developers and avatar makers can prepare characters in Blender and deliver files compatible with VRM-aware applications.

Key features

  • VRM import and export
  • Editing of VRM data in Blender
  • VRM Humanoid setup
  • MToon shader configuration
  • Python API for automation
