Blender add-on that makes 3D-printable personalized keychains from typed text and any TTF or OTF font in one click.

What Keychain Builder does

Keychain Builder generates ready-to-print keychains. Type your text, select a TTF or OTF font and click Create Keychain to receive a printable model.

The base shape follows the letter outlines using a metaball approach, creating a smooth, organic form rather than a plain rectangle. Fonts covering Cyrillic, Latin and numbers all work. Makers and print shops can produce custom name tags and gifts quickly.

Key features

  • Keychain created from typed text
  • Supports any TTF or OTF font
  • Metaball base that follows the letter outlines
  • Handles Cyrillic, Latin and number characters
